# Owen 中译方案 —— 约翰·欧文《希伯来书注释》翻译规范

欧文注释中文翻译的**完整方案与执行规范**。翻译前必读。

**方法论(一句话)**:**机器一遍翻译(强提示)+ 免费自动处理(术语字典·全角标点·纲要整份翻)
+ 免费自扫 + 人工抽查定点修**。**不用 LLM 二遍审校**——实测净值为负(见 §6)。

本管线不走 `translate_filibi`, 走 `scripts/translate_owen.py`(已替换原加尔文 04)。

---

## 0. 依据(据华人改革宗译界翻译欧文的既定范式, 非拍脑袋)

- **译名**:**约翰·欧文**(John Owen), 清教徒、改革宗神学家。
- **术语权威**:**赵中辉《英汉神学名词辞典》**(基督教改革宗翻译社, 2400+ 词条)+ **和合本圣经**
  —— 改革宗出版社正是欧文中译本(《圣灵论》《治死罪》等)的出版方。
- **文风标杆**:改革宗出版社欧文译本 —— **文白相济、庄重典雅**, 句式可长(呼应欧文拉丁化长句),
  术语学院化、严肃。

---

## 1. 质量底线(对得起大师作品)

1. **忠实**:不增不删义, 不臆测; 被动/情态译准(designed→本当, ought→当), 勿臆加原文没有的「欲/使」。
2. **清晰优先**:文白相济但以清楚达意为先, 不为文雅而过度压缩到歧义或悬空代词。
3. **庄重书面**:清教文风; 忌真现代/口语词(力度、能量、搞、到位), 但**勿为文雅乱改本已正确的词**。
4. **术语精确且互不撞词**:不同英文词 → 不同中文。
5. **原文语种保留**:希腊/希伯来/叙利亚/拉丁原样保留 + 圆括号简短中文译义。
6. **零幻觉**:中文不得出现英文原文没有的专名/概念。

---

## 2. 翻译原则

### 2.1 忠实与清晰
- 忠实英文, 不增不删; 长句可切分但不走味。
- **清晰优先**:勿过度压缩(反例「它们本欲人全然归向」= designed to be gathered unto, 既歧义又臆加
  「欲」→ 应「本当使人全然归向」)。悬空的「它/它们/其」改回所指名词。
- **句式重组(关键)**:英文长句与相关结构(so far…as to、not only…but、although…yet、such…as)按
  **中文语序自然重组**, 勿照搬英文从句嵌套与插入语位置; 相关连词用一套中文对应句式
  (so far…as to→「…到…地步, 足以使…」), **不重复连词**(反例「足以…却足以」)、不用「——」硬切主谓;
  让步/原因插入语(though…because…)移入括号或另起分句。这是「so far…as to」被拆坏一类的根治。

### 2.2 文风
- 文白相济、庄重典雅, 呼应拉丁化长句。
- 忌真现代/口语词; 但圣经词汇一律照**和合本**(如「瘸腿」勿改「跛足」), 常用书面词(撩动、扶持等)保留,
  **不为求文雅而改动本已正确的词**。

### 2.3 术语(和合本 + 辞典为准, 作「指南」非「枷锁」)
- 经文、书卷、人名一律**和合本**; 教父/学者按辞典通行译名。
- **教派/异端/学派/历史人物**(Novatians/Arians/Origen 等): 用学界通用译名, **首次出现括注原文**
  (诺洼天派(Novatians)、亚流派(Arians)), 后续同名不再重复括注。
- 神学术语依「附录·术语参照」, 但**按上下文取舍, 不同英文词必须不同中文**(勿机械替换)。
- **authority 双义**:位格治权(基督/君王, ἐξουσία)→**权柄**(和合本); 圣经/正典本身的权威性→**权威**。
- **canonical**:作表语/单用(called canonical)→「正典」或「正典书卷」; 仅作定语修饰名词才用「正典的」。
- **表外术语**(附录没有的)降级取义:① 圣经词 → 和合本对应经文用词; ② 神学术语 → 辞典;
  ③ 专名 → 和合本/通行; ④ 其余 → 上下文取庄重书面词且不撞已定词; ⑤ 关键又拿不准 → 中文后括注
  英文(如「德能(virtue)」)+ 记入待定, **定夺后追加进附录**(术语表只增不改)。

### 2.4 原文语种与结构保真
- 希腊/拉丁/希伯来引文**只保留原文 + 必要简短括注**; **切勿在原文后擅加重复整句的中译**(最高频错误)。
- 保留所有脚注标记 `[^N]`、HTML 标签、`<p id="sec-N">` 锚点、段首编号。
- **纲要/目录(词条列表)整份一起翻**再按编号拆回(40 条互为上下文, 零幻觉且能区分近义词);
  **切勿**单条孤立翻(塌成同义词), 也**切勿**拿整段正文去翻短标题(诱导照段落改写→幻觉)。

## 3. 高频错误规避清单(据导论1 全审校 24 段改动提炼, 已剔除伪问题)

单遍翻译时务必规避以下真问题(已写入 `translate_owen` 的 `PLAN_GUIDE`):

- **A 勿增译(最高频)**:拉丁/希腊引文只留原文 + 必要简短括注, 勿擅加重复整句中译。
- **B 专名**:保罗(非圣保罗)、俄利根(非奥利根)、一律和合本; 勿逐处重复英文括注。
- **C 实词精准**:effects→所产生的、will→会/将、press→催逼、circumvent→诓骗蒙蔽、becometh→相称。
- **D 忌真现代词**:力度/能量/搞/到位 → 书面语; 但勿把本已正确的词(瘸腿/撩动/扶持)改「文雅」。
- **E 勿漏**:保留所有 `[^N]` 与原文标点, 不漏词句。
- **F 勿幻觉**:不擅加原文没有的概念(holy penmen ≠ 圣灵默示的)。
- **G 清晰/代词**:清晰优先勿过压; designed/ordained→本当、ought→当, 勿臆加「欲/使」; 悬空代词改回名词。

> 每次人工抽查发现新模式 → 补进本清单与 `PLAN_GUIDE`, 频率逐篇下降。

## 4. 工具与产物

- **入口**:`python3 -u scripts/translate_owen.py --page <英文页> --resume --publish`
- **中英并存**:中文出 `<英文页>/zh/index.md`, **绝不覆盖英文**; 英文页回填 `zh_url` → 切换 pill。
  见 [[project_owen_bilingual_structure]]。
- **只翻正文**:front matter / eyebrow 保留; `#`/`<h2>`/`<p id="sec-N">`/纲要 `<nav>` 按结构解析。
- **内建自动处理(免费, 每次输出自动应用)**:
  - `cleanup_terms` —— 术语字典:圣X使徒名去「圣」、标准译名归一(奥利根→俄利根 等)。
  - `normalize_punct` —— 中文标点全角化(，；：（）「」→"), 保护章节号冒号(43:24)与拉丁/希腊句内标点。
  - 纲要整份翻→按编号拆回; 剥 `<<<…>>>` 分批标记 artifact。
- **产物必存**:缓存 `owen_raw/hebrews/zh_cache/`(md5, **入 git**)、中文 raw
  `owen_raw/hebrews/zh_exercitations/N.md`(chmod 444)。重跑全命中缓存秒回。
- **模型**:质量优先。

## 5. 免费自扫(发布前, 不花 token)

发布前脚本自查(命中即定点修):
1. **中英混排**:中文紧贴 `[a-z]{3,}`、整段英文残留。
2. **artifact**:`<<<`、审校旁白泄漏(如「让我先给出…」)。
3. **漏译**:脚注 `[^N]` ref/def 配对; 纲目条数 = 正文锚点数、无悬空。
4. **口语词**:力度/能量/搞/到位 等黑名单。
5. **撞词候选**:同页 power/energy/efficacy/authority 是否各异(需人眼确认)。

> ⚠️ **语义清晰/保真类**(过度压缩、虚词译偏、指代不清)**免费脚本抓不了**——靠 §3 提示预防
> + **人工抽查**。对大师作品, 人校是标准且必要的一环。

---

## 6. 质量分工(为何不用 LLM 二遍审校)

| 谁 | 负责 | 手段 |
|---|---|---|
| 机器一遍翻译 | 90% 的忠实与文风 | 强提示(§1–3 + PLAN_GUIDE) |
| 免费脚本 | 术语字典、全角标点、纲要拆合、自扫 | cleanup_terms / normalize_punct / 自扫, **不花 token** |
| 人(用户) | 语义清晰/保真的最后一环 | 抽查 → 我定点修(便宜) → 模式补进 §3 |

**为何停用 LLM 二遍审校**:导论1 实测, 二遍审校 diff 58 段——真值(删增译/意义偏差/术语区分/补脚注)
可在一遍提示中预防; 其余多为主观换词(净值≈0)、可免费做的标点、**甚至制造新错**(过度纠正
瘸腿→跛足倒退、旁白「让我先给出译文」混入正文)。**烧 token 且净值为负, 故弃用。**

---

## 7. 执行流程

1. 一遍翻译(`translate_owen --review` **不再使用**;直接 `--resume --publish`, 内建自动处理)。
2. 免费自扫(§5), 命中定点修。
3. 用户抽查 → 定点修 → 新模式补进 §3 与 PLAN_GUIDE。
4. 逐篇推进(导论 40 + 卷首 8 + 正文 13 章); 中文上线后对比功能可加「对比欧文中译」源。
