# 中译译名规范（历代解经各书通用）

## 一、查证顺序（从上到下，上面的说了算）

1. **和合本**：圣经书卷、人名、地名、经文措辞一律照和合本（`scripts/scripture_tool.py` + `zh_cuv.json`）。
2. **改革宗翻译社 / 改革宗出版社的通行译法**：台湾改革宗翻译社（Taiwan Reformation Translation Fellowship，1940 年代由赵中辉与 Samuel E. Boyle 牧师创办）
   所出各书，其译名集中在赵中辉主编《英汉神学名词辞典》（改革宗出版社，1998，约 2,400 条）。
   ⚠️ 这本辞典是纸本、有版权，**本站没有它的电子词表**（2026-11-03 查过：网上无公开版）。
   不得凭印象写「改革宗出版社译作 X」——要引它，须用户提供书页或扫描，按条核对后再收进下面的定译表，并注明出处。
3. **本站定译表**（第三节）：用户已拍板的译名，优先于模型自己的选择。
4. **神学词汇网** https://shenxuecihui.com/ ：3 万余条术语与人名的「标准译名 + 异译」，人工逐条查用；
   站点不让程序抓取，也未注明数据来源，只作参考，不作权威。

## 二、通则

- **概念词全篇、全书一译**：每段是单独送模型的，模型看不到别段的选择，同一个词会漂成几种译法
  （2026-11-03 达文南特 intention 一篇里出现「意向 / 意图 / 旨意」三种）。关键术语必须写进提示词的术语表，不能指望「保持一致」这句话。
- **相近概念不得撞词**：intention（意图）≠ will（旨意）；decree（预旨）≠ purpose（定旨）……新书开译前先把本书的核心概念对列出来。
- **先意思对，再通顺，后文气**：直译生硬的要改成中文习惯说法（not to be frustrated → 必不落空，而非「不可受挫」）。
- **音译专名每篇首次出现括注英文原名**：人名、地名、**教派与主义名**、**著作名**都算（`scripts/sect_names.py` 程序兜底教派名；
  书名目前只靠提示词，2026-11-03 普查五书书名号后无原文约 1,500 处，多数待补）。原名取**本篇英文原文实际的拼法**，原文没有就不补，不编。
- **原书错处照印，另加编者按**：中文写成「……〔编者按：当作第 19 题〕……」，纯文字、不加标签（加标签会过不了翻译闸、触发重译）。
- **`&c.` 一律译省略号 ……**，不作「等等 / 云云」。

## 四、定了一个新译名之后要改哪几处（缺一处就会回退）

1. **本表**加一行。
2. **翻译提示词**：对应书的 `scripts/translate_<书>.py` 里 `SYSTEM`（或各书共用的术语段）加上这一对。
3. **已译内容**：中文页（`<书>/<卷>/zh/…`）+ 中文成品（`<书>_raw/<卷>/zh_chapters/`，chmod 444，改前放开写权限、改后复原）
   + **翻译缓存**（`<书>_raw/<卷>/zh_cache/*.txt`）三处同改——只改中文页，下次重发布会被缓存覆盖回去。
4. 改缓存后用该书的 `check_block` / `structural_diff` 复核仍合格，否则下次发布会触发重译。
5. 中英原文另有错字的，先看原书影像再改英文（落人工核定表），英文一变缓存键就变，要把旧键译文迁到新键。
