# 中译批次运行规范

## 一、铁律：翻译出问题，先停下

> 用户 2026-11-03：「翻译出问题，要先停下，解决问题，彻底解决完之后再继续翻译，不要随意乱翻。」

出现下列任一情况，**立刻停掉翻译**，不许边跑边修、不许「先跑完、被拦的篇排到后面再补」、不许接着开下一本书：

- 监视到 `⛔ [篇] 有段落重试后仍不合格`（篇被拦）；
- 同一类 `retry-struct` 在不同段反复出现（说明是系统性问题，不是偶发）；
- 抽查发现已写出的译文有错（漏译、自语、占位符错乱、空括号、术语前后不一……）；
- 额度用尽（exit 42）——这时进程已自己停，**不要**立刻排队重跑。

**停的做法**（缺一步就等于没停）：
1. `pkill -f "translate_<书>.py"`；
2. 停掉排队的等待脚本（`pkill -f "while kill -0"` 之类）；
3. 杀掉孤儿 claude CLI 子进程（父进程为 1 的 `claude … --system-prompt`）；
4. 确认 `pgrep -fl translate_` 为空，`.git/index.lock` 不存在。

## 二、彻底解决 = 找到这一类、修在源头、验证过

1. **查原因到「类」**：不是只看被拦的这一段——问「还有哪些段会因同一原因出错」。
   例：`probationē` → `probationem` 被判漏译，根因是判据只认 ASCII 字母，同类还有 `Excōmunicatio`、`mendaciū`、`vitâ`……
2. **修在源头**：判据 / 提示词 / 发布脚本，不改产物了事；同一套闸在
   `translate_jenkyn / taylor / attersoll / candlish`（以及 davenant 的 `check_block`）里一并修。
3. **回归验证（两条都要过才算修好）**：
   - 拿**全部已缓存译文**跑新旧判据，比对结论：新增误报必须为 0（误报会让已合格的段在重发时被重译）；
   - **注入测试**：随机抽几百块已有译文，往中文里插常见英文词（the / however / Keep / Translation / Italic……），
     新判据必须全部抓出（2026-11-03 这样查出斜体内漏译 84/397 全漏抓）。
4. **单独重跑被拦的那一篇**，确认 `✓ 写入` + `[autopublish] 已提交并推送`，再看一眼产物。
5. 修判据、提示词的提交与产物提交分开写清楚；把这次的根因记进本 skill 第四节。

全部做完，才恢复批次。

## 三、开跑与恢复

- **只跑 1 路**（`--jobs 1`，一次一本书）；多路、多本并行须用户当次明说。排队用等待脚本时按**进程号**等（`while kill -0 <pid>`），
  不要用 `pgrep -f "translate_… --section"`——等待脚本自己的命令行就含这串字，会永远等下去；取不到 pid 时不许启动（曾因此并发跑出第二个进程）。
- **去掉无关上下文**：调用一律走 `translate_filibi.call_claude → claude_usage.call_cli`，自动带
  `--safe-mode --strict-mcp-config --disallowedTools '*'` + `--system-prompt`（不发工具定义、MCP、CLAUDE.md、skills）。不要自己拼 subprocess。
- **新书开跑前**：查有无正式中译本（有就不做）；试跑统计篇数 / 段数 / 字符并估价告诉用户；**先试译一篇短的**抽查，再放开全书。
- **恢复**：`--resume` 只补没缓存的段；已写出、缓存齐且过闸的篇自动跳过。
- 监视器只报 `✓ 写入 / ⛔ / Traceback / 额度`；到期就重挂。

## 四、已踩过的坑（判据与产物）

| 现象 | 根因 | 处理 |
|---|---|---|
| 希腊词尾成拉丁字母 `ἀποδιορίζοντES` `δένδρa` | 模型输出 | `restore_greek`：原文里前缀同、长度同、按形近字母对回唯一的词才换回 |
| `Answer with the bare translation alone.` / 开头「答案：」 | 只有标题的占位符块被当问答 | 「模型自语」判据（英语虚词 ≥2）+ `tidy` 去前缀 |
| `probationē` / `Excōmunicatio` / `ipsâ vitâ` 被判漏译 | 拆词只认 ASCII | 字符集扩到 À-ɏ；印本断词接回只认含音标的相邻两词拼合 |
| 斜体里的漏译抓不到 | 斜体一律放行 | 斜体内遇常见英语词且原文没有 → 拦 |
| 页面上空括号「比喻（）」 | 模型给页边旁注外加括号 | 发布脚本去掉只裹旁注的括号 |
| 短条目表（索引、教义表）反复被拦 | 一句话的块模型爱自语 | 跑到这类篇时多看一眼；仍按铁律停下处理 |
| 段首冒出 🧠 ⓘ ╋ ℰ 零宽空格、错字「징兆」、制表线「─」 | 模型吐垃圾字符（多在短条目表段首） | `odd_chars` 白名单判据：名单外且原文没有即拦；夹在 `*​*` 间的零宽空格有用、放过 |
| 目录页（全书纲目）编号「一、/第三讲/XV./[四、…]」混用、链接指英文页 | 结构化目录交给模型自由排版 | 发布脚本按固定格式重排（`publish_candlish_zh.fix_contents`）；**目录类页面一律程序生成格式，不信模型排版** |
| 「父从亡古以来」——生僻字写成形近常用字（亘→亡） | 模型逐字生成时偶发；质检原先不查用字 | `KNOWN_TYPOS` 已知错字表（发现一个收一个）+ 提示词写明正确写法；统计式形近扫描误报太多，只作人工辅助 |
| 改译名时把页面形态（`<span class="dv-orig">`）写进了缓存 | 页面与缓存形态不同，批量替换没分开 | 缓存/成品用圆括号形态、页面用 span 形态，分开替换；改完全缓存跑 `check_block` 复核 |
