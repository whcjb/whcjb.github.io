# 判据与守卫

每个阈值都注明在哪本书上量的。**换书必须重新量**——这些数字随错误谱变，
不是常数。唯一在两本书上分别验过、可以当常数用的只有「缩水守卫 = 3」。

---

## 第 ① 层：字形规则 + 判词典 + 语料自证

### 字形规则表

误读 → 正确，单向。这是扫描件的**指纹**，每本书不同，要自己归纳。
亚历山大那两份（1864 Scribner / 1846 Wiley）的：

| 原字 | 被读成 | 例 |
|---|---|---|
| `li` | `U` `H` `h` | appUed · Hterally · hke |
| `ll` | `U` | aU · wiU |
| `ff` | `fi` `flf` | efiect · scoflfers |
| `rn` ↔ `m` | | modem(modern) · scomers(scorners) |
| `w` | `iv` `vn` `ui` `tv` | ivith · vnth · uill |
| `r` | `i'` | fii'st · wi'iters |
| `k` | `Jc` `Tc` | wicJced · worTcs |
| `j` | `f` | Jield(field) · conjide(confide) |

**规则是单向的**，这一点后面要用到（见「字形可达」）。

### 判词典

只在 token **不是**真词时才允许改动。这是整个流程唯一的安全网——没有它就会
把 `shews`/`connexion` 这类 19 世纪拼法「改正」成现代拼法，属于篡改底本。

词典要收：韦氏词表 + 派生变位 + 古体 `-eth`/`-est` + 本书的专名补充表。

### 语料自证

候选必须在本书别处**正确地**出现过。这条拦住的是「换完仍是英文词」的错改：
`hang → liang`、`lieth → heth` 两个目标词都在词表里，词典拦不住，但它们在这
本书里一次都没正确出现过。

**门槛按 token 长度分档**（诗篇实测）：

- `len ≤ 3`：出现 ≥20 次才放行。三字母证据太薄，一次替换能落到好几个真词上
  （`thg→thig` `oui→ow` `Joh→Job`）。
- `len ≥ 4`：出现 ≥1 次即可。

> **以赛亚书上是 `len ≤ 4` → 20。** 那本书希伯来引文密度高，四字母残串遍地都是。
> 但同样的阈值搬到诗篇会**杀掉整个四字母的 `li→U` 类**（`faUs` `waUs` `sohd`
> `ahke` `Uved`），因为它们的目标词在书里只出现 4–11 次。所以这个参数必须
> **按书卷配**（`short_len`）。

## 第 ② 层：第二证人按位置判读

### 锚

用可疑词前后的干净词做锚，在证人语料里定位到同一段话，读出证人在**同一个
位置**上印的是什么。

三条约束缺一不可，少任何一条都出过事：

1. **由近及远**。锚离目标越远，中间夹进一处增删的概率越大，位移一错就读出
   隔壁的词（`Kighteousness` 读成 `Jehovah`）。窗口 ±6 词，第一个给出唯一
   读数的就采用。
2. **另一侧确认**。左锚定位后，证人在右邻位置上的词也要对上。少这一道，
   锚偶然撞到语料别处就会读出隔壁的词。
3. **三级回退**。①左锚+右邻确认 → ②右锚+左邻确认 → ③左锚不确认。
   粘连处（`SeeExod` = See + Exod）证人比我们多一个 token，右邻永远对不上，
   只有第三级能判出来；它也最容易误判，所以垫底。

锚长 3 词（35 万词语料里已足够罕见，2 词会撞上 "of the"）；
命中超过 8 处的锚当作太常见，弃用。

### 真词那一路要用严锚

**只动非词时用宽锚，动真词时必须用严锚（两侧各三词）。** 两者风险结构不同：

- 非词路：判词典 + 相似度 + 语料自证三道闸串在后面，锚撞车读出的
  `and`/`when`/`Jehovah` 过不了形状那一关。
- 真词路：没有任何闸能拦住一个**完美的真词**——以赛亚书上
  `assertion` 被四份证人一致改成 `assumption`，因为书里别处有
  「by the gratuitous assumption that」，四词上下文不够独特。

实测：把严锚用在非词路上，39 处判定**全部是宽锚对、严锚错**（严锚在错字
成片的地方更容易失配，退化成 nowitness）。

### 读数的四道闸

| 闸 | 判据 | 挡住什么 |
|---|---|---|
| 字形闸 | 编辑距离 ≤ 1/3 串长 **或** 字形规则可达 **或** 序列相似度 ≥ 0.55 | 两版之间的**改写**（证人是早出版本） |
| 判词闸 | 是真词 / 证人语料出现 ≥3 次 / 字形规则从我们这串走得到 | 证人自己读崩的残片 |
| 正字法闸 | 抹平英美拼写后相同则不算错 | 把底本的 `-ise` 改成另一版的 `-ize`、`waggon`→`wagon` |
| 语料自证 | 读数 ≤4 字母时还要求本书别处正确用过 | `di nne majesty` 证人读成 `ine`，位置严丝合缝但那不是词 |

**「长得像」有三种量法，任一成立即可。** 编辑距离和字形规则表都偏严——
连字被读成单个字形时一个 `U` 顶掉两个字母，`faUs → falls` 距离占串长一半；
规则表也穷举不完 `Imows→knows` `lilie→like` 这种多字母同时崩的。
相似度在 **0.55** 处分得很干净（诗篇实测：≥0.6 几乎全对，≤0.4 几乎全是锚撞车，
0.5 那档鱼龙混杂；最终取 0.55）。

### 字形可达：方向性证据

规则表是单向的（左边误读、右边正确）。**从我们这串按规则走得到证人那串，
就说明错在我们这边**；走不到则是两版各读各的。这条能救判词闸救不了的：
`Antilibanus` `majestaticus` `Alleghanies` 这类专名与拉丁词词典查不到、
证人语料里也只出现一次，判词闸只能当噪点否掉，可它们明明是对的。

反向自动成立：`Bathsheba → Bathshcba` 需要 `e→c`，规则表里没有，正好挡住。

## 拆词与拼词

一个词被劈开、或两个词被挤在一起，**不能简单换成证人读数**——那会吞掉相邻
的词。四种情形，各有判据。

### 词尾粘连 `revilingsto` = revilings + to

- 串必须比证人读数长出至少一个虚词那么多
- 摘掉虚词后**更像**证人读数（编辑距离 ≤1 **或**字形规则可达）
  — 只用编辑距离会漏掉 `appUcation → application`（一个 `U` 顶 `li`，距离是 2）
- 拆出来的虚词后面不能**又是**一个介词（`Salein of` 的真值是 `Salem of`，
  硬拆成 `Salem in` 会读出 "Salem in of"）
- 拆出来的两半在证人正文里**真的相邻出现过**
  — `hearkeit` 摘掉尾巴恰好是 `hearken`，可 "hearken it" 这说法书里没有

### 词头粘连 `waterbrooks` = water + brooks

**不能限定在虚词表里**（`water` 不在表里，于是整串被换成 `brooks`，把
`water` 吞了）。改成「前半是真词就算」，再按证人正文里 `a-b` 与 `a b` 的
出现次数定拼空格还是连字符。

### 跨 token 拼词 `confes- Bion` = confession

中间可能夹一两个非字母数字字符（空格、残留的行末连字符、OCR 噪点）。四道约束：

- 两截都 ≥2 个字母（`Mai. i` 是书卷缩写 Mal. i.，不是断词）
- 读数不等于其中任何一截（等于就说明另一截被吞了）
- 拼后长度与读数相差 ≤2
- 拼起来要比单独一截**更接近**读数（否则只是这个词自己掉了个字母，
  `rospered → prospered`，硬拼上后一个就把它吞了）

外加：拼出来的必须是真词或本书别处正确用过（否则会按证人**自己的**连写
错误，把我们本来正确的两个词并掉，`salvum fac` 差点被并成 `salvumfac`）；
证人正文里印着连字符写法的是书里本来就有的复合词（`co-extensive`
`Kirjath-jearim`），不能并。

### 撇号吃掉空格 `explained'by` = explained by

**这条最危险，跨书直接套会毁掉几十处。** 判据「两半都是词、合起来不是词」
在以赛亚书上完全正确，在诗篇上命中 48 处、其中 43 处是 `r` 被读成 `i'`
（`fi'om`=from `gi'eat`=great `wi'iters`=writers）——而 `fi` `om` `gi` `eat`
碰巧全在韦氏词表里。

补两道判据（两本书通用）：
- 字形规则表给得出解 → 是误读不是空格
- 撇号直接删掉就成词 → 同样是误读（`off'ering` = offering）

前半 ≤2 字母的（`of'the` `if'it`）在文本级用长度守卫挡掉，**但不必损失**：
交给判读阶段的 `splitq`，那里有位置证据——要求证人在该位置读出的**就是前半截**，
希伯来残渣（`ni'aa`）的证人读数不会是 `ni`，自动落不进来。

> **能用位置证据就别用长度启发式。** 文本级规则只看得见字符串，被迫用长度
> 兜底；判读阶段手里有证人在同一位置的读数，判据硬一个量级。
> 反过来也成立：位置证据不可靠时（锚撞车），只能靠形状启发式兜底。

## 通用守卫

| 守卫 | 判据 | 挡住什么 |
|---|---|---|
| **缩水守卫** | 读数比原串短 ≥3 字母、又不属于任何拆分规则 → 不采信 | 吞词（`waterbrooks→brooks` `explanations'of→explanations`）。**两本书分别验过都不用调，可当常数** |
| **碎片守卫** | token 紧挨着的符号**另一侧**还是字母数字 → 是半个词，不判 | `gi-atitude` 修成 `gi-gratitude`，比原来更坏 |
| **单字母守卫** | 读数是一个字母（a/I/O 除外）→ 不采信 | 把 token 缩成一个字母几乎不可能对（`Sb`→`b`） |
| **重复词闸** | 改完与左右邻居撞成叠词 → 不采信 | 把节号当成词（`Ezekiel x. IG` → `x. in in`） |
| **连字符复合词** | 连字符另一半是真词**且 ≥2 字母** → 是正常复合词 | `failui-e` 的 `e`、`ordinai-y` 的 `y` 是被甩出来的单字母，放行会得到 `failure-e` |

## 第 ④ 层：换引擎重扫

拉丁引擎读不出希伯来／希腊活字，读出来的是一串拉丁乱码。前三层全都救不了：
证人是同样按拉丁字母 OCR 的，影像只能告诉人「这里是希伯来文」。

**做法**：ABBYY XML 里每个字符都带坐标 → 从 PDF 原图按 600dpi 裁出 →
交给 tesseract 的 `heb`/`grc` 模型。

### 双引擎对比

同一张裁图分别跑 `eng` 与 `heb`/`grc`。拉丁活字上 `eng` 又准又稳，希伯来
活字上 `eng` 只吐垃圾——**用两个引擎的分歧当信号**，比单引擎设阈值硬。
`eng` 也很自信（≥80）且读出的正是 ABBYY 那串字母时，说明页面上印的本来
就是拉丁字母（专名、德文、拉丁文），不能拿希伯来读数去换。

### 同形字闸（最关键的一条，不是置信度）

tesseract 的希腊模型会把拉丁字母映成**视觉相同的希腊大写**：
`pp.`→`ΡΡ`（置信度 90！）、`ex-`→`ΘΧ-`、`sub-`→`Βαὺ-`、`(7NI)`→`ΟΝ)`。

真正的希腊文引文一律是**带变音符的小写**（`ἐρχόμενος` `σαβαώθ` `ποιμαίνω`
`ὁμοιότητα`）。所以判据是：

- 大写希腊字母占比 > 0.4 → 弃
- 读数里没有任何变音符 → 弃

### 其余门槛（诗篇实测）

- 置信度：`heb` ≥78，`grc` ≥82
- 希伯来字母 ≥2 个 / 希腊字母 ≥3 个
- 串太短（<3 字母且不含符号）→ 弃：`oi`→`οἵ` 置信度 97 也不能信
- 英文行末断词碎片（首尾带连字符）→ 弃

### 候选怎么选

两条路，看有没有一份判完的清单：

- **白名单**（诗篇）：残渣早已逐个判完落账，直接拿那份清单当候选。
  tesseract 次数压下一个量级（全书 36 分钟）。
- **现推**（以赛亚）：判词典不认的都算候选，判据放宽、安全性交给双引擎对比。
  没有现成清单时用这条。

两条路都要堵三类假阳性：撇号（`sun's` 的所有格）、带点缩写（`i.e.` `e.g.`）、
罗马数字（`xxi.`）；页眉**整行**跳过，不按 token 挡。

### 已知边界

**`heb` 模型读不出来 ≠ 不是希伯来文**，很可能是**带元音点**的（以赛亚书
最后 9 处全是这一类，其中四处三个模型全返回空）。别据此反过来判成
「拉丁活字错字」，那只能翻影像。
