与此看法相符的有 *Marckius* 的评注，此外还有 *Drusius*、*Piscator* 和 *Pemble* 的评注。耶和华的使者从第7节到本章末尾的话，似乎由两部分构成：第一部分是对约书亚及其同伴所说的，直到第8节中间；第二部分是对先知所说的，以「这些人实在是作预兆的」这句话起首，「这些人」或「他们」，仿佛他是指着约书亚和他的同伴说的。接着，「苗裔」与「石头」便是这些人乃象征性人物的凭据。像 *Henderson* 那样把两部分割裂开来，似乎并不妥当。我对整段经文的译法如下：—— *7.* <span style="color:#000080">*万军之耶和华如此说：*</span> <span style="color:#000080">*你若遵行我的道，*</span> <span style="color:#000080">*谨守我的命令，*</span> <span style="color:#000080">*你就可以管理我的家，*</span> <span style="color:#000080">*看守我的院宇；*</span> <span style="color:#000080">*我也要使你在这些站立的人中间*</span> <span style="color:#000080">*来往行走。*</span> *8.* <span style="color:#000080">*大祭司约书亚啊，*</span> <span style="color:#000080">你</span> <span style="color:#000080">*和坐在你面前的同伴，*</span> <span style="color:#000080">*都当听我的话，*</span> <span style="color:#000080">*这些人实在是作预兆的；*</span> <span style="color:#000080">因为</span> <span style="color:#000080">*看哪，我必使我仆人大卫的苗裔发出。*</span> *9.* <span style="color:#000080">*看哪，我在约书亚面前所立的石头，*</span> <span style="color:#000080">*在一块石头上有七眼。*</span> <span style="color:#000080">*万军之耶和华说：看哪，我要亲自雕刻这石头，*</span> <span style="color:#000080">*并要在一日之间除掉这地的罪孽。*</span> <span style="color:#000080">*当那日，万军之耶和华说：*</span> *10.* <span style="color:#000080">*你们各人要请邻舍*</span> <span style="color:#000080">*坐在葡萄树和无花果树下。*</span> 「苗裔」与「石头」作为弥赛亚的称号，乃是犹太人所熟知的象征，因为先前的众先知早已使用过。*Vitringa*、*Blayney* 等人将「眼」译作「泉源」，并将下一行译为「看哪，我开它的开口」，即泉源要涌流而出的孔口；他们认为这是暗指摩西在旷野中所击打的磐石。正如 *Marckius* 与 *Henderson* 所指出的，反对此说的主要理由是：译作「眼」的那个词是阳性的，唯有作阴性时才有「泉源」之意。—— *Ed.*
