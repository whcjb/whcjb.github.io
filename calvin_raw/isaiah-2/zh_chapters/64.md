# 第六十四章

<p style="text-align:center" markdown="1"><span style="color:#000080">前往 以赛亚书 64:1-12</span></p>

**1.** <span style="color:#800000">*愿你裂天而降！*</span>在本段经文中，<span style="color:#008080">לוא</span>（lu）这一助词在我看来是表达愿望之意；因为虽然它有许多含义，但上下文表明，这一含义比其他任何含义都更适合本段经文。此处信徒迸发出恳切的祈求，正如通常所发生的那样：当我们身处剧烈的患难之中，就觉得平淡的言辞不足以有力地表达我们的心意。

当神出人意料地显出某种非凡而惊人的大能明证时，就说他「裂天而降」。这种说法的缘由，不仅在于人在困苦逼迫之时通常仰望天上，指望从那里得着帮助，也在于神迹打断了自然的秩序，为自己开辟出一条不寻常的道路。如今，当神不施行任何帮助时，他就显得像是被关闭在天上，不理会地上所发生的事。因此，当他向我们显出某种他临在的凭据时，就说他「开天」、「裂天」；因为若非如此，我们就以为他离我们甚远。

<span style="color:#800000">*愿你降临*</span>。这一说法与前一说法一样，是迁就我们肉体的领悟力而说的；因为神并不需要从一处挪到另一处，乃是俯就我们，好叫我们更明白这些事。<span style="color:#800000">F1028</span>（创世记 11:5；18:21。）

<span style="color:#800000">*愿山岭在你面前震动*</span>。这就是说，

<p style="text-align:center" markdown="1"><span style="color:#000080">「愿你的威严公然显现，愿万物因</span></p>

<p style="text-align:center" markdown="1"><span style="color:#000080">感知它而震动，退让顺服。」（</span><span style="color:#000080">诗篇 18:11）</span></p>

这一点从紧接着的话中将更加明显地显出来。

<!-- PAGE 593 -->
**2.** <span style="color:#800000">*如熔化之火的焚烧，*</span> <span style="color:#800000">F1029</span> 火将水烧开。这一切都可以读作将来时，或读作虚拟语气；仿佛他说：「主啊，你若降临，万民必在你面前战抖；你的仇敌必立刻消化。」但我认为我所采用的译法更为质朴；因为十分确定的是，先知在此暗指西奈山，就是主在那里向他的百姓公开显现自己之处。由此我们也看出本章分段的极大荒谬；<span style="color:#800000">F1030</span> 因为这些所记述的事件，是用来支持那祷告的，而那祷告本应放在本章的开头才是。<span style="color:#800000">F1031</span>

我们从前已经看到，众先知在述说神帮助他的百姓时，总是从救赎的历史中举出一个实例。<span style="color:#800000">F1032</span> 因此，每当众先知题起这段历史时，他们所包含的乃是神从前赐给他百姓的一切恩惠；不仅是当他救他们脱离法老的暴政时，不仅是当他在西奈山向他们显现时，也包括当他在四十年间于旷野中供给他们一切所需之时，当他赶出他们的仇敌、领他们进入迦南地为业之时。总而言之，他们所包含的是一切明证，就是神从前藉以证明自己向他的百姓有恩、向他的仇敌可畏的一切明证。

他说「熔化之火使水烧开」，是因为与常例相反，火与闪电竟与暴雨相混；仿佛他说，神的火熔化了最坚硬的物体，而水又被那火的热气所吞灭。他所补充的话也是同样的意思，就是「众山在他面前流动」；因为他为他的百姓在最可怕的阻碍中开辟了道路。

**3.** <span style="color:#800000">*可畏的事，是我们素来所不知道的。*</span> 他说以色列人所见的，全然出乎他们意料之外；因为，虽然神已预先警告过他们，也曾多方使他们经历他的大能，然而他所说的那可惊惧的景象，却远远超乎我们的感官和人心的领悟之上。

<!-- PAGE 594 -->
**4.** <span style="color:#800000">*从古以来，人未曾听见。*</span> 这一节确证了上文所说的：信徒在此并非求什么奇异或罕有之事，只求神向他们显明自己，正如他从前向列祖所显明的那样；求他继续施行他的慈爱；并且既然他素来乐意扶助他的百姓，赐给他们无可置疑的临在凭据，愿他在将来也不停止使他的能力与大力越发光辉地显耀出来。他把信徒描绘为如此向神祈求：他们借着追念往事而坚固自己，更加勇敢地投奔神的帮助。

<span style="color:#800000">*神以外，眼未曾看见。*</span> 先知的用意无疑是要颂扬神无量的美善，藉着述说他古时向他百姓所施的众多恩惠；而当他被这些恩惠激起惊叹赞美，高呼除他以外并无别神，并且宣告主为他百姓成就的事乃是从未听闻、绝不寻常的时候，这种颂赞便格外壮丽。但这些话有两种读法，因为 <span style="color:#008080">אלהים</span>（*elohim*）既可作宾格，也可作呼格。「主啊，你为等候你的人所行的事，除你以外无人看见过。」但另一种读法更为人所接受：「从来无人见过、也无人听过这样的神。」不过按这种读法，我们必须补上比较的虚词「如」；否则句子便不完整。动词 <span style="color:#008080">יעשה</span>（*yagnaseh*）是绝对用法：「耳未曾听见，眼未曾看见，有这样的神行这样的事。」如此，神便与偶像分别开来——迷信的人幻想从偶像那里得着一切好处；其实偶像只是人手所造的虚构之物，既不能施益，也不能加害，唯有神将各样的恩惠赐给敬拜他的人。

保罗似乎对这段经文作了不同的解释，并将它转用于另一目的，甚至以不同的字句引用它（哥林多前书 2:9），这是因为他依从了希腊文译本。在这方面使徒们并不拘泥；因为他们更注重实质而非字句，只要能引导读者注意到一处圣经，从中可以得出他们所教导的内容，他们就以此为足。至于保罗似乎凭己意所加上的那句：「也未曾有人心里想到的，就是神为爱他的人所预备的」，他这样作是为了阐明其意；因为他所添加的，无一不与先知的教义完全相符。

为使我们更清楚地看出他与先知何等一致，我们必须明白他的用意。在那段经文中，他论述福音的教义，并证明这教义超越人类理解的能力；因为它所包含的知识与我们肉体的知觉大相径庭、相去甚远，简言之，它乃是 <!-- PAGE 595 --> 「隐藏的智慧」，因此保罗理当以惊叹的心来看待它。正如先知在思量神奇妙的慈爱作为时，像一个陷入惊愕的人那样呼喊说，这样的事从来未曾听闻；照样，在一切恩惠中最卓越的那一样上——即基督藉福音赐给我们——我们也可以照样呼喊说：「主啊，你所赐给你百姓的，超越人心一切的领悟：没有眼睛、没有耳朵、没有感官、没有心思能够达到这样的高度。」这样，保罗极其巧妙地将这段经文应用于他的论证，当他把神赐给他教会的那特殊恩典高举于世界之上时，他并未误用先知所说的话。

剩下的只有一个难点，就是保罗把先知在此论及属世性质的福分之言，应用于属灵的福分。但我们可以说，以赛亚在此只是注目于神赐恩惠的根源，虽然他眼中所见的是今生的处境；因为我们从神所领受的一切恩惠，就着饮食与养育而言，都是他向我们所存父亲般慈爱的证据；而信心特有的卓越之处，正在于从有形可见的恩眷上升到那不可见的恩眷。因此，虽然先知似乎是在讲外在的拯救和今生其他的恩惠，他却升得更高，主要注目于那些特别属于神百姓的事物。倘若我们在享受神的恩惠时，却不思量那泉源本身，即他父亲般的慈爱，这是何等的愚昧！寻常的恩眷是善人与恶人不加分别地一同享受的；但他用来拥抱我们的那恩眷，却特别属于国民。其结果就是，我们不仅仅观察那些落在人感官之下的事物，更默想那根源本身。因此，虽然眼睛与耳朵都不能达到领会那使主见证他是我们父亲的儿子名分之恩，他却藉着他圣灵的见证将这恩启示出来。

<!-- PAGE 596 -->
甚至很有可能，先知在述说神某一特定的恩慈作为时，藉此被提升到一种普遍的省思；因为在思想神的作为时，善人常常习惯从单一的事例推及全体。这样，神良善的这一单一却卓越的例证，便可将先知的心思提升到如此高度，以致他默想那为信徒存留在天上的无限丰盛之福。我们甚至清楚看见，这一称颂包含了神藉以收纳亚伯拉罕的子孙进入永生指望的那恩慈之约。（创世记 17:7）以上所说的可归结为此：「既然神的良善与权能如此浩大，我们就没有理由不信靠他；反倒应当将我们的信心安放在他身上，以致盼望他必定帮助我们。」先知在此所提及的那些卓越恩惠，其用意正是如此。

**5.** <span style="color:#800000">*你曾迎接。*</span>他继续同一主题；因为百姓哀叹自己命运的艰难，就是他们在患难中感觉不到丝毫舒缓，虽然从前神惯常向列祖伸出手来。因此信徒这样说：「你从前惯常迎接我们的列祖；如今你的脸却转离我们，你似乎不肯与我们和好，因为我们呼求你毫无所得。这种差异从何而来，好像你的本性已经改变，你如今与从前不同了？」他们接着又加上并承认，他们受刑罚是公义的，因为「他们犯了罪」。我从前已说过，在患难中最好的莫过于记念神的恩惠，不仅是我们自己所经历的，也包括圣经所记载的；因为再没有比这更坚固的盾牌，能使我们抵御各种试探。

在我看来，有些人认为我们应当把这些话紧密连读为<span style="color:#800000">*那欢喜行义的人*</span>，仿佛他说：「你曾迎接那些甘心事奉你、以行义为至大喜乐的人」，这样的解释并不准确。我认为此处的「欢喜」是指那些在顺境中欢乐的人；因为那时百姓正处在悲伤与哀哭之中。这里含有一个隐含的对比：「从前，列祖尚未被任何苦难所困扰时，你惯常迎接他们，以你的临近使他们欢欣；如今你却远离，容我们在哀哭忧伤中憔悴。」

<!-- PAGE 597 -->
<span style="color:#800000">*人在你的道中记念你。*</span>按着他现今所说的，他补充说他们「记念神」，因为他们享受了神现今的恩典，也感受到神是他们救恩的创始者与引导者；因此他所说的「神的道」，是指顺利兴盛的境况；或是因为神以这种方式亲近他们，如同待自己的儿女那样温柔和缓地对待他们，或是因为神按其本性乃是乐于施行慈爱的。但既然他说神惯常「迎接行义之人」，那么这「记念」也可指敬虔的实践，就是说他们热切地专心敬拜神；如此，这便是对前一句的解释，因为先知们常常用各种不同的说法来印证他们先前所说的话。「记念」神，就是被那对他甘美的记念所吸引、所俘获，以致我们不再渴慕别的，而将我们全部的福乐都安置在他里面。没有什么比记念神的怜悯更使我们喜悦；反过来说，我们若觉得神发怒，一提到他就使我们惊惧不安。

<span style="color:#800000">*我们犯了罪。*</span>这里说出了缘由；因为当他们发现神与他从前的作为如此不同时，他们并不向神发怨言，反而把一切的责咎都归在自己身上。让我们从此学到：我们思想主所加的管教时，绝不可不同时想起自己的罪，好叫我们承认自己受罚是公义的，并承认自己的罪咎。

<span style="color:#800000">*其中有长久。*</span>在本段中，<span style="color:#008080">עולם</span>（*gnolam*）所指的不过是「长久的存续」；但它可以指「罪」，也可以指「主的道」。指「罪」时，可如此理解：「虽然我们顽固地持续在罪中，且理当被你灭绝千次，然而我们至今仍因你的怜悯得蒙保全。」若我们理解为指「主的道」，那便是说出百姓未被灭亡的缘由，因为「主的道」是坚定不变、永久长存的，他的怜悯永不止息；在我看来，这个意思与本段最为契合。有些人补上文字，说「那世代」或「那长久」是建立在主的道上的。但我更愿按字面的意思领会这些话，正如大卫说主「不过是转眼之间」发怒（诗篇 30:5），说他容易与人和好，且始终有怜悯的心；因为他的怒气并不像人那样突然被点燃，或发作得毫无节制，反倒他在慈爱与恩宠上是不改变的。

<!-- PAGE 598 -->
<span style="color:#800000">*我们便得救。*</span>或译为<span style="color:#800000">*我们已经得救*</span>。我们尚未完全领会先知这句话的意思；因为他说这百姓「得救了」，虽然他们已被掳去，如同下到坟墓，正为自己的灾祸哀哭。因此我认为这里的过去时是代替将来时使用的，因为这与其说是一句断言，不如说是一个愿望或祈求。圣徒们并非夸口说自己已经得着了救恩，而是在哀叹自己的痛苦时，投奔于神永远的怜悯；因此，他们所称颂的是他们所盼望的，而非他们已经得着的。

**6.** <span style="color:#800000">*我们都像不洁净的人。*</span>信徒继续他们的哀诉；因为他们为自己的处境悲叹，因为神似乎不顾念他们。希伯来的作者们对<span style="color:#008080">בגד עדים</span>（*beged gniddim*）这两个词的意思意见不一。 <span style="color:#800000">F1033</span> 但可以确定的是，它所指的是某种卑贱无用之物，因其污秽，在人的鼻中发出臭气。然而这里有两件事当加注意：第一，信徒承认自己的罪责，并为此受了公义的刑罚；第二，他们却仍然诉说自己所受刑罚的严厉，并非为要责怪神，而是为要激发他的怜悯；正如一个犯人，当他设法缓和审判官的严厉时，便把自己的困苦与灾祸陈明在他面前。有些注释家曲解这段经文，主张先知在提到罪的污秽时，是无一例外地描述所有犹大人，尽管其中仍有一些人是真诚敬拜神的。但这种说法并无充分根据；因为先知所讲的不是个人，而是整个群体，这群体被众人践踏在脚下，受尽羞辱，故此他把它比作一件污秽的衣服。

有些人常常引用这段经文，为要证明我们的行为不但毫无功德，反而在神眼中是腐烂可憎的。但在我看来，这与先知的原意不合，因为他所讲的不是全人类，而是描述那些被掳之人的哀诉——他们亲身经历了主向他们发出的忿怒，因而承认自己和自己的义都像污秽的衣服。首先，他劝他们认自己的罪，好使他们承认自己的罪责；其次，他劝他们虽然如此，仍要向神求赦免，而得蒙赦免之道乃在于：当我们诉说自己是可怜困苦的时候，同时也承认我们所受的刑罚乃是因我们的罪而当受的。

<!-- PAGE 599 -->

<span style="color:#800000">*我们都像叶子渐渐枯干。*</span>这是一个极美的比喻，表明人一旦觉察神向他们发怒，便完全枯萎凋残；诗篇 90:6 与 103:16 对此有极精妙的描述。<span style="color:#800000">F1034</span>

所以，我们被比作叶子是理所当然的；因为「我们的罪孽好像风把我们吹去」。

**7.** <span style="color:#800000">*并且无人求告你的名。*</span>他在此印证前面所说的话；因为他劝勉信徒，即或神加于他们的刑罚显得严厉，仍要相信自己配受这样的刑罚。他列举了种种深重的罪；虽然逐一细数会显得冗长，他却指出那根源本身，说神的敬拜被人废弃了。在「求告」一词之下，他按圣经惯常的用法，包括了对神的全部敬拜；因为敬拜神最重要的部分，就是「求告」他，并且见证我们对他的信靠。祷告与祈求，在他们中间无疑是常有的；但因着心远离了神，他一切虚有其表的礼仪都被视为毫无价值。

<span style="color:#800000">*或激动自己抓住你*</span>。他如今更清楚地解释前一句，说无人认真专注心思，也无人竭力寻求神，众人都因自己的懒惰而消耗衰残。首先，他表明再没有什么比与神完全联合更为可羡慕的；因为当我们与他隔绝时，我们凡事都必不顺利。我们生来懒散迟钝，因此需要有鞭策加在我们身上。既然我们本性纵容自己的懒惰，就必须听从先知的劝告，免得成为全然愚顽的人；否则他反过来也必弃绝我们，或轻蔑地把我们赶开。先知在此描述这百姓可悲的光景：其中无人有寻求神的渴望，也无人采取任何办法激动人心归向敬虔。

<span style="color:#800000">*你使我们消化*</span>。他们再次哀诉自己被苦难的严厉所压倒，从神却得不着丝毫的缓解；因为以赛亚是奉全体百姓的名说这些话，并向神祈求，不容他们在如此深重的患难中继续消化衰残。

**8.** <span style="color:#800000">*耶和华啊，现在*</span>。他们既已哀诉几乎将他们压倒的苦难，如今就更公开地向神求赦免、求减轻他们的患难，并以更大的胆量向神申诉说，他们仍然是他的儿女。唯有那被收纳为儿子的恩典能鼓励他们怀抱美好的指望，使他们纵然被患难的重担所压倒，也不停止倚靠他们的父。这样的次序当仔细留意；因为为要我们心里真正谦卑下来，我们必须被抛下、被压低、几乎被碾碎。但当绝望抓住我们时，我们就当抓住这安慰的祭坛：「既然神乐意拣选我们作他的儿女，那么即使事态最为恶劣，我们仍当从他期待救恩。」因此，以色列人念着那恩典之约，肯定自己是神的儿女，为要经历他慈父般的仁爱，也为要使他的应许不至归于虚空。

<span style="color:#800000">*我们是泥，你是窑匠*</span>。他们借着一个比喻来称扬神的恩典，承认自己乃是用卑贱的泥土所造成的；因为他们不在自己身上寻找任何优越的根据，反倒在自己的本源上颂扬神的怜悯——祂竟定意从卑微污秽的泥土中为自己造出儿女来。

<span style="color:#800000">*我们都是你手的工作*</span>。这第二句与前一句意思相同，其中神被称为创造者，祂的百姓被称为祂手所作的工；因为他们将自己的一切所是与一切所有，都单单归给神。这才是真正的感恩；因为只要人稍微主张有什么是属于自己的，神的权利就被剥夺了。如今，以赛亚所说的并非人一般性的被造，而是重生；正因这重生，信徒才特别被称为「神的工作」，正如我们在解释其他经文时屡次说明的：<span style="color:#800000">F1035</span> 在此他们承认神那奇妙的慈爱之作为，就是祂拣选他们作自己的百姓，并以如此众多如此浩大的恩惠装饰他们。

**9.** <span style="color:#800000">*耶和华啊，求你不要大发震怒。*</span> <span style="color:#800000">F1036</span> 这百姓祈求刑罚的严厉与神烈怒的猛烈得以减轻；这并不是说神行事过了分寸，而是因为倘若祂选择以公义最严格的尺度对待他们，他们必被全然压毁。因此他们求刑罚得以缓和；正如耶利米也说：「耶和华啊，求你从宽惩治我」（耶利米书 10:24），就是说，要有节制；因为他将「审判」与「忿怒」作了对比；正如别处所说，神用「人的杖」责打我们（撒母耳记下 7:14），因为祂并不施展祂手的全力来惩罚我们，免得我们被全然灭绝。

<span style="color:#800000">*也不要永远记念罪孽。*</span>值得注意的是，他们并非绝对地躲避神的审判，也不祈求完全脱离审判，而是把自己交出来受管正，只求不至在鞭打之下昏倒。这就是他们渴望自己罪孽的记念被涂抹的缘故；因为若神不施怜悯赦免他们，管教就永无止息。

<span style="color:#800000">*我们都是你的百姓。*</span>先知重述他稍前所说的，即神拣选了亚伯拉罕的家；因为深信必得赦免的最坚实根据，就在于信守应许的神不能弃绝那些祂曾一次拣选的人。他用「都」这个字，如我先前所说，并非指着每一个人说的，而是包括教会的全体。虽然其中大部分人已因恶意的背叛而离弃了神，然而犹太人仍真是神的特选之民；这祷告并非无分别地为他们每一个人献上，乃单为那仍存留的神的儿女献上。<span style="color:#800000">F1037</span>这百姓并不在神面前陈述自己的功德，而是投奔那藉以被收纳的白白恩典之约。这是信徒确实而唯一的避难所，是治一切祸患的良药；这也是摩西和其余先知如此频繁重述它的缘故。（出埃及记 32:13）

**10.** <span style="color:#800000">*你的圣邑。*</span>教会再次数说自己的苦难，为要感动神施怜悯并得着赦免。她说众城邑已变为「旷野」；并且为着加强语气，又补充说「锡安变为旷野」；因为那里是王的居所，是神愿意人在其中求告祂的地方。她又提到耶路撒冷，锡安就在其中；因为神既将一座城分别为圣归给自己，这城竟被仇敌倾覆毁坏，实在显为可耻的事。

<!-- PAGE 602 -->
她称它们为「圣洁的城邑」，因为主既已使一族百姓成为圣洁，他也愿意那些城邑、甚至全地都被分别为圣归给他自己。因此，既然这些城邑是奉献给神的，就理当称为「他圣洁的城邑」；因为神在其中作王，人也在其中求告他。照样，今日我们也可以把「神圣洁的城邑」这称号，给那些丢弃迷信、以真诚正当的方式敬拜他的城邑。

**11.** <span style="color:#800000">*我们圣洁华美的殿。*</span> <span style="color:#800000">F1038</span> 它被称为「百姓的圣所」，与它被称为「神的圣所」意思不同；因为它既是神与百姓之间神圣联合的凭据，就常被称为「神的圣殿」，就是说，因为它与他的圣洁相称。但如今，信徒在被动的意义上称它为「他们的圣所」，因为他们必须从其中寻求自己的成圣。

「我们华美的」这几个字更清楚地证实了这一点。他们承认自己除了神愿在其中受敬拜尊崇的圣殿之外，别无可夸之处。然而我们看见，这种夸耀往往是没有根据的，因此耶利米曾加以责备，

<p style="text-align:center" markdown="1"><span style="color:#000080">「你们不要倚靠虚谎的话，说：『这是耶和华的殿，</span> <span style="color:#000080">是耶和华的殿，是耶和华的殿。』」</span> <span style="color:#000080">（</span><span style="color:#000080">耶利米书 7:4）</span></p>

然而，那些因空洞的名号而骄傲放肆之人的夸口固然毫无根据，但那些以内心接受主的定规、并倚靠祂话语的见证、晓得自己是住在祂荫下的人，他们的夸口却是真实而有根基的；因为祂已在他们中间为自己立了长久的居所。圣殿既是奉主的命令所建造，犹太人便可以正当地夸口：神是他们救恩的保护者。

<!-- PAGE 603 -->
<span style="color:#800000">我们列祖称赞你的圣殿</span>。因为那时对神的敬拜已被败坏和混杂，几乎众人都转向迷信与不敬虔，故此他所提及的不是当时的世代，而是先前的世代。这好像他说：「虽然我们未曾照所当献的敬拜献给你，然而这是我们列祖曾以纯正之心敬拜你的殿；你岂容它被污秽、被毁坏吗？这羞辱岂不要归到你自己身上吗？因为这事关乎你名的敬拜。」在此，犹太人对自己的生活一言不提，也不提出任何辩解，反倒承认自己的罪过，却将他们的敬拜献与神，好使祂记念祂的约，不容祂的应许归于虚空。这榜样是所有信徒所当效法的。「称赞」一词乃指感恩；这好像他说：「在那座殿中——如今其凄凉的废墟引出众信徒的哀哭与眼泪——曾一度回响着对神的颂赞，那时祂以仁慈温柔待祂的百姓。」<span style="color:#800000">F1039</span>

**12.** <span style="color:#800000">*耶和华啊，有这些事，你还忍得住吗？*</span> 百姓以确实的信靠坚固自己，相信神断不容自己的荣耀被人践踏在脚下，纵然人以无数的过犯惹他发怒。这对假冒为善的人绝不能带来任何安慰，唯独关乎那些真正感受到神怜悯的人。这样的人相信并深信：即使死亡威胁他们，神仍必顾念自己的荣耀，至少必向余民施恩，使那后裔不至灭绝。

<span style="color:#800000">*你仍静默使我们深受苦难吗？*</span>  <span style="color:#800000">F1040</span> 他表明，神不可能不记念自己的怜悯，因为「他不能背乎自己」（提摩太后书 2:13）。而我们的救恩是与他的荣耀相连的。这一点应当仔细留意；因为他在论及神的荣耀之后，接着说：「你不再使我们深受苦难。」所以，主必约束他的管教；因为他不能轻忽的荣耀，与我们脱离死亡的拯救有着极深的关联。因此，每当我们被仇敌攻击时，就当奔向这祷告；不是效法假冒为善之人的样式（他们高傲地夸耀神的荣耀，自己却毫无经历），而是带着悔改与信心，使我们真实得着那荣耀的果效。
