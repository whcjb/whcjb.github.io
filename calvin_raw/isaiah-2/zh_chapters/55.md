# 第五十五章

<p style="text-align:center" markdown="1"><span style="color:#000080">前往 以赛亚书 55:1-13</span></p>

**1.** <span style="color:#800000">*你们一切干渴的都当来。*</span> 先知在此以崇高的赞辞描述神的良善；这良善在基督的国度之下，要比从前更加丰盛充溢地浇灌下来，因为「一切的珍宝」（歌罗西书 2:3）——即神恩典的一切珍宝——都藏在基督里面。因为神在基督里将祂的心意向我们完全阐明，以致约翰所说的话真正应验了：「从他丰满的恩典里，我们都领受了，而且恩上加恩。」（约翰福音 1:16）诚然，列祖也曾有分于此处所提到的那神圣的良善与属灵的恩慈。大卫说：「敬畏你、投靠你的人，你为他们所积存的恩惠是何等大呢！」（诗篇 31:19）但神在基督里将这恩惠浇灌得远为丰厚充溢。因此，这是对在基督国度中显给我们之神恩典的一个卓越的赞辞；因为先知并非只教导我们那曾一次成就的事，也教导我们那每日所行的事，就是主藉着祂的教义邀请我们享受一切的福分。

<span style="color:#800000">*到水边来。*</span>有些人认为「水」一词是指福音的教义，另有人认为是指圣灵；但依我看来，这两种解释都不正确。那些认为它表示福音的教义、并将其与律法相对立的人（犹太作者们认为先知在此处所论的乃是律法），只包含了先知本意的一部分。那些将其解释为指圣灵的人稍显合理些，他们引用约翰福音中的那段话：

<p style="text-align:center" markdown="1"><span style="color:#000080">「你若知道神的恩赐，和对你说</span> <span style="color:#000080">『给我水喝』的是谁，你必早求他，他也必早给了你</span> <span style="color:#000080">活水。」（</span><span style="color:#000080">约翰福音 4:10）</span></p>

稍后，基督似乎在解释这段经文，他说：

<p style="text-align:center" markdown="1"><span style="color:#000080">「凡喝这水的还要再渴；</span> <span style="color:#000080">人若喝我所赐的水就永远不渴。</span> <span style="color:#000080">我所赐的水要在他里头成为泉源，</span></p> <!-- PAGE 421 --> <p style="text-align:center; color:#000080; margin:14px 2em;" markdown="1"><span style="color:#000080">直涌到永生。」</span> <span style="color:#000080">（</span><span style="color:#000080">约翰福音 4:13, 14）</span></p>

但我毫不怀疑，以赛亚在「水、奶、酒、饼」这些词语之下，包含了属灵生命所必需的一切；因为这些隐喻是借用我们日常所用的各种食物。正如我们靠着「饼、酒、奶、水」得着滋养，照样，我们也当知道，我们的灵魂乃是靠福音的教义、圣灵，以及基督其他的恩赐而得喂养、得扶持。

先知高声呼喊，声调超乎寻常，说：*嗐！* 因为人的迟钝如此之大，要唤醒他们极其困难。他们虽然饥饿，却不觉得自己有所缺乏；虽然极需食物，却不渴想食物；因此，那种漠不关心必须用大声而不断的呼喊来加以摇醒。所以那些对这劝勉充耳不闻的人，其懒惰就越发卑贱可耻；他们甚至在被如此严厉催逼之时，仍旧沉溺于自己的懈怠之中。此外，这邀请是普遍的；因为没有一个人不缺乏这些「水」，也没有一个人不需要基督；因此他不分彼此地邀请众人，不看人的外貌。然而人是如此可怜，虽然知道自己需要基督，却设计出种种办法使自己被夺去这恩益，宁可信那设下各种障碍的魔鬼，也不信这慈爱的邀请。

因此我们必须探究：领受这恩典的真正预备是什么。先知用「口渴」一词来描述它。那些被虚妄的自信所膨胀、饱足自满的人，或那些被地上的欲望所醉、灵魂毫不觉得口渴的人，必不接受基督；因为他们对属灵的恩典毫无胃口。他们就像那些需要养分的人，却因被风气充胀肿大而厌弃食物；又像那些被自己虚妄的幻想掳去、以自己的愚昧为食粮的人，仿佛一无所缺。其结果是：凡因骄傲、或因对自己之义的错谬看法而自高自大的人，或凡被肉体的诱惑困于昏睡的人，都轻看或弃绝神的恩典。所以我们必须有「渴」，就是热切的渴慕，如此我们才有可能领受这样浩大的恩福。

<!-- PAGE 422 -->

<span style="color:#800000">*不用银钱来买。*</span>他的意思并不是说有人拥有丰足的银钱，而是这话应当这样解释：「他们虽然贫穷，虽然陷在极深的贫乏之中，通往基督的路却仍为他们敞开，而这些恩福正是藉着基督白白赐下的。」有人会说：「然而，不用价银怎能买呢？」我回答：「买」是以喻意指我们取得某物的方法；此处 <span style="color:#008080">שבר</span> （*shabar*）是作「取得」用，「价银」则指劳力或勤劳，或人藉以获得某物的任何其他方法。他借此表明：我们是贫穷的、一无所有的，我们没有任何东西可使我们配得神的恩宠；但他慈爱地邀请我们前来，好使他能白白赐下一切，不要任何报偿。

**2.** <span style="color:#800000">*你们为何花钱？*</span> [^f919] 他在此哀叹人的忘恩与疯狂：神白白地将万物赐予他们，他们却弃绝或藐视神的恩慈，反倒为各种毫无益处的虚浮之事大大劳苦自己。人被魔鬼迷惑到这等地步，宁愿在旷野中漂流、徒然自扰，也不肯倚靠神向他们所赐的恩典。当今世代的经验充分表明：先知不仅是在与本国之民争辩，更是向历世历代的一切人发出呼喊；因为亚当的一切后裔都被这样的疯狂所掳，以致他们在寻求通往属天生命的道路时， [^f920] 完全走差了路，宁听从自己虚妄的意见，而不听神的声音。

先知在此并非抱怨那些人的懈怠，就是那些全然忘记自己、忘记神，对灵魂属灵生命毫不关切的人（这样的人为数甚多）；他所抱怨的，乃是那些渴慕生命，却不明白得着生命的方法与道路，反而在旷野和无人行走的路径中彷徨迷失的人。因此，凡人所设想出来、与神的话语相违背的得救之法，在此都被定罪，并被宣告为徒费钱财；因为他用「银钱」一词，表明凡属乎人的一切勤劳、思虑与劳苦。这并不是说，神看重我们敬拜他的一切虚妄尝试，哪怕值一文钱；而是因为那些愚昧地承担起来的劳苦，在肉体的判断中却被看作大有价值。

<!-- PAGE 423 -->

<span style="color:#800000">*你们的劳碌，却得不着饱足。*</span> 我们看见，这里所说的「饼」，与先前所说的「水」意思相同；而他称为「劳碌」的，正是先前所称的「银钱」。仿佛他说：「人劳苦却毫无益处；因为当他们随从自己的发明时，无论怎样热切地折磨自己、疲累自己，都无权指望得着任何赏赐。」因此他断言，那些轻率妄为地劳碌的人不能「得着饱足」；因为凡离弃神、另寻新的得救之法的人，永远不能「得着饱足」。正如何西阿所说，「他们吃风」（何西阿书 12:1）。他们固然可能以为自己已经饱足，因为他们被虚妄的自信所膨胀；但他们就像那因胀满了风而觉察不出自己饥饿的人。然而，倒不如让他们被饥渴大大压迫，好使他们以真诚的心呼求耶和华，正如诗篇所说：「我的心渴想你，如干旱之地盼雨一样。」（<span class="ages-code">&lt;19E306&gt;</span>诗篇 143:6）但单有饼，或单有水，都不足以使人「饱足」，靠其中任何一样也不能维持生命；这就是先知使用多样词语的缘故，为要表明主丰丰富富地供给一切生命所需之物，使我们不至于以为应当从别处寻求帮助。

<span style="color:#800000">*你们要留意听我的话。*</span>  [^f921] 因为人人都被自己的谋算引入迷途，凡忽视神的人都在邪恶的想象中消逝虚空，所以先知在此加上了那唯一的救治之法，就是我们必须完全依靠神的口。凡肯服从他话语的人，就无须惧怕自己会把力气花费在毫无价值的事上。我们在此看见神那令人惊叹的良善：他把自己的恩典赐给世人，尽管他们不知感恩，也不配得。

但他附加了条件；因为除了「听」他以外，我们没有任何途径可以进入生命；正如我们灭亡的缘故乃是我们对神的声音充耳不闻，同样，我们若向他侧耳而听，通往生命的道路便敞开了。[^f922] 为要在我们心中留下更深的印象，他重复同一劝诫，并将同一话语加倍，说「你们要听，要留意听」；又为了更温柔地吸引我们，他郑重宣告：他是否要用一切丰盛的福分「使」我们满心「得享肥美」，全在乎我们自己。

<!-- PAGE 424 -->

**3.** <span style="color:#800000">*你们当侧耳而听。*</span> 这一连串的词句更加清楚地表明我稍前略微提到的一点，就是神毫不放过任何足以纠正并激励我们迟缓之心的手段。然而其中含有隐含的责备；因为人若在如此温柔的呼召之下仍不立刻顺服，那必是愚顽到极处。这是一段极其重要的经文，从中我们看见，我们全部的福乐都在于顺服神的话。当神如此说话时，他所存的心意乃是要引导我们进入生命；[^f923] 因此过错完全在我们自己，因为我们轻忽了这拯救人、赐生命的话语。

<span style="color:#800000">*你们当就近我来。*</span> 神若只吩咐我们当作之事，他固然是定下了得生命的方法，却于我们无益；因为出于神口的律法乃是死的执事；但当他邀请我们「到他自己那里来」，当他收纳我们为儿女，当他应许赦罪与成圣时，其结果便是：凡听从的人都从他得着生命。所以我们应当留意那含有生命的教义是何种教义，好叫我们从其中寻求自己的救恩；由此我们推论，我们若不顺服神和他的话，便毫无得救的指望。这就定了全人类的罪，使他们不能以无知为借口；因为拒不听从的人，无法为自己的案情提出任何确实的辩词。

这些重复的呼唤描绘了神在呼召我们时的忍耐；因为祂并非只邀请我们一次，而是当祂看见我们迟钝懈怠时，就再一次、甚至第三次发出警告，为要胜过我们的刚硬之心。因此，祂并非一下子就弃绝那些藐视祂的人，而是在多次邀请之后才如此行。

此外，当祂吩咐我们「到祂那里来」时，这乃是对信心之本质的描述。我们听主的话，当以信心随之而生的方式来听；因为凡以信心接受神话语的人，已经放下了自己的私欲，藐视了世界，可以说是已挣断了锁链，以致他们甘心乐意地「亲近神」。然而信心不能不藉着听而生（罗马书 10:17），也就是说，不能不藉着明白神的话语而生，所以祂吩咐我们先「听」，然后才「到祂那里来」。因此，每逢提到信心，让我们记得信心必须与话语相连，因为信心的根基就在于话语。

<!-- PAGE 425 -->

<span style="color:#800000">*我必与你们立永约。*</span> 有人会问：犹太人从前不是已经与神立了永约吗？因为在此祂似乎应许某种新奇而不寻常的事。我回答说：这里所应许的，并没有什么是主从前未曾与祂百姓立约应许过的；这乃是约的更新与坚定，免得犹太人以为神的约因那长久的被掳而归于无效。因为当他们被赶出那应许给他们之地时，[^f924] 当他们没有圣殿、没有祭祀，除割礼之外没有任何「约」的记号时，谁能不断定他们已经完全绝望了呢？所以，以赛亚采用这种说法，是为迁就百姓的领受能力，使他们知道神与列祖所立的约是坚定的、确实的、永远的，并非可变的或暂时的。

这也就是他所说<span style="color:#800000">*大卫的恩典*</span>的含义；然而他用这话宣告说，这是一个白白施恩的约，因为它所根据的无非是神绝对的良善。所以，每逢圣经中出现「约」这个字，我们同时就当想起「恩典」这个字。他称之为「大卫那**可靠**的恩典」，[^f925] 便是宣告他在其中必守信实，同时又间接地表明，他是信实不变的，不能被指控为虚谎，好像他曾背了自己的约似的；相反，犹太人才是背约者与叛逆者（因为他们已经离弃了他），而他却不能后悔他的约或他的应许。

他称之为「**大卫**的恩典」，是因为这如今已被郑重坚立的约，是在「大卫」的境内所立的。诚然，耶和华曾与亚伯拉罕立约（创世记 15:5；17:7），后来藉摩西加以确认（出埃及记 2:24；33:1），最终又在大卫手中批准了这同一个约，使它成为永远的约（撒母耳记下 7:12）。所以，犹太人每逢想到一位救赎主，就是想到自己的拯救时，就当记念「大卫」这位预表基督的中保；因为在此不可把大卫看作一个私人，乃当看作担负着这名分与身份的人。然而也当顾及这预言发出的时候；因为在<!-- PAGE 426 -->巴比伦被掳期间，国度的尊荣已被抹去，王室的名号已变得卑贱可鄙，看来仿佛因那家室的败落，神的真实也随之衰残了；因此他吩咐他们凭信心仰望那已被倾覆的大卫的宝座。

**4.** <span style="color:#800000">*我已立他作万民的见证。*</span>先知如今更充分地解释他提到「大卫」的缘由。乃是因为那将要来的救赎主的应许已交托在他手中，而这番话或可就他的公共身份而说，就他作为约的中保而言；因为他并非为自己一人行事，乃是被立为神与百姓之间的一位中保。然而毫无疑问，先知是直接引他们归向基督，从大卫过渡到基督既自然又容易；仿佛他说：「大卫那位后裔必要出来，藉他的手，完全的拯救与福乐已蒙应许。」

他称他为"见证"，意思是他所立的约必在基督里得着确立与坚固。"见证"一词含有极重的意义；因为他清楚地表明，这约必在基督里得着证实，神的真实必藉他显明出来。他必见证神并非虚假的。但这见证在于教义；若不加上这一点，我们从基督降临所得的益处就微乎其微，正如所说的："我要传圣旨。"（诗篇 2:7）以赛亚在另一处也是照这意思说，基督必有口如刀剑或箭矢一般。（以赛亚书 49:2）

<span style="color:#800000">*为万民的君王和司令。*</span>之所以加上这句，是为要使人留心他的教训；因为，我们若在他说话时不听他，若不以确实的信心接受他向我们所宣示的关乎父神美意之事，他的权能便被弃置一旁了。照样，教皇党人口中把基督的名号喊得够响亮了；然而既然他们不肯接受他作教师和司令，只是徒有其名地承认他，他们的夸口便是空虚可笑的。

<span style="color:#800000">*为万民。*</span>加上这句是为了扩展其意，因为教会若非藉着招聚外邦人，便不能恢复其古时的尊荣，也不能扩展；因此，基督的声音必须传到最遥远的国度，因为他已被立为全人类的"见证、君王和司令"。

<!-- PAGE 427 -->

**5.** <span style="color:#800000">*你素不认识的国民，你也必召来。*</span> 以赛亚在此更详尽地阐明他先前用一句话所略略提及的事；因为他宣告基督必作「君王」，不单作一族之君，乃作万民之君。此处「召」乃表明得着为业；因为「召」与「应」二词之间有相互的关系。所以基督乃是以权柄「召」人，如同那位被赋予至高权能者；他「召」外邦人，为要使他们进入顺服的地步，使他们降服于他的话语之下。

他说他们必甘心顺服，虽然他们向来是不认识的；这并非说神的儿子——万物借他而造——不认识他们，乃是因为他并未眷顾他们 [^f926]，直到他们开始被算为属乎教会的人。神曾以特别的方式呼召犹太人；外邦人则似乎被排除在外，仿佛丝毫不属乎他。但如今，他对基督说话 [^f927]，应许基督必使外邦人顺服他，虽然他们从前是抗拒他权柄的。他在紧接着的话中把这一点表明得更加清楚。

<span style="color:#800000">*素不认识你的国民也必向你奔跑。*</span> 他把动词 <span style="color:#008080">ירוצו</span>（*yarutzu*）*必奔跑* 用作复数，意在更充分地说明：教会必从万民中被招聚而来，使那些从前四散的人被聚集成为一体；因为「奔跑」一词乃关乎信仰的合一。他如今说外邦人「不认识基督」，此语的意思与他稍前所说他们不为基督所认识者不同；因为一切外邦人和不信者，照字面的意义而言，都被宣告为处在无知的状态中，因他们缺乏属天教义之光，而没有这光，他们就不能认识神。虽然按本性而言，对神的认识已铭刻在众人心中，然而这认识却是如此混乱幽暗，又被诸多谬误所缠绕，以致若不加上圣道之光，他们纵然知道，却仍不认识神，只在黑暗中可怜地飘荡。

<!-- PAGE 428 -->
在这里，我们有神关乎外邦人蒙召的一个卓著明证；基督既为犹太人被立，也同样为外邦人被立。由此我们也学到：只要我们顺服他的权柄，神就眷顾我们；而且他所施的眷顾，不仅是他对一切受造之物的眷顾，乃是父亲对儿女的那种眷顾。

然而，「奔跑」一词更充分地描述了这蒙召的效力；因为这呼召的目的，是叫我们顺从神，是叫我们甘心乐意地站在他面前，存受教之心，随时预备遵行他所显明的任何旨意；正如保罗表明，顺服乃是我们蒙召的目的。（罗马书 1:5；16:26）但因外邦人远离神甚远，他们就必须切切竭力，越过一切阻碍，好得以亲近他。

<span style="color:#800000">*因耶和华你的神。*</span> 他指出这般预备与乐意之心的根源何在。乃是因为外邦人将要知道，他们所面对的是神；因为，我们若单单把基督看作人，就不会被他的教训大大感动，然而当我们在他里面看见神时，就有一股奇妙的爱火在我们心中点燃。如今，基督在此被描述为神所设立、执行他工作的一位仆役；因为他与我们的肉体一同担起了仆人的身分，就这一点而言，他服从于父，如同属于其他人的等次一般，并无不合宜之处。

然而我们应当记住我们屡次见过的关乎元首与肢体联合的教训；因为此处论到基督的话乃是关乎全body（全身），因此这荣耀是全教会所共有的。然而基督始终居于至高的地位；因为他被高举，超乎全世界之上，使万民都归向他。总而言之，他表明人之所以顺服基督、服从他的教训，乃因神已高举他，并定意要使万人认识他的尊荣；否则，福音的传讲便少有果效，若神不藉着圣灵将能力与功效赐给他的教训。

<!-- PAGE 429 -->
**6.** <span style="color:#800000">*当趁耶和华可寻找的时候寻找他。*</span>先知既已论及福音在外邦人中的美好果效——他们从前原是与神的国无分的——如今便催逼犹太人，叫他们为自己在别人奔跑时仍旧逗留而羞愧；因为他们既是最先蒙召的，落在末后便是可耻的。所以这劝勉严格说来是针对犹太人的，把外邦人的榜样摆在他们眼前，为要激动他们的嫉妒之心；正如主曾预言："我要以那不成子民的触动他们的愤恨，以愚昧的国民惹动他们的怒气。"（申命记 32:21）

<span style="color:#800000">*当趁他可寻找的时候。*</span>此处"可寻找的时候"，其意与诗篇 32:6 [^f928] 中所用的并不完全相同，乃是指神将自己向我们显明的时候，正如在别处他为自己的恩悦与我们的救恩定下了确定的日子。（以赛亚书 49:8）不过我也乐意承认，它同样指着那因困苦催逼我们寻求神帮助的时候；但我们尤当记得，神乃是在合宜的时候被寻见，就是当他自愿前来迎接我们的时候；因为懒惰迟钝的人，日后为自己所弃绝的恩典而哀哭，也是徒然。主有时容忍我们的怠惰，宽容我们；但他若终究不得其功，便要收回，将他的恩典赐给别人。为此缘故，基督劝我们应当趁着白日行走，因为黑夜将到，那时行路的机会必被夺去。（约翰福音 12:35）我们既确知寻求神并非徒然，就当从中汲取极大的安慰。基督说："你们祈求，就给你们；寻找，就寻见；叩门，就给你们开门。"（马太福音 7:7）

<span style="color:#800000">*相近的时候求告他。*</span>「求告」一词在此可作一般意义解；但我认为它标明了「寻求」神的一种方式，其重要性超乎其余一切，仿佛祂命令我们借着祈祷与恳求投奔于祂。祂说自己「相近」，是当祂开门并温柔地邀请我们到祂面前来的时候，或当祂公然显现，以致我们不必绕许多弯路去寻找祂的时候。但我们必须留意保罗的解释，他告诉我们这是指福音的传讲。（罗马书 10:8）当福音的声音大声呼喊时，「主已经近了」（腓立比书 4:5），并将自己显明给我们；我们不需远求，也不需像不信者那样迂回绕道，因为祂在祂的话语中将自己显明给我们，使我们这一方面得以亲近祂。

<!-- PAGE 430 -->
**7.** <span style="color:#800000">*恶人当离弃自己的道路。*</span>他证实了前面的话；因为他先前既呼召人来领受神的恩典，如今就更详尽地描述领受恩典的方式。我们知道，伪善之人每逢渴望脱离苦境时，便高声呼求神，然而却以邪恶的顽梗封闭自己的心； [^f929] 因此，为免犹大人以伪善之心寻求神，他劝勉他们要有真诚的敬虔。由此我们推知，悔改的教义理当始终与救恩的应许相伴；因为人若不因自己的罪而厌恶自己，并弃绝自己与世界，就断无别法可以尝到神的美善。的确，人若未被真实而恳切的悔改所感动，就必不会真诚地渴望与神和好、并得着罪的赦免。

他以三种说法描述悔改的性质——*第一*，「恶人当离弃自己的道路」；*第二*，「不义的人当除掉自己的意念」；*第三*，「归向耶和华」。在*道路*一词之下，他包括了人生的全部行程，因而要求他们结出义的果子，作为他们生命更新的见证。他又加上*意念*一词，暗示我们不仅要改正外在的行为，更必须从内心开始；因为纵然在人看来我们的生活方式似有改善，若心未曾改变，我们所取得的进步也是微不足道的。

因此，悔改包含了全人的改变；因为在人里面，我们看到有意向、有目的，然后才有行为。人的行为是可见的，但里面的根却是隐藏的。这根必须首先得着更新，其后才能结出丰硕的果子。我们必须首先洗净心中一切的污秽，制胜邪恶的意向，然后外在的见证才得以添上。倘若有人夸口说自己已经改变了，却仍照素常所行的而活，这夸口便是虚妄的；因为二者都是必需的，就是心的归正与生活的改变。

此外，神并不吩咐我们归向他，而不先为叛逆施行医治；因为假冒为善的人乐意容许我们称赞那良善正直的事，只要容他们仍旧蹲伏在自己的污秽之中。但我们若不脱离自己，就与神毫无相干，尤其当我们因邪恶的悖逆而已被隔绝之时；所以自我否定必须先行，好领我们到神那里去。

<!-- PAGE 431 -->
<span style="color:#800000">*就必蒙他怜恤。*</span> 我们当仔细察考这段上下文，因为先知在此表明：除了向人展示赦罪的确据以外，断无别法能引人悔改。所以，凡讲论悔改之道，却不提及神的怜悯与藉白白恩典而来的和好的人，都是徒劳无功；正如教皇派的博士们以为自己已尽了本分，因他们在这一点上大加铺陈，其实他们对悔改之道只是喋喋空谈、儿戏而已。但即便他们教导了真正悔改的方法，仍是于事无补，因为他们撇下了白白赐下的赦免这一根基，而唯有藉此良心才能得着平安。的确，正如我们从前所说的，只要罪人被拖到神的审判台前为自己的一生交账，他就必总是在神面前退缩畏避；而在他的心未被带入平安的境地之前，他也决不会被制服而生敬畏与顺服。

<span style="color:#800000">*因为他必广行赦免。*</span>如今，既然要从战兢的心灵中除去惧怕是何等困难，以赛亚便从神的本性中引出论据，说明他乐意赦免、乐意与人和好。因此，圣灵在这一教义上反复申说，因为我们总是怀疑神是否愿意赦免我们；因为，虽然我们对他的怜悯略有些念想，却不敢全然相信这怜悯与我们有份。所以，加上这一句并非没有缘故，好使我们不至于因着对他向我们那无限慈悲的疑惑或迟疑而受阻。

**8.** <span style="color:#800000">*我的意念非同你们的意念。*</span>这段经文有多种解释。有人认为它是普遍地定人的生活为有罪，使人不至于以自己的生活为满足，或自我粉饰其恶行；因为我们唯有除去对自己之义的虚假确信，才能亲近神。的确，除了那些被疾病的猛烈逼迫、不得不寻求健康与医治的人，无人会求医。故此，他们将这段经文与我们主的那句话相比：

<p style="text-align:center" markdown="1"><span style="color:#000080">「人所尊贵的，是神看为可憎恶的。」</span> <span style="color:#000080">(</span><span style="color:#000080">路加福音 16:15)</span></p>

<!-- PAGE 432 -->
但我认为先知的意思有所不同；依我判断，另一些注释者的解释更为准确，他们认为先知在此是将神的心意与人的心意加以区别。人惯于按着自己来判断和衡量神；因为人心被忿怒的情欲所激动，极难平息，所以他们以为自己一旦触犯了神，就再不能与神和好了。但主表明祂远不像人。祂仿佛说：「我并非必死的人，会向你们显为严厉、不可和解的。[^f930] 我的意念与你们的意念大不相同。你们若是不肯和解，难以与那伤害你们的人重归于好，我却不像你们，会那样残酷地对待你们。」

**9.** <span style="color:#800000">*天怎样高过地。*</span> 这与大卫描述神的怜悯时所说的那段话十分吻合，他说（<span class="ages-code">&lt;19A311&gt;</span>诗篇 103:11）神的慈爱之浩大，就如「天离地何等的高」；因为虽然应用之处不同，其意义却是一样的。总而言之，神有无限的慈悲，无限地乐意赦免；因此，我们若得不着祂的赦免，就只能全然归咎于我们自己的不信。[^f931]

再没有什么比我们以为神与我们自己一样，更叫我们的良心不安的了；因其结果就是我们不敢亲近祂，反倒像逃避仇敌一样躲避祂，永无安息。然而，那些以自己为尺度来衡量神的人，所形成的乃是虚假的观念，与祂的本性完全相反；实在说来，他们再没有比这更大的方式来亏负祂了。人既被邪情私欲所败坏、所贬抑，竟不以为耻地拿神那至高无染的本性与自己的本性相比，并把那无限者拘限在他们自己深感其苦、被可怜地束缚于其中的狭窄界限之内吗？我们中间有谁能被囚禁在比自己的不信更狭窄的监牢里呢？

在我看来，这就是先知明白而朴实的意思。然而我并不否认，他同时也暗指人的生命，正如他先前所描述的那样。总之，他的意思是：人若愿意归向神，就必须忘记自己；而没有什么障碍比我们以为神不可能与我们和好更大、更具毁灭性。因此，我们必须把这虚假的想象从心中根除。

<!-- PAGE 433 -->
此外，我们由此得知，那些滥用神的怜悯、反从其中取得更大犯罪胆量的人，是何等大错。先知的推理是这样的：「悔改吧，离弃你们的道路，因为神的怜悯是无限的。」当人对获得赦免绝望或疑惑时，通常会变得更加刚硬顽固；但当他们体会到神有怜悯，这就吸引他们、使他们回转。因此可见，那些不停止作恶、心里毫无改变的人，在这怜悯上并无份。

**10.** <span style="color:#800000">*雨雪从天而降。*</span> 先知在讲述了神对我们那温柔的慈爱和难以测度的宽容之后，再次提出应许，使我们靠着倚赖这些应许，得以除去一切疑虑，脱离各样危险。若不提醒我们注意「祂的话」——神藉此启示自己——那么单单谈论神的本性或祂隐秘的旨意，于我们益处甚微。如今神既已向我们公开说话，我们就无需再作更多的查究。因此我们必须来到祂的话语面前，在那里祂的旨意毫无隐晦地宣告出来，只要我们一切的心思都被限制在这界限之内；否则我们就仍处在悬疑之中，怀疑祂对我们究竟定了什么，纵使主千次宣告祂与人完全不同也是如此；因为人虽承认这一点，却仍愿在自己和自己的救恩上得着确证。[^f932] 为此，我们当仔细留意先知所遵循的次序。摩西也是这样把百姓召回到对神的认识上：「你不要说：谁能升到天上？谁能下到深渊？这话却离你甚近，就在你口中，在你心里。」（申命记 30:12）保罗说：「这道就是我们所传信主的道。」（罗马书 10:8）

他在此采用了一个取自日常经验的比喻，极其恰切；因为，若我们看见雨水浇灌土地、使之肥沃有如此大的功效，那么神在他的话语中所显出的功效必更大得多。雨水是短暂的，且易于消失；但话语却是永恒的、不变的、不朽坏的，不能像雨水那样归于虚无。

<!-- PAGE 434 -->
为使我们更充分地明白先知的话，我们必须留意他所指向的目的。人们怀疑神是否真会成就他在自己话语中所应许的；因为我们看待那话语，仿佛它悬在空中，毫无效力。这是何等可怕的事，他便从自然的进程本身加以证明；因为把话语看得比一个无声的受造物还不如，实在是极不合理的；因此他教导我们，他的话语绝不落空。有些人将此理解为：福音的宣讲从不徒然无益，总要结出些果子。这话本身是真的；因为主藉着他的圣灵动工，并且「叫他生长」（哥林多前书 3:7），故此他仆人的劳苦不至无果。但先知的意思却不同；即神并非徒然说话，也不是把他的应许撒散于空中，而是我们必实实在在地领受这些应许的果实，只要我们不以自己的不信拦阻它。

<span style="color:#800000">*却滋润地土，使地上发芽结实。*</span> 他提到雨水浇灌所产生的两种效果，即雨水使土地肥沃；第一，人有丰富的食物得以养生；第二，人有种子可在次年获得收成。因此，若在这些转瞬即逝之事上神的能力尚且如此之大，那么对于他的话语我们又当如何看呢？[^f933]

**11.** <span style="color:#800000">*我的话也必如此。*</span>神的话从神口中发出，其发出的方式使它同样也「从人的口中发出」；因为神并不从天上公开说话，而是使用人作他的器皿，藉着他们的服事把他的旨意显明出来。然而，当我们听见这些应许是从神圣洁的口中发出时，应许的权威就更加得着确证。所以，虽然他从地上举出见证人，他却宣告他们所应许的一切都必被证实、必然稳固；并且为要把讲道的能力与功效更深地印在人心里，他宣告他并非漫无目的地撒下那宝贵的种子，而是为着一个既定的目的而指派它，因此我们对其果效不应有丝毫怀疑；因为世人最容易犯的毛病，莫过于以自己来衡量神，以致不肯信服他的声音。

这一教义必须反复申说、谆谆教导，使我们晓得：神一旦说过的话，他必成就。因此，当我们听见神的应许时，就当思想他在其中的心意；这样，当他应许白白赦免我们的罪时，我们便可以完全确信我们已藉着基督与神和好了。然而，正如神的话对信徒的救恩大有功效，同样，它对定恶人的罪也满有功效；正如基督也教导说：「我所讲的道在末日要审判他。」

<!-- PAGE 435 -->
**12.** <span style="color:#800000">*你们必欢欢喜喜而出来。*</span>先知在此总结本章的题旨；因为他先前讲论神的怜悯，其目的是要使犹大人确信主必拯救他们。如今他把先前论及神无限良善的那番话，应用于他的目的上，并显明他的意念与人的意念大不相同。而真正的教导之道正是如此：我们当把普遍的真理应用于眼前的需要。最后，他论到百姓的复兴，而这复兴全然仰赖于神白白赐下的怜悯。

<span style="color:#800000">*大山小山必在你们面前发声歌唱。*</span> 他所说的「大山小山」，是指他们在路途中所要遇见的一切事物，虽然在别的方面本是有害的，却必帮助那些要归回耶路撒冷的人。这些都是比喻，藉此他表明一切受造之物都顺服神的旨意，都欢喜快乐，都出力协助推行祂的工作。正如众先知惯常所行的，他在此暗指从埃及得拯救之事（出埃及记 14:22）；因为诗人如此描述说：「大山踊跃如公羊，小山跳舞如羊羔。沧海啊，你为何奔逃？约旦哪（约书亚记 3:16），你为何倒流？」（<span class="ages-code">&lt;19B404&gt;</span>诗篇 114:4, 5）因为教会的复兴可算是整个世界的更新，因此天地也被说成改变了，仿佛其次序被颠倒过来。但这一切都是根据先前的预言，藉着这些预言，他们已经领受了归回的应许。

<!-- PAGE 436 -->
**13.** <span style="color:#800000">*松树长出，代替荆棘*</span>  [^f934]。他仍旧在颂扬神的大能，这大能要在这百姓的复兴上显明出来；因为他指出，那改变将是如此之大，以致他们归回的道路必畅通无阻。有些人作寓意解释，认为「荆棘」是指那些想要加害于人、使人受伤的人，而这些人将变为「松树」，就是结果子、有益于邻舍的树木；但这类解经过于逞聪明了。当他们说这些话与基督的国度有关，因此应当按属灵的意义来理解时，我同意他们的看法；因为先知是从离开巴比伦说起，并且涵盖了教会的全部景况，直到基督向世界显现。但那寓意的恰当性却不可因此而被承认；因为他所说的是离开巴比伦一事，并且为要为祂的百姓开路，祂说必挪去一切阻碍，供应他们一切所需，使他们不受任何困苦。照样，当基督应许救赎的恩益时，祂也照样除去一切有损或阻延之物，甚至使那些事物转向另一个截然相反的目的，好叫他们从中也得着益处。万事（罗马书 8:28）都叫信徒得益处，而那些本来有害且能致人毁灭的事，神却用作洁净他们的良药，使他们不致沉溺于世界，反倒在事奉主人的事上更加乐意、更加殷勤。

<h2 class="scripture-anchor" id="f935" data-ref="F935" style="display:none">F935</h2>

<span style="color:#800000">*这必成为耶和华的名。*</span> 当他说这必"归耶和华为名"时，他表明了教会得以复兴的目的所在。其目的乃是：叫神的名在人中间更为显赫，叫人对他的记念得以兴旺并存留。因此他补充说，这必成为永远的证据，就是一座纪念碑，如我们通常所说的，一个记念。虽然在这些风暴之中，教会以各样方式被摇撼颠簸，然而，因为主愿意人对他名的记念存到永远，他必看守并保卫她。
