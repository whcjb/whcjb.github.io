# 第五十二章

<p style="text-align:center" markdown="1"><span style="color:#000080">前往 以赛亚书 52:1-15</span></p>

**1.** <span style="color:#800000">*锡安哪，兴起！兴起！*</span> 他确认前面的教义，为要更加激励这被忧愁与悲伤所压倒的百姓。这些话必须加上，作为鞭策，使教义更容易透入他们昏睡麻木的心；因为他所对之说话的教会，看来正处于麻痹昏睡的状态，他吩咐她「兴起」，好叫她重新聚集力量、恢复勇气。他第二次重复这话，实在极为合宜；因为那些心被神怒气所击打、甚至被击倒在地的人，是很难被唤醒、很难重新振作的。

<span style="color:#800000">*披上你的能力。*</span> 这仿佛是说：「从前你颓丧沮丧，辗转于污秽不洁之中；如今当预备迎接主要使你复归的那幸福兴盛的光景。」因此他以*「能力」*与那种在事态绝望时常见的沮丧相对照；又以<span style="color:#800000">*华美的衣服*</span>与污秽不洁相对照。

<span style="color:#800000">*因为从今以后必不再进入你中间。*</span> 他所陈明的理由是：从今以后神必不容恶人放纵他们邪恶的性情来毁坏她。教会既已脱离他们的暴虐，就已有欢喜的缘由；而将来的安稳更为喜乐欢欣提供了坚实的根基。以赛亚也劝我们，当神与他的教会和好时，我们当彼此同贺；实在说来，我们若心中稍有敬虔，就当深切关怀教会的境况，以致在她兴盛时欢喜，在她患难时忧伤。[^f881] 简言之，这理当成为我们喜乐的极致，正如诗篇作者所说：

<p style="text-align:center" markdown="1"><span style="color:#000080">「我若不记念你，若不看耶路撒冷过于我所最喜乐的，</span></p>

<p style="text-align:center" markdown="1"><span style="color:#000080">情愿我不看耶路撒冷过于我所最喜乐的。」（</span><span class="ages-code">&lt;19D706&gt;</span><span style="color:#000080">诗篇 137:6）</span></p>

他所用**进入**一词，意思就是我们通常以*（Avoir e entree，"得以进入"）*这一说法所表达的「有门路可进」。

<!-- PAGE 369 -->

<span style="color:#800000">*未受割礼、不洁净的人，*</span>他指的是一切不虔的人，他们败坏对神的敬拜，又以暴虐压制人的良心。当时的惯例是把「未受割礼的」这称号加给一切与教会隔绝之人，因教会以「割礼」为记号，凡信徒都藉此得以分别出来。但既有许多人虽身上带着这约的外在印记，却并不比别人更好，为除去一切疑惑，他便加上「不洁净的」一词；因为「受割礼不受割礼全无功效」（加拉太书 5:6），而且（除非如保罗所说，心中兼有洁净）「他的割礼就算不得割礼」（罗马书 2:25）。因此他宣告说，从此以后这样的人必不得进入教会，为使教会藉着除掉污秽、恢复对神的敬拜，得以有完全的喜乐。然而，我也不反对把这些话理解为指外邦的仇敌，先知以可憎的名称呼他们，为要藉着刑罚的严厉警醒犹大人，使他们知道自己罪行的可憎。

**2.** <span style="color:#800000">*耶路撒冷啊，要抖下尘土，起来。*</span>他更充分地阐明教会的拯救，并以<span style="color:#0000d4">ὑποτύπωσιν</span>（生动的描绘）将其显明出来。当他吩咐她「抖下尘土，起来」时，我们不可因此就以为自由在我们的能力之内，仿佛我们随时可以照自己的意思得着它；因为唯独属乎神的，才是将我们从尘土中扶起，在我们俯伏之时将我们举起，并折断或解开我们的锁链，使我们得自由。那么，先知为何使用命令语气呢？因为要求我们所不能行的事，乃是不合理的。我回答说：这样的命令式的呼唤，远比他若用平铺直叙的叙述更有力地激励人；因此他宣告说，当神使她恢复从前的自由时，她必从泥泞中出来。

<span style="color:#800000">*耶路撒冷啊，要……坐。*</span>「坐」这个词表示兴盛的境况，与「躺卧」一词相对，后者表示最卑下的灾祸。有时它固然指「俯伏在地」，如他从前对巴比伦所说的：「下来坐在尘埃」（以赛亚书 47:1）。但这里的意思却不同；因为他吩咐她起来之后，又加上「使她可以坐着」，就是说，使她不再躺卧，而是重得从前的境况，将来不再被仇敌打倒在地。

<!-- PAGE 370 -->

**3.** <span style="color:#800000">*耶和华如此说。*</span>许多注释家对这一节的解释极为拙劣，他们在此偏要进入哲学式的精微思辨；因为他们凭空想出许多与先知本意相违的说法。这节与他从前所陈述的相合，

<p style="text-align:center" markdown="1"><span style="color:#000080">「我将你们卖给我哪一个债主呢？」（</span><span style="color:#000080">以赛亚书 1:1。）</span></p>

因为在此，他也照样说：「**你们是无价被卖的**」；仿佛说，他并未收取任何价银，因此对任何债主毫无义务，也没有哪个债主能主张他们是他所买来的。这大大坚固了这应许；因为犹太人对所应许给他们的自由或许心存疑惑，既然他们长久被巴比伦人所占有，而巴比伦人乃是万国中最强大的。主便迎面回答这疑惑：「我并没有把你们卖给他们，也没有将你们转让给他们；你们是无价被卖的；所以我可以正当地宣称你们是我的产业，并将你们卖掉。因此，当我应许你们自由时，不要衡量你们的困难有多大，也不要凭人的理据来推论此事；因为巴比伦人无权扣留你们，也不能阻止你们得释放。」

**所以你们也必无价被赎。** 最后，正如他先前所说，他并不像一个浪费产业的人，被迫卖掉自己的儿女，或将他们抵作偿还，照样在这段经文中他宣告说，他「无价将他们卖了」，把他们交在仇敌手中，别无缘故，只因他们以自己的罪激怒了他；因此拯救他们并不比将他们交在仇敌手中更为艰难。

有些人作了更巧妙的解释，说基督是以白白的恩典救赎了我们。这教义固然必须坚守，但与先知的本意不合；因为先知的用意是要纠正犹太人的疑惧，使他们对自己必得释放一事毫无怀疑。我们只需知道：当神乐意拯救他的百姓时，无需与巴比伦人讲什么赎价的交易；纵然他们抗拒，神也毫不费力就能将他们从其不义的占有中驱逐出去。

<!-- PAGE 371 -->
**4.** <span style="color:#800000">*我的百姓从前下到埃及。*</span> 在此处注释家们也是天上地下都摸不着；因为犹太人幻想有三次被掳，而基督徒与他们不同，认为这里所指的是第三次被掳，将在敌基督之下发生，而基督必拯救他们脱离。但依我看来，先知的意思与此大不相同；因为他是由小推大，引证埃及被掳之事为例——从前神曾以奇妙的能力将他的百姓从那里召回。（出埃及记 14:28）因此这论证乃是如此：「如果耶和华因埃及人待他百姓严酷不义而惩罚他们，（创世记 15:14）那么他岂不更要惩罚那残暴地辖制他们的巴比伦人么？」

<span style="color:#800000">*又有亚述人无故欺压他们。*</span> 法老主张对犹太人有统治权，其理据比巴比伦人的要充分得多；因为雅各既是自愿带着全家下到埃及的，（创世记 46:5）他无疑就归在法老的权下，而法老为报答从约瑟所受的恩惠，[^f882] 也将一片广大之地和丰足的牧场分给了他。法老的后继者却忘恩负义，忘却约瑟所赐给他们的益处，用各种方法苦害雅各的一切后裔。这种忘恩与残暴，耶和华严厉地惩罚了。然而巴比伦人的恶行却远为卑劣凶残，他们将犹太人从合法的产业中驱逐出来，掳去为奴。既然耶和华连埃及人也不能容忍——他们虽忘恩负义、以不义的律例辖管，但在别的方面对占有权尚有正当的名分——那么他岂能容忍那强暴残酷的巴比伦人？他们对他的百姓毫无治理之权，却以暴政欺压他们。

他所说的「亚述人」，是指巴比伦人，因为他们与亚述人同属一个君主国之下；不过他特别提到「亚述人」，因为亚述人是首先严重苦害犹大人的，也是为这次被掳预备了道路的。

**5.** <span style="color:#800000">*耶和华说：我的百姓既是无价被掳去，我在这里还有什么可作的呢？*</span> 他继续申明并印证我前面所说的：神再让祂的百姓受人欺压而默然不语，是不合理的。祂用这些话在某种程度上是责备自己的迟延；仿佛祂说：「我岂不伸出我的手来吗？我岂不为我的百姓伸冤吗？法老虽是合法的主人，尚且不能阻拦我，难道强盗的暴行反倒能阻拦我吗？」接着祂列举那些理当感动祂使百姓归回的理由。

<!-- PAGE 372 -->

<span style="color:#800000">*我的百姓无价被掳去。*</span> 在「被掳去」这个分词上，必须理解为暗含一种对比；因为埃及人并非用武力「掳去」雅各，他是在饥荒压迫之下自愿下到那地的，然而神仍将他从那里拯救出来；[^f883]那么，对于那些把他从本乡撕裂出来、用暴力掳掠为囚的人，神岂不更要把他从他们手中救出来吗？

<span style="color:#800000">*使他们哀号。*</span>为了更有力地表明这种行径的可耻，他说他们被迫不停地哀号。有些人把这动词译作中性（不及物）动词；[^f884] 但我认为这是要表达他们仇恨之烈，因此我把它看作主动动词，表明巴比伦人对犹太人所施行的暴虐；因为他们不但不公不义地辖制他们，而且待他们极其残酷。"哀号"比叹息或哭泣更甚；因为那发出高声痛哭的痛苦，我们有理由相信是极其剧烈的。这比喻取自野兽，表示极度的绝望。

主要拯救他的百姓，第三个也是最主要的原因，就是<span style="color:#800000">*他的名不断被*</span>恶人<span style="color:#800000">*亵慢*</span>、褻渎。主为着他自己的荣耀保存教会，并护卫对他名的纯正敬拜。因为恶人抓住教会的患难处境作为褻渎的理由，狂傲地讥笑神，所以他理所当然地说，他借着拯救他的百姓，乃是为自己的缘故争辩。我在此不一一列举各种不同的解释，也不停下来驳斥它们；因为对我来说，简要地阐明先知的真正意思就够了。

<!-- PAGE 373 -->
**6.** <span style="color:#800000">*所以，我的百姓必知道我的名。*</span>在这一节里，他总结了前两节所略略提到的，就是这百姓终必被神救赎，因为神不能与自己不符；因为，若他救赎了列祖，若他始终帮助教会，那么他绝不会容许他照同样方式所收纳的后裔被倾覆。我们当仔细留意"知道"这个词；因为"知道主的名"就是撇弃一切虚假的观念，从他的话语——那是他真实的形象——并其次从他的作为来认识他。我们不可照人的臆想去想象神，而必须照他向我们所宣告的自己去领会他。所以，主断定他必实实在在地帮助他们，必成就他所应许的一切，使这百姓知道他们的希望并非毫无根据，也使他们在对他名的认识上越发得着坚固。我们必须记住我们在别处所说过的，关于那证实话语真实性的经验性认识。

<span style="color:#800000">*就是我在说话。*</span>「说话」这动词与应许有关。<span style="color:#008080">הנני</span> *(hinni，)* <span style="color:#800000">*看哪，是我，*</span>则与实际的能力有关；仿佛他说：「虽然如今除了那应许几乎不可能之事的言语在你们耳中作响以外别无其他，你们却必速速得着它；因为我必实在成就我所应许的。」由此我们应当引出一条普遍的教义，即：神的应许与应许的成就乃以不可解开的纽带相连。因此，每当撒但试探我们、催逼我们不信，仿佛神已离弃并丢弃了我们，我们就必须回到这一点上，把信靠放在神身上，因祂从不徒然应许什么。「祂若至今尚未施行，到了适当的时候祂必扶助。」

**7.** <span style="color:#800000">*在山上何等佳美。*</span>先知再次坚固信徒，使他们确信神的话，好叫他们完全相信自己必被复归于先前的自由，并在那艰苦的奴役中以确定的盼望安慰己心。他对这信息发出极大的称赞，为要使信徒确信：神在他们的灾祸中向他们伸出将来得救的盼望；而且实在如此，当神说话时，他们就当接受那安慰，好叫他们倚靠它，安静忍耐地等候应许的成就。这样，为要使信徒以忍耐约束自己的渴望，他极其华美地装饰神的话。「难道你们要这样不知感恩，竟不以那含有如此众多恩惠、无与伦比的话语之宝藏为足吗？难道你们要放纵那不受管束的情欲吗？难道你们要向神发怨言吗？」他要防止百姓陷入不信——他们本被种种诱惑所牵引，未曾完全倚靠神的话；因此他称赞这教义的卓越，并表明主赐给「我们的，超过我们所求所想的」（以弗所书 3:20）。

<!-- PAGE 374 -->

他指出，他现今所说的并非各种各类的教义，乃是那适于安慰的教义；因此他表明，那些从神口中带来安慰之人的到来，是「佳美」可爱的，因为这安慰不但能减轻我们的忧伤，甚至能将丰盛的喜乐赐给我们。他在此所说的是救恩的教义，因此说所传扬的是<span style="color:#800000">*平安、福乐、救恩*</span>。他用「平安」一词表示兴盛幸福的境况，正如我们在别处已详尽解释过这词的意义。

<span style="color:#800000">*对锡安说。*</span> 由此我们推知，以赛亚所宣讲的教义乃从何处开始，也推知我们首先当渴慕的是什么，就是愿神的国在我们中间被建立；因为除非祂在我们中间掌权，我们一切的事都必败坏，我们也必悲惨可怜。反之，当神乐意眷顾我们时，这本身就是救恩的首要部分；并且这也是获得平安的唯一途径，纵然万事的光景已然崩毁、绝望。我们也当记住，这信息是传给教会的；因为它不能适用于那些不认识神的外邦人。

保罗引用这段经文，为要证明福音的宣讲不是出于人，而是出于神，并且那些传报救恩信息的仆人是由祂所差遣的。他运用了这样一连串的推理：「『凡求告主名的，就必得救。』然而，人若不先认识神，就断不能求告祂；因为求告祂的门，唯有藉着信心才得敞开，使我们既以神为父而接纳祂，就可以亲密地将我们的忧虑倾倒在祂怀中。而这信心的根基乃是教义，神藉此向我们启示祂自己，并为此目的使用人的效力与服事。因此他最后又加上说，若非受神差遣，就必无人传道。」（罗马书 10:15）

但也许有人会认为，保罗曲解了先知的话；因为以赛亚并没有说神差遣祂的仆人，只说他们的临近与到来是可羡慕的。我回答说，保罗乃是以这一原则为前提：凡不是从神而来的，都不可羡慕。然而救恩从何而来呢？从人吗？绝非如此；因为除神以外，无人能作这等卓越恩惠的创始者。所以他理当断定，这是出于神，而不是出于人。

<!-- PAGE 375 -->

**8.** <span style="color:#800000">*听啊，你守望之人的声音。*</span> 他继续先前的论证；因为他表明，这百姓必得着这样的复兴，以致报信的人要放胆宣扬。<span style="color:#800000">*扬起声来*</span>与他先前所用「在山上」（第7节）一语意思相同。这事必不隐藏，乃是何等清楚显明，以致引起众人的惊叹。凡谈论可疑之事的人，都是含糊低语[^f885]，不敢「扬起声来」；但在此处，绝无可疑或不确定之事。

先知是从城中常设的守望者借取这个比喻的，虽然「守望者」这称呼通常用来指一切先知，因为他们仿佛被安置在守望楼上，为百姓的安全守望。当他说他们必扬起声来时，他的意思是：在被掳期间必有静默，因为先知的声音必不得听见；因为他们虽私下警戒各人，却没有言论的自由。因此耶利米也说：「他当口贴尘埃。」（耶利米哀歌 3:29）但当耶和华喜悦领这百姓出来时，从前哑口的守望者，他们的口必被开启，宣告他们可以自由归回；因为他们不是在私宅之内说话，也不是稍稍给予安慰，乃要公开宣扬那救恩。关于这题目，我在第四十章开头已详加论述。

<h2 class="scripture-anchor" id="f886" data-ref="F886" style="display:none">F886</h2>

<span style="color:#800000">*眼对眼*</span>；意思是，公然地、明明地。这固然延伸至属灵的归正；但我们不可因此就离弃字面的意思，以致不把主赐给古时百姓的恩惠也包括在内；因为当祂使犹大人重得自由，并使用所罗巴伯、以斯拉、尼希米的服事时，这些事就得了应验。然而与此同时，这些事也当一直延续到基督的降临，藉此教会从世界各处被招聚起来。但我们还当往前推进到基督末后的降临，藉此万物都要完全得着复兴。

<!-- PAGE 376 -->
**9.** <span style="color:#800000">*应当歌唱，一同欢呼。*</span>他劝勉信徒感恩，但主要是要在这救恩的盼望与确信上坚固他们；仿佛他们已经实际享有这救恩，因而被呼召为此感谢神。[^f887] 当主见证祂必帮助我们时，我们并未被充分地感动，反倒以为若祂不实际显明出来，我们就是受了欺骗。因此，众先知极力坚固信徒的心，几乎把这事摆在他们眼前。虽然在忧伤之中吩咐人唱喜乐之歌，看来似乎不合情理、不合时宜，然而我们在别处已经看到，这种表达方式极适于唤醒那些在忧愁、惧怕与挂虑的重担下叹息的人。

<span style="color:#800000">*耶路撒冷的荒场*</span>。他称它们为耶路撒冷的「旷野」或「荒废之地」，为要使他们尽管在倾覆毁灭之中，仍可盼望它必被重建。这个称号比称她为兴盛或繁荣更能驱散惧怕；因为他们的处境极其可怜，若不描述他们的苦难，就没有什么能使他们想到这些应许是与他们有关的；而他们正需要在这苦难面前得着坚固，好叫他们虽然眼中所见惟有荒凉与可怕的废墟，却仍能以确定的信心仰望复兴。

<span style="color:#800000">*因为耶和华安慰了他的百姓*</span>。耶和华已将他百姓的哀哭变为喜乐，使他们从被掳之地得着自由。然而有人会说 [^f888]，这事尚未发生。但在神的应许中，如同在镜子里，我们当仰望那些眼睛还看不见的事，纵然这些事在我们看来似乎与理性相违。

<span style="color:#800000">*他救赎了耶路撒冷。*</span>我们在此看见，拯救教会乃是神自己的工作。既然连从巴比伦得赎——那只不过是影儿性质的救赎——我们都当如此判断，那么对于属灵的救赎，我们又当怎么说呢？难道能把它归给人，而不至于严重亵慢神吗？正如单单拯救教会属乎神，照样，保守教会的自由也属乎他。

**10.** <span style="color:#800000">*耶和华在万国眼前露出圣臂。*</span>先知从战士身上借用了这个比喻：战士预备上阵时便伸出膀臂。此处「露出」并非指伸出赤裸的膀臂，而是指施展膀臂；因为我们闲坐无事时，或是抱着膀臂，或是把膀臂藏起来。照样，我们也按着自己感官的粗陋来设想神，以为他像一个疲乏或懒惰的人，除非公开显出他的能力，便连一个指头也不动。

<!-- PAGE 377 -->

先知称之为「圣臂」，是因为他要为百姓的拯救施展他的能力。这暗示了神与教会之间的相互关系，就是主已分别为圣归自己的教会。诚然，他在治理全世界之时也「露出他的膀臂」；但当他向自己的教会施行特别的帮助时，他才如本节这样称之为「圣臂」。神的能力应当从两方面来看：首先是普遍的，即保存一切受造之物；其次是特殊的，即保护教会；因为他对自己的百姓有一份独特的看顾，是其余之人所不能与他们同享的。

<span style="color:#800000">*在万国眼前。*</span>他的意思是，这拯救将何等可惊叹，以至瞎眼的人也能看见。这宏伟的景象延伸至地极，足见先知所说的并非几年之后将要发生的百姓归回，而是整个教会的复兴。犹太人恶意地将这预言局限于脱离巴比伦的拯救，而基督徒又不当地将它局限于我们藉基督所得的属灵救赎；因为我们必须从古列时期所成就的拯救开始（历代志下 36:22, 23），一直贯通到我们自己的时代。这样，主开始在玛代人和波斯人中间显明他的能力，但此后他使这能力在万国眼前显现出来。

**11.** <span style="color:#800000">*你们离开，离开吧。*</span>他现在劝勉百姓要时刻预备启程，同时也要忍耐地承受他们的苦难。百姓过度的急躁需要加以约束，同样，他们的懒惰也当被抖落；因为在拯救的时候还未来到之前，他们以过分的热切渴望离去；但到了被掳的期限满了，他们却因长久的延迟而变得倦怠，抛弃了一切归回的希望与愿望，以致回到犹大的人甚少。[^f889] 他们已与巴比伦人混杂，巴比伦人的风俗把他们迷住、败坏得如此之深，以致他们轻忽了自己的本土；因此他们需要被唤醒、被警戒，免得因长久的等候而丧胆，也免得容让自己被巴比伦人的污秽所败坏。

<!-- PAGE 378 -->

<span style="color:#800000">*不要沾不洁净的物。*</span> [^f890] 这话把我们已经说过的意思表达得更清楚。他吩咐他们保守自己纯洁，远离巴比伦人使自己受染的那些污秽；因为他们有被外邦人的污染所腐化的危险，正如我们众人都偏向恶事，容易被坏榜样引诱。因此，他劝勉他们：虽然身为俘囚，却不可为了讨主人的喜欢、或为了改善自己的处境而有所作为；不可让自己被引离对神纯正的敬拜；不可被他们的偶像崇拜所污染；不可假装敬拜偶像或认同他们的宗教；因为这正是先知吩咐他们躲避的可憎的「不洁」。俘囚之人以及在暴政下叹息的人常遇见这类试探，他们往往屈服于其下，以为要缓和暴君的怒气，便容许自己做许多不法与卑贱的事。但从这段经文我们看出他们的推托何等轻浮；因为先知并不是劝勉犹大人在得自由之后才洁净，而是在他们被掳期间、甚至在他们性命危险之时就当洁净。这些话无疑也与我们相关，保罗劝勉我们不但要「灵」洁净，也要「身体」洁净（哥林多后书 7:1）。

<span style="color:#800000">*扛抬耶和华器皿的人哪，务要自洁。*</span> 这劝勉尤其是向祭司和利未人说的，他们既是擎旗的人，就当持守更大的正直；并非说别人可以任意污染自己，而是他主要向这些人说话，好叫他们给众人作榜样，因为他们已被立为众人的领袖。此外，我们必须记住我们已经看过的、以赛亚在本书末了还要再重述的一点：在被赎的百姓中将有新的祭司职分（以赛亚书 66:21）。

<!-- PAGE 379 -->
不过我赞同这简明的意思，就是利未人和圣殿的仆役是以卓越者的身分（<span style="color:#0000d4">katj ἐξοχὴν</span>，「按其尊贵而言」）代表全体百姓。因此，这教训在今日不仅关乎传道的仆人，也关乎一切基督徒，他们同样被称为「有君尊的祭司」（彼得前书 2:9），并且不仅被派去扛抬圣殿的器皿，他们自己就是「神的殿」（哥林多前书 3:16，及 6:19）。故此以西结曾预言，在教会复兴之时，利未人将作大祭司，全体百姓都要被纳入利未人的行列。既然主已将众人提升到这样尊高的地位，那么这「洁净」就是无一例外地向所有人所要求的；也正因如此，保罗把这段经文应用于全教会。

**12.** <span style="color:#800000">*你们出去必不至急忙。*</span>先知再次高举这救赎之恩，因为这在当时看来是难以置信的，他们几乎所有人都陷入如此深的绝望之中；他所对之说话的，主要是那些将被掳去为奴的人，免得他们在那可怜的境况中丧失勇气。他应许说，这拯救必不像出埃及时那样的仓皇逃奔；因为此处隐含着出埃及之拯救与出巴比伦之拯救的对比。他们是"夜间"逃出埃及的（出埃及记 12:31），假称只是"往旷野去走三天的路程，祭祀神"（出埃及记 5:3）。他们照所吩咐的"急忙"（出埃及记 12:33）匆匆而去，法老还追赶他们，图谋灭绝他们。但先知宣告说，眼前这事必截然不同，他们将如得胜者一般离去，以致无人敢加以骚扰，或如我们常说的："他们必大张旗鼓地出去"（*Ils s'en iront a enseigne desployee,*），因此这拯救必更为卓越奇妙。

<span style="color:#800000">*耶和华必在你们前头行；*</span>就是说，必作你们旅程的领队。有人会说，当神领他古时的百姓出埃及时，他也是他们的领队。这无疑是真的；但他那时并未如今日这般显出他的威严——如今他像一位元帅，在战胜了仇敌之后，率领他的军队归回。

<span style="color:#800000">*以色列的神必作你们的后盾（"必聚集你们"）。*</span>"聚集"一词可证实方才所作的解释；因为不会有那种人在惊恐之下常有的四散奔逃，他们也不会东奔西窜，而必如在旗帜之下，按着整齐常规的次序行进。这好像他说："神必带领你们出来，如一队列阵的军兵；不是一个跟着一个，像那些暗暗溜走的人；你们乃要公然成群聚集，毫无惧怕地起行。必无人扰害你们；因为你们既聚集在作你们领队的神之下，就必归回本土。"

<!-- PAGE 380 -->

**13.** <span style="color:#800000">*我的仆人行事必有智慧*</span>。 [^f891] 以赛亚在论述了教会的复兴之后，转而论到基督，因为万事都归总在他里面。有些人将 <span style="color:#008080">ישכיל</span> (*yashkil*) 解作"行事精明"；但既然紧接着又说他必被高举，上下文似乎要求我们宁可理解为"顺利兴盛"，因为 <span style="color:#008080">שכל</span> (*shakal*) 也有"兴盛"之意。因此，他所讲的是教会的兴盛；而由于这兴盛当时并不可见，他便把他们的注意力引向那位至高的君王，万事都要藉他得以复兴，并吩咐他们等候他。在此我们应当仔细留意先知所立的对比；因为他把这位耶和华所要高举的君王的大能，与那几乎陷于绝望、可怜卑贱的百姓之状况相对照。他应许这位君王必作百姓的元首，使百姓在他这位领袖之下昌盛，尽管他们如今正处在极深的苦难与困苦之中；因为他的道路必然顺利兴盛。

他称基督为"我的仆人"，是因着所交付给他的职分。基督不当被看作一个私人个体，而当被看作担任着父所委派他的职分，就是作百姓的领袖、万事的复兴者；因此，凡他论及自己所说的，我们都当明白也是属于我们的。基督已赐给我们，所以他的职事也是属于我们的；因为先知本可以一言以蔽之，说基督必被高举、必大得尊荣；但他既称他为"仆人"，其意乃是说，他被高举是为了我们的缘故。

**14.** <span style="color:#800000">*许多人*</span>。他在此用了一种预先辩明的手法；因为基督被高举的状态起初并非显然可见，人可能就以此为借口而弃绝他。因此，他告诉他们，基督必须先被弃绝、被降卑，并预先解答那可能因他极其卑贱、毫无佳形美容的状况而生的疑虑。仿佛他说："人没有理由因那毫无佳形与羞辱而惊骇，因为紧随其后的便是永远的福乐。"

<span style="color:#800000">*以致被人如此毁损。*</span> 我把 <span style="color:#008080">כן</span> (ken) 译为*如此*；因为若以为它是引出比较的后半部分，那便是误解。[^f892] 我认为 <span style="color:#008080">מאיש</span> (*meish*) 的意思是「被人」；因为我并不认为 <span style="color:#008080">מ</span> (*mem*) <!-- PAGE 381 --> 如别人所解释的那样是表示比较的介词，即「胜过」人，或「超过」人间通常所见的；我采取一个更简明的意思，就是：基督在人中间被毁了容貌，或者说，他的美貌因人悖谬的judgment判断而被损毁。

<span style="color:#800000">*都惊奇。*</span>[^f893] 有些注释者认为这「惊奇」是指人因基督所行的奇事而生的惊愕，其次是指当他必须走上十字架时，他立刻就被他们弃绝了。但他们并未领会先知的本意；因为先知是说，基督的形状必至于使众人都因他而震惊。他来到世上，以致处处被人藐视；他的荣耀隐藏在卑微的肉体形状之下；因为虽然「父独生子」（约翰福音 1:14）所当有的荣光在他身上照耀出来，然而大多数人却看不见，反倒藐视那极深的卑微——那正是遮盖他荣耀的帕子或外衣。

他们惊奇的缘故就在于：他住在人中间，毫无外表的荣华；而犹大人并不以为救赎主会以那样的境况或装束而来。及至他被钉十字架的时候，他们的骇异就更加深了。保罗描述基督这样的自卑与随后的升高，说：

<p style="text-align:center" markdown="1"><span style="color:#000080">「他本有神的形像，不以自己与神同等为强夺的；反倒虚己，</span> <span style="color:#000080">取了奴仆的形像，成为人的样式；既有人的样子，就自己卑微，</span> <span style="color:#000080">存心顺服，以至于死，且死在十字架上。所以神将他升为至高，</span> <span style="color:#000080">又赐给他那超乎万名之上的名，叫一切在天上的、地上的和地底下的，</span> <span style="color:#000080">因耶稣的名无不屈膝，无不口称耶稣基督为主，</span> <span style="color:#000080">使荣耀归与父神。」（</span><span style="color:#000080">腓立比书 2:6-11）</span></p>

因此，基督必须先被降卑、被羞辱所遮盖；他将要被高举到的那尊荣，并非一时之间就显明出来；乃是十字架的羞辱之后，随之而来的是荣耀的复活，伴随着至高的尊荣。

<!-- PAGE 382 -->

**15.** <span style="color:#800000">*这样，他必洗净（原文作「弹洒」）许多国民。*</span> 有些人解作「使之滴落」，认为这是「说话」的隐喻说法。但既然 <span style="color:#008080">נזה</span> 意为「弹洒」，且在圣经中通常都是这个意思，我宁可采纳这种解释。他的意思是，主要将他的道倾倒在「许多国民」之上。接着他提到教义所产生的果效，就是*君王要向他闭口*，即表示惊愕，但这种惊愕与他先前所描述的那一种不同。当事情的浩大无比，以致无法言表、超乎一切言语所能表达时，人就「闭口」不言，惊讶得不知所措。

<span style="color:#800000">*未曾听见的事。*</span>他的意思是，这种惊愕并非仅仅出于基督外表的显现，恰恰相反，乃是出于福音的传扬；因为，纵然他已从死里复活，若非他复活的荣耀被宣扬出来，众人仍会以为他不过是个死人罢了。所以，那从前未曾看见、未曾听闻的事，是藉着福音的传扬才显明出来的；因为这道理被传给了那极其遥远的君王与列邦，甚至传到地极。

保罗引用了这段经文，并表明它在自己的职事中得着应验，且以此夸口，就是他将福音的道传给那些从来全未听闻之人。（罗马书 15:21）这属于使徒的职分，而非每一位传道人的职分。他的意思是，基督的国度并不只限于犹大一地，如今也不再被囚于这般狭窄的疆界之内；因为这国理当遍传万邦，甚至延及地极。犹太人从律法和先知书中已听闻过一些关于基督的事，但对外邦人而言，他却是全然不为人知的；由此可见，这些话严格说来是指着外邦人说的。

<span style="color:#800000">*他们要明白。*</span>他用这个词表明，信心在于确据与清晰的领悟。所以，凡缺乏这种知识之处，信心也必定是缺乏的。由此可见，教皇党人关于「隐含之信」（implicit faith）的说法何等虚妄，那不过是粗鄙的无知，或更确切地说，纯属凭空杜撰之物。
