<p class="title-block-h1" style="text-align:center; font-size:22px; font-weight:bold; margin:18px 0 12px;" markdown="1"><span style="color:#0000d4">诗篇 127</span></p>

本篇诗表明：社会的秩序，无论是政治的还是家庭的，都单单藉着神的赐福得以维持，而不是靠人的谋略、勤勉或智慧；并且生养儿女乃是祂特别的恩赐。

<p style="text-align:center; color:#000080; margin:14px 2em;" markdown="1"><span style="color:#000080">*所罗门上行之诗。*</span></p>

<h2 class="scripture-anchor" id="psalm-127-1-2" data-ref="PSALM 127:1-2" style="display:none">PSALM 127:1-2</h2>

<div class="scripture-box" markdown="1">
<p class="scripture-ref"><span class="ages-code">&lt;19C701&gt;</span><span class="book-name">诗篇</span> <span class="verse-range">127:1-2</span></p>

**1.** [^fe94] 若不是耶和华建造房屋，建造的人就枉然劳力；若不是耶和华看守城池，看守的人就枉然警醒。2. 你们清晨早起，夜晚安歇，吃劳碌得来的饭，本是枉然；因为[^fe95]他所亲爱的，必叫他安然睡觉。

</div>

<!-- PAGE 667 -->
**1.** <span style="color:#800000">*若不是耶和华建造房屋。*</span> 犹太人没有理由否认这篇诗是所罗门所作。他们以为那字母 <span style="color:#008080">ל</span>（*lamed*，即我们译作「的」的那个字）相当于「*为所罗门*」；这与通常的用法相悖，因为这样的题注在一切情形下都是标明作者。因此，他们荒谬地杜撰出一个新的意思，而这全无必要，因为所罗门在治国之事上被赋予智慧的灵，由他来论述自己所熟知、所经历过的事，本是十分合宜的。他既肯定神管理世界与人的生命，乃是出于两个缘由：第一，凡人所遇的顺利之事，他们的忘恩负义立时显明出来，因他们将这一切全归于自己；如此神就被夺去了他当得的尊荣。所罗门为要纠正这种乖谬的错误，便宣告说，若非神赐福我们的行事，我们就没有一件事能顺利成就。第二，他的用意是要打掉人愚妄的自负——他们把神撇在一边，竟毫不惧怕地全然倚靠自己的智慧与力量去从事任何事情。因此，他剥去他们无端僭取的东西，劝勉他们要谦卑，要求告神。然而他并不弃绝人的劳碌、事业或谋算；因为殷勤尽自己本分的职责，乃是值得称许的美德。主的旨意并不是要我们像木头一般，或抱着双臂无所事事；[^fe97] 乃是要我们运用他所赐给我们的一切才干与便利。诚然，我们大部分的劳苦是出于神的咒诅；然而即使人仍保有其原初状态的完全，神也必要我们有工作可做，正如我们看见亚当被安置在伊甸园中修理看守。（创世记 2:15）所以，所罗门并非责备儆醒守望这件为神所嘉许的事，也非责备人的劳碌——人若照着神的吩咐甘心从事劳碌，就是向他献上蒙悦纳的祭；乃是恐怕他们被自负蒙蔽，强行把属神的据为己有，所以警戒他们说：他们纵然忙碌操劳，若非神赐福他们的努力，也毫无益处。他用<span style="color:#800000">*房屋*</span>一词，不单指木石建成的房舍，也包括一家的全部秩序与治理；正如稍后他用<span style="color:#800000">*城*</span>一词，不单指建筑物或城墙的围拢，也指整个国家的普遍情形。「*建造者*」和「*看守者*」这两个词也同样是提喻；因为他总的意思是说：人无论用何等的劳力、远见和技巧去维持一个家庭，或保守一座城池，若非神从天上使这一切有顺利的结局，就都归于徒然。

<!-- PAGE 668 -->
我们理当记住我方才所提到的：既然人心通常被那种引他们藐视神、并过度夸大自己手段与优势的顽梗自大所盘踞，那么再没有什么比使他们降卑更为要紧的了，为要叫他们看清：若非神出于纯全的恩典使其兴盛，他们所从事的一切都必化为烟云。哲学家们论到一国的政务时，巧妙地搜罗一切在他们看来合乎其目的的材料——他们敏锐地指出建立国家的途径，另一方面又指出那些常使治理良好的邦国败坏的恶习；总之，凡在这题目上必须知晓的一切，他们都论述得极其精妙，只是遗漏了最要紧的一点——就是：人无论在智慧与美德上何等超群，无论从事何等事业，若非神向他们伸出手来，或说若非神使用他们作他的器皿，他们就一无所成。哲学家中有哪一位曾承认，一个从政者不过是被神的手所引导的器皿呢？不然，他们反倒认为人善于经营乃是社会群体幸福的首要原因。既然必死的世人如此以亵慢的胆量起来建造城邑、整顿普世的国政，圣灵责备这样的狂妄乃是公义的。那么，就让我们各按自己才能的分量与职分的性质去尽力从事，同时使我们努力所得成功的荣耀单单归于神。许多人所设想的那种分割——即人若英勇有为，便把一半荣耀留给神，另一半取归自己——是当受完全定罪的。神的赐福理当独占全份，唯独居于宝座之上。

既然我们在地上的境况全然系于神的美意，我们又要凭什么翅膀飞上天呢？当人计划一所房屋，或选定某种生活方式——是的，甚至当人制定律法、施行公义时，这一切也不过是在地上爬行罢了；然而圣灵却宣告，我们在这些事上的一切努力都是徒劳无益的。那么，那些竭力要凭自己的能力甚至闯入天上的人，其愚妄就更是不可容忍了。再者，我们可以从这教义中看出：今日世界的光景何以如实际所见的这般纷乱困扰，也就不足为奇了——公义在城中被逐、夫妻彼此控告、父母为儿女忧愁——总之，人人都在为自己的境况哀叹。因为能有几人在自己的呼召中归向神，而不是被自负充满、恶劣地自高自大呢？神既被夺去他的尊荣，就公义地将这可悲的报应加给忘恩的人。但人若都谦卑地降服于神的护理之下，无疑所罗门在此所称扬的这福分，必要照亮我们生活的各个层面，无论是公共的还是私人的。

<!-- PAGE 669 -->
动词 <span style="color:#008080">עמל</span>，*amal*，我们译作*劳碌*，不仅指人从事某项工作，也指人劳苦到疲乏困顿的地步。我先前说过，*看守者*一词不只指那些被派定守望的人，也包括一切官长和审判官。他们若有警醒之能，这乃是神的恩赐。然而还需要另一种警醒——就是神的警醒；因为除非祂从天上看守，人的任何明察也不足以防范危险。

<!-- PAGE 670 -->
**2.** <span style="color:#800000">*你们清晨早起，夜晚安歇……乃是枉然。*</span> 所罗门如今更明白地表示，人为积攒钱财而徒然劳苦，甚至禁食自苦，都是枉然，因为这些也惟独是神所赐的福分。为更有力地打动他们，他向每一个人各别说话：<span style="color:#800000">*于你们乃是*</span>枉然，他说。他特别举出两样被认为极能助人积聚财富的手段。有些人不惜任何辛劳，昼夜不停地经营他们的行业，只从劳碌所得中给自己极微薄的口粮——这等人短期内致富，原不足为奇。然而所罗门断言，无论是俭省度日，或是勤于事业，其本身都全然无益。这并非说他禁止我们在饮食上节制，或禁止我们早起料理世上的事务；乃是为激发我们祷告、呼求神，也为教导我们对神的赐福存感恩之心，他就把一切遮蔽神恩典的事都归于无有。因此，惟当我们的盼望单单系于神，我们才算是以正当的方式着手世上的职业，那时我们的成就也必如我们所愿。但人若不把神放在眼中，只顾急切奔忙，就必因自己的躁进而自取败亡。所以先知的用意，并非鼓励人放纵懒惰，以致他们终身无所思虑，只是昏睡，任凭自己游手好闲；他的意思毋宁是：他们在执行神所吩咐的事时，总当以祷告和呼求祂的名为开端，将自己的劳作献上，求祂赐福。<span style="color:#800000">*劳碌得来的饭*</span>这一说法，可作两种解释：或指藉艰辛忧虑之劳所得的，或指怀着心中不安而吃的；正如我们看见那些吝啬紧握的人，饭还没尝上一口，就把手从口边缩了回去。采取哪一种意思并不十分要紧；因为这里所教导我们的，无非是吝啬之人一无所获——纵然他们因自己的悭吝，连天性所需的份量也舍不得吃，仍旧一无所获。

<!-- PAGE 671 -->
<span style="color:#800000">*惟有耶和华所亲爱的，必叫他安然睡觉。*</span> 这位受默示的作者暗示，他所说的神的赐福，实实在在显在祂的儿女和仆人身上。仅仅相信这教义——就是人无论图谋什么都是徒然——尚且不够；还必须加上应许，好叫他们怀着确定的盼望去尽本分。这句话可以这样读：*祂必将睡眠赐给祂所亲爱的*，或读作：*祂必在睡中赏赐*；就是说，不信者靠自己勤劳才得着的那些东西，祂却白白赐给他们。<span style="color:#008080">כן</span>*，ken*，即*如此*这个小品词，是用来表达确定的；[^fe98] 因为所罗门为使人更确信这真理——即神不用祂子民多费心力便供给他们食物，这在人看来似乎难以置信、如同虚构——就仿佛用指头把这事指给人看。他固然说得好像神以温柔的对待喂养祂仆人的怠惰；但我们既知道人受造原是要作工的，又见下一篇诗篇中说，神的仆人吃劳碌得来的必得享福，那么显然，<span style="color:#800000">*睡觉*</span>一词并非指懒惰，乃是指一种安然的劳作，是真信徒因信心的顺服而甘心承担的。不信者何以有如此炽烈的热切，以致连动一动指头也要闹得纷扰不安，换言之，也要以多余的忧虑折磨自己？岂不正因为他们全然不把任何事归于神的护理！反之，信徒虽过着劳苦的生活，却以镇定安宁的心志各尽其职。这样，他们的手并不闲懒，他们的心却安息在信心的宁静中，如同睡着一般。若有人再反驳说，神的子民常被苦恼的忧虑搅扰，且被逼人的贫穷所压，一无所有，为明日忧心忡忡；我回答说：倘若神的仆人信心与爱神之心是完全的，先知所提说的祂的赐福就必显明出来。他们每逢受折磨过度，这是出于他们自己的过失，因为他们没有全然安息在神的护理之上。我还要补充说，神惩治他们比惩治不信者更为严厉，因为让他们暂受不安的搅扰对他们有益，好叫他们终究得着这安然的睡眠。然而在此期间，神的恩典仍占上风，在黑暗之中常常闪耀，就是祂如同以睡眠养育祂的儿女那样眷顾他们。

<h2 class="scripture-anchor" id="psalm-127-3-5" data-ref="PSALM 127:3-5" style="display:none">诗篇 127:3-5</h2>

<div class="scripture-box" markdown="1">
<p class="scripture-ref"><span class="ages-code">&lt;19C703&gt;</span><span class="book-name">诗篇</span> <span class="verse-range">127:3-5</span></p>

**3.** 看哪，儿女是耶和华所赐的产业；所怀的胎是他所给的赏赐。[^fe99] 4. 少年时所生的儿女好像勇士手中的箭。[^fe100] 5. 箭袋充满的人便为有福；[^fe101] 他们在城门口和仇敌说话的时候，必不至于羞愧。

</div>

**3.** <span style="color:#800000">*儿女是耶和华所赐的产业。*</span>所罗门在此举出一个特例，要我们在其中特别认清他迄今所普遍主张的真理——即人的生命是由神所掌管的。似乎没有什么比人由人所生更为自然的了。世人大多幻想，神在起初一次性定下此事之后，儿女从此便单单藉着自然的隐秘本能而被生出，神不再插手其间；就连那些略有几分敬虔之感的人，虽然不否认神是人类的父与创造主，却不承认他的护理之工下达到这一具体事上，反倒以为人是由某种普遍的运行所造成的。为要纠正这荒谬的错误，所罗门称儿女为*神的产业*，称所怀的胎为*他的赏赐*；因为希伯来文<span style="color:#008080">שכר</span>*，sachar*，译作<span style="color:#800000">*赏赐*</span>，乃指神向人所施的一切恩惠，这从圣经许多经文中显然可见。其意思便是：儿女并非偶然的果子，乃是神照他所看为美的，把他们分派给各人。此外，先知既将同一件事说了两遍，*产业*与*赏赐*就当视为同义；因这两个词都是与命运或人的力量相对而立的。人越强壮，似乎就越适合生育。所罗门却反过来宣告说：作父亲的，乃是神所赐下这尊荣的人。

<!-- PAGE 672 -->

既然多有儿女并不总是父母喜乐的源头，就又加上神的第二重恩眷，就是他塑造儿女的心志，以美好的性情和各样的德行装饰他们。亚里士多德在其《政治学》中很恰当地讨论了这个问题：<span style="color:#0000d4">poluteknia</span>（多子）究竟当不当算在美好之事中；他的答案是否定的，除非再加上<span style="color:#0000d4">eujgeneia</span>（尤格尼亚），即儿女自身性情的高尚与良善。的确，对许多人而言，无儿无女或不能生育，反倒比子孙满堂却只成为他们流泪叹息的缘由，要幸福得多。因此，所罗门为要把神这一福分——有后裔——清楚彰显出来，便称许儿女身上美德与高尚的性情。为此所引用的比喻是：正如弓箭手带着装备齐全的弓，人也照样藉着儿女得着护卫，如同有弓有箭一般。这比喻乍看之下似乎稍嫌生硬；但若稍加细察，它的精妙便不难承认。先知的意思是：无儿无女的人可说是没有兵器的；因为无后不就是孤单么？人能在后裔中得着更新，这是神不小的恩赐；因为神便藉此赐他新的力量，使那本来立刻就要衰残的人，可以说是开始了第二次的生命。

认识这教义大有益处。就连低等动物的繁衍，圣经也明明单单归给神；他既要人把母牛、羊群、母马之*怀胎*算作他的恩惠，那么当他以「父亲」这尊荣的名分装饰人时，人若把这恩眷当作无足轻重，其不敬虔岂不是无可推诿么？还当补充的是：人若不把儿女看作神的赏赐，在供养他们的事上就会疏忽而勉强；反之，认识这一点极大地激励人尽心抚养自己的后裔。再者，凡这样思想神赐他儿女之恩慈的人，必甘心乐意、心里安稳地仰望神恩典的延续；纵然所能留给他们的产业微薄，他也不至因此过度忧虑。

<!-- PAGE 673 -->
**5.** <span style="color:#800000">*他们在城门口和仇敌说话的时候，必不至于羞愧。*</span> 所罗门在此描述这样的儿女：他们以正直和纯全著称，毫不迟疑地为自己的生活作出交代，以致堵住那些恶意中伤者和诬告者的口。众所周知，古时审判的集会 [^fe102] 是在城门口举行的。因此他在此提到城门，正如今日人们提到公堂、法庭或议会一样。要注意，儿女身上最受称许的乃是无邪的清白，好叫为父的按其真正价值来看重这恩典。在前一句中，他把秉具德行与优良品性的儿女比作箭。如今，为免有人对这比喻作出强横的解释，仿佛是要容许儿女像强盗一般，不顾是非曲直，向凡挡路之人猛冲加害，他便明确地指出，德行与道德上的正直才是他们当为父亲提供的保障。因此他教导我们：我们所当渴望的儿女，并非那等以暴力欺压困苦受难之人的，也非以诡诈欺骗占人便宜的，也非以不法手段积聚巨富的，也非为自己攫取专横权势的，乃是那等行事正直、甘愿顺服律法而活、并预备好为自己的生活作交代的。再者，父亲们固然当殷勤地以圣洁的管教之法塑造自己的儿女，然而他们要记得：若非藉着神纯全而特殊的恩典，他们绝不能达成所追求的目标。所罗门也隐然暗示：无论我们何等热心致力于操练正直，我们也绝不会没有诋毁者和毁谤者；因为倘若正直的生活可以免于一切诬蔑，我们与仇敌之间就无争端了。
