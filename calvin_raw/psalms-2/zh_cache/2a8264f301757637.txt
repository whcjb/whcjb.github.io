[^fc478]: 注释家们大多把*慈爱*与*诚实*归于神；这段经文也被理解为颂扬神诸属性在人之救恩上的和谐一致。这一描绘极其优美崇高。娄斯主教在阐释本节时说：「诗人对神诸属性所作的这一著名拟人化描写，何等令人赞叹！即便仅按字面意义，将其用于犹大民族从巴比伦被掳之地的复兴，它也显得何等恰切、何等雅致、何等辉煌！但若按那更为崇高、更为神圣、更为奥秘的意义来解释——这意义在表面的图画之下并非隐晦不明——那么它无疑是异乎寻常地高贵超迈、奥妙庄严。」——（*Lowth*’*s Lectures on Hebrew Poetry*，娄斯《希伯来诗歌讲义》，卷一，第284页。）亚当·克拉克博士对本节作了另一种转述，使其效果更加突出。他说：「若照原文译作 <span style="color:#000080">「慈爱和诚实在路上相遇；</span> <span style="color:#000080">公义和平安彼此相亲」，便更为简明。</span> <span style="color:#000080">这是一处引人注目的经文，前人论之已多；但我以为其中有一种美</span> <span style="color:#000080">尚未被人留意。</span> <span style="color:#000080">「</span><span style="color:#000080">*慈爱*</span> <span style="color:#000080">与</span> <span style="color:#000080">*平安*</span> <span style="color:#000080">在</span> <span style="color:#000080">一边：</span> <span style="color:#000080">*诚实*</span> <span style="color:#000080">与</span> <span style="color:#000080">*公义*</span> <span style="color:#000080">在</span> <span style="color:#000080">另一边。</span> <span style="color:#000080">*诚实*</span> <span style="color:#000080">要求</span> <span style="color:#000080">*公义*</span><span style="color:#000080">；</span> <span style="color:#000080">*慈爱*</span> <span style="color:#000080">呼求</span> <span style="color:#000080">*平安*</span><span style="color:#000080">。</span> 「它们在路上相遇：一方是去追究罪，另一方是去代求和好。既已相遇，它们之间的分歧便因某些考量（此处未特别提及）得以调解：彼此的要求融汇为一个共同的旨趣；于此，*平安*与*公义*立时相拥。这样，*公义*便归给了*诚实*，*平安*便归给了*慈爱*。「那么，它们是在*何处*相遇的呢？——在基督耶稣里。「它们何时和好的呢？——当祂在各各他倾倒祂的生命之时。」
