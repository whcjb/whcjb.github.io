# 第二十一章
<<<END>>>

<p class="title-block-h2" style="text-align:center; font-size:16px; font-weight:bold; margin:18px 0 12px;" markdown="1"><span style="color:#000080">前往 约书亚记 21:1-19</span></p>

**1.** <span style="color:#800000">*于是众族长前来*</span>等等。在这里，我们看到较晚时期才叙述本应在先发生的事。因为在利未人分得城邑之前，逃城尚未指定。除此之外，还可加上先前所说的，约书亚和以利亚撒已经完成了分地。然而，直到利未人的居所确定之前，地并未真正分完。因此我们必须明白，当为十支派抽签分地时，已在迦南地保留了一些城邑作利未人居住之用。在约旦河东，他们的产业早已分定。但既然利未人前来请求确认这神圣的赐予，看来在他们为自己申诉之前，他们是被忽略了。因为事情往往如此：各人只顾料理自己的事务，以致连弟兄也被遗忘。百姓竟需被人揪着耳朵、被提醒耶和华就利未人所明明吩咐的事，这实在是他们的耻辱。然而，倘若利未人不为自己请求居所，他们就有露宿野外之虞；尽管与此同时，我们可以推断，百姓的过错更多是出于疏忽与健忘，而非有意欺瞒，因为他们一经提醒便毫不迟延；不但如此，他们还因顺服而受称赞，因为他们照着耶和华的话行了公正合理的事。

<!-- PAGE 152 -->
**4.** <span style="color:#800000">*众族拈阄*</span>等等。这里首先描述了城邑的数目，我们稍后将会讨论到。其次，经文明确指出，签落在犹大支派中亚伦子孙的身上。这并非偶然发生的，因为神以他奇妙的旨意，将他们安置在他所定意要为自己拣选圣殿的那个地方。第三，叙事继续列出了这些城邑的确切名称，其中首先提到的是希伯仑，就是迦勒极其平心静气地任凭自己被夺去的那座城。若有人反对说，本应首先分给他们的城，理当是耶路撒冷，就是他们将来要驻扎之处，答复并不难：分给他们的乃是与其身分相称的中等城邑。此外，耶路撒冷当时尚未被攻取，仍在耶布斯人的权势之下。总而言之，把王都指派给祭司乃是荒谬的。而且，他们的宗教与信心正因此更得显明，因为他们自愿离开本乡故土，专心从事圣事。因为没有一个祭司在履行职分时不成为寄居的客旅。然而，他们的软弱在此得到了几分体谅，就是分给他们邻近的城邑，免得他们在前去尽本分时受长途跋涉之劳。再者，将十三座城作为居所分给一个家族，而这家族人数又并不众多，这就印证了我在别处所说的：其余各支派拥有极多的城邑，[^f169] 只是没有提及；不久之后，这一点将得到更确切的证实。

<p class="title-block-h2" style="text-align:center; font-size:16px; font-weight:bold; margin:18px 0 12px;" markdown="1"><span style="color:#000080">前往 约书亚记 21:20-45</span></p>

**20.** <span style="color:#800000">*哥辖子孙的宗族*</span>，等等。利未人为何必须分散居住在各支派之间，读者可参看我在《摩西五经注释》中的论述。这种分散，起初确实是作为刑罚加在他们祖先身上的，因他曾对示剑的居民行过残忍与背信之事（参创世记 34 章）；然而这羞辱却被转化为至高的尊荣，因为神指派他们在各地区充作某种守护者，使百姓持守对神纯正的敬拜。诚然，他们无论在何处都是寄居的外人；但他们乃是以极高的尊贵身份，作神的管家，防止自己的同胞背离虔敬。这就是为何本处如此仔细地记载他们从每一支派各得了多少城邑的缘由；他们要在各处守望，使圣礼的纯洁得以完好无损地保存。

<!-- PAGE 153 -->
**41.** <span style="color:#800000">*利未人的一切城邑*</span>，等等。这段经文尤其印证了我已不止一次提到的一点：其余各支派的地界并非狭小到仅能容纳此处实际提及的那些城邑，而是远远包含更多的城邑。众所周知，利未支派人数是各支派中最少的。既然如此，又怎能公平地容许它扩展到西布伦支派所得之地四倍之广呢？须知西布伦人数虽较多，却记载只拥有十二座城。以萨迦支派所列不过十六座城，拿弗他利支派十九座，亚设支派二十二座。若把更多的城邑给人数较少的支派居住，那分配实在是不公平的。由此我们可以推断：不仅此处作为诸城附属而记下的乡村适宜居住，还有其他并未被提及的城邑也包括在内。总之，利未所得之地的广阔，足以清楚显明其余各支派的疆界该是何等辽阔宽广。

**43.** <span style="color:#800000">*耶和华将……赐给以色列人*</span>等等。倘若有人对这「安息」提出疑问，答案是显而易见的。迦南诸族被恐惧彻底压倒，以致他们认为再没有比卑躬屈膝地奉承以色列人、不惜任何代价向他们买得平安更能顾全自身利益的办法了。[^f170] 因此显然，这地已被制伏，成为可以安然居住之处，因为无人再来搅扰，也无人胆敢心怀敌意，既没有威胁，没有埋伏，没有暴力，也没有阴谋。

然而，还有第二点引起了一些疑问，[^f171] 就是：既然应许给以色列人的那地，他们竟仍与许多仇敌混杂而居，那么在何种意义上可以说他们已在这地得了产业、成了这地的主人，以致就享用这地而言，神的应许竟无一言落空呢？因为我们已经看到，仇敌中有许多人与他们混杂共居。神的心意本是：不容一个仇敌得以存留；然而以色列人非但没有赶出许多仇敌，反倒收纳他们作邻舍，仿佛这产业是彼此共有的一般；他们甚至与仇敌立约。那么，这两件事又怎能调和呢——一面说神照着所应许的，把地赐给这百姓为业；一面又说他们竟因仇敌的势力或顽强抵挡，而被拒于地的某些部分之外？

为除去这表面上的矛盾，必须加以区分：一方面是神在守其应许上确定、明白、坚定不移的信实，另一方面是这百姓的软弱与懈怠——正因如此，神美善的恩惠竟仿佛从他们手中滑落。无论这百姓兴起何等战事，无论他们将旌旗移向何方，胜利早已预备妥当；<!-- PAGE 154 -->他们之所以未能剪除一切仇敌，除了自己甘心情愿的迟钝之外，再无别的耽延或阻碍。因此，虽然他们并未将众敌尽行击溃、以致得着毫无争议的产业，然而神的真实仍显然彰显、确实应验，因为倘若他们乐意运用神所赐下的胜利，那些余剩之地本可毫无困难地取得。总而言之，他们未能完全、无缺地享用神的美善，全然是因自己的怯懦。这一点从下一章将更加清楚。
