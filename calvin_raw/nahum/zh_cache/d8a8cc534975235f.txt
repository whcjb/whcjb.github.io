从 *Marckius* 可见，*Theodoret* 与 *Cyril* 与加尔文一样，把本节视为迦勒底军队攻入尼尼微之后情形的描写；而 *Jerome* 与 *Cocceius* 则视之为先知当时尼尼微状况的写照；*Newcome* 赞同后一种看法，*Henderson* 则与前一种看法相合。他们所给出的译文几乎都相同。就诗篇章法的次序而言，把本节看作描写当时尼尼微的状况，确实更为一贯，因为尼尼微被劫掠之事在前面已极细致地描绘过了。既已如此描绘，便可设想先知在此为他所提及的可怕灾祸陈明缘由。基于这一看法，并且在某些分句的意义上与他人不同，我提出以下三节的译文：—— <span style="color:#000080">*1. 噢！这流血的城！满是诡诈；*</span> <span style="color:#000080">*充满掠物，无人能查出其所夺之财：——*</span> <span style="color:#000080">*2. 鞭声，车轮辘辘之声！*</span> <span style="color:#000080">*马匹腾跃，战车跳动！*</span> <span style="color:#000080">*马兵上马，*</span> <span style="color:#000080">*刀剑闪烁，枪矛发光！*</span> <span style="color:#000080">*一群人舞蹈，一群人呆滞不动！*</span> <span style="color:#000080">*她的人民无穷无尽！*</span> <span style="color:#000080">他们</span> <span style="color:#000080">*与其列国一同倾倒，*</span> <span style="color:#000080">*3. 都因那妓女多行淫乱，*</span> <span style="color:#000080">*她以美貌夸耀，*</span> <span style="color:#000080">又</span> <span style="color:#000080">*行邪术；*</span> <span style="color:#000080">*她用淫行卖了列国，*</span> <span style="color:#000080">*用邪术卖了万族。*</span> <span style="color:#008080">ימיש</span>「查出」，我认为出于 <span style="color:#008080">מש</span>，其意为为探查而摸索，进而为探查或查出；参 创世记 31:34。第二节只是列举这城所呈现的种种情景。<span style="color:#008080">רב חלל</span>「一群人舞蹈」或吹笛，<span style="color:#008080">חלל</span> 中省略了 <span style="color:#008080">ו</span>，正如 <span style="color:#008080">חללים</span>（吹笛的人）一样，见 列王纪上 1:40。接着作为对比的，是那死沉、笨重、呆滞不动的一群，<span style="color:#008080">כבד פגד</span>。「归她的人民」或列国，<span style="color:#008080">לגויה</span>，<span style="color:#0000d4">toiv eqnesin authv</span>。——*Sept.* 在 <span style="color:#008080">בנויתם</span> 一词中，我认为 <span style="color:#008080">ת</span> 是 <span style="color:#008080">ה</span> 之误。若取「尸首」之意，则 <span style="color:#008080">ת</span> 之前须有一 <span style="color:#008080">ו</span>；参 <span class="ages-code">&lt;19B006&gt;</span>诗篇 110:6。第三节必须与第二节相连，否则在文法上无从构句。——*Ed.*
