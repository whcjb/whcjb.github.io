# 提摩太前书注释

<p class="title-block-h2" style="text-align:center; font-size:16px; font-weight:bold; margin:18px 0 12px;" markdown="1"><span style="color:#006411">注释</span></p>

<p style="text-align:center" markdown="1">论</p>

<p class="title-block-h2" style="text-align:center; font-size:16px; font-weight:bold; margin:18px 0 12px;" markdown="1"><span style="color:#006411">书信</span></p>

<p class="title-block-h1" style="text-align:center; font-size:22px; font-weight:bold; margin:18px 0 12px;" markdown="1"><span style="color:#0000d4">提摩太、</span> <span style="color:#0000d4">提多与</span> <span style="color:#0000d4">腓利门</span></p>

<p class="title-block-h2" style="text-align:center; font-size:16px; font-weight:bold; margin:18px 0 12px;" markdown="1"><span style="color:#006411">约翰·加尔文 著</span></p>

<p style="text-align:center" markdown="1">由威廉·普林格牧师从拉丁文原文译出</p>

<!-- PAGE 3 -->

<p class="title-block-h1" style="text-align:center; font-size:22px; font-weight:bold; margin:18px 0 12px;" markdown="1"><span style="color:#0000d4">译者序</span></p>

探究为何《提摩太前书、后书》和《提多书》相较于使徒保罗的其他书信，在通俗注释中所受阐释较少，或许是自然而然的疑问。原因大概在于：这些书信主要是写给教会中担任圣职者，而非普通会众的；尽管其中充满每一位基督徒都当殷勤研读的教义陈述与实践教导。

虽然投身于神这部分话语讲解的注释家比人们所期望的要少，但其中的主要主题已经以不同的形式被人得力地处理过。且不必提到早期教父们，只要举出《牧养的*关顾*》、《归正的牧者》以及其他同类著作，就足以说明问题；这些书已经跻身于基督教神学的标准典籍之列。*除了*那些涵盖整个圣工事奉领域的详尽论著之外，其中某些独立的部分有时也被单独选出加以阐发。凡是有助于造就

<p style="text-align:center" markdown="1"><span style="color:#000080">"叫属神的人得以完全，预备行各样的善事。"（提摩太后书 3:17）</span></p>

其中大部分内容涉及牧职的本分。这一点对于宗教的利益具有难以言表的重要性，也当作为神恩典的颂赞而被记录下来：读者所能接触到的关于此主题的宝贵教导，因其作者圣洁的生活与忠诚的热忱而更添分量——这些作者所教导别人的，正是他们自己所忠实实践过的。凡是心志向着圣职的人，或已经受任此职的人，阅读这些书籍必大得益处。

然而在此，正如在一切事上一样，让我们诉诸

<p style="text-align:center" markdown="1"><span style="color:#000080">"人当以训诲和</span> <span style="color:#000080">*法度*</span><span style="color:#000080">为标准。"（以赛亚书 8:20）</span></p>

<!-- PAGE 4 -->
一切引导基督仆人事奉的规章，其根基不可求之于未受默示之人的判断——无论他们何等能干、何等明达——而必须求之于圣经，尤其是《提摩太前书》《提摩太后书》和《提多书》这几卷书信，因此对这几卷书的准确解释，其价值不可言喻。加尔文以其一贯的娴熟功力对这几卷书作了考察，读者必当凝神细听。他的坦诚在此显得格外可贵。他从不将圣灵的话语强解到超出他所看到的自然意思之外，也不为了突出自己独有的见解，就偏离作为释经者严格履行本职的道路。关于这一点，只要看看他对某些福音仆人似乎凌驾于其他人之上所行使之权柄的评论，就足以见到他坚定不移地依据圣经原文、丝毫不在乎那些教会治理观点与他相左之人可能会如何利用这些论述，这就是一个明证。他那纯正无伪的诚实，在这里比在任何别处都更加显而易见。

本卷的注释因大量摘自一部罕见之作——即作者论提摩太前后书的《讲道集》——的引文而更加丰富。若非后人殷切普遍地渴望聆听这位伟大传道者的教诲，那些《讲道集》原本永不会问世。它们乃是随着作者口中所讲述的话语当场记录下来的，其方式与他即席讲授的拉丁文注释相同——关于后者，别处已有若干记述。这些《讲道集》虽为解经性讲章，将两封书信无一处不加以详述，却是向广大基督徒会众所讲说的，并以那种朴实而震撼的呼吁、以及那种令人叹为观止的语言之精妙为其特色——甚至连他的传记作者奥丁（Audin）也不情愿地承认这一点归属于他。

<!-- PAGE 5 -->

<p style="text-align:center" markdown="1">致最尊贵、真正属基督的君王，</p>

<p class="title-block-h1" style="text-align:center; font-size:22px; font-weight:bold; margin:18px 0 12px;" markdown="1"><span style="color:#0000d4">致萨默塞特公爵爱德华</span></p>

<p style="text-align:center" markdown="1">赫特福德伯爵等，英格兰与爱尔兰之护国公，皇家太傅，</p>

<p class="title-block-h2" style="text-align:center; font-size:16px; font-weight:bold; margin:18px 0 12px;" markdown="1"><span style="color:#006411">约翰·加尔文</span></p>

<p style="text-align:center" markdown="1">致以问安。</p>

最尊贵的君王啊，您那卓著的声誉——不仅因您那全然英雄气概的诸般美德，尤因您那出类拔萃的敬虔——在众善人心中激起何等炽热的爱戴，即便是那些未曾一睹您尊容的人也不例外；故此，在英格兰王国之内，凡心地正直之人，无不对您怀有非凡的敬爱与尊崇。这些人所蒙的特权，不仅在于能亲眼目睹那些为他人只能耳闻而心生仰慕的恩泽，更在于能亲身领受一位至为卓越的执政者所能施予全体百姓、并施予其中每一位成员的一切益处。加之，加于您身上的赞誉绝无可疑其虚妄、以为出自谄媚者之口的理由；因为您的行事本身，便是这些赞誉的明证。

当一个学生属于私人身份，且其财富有限时，教师的工作会遇到困难；但你所担任的教师之职，不仅是一位君王的教师，更是一个极其庞大王国的教师，你以如此的智慧与才干履行这一职责，以致众人都为你的成就所惊叹。为使你的美德不仅在律法之中、在国家太平之时闪耀，神也在战事之中将其显明出来——迄今为止，这战事在你的率领之下，同样以顺利和英勇的方式进行着。

<!-- PAGE 6 -->
然而，每个人都能看出您所经历的巨大而繁多的艰难，却并未拦阻您将复兴信仰作为首要目标。这一考量对王国公众之益处的贡献，绝不亚于其配得一位君王的尊贵；因为唯有当国度所建立之根基者、所赖以存续者——神的儿子自己——统治其上时，这些国度才得享稳固的兴盛与忠信的守护。因此，您不可能比藉着除灭偶像、在英格兰立起对神的纯正敬拜，更牢固地建立英格兰王国；因为长久以来被罗马敌基督之亵渎暴政所压制、埋没的敬虔真道，必须得以复兴；而这不正是将基督安置在他的宝座上吗？此举本身已属卓越，而今日承认自己至高之位当臣服于基督属灵权杖的君王为数寥寥，这就更显此举之可称赞。

因此,对这位杰出的君王而言,有这样一位与他有血缘之亲的人来引导他的少年时代,乃是极大的益处。因为,虽然他心志的高贵品格众口称颂,然而在训练他养成刚毅坚定的品格、并在他年幼未能亲自履行这些职责期间治理英国教会一事上,却极需这样一位导师。我毫不怀疑,即便如今他也承认:神藉着他特别的恩慈将您赐给他,好使他不久之后便能从您手中接过治理妥善的国事。

<!-- PAGE 7 -->
就我自己而言，无论地理上的遥远还是我卑微的地位，都不能阻止我为你在推进基督荣耀上所取得的卓越成就向你道贺。既然神喜悦使我成为那些人中的一员——藉着他们的劳苦与辛劳，神在今日将比以往更纯净的福音教义赐给了世界——那么，尽管我与你相隔遥远，我为何不尽力表达我对你的敬意呢？你已藉着神格外的恩慈被立为这教义本身的捍卫者与保护者。既然我没有其他方式可以证明我的敬意，我就想至少作为我心意的凭据，将我对保罗两卷书信的注释献给你，乃是我的本分。我所选的礼物并非随意挑选，乃是经过我的判断，选出在我看来最合适的一份。在这卷书信中，保罗劝诫他所亲爱的提摩太，他当以怎样的教义来建立神的教会，当抵挡怎样的恶习与仇敌，当忍受何等众多的烦扰。他劝勉提摩太不要向任何艰难让步，要以勇气战胜一切危险，要以权柄约束恶人的放纵，也不要因急于讨他们的欢心而滥施恩惠。简言之，在这两卷书信中，教会真正的治理以生动的画卷摆在我们面前。

如今，为要恢复英国教会——她与基督教国度几乎每一处地方一样，已被教皇制那令人震惊的邪恶严重败坏——阁下在王上的引领下竭力尽劳，并为此目的将许多"提摩太"置于您的督管之下。您与他们指导这神圣事务，没有比以保罗在此所定的规则为典范更有益的路径了。因为其中所论，无一不切合我们这时代；凡建造教会所必需的，几乎无一不可从中汲取。我盼望我这番劳作至少能提供些许帮助；但我宁愿这一点由经验来证明，而非由我用言辞夸口。至尊贵的殿下，若您嘉纳这份工作，我便有充足的理由为自己庆幸；而您那非凡的仁慈也不容我怀疑：您必以美意接纳我今所献上的这份事奉。

愿那手中掌管地极的主，长久扶持英格兰国度的安全与昌盛，以王者之灵装饰其显赫的君王，将各样福分丰丰富富地赐给他，并赐给您恩典，使您在这高尚的道路上欢然坚忍到底，好叫他的美名藉着您传扬得越发广远。

日内瓦，1556年*7月25日*。

<!-- PAGE 8 -->

<p class="title-block-h1" style="text-align:center; font-size:22px; font-weight:bold; margin:18px 0 12px;" markdown="1"><span style="color:#0000d4">引论</span></p>

<p style="text-align:center" markdown="1">论</p>

<p class="title-block-h2" style="text-align:center; font-size:16px; font-weight:bold; margin:18px 0 12px;" markdown="1"><span style="color:#006411">提摩太前书</span></p>

在我看来，这封书信之写成，与其说是为提摩太，不如说是为着别人的缘故；凡肯细察全篇者，必会同意此见解。我固然不否认保罗也有意教导和劝勉提摩太，但依我看，这封书信中所含的许多事，若他只是单单与提摩太打交道，则本可不必写。提摩太乃是一位年轻人，尚未披上足以压制那些起来抵挡他的顽梗之辈的权柄。从保罗所用的话语可以清楚看出，那时有些人极其倾向于夸耀虚荣，因此不肯甘心让步于任何人；他们又满怀那样炽烈的野心，若非有比提摩太更大者出面干预，就断不肯罢休扰乱教会。同样明显的是，在以弗所有许多事需要处置，需得保罗的认可，需得他名义的批准。故此，保罗既有意在许多事上劝导提摩太，也就同时决意藉着提摩太之名劝导他人。

*在第一章中*，他攻击某些野心勃勃之人，他们以讨论虚妄问题为夸口。可以清楚地看出，这些人乃是犹太人；他们假装对律法满怀热忱，实则漠视造就人的事，只专注于琐碎无谓的争论。若从神的律法中汲取不到任何有益的教训，反倒只是拾取些谈资，滥用其名义以卑贱琐屑之事加重教会的负担，这乃是对神律法不可容忍的亵渎。

<!-- PAGE 9 -->
在教皇制之下，这类败坏已经猖獗得太久了。因为经院神学岂不正是一堆空洞无益之思辨所堆砌的庞大混沌吗？就是在我们今日，也有许多人为要在处理神的话语上炫耀自己的敏锐，竟容自己以对待世俗哲学的方式戏弄神的话。保罗承担起支持提摩太纠正这一恶习的责任，并指明从律法中应当得出的主要教训是什么；这样便可显明：凡以别样方式使用律法的人，都是败坏律法的人。

接着，为了不使自己的权柄被人藐视，他在承认自己的不配之后，同时以崇高的言辞宣告他藉着神的恩典所成就的一切。最后他以一段郑重的警戒结束本章，藉此既坚固提摩太持守纯正的教义与无亏的良心，又以许米乃和亚力山大的鉴戒使他人心生敬畏与惊惧。

*在第二章中*，他吩咐要为万人，尤其为君王和执政掌权者，向神献上公祷；并在此顺带论及世界从公民政府得着的益处。接着，他指出我们当为万人祷告的缘由；即神藉着将福音和中保基督展示于万人，表明祂愿意万人得救；他又以自己特别蒙召作外邦人使徒的身份，来印证这一论述。其次，他邀请万人，无论国籍或居处何方，都当向神祷告；并借此机会，教导妇女在圣会中当持守的端庄与顺服。

*在第三章中*，在宣告了监督职分的尊贵之后，他描绘了一位真正的监督，并列举了监督所应具备的资格。接着，他描述了执事的资格，以及执事和监督之妻子的资格。为使提摩太在遵行诸事上更加勤勉尽责，他提醒提摩太，受托治理"神的家、真理的柱石──教会"是何等重大的事。最后，他提到全部属天教义中最首要、最根本的一点──即那位在肉身中显现的神儿子；与这一点相比，那些他所察觉野心之辈全然专注的其他事物，都当被视为毫无价值。

<!-- PAGE 10 -->
至于接下来的内容，在**第四章**开头，他严厉谴责了禁止嫁娶和禁戒各样食物的假教义，以及与此教义相悖的荒谬虚构故事。接着他又补充说，他自己和所有持守这教义的良善之人所面对的敌手，无非是那些不能容忍人将信靠倚托于永生神的人。在本章末尾，他再次以一番新的劝勉坚固提摩太。

*在第五章*，他在推荐了责备中的谦和与温柔之后，论及寡妇，就是当时被接纳进入教会事奉的那些人。他吩咐不可不加分辨地收纳她们，只可收纳那些一生皆经查验、已届六十岁、且无家庭牵累者。由此他转论长老，阐明长老在生活样式与执行纪律两方面应当如何行事为人。使徒以庄严的誓言封印这教训，并再次禁止提摩太轻率地按立任何人担任长老的职分。[^f1] 他劝提摩太当喝点酒，不要单喝水，以保养身体。在本章末尾，他劝提摩太对于隐藏的罪过，当延迟宣告判决。

*在第六章中*，他教导仆人应尽的本分，并借此机会对假教师发出严厉抨击——这些人争辩无益的空谈，贪图利益胜过造就人，他又表明贪婪乃是最致命的瘟疫。随后，他再次发出与前面类似的郑重嘱咐，使他此刻给提摩太的劝勉不致徒然。最后，在略略提及财富之后，他再次禁止提摩太陷入无用的教义之中。

<!-- PAGE 11 -->
至于希腊文抄本通常的题注说这封书信是从老底嘉写的，我并不认同。因为保罗在坐监中写信给歌罗西人时，明确表示他从未见过老底嘉人；那些持我所反对之见解的人，就被迫在小亚细亚设立两个老底嘉，尽管历史学家只提到一个。此外，保罗前往马其顿时，把提摩太留在以弗所，这是他自己明确宣告的。他写这封书信，要么是在途中抵达之前，要么是在旅程归来之后。而老底嘉显然比以弗所距离马其顿更远；保罗归来时不太可能绕过以弗所前往老底嘉，尤其是有许多缘由促使他去访问以弗所。因此我更倾向于认为他是从别处写的。不过这件事并非重要到我要与持不同意见者辩论。让各人凭自己的判断去看便是。我只不过指出——至少在我看来——更为可能的说法罢了。
