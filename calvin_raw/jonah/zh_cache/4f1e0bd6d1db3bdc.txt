从前文的“说”可见，他在此所述的，是他在鱼腹中所献的祷告，而非得救之后所献的祷告。有些人持后一种看法，因为这里有些动词是过去时态；但这情形只表明，他从被鱼吞下之时起，直到得蒙拯救之时，一直不断地祷告。这是一个持续的行动。这就如同他说：“我曾呼求，且仍在呼求耶和华。” *Marckius*，以及 *Dathius*，都将这些动词译为现在时态：“我呼求”等等。以下是按照对此祷告的这种理解所作的翻译，—— <span style="color:#000080">*3. 我在患难中呼求耶和华，他必应允我；*</span> <span style="color:#000080">*我从阴间的腹中呼号，——你听我的声音。*</span> <span style="color:#000080">*4. 你将我投下深渊，直到众水的中心，*</span> <span style="color:#000080">*大水环绕我，——*</span> <span style="color:#000080">*你的波浪洪涛都漫过我身；*</span> <span style="color:#000080">*5. 我便说，我从你眼前被驱逐了；——*</span> <span style="color:#000080">*然而我仍要仰望你的圣殿。*</span> <span style="color:#000080">*6. 诸水环绕我，及于我魂，*</span> <span style="color:#000080">*深渊围困我，*</span> <span style="color:#000080">*海草缠绕我的头：*</span> <span style="color:#000080">*7. 我下到山根的断裂之处；*</span> <span style="color:#000080">*大地啊！它的门闩*</span> <span style="color:#000080">乃</span> <span style="color:#000080">*常在我四围：*</span> <span style="color:#000080">*但你必将我的性命从灭亡中救出，*</span> <span style="color:#000080">*耶和华我的神啊。*</span> <span style="color:#000080">*8. 我心在我里面发昏之时，*</span> <span style="color:#000080">*我就记念耶和华；*</span> <span style="color:#000080">*我的祷告必进到你面前——*</span> <span style="color:#000080">*达到你的圣殿。*</span> <span style="color:#000080">*9. 那信奉虚无之偶像的人，*</span> <span style="color:#000080">*离弃自己的怜爱：*</span> <span style="color:#000080">*10. 但我必用称谢的声音向你献祭，*</span> <span style="color:#000080">*我所许的愿我必偿还：*</span> <span style="color:#000080">*救恩*</span> <span style="color:#000080">属</span> <span style="color:#000080">*乎耶和华。*</span> *Parkhurst* 说，第7节中的“断裂之处”，是指洪水之时从群山*断裂*而下的那些部分。七十士译本作 <span style="color:#0000d4">scismav</span> ——裂口、裂缝。有些人采用“根”、“底”、“基”等译法，但与原文词义不合，——大地的“门闩或门栓”传达出他归回地上之路受阻的意思。它们“在”他“四围”，或字面作“在他之上”，<span style="color:#008080">בעדי</span>，就是说，它们仿佛已在他身上关闭了。— *Ed.*
