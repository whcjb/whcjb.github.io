<p class="title-block-h1" style="text-align:center; font-size:22px; font-weight:bold; margin:18px 0 12px;" markdown="1"><span style="color:#0000d4">圣物的供献</span></p>

<p class="title-block-h2" style="text-align:center; font-size:16px; font-weight:bold; margin:18px 0 12px;" markdown="1"><span style="color:#006411">利未记 24</span></p>

<p style="text-align:center; margin:18px 0;" markdown="1"><span style="color:#000080">前往 利未记 24:5-9</span></p>
<p style="text-align:center; margin:18px 0;" markdown="1"><span style="color:#000080">前往出埃及记 29:38-46</span></p>
**38.** <span style="color:#800000">*你每天所要献在坛上的。*</span> 我认为把每日献的祭放在诸祭之首是合宜的，这祭被称为常献的祭；因为神愿意人每早晨、每黄昏各献给祂两只羊羔，使百姓可以不断操练自己，思念那将来的和好。然而，虽然律法之下的祭物不断重复献上，因为它们的献上本身在赎罪上并无效力，但我们仍当留意：正如大祭司每年一次带着血进入至圣所，如今另有一类祭牲每日摆在百姓眼前，这也是于他们有益的，好叫他们思想自己时刻需要与神和好。因此每日用两只羊羔行赎罪之礼，为使以色列人从一日之始到一日之终都被提醒自己的罪咎与该受的定罪，从而学会奔向神的怜悯。为此祭所选的羊羔是无瑕疵、完全的，因为提到它的年龄（一岁）便意味着它的完美无缺。它是与调油的细面饼并奠的酒一同献上；无疑，古时的人从这些象征中受教：向神献上淡而无味之物是不合法的。诚然，神并非因它们的馨香之气而得满足，也不是要使祭司习于美味，以宗教为名作享乐之徒；因为酒的香气本身不能使神喜悦；这些调味之物的用意，乃是使百姓不停留在赤裸空洞的表记之上，而要承认在其底下有更美更卓越的实体。那么，酒与油的香气，无非就是属灵的真理；即百姓在他们那一方面，当把信心与悔改带到祭物面前。诚然，外在的礼仪若无实体，便纯粹是愚妄。就连外邦人也部分地效法了这仪式；由此贺拉斯（Horace）有言——

<p style="text-align:center; color:#000080; margin:14px 2em;" markdown="1"><span style="color:#000080">*“Utque*</span> <span style="color:#000080">*sacerdotis fugitivus, liba recuso: ”*</span> [^f230]</p>

<p style="text-align:center; color:#000080; margin:14px 2em;" markdown="1"><span style="color:#000080">*“我像逃离祭司的人一般，拒绝那些祭饼：”*</span></p> <!-- PAGE 195 --> 他借此暗示，各处都有饼被献给偶像。然而这只不过是盲目的效仿，因为他们的眼光并不向上，反倒以为他们的神像人一样，喜爱香甜精美的食物；而正如我上文所提示的，神的用意却大不相同；因为祂要藉着外在的香气激动祂的百姓，使他们怀着真诚的悔改之情和纯正的信心，不在他们所看见被杀的羔羊里，而在应许给他们的祭牲里寻求罪的赦免。他们称之为「常献的」祭，因为神吩咐这祭要世世代代不断地献上；但从但以理书可见，这祭是暂时的，因它在基督降临时便止息了；因为天使如此说：基督

<p style="text-align:center; color:#000080; margin:14px 2em;" markdown="1"><span style="color:#000080">「必与许多人坚定盟约，一七之内，</span> <span style="color:#000080">他必使祭祀与供献</span> <span style="color:#000080">（</span><span style="color:#000080">*minha*</span><span style="color:#000080">）</span> <span style="color:#000080">止息。」</span> [^f231] <span style="color:#000080">（</span><span style="color:#000080">但以理书 9:27）</span></p>

显然他所说的正是这一类的祭。由此我们可以确知，百姓的心思藉着这祭被引向基督。但若这在古人身上乃是它的功用与目的，如今它的益处便归回到我们身上，使我们晓得，当时在形像之下所显明的一切，都在基督里得了成就。神应许这祭在祂面前要作「馨香之气」。[^f232] 因此我们不可怀疑，祂已藉着祂独生子的献祭完全向我们施了怜悯，并赦免了我们的罪。虽然基督只一次献上，好使祂藉那一次的献上使我们永远被分别为圣归给神，然而藉着律法之下这每日的献祭，我们得知因祂之死的恩惠，赦免总是为我们预备好的；正如保罗所说，[^f233] 神在福音中将基督的祭摆在教会面前时，便不断使自己与教会和好。至于 *minha* [^f234] 一词，虽然它源自 <span style="color:#008080">נחה</span> *nachah*，意即献上，我们仍须认定它是特别用于这项供物的，而这供物乃是每日献祭的一种附加之物。也有人将它单单限于晚祭，但当它与祭牲连用时，它也普遍地延伸到别的供物上。

<!-- PAGE 196 -->
**42.** <span style="color:#800000">*会幕门口*</span> [^f235] <span style="color:#800000">*，就是聚会的帐幕。*</span> 这段经文向我们表明，<span style="color:#008080">מועד</span> *mogned* 一词与帐幕连用时是何意义。有人译为「见证」，有人译为「教会」，有人译为「集会」（*conventum*），有人译为「约定」（*constitutum*）；但它的词源在此处已足够显明，因为摩西说明这名称的缘由时，用了 <span style="color:#008080">יגד</span> *yagnad* 一词，此名即由此而来。那么，何谓相会的帐幕？神自己回答说，这是祂为祂的百姓所拣选、所指定的地方，使他们可以在那里彼此相会。有人以为其字根是 <span style="color:#008080">עדה</span> *gnadah*，意即以庄严仪式作郑重宣告；但既然这与文法不合，我便采取确定无疑的解释。<span style="color:#008080">יעד</span> *yagnad* 一词在这种构句中，意思是与人立约或议定，或至少是为处理彼此的事务而聚集；因此，在我看来，没有别的词比「相会」（*convention*）更接近它的意思了；因为神邀请他们与祂亲密交谈，这对于保守信徒对祭司应有的谦逊敬重，具有极重的分量。在下一节中，祂用第三人称向他们重申：凡愿被算在以色列人中的，都不可转离或漂流他处；因为已为以色列众子定下律例，要他们在那里寻求神。此外还附上另一重印证，即：这地方当被分别为圣，因为神要在那里荣耀地彰显祂的荣光。总之，从全段看来，神的心意是要藉利未祭司职分的联结，将百姓系于祂自己；然而我们必须留意，唯有神使这地方、这些祭物、并这些人成圣。所以，那些僭取超过神所赐与他们之地位的人，其夸口实属无谓。若我们信教皇的话，圣洁之圣洁便在他身上；然而，既然他并未为此拿出神的授权，只是以毫无根据、凭空杜撰的名号自夸，我们尽可放心讥笑他愚妄的厚颜。但从这处及类似的经文，我们得着这样的教义：不可按人的方式估量基督，乃当按祂属天与属神的能力来看祂。由此，教皇派祭司「献上基督」的夸口也被驳倒了；因为我们必须常常追问他们：凭什么权柄？既然神单单为自己保留了这使人得以行合法祭司职分的成圣之权。

**46.** <span style="color:#800000">*他们就必知道我是耶和华。*</span> 神藉这些话表明，祂不只在一次事上作了祂百姓的拯救者，乃是要主宰他们的福祉，并以实际行动证明祂住在他们中间。此外，祂设立圣所作为祂同在的记号，可说是其凭据；祂要敬虔的准则由此发出，也要祂的敬拜者在此寻求。

<p class="title-block-h2" style="text-align:center; font-size:16px; font-weight:bold; margin:18px 0 12px;" markdown="1"><span style="color:#006411">民数记 28</span></p>

<p style="text-align:center; margin:18px 0;" markdown="1"><span style="color:#000080">前往 民数记 28:1-15</span></p>
**1.** <span style="color:#800000">*耶和华晓谕摩西说。*</span> 摩西既要再次论及那「常献的」祭，便先在总体上申明：百姓在献祭之时，凡神所吩咐的都当殷勤遵行；因为「谨守」（*custodiendi*）一词所表达的，不仅是殷勤，也是顺从。然而，为要使他们更加认真地防避一切违犯，神把那素常每日摆在桌子上的，或是附加于燔祭之上的，称为*祂的*食物，仿佛祂如同人一样吃它。这诚然是一句难解的说法，但祂古时百姓的粗陋迫使祂如此粗浅地说话，好使他们一方面得以学知：这礼仪为神所悦纳，正如食物为人所悦纳；另一方面也使他们竭力更纯洁、更贞洁地献上他们的祭物。

**3.** <span style="color:#800000">*你要吩咐他们说。*</span> 他重述了我们在出埃及记中所见的：他们当每日宰杀两只羊羔，一只在早晨，一只在晚上；但他更详尽地讲到与之相伴的细面与酒，并且提到这类祭的古老性，作为其可称之处，因为它是在西奈山上开始献与神的，且是「馨香的火祭」。[^f236] 此处所提及的奠酒，在外邦诸族中亦有通行；但因其没有神的命令与应许，就不能不是毫无意味的（*insipidum*）。[^f237] 并且（如我们在别处所见），外邦人许多礼仪很可能是从古时列祖那里传下的，却只是虚假空洞的效法；因为他们既已忘却其中的缘由，他们所行的一切便只能是纯然的戏台排场。但我们已经说过，如此便是提醒人在日用饮食中总要将神摆在眼前；因此要在各方面习惯于操练圣洁。

<!-- PAGE 198 -->
**9.** <span style="color:#800000">*当安息日。*</span>前一处经文中所省略的，在此得以补足，就是说，在安息日，常献的祭要加倍，献两只羊羔而非一只；因为这是合宜的：既然第七日是特别分别为圣归给神的，就当以某种非凡而独特的记号使它超乎其余的日子之上。祂又吩咐在月朔，即新月之初，要献上更大的祭物，即两只公牛犊、一只公绵羊，并一只公山羊作赎罪祭；因为我们知道，每月的初一日都是分别为圣归给神的，为要使百姓更频繁地重新记起他们敬虔的本分；而那作赎罪之用的公山羊被加上，乃是为叫他们每月都在神面前以有罪之人的身分呈现自己，以求息祂的忿怒。

<p class="title-block-h2" style="text-align:center; font-size:16px; font-weight:bold; margin:18px 0 12px;" markdown="1"><span style="color:#006411">民数记 28</span></p>

<p style="text-align:center; margin:18px 0;" markdown="1"><span style="color:#000080">前往民数记 28:16-31</span></p>
**16.** <span style="color:#800000">*正月十四日。*</span>诚然，这里所赐的训诲与逾越节的筵席有些关联，但既然此处明明是论到献祭的事，而除本处之外并未提及逾越节其余的规条，我便把它与常献的祭连在一起，视为其附随之事或其一部分。摩西固然顺带提到我们前面已经看过的事，即百姓当七日之内除去酵，吃无酵饼；但随后他便进入他在此所要论述的要点，就是百姓当献两只公牛犊为燔祭，并一只公绵羊、七只羊羔，又要献一只公山羊为赎罪祭；且这祭要在整个七日之内反复献上。这样，为使逾越节所受的尊崇得以加增，这特别的祭便加在常献的祭之上：一方面使他们藉此愈发受激励，将自己献给神；一方面使他们承认神以怎样亲密的慈爱怀抱他们，因为祂是从他们的羊群牛群中取这些供物，又要人也从他们的地窖和仓廪中为祂预备圣洁的筵席；再一方面，也使他们自认是配受永死的，好逃奔到祂那里求赦免，同时明白只有一条和好之路，即神因祭物而得以息怒。

<!-- PAGE 199 -->
**26.** <span style="color:#800000">*又在初熟之日。*</span>摩西就另一个节期，即他们献初熟之物的那节期，颁下同样的诫命。他教导他们说，那时也当在常献的祭上加添两只公牛犊、一只公绵羊、七只羊羔、一只公山羊为赎罪祭，连同 *minha*（素祭）与奠祭，其目的我已经讲过。此处出现一个令人费解的难题，因为在利未记 23 章里，所提的不是两只公牛犊，而是一只；反之，所提的不是一只公绵羊，而是两只。[^f238] 有些人以为在这事上是任凭祭司选择；但当我思想神在万事上所赐的命令是何等精确时，我便怀疑这样的取舍是否交由他们裁量。有人以为，神曾一度只满意于一只公牛犊，因为在旷野中牲畜并不丰足——在我看来这是一种遁辞。我承认我不知道如何解开这难题，除非我们或可这样说：既然在其余一切细节上，神已作了足够精确的规定，使凡事都不至无因而行，那么单在这一点上，他们乃是受提醒：神本身并不在乎祭牲的多寡大小。我们若说，正如在次要之事上时有发生的，这里的数目或因抄写者的疏忽而有讹误，[^f239] 也无损于当有的敬畏；而这大概是最自然的解答。依我看来，较正确的读法是，他们当献两只公牛犊、一只公绵羊；但既然别处已解释神为何设立这日，他在此只简略提说：「当他们把初熟之物同 *fainha*（即 minha，素祭）一并带来的时候。」

<p class="title-block-h2" style="text-align:center; font-size:16px; font-weight:bold; margin:18px 0 12px;" markdown="1"><span style="color:#006411">民数记 29</span></p>

<p style="text-align:center; margin:18px 0;" markdown="1"><span style="color:#000080">前往民数记 29:1-39</span></p>
**1.** <span style="color:#800000">*七月初一日。*</span> 我已经指出，这里所论的并非（一般而言的）节期，而只是那些用以增添节期庄严的祭物。七月之初有所谓吹角的纪念日。因这是较次要的节期，摩西只吩咐宰杀一只公牛；但出于别的缘由，牛的数目有所增加，因为我们前面已经看到，每月初一要献两只公牛。因此，这一日有三只较大的祭牲，而其余祭牲的数目则加倍，即两只公羊、十四只羊羔。如此，神便使这一日双重地归祂为圣，好使这一个庆典丝毫不减损另一个；否则祂就似乎废除了自己曾一度所吩咐的。所以，吹角的纪念并不废去月朔之礼，而是他们同时遵守这两项条例。

<!-- PAGE 200 -->
**7.** <span style="color:#800000">*七月初十日。*</span> 这是赎罪日。因为他们虽然从不曾不带着求赦免的祈求就来到神面前，但在这一日他们却以特别的方式承认自己的罪，因为神定下禁食，作为他们有罪的标记。因为利未记 23:29 如此记着说：

<p style="text-align:center" markdown="1"><span style="color:#000080">「当这日，凡不刻苦己心的，</span> <span style="color:#000080">必从民中剪除。」</span></p>

至于祭物，只要求献一只公牛；其余的与前面所述相同，只是加上了一项例外，这在先前的条例中是略去的。因为除那只公山羊之外，另有一祭被指定为挽回祭，与他们刻苦己心的事相称。因为若没有和好的盼望，认罪之意识对他们的良心必成为可怕的折磨。这祭的缘由随后即会说明。

**12.** <span style="color:#800000">*七月十五日。*</span> 在他们的众节期中，这末一个是最主要的，[^f240] 他们要在其中住棚七日；因为在

在逾越节，他们纪念自己脱离埃及诸灾、得着自由的那一夜；而借着住在帐棚里，他们则总括了那整整四十年——在旷野中他们的列祖持续经历神完全无缺的丰厚恩慈。这庄严的聚集还有另一个当下的用处，*即*为收成的丰收向神献上感恩。因此他们每日献祭，且数目众多：头一日，十三只公牛、两只公绵羊、十四只羊羔；第二日，十二只公牛；第三日，十一只；第四日，十只；第五日，九只；第六日，八只；末了第七日，七只；第八日，一只。摩西不惜用如此多的话语来逐一列举，绝非漫不经心：*第一*，为使一切都不得擅自行事，唯照神的吩咐；*第二*，免得他们觉得这样巨大的耗费令人厌烦或不堪负担，以致乐得逃避。因此，为使他们能甘心乐意地遵从神的命令，他勤勉地反复申明神要人每日向祂献上何等的祭牲。至于为何分配得如此不均，我承认对我并不明朗；与其以过于精微的揣测化为一缕青烟，不如坦承自己的无知。[^f241]

<!-- PAGE 201 -->
的确，有一种看法既不算好奇附会，也不当弃绝，*即*：由于每日递减其数，他们到第七日终于归到「七」这个数目，而七乃是完全的象征；至于第八日之所以附加上去，仅是作为一个总结。最后，摩西补充说，无论在那常献的祭上，或在这些特殊的祭上，他们都当坚守神所规定的，使一切不至按人的私意有所更改。至于那些系于第二版律法诸诫命的祭礼，我是刻意留待其合宜之处再论。
