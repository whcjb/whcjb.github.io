本节中所有的动词，在七十士译本中都是第三人称，<span style="color:#0000d4">koyetai</span>—「她必哀号」等。整节都应用在撒玛利亚身上。希伯来文也容许这种意思，只要把这些动词视为 Hiphil 式（它们本可如此），而 <span style="color:#008080">ו</span> 的省略也并非罕见。如此，这两节的译法便是：— <span style="color:#000080">*8. 因此我必使她悲哀哀号，*</span> <span style="color:#000080">*我必使她赤脚露体而行；*</span> <span style="color:#000080">*我必使她哀号如大鱼，*</span> <span style="color:#000080">*悲鸣如鸵鸟：*</span> <span style="color:#000080">*9. 因为*</span> <span style="color:#000080">她的伤痕必是</span> <span style="color:#000080">*沉重的；*</span> <span style="color:#000080">*且必*</span> <span style="color:#000080">要</span> <span style="color:#000080">*临到犹大，*</span> <span style="color:#000080">*达到我民的城门，就是耶路撒冷。*</span> <span style="color:#008080">תגים</span> 一词，在我们通行的译本中、加尔文以及其他许多人都译作「野狗（龙）」，*Newcome* 译作「狐狸」，*Henderson* 译作「豺狼」，而 *Bochart* 则译作「鲸」，或称为「海豚」的那一类；*Professor Lee* 在其《约伯记 40:25 注》中，似乎也持相同看法。据说海豚被捕时所发的哀鸣极其凄惨；史家也曾作证，它们在自由之时，夜间也发出悲哀的呻吟。—<span style="color:#008080">בכית יענה</span>，在我们的译本中作「鸵鸟（枭鸟）」，*Calvin* 与 *Newcome* 都译作「鸵鸟的女儿」，*Henderson* 译作「鸵鸟」。七十士译本作 <span style="color:#0000d4">qugaterwn seirhnwn</span>—「海怪的女儿」；*Aquila* 与 *Symmachus* 则译作 <span style="color:#0000d4">strouqokamhlwn</span>—「骆驼雀—鸵鸟」。字面的说法是「鸵鸟的女儿」，显然指其雌者。*Newcome* 所引 *Dr. Shaw* 的话说：「在夜间那孤寂的时分，它们常发出极其凄凉可怖的叫声。我常听见它们呻吟，仿佛正处在极大的痛苦之中；先知弥迦对此举动的引喻，实在美妙。」—*Ed.*
