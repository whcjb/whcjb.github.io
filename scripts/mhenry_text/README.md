# mhenry 中文正文对照 PDF 全书校正（2026-11-06）

把站内每卷正文（去标签、只留汉字）与中文 PDF 正文（去页眉页脚、去脚注区）按顺序对齐
（两边各只出现一次的 12 字片段作锚、取最长单调序列，锚点之间逐段比较），找出：

| 类别 | 处理 | 脚本 |
|---|---|---|
| 页底丢行/整段丢失（站内缺、PDF 有） | 按 PDF 原文补回 114 处；大段标题补成 mh-l1 块；落在经文框里的注释开头挪到注释段首 | `compare/apply_loss.py`（一次性，依赖对齐结果） |
| 约翰福音每章结尾截断 | 补到下一章标题前，共约 1.4 万字 | `john_chapter_tails.py` |
| 脚注定义/残段拼进正文 | 删除（页底已有该定义） | `remove_junk.py` |
| 小标题文字残留在上一单元末尾（含拖着的第 1 节） | 删除 | `remove_junk.py` |
| 脚注残段顶替正文、与印刷本不符的改写 | 按 PDF 换回 | `replace_text.py` |
| 下一单元首节经文漏进上一单元末尾 | 删除漏入行 | `leaked_verse_lines.py` |
| 经文框内重复/插错位置的经文 | 删多出的那份 | `verse_dups.py` |
| 句中被换行/空行断开（多为跨页） | 接回，经文框不动 | `join_broken_lines.py` |

除 `compare/` 下的一次性工具外，各脚本可重跑，第二遍零改动。
