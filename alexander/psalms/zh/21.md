正如在诗篇第十八篇中，大卫公开为撒母耳记下 7 章所载的应许向神称谢，这里他也把类似的感恩之辞放在教会、即蒙拣选之民的口中。在第 2-7（1-6）节，言说的对象是耶和华，而论到王时则用第三人称。在第 8（7）节，这一说话方式同时用于二者。在第 9-13（8-12）节，言说的对象是王。到第 14（13）节，又转回耶和华。至于这几个相继部分的实质或内容，第一部分为神所赐予王的一切而赞美他，第 2-7（1-6）节。第二部分转入另一主题，第 8（7）节。第三部分为王藉神的怜悯将要成就、将要享受的一切向他道贺，第 9-13（8-12）节。第四部分回到全篇起初所出发的那一点，第 14（13）节。有人认为本篇关乎前一篇中祷告的应验，这看法似乎与上文所述本篇的结构和内容不合。两篇与其说是前后相承，不如说是彼此平行的，其主要分别在于：第二十篇关乎战事中得助与得胜这一具体情形，第二十一篇所指的却是赐给主受膏者的全部神恩的整个范围。

<span class="ax-vnum">1.</span> *交与伶长。大卫的诗。* 第一句题注的准确，从本篇的结构即可看出，全篇说话的乃是古时的教会。至于另一句题注的准确，则可从以下数端推论：其文体与大卫诸篇大体相类，措辞上与之多有吻合之处，又有那种活泼盼望的语气，似乎表明所受的神圣启示为时未久——尤其是与其他方面与本篇相似的诗篇（如第 89 篇）相比较时更是如此。本篇与第 20 篇之间那种特别的相似，使二者互相为对方的真确与可信作证。

<span class="ax-anchor" id="psalms-21-1"></span><span class="ax-vnum">2 <span class="ax-veng">(1).</span></span> *耶和华啊，王必因你的力量欢喜，因你的拯救，他要何等快乐！* 本节以一句总述开始描写神向王所施的恩宠，此后在第 3-7 节（2-6 节）加以铺展。*你的力量，*即赐予他的力量，或为拯救他而施展的力量；后一解与平行的说法最为相合，*你的拯救，即*你搭救他脱离他所感受到或所惧怕的祸患。*在你的力量与拯救中，即*在对这力量与拯救的默想和经历之中。将来时的动词表明这恩赐尚未完全成就，但并不排除它已经开始的意思。

<span class="ax-anchor" id="psalms-21-2"></span><span class="ax-vnum">3 <span class="ax-veng">(2).</span></span> *他心中的渴望你已赐给他，他唇间的所求你并未不许。细拉。*上一节所说的喜乐与欢腾，其缘由在此得到更具体的陈述。虽无明文记载，却不难想见：撒母耳记下第七章中那伟大的应许，正是对大卫长久恳切祈求自己家中有后裔承继的答应。——译作*所求*的那个词仅见于此处，但其意义可由平行体与阿拉伯文的类比断定。将同一意念以肯定与否定两种说法并举（*赐给*与*并未不许*），是希伯来文所喜用的惯用语。

<span class="ax-anchor" id="psalms-21-3"></span><span class="ax-vnum">4 <span class="ax-veng">(3).</span></span> *因为你必带着美福迎向他，你必将精金的冠冕戴在他头上。* 正如路德所言，这是对他所求何事这一问题的回答。那*因为*把本节与前一节的陈述连在一起，此处是对前节的解释与证实。第 3 (2) 节中的过去时表明他的祈求在神的旨意中已蒙应允，这里的将来时则表明这应允将如何在事实上成就。*迎向，*即以友好的态度前来相迎。参看上文诗篇 17:13、18:6 (5)，并参申命记 23:5 (4)。——*美福，*不是指出于神的良善而发的祝福，而是指赐下好景况、福乐，或由好景况、福乐所构成的祝福。参看上文诗篇 16:2。——末句所指的，既不是大卫登基之初字面意义上的加冕，也不是他从拉巴的亚扪王头上取来的金冠（撒母耳记下 12:30），而是指神将这些荣耀的恩惠赐给他自己和他的后裔，由此而来的理想意义上的加冕。撒母耳记下第七章中神的那番晓谕，在此似乎被看作大卫作为神权政体君王唯一真实的加冕。本句末尾的那个词，与诗篇 19:11 (10) 中同寻常的「金」字相对而被译作*精金*的，乃是同一个词。

<span class="ax-anchor" id="psalms-21-4"></span><span class="ax-vnum">5 <span class="ax-veng">(4).</span></span> *生命他向你求，你已赐给*（它）*他，长久的日子，绵延与永远。*若不拘守马所拉的分句符号，句法可以简化而意义不变：「生命他向你求，你已赐给他长久的日子」……。本节末了的两个词常作副词用，意为*直到永永远远；*但既然二者皆是名词，最好在此与紧接其前的同一词类作同位语。末一分句表明，大卫所祈求的生命并非个人的长寿，乃是他后裔无尽的延续；这尊荣已赐给他，且在我们救主身上成就得超乎他的指望与心愿。参撒母耳记下 7:13, 16；诗篇 89:5（4）；132:12。

<span class="ax-anchor" id="psalms-21-5"></span><span class="ax-vnum">6 <span class="ax-veng">(5).</span></span> *他的尊荣因你的拯救而为大；荣耀与威严你必加在他身上。* 他亲身经历了神拯救的恩典，又与那为全人类所设的伟大救恩计划相连，这就把他高举到远超任何别的君王的尊位，足以使圣经中即便最崇高的措辞，也完全免于谄媚或夸大之讥。

<span class="ax-anchor" id="psalms-21-6"></span><span class="ax-vnum">7 <span class="ax-veng">(6).</span></span> *因为你必使他成为永远的福分；你必以你的面容*（或*同在）使他欢欣喜乐。*他不但自己蒙福，也要成为别人的福分；这一意念与措辞皆取自创世记 12:2 对亚伯拉罕的应许，这一暗指也把大卫之约与亚伯拉罕之约连在一起，从而使弥赛亚预言的大链条不致中断。*使他成为福分，*字面作*立他为*（或*定他作）福分。*复数形式暗示其丰盛与多样，如诗篇 18:51（50）、诗篇 20:7（6）。*以你的面容，*或*用你的脸，即*以恩慈垂顾他，不仅是在你面前或你跟前（视之为享受之处所），乃是藉着得见你（视之为其缘由与源头）。参上文诗篇 16:11 的注释。

<span class="ax-anchor" id="psalms-21-7"></span><span class="ax-vnum">8 <span class="ax-veng">(7).</span></span> *因为王*（是）*信靠耶和华的，并在至高者的恩中，他必不动摇。*这荣耀应许的成就固然遥远，但在信心的眼中却是历历可见。*在恩中*所指的，似乎不止于*藉着至高者的恩*（或*眷顾）*，即不止于指他确信的根据或他稳妥的来源。这几个字看来是在限定动词本身，表明他必不致从自己如今在神恩中所站的地位上被摇动。本节论到神与王都用第三人称，这就使它成了一种衔接的环节，把本篇前半直接对神的称呼与后半直接对王的称呼连在一起。

<span class="ax-anchor" id="psalms-21-8"></span><span class="ax-vnum">9 <span class="ax-veng">(8).</span></span> *你的手必寻出你一切的仇敌；你的右手必寻见*（那些）*恨你的人。*既已说明神要为他的受膏者成就何事，本诗转而描写后者藉神的帮助将要成就何事。与主语的这一转换相应的，是称呼对象的转换，前面已经提及。表达形式上有一种层层递进：*手*之后接以*右手*，这是主动之力更为有力的标记。*寻见*一词在此处的关联中，兼含「察出」与「够着」两重意思。参撒母耳记上 23:17、以赛亚书 10:10；后一处经文中该动词与一介词连用，正如本节前半句一样，而在后半句中则直接支配名词。倘若其间原有意义上的分别，大概也不过是英文中 find *与 find out* 之别（即「找到」与「查出」）。

<span class="ax-anchor" id="psalms-21-9"></span><span class="ax-vnum">10 <span class="ax-veng">(9).</span></span> *你必使他们如火炉，在你面前的时候；耶和华必在他的烈怒中吞灭他们，火必烧尽他们。*末句把这毁灭之工归于神，正表明王不过是他手中的器具。*你必使，*字面是*放*或*置，即*使他们处于某种境地。*火炉，*字面是*火的炉（或窑）。*此处说使他们如炉，并非说使他们成为毁灭别人的，而是按自然的省略说法，使他们如同身在火炉之中。*在你面前的时候，*字面是*你的脸，*可解作*当你注视他们之时。*

<span class="ax-anchor" id="psalms-21-10"></span><span class="ax-vnum">11 <span class="ax-veng">(10).</span></span> *你必使他们的果子从地上灭亡，使他们的后裔从* （在）*世人之子中* （或作*亚当之子*）*。* 这是把对仇敌所施的毁灭之威胁延及他们的世世代代。*果子*一词同样的比喻用法见于何西阿书 9:16。

<span class="ax-anchor" id="psalms-21-11"></span><span class="ax-vnum">12 <span class="ax-veng">(11).</span></span> *因为他们向你伸出恶来；他们设下诡计；他们必不能够*（成就它）。前一分句的比喻与历代志上 21:10 相同。（参撒母耳记下 24:12。）此处的意思是，他们威胁要降祸于你。由于「*能够*」这动词有时作绝对用法，故译为「*他们必不得逞。*」

<span class="ax-anchor" id="psalms-21-12"></span><span class="ax-vnum">13 <span class="ax-veng">(12).</span></span> *因为你必使他们转背；你必用你的*（弓）*弦对着他们的脸预备妥当。*第一个词通行译法作「所以」（therefore），不但与惯用法相违，而且因遮蔽了与上一节的连接而扰乱了文义；那连接本是这样：「他们必不得胜，*因为*你必使他们转背。」后一短语在希伯来文中惯用语色彩极浓，几乎无法确切迻译。*你必使*（或*置）他们肩背。*参看前面诗篇 18:41 (40) 的注释，那里出现了类似的惯用语。在本节中，时间次序被颠倒了：正是因着向他们的脸射箭，他才使他们转背。英文圣经借补入一个表时间的虚词来标明两个分句的真实关系：「你必使他们转背（当）你把（你的箭）搭在弦上对着他们的脸预备妥当（之时）。」*预备妥当*这一译法也是正确的，虽然有人把这短语译作*瞄准*，而瞄准实际上是由同一动词的另一形式表达的。此处所用这一形式的真义，从诗篇 11:2 可以看得明白；二者的分别用法，则可参诗篇 7:13, 14 (12, 13)。

<span class="ax-anchor" id="psalms-21-13"></span><span class="ax-vnum">14 <span class="ax-veng">(13).</span></span> *耶和华啊，愿你在你的力量中被高举；我们要歌唱，要颂扬你的大能。* 此处本篇重归于神这一大主题，将一切荣耀都归给他。*被高举，*即受尊崇，既在你自己里面，也在你子民的颂赞之中。参看上文诗篇 18:47（46）的注释。*你的力量与大能，*即显明在赐给你受膏者的力量之上。*颂扬，*以乐声颂扬，这希伯来文动词素来如此。本节有一极优美的对照，仿佛他说：你只要配得称颂，我们便必献上称颂。
