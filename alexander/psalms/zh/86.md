<span class="ax-anchor" id="psalms-86-1"></span><span class="ax-vnum">1.</span> *祷告。大卫的。耶和华啊，侧耳*垂听（并）*应允我，因为我是困苦穷乏的*。全篇称为祷告，因为通篇所包含的，不是直接的祈求，便是用以申明祈求的理由。此诗的语调与内容，极合于大卫在扫罗或押沙龙手下受苦的日子，更可能是后者，因为诗中屡次提及从先前同类试炼中蒙拯救。有人解释此诗何以置于一连串题为*可拉后裔的*诗篇之中，以为是可拉后裔代大卫立言、或按大卫的心志而作。参看前面诗篇 84:1 的注释。这些解经者又用同一假设来说明诗中许多借自大卫其他诗篇的措辞，仿佛*可拉后裔*有意重述他昔日在别的处境中所说的安慰之言来安慰他。参哥林多后书 1:4。此诗不容作细密或人为的分段。各部分唯一显著的差异在于：第 1-10 节祈求与论据相间，而第 11-17 节则较为纯粹的祈求。本节所提出的第一个理由或根据，取自需要的急迫。与此同时，其中也暗含一项要求神保护的凭据，即求告者乃是属他自己的子民中的一人。按诗篇的用法，困苦的与穷乏的，是指神子民中受苦的人。参看前面诗篇 10:2 的注释。

<!-- PAGE 369 -->
<span class="ax-anchor" id="psalms-86-2"></span><span class="ax-vnum">2.</span> *保守我的性命，因为蒙恩的一位*（是）*我；拯救你的仆人，就是你，我的神，那*（仆人）*信靠你的。*他求神保守他的魂或性命，因为仇敌所威胁的正是这个。见下文第 14 节。他所陈明的理由有两条，或者不如说是同一条以两种形式表达。第一条是：他是一个（חסיד）圣徒或蒙恩之人，一个有怜悯之心、因而配得神怜悯的对象。见上文诗篇 85:8 (7) 的解释。另一条是：他既为耶和华的仆人，就单单信而倚靠他。原文的用语不是*在*你里面，而是*向*你或*朝着*你，仿佛是说：信的人从一切别的倚靠根基转过身来、把目光移开，单单投向神。同样的结构上文出现过两次，见诗篇 4:6 (5)、31:7 (6)。

<span class="ax-anchor" id="psalms-86-3"></span><span class="ax-vnum">3.</span> *求你恩待我，主啊，因为我要整日向你呼求。*这祷告实质上仍与前相同，只是又加上了两重理由：一重隐含在所用的神名之中，即神是他的君主，既是君主，就有保护其臣民的责任；另一重则明说出来，即他的臣民从不停止求他相助。动词的将来时含义包括现在，却又添上一层意思，就是立定心意要如此行下去，直到得着所求的福分。参创世记 32:27（26）、路加福音 18:1。*整*日是一个常见的惯用语，相当于英文的*all the time*（一直、时时），因此虽未在形式上说出，却可视为包含了*每日*或*天天*的意思。参看上文诗篇 42:4, 11（3, 10）。

<span class="ax-anchor" id="psalms-86-4"></span><span class="ax-vnum">4.</span> *使你仆人的心欢喜，因为我的心仰望你，主啊。* 前一分句并不只是「使我欢喜」或「叫我喜乐」的换说法。它的意思是「使我由衷地欢喜，因为我是你的仆人」，这就为他的祈求提出了一个新的根据，形式上虽与前一节所提的不同，实质上却是一样的。那一节的后一分句与本节的后一分句之间也有类似的对应关系，只是本句的形式取自诗篇 25:1。此处与那里一样，将心魂举向神，就是以爱慕与坚强的信靠仰望他。见上文诗篇 24:4 的注释。同时，这里也暗指希伯来动词的严格本义，仿佛他说：「使我的心欢喜，因为我正是为此才把它举起、仰向你。」将来时的意味与第 4 节相同。

<span class="ax-anchor" id="psalms-86-5"></span><span class="ax-vnum">5.</span> *因为你，主啊，本为良善，乐意饶恕，且以丰盛的慈爱待一切*（那些）*呼求你的人。*神不但是他子民的君王，因而凭约有责任保护他们，他在自己的本性上也是仁慈的、良善的；这良善不仅是泛泛而言的，或是对他一切受造之物而言的，更是特别针对那不配得的与该受刑罚的，就是说，针对他们中间真心渴慕他恩眷、并以求告这一举动表明自己愿意得着它的人。*以丰盛的*（）*慈爱，*字面作*大*（或多、充足、丰盛，就）*慈爱*（而言）。这一说法，实则连同整段描述，都是取自出埃及记 34:6。

<!-- PAGE 370 -->
<span class="ax-anchor" id="psalms-86-6"></span><span class="ax-vnum">6.</span> *耶和华啊，侧耳听我的祷告，并留心*（或*垂听）我恳求的声音。* 同样的两个动词也以类似的连用出现在诗篇 5:2, 3（1, 2）。希伯来文中的末一词，按其字源，特指为求恩惠、恩典或怜悯而发的祷告。参看前面诗篇 28:6、31:23（22）的注释。此处除了刚才解释的那个词，以及首句中所用的神名所含的意思之外，并未提出新的理由或论据。

<span class="ax-anchor" id="psalms-86-7"></span><span class="ax-vnum">7.</span> *在我患难的日子我要呼求你，因为你必应允我。*将来时包含现在：我现在呼求你、也必要呼求你，呼唤你来相助，或向你求援。第二分句给出理由，即他深信自己的呼求必不落空。这一确信所隐含的根据是：凡他凭信心呼求的时候，从来没有、也不会不蒙垂听、不蒙应允。

<span class="ax-anchor" id="psalms-86-8"></span><span class="ax-vnum">8.</span> *诸神之中没有像你的，主啊，也没有像你作为的*（在他们的作为之中）。末了这几个字，看似为补全文意与平行体所必需，却被略去了，或许是为了暗示一个意思：诸神并没有作为，连敬拜它们的外邦人自己也不过是耶和华所造的，正如下一节所明说的。然而，即便上半句中那完整的比较，也未必是承认诸神自身有位格的存在，所承认的至多是它们那些物质偶像的存在，或者至多是它们那些昏愦的敬拜者心中的信念。可将本节与它所依据的摩西的范本相比，出埃及记 15:11，申命记 3:24，以及大卫对这些话的仿效，撒母耳记下 7:22，诗篇 18:32(31)。此处把耶和华独一的神性提出来，作为向他恳切祈求的一个独立的根据或理由。

<span class="ax-anchor" id="psalms-86-9"></span><span class="ax-vnum">9.</span> *你所造的万民都要来，在你面前敬拜，主啊，并将荣耀归与你的名。* 耶和华作为万人的创造主，与万人同有的这一层关系，如今虽为多数邦国所否认，终有一日必被普世承认；且不仅口里承认，更在行为上承认，就是在敬拜这最能表明心意的行为上承认，其中含有以信心认定神先前所显明的诸般完全——圣经称之为他的*名*。这种预见全地归信并事奉其创造主的眼光，足以显明旧约的作者们何等远离后来那些较少蒙光照的犹太人所持的狭隘民族观念，既不怀抱它，也不纵容它。参看前面诗篇 22:28, 29（27, 28）、45:13-17（12-16）、47:10（9）的注释，并参耶利米书 16:19，西番雅书 2:11，撒迦利亚书 14:9, 16。

<span class="ax-anchor" id="psalms-86-10"></span><span class="ax-vnum">10.</span> *因为大哉*（是）*你，又行奇事，你*（是）*独一的神。* 此处唯一的新意，是耶和华以其奇妙的作为证明了他独一的神性。节首的 *因为，*暗示这些神性的凭据迟早必产生其完全的效力。

<span class="ax-anchor" id="psalms-86-11"></span><span class="ax-vnum">11.</span> *指引我，耶和华，*（在）*你的道；我必行在你的真理中；使我的心合一，好敬畏你的名。* 通行译本将首个动词译作「教训我」，失之宽泛，未能显出此词特别适合表达这里所指的那一种教导。该希伯来词的本义是指出或标明道路。按诗篇的用法，神的*道*在此是指他护理作为的进程，他的*真理*则指他应许的信实，*行*在其中便是认同这些应许，或说安息于其中并信靠之。参看上文诗篇 25:4, 5 和 26:3 的解释。末句所求的，是愿他能毫无分心、毫无保留地如此而行。心的合一，其反面便是二心。参看上文诗篇 12:3 (2) 的解释，并比较雅各书 4:8。

<!-- PAGE 371 -->
<span class="ax-anchor" id="psalms-86-12"></span><span class="ax-vnum">12.</span> *主我的神啊，我要一心称谢你，我要荣耀你的名，直到永远。* 第一个动词并非泛指颂赞，而是为所蒙的恩惠而称谢。参看上文诗篇 6:6（5）的注释。本节所描述的，是前一节末尾那祷告蒙允准之后必然随之而来的果效。他的心一旦专一敬畏神，发自衷心而永不止息的感恩便是必然的结果。

<span class="ax-anchor" id="psalms-86-13"></span><span class="ax-vnum">13.</span> *因为你的怜悯*（向来）*是大的，临到我身上，你已救我的*魂*脱离最低的阴间。*这几句话最自然的解释，是把它们看作诉诸从前的怜悯，作为盼望新怜悯的理由。倘若本篇属于押沙龙叛乱的时期（见上文第 1 节的注释），这里所指的或许是大卫在扫罗手下所遭的危难与所得的拯救。*临到我身上，*字面作*在我之上，*其中含有自上而下的意思。*阴间，*取其广义，即死亡或死人的状态。见上文诗篇 6:6（5）的注释。*最低的，*或作较低的，即在下面的、地底下的。这一说法取自申命记 32:22。本节可与诗篇 18:6（5）、56:14（13）相较。

<span class="ax-anchor" id="psalms-86-14"></span><span class="ax-vnum">14.</span> *神啊，骄傲*（的人）*起来攻击我，强暴*（人）*的会众寻索我的性命，并没有将你放在他们面前。*大卫在论到扫罗的逼迫时曾用过几乎相同的话，诗篇 54:5(3)。但他在此不说*外人，*而说骄傲*者，*又在与之平行的*强暴、*欺压或暴虐（诗篇 37:35）一词之前，加上*会*或*会众，*似乎是要暗示其有组织；这两处的变动都与本篇与押沙龙叛乱相关的假设十分吻合。

<span class="ax-anchor" id="psalms-86-15"></span><span class="ax-vnum">15.</span> *而你，主啊，*（是）*一位有怜悯有恩惠的神，不轻易发怒，且有丰盛的慈爱与信实。*他在此诉诸神对自己的描述，作为他祈求怜悯的凭据。参出埃及记 34:6，以及约珥（2:13）与约拿（4:2）对它的仿用或引用。又参诗篇 85:11（10）。

<span class="ax-anchor" id="psalms-86-16"></span><span class="ax-vnum">16.</span> *转向我，施恩与我；将你的力量赐给你的仆人，拯救你使女的儿子。*头一句祈求含有神的脸先前已经转开之意。*将你的力量赐给，*即施展你的力量来保护他。*你使女的儿子*，或作你女奴的儿子，*即*家生的、世袭的仆人，既是如此，就有权得着保护与供养。这说法取自出埃及记 23:12，又见于诗篇 116:16。末一个动词是常用的那个意思为*拯救*的词，但在此处是借介词*to*（向、给）与其宾语相连。

<span class="ax-anchor" id="psalms-86-17"></span><span class="ax-vnum">17.</span> *求你向我显一个恩待的凭据，*（那时）*恨我的人必看见而蒙羞，因为你，耶和华，已帮助了我，安慰了我。*译作*向我显*的短语，严格说来意思是*向我行*，此处之所以用它，是因为所求的*记号*或*凭据*既非口头的宣告，也非神迹，而是神藉着他*待他*的作为所提供的、实际而带有护理性的恩眷表征。译作*恩待*的那个词，与诗篇 16:2 所用的是同一个，在那里与此处一样，它都有物质之福、安康、幸福的意思。*恩待的凭据*就是得着并享有此福的保证。那带有间接语气的结构——*使恨我的人看见*——其实已包含在直陈的将来时之内。*蒙羞，*即惊愕、失望、狼狈。末句中的过去时，是就这效果在仇敌身上产生之时而言的，那时神的帮助与安慰早已赐下了。
