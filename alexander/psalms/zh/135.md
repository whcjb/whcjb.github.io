耶和华的子民受劝勉，当颂赞他为他们独有的神，第 1—4 节；为自然界的神，第 5-7 节；为那把以色列从埃及领出、又在迦南施行拯救的神，第 8-12 节；也为他们将来的指望，第 13, 14 节；这指望因与偶像的无能相对照而愈显荣耀，第 15-18 节；此后本篇以起首的方式作结，仍是劝人颂赞神，第 19-21 节。按亨斯滕伯格（Hengstenberg）的编排与分配，本篇是一组十二篇诗（135-146 篇）中的第一篇，这组诗是在第二殿落成时所唱的，其中包括八篇大卫的诗（138-145 篇），前有三篇（135-137 篇），后有一篇（146 篇），皆属较晚的年代。他以此解释：这几篇古老的诗之所以未见于诗集的前半部，是因为它们已不再被视为独立的作品，而被看作它们所归入的那一组或那一系列中不可分割的部分。

<span class="ax-anchor" id="psalms-135-1"></span><span class="ax-vnum">1.</span> *哈利路亚！赞美耶和华的名。赞美*（它）*吧，你们这些耶和华的仆人！*本篇的结尾表明，祭司虽然被包括在*耶和华的仆人*之中（第 19 节），却并非专指他们，不像诗篇 134:1 那样。然而即便在那里，祭司也是全以色列的代表。

<span class="ax-anchor" id="psalms-135-2"></span><span class="ax-vnum">2.</span> *那些*（是）*站在耶和华殿中的，站在我们神殿的院宇中的。*分词表示持续的动作。提及院宇，正证实了前面就第 1 节所呼告的对象已经说过的话。

<span class="ax-anchor" id="psalms-135-3"></span><span class="ax-vnum">3.</span> *哈利路亚*（你们要赞美耶！）*因为良善*（的是）*耶和华。向他的名作乐，因为这是可爱的。*末了数语也可译作：*他是可爱的，即*一个配得至高眷恋的对象。

<span class="ax-anchor" id="psalms-135-4"></span><span class="ax-vnum">4.</span> *因为雅各，雅（Jah）为自己拣选了，以色列作他自己的产业。*他们尤其有责任赞美他，因为他们是他拣选的、特属他的子民。希伯来原文中的末一词，意指一份格外贵重的产业，从万族中分别出来、与众不同。参出埃及记 19:5，申命记 7:6，14:2，26:18。

<span class="ax-anchor" id="psalms-135-5"></span><span class="ax-vnum">5.</span> *因为我知道耶和华为大，我们的主（超）过万神。*无论世人怎样不认识他的至尊，我，这以色列的代表，并以此身分奉他的名说话的人，却从自己的观察与经历中晓得并确信这真理。

<span class="ax-anchor" id="psalms-135-6"></span><span class="ax-vnum">6.</span> *凡耶和华所愿的，他都行，在诸天与地上，在海洋与一切深渊中。* 参诗篇 115:3、传道书 8:3、约拿书 1:14、以赛亚书 46:10, 11。他们当颂赞他，不单因他是他们自己特有的神，更因他是普世的主宰。天、地、海三者并举，是用以代表整个受造的体系，如出埃及记 20:4 所用。

<span class="ax-anchor" id="psalms-135-7"></span><span class="ax-vnum">7.</span> *使雾气从地极上升*——*为雨造闪电*——*从他的府库中带出风来。*第 6 节既举出世上若干地域以界定他统治的广度，这里便举出若干自然现象作为他权能的产物。参耶利米书 10:13, 51:16。*从地极，即*从地的各处，连最遥远之处也不除外。见上文诗篇 61:3 (2) 的注释。第二句有人解作*化闪电为雨，即*使雷云消散成雨。但这不如通行译法自然：*他为雨造闪电，即*使闪电伴雨而来，或照公祷书中的意译，*使闪电随雨而出。*末句可参约伯记 38:22。

<!-- PAGE 538 -->
<span class="ax-anchor" id="psalms-135-8"></span><span class="ax-vnum">8.</span> *他击杀埃及的头生者，从人直到牲畜。*诗人既已列举神在自然界中至高主权的凭据，现今便转向历史中的凭据，尤其是他待自己百姓与百姓之仇敌的那段历史。诗篇 104 篇与 105 篇之间的关系正是如此。此处所选的头一个例证，就是埃及诸灾中末后而最大的一灾。*从人到牲畜，*乃是两者兼括；换言之，即人与牲畜都在其内。

<span class="ax-anchor" id="psalms-135-9"></span><span class="ax-vnum">9.</span> *在你中间，埃及啊，降下神迹奇事，在法老和他一切臣仆身上。神迹奇事，即*奇事异能，就是指那些在出埃及之前并与之同时发生的事。参看上文诗篇 78:43 的注释。*在你中间，埃及啊，*这说法与诗篇 116:19 中的相似，*在你中间，耶路撒冷啊！在法老身上，*字面作在法老里面并在他一切臣仆里面。

<span class="ax-anchor" id="psalms-135-10"></span><span class="ax-vnum">10.</span> *他击打多国，又杀戮大能的王。*如今在埃及与出埃及的神迹之上，又加上了迦南与得地的神迹。

<span class="ax-anchor" id="psalms-135-11"></span><span class="ax-vnum">11.</span> *亚摩利王西宏，和巴珊王噩，并迦南的一切国度。*这三项在希伯来文中各自前面都冠有介词（ל），意即*归于*或*为了；*此处并非笔误或偶然，由下一篇诗中同样的重复可见（诗篇 136:19, 20）。虽然这与动词（הרג）的用法不合——该动词在别处都是径直支配其宾语——但此处这个小品词仍须视作宾格记号，正如诗篇 129:3 所见；除非我们认为其意思乃是：方才所泛言者，具体说来也适用*于西宏，于噩，*以及*于迦南*（此处以国度代其诸王）*的众国度。*

<span class="ax-anchor" id="psalms-135-12"></span><span class="ax-vnum">12.</span> *又将他们的地赐下*（作）*为产业，作产业归与他的百姓以色列。*迦南地之所以成为以色列的产业，并非因为他们是迦南人的继承者，乃是因为这地要凭着世袭之权与继承之序，由父传子。参看上文诗篇 105:44, 111:6 的注释。

<span class="ax-anchor" id="psalms-135-13"></span><span class="ax-vnum">13.</span> *耶和华，你的名*（是）*到永远。耶和华，你的记念存到世世代代。名*与*记念*在此是同义的表述，指人藉以记念或称颂神的那一切，即他在作为中所彰显的完全。这名的长存意味着恩慈之举的持续不断或一再重复。

<span class="ax-anchor" id="psalms-135-14"></span><span class="ax-vnum">14.</span> *因为耶和华要审判他的子民，并要为他仆人的缘故回心转意。*他必成就申命记 32:36 中的应许。*他要审判（即*公正地对待）他的子民。见上文诗篇 72:2 的注释。至于将懊悔归于神是在何种意义上说的，见上文诗篇 90:13 的注释。

<span class="ax-anchor" id="psalms-135-15"></span><span class="ax-vnum">15.</span> *列国的偶像*（是）*银和金，人手的工作。*此处将主的神圣完全与偶像的无能和虚无对比而加以陈明。这一比较的用语取自诗篇 115:4-8，略有数处变动。

<span class="ax-anchor" id="psalms-135-16"></span><span class="ax-vnum">16.</span> （有）*口给他们，而*（然而）*他们不说话；*（有）*眼给他们，而*（然而）*他们不看见。*参看上文，诗篇 115:5，该节与此处这一节完全一致。

<span class="ax-anchor" id="psalms-135-17"></span><span class="ax-vnum">17.</span> *有耳，却* （仍）*不能听；同样，他们口中也没有气息。*参上文，诗篇 115:6 的注释。本节包含这两处经文中最显著的一处差异。两处的第二分句都以同一个希伯来词אַף开始；但在一处它是名词，意为*鼻*，在另一处却是副词，意为*同样*。这类保留词形而变换词义的差异，完全合乎希伯来文的惯用法。

<!-- PAGE 539 -->
<span class="ax-anchor" id="psalms-135-18"></span><span class="ax-vnum">18.</span> *像它们的，必是那造它们的，凡* （是）*倚靠它们的人。* 参看上文诗篇 115:8，本节与之完全一致。若其意仅为「造它们的人*与*它们相像」，按希伯来文的惯用法本应省去系词。因此，此处插入将来时形式的动词（יִהְיוּ），就要求严格译作*必是，即*不单在性情上如此，在结局上也如此。拜偶像的人必与他们那必朽的偶像一同灭亡。参以赛亚书 1:31。

<span class="ax-anchor" id="psalms-135-19"></span><span class="ax-vnum">19.</span> *以色列家啊，要称颂耶和华！亚伦家啊，要称颂耶和华！* 既已说明神在他自己里面是何等样的神、又与偶像相较是何等样的神，诗人便重申那劝勉之语——前面那番描述原是为解释并证实此劝勉而设的。本节与下一节可比较诗篇 115:9-11、118:2-4。那里作*倚靠，*这里却作*称颂，*与本篇开首所用的一样。参诗篇 134:1。

<span class="ax-anchor" id="psalms-135-20"></span><span class="ax-vnum">20.</span> *利未家啊，你们要称颂耶和华！敬畏耶和华的人哪，你们要称颂耶和华！* 在平行的各处经文中，并未特别提到利未人。

<span class="ax-anchor" id="psalms-135-21"></span><span class="ax-vnum">21.</span> *当称颂的，*（愿）*耶和华从锡安受称颂*——*那居住耶路撒冷的*——*哈利路亚！*此处暗指诗篇 134:3。耶和华既从锡安赐福，他自己也从锡安受称颂，因他的颂赞如从一个辐射的中心向外传扬。有人说，这是惟一一处以耶路撒冷代替锡安、作为神在地上居所的经文。但请看前面诗篇 76:3 (2) 的注释，并参诗篇 125:1, 2。
