<span class="ax-vnum">1.</span> *交与伶长。玛斯基拉。交与可拉的子孙。* 本篇中明显指涉个人经历与情感，这就更有必要把它标明为一篇*玛斯基拉*（Maschil），即教导性的诗，意在供长久的、公开的使用。参看上文诗篇 32:1 的注释。所述的经历显然是大卫的，而且极可能是在押沙龙叛乱、他因此被隔绝于圣所之时。见撒母耳记下 15:25。唯一可疑的，是本篇究竟出自他本人之手，还是出自可拉的子孙之手。这些人是利未支派中的一个歌唱家族，历代志上 6:1, 7, 16（16, 22, 31）、9:19、26:1，到约沙法在位时仍担任此职，由历代志下 20:19 可见。既然这是他们的职分，似乎更自然的是把他们看作本篇的演唱者，而非作者。再者，把一篇诗的写作归于整整一个班次或家族，也似乎不大可能。但另一方面，此处*可拉的子孙*是与*伶长*分开列出的，并且所占的正是我们通常见到作者名字的那个位置。同样值得注意的是，我们从未见过*可拉的子孙*与大卫或任何别的个别作者连名并举，惟有希幔是例外，而希幔很可能本就是他们中的一员。参看下文诗篇 88:1 的注释。若把他、或可拉的子孙中任何别的人看作本篇的作者，那就必须假定他是以大卫的身分写作的，*即*为要表达大卫在他历史上某一特定关头的情感。当然，远为明显的一个假设是：大卫自己为此目的写下了这篇诗。固然，大卫的名字在题给*可拉的子孙*的那十一篇诗的题注中一次也没有出现过，这一事实难以解释，无疑会削弱上述假设，却不能推翻它内在的可能性。本篇按其结构分为两部分，以第 6, 12（5, 11）节的叠句、即*副歌*为界。在第一部分，他哀叹自己被隔绝于神的面前，第 2, 3（1, 2）节，而仇敌的讥诮与对昔日特权的追忆更加重了这哀叹，第 4（3）节，但他满怀确信地盼望这一切的复得，并呼唤自己的灵魂仰望神、信靠神，第 5, 6（4, 5）节。在第二部分，他重走同样的路程，用的却不是同样的词句，第 7 至 11（6 至 10）节，末了以与前面相同的确信之语作结，第 12（11）节。

<span class="ax-anchor" id="psalms-42-1"></span><span class="ax-vnum">2 <span class="ax-veng">(1).</span></span> *如鹿切慕溪水，我的心也这样切慕你，*（哦）*神。*前一名词为阳性，动词却是阴性，故既可读作*公鹿，*亦可读作*母鹿。*此动词仅见于此处及约珥书 1:20，而后者显然是抄录本节而来。所指或是奔逃致竭，或是干旱的自然后果。参下文诗篇 63:2 (1) 的解说。其核心意思乃是极切的渴慕与压倒一切的缺乏之感。*溪水，*即水沟涧流。参上文诗篇 18:16 (15) 的解说。

<span class="ax-anchor" id="psalms-42-2"></span><span class="ax-vnum">3 <span class="ax-veng">(2).</span></span> *我的心渴想神，渴想永生的神。我几时得来朝见神呢？*第一个动词用过去时，表明他所表达的并非此刻才初次生出的愿望，而是他久已熟悉的愿望。此处所用的两个神名，一个（以罗欣，Elohim）是把神描述为宗教敬拜的对象，另一个（伊勒，El）则描述他为具有无限能力的存有。他是永活的、全能的，与虚构的神祇有别，与无能无生命的偶像有别。*我几时得来*一语含有空间上、身体上亲近之意，这与随后的*朝见神*相合；后者在律法中正是指按定期到圣所朝见的专门用语，只是其中的神名耶和华在此换成了以罗欣——此名在本篇出现十次，耶和华则仅出现一次。

<span class="ax-anchor" id="psalms-42-3"></span><span class="ax-vnum">4 <span class="ax-veng">(3).</span></span> *我的眼泪昼夜成了我的饮食，在*（他们）*终日对我说，你的神在*（哪里）*呢？* 译作*眼泪*的那个词，是诗篇 39:13(12) 所用的集合名词。希伯来文动词是单数。「我的哭泣成了我的饮食」，*即*我的食物。「我不进食，只是哭泣。」参看下文诗篇 102:5(4)，并比较撒母耳记上 1:7、约伯记 3:24。*昼夜，终日，*是表示不住地、常常地的有力而常见的说法。参看上文诗篇 1:2 的注释。*在说，即*在说的时候，当人这样说的时候。或可补出一个代词，*在*（他们）*说时，*当他们说的时候，*即*他的仇敌。*你的神在哪里呢？*这一问本身就是间接断言神已撇弃了他。参看上文诗篇 3:3(2)、22:9(8)，下文诗篇 71:11、115:2，并比较约珥书 2:17。示每的话或许曾浮现在大卫心中。参撒母耳记下 16:7, 8。

<span class="ax-anchor" id="psalms-42-4"></span><span class="ax-vnum">5 <span class="ax-veng">(4).</span></span> *这些*（事）*我要记念，要将我的魂倾倒在我身上，当我行在人群之中，*（当）*我行进*（同）*他们上到神的殿，带着欢乐与赞美的声音，带着节期的喧声*（或*喧嚷）。*惟有这样解析此句，才使那几个将来时的形式保有其本来的力量，而不至于被改作过去时；那样的改动纯属武断，因而也不合文法。倘若末一分句果真是追忆他昔日的特权，那就毫无理由不使用过去时的形式。*这些事，*不是指他从前的欢乐，而是指他眼下的苦难。*我要记念，*我决意如此行——这层意思正是由希伯来动词的形式本身所提示的。若本节只关乎过去，这样强烈的措辞便失其所宜。反省、内观这一行动，是用「将自己的魂倾倒在自己身上」这一有力的比喻来表达的，同时也带出情感激荡的意思；并不一定是悲伤，如约伯记 30:16 那样，而是在追念昔日的苦难与拯救时悲喜交集，正如我们可以说一个人的心被融化了，或因忧伤，或因感恩，或二者兼有。*当我行过，*更按字面则是*因我必行过，*若取此义，便表达了他对事情必有美好结局的笃定盼望。*行过，即*在庄严的行列中缓步前行。*人群，*或说稠密的众人；这希伯来词按其字源上的亲属关系，提示出丛林的意象，由此转为纷杂拥挤的一群。译作*行进*的那个动词仅见于此处与以赛亚书 38:15，而那里似乎正是取自我们眼前这处经文。它的句法与英文的 *march*（行进）相似：此词通常不及物，但在某些情形下可直接支配名词。我们若在此译作*我要率他们行进，*便additional地带出引领行列而非仅仅随行的意思。*上到，*比*到*更强的措辞，含有确已抵达所言之地的意思。上圣殿的行列中使用音乐，可由撒母耳记下 6:6 推知。译作*喧声*或*喧嚷*的那个词，也可指发出此声的*群众。*参前面诗篇 37:16 与 39:7(6) 的注释。但前一义是本义，也与平行的措辞最为相合。希伯来文中末一个词原意为*舞蹈*（撒母耳记上 30:16），但特指其在礼仪中的用法，作为宗教喜乐的表达（撒母耳记下 6:14）。

<span class="ax-anchor" id="psalms-42-5"></span><span class="ax-vnum">6 <span class="ax-veng">(5).</span></span> *你为何沮丧，*（哦）*我的魂哪，你为何在我里面烦扰？你当等候神，因为我还要称谢他*（为）*他面的诸般拯救*（或作*同在）。*诗人的信心向他那不信的惧怕说话，仿佛惧怕是另一个人。这发问含有责备之意，好像他说：你没有理由如此颓丧。*为何，*字面作*什么，即*出于什么缘由，或为着什么事。*你是，*字面作*你将是？*你为何要在这极端而无端的颓丧中执意不改？希伯来动词的形式是反身的，*你为何使自己沮丧，*这就比先前更有力地表明，那沮丧乃是出于自愿的，因而是该受责备的。*烦扰，*与诗篇 39:7（6）所用的是同一动词，也是上文第 5（4）节中意为*响声*或*群众*之名词的字根。此处如同别处，它所指的不只是不安，而是剧烈的激荡，有时也用于海的汹涌。见下文诗篇 46:4（3）的注释，并参耶利米书 5:22。*在我里面，*字面作*在我身上，*与前一节相同。*等候神，即*等候他应许的成就，其中含有信靠与盼望。译作*称谢*的动词严格说是*承认，*既用于认罪，也用于对所蒙恩惠的感恩承认。见上文诗篇 30:5（4）、32:5 的注释。*拯救，*指屡次的或完全的拯救。见上文诗篇 18:51（50）的注释。*他的面，*即他那施恩的容颜或面向，暗指民数记 6:25, 26 的祝福。见上文诗篇 4:7（6）、16:11、17:15、31:17（16）的注释。立定心志要为神的美善称谢他，这本身就含有确信：那美善必要显出。见上文诗篇 5:8（7）的注释。

<span class="ax-anchor" id="psalms-42-6"></span><span class="ax-vnum">7 <span class="ax-veng">(6).</span></span> *我的神啊，我的心在我里面忧闷。因此我要从约旦地、从黑门诸岭、从米萨山记念你。*尽管他如此争辩，他的沮丧仍未消去，惟有更直接地追念神是怎样的一位、曾为他作过什么，以及二者之间依然存续的相互关系，才能除去或减轻这沮丧。*在我里面，*与前两节同。此处这一短语或许意在暗示，倚靠自己只会加深他的沮丧，迫使他把信赖安放在另一个更为确实的根基上。*忧闷，*即必将如此，除非、且直到你将它扶起。*从……地*意味着他在那里因被隔绝于神的圣所之外而被隔绝于神的面前。那不确指的说法，*约旦之地，即*约旦河流经的一带地方，正如我们说密西西比河谷一样，此处因提到*黑门诸岭，即*（如有人所推想的）黑门山以及河这一边的其余诸山，而特指约旦河东岸；正如*巴力们*意指巴力以及与他同受敬拜的别的偶像（列王纪上 18:18）；或者更可能是指黑门山本身，不是看作一座孤峰，而是看作一条山脉或山系，如阿尔卑斯、阿勒格尼……。无论取哪一种解法，它都代表约旦河东的全境，那地严格说来并不属于迦南或圣地。（见约书亚记 22:11。）在这样宽泛的意义上，大卫即便是指他在玛哈念的居所，也可以这样说；玛哈念在雅博河以北，位于迦得与玛拿西的交界（撒母耳记下 17:24, 27；列王纪上 2:8）。*米萨，*意为小或微小。无论把它看作专有名词（别处并无此名的痕迹），还是看作一个描述性的称谓，其中似乎都带着轻蔑之意。

<span class="ax-anchor" id="psalms-42-7"></span><span class="ax-vnum">8 <span class="ax-veng">(7).</span></span> *深渊向深渊*（在）*呼唤，在你水闸的声音中；你一切的波浪与洪涛都漫过我身。*希伯来文的第一个词似乎严格指一大团水体，在此意义上用于海洋——参上文诗篇 36:7 (6)——也用于海的波浪。此处或指波浪，或指洪流。分词（呼唤）把这景象描绘为正在发生。其意或仅是彼此以声相应，或更着重地说，每一道浪都在招呼、召唤另一道浪接续而来。类似的说法可参上文诗篇 19:3 (2)。*声音，即*响声或喧声。希伯来词的用法不像英文那样受限，因此甚至不必假定这里有拟人。下一个词在它仅有的另一处出现（撒母耳记下 5:8）中，字面意思是水道或水沟。此处或指连绵不断倾注于地的雨流。译作瀑布或飞瀑的理解，虽有古译本支持，却在字源与用法上都无根据。以为大卫在此暗指环绕他四围的黎巴嫩瀑布，这想法建基于对第 7 (6) 节的错误解释；如我们已看到的，那一节是对约但河东之地的总括描写，后世称之为比利亚。*波浪与洪涛，*字面作*碎浪与滚浪，即*成片的水涌向岸边、在岸上碎裂。整节经文显然暗指那场普世的洪水，正如诗篇 29:11 (10)、32:6 及别处屡次所见。

<span class="ax-anchor" id="psalms-42-8"></span><span class="ax-vnum">9 <span class="ax-veng">(8).</span></span> *白日，耶和华必吩咐他的慈爱，黑夜，他的歌与我同在，一篇向我生命之神的祷告。*诗人虽身处苦难，仍深信神没有离弃他。有人把*白日*与*黑夜*解作顺境与逆境；但二者并列更可能是指一切时候，而歌颂与祷告之间的对举不过是韵律上的，*即*由平行体所致。参诗篇 92:3 (2)。*吩咐他的慈爱，即*以权柄施行慈爱，或说以君王的身分施行。*他的歌，*即向他而唱的赞美之歌，这意味着即便在患难之时仍经历了他的良善。参约伯记 35:10。这几个词可受前一分句动词的支配，*他必吩咐他的歌*（要）*与我同在，*意即他必使我有机会歌颂他的赞美；也可与所省略的系动词连读，*他的歌*（必）*与我同在。**我生命的神*可解作*我那生命的神，即*我那永活的神。参*我圣洁的山*——我的圣山——我的圣洁之山，诗篇 2:6。然而更为自然的，是把*我生命的神*理解为那位我的生命所归属、所倚赖、并理当由他护卫的神。「一篇向他而发的祷告——他按创造乃是我生命的源头，按约乃是我生命的保全者。」

<span class="ax-anchor" id="psalms-42-9"></span><span class="ax-vnum">10 <span class="ax-veng">(9).</span></span> *我要对神，我的磐石，说，你为何忘记我？我为何因仇敌的欺压而哀痛行走？* 这番申诉可视为神使他即便在苦难之中仍能献上的那*祷告*的一部分，或其样本。此处所用的神名是 אל（神），即表明能力的那一个。*我的磐石，*我的避难所，我的保护者，也是我盼望的根基。参看上文诗篇 18:3 (2)。*我为何行走？*更确切地说，我为何将要、或必须行走？*哀痛，*字面意思是蓬头垢面、污秽不洁。参看上文诗篇 35:14, 38:7 (6)。*在欺压之中，*或指在其持续期间，或指因其之故，或者更确切地说，两种意思都包含在内。

<span class="ax-anchor" id="psalms-42-10"></span><span class="ax-vnum">11 <span class="ax-veng">(10).</span></span> *我骨中带着杀戮，我的仇敌辱骂我，就在他们终日对我说，你的神在哪里？* 前一分句中这强烈的说法，意在表明极度的痛苦。*我的仇敌，* 按希伯来原词的意思，是压迫者或逼迫者。*辱骂我，* 这比 *责备* 或 *谩骂我* 更为强烈，不仅含愤怒与仇恨，更含轻蔑。*在他们说，即* 藉着他们所说的话，并当他们说的时候，与前一节相同。*终日，* 不住地。参看上文第 9（8）节。*你的神在哪里？* 参看上文第 4（3）节。

<span class="ax-anchor" id="psalms-42-11"></span><span class="ax-vnum">12 <span class="ax-veng">(11).</span></span> *你为何忧闷，*（哦）*我的心哪，你为何在我里面烦躁。你当仰望神，因我还要称谢他，*（作）*我面上的帮助、我的神。*如此类情形中常见的那样，这叠句或*副歌*与第 6（5）节的略有变化。参看上文诗篇 24:7-10 的注释。那里作*他面上的拯救，*这里却作*我面上的拯救。*有人试图藉着校改原文使二者趋于一致，这不但毫无版本与抄本的依据，而且与圣经作者重复自己或他人语句时的一般习惯相违。*我面上的拯救*是一个大胆而罕见的说法，似乎是指那样的搭救、那样丰盛的帮助，足以使先前阴云密布、沮丧低垂的面容重新开朗发光。*我的神*并非无意义的或多余的附加，乃是指向前一节中那讥讽的问话：*你的神在哪里？*仿佛他说：「看哪，他就在这里。我的神就是那驱散我的阴霾、鼓舞我的盼望、使我超乎仇敌的讥笑与暴怒之上的那一位。」这一变化使得重复不致全然雷同，而重复本身又使第二段诗节以及全诗得着一个醒目而匀称的结束。
