<span class="ax-vnum">1.</span> *交与伶长。属可拉的众子。一篇诗。* 这是一首凯歌，为庆贺蒙拣选之民胜过若干联盟的列国所得的一次显著胜利。第一节段，第 2-5 节（1—4 节），称颂耶和华为列国的征服者；第二节段，第 6-10 节（5-9 节），称颂他为列国合法的君王；两段都以他为以色列的护卫之神。两部分在形式上另有一处差别，似乎在于：前一段中，颂赞神的劝勉是直接向外邦人发出的；后一段中，则是向以色列、即古时的教会发出的。本篇处处显出是为某一特定事件而作；但既然诗中并未指明，便只能出于推测。在各家提出的种种假设中，最可能的是：本篇乃为纪念约沙法胜过亚扪人与以东人而作，此事记在历代志下第二十章。除了本篇与那里所述情势的大体相合之外，至少可说是一个极其特别的巧合：那段历史记载在那一次场合中，不单有利未人在场，而且特别提到可拉的子孙（历代志下 20:19）。我们又读到歌唱的人行在军前（第 21 节），并且到第四日他们聚集在一个山谷，称那地为*比拉迦*（祝福），因为他们在那里称颂耶和华（第 26 节）。再者，本篇文体朴素、生动、流畅，这也与下述假设十分吻合，即它是一篇受感而即席成就的诗，是在当时情境的激发之下写成的，或出于随军同行的某位无名先知之手，或出于可拉众子自己之手。参上文诗篇 42:1 的注释。关于本篇历史背景的这一推测，又由下一篇诗与同一事件之间显而易见的关联得到印证。参下文诗篇 48:1 的注释。

<span class="ax-anchor" id="psalms-47-1"></span><span class="ax-vnum">2 <span class="ax-veng">(1).</span></span> *万民哪，拍手！用得胜的声音向神欢呼！* 拍手既是凯旋的自然姿态，也是喝采的自然姿态。参那鸿书 3:19，并比较诗篇 98:8、以赛亚书 55:12。本节末一词所指的不是一种情感，而是借歌唱或呼喊把喜乐与欢腾发为可闻之声。见前文诗篇 5:12 (11) 的解说。此处所呼召的列国，并非刚被征服的那几个特定邦国，而是整个外邦世界，是列国的总和；他们被召来，为着刚刚显明的凭据而欢欣，即耶和华乃是他们合法的君王。见前文诗篇 18:50 (49) 的解说，并见后文诗篇 66:4 (3)、117:1 的解说，又可比较本节所仿照的原初说法，申命记 32:43。

<span class="ax-anchor" id="psalms-47-2"></span><span class="ax-vnum">3 <span class="ax-veng">(2).</span></span> *因为耶和华，至高者，是可畏的，是治理全地的大君王。*他并非如外邦人所惯于设想的那样，是一位仅属一方的神祇，单单作希伯来人的神，乃是全地的神，是普世的君王，是地上居民所当敬畏的对象。同样的称谓用于他身上，见诗篇 68:36（35）。

<span class="ax-anchor" id="psalms-47-3"></span><span class="ax-vnum">4 <span class="ax-veng">(3).</span></span> *他必使万民服在我们以下，使众族服在我们脚下。* 这既证明他与自己百姓所立的约的关系，也证明他对列邦所握的至高权能。他已成就的，不过是他将要成就之事的凭据。参 诗篇 18:39 (38), 48 (47)。此事在那些直接关涉的邦国看来固然不是可喜乐的，然而对普天下而言却大可视为喜乐之事，因为其中含着一个应许：外邦人有一日也要被收纳在这位神圣保护者的子民之中，同享他的恩眷。

<span class="ax-anchor" id="psalms-47-4"></span><span class="ax-vnum">5 <span class="ax-veng">(4).</span></span> *他要为我们拣选我们的产业，就是他所爱的雅各的荣耀。细拉。*神击败了那些想把以色列人逐出应许之地的仇敌（历代志下 20:11），诗意地说，便可谓是重新使他们安居其中，并像起初一样为他们拣选产业。*雅各的荣耀，*即他所引以为荣、所夸耀的，无论这是专指圣地而言，还是泛指他们作为耶和华特选之民所享有的一切特权与尊荣。*荣耀，*即高举，或尊崇，如那鸿书 2:3 (2)、阿摩司书 6:8。在阿摩司书 8:7，神自己也被如此称述。*雅各，*如诗篇 24:6，46:8 (7)，12 (11)。*他所爱的。*参玛拉基书 1:2，并比较诗篇 78:68。

<span class="ax-anchor" id="psalms-47-5"></span><span class="ax-vnum">6 <span class="ax-veng">(5).</span></span> *神在呼喊声中上升，耶和华在号筒声中（上升）。*此处所描绘的，是他在征服仇敌、拯救其民之后返回天上，正如在诗篇 7:8（7）中，他在审判列邦、为自己的百姓伸明权利之后所行的一样。参见诗篇 68:19（18），并比较创世记 17:22、士师记 13:20。呼喊声与号筒的响声表明这次上升是公开的、凯旋的。这理想中的场景预表了我们救主实际的升天。见下文诗篇 68:19（18）的注释。

<span class="ax-anchor" id="psalms-47-6"></span><span class="ax-vnum">7 <span class="ax-veng">(6).</span></span> *歌颂*（归于）*神，歌颂吧！歌颂我们的王，歌颂吧！* 与 *歌颂* 相对应的希伯来文是一个单词（זמרו），意思是以音乐赞美，兼指歌声与乐器。见上文论诗篇 9:3(2) 处。神先被提作赞美的对象，随后被称为*我们的王，*即以色列实际的王，也是全地理当拥戴的王，

<span class="ax-anchor" id="psalms-47-7"></span><span class="ax-vnum">8 <span class="ax-veng">(7).</span></span> *因为全地的王*（是）*神。要作一首玛斯基拉，即*唱奏一首教训性的诗。参看前面诗篇 32:1、42:1、44:1、45:1 的注释。此处所说的*玛斯基拉*（Maschil）就是这篇诗本身。题注中之所以略去这一名称，或许正因为它已包含在诗的正文之中。所教导的道理，就是耶和华普世的主权，以及万国最终归服于他和平的治理。这一思想在弥赛亚的国度中得以实现，因此这篇诗在广义上是弥赛亚性的。末句这一独特的含义，在通行译本（*你们要用悟性歌颂*）中已经失落；七十士译本（ψάλατε *συνετῶς*）、武加大译本（psallite sapienter，当以智慧歌颂）和耶柔米（canite erudite，当以通达歌唱）亦复如是。

<span class="ax-anchor" id="psalms-47-8"></span><span class="ax-vnum">9 <span class="ax-veng">(8).</span></span> *神已作王治理万国，神已坐在他圣洁的宝座上。*他已开始作王，已成为君王，并以此身分登上普世统治的宝座。本节与下一节可以特别视为第 8（7）节所提到的那篇*玛斯基拉*（Maschil）。*他圣洁的宝座，*即他的圣宝座，*即*他神圣的宝座，那与一切宝座迥异、且在其上的宝座。参看上文诗篇 22:4（3）处的注释，以及下文诗篇 103:19 处的注释，并参以赛亚书 6:1、66:1。

<span class="ax-anchor" id="psalms-47-9"></span><span class="ax-vnum">10 <span class="ax-veng">(9).</span></span> *列邦的君王聚集*——*亚伯拉罕之神的子民；因为地上的盾牌属乎神；他被高举至极。* 首字本义为*甘心的，*尤指甘心乐意的施与者；由此自然引申为慷慨的、大方的、尊贵的，作名词则为贵胄、君王。此处以他们为列邦的代表，聚集于神面前，向他致敬，承认他的至高主权。随后的短语可解作*如同、同着，*或*向神的子民，*最可能是第一种。*亚伯拉罕的神，*亚伯拉罕是他们的开基者与先祖，神与他立约，不单为他自己，也为他的子孙。参同样的说法，创世记 31:42，出埃及记 3:6，马太福音 22:32。*地上的盾牌，*即地上的保护者，此处用以指抽象的保护，或指上一分句所提到的*君王。*参何西阿书 4:18。惟有当地上一切执政的、掌权的都承认自己臣服于耶和华，他才算得着当有的、足够的高举。参上文诗篇 22:29 (28)。
