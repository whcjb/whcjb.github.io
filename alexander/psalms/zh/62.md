<span class="ax-vnum">1.</span> *交与伶长耶杜顿。大卫的诗。* 耶杜顿在此似乎是指那位名为耶杜顿的伶长所出的家族或歌班。参上文诗篇 39:1 的注释。本篇由三段均等的节段或诗节构成，每段皆以质词 אַךְ（*惟独*）起首，第一、第二段末尾皆有*细拉*。在这三部分中，主题或反复申说的要旨是同一个，即：神与人同作倚靠的对象时，二者之间的对比。

<span class="ax-anchor" id="psalms-62-1"></span><span class="ax-vnum">2 <span class="ax-veng">(1).</span></span> *惟独向着神* ，*我的魂是静默的；我的拯救* ，*从他而来。* 首词（אַךְ）的屡次重复，是本篇的一个特征。在所有这些地方，都当取其严格的排他之义，*即惟独*。参看上文诗篇 58:12（11）的注释。惟有在仰望神为我的拯救者之时，我的魂才是*静默的*，字面作*静默*。参看上文诗篇 22:3（2）、39:3（2）的注释。惟有这样的信靠，才能使他的心安定下来，脱去人与自己的神疏离时所自然有的那种不安。

<!-- PAGE 277 -->
<span class="ax-anchor" id="psalms-62-2"></span><span class="ax-vnum">3 <span class="ax-veng">(2).</span></span> *惟有祂*（是）*我的磐石，我的拯救，我的高处*（高地、避难所或庇护所）；*我必不动摇*（从稳固的立足之地被挪移）*甚*（或作*大大地*）。*甚*这一副词用法在希伯来文与英文中相同。这种有所限定的说法，似乎意在表明：他并不指望逃脱一切祸患灾难，所指望逃脱的只是那足以致命的灾祸。参看上文，诗篇 37:24。至于前半节中的比喻，参看上文，诗篇 9:10 (9)、18:3 (2)。*惟有祂，*即神而非别的任何一位，才能作这样的保护者。

<span class="ax-anchor" id="psalms-62-3"></span><span class="ax-vnum">4 <span class="ax-veng">(3).</span></span> *到几时*（还要多久）*你们要猛扑向*（或*攻击）一人，你们要杀害（即* 设法杀害他），*你们全体*（联合起来对付一个人，因此他）*像一堵倾斜的墙*（或被暴力压弯的墙），*一道篱笆*（或围篱）*被压碎*（被拆毁的？）。末一分句所指的是他自己而非他的仇敌，这从下一节继续同一描写即可明白。

<span class="ax-anchor" id="psalms-62-4"></span><span class="ax-vnum">5 <span class="ax-veng">(4).</span></span> *只是从他的高位他们商议要推下*（他，并且作为达此目的之手段）*他们喜爱虚谎；他用口，（即*他们用口）*他们要祝福，而在他们的内里*（内心里，或用他们的心）*他们要咒诅。细拉。*本节中间数的突然转换，乃至整段描写，都与诗篇 5:10（9）中的相仿。

<span class="ax-anchor" id="psalms-62-5"></span><span class="ax-vnum">6 <span class="ax-veng">(5).</span></span> *我的心哪，你当惟独向神静默，因为我的指望是从他而来。*（is）<!-- -->

等等，须按原文结构：

*惟独向神，我的心哪，你当静默，因为从他*（而来）*是我的指望。* 刚才对世人所作的观察，把他逼回到神那里，于是他劝勉自己要怀抱先前已经表白过的那同一份信靠。*你当静默，*即缄默、信靠、顺服。见上文第 2 节（1），并参诗篇 37:7。末句的意思是：凡我所渴慕、所盼望的，都从他而出。

<span class="ax-anchor" id="psalms-62-6"></span><span class="ax-vnum">7 <span class="ax-veng">(6).</span></span> *惟独他是我的磐石*（我盼望的根基）*和我的拯救（即* 其源头与创始者）——*我的高处*（避难所或庇护所）——*我必不动摇*（或*被摇动）。* 与第 3 (2) 节相比，这一更为绝对的说法，似乎表明一种更强的信心，乃是由前面将神与人作为信靠与爱慕之对象所作的比较而来。

<span class="ax-anchor" id="psalms-62-7"></span><span class="ax-vnum">8 <span class="ax-veng">(7).</span></span> *在神之上（即* 倚靠他、以他为根基）*是我的拯救，和我的荣耀*（兼指职分上的与个人的）；*我力量的磐石*（我坚固的磐石，或我自身力量所立的根基）；*我的藏身之处*（我的避难所）乃*在神里面。* 正是在他的同在、恩眷与保护之中，我得以躲避一切仇敌、一切危难。参看上文诗篇 7:11 (10)、61:4 (3) 的注释。

<span class="ax-anchor" id="psalms-62-8"></span><span class="ax-vnum">9 <span class="ax-veng">(8).</span></span> *你们要时时倚靠他，哦百姓啊，在他面前倾心吐意；神*（是）*我们的避难所。细拉。*他自己所怀的信心，也劝勉别人同有。*时时，*不仅在顺境之中，也在最酷烈的试炼与最绝望的境地之中。*百姓，*不单是指众人或个人，乃是指百姓，神的百姓，他所拣选的子民。倾心吐意乃是一个自然而生动的比喻，指把心思意念和盘托出。参看上文诗篇 42:5(4) 的注释，并下文诗篇 142:3(2) 的注释，又参撒母耳记上 1:15、耶利米哀歌 2:19。末句说出这劝勉的理由，并以一个庄严的停顿标明其恳切。

<span class="ax-anchor" id="psalms-62-9"></span><span class="ax-vnum">10 <span class="ax-veng">(9).</span></span> *惟有虚空，*（乃是）*亚当之子；一句谎言，世人之子；在天平里*（他们必定）*向上升；他们是虚空所成*（或*比虚空还轻）一同如此。*　至于有人以为上半节在尊贵之人与卑微之人之间立有对比，参看前面诗篇 4:3（2）、49:3（2）的注释。*惟有虚空，*参看前面诗篇 39:6（5）的注释。*一句谎言，*即使期望落空之物，一种虚假的倚靠。参看前面诗篇 4:3（2）的注释。*虚空所成，*由虚空构成，其中别无他物；或取该前置词常见的比较之义，（轻）*于虚空，*或（比虚空）*更虚空*（本身）。以赛亚书 40:17、41:24 中类似说法的含义，也同样存疑。

<!-- PAGE 278 -->
<span class="ax-anchor" id="psalms-62-10"></span><span class="ax-vnum">11 <span class="ax-veng">(10).</span></span> *不要信靠欺压，也不要因抢夺而成为虚妄；*（论到）*财富，当它增长时，不要放在*（你的）*心上。*前两个名词在利未记 5:23（6:4）中连用，指以暴力所得之物。因此不可将二者视为两种各别的倚靠根据，而应视为同一事物的不同部分或不同描述。*不要成为虚妄，*即不要同化于你所爱所望那虚空、不能使人满足的对象。参列王纪下 17:15，并比较耶利米书 2:5、约伯记 27:12。译作*财富*的那个词严格说来意为*力量*或*权势，*但既可指军事上的力量，也可指钱财上的力量。见前文诗篇 49:7（6）的注释。*增长，*字面意思是*发芽，*或自行生长，或许是与以暴力所得之财相对而言的暗指。即便是合法所得或偶然所得，也不要将你的心放在其上。这个希伯来文短语有时不过是指用心、留意的意思，有些人在此也如此理解，作「当财富增加时，不要去注意它，不要想着它」；但更强的意思，即将情感系于其上、爱它、信靠它，本身更为妥当，也更合乎上下文。

<span class="ax-anchor" id="psalms-62-11"></span><span class="ax-vnum">12, 13 <span class="ax-veng">(11, 12),</span></span> *一* （件事）*神已说过，这两* （件事）*我都听见，就是能力* （属）*乎神，并且* （）*属乎你，主啊，* （乃是）*慈爱，* （但）*你必照各人的作为报应他* （或 *行事）。* 这里实在提到了神的三项属性：他的能力、他的慈爱、他的公义；但末一项只是带着几分追补的意思，用来限定第二项，所以仍可算作两项。英文译本与其他许多译本所取的结构把两句分开，使前一句指同一真理的重复宣告或启示，即 *能力属乎神。* 这样一来，就不得不把 *一件事、两件事* 读作 *一次* 与 *两次。* 但这种读法虽有约伯记 33:14, 40:5 对本节的仿用为佐证，在此处却并非最自然的结构。诚然，*一* 与 *二，* 在绝对地或省略地使用时，有时可指 *一个时候，（即* 一次）与 *两个时候，（即* 两次）；但由此并不能推出同样的词在别的上下文中不能指 *一句话* 或 *一件事、两句话或两件事。* 圣经作者又惯常互相借用彼此的用语，或重复自己的用语，而在意思或应用上略作更动。第 12（11）节里的代词（זו）可以是指示词，也可以是关系词；若取后一说，便可读作：（有）*两* （件事）*是我所听见的；* 但前一说却是更简单、更自然的结构。第 13（12）节中的呼语，即人称的忽然转换，是大卫诸诗中常见的修辞，表明情感渐趋热切，以致方才还被平静地当作不在场者论及的那一位，忽然间就被当作亲自临在眼前而直接呼告。
