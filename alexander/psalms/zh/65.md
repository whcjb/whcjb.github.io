<span class="ax-vnum">1.</span> *交与伶长。一篇诗。大卫作。一首歌，即*一首赞美之歌。参上文诗篇 48:1、42:9（8）的注释。神先是被泛泛地称颂，作为向万人施怜悯与恩惠的神，第 2-9（1-8）节；随后又特别地被称颂，作为丰年与富足的赐予者，第 10-14（9-13）节。

<span class="ax-anchor" id="psalms-65-1"></span><span class="ax-vnum">2 <span class="ax-veng">(1).</span></span> *归你的是*（当有）*静默、赞美，神啊，在锡安；所许的愿也必向你偿还。* *静默-赞美*这两个词构成一种复合用语，正如诗篇 45:5（4）中的*谦卑-公义*，有人以为其意为*静默的赞美*；但此说与此处所献的赞美乃是出声的这一事实难以相合。更可能的意思是：这样的赞美，伴随着一切喧嚷激动的止息。参看上文诗篇 62:2, 6（1, 5）的注释。*在锡安，*即旧约的时代所指定的祷告与赞美之所。末句含示：因着神护理中的恩惠不断重复临到，感恩的许愿与还愿也就不断有了新的缘由。

<span class="ax-anchor" id="psalms-65-2"></span><span class="ax-vnum">3 <span class="ax-veng">(2).</span></span> *垂听祷告的主啊，凡有血气的都要上到你这里来。* 希伯来文的第一个词是分词，*垂听着的，*即你这素来垂听祷告者。此处是把它作为神的一种名号或属性提出来的。*上到你这里，*直到你面前，含有实际抵达之意，因而其表达力强于 *向你。凡有血气的* 有时指一切动物、一切有生之物（创世记 6:17, 19），但此处用的是其较窄的意思，指全人类（创世记 6:3, 12）。他们要到你这里来，*即*必须来，为要得着所需的供应，得着罪的赦免，总之，为要得着各样美善的恩赐和各样全备的赏赐（雅各书 1:17），无论是属世的还是属灵的。

<!-- PAGE 284 -->
<span class="ax-anchor" id="psalms-65-3"></span><span class="ax-vnum">4 <span class="ax-veng">(3).</span></span> *罪孽的话语强于我；*（至于）*我们的过犯，你必赎除它们，*或说，因着一个挽回祭而赦免它们。*罪孽的话语*一语，有人视为重复累赘的意译，即指罪孽本身。然而更可能的是，此语意指罪孽的控告或指控。参看上文诗篇 7:1、41:9（8）的解说，以及下文诗篇 105:27 的解说。*强于我，*即超过我所能解释或所能承担的。参看上文诗篇 40:13（12）的解说，以及下文诗篇 130:3 的解说。末一分句所含的安慰，正与首一分句所述那可惊的处境相称。

<span class="ax-anchor" id="psalms-65-4"></span><span class="ax-vnum">5 <span class="ax-veng">(4).</span></span> *有福的，*（就是他，你所）*拣选并使*（他）*亲近的，即*容他进到你面前，与你亲密相交，（以致）*他必住在你的院宇；我们必饱足，*即得满足或得充满，*以那美善，即*那快乐、那享受，*你家的，就是圣*（所）*你的殿，*或作你的圣殿、你的圣所——这一说法既用于会幕，也用于本义上的圣殿。参看上文诗篇 5:8（7）的解释。此处所描述的特权，不仅是在神所指定之处参与公开敬拜，更是住在他家中、分享他家人所享的种种权利。参看上文诗篇 15:1、23:6 的解释。由第三人称单数转为第一人称复数，表明前者不过是把教会或蒙拣选之民个别化地说出来罢了。

<span class="ax-anchor" id="psalms-65-5"></span><span class="ax-vnum">6 <span class="ax-veng">(5).</span></span> *在公义中以可畏之事，你必应允我们，我们救恩的神啊，是地与海一切尽头的所倚赖者*——（就是）*那最远之处的。*你必以可畏之事应允我们的祷告，*即*那足以激起虔敬与敬畏之感的应允。*所倚赖者，*即他们所信靠的对象。*地*（或*地土）*与*海*并举，是要描述全世界，而二者的*尽头*则指最辽远的国度，这一意思随后又由句末那个词直接表达出来。希伯来文无法表达最高级，但此处由上下文暗示出来。其意并非说世人实际上都怀有这种对神的信靠，而是说无论他们是否有此感觉，他们实在都单单倚赖于他。参 以赛亚书 42:4。

<span class="ax-anchor" id="psalms-65-6"></span><span class="ax-vnum">7 <span class="ax-veng">(6).</span></span> *以他的力量安定诸山，以能力束腰。*本节以全能的权能来说明一切受造之物对神的依赖；这权能并非笼统言之，而是借其一种效果或作为来描述，即安定诸山——地上最坚固、最不可动摇的部分。接着他被比喻为以能力*束腰*，或说以能力为衣。参下文第 13 (12) 节。

<span class="ax-anchor" id="psalms-65-7"></span><span class="ax-vnum">8 <span class="ax-veng">(7).</span></span> *平静诸海的怒号，它们波浪的怒号，万民的喧嚷。* 此句承接前一节而来。神不但起初造了这物质的宇宙，并且至今仍掌管着它。这里由同一措辞的字面用法美妙地过渡到比喻用法。严格说来，神平静海洋的汹涌，这是真的；但同样真实的是，他制伏人间社会与列国的骚动，而海正是这骚动天然而常用的象征。参看前面诗篇 46:3, 4（2, 3）的注释。因此他明言加上一句：*万民的喧嚷。*

<span class="ax-anchor" id="psalms-65-8"></span><span class="ax-vnum">9 <span class="ax-veng">(8).</span></span> *那时，住在尽处的都惧怕了*（或最远之处）*，你记号的尽处；早晨与晚上的出口，你必使之欢呼*（或 *歌唱）。那时* 一词在希伯来文中并未明言，译文中用它，是要表明此动词依附于前一句的动词。其意是说：每逢神如此平息列邦的喧嚣，连最遥远之地也都因*他的记号，即*他亲临与直接作为的可感标记而受震动。*出口*在希伯来文中是一个表处所的名词，指晚上与早晨出来或开始之处，*即*日落与日出之点，东与西，在此用以指东方与西方之地，又以这些地方代指其居民。前半句所说的惧怕并非单纯奴仆式的恐惧，而是一种与喜乐全然相合的情感，这从本节余下的话中便可明白。

<!-- PAGE 285 -->
<span class="ax-anchor" id="psalms-65-9"></span><span class="ax-vnum">10 <span class="ax-veng">(9).</span></span> *你眷顾大地，使它浸透；你必使它大大富足；神的河满了水；你必预备他们的五谷，因为你正是这样预备它，即*大地，为的正是这个目的。神显明他与受造之物同在时，无论是以审判还是以怜悯的方式，都说他*眷顾*他们。见上文诗篇 8:5(4) 注。*使它浸透，*即浸润，或使之漫溢。译作*大大*的那个词与诗篇 62:3(2) 中的相同。*神的河，*是与地上的河流相对而言。地上的河流纵然干涸，神的资源却取之不尽。*他们的五谷，*即人维生所需的五谷。见上文诗篇 4:8(7) 注。末句的意思似乎是：那位降雨使大地肥沃的主，也可指望他赐下果实本身。

<span class="ax-anchor" id="psalms-65-10"></span><span class="ax-vnum">11 <span class="ax-veng">(10).</span></span> *浇透它的犁沟，打平它的垄脊：你必用甘霖使它松软；它的生发你必赐福。* 第一个动词意为大量地浇灌，第二个意为压低或打下，含有雨势猛烈之意。译作*甘霖*的那个词，按其字源与用法，指频密而丰沛的雨水。*使之松软，*即使之消解、疏松。这个希伯来动词是诗篇 46:7 (6) 中那个动词的派生词。*生发，*萌芽，即种子撒下后所抽发萌生之物。有人把前一分句中的两个动词当作不定式，由其前后的限定式时态所决定。但它们的形式也容许被看作命令式，而由命令式转入将来时是全然自然的，并且合乎大卫诸诗的用法：每逢在强烈的祈求之后要紧接着说出笃定的期待时，便是如此。参看上文诗篇 54:3 (1) 的注释。

<span class="ax-anchor" id="psalms-65-11"></span><span class="ax-vnum">12 <span class="ax-veng">(11).</span></span> *你以你恩惠的年岁为冠冕，你的路径滴下脂油。*前一分句既可解作：你以你的恩惠*为*这年加冕；也可照有些人所取的构词法解作：你为你恩惠的年岁加冕——即因你的恩惠而显为特出的那一年——用那恩惠的种种具体施与和凭据为它加冕。后一分句这个强烈而优美的比喻，其显明的意思是：无论他显现在何处，他的行动所到之处必随着丰沛而使地肥沃的影响。*脂油*一如往常是丰美食物的比喻，而丰美食物又是普遍丰裕的比喻，

<span class="ax-anchor" id="psalms-65-12"></span><span class="ax-vnum">13 <span class="ax-veng">(12).</span></span> *它们滴下*——*旷野的草场，又*（以）欢乐*众山束腰。*译作*草场*的那个词，本义是*居所，*却特别用于羊圈与牧场，因为那是羊群聚集之处。参看上文诗篇 23:1 的注解。译作*旷野*的那个词，按其最可能的字源，原非指荒芜的沙漠，而是指一片既未耕种、人烟亦不稠密的地带，虽然作为牧场或许丰茂富饶。下一节中出现的衣服这一泛泛的比喻，在此先以腰带这一具体的比喻预示出来，因为腰带环绕身躯、束住衣裳。参看上文诗篇 18:33（32）的注解。

<span class="ax-anchor" id="psalms-65-13"></span><span class="ax-vnum">14 <span class="ax-veng">(13).</span></span> *草场以羊群为衣，诸谷将披上五谷；他们必欢呼*（因喜乐），*是的，他们必歌唱。*有人将上半节译作*羊群以羊羔为衣，*否认希伯来文中头一个名词曾有草场之义。但见前面诗篇 37:20 的注释。第一种译法所呈现的意象无疑更为自然、更为优美。它也使平行体更为完整：田野被摇曳的禾稼所覆盖，正如草场被吃草的羊群所覆盖。末一句中，草场与山谷藉着一种优美的拟人手法，被描写为迸发出欢呼与赞美之歌。见前面诗篇 60:10 (8) 的注释。
