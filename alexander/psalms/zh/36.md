这篇非凡的诗篇除题注（第 1 节）外，可分为三个可辨的部分。第一部分是对人之败坏的有力描述，第 2-5 节（1-4）。第二部分与此相对，陈明神的卓越，第 6-10 节（5-9）。在第三部分中，诗人祈求脱离前者，而得与后者有分，并深信他的愿望必得成就，第 11-13 节（10-12）。

第一部分无论在形式还是实质上都与其余部分不同，远为晦涩难解。

<span class="ax-vnum">1.</span> *交与伶长。耶和华的仆人所作。大卫所作。* 这几个词如此特别的排列，全书只在此处与第十八篇的题注中出现，似乎含有比「*大卫，耶和华的仆人*」这一描述更多的意思。所要表明的分别或许在于：*耶和华的仆人*并非作为描述性的称号附加在名字之后，它本身才是题注的要点所在，名字的加入不过是为了指明其人。这似乎表明，出于本篇自身之内的某种缘由，必须把它看作一位耶和华的仆人、一位受他默示之人的作品，这一点至关紧要——或许正是与下一节所说那出于败坏的「默示」相对照。

<span class="ax-anchor" id="psalms-36-1"></span><span class="ax-vnum">2 <span class="ax-veng">(1).</span></span> *恶行如此对恶人（那人）说，在我心的深处，他眼中不怕神。* 这是整卷诗篇中最难解、最可疑的一节。希伯来文的第一个词（נאם）是一个用作名词的被动分词，如拉丁文的 *dictum*（宣谕），在预言中用作固定套语，以标明说话者。通常的组合是（נְאֻם יהוה）*耶和华的一句宣谕，*我们的圣经一般译作 *主说*（或 *主如此说*）。在撒母耳记下 23:1，神名被大卫之名取代（נְאֻם דָּוִד），而在那里以及箴言 30:1 又有 *那人*（נְאֻם הַגֶּבֶר），二者似乎都是摹仿民数记 24:15 巴兰的话。这一套语既一贯用来引出预言性的 *dicta*（宣谕），似乎要求此处也作类比的解释，即其意不止于单纯的说话举动，而是暗示一种权威性的宣谕或神谕式的答复，这答复既不出于神，也不出于他的先知，而是出于罪（פֶּשַׁע），罪在此处取代了他们的地位。*恶行的一句宣谕，*或者，仿照英文圣经中 נְאֻם יְהוָֹה 那种虽属意译却人所熟知的译法，*过犯如此说*或 *败坏如此说。*——下一个短语*（לרשע）*的意义，可由诗篇 110:1 的类比来断定，在那里同一个介词接在 נְאֻם יְהוָֹה 之后，只能标示称呼的对象：*耶和华的宣谕*（或 *耶和华如此说*）*对我主说。*所以此处正确的句法不是 *恶人的过犯*——那在文法上本就说不通——而是 *过犯如此对恶人说。*按惯用法尚可容许的唯一一种修正，是使 לְרָשָׁע 表示宣谕的主题而非对象——*恶行如此论到恶人说*——这就是它所作的、指控他的见证。这一解释虽无诗篇 110:1 为凭，却与 ל 常用以标明主题的用法相合，并且给出一个良好的意思，即：在诗人心里，恶行本身作见证指控恶人，证明他眼中不怕神。另一方面，若 לרשע 标示称呼的对象，则上半句可以是恶人自己的话，下半句则是诗人对这话的评论。「*恶行如此对（我）这恶人说，在我心的深处。」他眼中不怕神。*这就是说，恶人以罪为他的神，以罪的怂恿为他的预言神谕，由此显明他眼中不怕神。若换一种断句法，这句也可得出如下意思：*恶行如此对恶人说：「在我心的深处，他眼中不怕神，」*或甚至说，在他面前也不怕神。但这一解释会使罪在对罪人说话时谈论自己的心，而且把 *他的眼* 归于神也略显牵强，因此取舍似乎只在前面所述的另两种句法之间；其中一种所得的意思，与通行译本所要表达的似乎相同：*恶人的过犯在我心里说，他眼中不怕神；*也与公祷书本相合：*我心向我显明不敬虔之人的恶行，就是……*在这些纷纭而可疑的解释之中，有一点是确定的：此处所描写的恶人，乃是一个不惧怕神的人，正如别处以敬畏神代表敬虔或虔诚一样。

<span class="ax-anchor" id="psalms-36-2"></span><span class="ax-vnum">3 <span class="ax-veng">(2).</span></span> *因为他在自己眼中自我阿谀，以为*（神）*察出他的罪孽*（并）*恨恶*（它）。原文的晦涩可由一种生硬的直译显出来：*因为他在他眼中向他抹平，以察出他的罪孽去恨恶。*「抹平（使平滑）」一语，在此处与箴言 29:5，是一种省略的说法，省去了「言语」或「行为」，*即*以阿谀的方式说话或行事。参看上文诗篇 5:10（9）的注释。因希伯来文中没有反身代词，人称代词有时便如此使用，*他*代*他自己，他的*代*他自己的，*……不过在本节，也可能把这些代词指向神，而仍取其严格的意义：*他*（恶人）*使*（他的言语或行为）*向他抹得平滑（即*向神）*，在他眼中*（即神的眼中）。换言之，他力图以一副冠冕堂皇的外表欺骗神。但这种解法较不自然：其一，它使*在他眼中*一语更显多余；其二，它把罪人描绘成一个伪善者，而非一个胆大妄为、自恃无惧的犯法者；其三，它使末句更加晦涩难解。*察出罪孽，即*查出并刑罚它，这说法借自创世记 44:16。此语取其不利的意思，是由所加的*去恨恶*二字决定的。若把这一句指向罪人自己的情感，则与用法不合。全节可与申命记 29:18（19）比较，并参看上文诗篇 10:6 的注释。

<span class="ax-anchor" id="psalms-36-3"></span><span class="ax-vnum">4 <span class="ax-veng">(3).</span></span> *他口中的言语*（是）*虚谎与诡诈，他已不再行事明智、行事良善。*以抽象代具体，用*虚谎*与*诡诈*代替*虚谎的*与*诡诈的*，使语气更加强烈。他所说的不仅是虚假的，简直就是虚假本身。这两个希伯来词的确切含义，见上文诗篇 5:6, 7（5, 6）。末句的两个动词都是使役形式，而这一形式总是带有主动的意义。因此，*成为智慧的*是不充分的译法，*行善*则是含混的译法，因为这个英文说法专指施惠之举或实际有益之事。末一动词的真正意思是*行得正*或*行得对*，与行恶相对。见下文诗篇 37:3。罪人非但没有停止犯罪，反倒连行善的外表也抛弃了。这种表达方式与以赛亚书 1:16 相似。

<span class="ax-anchor" id="psalms-36-4"></span><span class="ax-vnum">5 <span class="ax-veng">(4).</span></span> *虚谎他要在床上筹算；他要站定在一条不好的路上；恶他必不弃绝。* 第一个词（אָוֶן），无论在本节还是上一节，都不是单指虚谎的言语，而是指虚谎的品性，即不合乎真理的品性——而神的意志便是真理的标准。因此它与邪恶几乎是同义的。这些将来时表示现今的习性，以及执意持续下去的定意。只要他仍是这样的人，他就要继续这样行事。*在床上，*即在夜间，本是省察思虑的时辰。或者意思是说：他不去睡卧，反把安息的时辰用来筹算恶事、设计祸害。——译作*站定自己，*或*站定立场*的那个动词，与前面诗篇 2:2 所出现的是同一个词，兼含既定的意图与着手施行二者。——*一条不好的路*是所谓*meiosis*（缩言法，以少言多）这一修辞的一例：所说的比所表达的更多，而其余的则由上下文提示出来。它实际传给每一个读者的意思，乃是一条极坏的路，或是最坏的一条路。——末一个动词意为带着轻蔑与憎恶而拒绝、弃绝。参看上文诗篇 15:4 的注释。

<span class="ax-anchor" id="psalms-36-5"></span><span class="ax-vnum">6 <span class="ax-veng">(5).</span></span> *耶和华啊，在诸天*（是）*你的慈爱，你的信实（直）到云霄。* 他刚刚呈现了罪人那可憎的形象，此时便转开目光，默想神的全备属性。两分句的平行体似乎表明，*在诸天*意思是在天上也在地上，*即*从这一端伸展到那一端；这个意思随即按字面表述出来：*远及，*甚至到，或上达，*云霄，*而末一词不过是*诸天*的同义语。——*慈爱与信实*同样是平行的，后者指神在成就应许上的信实或真实，甚至向不配的人也是如此。参看下文，诗篇 37:3。

<span class="ax-anchor" id="psalms-36-6"></span><span class="ax-vnum">7 <span class="ax-veng">(6).</span></span> *你的公义*（如同）*大能者的山岭；你的审判*（是）*大渊；人与牲畜你都拯救，*（哦）*耶和华！* 此处的公义指最广义的正直，包括前一节所提到的诚实与信实。*审判*是一个惯用的同义语，用复数或是为了表达抽象之意，如（חַיִּים）*生命*，或是指一桩桩具体的公义作为。这一属性在此被描述为无限的，所用的方法是与自然界中浩大无垠之物相比。首先提到的是*神的山*，或*大能（的神）的山*，这里所用的神名正是本指全能的那一个。参看上文诗篇 5:5 (4)。若把此字解作抽象名词，便得出这样的意思：*力量的山，即*坚固的山；但这词一贯用作神名的惯例，似乎足以断定应取后一意思，即由神全能的大能所造、因而证明其大能的山岭。——*大渊*，即海洋，如创世记 7:11（参创世记 1:2）。此处所传达的，与其说是幽深奥秘的观念，不如说是广袤无垠的观念。神眷护之周遍，又借*人与牲畜*（或*走兽*）的连用而进一步显明。*拯救*一词包括帮助、保护与供给诸般作为。

<!-- PAGE 166 -->
<span class="ax-anchor" id="psalms-36-7"></span><span class="ax-vnum">8 <span class="ax-veng">(7).</span></span> *你的慈爱何其宝贵，*（哦）*神啊，世人在你翅膀的荫下可以投靠*（或作*避难*）*。* 神的慈爱之丰盛，正从这一事实显明出来：它为世人提供了庇护，当然所指的只是那些领受了应许的人。翅膀覆庇的比喻在申命记 32:11 和马太福音 23:37 有更充分的铺展。——本节所用动词的意义，见前面诗篇 2:12 的注释。

<span class="ax-anchor" id="psalms-36-8"></span><span class="ax-vnum">9 <span class="ax-veng">(8).</span></span> *他们必因你殿中的肥甘而饱足；* （以）*你乐河之水你必给他们喝* （或作*使他们得饮*）。他们，*即*世人之中蒙准在神的护庇下避难的那些人。——*必畅饮，*或作饮至满足、被浸透、被灌足。其所出之名词见于上文诗篇 23:5。——*肥甘，*字面意思是脂油或肥美，用以指最丰腴的食物。*你的殿，*你的家室，或有或无指向会幕之意，所指的不仅是敬拜之处，更是神在地上的居所。参看上文诗篇 23:6、27:4。后半句中有一处优美的典故，暗指那浇灌伊甸园的河（创世记 2:10）。此一暗指在译文中虽已失落，在原文中却由 עדן（eden，伊甸）一词取复数形式而意为「快乐」或「喜悦」标示出来。那*浇灌*或*使之得饮*的动词，也正是创世记 2:10 所用的同一个词，可见这并非偶然的巧合。

<span class="ax-anchor" id="psalms-36-9"></span><span class="ax-vnum">10 <span class="ax-veng">(9).</span></span> *因为生命的泉源在你那里；在你的光中我们必得见光。* 他们必从你得着这一切，因为唯独在你里面有这一切福分取之不尽的源头。——*在你那里，*即在你面前，在与你的联合与相交之中。——生命的泉眼、泉首或源头，是一切享受与益处的总括说法。随后同一思想又披上另一重比喻的外衣。*在你的光中我们必得见光。* 唯有藉着神面上的光，人才能见到任何的好处；唯有在神的恩眷中，人才能得福。所能得着、所当企慕的唯一福乐，乃是神所赐、并存于神里面的那一种。参看前面诗篇 4:7 (6) 的注释。

<span class="ax-anchor" id="psalms-36-10"></span><span class="ax-vnum">11 <span class="ax-veng">(10).</span></span> *求你向认识你的人延续你的慈爱，向心里正直的人延续你的公义。* 在以热切的言辞描绘了那存于神里面、从他恩眷中涌流而出的福分之后，诗人如今加上一句祈求，愿这福分也及于他自认所属的那一类人。首个动词的字面意思是*抽引*或*延伸，*与上文诗篇 10:9、28:3 中以不同用法出现的动词相同。——*认识你的人，*并因必然的结果而爱你的人，因为对真神的真实认识，与对他正当的情感是不可分的。——*你的公义，*即你向那些信靠你慈爱之人所施的真实可信的对待；这等人在此处以及别处常被称为心中与行事都*正直*、*心里*坦直的人，

<span class="ax-anchor" id="psalms-36-11"></span><span class="ax-vnum">12 <span class="ax-veng">(11).</span></span> *不容来*（临）*到我，骄傲的脚；也不让恶人（们）的手赶逐我。*他刚才为一般正直的人所求的，如今特为自己求；这显明他在第 2-5（1-4）节中对人心败坏所作的那番观察，乃是由他自己在恶敌手下所受的苦难、或对这苦难的惧怕而引起的。——前一分句中的动词并非仅指*前来攻击*、侵犯或威胁，而是*临到身上*，含有实际而凶猛的扑击之意。参看前面诗篇 35:8。提到*脚*，令人想起鄙弃、践踏、压碎的意思；提到*手*，则是施展力量或暴行这一较为泛指的意思。末一动词是使动式，严格说是使之逃窜、使之流离、或放逐他乡。可比较它在列王纪下 21:8 的用法。本节的总意是：不要把我交在仇敌的权势之下。

<span class="ax-anchor" id="psalms-36-12"></span><span class="ax-vnum">13 <span class="ax-veng">(12).</span></span> *作恶的人就在那里仆倒了；他们被击倒，不能起来*（或 *站立）。*这祷告之后，紧接着是忽然涌出的确信——确信祷告已蒙垂听；凭着这确信，诗人便把自己所求的说成是已经成就了的。见前面诗篇 20:7（6）的注释。——*那里*一词的意味，与日常言谈中作为突然的惊呼而发出时极为相近。*那里！他们已经仆倒了*（已经如此）。严格解释起来，它是指就在那一处地方、就在他们所指望的凯旋正酣之际。见前面诗篇 14:5 的注释，那里这虚词也是这样用的；并参诗篇 132:17 与士师记 5:11。在所有这些地方，保留*那里*的处所意义，都胜过换成那个臆测出来的「*那时，*」之义，因为后一意义在别处从未出现过。——*作恶*，即虚妄或虚假，意义如前面第 5（4）节所解释的。——*被击*，或*被打倒*，是比*被抛下*更重的说法。见前面诗篇 35:5。——末了几个字，或指他们站立不住、不能使自己免于跌倒，或指他们既已仆倒就不能再起来。见前面诗篇 1:5、18:39（38），并参箴言 24:16。
