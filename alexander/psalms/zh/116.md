<!-- PAGE 479 -->
教会宣告她要为自己所经历的拯救赞美耶和华，第 1, 2 节；随后较为细致地描述这拯救，第 3-10 节；接着宣告教会打算以何种方式表达她的感恩，第 11-19 节。七十士译本与武加大译本把前面两篇合为一篇，又把我们眼前这一篇分为两篇，前一种处置与后一种同样缺乏理由。本篇所提及的情形乃是悲喜交集的，加之其语言上的种种特点，合起来足以把它的年代定在从巴比伦归回之后不久。

<!-- PAGE 480 -->
<span class="ax-anchor" id="psalms-116-1"></span><span class="ax-vnum">1.</span> *我爱*——*因为耶和华垂听我的声音、我的恳求。* 通行译本把意思传达得不错，但借着把*耶和华*一词调换位置，回避了原文中那独特而罕见的句式。动词*我爱*的宾语，很容易从句子其余部分补出。参诗篇 18:2 (1)、申命记 6:6。两个动词虽在希伯来文中时态不同，却都可译为现在时。前一个用过去时式（*我已爱了）*，表明那机缘早已给定；后一个用将来时式（他将垂听），表明这垂听一直在继续，并且还要继续下去。末一个词按其字源而言，意为求恩、求眷顾的祷告。

<span class="ax-anchor" id="psalms-116-2"></span><span class="ax-vnum">2.</span> *因为他向我侧耳，我在我的年日中要呼求*（他）。前一分句中这个比喻的原意，似乎是指俯身前倾，以便听见那本来太微弱、不能清楚听闻的声音。参看上文诗篇 31:3 (2) 的注释，并比较诗篇 17:6，71:2，78:1，102:3。*在我的年日中*通常被理解为「终我一生的日子」，或「只要我还活着」。比较以赛亚书 38:8，又见上文诗篇 104:33 的注释。*我要呼求*或可理解为：我要继续向那位迄今应允我祈求的主祷告。但*呼求神*一语不单用于祷告，也用于感谢，这从下文第 13 节可以看出；在那里我们实际上看见此处所立定的心愿得着了成就。

<span class="ax-anchor" id="psalms-116-3"></span><span class="ax-vnum">3.</span> *死亡的绳索围住我，阴间的痛苦临到我；困苦与愁烦，我遇见。*此处开始描述神所拯救他脱离的那些苦难。这些措辞取自诗篇 18:5, 6（4, 5）。本节两次使用*动词「遇见」*，与英文中同义的 *catch*（染上）和 *seize*（抓住）两个动词的用法相类：人可以说「染上了病」，病也可以说「抓住了人」。试比较诗篇 119:143 与箴言 6:33。*阴间，*取其广义，相当于 *sheol，*即坟墓、死亡，或死人所处的状态。参看前面诗篇 6:6（5）的注释。

<span class="ax-anchor" id="psalms-116-4"></span><span class="ax-vnum">4.</span> *我呼求耶和华的名；哦现在，耶和华啊，求你搭救我的性命！*前一分句中的将来时可以严格地译出（我*将呼求）*，表达他在患难之中所立定的决心。见上文诗篇 18:5, 7（4, 6）注。*哦现在*在词源与意义上都与那恳求的加强语气词（*אָנָּה*，即 *אנא*，由 אה 与 נָא 合成）完全相应，通行译本将其意译为*我求你。*构成此词的成分之一已见于上文，诗篇 115:2。

<span class="ax-anchor" id="psalms-116-5"></span><span class="ax-vnum">5.</span> *有恩惠的*（是）*耶和华，又是公义的，我们的神施怜悯。*第一分句可比较诗篇 111:4、112:4。希伯来文的末一字是动词「*怜悯*」、「*体恤*」的主动分词，此处用以表示一种常态的习性，有别于一时的感情。

<span class="ax-anchor" id="psalms-116-6"></span><span class="ax-vnum">6.</span> *纯朴人的保守者*（是）*耶和华；我被带到低微，他把拯救带给我。*此处第一个词又是一个主动分词，*保守纯朴人的，即*习惯性地看顾他们。关于*纯朴人*的含义，见前文诗篇 19:8（7）的注释。*带*（brought）一字在本节译文中两次出现，在希伯来文里并无一个与之明确对应的字，但由于一种偶然的巧合，它恰好进入两个英文短语之中，而原文的两个动词正以这两个短语表达得最为贴切。译作*被带到低微*的那个动词，意思是在身位、力量或境况上被减损。见前文诗篇 79:8 的注释，并比较诗篇 41:2（1）中的同源形容词。另一个则是常见的希伯来文动词*拯救*，此处用迂回的说法表达，为的是保留原文中与介词*给*（to）连用的结构；这一结构也见于前文诗篇 72:4，86:16。

<!-- PAGE 481 -->
<span class="ax-anchor" id="psalms-116-7"></span><span class="ax-vnum">7.</span> *我的心哪，你要归回安息，因为耶和华已厚待了你*（恩惠）。他呼唤自己那曾动荡惊惶的心归回安息，由此表明危险已经止息。*安息，*按字面作*诸安息*或*诸安歇之处，*表示那安息的丰盛与完全。见上文诗篇 23:2 的注释。关于末一个动词（גמל）的意义与用法，见上文诗篇 13:6（5）的注释，并参诗篇 7:5（4），103:10。本节中那些不常见的语法形式，与诗篇 103:2, 5 中的相类。

<span class="ax-anchor" id="psalms-116-8"></span><span class="ax-vnum">8.</span> *因为你救我的性命脱离死亡，救我的眼睛免于流泪，救我的脚免于跌倒。*此处以突然的呼告，直接向神说话。本句的首尾两个分句取自诗篇 56:14（13）。第二个分句则与诗篇 56:9（8）及耶利米书 31:16 略有相似之处。

<span class="ax-anchor" id="psalms-116-9"></span><span class="ax-vnum">9.</span> *我要在生命之地（或译*活人之地*）行在耶和华面前。*这一句也是借自诗篇 56:14（13），只是把*光*换成了*地*（字面作*众地*）。参诗篇 27:13。此处所表达的盼望，与诗篇 115:17 恰成对照。

<span class="ax-anchor" id="psalms-116-10"></span><span class="ax-vnum">10.</span> *我信了，所以*（这样）*我说话；我大受苦难。*我必定是运用了信心，否则我不能这样说话。七十士译本的译法，为新约所沿用（哥林多后书 4:13），以不同的形式表达了同样的实质意思：*我信，所以我说话。*正是因为他的信心使他能够说话，所以他的说话便是信心的凭据。

<span class="ax-anchor" id="psalms-116-11"></span><span class="ax-vnum">11.</span> *我在惊惶中说。凡有血气的人*（都）*是虚谎的。*前一分句的措辞取自诗篇 31:23（22）。但此处与其说是承认自己的错误，不如说是信仰的宣告。即便在激动、惊恐、慌乱之中，他仍能转离一切人的帮助，单单信靠神。*凡有血气的人都是虚谎的，即*不可信托、不可倚赖——这一命题的补足与反面便是：所以惟独神是可信靠的。同样的对比在诗篇 118:8 中说得更为明白，并参诗篇 62:9, 10（8, 9）、108:18（12）、146:8, 4。

<span class="ax-anchor" id="psalms-116-12"></span><span class="ax-vnum">12.</span> *我拿什么报答耶和华向我所施的一切赏赐呢。*在本节与前一节之间，我们必须补上一层意思，即他的信心已因事情的结局而得了报偿、得了证实。这实在也已含在眼前这句发问之中。*何以，*字面作*什么，即*（以）*什么*（方式），或（藉）*什么*（手段）？参创世记 44:16。此处所用的*不寻常的词「赏赐」（bestowments）*，是用来对应一个仅见于此处的希伯来词，而该词显然由动词 גמל（施予、赏赐）构成，上文第 7 节即用此动词。这名词连同其代词词尾的特殊形式（תַּגְמוּלוֹהִי），为最高的语文学权威所公认，足以断定此篇的写作年代在被掳归回之后。

<span class="ax-anchor" id="psalms-116-13"></span><span class="ax-vnum">13.</span> *救恩（们）的杯我要举起，并要求告耶和华的名。*此句通常被解作指犹太人的传统，即与感谢祭同时或随后举行的祝谢之杯。但圣经中并无此杯的记载，这一传统的来源，多半正可追溯到拉比对本节的解释。若按圣经本身的类比来解，它不过是说：我要领受神为我所分定的分。关于*杯*的这种比喻用法，参前文诗篇 11:6, 16:5 的注释。复数形式*救恩（们）*表示丰盛或完全，如诗篇 18:52(51)、53:7(6)。*举起，*仿佛从神的手所摆放之处的桌上取起；或作*高举，*向天举起，作为承认领受的姿态。

<span class="ax-anchor" id="psalms-116-14"></span><span class="ax-vnum">14.</span> *我向耶和华所许的愿我必偿还*——*在他众民的面前。*通行译本中的 *now*（今／现在）一词使英文读者产生误解，他们几乎无可避免地把它理解为时间副词，意为*现今、立刻、毫不迟延*，然而它其实是恳求语气的小品词（נָא），诗篇 115:2 即用此字，此处用来缓和这一大胆的誓愿表白，使其系于神的允准。仿佛他说：我向耶和华所许的愿我必偿还——求容我在他众民的面前（我恳求）如此行。有些人把同样的意思归于译作*面前*一词的加长或词尾延长形式，该词严格说来意指前面或前部。这两处特点都被算作希伯来文写作年代较晚的标记。

<span class="ax-anchor" id="psalms-116-15"></span><span class="ax-vnum">15.</span> *在耶和华眼中为宝贵的，*（是）*他有恩之人（或作*圣民*）的死。*此处的意思与措辞取自诗篇 72:14，那里论到他们的血也是这样说的。*死*一字在词形上的特异之处，与第 14 节的*面前*一字相同，并且同样与介词 *「归于」连用：「那归于他圣民的死」，即*属于他们、他们所要死的那死。批评家视这些为本篇写作年代的又一标记。本节说明前面所许之愿的缘由，即：神看他子民的死极其贵重，不容轻易或无故舍弃。

<span class="ax-anchor" id="psalms-116-16"></span><span class="ax-vnum">16.</span> *啊现在，耶和华*——*因为我*（是）*你的仆人，我*（是）*你的仆人，你使女的儿子；你已解开我的锁链。* 开首那句恳求之语，所指的是一件未曾明言、却不难补出的事，即容他如此表白自己的感恩。啊现在，主啊（容我如此行）因为我是你的仆人……。所加的「*你使女的儿子*」一语，比「*你的仆人*」更为有力，描述他是家中所生的奴仆。参看上文诗篇 86:16 的解说。末句中我们又见一例：一个介词（ל）插在主动动词与其宾语之间，这是较古的希伯来文所不知的用法。不过，也可以把这几个字译作：*你已释放*（我）*关乎（即* 脱离）*我的锁链。*

<span class="ax-anchor" id="psalms-116-17"></span><span class="ax-vnum">17.</span> *我要向你献上感谢的祭，并要求告耶和华的名。*其意并非说：我要以感谢代替祭物，乃是说：我要献上一种真正表达感谢、且为此目的所设立的祭物。

<span class="ax-anchor" id="psalms-116-18"></span><span class="ax-vnum">18.</span> *我向耶和华所许的愿，我必在*（我恳求）*他众民面前偿还。*这是第 14 节的确切重复，连其形式上的一切特异之处也一并保留。

<span class="ax-anchor" id="psalms-116-19"></span><span class="ax-vnum">19.</span> *在耶和华殿的院中，在你中间，耶路撒冷啊。哈利路亚！* 本节补足了前一节，并解明了*在他众民面前*这一语。有人视之为一个证据，证明本篇诗是在圣殿实际重建之后所作。但在以斯拉记 2:68、3:8，我们见*神的殿*这一称呼被用于那片已分别为圣的地基。而*院*字的用法就更为自然，因为它原意是*围地*，这是早在圣殿重建之前就可以、也无疑已经划定了的。末句的补述似乎印证了这一解释。在主殿的院中，即在你中间、在圣城耶路撒冷啊，那已分别为圣的地方。
