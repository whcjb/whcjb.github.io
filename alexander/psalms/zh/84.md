<span class="ax-vnum">1.</span> *交与伶长。用*（或按着）*迦特（Gittith）。由*（或为）*可拉的子孙。* 诗人颂扬与神亲密相交之有福，第 2-8（1-7）节；并祈求自己得以享有此福，第 9-13（8-12）节。本篇在题材、语调与精神上与诗篇 42 篇相似，而尤可注意者，在于二者各自立于一组题为*属可拉的子孙*之诗的开端。此处所记的经历显然是大卫的，故我们必须或者把可拉的子孙理解为仅仅作为演奏者而被提及，或者设想他们作此诗是为表达君王本人的心情——亨斯滕伯格（Hengstenberg）以大卫在扫罗面前弹琴歌唱、以缓和其狂乱之发作一事，来说明这一假设。关于此问题双方的论据，见前文诗篇 42:1 的注释；关于*迦特*一语的含义，见诗篇 8:1、81:1 的注释。

<!-- PAGE 363 -->
<span class="ax-anchor" id="psalms-84-1"></span><span class="ax-vnum">2 <span class="ax-veng">(1).</span></span> *何等亲爱*（于我）*是你的居所，耶和华啊，万军*（之神）*！*这个形容词，英文诸译本作*可爱的，*取法文 *aimable*（可爱）之意，即令人悦慕的。但这希伯来词的用法要求把它理解为*亲爱的、蒙爱的，*这正是此处上下文所需的意思。参看上文诗篇 45:1 的注释。复数的*居所*指圣所的各部分及其附属建筑，在诗篇 43:3 中用于会幕。参诗篇 68:36（35）。这些神的称号一如既往含有深意。一个提示神与祈求者之间的约的关系，另一个则以他的主权为祈求他保护的根据。这一热切呼喊的力量，因句子的结构而更形增强，因为全句只有一个分句，正如诗篇 18:2（1）。全节可与诗篇 27:1-5 比较。

<span class="ax-anchor" id="psalms-84-2"></span><span class="ax-vnum">3 <span class="ax-veng">(2).</span></span> *我的魂渴慕，并且也衰竭，切望耶和华的院宇，我的心和我的肉体；它们歌唱*（欢然）*，归与永生的神。*第一个动词表达强烈的渴望，如诗篇 17:12。参创世记 31:30。英文圣经作 *yea even*（是的，甚至），而非 *and also*（并且也），这或许语气过强，暗示了一种作者并无意表达的递进。*衰竭，*即力竭，或为强烈的渴望所销蚀。复数的*院宇，即*围院，其解释当如第 2 (1) 节的*住处*。所罗门的圣殿有两个院子；但其中一个是专归祭司使用的，历代志下 4:9。会幕的院宇被题及，是作为神按定例与以色列相交之处。见上，诗篇 65:5 (4) 的注释；并见下，诗篇 92:14 (13) 的注释。此处题到它们，不过是作那相交本身的记号，而那相交无论在何处都可以享受。见上，诗篇 27:4，36:9 的注释。魂、心与肉体，指人的全体。见上，诗篇 63:2 (1) 的注释。希伯来文的重音符号把*心和肉体*连于前面的词。远为自然的分法是通行的那一种，即把它们直接与末句的动词连读。那动词在别处总是指欢乐的呼喊或歌唱；但其派生的名词（רִנָּה）却用以表示求救的呼声或恳切的祷告，有人便把这个意思加在此处的动词本身上，好使两个分句严格地成为平行体。若在此保留该动词通常的意思，这一分句便表明说话者已经经历了他所祈求的事。*永生的神，*即真实存在、并把生命赐给别人的那一位。见上，诗篇 42:3 (2) 的注释。

<span class="ax-anchor" id="psalms-84-3"></span><span class="ax-vnum">4 <span class="ax-veng">(3).</span></span> *是的，麻雀已找着一个家，燕子（找着）一个窝，*（在）*其中她安放她的雏，就是你的众坛，耶和华，*（万）*军之（神），我的王我的神。*首字本义是*也，*如前一节所用，有人译作*甚至，*仿佛他说：「连鸟儿都在神的圣所里有窝，我却被摒于其外。」参马太福音 8:20。但如此所称的事实极不可能，且别处并无记载。更自然的解释，是把麻雀与燕子（泛指弱小无助的飞鸟）看作敬拜者自身的象征。仿佛他说：是的，这漂泊的鸟儿终于为自己、也为它的雏找着了安歇之处，即家。此说与大卫的用语习惯全然相合，从撒母耳记上 26:20、诗篇 11:1、55:7(6)、56:1 即可看出。*就是你的众坛*这一译法，是假定希伯来文的小品词（את）标示动词的宾语，正如它在列王纪上 19:10, 14 中置于同一名词之前那样。然而它也可能是介词，意为*在……旁*或*靠近，*凡主张此处所指乃鸟儿实在筑巢于圣所的释经者，都取这一意义。所说的*坛，*是燔祭坛与香坛，如民数记 3:31 所载。特特提到它们，是因为神与人之间的交通，惟藉献祭与祈祷才成为可能。参诗篇 26:6。提到雏鸟，不仅是为了使图画完整，更是要表明：诗人如此珍视的那交通与神的保护，并非仅属个人，乃是家庭与群体的特权，是他为自己、也为倚靠他的人所切求的。*耶和华，*（万）*军之（神）*这一称呼，与第 2(1) 节同义。平行的说法*我的王我的神，*所传达的也正是至高主权与立约关系这两个根本观念；这一组合仅见于此处与诗篇 5:3(2)。

<span class="ax-anchor" id="psalms-84-4"></span><span class="ax-vnum">5 <span class="ax-veng">(4).</span></span> *你家中的居住者有福了，*（因为）*他们仍赞美你*（或 *将赞美你）。* 头一个短语正是本书开卷所用的那个惯用语，其特有的形式与意义，见上文诗篇 1:1，2:12，32:1, 2，33:12，41:2（1）的解释。*居住者，*即你家的住户，*即*你家中的成员，这几个字在耶利米书 20:5 正是这个字面意思。至于其属灵的或比喻的意义，见上文诗篇 15:1，23:6，24:3，27:4，61:5（4），65:5（4）的解释。这里所描述的特权，在任何地方都可以享有；但在旧约的时代，其外在的记号乃是常到圣所去。他们既是家中的人，不只是来访的客人，就必常有缘由、也常有机会去做他们初被接纳进神家时所做的事。*他们仍要赞美，*因为他们必不断有新的理由如此行。见上文诗篇 5:8（7），50:15, 23，79:13 的解释。

<span class="ax-anchor" id="psalms-84-5"></span><span class="ax-vnum">6 <span class="ax-veng">(5).</span></span> *那人有福，他*（有）*力量在你里面，*（他们*有）大道在他们心中。* 原文由几句感叹或惊呼构成——*有福的人！*——（有）*力量归他，在你里面！*——（有）*大道在他们心中？* 最后这句不寻常而晦涩的话，有人以为意思是：在其心思（或情感）中存着上耶路撒冷的大道，*即*那些仍念念不忘上去在那里敬拜的人。但另有一种解释，无论与紧接的上下文，还是与用法和类比，都远为吻合：它认为此处的比喻与诗篇 50:23、箴言 16:17、以赛亚书 40:3, 4 中的比喻相同；在那些经文里，凡拦阻神重临祂的百姓、与他们相交的道德或属灵障碍之被除去，都以诗意的笔法描绘为在无路的旷野或别样难行之地上开辟、铺平、垫高一条堤道。译作*大道*的那个词，从词源与用法两方面都可确定，并非指一条踩出来的小径或步道，而是指人工筑成、并高出其所经之地的道路。末一分句中数的突然转换表明，*人*是一个类名或集合名词。

<span class="ax-anchor" id="psalms-84-6"></span><span class="ax-vnum">7 <span class="ax-veng">(6).</span></span> *穿行流泪谷，他们使它成为泉源；并且，教师也被福泽所披覆。*这是全书最晦涩的经节之一。然而，释经者今日对前半句大致已有共识。把 *Baca* 解作桑树谷或巴迦树之谷（撒母耳记下 5:23, 24；历代志上 14:13, 14），现今多半已被放弃，而采纳古译本所给的解法，即流泪谷或忧伤之谷，这是对今生之为受苦之生的一个优美的诗意描写。与*那 *fons* lacrymarum*（泪泉）相对的，是救恩或喜乐的泉源；这一比喻在圣经中极为常见，单凭*泉*或*源*一词便足以唤起。参看上文诗篇 36:10（9）、46:5（4）的注释，并比较以赛亚书 12:3。照此解释，这半句的意思是：前一节被称为有福的人，自身乃是幸福的源头，他们把流泪谷本身变作欢乐的泉源。另半句的意思则至今仍有争议。头一个名词只需变动一个元音点，便可作*池*或作*福泽*；其后一词虽通常意为*教师*（列王纪下 17:28；箴言 5:13；以赛亚书 30:20），却另有一处（约珥书 2:23）具有*雨*、更确切地说是巴勒斯坦*秋雨*的意思；因此这半句可容许几种极不相同的解释。1. 雨水也遮满众池。2. 教师以福泽为衣。3. 雨以福泽覆盖它。有利于第二种解法的，是它紧紧贴合这三个关键词的通常用法；而且古译本所给的实质上也是这一意思。那么其义便是：这种奇妙的变化之力，乃是善人作为义的教师而施展出来的；两个有争议的词之一（מורה，教师）正是在这个意义上出现于约珥书 2:23——这也说明了何以该词在同一句中又被重复一次，藉着一种谐音双关，取*秋雨*之义，而此义别处是用一个同源形式（יורה）来表示的。可将此处的意旨与诗篇 51:15（13）相比较。至于末一动词取中性或不及物之义，参看利未记 13:45；弥迦书 3:7；耶利米书 43:12。

<span class="ax-anchor" id="psalms-84-7"></span><span class="ax-vnum">8 <span class="ax-veng">(7).</span></span> *他们必从力量到力量前行*；*他必在锡安朝见神。*数的变换与第 6（5）节中的恰好相反，但当按同一原则来解释。或者末句的单数动词是指第 7（6）节中的那位教师。此处的*力量*乃神所赐的力量，他们在对它的经历中不断前进。末句的措辞方式，是律法中用来指以色列人按定期到圣所朝见的那种说法。全节的意思是：凡与前面所描述的相符之人，终必得着与神联合的完满享受，而他们的福乐正在于这联合之中。

<span class="ax-anchor" id="psalms-84-8"></span><span class="ax-vnum">9 <span class="ax-veng">(8).</span></span> *耶和华，神，万军*（之主）*，垂听我的祷告；侧耳而听哪，雅各的神！细拉。*本篇第二部分自此开始，所载的祈求乃是建立在前文对与神相交所生之福乐的默想之上。此处加于神的诸名号，一如往常，提示着祈求所凭的根据，即他的永恒、自有、主权，以及他与自己子民所立的约的关系。

<span class="ax-anchor" id="psalms-84-9"></span><span class="ax-vnum">10 <span class="ax-veng">(9).</span></span> （哦）*我们的盾牌啊，看顾，*（哦）*神啊，垂顾你受膏者的面。*有人把第一个名词作为随后那动词的宾语，*看顾我们的盾牌；*但在第 12（11）节中，神自己就是如此被描述的，诗篇 3:4（3）、创世记 15:1 也是一样。它作为呼格置于此处，诚然不寻常，却似乎带有强调的意味。*垂顾那面，即*以恩眷垂顾之，恩慈地看顾之。*你的受膏*（者）*，即*大卫，这篇诗是由他、或以他的名义写成的。

<span class="ax-anchor" id="psalms-84-10"></span><span class="ax-vnum">11 <span class="ax-veng">(10).</span></span> *因为更好*（是）*在你院中的一日，胜过一千；我宁可拣选在我神的殿中守门槛，也不愿住在邪恶的帐棚中。*两个分句中的比较，都照希伯来文的惯例，用介词 *从、离开*来表达。「好，从一千，*即*与一千相比。」「我拣选，从居住，*即*而非居住。」第一个分句的意思当然是说，在神院中的一日，胜过在别处的一千日。*我已拣选*，并且仍在拣选，这比*我会拣选*或*我宁愿*语气更强。下一个动词全书仅见于此处，显然是由名词（סַף）*门限*或*门槛*变来的。译作*作看门的*（守门槛），以及*卧在门槛上*，都失之过于具体，似乎在原文的意思之外另有所加。其意或许是说：他宁愿站在神殿的门口往里观看（这原是摩西的圣所中敬拜者所能做的一切），也不愿住在罪孽横行的帐棚或房屋之内。本句中*帐棚*一词的用法，使得平行语句中的*神的殿*所指为会幕而非圣殿，显得更加可能。

<span class="ax-anchor" id="psalms-84-11"></span><span class="ax-vnum">12 <span class="ax-veng">(11).</span></span> *因为耶和华神是日头，是盾牌；耶和华必赐下恩惠和荣耀；他必不拒绝*（任何）*美善予那些行在完全*（道）中的人。开头的「因为」表明本节是为前一节所表达的那种偏爱陈明理由。神在此被称为日头，正如诗篇 27:1 称他为亮光。这两个比喻都把他描绘为福乐的泉源；盾牌之喻则把他描绘为安全的来源，或大能的保护者。*恩惠*与*荣耀*（或 *尊荣）*的关系，犹如因与果。后者包括神恩眷一切可感知的果效与彰显。参看前面诗篇 49:17 (16) 的注释。*在完全*一语，有人理解为*像一个完全的*人，*即*完完全全地、正直地。参看前面诗篇 15:2、18:24 (23) 的注释，并比较创世记 17:1。

<span class="ax-anchor" id="psalms-84-12"></span><span class="ax-vnum">13 <span class="ax-veng">(12).</span></span> *耶和华*（万）*军（之主），有福的是倚靠你的人。*此分词表达的是习惯性的倚靠。*倚靠你，*正如我所行的。
