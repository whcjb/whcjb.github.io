<span class="ax-vnum">1.</span> *交与伶长。交与可拉的子孙。玛斯基拉（Maschil）。* 此处所生的疑问与诗篇 42 篇相同，即本篇归于可拉子孙名下当作何解。根据彼处所陈的理由，总的看来，最有可能的仍是大卫为作者，尽管其名何以不见于题注、而可拉的子孙何以出现在通常属于他名字的位置上，殊难解释。见上文诗篇 42:1 之论。附加的*玛斯基拉，即*一篇训诲诗，意在表明本篇虽因某一特定事件而作（或许即诗篇 60 篇所指的那同一事件），却是为神子民长久的使用与造就而写下、而存留的。见上文诗篇 32:1 之论。思路的脉络格外分明。古时，神是以色列的保护者与拯救者，第 2-5 节（1-4 节）。他如今仍是他们立约的、本族的神，第 6-10 节（5-9 节）。然而他似乎已把他们交付仇敌，第 11-18 节（10-17 节）。但以色列仍紧紧依附于他，并为他的缘故受苦，第 19-23 节（18-22 节）。因此恳切求他再度显现，施行拯救，第 24-27 节（23-26 节）。本篇所描述的情形与所表达的心志，丝毫不足以成为理由，将它归于晚于大卫的任何时期；因为在大卫的时代，同样的哀诉与恳求的缘由早已存在，只是尚不及后世那般深重罢了。

<!-- PAGE 203 -->
<span class="ax-anchor" id="psalms-44-1"></span><span class="ax-vnum">2 <span class="ax-veng">(1).</span></span> *神啊，我们亲耳听见，我们的列祖向我们述说，你在他们的日子、在古时的日子所做的工。*他们耳中所听见的，暗暗与他们眼中所看见的大不相同之事相对照。参看下文诗篇 48:9（8），并参士师记 6:13、历代志下 20:7、哈巴谷书 3:2。*我们的列祖向我们述说，*正如出埃及记 10:2 所吩咐或所预言的。此动词本义为*数*，继而为*细数*或述说，特指逐一列举详情。参看上文诗篇 2:7 的注释。末句亦可解作独立的一句：*一件工，你曾做过，*……但这样一来，首句的两个主动动词便没有了语法上的宾语。动词与其同源名词的这一有力搭配，在英文圣经作*你所做的是何等的工，*已大为削弱，而公祷书译本作*你所做过的事，*则削弱得更甚。所指的那一件工，由下文可知，乃是攻取迦南、使以色列安居其中之事。

<span class="ax-anchor" id="psalms-44-2"></span><span class="ax-vnum">3 <span class="ax-veng">(2).</span></span> *你*（用）*你的手赶出列国，又栽植他们，压碎万民，又使他们蔓延。*这虽是字面的译法，在英文里却晦涩难明，因为两个分句中的代词*他们*都是指以色列。在后一分句中，它诚然可以指迦南人，而那动词可取「打发出去、驱逐」之义，如创世记 3:23、列王纪上 9:7、以赛亚书 50:1 所用。但此字也用来表示树木或葡萄树抽发枝条，见诗篇 80:12 (11)、耶利米书 17:8、以西结书 17:6, 7, 31:5，故平行体似乎足以断定此处当取后一义。译作*赶出*的动词，本义是使之承受产业，但有时也用于以此一承继者或占有者取代彼一者。见出埃及记 34:24、民数记 32:21, 33:52、申命记 4:38。译作*压碎*的动词也可仅作*损害*解，但此处当以较强之义为优。

<span class="ax-anchor" id="psalms-44-3"></span><span class="ax-vnum">4 <span class="ax-veng">(3).</span></span> *因为不是用（他们的）刀剑他们得了那地，他们*（自己的）*膀臂也没有拯救他们；因为*（那是）*你的右手，你的膀臂，和你面上的光；因为你喜悦了他们。* 句首的「因为」引出对上一节总括之语的证明或铺陈，即：栽植他们、使他们安居的乃是神。*拯救他们，*字面是*向他们或为他们。即*没有将拯救带给他们，也没有为他们成就拯救。将第二个 כִּי（因为）译作*但*，虽得了原文的意思，却失了原文的形式，因为紧接其前与其后的这个虚词都用的是严格本义，这就不容我们把中间的那一个作别解。首句可参 约书亚记 24:12，末句可参 诗篇 4:7（6）。

<span class="ax-anchor" id="psalms-44-4"></span><span class="ax-vnum">5 <span class="ax-veng">(4).</span></span> *你是他，我的王，*（哦）*神啊！为雅各吩咐拯救。* 前一分句的措辞极合希伯来惯用语，却略显晦涩。它或可解作「行了这一切的你仍是我的王」，或解作「你就是那位作我王的」，后一种译法可按英文的惯用语转述为「作我王的正是你」。参撒母耳记下 7:28、历代志上 21:17。教会在此声称自己与耶和华的关系，正是他子民历代先人所享有的那一关系。末一分句亦可译作*安排雅各的众拯救，即*使之成就，并以你的护理调度之。族长的本名在诗中取代了他作为选民之父的称号。参见上文诗篇 24:6 的注释。

<!-- PAGE 204 -->
<span class="ax-anchor" id="psalms-44-5"></span><span class="ax-vnum">6 <span class="ax-veng">(5).</span></span> *靠着你，我们要抵触我们的敌人；奉你的名，我们要践踏那起来攻击我们的。*以色列的指望仍旧倚赖那驱逐迦南人的能力。译作*敌人*的那个词，本义是那些*压迫*、欺压或逼迫人的。参看上文诗篇 3:2 (1)，并参诗篇 13:5 (4)，27:2, 12。我们的*仇敌*，字面是我们的起来者，即那些起来攻击我们的人。参看上文诗篇 18:40 (39)，并参申命记 33:11。前半句中的动词特指用角抵触、挑起或抵伤。见出埃及记 21:28-32，并参申命记 33:17，列王纪上 22:11。*奉你的名，*不单是凭你的权柄，或作你的代表，乃是在你里面，与你联合相通。参看上文诗篇 5:12 (11)，18:30 (29)。此处将来时动词的意思是：他们若要得胜，就只能循此而胜。他们必须如此得胜，否则就必败亡。

<span class="ax-anchor" id="psalms-44-6"></span><span class="ax-vnum">7 <span class="ax-veng">(6).</span></span> *因为我必不倚靠我的弓，我的刀也必* （或 *能）不救我。* 「凡在我列祖身上为真的，在我身上也照样为真。他们既不是靠自己的力量得胜，我也不能指望靠自己的力量得胜。」

<span class="ax-anchor" id="psalms-44-7"></span><span class="ax-vnum">8 <span class="ax-veng">(7).</span></span> *我们在神里面终日夸赞，并要称谢你的名，直到永远。细拉。*首句的结构虽与我们的语法习惯不合，却比单说*我们赞美了神*更有表现力。它先提出神，作为那*在其中*寻求并寻得赞美之机缘与题材的对象。「我们正是在神里面找到我们颂赞的题目。」通行译本（*夸口*）把此处所用的动词与同一字根的另一派生词混为一谈。*你的名，*即你所彰显的本性。见上文，诗篇 5:12（11）。*直到永远，*或作长久、永永远远。*终日*（之久）*，即*常常。见上文，诗篇 25:5，42:11（10）。*称谢，即*怀着感恩献上谢意。见上文，诗篇 6:6（5）。

<span class="ax-anchor" id="psalms-44-8"></span><span class="ax-vnum">9 <span class="ax-veng">(8).</span></span> *因为你曾拯救我们脱离我们的敌人，又使那恨我们的*（或作*那些恨我们的人）蒙羞。*本节的过去时是对前一节将来时的解释。「我们此后不倚靠自己，因为从前帮助我们的正是你。」若把过去时与将来时彼此混淆，或把二者都解作现在时，这两节之间的逻辑关系便被破坏了。*蒙羞，即*被击败、落空。见上文论诗篇 *6:*11（10）、14:6 处。

<span class="ax-anchor" id="psalms-44-9"></span><span class="ax-vnum">10 <span class="ax-veng">(9).</span></span> *不，你已弃绝我们，使我们蒙羞，你也不与我们的军旅同出。*开头的那个小品词（אַף）所含的意思，不止是否定刚才所述的恩眷，乃是说：「但如今你不这样待我们；*不但如此，*你竟已弃绝我们。」这个希伯来动词含有厌恶憎弃之意。参上文，诗篇 43:2 的注释。另一个动词意为使之羞愧、以羞辱遮盖之，如诗篇 35:4; 40:15 (14)。前面诸动词用过去时，表明这弃绝已经显明；随后所用的将来时，则表明有一种忧惧，恐怕此事仍要持续下去。*与我们的军旅同出，*作向导、作统帅、作盟友。参撒母耳记下 5:24。

<span class="ax-anchor" id="psalms-44-10"></span><span class="ax-vnum">11 <span class="ax-veng">(10).</span></span> *你使我们从敌人面前转身退后，而且*（如今）*恨我们的人已为他们自己掳掠，即*为他们自己。此处列举了战事中最令人不堪的两种遭遇：溃逃与被掠。*为他们自己掳掠，*不单指为着他们自己的好处，更是任凭他们自己的意愿与裁夺。参 撒母耳记上 14:48, 23:1。

<!-- PAGE 205 -->
<span class="ax-anchor" id="psalms-44-11"></span><span class="ax-vnum">12 <span class="ax-veng">(11).</span></span> *你必将我们如羊* （作）*食物，又把我们分散在列国中。* 时态的连属与前一节相同。*作食物的羊，或作食物的羊群，即*专备并惯于被人吃掉的。*给*一词或可解作安置、使成、立定，或解作交出、撇弃。末一分句有人理解为指巴比伦的被掳，并以此为年代较晚的证据。但在与四围列邦的每一次战争中，都有局部的掳掠与分散。参约珥书 4:2，阿摩司书 1:6, 9，并比较列王纪上 8:46。

<span class="ax-anchor" id="psalms-44-12"></span><span class="ax-vnum">13 <span class="ax-veng">(12).</span></span> *你必白白卖了你的百姓，并未因他们的价银而增多。*他们似乎是被无偿地交付出去，*即*没有必要，也无所得益。*白白地，*字面作财货或资财，指所得之产或等值之物。同一名词可在下一分句中重复，*你并未增多*（你的财货），正如英文中动词 *gain*（获利）可以独立使用一样。*他们的价银，*字面作*他们的诸价银，*或许是指各个被掳之人，或指此处所说这类买卖的屡次发生。另有一种可能却远为不自然的解法，把那介词仅看作连接词，读作*你并未抬高他们的价钱，即*未曾给他们定高价，意思是说，他反倒把他们贱卖了，或更确切地说，白白地送了出去。参 耶利米书 15:13。

<span class="ax-anchor" id="psalms-44-13"></span><span class="ax-vnum">14 <span class="ax-veng">(13).</span></span> *你必使我们成为邻邦的羞辱，成为四围之人的讥笑与戏谈。*若这光景继续下去，其必然的结局就是如此。*使我们，*字面作*安置我们，*把我们立起来，使我们暴露在人前。参看上文诗篇 39:9 (8) 的注释；全节可与诗篇 79:4、89:42 (41) 比较。

<span class="ax-anchor" id="psalms-44-14"></span><span class="ax-vnum">15 <span class="ax-veng">(14).</span></span> *你必使我们在列国中成为笑谈，在万民中成为摇头的对象。*笑谈，字面意思是一个比方或譬喻，是可以被引作令人难忘之例证或样板的事例。这一说法取自申命记 28:37。*摇头，即*人们要向之摇头的对象，以此表示轻蔑的怜悯。参看上文诗篇 22:8 (7) 的注释。

<span class="ax-anchor" id="psalms-44-15"></span><span class="ax-vnum">16 <span class="ax-veng">(15).</span></span> *终日我的羞辱在我面前，羞愧遮蔽了我的脸。* 它在我面前，以致我不能不看见它，也不能将它置之度外。参上文诗篇 38:18 (17)。羞愧在此被描绘为一种遮盖，如耶利米书 3:25，不过或许特别指脸上泛起红晕之状，如诗篇 69:8 (7)。

<span class="ax-anchor" id="psalms-44-16"></span><span class="ax-vnum">17 <span class="ax-veng">(16).</span></span> *因毁谤者与辱骂者的声音，因仇敌与报仇者的脸面。*这介词指出前一节所述羞辱的来源或起因。*脸面*在此或指当面，或指脸上的神色。末一个词本是分词，意为*施行报复*或*为自己伸冤*。此处与诗篇 8:3 (2) 一样，指怀恨而好报复的仇敌。

<span class="ax-anchor" id="psalms-44-17"></span><span class="ax-vnum">18 <span class="ax-veng">(17).</span></span> *这一切都临到我们身上，我们却没有忘记你，也没有向你的约行诡诈。*第一句可参士师记 6:13。*临到我们：*其结构与诗篇 35:8 相同。*我们没有行诡诈，*或作*行事虚假。*同一动词配同一介词，在利未记 19:11 中意为向人说谎、行事欺诈。又见诗篇 89:34（33）。此处所表白的，并非全然没有任何不忠之举，乃是没有犯那全然忘记神、背道离弃的死罪。以色列虽有不忠，仍自称是、并且确实是耶和华所拣选的子民。

<span class="ax-anchor" id="psalms-44-18"></span><span class="ax-vnum">19 <span class="ax-veng">(18).</span></span> *我们的心未曾转回，我们的脚步也未曾偏离你的路。* 否定词的效力贯及两个分句，正如诗篇 9:19（18）。*心* 与 *脚步* 分别代表内在的情感及其果实，即外在的行为。*转回* 与 *偏离* 乃是描述道德上背离的自然而常见的比喻。*你的路，* 即你诫命的道路。

<!-- PAGE 206 -->
<span class="ax-anchor" id="psalms-44-19"></span><span class="ax-vnum">20 <span class="ax-veng">(19).</span></span> *你竟在龙的所在之地把我们压碎，又用死荫遮盖我们。* 这里的句法是承接前一句而来的。按我们的语言习惯，这一关联可以这样说明：「我们并没有犯这样的不忠或全然的背道，以致你当如此待我们。」*压碎，*即压伤，或打成碎块。参看上文诗篇 10:10 的注释，以及下文诗篇 51:9（8）的注释。*龙*在此可理解为泛指野兽或孤居的走兽。至于这个希伯来词是否特指野猫、狼或豺狼，这在解经上无关紧要。整个短语的要义是：孤居之物所栖之地，*即*旷野或荒漠。参以赛亚书 13:22，34:13，43:20，耶利米书 9:10（11），10:22，49:33，诗篇 63:11（10）。*遮盖我们之上，即*盖没、完全蒙蔽，较之单纯的动词语气更强。*死荫，*或作死亡的阴影，是形容最深沉黑暗的有力诗体表达。参看上文诗篇 23:4 的注释。

<span class="ax-anchor" id="psalms-44-20"></span><span class="ax-vnum">21 <span class="ax-veng">(20).</span></span> *我们若忘记了我们神的名，向陌生的神伸开我们的手。*有些人视此为起誓时常用的省略句式：「（愿神如此待我们，并且加倍）若我们忘记了」，这等于说「我们并未忘记」。另一种补足此省略的方式见于约书亚记 22:22。但既然本节按条件句理解，与下一节连起来也有良好的意义，那么这种较为显明的结构就应当优先采纳。举起或伸开双手的动作，常被提及为恳求时自然的姿势。参出埃及记 9:29, 33，列王纪上 8:38，以赛亚书 1:15。译文中的*神*一词，在希伯来文中代表两个不同的神名，即*Elohim*（神）与*El*（神）。见上文诗篇 43:4 的注释。*陌生的神，*或*一位神*（他是）*一个外人，即*对耶和华和他的百姓而言。这个希伯来词被摩西既用于人（出埃及记 30:33），也用于偶像（申命记 32:16），

<span class="ax-anchor" id="psalms-44-21"></span><span class="ax-vnum">22 <span class="ax-veng">(21).</span></span> *神岂不查究这事吗？因为他知道心中的隐秘。*这是上一节所起句子的后半。「我们若这样行，神岂能不知道呢？」译作*查究*的那个动词，本义是*挖掘*，即把埋藏在地下的东西挖出来见光。由此很自然地转而指对一切隐秘之事的查考与揭露。这里的发问是对所论之事间接却有力的肯定。末句开头的「因为」，所指的并非发问的理由，而是那默然含蕴的肯定答覆的理由。*他*（是）*知道的，*这一表达形式所指的是持续而恒常的知晓。参看上文诗篇 1:6 的注释；至于其中的意思，可与诗篇 7:10 (9) 所表达的相比较。

<span class="ax-anchor" id="psalms-44-22"></span><span class="ax-vnum">23 <span class="ax-veng">(22).</span></span> *因为为了你的缘故我们终日被杀；*我们*被算作宰杀的羊。*开头的因果小品词并非指紧接其前的话，而是指较远的上下文，为前面那一断言——教会并未忘记或离弃神——提出一项凭据。这凭据就在于：他们所受的苦难正是为他的缘故。*为了你，*为你的缘故，字面作*在你身上，因*（着）*你，*为你的缘故。过去时的形式*我们已被杀，*包含现在的意思*我们被杀，*但另加一层意思，即所说的苦难并非新近之事，也不是刚刚才有的，乃是久已经历的。*被算，*被数点，被估价，*即*被我们的仇敌所估价，他们看我们的性命，并不比*宰杀的羊*的性命更贵重；字面作*宰杀之群，即*被定规或惯常要被宰杀的羊群。这一说法恰与上面第 12（11）节的*当食物的羊*或*当食物的羊群*相对应。全节是对仇敌恶意所招致的严酷逼迫与患难的有力诗意描写，保罗也正是如此将它用在基督教会的苦难上，古时的以色列仍在这教会中存留。参罗马书 8:36。

<span class="ax-anchor" id="psalms-44-23"></span><span class="ax-vnum">24 <span class="ax-veng">(23).</span></span> *奋起吧！主啊，你为何沉睡？醒来，不要永远丢弃。* 这大胆的呼告既表明坚强的信心，也表明热切的情感。这样的称呼不会向一个无生命之物、或一个虚构之存有发出。其意与诗篇 3:8（7）相同，即：神的帮助、或他可感知的同在之收回，可以用比喻的方式描述为一种不动或沉睡的状态，等他再次显明自己的同在、施予帮助时，他便从其中醒来、起身。参诗篇 121:4，马太福音 8:25。因此这一节实在不过是一句恳切的祈求，求神相助。*丢弃，*即以厌恶与轻蔑弃绝，与上文第 10（9）节所用的乃是同一个强烈的词。*永远，*字面作*直到永久。* 不过这希伯来语短语与上文第 9（8）节所用的并不相同。

<span class="ax-anchor" id="psalms-44-24"></span><span class="ax-vnum">25 <span class="ax-veng">(24).</span></span> *你为何要掩面，要忘记我们的苦难与我们所受的迫害*（或*压迫）*？刚才以睡觉的比喻所表达的同一件事，这里被描述为不肯看、不肯记念。这两个比喻都出现在上面诗篇 13:2（1），所指的正是同一件事。这类拟人的说法，若出自一个未受灵感的作者笔下便是不合法的，但在此处却完全可以理解，而且极富表现力。译作*苦难*（或*患难）*的那个词是通称，包含各种形式的身体之苦，接着就指明其中的一种，即强横而怀恨的仇敌所造成的痛苦。同一个词在诗篇 42:10（9）、43:2 中指恶人手下的*压迫*或*迫害*。*你为何要忘记*显然比*你为何忘记*多一层意思，因为它还传达出这样的含意：「你为何要一直这样行，像你从前所行、如今仍在行的那样？」

<span class="ax-anchor" id="psalms-44-25"></span><span class="ax-vnum">26 <span class="ax-veng">(25).</span></span> *因为俯伏*（或*沉落）于尘土的是我们的魂，紧贴于地的是我们的腹。* 两个希伯来动词都是主动态，字面意思是：我们的魂已俯伏下去，我们的腹已紧贴于地。*腹*一词或可取*身体*之义，与*魂*相对，如前面诗篇 31:10（9）；或按其本义理解，若如此，则全句所描绘的乃是最深的卑贱——匍匐于地，既无力亦无意起身，其状如最低等的爬虫，或如创世记 3:14 中加于蛇身上的咒诅。无论此处所呈现的是何种意象，其所要表明的显然是一种极深的沉沦与卑屈之境。

<span class="ax-anchor" id="psalms-44-26"></span><span class="ax-vnum">27 <span class="ax-veng">(26).</span></span> *求你兴起，作我们的帮助，为你慈爱的缘故救赎我们！* 这是他一切论据的结语，也是他一切祈求的总括。*兴起，* 脱离这表面上无所作为的状态，施展你的大能。不仅是 *为帮助我们，* 如诗篇 38:23(22) 那样，而是 *作我们的帮助，* 你自己就是我们的帮助，是帮助的源头、帮助的创始者，这比 *我们的帮助者* 语气强得多，虽然二者实质上同义。参看上文诗篇 40:18(17)，以及下文诗篇 63:8(7)。*因你的慈爱，* 是作为根据或理由；*按你的慈爱，* 是作为准则或尺度；*为你慈爱的缘故，即* 为着它的荣耀，以之为动机，也以之为所要成就的目的。
