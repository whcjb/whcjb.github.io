<span class="ax-vnum">1.</span> *交与伶长。调用证言的百合花。米斯托（Michtam）。大卫作。为要教导。* 此处的*百合花*，大概与诗篇 45:1 一样，是美丽或可爱的象征。*证言*是律法的一个名称，因律法是神对罪的见证。参看上文诗篇 19:8（7）的注释，并比较列王纪下 11:12，该处此词绝对地用来指律法，视律法为一卷书或一份文书。因此这个谜语式的题注，或可理解为表明本篇的主题乃是律法之美，或律法中某种可爱之物，而最可能是指所引自律法的那个恩典的应许。同时，这里似乎也暗指申命记 31:19 的吩咐：「现在你要写一篇歌，教导以色列人，传给他们，使这歌见证他们的不是。」本篇题注对这一节似有双重的暗指：其一在*证言*一词，它与译作「见证」之词同出一源；其二在末尾*为要教导*几字，其中的动词与申命记所用的相同。因此眼前这题注似乎是说：这篇诗歌如同摩西之歌，是要教导百姓的，在他们不信或悖逆之时，作为对他们的见证或证言。这样，*为要教导*的意思就是*被教导*，或*被学会*于心，熟记在胸。试比较撒母耳记下 1:18，英文译本在那里误补作「（用）*弓*」，而非「（之歌）*弓*」，所指的乃是紧随其后那首为扫罗和约拿单所作的哀歌，照古时的习惯，因第 22 节提到约拿单惯用的兵器而得此名。参看上文诗篇 9:1 的注释。正因这谜语般的暗指，并因真理在此是以隐蔽的形式显明的，本篇被恰当地称为*米斯托*、谜语或隐秘之事。参看上文前四篇诗篇题注的注释。本篇正文，撇开第 2 节附加的题注或历史性题记不计，可分为三段等长的诗节或诗章，每段四节。第一段中，诗人因神似乎离弃了他的百姓，便追忆他从前为他们所行的干预，第 3-6 节（1-4）。第二段中，他援引一个明确的应许，作为当下盼望的根基，第 7-10 节（5-8）。第三段中，他表达自己对那即将出征以东之役必蒙保守、必得成功的确信，第 11-14 节（9-12）。全篇中理想的说话者乃是以色列，被视为蒙拣选的子民。

<span class="ax-vnum">2.</span> *当他征服亚兰·拿哈连与亚兰·琐巴，约押回来，在盐谷击杀以东人一万二千的时候。* 通行译本对首个动词的译法（strove with，与之争战）似嫌太弱，因为此处分明已预设了得胜，而争战之意乃是由同一动词的一个同源形式所表达的。*亚兰*之名相当于最广最泛意义上的*叙利亚*，并常与别的名称连用，以指称那片广大地域中的某些特定部分。它甚至包括美索不达米亚——这是自然地理而非政治地理上的名称，指底格里斯河与幼发拉底河之间的地带，与本节中的*亚兰·拿哈连*，即*两河的叙利亚*相当。此地之王臣服于亚兰·琐巴王，纳贡于他，这从大卫第二次亚兰之战的记载可以看出（撒母耳记下 10:16, 19）。得胜之师从此役班师之后，约押才进军以东，成就了此处归于他名下的胜利，因他是全军统帅；但历代志上 18:12 却将此胜归于他的兄弟亚比筛，亚比筛大概是在他麾下领兵，正如后来一次战役中那样（撒母耳记下 10:10）；而撒母耳记下 8:13 又归之于大卫自己，因他是二人所代表的君王。*盐谷*已被近代旅行家考定为死海以南的一处山谷，位于以色列与以东的古代疆界上，参罗宾逊（Robinson）《巴勒斯坦》卷二第 483 页。此役所杀之数，撒母耳记下 8:13 与历代志上 18:12 均作一万八千。但这种出入很容易出于计算方式的不同，而且至少表明本节的作者并非盲目抄录历史书；同时他所记的数目较小，也足见他全无粉饰夸大的倾向。

<span class="ax-anchor" id="psalms-60-1"></span><span class="ax-vnum">3 <span class="ax-veng">(1).</span></span> *神啊，你丢弃了我们；你使我们破裂；你曾发怒；你必复还于我们*（你的恩惠，或我们先前的昌盛）。纵然你不悦的痕迹何等分明，我们仍满怀确信仰望你恩惠的回转。这或许是指战事前段所经历的挫败。*丢弃我们，*带着厌恶与轻蔑，如诗篇 43:2，44:10, 24（9, 23）。*使我们破裂，*或在我们中间打开缺口，这似是军事上的比喻，也是大卫在实际生活中所惯用的。见撒母耳记下 5:20，6:8，并比较士师记 21:15，约伯记 16:14，30:14。末一动词意为复还，如诗篇 19:8（7），23:3，惟所施之对象不同。参以赛亚书 58:12。

<span class="ax-anchor" id="psalms-60-2"></span><span class="ax-vnum">4 <span class="ax-veng">(2).</span></span> *你使地震动，你使它裂开；求你医治它的破口，因为它摇动。*此处以地震及其自然后果为喻，表明社会的灾祸与患难；诗人求神除去祸根，使这一切止息。

<span class="ax-anchor" id="psalms-60-3"></span><span class="ax-vnum">5 <span class="ax-veng">(3).</span></span> *你使你的百姓看见*（何为）*艰难；你使我们喝那使人东倒西歪的酒*（或作*踉跄*）*。*前一分句的意思是，神使他们经历了艰难。参见诗篇 71:20 中相似的说法。*使人东倒西歪的酒，*即令人摇晃踉跄的酒，在此用作混乱、软弱与困苦的比喻。同样的意象又见于诗篇 75:9（8）、以赛亚书 51:17, 22、耶利米书 25:15、49:12。参上文诗篇 11:6 的注释。

<span class="ax-anchor" id="psalms-60-4"></span><span class="ax-vnum">6 <span class="ax-veng">(4).</span></span> *你已赐给敬畏你的人一面旗帜，要因*（你的）*真实而被举起。细拉。*在你那溃败沮丧的子民眼前，你竖起了一面旗号，作为集结之处，也作为你所立之约真实可信的凭据。译作*旗帜*的那个词（נס），意思是任何高举起来作信号之物，乃源出于随后的那个动词；该动词在此处所用的形式中，本义是*自行高举，*如撒迦利亚书 9:16。此处作*真实*的词，并非通常如此译的那一个，但在箴言 22:21 以及亚兰方言中具有相同的意义。参但以理书 2:47，4:34。*因为，*字面作*从……面前，或从……的脸前，*这一说法所指出的、作为上述结果之成因的，乃是神自己的真实或信实。古译本及若干近代译本把末句译作*从弓前逃跑，*这既给动词、也给名词添上了毫无根据的意义。

<span class="ax-anchor" id="psalms-60-5"></span><span class="ax-vnum">7 <span class="ax-veng">(5).</span></span> *为要叫你所爱的人得蒙拯救，求你用你的右手施行拯救，并垂听*（或*应允）我们。*这是一个祷告，乃是由前一节所记载的、先前所经历的神的恩眷自然激发出来的。*你所爱的，*这一称谓在申命记 33:12 用于便雅悯，又构成所罗门另外那个名字*耶底底亚*的一部分，见撒母耳记下 12:25。另参诗篇 45:1。通行译本末了数字作「垂听我」，所依据的是旁注异文，即 Keri（可读之文）。

<span class="ax-anchor" id="psalms-60-6"></span><span class="ax-vnum">8 <span class="ax-veng">(6).</span></span> *神在他的圣洁中说了话；我要夸胜；我要分开示剑，疏割谷我要丈量。*诗人以以色列的名义说话，为其祈求再立一根据，就是诉诸耶和华的应许：他的子民必得迦南全地为业。这里所指的并非某一处孤立的应许，而是贯穿全律法的应许。在那里*神已说了话，*发出他的应许，*在他的圣洁中，即*作为圣洁的神而说，既是圣洁的神，就断不能不成就所说的。参诗篇 89:36 (35)、阿摩司书 4:2 中相似的说法。有人把下文理解为神所说的话；但第 11 (9) 节公认是百姓或其代表的言语，而其间又不易假定有何转换之处，所以似以把这几句同样解作大卫或以色列的话为宜。「神在他的圣洁中说了话（所以）我要夸胜。」因为他已应许我得胜而承受此地，我便满怀确信、预先欢欣。这得地而占有的意思，是用适合当初得地之时的措辞表达的，那时这地被丈量，并分配给各支派。参约书亚记 13:7、18:5。全国东西两大部分，以约但河为界，分别以示剑与疏割标记出来，那正是雅各从流亡归来时支搭帐棚之处，仿佛是要认领这应许之地为自己的产业。参创世记 33:17, 19。

<span class="ax-anchor" id="psalms-60-7"></span><span class="ax-vnum">9 <span class="ax-veng">(7).</span></span> *归我的，*（乃是）*基列，玛拿西也归我，以法莲是我头的力量，犹大是我的立法者。*此处的意思仍是：迦南全地按理都属于以色列。表述的形式与前一节相仿，却有一处优美的变化。前节以两个孤立的地点——示剑与疏割——代表约但河东西两大区域，此处则改用幅员辽阔的区域之名：犹大与以法莲，是河西两块最大的地业；巴珊与基列，是河东的地业，后者直呼其本名，前者则以占据其大部分的那一支派为名。参申命记 3:12, 13。末句对以法莲的军事实力给予应得的尊荣（创世记 48:19，申命记 33:17），却申明犹大在政权上的至尊（创世记 49:10）。译作*我头的力量*的这个短语，看似意为*我主要的力量；*但那样就须把两词的次序颠倒过来，作*我力量之首。*参创世记 49:3。它毋宁是指我头的护卫，正如诗篇 27:1 的*我性命的力量*意即那护卫我性命者；之所以提到头，是因它是格外暴露于危险的要害之处。参诗篇 68:22（21），110:6。有人以为此处的比喻是指头盔，这未免过于拘泥。末句显然暗指创世记 49:10 的预言。*立法者*在此取其本义，即治理者、君王。有人取其杖或权杖之义，那是建立在对民数记 21:18 一处可疑的解释之上。

<span class="ax-anchor" id="psalms-60-8"></span><span class="ax-vnum">10 <span class="ax-veng">(8).</span></span> *摩押*（是）*我的洗脚盆；我要向以东抛我的鞋；非利士啊，向我欢呼吧！* 以色列最常与之交战的三个敌对势力，在此被并列提出，作为轻蔑之辞所指的对象。摩押被比作家中最卑贱的器皿，即奴仆惯用来洗主人之脚的那只盆。以东则被比作奴仆本身，主人将要洗脚时，便把鞋扔给他、或向他扔去。参马太福音 3:11，使徒行传 13:25。这样解释远比某些人所设想的、指路得记 4:7 所载之俗，更合乎上下文；在那里脱鞋是放弃权利的表记，断不能在此用来表达相反的意思，即夺取或得胜占有。*向我欢呼*，或作*发出声响*，有人解为得胜之辞，并将全句视为反语。另有人解为臣民以欢呼喝采承认并拥戴其君王。参上文诗篇 2:11 的注释，那里「*战兢而欢喜*」的劝勉，同是这些解经者以同样的方式加以解释。无论取哪一种解释，此句都含有说话者居于尊位、而受其称呼者甘心或被迫降服之意。

<span class="ax-anchor" id="psalms-60-9"></span><span class="ax-vnum">11 <span class="ax-veng">(9).</span></span> *谁要领我进*（到）*坚固城？谁曾引我上到以东？* 凭着对神应许的倚靠，又怀着方才所表明的盼望与勇气，他的子民已预备好前行，所等候的不过是，可以说，有人带领他们进入仇敌的境内，甚而进入他的堡垒之中。*坚固城，*字面作*防御之城，或设防之城，*此语在诗篇 31:22 (21) 已经用过，所指乃是彼得拉，以东著名的都城，凿石而成，几乎全然无法攻取。参罗宾逊（Robinson）《巴勒斯坦》第二卷 573-580 页。末一分句用过去时，是把这问题表现为已经得着了答复。*上到，*直到，远及，所含的不仅是动向或方向，而是实际的抵达。

<span class="ax-anchor" id="psalms-60-10"></span><span class="ax-vnum">12 <span class="ax-veng">(10).</span></span> （岂）*不是你么，神啊，*（就是那）*丢弃了我们、不与我们的军队同去的？*前一分句若按较简单的结构来解，便是*你岂不是丢弃了我们么*。但把本节看作对上一节所提问题的间接回答，似乎更好。若不是那位弃绝我们的，还有谁领我们进入以东呢？其用语取自诗篇 44:10（9），而那一篇似乎正写于此处作为已过之事提说的患难之中。「岂不是你么——就是我们不久前不得不这样说的那位：你丢弃了我们，不与我们的军队同去？」参撒母耳记下 5:24。

<span class="ax-anchor" id="psalms-60-11"></span><span class="ax-vnum">13 <span class="ax-veng">(11).</span></span> *求赐我们帮助脱离患难*（或作：脱离仇敌）*；并且*（更是因为）*虚空*（乃是）*人的拯救，即*人所施予的搭救。那似乎为连接两个分句所必需的因果小词，即「因」、*「因为」*，在希伯来文中是隐含的，并未明言。第二个名词（צר）既可指*患难，*如诗篇 4:2(1)、18:7(6)，也可指施加患难者，即逼迫或欺压人的仇敌，如诗篇 3:2(1)、13:5(4)、27:2, 12、44:6, 8, 11(5, 7, 10)。两种意思都说得通，但后者因其在下一节中的出现而大有可取。

<span class="ax-anchor" id="psalms-60-12"></span><span class="ax-vnum">14 <span class="ax-veng">(12).</span></span> *在神里面我们必作成（即*取得或聚集）*力量，他必踏下*（或*践踏）我们的敌人*（逼迫者或压迫者）。祷告之后，紧接着便是对蒙应允的确信期待。*在神里面，即*与他联合，得着他。见前面诗篇 18:30(29) 的解说。下一短语的通行译法（必奋勇行事）含糊而可疑，因为在这一短语出现的若干处经文中都讲不通，而「*作成*」或「*聚集力量*」的译法却处处都能成立，所指乃是先前软弱之人获得或恢复力量。参看下文诗篇 108:14(13)、118:15, 16，并比较以西结书 28:4、路得记 4:11、申命记 8:17, 18、民数记 24:18；末一处显然是此处所暗指的，因其所论正是同一批仇敌。*踏下*或*践踏*，作为暴力制伏的象征，已见于同时期的一段经文，诗篇 44:6(5)。末了八节又作为诗篇 108 篇的一部分重现，两处的差异及其总的关系，将在该篇的解说中加以考察。
