<span class="ax-vnum">1.</span> *交与伶长。大卫作。一篇赞美的诗。* 按字面是*一篇诗，一首歌，*但参看前面诗篇 65:1、66:1、67:1 的论述。本篇与第十八篇极其相似，同是一首凯旋之歌，由某次显著的战胜或军事成功所引发，或许就是撒母耳记下 12:26-31 所记的那一次，它结束了大卫在位期间最后一场重大的战争。本篇开首是对神的泛称颂赞，称他为义人的拯救者、恶人的毁灭者，第 2-7 节（1-6）。随后借着以色列历史中若干时期加以申述和印证，首先是旷野中的行进，第 8-11 节（7-10）。接着是士师的时期，第 12-15 节（11-14）。再接着是王权在锡安的建立，以及刚刚取得的胜利对它的坚固，第 16-20 节（15-19）。这一切又被表明为耶和华对待他子民之全盘计划的一部分，第 21-24 节（20-23）。凯旋的行列得了描绘，第 25-28 节（24-27）。然而这一切不过是将来那普世征服的一个样本或预尝，第 29-32 节（28-31）。因着预先望见这一番变局，列国被召来同心颂赞耶和华，第 33-36 节（32-35）。这末段与前两篇相应段落的相似，或可解释本篇何以被置于此处。

<span class="ax-anchor" id="psalms-68-1"></span><span class="ax-vnum">2 <span class="ax-veng">(1).</span></span> *神必兴起，他的仇敌必四散；那恨他的人必从他面前逃跑。*本节提出全诗的主题，乃是历史中不断得着应验的一个事实。此处显然也暗指摩西在约柜——神同在的象征——起行时所说的话。参民数记 10:35。那里所表达的愿望，在此被宣告为已然成就。故命令式（קוּמָה）在此变为将来时（יקום），表明本节并非祈愿之意（愿神兴起），而是断言将来必定如此，正如在促成本诗的那件事上已经如此。现今的时候并未被排除在外，而是包含在这一普遍命题之中：事情必须如此、也必将如此。*必四散*比*被四散*更确切地译出了希伯来动词，虽然其含义无疑是指非出于自愿的、强暴的离散。*从他面前，*即从他的脸前，或从他的同在之前。见上文诗篇 9:4(3)、61:4(3) 之注。

<span class="ax-anchor" id="psalms-68-2"></span><span class="ax-vnum">3 <span class="ax-veng">(2).</span></span> *如烟被吹散，你必吹散*（他们）；*如蜡在火前熔化，恶人必在神面前灭亡。*其措辞形式与前一节相同，即*从火的面前，从神的面前（或说从神的同在）*。前半句中的动词与诗篇 1:4 所用的相同，在那里此处所暗含的「风」被明言为吹散或推送之力。以蜡作比在圣经中颇为常见，上文诗篇 22:15 (14) 已经出现。末句可与底波拉之歌的结语相比（士师记 5:31）；本篇中对那首歌有若干处仿效，至少也是回响。

<!-- PAGE 292 -->
<span class="ax-anchor" id="psalms-68-3"></span><span class="ax-vnum">4 <span class="ax-veng">(3).</span></span> *惟有义人必欢喜；他们必在神面前欢腾，并且喜乐快活。*这不仅就个别的义人而言是真的，就义的列国而言也是如此，尤其是就以色列作为这样的国而言；虽然她的许多成员并不是义的。但这些人并不被看作真正属于教会或选民，反倒被归在神那些恶敌之列。义人要*在神面前*欢喜，正如恶人在*他面前*逃窜。

<span class="ax-anchor" id="psalms-68-4"></span><span class="ax-vnum">5 <span class="ax-veng">(4).</span></span> *向神歌唱，颂扬他的名，修筑*（一条大道）给*那* *驾行过旷野的，凭他的名雅（Jah），并在他面前欢腾。*第二分句暗指为君王和军队开道。见前面诗篇 50:23 的注释，并参以赛亚书 40:3、玛拉基书 3:1。通行译本对这动词的译法（「尊崇」）所传达的意思，与这希伯来词的用法全然无关。*骑行，即*行路，若作军事上的应用，则为*行军。*通行译本对下一个名词的译法（「诸天」）毫无用法上的根据。这希伯来词至今仍为阿拉伯人用以指称以色列人漂流四十年所经之地。此处所提示的意思，在第 8-10（7-9）节中有更充分的发挥。*凭他的名雅，即*以此名所表明的身分而言；此名是*耶和华*的缩略形式，为摩西之歌（出埃及记 15:2）及后来仿效之作所特有。见我在以赛亚书 12:2、38:11 的注释。百姓受召，要为迎接这位荣耀的临访者作好预备。

<span class="ax-anchor" id="psalms-68-5"></span><span class="ax-vnum">6 <span class="ax-veng">(5).</span></span> *孤儿的父亲、寡妇的审判者*（乃是）*神，在他圣洁的居所中。*神所具有的最荣耀的品格之一，便是无辜者与无助者的保护者。*审判者，*即伸冤者、庇护者，是那位为他们主持公义的。此处他*圣洁的居所*不能指天上，而必指他在自己拣选之民中间的特殊居所。正是在那里，他既藉着这律法的条例，也藉着他护理的安排，确立了自己有权承当此处所归给他的这一崇高品格。

<span class="ax-anchor" id="psalms-68-6"></span><span class="ax-vnum">7 <span class="ax-veng">(6).</span></span> *神使孤独的人住在屋中，使被掳的人出来进入欢乐；惟有悖逆的人*（仍）*住在干旱之地*（或*旷野）。*这虽是一个普遍的命题，却似乎特指以色列人境遇的改变，即他们从旷野被领出、得了所应许之地为业的时候。原文中的两个分词（使安居、领出）表示惯常或习惯性的动作。*在屋中，*字面作*在一间房屋里，*更贴近原文则是*向着一间房屋，*其中实含迁移之意。此词亦可译作*归家*或*在家。*本句末一词在别处绝无所见，解释纷歧，或谓其意为*带着锁链、强力地，*或谓*进入欢愉*即欢乐，后一说今为大多数释经者所取。

<span class="ax-anchor" id="psalms-68-7"></span><span class="ax-vnum">8 <span class="ax-veng">(7).</span></span> *神啊，在你出去行在你百姓前面的时候，在你行过旷野的时候。细拉。*这句话要到下一节才说完，此处被一个庄严而惊叹的追忆之停顿所分开。前几节的笼统描述，现在借着提及出埃及和旷野中的行程而得着证实与说明。*行在你百姓前面，*是在云柱中，作他们的引导者与统帅。*你行过，*字面作*你的迈步、踏行，*更确切地说是*你的步伐*或*足迹。*为使这一指涉更为明确，这里译作*旷野*的词并不是通常如此翻译的那一个，而是借自申命记 32:10 的那一个。

<!-- PAGE 293 -->
<span class="ax-anchor" id="psalms-68-8"></span><span class="ax-vnum">9 <span class="ax-veng">(8).</span></span> *地震动，不，诸天滴落，这西乃，在神面前，就是在以色列之神面前。滴落，*即降下水滴、降雨。这是雷暴天气自然而常见的伴随现象。*这西乃*大概是说，*这*（事发生在）*西乃，*应当作插入语来读。通常的解法不但需要重复或补出一个动词，而且所得之义晦涩可疑，因为说不出为什么西乃要被称作*这西乃，*而译作*西乃自己也*则于用法无据。上半节描述的是西乃显现时伴随的那些宏大而可畏的现象。参出埃及记 19:16-18。

<span class="ax-anchor" id="psalms-68-9"></span><span class="ax-vnum">10 <span class="ax-veng">(9).</span></span> *你降下恩赐之雨，神啊；你的产业，并*（那）*困乏的，你使之坚固*（或*使之刚强）它。*第一个分句大概是指赐给旷野中百姓的那些丰盛而使人苏醒的恩赐（雨是这类恩赐天然而常见的象征），其中包括吗哪、鹌鹑和水。此处的将来时与诗篇 18:7(6) 中的用法相同。*降下，*字面是*摇动*或摇落。*你的产业，*即你的子民。其结构为独立主格，（至于）*你的产业*。下一分句更进一层，指出这恩赐正是在最需要的时候临到的。

<span class="ax-anchor" id="psalms-68-10"></span><span class="ax-vnum">11 <span class="ax-veng">(10).</span></span> *你的群羊曾住在其中；你必在你的恩惠中，为困苦的预备。*第一个名词严格说来指一只动物，尤指牲畜，但大概是用作集合名词，表示一群牲畜或一群羊；在大卫的时代，这个意思又被转喻地用于一队或一群人（撒母耳记下 23:11, 13）。*在其中，即*在应许之地，这地虽未在上下文中明言，却是作者心中所存的。参看下文第 15（14）节，并比较以赛亚书 8:21。*你必预备，*是不确指的，凡所需用的都包括在内；或更具体地说，*必预备，即*预备一个家、一处安歇之所。将来时把这描述为神行事的惯常方式，而在以色列身上尤其得着印证——因为以色列在安居迦南以先，正可称为受苦者，一个困苦或受欺压的人。

<span class="ax-anchor" id="psalms-68-11"></span><span class="ax-vnum">12 <span class="ax-veng">(11).</span></span> *主必赐下话语；那* (些女子) *传报* (它) *的，是一大群。* 关于将来时，见前文第 10, 11 (9, 10) 节的注释。此处的*话语*意即消息、信息，而如整个上下文所显明的，是好消息，这也由译作*传报*的那个词所暗示，因该词在用法上一贯用于喜讯。见前文，诗篇 40:10 (9) 的注释。这里显然是指古代东方妇女以歌舞庆贺胜利的风俗。见出埃及记 15:20，撒母耳记上 18:6, 7。所指的并非某一次特定的场合，而是一个理想中的歌队，歌颂某一伟大时期——或许是士师时期——的一切胜利。

<span class="ax-anchor" id="psalms-68-12"></span><span class="ax-vnum">13 <span class="ax-veng">(12).</span></span> *统帅军队的王必逃跑，必逃跑，那留在家中的妇女必分掳物。* 此处所描述的逃跑，不单是君王的逃跑，而是率领军队的君王的逃跑。动词的重复表明溃败之确实与彻底。*住在家中的*，有人按字面理解，指不参与争战的妇女。但另有人视之为一种比喻，指蒙拣选的子民，在仇敌消灭之后安然居家，那时「国中太平」（士师记 5:31，8:28）。

<span class="ax-anchor" id="psalms-68-13"></span><span class="ax-vnum">14 <span class="ax-veng">(13).</span></span> *当你们躺卧在界限之间，*（你们必如）*鸽子的翅膀镀银，她的翎毛镀黄金。*总的意思似乎是说，当「地上太平」之时，她的景况便是一种安然的昌盛。第一分句的通行译法（你们虽躺卧在羊圈之中）既无拉比传统的支持，也无古译本的根据。这个希伯来名词仅见于此处与以西结书 40:43，而在那里同样晦涩难明；创世记 49:14、士师记 5:16 中的同源形式也几乎一样费解。除已提到的那些意义之外，唯一略有可能的，是*羊栏*或*羊圈*之义；躺卧其间或可视为乡村牧歌式安息的诗意比喻，如此便与第一种译法归于一致——那译法所描绘的，是百姓安然居住*在疆界之间，即*在自己领土的边境之内，如今敌人已再度从那里退去。末一分句中以鸽羽变幻之色作比，优美之极，似意在暗示一种既安宁又辉煌的昌盛。

<span class="ax-anchor" id="psalms-68-14"></span><span class="ax-vnum">15 <span class="ax-veng">(14).</span></span> *当全能者在其中分散列王时，就在撒们降雪了。* 由战争转为和平，被比作黑暗或幽暗之中白雪的耀目洁白。后一层意思由*撒们*表达出来——那是示剑附近一座并不重要的高地——这一方面或许是指覆盖其上的幽暗森林（士师记 9:48），但主要还是取这名字本身的含义，即*荫*或*影*。与之平行的词*雪*，则引出至明之光的意象。参见诗篇 51:9 (7)、以赛亚书 1:18、马可福音 9:3、马太福音 28:3、启示录 1:14，并参马太福音 17:2。有些人把本节解作：遍地因被杀者而发白，正如撒们因雪而发白；但这远不及前说可取，因为这样便把撒们的高度估得太高了。希伯来文在前一分句中的结构是：*在全能者分散列王之际，即*他如此行的时候。此处所用的神名，并非诗篇中常译作*大能者*的那一个，而是出埃及记 6:3 所提到的那个列祖时代的称号。参创世记 17:1、28:3。此处用它，是因为所论及的事件乃是神全能的非凡施展与彰显。*分散*在此意为击溃、使之逃散。见上文第 13 (12) 节，并参同一希伯来文动词在撒迦利亚书 2:10 (6) 中的用法。

<span class="ax-anchor" id="psalms-68-15"></span><span class="ax-vnum">16 <span class="ax-veng">(15).</span></span> *神的山*（是）*巴珊山，多峰*（或*山脊）的山是巴珊山。*第一个短语的意思是：这山以其宏大显明神的创造大能。参看上文诗篇 36:7（6）。*巴珊山，*并非一座孤立的高峰，而是安提利巴嫩的高大山脉，也称为*黑门，*别族则称之为*西云*与*西连。*见申命记 3:9，4:48，诗篇 42:7（6），诗篇 89:13（12）。后两个名称因偶然的形似，容易使人联想到锡安圣山之名。多峰或多脊之山，*即*并非一座独立的山，而是一条拥有许多崇高顶峰的山脉，构成巴珊的北界。同时，本节的措辞也必然令人想到强大的邦国或王国，山岭素来是它们的象征。参看上文诗篇 46:3（2），65:7（6）。

<span class="ax-anchor" id="psalms-68-16"></span><span class="ax-vnum">17 <span class="ax-veng">(16).</span></span> *你们为何窥伺，*（你们）*众山哪，*（你们）*峰脊哪，就是神所切慕作他居所的那山？是的，耶和华必住在其中* （它）*直到永远。*疑问的语气含有不悦与轻蔑之意。参看上文，诗篇 2:1。这动词在旧约别处不再出现，但其意义在阿拉伯文中得以保存，即如仇敌般窥伺、埋伏守候，或如有些人所主张的，以嫉妒的眼光注视。二者所共有的乃是敌意或恶意的观念。英文圣经把这动词译作 *leap*（跳跃），《公祷书》译本译作 *hop*（蹦跳），似乎都不过是出于臆测。有人认为*众山*与*峰脊*这两个名词构成一种复合词，*峰脊之山，即*高耸或崎岖的山。可比较*酒－踉跄*这一说法，诗篇 60:5（3）。复数形式或指诸峰，或指这一山脉所代表的整类山岭。锡安在此被描写为外邦世界的群山所敌视、所嫉妒的对象，因为神拣选它作自己在地上的居所，使它得了这样的尊荣。诗人先以诗的笔法说他*切慕*它，*即*偏爱并拣选了它；为免人对这事的成就有所疑惑，又加上一句：不但如此，他现今确实住在那里，并要永远住在那里。第二、第三分句的动词虽然同义，在希伯来文中却并非同一个字。此处所用的神的名称，其取舍显然有深意。他不单作为 Elohim（以罗欣，神）拣选了它为自己的居所，更是作为耶和华——启示的神、以色列立约的神——实在地住在那里。

<span class="ax-anchor" id="psalms-68-17"></span><span class="ax-vnum">18 <span class="ax-veng">(17).</span></span> *神的车辇*（有）*二万，千千复千；主在其中，西奈在圣所。* 大卫最可畏的仇敌以战车为其特强之处（撒母耳记下 8:4，10:18），故此处神护卫的大能便以不可胜数的车辇来表达。同样的表述方式见于以利沙的记载，列王纪下 6:17。译作*二万*比译作*两万*更贴近原文，因为这希伯来词是另一词的双数形式，而那词既可泛指众多，也可确指一万之数。参看前面诗篇 3:7（6）的注释，那里出现的是同一词的复数。下一短语严格说来意为*重复*或*叠加的千数，即*千上加千。参但以理书 7:10。经文中并未提及*天使*，虽然历代释经者都设想必然隐含其在场，若非以天使为车辇本身，便是以其为神车辇的驾驭者；两种英文译本正是如此理解这希伯来短语的（*甚至千千的天使*）。此处显然也暗指申命记 33:2, 3 所述西奈山上颁布律法之事，新约似乎认定当时有天使在场，见加拉太书 3:19、希伯来书 2:2。然而，使圣所得保安全的，并非单单这些天军的数目，乃是主（Adhonai）亲身临在他们中间，故下一分句即如此申明。本节末了的词语晦涩难明，但最可能的意思是：昔日在西奈山上显现的那同一荣耀的神显，如今在锡安重新上演；有人以为这尤其是指约柜与石版在此的同在，它们乃是那一场立法之事的永久纪念，甚至是其永久的重演。这种把两座因神同在而成圣的山美妙地诗意合一的手法，或许正萦绕在使徒心中，使他写下那两山之间崇高的对比或并举，希伯来书 12:18-24。在律法之下，西奈在锡安中得以重现；在福音之下，锡安取代了西奈。

<span class="ax-anchor" id="psalms-68-18"></span><span class="ax-vnum">19 <span class="ax-veng">(18).</span></span> *你已升上高处；你已掳掠了所掳的；你已在人类中取了礼物，就是*（甚至在）*悖逆者中，*（为要）*住在*（这里）。*主，神啊！* 为要成就他在上文第 17（16）节所记的拣选与定意，*即*为要立锡安为他在地上的居所，神迎击了一切敌对的权势，制伏了它们，迫使它们纳贡，连最强悍、最顽梗的也不例外。征战告成的记号，就是得胜者回到自己的宝座，无论那宝座在地上还是在天上。参看上文诗篇 7:8（7）的注释，并比较诗篇 18:17（16）、93:4、102:20（19）。*掳掠了所掳的，即*掳获了大批仇敌为俘。所说的*礼物*，是被征服者被迫献上的贡物。*在人类中，即*当他以征服者的身分临在他们中间之时，并由此含有「从他们而取」之意。*就是悖逆者，*连最悖逆的也被迫降服。换言之，这征服是彻底的。按此处所用的军事意象看来，似乎隐含着：征服者如此索取而来的礼物，要分给跟随他的人。一面*收取礼物*，一面*颁赐礼物*，本是相互关联的观念与说法，所以保罗把这幅神权国度凯旋的图画应用于我们救主的得胜时，便以其中一种说法替换了另一种（以弗所书 4:9）。他在解释这段经文时，也正当地指出：那里所描写的升上，必然含有先前的降下。换言之，得胜以争战为前提。末一分句显然回指第 17（16）节相应的分句。*主神，*按字面是*雅，神啊！*参看上文第 5（4）节的注释。

<span class="ax-anchor" id="psalms-68-19"></span><span class="ax-vnum">20 <span class="ax-veng">(19).</span></span> *主是应当称颂的，日复*（又）*一日；*（凡）*将重担加于我们者，那大能*（的神即是）*我们的拯救。细拉。*第二分句因过于简短而晦涩，亦可如此翻译：（人）尽可将重担加于我们，（但）神是我们的拯救。*将重担加于我们，*字面作*负载于我们，*或*如同加于我们。*按这两种结构，加载都指压迫。不过，也可以赋予它英文诸译本所给的恩惠或恩典之义，但整个分句的结构便大不相同：*那大能*（的神）*必将我们的拯救堆积在我们身上，*或作*必以拯救充载我们。*这一盼望所凭依的情感之深与信心之力，由随后那沉思的停顿标示出来，或说不自觉地流露出来。

<span class="ax-anchor" id="psalms-68-20"></span><span class="ax-vnum">21 <span class="ax-veng">(20).</span></span> *神为我们是拯救的神，属乎耶和华主的*（有）*脱离死亡的出路。*本节更确切的译法，若保留其特有的惯用语，当作：*全能者*（是）*为我们的全能者，以施拯救；属乎耶和华主的*（有）*，就死亡而言，诸般出路*或*逃脱。*这不过是前一节末句的铺陈，*神是我们的拯救，*或照另一种解法，*神以拯救充满我们。*

<span class="ax-anchor" id="psalms-68-21"></span><span class="ax-vnum">22 <span class="ax-veng">(21).</span></span> *诚然神必打碎他仇敌的头，就是那在自己过犯中继续行走的多毛头顶。* 首词本义是*惟独，*此处用以表明情形如此而非相反，这一用意在我们的语文中可借一个强力断言的虚词来表达，如*的确*或*诚然。*参看上文第 7（6）节，并比较诗篇 39:12（11）、58:12（11）。*打碎头，*是形容暴烈而彻底的毁灭的有力比喻。参看下文第 24（23）节的解说，并比较创世记 3:15、诗篇 110:6、民数记 24:8, 17。*多毛的头顶，*或作*有发的头顶，*不过是*头*的诗意对应语或平行语。随后的话似乎藉着某种拟人手法加在它身上。比较箴言 16:31。但这一比喻若嫌过于大胆，也可在*行走*之前补出*那人的*或*那个人的*，以避开它。末一词未必意为*继续行走，*按其在别处的用法，可译作*四处行走，即*习惯性地以犯罪的方式行事。参看上文诗篇 12:9（8）、20:7（6）、26:3、35:14、39:7（6）、43:2（1）的解说。

<span class="ax-anchor" id="psalms-68-22"></span><span class="ax-vnum">23 <span class="ax-veng">(22).</span></span> *主说，我要从巴珊领* (他们) *回来，我要从海的深处领* (他们) *回来。* 有人认为本节两个动词的宾语是*以色列*或*我的子民，*如以赛亚书 49:12（参创世记 14:14）。但既然下文各节的主语仍是仇敌，不如把本节理解为威胁要把他们带回来受刑罚与毁灭——就在他们看似已凯旋撤去之时。此处与第 15（14）节一样，提到*巴珊*是作为圣地的边境之地。末句显然有递进之势：我要领他们回来，不单是从巴珊，若有必要，便从大洋的底处领回来。参诗篇 139:9，尤其是阿摩司书 9:2, 3。

<span class="ax-anchor" id="psalms-68-23"></span><span class="ax-vnum">24 <span class="ax-veng">(23).</span></span> *为要使你践踏*（他们）——*你的脚在血中*——（并）*你狗的舌头*（在血中）*从仇敌，*（就是）*从他。* 本节的大意是清楚的，但其构造则可疑而晦暗。第一个动词不能解作*蘸*或*洗*，除非擅改经文，读作 תרחץ，如诗篇 58:11(10) 那样。原文的动词（תמחץ）必与第 22(21) 节同义，并且可以有同一宾语，即神与他百姓的仇敌。接下来的几个词便可视为一个插入的限定小句，正如英文中*剑在手*一类的说法。*你的脚在血中，即*你的脚踏在他们的血中，或者说，使你的脚踏在他们的血中。希伯来文的末一个词（מנהו）被有些人理解为带词尾的名词，意为*它的分，即*舌头所得的那一份；但这在用法上毫无依据。另有些人将此语译作*从它，即*从那血，而将整个小句译作*你狗的舌头*（必要）*从仇敌得着其中的一分。*按上面所给的第一种译文，末一短语只是对前一短语的具体指明；*从仇敌，*（就是）*从他，*乃是指那整类人中某一个真实的或理想的代表。

<span class="ax-anchor" id="psalms-68-24"></span><span class="ax-vnum">25 <span class="ax-veng">(24).</span></span> *神啊，他们看见你的行进，我的神、我的王在圣所中的行进。* 第一个动词的主语，或指一般的人，或指旁观者，即未参与此处所描写的凯旋行列的人。*圣所，* 不是取其狭义，而是取希腊文 *ἱερόν*（圣域）的意义，指整个神圣的围院，有别于 *ναός,*（圣殿）即那座神圣的建筑。这行列似乎被描写为正进入此围院之中，为要把约柜迎回。

<span class="ax-anchor" id="psalms-68-25"></span><span class="ax-vnum">26 <span class="ax-veng">(25).</span></span> *歌唱的在前，奏乐的在后，在击鼓的童女中间，*即击打手鼓，这至今仍是东方的风俗。有人认为首句所述的次序表示声乐优先于器乐，因其是理性的、合乎情理的事奉。英文译本将末句作 *在*（她们中间有）*童女，*乃是多此一举地补出两个词，反倒把真意颠倒了，且这种结构为马所拉的点所不容。真正的意思是：歌唱的与奏乐的本身被这些击鼓的人围绕在中间。

<span class="ax-anchor" id="psalms-68-26"></span><span class="ax-vnum">27 <span class="ax-veng">(26).</span></span> *在大会中你们要称颂神，主，你们是从以色列的泉源而出的。*不仅是各人单独地称颂，也不仅是在凯旋的行列中称颂，乃是在百姓于圣所定期的聚集中称颂。参看前面诗篇 26:12 的注释，除作专名用者外（民数记 33:25），那是这希伯来词惟一另见之处，而在那里它显然也是同一意思。末了几个字*从以色列的泉源，*惟一令人满意的解释，是在其前补上*你们这些出于*，而将全句用作对蒙拣选之民的描述，取水流自泉源流出的比喻。参以赛亚书 48:1, 51:1 中相似的意思与说法。

<span class="ax-anchor" id="psalms-68-27"></span><span class="ax-vnum">28 <span class="ax-veng">(27).</span></span> *有小便雅悯，治服他们；犹大的首领，用石头击打他们；西布伦的首领；拿弗他利的首领。* 这几个支派是被举出来代表所有被认为在*那里，即*在凯旋行列中的支派。它们之所以被选出，一方面是就其地域居处而言，作为以色列南北两端的代表；另一方面是因为从摩西的时代直到大卫的时代，最卓著的功绩都是由这几个支派成就的。参士师记 5:18、撒母耳记上 18:7。*小便雅悯，*如此称呼乃是暗指雅各对他幼子的偏爱。见创世记 43:33，并参撒母耳记上 9:21。*他们的征服者，*或作*治服他们，*正如扫罗治服四围的列国一样。见撒母耳记上 14:47, 48。*用石头击打他们，*字面作*他们的用石头击打，*所出之动词一概只作*用石头打*解。这或许是暗指他们善用投石的技艺，或更确切地说，是暗指大卫击杀歌利亚所用的手段（撒母耳记上 17:49, 50）。这词尾所指的是仇敌，与前一分句相同。有些释经者曾指出一个值得留意的巧合：我们的主和他几位使徒出自犹大，保罗出自便雅悯（腓立比书 3:5），其余的使徒则出自加利利，而西布伦与拿弗他利的地界正在其中（马太福音 4:13）。

<span class="ax-anchor" id="psalms-68-28"></span><span class="ax-vnum">29 <span class="ax-veng">(28).</span></span> *你的神*（哦以色列）*已命定你的力量；求你刚强，神啊，你曾为我们成就*（这事）*。* 命定，意即藉他的全能所预备并保固的。*求你刚强，即*显出你的力量，为我们施展出来，日后也如你从前所行的一样。*为我们成就，*是不确指而泛言的，或作*成就（它，为我们，即*我们一直在歌颂的这拯救。参看上文诗篇 22:32（31）的注释，并比较以赛亚书 26:12。

<span class="ax-anchor" id="psalms-68-29"></span><span class="ax-vnum">30 <span class="ax-veng">(29).</span></span> *因你在耶路撒冷之上的殿，列王必将贡物带来给你。*第一个词本义是*从；*但此处地点的意思不能成立，故*从*可按*由……而生、由……而出*这类短语来理解，其中所含的是结果或后果的观念。译作*殿*的那个词原意为*宫殿，*故既可指摩西所立的圣所，也可指继之而起的所罗门的殿。参看前面诗篇 5:8（7）、48:10（9）、65:5（4）的注释。*在耶路撒冷之上，*兼有物质与道德两层意思，因锡安与摩利亚高悬于全城之上，而圣所的同在既是城的保障，又是城至高的荣耀。希伯来文中的末一词仅见于此处，以及以此为本的几处经文。见下面诗篇 76:12（11），并参以赛亚书 18:7。

<span class="ax-anchor" id="psalms-68-30"></span><span class="ax-vnum">31 <span class="ax-veng">(30).</span></span> *斥责你那芦苇中的野兽，那强壮*（公牛）*之群，连同列国的牛犊，俯伏献上银块；他已驱散列国*（那）*喜爱争战者。*他所确信期待的事，在前一分句中成了祈求，在末一分句中则描述为已然成就，二者都是间接预言的常见方式。译作*野兽*的那个词，就是上文第 11（10）节译作「群」的同一个词；但此处两种意思似乎都被提示出来，正如中文用复数时也可兼含二义。*芦苇中的野兽*被人作过各样解释：或指狮子（耶利米书 49:19，50:44，撒迦利亚书 11:3），或指鳄鱼（以西结书 29:3，32:2），或指河马——其希伯来名在形式上是复数（Behemoth），因而与此处所用的集合名词相类。此兽在别处也被描写为卧在*芦苇的隐密处*（约伯记 40:21）。鳄鱼也好，河马也好，都必然令人想到埃及；此处提及埃及，是因它为异教诸国中最强大者，故可作异教世界的合宜象征。形容词*强壮*是对*野公牛*的诗意描写，如诗篇 22:13（12）。这些或代表列国的首领，而*牛犊*则代表他们的臣民。分词*俯伏*在希伯来文中是单数，*自己俯伏下来*，众多者忽然化为一个理想中的个人。参上文诗篇 10:10 的注释。*献上银块，*即银币，作为贡物献给征服他们的人。参上文第 19（18）节的注释，并比较以赛亚书 60:9。在本节末了，他看见以色列那些好战的仇敌已被神的手驱散了。

<span class="ax-anchor" id="psalms-68-31"></span><span class="ax-vnum">32 <span class="ax-veng">(31).</span></span> *诸侯必从埃及出来；古实必急速向神伸出她的手。* 埃及再次被举出作为外邦世界的代表，但此处与邻邦古实即埃塞俄比亚并列，后者常被众先知提及，视为强盛而华美的帝国。参以赛亚书 18:7，45:14，西番雅书 3:10。译作*诸侯*的那个词本义是*肥壮者*，别处用以指兴旺有势力的人。参上文诗篇 22:30（29）的注释。一般认为，*哈斯摩尼（Hasmonean）这名即由此词派生而来，此名乃是*在旧约与新约之间的那段时期赐给马加比家族、即犹太诸侯的。*急速伸出*并非对原文措辞的直译，而是意译；原文严格说来意为*使她的手奔跑*，或许指行此动作时的那种急切。

<span class="ax-anchor" id="psalms-68-32"></span><span class="ax-vnum">33 <span class="ax-veng">(32).</span></span> *地上的列国啊，向神歌唱；赞美（或歌颂）主！细拉。* 鉴于此处所预见的征服，全世界都被召来承认以色列的神为普世的君王。参启示录 11:15。

<span class="ax-anchor" id="psalms-68-33"></span><span class="ax-vnum">34 <span class="ax-veng">(33).</span></span> （当歌颂）*那*（位）*乘驾在亘古诸天之天上者；看哪，他发出他的声音，大能的声音。* 本节意在尊崇所当称颂的那一位。*乘驾，* 如得胜的征服者凯旋而行。参看上文第 5（4）节。*诸天之天* 即至高的诸天，是我们所谓之天的那天之天。见列王纪上 8:27，并比较申命记 10:14，33:26。*亘古* 并不像英文中看似那样修饰 *乘驾，* 而是修饰紧接其前的名词，即 *远古的诸天* 或 *亘古的诸天。* 参看上文诗篇 55:20（19）。在末句中，他似乎听见从天上自身发出的可闻回应。那 *看哪，* 一如惯例，含有某事物骤然触及感官之意。*发出他的声音，* 字面作 *发出*（声响）*以他的声音，* 如诗篇 66:7（6）。

<span class="ax-anchor" id="psalms-68-34"></span><span class="ax-vnum">35 <span class="ax-veng">(34).</span></span> *将能力归给神！在以色列之上*（是）*他的威荣，他的能力在云中。*在这类语境中，所谓*归给*，自然就是归于、称述之意。参看前面诗篇 29:1, 2 的注解。本节其余部分给出这一吩咐的理由。神配得能力的颂赞，因为他的伟大显明在他向以色列所施的保护之中。正如圣所高踞于耶路撒冷之上，神也高踞于蒙拣选之民之上，作他们的元首与保护者。参看前面第 30（29）节的注解。同时，他的能力遍显于全宇宙，尤其显于那些非常的作为之中，在其中他仿佛从天上或从云中说话。参看前面诗篇 26:6（5）的注解。

<span class="ax-anchor" id="psalms-68-35"></span><span class="ax-vnum">36 <span class="ax-veng">(35).</span></span> *可畏的*（你是）*，神啊，从你的圣所而出；那大能的*（神）*，以色列的*——*他是*（一位神）*把力量和权能赐给百姓的。当称颂的*（是）*神！* 这结尾与诗篇 29 篇的收束相似。*从你的众圣所，*即从那里显明出来，显在所赐给你百姓的福分之中。他不仅自己大有能力，更是把能力赐予他人的那一位。参 以赛亚书 40:29, 31。
