<span class="ax-vnum">1.</span> *交与伶长。大卫的诗。* 这题注的可靠，由本篇与大卫其余诗篇之间显著的内在相似充分证实。其结构本身就是大卫式的，呈现出两个熟悉的要素：求脱离恶人仇敌的祈祷，第 2-6 节（1-5 节），以及确信必蒙应允的期待，第 7-11 节（6-10 节）。

<span class="ax-anchor" id="psalms-64-1"></span><span class="ax-vnum">2 <span class="ax-veng">(1).</span></span> *神啊，求你听我在哀诉中的声音；因惧怕仇敌，你必保全我的性命。*此处与诗篇 54:3 (1) 一样，信靠的表白悄然渗入祈求之中。*哀诉，*字面意为沉思、默想，但特指在苦难与危险中的沉吟。见前文诗篇 55:3 (2) 的注释。*惧怕仇敌，*即我有理由从他那里惧怕的事。

<span class="ax-anchor" id="psalms-64-2"></span><span class="ax-vnum">3 <span class="ax-veng">(2).</span></span> *你必把我藏起，脱离作恶者的密议，脱离作孽之人的喧嚷。*此处的*密议*当理解为他们私下的商议，以及在其中酝酿成熟的诡计。参看上文诗篇 25:14 的解释。分词*作恶，*用作名词（作恶者）以指称恶人的全类，是大卫所喜用的说法。参看上文诗篇 22:17 (16)，26:5，27:2，37:1, 9。正如*隐秘*属于阴谋的策划，*喧闹*或*喧嚷*则属于阴谋的施行。同样的两个比喻也并列于诗篇 55:15 (14)，只是用法大不相同。

<!-- PAGE 282 -->
<span class="ax-anchor" id="psalms-64-3"></span><span class="ax-vnum">4 <span class="ax-veng">(3).</span></span> *他们磨利舌头，如同刀剑，他们张开他们的箭，就是苦毒的言语。* 前一分句的比喻是大卫所喜用的。参看前面诗篇 52:4 (2)、57:5 (4)、59:8 (7) 的解释。*张开他们的箭，*字面是 *踏*（即 *弯）它，*这要么须解作省略——弯他们的（弓以射他们的）箭——要么解作诗体上的移用，把严格说来只适用于弓的动作转加于箭。参看前面诗篇 58:8 (7) 的解释。箭的比喻极适于形容侮辱与毁谤所造成的锥心之痛，而 *苦毒* 这一形容词也把这痛楚表达得很好。参申命记 32:24，撒母耳记上 15:32。

<span class="ax-anchor" id="psalms-64-4"></span><span class="ax-vnum">5 <span class="ax-veng">(4).</span></span> *在隐密处射*（向）*完全人；他们必忽然射他，并不惧怕。*前一分句可比较诗篇 10:8、11:2。*完全人，*即诚实正直事奉神的人，其品格中并无致命而根本的缺陷。参看前面诗篇 15:2，18:24（23），7:9（8），25:21，26:1、11，37:37 的解释，末一处的希伯来文形容词与此处的形式相同。*并不惧怕，即*不因惧怕神或惧怕人而有所退缩。参看前面诗篇 55:20（19）的解释。

<span class="ax-anchor" id="psalms-64-5"></span><span class="ax-vnum">6 <span class="ax-veng">(5).</span></span> *他们为自己坚立恶言；他们述说暗设网罗之事；他们说，谁能看见他们呢？* *坚立*即是使之坚固，构造得牢靠。*恶言*是一个惯用语，指阴毒的谋算，之所以如此称呼，是因为它乃是彼此商议交谈的果子。参看上文诗篇 41:9(8) 的注释。*述说，*即数算并复述他们各样的诡计，无论已往的还是当前的。参看上文诗篇 59:13(12) 的注释。末句的发问是间接的；与之相当的直接形式应为：*谁能看见我们呢，即*顾念我们呢？参诗篇 10:11；59:8(7)。

<span class="ax-anchor" id="psalms-64-6"></span><span class="ax-vnum">7 <span class="ax-veng">(6).</span></span> *他们搜寻罪孽；*（他们说）*我们预备好了*——*一个精研而成的计谋！人*（人人）*的内里与心思*（都）*深沉。*他们绞尽心思、翻遍记忆，只为寻出作恶的门路。*我们预备好了，字面作已完毕，*正如我们在英文里会说，*we are done*（我们弄完了）。下一短语由一个被动分词与一个同源名词构成，该分词是从句首的动词派生而来。此处的分词相当于 *exquisite（精妙的）、recherché（精心搜求而得的）,* 意指非经苦心搜求不可得之物，而那名词所描述的，正是这番搜求所得的成果。末句的添加是为了加重危险之感，表明这诡计并非出于浅薄表面的盘算，乃是出于深沉的筹谋。*内里，*字面作*里面，*与*心*同义，是大卫常用的说法。参看前面诗篇 5:10 (9)、49:12 (11)、55:16 (15)、62:5 (4) 的注释。

<span class="ax-anchor" id="psalms-64-7"></span><span class="ax-vnum">8 <span class="ax-veng">(7).</span></span> *但神已射了他们*——*用箭*——*忽然地*——*伤口是他们自己的。* 他以一个突兀却优美的转折，描写局势已在仇敌身上彻底倒转过来。这一对照之所以格外鲜明，是因为重复了第 4, 5（3, 4）节所用的动词、名词与副词。正当他们要忽然向义人射箭之时，神却忽然向他们射箭。他们本想加于别人身上的伤口，如今成了（הָיוּ）他们自己的。他们想击打别人，自己反被击打。总的意思与诗篇 7:12-17（11-16）、53:6（5）、57:7（6）相同。开首的转折连词是用来代替希伯来文那简单的连接词的，为使这一转折或对照在英文中更为显明。参看上文诗篇 52:10（8）、55:14（13）的注释。

<span class="ax-anchor" id="psalms-64-8"></span><span class="ax-vnum">9 <span class="ax-veng">(8).</span></span> *而他使他们倾倒；他们自己的舌头*（临）*到他们身上；凡看见他们的都必逃走。倾倒，*字面意思是使之跌倒或绊跌。参同一动词在史传散文中的用法，历代志下 25:8，并比较历代志下 27:23 的原文。此处的结构是不定的，如诗篇 63:11（10），*他们使他倾倒，即*他被倾倒，所指的是作为一个理想人格的仇敌；按这几篇诗的惯例，紧接着就以复数形式提及他。*他们的舌头，即*他们虚谎恶毒的言语与他们狠毒的谋算所带来的后果。末句中的动词，是诗篇 31:12（11）、55:8（7）所用那个动词的加强形式。*注视他们，*不只是看见他们，乃是带着情绪地看，或是惊奇，或是欢喜，或是惧怕。参上文诗篇 54:9（7）、59:11（10）的注释。这一句似乎暗指地开口吞灭可拉一党时众民的奔逃，民数记 16:34。

<span class="ax-anchor" id="psalms-64-9"></span><span class="ax-vnum">10 <span class="ax-veng">(9).</span></span> *众人都惧怕，并宣称*（这）*是神的作为，他的工作他们也明白。*带转换连接的将来时表明本句依赖于前文，所描写的动作并非实际已成的过去，而是紧随前面上下文所述那场大灾祸而来的后果。*并宣告神的作为，即*宣称这事乃是神所行的。参出埃及记 8:19。*他的工作他们明白，即*不再愚昧地把它归于偶然或人的作为。

<span class="ax-anchor" id="psalms-64-10"></span><span class="ax-vnum">11 <span class="ax-veng">(10).</span></span> *义人必因耶和华欢喜，并要投靠他*；*并且*（在他里面）*夸耀*（或*夸胜）的，是一切心里正直的人。* 他既已描述了神的插手干预对恶人、以及对世人所产生的效果，如今便指明这事将如何影响义人。*在耶和华里*，一如惯例，意即与他联合、以他为自己的产业。译作*投靠*的那个词，似乎原本是指人躲到一个遮覆之物底下寻求蔽庇的举动。参看前面诗篇 63:8 (7) 的注释。末句可比较诗篇 58:11 (10)、63:12 (11)。
