<span class="ax-vnum">1.</span> *交与伶长。交与*（或*由）可拉的子孙。一篇诗。*教会以先前的恩惠为凭据，祈求脱离眼前的祸患，第 2-8 节（1-7），并欢然预期必蒙应允，第 9-14 节（8-13）。无论题注还是诗篇本身，都没有什么可以断定其写作年代，或把它的应用限于某一特定的历史事件。它似乎适用于应许（利未记 26:3-13）的成就被暂止或被收回的每一种情形。

<span class="ax-anchor" id="psalms-85-1"></span><span class="ax-vnum">2 <span class="ax-veng">(1).</span></span> *你曾向你的地施恩，耶和华啊；你使雅各的被掳归回*（归于）*雅各的被掳。*有些释经者把这些话理解为新近所经历的恩惠：*你*（如今）*已施恩，*……。但从第 5-8（4-7）节可以清楚看出，百姓实际上正在受苦，因此第 2-4（1-3）节中的称谢必定是指着神从前怜悯的事例说的。有人以为此处所称谢的恩惠乃是从巴比伦被掳之地得释放，这一看法出于对末句的误解；其真正的意思参见前文诗篇 14:7 的注解。「被掳」是表示苦难的常见比喻，而神眷顾被掳之人则表示从苦难中得解脱。还有一点值得留意：所显的恩惠是向着那*地，即*向着仍然据有并实际居住其上的百姓而施的。

<span class="ax-anchor" id="psalms-85-2"></span><span class="ax-vnum">3 <span class="ax-veng">(2).</span></span> *你除掉了你百姓的罪孽；你遮盖了他们一切的罪。细拉。* 同样的说法已见于上文诗篇 32:1, 5。两个动词都不仅含赦免之意，也带有赎罪的意思。

<!-- PAGE 367 -->
<span class="ax-anchor" id="psalms-85-3"></span><span class="ax-vnum">4 <span class="ax-veng">(3).</span></span> *你收回了你一切的忿怒；你从你怒气的烈焰中转回。*此处大概暗指摩西在出埃及记 32:12 的祈求。第二分句中的希伯来文动词，严格对应于英文动词的及物或使役用法。然而以西结也以同样的方式使用它（以西结书 18:30, 32），而他在另一处（14:6）用的是*转脸离开*这一说法，前者或许正是其省略形式。

<span class="ax-anchor" id="psalms-85-4"></span><span class="ax-vnum">5 <span class="ax-veng">(4).</span></span> *求你转向我们，拯救我们的神啊，止息你向我们所发的恼怒。* 此处在追念昔日的怜悯之后，接着便祈求这怜悯再临。「你从前怎样怜恤你的百姓，如今也求你照样怜恤他们。」*求你转向我们，*就是求你再以怜悯眷顾我们。参看上文第 2 (1) 节，以及诗篇 14:7 的注释。末一分句中的动词意为废去、取消、了结、使之止息。此词见于上文诗篇 33:10。译作 *恼怒* 的那个词，本义是表达悲痛与愤慨相杂的一种情感。参看上文诗篇 6:7 (6) 的注释。

<span class="ax-anchor" id="psalms-85-5"></span><span class="ax-vnum">6 <span class="ax-veng">(5).</span></span> *你要永远向我们发怒吗？你要将你的怒气延续到世世代代吗！*希伯来文头一个词严格说来意为*到万代*或*到永永远远*。那个意为*延展*、延长、持续的动词，在诗篇 36:11（10）中则用于正面的意思。此处所表达的意思，与诗篇 30:6（5）中的正相反。

<span class="ax-anchor" id="psalms-85-6"></span><span class="ax-vnum">7 <span class="ax-veng">(6).</span></span> *你岂不转回* （并）*使我们复活，**你的百姓岂* （不）*要因你欢喜？* 前一分句可比较诗篇 71:20，80:19 (18)，申命记 32:39，何西阿书 6:2。后一分句可比较诗篇 5:12 (11)，9:3 (2)，40:17 (16)。「你岂不再以怜悯眷顾我们，把我们从如今这死亡或将死的光景中扶起，并使我们作为你的百姓，重新有因与你的关系、因与你的联合相交而欢喜的理由？」把疑问语气贯串全句的解法，比那种把后一分句看作系于前一分句、以之为目的的解法——*使你的百姓可以因你欢喜*——要简洁得多，也自然得多。同时，疑问的形式所表达的，乃是一种比单纯的祈求更有把握的期待。

<span class="ax-anchor" id="psalms-85-7"></span><span class="ax-vnum">8 <span class="ax-veng">(7).</span></span> *主啊，使我们得见你的慈爱；你的救恩你必赐给我们。*第一句祈求的是，愿神使他们亲身经历他的慈爱。在末一分句中，正如在许多别处一样，祈求的语式不觉间已换成了预期的语式。仿佛他说：「我们可以放胆求你将你的慈爱显给我们看，因为我们知道你必将你的救恩赐给我们。」

<span class="ax-anchor" id="psalms-85-8"></span><span class="ax-vnum">9 <span class="ax-veng">(8).</span></span> *我要听大能者*（神）*，耶和华，所要说的；因为他必向他的百姓、向他的圣民说平安；且愿他们不再转回愚昧。* 第一分句表明百姓甘愿聆听并顺服神的裁断。第二分句说出这种甘愿的缘由，即因他们知道那答复必是吉祥的。第三分句则为这种信心定下必要的限制，说明神施恩答应的条件。未能遵守这条件，正可解释应许何以只得部分应验——无论在个人身上，还是在整个教会身上都是如此。参看前面诗篇 80:19（18）的注释，并比较利未记 26:3-13 中的应许。*他的圣民，*即他怜悯的对象、他恩典的子民。参看前面诗篇 4:4（3）的注释。*且愿他们不再转回，*等于说：*所以*（或*因此）愿他们不再转回。* 若按我们的惯用语意译作「只要他们不再转回愚昧」，各分句之间真正的关联便可显得更加清楚。

<span class="ax-anchor" id="psalms-85-9"></span><span class="ax-vnum">10 <span class="ax-veng">(9).</span></span> *惟独临近敬畏他的人* （是）*他的救恩，使荣耀住在我们的地上。* 既然将应许限于敬畏神之人乃是这段描写中一笔不可或缺的要义，便无须偏离本句开首那个语助词（אך）的严格意义。参看上文诗篇 62:10（9）、68:7（6）的注释，并参诗篇 58:12（11）、73:1。如此其意便是：神的怜悯所预备的救恩，惟独赐给敬畏他的人。末一分句上文已按字面译出，按我们的惯用语来说，相当于*使荣耀得以住在我们的地上。* 「荣耀」一词与诗篇 84:12（11）中的用法相同。*住，*即长久居留，长远存续。

<span class="ax-anchor" id="psalms-85-10"></span><span class="ax-vnum">11 <span class="ax-veng">(10).</span></span> *慈爱与真实相遇*（在一处）*；公义与平安彼此亲嘴*（彼此）。所谓*真实，*我们当理解为神应许的真实，即神的信实。参看上文诗篇 25:5 的注释。真实与恩典或慈爱的同样搭配，见上文诗篇 25:10、40:11（10）、57:4（3）、61:8（7），以及下文诗篇 89:15（14）。*公义，*乃就其为神的恩赐而言，即称义，或为审判上的，或为护理上的。*平安，*乃免于一切搅扰之因，这就含有各样的昌盛在内。参看上文诗篇 72:3 的注释。*相遇，*是以和睦友善的方式相遇，末一分句中和好或亲爱的亲嘴，把这意思表达得更为有力。若把这句话解作：神向不配者所施的慈爱或白白的恩惠，如今显明与他的真实并行不悖——而他的真实原是立定要毁灭他们的；他们的平安或安稳，也与他的公义或审判并行不悖——若非如此，二者看来本是全然不能相容的：这样解释，便可使此句的意义更为醒目而有力。

<span class="ax-anchor" id="psalms-85-11"></span><span class="ax-vnum">12 <span class="ax-veng">(11).</span></span> *真理从地里发生，公义从天上垂看。*神应许的真理，仿佛可见其从地里发生，结出丰盛的果实；而他的公正，或说他对自己所立之约的信实，则在雨水与日光中从天上垂看。藉着这大胆而优美的构想，神护理看顾的确定性得着了表达，其力度远非任何单纯的教训性陈述所能及。末一分句中意象之美，又因所用的那个动词而更加鲜明：该词本义是俯身探头，为要向下注视较低之物。参看前面诗篇 14:2 的注释，并参士师记 5:28，撒母耳记下 6:16。

<span class="ax-anchor" id="psalms-85-12"></span><span class="ax-vnum">13 <span class="ax-veng">(12).</span></span> *耶和华也必赐下那*（物质的或属地的）*美善，我们的地也必献上它的土产*（或*出产）。*换言之，律法中所记载的应许必要应验（利未记 26:4），这句话的形式即借自那里，正如诗篇 67:7（6）一样。

<span class="ax-anchor" id="psalms-85-13"></span><span class="ax-vnum">14 <span class="ax-veng">(13).</span></span> *公义必在他面前行走，又使*（我们）*行在他脚步的路上。*前一分句的动词是一个意为行走或前行之动词的诗体强化形式。此处所表达的意思似乎是公开而庄严的显现。末一分句含义晦涩，其句法结构亦可疑。晚近的解经者将其理解为：*并为道路设立它的脚步，即*以它自己的脚步标明我们当行的道路。这归根结底所得出的意思，与上文所给的通行译法相同。
