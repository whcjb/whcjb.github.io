<span class="ax-anchor" id="psalms-66-1"></span><span class="ax-vnum">1.</span> *交与伶长。一首歌。一篇诗。向神欢呼，全地啊！* 题注的第二部分表明这是一篇赞美的诗。参看上文诗篇 65:1 的注释。诗篇本身的内容与结构也证实了这一点：其中首先是对神历代以来向他百姓所行奇事的总括颂扬，第 1-7 节；接着是对他在某一特定事件中所行之事的类似承认，第 8-12 节；最后是感谢的誓愿或应许，第 13-20 节。它与第四十六篇的相似，使有些人推测本篇是因同一事件而作，或是仿照那一篇而作，供教会在类似危难中使用。*欢呼*一词的形式是复数，这表明*全地*带有集合的意义。

<span class="ax-anchor" id="psalms-66-2"></span><span class="ax-vnum">2.</span> *歌唱他名的尊荣；献上*（给他）*尊荣，*（献上）*对他的赞美。*所谓他名的*尊荣*或*荣耀*，就是他所彰显的至美所应得的。参看上文诗篇 29:2 的注释。*献上，*字面作*安置*或*放置，*希伯来文中表达这类意思的动词常可互换。此处所用的同一短语也见于约书亚记 7:19、以赛亚书 42:12，显然与诗篇 29:1, 2、68:35（34）、耶利米书 13:16 中的*归荣耀*相当。末一分句的形式颇为特别：*归尊荣（作为*或*归于）他的赞美。*

<span class="ax-anchor" id="psalms-66-3"></span><span class="ax-vnum">3.</span> *你的作为何等可畏！因你能力的广大，你的仇敌必向你说谎。* 有些释经者认为，这里开始的话语，正是要向耶和华献上的那所要求的赞美；这一假设可以成立，却绝非必然。前一分句同样可以译作 *何等可畏*（是你在）*你的作为*（上），与下文第 5 节相类，其中代词的省略与诗篇 68:36（35）的情形相似。*因你能力的广大，即*由于它的缘故，或更确切地说，是在对它的认识与确信之中。参看上文诗篇 5:8（7）的解释。*向你说谎，*即因惧怕的影响而假意宣称效忠，献上虚伪的顺从。参看上文诗篇 18:45（44）的解释。

<span class="ax-anchor" id="psalms-66-4"></span><span class="ax-vnum">4.</span> *全地都要敬拜你，向你歌唱；他们要歌唱你的名。细拉。*此处动词又是复数，表明*全地*当作集合意义来理解，意即*万邦列地，*或地上一切的居民。见上文第 1 节。*敬拜你，*即俯伏下拜于你面前，这既是国民的致敬，也是宗教的敬拜。见上文诗篇 5:8 (7)。他们不单要向你歌唱，更要歌唱你的名，*即*不单颂扬你的存在，更颂扬你所显明的本性，即你先前作为所启示出来的属性。这种对万民同归耶和华的预期，与摩西之约时代的全部精神与旨意完全相合。

<span class="ax-anchor" id="psalms-66-5"></span><span class="ax-vnum">5.</span> *去，看神的作为，可畏的*（在）*对人之子的行动上。*希伯来文常以动词 *go*（去）作邀请或挑战的套语，而英文在此处则说 *come*（来）。参看下文第 16 节，并比较以赛亚书 2:3, 5。然而在此处，*go* 或许意在表达某种比 *用 come 所能表达的* 更多的意思。其意或许是：你若不信这些关于神的权能与统治的概括宣告，就自己去看那已在人类历史中、尤其是在以色列历史中所赐下的凭据：去埃及，去红海，去旷野，去约但河，在那里所行、并仍在教会的经历中不断重演的奇事中，看那证据——神确实拥有可畏的权能，足以辖制并左右世人。首句可比较诗篇 46:9（8），那是 מפעלות（作为）一词唯一另见之处。

<!-- PAGE 287 -->
<span class="ax-anchor" id="psalms-66-6"></span><span class="ax-vnum">6.</span> *他使海变为干* （地）*；他们必徒步过河；在那里我们要因他欢喜。* 这里显然暗指过红海与过约旦河，但并非仅作历史事件来提，乃是作为神为以色列施行非常干预的预表或样本，这样的干预在他们的经历中还可能再度实现。所以过去时与将来时的形式交错使用，仿佛是说：以色列的神必再使红海变为干地，让他的百姓经过；若有必要，他们必再脚不沾水地过约旦河；就在这些神迹发生之地，我们必再因他欢喜。海与河并提，似乎表明后者必须理解为约旦河，而不是如某些释经者所设想的幼发拉底河——虽然幼发拉底河通常被如此称呼。但可参以赛亚书 11:15, 16，撒迦利亚书 10:11。

<span class="ax-anchor" id="psalms-66-7"></span><span class="ax-vnum">7.</span> *以他的大能永远掌权；他的眼目在列邦之上*（或 *在列邦之中）鉴察；不容悖逆之人自高。细拉。* 首句的分词表示惯常的动作，「他恒常地、惯常地掌权」。参上文诗篇 22:29（28）。*以他的大能，*前面曾描述他以此为束腰。参上文诗篇 65:7（6）。名词 *永恒* 在此作副词用，意为 *直到永远。* 此处所描写的神的鉴察，含有这样的意思：人既不能抗拒神的能力，也同样不能躲避它。末句既可视为向神的祈求，也可视为对他仇敌的警戒。*自高：* קְרִי（当读的，即旁注的读法）作 *为他们*（或 *为自己）高举；* כְּתִיב（所写的，即正文的读法）作 *为自己举起*（或 *为自己高抬），* 若依此读法，则 *角* 一词可从诗篇 75:5, 6（4, 5）补出，或 *头* 可从诗篇 110:7 补出。悖逆的人，*即* 悖逆神的人，就是他那些顽梗不化、无可救药的仇敌。

<span class="ax-anchor" id="psalms-66-8"></span><span class="ax-vnum">8.</span> *列邦哪，你们要称颂我们的神，使他颂赞的声音得以听闻！* 在普遍描述神向他百姓所施的恩惠之后，这里似乎又加上了对此类恩惠中某一特定事件的纪念；然而这事件并非只关乎一地一方，乃是何等重大，以致列邦都被邀来同声为此颂赞神。参看前面诗篇 18:50（49）、22:28（27）的注释。

<span class="ax-anchor" id="psalms-66-9"></span><span class="ax-vnum">9.</span> *那* （位）*安置，*即将我们的魂置于生命中的那位，*并未将我们的脚交付*（给）*挪移，*即不容它动摇滑跌。前半句中这个不寻常的说法，似乎指使之复生，是从极大患难中得释放的一个比喻，而这类患难常被描写为死亡。参看前面诗篇 30:4（3）、49:16（15）的注释。*置于生命中*与诗篇 12:6（5）中*置于稳妥之地*的说法颇为相近。末句的表达方式与前面诗篇 55:23（22）相类，与下文诗篇 121:3 则完全相同。*交付给挪移，*即容许它从稳固的位置或安全之处被挪动。

<span class="ax-anchor" id="psalms-66-10"></span><span class="ax-vnum">10.</span> *因为你试验了我们，神啊，你洁净了*（或*熬炼）我们，像银子的洁净，*即如银子被炼净那样；有人认为，这里特别指银子所需的那种长久持续、反复多次的提炼过程。参看前面诗篇 12:7 (6)、26:2 的解说，并比较以赛亚书 1:25、48:10，撒迦利亚书 13:9，彼得前书 1:7。此处的总意是苦难，既作试验之法，又作洁净之法，下面几节即由此展开。

<span class="ax-anchor" id="psalms-66-11"></span><span class="ax-vnum">11.</span> *你使我们进入网罗；你把压力加在我们的腰上。*前一句描写重重的艰难与困窘，后一句描写痛苦与软弱。译作*网罗*的那个词，前面曾以极不相同的意义出现，指*塔*或堡垒，诗篇 18:3（2）。但即便作那样用时，它严格说来也是指*猎塔，即*猎人所用的瞭望与藏身之处；而从同一字根（צוד，打猎）也可推出*网*或*罗*之意，因其为打猎的惯用器具，以西结书 12:13 中无疑即是此义。译作*压力*的词仅见于此处，但从其词源上的亲属关系可知其基本含义。可比较诗篇 55:4（3）中的同源形式。有人以为这里的意思是压在身上的重压、负荷或担子，与阿摩司书 2:13 中该动词的用法相合。另有人使*压力*意为收紧、箍束，并由此必然含有疼痛或苦楚之意。提到腰，是因它是力量之所在（申命记 33:11），腰受损伤便既含疼痛又含软弱。参看下面诗篇 69:24（23）的注释。

<span class="ax-anchor" id="psalms-66-12"></span><span class="ax-vnum">12.</span> *你使*（或*容许）人骑在我们头上，我们进入火中，又进入水中，而*（如今）*你使我们出来，进入丰盈，*即满溢，*即*享受的满溢。*人，*指软弱必死的人，其暴虐因此更难以忍受。见上文诗篇 8:5（4）的注释。此处第一个分句在希伯来文中与在英文中一样含糊。*骑在我们头上，*虽是准确的直译，却只令人想到统率或引领之意，而上下文所要求的却是某种苦难。通行译本作*骑在我们众人的头上，*呈现的是骑兵践踏被征服之敌的景象。有人以为其意是*骑在我们身上，*如人驾驭并指挥驮着他的马。那么*头*之所以被提及，只是因它是最尊贵的部分，并不含骑者真的坐在其上之意。但正是这一点使该解释显得不自然而勉强。*火*与*水，*作为两样最具毁灭性的元素，是患难与危险的常见比喻。参以赛亚书 43:2。本节末了的那个希伯来词，只见于此处与诗篇 23:5。

<span class="ax-anchor" id="psalms-66-13"></span><span class="ax-vnum">13.</span> *我要来*（到）*你的殿，带着燔祭；我要向你还我的愿，即*他如此应许要献上的祭物。他的称谢不可仅止于口头或心中，而要见于礼仪，*即*以他所生活的那个时代所要求的象征形式表达出来。此处所指的，既非单指内心的情感，亦非单指外在的仪文，而是二者兼具。参看前面诗篇 40:7（6）、50:8、51:18（16）的解释。末句可比较诗篇 65:2（1）。数的突然转换，由复数转为单数，表明下文乃是一位理想说话者的言语，他所代表的，正是前文中说话的那些人——若非竟与他们是同一位的话。

<span class="ax-anchor" id="psalms-66-14"></span><span class="ax-vnum">14.</span> *这是我嘴唇所迸出、我口在我患难中所说的。*第一个动词极为有力而生动，在此处的用法与我们熟悉的说法 *bolted, blurted out,*（脱口而出、冲口而出）颇为相近，意谓他是出于某种无法抑制的冲动而开口，由此也预示了后面明言的事：这些所许的愿乃是极度困苦所促成的。这希伯来动词本义是张开或撑开嘴唇，或作为讥诮的姿态（耶利米哀歌 2:16），或作为恐吓的姿态（诗篇 22:14），或为要清楚发声说话（约伯记 35:16）。从士师记 11:35, 36 可以看出，古人对这词的绝对用法——特指那些不假思索、匆促许下的愿——是熟悉的。*在我患难中；*原文的说法是，*在那于我的患难中。*参看前面诗篇 18:7 (6) 的注释。

<span class="ax-anchor" id="psalms-66-15"></span><span class="ax-vnum">15.</span> *我要将肥畜的燔祭献给你，连同公羊的香；我要献上*（供物，即）*牛犊与公山羊。细拉。*译作「肥畜」的那个词尤多用于羊羔，以赛亚书 5:17。首句中的动词正是译作*燔祭*的那个名词所由出的字，严格说来意即*我要使之上升，即*升于坛上，或随烟气自坛上腾。*香*在此或可取其字源之义，指祭祀中所*焚烧*之物，虽然在用法上它仅限于芬芳的熏物；希伯来文这个词除本处之外，别处也都是如此，惟独此处似指在坛上焚烧的祭牲脂油。动词*献*在此作绝对用法，是摩西律法中的专门术语，表示献祭之举。参看出埃及记 29:36、利未记 9:7，并参士师记 6:19、列王纪上 18:23, 26。此处逐一列举各类祭牲，是要传达一场合乎定例、完备无缺之献祭的意念，其中所含的感恩远过于寻常。

<span class="ax-anchor" id="psalms-66-16"></span><span class="ax-vnum">16.</span> *去*（或按我们的惯用语，*来），听啊，你们一切敬畏*（你们敬畏）*神的人，我要向你们述说他向*（或为）*我的魂所行的事。* 「敬畏耶和华的人」是对信徒即神子民的常见称述。见诗篇 60:6（4）、61:6（5）。此处的邀请与诗篇 22:24（23）中的相似。*述说，*其本义为数算、计点，引申义为复述、陈说。*向我的魂，即*向我这生命或魂受威胁的人。*向我，*即作为所提那一行动的对象；或*为我，*即作为那蒙益处的人。这一呼吁为随后的宣告铺路；那宣告本于他自己的经历，即惟有诚心顺服并献身于神，方能得着他的保护。

<span class="ax-anchor" id="psalms-66-17"></span><span class="ax-vnum">17.</span> *向他，*（用）*我的口我呼求，而高声的赞美*（高举）*在我舌下。*只需在元音符号上略作更动，或假定标点有不规则之处，末句便可译作：*他在我舌下被高举，即*藉着舌头作为赞美的工具。但由于下文诗篇 149:6 出现了一个与之相应的复数形式，这个希伯来词（רוֹמָם）很可能是名词，意为崇高的赞美，或藉赞美而有的高举。*在我舌下*或许只等于*在*我舌上、或*用我的舌，*也可能意在暗示另一层意思：这样的赞美尚有积存留备，以待日后取用；有人认为诗篇 10:7 中这一短语正是此意。

<span class="ax-anchor" id="psalms-66-18"></span><span class="ax-vnum">18.</span> *罪孽我若看在心里，主必不垂听。*我若心存任何恶念，神就不听我的祈求。同样的思想见于箴言 15:29，以赛亚书 1:15，59:2，约翰福音 9:31，约翰一书 3:22。此处提出这一点，是作为他要据以申明自己并无任何此等败坏居心的根据，而他在下一节中确实如此申明。

<span class="ax-anchor" id="psalms-66-19"></span><span class="ax-vnum">19.</span> ((但))*神实在听了；他垂听了我祷告的声音。* 开头的希伯来语助词严格说来并非转折词，而是确认词。参看上文诗篇 31:23 (22) 的注释。其力度相当于我们所说的*然而、实则、事实上*……之类。前一节所提出的疑虑，在他身上已因那里所说的试验而消除。神已经垂听了他的祷告，由此作证：他并未犯那种口是心非之罪。

<span class="ax-anchor" id="psalms-66-20"></span><span class="ax-vnum">20.</span> *当称颂的* (是) *神，他未曾推却我的祷告* （离开他） *也未曾使他的慈爱离开我。* 此处与别处一样，当用于神时，*当称颂的* 只能是指 *受赞美的* 或当受赞美的。末句中这动词的双重用法，在翻译中不易仿效。希伯来文的同一个词既可用来表示 *弃绝* 一个祈求的举动，也可表示 *收回* 或不施恩惠。
