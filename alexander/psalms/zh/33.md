<!-- PAGE 148 -->
一篇赞美之歌，意在激发并表达以色列对耶和华的信靠，与其前那篇训诲诗紧密相连，彼诗结尾的思想在此得以展开。两篇诗之间的这种密切关系，或可解释本篇何以没有题注，正如第九、第十两篇的情形一样。参见上文第 46 页。

在第 1-3 节总括地呼吁众人赞美神之后，随即列出了赞美的理由，即他的真实、信实与怜悯，第 4-6 节；他创造的大能，第 7-9 节；以及他对人间行事者的掌管——不仅是个人，更是整个列邦，使他们都服事他自己的计划，第 10, 11 节；由这一切推出他特选子民所得的福分，第 12 节。诗人随后继续赞美神，称他无所不知，第 13, 14 节，并将一切受造之助的不足，第 15, 16 节，与蒙他保护之人的稳妥相对照，第 17, 18 节；全篇以他全体子民向他表达的坚强信靠作结，第 19-21 节。

<!-- PAGE 149 -->
<span class="ax-anchor" id="psalms-33-1"></span><span class="ax-vnum">1.</span> *欢呼吧，你们义人，在耶和华里！于正直人合宜的*（乃）*赞美。* 据字源学家所言，这希伯来动词本义是「欢跃起舞」，因此是表达最活泼之欢腾的极有力的说法。*在耶和华里，即*在于认识他、拥有他，尤其是就他与他特选之民之间的约的关系而言；这民在此被称为*义人*与*正直人*，乃是就卓越而言，如民数记 23:10，并非因为他们个个实际如此，而是因为他们本当如此，因为这正是一个蒙拣选之民的理念，或者可以说是其理论；而以色列那些并无此品格的肉身后裔，并无权享有教会的特权——反之，对真以色列而言，这些特权正是喜乐的正当缘由，并使赞美于他们格外*美好*或*合宜*。

<span class="ax-anchor" id="psalms-33-2"></span><span class="ax-vnum">2.</span> *你们要用琴称谢耶和华；用十（弦）的瑟* *向他歌颂。* 头一个动词的意思是承认，或承认罪过，或承认恩惠；前一种情形相当于*认罪，*诗篇 32:5，后一种相当于*称谢，*诗篇 7:18（17）。另参诗篇 28:7，30:10（9）。通行译本作*赞美，*则太过宽泛，虽然这层意思无疑包含在内。提到乐器并不排除歌声的赞美，只是为它添上伴奏与扶助，仿佛人声独自过于微弱，不足以发出对神的颂赞。此处所举乐器的确切形制今已无从知晓，也全然无关紧要。提及第二种乐器的十根弦，或是借这一类似的特征将它指认出来，或如有些人所推想的，是因为这数目带有奥秘的含义。同样的搭配又见于下文诗篇 144:9，而在诗篇 92:4（3）这两个词则分别使用，似乎是指不同的乐器。

<span class="ax-anchor" id="psalms-33-3"></span><span class="ax-vnum">3.</span> *向他唱新歌；要善于弹奏，发欢呼之声！* 新歌意味着不断有新的理由与时机来颂赞神，也意味着献上颂赞之人心中虔敬感恩之情的自然涌流。这是此语首次出现，但在后面的诗篇中屡屡再现——诗篇 40:4(3)、96:1、98:1——在新约中也出现过一两次，启示录 5:9、14:3。——*要善于弹奏，*字面作*在弹奏上行得好*或*在弹奏中行得好。*这一特殊的惯用语见于大卫的记载，撒母耳记上 16:17。——*欢呼之声，*见前，诗篇 27:6 的注释；该处与此处一样，并无确定或必然指向献祭之意，只是指宗教情感出声而活泼的表达。

<span class="ax-anchor" id="psalms-33-4"></span><span class="ax-vnum">4.</span> *因为耶和华的话是正直的，他一切的作为都是*（行）*在信实中。*这里所说的*话*是应许之言，而*作为*便是这话的履行或应验。*话*是正的或正直的，*即*出于真诚而发，并带着必要践约的完全定意。*在信实中，*即忠实地加以成就。参民数记 23:19，诗篇 105:42。

<span class="ax-anchor" id="psalms-33-5"></span><span class="ax-vnum">5.</span> *喜爱公义与公平*——（以）*耶和华的慈爱遍满大地。* 他是喜爱的，*即*他素常喜爱。末句将神的慈爱表明为众所周知、普世共睹之事，而全节则显出他的公义与他的慈爱彼此和谐，对他的百姓同样是安慰。

<!-- PAGE 150 -->
<span class="ax-anchor" id="psalms-33-6"></span><span class="ax-vnum">6.</span> *诸天藉耶和华的话而造成，其中的万象藉他口中的气息而成。* 诗人既已陈明耶和华在地上所显出的公义、信实与慈爱，如今便藉着展示他在创造并托住宇宙中所显的全能大力，来证实他拯救并保护其子民的能力。此处显然引及创世记中的创造史。这一点在末了的话*其中的万象*上尤为明显，这几个字取自创世记 2:1。*气息*是*话*的诗体同义语，且更有力地传达出这样的意念：神造一个世界是何等轻而易举。同时，圣经以这两个词来指神格中的第二位与第三位，也绝非偶然的巧合。参创世记 1:2，约伯记 27:3，33:4，诗篇 104:29, 30，以赛亚书 11:4。

<span class="ax-anchor" id="psalms-33-7"></span><span class="ax-vnum">7.</span> *如聚拢一堆般聚起海水，将深渊置于府库。*这分词表明这是一桩仍在延续的作为，持续不断地见证着神全能的大能；这大能在今日之必需，正如创造之初第一日一样，若非如此，大地必尽被淹没。——*如一堆。*乃是待流质如待固体，显然是暗指出埃及记 15:8。另参约书亚记 3:13-16、诗篇 78:13。——*置于，*字面作*给予，*即贮藏、存放。——*深渊，*指大量的水。这一描写的要点，在于神处置这些浩瀚的水体，犹如人处置大小适中的固体之物一般，把波浪堆垒起来，又将它们收贮起来，正如人之于石块或麦子。

<span class="ax-anchor" id="psalms-33-8"></span><span class="ax-vnum">8.</span> *愿他们惧怕耶和华*——*全地；愿他们敬畏他*——*世上一切的居民。* 动词置于各分句之首，大大加强了语气的力量。平行体极为工整，两边用语几近同义。首句的「地」指其有理性的居民，这一点由复数动词所暗示，又由平行的下句明说出来。译作*世界*一词的确切含义，参上文诗篇 24:1 的注释。其中更进一层的推论是：这位全能的宇宙创造者与保守者，既有能力保护他的子民，也配得他们的信靠。

<span class="ax-anchor" id="psalms-33-9"></span><span class="ax-vnum">9.</span> *因为*（乃是）*他*（才）*说*（要有），*就有了；*（乃是）*他*（才）*吩咐，就立定了。*整节的句式都仿照创世记中创造之记载的说法，那里这两个动词反复交替出现。通行译本作*他说话，事就成了，*有三处可议。其一，希伯来文中那个着重的代词未得公允的表达；其二，*事就成了*一语远不如*就有了*来得有力；其三，希伯来文的动词（אָמַר）并非 *speak*（讲说）之意，而是 *say*（说出某话）之意。参看上文诗篇 4:5 (4) 的注释。至于所说的是什么，凡读者皆可凭对创世记叙事的记忆补出。——*立定，*即显现、得以存在。参诗篇 119:90, 91。

<span class="ax-anchor" id="psalms-33-10"></span><span class="ax-vnum">10.</span> *耶和华废去了列国的筹算；他使万民的计谋归于无有。* 他既曾如此行，就能如此行，虽然此处并未明言。那创造并托住宇宙的主，能随己意使他自己受造之物的图谋归于徒然，无论是个人还是邦国；因此，他的子民对他们无所惧怕。

<span class="ax-anchor" id="psalms-33-11"></span><span class="ax-vnum">11.</span> *耶和华的筹算直到永远坚立；他心中的意念存到世世代代。* 这是上述命题的反面。既然受造之物的任何谋算都不能违背他的旨意而得逞，那么受造之物的任何抵挡也就不能影响他自己计划的成就。——*筹算，*即计划、意图。——*他心中的意念，*即他心思中的构想或旨意。——*到世世代代，*这是常见的惯用语，意思是一代接着一代，或不加限定地指一切世代。

<!-- PAGE 151 -->
<span class="ax-anchor" id="psalms-33-12"></span><span class="ax-vnum">12.</span> *有福啊，那以耶和华为神的邦国*（是）*耶和华，就是他所拣选归他为产业的子民。* 这是全篇的中心，是前文的结论，也是以下各节的题旨。在这一普遍的命题之下，含有对以色列的特别称颂，因为以色列实实在在是神的拣选、神的产业，*即*在一种特殊的意义上，藉着世代相承、历经久远的年岁，被拣选归属于他。

<span class="ax-anchor" id="psalms-33-13"></span><span class="ax-vnum">13.</span> *耶和华从天上观看；他看见人（或亚当）的众子。*他不是仅在某一时刻观看，而是时时观看；自他起初创造他们以来，他就一直看顾着他们。正如他的全能不断运行以维系他们的存在，他的全知也同样持续施行，其鉴察与起初无异。

<span class="ax-anchor" id="psalms-33-14"></span><span class="ax-vnum">14.</span> *从他居所之处，他注视地上一切的居民。*从他自己在地之外、地之上的居所，他一直专注地观看地上的居民。此动词是诗体用词，比寻常的*观看*更强。参雅歌 2:9、以赛亚书 14:16。

<span class="ax-anchor" id="psalms-33-15"></span><span class="ax-vnum">15.</span> *那*（神）*塑造他们众人之心的，那*（神）*留意他们一切作为的。*冠词与所省略之动词的主语相合，这一结构必须保留，才能使本句与上一句的联系如原文那样紧密。*塑造*含有*知晓*之意，而这层意思在另一半句中，就其外在行为而言，表达得更为明确。神被称为人灵魂的创造者，另见撒迦利亚书 12:1。参民数记 16:22, 27:16。至于神对人心的掌管，箴言 21:1 就君王而言有明确的断言。

<span class="ax-anchor" id="psalms-33-16"></span><span class="ax-vnum">16.</span> *王决不因势力之大而得救；勇* （士）*不因力量之大而得脱。* 必不如此，因为事实并非如此，向来也不曾如此。故此将来时实在含有一种普遍的现在。这否定自然要受前文的限制：人单凭己力的拯救之能，只在其与神对立、或妄称可以独立于神时，才被否定。诗人在此开始将神的完全与一切受造的帮助相对照，二者都视为所倚靠的对象。*王*是一个类名，指整整一类人，比我们那不定的说法*一位王*语气更强。

<span class="ax-anchor" id="psalms-33-17"></span><span class="ax-vnum">17.</span> *虚谎，*（是）*那为拯救而备的马，他也不能靠他力量的大而解救。*这不过是第 16 节那总括之语的一项具体申明。所说的*马*是战马，被单独提出，因为它是古人尤其惯于倚靠的军力要素之一。见上文诗篇 20:8 (7) 的解释，并参以赛亚书 31:1-3。*虚谎，*一件虚假之物，*即*一件欺哄人、叫人所寄托的信心落空的东西。此处所言的解救与拯救，是从战争的危难中得解救、得拯救。

<span class="ax-anchor" id="psalms-33-18"></span><span class="ax-vnum">18.</span> *看哪，耶和华的眼目*（是）*向着敬畏他的人，向着那等候他慈爱的人。* 当别人的物质力量不足以保障他们时，那些敬畏耶和华、仰望他慈爱的人，却安然处在他警醒的鉴察之下。这鉴察是为他们的益处，下一节说得更为明白。

<span class="ax-anchor" id="psalms-33-19"></span><span class="ax-vnum">19.</span> *要救他们的魂脱离死亡，又在饥荒中保他们存活。*此句承接前一节而来。他的眼目向着他们，正是为了在他看为必要之时施行干预，以拯救*他们的魂，*即他们的性命，*脱离死亡，*这是就一般而言；随后又加上一种为古代希伯来人所熟知的特定险境。*那饥荒*与第 16 节的*那君王*是同类的说法，也与我们惯用的*那瘟疫*一语相仿——即在泛指的意义上使用，并非指某一特定的疾病或降灾。

<!-- PAGE 152 -->
<span class="ax-anchor" id="psalms-33-20"></span><span class="ax-vnum">20.</span> *我们的魂已仰望*（或*等候）耶和华；我们的帮助和我们的盾牌*（是）*他。* 在本篇余下的部分，神的子民表白他们对他的倚靠，并祈求他按着他们的信心待他们。过去时所表达的，是一种业已养成并固定下来的习惯，因此实际上也包含了对现今情形的描述。本节的用语，似乎在几处呼应了摩西五经的措辞。参创世记 15:1、49:18，申命记 33:29。盾牌的比喻在前面已经出现过，见诗篇 3:4(3)、18:3, 31, 36 (2, 30, 35)。代词的位置带有强调意味，意义深长。我们的安稳与保障在于他，且唯独在于他。

<span class="ax-anchor" id="psalms-33-21"></span><span class="ax-vnum">21.</span> *因为我们的心要在他里面欢喜，因为我们素来信靠他的圣名。*这几个时态的承接并非无意或偶然。诗人对将来的确信，是从他已经拥有、且已受过试验、被证明确实存在的信心而来的。正因他已经信靠了，所以他知道自己将要欢喜。把这两个时态一概换成现在时，既削弱了文意，也不合语法。——*他的圣名，*此处「圣」字取本书中它常有的广义，几乎等于*他荣耀的名、他神性的名。*参上文诗篇 22:4（3）注。信靠这名，就是把自己的指望建立在神从前的作为中所显明的属性之上；就是相信他向来显明自己是怎样的一位，在他百姓的经历中他仍将是那样的一位。

<span class="ax-anchor" id="psalms-33-22"></span><span class="ax-vnum">22.</span> *愿你的怜悯，耶和华，临到我们，正如我们仰望了你。*这盼望中所含的信心既是神施怜悯的唯一条件，那么拥有这信心便构成对那怜悯的凭据，此处即以此为前面一切祈求的总结。这样仰望等候的，断不能不得成就。一位怜悯而公义的神，若不否认他自己，就不能扣住他百姓如此指望之物。至于任何近乎功德之凭据的意味，则被一条道理所排除——此处已足够暗示，别处更反复教导：这条件本身与系于其上之物同样都是神的恩赐。所以这凭据实际上不过是一个祈求：神既已赐下这渴慕，求他也成全它。——*正如，*即按照，而不仅是「因为」；按我们信心的分量，如此待我们。参马太福音 9:29。
