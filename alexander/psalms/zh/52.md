本篇除题注（第 1, 2 节）外，共有三段，每段三节。第一段中，诗人责问一个傲慢、残忍而诡诈的仇敌，第 3-5（1-3）节。第二段中，他预言这仇敌必因神的审判而灭亡，又预言其愚妄所要招致的藐视，第 6-8（4-6）节。第三段中，他将这不信所结的致命果子，与他自己倚靠神所得的美好果效相对照，第 9-11（7-9）节。第 5, 7（3, 5）节中的两个*细拉*，与其说是关乎本篇的形式，不如说是关乎诗人的情感，因此所置之处并不整齐。参见上文诗篇 3:3（2）的注释。英文圣经与希伯来文圣经在本篇节数编次上的出入，与第 51 篇相同，所由之因也相同。

<span class="ax-vnum">1.</span> *交与伶长。玛斯基拉。大卫作。* 本篇明确标明为*玛斯基拉*（Maschil），即教训诗，因为它既公开表明与大卫生平中某一特定事件相关，其教训之用意便极易被忽略。参看上文诗篇 32:1、42:1、45:1 的注释。然而，本篇虽因这一事件而作，却是为古时教会长久而公开的使用而写的，故题作*交与*（或*为了）伶长。*参看上文诗篇 4:1、51:1 的注释。

<!-- PAGE 244 -->
<span class="ax-vnum">2.</span> *当以东人多益来告诉扫罗，对他说，大卫到了亚希米勒家。* 这不过是故事的开端，诗篇的读者想必早已熟知其事，详载于撒母耳记上 22 章。提到多益，仅是作为证人或告密者，事情由他而传到扫罗耳中。*当他来，*字面作*在他来时，*与诗篇 51:2 所用的表达形式相同。

<span class="ax-anchor" id="psalms-52-1"></span><span class="ax-vnum">3 <span class="ax-veng">(1).</span></span> *你为何以作恶自夸呢，勇士（啊）？全能者的慈爱*（乃是）*整日的。*动词的将来时形式含有顽固持续之意。*以作恶自夸，*即以加害于人为乐、为荣。这*勇士*不是多益，乃是扫罗；在圣经历史的一切人物中，惟有他最接近古典意义上的英雄。因此这称呼里含着几分敬重与称赏，仿佛他是说：「一个本可在行善上如此卓越的人，怎么竟以自己的羞辱为荣，以作恶自夸呢？」末句中，这勇士的恶毒与那全能之神永不止息的良善之间，有一显而易见的对照。所以此处所用的这一特定神名格外有深意。见上文诗篇 5:5 (4)，第一行。仿佛他是说：「任凭你何等有能有恶，耶和华的能力与慈爱仍然更大。」*整日，即*永不间断，连绵不绝。见上文诗篇 42:11 (10)。

<span class="ax-anchor" id="psalms-52-2"></span><span class="ax-vnum">4 <span class="ax-veng">(2).</span></span> *毁灭之事，你的舌头必谋算，如同磨快的剃刀，行诡诈。*头一个词指灾祸之事，即一人因另一人的恶意而遭受的祸患。见前，诗篇 5:10 (9)、38:13 (12)，并见后，诗篇 57:2 (1)。此处将来时的特别含义与第 3 (1) 节相同。这里说*舌头*思量或谋算毁灭之事，是因为舌头被拟人化了，或是以诗意的手法代替说话的人。所指的是扫罗控告亚希米勒与大卫同谋敌对他时那些伤人的话（撒母耳记上 22:13）。这项诬告，或说出此诬告的舌头，被比作剃刀，不单是锋利的，而是为着某一目的或场合特意磨过、磨快的。见前，诗篇 45:6 (5)。类似的比较见于诗篇 55:22 (21)、57:5 (4)、59:8 (7)、64:4 (3)，耶利米书 9:2, 7 (3, 8)。*行诡诈，*字面作*诡诈*或*欺骗。*就语法而言，这几个字可以指说话者或他的舌头在行诡诈；但若理解为指剃刀行事诡诈，*即*它下手最狠之时，动作却无声而平顺，意思就更为鲜明。

<span class="ax-anchor" id="psalms-52-3"></span><span class="ax-vnum">5 <span class="ax-veng">(3).</span></span> *你爱恶*（过于）*善，爱虚谎*（过于）*说公义。*这里的过去时，像前面几节中的将来时一样，含有现在的意思；但与它们不同的是，它把对罪的爱表现为早已持续已久、积习成性的。可将此处的表达形式与诗篇 45:8（7）中的相比较。*公义*包含*真实*或诚信，正如属包含种。此处所指的那一种不义乃是虚谎，这从对偶可以看出。那*细拉*无言地透露出作者对他所描述之事的憎恶。

<span class="ax-anchor" id="psalms-52-4"></span><span class="ax-vnum">6 <span class="ax-veng">(4).</span></span> *你喜爱一切吞灭的话，诡诈的舌。*这与其说是前文论述的继续，不如说是为了从中引出结论而作的重提或总括。若按周期句式，诸观念之间的联络可以这样显明：*「*既然你如此喜爱……，所以神必……」……。*吞灭的话，*字面作*吞咽之话*或吞食之话。后一名词仅见于此处；但*吞灭*这一动词在希伯来文中常用来表达彻底毁灭的意思。参看前面诗篇 21:10 (9)、35:25 的注释。*诡诈的舌*或*行诡诈的舌。*此语可视为受动词支配，即*你喜爱一切吞灭的话（并*或*乃至）诡诈的舌。*但若把它当作呼语，即径直对那诡诈的舌说话，则语势更强，也更合乎上下文的句式。

<!-- PAGE 245 -->
<span class="ax-anchor" id="psalms-52-5"></span><span class="ax-vnum">7 <span class="ax-veng">(5).</span></span> （所以）*神也必照样永远毁灭你；他必把你夺去，把你从*（你的）*帐棚中拔出，又将你从活人之地连根拔除。细拉。*开头的那个小品词，*也、照样，*表明本节与前一节的关联；前一节实际上是条件句，虽然形式上不是。「正如你那一面喜爱一切吞灭人的言语，照样神在他那一面也必毁灭你。」任何精确的翻译都无法传达本节诸动词的全部力量，它们接连提示出好几幅关于毁灭或剿除的鲜明图景。第一个动词本义是指拆毁房屋（利未记 14:45），第三个动词似乎也以此为本义（箴言 15:25），虽然有人认为它指的是拔起的动作，与*栽种*相反，正如第一个动词与*建造*相反。第二个动词在它出现的其他每一处，都与火或炭的拿取与搬运有关。参箴言 6:27, 25:22，以赛亚书 30:14。因此在希伯来读者耳中，它几乎必然提示的不只是「移去」这一笼统的意思，而是像对待火那样挪开、取走的特定意思，*即*如同人把炭从炉中扫出，或用别的方式把它熄灭。余下的那个动词又在这些图景之上添了猛力连根拔起的意象，用它对应的英文词已足以表达。*活人之地，*或照通常的译法，*活着之人的地，*是以一个国度为喻，对生命本身、即今生存在状态的诗意描写。见前文诗篇 27:13 的注释。停顿记号的迅速再现，含有情绪激动之意，并提请人留心紧接其前的那句威吓之辞。

<span class="ax-anchor" id="psalms-52-6"></span><span class="ax-vnum">8 <span class="ax-veng">(6).</span></span> *义人必看见，他们必惧怕，并且要嗤笑他。* 这里所说的惧怕，是神的同在与权能一经明显彰显便生出的那种宗教性的敬畏。在诗篇 64:9, 10（8, 9）中，这敬畏被视为与喜乐并行不悖；在此处则与对恶人的嗤笑并行。这嗤笑并非为他的受苦而生的自私快意——旧约明明定那为罪（箴言 24:17；约伯记 31:29）——乃是对罪之荒谬的一种感知；这感知在最纯净的心里必最为强烈，因此也绝不与怜悯相抵触，何况圣经把这嗤笑归于神自己（诗篇 2:4）。译作 *看见与惧怕* 的两个动词之间的谐音双关，与诗篇 40:4（3）中的相同。*将要看见，即* 第 7（6）节所威吓的毁灭。*嗤笑他，* 即那被如此毁灭之人，也就是前文直接呼告的那一位。若把 *嗤笑他* 换作 *嗤笑它，即* 那毁灭本身，便可避开这 *enallage personae*（人称转换）；但这样不合希伯来文的惯用语，因为希伯来文向来宁取有位格的说法，不取抽象的说法。

<span class="ax-anchor" id="psalms-52-7"></span><span class="ax-vnum">9 <span class="ax-veng">(7).</span></span> *看这人*（他）*不以神为他的力量，却倚赖他财富的增多，*（并）*在他的恶中刚强。*这可以看作第 8（6）节所提到的那些发笑之人的话。*看这人，看*他已落到何等地步。这*看*字的效果与以赛亚书 14:16 中的反问相似。译作*人*的那个词不是通常所用的词，而是一个含有力量或权势之意的词，因此用在这里便给这段话添了一种讽刺的意味。可比较诗篇 8:5（4）、10:18 中一个相反的说法的类似用法。将来时表示执意不肯、并且预料他会在这拒绝中持续下去。*以为*，字面作*安置*或*设立*。参看上文诗篇 40:5（4）。*他的力量*，更确切地说，是他的*坚垒*或堡垒。参看上文诗篇 27:1、37:39、43:2。*增多*，或仅作丰盛、众多。参看上文诗篇 5:8（7）、51:3（1）。译作*恶*的那个词，是上文第 4（2）节译作*毒害*的那个词的单数形式。它似乎特指一种存心加害的恶意倾向。

<span class="ax-anchor" id="psalms-52-8"></span><span class="ax-vnum">10 <span class="ax-veng">(8).</span></span> *而我*（却）*像神殿中一棵青翠的橄榄树，我已倚靠神的慈爱*（直）*到永远和永恒。*他所期待的，不单是恶人的灭亡，也是自己的得救。为了把前后两节的关系表达清楚，按我们的语文习惯，开头应当加一个转折词，*但我*。参看上文诗篇 2:6 的注释。青翠结实的树木是兴盛的一个常用象征。参看上文诗篇 1:3 的注释。此处特意举出橄榄树，正如诗篇 92:13, 14（12, 13）特意举出棕树与香柏树一样。本节的意象为耶利米书 11:16 所沿用。*神的殿，*即会幕，视之为他在地上的居所，他在其中款待朋友、供养自己的家人。参看上文诗篇 15:1，22:6，27:4, 6，36:9（8）的注释。这里比喻的交错混用，只说明整段描写都是象征性的，也应当照此解释。*我已*（早已）*倚靠，*这既包括他此刻的倚靠，也包括得更多，即这并非一时新起的冲动，而是他心灵中已然安定的习惯。两个名词*永远*与*永恒*连用，合成副词性的意义，*直到永永远远。*参看上文诗篇 10:16，21:5（4），45:7（6），48:15（14）的注释。这一限定语所关涉的，不是他倚靠的动作，而是他倚靠的对象。他的意思不是「我要永远倚靠神的慈爱」——那样便须用将来时的动词；而是「我已经倚靠、如今仍旧倚靠他的慈爱，因为那是一种存到永远的慈爱」。

<span class="ax-anchor" id="psalms-52-9"></span><span class="ax-vnum">11 <span class="ax-veng">(9).</span></span> *我要称谢你，直到永远，因为你已成就了*（这事）*，并要仰望*（于）*你的名*——*因为这是美善的*——*在你的圣民面前。*前一个动词的通行译法（赞美）不够确切，因为它本来表示的是一种特定的赞美，即为所蒙恩惠而发的称谢。参看前面诗篇 6:6（5）、7:18（17）、49:19（18）的注释。*你已成就了*这动词的宾语须由上下文补出。参看前面诗篇 22:32（31）、37:5、39:10（9）的注释。*你的名，*即你的本性的彰显。参看前面诗篇 5:12（11）、20:2（1）、23:3、48:11（10）的注释。期待神的名，或等候它，就是信靠那些已经显明过的同样的神圣完美，在将来仍要施行、仍要显明。通行译本作*我要等候你的名，*不如《公祷书》所作的*我要仰望你的名*来得贴切。此处与第 10（8）节一样，那句附加解释的子句，*因为这是美善的，*所指的不是期待这一行动，而是期待的对象。他的意思不是「因为仰望你的名是好的」，而是「因为你的名是美善的，所以当仰望它」。这一点从诗篇 54:8（6）、69:17（16）、109:21 的类比中可以看清；这几处也表明，末了的那几个字，*在你的圣民面前，*既不可与随后的话连读，作*这在你的圣民面前是美善的，即*在他们看来是美善的，也不可与较远的前文*我要称谢你*相连，而当与较近的前文相连：*我要在你的圣民面前仰望你的名，即*我要宣认我对你怜悯的信靠，不仅在隐密处，更是在你子民、就是教会的面前。参诗篇 22:23（22）。如此，*因为这是美善的*便须读作插入语。*你的圣民，*即蒙你怜悯而自身也存怜悯的人。参看前面诗篇 4:4（3）、50:5 的注释。此处仅用作神百姓的一般称谓或描述。
