<span class="ax-vnum">1.</span> *大卫的诗，当他在*（当他身处）*犹大旷野的时候。*这旷野就是沿犹大支派东界一带的旷野。在押沙龙叛乱与大卫在他面前逃亡的记载中屡次提到它。参撒母耳记下 15:23, 28，16:2, 14，17:16。在那段历史中，我们也遇见好几处与此处所用一模一样的说法；再加上本篇在内在气质上与另几篇涉及押沙龙叛乱的诗篇（如诗篇 3、4、42、61 篇）有极强的相似，足以表明它属于同一时期，而不属扫罗逼迫的时期——第 12（11）节提到王，本来就不容作后一种解释。本篇分为两部分，各自呈现的思路次序大体相同，只是照一切此类情形的惯例略有变化。两部分都以切望神的同在、渴慕与他相交开头，又都以笃定地期待他的怜悯作结；但在第一部分，第 2-9（1-8）节，这怜悯被设想为显明在诗人脱离苦难上；在第二部分，第 7-12（6-11）节，它则被看作保证了他仇敌的灭亡。

<!-- PAGE 279 -->
<span class="ax-anchor" id="psalms-63-1"></span><span class="ax-vnum">2 <span class="ax-veng">(1).</span></span> *神啊，我的神*（是）*你；我要切切地早寻求你；我的心渴想你：我的肉身切慕你，在干旱疲乏无水之地。*第二个神名是表明能力的那一个，在此也可译作*我的大能者*（那一位）。单是用这个名字，本身就已直接诉诸神的全能。首句中的动词在词源上与一个意为「黎明」的名词相连，该名词见于上文诗篇 57:9(8)。近代的辞典编纂者排除了*清早*之意，以为该动词不过相当于英文的*寻求*（seek），至多是指殷切地寻求。然而时间的概念确实包含其中，这似乎可由以赛亚书 26:9 的对照得出。清早寻求一物的举动，含有迫不及待或恳切渴求之意。心与肉身合起来，指整个人。参看上文诗篇 16:9 的注释。此处显然暗指大卫在犹大旷野中实际经历的穷乏。参看第 1 节注释所引诸处，另加撒母耳记下 17:2；那里译作*疲乏*的希伯来词正是用在大卫自己身上，这就要求、或至少容许在此处作同样的应用，尤其因为该形容词的形式是阳性，而*地*在希伯来文中是阴性。严格说来，文法上的一致或许是与*肉身*相合，这个词在希伯来文中是阳性。

<span class="ax-anchor" id="psalms-63-2"></span><span class="ax-vnum">3 <span class="ax-veng">(2).</span></span> *要见你的能力和你的荣耀，正如* （如同）*我曾在圣所中瞻仰你。* 前一分句说明上一节所表达的那强烈渴慕之对象。为使这一关联明晰，通行译本将两个分句对调，此处仍予保留，因为在所提出的许多译法中，这一种总的说来是最好的。晚近有一种译法把本节解作一种承认：他在旷野中确实寻得了一处圣所，因为凡神乐意显明其同在之处，便总有圣所可寻。然而，这一意念纵然纯正而合乎圣经，若不加以牵强，终难从眼前这节经文中引出。

<span class="ax-anchor" id="psalms-63-3"></span><span class="ax-vnum">4 <span class="ax-veng">(3).</span></span> *因你的恩惠比生命更美，我的嘴唇要赞美你。*有一种更简单、或许也更合乎希伯来惯用法的句法，是把前一分句看作前几节所表达的那强烈渴望的理由，*因你的恩惠比生命更美，*而末一分句不过是加上一句感恩称颂的誓言，*我的嘴唇要赞美你。比生命更美，*不单是比我如今所过的这生命更美——那样的生命几乎算不得配称为生命——乃是比我在缺了神恩惠之下所能过的任何生命都更美；故此这恩惠绰绰有余，足以作其替代与补偿。

<span class="ax-anchor" id="psalms-63-4"></span><span class="ax-vnum">5 <span class="ax-veng">(4).</span></span> *这样我要一生称颂你，我要奉你的名举起我的手。这样，*即按着所赐下的恩赐。*称颂，即*赞美你、感谢你。参看前面，诗篇 16:7，34:2 (1)。*在我的一生*可以指*只要我活着*，这是显然而通常的解法；也可以指*当我从这活着的死亡之境得回生命的时候*，有些最优秀的释经者取后一义，因为他们认为此处暗指前一节的*胜于生命*；但这远不是最自然的结构。*奉你的名，*即呼求你为我敬拜的对象，尤其是我感恩赞美的对象。在祈祷中*举起我的手*，而在此处更具体地说，是在感谢中举手。参看前面，诗篇 28:3 (2)。

<span class="ax-anchor" id="psalms-63-5"></span><span class="ax-vnum">6 <span class="ax-veng">(5).</span></span> *如同*（用）*骨髓与肥油，我的魂必得饱足，*并（用）*欢呼的嘴唇，我的口必赞美*（你）。他继续抒发那满有喜乐的确信与盼望。*骨髓与肥油*是用来译出两个希伯来词的，二者都指牲畜的脂油，此处借指丰美的食物，又借食物指各样丰足的供应。*欢呼的嘴唇*既可指欢乐的嘴唇，也可指藉以发出欢呼的嘴唇。这里不附任何条件地立志要赞美神，照例含着一种坚定的信念：他必有机会如此行。参看前面诗篇 5:8（7）的注释。

<span class="ax-anchor" id="psalms-63-6"></span><span class="ax-vnum">7 <span class="ax-veng">(6).</span></span> *当我在床上记念你，在夜更中我要默想你。*希伯来原文的首字即通常译作*如果*的那个词；但它所指明的条件有时特指时间。本节似乎提到古时出于治理与军事的需要而将黑夜划分为三更：初更（耶利米哀歌 2:19）、中更（士师记 7:19）和晨更（出埃及记 14:24，撒母耳记上 11:11）。参下文诗篇 90:4 的注释。*我要默想你，*更字面地说是*在你里面*默想，意谓他的心力与情感全然沉浸于这一对象之中。参上文诗篇 1:2 的注释。

<span class="ax-anchor" id="psalms-63-7"></span><span class="ax-vnum">8 <span class="ax-veng">(7).</span></span> *因为你曾作我的帮助，我要在你翅膀的荫下欢呼。* 他已经经历过的保护，他确信在将来的日子里仍要享有。把头一个动词译作现在时（你是我的帮助），不但削弱了这一对比，也违背了一种恒常的用法。参看前面诗篇 59:17(16)、61:4(3) 的解说。末一分句所呈现的意象，与诗篇 17:8、36:8(7)、57:2(1)、61:5(4) 中的相同。

<span class="ax-anchor" id="psalms-63-8"></span><span class="ax-vnum">9 <span class="ax-veng">(8).</span></span> 我的*魂紧随你，你的右手扶持我。*这是对神与信徒之间相互关系的一个有力的比喻性描述：一面是信靠的倚赖，一面是不断的恩眷与保护。*紧随*是一个常见的说法，意思是*紧贴着你而跟随。*右手历来是能力的象征。参看上文，诗篇 18:36（35）、44:4（3）、60:6（5）的注释。

<span class="ax-anchor" id="psalms-63-9"></span><span class="ax-vnum">10 <span class="ax-veng">(9).</span></span> *而他们为着*（他们自己的）*毁灭寻索我的性命；他们必入地的深处。* *归于毁灭*这一短语的意思与诗篇 35:8 中完全相同，即归于他们自己的灭亡。*正寻索，*原文为将来时；将来时所提示的意思是：他们若仍执意寻索，便是自取灭亡。有人用另一种句法得出同样的意思：*那些*（将归）*于毁灭的*（人乃是那些）*寻索我性命的；*但这要假定两处省略，而无必要时不应作此假定。更不能令人满意的，是把全节看作一个单句的读法：*那些以毁灭为念*（或为要毁灭它）*而寻索我性命的人必往*……。寻索人的性命，即便在散文中，也无须加任何限定语便已含有置之死地的意图。见撒母耳记下 16:11。*地的深处，*字面意思是地的低处或最低处，这或许只是指坟墓（正如我们说*在地下），*或是暗指可拉一党的结局（民数记 16:31-34）。参前文诗篇 55:16（15）的注释。

<span class="ax-anchor" id="psalms-63-10"></span><span class="ax-vnum">11 <span class="ax-veng">(10).</span></span> *他们必被交于刀剑的势力之下，必作豺狼的猎物。* 前一分句的字面译法是，*他们必将他倾倒在刀剑的手上，* 这里以复数动词表达不定或被动的意思，提到仇敌时又忽而用单数忽而用复数，再加上「刀剑有手」「人被倾倒在手上」这等大胆而富于希伯来语特色的比喻，种种看似不合文法之处汇于一处，非经意译无从索解。译作*猎物*的那个词，本义是*份*或*分；*前面诗篇 11:6，16:5 已出现过。本小句中另一个名词，是希伯来文中*表示狐狸*的常用词，但用法甚宽，可以涵盖豺狼；此处当取豺狼之义，因为狐狸并不以死人为食——除非把这一分句仅仅理解为：他们必被弃置于旷野，任其横陈，而旷野正是这类野兽栖息之所。这样解也通，只是比上面所说的那层意思软弱得多。

<span class="ax-anchor" id="psalms-63-11"></span><span class="ax-vnum">12 <span class="ax-veng">(11).</span></span> *并且王必因神欢喜；*（在他里面）*凡指着他起誓的都必夸口*（或*夸耀），因为那些说谎之人的口必被封住*（或堵住）。他没有用人称代词，而是用了自己的官称，*王，即*我身为王。*因神欢喜，即*在与他的联合之中、在他恩眷的经历之中欢喜。*夸口*或*自我称赞，即*因拥有这些荣耀的尊荣与益处而自庆。*指着他起誓，即*有人以为，是指着此处所提的王起誓，按照古埃及的习俗（创世记 42:15, 16），这习俗在以色列中也留有些许痕迹（撒母耳记上 17:55，25:26，撒母耳记下 11:11）。倘若这确是正确的语法结构，我们或许可以把这句解作*向他起誓，即*宣誓效忠或归顺，以他为合法的君王而向他称臣。但事实上，并没有充分的理由背离那显而易见的结构，即把代词归于最近的先行词*神。*末句说明了此处所预言的喜乐与凯旋的直接缘由，就是虚谎奸诈的叛党之溃败。参看上文诗篇 62:5（4）的注释，并比较撒母耳记下 18:7, 8。
