<span class="ax-vnum">1.</span> *一首歌。一篇诗。归* （或*由）可拉的子孙。交与伶长。论使人受苦的疾病。一篇训诲诗。以斯拉人希幔作。* 这题注的第一个词在别处指称颂或凯旋之歌。参看前面诗篇 42:9(8)、83:1 的注释。然而它在此处却冠于全集中最为沮丧的一篇诗之前，其中的怨诉与哀叹并无任何欢欣的盼望或坚强信靠的言辞来舒解。对这些事实唯一令人满意的解释，是假定诗篇 88 篇与 89 篇原本要构成一对、或一篇双连的诗，正如第一与第二篇、第三与第四篇、第九与第十篇、第四十二与第四十三篇……。如此，诗篇 88 篇中沮丧的哀叹便不过是诗篇 89 篇中令人振奋之期待的引言。这一假定也解释了眼前这篇题注异乎寻常的长度：其前半部分可视为属于两篇诗，而末一分句则相当于诗篇 89 篇的题注。*使人受苦的疾病，*字面作*使人受苦*或*降卑的疾病。*关于疾病的比喻性用法，以及此题注的含义，参看前面诗篇 53:1 的注释。以斯拉人希幔与亚萨、以探一同被题及，为大卫在位时的首席乐师，见历代志上 6:18(33)、15:17、16:41, 42。历代志上 2:6 称希幔与以探为以斯拉人*（即*谢拉的子孙），列王纪上 5:11 又称他们以智慧著称；有人认为那是另外的人，因为他们属犹大支派，另有人则认为他们是被收纳入该支派的利未人。眼前这篇诗既不需要、也不容许任何细密或人为的分段。

<span class="ax-anchor" id="psalms-88-1"></span><span class="ax-vnum">2 <span class="ax-veng">(1).</span></span> *耶和华，拯救我的神，*（在）*白日我已呼求，也在夜间，在你面前。* 拯救我的神，即我所信靠、要救我的那位神，因他本是施行拯救的神，或作「神我的救主」。参上文，诗篇 85:5 (4)。此处 *白日与在夜间* 二者的关系，正如诗篇 77:3 (2) 中 *夜间* 与 *在白日* 的关系。*在你面前表明*，他的哀呼并非只是遭难时本能的呻吟，而是向神所发的祈求。全节可与诗篇 22:3 (2) 相比。

<!-- PAGE 375 -->
<span class="ax-anchor" id="psalms-88-2"></span><span class="ax-vnum">3 <span class="ax-veng">(2).</span></span> *愿我的祷告达到你面前；侧耳听我的呼求。*头一句祈求是愿他的祷告能引起神的注意，末句则换以另一比喻来表达，即一人俯身倾听那微弱或遥远的呼声。参看上文对诗篇 17:6、31:3（2）、71:2 的解释。

<span class="ax-anchor" id="psalms-88-3"></span><span class="ax-vnum">4 <span class="ax-veng">(3).</span></span> *因为我的魂饱尝祸患，我的生命临近坟墓。祸患，*苦难、困苦。*生命*一词在希伯来文中是复数，故可照常规与复数动词连用；但这个动词本是使役形式，所以也可以*祸患*作主语，或以泛指的人为主语，作*他们使我的生命临近坟墓。*第一种结构有诗篇 107:18 的类比可以支持。*坟墓，sheol，*即死人所居之境。参上文诗篇 6:6（5）的注释。

<span class="ax-anchor" id="psalms-88-4"></span><span class="ax-vnum">5 <span class="ax-veng">(4).</span></span> *我被算在下坑的人中；我成了*（或*已成为）一个毫无力量的人。* 第一分句可比较诗篇 28:1；143:7。*毫无力量，*字面作（他）*没有力量。*希伯来文中最后一个词仅见于此处，但诗篇 22:20(19) 有一个同源的字形。原文中有一种单凭翻译无法传达的对照，因为前面用来指*人*的那个词，本身含有强壮之意。

<span class="ax-anchor" id="psalms-88-5"></span><span class="ax-vnum">6 <span class="ax-veng">(5).</span></span> *与*（或*在）死人同列，自由，像被杀的，躺卧在坟墓里，是你不再记念的，他们也藉（或从）你的手被剪除。* 作神的仆人乃是最高的特权与尊荣（诗篇 86:16），所以脱离他的服事（约伯记 3:19）便是悲惨。此处所指的并非一般意义上的死亡，而是暴死，是作为刑罚的死。*被杀的，*字面意思是*那*（受了致命）*伤的。* 参上文诗篇 69:27(26) 的注释。本节后半含有一段强烈的诗意描写，形容恶人不再是神护佑眷顾的对象。在*从*与*藉你的手*这两种译法中，前者所传达的意思与前面的话相同，后者则把神仇敌的毁灭表现为他亲手所作的工。

<span class="ax-anchor" id="psalms-88-6"></span><span class="ax-vnum">7 <span class="ax-veng">(6).</span></span> *你将我放在深坑里，在黑暗之处，在深渊中。*深坑，字面作低处或下界之坑。参看上文诗篇 63:10（9）、86:13，并参以西结书 26:20。*黑暗之处*即那不可见的下界之处。*深渊，*即水的深处或深渊。参看上文诗篇 69:3（2）。

<span class="ax-anchor" id="psalms-88-7"></span><span class="ax-vnum">8 <span class="ax-veng">(7).</span></span> *你的忿怒重压在我身上，又*（以）*你的一切波涛压制我。细拉。*译作*波涛*的那个词，按词源对应于*碎浪*。参看前面诗篇 42:8（7）的注释。首半句可比照诗篇 38:3（2）。那个意为*压制*或*苦待*的动词，在历史叙事体的散文中用于指以色列人在埃及所受的压迫，见创世记 15:13、出埃及记 1:12。同一动词的不定式出现在本篇诗的题注中。*细拉*表明他愁苦之深，也表明在重新接续这番描述之前必须有一停顿。

<span class="ax-anchor" id="psalms-88-8"></span><span class="ax-vnum">9 <span class="ax-veng">(8).</span></span> *你使我的熟人远离我；你使我成为他们所憎恶的；*（我是）*被关闭，不能出来*。前一分句所诉的苦，常被提及作为患难之加重。参看前面诗篇 31:12（11）、38:12（11）、69:9（8）的解说，并比较诗篇 27:10。下一分句表明他所诉的不止是被人冷落而已。*使我成为，*字面是*置我*或*放我*。参看前面诗篇 39:9（8）的解说。这里或许暗指历史中的记载：以色列人在埃及的主人眼中乃是可憎的，是宗教上厌恶憎恨的对象。见创世记 43:32，46:34。末一分句，有人理解为：我被无法摆脱的困境所围困。比较耶利米哀歌 3:7，约伯记 3:23。另一些人把它与前文相连，这更为可能，其意是说，他不愿使自己暴露在这种无端的憎恨与轻蔑之下。见约伯记 31:34，并比较诗篇 44:14（13），80:7（6）。

<!-- PAGE 376 -->
<span class="ax-anchor" id="psalms-88-9"></span><span class="ax-vnum">10 <span class="ax-veng">(9).</span></span> .*我的眼因苦难而衰残；我天天求告你，耶和华啊；我向你伸开我的双手。* 上半节可比较诗篇 6:8（7）、31:10（9）、38:11（10）、69:4（3）。末句可比较诗篇 44:21（20）。希伯来文第一个动词是极罕见的词；摩西在申命记 28:65 用了由此字根派生的一个名词。这些过去时表明，所受的苦并非新近之事，而是长久以来一直如此。

<span class="ax-anchor" id="psalms-88-10"></span><span class="ax-vnum">11 <span class="ax-veng">(10).</span></span> *你要向死人行奇事吗，或者阴魂会起来* （并）*称谢你吗？细拉。* 其中隐含的论据是：今生才是领受那些属乎今生之恩惠的合宜时候。见前文诗篇 6:6（5）节的注释。末句中的 *利乏音，* 本是迦南一支巨人族 *的* 名称，诗体中则用以指死人那些巨大的阴影或鬼魂。见我在以赛亚书 14:9 的注释。*行奇事，* 字面作 *奇事，* 与诗篇 77:12（11）同。

<span class="ax-anchor" id="psalms-88-11"></span><span class="ax-vnum">12 <span class="ax-veng">(11).</span></span> *你的慈爱岂在坟墓中被述说，你的信实（岂在）灭亡之地？* 末了那个词（Abaddon，亚巴顿）在别处也与坟墓、死亡连用，作为诗体中的同义之词。参箴言 15:11，约伯记 26:6，28:22。

<span class="ax-anchor" id="psalms-88-12"></span><span class="ax-vnum">13 <span class="ax-veng">(12).</span></span> *你的奇事岂能在黑暗中被知晓，你的公义岂能在遗忘之地被知晓？* 这些是对死亡状态的种种比喻性描述，都从消极的一面着眼，视之为生命的剥夺或生命的反面。此处的*黑暗*与*生命之光*或*活人之光，*相对，诗篇 56:14（13）。遗忘之地，即人在其中遗忘（传道书 9:5, 6, 10），又被人遗忘（诗篇 31:13〔12〕）之地。

<span class="ax-anchor" id="psalms-88-13"></span><span class="ax-vnum">14 <span class="ax-veng">(13).</span></span> *而我，耶和华啊，向你呼求，清晨我的祷告必来到你面前。* 他从前所行的，如今仍决意去行，因为这是得救的唯一途径。故有过去时与将来时的交替。首个动词的意思是呼求帮助。参看上文，诗篇 18:42 (41)。末句可比较诗篇 5:4 (3)、57:9 (8)、59:17 (16)。该动词在此取其本义，即来到某人面前或进到他的面前。参看上文，诗篇 17:13，18:6 (5)，21:4 (3)。

<span class="ax-anchor" id="psalms-88-14"></span><span class="ax-vnum">15 <span class="ax-veng">(14).</span></span> *耶和华啊，你为何丢弃我的灵魂，为何向我掩面？*前一动词的意思是厌恶地弃绝。参看前文诗篇 43:2，44:10, 24（9, 23），60:3, 12（1, 10），74:1，77:8（7）。这一发问含有这样的意思：如此的弃绝与神的信实不相符，因此它并非全然绝望的流露。

<span class="ax-anchor" id="psalms-88-15"></span><span class="ax-vnum">16 <span class="ax-veng">(15).</span></span> *困苦*（的是）*我，自幼便气息奄奄；我担受你的惊恐；我绝望了。* 气息奄奄，濒于消亡，命在旦夕，是对极度苦境的有力描绘。这*幼年*可以指受苦者个人的幼年，也可以指以色列作为一个民族的幼年（何西阿书 11:1）。两种应用或许都是作者的本意。

<span class="ax-anchor" id="psalms-88-16"></span><span class="ax-vnum">17 <span class="ax-veng">(16).</span></span> *你的烈怒从我身上漫过；你的惊吓毁灭了我。*前半句的意象与诗篇 42:8（7）相同。*烈怒，*字面意思是灼热或焚烧，但一向用于指忿怒。其复数形式仅见于此处。末一动词的罕见形式，有人认为是作者自造的，为要影射利未记 25:23。

<!-- PAGE 377 -->
<span class="ax-anchor" id="psalms-88-17"></span><span class="ax-vnum">18 <span class="ax-veng">(17).</span></span> *它们终日如水围绕我；它们一齐环绕我*（或作 *一同）。* 洪涛淹没的比喻在此仍延续着。这两个动词的主语只能是第 17（16）节所说的忿怒与惊恐。

<span class="ax-anchor" id="psalms-88-18"></span><span class="ax-vnum">19 <span class="ax-veng">(18).</span></span> *你使良朋密友远离我；我的熟识者*（乃是）*黑暗*（或作：幽暗之处）。前半句是第 9（8）节的重复。后半句晦涩难解，有人以为意思是：我的熟识者消逝了，隐没在黑暗之中；另有人以为是：我的熟识者让位于黑暗，由黑暗接替了他们；如今我唯一的朋友就是那幽暗之处，*即*坟墓或死亡。若照此理解，这里所表达的情致与约伯记 17:14 颇为相近。
