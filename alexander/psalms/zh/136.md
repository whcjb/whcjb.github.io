本篇在主题与结构上与前一篇相近，而若干措辞上的巧合更使这种相似格外显眼。此处同样是邀请百姓赞美耶和华，第 1-3 节；因他是自然界的神，第 4-9 节；是以色列出埃及的拯救者，第 10-15 节；是他们在旷野中的引导者，第 16 节；是仇敌的征服者，第 17-24 节；是万有的供养者，第 25 节；是天上的神——结尾再次宣告赞美当归于他，第 26 节。本篇在形式上有一个宏伟而独特之处，为其余诸篇所无，就是每一节的末尾都规则地重现一句叠唱或*副歌，*有如连祷中的应答，却贯彻得更为整齐划一。这构成每节第二分句的本文或主题，前此已屡次出现，见诗篇 106:1，107:1，118:1-4, 29。参历代志上 17:34。释经者们素来喜欢认为，这类重复必定意味着有轮唱或应答的两班歌班。但诗篇中其余可证此种作法的迹象都极为可疑；只需设想歌唱者有时自问自答，有时如本篇这样由会众齐声接唱那叠句或合唱，一如他们惯常同声说「阿们」，解经上的一切条件便都得以满足。参上文对诗篇 106:48 的注释。

<span class="ax-anchor" id="psalms-136-1"></span><span class="ax-vnum">1.</span> *你们要称谢耶和华——因为他的慈爱存到永远。*这句开场白与前面已从诗篇 106、107、118 篇引用的那几句完全相同。

<span class="ax-anchor" id="psalms-136-2"></span><span class="ax-vnum">2.</span> *称谢那万神之神——因为直到永远*（是）*他的慈爱。*本节与下节中的这一神圣称号或描述，皆借自申命记 10:17。*神*（gods）在此并非指假神，而是一个最高级的复数，用以修饰其前之词。参看上文诗篇 77:14 (13)、135:5 的注释。

<!-- PAGE 540 -->
<span class="ax-anchor" id="psalms-136-3"></span><span class="ax-vnum">3.</span> *称谢万主之主*——*因为直到永远*（是）*他的慈爱。* *万主之主，即*至高之主，卓然超绝的主，正如英文中以 *heart of hearts*（心中之心）指最深处的心。

<span class="ax-anchor" id="psalms-136-4"></span><span class="ax-vnum">4.</span> *归与*（他）*那行奇妙*（事）*的、大*（事）*的、独自*——*因为直到永远*（是）*他的慈爱。*　试比较 出埃及记 15:11 中*行奇事*的说法。*独自*，不仅是过于众人，而是把众人都排除在外。本节及以下各节中的*因为*，所指的并非紧接在前的话，而是要在句首补出的动词*称谢*。

<span class="ax-anchor" id="psalms-136-5"></span><span class="ax-vnum">5.</span> *向那用智慧造诸天的*——*因为直到永远*（是）*他的慈爱。那造的，* 字面作 *正造着，* 或许是指神创造之能的持续施行。*用智慧，* 或作带着 *聪明。* 见上文诗篇 104:24 的注释，并参箴言 3:19。

<span class="ax-anchor" id="psalms-136-6"></span><span class="ax-vnum">6.</span> *那将地铺在水上的*——*因为直到永远*（是）*他的慈爱。那铺开，*字面作*正在铺开，*与第 5 节相同。*在……上面*（不是贴在其上，而是高过）*众水。*参上文诗篇 24:2 的注释。

<span class="ax-anchor" id="psalms-136-7"></span><span class="ax-vnum">7.</span> *称谢那造大光的*——*因为直到永远*（是）*他的慈爱。*复数的 *lights*（光体，אורים）仅见于此处，但与创世记 1:14, 16 所用的那个词同源同义。

<span class="ax-anchor" id="psalms-136-8"></span><span class="ax-vnum">8.</span> *太阳管理白昼*——*因为直到永远*（是）*他的慈爱。*此诗的音乐性构思，在副歌插入同一句子不可分割的两部分之间时尤为明显，本节即是如此；其内容取自创世记 1:16，但措辞与结构都略有更动。

<span class="ax-anchor" id="psalms-136-9"></span><span class="ax-vnum">9.</span> *月亮和星宿管辖黑夜*——*因为直到永远*（是）*他的慈爱。管辖，*字面作*诸般管辖*或*诸般权柄，*或许是因为此处星宿与月亮同分黑夜的管辖之权。

<span class="ax-anchor" id="psalms-136-10"></span><span class="ax-vnum">10.</span> *那击打埃及，在他们长子身上的*——*因为他的慈爱直到永远。*这里是从自然转到历史，正如诗篇 135:8。*那击打*（或*那击打者*）*埃及，即*埃及人。故用复数代词，*他们的长子。*

<span class="ax-anchor" id="psalms-136-11"></span><span class="ax-vnum">11.</span> *又领以色列从他们中间出来*——*因为直到永远*（是）*他的慈爱。*这里我们头一次遇见一个限定式的时态（将来时的连续式），它打断了那一长串分词，而那些分词都与所省略的*耶和华*相呼应。

<span class="ax-anchor" id="psalms-136-12"></span><span class="ax-vnum">12.</span> *用大能的手和伸出来的膀臂*——*因他的慈爱存到永远。* 这些都是摩西所惯用的比喻，用以表明能力之积极而有力的施行。参出埃及记 3:19，6:1, 6，13:9，15:12，申命记 4:34，5:15，7:19，11:2，26:8。

<span class="ax-anchor" id="psalms-136-13"></span><span class="ax-vnum">13.</span> *那将红海分成几分的*—*因为直到永远*（是）*他的慈爱。分*与*分*二词彼此的关系，正如希伯来文的动词与名词之间的关系。

<span class="ax-anchor" id="psalms-136-14"></span><span class="ax-vnum">14.</span> *又使以色列从其中经过*——*因为直到永远*（是）*他的慈爱。*此处我们又见一个有限式时态，不是像第 11 节那样的连续将来时，而是过去时。*从其中经过，*即从它被分开的两部分中间经过。有人以为这是暗指创世记 15:17 的立约之事，那里译作*分开的块子*一词，正是上文第 13 节所用的那个词。

<span class="ax-anchor" id="psalms-136-15"></span><span class="ax-vnum">15.</span> *又将法老和他的军兵抖落在红海中*——*因为直到永远*（是）*他的慈爱。*前一个动词严格说来意为*抖落*或*摇落*，取自出埃及记 14:27。其被动形式见于上文诗篇 109:23。

<!-- PAGE 541 -->
<span class="ax-anchor" id="psalms-136-16"></span><span class="ax-vnum">16.</span> *那引领他百姓经过旷野的——因为他的慈爱直到永远。* *引领，*字面作"使之行走"。参看上文诗篇 125:5。此处重又接续分词的结构。

<span class="ax-anchor" id="psalms-136-17"></span><span class="ax-vnum">17.</span> *那击杀大君王的*——*因为直到永远*（是）*他的慈爱。*试比较平行的经文，诗篇 135:10，此处被主题句或副歌隔开。参见上文第 8 节。

<span class="ax-anchor" id="psalms-136-18"></span><span class="ax-vnum">18.</span> *又击杀有力的王—因为直到永远*（是）*他的慈爱。*前一分句与诗篇 135:10 的后半相应，只是把其中表示*有力的*的那个希伯来词换成了另一个词。

<span class="ax-anchor" id="psalms-136-19"></span><span class="ax-vnum">19.</span> *亚摩利王西宏*——*因为直到永远*（是）*他的慈爱。* 字面作 *归于、为了，*或 *至于*西宏，……。参看上文，诗篇 135:11。

<span class="ax-anchor" id="psalms-136-20"></span><span class="ax-vnum">20.</span> *又有巴珊王噩——因为直到永远* （是）*他的慈爱。* 意即「给，为，或论到巴珊王噩」。

<span class="ax-anchor" id="psalms-136-21"></span><span class="ax-vnum">21.</span> *又将他们的地赐为产业——因为直到永远* （是）*他的慈爱。赐为产业，*字面作为产业。参上文，诗篇 135:12。

<span class="ax-anchor" id="psalms-136-22"></span><span class="ax-vnum">22.</span> *作为产业赐给他仆人以色列*——*因为直到永远*（是）*他的慈爱。*这是诗篇 135:12 的后半句，与前半句之间被这主题句或叠唱所隔开。

<span class="ax-anchor" id="psalms-136-23"></span><span class="ax-vnum">23.</span> *谁在我们卑微之时记念我们——因为直到永远* （是）*他的慈爱。* 在我们卑微之时，即在我们的屈辱中，在我们被降卑、被贬抑之时。记念我们，或为我们记念，为我们的益处，如诗篇 132:1。由诗篇 107:16, 18, 26 与 115:12 的类比，我们得知此处所指乃是巴比伦的被掳，那也正是下一篇诗的主题。

<span class="ax-anchor" id="psalms-136-24"></span><span class="ax-vnum">24.</span> *又从我们的敌人手中把我们夺出*——*因为直到永远，*（是）*他的慈爱。*头一个动词向来表示强暴的动作。参看上文诗篇 7:3 (2) 的注释。此处意为夺出或扯离，如耶利米哀歌 5:8，所指的是那场大变局，巴比伦的权势藉此被打破，犹太人得以获释。

<span class="ax-anchor" id="psalms-136-25"></span><span class="ax-vnum">25.</span> *赐粮食给凡有血气的——因为直到永远*（是）*他的慈爱。* 此处的描述忽然从神向他百姓所施的怜悯之举，转到他向一切有生之物普遍的恩惠，或许意在暗示：他既这样顾念普世的人，甚至顾念低等的生物，就必不肯、也不能任凭他的百姓灭亡。参马太福音 6:30。

<span class="ax-anchor" id="psalms-136-26"></span><span class="ax-vnum">26.</span> *要称谢天上的神，因为他的慈爱直到永远。* 天上的神在形式上是一个新的称谓，但实质上与诗篇 7:8（7）、11:4、14:2、33:13, 14 中的说法相当。
