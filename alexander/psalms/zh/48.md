<span class="ax-vnum">1.</span> *一篇诗。一首歌。归可拉的子孙。* 泛称的*诗*（mizmôr）一词，因加上*歌*（shîr）而变得更为确切，后者通常指颂赞之歌。参看上文诗篇 42:9 (8) 的注释。诗题further又说它是（属）*可拉的子孙*的，或指他们为作者，或指为歌咏者。参看上文诗篇 42:1 的注释。本篇颂扬耶和华，并颂扬作他居所的耶路撒冷，第 2-4 (1-3) 节；其中特别提到新近从几位结盟的君王手中得蒙拯救，第 5-9 (4-8) 节；这拯救被认定为永远称颂的题目，第 10-15 (9-14) 节。关于本篇的历史背景，最可能的推测是：它所指的，正是前一篇所纪念的那同一件事。这推测尤其可信，因为我们从历代志下 20:19, 27 得知，约沙法和跟随他的人先是在战场上或战场附近为所得的拯救赞美神，回到耶路撒冷之后，又在殿中再度赞美。本篇大概就是为后一次而写的。

<!-- PAGE 222 -->
<span class="ax-anchor" id="psalms-48-1"></span><span class="ax-vnum">2 <span class="ax-veng">(1).</span></span> *大哉*（是）*耶和华，极当受赞美，在我们神的城中，在他的圣山上。*本节提出全篇的主题，即耶和华向他自己的子民所显明的荣耀。*当受赞美：*见上文，诗篇 18:4（3）。英文圣经中*great and greatly to be praised*（大而极当受赞美）的谐音双关，原文中并不存在；英文圣经译作*great*（大）与*greatly*（极）的那两个词，在字形与字源上全然不同。*我们神的城：*见上文，诗篇 46:5（4）。与之平行的说法，*他圣洁的山、他的圣洁之山、他的圣山，*意在传达同一观念：此处所指的，广言之是耶路撒冷，狭言之是锡安，乃神权政体的所在，是神居于他特选子民中间、作他们的王与护佑之神的地方，因此在那里赞美他的本分也就格外当尽。

<span class="ax-anchor" id="psalms-48-2"></span><span class="ax-vnum">3 <span class="ax-veng">(2).</span></span> *美在高耸，全地的喜乐，锡安山，*（在）*北面的尽边，大君王的城。*通行译本作*坐落之地，*虽非错误，却过于笼统。此处所指的是耶路撒冷那崇高的地势，从四围的乡野望去所见的样子。称它为全地的喜乐，是因它乃万国属灵福分的源头。*北面的尽边*或指城的北部，与位于南部的锡安并举，以表全城。或者，因此处译作*尽边*的那个词素来指极远的边际或疆界，这里便可用来描绘圣城在从南方凯旋归来的大军眼前渐次升起时的景象。这两种解释，无论哪一种，都比近人的解法自然：那种解法设想此处影射异教观念中极北之处有一座众神居住的山，并以为以赛亚书 13:14 也提到这一信念。

<span class="ax-anchor" id="psalms-48-3"></span><span class="ax-vnum">4 <span class="ax-veng">(3).</span></span> *神在她的宫殿中显为避难所。* 在这一处他所拣选的居所里，他早已将自己显明为他百姓的保护者。参下文诗篇 76:2 (1)。

<span class="ax-anchor" id="psalms-48-4"></span><span class="ax-vnum">5 <span class="ax-veng">(4).</span></span> *因为看哪，列王聚集*——*他们一同过去了。* 他们刚一聚拢，便一同消失了。*看哪*或*瞧啊，*一如往常，指示某种出人意料之事。这确指的说法，*列王，*似乎是指近来发生而众所周知的事。原本所指的列王乃是摩押与以东的诸王。译作*聚集*的那个词意思是按约定或协议而会合，此处含有结盟敌对犹大之意。参诗篇 83:4-6（3-5）。*过去了，*即逃遁或消失。

<span class="ax-anchor" id="psalms-48-5"></span><span class="ax-vnum">6 <span class="ax-veng">(5).</span></span> （正如）*他们看见，就这样惊奇，被恐惧击打，被逼逃窜。*本节解明前一节所说他们*经过*的意思。与第 9 (8) 节所明言的*这样*相应的那个*正如*，此处似被省略，正如以赛亚书 55:9 一样。*他们一看见*这圣城，或是神保护的凭据。末二动词皆为被动。第一个动词的意义，见上文诗篇 2:5 的解释；第二个的意义，见诗篇 31:23 (22)。全节所描写的，是一场导致溃散或逃窜的惊惶。

<span class="ax-anchor" id="psalms-48-6"></span><span class="ax-vnum">7 <span class="ax-veng">(6).</span></span> *战兢在那里抓住他们，疼痛如临产的*（妇人）。那里，*即*在他们所预期得胜的那一处地方。参看上文，诗篇 14:5。或指他们初次望见耶路撒冷的那一处。此处或即提哥亚（历代志下 20:20），其地势高耸，远近尽收眼底。参罗宾逊（Robinson）《巴勒斯坦》第二卷 182 页。末句的比喻在圣经中屡见不鲜，用以表明剧烈却短暂的疼痛。比较以赛亚书 13:8, 21:3, 42:14。

<!-- PAGE 223 -->
<span class="ax-anchor" id="psalms-48-7"></span><span class="ax-vnum">8 <span class="ax-veng">(7).</span></span> *你必用东风打破他施的船只。* 这样的灾祸确曾临到约沙法自己的船队，实为一桩耐人寻味的巧合。参列王纪上 22:49（48）、历代志下 20:36, 37。有人以为此处所指的正是这一件事，另有人则把它理解为对神掌管一切低等受造媒介之主权的比喻性描写。提到东风，似乎因为它在邻近诸海中最为可畏。与他施、俄斐的贸易，几乎是当时希伯来人所知的唯一海上通商。参历代志下 9:21，并比较以赛亚书 2:16，23:1, 14；60:9。

<span class="ax-anchor" id="psalms-48-8"></span><span class="ax-vnum">9 <span class="ax-veng">(8).</span></span> *我们所听见的，我们也照样看见了，在万军之耶和华的城中，在我们神的城中。神必坚立它，直到永远。细拉。*他们从前只是听说发生在别处或古时的事，如今亲眼得见了。参看上文诗篇 44:2（1），并比较约伯记 42:5。*万军之耶和华；*见上文诗篇 24:10。*神必坚立它，*或*立定她，即*耶路撒冷，我们神的城。他必保守这城，不再受它刚刚脱离的那类攻击。既然此处的耶路撒冷不是被看作一座寻常的城邑，而是神治政体的所在、神在地上的居所，那么这应许就其最强的意义而言，对教会仍然有效——古时的锡安正是教会受命定的预表与地上的中心。

<span class="ax-anchor" id="psalms-48-9"></span><span class="ax-vnum">10 <span class="ax-veng">(9).</span></span> *我们曾思想，神啊，你在你殿中的慈爱。*本节中的动词有时意为*默想，*但几乎从不——若曾有过的话——脱离其「使相似」或「相比」的本义。此处或可指他们把所见与先前所闻两相比较的举动，正如前一节所言。*在……中间*的（*即*在……之内）*你的殿，*字面为*你的宫殿，*此词既用于会幕，也用于圣殿，指耶和华的王宫。参看前面诗篇 5:8（7）、11:4、18:7（6）、27:4、29:9 的注释。此语与下述设想甚为相合：本诗原是预备在军队凯旋之后于殿中咏唱的。参历代志下 20:27。

<span class="ax-anchor" id="psalms-48-10"></span><span class="ax-vnum">11 <span class="ax-veng">(10).</span></span> *神啊，你的名怎样，你的颂赞也怎样，直到地极；*（）*公义充满你的右手。* 前一分句最明显的意思似乎是：凡神被认识之处，他就被颂赞。然而有些人以*名*指神本性先前的彰显，而*以颂赞*指他最近为他百姓所行的干预应得的荣耀。这样，其意思仍与第 9（8）节相同，即当时的以色列人从前所听见的神奇妙作为，如今已在自己的经历中亲眼看见、亲身体会。*直到地极，*字面作*在*其上或*越过*其上，这或许是一种诗意的夸张，形容这些事的名声已越过地的边界。参看下文第 15（14）节。*公义，*即神的公义，显明在他仇敌的毁灭与他百姓的拯救上。参看上文诗篇 35:28。这公义被说成充满他的右手，*即*在他全能的施展中丰丰富富地显明出来。参看上文诗篇 16:11。

<span class="ax-anchor" id="psalms-48-11"></span><span class="ax-vnum">12 <span class="ax-veng">(11).</span></span> *欢乐吧锡安山，欢腾吧犹大的众女儿，因你的审判。*按一种极其古老的用法——这用法甚至出现在专门地理学的散文记述中（约书亚记 15:45, 47）——*犹大的众女儿*可以指隶属于耶路撒冷的那些小城邑。较为明显的意思则是指女性居民；她们作为较软弱的一性，对于国家从野蛮入侵者手中得蒙拯救，格外有理由欢喜。这两个动词可以理解为表达愿望或祈求（*愿锡安山欢乐，*……）。但照本来的将来时意思来讲，更合乎紧接在前的内容：前面既已宣告，神的大能与信实这一番显明已经使荣耀归与他的名，接下去便宣告这同样的果效还要继续下去。*为着*（或*因着）你的审判，*就是你的公义藉着实际施行所提供的那些可凭经验验证的明证。

<!-- PAGE 224 -->
<span class="ax-anchor" id="psalms-48-12"></span><span class="ax-vnum">13 <span class="ax-veng">(12).</span></span> *环绕锡安，周行其四围；数点她的城楼。*前一分句中的两个动词意为*绕行*（或*环走*）。在攻取耶利哥的记载中，这两个词曾两次连用（约书亚记 6:3, 11）。后一个词见于前面诗篇 17:9 及 22:17（16）。此处所提议的行走，其目的是察看她防御工事的完好情形，看它们何等未受近日危难的触动。参以赛亚书 33:20。*数点她的城楼，*看是否有哪一座已被拆毁。

<span class="ax-anchor" id="psalms-48-13"></span><span class="ax-vnum">14 <span class="ax-veng">(13).</span></span> *你们要留心她的城垣，细察她的宫殿，好叫你们述说*（这事）*给后来的一代。* 头一句的意思是，*用你们的心，*即留意、细细察看。译作*城垣*的那个词，似乎是指外围的环城工事，此处与它所环绕的*宫殿*相对而言。*述说这事，即*你们察看所得的结果，或防御工事的完好无损；这既是对这一次特定拯救的记念，又是教会在神的保护之下所享安稳的预表或象征，因此配得永远被记念。希伯来文的末一个词不是分词，而是形容词，严格说来意为*较后的*或*后来的，*即随后的、将来的。

<span class="ax-anchor" id="psalms-48-14"></span><span class="ax-vnum">15 <span class="ax-veng">(14).</span></span> *因为这位神*（是）*我们的神，直到永永远远；他必引导我们，直到死亡。*这里的「因为」说明何以要把这事当作应当记念的事，即因为它是耶和华恩眷的一个凭据，而他乃是我们永久的保障。整句也可以合成一句读，不必在前半句补出*是*：*因为这位神，我们的神，直到永永远远，他必引导*……。或者，更合乎代词（זֶה）通常的用法，可读作*这位就是我们的神，直到永永远远，即*，行了这事的那一位，现在是、将来也仍是我们的神。按另一种更常见的读法，*这位神*指的是行了这些奇事的神。*直到永永远远，*字面作*永世与长久。*参上文，诗篇 9:6（5）、10:16、21:5（4）、45:7（6）。*直到死亡，*有人解作*在死的时候，即*他必救我们脱离死；另有人解作*越过死亡，*即在死之外。但最浅明、也最合乎用法的解释，是把这话理解为直到生命的终点，或说只要我们活着。来生的观念虽未明说，却并未被排除在外。参上文，诗篇 17:15。
