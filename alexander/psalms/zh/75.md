<span class="ax-vnum">1.</span> *交与伶长。亚勒·他施黑。亚萨的诗。一首歌*（赞美的）。见前，诗篇 68:1 的注释。本篇中，古时的教会表达了一种确信的期望：神必施以援手，使之脱离某一强大敌国势力的辖制，而那势力的覆亡在此被预先宣告。其直接的历史缘由，我们没有可直接凭据的手段加以断定；但就本篇自身看来最为切合的，乃是希西家年间亚述大军的覆灭。见前，诗篇 46:1 的注释，并见后，诗篇 76:1 的注释，又参以赛亚书 36 章与 37 章。本篇所指乃是一个危难迫近、非比寻常的时期，这一点又由 *亚勒·他施黑，*或曰 *不要毁坏,*这一语加以表明。见前，诗篇 57:1 的注释。

<span class="ax-anchor" id="psalms-75-1"></span><span class="ax-vnum">2 <span class="ax-veng">(1).</span></span> *我们称谢你，神啊，我们称谢；并且*（近了）*是你的名；他们述说你的奇事。* 这称谢是对某一重大事件的预先感恩，含着对其必然发生的坚强信心。*你的名近了，*意即你属性的显著彰显已在眼前，以致人已经开始述说你的奇妙作为，如同已经成就了一般。或者，这也可以指他们述说神从前向他们所行的事，作为盼望同样甚至更大之事将要来到的根据。末句另有一种结构，或许更为自然，即英文圣经所采的译法：*你的名近了，你的奇妙作为宣告出来。* 至于希伯来文中末一词的意义与用法，参看上文，诗篇 9:2 (1)、26:7、40:6 (5)、71:17 的注释。

<span class="ax-anchor" id="psalms-75-2"></span><span class="ax-vnum">3 <span class="ax-veng">(2).</span></span> *因为我必选定所定的时候；我必按公正施行审判。*如今最好的释经者都主张将这些话解作神自己的话，其中所含的应许，正是前一节所表达之盼望的根据。*选定*一词因而兼含「拣选」与「为所定之目的而使用」这两重意思。译作*所定的时候*的那个词，与诗篇 74:4, 8 中意为*会众*的是同一个词。即使在那里也已含有「所定之期」的意思，在此处则成了主要的意思。该词的同一用法见于诗篇 102:14（13）、哈巴谷书 2:3、但以理书 8:19，11:27, 35。此处显然暗指公开施行审判的那些定期。参使徒行传 19:38。就如同他说：我要定一个时候，到了那时候，我必登上审判之座。受审的一方乃是神百姓的仇敌与欺压者。那代词是着重的：是我，而非别人，要作审判者。参前面诗篇 50:6 的注释。*按公正，*字面作*诸般公平*或*诸般正直。*参前面诗篇 17:2，58:2（1）的注释。以复数作抽象名词的用法，以及名词作副词用的用法，都是希伯来文惯见的惯用语。恶人在神的审判台前受审，意味着他们被定罪，并且作为必然的结果，就是他们所欺压、所损害之人得蒙拯救。

<span class="ax-anchor" id="psalms-75-3"></span><span class="ax-vnum">4 <span class="ax-veng">(3).</span></span> *消融了，*（乃是）*地和一切住在其上的；我称过它的柱子。细拉。*因惧怕而消融、衰弱无力，或归于乌有。参看上文，诗篇 46:7(6)。末一分句的比喻含义晦暗。称量这一动作，或许意在暗示举起、托住。参以赛亚书 40:12, 18, 16。然而也有人以为，它的意思是量度、估定或估价，所含的不只是全备的知识，还有创造的能力。作为上一节所起首的应许或安慰性保证的一部分，本节必定是说：神自己要阻止或纠正他仇敌所造成、所威胁的祸患。

<span class="ax-anchor" id="psalms-75-4"></span><span class="ax-vnum">5 <span class="ax-veng">(4).</span></span> *我对夸口的人说，不要夸口，对恶人说，不要高举角！* 有些人把这些话看作诗人的话，是他再度以教会的身份发言。这样，其意便是：神的子民既因神应许保护拯救而得着鼓励，就警告他们的仇敌不可夸胜。然而，把这些话解作神自己话语的延续，似乎更为自然，因为他向自己子民所作的保护之保证，实际上正是对他仇敌的毁灭之警告。有人反对说，若是如此，下文就必须归于同一位说话者；这反对分量甚轻，因为在结构带有戏剧性的诗篇中，由一个说话者转到另一个说话者，通常并无显著的标记，往往是全然不着痕迹的。末了的比喻取自有角之兽的习性，与人高昂其头以示骄傲的举动几乎相当。关于这一比喻的另一种用法，见上文诗篇 18:3(2) 的注释。

<span class="ax-anchor" id="psalms-75-5"></span><span class="ax-vnum">6 <span class="ax-veng">(5).</span></span> *不要高举你们的角，*（并）*用骄傲的颈项说话，*或作*伸着*（伸长的）*颈项骄傲地说话。*末一个词是形容词，意为无礼的或狂傲的。参看前面诗篇 31:19（18）。它或是与*颈项*一致，指颈项的姿态与举止显出骄傲（诗篇 73:6），或是作动词的宾语，这样一来*用颈项*便可指*用*伸长或延展的颈项，不是向前突出，而是向后仰起。参以赛亚书 3:16，并比较希伯来原文的约伯记 15:26。类似的省略，见下文诗篇 77:16（15）。

<span class="ax-anchor" id="psalms-75-6"></span><span class="ax-vnum">7 <span class="ax-veng">(6).</span></span> *因为不是从东，也*（不是）*从西，也不是从山的旷野，*这对这些罪人的审判要临到，而是从一个截然不同的方位而来。译作*东*的那个词本义是*日出*，或更准确地说是日头出来之处；与之平行的词则是*日落*，即傍晚之处。第三个方位由*旷野*来表示，即位于巴勒斯坦以南的阿拉伯大沙漠。希伯来文的末一个词（הרים）容许两种全然不同的解释。其一，即英文圣经所采用的，视之为第 5, 6 节（4, 5）中译作*举起*的那个动词的不定式，设想它指举起的动作，或高升的状态。如此，意思便是：提拔不是从地上任何方位而来，乃单单从神而来。另一些人则反对说，此处所论的并非提拔，而是审判，这从前后文都可看出。因此他们随从古代诸译本，把（הָרִים）看作希伯来文常用的*冈*或*山*一词的复数，并解释整个短语的意思为*多山的旷野*或*山的旷野*，这一描述极其适合以东与石头阿拉伯。其根本的意念仍是*南方*，在此加于*东*与*西*之上，作为对巴勒斯坦周边各国的一个总括的描述。南方被列在最后，或许是为着着重提及埃及，因为亚述人以为犹太人特别倚靠这一外邦势力。参以赛亚书 36:4-6。略去*北方*，或是出于偶然，或（如有些人所设想的）是有意暗示：敌人入侵正是从这一方位而来；事实也正是如此，连从极东而来的侵略者，通常也是从这一面进入该地。于是全节的意思便是：从一个方位临头的危险，断不能靠别处单凭人的援助来挡开，惟有藉着下一节所提到的方法才能。

<span class="ax-anchor" id="psalms-75-7"></span><span class="ax-vnum">8 <span class="ax-veng">(7).</span></span> *因为神*（是）*审判者（或正在施行审判）；这*（一个）*他要降卑，而这*（一个）*他要升高。开头的「因为」*引出前一节否定陈述的理由。不是人，*因为*乃是神，才能成就此事。在我们的惯用语中，两句之间的这种关系通常用*但*来表达。审判的行动，或审判者的职分，在此含有绝对主权之意。*这个和这个*是希伯来文的惯用语，相当于英文的*一个和另一个*。见上文诗篇 20:8（7）的注释。

<span class="ax-anchor" id="psalms-75-8"></span><span class="ax-vnum">9 <span class="ax-veng">(8).</span></span> *因为有杯*（在）*耶和华手中，酒正发酵，且满了搀杂之物，他从这*（杯）*中倒出；惟有其渣滓，他们必拧*（或*吸）出来，他们必喝尽*——*地上一切的恶人*（或*国中的恶人）。*这是圣经中表明神忿怒的常见比喻，见上文诗篇 11:6 的解释。杯中所盛的，是分派给那受罚之罪人的定量。*发酵*或*已经发酵了，*意在表明这是真正的酒，是烈酒。*它是红的*这一译法，如今被认为所依据的字源可疑。有些解经者把这句解作*它因酒而起沫；*但这种结构不但本身不够简明，而且赋予该动词一种并非全为惯用法所认可的意思，又须把名词（כּוֹס）*杯*——它在别处皆为阴性——当作阳性来解。*它*（指酒）*充满了搀杂之物，即*搀了香料，以增强其烈性与刺激之力。*惟有其渣滓*乃是希伯来文的一个惯用语，并不像英文中看来那样，意谓他们只喝渣滓而已。其意毋宁是说：他们别无所余，别无生路，别无选择，只能把这杯饮至涓滴不剩，*即*把神的忿怒受到极处（帖撒罗尼迦前书 2:16）。句子的主语被置于末尾，使语气更加着重。见上文诗篇 40:15（14）的解释。

<span class="ax-anchor" id="psalms-75-9"></span><span class="ax-vnum">10 <span class="ax-veng">(9).</span></span> *我却要永远宣告，我要歌颂雅各的神。*这里着重的代词把他与*地上的恶人*或*这地的*恶人对立起来。「当他们如此被除灭时，我却要宣告，」云云。前半句中动词的宾语由后半句определ定：由后半句所决定。*歌颂，*即奏乐，作为颂扬神之荣耀的一种方式。参看前面诗篇 9:12（11）、30:5（4）、47:7（6）、66:4 的注释。*雅各的神，*即那位藉着成就古时向以色列所立的应许、证明自己确是如此的神。此处以诗意的笔法，用这位先祖的本名代替了他作为民族奠基者时本该用的那个名字。参看前面诗篇 24:6 的注释。

<span class="ax-anchor" id="psalms-75-10"></span><span class="ax-vnum">11 <span class="ax-veng">(10).</span></span> *并且恶人（们）的一切角我都要砍断；义人的角必被高举。*第 5, 6（4, 5）节中用来表示恶人自高的那同一个名词与动词，这里却用于褒义，表示神恩慈地高举义人。参马太福音 23:12，路加福音 14:11，18:14。在上半节中，除了与高举相对的那个单纯的「降卑」之意外，还加上了猛然毁灭的意思。义人的角要被高举，恶人的角却不但要被压低，更要被砍断。从复数（恶人们）转到单数（一个义人），若果真有所指，或许是指着说话者而言，视其为一位理想中的个体。把这些话当作神自己的话来解，既属无据，又显生硬。这话毋宁是教会所说的，教会在此代表神，或是倚靠他的力量、奉他的权柄而行。
