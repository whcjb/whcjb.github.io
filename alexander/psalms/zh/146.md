<!-- PAGE 563 -->
本篇可分为相等的两部分，前一部分描述那些信靠神而不信靠人之人的福乐，第 1-5 节；后一部分则从神的诸般完美中引出其缘由，第 6-10 节。就其全部的内在性质而言，本篇与在它之前的大卫系列诸篇（138-145 篇）判然有别。与此同时，它在措辞上与紧接其前的一篇屡屡相合，表明它原是要与那一篇连着使用的，因而可视为自诗篇 135 篇开始的整组诗篇的终篇；这一整组诗篇属于哈该与撒迦利亚的时代，而七十士译本正明确地把我们眼前这一篇归于那个时代。

<!-- PAGE 564 -->
<span class="ax-anchor" id="psalms-146-1"></span><span class="ax-vnum">1.</span> *哈利路亚！我的心哪，赞美耶和华！* 参看前面诗篇 103:1, 22；104:1, 35。*哈利路亚*一语从未出现在任何冠以大卫之名的诗篇中；实际上，它之于后期诸篇，正如*细拉*之于更古老的诸篇，同为其特征。

<span class="ax-anchor" id="psalms-146-2"></span><span class="ax-vnum">2.</span> *我要一生赞美耶和华；我还在*（存活）*的时候，要向我的神作乐。*这些话的字面意义，见上文诗篇 104:33 的注释，此处即取自该处，只是把*歌唱*改作*赞美*，无关紧要。

<span class="ax-anchor" id="psalms-146-3"></span><span class="ax-vnum">3.</span> *你们不要倚靠王子，不要倚靠世人之子，在他并无拯救，*他既不能救自己，也不能救别人，乃是全然仰赖神。参诗篇 40:5（4）、75:7, 8（6, 7）、108:13、116:11、144:10。这可视为以色列向世人发出的劝勉，而这劝勉是建立在他自己的经历之上的。

<span class="ax-anchor" id="psalms-146-4"></span><span class="ax-vnum">4.</span> *他的气息出去，他归回他的尘土；就在那一日，他的思念就消灭了。*首句的意思，见前面诗篇 104:29 的注释。希伯来文这个词（רוּחַ）的用法中，*气息*的本义与*灵*的引申义彼此交融，故译文中可取其一，而不至于完全排除另一义。*他的思念，*即他那些虚妄的念头或野心勃勃的计谋。

<span class="ax-anchor" id="psalms-146-5"></span><span class="ax-vnum">5.</span> *有福的是那以雅各的神为帮助的人，*（和）*他的仰赖在耶和华他的神身上。谁的帮助，*字面作*在谁的帮助之中，即*投身其中、受用于此，或更可能是*在谁的帮助者之列。*参诗篇 45:10（9）、54:6（4）、99:6、118:7。此处所用的神名（אֵל）含有全能之力的意思，与人的软弱相对。*仰赖，*字面作*期待、盼望；*但「倚靠」之意必由介词 *on*（在……之上）所引出。

<span class="ax-anchor" id="psalms-146-6"></span><span class="ax-vnum">6.</span> *那造天、地、海和一切*（是）*在其中之物的*——*那*（位）*永守真实的。*这里给出了如此倚靠神的两重理由：其全能的大能，已在创世之中施展并得着明证；以及他不变的信实。参见上文诗篇 25:5。*那造了的，*字面是*正在造的，*一如惯例，指向神的创造之能仍在宇宙的维系中施展着。参见上文论诗篇 65:7(6)、121:2、144:2 之处，

<span class="ax-anchor" id="psalms-146-7"></span><span class="ax-vnum">7.</span> *为受欺压的人伸冤*——*赐食物给饥饿的人*——*耶和华，释放*（或*那释放）被囚的人。* 祂不但能够、而且惯于搭救困苦之人，这里举出几类不同的人作为例子。参 诗篇 37:19，68:6, 7（5, 6），107:5, 9, 10，145:14。饥饿与被掳，既是外在患难的字面称谓，也是属灵祸患的常见比喻，二者在此都可视为包含在内。

<span class="ax-anchor" id="psalms-146-8"></span><span class="ax-vnum">8.</span> *耶和华开启瞎子*（的眼睛）*；耶和华扶起被压弯的；耶和华喜爱义人。*第一句中的省略，在希伯来文里不像在英文里那样生硬，因为该动词（פָּקַח）按用法几乎专用于眼睛，希伯来读者一见便会想到眼睛。三个动词都是分词形式，*开启、扶起、喜爱，即*持续不断地如此行。第一句既可指身体的瞎眼，也可指心灵的瞎眼。参申命记 28:29，以赛亚书 59:10，约伯记 12:25。第二句取自诗篇 145:14。

<!-- PAGE 565 -->
<span class="ax-anchor" id="psalms-146-9"></span><span class="ax-vnum">9.</span> *耶和华保护寄居的；孤儿和寡妇他扶助；恶人的道路他却使之弯曲。*寄居的、孤儿和寡妇，在律法中常被提出来作为怜悯与善行的对象。参看前面诗篇 68:6, 7（5, 6）的注释。*扶助，*即复兴、从卑微的境地中扶起。正如平直的道路是亨通的象征，使人的道路弯曲就是使他陷入灾祸。同一个动词也在道德的意义上用于恶人的乖僻行径，诗篇 119:78。

<span class="ax-anchor" id="psalms-146-10"></span><span class="ax-vnum">10.</span> *耶和华*（作王，且）*必作王直到永远；锡安哪，你的神必作王，直到世世代代。哈利路亚*（你们要赞美耶）！本篇以摩西之歌中的一句宏大话语作结，即出埃及记 15:18，其后加上一句平行的分句，并以 *哈利路亚* 收尾，为这一整组诗篇作结；据推想，这组诗篇是在第二殿落成之时所唱的。
