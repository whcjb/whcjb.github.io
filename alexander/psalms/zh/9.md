<!-- PAGE 48 -->
本诗以一连串自然而醒目的交替转折，表达了对既往拯救的感恩、对神施行拯救之能力与心意的信靠，以及为再度蒙此拯救所作的直接而恳切的祈求。首先是对昔日怜悯的追念，第 2-7（1-6）节；其次是对将来的信靠之辞，第 8-13（7-12）节；再次是由此而生的祈求，第 14, 15（13, 14）节。同样的思路次序又重复一遍：追忆往事，第 16, 17（15, 16）节；前瞻将来，第 18, 19（17, 18）节；为眼前即时的帮助祈祷，第 20, 21（19, 20）节。各部分之间的这种平行体，使本诗的结构与第七篇极为相似。此篇的写作有意如此构造，好使教会在任何争战与逼迫的时期，都能藉之抒发虔敬之情。其形式属于旧约；但其实质与精神则为新旧两约的时代所共有。

<!-- PAGE 49 -->
<span class="ax-anchor" id="psalms-9-1"></span><span class="ax-vnum">1.</span> *交与伶长，阿勒慕拉便（Al-muth-labben）。* 这个谜样的题注历来解释纷纭。有人以为它是在描述诗的主题，把 *labben* 看作 *Nabal*（拿八，大卫的一个仇敌之名）的字母易位，同时又是一个通名，意为 *愚顽人*，而这个词常用来指恶人；例如可参诗篇 14:1。如此，全句便是 *论那愚顽人之死，即*罪人之死。据说这一类谜样的字母更换也见于耶利米书 25:26，51:1, 41；撒迦利亚书 9:1。另有人更改希伯来文的点符，不读 *al-muth* 而读 *alamoth*（亚拉末，Alamoth），即诗篇 46 篇题注中所见的乐语，或读一个同源的形式 *almuth*，并把 *labben* 解作 *为便*，或 *为便的（子孙）*，便是历代志上 15:18 所提到的利未歌唱者之一。这两种解释似乎都不及第三种来得自然：第三种以为 *muth-labben* 是另一首诗的篇名，或其起首之语，或其中一句显著的话，本篇乃是仿其体裁、或按其曲调而作。即 *按……的样式*，或 *用……的调*，唱（那首歌或诗）*死归于子*，或那子之死。可比较撒母耳记下 1:18，那里大卫为扫罗所作的哀歌似乎被称为 *基舍特（Kesheth）*，即 *弓*，因为这个词是该诗中一句显著的话。既然不能设想这些话原本毫无意义，那么在此处以及许多类似的情形中，其晦涩反倒是年代久远的凭据，而非相反。

2 (1)。*我要称谢耶和华，*因他的恩惠赞美他，*尽我的心，*真诚地、由衷地，并对他恩惠之大有恰如其分的领会。*我要述说你一切的奇事，*即你所行的奇妙之事，尤其指那些为他自己的经历所印证的。由第三人称转为第二人称是极其自然的，仿佛诗人情感之热切，使他不能再仅仅把神当作不在眼前的一位来述说，而是迫使他转向他，以他为直接称呼的对象。因此不必在前一分句中补出*你*，也不必把*耶和华*解作呼格。

<span class="ax-anchor" id="psalms-9-2"></span><span class="ax-vnum">3 <span class="ax-veng">(2).</span></span> *我要因你欢喜夸胜*，不仅是在你面前欢喜，也不仅是因你的缘故，*即*因你所行的事而欢喜，乃是与你相交而欢喜，因我与你有切身的关系而欢喜。此处以及前一节末句中动词的形式，表达强烈的愿望与坚定的决心；见上文诗篇 2:3。*我要赞美*，或*歌颂*；见上文诗篇 7:18(17)。*你的名*，即你所彰显的卓越；见上文诗篇 5:12(11)。*（你）至高者*，或*至高的主*！见上文诗篇 7:18(17)。此处再一次特别提到神近来对付诗人与其仇敌之事，这些作为正是他至高主权的凭据。

<span class="ax-anchor" id="psalms-9-3"></span><span class="ax-vnum">4 <span class="ax-veng">(3).</span></span> *在我仇敌转身退后之时，即*从他们对我的攻击中退后，这等于说：在他们的退却、他们的败亡、他们的失望之时。这句或可与前文相连，视为那里所应许之赞美的缘由或时机：「当我的仇敌转身退后时（或：因为我的仇敌转身退后），我要颂扬你的名」；或可另起一句，把他们的败亡归于神自己的作为：「当我的仇敌转身退后（这是因为）*他们必要跌倒，在你面前灭亡*」，即在你之前，或*在你的面前，即*你一显现之时。希伯来文的这个介词兼有表原因与表处所两义。动词的形式并不必然意味着所承认的拯救仍属将来，只是表明此事可能再次发生，而在任何这样的情形下，无论已过还是将来，耶和华都是、也必是所得胜利的真正成就者。跌倒之举含有仆倒为其自然结果之意，圣经中常以此为彻底而毁灭性之失败的比喻。

<!-- PAGE 50 -->
<span class="ax-anchor" id="psalms-9-4"></span><span class="ax-vnum">5 <span class="ax-veng">(4).</span></span> 这并非悬而未定的指望，乃是确凿无疑的经历。*因为你已成就了，* 作成了、执行了、办理了，并因此维护了，*我的案件与我的权利。* 这一短语在别处总是用于有利的意义上，从不用于那种含混的意思，即单单施行公义，无论是对无辜者或对有罪者。见申命记 10:18；列王纪上 8:45, 49；诗篇 140:12；并参以赛亚书 10:2。而这样的辩护不仅是一位辩护人的辩护，更是一位审判官的辩护，或更确切地说，是一位君王在行使那属于王权的审判职分时所施行的辩护。见箴言 20:8。*你已坐，* 并且仍坐着，*在宝座上，* 即普世主权的宝座，*施行正直的审判，即* 按正直施行，或作 *公义的审判者，* 一位公义的审判官。见上文，诗篇 7:12（11）。诗人早已在这威严的身分中看见了耶和华，因此他以此为理由，指望他如今也照着这身分行事。

<span class="ax-anchor" id="psalms-9-5"></span><span class="ax-vnum">6 <span class="ax-veng">(5).</span></span> 前一节的法庭用语，如今得着解释，指的是神的仇敌的毁灭。*你责备了列邦*——不只是个人，而是列邦。神的管教常被称为责备，因为他在其中以行为说话，与用言语说话同样清楚。*你已毁灭恶（者），即* 许多恶敌，在从前的时候，在别的事例中，而且所加的不是局部的败亡，乃是连他们的记念都尽行剪除的灭绝。*他们的名*，就是人赖以被分别、被记念的，你已经*涂抹了*，抹去、擦净、消灭得无踪，*直到永远永远*——这是一个惯用语的连用，与英文的 *for ever and ever*（永永远远）意义相合，形式却不同。本节所指的并非神的能力与忿怒的某一次单独显明，乃是他对待仇敌的一贯行径，尤其是其从不更改的结局：敌对一方的毁灭。

<span class="ax-anchor" id="psalms-9-6"></span><span class="ax-vnum">7 <span class="ax-veng">(6).</span></span> *那仇敌，*或作*至于那仇敌，*这是为着强调而置于句首的独立主格——*完结了，*即告终了，*是（他的）荒场，*荒凉，*直到永远，即*他永远被毁灭、被荒废了。把首词解作呼格——*哦仇敌啊，（你的）荒凉已告终，直到永远，即*由你所造成的荒凉——虽可得一善解，却既不如前一种解法合乎通例，也不如它合乎上下文。至于其他人对这一难解分句所给的译法，就更不相合了。*例如*：仇敌永远彻底荒凉；——仇敌被灭尽了，（惟有）废墟（或荒凉）直到永远，……。此处所对之言仍是耶和华，与上一节同。*而（他们的）城邑，*即仇敌的城邑，*你已毁灭。*若按上面所给的第二种解法，这便当作*你*（仇敌啊）*已毁灭了城邑，*但如今你自己也被毁灭了。前面所举的同样理由，要我们宁取耶和华为所对之人。*消逝了，*灭没了，*正是他们的记念。*本分句原文那种惯用语的形式，在译文中无法保存。最接近的译法当是：*消逝了他们的记念，他们自己。*这或可解作*他们的记念，*即*（属）他们自己的，即*他们自己的记念；或解作*他们的记念灭没了，（连）他们自己（也一同灭没）。*这里显然暗指摩西五经中对亚玛力人的威吓之言（出埃及记 17:14；民数记 24:20；申命记 25:19），那威吓在扫罗与大卫的征战中得了字面的应验（撒母耳记上 15:8, 7，27:8, 9，30:1, 17；撒母耳记下 8:12；历代志上 4:43）。但此处显然只是把它作为战胜四围列国的一个样本提出（撒母耳记下 8:11-14），而这些胜利本身，也不过是神为自己子民所行、并在上面第 2 (1) 节所颂扬的那些奇事的样本罢了。

<!-- PAGE 51 -->
<span class="ax-anchor" id="psalms-9-7"></span><span class="ax-vnum">8 <span class="ax-veng">(7).</span></span> *而耶和华直到永远，*即永永远远，*必坐着，*正如他此刻坐在宝座与审判席上一样。*他已为审判设立了，*为了行使审判者之职，*他的宝座。*耶和华作王，不是以绝对的或专断的统治者的身分，而是以公义的审判者的身分。这里承认神的审判者身分与职任乃是永存的，意在为下文呼求他在当前之事上施行公义的干预铺路。

<span class="ax-anchor" id="psalms-9-8"></span><span class="ax-vnum">9 <span class="ax-veng">(8).</span></span> *而他，*即他自己，重音落在这代词上，*要审判世界，*就是希伯来原词本来所指的那片丰饶而耕作过的大地，这里用以代指其上的居民，*以公义，*或曰按着公正，*即*在施行这一神圣完全之德。*他要审判，*此处另是一个希伯来动词，我们没有与之相当的词，*他要审判万民，*即列族、列种，而非仅仅个别的人，*以诸公正，*就是以公平，复数形式表示丰满或完全，如诗篇 1:1 中一样。前一节既把耶和华的王权描述为审判性的，此处这一节便把他表现为正在实际施行其审判之职。

<span class="ax-anchor" id="psalms-9-9"></span><span class="ax-vnum">10 <span class="ax-veng">(9).</span></span> *而（这样）耶和华必作一座高处，*即险难所不能及之处，因而为避难所，*为受欺压者，*字面作被压碎的或被击成碎片的，*一座高处，*避难所，*在患难的时候，*字面作*在时候中处于患难，*即*在（人）*处于患难的*时候。*神施行祂审判的主权，正是为了救助受苦的人，拯救处于危难中的人。

<span class="ax-anchor" id="psalms-9-10"></span><span class="ax-vnum">11 <span class="ax-veng">(10).</span></span> *并且投靠你的，*如同现今，也如同将来一切的时候，*是认识你名的人，*就是那些知道你从前所彰显的伟大与良善的人，凡此一切都包含在神的*名*之内。参第 3 (2) 节，以及诗篇 8:2 (1)、7:18 (17)、第 12 (11) 节。*因为你未曾撇弃寻求你的人，*或作*（那些）寻求你的人，主啊，*耶和华，*即*总的说来是寻求你的恩眷，特别是寻求你的保护以抵挡他们的仇敌。对这一事实的确知，被立为前半句所表达之信靠的根基。

<span class="ax-anchor" id="psalms-9-11"></span><span class="ax-vnum">12 <span class="ax-veng">(11).</span></span> *歌唱，*奏乐，以歌声或乐声献上赞美，*归与耶和华，*即以色列的神，*居于锡安，即*那里所设立的圣所。或者这些词也可解作*坐着，*如君王般登位而坐，*（在）锡安，*这与上文第 5、8（4、7）节中同样动词的用法甚为吻合；不过前一种译法则得着另一方面的支持，因为此处显然暗指摩西律法之下圣所的象征意义，即教导神住在人间这一伟大教义。参看上文诗篇 3:5（4）、5:8（7）的注释。锡安在此被描绘为一个圆周的中心，而这圆周远远伸展到以色列家之外，实与全地同其广袤。*述说，*宣告，使人知晓，*在，*就是在*列国中，他的作为，*他那些尊荣的事迹，即第 2（1）节所提到的*奇事*。我们在此，于这受默示的敬拜格式中，得着一个明证：古时的教会已经相信并明白那伟大的真理——训诲必出于锡安，耶和华的言语必出于耶路撒冷，以赛亚书 2:3，弥迦书 4:2。

<span class="ax-anchor" id="psalms-9-12"></span><span class="ax-vnum">13 <span class="ax-veng">(12).</span></span> *因为寻索血，*或*作为血的追讨者，他已记念，*他记念*它，即*那血；*他没有忘记困苦人的哀求。*神在此显明的，正是他在创世记 9:5 中所取的身分，那里所用的动词与名词，与本节前半句所用的相同。译作*血*的这个词是复数形式。参看上文诗篇 5:7(6) 的注释。因此下一个词的字面译法是*他已记念它们，即*那些血，或说那些凶杀。这里所说的哀求，是受苦与控诉的哀求，尤其与创世记 4:10 相呼应。按末句的另一种读法，这哀求是谦卑人或困苦人的哀求，而非受难者的哀求。但通行的经文给出的意思更好，并且实际上已包含了另一种读法，因为受难者的无辜虽未明言，却已隐含其中。本节的总意是：神的审判虽有迟延，却未曾废弃；他并不忘记那些他似乎不加理会的事；他迟早必要显现为报应者。这里以凶杀作为侵害人身的最高罪行，用以代表其余一切罪行，实则代表一般的邪恶。

<span class="ax-anchor" id="psalms-9-13"></span><span class="ax-vnum">14 <span class="ax-veng">(13).</span></span> *求你怜悯我，*或说恩待我，*耶和华啊，看我因恨我之人所受的苦，你将我从死门中举起。*前面所论及神的信实与公义，如今成了他恳切祈求的根据，求神救他脱离眼前的危险与患难。*恨我之人，*即那些恨恶我的人。*从恨我之人，*可视为一种含蓄的句法，意思是：看我所受的苦（并救我）脱离仇敌。撒母耳记下 18:19 便是如此：「耶和华已经为他伸冤，脱离仇敌的手」，意思是「已经为他伸张公义（因而使他得脱）离仇敌的权势」。下文诗篇 22:22（21）中有类似的说法。然而就本处而言，把*从*解作表原因的意思，似乎更自然、更明显：「看我的患难，它是出于、或是由那些恨我的人所致。」*将我举起*并不是指一个伴随的动作，仿佛他说：看我的患难，同时将我举起云云。这倒是在描述神的某种品格或常行之事，与所省略的第二人称代词相合：「你这举起我的」，即素来如此行的，在别的事上曾这样行的，其中隐含着祈求：如今也求你这样行。*死门*或许是指地下牢狱的意象，被囚者无法自行脱身；或许只是一个诗意的说法，指进入坟墓、即死人之境的*入口*。参以赛亚书 38:10 与马太福音 16:18。

<span class="ax-anchor" id="psalms-9-14"></span><span class="ax-vnum">15 <span class="ax-veng">(14).</span></span> *使我在锡安女子的城门中述说你一切的赞美，因你的救恩欢腾。* 这是他求拯救的一个重要目的，即：愿神因他的得救而得着赞美。希伯来文本中留有原为复数形式 *赞美（诸端）* 的痕迹，若如此，则可指那些可赞之作为，即值得传颂的行动。但下文诗篇 106:2 中单数形式也与 *一切* 连用。此处所提的城门与前一节的城门相对照。那位救他脱离死亡之门的神，必在锡安女子的城门中因这拯救而受赞美。末一语，有人认为是把居住在锡安或耶路撒冷的百姓加以拟人化，而这百姓又代表全以色列，即教会或选民。另有人认为此处的属格结构等于单纯的同位语，如 *幼发拉底之河*，或我们熟悉的说法 *耶路撒冷之城*。如此，则被拟人化的乃是城本身，被看作一位理想中的处女，因而称为 *女子*，其用法与法文中相应的词相似。无论取哪一说，此处显然是指着古时的教会说的，它或是诗人赞美的场所，或是其见证。末句的动词可视为受本节开头的小品词管辖，*[使]我欢腾*；也可更有力地解作独立的命题，*我要因你的救恩欢腾。* 该动词的形式与上文诗篇 2:3 相同。第二个动词本身见于那篇诗的第 11 节，与那里一样，既可指内心的情感，也可指其外在的表达，*我要欢呼。因你的救恩，即* 在于得着或经历这救恩，并在于承认自己已如此经历、已如此得着。

<span class="ax-anchor" id="psalms-9-15"></span><span class="ax-vnum">16 <span class="ax-veng">(15).</span></span> *列国陷在自己所造的坑中；在他们所藏的网里，他们的脚被缠住了。* 这或是以信心预期将来之事，视之如同已然成就；或是再一次追述先前的拯救，作为盼望此后诸般拯救的根据。*列国*，即整个整个的邦国，当其与神为敌之时。参诗篇 2:1。对希伯来读者而言，*外邦人、异教之民* 这一附带的意思也必同时浮现于心。多数译本作定指形式，*那坑、那网*；但原文的不定形式在英文中同样明白可解，因而作为更精确的译法更为可取。关系词的省略，*一个坑*（那）*他们所造的*，乃希伯来惯用语与我们自己的语言所共有。此处的比喻取自古时猎取禽兽的方法。见上文诗篇 7:16(15) 的注释。*他们的脚*，即他们自己的脚，而非他们所欲加害的那受害者的脚。

<span class="ax-anchor" id="psalms-9-16"></span><span class="ax-vnum">17 <span class="ax-veng">(16).</span></span> *耶和华已被知晓，*或作已使自己被人认识。*公义他已施行，*或作审判他已执行。*在他自己手所作的工中，恶（人）被缠住。希加约，*默想。*细拉，*停顿。神虽似乎遗忘不动，却已显明自己乃是临在而留意的：他向仇敌施行公义，或者更确切地说，是叫他们自己向自己施行公义，使他们加害他人的诡计反成自取灭亡的手段。面对神护理之统治这一最触目的明证，读者被召来省思，又藉着一处意味深长而庄重的停顿得以从容省思。「默想」或「省思」之义，由诗篇 19:15（14）与耶利米哀歌 3:62 可以看得明白。参下文诗篇 92:4（3）。此处在*细拉*之上加了*希加约*（Higgaion），正可印证前面对后一词所作的解释。参上文诗篇 3:3（2）。按这样理解这两个词，则每逢见到护理中显著的报应，尤其是罪恶昭然地自作自受之时，我们大可对自己、对他人说一句：*希加约，细拉！*

<span class="ax-anchor" id="psalms-9-17"></span><span class="ax-vnum">18 <span class="ax-veng">(17).</span></span> *恶人必转回，直到阴间，*即转入死亡或坟墓，*一切忘记神的列国。*神与他子民的仇敌，不仅要受挫败退，更要被驱入灭亡；而且不只是个人如此，列国亦然。*Sheol*（阴间）一词的含义见上文诗篇 6:6（5）的注释。此处转回、退却、败落的比喻，与上文第 4（3）节所用者相同。所表达的意思，并非是径直被转入阴间，乃是先转回到原处，再越过原处，转入坟墓或阴间。末句暗指上文第 13（12）节所隐含的、对神有所遗忘的指控。他并未如他们所惧、如仇敌所信的那样忘记那些「可怜的无辜者」；反倒是这些仇敌忘记了他，如今必须承担自己遗忘所招致的后果。本节的将来时形式，或许所指的正是前一节中作为已然之事提及的同一些事。然而，把它们解作一种笃定的预期似更为自然：既然同样的原因已经产生过那样的结果，如今便确信必有与之全然相似的结果。耶和华既已使外邦人成了自取灭亡者，人就可以期望他在另一情形下重施同样的审判程序。

<span class="ax-anchor" id="psalms-9-18"></span><span class="ax-vnum">19 <span class="ax-veng">(18).</span></span> *因为穷乏人必不永远被忘记，*（且）*谦卑人的指望也不至于永远灭没。*无论神显得多么长久地忘记了他受苦的百姓，就连这看似的遗忘也必有终结。这里又一次提到上文第 18（12）节中所含的、被人指为遗忘的那项责难或归咎。*谦卑*与*困苦*两种读法（ענוים 与 עניים）之间的差别并不要紧，因为上下文表明，所说的谦卑人正是谦卑的受苦者。

<span class="ax-anchor" id="psalms-9-19"></span><span class="ax-vnum">20 <span class="ax-veng">(19).</span></span> *起来吧，耶和华！不要让人，*即软弱的人，*强壮。愿列国，*或作外邦人，*受审判，*并因此必然被定罪，*在你面前，*即在你眼前，在你的审判台前。此处与第 13, 14（12, 13）节一样，坚强信心的表白又成了恳切祷告的缘由。可见坚定的倚靠绝不会叫人丢开敬畏之心，在神面前止住祷告。关于「起来」这一劝呼——即从先前不动作的状态中起来——参上文诗篇 3:7（6）。译作*人*的那个词的完整意义，参上文诗篇 8:5（4）。*不要让他强壮，即*不要让他显得强壮，也不要让他自以为强壮。不要让他因着神的宽容或长久不加刑罚，而有机会怀抱这种幻想，或行这种欺瞒。要在与神的争战中把人算作较强的一方，其荒谬悖理已到了极处，故此呼吁神起来，把这谬妄一举揭破。就恶人而论，受审判自然就是被定罪；在神面前、在他的审判台前受审判，自然就是被定罪而无可上诉。

<span class="ax-anchor" id="psalms-9-20"></span><span class="ax-vnum">21 <span class="ax-veng">(20).</span></span> *安置，*安放，或联结，*耶和华啊，使惧怕归与他们。愿列邦知道，*或作「那时列邦就必知道」，*（知道）人，*而非神，*（乃是）他们。细拉。*神在此被恳求如此惊吓他们，好叫他们自觉其渺小与软弱。译作*惧怕*的那个词，在别处用以指*剃刀*。故此有人愿将前一分句译作*把剃刀加于他们身上，即*剃去他们的须发，暗指东方人对胡须的看法。但此说未免牵强，而马所拉的读法所得的意义更佳。前一短语确切的意思似乎是：设立惧怕，如同看守他们的卫兵（诗篇 141:3），或把惧怕系于他们身上，作常随的伴侣。译作*人*的那个词，仍与前一节所用的相同，因此原是要提示人之脆弱的观念，与神的全能相对照。
