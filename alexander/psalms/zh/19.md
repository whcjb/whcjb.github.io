本篇分为三部分。第一部分的主题是神在其物质的作为中对自己的启示，第 2-7 节（1-6 节）。第二部分的主题是神在其律法中对自己更为荣耀的启示，第 8-11 节（7-10 节）。第三部分则说明这些真理对作者本人、以及对一切与他同有此信心之人的品格与益处所产生的关联，第 12-15 节（11-14 节）。

本诗的用意不在于把道德的启示与自然界的启示相对照，而在于指明二者出于同一位作者、同指一个主题。全篇的教义要旨乃是：那位建立自然之架构的神，正是赐下律法的神，而这律法在一切方面都与它的作者相称。

<span class="ax-vnum">1.</span> *交与伶长，大卫的诗。* 此题注的形式与诗篇 13 篇相同。其历史上的真确性，可由它在诗篇集中的位置、它与诗篇 8 篇的相似、以及它独特的文风与气息得到印证。

<span class="ax-anchor" id="psalms-19-1"></span><span class="ax-vnum">2 <span class="ax-veng">(1).</span></span> *诸天*（是）*在述说神的荣耀，他手所作的工*（是）*穹苍在宣告。*这些分词表达持续不断的动作。*神的荣耀*乃是他所启示的全部完美之总和（参诗篇 24:7-10，29:3，罗马书 1:20）。*穹苍*或*苍穹*被用作*天*的同义词，即使在创世的记载中也是如此，创世记 1:8。宣告他手所作的工，就是显明他所能作的、以及他实际已作成的。通行译本作 *handy work*，其意不过是 *handwork*（手所作之工）；把 *handy*（灵巧的）当作一个称赞的修饰语，乃是一种粗俗的谬误。

<!-- PAGE 96 -->
<span class="ax-anchor" id="psalms-19-2"></span><span class="ax-vnum">3 <span class="ax-veng">(2).</span></span> *这日到那日倾吐言语，这夜到那夜发出知识。* 两个动词都是旧约诗体方言与诗歌书卷所特有的。*倾吐，*如丰沛而永不止息的泉流涌出。第 2（1）节的分词表达持续不断的动作，这里的将来时则含有在一切将来的时日中延续之意。*言语*指对神荣耀的宣告，*知识*指对这同一伟大对象的认识。永续作见证的观念，是借着一日接一日、一夜接一夜如证人般接连不断的比喻表达出来的。

<span class="ax-anchor" id="psalms-19-3"></span><span class="ax-vnum">4 <span class="ax-veng">(3).</span></span> *没有言语，也没有话语；他们的声音全然听不见。* 由于前一分句似乎与第 3 (2) 节的首句相抵触，诗人便加上 *没有话语，*以表明他在此是取 *言语* 的严格意义，即分明的语言。——末句的第一个词本是名词，意为止息或缺失、不存在，这里用作更着重的否定词，译文中以 *全然* 一语表之。——*他们的声音* 或可专指第 2 (1) 节的 *天* 与 *穹苍，*或可推及第 3 (2) 节的 *昼* 与 *夜。*但前一种解法才是正确的，这从下一节可以看出。分明语言之阙如非但没有削弱这见证，反使它更为有力。纵然没有言语、没有话语，诸天仍向万人见证神。这样解此句，比古时的解法——即通行译本所沿袭的「无言无语，也无声音可听」——以及另一些人所取的「并非没有言语、没有话语，其声音是听不见的」，既更为简明，也更为确切。真义见于英文圣经的旁注。

<span class="ax-anchor" id="psalms-19-4"></span><span class="ax-vnum">5 <span class="ax-veng">(4).</span></span> *诸天的量线通行全地，他们的言语传到世界的尽头，*（原文无「是」字）*为太阳他在其中支搭了帐棚。*译作*量线*的那个词，总是指丈量用的绳，在耶利米书 31:39 就是在这意义上与此处同一动词连用。其意是说，它们的疆域与全地同其广阔，纵在地极最远之处，它们说话也带着权柄。——*言语*一词也可与前半句的动词连属，但那样就必须把那介词译作*到*。有人把*量线*解作乐器的弦，进而指弦所发的声音，这解法虽得古译本的支持，却与希伯来文的用法全然不合。末句动词的主语，即上文第 2 (1) 节所题的神的名。——*支搭了帐棚，*即为之预备居所，若不用比喻说，就是给它指定了位置。*在其中*必是指第 2 (1) 节所提的*诸天*，由此可知，其间各句中所有复数代词，很可能都以此为先行词。此句之所以引入太阳，大概是因为太阳视行的轨道，正是前半句所述那广大疆域的量度。那疆域必与全地同其广阔，因为遍临全地的太阳，其居所原在天上。诸天及其见证的无远弗届，保罗曾用以表明福音的普世传布（罗马书 10:18）；同样的事本也可以教导早期的犹太人：他们所独享的特权，不过是暂时赐下的，是达至更荣耀之结局的一种手段。

<span class="ax-anchor" id="psalms-19-5"></span><span class="ax-vnum">6 <span class="ax-veng">(5).</span></span> *他*（如）*新郎出自его洞房；他欢然奔路，如勇士一般。*后一个比喻指太阳每日的行程，前一个则指它在黑夜过后精力充沛、欢欣焕发的重现。此处以一种精妙的转折，把帐棚或居所的笼统观念换成了婚帐或洞房的具体观念。*欢然，*字面作*必欢然，*即永远如它此刻所行的那样。

<!-- PAGE 97 -->
<span class="ax-anchor" id="psalms-19-6"></span><span class="ax-vnum">7 <span class="ax-veng">(6).</span></span> *从天这边* （是） *他的出来，他的周行直到天那边的尽头，并没有一样（或一物）能隐藏、得不着他的热气。* 第 5（4）节论天所说的话，这里是论日头所说的，即他的疆域与地、或与人所居之世界一样广阔。末一分句之所以加上，是要表明这并非一种无所作为的临在，乃是既可见、也可感的临在。此处提到日头的热，不是与他的光相对照，而是把热当作光不可分离的伴随之物。——复数的*尽头*之所以加在单数之后，似是为把意思说尽，至少是为加强这一表述。译作*周行*的那个词含有回到起点的意思。希伯来文的介词本义是*直上到*（或*直下到）*它们的极处。

<span class="ax-anchor" id="psalms-19-7"></span><span class="ax-vnum">8 <span class="ax-veng">(7).</span></span> *耶和华的律法是完全的，使人心灵复原；耶和华的证言是确定的，使愚蒙人有智慧。* 那位藉着物质受造之物彰显其荣耀的神，也是一部属灵律法的作者；诗人在接下来的三节里，用六个特有的名称、六个修饰性的形容词、以及它所产生的六种道德果效来描述这律法。在本节中，除了通常的「*律法*」一词外，它又被称为神的*证言，即*他为真理作证、驳斥罪孽所作的见证。它被描述为*完全的，即*毫无缺欠或瑕疵；又被描述为确定的，*即*明确、断然而无谬。本节所提到的两种果效，第一是*使人心灵复原，即*使因灾祸而枯竭的生命与精神得以恢复。参见下文诗篇 23:3，并比较路得记 4:15、耶利米哀歌 1:11, 16。*使人心灵归正*这一果效，在此处的上下文里是不会归给律法的，因为作者在这里描述的，是已经归正之人对律法所怀的情感；这就除去了一切与保罗所说律法叫人死的表述之间的表面矛盾，同时也除去了把「律法」解作「福音」、或以其他方式偏离这希伯来词显明而惯常之意义的必要。归给律法的另一果效是*使愚蒙人有智慧*——不是指愚顽人，即那个词被用在不敬虔之人身上时所带的那种强烈意义（见上文诗篇 14:1），而是指那些受光照尚不完全、仍需属灵引导的人；这一描述或多或少适用于一切信徒。有一件事颇为特别：这个希伯来词的此种用法为大卫所独有，而所罗门却一贯用它来指未归正之人那种有罪的愚蒙。（见诗篇 116:6、119:130，箴言 1:22、7:7、9:4、14:15……）——保罗照样把「圣经」描述为*能使人有得救的智慧，*提摩太后书 3:15。

<span class="ax-anchor" id="psalms-19-8"></span><span class="ax-vnum">9 <span class="ax-veng">(8).</span></span> *耶和华的典章*（是）*正直的，使心欢喜；耶和华的诫命是清洁的，使眼明亮。*译作*典章*与*诫命*的两个词彼此差别甚微，前者较明确地表达托付或委任之意，后者则表达规定或指示之意。本节加在神的律法上的两个形容词之间，也没有多大分别：律法是*正直的*，因它是神公义的准确表达；是*清洁的*，因它毫无不义或罪孽的玷污。所描述的第一个效果是*使心欢喜*，即使那爱慕公义的心欢喜——这样的心既爱公义，便渴望借着知道何为神所悦纳、何为神所要求的，来知道何为正直。另一个效果，*使眼明亮*，有人理解为在属灵事上的理智光照。但更合乎希伯来文惯用语的，是设想此处暗指因极度衰弱、临近死亡而生的目光昏暗，从那光景中得以复原，便以比喻的方式表述为眼目得了光明。见前文诗篇 13:4(3) 的注释，并参诗篇 34:6(5)。这样解释的比喻，与前一节的*苏醒灵魂*极为相似，只是后者所指的更是生命本身，前者所指的更是感官。

<span class="ax-anchor" id="psalms-19-9"></span><span class="ax-vnum">10 <span class="ax-veng">(9).</span></span> *耶和华的敬畏是洁净的，存到永远；耶和华的典章是真实，它们全然公义。* 因为「敬畏耶和华」按其本义在此处并不合宜，又因律法原是要教导人如何敬畏主（申命记 17:19），所以这一短语在此可以理解为就律法这一特殊目的而言对它的描述，*敬畏主*乃是用来指那引导或教导人敬畏他的事物，这个用法据信在别处若干经文中也可见。参诗篇 34:12（11），箴言 1:29，2:5，15:33。——*存到永远，*即其约束力永不废止。连基督也说他来不是要废掉，乃是要成全。见马太福音 5:17, 18。此处的措辞形式可与诗篇 33:11，112:3 相比。——*典章*本指司法上的判决，但此处如同诗篇 18:23（22）一样，用以指神一切的要求。*它们是真实*（真实本身）或许是一种强烈的说法，意思是它们完全而绝对地真实；但这样一来，末句便几乎只是同义反复了，所以前一短语也可理解为：它们确实就是它们所自称、所声言的那样，因而必然是*全然公义，即全部，*毫无例外地公义——这在实质上虽不在形式上，等同于说*完全*或*彻底公义。*

<span class="ax-anchor" id="psalms-19-10"></span><span class="ax-vnum">11 <span class="ax-veng">(10).</span></span> （判语）*是可羡慕的，胜于金子，胜于许多精金；且比蜜与蜂房的滴蜜更甜。* 对神律法的描述，以把它比作日常所用最贵重、最甘美之物作结。此处被动分词的意义与诗篇 18:4(3) 中的相同。它的复数形式，以及希伯来文中加于其上的冠词，表明它当与*判语*连读，且句子是从上一节延续下来的，正如诗篇 18:31(30)、33(32)、34(33)、35(34)、48(47)、51(50) 一样。——与*精金*相应的希伯来文是一个单词（פז），不用于散文体，有人以为意指实心的或沉重的金子，但按更可能的词源，乃指提炼过的或精纯的金子。此处所用的这一组合，也见于诗篇 119:127。另参箴言 8:19，并参下文诗篇 21:4(3)。为使两个分句的对应臻于完全，*蜜*的通常用字之后，接以一句优美的迂回说法，指那最被看重的一种蜜。这两个比较所表达的意思，都是贵重与甘美。——前面各节既描述律法本身如何、其普遍功效如何，这一节则似乎表明律法在诗人的领会与情感中是什么，于是便从前文那些总括性的教义，过渡到对这些教义在实际与个人方面的认可，这认可随即展开，并以之结束全诗。

<span class="ax-anchor" id="psalms-19-11"></span><span class="ax-vnum">12 <span class="ax-veng">(11).</span></span> *并且，你的仆人因它们得光照；遵守它们，有大赏赐。*前一分句中的动词，是特指对危险的告诫与警戒而言。参传道书 4:13，出埃及记 33:4, 5, 6，传道书 12:12。复数词尾所指的是上文第 10（9）节的*典章*。——*赏赐*在此并非指按严格公义所挣得的报偿，而是指白白赐下的恩惠。这段话的精神与哥林多前书 15:19、提摩太前书 4:8 相同。*你的仆人*一语，把前文所述的普遍教义，具体应用到作者自己身上。

<span class="ax-anchor" id="psalms-19-12"></span><span class="ax-vnum">13 <span class="ax-veng">(12).</span></span> *错误，谁能明白呢？求你赦我脱离那隐藏的！* 译作*错误*的那个词，与律法中有时用来指无心之过、错失或软弱之罪的词同源，这类罪与蓄意的、故意的、擅敢妄为的罪相对，后者正是下一节所祈求免去的。参利未记 4:2-27，民数记 15:27。对这类罪，任何智慧或警醒都无法全然防范。——译作*赦*的那个词也取自律法，其意与其说是藉心灵的更新而洁净，不如说是藉审判的判词而宣告无罪。参出埃及记 34:7，民数记 14:18。在得罪神的罪人身上，这样的宣告无罪便包含了白白赦免的意思。

<span class="ax-anchor" id="psalms-19-13"></span><span class="ax-vnum">14 <span class="ax-veng">(13).</span></span> *求你也拦阻你的仆人不犯擅自妄为的*（事）*；这样我就完全，免于许多的过犯。*他既为自己无心之过求赦免，也为那些明知故犯之罪求拦阻。希伯来文词（זֵדִים）本意是指骄傲的人，但此处似是借着强烈的拟人用法转指罪恶。其动词字根及派生词在旧约中的用法，可比较出埃及记 21:14、申命记 17:12、18:22、撒母耳记上 17:28。——「完全」一语与诗篇 18:24-26（23-25）中的意思相同。那里既不是指无罪的完全，本节的措辞更可为证。——*那大罪过，*仿佛指某一桩特定的过犯，并非这希伯来短语的真意；此语是不定的，与上文第 12 节（11 节）译作*许多*（或*大）赏赐*的那一短语完全相类。

<span class="ax-anchor" id="psalms-19-14"></span><span class="ax-vnum">15 <span class="ax-veng">(14).</span></span> （那时）*必蒙悦纳*（或*可悦纳）的，是我口中的言语，和我心中在你面前的思念，耶和华，我的磐石、我的救赎主。* 这希伯来文句子最简单、最自然的结构，是把它看作第 14 (13) 节末句的直接延续，与那句一样，是对前面诸祷蒙应允后可期的美好结果的预先展望。倘若他误犯的罪得蒙赦免，而他本性的败坏所催逼的故犯之罪又被神的恩典所拦阻，他便可盼望不但免去许多罪愆，更要成为神所喜悦的对象。既然这种笃定的展望实际上含有愿其成就的祈求，那么上面所给的结构与通行译本——*愿我口中的言语、我心里的意念，在你面前蒙悦纳……*——之间，其实并无多少实质的分别。不过，把 *在你面前* 与紧接其前的 *我心里的意念* 相连，远比照英文圣经那样与本节开头的几个字相连来得自然。于是 *我在你面前所思想的* 便与 *我口中的言语* 并列，用以表达一切祷告，无论是否形诸言辞。参看前面论诗篇 5:2 (1) 处。本句中求蒙悦纳的祈祷或指望，因明显暗指摩西律法中同一希伯来短语（לרצון）的屡次使用而别具美感——那里的用法是指祭物蒙悦纳，或更确切地说，是指献祭者因祭物而蒙悦纳。参出埃及记 28:38，利未记 19:5, 7，22:19, 20, 29，23:11，以赛亚书 56:7，60:7，罗马书 12:1。这一暗指还带出一层译文所无法传达的意思，即赎罪、挽回，乃是诗人所盼望、所祈求之蒙悦纳的根据。
