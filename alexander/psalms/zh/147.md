这是一首赞美耶和华的诗歌，因他普遍施于一切受造之物的美善，尤其因他施于他的教会即选民的美善。这两个主题贯穿全篇；但前半部（第 1-11 节）以前者为主，后半部（第 12-20 节）以后者为主。余下的四篇（147-150 篇）彼此相连，并与前文有别：它们都以*哈利路亚*起首、以之收束；语调欢欣，不杂哀歌或怨诉；屡屡提及新近经历的某次大拯救；又以独特的方式，把神在自然之工中的荣耀显现与他待教会的作为并列同观。有人因此认为这四篇乃是一组，意在纪念尼希米筑成耶路撒冷城墙之事，并非没有道理；历史本身正把这件事描述为除去以色列的羞辱、使圣城恢复其应有地位。参尼希米记 1:3，2:5, 17，6:6, 7, 15, 16，7:4，9:6, 13, 14，10:29，12:27, 35, 41, 43。

<span class="ax-anchor" id="psalms-147-1"></span><span class="ax-vnum">1.</span> *哈利路亚*（你们要赞美雅），因为*歌颂我们的神本为善，因为这是甘美的*，（并且）*赞美是合宜的。*此句由另外三篇诗篇的开头拼合而成。参看上文诗篇 92:2(1)、135:3、33:1。*歌颂，*即以歌声与乐器向他奏乐。参看上文论诗篇 7:18(17) 处。有人不作*这是甘美的*，而读作*他是可爱的，即*至高爱慕的合宜对象，如诗篇 135:3 那样。但即使在该处，这种结构也颇为可疑；而在本节，上文所提出的第一种译法更为可取，因为前后的形容词所指的并非神自己，乃是对他的赞美。

<span class="ax-anchor" id="psalms-147-2"></span><span class="ax-vnum">2.</span> *建造耶路撒冷的*（是）*耶和华；以色列被赶散的人，他聚集。* 尼希米时代城墙的重建，可以说是成全了以赛亚书 11:12, 56:8 应许的应验。参诗篇 107:3。

<span class="ax-anchor" id="psalms-147-3"></span><span class="ax-vnum">3.</span> *那*（位）*医治心碎之人、裹束他们伤处的。*这作为一般的描述本是真确的，而在以色列所经历的拯救中尤得着印证。参看上文诗篇 34:19（18）、103:3 的注释，并比较以赛亚书 61:1。

<span class="ax-anchor" id="psalms-147-4"></span><span class="ax-vnum">4.</span> *数点星宿的数目*——*给它们全体他叫出名字。*那位如此眷顾以色列的神，既是施恩之神，也同样是自然界之神。*数点，*计数、核算、估量。并非预先定规，而不过是作人所不能作的事。参创世记 15:5，并比较创世记 13:16、民数记 23:10、以赛亚书 65:12。他不仅数点它们，还给它们命名，*按名呼唤它们全体。*本节取自以赛亚书 40:26，在那里，如同在此处一样，神对自然界的知识与掌管被呈现为他子民得安慰的源头。

<!-- PAGE 566 -->
<span class="ax-anchor" id="psalms-147-5"></span><span class="ax-vnum">5.</span> *我们的主为大，大有能力；他的聪明无可计数，即* 不可胜计、浩大无穷。参 以赛亚书 40:26, 28。*大有能力，* 或作力量丰盛。

<span class="ax-anchor" id="psalms-147-6"></span><span class="ax-vnum">6.</span> *扶起卑微者*（的是）*耶和华，将恶人摔倒在地。*参上文诗篇 146:8, 9。*摔倒在地，*字面作直至地面。

<span class="ax-anchor" id="psalms-147-7"></span><span class="ax-vnum">7.</span> *当以感谢应答耶和华；用琴向我们的神作乐。*第一个动词取其本义「回答」或「应答」，如诗篇 119:172。它是否曾单单作「歌唱」解，尚可存疑。*应答，即*应答他那多方的恩眷。

<span class="ax-anchor" id="psalms-147-8"></span><span class="ax-vnum">8.</span> *那*（一位）*以云遮盖诸天的*——*那*（一位）*为地预备雨水的*——*那*（一位）*使诸山发出青草的。*青草借着雨水而生，雨水借着云彩而降。见上文，诗篇 104:13 的注释。

<span class="ax-anchor" id="psalms-147-9"></span><span class="ax-vnum">9.</span> *将食物赐给牲畜*——*给那啼叫的小乌鸦。*前一个名词也可译作*走兽，*但仍是指家养的牲畜而言，与之相对的是另一分句中的乌鸦，一种与人无涉的野鸟，有些人以为此处还暗指它那粗厉刺耳的叫声。见上文诗篇 104:21, 145:15，并参约伯记 38:41。*小乌鸦，*字面意思是乌鸦的*众子。*

<span class="ax-anchor" id="psalms-147-10"></span><span class="ax-vnum">10.</span> *他不喜悦马的力大；他不喜爱人的腿快。* 末一分句中那些特异说法，最好的解释是：全节意在描写马与步卒，即骑兵与步兵，二者构成军队的武力。神并不乐意向倚仗这些的人施恩，这等优势也丝毫不能吸引他。

<span class="ax-anchor" id="psalms-147-11"></span><span class="ax-vnum">11.</span> *耶和华喜悦*（的是）*那些敬畏他的人，那些仰望他慈爱的人。*这暗示他们缺乏世俗的凭借，或至少并不倚靠这些凭借，而怀着单单仰赖神的心。

<span class="ax-anchor" id="psalms-147-12"></span><span class="ax-vnum">12.</span> *耶路撒冷啊，当颂扬耶和华！锡安啊，当赞美你的神！* 此处开始本篇的第二部分，以神向他子民所施的恩慈为主题，而以子民自身为呼告的对象。

<span class="ax-anchor" id="psalms-147-13"></span><span class="ax-vnum">13.</span> *因为他坚固了你城门的闩，他在你中间赐福与你的众子。* 前一分句虽可作一般性的比喻应用，但似乎显然暗指本篇的历史背景，或至少支持这样的看法：本篇意在颂赞圣城重修的防御工事。

<span class="ax-anchor" id="psalms-147-14"></span><span class="ax-vnum">14.</span> （这是）*他使你的境界成为平安，*（并用）*麦子的脂油使你饱足。他使，*字面作*那*（一位）*安置的。境界*一词用以指它所包含或所界定的一切，即你的疆土或领域。使它成为平安，就是使它平安无事，或赐它平安。见以赛亚书 54:12。末句可比较诗篇 81:17、申命记 32:14。

<span class="ax-anchor" id="psalms-147-15"></span><span class="ax-vnum">15.</span> *他差遣他的命令者*（降在）*地上，他的话极迅速地奔跑。*这里的结构与前一节相同。*他差遣者，*即那差遣的（一位）。*命令，*字面作*所说的话，*即他所说的。*极迅速地，*字面作*直至迅速。*神那带着权柄的话语在此被拟人化为他的使者或执行者，其迅速的奔跑表明神旨意的即刻成就。

<span class="ax-anchor" id="psalms-147-16"></span><span class="ax-vnum">16.</span> *那降雪如羊毛、撒白霜如炉灰的。* 神以雪或霜覆盖大地，正如人撒开羊毛或灰烬一般轻易。此处所择取的乃是冬令特有的景象，或许与本篇写成、或最初咏唱的时令有关。与此同时，这些景象大概也意在作为那长久困苦的象征——归回之于这困苦，正如春天之于冬天，使之告终。本节的这些比拟，对我们的感触不及那些雪与霜并不常见之地的居民来得深切。

<!-- PAGE 567 -->
<span class="ax-anchor" id="psalms-147-17"></span><span class="ax-vnum">17.</span> *他降下冰雹如碎屑。在他的寒冷之前谁能站立得住？*后一名词意为碎块或零块，但在用法上专指食物。参创世记 18:5、士师记 19:5。这似乎是在描写冰雹，神将它降在地上，其轻而易举、毫无吝惜，正如人撒下面包屑或抛掉吃剩的残渣一般。有人认定此处暗指喂养家畜，这虽讲得通，却属多余。

<span class="ax-anchor" id="psalms-147-18"></span><span class="ax-vnum">18.</span> *他发出他的话语，使它们融化*——*他使他的风吹起*——*水就流动。发出他的话语，*即发出他的命令。复数代词（它们）指第 16、17 节中的雪、霜和冰。这里所说的风，是春天的暖风，随之而来的是普遍的消融。

<span class="ax-anchor" id="psalms-147-19"></span><span class="ax-vnum">19.</span> *向雅各宣告他的话，向以色列宣告他的律例和他的典章。* 自然界的神就是启示的神。那位如此掌管万象与节令的，正是以色列的神；他必成就与这些自然现象相应的属灵变化，使那蒙他托付、得了他旨意之启示的子民得益处。

<span class="ax-anchor" id="psalms-147-20"></span><span class="ax-vnum">20.</span> *他未曾这样待每一国*——*而*（至于*）典章，他们一无所知。* 这启示乃是以色列所独有、所专享的。*每一国，*由此含蓄地说，也就是*任何一国。*事实上，这是希伯来文中唯一能表达该意思的说法。末一分句宣告：列国不但不知道*他的律例*或*典章，*连任何配称此名的也一概不知。
