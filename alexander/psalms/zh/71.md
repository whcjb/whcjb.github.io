<!-- PAGE 306 -->
一位受恶敌怨毒所苦的人祈求拯救，第 1-3 节。他承认神在他早年所施的恩慈，第 4-8 节，并祈求这恩慈在年老时得以延续，第 9-13 节。他满有把握地期待祷告蒙应允，第 14-21 节，并应许以相称的赞美作为回报，第 22-24 节。

本篇与其他以义人的苦难为主题的诗篇极为相似，如第二十二篇、第三十五篇、第三十八篇与第四十篇；末一篇中的一段似乎被置于本篇之首，作为一种经文或主题，或是为了把本篇与方才所提的那一整类作品联系起来。这就说明了为何本篇没有题注或篇题，正如第二篇、第十篇、第四十三篇以及其他几篇的情形一样。

<span class="ax-anchor" id="psalms-71-1"></span><span class="ax-vnum">1.</span> *耶和华啊，我投靠了你，*即避难于你；*求你不要叫我蒙羞，*即失望而狼狈，*直到永远，*即永不。本节与其后两节，略有出入地取自诗篇 31 篇的开头。

<span class="ax-anchor" id="psalms-71-2"></span><span class="ax-vnum">2.</span> *凭你的公义搭救我，使我逃脱；侧耳听我，拯救我。*参看上文诗篇 31:2, 3（1, 2）的注释，那里前一分句仍保留命令式，未像此处这样改作将来时。那里的动词*搭救我*出现在此处的第二分句中；而那里的限定语*急速*或*快快，*在本节中则被略去。句子的划分也不相同，故两处的节次并不完全对应。

<!-- PAGE 307 -->
<span class="ax-anchor" id="psalms-71-3"></span><span class="ax-vnum">3.</span> *求你作我居住的磐石，*一块我可以安然居住、安家其中的磐石，（使我得以）*常来，即*每逢需要之时；*你已下令拯救我，*我的得救已经定下；*因为你是我的磐石，*我的藏身之处，*是我的山寨。*此处所用的意象与词语，与诗篇 18:3 (2) 中的相似。*下令拯救我；*见前文论诗篇 44:5 (4)、68:29 (28) 处。此处对诗篇 30 篇的仿效，不知不觉地转入了一篇新的、独立的作品。

<span class="ax-anchor" id="psalms-71-4"></span><span class="ax-vnum">4.</span> *我的神啊，救我脱离，*使我逃脱，*脱离*恶人*的手，脱离*那*行事乖谬败坏之人*的掌——「掌」是「*手*」的诗体同义语。希伯来文中最后一个词仅见于此处，但从其构词形式看，似是一个动词的分词，该动词意为变酸（或发酸）、发酵、腐坏。同一动词的不定式在以赛亚书 1:17 中用以指道德上的恶。

<span class="ax-anchor" id="psalms-71-5"></span><span class="ax-vnum">5.</span> *因为你*（是）*我的盼望，主耶和华啊，我的倚靠，*即我所信托的对象，*从我幼年以来。*试将*主耶和华*这一组合与诗篇 68:21（20）、69:7（6）中的用法相较，并将*我的倚靠*一语与诗篇 40:5（4）相较。

<span class="ax-anchor" id="psalms-71-6"></span><span class="ax-vnum">6.</span> *我倚靠你，*或说由你扶持、托住，*从母腹；从我母亲的胎中，*一个同义的说法，*你*（是）*我的带出者，*就是那把我带出来的，这与诗篇 22:11（10）所表达的是同一个意思，只是说法不同。此处所用动词的含义，无论其及物还是不及物的形式，都可从诗篇 90:10、民数记 11:31 看出。*我的赞美常常在你里面；*它由你而起，围你而转，归你而终。可比较诗篇 22:26（25）中类似的说法。

<span class="ax-anchor" id="psalms-71-7"></span><span class="ax-vnum">7.</span> 像*一个异兆，*或说奇观，一个令人鄙夷惊愕的对象，*我曾是，*或说*我向许多人已成了这样，*因着我那非比寻常的苦难；*但你是我力量的避难所，*我坚固的避难所，既是我的保护者，也是我的藏身之处。前一分句可与申命记 28:46、以赛亚书 53:14、哥林多前书 4:9 相比较。

<span class="ax-anchor" id="psalms-71-8"></span><span class="ax-vnum">8.</span> *我的口必被充满，*（以）*你的赞美，并终日*（以）*你的荣美，*或荣耀，作为那赞美的题材。瞻仰你的卓越，如今激起、且必永远激起我的惊叹与颂赞。

<span class="ax-anchor" id="psalms-71-9"></span><span class="ax-vnum">9.</span> *求你不要丢弃我，在年老的时候；当我的力量衰败，*字面是照着我力量的衰败，*不要离弃我，*求你不要撇下我、丢下我。他在此祈求：他年轻时所经历、且在上文已经承认的恩典，可以延续并扩及他的年老之时。参以赛亚书 46:3, 4。

<span class="ax-anchor" id="psalms-71-10"></span><span class="ax-vnum">10.</span> *因为我的仇敌曾说*（如此）*对我，即*他们对我说，神必离弃我、或已经离弃了我；并且作为他们确信此事的凭据，*那些窥伺我性命的人，*即那些守候、埋伏要毁灭我性命的人，*一同商议，即*商议攻击我——倘若他们真以为我在神的保护之下，就断不会如此行了。首句中的*对我，*也可读作*论到*（即关于）*我，*这既不违背用法，意思也无实质的改变。参看上文诗篇 3:3（2）的注释。

<span class="ax-anchor" id="psalms-71-11"></span><span class="ax-vnum">11.</span> *说，神已离弃他，追赶捉拿他吧，因为无人搭救，*字面作无搭救者。本节是前一节中*他们说*（如此）一语的铺陈，把他们所说的原话一一道出。首半句可比照诗篇 3:3（2）、41:6（5），以及撒母耳记下 17:1, 2 中亚希多弗的话；此处或有直接的暗指，因那正是大卫亲身经历中、此处所理想地描绘之事的一个实例。末半句可比照诗篇 7:3（2）。

<!-- PAGE 308 -->
<span class="ax-anchor" id="psalms-71-12"></span><span class="ax-vnum">12.</span> *神啊，求你不要远离我；我的神啊，向*（或 *为）我的帮助速来。* 可比较诗篇 22:20(19)、35:22、38:22, 23(21, 22)、40:14(13)、70:2(1) 中类似的说法。第二小句中更有力的称呼*我的神，*是以他与神所立之约的关系相敦促，作为指望蒙垂听的理由。

<span class="ax-anchor" id="psalms-71-13"></span><span class="ax-vnum">13.</span> *他们必蒙羞，他们必灭没*（或作*被消灭）*—*我性命的仇敌；他们必披上*（或作*被遮以）责备或羞辱*—*那些寻索加害于我的人。*这些动词也可译作祈愿语气，*愿他们蒙羞，*……。但这其实已含在将来时的严格意义之内。参平行的经文，诗篇 35:4, 26；40:15（14）；70:3（2）。

<span class="ax-anchor" id="psalms-71-14"></span><span class="ax-vnum">14.</span> *我却要常常盼望，并且加增*（字面作*加在……之上*，积累、增多）*你一切的赞美。*就是在我迄今所献上的一切赞美之上，我仍要不断加添。

<span class="ax-anchor" id="psalms-71-15"></span><span class="ax-vnum">15.</span> *我的口要述说你的公义，终日* （不住地）*述说你的救恩，因我不知其数目* （以表明之），我数算不过来，其数无穷。神的*公义*或正直，包括他的真实与信实，在此被提及，作为他*救恩*的根由，即那以他为源头、以他为成就者的拯救。

<span class="ax-anchor" id="psalms-71-16"></span><span class="ax-vnum">16.</span> *我要带着主耶和华的大能作为而来；我要题说*（或*记念）你的公义，唯独你的。*第一个短语也可以译作*我要进入那些大能作为，*……正如我们说「进入某一题目的细节」一样。但这是英文的惯用语，而非希伯来文的惯用语。通行译本作*我要靠主神的大能而行，*这与动词和名词的用法都不合，因为前者并非绝对地指*行走，*而是指*进入*或*来到*某一处所，无论该处所是明说的还是隐含的。此处的省略可由诗篇 5:8 (7) 与 66:13 补出，这两处同一动词都表示为着庄严颂赞而来到神殿的举动，而在后一处所引的经文中，其后还跟着同一个介词，*我要带着燔祭进你的殿，即*我要把燔祭带到那里。这一含义与前两节中颂赞神的誓愿十分契合，也与本节另一分句中记念的应许相合。见上文诗篇 20:8 (7) 的注释。这也使我们得以把那名词（נבורות）取其通常的含义，即神的伟业或大能作为。见下文诗篇 106:2，并参申命记 3:24。*唯独你的，*不是我自己的，也不是任何受造之物的。见上文诗篇 44:4, 7 (3, 6) 的注释。

<span class="ax-anchor" id="psalms-71-17"></span><span class="ax-vnum">17.</span> *神啊，你从我幼年以来就教训了我*（颂赞你）*，*藉着你在我身上的护理作为，*即*给了我称颂你的机缘，*直到如今我要宣告，即*我仍在宣告，仍有理由宣告，*你的奇妙作为。*参看前文诗篇 9:2 (1)、26:7、40:6 (5) 的解说。

<span class="ax-anchor" id="psalms-71-18"></span><span class="ax-vnum">18.</span> *并且也*（或*甚至）直到年老发白之时，神啊，求你不要离弃我，直等我向（下一）世代宣告你的膀臂，即*你能力的施展，*向那*（下一）*世代，*（并）*向一切将要来的人，你的大能。*末一分句确定了那不定说法*一个世代*的含义。参看上文诗篇 22:31(30)。至于*你的膀臂*这一短语，可比较诗篇 44:4(3)。

<span class="ax-anchor" id="psalms-71-19"></span><span class="ax-vnum">19.</span> *你的公义，神啊，*（达）*直到高处*（或作*高所），即*天，（你）*行了大事，神啊，谁能像你？*第一分句可比较诗篇 36:6（5）、57:11（10）；末一分句可比较出埃及记 15:11、申命记 3:24、撒母耳记下 7:22。

<!-- PAGE 309 -->
<span class="ax-anchor" id="psalms-71-20"></span><span class="ax-vnum">20.</span> （你）*曾使我们看见的，*使我们得见，*即*使我们亲身经历，*苦难又多又重*（或*多且恶的苦难）必转回*（并）*使我们活，*使我们复苏或苏醒，*又必从地的深处转回*（并）*把我们带上来，*使我们上升。同指一个主体，形式却骤然由单数转为复数，这使马所拉注音的作者们在本节也把单数恢复过来；但正文所存的读法无疑才是原初而真确的。由于译作*深处*的那个词在别处一律用于水，有人以为此处暗指洪水，如诗篇 29:10, 32:6, 36:7（6）。参以赛亚书 8:7, 8。此处两次用到的动词*转回，*按希伯来文的惯用语，可以只是修饰它所冠于其前的动词，*你必再使我们苏醒，你必再把我们带来。*但下一节相似的说法使人有理由认为，这动词原是要有独立的意思，指明此处所盼望的苏醒与复兴，系于耶和华转回到他所弃离的百姓那里。参见前面诗篇 14:7 的解释。

<span class="ax-anchor" id="psalms-71-21"></span><span class="ax-vnum">21.</span> *你必加增我的尊大，又必转回* （并）*安慰我。* 既然译作*尊大*的那个词在别处是用于神为保护、拯救他百姓所行的大事（诗篇 145:3，撒母耳记下 7:23），这里的*我的尊大*便可能带有宾格的意味，指向我所行、为我所行的大事。参看前面第 19 节的注解，并比较诗篇 40:6（5）。

<span class="ax-anchor" id="psalms-71-22"></span><span class="ax-vnum">22.</span> *我也要用琴这器具称谢你，即*用琴或七弦琴作为赞美的器具，（为着）*你的真实，*或*论到你的真实，*即真诚与信实；*我要向你奏乐，*向你作乐，赞美或颂扬你，*用七弦琴，*（你）以色列的*圣*者，*即*他特有的神，具备一切神性的全备。参看前面诗篇 22:4（3）的注释。先知们所用的这一称号即借自此处，其中以以赛亚用得最为频繁。

<span class="ax-anchor" id="psalms-71-23"></span><span class="ax-vnum">23.</span> *我的嘴唇要歌唱，当我向你弹奏时，我的灵魂也要，就是你所救赎的。* 首句照上面的译法，似乎是应许要将歌声与乐器之声合在一处来赞美。但第一个动词通常意为欢呼或欢然歌唱，有时仅仅是喜乐；第二个动词所表达的，通常也不只是奏乐的意思，而是赞美的意思。因此这一句也可以解作：*我的嘴唇要欢乐，因我要向你歌唱*（或 *赞美你），我的灵魂*（也要欢乐）。末句可比较诗篇 34:23 (22)。

<span class="ax-anchor" id="psalms-71-24"></span><span class="ax-vnum">24.</span> *并且我的舌头终日要默想你的公义，因为他们蒙羞，他们脸红*——*那些谋害我的人。*前一分句中的动词意为出声地思想、自言自语，因而同时含有思想与声响两重意思。此处用于舌头，是把舌头当作人借以表达其思想的器官，而这表达并非向别人，乃是向自己。参看上文诗篇 1:2，2:1，35:28，37:30，38:13（12），63:7（6），以及下文诗篇 90:9。末一分句把主语置于句尾，具有强调作用，正如上文第 13 节。诸动词用过去时形式，是把这结果说成已经成就的事，虽然实际上仍属将来。
