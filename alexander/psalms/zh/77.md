<span class="ax-vnum">1.</span> *交与伶长，为*（耶杜顿的歌班或家族）*耶杜顿。亚萨的作品。一篇诗。* 此题注的含义，参上文诗篇 62:1 的注释。本篇所载，乃古时教会在深重患难之中的哀诉与祈求。全篇分为两部分。前一部分，教会述说自己可悲的光景，哀诉神的离弃，第 2-10 节（1-9）。后一部分，她以追念昔日的拯救自勉，尤其是出埃及那一次的拯救，第 11-21 节（10-20）。具体的历史缘由未经指明；但若如有些人所推测，是约西亚年间的时局危难，那么*亚萨*一名就当解作指那家族，而非指其始祖。参上文诗篇 50:1 的注释。哈巴谷书第三章中有几处明显是摹仿本篇的。

<span class="ax-anchor" id="psalms-77-1"></span><span class="ax-vnum">2 <span class="ax-veng">(1).</span></span> *我的声音向着神*（我要扬起）*并且我要呼求；我的声音向着神*（我要扬起），*他必侧耳听我。*有些人把末一个动词当作命令式，*并且*（当我扬声之时）*求你侧耳而听。*但且不说人称的突然转换——这种转换虽属常见，却不可无故假定——希伯来文动词的形式乃是不定式，当照前一个动词同化而定其意。如此，末一分句其实是为首一分句所表明的意向陈明理由。倘若他绝望于不蒙垂听，就不会祷告了。

<span class="ax-anchor" id="psalms-77-2"></span><span class="ax-vnum">3 <span class="ax-veng">(2).</span></span> *在我患难的日子我寻求主；我的手夜间伸开，并不发麻；我的心不肯受安慰。*此处的「日」是指时候，但也不无用意地与下一分句所提的「夜」相呼应，以表达他昼夜祈祷之意。译作*伸开*的那个动词，严格说是倾倒、浇出、散开之意，但在此似是诗意地用于指伸开双手这一惯常的恳求姿态。见上文诗篇 44:21(20) 的注释。通行译本作*我的疮流脓*，在字源与用法上都没有根据。下一动词的意义，见上文诗篇 38:9(8) 的注释。其形式为将来时，但那连接词虽被否定词隔开，仍可视为发挥了转换时态的作用。

<span class="ax-anchor" id="psalms-77-3"></span><span class="ax-vnum">4 <span class="ax-veng">(3).</span></span> *我记念神，就哀叹；我默想，我的灵便被压倒。细拉。* 神从前的恩慈，与他如今似乎的撇弃相对照，这样的追忆迫使这受苦者发出不安的言语。希伯来文中的第二个动词，与诗篇 39:7（6）、42:6, 12（5, 11）、55:18（17）中所用的是同一个字。*我的灵*并不单单等于*我自己*，而是另外含有内心深处激荡不宁的意思。

<span class="ax-anchor" id="psalms-77-4"></span><span class="ax-vnum">5 <span class="ax-veng">(4).</span></span> *你紧握我的眼目；我被击打，不能言语。* 这里译作*紧*的那个词，严格说是一个被动分词，意为*被看守、被守住*，而在此处依上下文，乃指（眼目）被保持清醒或睁开。加上这一情节，是要使他悲惨境况的描写更形深重。

<span class="ax-anchor" id="psalms-77-5"></span><span class="ax-vnum">6 <span class="ax-veng">(5).</span></span> *我思想古时的日子，亘古的年岁*（或作 *永世。'）* 以今日与往昔相对照，再一次被提出来，作为他处境中令人倍觉沉重的一端。

<!-- PAGE 333 -->
<span class="ax-anchor" id="psalms-77-6"></span><span class="ax-vnum">7 <span class="ax-veng">(6).</span></span> *我要在夜间记念我的歌，我要用我的心默想，我的灵在寻索。*前一分句中的将来时指向实际受苦的那段时候。译作*歌*的那个词严格说来是指*弦乐器，*或那一类音乐，但在此处用得较为宽泛，表示以音乐发出的感恩。*在夜间*所限定的是紧接其前的词（我的歌），而不是更远的前项（*我记念）。与我的心，即*在与心相交中，与我自己。*我的灵在寻索，即*我从心底发出下面几节所记的那些发问。

<span class="ax-anchor" id="psalms-77-7"></span><span class="ax-vnum">8 <span class="ax-veng">(7).</span></span> *主要永远丢弃，并且不再施恩么？* 受苦者的心灵正是如此发问。*永远，* 字面作 *到诸永世* 或 *到万代。丢弃，* 带着厌恶与轻蔑。参上文，诗篇 43:2，44:10, 24（9, 23），60:3, 12（2, 11），74:1。末句的惯用语形式是：*他岂不再度加添施恩*（或 *更长久）？*

<span class="ax-anchor" id="psalms-77-8"></span><span class="ax-vnum">9 <span class="ax-veng">(8).</span></span> *永远止息了他的慈爱，断绝了* （他的）*话到世世代代？* 这里的一般性用语 *话* 特指应许之话。参上文诗篇 18:31(30)。*世世代代，即* 一切相继的世代，在此并非作为应许的对象、作为神的话所指向的人而被提及，乃是作为其断绝所历的时期。

<span class="ax-anchor" id="psalms-77-9"></span><span class="ax-vnum">10 <span class="ax-veng">(9).</span></span> *那大能的*（一位）*忘记施恩了吗，或在怒中闭住了他的怜悯？细拉。* 此处用神名 *El*（大能者）是有意味的，仿佛是在问：神的恩慈不再与他的伟大相称了吗？译作 *闭住* 的那个动词只见于诗体文字。*他的怜悯* 所对应的原文措辞含有 *他的肺腑* 之意，这合乎那以内脏为最柔情之所在的惯用语。

<span class="ax-anchor" id="psalms-77-10"></span><span class="ax-vnum">11 <span class="ax-veng">(10).</span></span> *我说，这是我的苦难，是至高者右手的年岁。*这一节可视为全篇的转折所在。在前面所述的种种怨言与疑惑之后，我终于说出了我本可、也本当早已说出的话。*我的苦难，*字面作*我的疾病，*乃是以这一特定形式的痛苦代表一切痛苦，即出于神之手所加的痛苦。*年岁*一词的使用，似乎暗示这试炼已历时甚久。神的名号或称谓（至高者）则提示人有顺服他至高美意的本分与必要。

<span class="ax-anchor" id="psalms-77-11"></span><span class="ax-vnum">12 <span class="ax-veng">(11).</span></span> *我要传述耶的作为；因为我要记念你古时的奇事。* 两个分句中动词的形态并不相同，虽然马所拉的校勘家与各译本不必要地将二者同化了。后一个是原始动词*记念；*前一个则是它的派生形式，意为使人记念、传述、称颂。末了几字的字面意义是*从古时以来你的奇妙，*这是一个集合而抽象的说法，指*你奇妙的作为。*关于神的名「耶」的由来与用法，见前文诗篇 68:5 (4) 的注释。

<span class="ax-anchor" id="psalms-77-12"></span><span class="ax-vnum">13 <span class="ax-veng">(12).</span></span> *我也要默想你一切的作为，思想你的所行。*原文所用的不是*论到*它们，而是*在*它们之中，仿佛是说，心思与情感全然沉浸于所思之物。

<span class="ax-anchor" id="psalms-77-13"></span><span class="ax-vnum">14 <span class="ax-veng">(13).</span></span> *神啊，你的道路在圣洁之中。有何大能者*（者）*像神那样伟大？*通行译本作*在圣所中，*也可得出一个很好的意思；但另一种译法更可取，因为出埃及记 15:11 显然是此处所暗指的经文。*圣洁*在此指神的完全，指一切将造物主与其受造之物区别开来的属性。参看前面诗篇 22:4 (3) 的注释。*你的道路，即*你对待受造之物、尤其是对待你子民的方式。此处再次用了*El*（神）这一名称，颇有深意。有谁像神呢，纵使在最有能力、最被高举的存有之中？

<span class="ax-anchor" id="psalms-77-14"></span><span class="ax-vnum">15 <span class="ax-veng">(14).</span></span> *你*（是）*那行奇事的全能者；你曾在列国中显明你的能力。*你是真正的全能者，与一切假冒的相区别。*行，即*习惯性地、本质性地，行奇事。下一个词是单数形式，却有集合的意义，正如上文第 12（11）节。*在列国中，*不单是向他们显明，更是在他们中间、在他们当中、在他们亲身的经历之中。神全能的彰显并不限于他自己的子民，也延及四围的列国。这在出埃及的历史中有特别的记述。参出埃及记 9:16, 15:14。

<span class="ax-anchor" id="psalms-77-15"></span><span class="ax-vnum">16 <span class="ax-veng">(15).</span></span> *你曾用膀臂救赎你的百姓，就是雅各和约瑟的子孙。细拉。* 刚才所提到的神力的那一次特定彰显，如今得以指明。*救赎，*即从被掳或为奴之地救回。*用膀臂，即*藉着能力的施展。参看前面诗篇 44:4(3) 的解释。此处除*雅各*之外又提*约瑟，*是为了把十支派也包括在这句话之内；否则这话或许只会被用于犹大，视其为古时以色列唯一合法的继承者。有些释经者在这一分句中看出明确的暗指，以为十支派之国的倾覆在本篇写作之时已然发生。

<span class="ax-anchor" id="psalms-77-16"></span><span class="ax-vnum">17 <span class="ax-veng">(16).</span></span> *诸水看见你，神啊，诸水看见你；它们颤抖，是的，深渊震动。* 其历史所指自然是过红海之事，但同时也暗指圣经中以海为象征的用法。参看上文诗篇 46:3(2) 的注释。由过去时转入将来时或现在时，表明作者忽然把自己置身于他所追念的事件之中。末句中的 *是的* 或 *不止如此*（אף）带有强调意味。不单是水面在动，连它最深之处也被搅动震撼。

<span class="ax-anchor" id="psalms-77-17"></span><span class="ax-vnum">18 <span class="ax-veng">(17).</span></span> *云中倒出水来；天空发出响声：是的，你的箭飞射。*这些都是暴风雨中的自然现象，在此被记为神同在的标志。见上文，诗篇 18:12-15（11-14）。*天空，*即构成可见诸天的云气。见上文，诗篇 68:35（34）。*发出响声，*即发出它们的声音，是对雷鸣极优美的描述。那*是的*表明语势层层上升。不但有雨有雷，更有闪电，其一道道光芒被诗意地称为箭。见上文，诗篇 18:15（14）。译作飞射的那个词，是动词*行走*的加强形式，含有迅疾之意，或许还含有方向之纷杂，忽此忽彼，往来不定。见上文，诗篇 26:3，35:14。本节可与哈巴谷书 3:11 相参。

<span class="ax-anchor" id="psalms-77-18"></span><span class="ax-vnum">19 <span class="ax-veng">(18).</span></span> *你雷轰的声音*（在）*旋风中；闪电照亮了世界；*（于是）*地震动战抖。*译作*旋风*的那个词通常意为*轮子*，但有时也用来指任何被风卷动、旋转而行之物。参见下文诗篇 83:14 (13) 的注释，并比较以赛亚书 17:13。因此，它很自然地可以用来指旋风本身，即这种旋转运动的成因。这样解释，比起把它仅仅视为对迅疾或速度的描绘，无疑更合乎用法。通行译本作*在天上，*若不是全然任意，就必定是基于一种假设的暗指，即天的穹隆外观。*使之发光，*照明，点亮。然而，这个希伯来词与表示*闪电*的词之间并无亲缘关系。整段描写与诗篇 18 篇中神显现的描写极为相似。另参哈巴谷书 3:14。

<span class="ax-anchor" id="psalms-77-19"></span><span class="ax-vnum">20 <span class="ax-veng">(19).</span></span> *在海中*（是）*你的道路，你的路径在大*（或*多）水中。你的脚踪无人知道。* 这一节可以理解为对神作为之不可测度的概括描述，若如此，所补的动词就当用现在时，*是你的道路，无人知道。*然而，将本节——至少就首要意义而言——理解为指出埃及一事，更合于上下文，也与本篇这一部分生动如画的笔致远为相称；那时实在可以说，耶和华作为祂百姓的拯救者与引领者，祂的道路乃*在海中，*而祂的脚踪与他们的脚踪都无从寻觅，因为众水随即翻卷而过。本节可与哈巴谷书 3:15 相比较。

<!-- PAGE 335 -->
<span class="ax-anchor" id="psalms-77-20"></span><span class="ax-vnum">21 <span class="ax-veng">(20).</span></span> *你曾藉摩西和亚伦的手，像领羊群一样引导你的百姓。* 像羊群一样，在全然的安稳中、以全然的轻易被引领。此处把摩西比作牧人，在以赛亚书 63:11-14 又再出现。本篇的结尾看似突兀，然而任何敬虔的以色列人都能自行推出其中的结论：那位曾如此荣耀地拯救他百姓的，必能再次搭救他们。
