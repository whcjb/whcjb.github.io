<p class="title-block-h1" style="text-align:center; font-size:22px; font-weight:bold; margin:18px 0 12px;" markdown="1"><span style="color:#0000d4">诗篇 125</span></p>

信徒在这世上与不敬虔的人混杂共处，看似与其他人一样遭遇人生的种种祸患；因此先知将他们比作耶路撒冷，表明他们是被一道不可攻破的堡垒所护卫。倘若神有时容许他们受恶人的恶毒所苦，先知便勉励他们要存美好的盼望。然而他同时也在真以色列人与假以色列人之间作了分别，免得假冒为善之人将此处所论义人得蒙保守的话应用在自己身上。

<p style="text-align:center; color:#000080; margin:14px 2em;" markdown="1"><span style="color:#000080">*上行之诗。*</span></p>

<h2 class="scripture-anchor" id="psalm-125-1-2" data-ref="诗篇 125:1-2" style="display:none">诗篇 125:1-2</h2>

<div class="scripture-box" markdown="1">
<p class="scripture-ref"><span class="ages-code">&lt;19C501&gt;</span><span class="book-name">诗篇</span> <span class="verse-range">125:1-2</span></p>

**1.** 倚靠耶和华的人好像锡安山，永不动摇。[^fe79] 2. 众山怎样围绕耶路撒冷，耶和华也照样围绕他的百姓，从今时直到永远。

</div>

<!-- PAGE 654 -->
**1.** <span style="color:#800000">*倚靠耶和华的人好像锡安山。*</span>本篇诗与前一篇的不同之处在于：在前一篇中所说的，乃是教会<span style="color:#800000">*已经藉着*</span>神的大能、不藉任何人的手段而蒙保守；而在我们眼前这一篇里，圣灵所教导的，乃是*在将来的日子里*，她必永远存留于*完全的*安稳之中，因为她有神那不可战胜的大能作护卫。当教会被以耶路撒冷城的地势作象征性的描绘时，先知的用意乃是要鼓励每一位信徒相信：那应许给全体蒙拣选之民所共有的安全，也是属于他自己的。但先知在众人眼前展示教会的一幅可见图像时，乃是俯就那些人的粗鄙——他们被肉体的迟钝所拘留，仍旧安居于地上。因此，首先当留意的是：对那些未能凭信心充分领会神隐秘保护的人，环绕耶路撒冷的众山被展示为一面镜子，叫他们在其中可以毫无疑惑地看见，教会免受一切危险，其稳妥正如四面被这样的城墙与堡垒所环绕一般。此外，我方才所提及的那一点也是有益的，就是：每逢神向他全体的子民说话时，他也是向他们各人说话。正如不少应许是普遍地延及教会全体，许多人便把这些应许看作遥不可及、与自己毫不相干，不敢将其归为己有。所以此处所定下的规则必须遵守，就是：凡神向他教会所共同应许的，各人都当应用于自己身上。诗人以耶路撒冷来代表教会，也并非没有缘由，因为神的圣所与约柜都在那里。

<!-- PAGE 655 -->
至于字句的解释，须注意第一节末尾的两个动词可有两种理解方式。二者都可以「耶路撒冷」为主语。但有些人认为前一个动词 <span style="color:#008080">לא ימוט</span> al, *lo yimmot,* <span style="color:#800000">*必不动摇*</span>，单指耶路撒冷而言；而后一个动词 <span style="color:#008080">ישב</span>, *yesheb,* <span style="color:#800000">*永存*</span>，则指信徒而言。按此看法，这里有一处数的转换，这在希伯来文中极为常见——即用单数 <span style="color:#008080">ישב</span>, *yesheb,* 代替复数 <span style="color:#008080">ישבו</span>, *yeshbu.* 诚然，这句话译作如下亦无不可：*倚靠耶和华的人，好像锡安山，必不动摇，要永远居住*，或*常存坚立*，因为译作*居住*的那个动词正有此意。我们现在明白了先知的意思，就是说：世界虽然屡遭如此众多而突然的变故，几乎每一刻都换上一副新面孔，信徒虽然与众人混杂同处，外在境遇与别人无异，然而在神那不可战胜的保护之下，他们的平安却坚立不移。这并非说他们得以安然无扰、悠闲度日；乃是因为他们的安全既在神的看顾之下，一切攻击便都归于徒然；至少他们纵然踉跄，也绝不至于全然仆倒。但我们要注意，<span style="color:#008080">הבמחים</span>*, habbtechim,* 这个字意为*那些盼望*或*等候的人*，其中含蓄地命令我们要有坚定的信心。因此，凡愿得神之手扶持的，就当恒常倚靠那手；凡愿得神之手保护的，就当忍耐安息在其下。当神容许我们时常被这里那里地带来带去，或如糠秕被风吹散，这乃是出于我们自己的反复无常——因为我们宁可在空中飘荡，而不肯将心思定于他救助的磐石之上。第二节所用的比喻十分明白，教导我们：正如耶路撒冷四围绵延的群山如同城墙一般，神也照样以他的大能环绕信徒，为他们抵挡一切伤害。[^fe79A]圣经中常有类似的说法：神屡次应许要作他百姓的墙垣和外郭。但大卫，或无论本篇的作者是谁，还更进一步，藉着群山的形象指出神暗中保护他自己百姓的方式，为要叫那些因自己悟性迟钝仍被拘于地上的无知软弱之人，得以借着眺望群山，将心思向上提升，去思想并默想天上的事。

<h2 class="scripture-anchor" id="psalm-125-3-5" data-ref="PSALM 125:3-5" style="display:none">诗篇 125:3-5</h2>

<div class="scripture-box" markdown="1">
<p class="scripture-ref"><span class="ages-code">&lt;19C503&gt;</span><span class="book-name">诗篇</span> <span class="verse-range">125:3-5</span></p>

**3.** 恶人的杖不常落在义人的分上，免得义人伸手作恶。[^fe80] 4. 耶和华啊，求你善待那些为善和心里正直的人。5. 至于那偏行弯曲道路的人，[^fe81]耶和华必使他和作恶的人一同出去受刑。愿平安归于以色列。

</div>

<!-- PAGE 656 -->
**3.** <span style="color:#800000">*恶人的杖不常落在义人的分上。*</span> 这句话可说是对前面那句的一种补正。诗人先前说过，神的手四面伸出，护卫他的教会。但我们惯于把神的应许拉向对自己有利的方向，把它们解作我们必得免于一切患难；因此这里警告我们：神的看顾并不保证我们不至有时被十字架和苦难所操练；敬虔人也就不当自许在今世过安逸舒适的生活，只要在需要他帮助的时候不被神撇弃，这就够了。诚然，他们的天父极其温柔地爱他们，然而他要用十字架唤醒他们，免得他们过分沉溺于肉体的欢愉。所以，我们若接受这教义，纵然遭恶人的暴虐所压制，也必耐心等候，直到神或折断他们的杖，或将杖从他们手中夺去。我承认，看见恶人在耶和华的产业中逞其残暴，而敬虔人却仆倒在他们脚下，这是极重的试探；但既然神并非无故如此使他的百姓降卑，他们就当从经文所提示的这一点得着安慰。

接着说明了神为何不容恶人常常胜过义人的缘由——就是免得义人被试探所胜，全然放纵自己去犯罪；这理由是应当留心细察的。由此我们看出，神因愿意担待我们的软弱，就节制我们所受的逆境。因此，纵然我们里面并无足够的刚毅与恒心，使我们能在本分上片刻坚守，然而愿这一意念常存我们心中：神必看顾，使我们纵然被苦难压碎，也不至离弃对他的事奉。就算他终我们一生毫不间断地苦待我们，十字架对我们无疑总是有益的；因为我们看见我们肉体的悖逆何等难以驯服，它又以何等猛烈的冲力不住地沸腾；不，倒不如说，它在那本该使它归于顺服的苦难之中，仍不停地踢蹬。所以这一课的教训就更显必要——主适时地为我们的试探定下界限，因为他知道我们太软弱，无力抵挡。先知也不只是说软弱的人有跌倒之虞，乃是说连那些以真诚从心里事奉神、殷勤操练圣洁生活的义人，也有被重担压垮之虞。因此，无论敬畏神的心在我们里面何等有力，我们总要记得：若非主顾念我们的软弱，我们并未得着足以坚忍到底的力量。圣灵既对最优秀的勇士作此宣告，那么对那些尚未受完全操练、初入战阵的新手又将如何呢？此处所用的说法也值得留意——<span style="color:#800000">*免得他们伸出手来*</span>；这是表明试探的攻击何等猛烈，以致义人的手，先前可说是被捆住的，其动作也是按神的旨意被塑造、被规范的，如今却仿佛被松开，毫无约束地去从事犯罪。

<!-- PAGE 657 -->

**4.** <span style="color:#800000">*耶和华啊，求你善待那些为善和心里正直的人。*</span> 先知已经向一切信徒应许了神及时的帮助；然而他仍旧诉诸祷告，这并非没有缘故；因为信心虽能扶持我们，但由于我们属肉体的知觉与理性摇摆不定，我们理当以祷告相伴，好叫自己得着坚固。那么，让我们效法先知这条准则：他既劝勉一切信徒当存信靠之心，同时又教导他们不可无所事事、袖手闲坐，而当投奔神，藉着祷告恳切求他成就他藉自己的话吩咐他们所盼望的。诚然，使用这药方之要紧，从以下一点即可看出：在患难的黑暗之中，人看不见神的帮助，反倒似乎觉得他不分别义人与恶人。诗人在此不单单祈求神恩待良善之人，他还界定了那使他们与众不同的良善，即出于内心真诚情感的良善。神的儿女若仅仅戒绝一切恶行，而没有与之相称的心中正直为标记——或者说，若这正直不管辖他们的全部生活——那是不够的。

**5.** <span style="color:#800000">*至于那偏行弯曲道路的人，*</span>等等。既然分词 <span style="color:#008080">המטים</span>（*hammattim*）属于 *Hiphil*（使动）语干，按文法规则本应译为主动之意——<span style="color:#800000">*那使人偏离的人*</span>；但该语干的动词被取作中性含义并非罕见，所以我所采用的译法很可能是正确的。不过，主动的含义也同样贴切，我愿让读者自由运用自己的判断。其意思是：那些人一面夸口于空洞虚假的信仰告白，一面随自己的私欲东游西荡，甚至败坏单纯的人，把他们拖入与自己同样过度的犯罪之中；神并不总是对这等人的邪恶视而不见。我毫不怀疑，诗人在此所说的是假冒为善之人，他们因一时不受刑罚而变得刚硬，竟因神对他们宽容忍耐，就自居于至圣之人的行列中。我们所见的，不只是世上善恶混杂，我们更看见在主的禾场上，麦子隐藏在糠秕与渣滓之下。在这暧昧混乱的光景中，恶人心高气傲，好像自己是<!-- PAGE 658 -->神最好的仆人之列。因此我们理当祈求神将他们拖到光中来，与作孽的人一同推下去，受他们所应得的刑罚。其结果便是<span style="color:#800000">*平安*</span>，先知愿这平安归于以色列。他并非泛指亚伯拉罕按肉体所生的全族；他所愿的，乃是神的教会得以洁净，除去那些占据其中地位的假冒为善之人，直到神举手施行审判。因此我说过，教会的平安正源于此——神向那些撕裂、扯碎教会腹中肺腑的假冒伪装的以色列人施行他公义的报应，同时聚集心里正直的人，并藉着他的赐福公开显明他向他们所怀的父亲般的慈爱。
