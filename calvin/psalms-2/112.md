<p class="title-block-h1" style="text-align:center; font-size:22px; font-weight:bold; margin:18px 0 12px;" markdown="1"><span style="color:#0000d4">诗篇 112</span></p>

世人大多指望靠恶行发达，通常竭力以掠夺、欺诈和各样不义来使自己富足；因此先知在此列举神的诸般赐福，就是那些以纯正之心敬拜他的人所得的福分，为要叫我们晓得：立志过敬虔正直的生活，绝不至于失了赏赐。[^fd341]

<h2 class="scripture-anchor" id="psalm-112-1-3" data-ref="PSALM 112:1-3" style="display:none">诗篇 112:1-3</h2>

<div class="scripture-box" markdown="1">
<p class="scripture-ref"><span class="ages-code">&lt;19B201&gt;</span><span class="book-name">诗篇</span> <span class="verse-range">112:1-3</span></p>

**1.** 你们要赞美耶和华！敬畏耶和华，甚喜爱他命令的，这人便为有福！ 2. 他的后裔在世必强盛；[^fd342]正直人的后代必要蒙福。 3. 他家中有货物，有钱财；他的公义存到永远。

</div>

<!-- PAGE 436 -->
**1.** <span style="color:#800000">*敬畏耶和华*，*这人便为有福*</span>。虽然先知以劝勉开篇，但正如我先前已指出的，他的目的不止于单单呼吁信徒赞美神。行恶与行不义，在各处都被视为莫大的福气；纵然正直偶尔也受人称赞，然而百人中几乎难有一人追求它，因为众人都以为，若不用这样或那样的手段，把凡落到手中的一切都攫为掳物，自己必定悲惨。与此相反，先知告诉我们：从神慈父般的眷顾中所可指望的益处，远胜过我们竭尽所能施行各样伤害、犯下各样不义所得的；他借着把确实的赏赐盼望摆在我们眼前，召我们回到公平与行善的实践上。以下是我对本节的分析：<span style="color:#800000">*敬畏耶和华、喜爱他命令的，这人便为有福*</span>；这样，先知就借本节的后半句，指明敬畏神究竟在于什么。而这一解释性的补充之所以必要，从我们在前一篇诗篇末了所论的，便十分显明。因为当律法被世人肆意藐视之时，最寻常不过的事，莫过于人假称自己敬畏神。先知对这等不虔驳斥得极好，他所承认的敬拜神之人，惟有那竭力遵守神律法的人。希伯来文动词 <span style="color:#008080">≈pj</span>（*chaphets*）颇有力度，意思仿佛是*以此为乐*，我译作<span style="color:#800000">*喜爱*</span>。因为先知在此区分了甘心迅速地努力遵守律法，与那仅仅出于奴仆式、被迫的顺从。所以我们必须欢欢喜喜地领受神的律法，并且要以这样的方式领受：使那对律法之爱、并其一切甘甜，胜过肉体的一切引诱；否则，单单留意律法也是徒然。因此，人不能被看作律法真正的遵行者，直到他达到这一地步——即他在神律法中所得的喜乐，使顺从对他成为乐事。现在我再回到本段的整体来看。先知既断言敬拜神的人*是有福的*，便警戒我们防备不敬虔的人加在自己身上那极危险的欺骗，就是妄想自己能从作恶中收获某种我所不知的幸福。

<!-- PAGE 437 -->
**2.** <span style="color:#800000">*他的后裔在世必强盛*</span>。为要证实他先前所论的——敬畏耶和华、甚喜爱他命令之人的福分——先知在此列举神向敬拜他之人所惯常施予的慈爱凭据。首先，他说神那父亲般的恩慈并不止于他们本身，也延及他们的后裔；正如律法中所说的：「爱我、守我诫命的，我必向他们发慈爱，直到千代」，出埃及记 34:7。在<span class="ages-code">&lt;19A308&gt;</span>诗篇 103:8、9 以及别的经文中，我们已经论及这条教义。然而，因为有不少人惯于曲解这条教义，把它当作衡量神分派现世恩惠的准绳，所以当记住我在诗篇 37:25 所说的：这些恩惠乃是照着神所喜悦的方式与分量赐下的。有时敬虔人反倒无儿无女，而不生育本身在当时被视为神的咒诅。再者，神的许多仆人被贫穷缺乏所压，被疾病的重担所困，又被各样灾祸搅扰困惑。因此必须持守这条总原则：神有时更丰盛地、有时更节制地把他的厚赐倾于他儿女身上，全按他所看为对他们最有益的；而且，他有时还隐藏他慈爱的凭据，好像全然不顾念他的子民一般。然而，在这一片扑朔迷离之中，仍不断显明这些话并非徒然：<span style="color:#800000">*义人和他们的后裔是蒙福的*</span>。神极常吹散不敬虔之人的虚妄指望；他们一心所求的，无非是在世上掌权，并把儿女抬举到富贵尊荣的地位。反过来，信徒既以敬畏神的方式养育儿女为满足，又甘心过俭朴的生活，神便仿佛伸手将他们高举到尊荣的地步。还要加上一点：在古时律法之下，这教义的真实性更为显著；因为对一群缺乏经验、软弱的百姓，必须借着现世的恩惠循序渐进地加以训练，好叫他们怀抱更美的盼望。就是在我们这时代，若不是因我们的种种恶行，神现世的恩慈本会更明亮地照在我们身上。因为经验表明，紧接着所附加的这句话并非一律应验：<span style="color:#800000">*他家中有货物，有钱财*</span>。品德端正、圣洁的人忍饥挨饿、连最粗陋的口粮也缺乏，这并非罕见的事；正因如此，神若赐他们更多属地的好处，反倒于他们无益。在困苦的处境中，他们当中许多人尚且不能行事为人与所蒙的呼召相称。同时我们可以留意：先知所称许的这恩典，主要显在这一点上——良善诚实的人以自己微薄的家境为足，而不敬虔的属世之人，纵然得着极大的产业，甚至得着全世界，也仍不知足。那句古谚是真的：贪婪的人不但缺乏他所没有的，也缺乏他所有的；因为他一无所主，反作了自己财富的奴仆。与这一句相连的，还有下面所接的：<span style="color:#800000">*他的义存到永远*</span>。事实上，这正构成敬虔人与不敬虔人之间真实而恰当的分别；因为后者或可一时积聚巨富，但那一切都要照先知的话，「因我的殿荒凉，你们各人却顾自己的房屋」，或如经上所言，被全能者一吹便忽然消散，哈该书 1:9。我们也天天看见，凭强暴诡诈所得的，转成了别人的猎物与产业。但对信徒而言，他们的正直乃是神诸般恩福最好、最稳妥的保守者。

<!-- PAGE 438 -->

<h2 class="scripture-anchor" id="psalm-112-4-8" data-ref="PSALM 112:4-8" style="display:none">诗篇 112:4-8</h2>

<div class="scripture-box" markdown="1">
<p class="scripture-ref"><span class="ages-code">&lt;19B204&gt;</span><span class="book-name">诗篇</span> <span class="verse-range">112:4-8</span></p>

**4.** 光在黑暗中向义人升起[^fd343]：他有恩惠，有怜悯，有公义。5. 善人[^fd344]施怜悯，并且借贷：他按正直处理自己的事务。6. 他必永不动摇：义人被记念，直到永远。7. 他听见凶恶的信息必不惧怕：他心坚定，因为他倚靠耶和华。8. 他心确定，总不惧怕，直到[^fd345]他看见自己的心愿[^fd346]临到仇敌身上。

</div>

<!-- PAGE 439 -->
**4.** <span style="color:#800000">*光……升起*</span>。希伯来文动词 <span style="color:#008080">jrz</span>（*zarach*，撒拉赫）可作不及物动词解，如我在正文中所采用的；也可作及物动词解，如旁注所载；无论哪一种，意义都是一样的。无论你采用哪一种译法，这些话都可有双重解释：或是说，正如太阳照在地的一方，而地的其余部分都被黑暗笼罩，照样，神也使义人免受人生共有的灾祸；或是说，正如白昼接续黑夜，照样，神虽容许他仆人的心暂时忧伤，却必使平静与晴朗的日子重新临到他们。若采用后一种解释，那么先知所说的<span style="color:#800000">*黑暗*</span>，或阴云、霪雨、暴风之季，便是指神加于他仆人身上、为要试验他们忍耐的那些苦难。前一种解释似乎更为合宜，即：当全世界被患难所淹没之时，神的恩典却照耀在信徒身上，他们因神向他们施恩而得安慰、得喜乐。他们的境况正是这样与其他人共有的命运恰当地区别开来。因为不敬虔的人，虽在亨通中夸耀，却仍是在光中瞎眼，因为他们与神的父性慈爱无分；而在逆境中，他们又被投入死荫的幽暗，因此他们从不享有安宁平静的时刻。相反，敬虔人既有神的恩眷常照，虽也不免遭遇人所难免的祸患，却从不被黑暗吞没；因此这里所说的<span style="color:#800000">*光在黑暗中向他们升起*</span>，是极其恰当的。若我们把这希伯来文动词作主动意义解，那么就某一方面而言，字句的结构会更为妥当。因为我毫不怀疑，先知的意思是把<span style="color:#800000">*有恩惠、有怜悯、有公义*</span>这几个称谓归于神。所以，若我们把它读作中性（不及物）动词——<span style="color:#800000">*光升起*</span>——那么本节后半句便是前半句所言之缘由。至于那种解释，说义人与仁慈之人不像不义与邪恶之人那样把黑暗散布于世上，说他们不是从光中生烟，乃是从烟中生光——这只能视为对先知言语的一种曲解。

<!-- PAGE 440 -->
**5.** <span style="color:#800000">*善人*</span>。这是本段通常被接受的解释。然而我倒宁愿采取另一种解释，即：凡施恩慷慨的人必得福乐；因为这更合乎先知言语的主旨。他的用意是要显明：不敬虔的人用奸恶不法的手段去追求幸福，是何等地自欺；因为神的恩眷才是一切美善的源头与根由。因此就必须补上关系代词*凡……的人*。于是他继续提醒我们提防那些人的自欺——他们急欲靠着卑鄙的吝啬与横暴的勒索发财致富；而信徒却藉着他们的宽厚与仁慈，开通了一条渠道，使神的恩眷藉此流向他们：因为 <span style="color:#008080">bwf</span>（*tob*，托伯）一词，虽是阳性，意为<span style="color:#800000">*善*</span>，却常被当作中性使用，指美好之事。他把<span style="color:#800000">*借贷*</span>放在这里，仿佛是怜悯所结的果子；因为放高利贷的人也借贷，只是他假借帮助困苦人之名，为要掠夺他们。所以，神所使之亨通的，乃是那真正慷慨的人——他们出于怜悯，而非出于陷害穷人的图谋，向穷人施以周济。本节末了的 <span style="color:#008080">µybd</span>（*debarim*，德巴林）一词，意为*言语*；但我与拉比中最精确的解经者大卫·金希（David Kimchi）一同，把它理解为<span style="color:#800000">*事务*</span>。译作*言语*是极为平淡无味的，[^fd347]更不用说，若先知果有此意，他必会用更简明的措辞来表达。我所采用的译法才是恰当的，即：义人必以谨慎与明辨处理自己的事务；因此，在家务上，他们既不奢侈浪费，也不卑鄙吝啬；乃是凡事力求俭朴与节制并行，绝不放纵奢华。而在一切商务往来中，他们也总是以公平与道德的原则为准绳。

**6.** <span style="color:#800000">*他永不动摇。*</span> 希伯来文虚词 <span style="color:#008080">yk</span>，*ki*，在此可按其本义或因果义来理解，因而译作 *因为*，尤其当我们在前一节采纳旁注的读法「这人必得福」时更是如此。因为他在此以更明确的措辞论及他先前所说的那种福乐，即：神扶持怜悯人、慈爱待人的人，使他们在人生一切变迁之中屹立不动；神使他们的清白显明，保护他们免受不公的毁谤。经上说 <span style="color:#800000">*他们永不动摇*</span>。诚然他们并非不遭遇人所常遇的事，甚至常常看似将要在灾祸的重压下沉沦；然而他们的信靠丝毫不动摇，凭着不可战胜的忍耐胜过一切逆境。虽有神作他们义的辩护者，他们仍不免遭受不敬虔之人的诽谤攻击；但对他们而言，只要自己的名在神面前、在众天使面前、在敬虔人全会众面前蒙福，这就够了。

<!-- PAGE 441 -->
**7.** <span style="color:#800000">*他必不怕凶恶的信息*</span>。这似乎是对前一节所述的印证，意思无非是说：义人得免于恶人因其败坏行径而自招的臭名。不过我宁可这样理解：义人不像不信者那样，一听见风吹草动便战兢不安；乃是在临到他们的一切凶恶信息中，安然平静地倚靠神慈父般的看顾。不信者何以常在惶惑不安之中？岂不是因为他们幻想自己在地上不过是命运的玩物，而神却在天上安逸无事么？既然如此，落叶的窸窣声使他们烦扰惊惶，也就不足为奇了。信徒得免于这样的不安，因为他们既不理会流言，也不因惧怕流言而停止不断地呼求神。神的儿女在危难迫近之时，或许也会显出惧怕的迹象；因为他们若对灾祸全然无动于衷，这种漠然便不是出于对神的信靠，而是出于麻木无感。但即或他们不能全然放下惧怕与忧虑，他们仍承认神是他们生命的守护者，照常走自己当行的路，把自己交托于神保守的看顾，欣然听凭他的安排。这就是义人的宏大气度；先知宣告说，在这气度的影响之下，他们能不把那些使别人惊惶的凶恶传闻放在心上。他们倚靠神的扶持，也确是智慧之举；因为我们四面被无数的死亡围困，若不是靠着「我们在神的保护之下必得安稳」这一信念托住，早已陷入绝望了。可见，先知在此所描述的，才是真正的稳固，它*在于*以不动摇的信靠安息于神。反之，不敬虔之人所醉心的那种狂妄自信，反倒使他们更招惹神的震怒，因为他们无视人生的脆弱，心里骄傲，狂妄地与神为敌。所以，「人正说平安稳妥的时候，灾祸忽然临到他们」（帖撒罗尼迦前书 5:3）。然而对灾祸的知觉，虽使信徒惊动不安，却不至使他们灰心丧胆，因为这并不动摇他们的信心，而信心使他们刚强坚定。总之，他们对自身的试炼并非毫无所感，[^fd348]但他们置于神身上的信靠，使他们能超越今生一切的挂虑。他们因此保守心思的平静与镇定，耐心等候，直到向恶人施行报应的时候来到。

<h2 class="scripture-anchor" id="psalm-112-9-10" data-ref="PSALM 112:9-10" style="display:none">诗篇 112:9-10</h2>

<div class="scripture-box" markdown="1">
<p class="scripture-ref"><span class="ages-code">&lt;19B209&gt;</span><span class="book-name">诗篇</span> <span class="verse-range">112:9-10</span></p>

**9.** 他施舍，周济贫穷；他的仁义存到永远。他的角必被高举，大有荣耀。10. 恶人看见便恼恨，必咬牙而消化；[^fd349]恶人的心愿要归灭绝。

</div>

<!-- PAGE 442 -->
**9.** <span style="color:#800000">*他施舍，周济贫穷*</span>。他再一次断言，义人绝不会失去他们慷慨的果子与报偿。首先，先知以<span style="color:#800000">*施舍*</span>（分散）一词暗示，他们并非吝啬勉强地施与——如某些人所行的，以为把一点点微薄的施舍丢给穷人便算尽了本分——乃是照着需要之所急、能力之所及，慷慨地施与；因为有可能一颗慷慨的心并不拥有今世丰厚的财物。先知的意思无非是说，他们绝不至于吝啬到不随时按其力量施舍。接着他又补上，<span style="color:#800000">*周济贫穷*</span>，意即他们并非漫无目的地施行慈惠，乃是以智慧与判断力去满足困乏者的需要。我们知道，为着炫耀而作的不必要、过度的花费，往往为世人所称赞；因此，挥霍在奢华与虚荣上的今世美物，远多过审慎施与的慈惠。先知教导我们，慷慨所当得的称赞，并不在于毫不顾及施与的对象与用途而散尽己物，乃在于救济真正困乏之人，并将钱财用在正当合法的事上。这段经文被保罗所引用（哥林多后书 9:9），他在那里告诉我们，神大可以丰丰富富地赐福与我们，使我们能自由地、慎重地、不偏私地施行慷慨，这与先知的用意最为吻合。下一句，<span style="color:#800000">*他的仁义存到永远*</span>，可有两种解释。那驱使不敬虔的人挥霍财物的过度虚荣心，不配称为美德。因此，可以恰当地说，先知在此所称赞的，乃是持之以恒的慷慨，正如他先前所论的，*义人办事有分辨。* 若有人宁愿将之归于义的果效，我也不反对。而且，这确实似乎是重复我们方才所留意的同一句话。于是先知显明，神如何藉着祂的恩惠保守那因他们慷慨而当得之义的荣耀，并不使他们的赏赐落空，因祂越发高举他们的角，即他们的能力或兴盛的境况。

<!-- PAGE 443 -->
**10.** <span style="color:#800000">*恶人看见便惱恨。*</span> [^fd350]此处所接续的对比，与我们在诗篇 2:5 中所见的相似，它使神向信实之人所施的恩典更加显赫。他的意思是：恶人虽可尽然抛弃一切对敬虔的顾念，从心中驱逐一切"人间万事皆在神看顾之护理之下"的思想，他们却终必被迫感受到——无论他们愿意与否——义人遵从神的命令、专心致志于培养仁爱与怜悯，并非徒然。任凭他们随意刚硬己心，先知却宣告说，神加于其儿女身上的尊荣，必要陈列在他们眼前；他们一见此景，便要咬牙切齿，并激起一种嫉妒，将他们一寸一寸地消磨殆尽。[^fd351]末了他又补充说，<span style="color:#800000">*恶人的心愿要归灭绝*</span>。他们从不知足，反倒不住地渴求着什么；他们的自恃何等狂妄，他们的贪婪便何等无边。因此，在他们愚妄的指望中，他们竟毫不迟疑地想要攫取全世界。但先知告诉他们，神必从他们手中夺去那他们自以为已经到手之物，以致他们始终一无所有、饥饿而去。
