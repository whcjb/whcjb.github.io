<p class="title-block-h1" style="text-align:center; font-size:22px; font-weight:bold; margin:18px 0 12px;" markdown="1"><span style="color:#0000d4">第五章</span></p>

<p style="text-align:center" markdown="1"><span style="color:#000080">前往创世记 5:1-32</span></p>

<div class="commentary-anchor" id="genesis-5-1"></div>
**1.** <span style="color:#800000">*这是亚当的后代记略*</span>。在本章中，摩西简要地叙述了从世界受造到洪水之间所经过的时间长度；同时也略微触及那段时期历史的一部分。虽然我们不能测透圣灵的用意——为何祂将一些伟大而值得记念的事件略去不载——但默想那些被沉默带过之事，仍是我们分内当尽的本分。我全然不赞同各人凭轻率臆测为自己编造的种种猜想，也不愿给读者留下在这方面放纵己意的机会；然而，正如我们将在合适之处所见，从这段朴素而看似枯燥的记载中，多少仍可推知那时代的光景。按希伯来文的用法，「书」乃指一份名录。「后代」意指一个族类连续不断的传承，或说一脉相连的子嗣。此外，编制这份名录的用意，乃是要告诉我们：在这庞大——或不如说是浩瀚惊人的——人群中，始终有一群人，虽为数不多，却敬拜神；并且这一小群人蒙上天护佑，奇妙地得蒙保守，免得神的名被完全抹去，也免得教会的后裔断绝。

<!-- PAGE 146 -->
<span style="color:#800000">*当神创造的日子*</span>。他并非将这些「后代」局限于创造之日，而只是指出其起始；同时，他将我们的始祖与其余人类区分开来，因为神是以一种独特的方式赐予他们生命，而其他人则出于先前的族类，是由父母所生。[^f251] 此外，摩西再次重复他先前所述的，即亚当是照着神的形象被造的，因为这一恩眷的卓越与尊荣是无论怎样称颂都不为过的。人在受造之物中被赋予首要的地位，这本已是极大的事；但更为崇高的尊贵在于，他要与他的创造主相似，正如儿子肖似父亲一般。神对人所行的，实在不可能比将他自己的荣耀印在人身上更为慷慨，仿佛使人成为神的智慧与公义的活的形象。这一点也有力地驳斥了恶人的诽谤——他们巴不得将自己邪恶的罪责推给他们的创造主，倘若不是经上明确宣告：人按其本性受造时，原是与他如今这般大不相同的存在，乃是因他自己背离神的过犯，才沦为现今的模样。

<div class="commentary-anchor" id="genesis-5-2"></div>
**2.** <span style="color:#800000">*他造男造女*</span>。这一句称许了婚姻的神圣纽带，以及丈夫与妻子之间不可分离的结合。因为摩西虽然起先只提到一个人，随即便将*二者*都涵括在*一个*名称之下。他不加区别地将一个共同的名字赋予二人，为要叫后世更加圣洁地珍视彼此之间的这种联系，因他们看见自己的始祖被称为一个人。犹太作者们那微不足道的推论——说*惟有*已婚之人才被称为亚当（或人）——已被创造的历史所驳倒；圣灵在此处所指的，实在不外乎是说：婚姻设立之后，丈夫与妻子便如同一人。此外，他记下神向他们所宣告的祝福，为要叫我们从中看见神持续赐下这祝福的奇妙慈爱；然而我们也当知道，由于人的败坏与邪恶，这祝福在某种程度上曾被打断。

<!-- PAGE 147 -->
<div class="commentary-anchor" id="genesis-5-3"></div>
**3.** <span style="color:#800000">*并且生了一个儿子，形像样式和自己相似*</span>。我们方才已经说过，摩西只沿着塞特这一支追溯亚当的后裔，目的是要我们思想教会的传承。他说塞特生了一个儿子，样式和自己相似，这一方面指向我们本性最初的源头；同时也当留意其中的败坏与污秽——这败坏乃是亚当因堕落而沾染的，又流传到他一切的后代。假如他持守正直，他必将自己所领受的传给一切儿女；然而如今我们读到，塞特和其余的人一样都被玷污了，因为亚当既已从起初的地位坠落，他所能生的就无非是与自己相似的人。若有人反驳说，塞特和他的家室是蒙神特殊恩典拣选的，答案是显而易见的：超自然的补救并不能拦阻属肉体的生育去分沾罪的败坏。因此，按肉体说，塞特生来是罪人；但后来他借着圣灵的恩典得以更新。这位圣洁列祖身上这可悲的例证，给了我们充分的缘由去哀叹自己的凄惨光景。

<div class="commentary-anchor" id="genesis-5-4"></div>
**4.** <span style="color:#800000">*亚当生塞特之后的日子*</span>。在此处所记载的年数中，我们尤其应当思想列祖共同在世相处的漫长岁月。因为历经连续六个世代，当塞特一族已繁衍成众多之民时，亚当的声音仍可每日回响，好叫众人重新记念神对人的创造、堕落与刑罚；见证那在惩治之后仍存留的救恩盼望，并复述神的诸般审判，使众人都可从中得着教导。他死后，他的众子固然可以将所学的，如同手手相传一般，交付给他们的后裔；然而，从那位亲眼目睹这一切之人口中所出的教诲，其果效必远为深切。可是，那普遍的顽梗竟是如此奇异、甚至骇人，以致连人类中较为健全的那一部分，也不能被存留在对神的顺服与敬畏之中。

<div class="commentary-anchor" id="genesis-5-5"></div>
**5.** <span style="color:#800000">*他就死了*</span>。这句记录每位列祖之死的话，绝非多余。因为它警戒我们：死亡向人所宣告的刑罚并非徒然；除非我们从别处得着拯救，否则我们如今仍伏在那定给人的咒诅之下。同时，我们必须思想自己何等可悲的光景，就是：神的形象在我们里面既被毁坏，或至少已被抹去，我们所存留的不过是生命微弱的影子，而我们正从这影子中匆匆奔向死亡。在这样一幅历经诸多世代的图画中，一眼便可看见神的报应如何持续不断、始终如一，这是有益的；因为若非如此，我们便会想象神仿佛在某种程度上遗忘了；而我们最容易犯的毛病，莫过于妄想在地上得着不死，除非死亡屡屡被摆在我们眼前。

<!-- PAGE 148 -->
<div class="commentary-anchor" id="genesis-5-22"></div>
**22.** <span style="color:#800000">*以诺与神同行*</span>。无疑，以诺在他同时代的人中被赋予了独特的赞誉，因为经上说他与神同行。然而当时塞特、以诺、该南、玛勒列和雅列也都还活着，他们的敬虔在本章前半部分已被称颂。[^f252] 既然那个时代拥有如此众多最卓越的教师，就不可能是更粗鲁或野蛮的时代；由此我们推断，这位圣洁之人的正直——圣灵将他从常人的序列中提拔出来——是罕见的、几乎是独一无二的。与此同时，这里指出了一种方法，使我们防备被那些与我们交往之人的乖谬风俗所裹挟。因为公众的习俗如同猛烈的暴风；一方面因为我们容易任凭自己被众人牵着东奔西走，另一方面因为人人都以为凡是普遍被接受的就必然是正确合法的；正如猪彼此传染疥癣一样；没有什么传染比恶榜样更坏、更可憎的了。因此，我们更当殷勤留意这句话中所包含的对圣洁生活的简短描述：「以诺与神同行」。那么，愿意的人尽可以夸口自己是照别人的习俗而活；然而神的灵已经确立了美好而正直生活的准则，藉此我们脱离那些不照神律法塑造自己生命与品行之人的榜样。因为那藐视神的话语、任凭自己去效法世界的人，必被视为是为魔鬼而活。此外（正如我刚才所暗示的），其余所有的列祖并未被剥夺义的赞誉；但在一个人的身上，为我们摆出了一个卓越的榜样，他在最可怕的堕落放纵之时坚定站立；为要使我们，若愿意正直而有序地生活，能学会看重神过于看重人。因为摩西所用的言语，其力度无异于说：以诺为免被人的败坏引入歧途，惟独仰望神；如此，他便能以纯洁的良心，如在神眼前一般，培养正直。

<!-- PAGE 149 -->
<div class="commentary-anchor" id="genesis-5-24"></div>
**24.** <span style="color:#800000">*他也不在世了*</span>，<span style="color:#800000">*因为神将他取去*</span>。凡不肯承认此处所指乃是某种非比寻常之事的人，必是厚颜好辩之徒。诚然，众人都因死亡被从世上取去；但摩西明明宣告，以诺乃是以一种不寻常的方式被从世上取去，是被主以神迹般的方式接去的。因为在希伯来人中间，<span style="color:#008080">hql</span>（*lakah*）既有单纯「取」之意，也有「取归己有」之意。然而，我们无须纠缠于字义，只要牢牢把握事情本身即可，就是说：以诺在人生的中途，忽然以一种前所未有的方式从人的眼前消失，因为主将他取去，正如我们所读到主对以利亚所行的一样。既然在以诺的迁去一事上，显明了不朽的一个明证，那么毫无疑问，神有意在祂众圣徒离世之前，以确实的信心提升他们的心志；并借此安慰，缓解他们对死亡可能怀有的恐惧，因他们既知道另有一更美的生命为他们存留在别处。然而值得注意的是，亚当自己却被剥夺了这信心与安慰的支撑。因为神那可畏的判语「你必定死」不住地在他耳中回响，他极其需要某种慰藉，好叫他在死亡之中，除了咒诅与毁灭之外，还有别的可供思念。但直到他死后约一百五十年，[^f253] 以诺的迁去才发生，这原是要作为蒙福复活的一幅可见的写照；亚当若曾因此得着光照，本可以平静的心为自己的离世束腰预备。然而，既然主在施行刑罚时曾节制其严厉，且亚当自己亲耳从神口中听见足以给他不小宽慰的话；他既满足于这一类的救治，就当以耐心担当今世中这持续不断的十字架，以及他一生那苦涩悲哀的终局，这乃是他的本分。但至于其他人，既未曾照样借着明确的神谕受教去盼望战胜那蛇，那么在以诺的迁去一事上，便为所有敬虔之人存留了一个教训，就是他们不当把盼望局限在今生短暂的界限之内。因为摩西表明，这迁去乃是神对以诺之爱的凭据，他将此事紧接在以诺敬虔正直的生平之后叙述。尽管如此，丧失生命本身并非可羡慕之事。因此可见，他乃是被接到一个更美的居所；甚至当他还在世上作寄居者时，就已被接入一个属天的家乡；正如使徒在《希伯来书》（希伯来书 11:5）中所明明教导的。此外，若有人查问以诺为何被迁去，以及他如今的光景如何；我的回答是：他的迁移乃是出于一种特殊的恩典，正如其他人若一直保持其起初的状态，本也当有的一样。[^f254] 因为他虽然仍必须脱去那必朽坏的，却得以免去那本性所畏缩的强暴的分离。简言之，他的迁去乃是一次平静而喜乐的离世。然而他并未被接入属天的荣耀，只是脱离了今生的困苦，直到基督降临——就是那将要复活之人的初熟果子。既然他是教会众肢体中的一员，他就必须等候，直到众人一同前去迎接基督，好叫全身与其元首联合。倘若有人以使徒的话作为反驳，说：

<!-- PAGE 150 -->

<p style="text-align:center" markdown="1"><span style="color:#000080">「按着定命，人人都有一死，」（</span><span style="color:#000080">希伯来书 9:27，）</span></p>

答案很简单，即死亡并不总是灵魂与身体的分离；凡脱去其朽坏本性的人，也被称为死了：末日那些仍存活的人，其死亡便属于这一类。

<div class="commentary-anchor" id="genesis-5-29"></div>
**29.** <span style="color:#800000">*给他起名叫挪亚*</span>，<span style="color:#800000">*说*</span>，<span style="color:#800000">*这个儿子必为我们的操作……安慰我们*</span>。在希伯来文中，动词 <span style="color:#008080">µjn</span>（*nacham*）的词源与名词 <span style="color:#008080">jwn</span>（*noach*）并不吻合，除非我们把字母 <span style="color:#008080">µ</span>（*mem*）视为多余的；正如有时在合成词中，某些字母是冗余的。<span style="color:#008080">jwn</span> *Noach* 意为*赐下安息*，而 <span style="color:#008080">µjn</span> *nacham* 意为*安慰*。挪亚这名字是从前一个动词衍生而来的。因此，当拉麦说「这个儿子必为我们的操作安慰我们」时，其中要么是一个字母转换为另一个字母，要么只是单纯的*谐音影射*。[^f255] 但就眼下的要点而言，毫无疑问，他是在向自己应许一种劳苦的减轻或慰藉。然而有人会问，他既然还无从看出这儿子的性情，又何以对他怀有这样的盼望。犹太人宣称拉麦的话是一段预言，这判断并不错误；但他们过于粗浅，竟把本应适用于人生一切苦难——那些出于神咒诅、乃是罪之果实的苦难——的话，局限于农事一端。我确实得出这样的结论：那些圣洁的先祖之所以焦虑叹息，是因为他们被如此众多的祸患所围困，不断被提醒起一切祸患最初的根源，并视自己为处在神的不悦之下。因此，在「我们双手的操劳」这一表述中，含有*提喻*的修辞；因为他以一种劳苦，涵括了人类所堕入的整个悲惨境况。因为他们无疑记得摩西在前面所记述的，就是亚当被定命所过的那种劳苦、愁烦、忧虑的生活；而既然人的罪恶日益增长，倘若耶和华不施以意外的援助，这刑罚便毫无缓解的指望。他们极其恳切地仰望神的怜悯，这是很可能的；因为他们的信心刚强，而困厄催逼他们热切地渴求帮助。至于这名字并非草率地给了挪亚，我们可以从此推知，就是摩西特意将它标记为值得记念的事。诚然，其他先祖的名字底下也隐含着某种意义；然而摩西略过了他们何以如此得名的缘由，唯独强调挪亚这个名字。因此，不可容那好争辩的读者据此断言，说挪亚身上有某种特别之处，是在他以前的人所不具备的。这样，我便毫不怀疑，拉麦是盼望从他儿子身上得着某种罕见非常的事，而且这盼望乃是出于圣灵的默示。有些人以为他受了欺骗，因为他相信挪亚就是基督；但他们提不出任何合乎理性的推测来支持这看法。更为可能的是，他既见有某种伟大的事关乎他儿子被应许出来，便不禁将自己的臆想掺杂进那神谕之中；正如圣洁之人有时也惯于超越启示的分寸，如此一来，他们便既够不着天，也够不着地。

<div class="commentary-anchor" id="genesis-5-32"></div>
**32.** <span style="color:#800000">*挪亚五百岁*</span>。关于摩西迄今所列举的这些先祖，我们不容易推断他们各人是否都是本家的长子；因为摩西只想追述教会一脉相承的世系。但神为了防止人因血气的虚妄自信而自高自大，往往拣选那些按自然次序处于后位的人归于自己。因此，我不能确定摩西记录的名单，究竟是那些蒙神看重、优于他人之人，还是那些凭长子名分在弟兄中居首位之人；我也不能确定他们各人有几个儿子。至于挪亚，显然他只有三个儿子；摩西刻意屡次申明这一点，好叫我们知道他全家都得蒙保全。然而在我看来，有些人以为此处是在宣扬挪亚的贞洁，因为他独身度过将近五百年之久，这乃是错的。因为经文并没有说他直到那时仍未娶妻，也没有说他在几岁时开始为人之父。摩西不过是在提及他得知将来洪水之警告的那个时间时，同时补充说，大约在同一时期，他做了三个儿子的父亲；这并非说他那时已经有了他们，而是因为他们不久之后才出生。至于他确实在闪出生之前已过了五百岁，从第十一章可以看得明白（创世记 11:1）；至于其余二子，除了知道雅弗是最小的以外，别无确切可考。[^f256] 令人称奇的是，自从他领受了有关人类灭绝的可怕信息之时起，他并未因极大的忧伤而与妻子断绝同房；然而必须有些遗留之人存活下来，因为这一家注定要担负重建第二个世界的使命。虽然我们读不到他的儿子们是在何时娶妻的，我却认为这远在洪水之前就已行了；只是他们照着神的护理未曾生育，因为神已定意只保全八个人。

[^f256]: 加尔文之所以推断雅弗是幼子，似乎是根据一种与我们不同的创世记 10:21 译本得出的。在我们的译本中，那里称闪为「雅弗兄弟中的长者」。但注释家们普遍一致认为英文译本是正确的。它不仅更符合原文的自然含义，而且有旁证加以佐证。因为显然挪亚是在五百岁那年开始生子的。闪在洪水之后两年时是一百岁，因此是在他父亲五百零二岁时出生的。那么，挪亚必定有某个儿子是在此之前出生的。如今我们知道含是幼子（创世记 9:24）。因此雅弗必定是他的长子。——参看帕特里克（Patrick）与布什（Bush）的注释，以及威尔斯（Wells）的《旧约地理》。——编者注
