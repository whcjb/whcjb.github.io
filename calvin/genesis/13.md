**1.** <span style="color:#800000">*亚伯兰从埃及上去*</span>。在本章开头，摩西记念神保护亚伯兰的良善；因着这良善，他不仅平安归回，还带着大量的财富同去。这一情节也值得留意：当他离开埃及时，牲畜、财宝极其丰盛，却得以平平安安地继续他的行程；因为令人诧异的是，埃及人竟容让亚伯兰在他们中间所积攒的一切被转移到别处去。摩西接着表明，财富并未成为足以阻碍亚伯兰的障碍，使他不能持续地顾念自己所定的目标，也不能以不懈的脚步向着这目标前行。我们知道，即或只是中等的财富，也何等大地拦阻许多人向天举目；至于那些真正拥有丰盛家业的人，不但懒散地昏睡，甚至完全被埋在地里。因此，摩西将亚伯兰的美德与众人常有的恶习相对照；当他叙述亚伯兰不被任何拦阻所拘，重新寻求迦南地的时候。因为他本可以（像许多人那样）用某种冠冕堂皇的借口来自我安慰：例如，既然神——他从祂领受了非凡的恩福——在埃及待他恩慈良善，他就理当留在那里。但他并未忘记神所命定于他的；因此，他如同一个无所羁绊的人，急速奔向他蒙召所往之地。所以，富人若这样扎根于地，以致不理会神的呼召，就毫无可推诿的余地了。然而，在此有两个极端须要提防。许多人把天使般的完全归于贫穷；仿佛除非抛弃财富，就不可能操练敬虔、事奉神。诚然，效法底比斯人克拉特斯（Crates the Theban）——他把自己的财宝抛入海中，因为他认为除非那些财宝丧失，自己就不能得救——的人并不多。然而许多狂热之徒却把富人从得救的盼望中排斥出去；仿佛贫穷是进天堂的唯一门户；而贫穷有时反倒比财富使人陷入更多的拦阻。但奥古斯丁明智地教导我们说，富人与穷人都一同被收聚在同一份生命的产业中；因为贫穷的拉撒路被接到富有的亚伯拉罕的怀里。另一方面，我们也必须提防相反的恶；免得财富在我们路上设下绊脚石，或如此重压我们，使我们不那么甘心乐意地向着天国前进。

<div class="commentary-anchor" id="genesis-13-3"></div>
**3.** <span style="color:#800000">*他从南地渐渐往伯特利去*</span>。摩西在这些话里教导我们：亚伯兰没有安歇，直到他回到伯特利。因为他虽然在许多地方支搭帐棚，却在任何一处都未曾如此扎根，以至于把那里当作长久的居所。他说到「南地」，并非指埃及；他所指的不过是他已进到犹大地的南部；因此，他经过了漫长而艰辛的旅程，才抵达他决意要留居的地方。摩西接着补充说，那里从前已有他所筑的一座坛，而他此时又重新开始求告耶和华的名：由此我们可以看出，这位圣洁的人在敬拜神、显明他的虔诚上始终如一。有些人解释说，当地的居民已被带入对神纯正的敬拜，这种说法既不可信，也无法从摩西的话中推断出来。我们已在别处说明「奉……的名求告」或「求告耶和华的名」这一表达的含义；即是公开表明对神真实而纯正的敬拜。因为亚伯兰求告神，并不只是他一生中那十二次而已；乃是每当他公开尊崇神，并借着庄严的礼仪显明他与外邦人的迷信毫无相干时，就说他求告了神。因此，虽然他常常敬拜神，天天操练祷告；然而，正因他没有天天在人面前借外在的表白见证他的虔诚，摩西在此便特别称许这一美德。所以，把求告与祭坛联系起来乃是合宜的；因为借着所献的祭物，他清楚地见证了他所敬拜的是哪一位神，为要使迦南人知道他并未沾染他们通行的偶像崇拜。

**5.** <span style="color:#800000">*与亚伯兰同行的罗得*</span>。接下来所记的，是亚伯兰因财富而遭受的不便：他被迫与自己深爱的侄儿分离，仿佛骨肉被割裂一般。诚然，倘若容他选择，他宁愿抛弃财富，也不愿与这位他视如独生子的人分开；然而他找不到别的方法来避免纷争。我们该把这桩憾事归咎于他自己过分的执拗，还是归咎于他侄儿的莽撞呢？不过，我认为我们更该思想神的旨意。当时有一种危险，就是亚伯兰或许会因自己的顺遂而沾沾自喜，因为兴旺常使许多人盲目。因此神以苦味来冲淡财富的甘甜，不容他仆人的心过分被财富所迷。每当对财富的虚妄估量驱使我们无度地贪求它——因为我们看不见财富所附带的种种大害处——但愿这段历史的回忆能拦阻我们对财富这般无度的迷恋。再者，凡富足之人若因财富而遇任何烦扰，就当学习用这剂良药洁净自己的心，免得过分沉溺于今生的美物。实在说来，若非主时而给人套上嚼环，人在兴旺满溢之时，岂不堕入难以测度的深渊么？另一方面，我们若被贫穷所困，就当知道：神也借此法矫正我们肉体中隐藏的邪恶。末了，愿那富足的人记得，自己被荆棘环绕，务要谨慎免得被刺；也愿那境遇窘迫、诸事受挫的人知道，神正眷顾他们，好使他们不致陷入邪恶有害的网罗。这次分离叫亚伯兰心中忧伤，却适于矫正许多潜伏的邪恶，免得财富窒息他热心的甲胄。然而亚伯兰既需要这样的解毒剂，我们就不必希奇：神若借着施加某种打击来抑制我们的放纵。因为祂并不总是等到信徒跌倒之后才动手，乃是预先为他们顾念将来。所以祂并非当真在矫正祂仆人亚伯兰的贪婪或骄傲，而是借着预防性的医治，使撒但不能以任何诱惑玷污他的心。

**7.** <span style="color:#800000">*于是起了争执*</span>。我先前论到财富所提示的道理，同样也适用于庞大的仆役随从。我们看到，许多人怀着何等的野心，渴望拥有一大群仆人，几乎多得如同一整个民族。但既然亚伯兰的家眷使他付上如此昂贵的代价，我们就当心满意足地只有少数仆人，甚或全然没有仆人——倘若主看为合宜要如此。在一个人数众多的家中，几乎不可能避免极大的纷乱。经验也证实了那句箴言的真确：人群通常是骚动不安的。既然安宁与平静乃是无可估量的美善，就让我们明白：当我们拥有一个小家，安静地、不受喧扰地在家人中间度日时，我们才最能顾及自己真实的福祉。这个摆在我们眼前的例子也警戒我们，要谨防撒但用迂回的方法把我们引入争竞。因为当他无法在我们之间点燃彼此的仇恨时，他就要把我们卷入他人的纷争。罗得与亚伯兰彼此和睦，然而他们牧人之间所起的争执，却不由分说地把他们裹挟而去，以致他们被迫彼此分开。毫无疑问，亚伯兰曾忠心地教导自己的人要培育和睦；然而他的心愿与努力却未能成功到足以拦阻自己目睹家中燃起那最具毁灭性的不和之火。因此，倘若我们看见教会中——那里人数更为众多——常常兴起纷扰，这也就不足为奇了。亚伯兰约有三百个仆人，罗得的家眷很可能与之相近：[^f351] 那么，当五六千人——尤其是自由人——彼此相争时，又当预料会发生什么呢？然而，正如我们不应因这等丑事而受扰乱，我们也必须千方百计地留意，不让争竞演成暴烈。因为除非迅速加以应对，它们不久便要爆发为致命的分裂。

<span style="color:#800000">*迦南人与比利洗人*</span>。摩西加上这句，是为要突显这罪的严重。因为他表明这争执之激烈已到了如此地步，以致连迫在眉睫之毁灭的恐惧都无法将其扑灭或缓和。他们四围的仇敌，多如他们的邻舍。因此，要使他们灭亡，所缺的不过是一个合适的时机；而这时机正是他们自己借着争吵所提供的。盲目的狂怒竟能如此使人昏聩：一旦争竞的激烈占了上风，人便漫不经心地藐视那摆在眼前的死亡。如今，我们虽不像他们那样时时被迦南人所环绕，然而只要我们还寄居在世上，就仍处于仇敌之中。所以，我们若对自己和弟兄的得救怀有任何渴慕，就当谨防那要把我们交给撒但去毁灭的争竞。

**8.** <span style="color:#800000">*亚伯兰对罗得说*</span>。摩西首先陈明：亚伯兰一察觉纷争已经兴起，便立即尽了一个好家主的本分，设法在自己的家仆之间恢复和睦；随后，又以他的宽厚，藉着除去这祸患来医治它。虽然争竞的只是那些仆人，他说「你我不可相争」却并非徒然：因为争端的传染几乎不可能不从家仆蔓延到他们的主人身上，纵然在其他事上他们全然和睦。他也预见到，除非及时设法医治这暗藏的祸患，他们的友谊便不能长久保全无损。此外，他提醒对方彼此之间骨肉相连的关系；这并不是说单凭这一点就足以促进彼此和睦，而是好叫他更容易折服并软化他侄儿的心。因为当敬畏神在我们心中所生的果效不及本当有的那样大时，援引其他一些能使我们持守本分的帮助，也是有益的。然而如今，既然我们众人都被收纳为神的儿子，且附带着这样的条件，就是我们彼此之间当互为弟兄：那么，倘若这神圣的联结不足以平息我们的争竞，它在我们心中所受的看重，就不及本当有的那样了。

<div class="commentary-anchor" id="genesis-13-9"></div>
**9.** <span style="color:#800000">*遍地不都在你眼前吗？*</span> 这里正体现了我前面所说的那种克制；就是说，亚伯兰为了平息纷争，甘愿放弃自己的权利。因为野心与求胜之欲[^f352]乃是一切争端之母；所以，当各人都温和有度地在某种程度上让开自己正当的主张时，便找到了除去一切苦毒之根的最佳良方。亚伯兰本可以名正言顺地更加固执地坚守他所放弃的那份权利，然而为了恢复和睦，他甘愿舍弃一切：因此他把选择权留给了他的侄儿。

**10.** <span style="color:#800000">*罗得举目*</span>。正如亚伯兰的公平极堪称许，摩西在此所描述的罗得的轻率，则应受责备。他本当反倒与叔父争让谦逊之美德；这也正是自然的次序所提示的；然而他却仿佛在各方面都高人一等似的，为自己攫取了较好的份，拣选了那看似更肥沃、更宜人的地方。而事实上必然如此：凡过于急切专注于自身利益的人，对他人便缺乏仁爱。毫无疑问，这不义之举必刺痛亚伯兰的心；但他默然忍受，唯恐因此又生出新的争端。每当我们察觉与我们相关的人不够顾念自己的本分时，我们也全当这样行；否则纷争便永无止境。当邻近所多玛的平原被比作神的乐园时，许多注释者只将其解为：那地极其美好、肥沃至极；因为希伯来人称任何卓越之物为「神圣的」。然而我认为，此处所指的乃是亚当起初所居之处。因为摩西并非提出一种笼统的类比，而是说：「那地是有水滋润的」；正如他论到人最初的居所时所述的一样，即有一道河分为四支滋润那地；他也论到埃及的一部分说了同样的话。由此更清楚地看出，此处仅在一个特定之点上，将此地与那两处相比较。

**13.** <span style="color:#800000">*所多玛人*</span>。罗得以为自己得着了福气，因为如此丰饶的居所落到了他的分中；但他终究学到，他那与其贪婪同等鲁莽的仓促之选，其实是不幸地临到了他，因为他不得不与骄傲乖僻的邻舍打交道，忍受他们的行为，远比与土地的贫瘠相争更为艰难。所以，既然他单单被眼前景致的宜人所引诱，他就为自己愚蠢的贪欲付上了代价。那么，让我们借这个例子学会：我们的眼目不可信任；我们倒要提防，免得被眼目所诱陷，在不知不觉中被众多祸患所环绕；正如罗得，当他自以为住在乐园之中时，却几乎被投入地狱的深处。但似乎令人诧异的是，摩西既要定所多玛人极大的邪恶之罪，为何说他们是在耶和华面前作恶，而不说是在人面前；因为当我们来到神的审判台前时，各人的口都必被塞住，普世的人都要伏在神的审判之下；因此有人或以为摩西如此说是有意为他们开脱。然而事实并非如此：因为他的意思是，他们不仅仅落在那遍行于人间的常见罪恶的辖制之下，乃是被撇弃于最可憎的罪行之中，那罪恶的呼声甚至上达于天（正如我们后面将要看到的），向神呼求报应。然而神暂时容忍了他们；不仅如此，还任凭他们居住在极其肥沃之地，尽管他们全然不配得光与生命——由此我们可以学到，当神也暂时容忍恶人，或以恩慈甚至慷慨相待、以他的宽容与他们的忘恩相争时，这决不给恶人自庆的理由。虽然他们在自己的奢华中欢腾，甚至向神放肆狂妄，但愿神的众子受此警戒，不要嫉妒他们的境遇；却要稍等片刻，直到神将他们从沉醉中惊醒，召他们去受他可怕的审判。因此，以西结论到所多玛人，宣告他们灭亡的原因乃是：他们饱食酒饭，充满肥甘，却向穷人施行骄傲的残忍（以西结书 16:49）。

<div class="commentary-anchor" id="genesis-13-14"></div>
**14.** <span style="color:#800000">*耶和华对亚伯兰说*</span>。摩西现在叙述，在亚伯兰与他侄儿分开之后，神赐下安慰以平抚他的心。毫无疑问，那次分离所造成的创伤极为沉重，因为他不得不打发走一个于他并不亚于自己性命所珍爱的人。因此，当经上说耶和华说话时，就当留意此处的时间背景；仿佛摩西是说，神话语的良药此刻已被带来减轻他的痛苦。他借此教导我们：缓解并医治忧伤的最佳良方，就在于神的话语。

<!-- PAGE 257 -->
<span style="color:#800000">*你举目观看*</span>。既然主将这地应许给亚伯兰的后裔，我们便看出神在罗得离去一事上奇妙的旨意。神原是单单将这地指定给亚伯兰的；倘若罗得仍与他同住，两人的后裔就会混杂在一起。他们纷争的缘由固然有可责之处；然而主照着他无穷的智慧，使这事有了美好的结局，即罗得的后裔在这产业中毫无份。这就是他之所以说：『你所看见的一切地，我都赐给你和你的后裔。因此，将来既要赐你如此美好的赏赐，你就没有理由为这孤单与缺乏而过度忧伤烦恼。』因为虽然同样的话早已应许给亚伯兰，如今神却使他的应许适应于当下忧伤的宽解。故此当记得：这里不仅重述了一个应许，以滋养并坚固亚伯兰的信心；更是赐下一则特别的神谕，使亚伯兰从中得知，罗得与他分开，正是为了促进他自己后裔的益处。路德在此处（如在别处一样）的臆测毫无根据，就是说神是借着某位先知说话的。神应许这地「直到永远」，并非单指永久无尽；而是指那被基督降临所终结的那段时期。至于 <span style="color:#008080">µlw[</span>（*olam*，意为「世代/永远」）一词的意思，犹太人的争辩出于无知：但既然此词在圣经中有各样的意义，它在此处（如我方才所暗示的）涵盖了律法的整个时期；正如主与他古时百姓所立的约，在许多地方被称为永远的约一样；因为借着基督的降临更新世界，本是基督的职分。然而基督所带来的改变，并非*废除*那些旧的应许，反倒是*坚立*了它们。因此，既然神如今在迦南地并没有一群独特的子民，乃有一群遍布地上各方的子民；这就与那论断并不矛盾，即那地永远的产业乃是理所当然地应许给了亚伯兰的后裔，直到将来的更新。

**16.** <span style="color:#800000">*我也要使你的后裔如同地上的尘沙那样多*</span>。我略去那些人借以空谈无物的琐碎辩论，只简单地解释这些话的意思：亚伯兰的后裔之所以被比作尘沙，是因其数目浩繁；而这词语的真义，唯当从摩西自己的话中去寻求。然而，此处有必要补充一点：神要为他兴起后裔——这后裔他至今尚且没有。我们看见，神始终以他自己的话语约束着他，要他全然仰赖神口中所出的话。亚伯兰被吩咐去观看尘沙；但当他转眼看自己的家眷时，他孤身一人的光景，与那数不胜数的尘埃微粒之间，又有何相似之处呢？因此，主要求我们把这样的权威归于他自己的话语，惟独这话语对我们就已足够。神吩咐亚伯兰行走全地，直到走遍察看，这或许也会招人讥笑。他这样做究竟为何？岂不正是要他更清楚地认识到自己不过是寄居的客旅；并且，在持续而徒劳的辗转不安中精疲力竭之后，对任何稳固恒久的产业都感到绝望么？因为他既然连汲水都几乎不得允许——尽管他费尽辛劳挖了井——他又怎能说服自己是那地的主人呢？然而这些正是信心的操练，为要叫信心能在话语之中看见那些遥不可及、并向属肉体的感官所隐藏的事物。因为信心就是看见那看不见之事（希伯来书 11:1），它以话语为镜子，从中得见神那隐藏的恩典。而敬虔之人今日的境况亦无二致：因为他们既被众人所恨，遭人藐视辱骂，居无定所，四处漂泊，有时被驱来赶去，又受赤身与贫穷之苦，然而他们的本分仍是要持守那所应许的产业。所以，让我们行走世间，如同被剥夺了一切安息的人，除了话语这面镜子之外，别无所靠。

**18.** <span style="color:#800000">*亚伯兰就搬了帐棚*</span>。[^f353] 摩西在此叙述这位圣洁之人如何因神重申的应许而受激励，以极大的勇气巡行全地，仿佛单凭举目一望就能使这地归服于己。由此我们看见那神谕给他带来了何等的益处：并不是他从神口中听见了什么前所未闻的话，而是因为他得着了一剂如此合宜、如此对症、恰能医治他当下之忧愁的良药，以致他重新聚集精力，向着天举起心来。摩西最后记载，这位圣洁之人巡行既毕，便回到幔利的橡树，或说幔利谷，在那里居住。然而，摩西再一次称许他的敬虔，就是他筑起一座坛，呼求神。这话的意思我先前已多次解明：因为他自己心中原已存着一座坛；但既然那地充满了亵渎的祭坛，迦南人和其他列国在其上玷污了对神的敬拜，亚伯兰就公开表明他所敬拜的乃是真神；而且这敬拜并非出于随意，而是照着神藉话语向他所启示的方式。由此我们推知，所提及的那座坛并非他一时冲动、随手筑成的，而是照着神那同一句话语被分别为圣的。

[^f353]: Et tetendit Abram tabernaculum.（拉丁文：亚伯兰支搭帐棚）“亚伯兰支搭他的帐棚。”这似乎是 <span style="color:#008080">lhayw</span> 一词的真正含义；不过就上下文而言，“支搭”（pitched）一词不如“迁移”（removed）一词贴切；在使用后一词时，我们的译者是跟从了七十士译本（<span style="color:#0000d4">ἀποσκηνώσας</span>）与武加大译本（movens igitur tabernaculum，即「于是迁移帐棚」）。阿拉伯译本（据拉丁文译本）则以意译的方式带出同样的意思：“亚伯兰将帐棚支搭于各处，直到他前来住在幔利地。”这大概就是这一难题的正解。——编者注

[^f351]: “Familiam Lot minime fuisse parem verisimile est.”（拉丁文：罗得的家眷极可能并不相当。）这句话依 minime 一词所取意义之不同，可有两种截然相反的译法。它既可指「绝非」，也可指「至少」。旧英译本采用前一种译法：「罗得的家眷很可能少得多。」法文译本则取后一意义：「Il est bien vraye — semblable que la familie de Lot n’a pas este moindre.」（罗得的家眷很可能并不更少。）两种译法所给出的意思都不甚可信。上下文似乎几乎要求采用编者所斗胆采取的译法。——编者
