# 第六十五章

<p style="text-align:center" markdown="1"><span style="color:#000080">前往 以赛亚书 65:1-25</span></p>

**1.** <span style="color:#800000">*素来没有访问我的，我叫他们遇见。*</span> 先知现在转到另一项教义；因为他表明，神弃绝、丢弃犹大人是有充分理由的。这是因为他们无论受警戒还是受威吓，都毫无长进，不肯从自己的错谬中被带回正路。但为免他们以为主的约会因此归于无有，他补充说，主将拥有另一群百姓，就是从前算不得百姓的；并且在他从前不为人所知之地，他的名必被人熟知，并大受称扬。犹大人视此为骇人之事，认为若这样的恩惠延及亚伯拉罕后裔以外的人，就与主同亚伯拉罕所立的约（创世记 17:7）完全不相合。但先知的用意是要剥去他们那愚昧的自信——他们妄想神已被束缚在亚伯拉罕的后裔身上；因为主并非无条件地将自己限于他们，而是立于一个绝对的条件之上；他们若违背这条件，就要像背约者与叛逆者一样，被剥夺从约而来的一切益处。这应许也并非单单赐给亚伯拉罕和从他而生的人，而是赐给一切因信被接枝入他家中的人。不过，从第二节开始更为方便，因为在那里他解释了弃绝的缘由，使我们能更充分地明白先知的旨意。<span style="color:#800000">F1041</span>

**2.** <span style="color:#800000">*我整天伸手招呼。*</span> 他控告犹太人，抱怨他们的忘恩负义与悖逆；他以此证明，他们绝无理由说：若主将祂的恩典赐给别人，就是待他们不公。犹太人在神面前行事骄傲放肆，仿佛他们是凭自己的功德蒙拣选的。因着他们的忘恩与狂妄，主弃绝他们为不配的，并抱怨说，祂"伸手"要吸引他们、领他们归回自己，却是徒然。

<!-- PAGE 605 -->
所谓"伸出双手"，祂是指每日的邀请。主"向我们伸手"有多种方式；因为祂吸引我们归向自己，或是以有效的恩召，或是藉着话语。在本段中，这主要必是指话语而言。主对我们说话时，从不会不同时"伸出祂的手"要把我们联于祂自己，也不会不叫我们从另一面感受到祂与我们相近。祂甚至拥抱我们，显出父亲般的关切，以致我们若不顺从祂的邀请，其过失必全在我们自己。这罪的深重，更因其历时长久而大大加增：在历世历代的漫长年月中，神不断差遣一位又一位的先知，甚至如祂在别处所说的，清早起来，直到晚上仍存这同样的看顾。（耶利米书 7:13；11:7；35:14）

<span style="color:#800000">*招呼那悖逆的百姓。*</span> 首先，祂称他们为"悖逆的"或不顺从的，但随即宣明那悖逆的性质何在，就是这百姓*随自己的意念行*。没有什么比人成为 <span style="color:#0000d4">αὐθάδεις</span>（自我放纵的，彼得后书 2:10），就是任凭自己性情喜好的，更为神所憎恶；因为祂吩咐我们要交出自己的判断，好使我们能领受真道理。所以主在此见证：祂并未停止向他们施行素来的恩眷，责不在祂；乃是他们因自己的狂妄而自行疏远，因为他们宁愿固守自己天性的癖好，也不肯跟从神作他们的元帅。

既已指出这弃绝的缘由，我们就当进而论到外邦人的呼召，他们乃是接续犹大人的地位而入的；因为第一节所论的无疑正是这题旨。主早已藉着摩西预言了此事，故此他们本不该以为这预言中有何新奇之事。

<p style="text-align:center; color:#000080; margin:14px 2em;" markdown="1"><span style="color:#000080">「他们以那不算为神的触动我的愤恨，以</span> <span style="color:#000080">虚无的神惹了我的怒气。我也要以那不成子民的</span> <span style="color:#000080">触动他们的愤恨，以愚昧的国民惹了</span> <span style="color:#000080">他们的怒气。」（</span><span style="color:#000080">申命记 32:21）</span></p>

最后，先知如今所威胁的，正是后来当那瞎眼之事临近时基督所预言的同一件事。

<p style="text-align:center" markdown="1"><span style="color:#000080">「神的国必从你们夺去，赐给那能结果子</span> <span style="color:#000080">的百姓。」（</span><span style="color:#000080">马太福音 21:43）</span></p>

<!-- PAGE 606 -->

**1.** <span style="color:#800000">*素来没有访问我的。*</span> <span style="color:#800000">F1042</span> 当他说神向「素来没有访问我的」显现自己时，他表明外邦人是被神的恩典所抢先的，他们并未带着任何功德或优点来促使神将恩典赐给他们。这显然与我们所引用的那段经文相符，摩西在其中称他们为「愚昧的国民」（申命记 32:21）。因此，他在一个普遍的表征之下描述了人在主以怜悯抢先临到他们之前的本性；因为他们既不求告主，也不寻求他，也不思念他。这段经文当被仔细留意，为要确立我们蒙召的确定性，这确定性可说是为我们开启天国的钥匙；因为藉着它，我们的良心得着平安与安息，若不倚靠这样的见证，良心就必永远处于疑惑与不安之中。因此我们看见，我们被神呼召并算作他的百姓，并非偶然发生，也非突然发生；因为这在许多经文中早已预言许久了。保罗从这段经文出发，极力为外邦人的蒙召辩明，并说以赛亚放胆宣告，断言外邦人已被神呼召，因为他所说的比他自己时代的处境所要求的更加清楚、更加响亮。因此我们在此看见，我们乃是照着神永远的旨意，在事情发生以前许久就被呼召了。

<span style="color:#800000">*我在这里，我在这里。*</span> 他将这话重复两次，就更加确证了这宣告：神向外邦异教之民如此友善地显明了自己，以致他们毫不怀疑他就住在他们中间。的确，那突然的转变需要被确证，因为这是难以相信的；虽然先知正是要藉着那新奇之事来彰显神那出人意外的恩典。其意可如此总括：「当主将自己呈现给外邦人，他们也被接入亚伯拉罕圣洁的家族之后，犹太人虽被赶出，世上仍必有教会。」如今我们看见，先知在此所预言的一切，都藉着福音得了应验，主藉着福音实际地将自己呈现并显明给外邦之民。因此，每当福音的这声音在我们耳中响起，或当我们记念主的话时，就当知道主是临在的，并将自己呈现出来，使我们可以亲密地认识他，可以放胆并带着确实的信心求告他。

<!-- PAGE 607 -->

**3.** <span style="color:#800000">*这百姓时常当面惹我发怒。*</span>先知在此更详尽地描述并说明犹太人在哪些方面悖逆了神。乃是因为他们离弃了神的诫命，又用各样的迷信玷污了自己。他在稍前之处曾说（以赛亚书 63:17），犹太人自己与神疏远了，因为他们随从自己的臆想飘流；如今他指出那放纵的果子，就是他们任凭自己的心思驰骋，以致倾覆了对神纯正的敬拜。无疑地，这正是一切迷信的根源，就是人喜悦自己所发明的，宁可在自己眼中看为有智慧，也不肯约束自己的心思去顺服神。人徒然抬出他们所谓的虔敬心与善意，而神对这些却如此憎恶厌弃，以致凡随从这些的人，都算是背了约、离弃了当尽的忠诚；因为我们本不当凭自己的意思擅自兴办甚么，惟当在神吩咐时顺从他。总之，合法敬拜的开端与完全，就在于甘心顺服。

先知用「惹动怒气」一词，描述这百姓的厚颜无耻：他们仿佛是蓄意去惹神发怒，对他的威严毫无敬畏之心，不肯服在他的权柄之下。他又加重了这描述，说<span style="color:#800000">*「当面」*</span>；因为神既借着他的话警戒人，就可说是亲临在那些人面前、被他们亲眼看见，那么这些人所犯的罪就更为可憎，其厚颜与悖逆也远超过那从未听过这话语的人。

<span style="color:#800000">*在园中献祭，在坛（原文作砖）上烧香。*</span>他提到他们分别为圣归给偶像的「园子」，说他们借这些惹动他的怒气。有些人认为提到「砖」是带着轻蔑的意味，是间接与那座神所独许他们在其上献祭的祭坛相对照；因此他们认为，此处所指的是屋顶，因为迷信之人惯常在屋顶上献祭，而屋顶是用「砖」造的。但我认为，这不过是指他们为偶像所筑的祭坛；因为他们虽然并非没有貌似合理的借口，声称是要效法神所吩咐的那种祭坛的样式，然而神却憎恶它，因为它违背了他的话语。

<!-- PAGE 608 -->

**4.** <span style="color:#800000">*住在坟墓间。*</span> 他列举了另外几类迷信；虽然因着叙述简短，描写显得晦涩，我们却可以轻易从别处的经文得知它们的性质。因为在外邦人中普遍行招魂之术，犹太人也照样在「坟墓和旷野」中求问鬼魔，而不单单求问神——这本是他们当尽的本分；他们仿佛要从死人得着答复，竟以受鬼魔幻术的欺骗为乐。<span style="color:#800000">F1043</span> 主如何郑重地禁止此事，从申命记 18:10, 11 及别处经文可看得极为清楚；本卷书前面部分我们也见过类似的事（以赛亚书 8:19）。总而言之，我们受教得知：神所要的不过是听命，他喜悦听命胜于所宰的牲畜与祭物（撒母耳记上 15:22）。

<span style="color:#800000">*吃猪肉。*</span> 前面他控诉神的敬拜被外来的臆造所污染；现今他又加上一句，说他们废弃了一切区别，以致不分辨洁净与不洁净；他举出一个例子，就是他们不禁戒「猪肉」。但或许有人以为这是小事。绝非如此；因为一件罪何等可憎，我们不当照自己的看法来判断，而当照那立法者的看法来判断；凡主所禁止的，都不可看为轻微（利未记 11:7；申命记 14:8）。这与信仰的外在表明有关，

犹太人有责任藉此见证自己与外邦人的污秽相隔何等遥远。因此，主吩咐我们的那条准则，我们连一发之地也不可偏离。<span style="color:#800000">F1044</span>

**5.** <span style="color:#800000">*你自己站开吧。*</span> <span style="color:#800000">F1045</span> 他在此指出犹大人极端的不敬虔：他们顽梗悖逆地抵挡敬拜神的人，也不肯听任何警戒。只要我们还肯侧耳听劝戒与责备，就仍有悔改的指望；但我们若弃绝这些，我们的处境无疑就毫无指望了。

<!-- PAGE 609 -->
这些字句表面上似乎晦涩难明，其意思却归结为此：假冒为善的人轻蔑而凶暴地拒绝忠信的劝告者，或因他们虚假地自夸圣洁，或因骄傲之故而不容自己被责备；因为假冒为善绝不会脱离那种目空一切的轻蔑与高傲。所以，我们不必惊奇：染上此恶的人竟以狂傲的自命不凡自我膨胀，夸耀自己的德行与圣洁，看自己比众人都高；因为撒但已使他们瞎了眼，叫他们对自己所谓的虔敬之举作空洞而炫耀的夸口，却藐视神的话。

诸注释家认为这是一句普遍的陈述，责备犹大人不肯服从众先知。但在我看来，我们当顾及一个他们未给予足够重视的情形，就是这一节与前面几节紧密相连、直接衔接，其中含有对犹大人尖锐的责备：他们不但背离真正的敬拜，更且顽固地随从自己所发明的一套，以致轻蔑地弃绝一切不奉承他们的人；因为「你自己站开吧」这句话，无非就是「你走开！」的意思，仿佛他们声明自己与正直的教导者毫无相干。 <span style="color:#800000">F1046</span>

**6.** <span style="color:#800000">*看哪，这都写在我面前。*</span>他在此暗指审判官通常的做法：他们把关乎某案的审讯记录，连同证词、诉讼行为以及一切此类文件，都以书面形式存放在面前，为的是一旦需要动用这些材料时，可以轻易证明犯人的罪状；因为凡我们愿意后世记念之事，我们就把它写下来。因此，主见证说，这些事绝不能归于遗忘，因为它们已被记录在案；因为纵然他一时缄默不言，恶人却终不得逃脱惩罚，反而终必觉悟他是公义的审判者。

由此我们当学会：不可滥用神的忍耐，虽然他长久宽容我们，不立即伸手惩罚我们；因为我们一切的过失仍旧写在他面前，我们若不悔改，终必为此受刑罚。<span style="color:#800000">F1047</span> 诚然，主并不需要藉着书写来帮助记忆；但他使用这种说法，免得我们以为他迟延施行审判时，就是已经忘记了什么。耶利米甚至明确地说：

<p style="text-align:center" markdown="1"><span style="color:#000080">“犹大的罪是用铁笔、用金刚钻</span> <span style="color:#000080">记录的。”（</span><span style="color:#000080">耶利米书 17:1）</span></p>

<!-- PAGE 610 -->

<span style="color:#800000">*报应在他们身上*</span>（直译为「报应到他们怀中」）这一说法在圣经中屡见不鲜；因为人们或以为自己的罪隐而不露，或以为无须为此交账；他们被放纵的私欲所席卷，或将过失推给他人，就把惧怕远远赶开。（诗篇 79:12；耶利米书 32:18。）为此缘故，主威胁说他要「报应到他们怀中」，使他们思量自己所要面对的审判者是谁。

**7.** <span style="color:#800000">*你们的罪孽和你们列祖的罪孽*</span>。以赛亚在此详述他在前一节中简略提及的事；因为他表明犹大人并非今日才初犯这背叛之罪，乃是有列祖的古老先例，而他们紧随其后步其脚踪。同样，主从前也曾抱怨说，他久久容忍那百姓，终究因他们而生厌烦。因此他描述这罪过何以加倍可憎，就是说犹大人效法他们列祖的榜样；如同他说：「他们是恶乌鸦所生的极恶之卵。」因为人受警戒越频繁、越严切，若仍不悔改，就越该因其顽梗而被定罪。这样，他表明他们轻忽警告与威胁，多年执迷于卑劣与不敬虔之中；使他们再不能提出任何借口或托词，反倒当知道自己理当受严厉的刑罚。

我们在此看见，从列祖流传而来的败坏，远不能成为儿女的借口（无知之人却常以此为盾牌而如此辩解），反倒使他们招来更严厉的审判。他又加上 <span style="color:#008080">יחדו</span>（*yachdav*），意即「一同」。如同主说，他要把列祖与儿女的罪恶聚集起来，仿佛捆成一束，以便最终加以刑罚。这并不是说

<p style="text-align:center" markdown="1"><span style="color:#000080">「儿子必不担当父亲的罪孽」（</span><span style="color:#000080">以西结书 18:20），</span></p>

也不承受父亲当受的刑罚；而是说，既然他们继续行他们祖宗所犯的罪恶，他们就必被算在同一审判之中，与之一同受定罪，因为他们的顽梗表明他们的疾病已无可救治。

<!-- PAGE 611 -->

<span style="color:#800000">*因为他们在山上烧香*。</span>他在此提及一种罪，并以举隅法（以部分代表全体）借这一种罪描述他们其余的罪；因为他借此指着百姓离弃真敬拜、专心委身归向外邦神明的那全然背道而言。这是罪恶的极处；因为当敬畏神的心被除去时，我们里面就再没有一点健全无病之处。这样，他指出了一切邪恶的根源，而这一点尤当格外殷勤留意，因为人们极为自满，以为自己按自己的心意敬拜神便配得极大的称赞，却不明白在神眼中没有什么比出于人意捏造的假敬拜更可憎的了。毫无疑问，那百姓「在山上烧香」，本是想要得神的悦纳；然而我们判断他们的行为，不可凭他们心中的意图，也不可凭他们所谓的「善意」。我们当越过众人，先听主的声音；主既见证他因此大受亏辱，我们就不当以自己的善意为自己辩护，因这只会使我们在神面前罪加一等。

<span style="color:#800000">*所以我要将他们从前所行的量给他们。*</span> <span style="color:#008080">ראשנה</span>（*rishonah*）一词可有多种解法，或作「我要按他们的古旧量还他们」，或作「首先」，或作「从前」，或作「从起初」。但我们必须考虑本段的上下文关联，先知的意思便可从中清楚看出。他在稍前既已论到列祖的行为，无疑是在讥笑那些以列祖为堡垒的人。这是一种薄弱无用的辩护；在神面前以列祖的惯例、就是他们长久积习的败坏为借口，实在是徒然的；因为我们这样行，只是给自己招来更重的审判。然而许多人竟被这借口迷醉，以为无人能对此提出任何反驳，甚至不肯听别的话。<span style="color:#800000">F1048</span> 古旧固然极其可敬，但没有人可以将它看得那么重，以致丝毫削减神的尊荣。这是一段极其有力的经文，足以驳倒那些以年代久远来维护迷信的人，好像陈旧已久的错谬就应当被当作律法一样。

<!-- PAGE 612 -->
**8.** <span style="color:#800000">*耶和华如此说。*</span> 先知在此缓和了前面的话；因为若不然，说列祖的罪孽要被记念，以致主要将列祖与他们的子孙一同灭绝，这话就实在太严厉了；这些话可能使信徒惊恐战栗，以为他们的救恩已全无指望。因此我们必须谨慎防备，并要留意主向我们发怒的缘由；因为他愿意使我们惧怕，为要引我们归向他自己，而不是要把我们抛入绝望。为此缘故，他向信徒伸出希望，免得他们丧胆；并借着显明安慰，激励他们悔改。他又用一个比喻来加以证实。

<span style="color:#800000">*好像人在葡萄累中寻得新酒。*</span> 就如一个人已决意要拔除一棵于他不便或有害的葡萄树，若发现其上有一根结果子的枝子，便必存留它；照样，主也必不拔除那些他在其中寻见了力量或滋味的人。他从前曾抱怨这百姓毫无用处，甚至结出苦涩的果子（以赛亚书 5:2, 4, 7）。以赛亚保留同样的比喻，却以不同的方式应用它：「虽然这百姓可称为不结果子、变质败坏的葡萄树，然而其上仍留有一些结果子的枝子，主必不容它们灭亡。」

但这话可有两种理解：或是说主要为选民的缘故保存他的百姓；或是说当被弃者被毁灭时，他要从毁灭中救出信徒。这两种解释相差甚远。关于第一种，我们知道恶人有时是因着善人得蒙宽容，因为神不愿毁灭这些善人，也不愿使他们卷入同样的审判之中，圣经中的种种例证足以显明这一点。主本要宽容所多玛，只要他在其中寻得十个义人（创世记 18:32）。与保罗同船的众人，共"二百七十六个"（使徒行传 27:37），都被"赐给他"、从船破中得救，为要使他在自己仆人身上所显的能力更加荣耀地彰显出来（使徒行传 27:24）。主赐福给波提乏的家，使他一切所有的都蒙福，是为着在他家中的约瑟的缘故（创世记 39:5）。此外还有同类的例证，各人都能轻易自行搜集。

<!-- PAGE 613 -->
但我更赞同另一种解释，即主惩罚他百姓的罪时，仍要顾念属他自己的人，不将众人一概卷入同样的毁灭。他所说的，不仅是信徒必得拯救，更是必有余剩的百姓存留，在他们中间有人求告他的名。这对比应当仔细留意；因为他显明，与当时的众多人口相比，所剩的余民必是稀少的，这已如前所解释（以赛亚书 1:9）。

至于信徒常与被弃者一同受罚，我们不要以为这是不公的；因为主在我们各人身上，常能找出足够的过失来苦待我们、惩罚我们。此外，他愿意藉着管教教导我们、唤醒我们；既然我们已与某一民族相连，可说是被接在他们的身体上，那么，我们这些可称为患病的肢体，若同受一样的击打与痛苦，实在不当以为奇怪。然而主节制刑罚，不至于将所拣选的树苗连根拔起。

**9.** <span style="color:#800000">*我必从雅各中领出后裔。*</span> 他用别的话解释前一节，并表明主愿意为自己留下一些呼求他名的「后裔」；因为主管教他的百姓，向来是以这样的方式，即定意要使教会存留，好使他的真理与纯正的敬虔在其中得以保存；保罗正是为此缘故称教会为「真理的柱石和根基」（提摩太前书 3:15）。因此，我们不可凭眼前的光景来判断教会，（因为在这世上没有什么能长存，）而当凭神的旨意来判断，这旨意必不容教会被倾覆或毁灭。这是我们当谨记在心的，好使我们不因任何灾祸、废墟，或教会任何可怕的荒凉而惊惶。

<span style="color:#800000">*从犹大中领出承受我众山的。*</span> 他称那些从被掳之地归回、将再次居住本乡的人为「承受众山的」。众所周知，犹大是多山之地。他再次解释那本来似乎略显隐晦之处。

<!-- PAGE 614 -->
<span style="color:#800000">*我的选民必承受。*</span> 他的意思是，犹太人必归回他们原初的境况，好使他们享有那地作为自己的产业——就是他们曾被赶出的那地。此后不久，犹大便被弃为极其荒凉。主见证这荒凉不会长久；并且，为要更加坚固这应许，他简要地提到那立定将此地归给他们的约，使他们可以按承受产业的权利占有它。因此，尽管他们长久被掳，这「产业」一词却当激励他们怀着确信的盼望，相信他们终必重得那地。但当留意的是，这恩典只限于选民和神真实的敬拜者，免得人人都不加分别地把它应用在自己身上。<span style="color:#800000">F1049</span>

**10.** <span style="color:#800000">*沙仑必成为羊群的圈。*</span> 他借这些比喻所表达的，不外乎是：那曾荒凉的地必再有人居住；因这里含有一种隐含的对比。「虽然因她的居民被掳到远方，她将被弃置荒凉，然而她终必再有人居住，以致牛羊成群，田地肥美、宜于放牧，丰丰富富地供应人一切饮食与生活所需。」沙仑是适宜牧放之地，亚割谷也是如此；只是前者适宜羊群，后者适宜牛群。

我们在此看见，神的应许所包含的福分，不单属于将来的生命，也属于今世的生命，使我们得以愈发尝到他的丰厚与慈爱；因为借着后者 <span style="color:#800000">F1050</span> 我们被引往天上生命中那更大更美的福分。当主将他的丰厚施及牛羊时，这更当坚固我们，使我们更确信他对我们那父亲般的看顾与关切；因为他既眷顾那些为我们的缘故所造的羊群，就更必将一切所需供给我们，

<p style="text-align:center" markdown="1"><span style="color:#000080">「因今生和来生都有应许。」</span> <span style="color:#000080">(</span><span style="color:#000080">提摩太前书 4:8)</span></p>

然而我们同样必须留意那属灵的意义（我们前面已经论过），就是从神地上的祝福引领我们到基督属灵的国度，先知们乃是用那形象将这国度预表出来。

<!-- PAGE 615 -->
<span style="color:#800000">*为我的民。*</span>在此他也把被弃绝的人排除在外，那些人并不以虚妄虚假地夸耀神的名为耻。虽然他们大胆自夸有应许与圣礼，然而他们与神的儿女毫无相干；他们既被断绝于神一切恩惠的指望之外，便要领受自己罪孽的报应。他又加上「寻求我的」这话，更清楚地描述谁才是要得着这些恩福的人，为要如前所说，将被弃绝者与假冒为善之人完全剪除。绵羊羔与山羊羔、合法的儿女与私生子得以分辨的确实标记，就是「寻求」耶和华；因为单单藏身于一个名号和称衔之下是不够的，我们必须以纯洁的良心寻求耶和华，好使我们全心与他相连。（申命记 6:5）

**11.** <span style="color:#800000">*但你们这些离弃耶和华、忘记我圣山的。*</span>为免假冒为善之人滥用这些应许，或以为那论到百姓复兴的话与他们有关，先知再次用这些话向他们说，称他们为「离弃者」，<span style="color:#800000">F1051</span>因为他们「忘记」了锡安山；也就是说，背离了对神的真敬拜。他用「我圣山」一语，喻指那已在主的话语中所立定的圣洁生活的准则；因为圣殿是照着主的吩咐建造的，好叫这些人可以求告他；祭坛也是如此，主愿意人在其上献祭。因此，凡在别处、或向别神、或以任何偏离律法礼仪严格遵守之方式所献的祭物与供物，都是不洁的。人不可凭自己的意思擅自行事；因为主所要求的无非是听命（撒母耳记上 15:22），而没有信心就没有听命；没有话语也就没有信心（罗马书 10:17），唯有藉着话语，我们才可以探究或思想关乎神的事。

<!-- PAGE 616 -->
<span style="color:#800000">*为那军队摆设筵席的*</span>。<span style="color:#800000">F1052</span> 他在此列举他们的迷信。<span style="color:#008080">גד</span>（*Gad*）一词有各样的解释。有人认为它指木星，或木星那颗星；另有人认为它指命运（Fortune）。耶柔米译作：「你们这为命运摆设筵席的」，因为他认为这词意指亨通。但我认为更可取的看法是，<span style="color:#008080">גד</span>（*Gad*）意指「一群」、「一队」，甚至「一支军队」；这与该词的字源和上下文都甚为相合。有一处经文尤其值得注意，就是创世记 30:11，利亚因添了儿子而欢喜；因为我认为她所用的<span style="color:#008080">בגד</span>（*begad*）一词，当理解为她说：「如今我有许多儿子了。」因为在那以前她已生了不少孩子，故此她给自己第五个儿子起名叫<span style="color:#008080">גד</span>（*Gad*）。因此我认为，<span style="color:#008080">גד</span>（*Gad*）在此处当解作「一队」或「一支军队」；因为他们的假神何等众多，多得几乎数算不过来。

<span style="color:#800000">*为那命运盛满调和酒的*</span>。此处的「盛满」可有两种解法：或是指他们为敬拜偶像大量而丰厚地供应一切（因为迷信没有界限、没有分寸，那些在敬拜神的事上吝啬的人，为着偶像却极其乐意倾尽所有）；或是指他们没有放过任何一个偶像而不向它献上敬拜。我更取后一种意思；因为拜偶像的人若不向每一位圣徒都致上尊崇，就不认为自己作得够了；而他们所尊崇的圣徒越多，就越以为自己必得更大的顺遂。我们在教皇派人身上，每日都对此有太多的经历。

他所说的「数目」，与他先前所说的「军队」是同一个意思；因为这是希伯来作者极常用的重复手法。所以他的意思是：「摆设筵席」，就是献祭，并非献给单单一个偶像，乃是献给极多的偶像；为要清楚显明他们所应得的刑罚是何等沉重。

**12.** <span style="color:#800000">*所以我要命定你们归在刀下。*</span>他在此暗指众神的数目；耶和华宣告说，他必轻易查明它们究竟有多少，因为他要「命定他们归在刀下」。由此我们看出，先知在前一节所说的，并非如某些人所想的那两颗行星——木星与水星——乃是指他们不以独一的神为满足，反倒为自己搜罗各样的偶像。有人臆测<span style="color:#008080">מני</span>（*meni*，弥尼）一词是指水星，理由是<span style="color:#008080">מנה</span>（*manah*）意为「数点」，而水星乃是掌管数目与商贾之神——这不过是无稽之谈。<span style="color:#800000">F1053</span>先知的用意是显而易见的：他宣告这百姓「必被数点归于刀下」，因为他们以神明众多为乐，而不肯专靠独一的神。

<!-- PAGE 617 -->
<span style="color:#800000">*因为我呼唤，你们没有答应。*</span>他在此加重这背逆之罪的深重与可憎，指明犹太人犯罪乃是出于蓄意的恶毒、明知故犯，而非出于无知。他们屡次受教诲、受警戒，却轻蔑地弃绝一切警戒，因此比那些从未有先知奉差前往的人更加无可推诿；因为无知固然不能作任何人的托辞，然而对犹太人、以及凡有神的话向他们宣讲的人，就更加不能作托辞，正因如此，他们所受的定罪与刑罚必比别人更重。

<span style="color:#800000">*我说话，你们没有听从。*</span>他在此描述呼唤的方式，就是借着众先知劝勉这百姓；因为他用「说话」一词把同一件事重述两次，正如我们已经指出的，这是希伯来作者惯用的笔法。「听」耶和华，就是顺服他的话；因为我们若不顺服这话，单单侧耳而听便是无关紧要的事；那样一来，我们的光景正如俗语所说：「他们是用驴的耳朵在听。」<span style="color:#800000">F1054</span>神愿人诚心地听他，并不悦纳虚假的聆听；他也指明他们弃绝这呼唤的缘由何在，就是因为他们向众先知的教训塞住了耳朵；因为顺服的起点，乃在于存着求学的心志而来。

<span style="color:#800000">*行我眼中看为恶的事*</span>。「在我眼前」这一说法与他稍前（第3节）所用的「向我的面」是同一含义。诚然，一切人都是在耶和华「眼前」犯罪，无人能躲开他的面。但我们被称为「在他眼前」犯罪，却有一种特别的意义，就是当他呼召了我们，我们却不惧怕他的临在；因为对那些他藉先知所呼召的人，他更加靠近他们，可以说，是向他们显明自己是临在的。所以，那些丢弃一切羞耻之心的人，当神走近来呼召、邀请他们时，他们却轻视嘲弄他，这样的不敬更为可憎，更配受严厉的管教。

<!-- PAGE 618 -->
<span style="color:#800000">*择我所不喜悦的事。*</span>从本节末尾这一句可以明显看出，他们被定罪，并非因为犯了粗鄙的罪行，而是因着自己捏造的愚妄敬拜，藉此败坏了神的敬拜。虽然他们热心致力于自己所设想出来的祭祀，因为他们以为这样便可得着神的恩眷；然而他宣告说，他厌恶他们邪恶的作为。人不可随意自由选择自己所以为合适的，反倒众人都当遵守神所悦纳的，绝不可稍有偏离。如今我们看见，人在敬拜神的事上任凭己意，敬奉自己的发明而不敬奉神，这并非某一个时代所独有的过失；然而，无论人在「这些事上」怎样「喜悦」，耶和华都郑重宣告，他定其罪，并且厌恶它们。

13、14节。<span style="color:#800000">*我的仆人必得吃。*</span>在此，先知也更清楚地区别了那些在教会中占有一席之地的假冒为善者，与真实合法的儿女；因为虽然众人都不加区别地被称为儿女，他却表明，许多人将被弃绝为不属这家的人，并且那些顶着神百姓的名号、骄傲自大地自我高举的人，必在他们那虚妄虚假的指望上落空。我们必须仔细留意「神的仆人」与那些假冒他名之人之间那极具分量的对比；因为他表明，空洞的名号、虚假的夸口或虚妄的自恃，对他们毫无益处。

<span style="color:#800000">*必得吃，必得喝。*</span>他用这些话指明幸福与生活的兴盛境况；仿佛他说，他必看顾信徒，使他们一无所缺。但主向他的仆人所应许的，与他实际所赐的却有所不同；因为他们常常"又饥又渴"（哥林多前书 4:11），而恶人却各样享受丰足，并滥用这些享受于奢华放纵。然而当注意的是，基督的国在此是以形象化的比喻来描述的；因若非如此，我们便无法理解它。因此，先知乃是取地上诸国为比方；在那些国中，当百姓财富丰足、各样安逸俱备时，便有神的祝福显然可见，我们从而可以判断他慈父般的爱。

<!-- PAGE 619 -->
但既然善人不宜让自己的心思被地上的好处所占据，那么，对那些好处稍有品尝以支持他们的信心，便已足够。他们若有时被饥饿所压，然而，既以适度的分量为满足，他们仍然承认神是他们的父，并且他厚待他们；他们在贫穷中比君王贵胄更加富足。另一方面，恶人无论有何等丰盛的美物，都不能以无愧的良心享用，因此是人中最可悲的。所以，先知眼中所注视的乃是正当使用神的恩赐；因为凡以正当方式事奉神的人，都如儿女从父亲手中领受这一生所必需的一切，而其余的人却像贼与亵慢者一般，用强暴夺取。恶人无论财富何等浩大，从不知足；他们时常恐惧战兢，良心永不得安。

因此，主在此所应许的，并非他不实际赐下的；而这幸福也不可按外在的境况来衡量。这从下文更为明显，那里他论到欢乐与颂赞。先知无疑是要用几句话说明：知足并不在于地上享受的丰盛，而在于心灵的平静安宁与属灵的喜乐；因为不信者对这等事毫无胃口，但对信徒而言，深信神慈父般的爱，比一切地上的享受更加甘美。然而让我们留意：我们当单单仰望神赐下一切的兴盛，他必不容他的百姓缺少任何属乎幸福生活之物。

**15.** <span style="color:#800000">*你们必留下自己的名给我的选民作咒诅*</span> <span style="color:#800000">F1055</span>。他继续申明同一教义，教导我们说：神终必将假冒为善者与祂真实的仆人分别出来。的确，先知如此反复强调这一点，我们不必觉得希奇；因为再没有别的事比使假冒为善者信服更为困难的了，他们因骄傲自满而自欺自盲。他断言"他们的名"必成为"咒诅"，因为他们以为自己就是那圣洁的种类，天下再没有别的值得记念。"留下"一词也含此意；仿佛他说：他们如此紧紧执守的虚假夸口，必被强力夺去；因此，为免他们以那短暫易逝的荣耀自夸，主责备那种傲慢，宣告祂必另有仆人，而这些人要以他们为咒诅，甚至在郑重的咒诅中要引他们为例说："愿神咒诅你，如祂咒诅犹大人一样！"

<!-- PAGE 620 -->
<span style="color:#800000">*却必称他的仆人另起别名*</span>。他指出那民族的自信何等毫无根据；他们以为若神没有亚伯拉罕的后裔，就必没有百姓了。因此祂郑重宣告，祂要收纳一群新的百姓，祂并不受限于犹大人，以致不能轻易找着别人来以祂百姓的"名"相称。有人以为"别名"是指基督徒之名，这种见解极其牵强；甚至从上下文也显明先知所着眼的完全是另一件事。因犹大人骄傲地夸耀自己名号的古远，又因早已蒙神拣选而变得狂傲，似乎神离了他们便不能成事；故此祂指明祂要拣选并收纳另一群百姓，然而不能因此指责祂任性或反复无常，好像祂改变了心意一般。祂必向那些假借祂名之虚饰、遮蔽祂荣耀、败坏一切敬虔的人，施行祂的定旨与公义的审判。

**16.** <span style="color:#800000">*在地上为自己求福的*</span>。这里是将全世界与犹大的一隅相对照——在那一隅之地，可以说敬拜神之事曾被封闭起来。自从神在各处显明以来，祂如今不再单在某一地方受敬拜，而是不分处所在各地受敬拜；正如基督也教导说（约翰福音 4:21）："时候将到，你们拜父，也不在这山上，也不在耶路撒冷。"保罗也说：

<p style="text-align:center" markdown="1"><span style="color:#000080">「我愿男人无忿怒，无争论，举起圣洁的手，</span> <span style="color:#000080">随处祷告。」（</span><span style="color:#000080">提摩太前书 2:8）</span></p>

因此，他在此处用「地」一词来指整个世界，是隐含地与犹大形成对比。

<span style="color:#800000">*必凭真实的神自称为有福。必凭真实的神起誓。*</span> 他以「祝福」和「起誓」来指称对神的全部敬拜。正如我们从前所见，<span style="color:#800000">F1056</span>「起誓」乃是敬拜神的一种方式；因为我们藉此宣告一切审判都属于神，并承认他完全知晓我们所行的一切。我们「祝福」，是当我们愿从他得着一切的兴盛，并单单向他献上感谢之时；简言之，就是当我们承认我们的兴盛并非出于别的源头，唯独出于他白白的恩慈。「真实的神」意思是说，他信守自己的应许，坚定不移地成就自己的旨意；不过或许其中也隐含着「真实的神」与外邦人的假神之间那种间接的对比。

<!-- PAGE 621 -->

<span style="color:#800000">*因为从前的苦难已经交与遗忘。*</span>这应许只关乎信徒。神宣告他必使他们的苦难与患难止息，免得教会的灾祸永无穷尽。这话开始应验于百姓被领出巴比伦之时；因为，虽然他们无论在归回途中或在本土都多方受苦，然而刑罚的严厉已被减轻；因为归回故土、重建圣殿、恢复正常的治理，抚慰了他们的忧伤，并以美好的盼望支撑他们的心，直到基督降临。

**17.** <span style="color:#800000">*看哪！我造新天新地。*</span>他用这些比喻应许局势将有非凡的改变；仿佛神说，他既有心意也有能力，不但要复兴他的教会，而且要以这样的方式复兴她，使她显得获得新的生命，居住在一个新的世界里。这些是夸张的表达方式；然而这样一个将在基督降临之时显明的极大恩福，无法用别的方式来描述。他所指的也不仅是第一次降临，而是整个国度，这国度必须延伸直到末后的降临，正如我们在解释别处经文时已经说过的。

这样，世界（可以说）就藉着基督而更新了；因此使徒（希伯来书 2:5）也称之为「新的世代」，无疑是暗指先知这里的话。然而先知所说的是教会在从巴比伦归回之后的复兴。这无疑是真的；但那复兴若不延伸直到基督，就是不完全的；甚至如今我们仍在其进展与成全之中，而那些事要到末后的复活才得完全实现，那复活已被定为我们的界限。

<!-- PAGE 622 -->
<span style="color:#800000">*先前的事不再被记念。*</span>有些人把这些话解作指天与地，好像他是说，此后它们必不再有声名，也不再有名号。但我宁愿把这些话解作指先前的时候；因为他的意思是：他们复兴时的喜乐将如此之大，以致他们不再记念自己的苦难。或许有人认为更可取的看法是，这些话是指那些恩惠，它们虽然本值得被记载，却在神奇妙的恩典照耀出来时失去了名声。先知在别处正是按这意思说：「你们不要记念从前的事。」（以赛亚书 43:18）这并非说神愿意头一次的拯救被搁置，或从信徒心中被涂抹；而是因为相比之下，这一件使人对那一件生出某种忘却，正如太阳升起时，便夺去了众星的光辉。

我们要记得，这些事是照着我们得以更新的程度而在我们里面发生的。但我们只是部分地得了更新，因此我们还未看见新天新地。所以我们不必惊奇，我们仍旧哀恸哭泣，因为我们尚未完全脱去旧人，仍有许多残余留存。这更新也当从我们身上开始；因为我们居首位，而正是因着我们的罪，「受造之物叹息，服在虚空之下」，如保罗所指明的。（罗马书 8:20）但当我们完全得了更新，天与地也必完全得更新，并要恢复它们原初的状态。由此可以推断——正如我们屡次所论——先知眼中所看的是基督全部的国度，直到其最终的结局，这结局也被称为

<p style="text-align:center" markdown="1"><span style="color:#000080">「万物复兴的时候」（</span><span style="color:#000080">使徒行传 3:21）</span></p>

**18.** 但你们当永远欢喜快乐。他劝勉信徒当为神所赐这样的恩惠，以合乎当有的方式欢喜。这话是为了加强语气而添上的；因为人对神其余的恩惠尚且不能充分体会，何况这至高至美的恩惠；他们或是完全漠视，或是不如所当有地珍视。因此，必须用这样的劝勉激动催促信徒，使他们不显为忘恩负义、不加思念，也不以为这事可以轻轻放过——就是他们既被基督的手所赎，便在心里怀有那永恒属天生命的凭据。这就是以赛亚指明的缘故：信徒若不在一生的整个历程中持续这喜乐，不以颂扬神的赞美为己任，就断不能为救赎献上当有的称颂。

<!-- PAGE 623 -->
<span style="color:#800000">*因我造耶路撒冷为人所喜，造其中的居民为人所乐。*</span>乍看之下，这话似乎显得过于强烈；但从中却得出一个极美的意思，就是教会得蒙拯救所生的喜乐根基如此之大，足以驱散一切忧愁的阴云。的确，既然连患难也有助于我们的救恩（罗马书 8:28），我们就大有理由在患难中欢喜。

**19.** <span style="color:#800000">*我必因耶路撒冷欢喜。*</span>他所说的比前一节更多；因为他借这些话表明，他不但要赐给人欢喜的根基，甚至要亲自与他们同享这喜乐。他对我们的爱是如此之大，以致他喜悦我们的兴盛，不亚于他自己与我们一同享受。由此我们的信心便得着不小的坚固，当我们晓得神被这样的情感所感动，且被如此有力地感动，是为着我们的缘故。若我们处在苦痛困迫的境况中，他说他自己也为忧伤悲痛所触动；反之，若我们的境况顺遂安舒，他说他也大大喜悦我们的兴盛。因此我们从前也曾看见，当他所要求所嘉许的次序被倾覆搅乱时，「主的灵忧伤、担忧」（以赛亚书 63:10）；在另一处，他又以丈夫的身分自居，以妻子的爱为满足（以赛亚书 62:5）。

**20.** <span style="color:#800000">*其中必没有数日夭亡的婴孩。*</span> 有些人认为这里指出了律法与福音之间的分别；因为「律法是训蒙的师傅」（加拉太书 3:24），把学生拘守在初步的原理之中，但福音却引领我们进到成熟的年岁。另有些人以为这是说不再有年龄的分别；因为在永生之处，孩童与老年人之间并无界限。但我这样解释先知的话：「无论是孩童或老年人，他们都必达到成熟的年岁，以致常常精力充沛，如同壮年之人；简言之，他们必永远健康强壮。」因为我们之所以衰老、丧失力气，乃是因我们的罪。摩西说：「我们经过的日子都在你震怒之下；我们度尽的年岁好像一声叹息。我们一生的年日是七十岁，若是强壮可到八十岁；但其中所矜夸的不过是劳苦愁烦；转眼成空，我们便如飞而去。」（诗篇 90:9-10）但基督来是要修复我们的力量，恢复并保守我们原初的状况。

<span style="color:#800000">*因为百岁死的仍算孩童。*</span> 应当把这两个分句加以区分；因为在说了教会的 <!-- PAGE 624 --> 众民必得长寿，以致无人在未达成熟年岁、未完全跑尽路程之前被从世上取去之后，他又补充说，即使到了老年，他们仍必强壮。虽然大多数信徒因软弱几乎难以支撑自己，另一些人的力气甚至未到时候就已衰残，然而那应许并未落空；因为倘若基督真实而完全地在我们里面作王，他的力量无疑必在我们里面兴旺，并使身体与灵魂都得以强健。所以，我们之所以易受疾病、痛苦、衰老，以及其他种种不便之苦，乃当归咎于我们的罪；因为我们不容基督完全占有我们，也未曾在生命的更新上长进到把一切旧样都脱去的地步。<span style="color:#800000">F1057</span>

在此还当留意：无论灵魂或身体的祝福，都只在基督的国里，就是在教会中才寻得着；在教会之外，除了咒诅一无所有。由此可见，凡在那国里无分的人，都是可怜不幸的；他们无论看来何等鲜活强健，在神眼中却仍是腐烂发臭的尸首。

21、22.<span style="color:#800000">*他们要建造房屋，自己居住。*</span>在这两节中，他提到律法所记载的事；因为这些正是律法中的祝福：凡顺服神的人，必住在自己所建造的房屋中，必从自己所栽种的树上摘取果子。（利未记 26:10）反之，悖逆的人必从自己所建造的房屋中被赶出，让位给外邦人，且被夺去自己所栽种之树的果子。以赛亚说：「耶和华必保护你们脱离那咒诅，使你们得以享用自己的产业。」如今众先知虽提出与今生有关的事，并从其中取譬喻，但其目的乃是要教导我们升到更高之处，去把握那永恒有福的生命。我们切不可把全部注意力停留在这些转瞬即逝的祝福上，而当把它们当作梯子来使用，好叫我们被提升到天上，享受永恒不朽的福分。教会既已被更新，且全然倚靠神的美意与白白的恩宠，那么将不信者自己所丧失的那些福分应许给她，乃是理所当然的。

<!-- PAGE 625 -->

<span style="color:#800000">*因我民的日子必像树木的日子。*</span>有些人认为这是永生的应许，仿佛人得着了生命树；但那是虚构的巧思，与先知的原意相去甚远。我实在诧异，注释家们为解释这段经文竟如此煞费苦心；因为先知所说的，不仅是生命，而是生命的安稳境况；仿佛他说：「你们要栽种葡萄园，吃其中的果子；你们不至于在得着果子之前就从今生被夺去，这果子不但你们自己享用，你们的儿女和后裔也要享用。」他用树的比喻，是因他先前曾说到栽种葡萄园；因此他应许这百姓必平安享用他们的房屋与葡萄园，不被仇敌或强盗扰害，而这安稳的境况必存留如树木的年岁那样长久。

<span style="color:#800000">*我选民所做工的必长久享用*</span>   <span style="color:#800000">F1058</span>。一件工作被称为持续或长久，是指其结果亨通；否则人就要担受长久艰辛的劳苦，却全然徒然，倘若神不赐下成功。仇敌或将夺去、或将毁坏我们所开始的工，而完成它也不在我们能力之内；所以严格说来，所谓持续，并非仅指有些进展，而是指工作得以完成。这里当注意的是：我们不能以别的方式拥有自己的财物、并平安合法地享用它，惟有住在基督的国里——祂是世界唯一的承受者——并被接枝在祂的身体上，才能如此。恶人固然可以多年享用今生的美物；但他们必不断惶惶不安，可怜地自我吞噬，以致连所拥有的也成为毁坏与致死的；因为惟有借着信心，我们才得着凡属有福生命的一切，而没有信心的人不能作基督的肢体。

<!-- PAGE 626 -->
**23.** <span style="color:#800000">*他们必不徒然劳碌。*</span> 他在此列举神应许赐给基督国度的其他各样福分；因为神虽然常常赐福给祂的百姓，然而这些福分在某种程度上是被搁置的，直到基督降临，在祂里面才显出完全而丰满的福乐。总而言之，在基督的治理之下，犹太人与外邦人在各方面都要蒙福。既然我们劳碌却毫无所得乃是神忿怒与咒诅的记号，那么反过来，我们清楚看见自己劳碌的果效，便是蒙福的记号。因此他说，那些从被掳之地归回、为要得着真实完全之拯救的人，必不徒然劳碌，也不白费气力。律法所警告的是亲属的死亡、毁灭性的战争、财产的丧失，以及心中的惊恐（利未记 26:22；申命记 28:48）。而在此处则相反，所应许的乃是丰饶、平安、劳碌的果效与安息。这一类的福分理当仔细留意；因为在劳碌之中，很少有人思想神的赐福，以致将万事单单归于祂，并深信除非主赐下亨通的结果，否则他们必一事无成。因此，正如一切福分都当向神寻求，照样，既已领受，就当单单向神献上感谢。

<span style="color:#800000">*所生产的，也不遭灾害。*</span> 当经上说妇人"生产不遭惊恐"时，有些人解释说，这意味着她们对生产不再有不安或惧怕，因为她们必脱离痛苦。我们知道，这刑罚是因罪而加在妇人身上的，就是艰难地生产，并有死亡的危险。当人预料战争临近时，儿女的出生便伴随着恐惧战兢；而先知在此更可能着眼于此，就是必有如此稳固的平安，以致妇人和男子都无缘由惧怕；因为这必须看作是关乎父母双方的，他们不必为儿女惊惧，不像危险临近时通常所发生的那样。

<span style="color:#800000">*因为他们是蒙耶和华赐福的后裔。*</span> 这理由极为恰当；因为惧怕与惊恐从何而来，惊慌从何而来，岂不是从神的咒诅而来吗？既然咒诅已被除去，先知就理所当然地说，父母连同他们的后裔必脱离惊惧与忧虑不安；因为他们必深信，藉着神的恩眷，他们必永远平安稳妥。

<span style="color:#800000">*并他们的后裔与他们同在。*</span>这是与无子的状况相对照的，而无子乃被列在神的咒诅之中；因此这话就等于说：「我不再夺去他们的儿女，反要使他们享有儿女，连同我将赐给他们的其余福分一同享受。」

<!-- PAGE 627 -->

**24.** <span style="color:#800000">*他们尚未求告，我就应允。*</span>这是一个极宝贵的应许；因为再没有什么比神与我们和好、并使我们能够坦然无惧地亲近他更为可羡的了；因为纵然我们四面被无数的困苦灾难所围绕，只要我们仍可自由地投奔于主，我们就不能算为可怜的。所以主在此应许，我们的祈求必不徒然。然而这也曾应许给律法之下的列祖。诚然，自世界之初，神就垂听列祖，垂听一切求告他的人；因为这是信心最宝贵的果子。但他将此应许愈加坚固。因为犹太人要长久被掳流亡，主就郑重宣告，他必不容他们再在被掳之地衰残，也不再延迟他的帮助，乃要「在他们未曾呼求之先就应允他们」。

这主要是关乎基督的国，我们藉着他得蒙垂听，也藉着他得以进到父神面前，正如保罗所极精妙地阐明的（以弗所书 2:18；3:12）。列祖固然也享有同样的进路，他们得蒙垂听也别无他途，唯藉基督而已；但那门仍是窄的，甚至可说是关闭的，而如今却已最广阔、最完全地敞开了。在律法之下，百姓惯于远远站在外院；但如今却再无一物阻挡我们进入至圣所本身，因为

<p style="text-align:center" markdown="1"><span style="color:#000080">“殿里的幔子从上到下裂为两半。”（</span><span style="color:#000080">马太福音 27:51）</span></p>

因此，我们借着基督得以进入天上，

<p style="text-align:center" markdown="1"><span style="color:#000080">“只管坦然无惧地来到施恩的宝座前，为要得怜恤，蒙恩惠，作随时的帮助。”</span> <span style="color:#000080">（</span><span style="color:#000080">希伯来书 4:16）</span></p>

有人会提出一个问题：「难道当今世上没有信徒，基督也没有国度吗？因为看来神并不那样乐意施行帮助，我们的祈求也看不见什么果效。」我回答说：虽然唯有事情实际应验了，我们才充分看明自己的祷告已蒙垂听，然而在这期间神并未忽视我们；因为祂不容我们疲乏丧胆，而是以祂圣灵的能力扶持我们，使我们能忍耐等候祂。祂的迟延也不像人那样是因为需要时间，而是因为祂要操练并试验我们的忍耐。总而言之，神垂听我们有两种方式：第一，是公开地施行帮助；第二，是以祂圣灵的能力扶助我们，使我们不至在患难的重压下沉沦。倘若这教义深深铭刻在人心里，他们必更迅速、更坦然地奔向神，也不会那样热切地争辩向圣徒祈求的事。因为，人为自己臆造出各式各样的中保，宁可投奔他们而不投奔基督，这究竟是从何而来呢？岂不正因为他们不接受这教义，弃绝了这般宏大丰厚的应许吗？

**25.** <span style="color:#800000">*豺狼必与羊羔同食。*</span> 他的意思是，当基督作王的时候，万物都要完全得着复原。这里似乎暗含着亚当与基督之间的比较。我们知道，今生一切的患难都是从头一个人的罪流出来的；因为在那时我们就丧失了神赐给人（创世记 1:28）管辖各类动物的治权与主权，而这一切动物起初无疑都欣然俯服在人的治权之下，顺从他的意志；但如今其中大多数却起来抵挡人，甚至彼此争战不息。因此，当豺狼、熊、狮子和其他这类凶猛的野兽伤害人，并伤害那些于我们有益的走兽时，当那些本应对人有用的动物竟与人为敌时，这都应归咎于人的罪，因为他的悖逆颠覆了万物的秩序。但既然基督的职任就是使万有归回其本来的状态与秩序，所以他在此宣告，如今人间事务中所存的混乱与败坏，必因基督的降临而被除去；因为在那时，败坏既已除净，世界便要归回它最初的本原。

<span style="color:#800000">*狮子必吃草与牛一样。*</span>「狮子」要无害地进食，不再寻觅它的猎物。蛇要以尘土为足，蜷伏其中，不再以毒牙伤人。总而言之，一切失序混乱的，都要复归其应有的秩序。然而毫无疑问，先知在此是以寓意说到那些残暴凶横之人：当他们服在基督的轭下时，他们那残忍狂野的本性就必被制服。但我们首先必须仔细思量：因人的堕落，一切受造之物所遭遇的那种混乱；因为若不顾念这一点，我们就无法对这复原的恩福有足够正确合宜的认识。同时，我们也当记念我们在解释第十一章中类似的寓意时所说的话。<span style="color:#800000">F1059</span> 在此我们受教认识：在主使人归正、收纳他们进入祂羊圈之前，人的本性究竟如何；因为他们乃是凶残未驯的野兽，唯有当主制服了他们邪恶的倾向和暴虐好害人的欲望时，他们才开始不再行凶伤害。

<span style="color:#800000">*在我圣山的遍处。*</span>加上这一句，是因为当渣滓与污秽被除去之后，主必为自己招聚一个毫无瑕疵的教会。「遍处」一词是指洁净。然而我们不该以如今仍有许多凶暴之人为奇；因为真正住在神圣山上的人甚少，正直而忠信的人也甚少，即便在那些自称为基督徒的人中间也是如此。既然旧人在他们里面仍然掌权、仍然强壮，争竞与战争也必然存在，并在他们中间盛行。
