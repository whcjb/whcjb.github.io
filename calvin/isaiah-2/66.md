# 第六十六章

<p style="text-align:center" markdown="1"><span style="color:#000080">前往 以赛亚书 66:1-19</span></p>

**1.** <span style="color:#800000">*耶和华如此说。*</span>这一段论述与前面的不同；因为先知在此斥责犹大人，他们因倚仗祭物与圣殿的虚妄自信而自高自大，肆意放纵于自己的逸乐，并以此为藉口而自安于罪中。他指明这种自信不但愚妄无据，而且是魔鬼的、可咒诅的；因为凡想要用外在礼仪来事奉神、平息神怒气的人，都是大大地讥笑神。因此，他责备他们：当他们把神关闭在圣殿之内时，就是竭力要造一个偶像来取代神。其次，他讲到教会的更新，以及教会将扩展到全世界。

<span style="color:#800000">*天是我的座位。*</span>先知的目的既是要动摇那些假冒或虚伪敬拜神之人的自满自足，他便从神的本性说起。他以「天」为神的居所，意思是说，神的威严充满万有，无处不在弥漫；祂不但绝非被囚于圣殿之中，甚至不被任何地方所关闭或限制。圣经常常教导我们神在天上；这并非说祂被关在天上，而是要我们的心思超越这世界，不对祂存任何低俗、属肉体或属地的观念；因为单单仰望天空，就当把我们提得更高，使我们进入惊叹之中。然而祂在无数经文中又声明祂与我们同在，祂的能力遍及各处，免得我们以为祂被关在天上。

<!-- PAGE 631 -->
或许有人认为这一点毫无争议，当时人人都承认；因为谁不知道神的威严充满天地呢？所以他们可能反驳说，没有人想把神从天上赶出去，先知没有理由发怒，并作如此激烈的斥责。而他们无疑极其骄傲地弃绝先知这教训，大为恼怒愤恨，仿佛自己受了极大的侮辱。但很容易回答说：当人照自己的臆想设法平息神的怒气时，他们就塑造出一个与神威严完全相反的偶像。他们倚靠自己那些无用的礼仪，以为只要常常上圣殿，在殿中献上祈祷与祭物，就算尽了本分。先知指明，神的威严不可用这样的标准来衡量；他们所献上的一切，若不伴随内心的纯洁，便纯属琐屑无用之物；因为既然从祂以天为居所可见神的本性是属灵的，那么敬拜若不与这本性相称，就必然是邪恶败坏的。

<span style="color:#800000">*你们要为我造何等的殿宇？*</span>先知在「殿宇」或「圣殿」一词之下，包括了他们以为敬拜神所在的一切礼仪；又因为他们以圣殿为标准来衡量神与对神的敬拜，先知便指明，把神的临在看作被限制在一座可见而脆弱的建筑物之内，是与神的威严不相称的。他所论的不仅是神的本质，同时也是论到对神真正的敬拜，他指明这敬拜乃是属灵的，好与「神是个灵」（约翰福音 4:24）的本性相称。人若殷勤思想神的本性是怎样的，就不会为祂设计外来的、新奇的敬拜方式，也不会以自己来衡量祂。<span style="color:#800000">F1060</span>这平常而屡屡被表明的道理，比先知提出某种新奇之事更为沉重有力；因为他指明他们如此愚钝迟蒙，竟连最愚拙的人都熟知的事也茫然不知，并且他们竟像无知的畜类一般，以为神住在圣殿中，安息在其中。因此他轻蔑地问：「那殿宇在哪里呢？」因为无论以为神住在地上，或以为祂被藏匿囚闭在牢狱之中，都是荒谬的。此外，圣殿建在一座小山之上，其有限的规模也不能容纳神的荣耀。

<span style="color:#800000">*我安息的地方在哪里呢？*</span>然而，耶和华曾论到圣殿说：「这是我永远安息之所；我要住在这里，因为我选中了这里。」（<span class="ages-code">&lt;19D214&gt;</span>诗篇 132:14）另有一处说：「耶和华神啊，求你起来，进入安息之所。」（历代志下 6:41）此外，我们在本书前面已看到，「他安息之所大有荣耀。」（以赛亚书 11:10）总之，这是圣殿惯常的称号，然而先知如今却对此加以责难。我的回答是：圣殿被称为神的安息之所，是因为他在殿中赐下他临在的表记；<!-- PAGE 632 -->因为他既拣选此地作人求告他的所在，也要从此地显出他的能力与权柄。但他吩咐建造圣殿，并非为叫人可以照自己的幻想去揣度他的威严，<span style="color:#800000">F1061</span>而是要人藉着神临在的外在标记得着提醒，将心思提得更高，上升到天上，承认神比全世界更伟大、更超卓。然而，人的心思既倾向迷信，犹太人便把那本为帮助他们的事物，变成了自己的绊阻；他们本当凭信心上升到天上，却以为神被拴在他们身上，只草率敷衍地敬拜他，或者说，竟随自己的意思拿敬拜当作戏耍。

这段经文被司提反极其恰切地引用（使徒行传 7:49），保罗也间接地把它应用于我们如今所述的意思上；因为他们都表明，那些把属肉体的礼仪献与神、仿佛纯正的敬拜与虔诚就在于此的人，或那些以雕像和偶像邪恶亵慢地污损神之敬拜的人，都大大受了欺骗，远离了正路。司提反对犹太人说话，他们既执着于律法的影儿，就轻忽了真敬虔；而保罗对外邦人说话，则断言「创造宇宙和其中万物的神，……不住人手所造的殿。」（使徒行传 17:24）

**2.** <span style="color:#800000">*这一切都是我手所造的。*</span>先知在此驳斥人对敬拜神所持的错谬观念，即以为祭物与外在礼仪本身有极大的价值；因为问题的实质在于此：神并不看重礼仪，反倒当人以为藉着礼仪就使神满意时，这些礼仪只是空洞无用的面具。他说这一切都是他所造的，这不可仅仅理解为指圣殿，而是指在那里献与神的一切。他如今说他「造了这一切」，目的是要人知道神并不需要这外在的敬拜，正如他宣告（诗篇 50:10）众牲畜都是他所造、都是属他的，尽管犹太人指望藉着献上这些牲畜得他的恩眷。但愚昧的世人身上深植着这样一种病症：他们照自己的偏好去改造神；其实神设立外在敬拜并非为他自己的缘故，而是为我们的益处，就是要照我们肉体的能力藉此训练我们。

<!-- PAGE 633 -->

<span style="color:#800000">*这一切都是我手所造的。*</span>这就等于说，他不可与这些曾在某时开始存在的事物相比；因为他是永恒的，没有起始。主仿佛说：「我可以不需要你们的祭物，因为在它们尚未存在之先，我已存在，所以它们对我毫无效用。」简言之，他坚持礼仪本身毫无功效，而是指向另一个目的。以赛亚以此为不言而喻之理：神绝不可能被加添什么；由此可见，他单单以自己为满足；因为从永恒里他就可以不需要这世界。

<span style="color:#800000">*但我所看顾的，就是虚心痛悔的人。*</span>接着又加上合法敬拜的定义；因为当他说神「看顾虚心的人」时，我毫不怀疑，他是间接地将那「虚心痛悔」的人与礼仪的排场、辉煌与华美相对照——人的眼目常被这些所炫惑，以致被卷入惊叹之中。反之，主见证说，他所要求的是谦卑俯伏、因他诫命而战兢的心。他用这些话描述内心的洁净与对敬虔的真诚渴慕，同时指明我们当以何种方式预备自己，才能使神喜悦。

<span style="color:#800000">*因我话而战兢的人。*</span>就「战兢」而言，乍看之下，他向信徒要求这一点似乎奇怪，因为再没有什么比主的话语更甘甜、更温柔，也再没有什么比激起恐惧更与之相违。我的回答是：战兢有两种；一种是那些憎恨神、逃避神的人所有的惊惧，另一种则是感动那些敬畏神之人的心、促使他们顺服的战兢。我知道有人把这一句看作与律法有关，因为律法威吓人、使人惊恐，并宣告神可怕的审判。但我按更广义来理解；因为信徒即使在存敬畏之心领受应许时，也会战兢。由此可以推论，真敬虔在于使我们的心思意念降服于神的顺服之中，并且不为自己作任何夸口或邪恶的主张。信心的本性就是向神顺服，并在他说话时专心忍耐地聆听他。然而当我们自高自大、被对自己的虚妄自信所卷走时，我们就毫无虔敬、毫无敬畏神之心；因为我们若为自己主张丝毫，就必轻视神。

<!-- PAGE 634 -->

我们应当仔细留意他所用的措辞：「因神言语战兢」。许多人夸口说自己敬畏神；然而他们既轻忽神的话语，也就同时表明自己是藐视神的人。我们所当归给神的一切敬畏，都必须归给他的话语，因为他愿意在他的话语中被人充分认识，如同在一幅活的形像中。这里所说的要义乃是：当信徒藉着真实的克己，卑微俯伏，以致对自己毫无高抬的看法，反倒甘愿被贬为无有之时，神看重这祭胜过其余一切的祭。诗人也照样说：「神所要的祭就是忧伤的灵；神啊，忧伤痛悔的心，你必不轻看。」（诗篇 51:17）因为这信心的谦卑生出顺服，所以这敬虔的情感也一同加上：他们放下一切顽梗，因神的话语战兢。

从这些话中，我们当汲取一项非凡的安慰：「我们虽在卑微谦抑之中显为可怜，虽显为不配被人看顾，我们却是真正有福的；因为主眷顾我们，将他的恩宠赐给我们。」当我们被试探而近乎绝望时，让我们思想：主正是以这样的方式，将他的仆人高举到天上，纵然他们曾被抛入阴间，几乎在重担之下沉沦。

**3.** <span style="color:#800000">*假冒为善的宰牛，好像杀人。*</span> 这一节有两个分句。在前一分句中，以赛亚明白宣告：他本国的一切祭物在神眼中毫无价值，反被他所憎恶；在后一分句中，他描述那可怕的败坏，就是他们将外邦人的礼仪掺杂在律法的祭祀之中，如此便把一切都玷污扭曲了。大部分注释者认为这些话废除了律法的祭祀，但这是一种错谬；因为以赛亚在此处所论的，与他先前在第一章和第五十八章中所论的是同一主题，他并非绝对地定罪献祭，而是定罪其中的瑕疵与败坏，因为犹太人以为神满足于虚伪空洞的外表，同时却毫不顾念真正的敬畏神与清洁的良心。所以他并非论到事情本身，乃是责备那些滥用祭祀的人；因为这无异于把空核桃的壳献给神。总而言之，除了那些出于纯洁的心与正直的意志的祭物之外，没有别的祭物是神所悦纳的。

然而，先知在此很可能是暗指外邦人的祭祀，那些祭祀是骇人而怪异的；因为他们杀人，或将人活埋。无论是罗马人（他们自以为比别国更敬虔），甚至犹太人，都未曾远离这罪。不仅如此，那些（<span style="color:#0000d4">κακόζηλοι</span>，恶劣的效法者）以许多杀婴之举污秽自己，还以为自己是效法他们的父亲亚伯拉罕。以赛亚说，"他们宰牛之时，所行的正如杀人一样"；<span style="color:#800000">F1062</span> 他借此表明：犹太人虽有独特的、神所设立的宗教，却在任何方面都不比外邦人更好——外邦人中间一切都被污染、都是亵渎的——他们也并不更蒙神的悦纳；因为借着宗教上的假冒为善而亵渎神的名，与借着败坏虚假的敬拜而亵渎神的名，其罪并无轻重之分。这一警告何等必要，我们先前已经看见；因为犹太人虽在一切罪上被定罪，然而只要他们藏身在这遮蔽之下，就自以为安然无虞。所以先知理当迎面驳斥他们，说：他们企图平息神怒所得的，不过与他们想从外邦人可憎的亵圣之物中献祭一样，毫无所得。

<!-- PAGE 636 -->
<span style="color:#800000">*他们倒喜爱自己所择的道路*</span>。对这段经文有两种解释；因为这代词的先行词或可指外邦人，或可指犹太人；就是说，或指犹太人与外邦人邪恶的礼仪相混杂、相纠缠，或指他们随从自己的臆造。前一种解释本不算不合宜，只是它不够自然，因为前文并未提及"外邦人"一词。犹太人的罪恶中最为加重的一点，就是他们不但滥用神纯正的敬拜，而且因藐视律法，以邪恶可憎的迷信污秽了圣殿和一切别的地方。他们在高处筑坛，栽植培育树林，喜爱赛会与公众娱乐，并且效法一切由公众权柄所设立、为要败坏人心的事。这样，在他们中间就产生了迷信的混杂杂糅，正如我们今日在教皇制中所看见的：在其中我们看见各式各样的补缀缝合在一起，取自各类迷信——不但有异教的、犹太的，也有撒但近来所设计的，为要更容易、更貌似有理地欺骗世人。这些以及类似的行径，先知理当宣告为双倍该受定罪的，因为他们一面夸耀神的名，一面自称敬拜他，却仍不以拜偶像之邦的亵圣之事玷污污秽这敬拜为耻。

另一种解释也并不含晦，且同样合宜，即犹太人一心专注于自己的臆造，随从自己可憎之事。先知断言：凡按自己的任意妄想藐视神的人，都不是真诚敬拜神的人；这不仅因为他们满了贪婪、仇恨、野心、不诚实、残忍和勒索，也因为他们以自己的设计败坏了对神的敬拜。虽然那代词指犹太人，先知却也一并定罪他们从异教诸国借来的一切迷信。因此这两种解释相差甚微；因为他所教导的不过是：既然他们蛮横悖逆地挣脱了神的轭，既然罪恶在他们中间公然横行，那么凡从他们而出的都是污秽可憎的。从污泥浊水的泉源流出、带着污秽可厌之物的溪流，绝不可能洁净纯清。"喜爱"与"心愿"更清楚地显明他们的顽固；就是说，因为他们明知故犯、甘心乐意地藐视神的诫命，把心专注于一切与诫命相违之事，仿佛他们有意要轻蔑一切从神而来的，好去顺服自己败坏的私欲。

<!-- PAGE 637 -->
**4.** <span style="color:#800000">*我也必选择他们所怕的（我也必拣选他们的妄想）。*</span> <span style="color:#800000">F1063</span> 先知的意思是：犹大人虽然摆出种种貌似合理的托词、寻找各样借口，却毫无所得；因为神并不在意人的狡诈或漂亮言辞。的确，我们不当以自己的悟性来衡量神，也不应倚赖人的判断；我们的本分乃是照着神的话来判断神的作为。「我要选择」，就是说：「他们竭力用来蒙蔽自己的云雾，我要将其吹散，使他们的妄想显明出来，众人都能看见；因为如今那些事似乎隐藏着，但有一天必被拖出来公开示众。」其含义可如此总括：「因为犹大人放纵自己任意犯罪，以致凡他们所选择的都被他们看得比神的诫命更重，所以神也要反过来照他自己的心意揭露他们的妄想。」

<span style="color:#800000">*使他们所怕的临到他们。*</span> <span style="color:#800000">F1064</span> 他按希伯来作者的惯例，用「所怕的」一词重复同一件事。「我要使他们知道，他们已陷入错谬之中，他们所纵容的那些恐怖必归到他们自己头上。」 <span style="color:#800000">F1065</span> 这样，他们的借口或假冒为善的托词，就丝毫不能混淆真理与虚谬、掩盖迷信；因为主必将二者清清楚楚地分别出来。

<span style="color:#800000">*因为我呼唤。*</span> 先知再次责备犹大人的顽梗，因他们不容主纠正他们。矫正我们恶习所存留的唯一良方，就是听主说话，当祂设法把我们领回正路的时候；然而当我们塞住耳朵、刚硬己心时，这便是万恶中最恶的了。所以，人何时把自己的臆造看得比神的典章诫命更重，就何时公然藐视神，而他们本该顺服神的旨意。当再加上那种顽梗的心硬，把圣洁的警告关在门外时，情形尤其如此；他们若辩称自己所行的既是为了敬拜神，就不可能使神不喜悦，那也是徒然的；因为凡人忽略神的话而自行选择、自行遵从的一切，主都弃绝厌恶。

<span style="color:#800000">*在我面前。*</span>他重复先前所说的，就是犹大人在神眼前犯罪，好像他们决意要惹他发怒。最后他又加上他们如此行的方式，就是他们以刚愎的欲望追求神所禁止的事；他之所以如此频繁地责斥人的邪恶狂妄——藐视神所悦纳的，从而夺去神当得的权利——绝非没有充足的理由。

**5.** <span style="color:#800000">*你们……当听耶和华的话。*</span>他将话语指向那些真心敬拜神的人，并向他们应许在那些可怕的灾祸中他们几乎不敢期望的事；他特意向他们说话，因为那时有许多人虚假地夸耀神的名。不但如此，他离开那不加区分的众人，单独向一小群人说话，正如他先前所说：

<!-- PAGE 638 -->

<p style="text-align:center" markdown="1"><span style="color:#000080">「要卷起律法书，在我门徒中间封住这训诲。」</span> <span style="color:#000080">(</span><span style="color:#000080">以赛亚书 8:16)</span></p>

<span style="color:#800000">*你们听见他话战兢的人。*</span>他在此以这一标记指出神真实诚恳的儿女，就是他们「听见耶和华的话就战兢」。这实在是一种罕有的美德；因此他将它与那些人虚假的信仰宣认相对照——那些人只带着割礼的外在标记，却愿被算在神的百姓之中，并且大肆宣称、炫耀自己的圣洁；使我们知道，唯有那敬畏尊重神圣言的人，才是敬畏尊重神的人；也就是说，那因听见神的声音而被大能所折服，以致强迫自己一切的感官去顺服的人；因为这是敬虔的显著凭据。

<span style="color:#800000">*你们的弟兄说。*</span>因为假冒为善地敬拜神的人惯常大声夸耀他们浮华的礼仪，所以先知的用意乃是要武装并坚固信徒，使他们能忍受这些人的攻击，免得在被讥笑侮辱时便退缩。这好像他说：「你们不但要与外邦人争战，也要与家里的仇敌争战，就是那些在教会中占有一席之地、并因你们所共有的神之约而与你们有弟兄名分之联系的人。倘若他们讥笑你们的纯朴，正如他们骄傲地藐视神自己一样，你们就当勇敢无惧地抵挡那试探。」因此他称他们为「弟兄」，虽然他们是信徒和神的话语的仇敌，因为他是姑且让步，才把他们所僭妄冒用的名称给他们。由此我们推知，这并不是一种新的祸患，即那些顶着弟兄之名的仇敌，竟在教会的怀中被养育。这内部的争战必须与假冒为善之人不断地进行下去，因为他们不能容忍我们以诚实正直的良心敬拜神。

<!-- PAGE 639 -->
<span style="color:#800000">*为我名将你们赶出。*</span>按字面意思是「吩咐你们滚开」。正如我们看见教皇可怕地向我们发出雷霆之怒，仿佛我们是卑贱无用之人；假冒为善之人也是这样把那为数不多的信徒赶出去；因为他们在人数、权势和财富上占优势，便也如此施行那样的专横，凡事都照自己的任意妄想去认可或否定，并使信徒被视为毫无价值——他们不但如糠秕压过麦子一般以其庞大的数目淹没信徒，更骄傲地将他们践踏在脚下。

<span style="color:#800000">*愿耶和华得荣耀。*</span>或按将来时译作「耶和华将得荣耀」。另有人译作「耶和华是严厉的」；但让我们看看哪一种意思更为可取。那些译作「耶和华是严厉的」的人认为，这是恶人抱怨神过于严厉，不肯宽容祂的百姓，反而严厉对待他们；他们又认为，百姓因这话被引诱至绝望；因为当恶人企图使我们偏离神时，他们便夺去一切得救的盼望与信心。然而我更倾向于另外两种解释中的任一种。最为普遍认同的是以下这一种：恶人讥笑那些预言与应许，因为先知们屡屡提及的那荣耀，处处都看不见；仿佛他们说：「愿主显出祂荣耀的某些凭据，好使我们可以稳妥地倚靠它。」因此先知愿意武装信徒，抵挡这样的褻慢，免得他们让自己的信心被恶人的嗤笑所倾覆。但这段经文也可以恰当地、或许更为准确地解释为：恶人为自己夸下极大的口，好像凭着他们的善行就配得神的恩眷一样，正如阿摩司书 5:18 也责备他们，说他们一面无所畏惧地惹动神，一面却自信满满地倚赖祂必向他们施恩。因此，既然他们倚仗自己的祭物，藐视一切的威吓，又夸口说神必帮助他们，先知便回答说：他们必以极不相同的方式看见神的荣耀。<span style="color:#800000">F1066</span>

<span style="color:#800000">*他却要显现，使你们喜乐。*</span>这好像是说：「神藉着祂的降临，必使信徒知道他们并未徒然盼望；因为祂的显现是为信徒的益处，也是为那些坚称祂必作恶行护卫者之人的灭亡——对这等恶行，祂反倒要作严厉的报应者。前者必享欢乐与安慰，后者却必羞愧、必蒙羞，因为他们快要觉察到：他们如今所讥笑的神的审判，已经临近了。」

<!-- PAGE 640 -->
**6.** <span style="color:#800000">*有喧哗的声音出自城中，有声音出于殿中。*</span>他在此确证前面所说的话，就是：神并非徒然发出威吓，说祂必速速降临，向假冒为善的人施行报应；这样，那关乎欢乐的应许就可被信徒更加热切地期待。他所描述的仇敌是谁，尚不确定；因为这段经文可解释为指着巴比伦人说的，他们的毁灭就是神教会的拯救。也可解释为指着别的仇敌，就是在教会怀中被养育起来的那些人；我更赞同这后一种看法，虽然我不否认这话也可看作指任何一类仇敌。但他心中所注目的乃是家内的敌人，即他先前所论及的那些人，他们藐视神藉先知之口不断向他们发出的声音。因此他威吓说，他们必速速听见另一种更为可怕的声音；但随即又加上缓和之语，免得同一样的恐惧使神那些信实的仆人丧胆。

其含义可归纳如下：「恶人夸口，以自己的顽梗抗拒神的审判，全是徒然；因为他们逃不出祂的手，甚至那作他们虚假倚靠的藏身之处——『殿中』——也必发出祂的声音，那时信徒便得着他们忍耐的果子。」但愿我们今日不曾在假冒为善之人身上经历同样的轻蔑，他们蔑视一切劝责与警告，全不尊重神的话！因此，对这等人，我们不得不威胁说，取代他们如今所听见那温和柔缓之声的，将是「哄嚷的声音」，是他们有一天要从别的、且是大不相同的主人口中听见的；因为世人既以不虔的嘲讽藐视神的话，就必被迫不但听见、更要亲身经历那带着兵器的声音，就是刀剑与火。

<!-- PAGE 641 -->
**7.** <span style="color:#800000">*锡安未曾劬劳就生产*</span>。先前先知既安慰信徒，使他们不因弟兄的傲慢与轻视而丧胆——神终必刑罚那等人——又如此吩咐他们要以坚定不移的心等候主的降临，主同时又加上一句：祂刑罚他们的方式，乃是藉着他们的灭亡来成全信徒的安全。祂所说的不是一两个人，而是全教会，祂将教会比作一个妇人。这同一比喻祂先前已数次用过；因为神主要的目的乃是将我们聚集成一体，使我们在其中得着我们得儿子名分的凭据，承认祂为父，并在教会——我们的母亲——的腹中得着养育。所以这「母亲」的比喻极为贴切。其意是说：教会虽一时看似无儿无女、且是不生育的，却必如此得着复兴，以致她要得着众多广大的后裔。

<span style="color:#800000">*未觉疼痛就生出男孩*</span>。他重复了他在别处已经用过的同一说法；但他在此表达了更多的意思，就是神这工作必是突然而出人意外的；因为他警戒信徒不要存属肉体的看法，免得他们按自己的意见来判断教会的复兴。妇人怀胎九个月，最后在大痛苦中生下孩子。但主生养儿女的方式却大不相同；因为祂说，祂要使那孩子见光，甚至在人还未能藉任何疼痛的感觉察觉或辨识之前。为此，祂也将一切赞美都归给自己，因为奇事排除了人的劳作。

<span style="color:#800000">*她生了一个男孩。*</span>他特意提到「男孩」，为要描述这些儿女刚强勇毅的心；因为他的意思是，他们必是尊贵的后裔，而非柔弱娇气的。照样，我们知道信徒是由基督的圣灵重生的，好使他们能以不动摇的刚毅走完争战的路程；正是在这意义上，保罗说他们「所受的不是胆怯的心」。（罗马书 8:15）

<!-- PAGE 642 -->
**8.** <span style="color:#800000">*国岂能一日而生？*</span>他极力称扬自己所述之事的伟大；因为他的意思是，教会必有一场奇妙、「前所未闻」的复兴；以致信徒不当照自然的常规去判断此事，而当照神的恩典去判断；因为当人思量此事时，他们觉得这好像是做梦，正如诗人所说的（<span class="ages-code">&lt;19C601&gt;</span>诗篇 126:1）。他并不是说教会必在一瞬间得着完全的复兴；因为这复兴的推进是宏大而长久的，按肉体的估量甚至是缓慢的；然而他表明，即连它的开端也超乎人一切理解力所能领会。他也并非说夸大之辞；因为我们常见教会生产儿女，而先前她看来并未怀孕。不但如此，当人以为她不能生育时，她却因福音的宣讲而多结果子；以致当那事发生之后，我们大为惊叹——就是我们从前认为绝不可能之事。

这些事在百姓从巴比伦归回之时曾在某种程度上得着应验；但在福音里却有了远为光辉的见证，因着福音的传扬，一群多样而众多的后裔立时被生了出来。在我们自己的时代，我们岂没有看见这预言的应验么？在福音得着宣讲的这三十年间，教会生了多少儿女？在今日，主岂不是在全世界拥有数目极大的百姓么？所以，这里所预言的，没有一件不是清楚可见的。

<span style="color:#800000">*国岂能一时而生？*</span>他用一个比喻来彰显这奇事的荣耀。从来没有一个「国」是在一瞬之间进入世界的；因为人是渐渐聚集，渐渐增多，渐渐扩展成为一国。但教会的情形却大不相同，她一举之间，且不止在一处，生下无数的儿女。这话的意思是：神要以奇妙的方式，使教会无数的儿女在非常的作为中，一时之间、忽然之间被生下来。

<span style="color:#800000">*国岂能一日而生？*</span><span style="color:#008080">ארץ</span>（*eretz*）这字，「地」，既可指任何一片地土，也可指其上的居民。

<!-- PAGE 643 -->
**9.** <span style="color:#800000">*耶和华说：我既使她临产，岂不使她生产呢？*</span>他在前一节以崇高的言辞称扬神的作为，如今则指明，这作为不当被视为不可信的，我们也不当怀疑他那超越一切自然次序的能力；因为我们若思想说话者是谁，思想成就他所应许之事对他是何等容易，我们就不会停留在那样的迟疑之中，反倒立刻想起：世界的更新在他手中，而他要在一瞬之间创造一百个世界也毫无难处。稍前他借着惊叹之情的迸发，意在夸显这工作的伟大。但如今，为免敬虔人的心思陷入困惑或为难，他劝他们思想他的力量；并且为要更充分地使他们确信，凡在人眼中看为极难的事，在他却无一不在他能力之内、无一不为他所轻易成就，他就提出我们每日所见的事；因为在妇人生子这事上，我们清楚看见他奇妙的能力。那么，在扩展并增多教会——他荣耀最主要的舞台——这事上，主岂不显明自己更加奇妙吗？因此，若以为他直接行事、公开伸手作为时，反不如藉自然的方法行事时那样有能力，从而限制他的力量，这乃是极大的罪恶。

**10.** <span style="color:#800000">*你们爱慕耶路撒冷的都要与她一同欢喜快乐。*</span> 他应许说，从前忧愁悲伤的人，将有欢乐的光景；因为以赛亚所着眼的不是他自己的时代，而是被掳的时期。在那期间，信徒不断哀叹，被忧愁所压倒，几乎绝望；因此他劝勉并激励一切对教会怀着深切之爱、且以教会的兴盛为最可羡慕之事的信徒，叫他们欢喜。他借此教导他们：惟有那些被对教会的敬虔之爱所感动、并渴慕寻求她得拯救的人，才有分于如此宝贵的福分——而且是在教会于世人眼中被藐视之时仍然如此；正如诗人所说：

<p style="text-align:center" markdown="1"><span style="color:#000080">「你的仆人原来喜悦她的石头，</span> <span style="color:#000080">可怜她的尘土。」（</span><span class="ages-code">&lt;19A214&gt;</span><span style="color:#000080">诗篇 102:14）</span></p>

因此他接着说——

<span style="color:#800000">*所有为她悲哀的人；*</span>因为在被掳之中有可怕而骇人的荒凉，似乎再没有得救的指望，所以他激励信徒，吩咐他们欢喜快乐，或至少预备自己迎接喜乐。这劝勉中也含着一个应许，且不止于此，因为单单一个应许不足以有这样的分量。然而这些话不可只局限于某一个时期；我们当持守那已多次论及的普遍原则，就是：这些应许当从百姓的归回一直延伸到基督的国度，以及那国度的完全成就。

<!-- PAGE 644 -->
**11.** <span style="color:#800000">*使你们……得吃奶。*</span>这一节应当与前一节相连；因为先知在此说明喜乐的缘由是什么，就是教会那可怜困苦的境况必转为幸福兴盛的境况。他用「吃奶」一词，是暗指婴孩；如同他说：「使你们尽享母亲的一切好处，紧靠在她的怀中。」在此，凡属信徒的，无论年岁如何，他都比作孩童，好叫他们记念自己的软弱，并因主的力量得以坚固；因此这「吃奶」与「挤奶」的比喻当予以细心留意。

<span style="color:#800000">*从她安慰的怀中。*</span>有人将「安慰」一词作主动意义解，也有人作被动意义解；但我更愿采用被动的含义；因为他所指的是教会所领受的安慰，并将这安慰分给她的儿女。的确，没有什么比这喜乐的根基更大、更丰富、更卓越的了；而这从下面的话更显明可见：「使你们因她荣耀的丰盛得喜乐。」

**12.** <span style="color:#800000">*我要使平安像河水延到她那里。*</span> 他继续他的比喻，把神的儿女比作婴孩，被母亲抱在怀中，在母亲胸怀里得着温暖，母亲甚至与他们嬉戏。为要更强烈地表明祂对我们的慈爱，祂把自己比作母亲，而母亲的爱，正如我们前面所看到的（第30页），远远超越一切其他的爱（以赛亚书 49:15）。主愿意为我们作母亲，好使我们从前所忍受的烦扰、辱骂、困苦和忧虑，转为祂温柔的对待，仿佛把我们抚抱在祂怀中。祂用「平安」一词，是指兴盛安泰。

<span style="color:#800000">*使外邦的荣耀像涨溢的河。*</span> 「荣耀」一词乃是重复的说法，藉此指出各样的财富，使那完全丰盛的平安一无所缺；因为外邦人从前生活奢华，享有一切可羡之物的极大丰盈，所以他断言一切财富、以及凡属幸福生活的事物，都必归信徒所有，如同江河流入大海。祂用「不断涨溢」表明其长久持续；因为神既是永不枯竭的泉源，祂的平安就与世界的平安大不相同，后者迅速消逝、很快干涸。因此每当我们看见教会可悲忧愁的境况，就当记得这些应许与我们相关，并不亚于与那百姓相关。既然主有平安的江河，愿意使之流入祂的<!-- PAGE 645 -->教会，那么纵在最猛烈的战争中，我们也不当绝望；反倒要在困苦艰难之中，使我们的心欢畅喜乐。当祂喜悦我们如婴孩，而非如成年之人时，我们就当承认自己的光景，好叫我们以这样的安慰为足。的确，祂如此担当我们的软弱，正是祂何等俯就的明证。

**13.** <span style="color:#800000">*母亲怎样安慰儿子*</span>  <span style="color:#800000">F1067</span> <span style="color:#800000">*，我就照样安慰你们。*</span> 令人惊奇的是，先知似乎已经就这更新之事说得够多了，却仍如此详尽地反复申论。但因为他既无法表达神向我们所存之爱的伟大与热切，也无法说得使自己满意，所以他就屡屡提说、反复申明。

<span style="color:#800000">*你们也必在耶路撒冷得安慰。*</span> 这句话有两种解释方式。或可说，当信徒看见教会得着复兴时，心中必然欢喜；或可说，教会在得着复兴之后，必尽其本分，使她的儿女欢乐。我更取后一种解释，虽然两者都无不可。前一种看似更为丰富；但我们当思想的是先知的原意，而非我们自己认为最美的说法。诚然，他首先以神为这喜乐的创始者，这是理所当然的；但其次，他又补充说，耶路撒冷是神的使女。然而这话并非对那些不敬虔的讥诮者说的，他们对教会毫无挂念；乃是对那些以圣洁的热忱宣称自己是教会儿女的人说的。

**14.** <span style="color:#800000">*你们看见，*</span> 先知用「看见」一词，表达确凿无疑的经历，好叫信徒对结局不再怀疑，反倒以完全的信心持守这预言，暂且忍耐教会荒凉的光景。

<!-- PAGE 646 -->
<span style="color:#800000">*你们的骨头必得滋润像嫩草一样。*</span> 他用一个比喻来阐明前面所说的，就是说「他们的骨头」必重得从前的元气，如同枯干的「草」再次转青发嫩。他提到「骨头」，因为骨头通常因忧伤的心灵而枯干（箴言 17:22），反之，则因喜乐畅快的心境而丰润刚健。他借此描写一种炽热而无可估量的喜乐，并且似乎暗指信徒在被掳期间几乎被忧愁枯干、形同死人的光景。因此，主安慰他们，应许教会必兴盛，凡所羡慕的必样样丰足；如同缺乏滋润的骨头重得从前的元气，又如冬天看似枯死的青草，年年恢复其翠绿。

<span style="color:#800000">*耶和华的手向他仆人所显的。*</span>为要使他们怀抱信心，他接着吩咐他们仰望神，因神那时必显明他的帮助。由此可见，神的手并非总是被人知晓，有时却是隐藏的，仿佛他毫不顾念自己的百姓。乍看之下，他似乎已将他们弃绝；因为但以理和其他敬虔人（但以理书 1:6）也与西底家一样（耶利米书 52:9）被掳去了。他说，当好天气向他们微笑之时，善人与恶人之间必有这样的区别，以致从前多少有些隐藏的这手要被显明出来；因为他不再隐藏自己，也不再容许恶人肆意掠夺而不受约束，反要公然显明他对自己百姓的看顾何等殷切。所以，倘若仇敌一时占了上风，肆行不法而未受刑罚，倘若我们似乎被忽视、毫无援助，我们也不要绝望；因为时候将到，主必显明自己，从他们的攻击与暴虐之下把我们救出来。

**15.** <span style="color:#800000">*看哪，耶和华必在火中降临。*</span>这一（<span style="color:#0000d4">ὑποτύπωσις</span>，生动描绘）活泼描写的目的，是使信徒看见卑劣之人讥笑他们的苦难、且越发放肆时，不致因此偏离正路，或丧失勇气；因为先知的意图不只是要击打那些不为任何威吓所动、藐视一切教训的恶人，<span style="color:#800000">F1068</span>更是要安慰敬虔人，使他们觉得自己是有福的，因他们在神的保护之下；也不致因恶人事事顺利而依附他们。所以，他所主要顾念的是信徒的益处，使他们以神的保护和恩典为满足。但这里或可存疑：他是否把末后的审判，与他此刻开始用以管教恶人的暂时刑罚一并包括在内。就我而言，我毫不怀疑他也有意把那审判包括在内，与那些仅是永远沉沦之先兆的刑罚一同论及。

<!-- PAGE 647 -->

<span style="color:#800000">*必降临。*</span>这话开始应验，是在神将百姓掳到巴比伦、向境内的仇敌施行报应之时。其次，当拯救的时候满足了，他就用武力更严厉地攻击那些邪恶的外邦人，并不断赐下其他种种他临近的凭据，藉此表明他与被拣选的百姓同在，并在火中降临审判他们的敌人。最后，我们知道在末日他必在火中降临，向一切恶人施行报应。然而这段经文不应局限于末后的审判，以致把其余一切都并入其中。不过这些威吓，正如我们随后就要看见的，先知乃是特别针对假冒为善的犹大人而发的。

这类隐喻的说法在圣经中极为常见；因为若非先知们采用取自我们所熟知、所习见之物的隐喻，我们便无法领会神这可怕的审判。（帖撒罗尼迦后书 1:8；彼得后书 3:7。）先知借着这些隐喻，力求在我们的知觉上留下深刻的印象，使我们既被真正的敬畏神之心所震动，就不再羡慕恶人，因为如此可怕的报应已为他们预备好了。由此可见，那些诡辩家的思辨何等琐碎无益，他们争论那火的精微性质与属性；因为圣经的用意乃是借着比喻向我们指出神那可怕的审判，否则我们既无从想象，也无从理解。这一点从下一节中「刀」这个字更加显明，因为它所传达的正是同一个意思。

**16.** <span style="color:#800000">*因为耶和华必以火施行审判。*</span>他在此并未提出什么新的内容，只是确认前面所说的，并表明这审判将是可怕的，免得有人以为这是无关紧要的事。因此，他用极强烈的言辞描述那种恐怖，使恶人生惧，另一方面也使信徒保守自己圣洁贞正，远离恶人的社会。然而，愿他们忍耐地承受仇敌不义而残酷的攻击，直到那全副武装的报应者从天而来。<span style="color:#800000">F1069</span>

<!-- PAGE 648 -->
<span style="color:#800000">*被耶和华所杀的必多。*</span>他警告说众人都必灭亡，以致尸首堆积如山。他特意加上这句话，因为不敬虔之风到处盛行，而信徒因恶人的兴盛而陷入危险的试探；因为我们的心思何等反复无常，竟容许自己被恶劣的习俗引诱，又被众人的势众所惊吓，仿佛这就足以拦阻神的手。先知纠正这有罪的惧怕，提醒他们说：不敬虔越是充斥，恶人的数目越是众多，耶和华的怒气就越发被点燃，为要施行更大、更广泛的杀戮；不敬虔之人的众多与同谋，绝不能拦阻他将他们一同投入同样的毁灭之中。

**17.** <span style="color:#800000">*那些洁净自己……的人。*</span> 他现在描述那些仇敌，就是他先前说神的忿怒要向他们发作的人；因为可能有人怀疑，他所说的究竟是外邦的、公然的仇敌，还是把话指向那些藐视神的人——虽然这些人混杂在蒙拣选的圣民中间。因此，他明明白白地对那些虚伪、堕落的犹太人说话。我毫不怀疑，他首先斥责的是假冒为善的人，其次，当他说「吃猪肉的」时，他所描述的是那些生活败坏的人，就是那些公然作恶、放纵至极的人。假冒为善的人洁净自己，就是说，他们披上虚假的圣洁外衣，并借着这种伪装欺骗了许多人。

他们<span style="color:#800000">*在园中洁净自己*</span>；就是说，他们以各样的迷信玷污了自己，虽然他们自以为借着那些迷信，就使自己在神眼前成为洁净了。另有些人则毫无掩饰地藐视神和一切宗教。所以这是一句总括的话，其中包含了一切不敬虔的人，无论属于哪一类；就是说，既包括那些公然显露其邪恶的人，也包括那些以各样伪装遮盖掩饰其邪恶的人。

<span style="color:#800000">*随从中间的一个。*</span> <span style="color:#800000">F1070</span> 有些注释者在此补上「池」或「盆」一词；仿佛有圣水安置在园子「中间」，供人洗濯之用。但另一种解释同样贴切：即各人各自为己拣选一位神，因此在众多的树木中，各人都有自己的一棵树。

<!-- PAGE 649 -->
**18.** <span style="color:#800000">*我知道他们的行为和他们的意念。*</span> <span style="color:#800000">F1071</span> 他在此确证前一节所说的话，就是刑罚必要临到一切不敬虔的人身上；虽然主暂时容许他们犯罪而不受惩治，信徒既深知他们终有一日必受刑罚，就当谨慎，不去效法他们。主在此见证说，他看见并察看他们的行为，并且有一日他必实实在在地显明：无一件事能在他眼前隐藏。另有些人将此解释为：不敬虔的人若非得着神的许可，什么也不能作成。这话固然真实，却不适用于本段经文；因为人人都看得出，那样的解释既不自然，也与先知的上下文不合，先知在此只是确证他先前所说的：假冒为善的人和恶人终不得逃脱刑罚而无事，因为神察知他们一切的作为、谋算和意念；他们的种种推诿毫无益处，仿佛他们永不会被拖到审判台前。

<span style="color:#800000">*时候将到。*</span> 这些话更加确证了上文所说的，因为他说，时候近了，那时他要聚集万民，为要弃绝假冒为善的人和不敬虔的人，并从他们中间为自己招聚并收纳一群百姓。犹大人心中自高自大，藐视一切别的民族为不洁。但主宣告说，他要收纳那些外邦人，使他们得与他的荣耀有分，而犹大人却自证为不配得这荣耀。

这是一段极其重要的经文，它教导我们：神并不受限于任何一个民族，以致他不能照自己所喜悦的拣选任何人，也不能弃绝那些他先前所召来归他自己的不信之人。保罗对此作了充分的阐明（罗马书 10:19；11:25），他在那里指出，我们是进入了一个因犹大人不信而被弃绝、以致空置的产业。以赛亚现在就这样威吓他们：「不要以为，当你们背叛、自证为不配得他恩典的时候，神就缺少百姓了；因为他必另有别的百姓；他必显明自己是审判者，绝不容你们终久这样滥用他如此大的宽容。」

<span style="color:#800000">*他们必来。*</span>他说“他们必来”，因为借着信心的合一被接枝进来，他们要在教会里与那些未曾偏离嗣子名分的真以色列人联合为一；因为犹大人既是与神相近的，那本是远离的外邦人就必须与他们相连，好使隔阂既已除去，他们便成为一体。

<!-- PAGE 650 -->

<span style="color:#800000">*看见我的荣耀。*</span>“看见”主的“荣耀”，无非就是享受祂从前赐给犹大人的那恩典；因为那民族特有的殊荣，就是他们瞻仰神的荣耀，并拥有祂临在的凭据。他说，如今那素来未曾得享这些恩惠的外邦人，也要看见并瞻仰那荣耀，因为主要向万民无一例外地显明自己。

**19.** <span style="color:#800000">*我要显神迹（原文作“记号”）在他们中间。*</span>这话可有两种解释：或是神竖立一个记号，或是祂用某种表记或印记来印证祂自己的百姓，使他们得以安然无恙。前一种解释较为众人所认同，但有些人幼稚地把它牵扯到十字架的记号上，另有些人则把它归于福音的传扬。依我看来，两者都错了；因为祂似乎更是在暗指摩西所告诉我们的，在百姓出埃及得拯救之时所发生的事。启示录 7:3 也宣告说，“凡主所印了印的”都必平安无事，即使祂的忿怒在全世界猛烈发作之时也是如此；正如在埃及门框上有记号的人得以安然逃脱一样（出埃及记 12:13）。祂借此表明，除了蒙拣选的人——就是主已在他们身上刻下祂的标记与印记的人——无人能逃脱神的忿怒。

<span style="color:#800000">*我要从他们中间差遣所逃脱的。*</span>总而言之，先知在此加强了前面已经说过的话，就是主要向不敬虔的人施行那可畏而可怕的报应；因为若非主用他的印记标出其中一些人，众人就必无分别地一同灭亡。所以，从全民族的普遍毁灭之中，他说他要存留少数人。这正是先知的真意；正如他在别处曾说，他要从那普遍的烈火中救出「余民」（以赛亚书 1:9；10:22）。至于这被存留下来的一小群，他说其中有些人要作他的使者，在外邦人中传扬他的名；正如我们看见，救恩的道理藉着少数人的工作而远播四方。

<!-- PAGE 651 -->
<span style="color:#800000">*往他施、普勒、路德去。*</span>他用「他施」这名指基利家，并包括与犹大相对的整个地中海沿岸。有人认为它指非洲和加帕多迦，但我宁取前一种看法。至于路德，有人以为指吕底亚，也有人以为指小亚细亚。「善于拉弓的」是指帕提亚人，因为他们擅长射箭。他用土巴、雅完指意大利与希腊，用「海岛」指那些未知的地方；因为正如我们在许多前面的场合所见，犹太人用「海岛」一名指称一切海外之地。

<span style="color:#800000">*素来没有听见我名声的。*</span>他的意思是，对神的认识必要遍传全世界；因为希腊人、意大利人、帕提亚人、基利家人以及其他各族，从未听闻纯正的宗教和对神真实的敬拜；全世界都沉沦在无知的幽暗深处。因此他应许神的荣耀必要在世界各处被人知晓。「列国」一词是着重语；因为那时主只被一个民族所认识，如今他却已向万民显明自己。

**20.** <span style="color:#800000">*他们必带来。*</span>在此他明白地解释了前面所说的话，就是凡逃脱存留的人，虽然数目稀少，却都要作祭司，从各处将祭物带来献给神。他在此暗指律法之下古时的礼仪，然而他也指出这些供物与古时律法中的祭物之间将有的差异；因为他所设立的是一种新的惩治和新的祭物。正如他先前说他要招聚万国，如今他又表明，他所设立的这些祭司必不徒然劳苦；因为神必使他们的工作兴盛。

<span style="color:#800000">*你们的众弟兄。*</span>他把从前是外人的称为「弟兄」；因为他所注目的是那从信心而生的新关系。我们知道，外邦人是藉着信心被接在亚伯拉罕的家中。然而另有人提出另一种解释，我也并不全然弃绝：「当神从外邦人中为自己招聚新的百姓时，那四散各方的犹大人，必被带到一处来。」这事也确曾成就；但把它归于外邦人的呼召似乎更为恰当，因为那时藉着那分隔的除去，在凡神愿意收纳为儿女的人中间，便开始建立起弟兄的关系。亚伯拉罕曾是一国之父，然而凡照着肉体从他而生的，并不都算为他的儿女；因为以实玛利人和以东人都被弃绝了（罗马书 9:7）。他成为「多国的父」（创世记 17:5；

<!-- PAGE 652 -->

罗马书 4:17）的时候，乃是神收纳外邦人，藉着约将他们与自己联合，使他们得以跟随亚伯拉罕的信心之时。由此我们便看出，先知为何称我们这些从前在神的教会之外的人为犹大人的「弟兄」。这是因为他先前已将那些虚假被弃的弟兄从他们的地位上赶了出去。

我们有责任留意那些忠心事奉主的人，藉其敬虔的劳苦所结出的这果子，就是：他们「带领弟兄」脱离致死的谬误，归向神这生命的泉源。他们理当以这安慰欢畅自己的心，并在所忍受的困苦与患难中藉此扶持自己。主不容许他自己的百姓中有一人灭亡。因此，当他愿意使用我们的劳苦来拯救我们的「弟兄」时，这是极高的享受与特权。

<span style="color:#800000">*从万国中。*</span> 他的意思是，犹太人与外邦人之间再无分别；因为神必拆毁那「中间隔断的墙」（以弗所书 2:14），并要「从万国中」组成一间教会。这样，大卫论到基督所说的话就应验了，

<p style="text-align:center" markdown="1"><span style="color:#000080">「你求我，我就将列国赐你为基业，</span> <span style="color:#000080">将地极赐你为田产。」（</span><span style="color:#000080">诗篇 2:8）</span></p>

当他提到「圣山」时，他是按那个时代的习俗与惯例说话的；因为在耶路撒冷，神是在殿中受敬拜的。但如今殿已遍布各处；因为我们无论在何处都可以自由地「举起圣洁的手向神祷告」（提摩太前书 2:8），场所的分别再不存在了。他同样提到在殿中献上的供物与祭物；虽然如今所要献的祭与古时的祭大不相同。但正如我们屡次所论及的，先知们不得不从已知而熟悉的事物中借用比喻。从前的祭物是取自羊群牛群；但使徒和基督其余的祭司却是宰杀人本身，借着福音将他们作为活祭献给神。保罗见证说，当他用福音的刀剑宰杀人时，他就是在执行祭司的职任，「叫所献上的外邦人，因着圣灵，成为圣洁，可蒙悦纳。」（罗马书 15:16）

<!-- PAGE 653 -->

因此，这并不是律法之下的祭司职分，也不像教皇党人的祭司职分——他们说自己在献祭基督；<span style="color:#800000">F1072</span> 这乃是福音的祭司职分，藉此人被宰杀，好使他们因圣灵而得更新，被献给主。这样，凡我们能为基督所赢得的人，我们就把他们献为祭物，使他们全然被分别为圣归给神。此外，每一个人当他把自己奉献并献纳给神，并向他献上毫无保留的顺服时，他就是在献祭；这就是保罗所称为「理所当然」的祭（罗马书 12:1）。这里指明我们蒙召的目的乃是：洗净我们的污秽，向自己死，好学习专心致志地追求圣洁。

<span style="color:#800000">*用马匹、车辆。*</span>有些人试图在此寻找一个寓意，他们认为先知之所以使用「带来」一词，是因为福音并非以惧怕强迫人，而是温柔地吸引人，使他们甘心归向神，欢欣喜乐地奔跑。但就我而言，我对这段经文取更简明的看法。因为许多人心中可能会生出这样的疑问：「人怎能从如此遥远的地方来到我们这里呢？」他便回答说：「马匹、车辆、轿辇都不至缺乏；因为凡能帮助他的百姓、并引领他们达到他所定目标的一切，都听凭主的吩咐。」然而我也不否认福音可以被称为「车辆」，因为它载我们进入永生的盼望；但我认为先知在此只是宣告：没有什么能阻挡神聚集他的教会，他必掌管一切必需的手段，使他所召的选民中无一人在中途失落。

**21.** <span style="color:#800000">*我也必从他们中间取人为祭司，为利未人。*</span>先知在此加强了他先前所宣告的、关于神那非凡恩典的描述。他已经宣明，神的教会要从万民中被招聚出来，以致纵有种种艰难与阻碍，连远方的民族也要亲近他们。但现在他更进一步，教导他们说：外邦人不但要被神收纳为儿女，还要被他提升到至高的尊荣。外邦民族原是不洁污秽的，如今竟算为圣洁的民，这已经是极大的尊荣了；而这里所说的却远为奇妙，就是他们被提升到品位的最高峰。

<!-- PAGE 654 -->

由此我们看见，基督之下的祭司职分与律法之下的大不相同；因为在律法之下，惟有一个支派得以承担祭司的职任，而外邦人既为不洁，不但无从执行那祭司的职分，甚至连进入圣殿都被禁止；但如今众人都被一同接纳，不分彼此。有些人笼统地解释这段经文，说外邦人要作祭司，即要将自己献给神，正如圣经屡次称一切信徒为"有君尊的祭司"（彼得前书 2:9；启示录 1:6；5:10）。然而他似乎特别是在描述那些执事与教师，就是主也从外邦人中所拣选、并派定去执行这尊贵职任的人；这职任就是传扬福音，例如路加、提摩太，以及同类的其他人，他们借着福音将属灵的祭献给神。

**22.** <span style="color:#800000">*我所要造的新天新地，怎样在我面前长存。*</span>他在此应许，教会的复兴必是这样的性质，就是要永远存留。许多人或许惧怕教会会第二次被毁；因此他宣告说，从此以后，教会既已蒙神复兴，其光景必是长存不变的。所以他在这里提到两样极其卓越的恩惠：复兴与永恒。当他说到"新天"与"新地"时，他所注目的是基督的国度，万事都借着基督得以更新，正如使徒在希伯来书中所教导的。这更新的目的，乃是要使教会的光景常常兴盛蒙福。凡旧的都渐趋衰残；凡被复兴更新的，就必存留更久（希伯来书 8:13）。

<span style="color:#800000">*你的后裔和你的名字也必存留。*</span>神曾应许说，「日月」只要还存留在天上，就必作那永久继承的见证，使大卫的后裔不至断绝。但因百姓的背信与忘恩，其间曾有中断；而基督所成就的复兴，实际上正证实了那预言。因此以赛亚公正地说：「你的众子要接续你，你众子的子孙要接续你的众子」；正如神要坚立世界，使它永不灭亡，教会的传承也必是永久的，可延续到万代。

<!-- PAGE 655 -->

总而言之，他在此解明他先前所说关乎更新世界的话，免得有人以为这是指树木、走兽或星辰的次序而言；因为这必须归于人内里的更新。古人以为这些事绝对是指末日的审判，乃是错了；他们没有充分斟酌先知的上下文，也没有充分斟酌使徒的权威。然而我并不否认这些事延伸到那审判，因为在基督——世界的生命——显现之前，我们不可期望完全的复兴；但我们必须从更高处、就是从基督重生他百姓、使他们成为新造之人的那拯救开始。（哥林多后书 7:1）

**23.** <span style="color:#800000">*每逢月朔、安息日。*</span> <span style="color:#800000">F1073</span>

先知在此再次指出，基督国度之下神那属灵敬拜的性质，与律法之下那属肉体的敬拜有何不同。从前每逢月朔都要献祭。又有安息日、其他节期和圣会之日，他们都谨慎守之。但在基督的国度之下，将有一种恒常不间断的节庆；因为我们没有固定规定的献祭日子，必须上耶路撒冷去，或必须在这地或那地献上什么；我们的献祭、节期与欢乐乃是日复一日、连绵不断地持续着。然而他仍照着我们已经说过的、先知们常有的习惯，暗指古时献祭的规例。

<!-- PAGE 656 -->
因此，主愿意人天天将「洁净的祭物」献给他（彼得前书 2:5），并非从前律法之下所献的那些，也不是如今教皇党人所献的那些——他们或愚妄地倚靠自己的礼仪，仿佛这些能赎罪，或竟卑劣地擅敢献祭基督， <span style="color:#800000">F1074</span> 乃是属灵的祭，好使我们以纯洁真诚的敬拜来敬畏、崇奉神（约翰福音 4:24）。至于有些人认为这段经文证明律法与古时礼仪已被废止，在我看来其根据尚不充足；那些律法礼仪确已被撤去，这是无疑的，而且也可从本段经文推知；但若要证明这一点，我宁愿采用其他更有力的经文。这里所作的，只是律法之下所守的安息日与节期，同我们今日所享的永恒安息日之间的对比（希伯来书 4:9, 10）。

**24.** <span style="color:#800000">*他们必出去。*</span> 我们在此不必寻求精微巧妙的解释；因为他只是告诉那些将被接纳进入教会的人说，他们必要看见四围有神可畏的报应。然而其中隐含一种对比，即灾祸中的困迫与自由的出离之间的对比；仿佛他说：「他们从前被囚的黑暗牢狱中，必再出来见光。」

<span style="color:#800000">*他们必看见那些人的尸首。*</span>他的意思并非说这屠杀要发生在信徒的聚集之中；因为这样便大大减损了教会的福乐，而神在教会中显明一切喜乐欢欣的凭据。然而，正如他先前论到神要以之尊荣他百姓的永恒荣耀，如今他也警告神要加于被弃绝者身上的刑罚，好使敬虔人更加谨慎地持守在敬畏神之中。

<span style="color:#800000">*火也不灭。*</span>当他说他们要被「火」折磨时，正如我先前所论，<span style="color:#800000">F1075</span> 这种表达方式是隐喻性的。这从随后的那一分句中显然可见；因为并不会有虫从地里生出来啮咬不信者的心。所以，明白的意思是：恶人必以邪恶的良心为刑役，无止无休地折磨他们，且有超乎一切其他痛苦的痛苦等着他们；末了，他们要以可怕惊人的方式战抖不安，如同有虫啮咬人的心，或有火焚烧人的心，而人虽如此被焚烧，却仍不得死。

<span style="color:#800000">*凡有血气的都必憎恶他们。*</span>因为恶人如今被人极其尊崇，且从其高位上轻蔑地俯视善人，故此先知警告将有骇人的变局；因为除了难以言喻的痛苦之外，他们还要承受最深的羞辱；这乃是公平合理的，就是那些藐视并亵慢神荣耀的人，必被一切羞辱所压，成为天使和全世界所憎恶的对象。
