# 第六十一章

<p style="text-align:center" markdown="1"><span style="color:#000080">前往 以赛亚书 61:1-11</span></p>

**1.** <span style="color:#800000">*主耶和华的灵。*</span> 既然基督将这段经文解释为指着自己说的（路加福音 4:18），注释家们便毫不迟疑地将它限定于基督身上，并立下这一原则：此处是基督在说话，仿佛整段经文都单单与他有关。犹太人对此嗤之以鼻，认为这是把同样适用于其他先知的话，轻率地应用到基督身上。我的看法是：本章乃是加在前一章之上的印记，为要坚固此前所说关于重建基督教会的一切；为此目的，基督见证他自己已受了神的膏抹，因而他理当把这预言应用于自己身上；因为别人所隐晦陈述的，他却清楚公开地显明了出来。

但这并不妨碍我们把这句话应用于耶和华所膏的其他先知；因为他们并不是以个人的名义说话，也不是为自己主张这权柄，他们的职责主要在于指明基督的职分——这些事的宣告固然属乎基督，其成就也同样属乎他。因此，本章应当这样理解：作为众先知之首的基督占据首位，独自作成这一切的启示；而以赛亚、其余先知并使徒，都是把自己的服事献给基督，各人尽自己的本分，使基督的恩惠得以显明。这样，我们就看见，以赛亚所说要由基督成就的那些事，如今已实实在在地成就了。

<!-- PAGE 543 -->
<span style="color:#800000">*耶和华膏我。*</span> 这后半句是为着解释而加上的；因为若先知对自己为何被赋予神的灵一语不提，前半句就会显得有些晦涩；但如今借着指出其用途，意思就清楚得多了，因为他宣告自己是履行一项公开的职任，好使人不把他看作一个私人。每当圣经提到圣灵，说他「住在我们里面」（罗马书 8:11；哥林多前书 3:16），我们不可视之为空洞无实之言，而当默想他的能力与功效。所以先知在讲到神的灵之后，接着提到「膏」，意思是指从他而出的各种才能，正如保罗所教导的，恩赐原有分别，圣灵却是一位。（哥林多前书 12:4）

这段经文当仔细留意，因为除非有人显明自己是受神的灵所催促，就无人能主张有教导的权利或权柄，正如保罗也断言：「若不是被圣灵感动的，也没有能说耶稣是主的。」（哥林多前书 12:3）但有人会说，我们看见几乎所有人都夸口自己有神的灵；因为教皇、重洗派，以及其他异端与狂热之徒，口中不断挂着圣灵的名，好像他们是受他管理的一样。那么，我们怎能判断一个人是奉神所差、并被他的灵引导呢？就是凭着「膏抹」；也就是说，看他是否被赋予那职任所必需的恩赐。因此，若一个人是蒙主所立，且在圣灵的恩赐与这呼召所要求的才干上丰丰富富，他就真是有圣灵。但他若声称自己享有那位教师，却毫无教义，<span style="color:#800000">F1008</span> 就当把他看作骗子。

<span style="color:#800000">*他差遣我传好信息。*</span>先知并未在表明主"差遣了他"之前，就为自己主张教导的权利与权柄。这权柄乃是建基于他已被"膏抹"，就是被神赋予了必需的恩赐。因此我们听他，不该当他是一个私人，而当他是一位从天上而来的公众仆人。

<!-- PAGE 544 -->
<span style="color:#800000">*给困苦人。*</span>有人译为"给温柔人"；<span style="color:#008080">ענוים</span>（*gnanavim*）一词兼含这两重意思。但我宁取前一种含义，因为先知在此所论的是被掳的人和被囚的人。不过我认为他把两者都包括在内；因为他所指的是那些既全然被弃、被撇下，同时自身又是可怜困苦的人。基督只应许给那些被自己苦境的知觉所降卑、所压伏的人，就是那些毫无高傲自负、却持守卑微谦逊的人。由此我们推知，以赛亚在此确实是论到福音；因为律法的赐下，是为要贬抑那因虚妄自信而膨胀的骄傲之心，而福音却是为"困苦人"预备的，就是为那些知道自己一无良善的人预备的，使他们可以得着勇气与支撑。先知、使徒并其余的仆人受膏被差，若不是为要以恩典的道理来激励安慰困苦人，又是为什么呢？

<span style="color:#800000">*医治伤心的人。*</span>先知使用了许多隐喻，为要把同一件事说得更加明白。他所说的"缠裹"，意思不过是"医治"，但此处他所表达的比前一句更进一层；因为他指出，道的宣讲并非空洞的声音，而是有能力的良药，其功效并非顽梗硬心之人所能体会，唯有受伤的良心才能感受得到。

<span style="color:#800000">*报告被掳的得释放。*</span>这也是福音的目的，就是使被掳的人得着释放。所以在我们藉着基督的恩典得着自由（约翰福音 8:36）之前，我们乃是囚徒、是被掳的；当基督愿意折断我们的锁链时，我们切不可拒绝所赐给我们的恩典。总的来说，当留意这一点：此处所列举的诸般福分，是藉着从天而来的教义赐给我们的；除了那些自觉贫穷、切切渴慕基督帮助的人以外，无人配得享受这些福分，正如他自己所说：

<p style="text-align:center" markdown="1"><span style="color:#000080">「凡劳苦担重担的人可以到我这里来，</span> <span style="color:#000080">我就使你们得安息。」（</span><span style="color:#000080">马太福音 11:28）</span></p>

**2.** <span style="color:#800000">*报告耶和华的恩年。*</span>这里他特意提到赐下如此卓越恩典的时候，为的是除去可能生出的疑惑。我们从日常的经历知道，扰乱人心的忧虑是何等繁多、何等纷杂。他宣告自己是将来恩典的传报者，并且从神的「喜悦」（good-pleasure，恩悦）来定这恩典的时候；因为既然他要凭白白的恩典作教会的救赎主，那么择定时候便在乎他的权柄，这也是理所当然的。

或许他在此暗指禧年（利未记 25:10），但毫无疑问，他是要断言：我们必须安静温和地等候，直到神乐意伸出他的手。保罗称这一年为「时候满足」（加拉太书 4:4）。我们同样看见先知说：「看哪，现在正是悦纳的时候；现在正是拯救的日子。」

<!-- PAGE 545 -->

（以赛亚书 49:8）保罗将这话应用在他自己的传道上；因为当主藉着福音向我们说话时，天门就为我们敞开，使我们如今可以说是进入了神诸般恩惠的享有之中（哥林多后书 6:2）。因此，我们不可迟延，而当在如此卓越的祝福摆在我们面前之时，殷勤地把握这时候与这机会。

<span style="color:#800000">*和我们神报仇的日子。*</span> 然而这两个说法看来彼此相悖，就是「悦纳的日子」与「报仇的日子」。以赛亚为何将如此相反的事连在一起呢？因为神拯救他的教会，必不能不显明他是公义的审判者，不能不向恶人施行报应。所以他用「悦纳」一词，是指着蒙拣选的人说的；用「报仇的日子」一词，是指着那些不断迫害教会的恶人说的，他们既如此，就必在教会得拯救之时受到刑罚。保罗也照样说：「神使受患难的人得安息，又报应那不义地加患难给信徒的仇敌，这在神看来是公义的」（帖撒罗尼迦后书 1:6）；而犹太人也不能期望他们的苦难得着终结，除非他们的仇敌先被毁灭。

然而我们应当留意我们得拯救的原因；因为这只能归于他的怜悯，而绝不可归于我们的功德、卓越或勤勉。诚然，正如我稍前简略指出的，他似乎在暗指禧年；但我们最当留意的是：我们的救恩全然在乎神白白的美意。

<span style="color:#800000">*安慰一切悲哀的人。*</span>我们应当记得先前所论的：福音的目的乃是要我们脱离一切的祸患，并且既已被复归于原初的自由，眼中的一切眼泪都被擦去，就得以有分于属灵的喜乐。倘若我们没有分享这如此浩大的恩惠，那就必须归于我们的不信与忘恩，因这不信与忘恩，我们竟拒绝并推开那白白将自己赐给我们的神。

<!-- PAGE 546 -->
**3.** <span style="color:#800000">*赐华冠与锡安悲哀的人。*</span>他继续论述同一主题；因为他的意思是，那要加在这百姓身上的刑罚，其性质仍然给赦免留有余地。并且，为要更充分地使他们信服这一点，他说主已将这职分交托与他，使他可以宣告这拯救；不但交托与他，也交托与其他人，直到那位首要的使者来到，就是基督，他实际地赐下并显明神在当时所吩咐为将来之期所要传扬的事。然而他的意思是，那「悲哀」并不拦阻神在他认为合宜的时候赐下喜乐的根据；因为「赐」（appoint）与「定期」同义，免得延迟的漫长使他们丧胆。

<span style="color:#800000">*赐华冠与锡安悲哀的人，代替灰尘。*</span> 他用「赐」这个词，是要称许这预言的功效，好使他们对所要成就之事深信不疑。这是暗指犹太人古时的风俗：每逢有灾祸重压他们，就把灰撒在头上，身穿麻布（以斯帖记 4:3）。他借此指出那必然伴随百姓悲惨光景的污秽与哀恸，并将其与他们得释放归回自由时所要享有的喜乐欢欣相对照。我认为我们不可略过 <span style="color:#008080">פאר</span> (*peer*，华冠) 与 <span style="color:#008080">אפר</span> (*epher*，灰尘) 二字之间的双关；因为仅仅调换字母的次序，他就有意指出截然不同的两样事物，并以优美的倒置表明境况的转变。

<span style="color:#800000">*公义树。*</span> 他用这些话指出百姓的复兴；仿佛说：「他们从前被连根拔起，如同枯干的残干，如今却要被栽种、被安置。」这样，他提醒他们当思想神的大能，使他们虽被杀戮、已然死亡，仍可确信盼望自己必被复兴，以致扎根、得力、生长。由此当引出一条普遍的教义，就是：我们得以复生，别无他途，唯有被主栽种。我们诚然被称为祂的「栽种」，因为祂从起初就拣选了我们（以弗所书 1:4）。但还有另一种「栽种」随着前一种而来，就是呼召，藉此我们因信被接枝在基督的身体上。主是藉着福音的运行与职事成就此事；然而这必须完全归于祂，因为「惟有神叫他生长」（哥林多前书 3:7）。我们必须常常记得，头一次的拯救乃是预表性的，用以说明基督属灵的国度。

<!-- PAGE 547 -->

凡有神的公义或良善秩序在其身上显明的人，祂就称他们为「公义树」。然而我们要知道，主收纳我们乃是有此条件的，就是我们要成为新造的人，真正的义要在我们里面掌权。由此可见，我们本性乃是败坏堕落的，除非被主更换、被主栽种，就断不能结出果子。这就推翻了教皇党人虚妄狂傲的见解，他们捏造种种预备或自由意志的辅助，僭取唯独属于神的荣耀；因为我们若是被主栽种的，就可见我们本性是枯干而不结果子的。

<span style="color:#800000">*使他得荣耀。*</span>这就是我们「栽种」的目的；但关于这些事，我们在解释前一章第二十一节时已经论及。

**4.** <span style="color:#800000">*他们必修造已久的荒场。*</span>他继续更详尽地描述教会的那次复兴；主要用意在于：使犹大人对拯救怀有确切的盼望，因为那些应许在当时看来完全难以置信。这也正是他何以用广博而华美的言辞来装饰救赎之恩的缘故。有人以为「已久」「历代」这些字眼是指着将来的时期，好像他是说他所论的建造必坚固长存——这是错解。先知的意思大不相同；因为他表明（正如我在另一处所解释的），那城长年累月的荒废，并不能阻止它重新兴起。当一座城的居民四散各方、离开已极其久远之时，重建它便毫无希望可言；正如今日无人再关心重建雅典一样。因此，当犹大人被掳到远方之地，耶路撒冷被弃置七十年之久，谁还能盼望它竟由本城的居民自己重建起来呢？

<!-- PAGE 548 -->
为此以赛亚使用「已久的荒场」「先前凄凉之处」「荒废的城邑」「历代荒凉之处」这些称谓，为要表明这一切都不能阻止耶和华在合适的时候重建那城，使他的选民居住其中。然而这些话也当应用于我们的时代，以致虽然主容许他的教会倒塌之后长久卧在废墟之中，虽然重建之望似已断绝，我们仍可用这些应许坚固己心；因为这正是神独有的作为：将先前被毁坏、仿佛已交付于永远腐朽之物重新兴起、更新。但关于这些事，我们从前在第五十八章已经论述过了。

**5.** <span style="color:#800000">*那时，外人必起来牧放你们的羊群。*</span>先知的意思是，外邦人和寄居的人必甘心乐意地服事他们；因为他们那时既与其余的列国隔绝，无人愿意帮助他们，所以他说「外人必起来」，就是说，他们已预备好前来援助他们。至于随后所说的「牧放羊群」以及「耕种田地、修理葡萄园」，这些都是隐喻的说法；因为先知所论的是基督的国，那国乃是属灵的，但他借着这些比喻描写那国完全的福乐，使我们可以借着取自我们所熟知之事的例子更好地明白它。因此，让我们晓得，当基督在我们身上施行祂的治权时，我们才真是有福的；因为如此我们也必出乎意料地得着许多益处，而这些益处按公义乃是亚当的子孙所当被剥夺的。

**6.** <span style="color:#800000">*你们倒要称为耶和华的祭司。*</span>这一节使前一节的意思更加明亮；因为在这节的后半，先知预言信徒必享用外邦人的财物，并要承接他们的地位而被高举得荣耀。犹太人固然急切地抓住这类的宣告，早已凭着贪心吞吃万国的财富，仿佛有一日必要占有它；又夸口说，仿佛全世界的荣耀都要归他们所有。

<!-- PAGE 549 -->
但在这些话中，主要有两件事是当留意的，好使我们更充分地明白它们。第一，先知们若要描写基督之国的荣耀与福乐，便从人间的事上借用比喻。第二，他们论到教会时，将头与肢体如此联结，以致有时他们所看的是头多于肢体。我们不可把享用别人财物理解为：归信基督的人要夺取别人的财富、荣耀或地位，那与真敬虔最是相违；乃是因为万物都要归在基督的治权之下，惟有祂独掌权柄、独自掌管。这正是我先前所说的，他既看肢体，也看那头。但当这些事物归入基督的权下时，它们就被称为我们的，因为基督并不拥有任何与祂教会分离的东西。

同样地，别处也说（以赛亚书 45:14），基督的仇敌“必亲他的脚，恳求赦免”，虽然这事是在教会中成就的，他们在教会里承认基督，并降服于他的教义之下。这样，以赛亚指明父将要赐给子什么，因为子对全世界拥有合法的权柄（马太福音 28:18），并且

<p style="text-align:center" markdown="1"><span style="color:#000080">“万物都必服在他的脚下。”（</span><span style="color:#000080">希伯来书 2:8）</span></p>

然而我们不可略去我在前面稍稍提到的一点，就是神在世上大大地、慈爱地扶持他的选民，为要使他们觉得自己的境况远胜过不信者的境况；因为他们虽然缺乏许多东西，却以所有的一点为足，欢然向神献上感谢，以致他们的饥饿胜过不信者一切的丰富。

<span style="color:#800000">*耶和华的祭司。*</span>他用这个称号表明，这百姓的地位将远比从前更为尊贵；仿佛他说：「直到如今，耶和华拣选你们作他的产业；但他要用更为尊贵的恩赐装饰你们，因为他要将你们提升到祭司的尊荣。」虽然全体百姓都是「祭司的国度」（出埃及记 19:6；申命记 33:10），我们却知道唯有利未支派履行这职分；但先知宣告说，将来这职分要归众人所共有。这事直到基督的国度之下才显明出来。教会的复兴固然从百姓从巴比伦归回之时便已开始；然而到了基督降临，信徒才终于得着这尊荣的装饰与荣耀；因为众圣徒都已被分别为圣归给基督，并履行那职分。彼得的话正属于此：

<p style="text-align:center" markdown="1"><span style="color:#000080">「你们是……圣洁的国度，……有君尊的祭司。」（</span><span style="color:#000080">彼得前书 2:9</span><span style="color:#000080">）</span></p>

<!-- PAGE 550 -->
这种祭司职分的性质究竟如何，应当仔细留意；因为我们不再需要向神献上属地的祭物， <span style="color:#800000">F1009</span> 而是要将人献上并宰杀，使他们顺服基督，正如保罗宣告说，他用福音的刀剑宰杀了外邦人，使他们从此顺服主。 <span style="color:#800000">F1010</span> （罗马书 15:16）

由此可以推知教皇党人的愚妄何等幼稚，他们滥用这段经文来证明他们的祭司职分；因为教皇和他的仆从们所按立的祭司，是为献祭基督，而不是为教导百姓。然而基督已经献上了自己，「成了永远赎罪的事」（希伯来书 9:12），惟独祂一次性地执行了这祭司的职分，并且命定：那位作为祭物的祭司，要藉着福音的教义被献给我们。因此，那些僭夺此职、想要重复祂已完成之事的人，是犯了亵渎神圣之罪。

然而，各人都当将自己（罗马书 12:1）以及自己所有的一切献给神为祭，如此才是执行这合法的祭司职分；其次，那些被特别呼召担任教导之职的仆人，当运用道的宝剑杀死人，并将他们分别为圣归给神。最后，惟有那些不凭自己擅自尝试或从事任何事，而是忠心殷勤地执行从神所领受的命令的人，才是合法的仆人。

**7.** <span style="color:#800000">*你们必得加倍的好处，代替你们的羞辱。*</span> 他在此确证前面所说的：那些身穿麻衣、蒙着灰尘哀哭的信徒，必被喜乐油所膏。哀哭变为喜乐，这应许再次被宣告。

<span style="color:#800000">*必得双倍的产业。*</span>有些人解释「双倍」一词，意思是那些蒙神救赎的人必在神面前与在人面前都同样有福。但我不知道这种解释有何坚实的根据。我宁愿采取较为简明的看法；仿佛先知是说：「教会的兴盛必如此之大，远远超过她现今所受一切的灾祸与患难。」因此，她若如今厌倦自己的处境，就当仰望那日，那时她必最为有福，正如保罗将「极重无比、永远的荣耀」与「至暂至轻的苦楚」相对照（哥林多后书 4:17）。

<!-- PAGE 551 -->
<span style="color:#800000">*代替所受的羞辱，必因自己的分而欢乐。*</span>恶人向我们夸口，肆意放纵，因为他们以为自己占了上风；但主应许不久之后，他必使善人脱离他们的暴虐，得着自己的分。这事的确在百姓从被掳之地归回时便已开始；但更明确的证据已在基督身上显明，且每日都在显明，最终必在他末后降临之时完全成就，那时万事都要全然更新，恶人必被倾覆，使我们得着世界为业。这就是为何他以承认的口吻说，地是那些恶人的分；因为他们现今夸口自己是世界的主人，但他们终必觉悟，这地是特别专属于神儿女的。

<span style="color:#800000">*永远之乐必归与他们。*</span>这可以指教会外在的处境；因为他每日都赐给他的百姓感恩的缘由；但既然他们也必须吞下许多忧愁，且被各样悲伤所围绕，这预言唯有在心灵的喜乐在我们心中掌权、居于首位时才得应验，并伴随着那「（如保罗所说）出人意外的平安」（腓立比书 4:7），这平安唯有神的儿女在得着儿子名分的凭据时才享受得到。他称之为永远的，为要显明这喜乐与恶人的喜乐大不相同；恶人的喜乐是片刻的，转眼消逝，甚至变为「切齿」（马太福音 8:12）。

**8.** <span style="color:#800000">*因为我耶和华喜爱公平。*</span>他不仅是以主的名确认自己所应许的，同时也劝勉犹大人悔改，并指明他们当从何处期待救恩，以及我们所要面对的这位审判者是谁、何等伟大；因为他从神的本性推论出他们当如何规范自己的生活，免得他们因自己的邪恶而弃绝所赐给他们的恩典。

在「公平」一词之下，他包括了一切公义正直的事；因为他将这个词与犹大人那些无用的发明相对照——他们以为借着这些发明就使神满意了，同时又掩藏自己的恶毒。正如我们屡次所见，主并不看重这样的面具与虚假的伪装，而是要求心中真实的洁净，以及不染任何不义的洁手。凡愿意使自己和自己一切所行得着神称许的人，必须有正直的心和无可指摘的生活。

<!-- PAGE 552 -->

<span style="color:#800000">*恨恶燔祭中的抢夺。*</span>他以一个部分喻指一切假冒为善的敬拜；而在「燔祭」之下包括了各种祭物。最可憎的莫过于人从欺诈和抢夺所得的向神献祭，或将自己的虚谎、伪善和心中的污秽混杂在祭物之中，或以卑劣地亏负神的方式败坏对神的敬拜。这恶习不只盛行于某一个时代，而是在各个时代都甚为普遍；因为众人都假称敬拜神，甚至恶人也羞于毫无宗教的外貌，因为神乃是治理者这一印记，深深刻在众人心上，无法被抹去。然而大多数人却戏弄神，企图用幼稚琐屑之物使他满意。

因此，以赛亚责备并憎恶这种假冒为善，并教导我们说，主向我们所要求的是「怜恤，不是祭祀」（何西阿书 6:6；马太福音 9:13；12:7）。我们若不遵守第二块法版，不禁绝一切欺诈与强暴，就不能以正当的方式敬拜神；因为凡欺骗或亏负邻舍的人，也是向神施行强暴。总之，先知的意图是要教导何为真悔改的真实特质；即：敬拜神的人当撇下假冒为善，弃绝一切人为的虚构，彼此存着出于本性的仁慈相待。

<span style="color:#800000">*我要凭诚实使他们的工作得赏赐。*</span>有些人将此解释为工作的「赏赐」。但我倒认为，这是指人生一切的作为，主应许要使这些作为顺利成就。人的作为往往极其失败，因为他们不肯求问神的旨意，也不肯在祂的引导之下有所行动。这样，他们因自己的鲁莽而受公义的刑罚；因为他们或倚靠自己的谋算，或依赖命运盲目的一击——其中毫无实质，只有虚假的影儿。但那些被神的灵引导、将自己完全交托于祂保护之下的人，得以顺利成就、如愿以偿，这并不足为奇；因为一切的顺利都单单出于祂的祝福。

「**诚实**」一词的意思是持久不变的进程；因为连不信的人也常因短暂的喜乐而自我膨胀，但那喜乐转眼就消失了。

<!-- PAGE 553 -->
<span style="color:#800000">*又要与他们立永约。*</span>在这节的末尾，他指出这种坚定稳固的原因。原因就在于：神喜悦不只一次向他们伸手，而是要作他们一路的引导者。我们能够坚忍到底的真正支撑，乃是他俯就与我们立永远的约；在这约中，他自愿使自己成为我们的债主，并白白地将万物赐给我们，虽然他丝毫不欠我们什么。

**9.** <span style="color:#800000">*他们的后裔必在列邦中被人认识。*</span>在这里，先知更清楚地论到教会的扩展；当时的教会可说是局限在地上一个狭小的角落里，而后来，正如我们已经看见的，更是极其减少、极其衰败（以赛亚书 1:9；10:22）。因此以赛亚在此论述教会：她在经历了如此严重的减损之后，将要遍布全世界，以致万国都能看见。然而，即使在所罗门作王的时候——那时犹大人的财富与荣华最为兴盛——这事也未曾发生（列王纪上 10:21, 27）。这在当时看来是完全不可信的；这就是众先知为何如此费力要说服人相信这事，并且极其频繁地重复它，免得犹大人按自己的理解或按眼前的光景来衡量这复兴。

现在有一个问题产生：这些事是何时发生的呢？我的回答是（如我以往常常所说的）：它们在百姓归回本国之时就已开始；因为从那时起，他们连绵不断地经历了神向他们所施的多方恩慈。但因为所显出的不过是微弱的火星，那完全的光辉便在基督里照耀出来，在他的国度中这些事才全然成就；因为在最为荒芜、毫无敬虔之处，亚伯拉罕的后裔发了芽，因为外邦人藉着信心被接在选民的身上。这样，外邦与野蛮的民族便承认犹大人是神所赐福的后裔（创世记 22:18），因为他们与犹大人同归于一样的信仰认信；这事并非只一次成就，而是每日都在成就之中。

<!-- PAGE 554 -->
至于犹太人得以居先、在神的约中占首位，这应当归于神的怜悯，而非归于他们自身的优越，正如保罗（罗马书 3:2）所教导的；因为他先证明了他们按本性与外邦人毫无分别，又把他们置于同样的定罪之下，随后同样教导说，他们之所以持有这优先的特权，乃因他们是最先领受神的话语和应许的人。然而这出于神白白的恩慈，并非出于他们的功德或优越。

**10.** <span style="color:#800000">*我因耶和华大大欢喜。*</span> 他把教会描绘为向神献上感谢，为要使他们更充分地确信他先前所说的真实。这可视为一种（<span style="color:#0000d4">ὑποτύτωσις</span>，生动描摹）活画的描写，藉此把事情仿佛绘画一般摆在人眼前，以除去一切疑惑；因为我们按本性倾向于不信，又如此善变，以致我们宁可信靠人的臆想，而不信靠神的话。关于这种确证的方式，我们已在第十二章第1节、第二十六章第1节以及其他经文处论述过。

<span style="color:#800000">*因他以……给我穿上。*</span> 这些事诚然仍在遥远之处，却必须用信心的眼睛看见并领悟；因为当先知论及救恩与义时，眼目无疑当举向天上。在此没有什么是可见的，何况在万事都趋于灭亡之际，如此great的福乐更不可能被感官所察觉。但因为即使在今日，我们也看不见教会有这样的荣美——教会在世人眼中，披着十字架那令人厌恶的衣装，甚至是可鄙的——所以我们需要信心，因信心能领会属天的、不可见的事。

<span style="color:#800000">*以拯救为衣。*</span>他将「义」与「拯救」相连，因为二者不可分离。「衣服」与「外袍」是众所熟知的比喻。这就如同他说，义与拯救已经赐给了他们。既然是耶和华赐下这些恩惠，可见我们唯当从他求取、并从他等候这些恩惠。

<!-- PAGE 555 -->
<span style="color:#800000">*他以…为我打扮。*</span>有人认为这比喻取自祭司的装饰，因此有些人便就此推想基督的祭司职分。但我不认为先知说话如此巧曲；因为他所提出的乃是新郎与新妇的比较 <span style="color:#800000">F1011</span> 从前教会躺卧在污秽与破烂之中，被众人藐视，如同一个被弃的妇人；但如今她既已重得丈夫的恩宠，便发出奇妙的光辉。何西阿书 2:20 有一处平行的经文。这在基督降临之时得着了成就；然而当耶和华以义和拯救装饰他的百姓时，这也日日赐给我们。但正如我们已经多次说过的，这一切都要在基督末后降临之时完全成就。

**11.** <span style="color:#800000">*田地怎样使百谷发芽。*</span>先知用一个优美的比较来印证前面的应许；因为他提醒犹大人思想神那平常的能力，这能力在受造之物本身中光辉地照耀出来。田地每年发出嫩芽，园子在撒种之后长出青翠，简言之，那些在冬天看似枯死的花草树木，到春天便复苏并恢复生机。如今这些正是神的能力与他向我们所施慈爱的凭据与极为明显的例证；既然如此，人还当疑惑吗？那位赐给田地这样能力与力量的，岂不更要在拯救他百姓的事上显明这能力吗？他岂不使那蒙拣选的种子发芽吗？他曾应许这种子要永远存留在世上。

<span style="color:#800000">*在万国之前。*</span> 他再次表明，教会的疆界不再像从前那样狭窄，因为主必使她充满全世界。

<span style="color:#800000">*使公义和赞美发生。*</span> 他提到「公义」，这公义在主救赎他百姓的时候得以完全彰显；然而神的义主要是在基督向世界显现之时被看见的；这并非说神在那时以前将他的义隐藏起来，而是人不认识它。这就好像他说：「神必以这样的方式拯救并复兴他的百姓，以致众人都要承认他是公义的。」因为救赎是神公义的显著明证。

接着他提到赞美；因为这样的恩惠理当伴随着感恩。「公义」的目的乃在于将荣耀归给神；因此他劝勉我们要存感恩之心；因为领受了神的恩惠之后仍旧缄默不言，是极其可耻的。
