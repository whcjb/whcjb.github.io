# 第五十六章

<p style="text-align:center" markdown="1"><span style="color:#000080">前往 以赛亚书 56:1-12</span></p>

**1.** <span style="color:#800000">*耶和华如此说。*</span>这是一段极为重要的经文，先知在此指明：当神向我们显出他恩眷的标记，或应许他必乐意与我们和好，使我们的和好得以确立之时，他向我们所要求的是什么。他要求我们有这样的一种归正：使我们的心思意念得以更新，弃绝这世界而向着天上上升；随后他也照样要求悔改所结的果子。

<span style="color:#800000">*你们当守公平，行公义。*</span> 在「公平」与「公义」这两个名称之下，他包括了人与人之间所当尽的一切本分；这些本分不仅在于不作恶害人，也在于援助我们的邻舍。这就是律法第二块法版的总纲；我们若有敬虔，就必在遵守这法版上显出证据来。因此，众先知总是把我们的注意力引向那块法版；因为借着它，我们真实的品性更容易被认出，真正的正直也得以查明；因为伪善之人，正如我们从前所见，[^f936] 常借着礼仪行欺骗之事。

<span style="color:#800000">*因我的救恩临近，我的公义。*</span> 他在此陈明理由，同时也指出众人当献身于生命更新的根源与缘由。正因为「主的公义」向我们临近，我们自己一方也就当亲近他。主称自己为「公义的」，并宣告这是「他的公义」，并非因为他将公义封闭在自己里面，而是因为他将公义浇灌在人身上。同样，他称之为「他的救恩」，即他借以救人脱离灭亡的救恩。

<!-- PAGE 438 -->
这番话虽是对犹太人说的，为要他们以真诚的心意和正直的行为，向神他们的救赎主表明感恩，然而它也关乎我们每一个人；因为全世界若不单从神那里得着救恩，其自身便是败亡无救的。所以我们必须留意这劝勉，它教导我们：我们越是靠近神，就越当被大力激发去操练敬虔。因此保罗也警戒信徒说：[^f937] 「你们要脱去暗昧的行为，带上光明的兵器；因为我们得救比先前所想的更近了。」（罗马书 13:11, 12）

**2.** <span style="color:#800000">*如此行的人便为有福。*</span>当他称那些既已接受这教训、便专心正直行事的人为"有福"时，他间接使我们得出结论：必有许多人耳聋不听或悖逆不从；然而，为免他们的邪恶或漠然拦阻了被拣选的人，他便从这劝勉所带来的益处上来推荐它。因此，为使信徒抛弃一切的迟延，他高声宣告：凡蒙赐下[^f938]得此智慧的人，都是"有福"的。

<span style="color:#800000">*谨守安息日。*</span>我们曾说过，前一节中"公平"与"公义"二词涵盖了第二块法版的一切本分；但此处他提到安息日，那是属于第一块法版的。我的回答，正如我先前已简略提及的，乃是：凡与邻舍相处不使人跌倒、行事公正的人，便证明他们是事奉神的；因此我们不必惊奇，先知在略述了第二块法版之后，也提到第一块法版；因为二者本当联合在一起。总而言之，以赛亚宣告说：凡顺服神、完全遵守他律法的人，必"有福"；因为神的救恩与神的义都要归给他。既然如此，人们既在自己的臆想之中漫无目标地游荡，采取种种方式敬拜神，他便指明只有一条道路，就是人竭力照着律法的命令来塑造并规范自己的生活；否则他们走别的路，只是徒然使自己疲乏。简言之，这是一段极为显著的经文，表明除了遵守律法以外，没有什么能使神喜悦。

若有人问："人能靠自己的行为得着义与救恩吗？"回答便不难；因为主赐救恩给我们，并非因他被我们的功德所抢先（相反地，是我们被他抢先了），而是白白地将自己赐给我们，只要求我们在自己这一面亲近他。既然他甘心乐意地邀请我们，既然他借着白白的恩典赐下义，我们就当竭尽全力，免得失去如此大的恩惠。

<!-- PAGE 439 -->

再者，正如摩西所宣告的（出埃及记 31:13、17），又如以西结书 20:12 所重申的，安息日乃是敬拜神最重要的标记；因此，藉着那以部分代全体的修辞法——即所谓的*synecdoche*（提喻法）——安息日便包括了敬虔的一切操练。然而我们必须将安息日与随之而来的一切事一同看待；因为神并不以外在的礼仪为满足，也不喜悦我们的懒惰，乃是要求我们真诚地克己，使我们全然献身于事奉他。

<span style="color:#800000">*免得他污渎它。*</span>此句通常译作「使他不污渎它」；按字面则作「从污渎它」；因此我们认为在「免得他污渎它」这句之前加上*「免得」*一词是恰当的，以除去一切含糊之处。

<span style="color:#800000">*禁止己手不作恶。*</span>他现今又加上另一个*synecdoche*（提喻法），来描述人彼此当尽的本分。其要义乃是：除了真诚的敬虔与无可指责的生活之外，别无正确事奉神之道；正如他也在这两部分中包含了度圣洁生活的准则。总而言之，这是对主的律法中所载之真义的阐释，要我们安息其中；因为人若寻求任何别的达至完全之路，都是徒然的。此处也一并推倒了一切虚假的敬拜与迷信，最终推倒人所妄自捏造、与神的话相违背的一切事物。

**3.** <span style="color:#800000">*与耶和华联合的外邦人*</span> [^f939] <span style="color:#800000">*不要说。*</span>先知表明，神这恩典是何等浩大，以致从前与他隔绝、可说是被关在门外的人，也能获得新的地位，或得以完全复兴。他预先回应了他们的怨言，免得他们说自己已被弃绝、不配、是「外邦人」、或因某种标记而被排除在外；因为主必挪去一切拦阻。这既可指犹太人——他们因暂时被弃绝而落到与外邦列国相似的光景——也可指外邦列国本身。就我而言，我乐意将它推及两者，好与何西阿的预言相符：

<p style="text-align:center" markdown="1"><span style="color:#000080">「我必对本非我民的说：你是我的民。」</span> <span style="color:#000080">（</span><span style="color:#000080">何西阿书 1:10）</span></p>

<!-- PAGE 440 -->

<span style="color:#800000">*与耶和华联合。*</span>当他说他们「与神联合」时，他是在提醒人：这安慰只属于那些在神呼召他们时跟随了他的人；因为有许多「太监」，神并不将他的恩惠赐给他们，也有许多「外邦人」，并不将自己与神的百姓联合。所以这应许仅限于那些蒙召而又顺从了的人。

他称他们为「外邦人」和「太监」，用这两类人来描述一切看似不配被神算在他子民中的人；因为神曾为自己分别出一群特选的子民，其后又将他们赶出他的产业之外。外邦人则完全被摒弃在他的国度之外，这一点从整本圣经都足以看得明白。保罗说：

<p style="text-align:center" markdown="1"><span style="color:#000080">「与以色列国民为外人，在所应许的诸约上是局外人，</span> <span style="color:#000080">并且活在世上没有指望，没有神。</span> <span style="color:#000080">你们从前远离神的人，如今却在基督耶稣里，</span> <span style="color:#000080">靠着他的血，已经得亲近了。」</span> <span style="color:#000080">（</span><span style="color:#000080">以弗所书 2:12, 13）</span></p>

因此，外邦人起初或许会怀疑：那按字面而言是为犹太人所预备的收纳为儿子的恩惠，是否也属于他们。我们也看见，当主吩咐使徒们（马可福音 16:15）「往普天下去，传福音」时，他们何等退缩；因为他们以为，若将救恩的教义不加分别地既传给外邦人又传给犹太人，就是亵渎了这教义。同样的犹疑也可能困扰蒙拣选的子民，因为自从他们被逐出圣地之后，这便成了神弃绝他们的记号；所以先知吩咐他们撇下这些疑虑。

<!-- PAGE 441 -->
<span style="color:#800000">*太监也不要说。*</span>先知在此仍用以部分代全体的修辞，将凡带着某种羞辱标记、以致被隔绝于神百姓之外的人，都包含在这一称呼之下；因为「太监」以及无儿无女的人，似乎是被神弃绝、被排除在主向亚伯拉罕所立的应许之外的，主曾应许「他的后裔要如同天上的星」（创世记 15:5），「如同海边的沙」（创世记 22:17）。总之，他警告众人不要看自己，好使他们专一定睛于神的呼召，从而效法亚伯拉罕的信心（创世记 15:6）——亚伯拉罕并不看自己已经衰残的身体，也不看撒拉的胎不能生育，以致因不信而在心里与自己争辩神的能力，反倒在无可指望的时候仍存指望（罗马书 4:18-20）。先知所对之说话的，是那些被人藐视、被人羞辱的人；因为正如彼得所说：

<p style="text-align:center" markdown="1"><span style="color:#000080">「神不偏待人。</span> <span style="color:#000080">原来各国中，那敬畏主、行义的人都为主所悦纳。」</span> <span style="color:#000080">（</span><span style="color:#000080">使徒行传 10:34, 35）</span></p>

**4.** <span style="color:#800000">*因为耶和华如此说。*</span>现在接着的是一项确证；因为那些真诚敬拜神、谨守安息日、遵行律法之义的人，即使是「太监」[^f940]，或有任何别的妨碍，仍必在教会中有一席之地。他似乎藉此把犹太人惟独引以自夸的一切外在标记[^f941]尽都废去；因为教会的尊贵地位不在乎外表，而在乎属灵；虽然信徒在世人眼中并无任何显赫的标记，甚至被人藐视、被人羞辱，然而在神看来，他们的地位却是崇高的。

<span style="color:#800000">*拣选我所喜悦的事，持守我的约。*</span>他把顺服和坚守「约」与「守安息日」联系在一起；由此我们可以轻易推断：他到目前为止论及安息日时，所着眼的并非一种空洞的礼仪，而是完全的圣洁。同时，他再次约束神的儿女，叫他们连最微小的地方也不可偏离律法的命令；因为他们所被允许「拣选」的，并非他们自己认为合适的任何事，而是神宣告为祂所喜悦、所悦纳的事。因此，虚伪与鲁莽的热心在此都被定罪，因为神不但把自己的诫命与人的臆造相对立，更郑重吩咐他们要「持守祂的约」。

<!-- PAGE 442 -->
**5.** 我必使他们在我殿中……。我们在此看见，一切人，无论何等不配，都可得以进入神的国。他所暗指的是耶路撒冷，以及主在其中安置祂名的记念的圣殿。在那殿中，除了犹太人以外，别人毫无地位；倘若有外邦人进入其中，他们就会认为圣殿被污秽了。因此也曾因保罗带未受割礼的人进殿，而引起一场严重的暴动。如今主毫无分别地接纳祂先前所禁止的人；实际上，当我们这些外人之子被祂领进殿中，就是领进祂的教会时，祂就废去了这分别；这教会不再像从前那样局限在犹大那狭窄的界限之内，而是遍及全世界。

<span style="color:#800000">*一处地方和一个名号。*</span>此处的<span style="color:#008080">יד</span> *(yad)* 是指「地方」，正如许多别处经文一样。也可以认为它表示「权柄」或「能力」；因为他们必被高举到如此的尊荣地位，以致被算为神的儿女。

<span style="color:#800000">*强如有儿女的。*</span> 这里可能产生一个问题：主是把当时在教会中的犹太人与他日后要安置在他们地位上的信徒相比呢，还是把这百姓将来的境况与他们当时的境况相对照呢？因为可以确定的是，外邦人所得的「名」比犹太人的更「强」，犹太人「因为不信」而「被折下来」；我们就代替了他们的地位，「如同野橄榄接在好橄榄树上」，正如保罗所说的。（罗马书 11:24）所以其意思可能是：「太监」和「外人」要比那些被视为神产业的儿女和家里人得着「更美的名」。不过我宁愿按另一种方式来解释，就是：信徒在基督之下的尊荣，要高过在律法之下的尊荣。列祖称神为父，与他立约相连的时候，确有极其尊贵的「名」；然而自基督降临以来，神的恩典远更丰盛地浇灌在我们身上，因此我们在他里面得着了远为尊贵的名。

<span style="color:#800000">*永远的名。*</span> 他称这名为「永远的」，因为它是记在天上的，要在那里存活兴盛，历世不衰。恶人愿意自己的名在这世上显赫，竭力抬高自己的声誉，使自己名字的记念可以长存；然而那是必衰残的、短暂的。这名却大不相同，因为它使我们成为天国的后嗣，以致在众天使面前我们被算为神的儿女。

<!-- PAGE 443 -->
我们也可以把 <span style="color:#008080">מבנים</span>（*mibbanim*）解作「比那由儿女而来的名更美」；[^f942] 因为人藉着有儿女，在某种意义上使自己的名得以延续。他应许这名要远为尊贵。不过我更愿意采纳前一种解释。

**6.** <span style="color:#800000">*还有那些与耶和华联合的外邦人*</span>他重述先前所说的，即神必将他殿的门向所有人敞开，无分彼此，以致犹太人与希利尼人之间再无分别。他宣告说，凡神藉着道——就是我们得儿子名分的凭据——领进与他相交之境的人，都是「与神联合」的。这就是何西阿所说的「以慈爱和怜悯聘你归我」。（何西阿书 2:19, 20）神不但赐给他们一座殿，使他们可以在其中敬拜他，如同全体百姓素常所行的那样，而且赐给他们更尊贵的地位，就是使他们事奉他；也就是说，神承认那些从前是外邦人的，为祭司或利未人。

<span style="color:#800000">*又爱耶和华的名*</span>我们必须留意此处所陈明的呼召之目的；因为他说，他们要作神的仆人，其条件乃是爱他的名。这样，假冒为善的人便被排除在外；因为这呼召把两件事联在一起：我们事奉神，且我们的事奉出于甘心乐意、欢欣的心志。若我们不甘心乐意地顺服，就根本没有对神的敬拜。关于施舍所说的话，「神所爱的是捐得乐意的人」（哥林多后书 9:7），当应用于生活的各个方面，就是我们要以甘心乐意的心事奉神。

<span style="color:#800000">*凡谨守我的安息日*</span>他再次提到安息日；我们已经说过，这词之下包含了对神的全部敬拜。在守安息日的事上，百姓忽略了其中至为重要的部分；因为他们只满足于外在的礼仪，就忽略了真理，就是生活的改正。主吩咐他们如此安息，乃要他们的手和心都远离一切罪恶与邪僻。

<span style="color:#800000">*并且持守我约的。*</span>此处他描述那些将自己交托于神、紧靠祂话语之人的热心与坚忍。因此，我们既已藉着约与神相联，就当恒久持守此约，坚定不移地遵循纯正的教义，使人无论以何种方式都不能把我们从祂那里挪去或分开。

<!-- PAGE 444 -->

**7.** <span style="color:#800000">*我要领他们。*</span>先知以这些说法描述他先前所宣告的事，即从前被排除在神的教会之外的外邦人，如今被召入教会；因此从此以后，受割礼与未受割礼之间的分别必被废除。这不能指那些藉着割礼被接纳进入神百姓之列的归化者，因为那算不上什么新奇或罕见之事；他所见证的乃是：神的恩典要遍布全世界。而这事若不使外邦人与犹太人联合成为一体，便不能成就；这正是在受割礼与未受割礼的差别被除去之时所发生的。所以，如今再无任何事阻止外邦人事奉神，因为他们已被召入殿中，就是召入信徒的聚会中。不但如此，我们稍前已看见，祭司的职任从利未支派被移去，不仅归给全体百姓，甚至也归给外邦人。

犹太人如何极其憎恶这一说法，是众所周知的；因为他们虽然读到先知这些话，却仍认为外邦人被召来分享神这特殊的恩惠——那本是专为他们所预备的——乃是极其骇人怪异之事。然而先知的意思如此明白，若非极度厚颜无耻，便无法加以质疑。他从这恩典所结的果子来称扬它；因为真实完全的福乐，乃是与神和好并享受祂的恩眷。我们固然知道，恶人纵情欢乐；但那欢乐要变为切齿，因为神的咒诅停留在其上。然而神以最甘美的喜乐充满信徒的心，不仅藉着显明祂与他们和好，也藉着在他们的顺境中彰显祂的恩眷与慈爱。但他们至高的喜乐，乃是从良心的「平安」而来的，保罗将这平安归于「神的国」（罗马书 14:1-7），我们藉着基督与神和好时便享有这平安。（罗马书 5:1）

<!-- PAGE 445 -->
<span style="color:#800000">*他们的燔祭和平安祭，在我坛上必蒙悦纳。*</span>他应许他们的祭物必蒙他悦纳，因为凡被召的人都是在这条件之下被召的，即他们要将自己以及自己所有的一切都献给神。他用「祭物」一词，是指福音所命定的那种属灵的敬拜；因为先知是照着他那时代的习惯说话，那时对神的敬拜乃是包裹在种种礼仪之中。但如今我们不再献祭，却将赞美、感谢、善行，以及最终将我们自己献给神。当他宣告这些必蒙悦纳时，我们不可以为这是出于它们本身的价值或优点，乃是出于神白白的恩慈；因为若他按它们本身来看，他尽可公义地弃绝它们。当我们看见自己那毫无价值的工作竟被神接纳，如同它们是纯洁的祭物一般，这就当作马刺，激起我们热切的渴慕来敬拜神。

他又加上，<span style="color:#800000">*在我坛上；*</span>因为祭物若不是「在坛上」，就断不能蒙神悦纳，而「使礼物成圣的」正是那坛。（马太福音 23:19）因此，我们所献的一切，若不被那作我们祭坛的基督「成圣」，就都是污秽的。

<span style="color:#800000">*因我的殿必称为祷告的殿。*</span>从前圣殿是单单为犹大人所设立的，主特别愿意他们求告他；因为保罗指明犹大人比外邦人有优越之处时，他说<span style="color:#0000d4">λατρεία</span>，就是「敬拜神的礼仪」，是属他们的。（罗马书 9:4）这样，藉着一项非常的特权——其余的列国不得享有的特权——就在他们中间建造了一座殿。但如今这分别已被除去，凡属任何邦国、任何地方的人，都可自由地进入这殿，就是进入神的家。这殿已被扩张到如此的地步，以致遍及全世界的各处；因为万国都已被召来敬拜神。

<!-- PAGE 446 -->
在此我们看到律法与福音之间显著的分别；因为在律法之下，对神真正的敬拜只由一个民族所遵行，圣殿也特为这民族分别为圣归给他；但如今众人都毫无分别地被自由接纳进入神的殿，好使他们在其中纯正地敬拜他，就是说，在各处敬拜他。我们必须留意这种表达方式，这是先知们惯用而熟悉的；正如我们已经说过的，他们采用与自己那个时代相符的表象，以「祭物」和「圣殿」之名来描述对神纯正的敬拜。他描绘基督属灵的国度，在其中我们可以随处「举起圣洁的手」（提摩太前书 2:8），求告神；并且正如基督所说的，如今神不再是在那殿中受敬拜，而是「那真正拜父的，要用心灵和诚实拜他」（约翰福音 4:24）。

因此我们看见这明白的预言得着应验，就是「神的殿向万民成了祷告的殿」，使众人都能称他「阿爸，父」（罗马书 8:15；加拉太书 4:6），就是用各种语言称呼他；从此犹太人不可再夸口说惟独他们有神。这样，先知们不得不使自己的言论适应他们自己的时代，以及当时通行的宗教礼仪，好叫众人都能明白；因为完全启示的时候尚未来到，而对神的敬拜乃是披着各样表象的。然而，那已经被分别为圣归于神之名的圣殿，无疑实在就是他的居所；因为他藉摩西作见证说，凡他记下自己名的地方，他必在那里（出埃及记 20:24）；所罗门在献殿的时候也说：「你仆人和你民以色列向此处祈祷的时候，求你在天上你的居所垂听。」（列王纪上 8:30）因此基督责备犹太人「使他父的殿成了贼窝」（马太福音 21:13；马可福音 11:17），并将这段经文与耶利米书 7:11 中的一段经文相连。

基督称圣殿为「祷告的殿」，乃是就福音尚未传开的那个时期而言；因为他虽已降临，却尚未为人所认识，律法的礼仪也尚未废去。但当「殿里的幔子裂开」（马太福音 27:51），赦罪之恩得着宣扬时，这些对圣殿的称颂就与其他礼仪一同止息了；因为神已开始被「万民」在各处求告。

但这里必须留意：我们被召入教会，正是为了我们可以呼求神；因为那些忽略祷告与真实呼求神的人，虽在教会中占有一席之地，其自夸却是徒然的。因此，无论我们身处何地，都不可忽略这信心的操练；因为我们从以赛亚的话中学到（正如另一处所说的，诗篇 1:14），这是神所要求的至高、至美的祭；所以殿的圣洁就在于其中不断有祷告献上。

<!-- PAGE 447 -->
**8.** <span style="color:#800000">*主耶和华说。*</span> 以赛亚再次坚立他先前所见证的关于百姓复兴之事；因为虽然他以极其崇高的言辞称扬神的恩典——神要藉此拯救他的百姓——然而教会当时的境况却使这一类应许显得可笑。因此，这样的重复并非多余，而是必要的添加，为要坚固软弱的心，使他们对那本来难以置信的事得着完全的确信。

<span style="color:#800000">*就是聚集以色列被赶散的。*</span> 他将这称号加于神身上，正是与手头所论的题旨相关；因为聚集分散的教会乃是属乎他的事，而「他聚集以色列中被赶散的」这同样的话在此处也是同样的意思。（<span class="ages-code">&lt;19E702&gt;</span>诗篇 147:2）他因此应许要聚集他们，并且不只聚集他们，还要把各样的「民」加给他们，使教会得以大大加增繁衍。所以，每当我们因教会各样的灾祸而对他聚集他们一事心生疑惑时，我们就当举起这面盾牌：「聚集以色列被赶散的，乃是属乎主的事；他们虽然被广泛地驱散飘零，他却必轻易而全然地使他们复兴。」

<span style="color:#800000">*我还要将他所招聚的，聚集在他那里。*</span>我宁愿保守先知原话的字面意义。<span style="color:#008080">על</span> *(gnal)*，即「向」或「在……之上」；因为在我看来，他是着眼于前一节所说的，就是殿要向万民敞开；他的意思是，他还要将许多别人加添给那已被招聚的犹太人。这事果然应验了；因为他不但招聚了在巴比伦分散的人，也招聚了其余多次的、几乎日日发生的分散之民。他也从未停止招聚；以致他在已被招聚的人之上又添加了极大的一群。

<!-- PAGE 448 -->
**9.** <span style="color:#800000">*田野的诸兽。*</span>这预言似乎与前面所说的彼此不合；因为先知至此所讲的，满是最甘美的安慰，如今他却似乎严厉地威吓，并预告可怕的毁灭。这些话语固然看似互相矛盾；然而，在安慰了信徒之后，他预先警告他们将来的灾祸，使他们看见万事临近败亡时不至丧胆，并使这必要的处境也催促他们更加火热诚恳地投奔神的恩典——这就不该被看作前后不一致了。此外还有另一个缘由，就是伪善之人滥用神的应许，借虚假的名义把它们高举出来，怀抱毫无根据的指望，并且蛮横地夸耀那些丝毫不属于他们的事；因此以赛亚有意除去他们虚假夸口的根基。

如此，他的用意是双重的：第一，使信徒的心不因各种灾祸而沮丧——那些灾祸几乎要把他们带到全然的毁灭；并且即使在昌盛平安之中，他们凭信心远远望见将来的灾祸，也能以这一样的安慰为满足；第二，使他能以惊惧与恐怖击打伪善之人，叫他们不至凭虚妄的自信自高自大，也不至借这些应许为托词而放纵自己罪恶的倾向。为此，神所呼召的不是人，而是凶暴的「野兽」，为要吞吃这百姓。所以，当这些野兽被打发来时，他禁止信徒惊慌，也禁止他们被引诱陷入不信。然而他也有意使他们心生畏惧，为要激动他们悔改，并劝勉他们寻求神的怜悯，免得那些应许失去它们的价值。

他称它们为「田野的走兽」，意指各类的走兽，其中不仅包括巴比伦人和亚述人，也包括安提阿古、罗马人，以及其他给这百姓带来种种灾祸的仇敌。但他所着眼的，主要是他们从巴比伦人手中所受的败亡——巴比伦人把他们掳去，陷于可悲的奴役之中。

**10.** <span style="color:#800000">*他看守的人是瞎眼的。*</span> 他现在指出这百姓必被毁灭的缘由：因为他们受邪恶的君王和牧人所治理。这并不是说他愿意把罪责单单归在这些人身上，以为百姓是无辜的；而是因为恶事乃是由此而起。我们若随从瞎眼的领路人，并不能免于罪责，相反，我们因自己的过犯受刑罚乃是公义的；因为主要惩罚那些忘恩负义的人，就把善良的引导者从他们中间挪去。

<!-- PAGE 449 -->
「看守的人」[^f943] 一词，他所指的不单是那些受托担任教导职分的先知，同样也包括本当以正当方式治理一切的士师、君王和首领。他把两种治理都包括在内：君王的治理，以及圣道仆人的治理；主设立这二者，如同身上的两眼，为要治理教会。因此，他们若是邪恶或不忠，对一个国邦而言，就再没有比这更为毁灭性的灾祸了。

<span style="color:#800000">*都是无知的。*</span>首先，他指责他们缺乏知识；因为好牧人首要的美德，就是认识自己的职责，能够判断什么对羊群有益、什么有害，并且辛勤守望，如同站在守望楼上，多方促进羊群的安全；所以再没有什么比无知和瞎眼更与这职分相违背的了。因此，人若不明白治理百姓的正确方法，就绝不能成为好牧人。由此我们便看出，对我们这时代那些偶像该有何等看法——他们高傲无耻地夸耀自己牧人或牧师的名号，其实却是未受教导的无知畜类。

<span style="color:#800000">*都是哑巴狗。*</span>其次，他称他们为「哑巴狗」，指控他们懒惰与漠不关心；因为好牧人的本分是勤勉谨慎，先知既称他们懒惰、漠不关心，就表明他们身上毫无一样是牧人所当有的。所以，当我们被夺去好牧人，代之而起的是懒惰甚至凶残的野兽时，让我们承认这是神的忿怒，并要知道毁灭已不远了；因为先知在牧人「哑巴」之时，正是在威胁并预言百姓的灭亡。

由此也可见，神设立他们去尽「狗」的职分，就是守望，驱赶强盗与贼，不容他们进入羊圈。狗既是这样忠信的守卫，对主人如此依恋，以致不断为主人的安全守望，一见有危险临近，便吠叫不止，加以驱逐；那么牧人若放任自己懒散昏睡，被一只畜类比过，岂不当羞愧吗？

<!-- PAGE 450 -->
**11.** <span style="color:#800000">*这些狗贪食，不知饱足。*</span> 他在邪恶的牧人身上所指出的第三样恶，就是无法满足的贪婪。他们在凡与善治有关的事上都懒惰，然而对于食物却有强烈而贪馋的食欲。有些人认为先知的话含义更广，是说他们施行暴虐的统治。以西结明确地为这罪责备他们；因为假先知通常凶暴，对神的百姓行事残忍野蛮。（以西结书 34:4）但若有人仔细察考这事，就会看出先知所说的乃是他们无法满足的贪婪，这贪婪他随后又用各样的说法加以描述。

<span style="color:#800000">*各人偏行己路。*</span> 意思是：「他们热切地专顾自己的事务；各人只谋自己的好处。」总之，他的意思是：没有一个人不想被人看为高过别人，好像各人都是单为自己而生的。

<span style="color:#800000">*各图自己的利益。*</span> [^f944] <span style="color:#008080">מקצהו</span>（*mikkatzehu*）有各种不同的解释。有些人译作「在他的末端」，即「在他的事务中」，仿佛原文是 <span style="color:#008080">בקצהו</span>（*bekatzehu*）。但这与先知的意思不符。另有人译作「从他贪婪的极处」。我认为较为简明的解释是「从他那一端」，即「就他一方面而言」；或如我们通常所说的（*Chacun en son endroict*，各人在自己的地位上），「各人在他的本位上」。这样，各人都一心专于贪婪，把万事都拉到自己身上、据为己有，只谋自己的好处，全然不顾自己职分上的本分。

由此我们得知，凡被邪情私欲所辖制的人，都不能事奉神；那专心积攒财富的人，必不会用心去建造主的教会。没有一种瞎眼比贪婪更危险；因此，牧者若愿作神忠心的仆人，就更当竭力躲避它。当我们看见先知抱怨他那时代的恶劣牧者时，我们不必因今日遇见同样的事而惊慌；也不要以为如今甚少有人殷勤从事主的工作乃是罕有之事。

<!-- PAGE 451 -->
**12.** <span style="color:#800000">*你们来吧，我去拿酒。*</span> 先知既已论及牧者的贪婪与怠惰，接着便指出他们无可救药的邪恶与顽梗；因为他描写他们所说的话，[^f945] 引述他们那铁石心肠的言语，由此可见，无论何等的劝诫或警戒都不能使他们回到正路，反倒毫无惧怕地一概藐视。在另一处，先知引述那些讥诮之人的话；当神的仆人劝他们披麻蒙灰时，他们却彼此邀约宴乐畅饮：「我们吃喝吧！因为明天要死了。」（以赛亚书 22:13）这些先知为何搅扰我们呢？我们若听从他们，事情决不会顺利。（以赛亚书 28:15）以赛亚在此重申类似的控诉，就是牧者顽固到底，硬着心抵挡神的审判。

他并非单单责备他们喝*酒与浓酒*——这本身并非罪——乃是责备那种心灵的醉酒与麻木不仁，人因此骄傲放肆地藐视神的话。在别的经文中，醉酒与滥饮乃是被定罪的；但在此处，先知所痛斥的，是牧者以何等的癫狂与放肆自高抵挡神，将一切警戒、劝告、责备，总之将一切宗教敬虔都践踏在脚下。然而毫无疑问，他也在责备那种粗鄙可耻的恶行，就是他们仿佛故意以纵酒宴乐来埋葬自己的省察，使羞耻、惧怕，以及对神对人的敬畏，都不能搅扰他们的安逸；正如不敬虔的人竭尽所能，用非法的宴乐使自己麻木，好叫他们更加放胆、更少顾忌地纵情作恶。

看见这样藐视神、藐视信仰的事，竟不是出在外邦人身上，不是出在平民百姓身上，而是出在官长和君王自己身上——他们本当以自己的榜样教导别人，因他们身处那承载着基督形象的神圣职分之中；因为君王与祭司都担负着他的样式与形象——这真是骇人而可怕的景象。人竟以何等狂暴抵挡神的话，这种骄傲何等不可容忍，是众所周知的。当这最后一剂良药被我们弃绝时，我们就彻底败亡、无可挽回了；因为我们不容许主把我们领回正路。[^f946] 为此缘故，他在另一处威胁说：「这罪孽必不得赦免。」（以赛亚书 22:14）他就这样责斥那不敬虔的极点；而我们仔细衡量随后的话语，是极为重要的——

<!-- PAGE 452 -->
<span style="color:#800000">*今日如此，明日也必如此。*</span>意思是：「我们今日若安好，明日也必安好。不要未到时候就自寻愁苦。」[^f947] 他描述他们罪责的加重，因他们竟嘲弄神的温柔与宽容，自以为必能逃脱刑罚，仿佛神每当延缓他的审判时，就是在天上睡着了，或安逸享乐。凭着这样出于魔鬼的俗谚，就是在今日，人们仍竭力抚慰、甚至迷惑自己的良心，为要更彻底地放纵于各样宴乐，沉溺在自己的罪孽与恶行之中。因此，为使我们不落在主这可怕的审判之下，愿各人省察自己，远远地就看出神的忿怒，免得它突然临到，使我们毫无防备。
