# 第四十二章

<p style="text-align:center" markdown="1"><span style="color:#000080">前往 以赛亚书 42:1-25</span></p>

**1.** <span style="color:#800000">*看哪，我的仆人。*</span> 先知似乎是突然中断话题而转论基督，但我们当记得从前[^f752]解释另一处经文（以赛亚书 7:14）时所提到的：众先知每逢应许难以置信之事，随即便提及基督；因为一切应许都在祂里面得以确立，若不然，这些应许便是可疑而不确定的。保罗说：「在基督里」乃是「是的」与「阿们」。（哥林多后书 1:20）因为若没有中保介于我们之间，我们与神岂能有什么交往呢？我们无疑与祂的威严相隔太远，因此除了借着基督的恩慈，我们既不能得救，也不能有分于任何别的福分。

此外，当主应许拯救犹太人时，他也愿意提升他们的心思，使他们仰望比肉身的自由和归回犹大更大、更宝贵的恩赐；因为那些福分只是他们最终藉着基督所得、而我们如今所享的那救赎的先尝。神在其百姓归回之事上所显的恩典，若他当时未将自己启示为他教会永久的救赎主，实在是不完全的。但正如我们已经说过的，巴比伦被掳的结束包含了教会的完全复兴；因此，我们不必惊奇先知们将那恩典的开端与基督的国度交织在一起，因为这样的连贯次序在许多经文中都曾提及。所以我们必须归向基督，没有他，神就不能与我们和好；也就是说，除非我们藉着被接枝于他的身体，而被收纳入神儿女的数目之中。从下文可以清楚看出，先知此处所说的基督乃是长子与元首，因为下面的宣告不能应用于任何别的人，而福音书作者们更使这事毫无争议（马太福音 12:17-21）。

<!-- PAGE 116 -->
他称基督为他的**仆人**（<span style="color:#0000d4">kat ἐξοχήν</span>，卓越地、专称地），是以尊崇的方式而言；因为这名原属于一切敬虔人，缘于神收纳他们的条件，是要他们将自己和自己的全部生命都指向对他的顺服；而敬虔的教师，以及那些在教会中担任公职的人，更是特别被称为神的仆人。但这里还有更为非凡之处，使这名尤其归于基督，因为他被称为「仆人」，乃是由于父神不仅吩咐他教导或行某一件特定的事，更是呼召他去作一件独特无比的工，是与其他一切工作毫无共同之处的。

这名虽归于他的位格，却属于他的人性；因为既然他的神性是永恒的，又因他在神性中始终拥有与父同等、完全相似的荣耀，他就必须取了肉身，才能顺服。故此保罗也说：

<p style="text-align:center" markdown="1"><span style="color:#000080">「他本有</span> <span style="color:#000080">神的形像，不以自己与</span> <span style="color:#000080">神同等为强夺的；反倒虚己，取了奴仆的形像」</span><span style="color:#000080">等等（</span><span style="color:#000080">腓立比书 2:6）。</span></p>

他作仆人乃是出于自愿的作为，因此我们切不可以为这有损于祂的尊位。教会中的古代作者以「安排」（Dispensation，即降卑之安排）一词来表达此事，他们告诉我们，藉此祂便担负了我们一切的软弱。祂是出于自愿的决定而顺服 神，并且以这样的方式顺服，以致也成为服事我们的；然而那极其卑微的地位丝毫不妨碍祂仍然拥有至高的威严。因此使徒也说祂被「升为至高，又赐给祂那超乎万名之上的名」（腓立比书 2:9）。他用指示词**看哪**，是为要引导犹太人把这事看作确实已经成就的；因为他们眼前所见的景象可能使他们绝望，所以他吩咐他们把眼目从眼下的实况转开，仰望基督。

<!-- PAGE 117 -->
<span style="color:#800000">*我要倚靠他，*</span>或作，我*要扶持他*。[^f753] <span style="color:#008080">אתמך</span>（*ethmoch*）一词，有人解作主动意义，有人解作被动意义。若取被动意义，其意思便是： 神要如此「倚靠」祂的受膏者，以致将全部职任都交托与祂，正如主人通常对忠心的仆人所行的；而这乃是非凡忠信的明证——父 神将万有交在祂手里，并把自己的权能与权柄交付于祂（约翰福音 13:3 及 17:10）。然而我也不反对主动的含义，「我要举起祂」，或「我要高举祂」，或「我要在祂的尊位上扶持祂」；因为紧接着的话，*我已将我的灵赐给他*，正是同一意念的重述。所以在前一分句中他说，*我要扶持他*，随后便描述这「扶持」的方式，即祂要藉自己的灵引导祂，这话的意思是： 神必在万事上帮助基督，绝不容祂被任何艰难所胜。如今，基督必须被 神的灵所充满，方能执行那神圣的职分，作 神与人之间的中保；因为如此浩大的工作是人的能力所不能成就的。

<span style="color:#800000">*我所拣选的。*</span> 在这段经文中，*拣选* 一词意为「卓越的」，正如在许多其他经文中一样；因为那些正当年华鼎盛之人被称为拣选的少年（撒母耳记上 26:2，撒母耳记下 6:1）。因此耶和华称他为「卓越的仆人」，因为他带来和好的信息，也因为他一切的行动都由神引导。同时，他也彰显自己白白的爱，就是他在他独生子里所拥抱我们众人的爱，使我们在基督的位格中得见那使我们被收纳而进入永生之望的拣选之荣耀显明。既然天上的能力住在基督的人性之中，那么当我们听他说话时，就不要看肉体和血气，而要将心思提升得更高，从而认识到他所行的一切都是属神的。

<span style="color:#800000">*我心里所喜悦的。*</span> 从这段经文我们得知，基督不仅是父所爱的（马太福音 3:17），更是唯一被他所爱、被他所悦纳的，以致除了藉着基督的代求以外，别无从神得蒙恩宠之路。福音书作者正是在这层意义上引用这段经文（马太福音 12:18），正如保罗也宣告我们是「在爱子里」得与神和好，从而因他的缘故而被爱（以弗所书 1:6）。先知随后表明，基督将被赋予圣灵的能力，并不单是为他自己，而是为要将其广传远播。

<!-- PAGE 118 -->
<span style="color:#800000">*他必将公理传给外邦。*</span> 先知用 *公理* 一词，所指的是井然有序的治理，而非法官在审判席上所宣告的判词；因为在希伯来作者中，*审判* 意为「命令、掌权、治理」。他又补充说，这公理不仅在犹大，更要遍及全世界。这应许极其新奇罕闻；因为神从前唯独在犹大被人所认识（诗篇 76:2），而外邦人则被隔绝于一切对他恩宠的倚靠之外（以弗所书 2:12）。

因此，这些清楚的凭据对我们极为必要，使我们能确知自己的呼召；否则我们或许会以为这些应许与我们毫不相干。基督被差来，是要使全世界都归于神的权柄之下、服从于他；这就表明，若没有他，一切都是混乱失序的。在他来到我们中间以前，我们中间不可能有正当的治理；所以，我们若渴望被良善公正地治理，就必须学会服从他。如今，我们应当按他国度的性质来判断这治理；他的国度不是外在的，而是属乎内心的人的；因为它在于良善的良心与生活的正直，不是人前如此看为正直，而是神前如此看为正直。这教义可以如此总括：「因为自从我们在亚当的堕落中在各方面都被败坏之后，人的全部生命都已被扭曲，所以基督带着他圣灵的属天能力而来，为要改变我们的性情，从而重新塑造我们，使我们『一举一动有新生的样式』。」（罗马书 6:4）

**2.** <span style="color:#800000">*他不喧嚷。*</span>先知在此指明基督降临将是何等性质；就是没有地上君王临驾时常有的排场与荣华——他们一到，便有各种响声与高呼，仿佛天地要相混一般。但以赛亚说，基督来临却不带任何喧嚷或呼喊；他这样说，不仅是为称许基督的谦和，更是要，第一，使我们不至于对他形成任何属地的观念；第二，使我们既已认识他吸引我们归向自己的慈爱，便欢然快跑迎见他；最后，使我们的信心不至于衰残，纵然他的境况卑微可鄙。

<!-- PAGE 119 -->
<span style="color:#800000">*不扬声，*</span>意思是，他不制造任何骚动；正如我们通常论到一个安静平和的人时所说的：「他不大声喧哗。」[^f754] 事实上，他并未在众人面前自夸，反而屡次禁止他们传扬他的奇事，好使众人都明白：他的能力与权柄，与君王或诸侯所得的截然不同——那些人是靠着使自己被人大声传扬，以博取群众的喝彩。（马太福音 8:4；9:30；12:16；马可福音 5:43；路加福音 8:56）

**3.** <span style="color:#800000">*压伤的芦苇，他不折断。*</span> 先知先总括地宣告基督必不像地上的君王，接着便在这一点上述说他的温柔，就是他必扶持软弱疲乏的人。这就是他用「压伤的芦苇」这比喻所要表达的：他不愿折断、更不愿彻底压碎那些已经半折的人，反倒要扶起他们、支撑他们，使他们里面一切美善之物得以保全并得着坚固。

<span style="color:#800000">*将残的灯火，他不吹灭。*</span> 这个比喻与前一个意思相同，是取自灯的灯芯：灯芯若燃得不明亮，或冒出烟气，就可能令我们不悦，然而我们并不将它掐灭，反倒修剪它、使它明亮。以赛亚将那种宽容归给基督，就是他以之容忍我们的软弱；这一点我们确实看见在他身上得着应验，因为凡有一点敬虔的火星显露之处，他就加以坚固、加以点燃；他若以极严厉的态度对待我们，我们早已归于无有。因此，人虽然摇摇欲坠、跌跌撞撞，虽然甚至已被震动、脱了骨节，他却不立即把他们当作全然无用之物弃绝，反倒长久忍耐，直到使他们变得更强壮、更坚定。

<!-- PAGE 120 -->
当神指派基督开始履行其使者的职分时，他就显明了这种温柔；因为圣灵是以鸽子的形状从天降下，而鸽子所标记的无非是温和与柔顺。（马太福音 3:16；马可福音 1:10；路加福音 3:22；约翰福音 1:32。）这记号确实与实情完全相符；因为他不大声喧嚷，也不使自己成为可畏之物，像地上的君王通常所做的那样，也不愿过分地苦待或压制他的百姓，反倒要抚慰他们、安慰他们。他不只在显现于世界之时如此行，如今他也借着福音天天显明自己是这样的。福音的仆人既是他的代表，就当照着这榜样，显明自己是温柔的，扶持软弱的人，温和地引导他们走当行的路，以免在他们里面熄灭那最微弱的敬虔火星，反倒要竭尽全力将其点燃。但为免我们以为这种温柔是在纵容罪恶与败坏，他就补充说——

<span style="color:#800000">*他凭真实将公理传开。*</span> 基督虽然抚慰并扶持软弱的人，却绝不用那助长恶行的谄媚之言；因此我们责备恶行时也不当谄媚，因为谄媚与那温柔最是不相容的。所以我们当殷勤防备两个极端：既不可用过分的严厉压碎软弱者的心，也不可用柔顺的话语纵容任何邪恶。

为使我们更明白究竟当效法基督的榜样，向哪些人施行这般温和，我们应当仔细斟酌先知的用语。他称他们为「压伤的芦苇」和「将残的灯火」。这些话并不适用于那些放胆而顽固抗拒的人，也不适用于那些凶暴刚硬的人；因为这样的人不配得这般宽容，倒必须被话语的严厉如锤击一般打碎压碎。他一面称许温柔，一面也指明这温柔适用于何人、在何时、当以何等方式施行；因为它不适于刚硬叛逆的人，也不适于怒焰腾腾的人，只适于那些顺服、甘心乐意负基督的轭的人。

<!-- PAGE 121 -->
「*将残*」（smoking，冒烟的）一词表明，他所维护、所珍惜的不是黑暗，而是火星，尽管那火星微弱、几乎难以察觉。所以凡有不敬虔与顽梗之处，我们就必须以极大的严厉行事，绝不宽容；但另一方面，凡有尚未到不可容忍之地的过失，我们却要以这样的温和，不是去纵容，而是去纠正、改造它们；因为我们总要首先看重他所说的*真实*，使恶行不至被掩藏、因而暗中腐败下去，而要使软弱的人渐渐被训练成诚实正直。因此这些话是指那些人：他们虽有许多不足，心里却存正直，切切渴慕遵行真敬虔，或者至少我们在他们身上看见某些良好的开端。有许多经文（马太福音 12:39；22:18；23:13）清楚地显明，基督如何严厉对待轻慢的人；因为对那些不肯服在他牧人杖下受管理的人，他不得不动用「铁杖」将他们打碎。正如他向甘心的门徒公义地宣告说「我的轭是容易的，我的担子是轻省的」（马太福音 11:30），大卫也照样有充分的理由用「铁杖」（诗篇 2:9）装备他，使他打碎仇敌，并宣告他必被他们的血浸透。（<span class="ages-code">&lt;19B006&gt;</span>诗篇 110:6, 7）

**4.** <span style="color:#800000">*他不灰心，也不丧胆。*</span> 先知在此呼应前一节，并证实他先前所说的：基督对软弱者固然温柔和缓，然而他绝不流于绵软或柔弱无力；因为他必刚毅地执行从父所领受的使命。这就是他说「他不灰心」的意思；而在 <span style="color:#008080">יכהה</span> *(yichheh)* 这个动词里，含有对前一节的呼应，就是他所说的「将残的灯火」。如今他指明何为温和的真正节度，即不偏向过度的宽纵；因为我们运用温和，当以不偏离本分为限。许多人愿意藉温和之名得益，以博取世人的称许与敬重，同时却卑劣可耻地背卖了真理。

我记得在一座人烟稠密的城中有两位传道人，其中一位大胆而严厉地责备罪恶，另一位却以谄媚讨百姓的欢心。这位逢迎的传道人正在讲解先知耶利米书，恰遇一段满是最温柔安慰的经文，他以为寻得了良机，便开始高声抨击那些严峻苛刻的责备者，说他们惯用言语的雷霆惊吓众人。然而次日，当先知转换题目，以他独特的激烈笔调痛斥恶人时，这可怜的谄媚者不得已要收回那些众听众记忆犹新的话，因而遭受尖刻的讥笑。于是他所赢得的一时之宠迅速消散，因为他暴露了自己的心性，使自己成为善人与恶人共同憎恶的对象。

<!-- PAGE 122 -->
因此我们必须分辨顺服的人与顽梗的人，免得我们滥用那温和，不分场合地一概施用。然而以赛亚宣告说，基督的刚毅必坚定不移，胜过一切阻碍；因为他用<span style="color:#800000">*直到他设立公理*</span>这话，是指基督的职事必如此有效，以致他教义的果子必然显明。他并非仅仅说「直到他将父的旨意宣明」，而是说「直到他设立*公理*」，也就是我们先前所说的，正当的治理。所以他见证说，基督的职事绝不徒然无果，而必有如此的功效，使人因它得以改正。

这不可只限于基督的身位，而是延伸到福音的全部进程；因为祂不仅在三年之间履行了所交托给祂的使命，更藉着祂的仆人们每日继续履行同一使命。然而我们由此得着提醒：我们若要履行这职分，就必然要忍受许多烦扰，并要经历如此严酷、如此危险的争战，以致我们几乎被压倒，几乎要放弃一切。但我们仍不可退缩，而当在本分上恒切坚忍，奔跑直到终点；因此先知见证说，基督必这样坚定不移，以致祂要将自己的呼召追寻到底；我们效法祂的榜样，也当勇敢地坚忍到底。

<span style="color:#800000">*海岛都等候他的训诲。*</span> 此处他用「律法」一词来指「教义」，因为希伯来文中「律法」一字是从一个意为「教导」的动词而来；[^f755] 众先知也习惯这样称说福音，为要表明福音并非新的，也不与摩西所教导的相违。

<span style="color:#800000">*海岛。*</span> 我们先前已经指出，希伯来作者们将海外之地称为*海岛*。

先知确证了前面所宣告的，即基督被立，不单是为犹太人，也是为外邦人，虽然外邦人与犹大国原本毫无相干。总而言之，那应许乃是关乎万国的，好使这复兴与更新的益处，得以为世上各方所共享。

<!-- PAGE 123 -->
他用「等候」一词，意思是：选民必要热切接受向他们所提供的福音；因为主在此显明祂拣选的能力，即「那些在黑暗里行走的人」（马太福音 4:16），一听见福音的声音，便以极大的渴慕接受它；他们从前虽像分散迷失的羊漂流，如今却立时听见牧人的声音，甘心顺服于祂，正如基督自己也曾说过的（约翰福音 10:16）。由此我们知道，奥古斯丁的那句话极为真确：「有许多羊在羊圈之外漂流，而豺狼却常常住在羊圈之内。」这种留心听从乃是神的工作，就是当那些自以为有智慧的人放弃自己的判断，转而必须学习基督的福音，以致全然依靠这位教师。

**5.** <span style="color:#800000">*耶和华说。*</span> 他确证本章开头关于基督之国所说的话，即祂必更新并复兴万事；由于这似乎难以置信，他在此便加上一段对神的能力的壮丽描述，我们的信心当由此得以坚固，尤其当事情的外在光景正与之相反的时候。为此他提出神能力的明证，使众人因提及这些而被激动，深信那位从无造出万有、铺张诸天、生出草木、赐生命给活物、并以其能力扶持保护万有的神，必轻而易举地成就祂所应许关乎基督之国的事。这些表达方式提醒我们，我们当常常思想神的能力，好叫我们对祂话语的权威与确定无疑的真实性有充分的确信；因为以赛亚作这样的开场并非无故，而是为要除去一切疑惑，因为在神没有难成的事，全世界都服在祂的权柄之下；在以下各章中，他也要使用类似的表达方式。

<span style="color:#008080">האל</span>（hael）有人译作「有能力的」，也有人译作「神」；但这无关紧要，因为意思是一样的；因为他在此彰显神的能力与威严，并以这一连串的称号来装饰他，为要使我们知道：凡已倾倒败落的，他都能轻易地复兴。

<!-- PAGE 124 -->
**6.** <span style="color:#800000">*我耶和华凭公义召你。*</span>他再次重提神的名，在此我们应当补上他在前一节所说的关乎神能力的话。一般认为，这里指出基督被召的目的，就是他被父所差派，为要在人间建立「公义」；人若没有基督，便毫无公义，反倒放任于一切罪恶与败坏之中，被掌控在撒但的暴政之下。但因「义」一词有更广的含义，我便略过那精巧的分辨；因为经文甚至没有说他被召「归于义」，而这种说法应视为与副词性的表达相当，即「按公义地」或「以圣洁的方式」。我倒认为其意乃是：基督「凭公义被召」，因为他的呼召是合法的，因此必是坚固稳妥的。我们知道，凡不是按正当合宜的方式而行的，都不能长久存留。或者也许有人认为这样理解更佳：神既指派基督来复兴教会，他所寻求的理由不在别处，惟在他自己和他自己的义；但可以确定的是，这个词表明的是稳固，仿佛他说「信实地」。

<span style="color:#800000">*必扶持你的手。*</span>他以「握住手」来指神那直接的帮助；仿佛他说：「我必在我所指派你的呼召中引导你、坚立你。总之，你的呼召既是公义的，我也必护卫你、扶持你，如同我握住你的手作你的引路者。」

<span style="color:#800000">*保守你。*</span>「保守」这一词明白地显出「扶持你的手」是何意，就是说，基督必受父的引导，以致他有父作他的保护者与看守者，享有父的帮助，简言之，在万事上都感知父的同在。

<span style="color:#800000">*使你作约。*</span>他现今陈明神为何应许要作基督的看守者。此外，先知分别提及犹大人与外邦人；这并非因为他们的本性有别，也不是因为一方比另一方更为尊贵（因为众人都需要神的恩典，罗马书 3:23，而基督也无分别地把救恩带给众人），乃是因为主将首位给了犹大人（马太福音 10:6），故此他们理当与其余的人有所分别。所以，在「隔断的墙」（以弗所书 2:14）尚未拆毁之前，他们是卓越的，然而这卓越并非出于他们的功德，而是出于神的恩眷，因为恩典之约首先是与他们立的。

<!-- PAGE 125 -->
或有人反驳说：「基督既被立为约，为何这约早已在先前就得了确立呢？因为在两千多年以前，神就已收纳了亚伯拉罕为儿子，如此说来，这分别的起源远在基督降临之先。」我回答说：与亚伯拉罕及其后裔所立的约，其根基原就在基督里；因为约的话语是这样说的：「并且地上万国都必因你的后裔得福。」（创世记 22:18）这约也不是以别的方式得以确立，乃是在亚伯拉罕的后裔里，就是在基督里得以确立；这约虽早已立定，却因基督的降临而得了坚固，并实际得了印证。因此保罗也说：「神的应许在基督里都是是的，都是阿们的」（哥林多后书 1:20）；在另一处又称基督为「受割礼人的执事，要证实所应许列祖的话」（罗马书 15:8）。他更明白地宣告基督是众人的「和睦」，以致从前分隔的人在他里面合而为一，远处的人与近处的人都如此与神和好（以弗所书 2:17）。由此也显明，基督不单是应许给犹大人的，也是应许给全世界的。

<span style="color:#800000">*作外邦人的光。*</span>这里我们又得着外邦人蒙召的一个明证，因为他明说基督被立为他们的「光」。他称他为*光*，因为当主单单光照犹太人的时候，外邦人正沉沦在最深最浓的黑暗之中。既然如此，我们若不得与这救恩有分，过错全在我们自己；因为他呼召万人归向自己，无一例外，又将基督赐给众人，好叫我们藉着他得着光照。我们只要睁开眼睛，惟独他必驱散黑暗，用真理的「光」照亮我们的心思。

**7.** <span style="color:#800000">*开瞎子的眼。*</span>他在此更充分地解明，父差遣基督究竟为了什么目的，好叫我们更清楚看见他给我们带来何等的益处，并我们何等需要他的帮助。他提醒众人认识自己的「瞎眼」，好叫他们承认这一点，若他们愿意被基督光照的话。总之，他借着这些比喻宣告：在基督作救赎主向人显明光辉之前，人的光景是何等的，就是说，他们极其可怜、空虚、毫无一切福分，被无数患难所围困、所淹没，直到他们被基督拯救出来。

<!-- PAGE 126 -->
如今，先知虽是向基督自己说话，眼中所看的却是信徒，好叫他们知道当信靠他，并且不疑惑：他们若求他相助，一切苦难都必有医治之法。神在此并非吩咐基督当行何事，仿佛他需要被教导或领受诫命；乃是为我们的缘故向他说话，好叫我们晓得父为何差遣他；正如他也说（诗篇 2:7,8）：「受膏者说，我要传圣旨；……你求我，我就将列国赐你为基业」；因为那段经文宣告了基督的尊位与权柄，好叫我们知道父已将至高的权柄赐给他，使我们更加稳妥地将一切盼望与信靠都安放在他身上。

**8.** <span style="color:#800000">*我是耶和华。*</span> 由此可以推知，不信之病的性质与程度何等严重，因为主几乎无法用任何言语来充分表达对它的医治。我们生性倾向于疑惑，神说话时我们并不相信，直到祂完全制伏我们的顽梗。此外，我们因自己的轻浮，若非祂用许多缰绳勒住我们，就必不断跌回同一过失之中。所以祂再次回到我们从前所论及的那种确证，使祂的应许得以坚立不动摇。

<span style="color:#800000">*这是我的名。*</span> <span style="color:#008080">הוא</span>（hu）有时被视为一个实词，作为神的专有名称；[^f756] 但我以更简单的方式解释它：「*这* 是我的名」，即「*耶和华* 是我自己的名，不可合法地给予任何别的。」总之，祂借这句话为凡论到基督职任的一切话盖上印记，仿佛在应许上加上封印：「宣告这些事的那一位见证祂独自是神，这名也只住在祂里面。」

<span style="color:#800000">*我必不将我的荣耀归给假神；*</span> 意即：「我必不容我的荣耀被削减；倘若我在应许上被发现是虚假的或反覆无常的，我的荣耀就要被削减了。」因此祂宣告祂必守住自己的应许，因为祂愿意维护自己的荣耀，并保全其完整，使它丝毫不受削减。

这是一段极为重要的经文，藉此我们受教知道：神的荣耀主要显明在祂成就自己所应许的事上。由此我们的信心得着独特的坚固，就是主从不欺哄人，从不背离祂的应许，凡祂一次定意的事，无一能加以阻挠。然而，撒但用惊人的伎俩竭力遮蔽神这荣耀，将它归给人和假神；因此神在此见证说，祂决不容许自己在应许上被人看作反复无常或诡诈欺人。

<!-- PAGE 127 -->

<span style="color:#800000">*也不将我的称赞归给雕刻的偶像。*</span> 这里将独一的真神与偶像作了对比，并且是就时间而言的；因为，倘若神未曾作祂百姓的救赎主，不信的人就要夸口，仿佛真信仰乃是虚假无用的。所以神宣告说，祂必不容恶人因压迫教会而夸胜；并且毫无疑问，主至今宽容我们，如今仍这样温柔地待我们，正是为了不使祂的福音落在教皇党人褻慢的辱骂之下。我们应当从此引出一项普遍的教义，就是：主愿意祂的荣耀丝毫不受损；因为祂到处以极大的热忱护卫并维护这荣耀，为要显明祂对此极其忌邪（出埃及记 20:5），连其中最小的一分也不容归与别人。

**9.** <span style="color:#800000">*先前的事。*</span> 祂现在唤起人回想从前的预言，藉着这些预言的应验，表明将来的事也当信靠祂；因为凡我们已亲身经历而知道的，理当大大坚固我们的信念。这就如同祂说：「我曾屡次向你们的列祖说话，你们也发觉我在一切事上都是真实的；然而你们对将来的事却不能信靠我：以往作为的经历在你们身上毫无功效，也不激励你们有更好的表现。」因此，我们提说神的恩惠时，当以这样的方式：无论何时我们的救恩仍隐藏在盼望之中，我们都可安息在神的话语上，并终其一生藉此得着坚固。

<span style="color:#800000">*看哪，都成就了。*</span> [^f757] 他用「看哪」这个副词，如同用手指指出：他们已从经验中学到，神并非虚谎的，也没有藉着众先知徒然说话；因为明明的凭据公开见证并宣扬了神的真实。

<!-- PAGE 128 -->
<span style="color:#800000">*在发生以前。*</span> [^f758] 他以这一标记将神与偶像区别开来：唯独他知道并预言将来的事，而偶像却不知道。至于外邦人的神明所给出的绝大部分回应，我们从前已经看见，那些回应或是虚假的，或是含糊两可的；因为信赖它们的人常常受到可耻的欺骗，而这正是他们所该得的报应。倘若初看之下所应的事果然发生了，这反倒把他们更深地推入永远的沉沦；这乃是照着神公义的审判，任凭撒但用这样的迷惑欺骗他们。神圣的神谕却截然不同，教会藉着它们，为自己的益处和救恩，时而被引向悔改，时而被激励怀抱美好的指望，免得在刑罚的重担之下沉沦。这仍是确定不移的原则：凡神所预言的，都必由事实印证；因为他以自己的护理统管、引导万事。

**10.** <span style="color:#800000">*你们要向耶和华唱歌。*</span> 他现在劝勉百姓当存感恩的心；因为神的恩惠总当藉着我们的追念，激动我们献上感谢、颂扬他的赞美。此外，他藉这劝勉呼召信徒来观看这预言实际已然成就，并坚固他所说的那些应许。我们当留意先知的这一用意：信徒虽被严严地压制，却没有理由任凭自己陷入忧愁，反倒当让美好的指望激励他们欢乐，使他们如今就预备献上感谢。

这首歌的主题是：基督已向世界显明，且为父所差遣，为要解除祂教会的种种苦难，将她恢复到完全的秩序，实在可说是要更新整个世界。因这事难以令人相信，先知便要除去一切疑虑，使这些预言更深地扎在他们心里。他们既已落到极其困窘的境地，再无得救的指望，先知如此竭力唤醒他们，我们也就不必希奇。事情的表象本身足以动摇他们的信心，甚至使他们疑心众先知所预言的一切都是无稽而荒谬的。因此这一劝勉的目的，是要他们在万事绝望之时，仍然欢欣喜乐，倚靠这些应许。

<span style="color:#800000">*新歌。*</span>他以*新*字所指的，是一首卓越、美好、优雅的歌，不是平凡普通的歌，而是能激起人惊叹的歌，因为它关乎神那非凡的恩典，这恩典从来未有过如此显著的先例。诗篇 33:3 与 96:1 也是在这意义上使用此词。此处的*新*是与<!-- PAGE 129 -->寻常之事相对；他借此高举神那无穷的怜悯，就是将要在基督里显明的怜悯，因此理当以最高的赞美来歌颂称扬。由此我们可以推知，我们每一个人所领受的恩惠越多，就当越发热切地传扬神的赞美。宣扬颂赞归给神，固然是众人的本分，因为没有一个人不是被最强的义务所约束；但那些蒙赐更宝贵恩赐的人，理当发出更崇高的赞美。既然神已在基督里为我们开启了一切福分的泉源，展示了一切属灵的丰富，那么祂若要求我们向祂献上非寻常而卓越的赞美之祭，我们也就不必希奇。

应当注意，这*歌*唯有更新了的人才能歌唱；因为它必须发自内心最深处的情感，所以我们需要圣灵的引导与感动，好使我们能以合宜的方式歌唱这些赞美。此外，他不是劝勉一国或数国如此行，而是劝勉世上万国；因为基督是为万国被差来的。

**11.** <span style="color:#800000">*旷野和其中的城邑当扬声。*</span>先知虽然把世上各个地方都包括在内，却特别提到犹太人较为熟悉的那些地方；因为犹大西边是海，东边是旷野和亚拉伯。他提到*基达*的帐棚、*旷野*和*磐石*时，所指的是亚拉伯；但这是以部分代全体的修辞，因为它包括了整个东方。这就如同他说，从日出之地到日落之处，都必听见这赞美之声；因为神必在各处受人敬拜，虽然从前只在犹大受敬拜；如此，局势必要改变，那赞美必在地上极远之处被听见。[^f759]

<!-- PAGE 130 -->
<span style="color:#800000">*基达人居住的村庄。*</span>他提到*基达*，因为众所周知，那些住帐棚的[^f760]亚拉伯人是住在帐棚里的。但他一面说到旷野，一面又用*村庄*这个词；因此应当注意，*旷野*不仅指横亘在犹大与亚拉伯之间的广大荒野，也指那些更遥远的地区——它们通常是照着与自己相邻的那一部分来命名的，正如有些人把山那边的平原称为「山地」；因为一般人的注意力如此专注于近处所见之物，以致他们以为远处别的地方也与之相似。然而先知在此高举并称颂神恩典的伟大，因为这恩典竟临及那些粗野蛮荒的民族，他们的凶暴残忍是众所周知的。

**12.** <span style="color:#800000">*愿他们将荣耀归给耶和华。*</span>他解释那呼喊的性质是什么，就是颂扬神的赞美；因为他的良善与怜悯必要处处显明；因此他吩咐他们以欢乐的声音颂扬这救赎，因为它所带来的蒙福果效必为万民所共享。由此我们也受到提醒：今日当我们宣扬神的赞美时，也要以最大的热切放声呼喊，使我们自己被点燃，并以我们的榜样激励他人照样而行；因为那些真正尝过神恩典之人，绝不可能温温冷冷、口中喃喃，或如俗语所说，只为自己和缪斯而歌唱。

**13.** <span style="color:#800000">*耶和华必像勇士出去。*</span> 以赛亚现今所补充的话，意在胜过信徒所受的试探。他将力量与能力归给神，使他们知道自己在他里面必寻得确实的护庇；因为在患难之中我们心里困惑，怀疑神是否能施予我们帮助，尤其当他迟延不动、似乎在某种程度上拒绝我们的祈求之时。因此先知高声称扬神的能力，使众人都学会依靠他、将信心安置于他。

<span style="color:#800000">*必出去。*</span> 这里所提到的「出去」必须按比喻来理解；因为当神容许他的百姓受苦、被压迫而全无施助的表征之时，他仿佛是隐藏起来的；所以这词的意思是「为施助的缘故而公开显现出来」。下文所说的话也证实了这一点。

<span style="color:#800000">*又像战士。*</span> 当他将烈怒归于神，说神带着这烈怒「像战士」一般冲向他的仇敌时，这些比拟乃是取自人的情感，向我们宣告神大能的帮助；若不如此，这帮助便不能在我们心中留下足够有力的印象。因此，正如我们屡次所说的，他俯就我们的领受能力，使我们知道他何等火热地渴望保全我们，也知道信徒的困苦与被压使他何等痛心，并且知道每当他束腰上阵之时，他的怒气何等可畏。

<!-- PAGE 131 -->

我们应当常常留意先知所注目的那特殊时期，这些预言必须应用于其上；因为当仇敌愈发凶暴、讥笑这可怜的百姓之时，信徒的本分就是要仰望与他们肉眼所见截然不同的事，并且相信神有足够的能力制伏他们的仇敌，将他们从仇敌手中救出来。这应许不仅在被掳期间对减轻他们的忧伤有重大意义，几乎直到基督降临都是如此；因为正如历史所显明的，他们不断地、痛苦地被迫面对严酷的患难。

**14.** <span style="color:#800000">*我许久闭口不言。*</span>先知在此针对那些通常令我们大为不安的试探，就是当神迟延施助之时所来的试探。我们受不耐烦的试探，惧怕他的应许是虚假的。我们以为神在恶人高抬自己之时缄默不语、可以说是沉睡不醒，乃是不合理的；他们热切地行恶，他却冷淡漠然；他们竭力追求各样的残暴，他却对他们的罪行视若无睹。当他们的心灵困苦、几乎被压倒之时，先知愿意安慰他们，使他们不至于以为神已离弃他们，虽然一切看来都已绝望。

<span style="color:#800000">*许久。*</span>他特意提到「那漫长的时日」，免得他们的心因这令人厌倦的迟延而衰残；因为自约沙法死后，他们几乎在不断的灾祸中被压碎，如今要在被掳中度过七十年，实在是极其艰难困苦的。而这甚至还不是他们苦难的终点，因此他们需要被殷勤地劝勉：虽然神不立即施行拯救，只要信徒以忍耐等候，就必不因这迟延而受任何亏损。他借这些话也责备那些不信的人，他们仗着神的宽容，肆意放纵行各样的恶事；因此神宣告说，他虽然一直忍耐、缄默旁观，却并不因此就失去他的能力。

<span style="color:#800000">*像产难的妇人。*</span>他用这个比喻表达出令人惊叹的爱之热切与情感之温柔；因为他把自己比作一位母亲，她虽在极大的痛苦中生下孩子，却格外地疼爱他。有人可能认为这些说法不适用于<!-- PAGE 132 -->神；然而，除了藉着这类修辞的表达，他对我们炽热的爱无从被述说。因此他必须从我们所熟知的事物中取来比拟，好使我们能明白那些我们所不知的事；因为神爱人的方式与人大不相同，就是说，更为完全、更为纯全，并且，虽然他超越一切人类的情感，然而凡是无序失当的，都与他无关。

此外，他也有意暗示，他百姓的救赎将是一种生产，使犹大人知道，坟墓要成为他们的胎腹，如此，即使在腐朽之中，他们仍可怀抱得救的盼望。虽然他为自己造出一个新的教会，并不需要痛苦或劳力，然而，为了更充分地显明他在这新生中恩典的卓越，他并非不合宜地将「产难的妇人」的呼喊归于自己。

<span style="color:#800000">*我要毁灭，我要一同吞灭。*</span>因为那产难妇人的比喻可能有些贬损神的威严与能力，所以先知决定在此加上一种不同的情感。因此，就爱而言，他说神像一位母亲；就能力而言，他说神像狮子或勇士。

**15.** <span style="color:#800000">*我要使大山小冈变为荒场。*</span>先知的意思是：恶人所自夸的一切防御工事与军事力量，都不能阻止神释放祂的百姓得自由。这话必须加在前面的宣告之后；因为当我们看见仇敌极其强盛、几乎不可战胜时，我们就战兢，不再仰望神的帮助——然而这帮助正是保守我们信心刚强所必需的。因此，先知在这一点上反复申论，为要表明：当耶和华愿意拯救祂的百姓时，无论何等权势或军队都不能抵挡。总之，他表明必有这样的翻转：从前最强盛的必被压碎，他们一切与神对抗的图谋必一无所得。

<!-- PAGE 133 -->
在我看来，这就是本段明白的意思，不必像有些人那样进入巧妙的思辨；他们对这些话作寓意解释，断定「大山小冈」是指城邑，而「草木」是指住在其中的人。但没有必要追求这等精细的解法；因为他只是宣告：神有充足的能力成就祂的应许、拯救祂的教会，因为祂必轻易胜过一切在我们眼前显现的艰难。这一宣告也与我们从前所见的其他预言相符，在那些预言中先知教导说：神一旦决意帮助祂的百姓，祂的能力就不受自然手段的限制，乃是奇妙地冲破一切看似阻挡祂通行的障碍。

**16.** <span style="color:#800000">*我要引瞎子。*</span>他既已表明仇敌的势力不能阻止神拯救祂的百姓，便接着讲论他先前已提及的那安慰。他用「瞎子」一词描写这样的人：他们的处境如此艰难、错综、混乱，以致他们不知当转向哪一边，或往何方逃避，简言之，他们看不见任何脱身之路，只见四面皆是深渊。当我们的事情进行得相当顺利时，眼前便摆着一条平坦易行的道路；照样，当我们的事情痛苦愁烦，尤其当它们不给我们存留任何得释放的指望，反倒以毁灭相威胁，并且被幽暗凄惨的黑暗所笼罩时，我们就成了瞎眼的。先知告诉我们：当我们这样毫无脱身之路时，正是那时候，我们尤其应当仰望盼望，等候耶和华的帮助。

对我们而言，有时无路可走、四面被围困逼迫、甚至双目失明，反倒是有益的，好叫我们学会单单依靠神的帮助、专一仰赖他；因为只要还剩下一块我们以为可以抓住的木板，我们就会全心转向它。当我们被驱赶得四处奔走时，结果便是天上恩典的记念从我们的心中消退。因此，我们若愿神帮助我们、解救我们的困境，我们就必须*瞎眼*，必须把眼目从眼前的处境上转开，抑制自己的判断，好使我们全然仰赖他的应许。虽然这种瞎眼绝非令人愉悦的事，且显出我们心智的软弱，然而，倘若我们从它所产生的良善果效来判断，就不应极力避开它；因为宁可作被神的手引领的「瞎眼」之人，也胜过凭着过度的精明为自己筑造迷宫。

<!-- PAGE 134 -->
<span style="color:#800000">*在他们面前使黑暗变为光明。*</span>当他应许要以「光明」代替「黑暗」时，他就证实了前面所说的话；因此，纵然我们在患难中连一线光都看不见，也不该对神的帮助绝望，反倒正在那时候尤其当紧紧抱住他的应许；因为主必轻易将黑暗变为光明，使弯曲的迂回之路变直，引我们进入正路，使我们可以安然行走。然而，让我们明白这些事只应许给信徒，就是把自己交托与神、容他管理自己的人；简言之，就是那些已认识自己瞎眼、甘心跟随他为领路者、并在患难的黑暗中忍耐等候恩典之黎明的人。惟有对那些坚守他应许的人，他才伸出手来；至于那些聪明人[^f761]，就是不顾他而妄想自己看见的，或被不法的图谋所催逼的，他必不如此。

**17.** <span style="color:#800000">*他们必被驱赶后退。*</span>这使我们更清楚地看见前面的教义是关乎何人的，因为它把敬拜神的人与敬拜偶像的人区分开来。主必作他自己百姓的领路者，但另一方面，<span style="color:#800000">*那些敬拜偶像的必然抱愧*</span>。这就如他说，在此主给我们一个选择：或因他的恩典得救，或悲惨地灭亡；因为凡把得救的指望放在偶像上的都必灭亡，惟有信靠神话语的人必定得救；因为他们虽常受重压的苦难，主却终不容他们的指望蒙羞，反要用结局证明他并非徒然立下这一区别。

<!-- PAGE 135 -->
<span style="color:#800000">*对铸造的偶像说：你是我们的神。*</span>可以确定的是，凡将自己的指望寄托于独一真神以外者，一切拜偶像的人都被这两个标记所描绘；因为纵然拜偶像的人不在偶像前屈身下拜，然而他们既将神性归给偶像，就是向那独一真神施行褒渎。因为敬拜神最主要的部分在于信心与呼求他，而先知在此正是描述这两者。或有人问：他们竟如此愚昧，向一个像说「你是我的神」吗？因为一切迷信之人都承认神在天上，并未公然将神性归给木石。我回答说：一切拜偶像的人都将神的能力归给偶像，尽管他们承认神在天上；因为当他们逃向雕像与偶像，向它们许愿还愿之时，他们无疑是将属于神的归给了它们。所以他们用貌似合理的借口来掩饰自己的无知，乃是徒然的，因为他们把木石算作神，就是对神施行至极的侮辱。因此先知并非用夸张之辞，也非诬告他们拜偶像；因为他们的言语和话语明明作了见证，就是他们称自己的偶像和形像为神。即使他们一言不发，他们的癫狂也已公然显明，因为他们幻想若不在偶像前屈身献上祷告，就无法达到神的手或神的耳。这些话的目的乃是要众人明白：除了单单信靠神的人，无人能得救。

**18.** <span style="color:#800000">*你们这耳聋的，听吧！你们这眼瞎的，看吧！*</span>他如今使用「瞎眼」和「耳聋」这些字眼，其意思与他先前（第16节）所用的不同；那里他是以喻意描述那些没有悟性的人，他们被如此沉重的苦难所压倒，以致因忧愁而眼目昏暗。而在这里，他称那些在光中闭上眼睛、不看神作为的人为*瞎眼*的；称那些拒绝听他、在自己无知的渣滓中沉沦于愚顽懒惰的人为*耳聋*的。因此他定犹大人「瞎眼」的罪；或者照我自己的看法，他是定一切人的罪。因为他虽然直接责备犹大人「听是要听见，却不明白；看是要看见，却不晓得」（以赛亚书 6:9；马太福音 13:13），然而这在某种程度上也适用于外邦人——神藉着他所造之物向他们显明自己，又将对他的认识刻在他们的心上和良心里，并且已向他们显明、也仍要显明他奇妙的作为。他既要求人留心听，就宣告说：除了他们「耳聋眼瞎」以外，再没有什么阻碍他们领悟神的真理与能力。这里也并非没有恶意与忘恩；因为他公然教导他们认识他的能力，又赐给他们极其显著的凭据；然而无人留心他的教训或他奇妙的作为，其结果就是他们是甘心「瞎眼」的。这样，先知表明人不认识神的能力，过错完全在于人自己。

**19.** <span style="color:#800000">*谁比我的仆人眼瞎呢？*</span>有些人解释这一节，好像先知是在描述恶人惯常向众先知发出的辱骂；因为他们把自己所不能忍受的责备与指控，反过来加在主的仆人身上。

<!-- PAGE 136 -->

「你指责谁瞎眼呢？你称谁为耳聋呢？这话该归到你自己身上。除了你以外，谁是瞎眼的呢？」因此他们认为，这好像是主如此与犹大人争辩说：「我看见你们把我的先知当作瞎眼耳聋的。」但我们随即就要看到，这种解释与上下文并不相合；因为先知在后面（第20节）说明了他为何称他们为「瞎眼的」。乃是因为他们虽看见许多事，却毫不留意。的确，这一点丝毫不适用于众先知，所以让我们遵循平实自然的意思。

以赛亚曾指控众人瞎眼，尤其是犹大人，因为他们本当比其余所有人看得更清楚；因为他们不但有某种寻常的光照与悟性，更享有神的话，主藉此丰丰富富地向他们显明了自己。所以，纵使其余的人都是瞎眼的，犹大人却本当看见并认识神，既然他们被神的律法和教导所照亮，如同被极其明亮的灯照亮一般。此外，以赛亚在后面这样对犹大人说：

<p style="text-align:center" markdown="1"><span style="color:#000080">「兴起，发光！因为黑暗遮盖大地，</span> <span style="color:#000080">耶和华却要显现照耀你。」（</span><span style="color:#000080">以赛亚书 60:1, 2）</span></p>

犹太人在如此明亮的光中却闭上眼睛，这就是先知向他们发出这特别责备的原因。仿佛他说：「我与那些与我疏远的人辩论是徒然的，他们瞎眼并不足为奇；但令人骇异的是，这事竟发生在我的仆人身上（光已摆在他们眼前），他们对那不断在他们耳中响起的教义竟然耳聋。因为这些事如此清楚，连瞎眼的也能看见；如此响亮，连耳聋的也能听见；然而我对他们说话却是徒然，因为再没有比他们更迟钝愚昧的了；他们本当比众人看得更清、听得更明，如今却找不出比他们更聋更瞎的人。」

<!-- PAGE 137 -->
<span style="color:#800000">*我所差遣的使者。*</span> 先知从普世的人类逐步降至犹太人，其次降至祭司，因祭司是领袖人物，可算是身居最高的地位。解释律法、在众人面前树立善榜样，简言之，指明救恩之路，本是他们的职分。神吩咐百姓要从「祭司的口中」「寻求律法」（玛拉基书 2:7）。因此先知哀叹说，那些本当为他人引路的，自己却是瞎眼的。

有些人认为*仆人*一词是指以赛亚，另一些人则认为是指基督，并以为基督与以赛亚一同被指为瞎眼；但这与先知的原意毫无关系。因此，他借着对比放大他刚才所提出的、关乎犹太人懈怠的控诉；因为他们的过失比别人更深，而最重的罪责却落在作他们领袖的祭司身上。所以让我们学到：我们越是亲近神，所被高举的地位越高，我们就越无可推诿。出于同样的理由，他将*完全*一词用在那些本当完全的人身上；因为他带着责备的意味提到那种完全，就是他们借着邪恶的背叛所堕落离开的，因而卑劣地亵渎了神最卓越的恩赐。他们既已拥有「完全」的义的准则，遵行与否全在乎他们自己。

**20.** <span style="color:#800000">*你看见许多事。*</span> 先知自己解释了他所说的这瞎眼是何性质，并指明它是双重的；这就清楚地表明他所说的是犹大人，他们以恶意的藐视扑灭了神的光。当我们来到神的审判台前时，倘若他显明光而我们闭上眼睛，他借他的话语施教而我们塞住耳朵，我们的罪责就要加倍。外邦列国固然无可推诿；但犹大人以及其他那些主曾以如此多的方式向他们启示自己的人，因着拒绝看见或听见神，就当受双倍的定罪。因此，我们今日既有如此众多、如此显赫的榜样摆在面前，就当惧怕这样的审判；因为在许多人身上，如今可见的瞎眼与顽固并不比从前犹大人中间的更少，也并不更可推诿。

**21.** <span style="color:#800000">*耶和华喜欢。*</span> 为了更加重犹大人的罪责，他现今指明：并不是神阻挡他们过兴盛幸福的生活。他先前已经说过，他们所受的困苦与患难乃是他们瞎眼的刑罚，而这瞎眼是他们自己甘心招来的；现今他又加上一点，作为这控诉的顶点，即他们因着自己的顽梗，拒绝了一切的救助。

<!-- PAGE 138 -->

这段经文有各种不同的解释。有人译作「耶和华如此定意」；有人译作「他是有怜悯的」；但就我自己而言，我译为「耶和华愿意」，即他有意、并倾向于拯救他的百姓，而其目的是为要使他的律法为大，并高举他的义。这样，神便说明了他为何乐意帮助那不配的人：因为他愿意在他们的救恩中传扬他的荣耀，使他的义藉此得以荣耀地显明，并使他的律法得以通行、兴盛。至于临到犹大人身上那沉重的灾祸，其缘由乃是他们自己甘愿作瞎眼的，甘愿自招患难，而不肯顺服神；否则主本是愿意使他们富足、使他们尊大的。另有人如此看待此处：「耶和华愿意使他的律法为大，因为他愿意显明自己在刑罚犹大人的事上是信实的，正如他曾藉着他的律法警告他们的」；他们于是认为「义」是指神向恶民所施行的刑罚与报应。

另有人译作「为他的义者」，把它归于基督；但他们误解了 <span style="color:#008080">צדקו</span> *(tzidko)* 一词的意思。毫无疑问，先知在此所论的是义，其意是说：主本乐意显明他应许的宏大，也乐意在保守他百姓的事上显出他公义的凭据，只是他们自己表明自己忘恩负义、不配蒙此恩。有人认为主在此是为自己作辩解，因为当他所收纳为儿女的百姓遭遇如此众多的祸患时，看来仿佛他的信实动摇了；先知有意驳斥这一毁谤，指出他们被掳掠、成为掠物，并非因为主喜悦他们的苦难，乃因他重视自己的义过于一切。

<!-- PAGE 139 -->
就我自己而论，我只按简明的意思解释：「主为了使自己的律法得着尊荣，本有意向他的百姓施恩，为要使他的荣耀与公义在其中照耀；但他的百姓表明自己不配得这样大的恩惠，因此他们以自己的顽梗使自己的创伤无法医治。」此外，我们当从这段经文学到主为何将如此众多的恩惠赐给他的教会：乃是为要推进他的律法，就是要使人尊崇他的威严，使他的真理越发照耀。当他说主乐意、有意向他们施恩时，他明明表示激动他如此行的，不是别人，乃是他自己；但他加上<span style="color:#800000">*为自己的义的缘故*</span>时，就把这一点说得更充分了；因为他排除了人所能带来的一切。主施恩行善，并非受任何别的考虑所推动，乃因他是公义的；因为在人中间找不出任何功德或价值。然而这理由尤其适用于犹太人，因为唯有他们是他所俯就收纳的。

**22.** <span style="color:#800000">*但这百姓*</span>。以赛亚现在宣告说，这百姓之所以困苦、被定为灭亡，全是他们自己的过错，因为他们弃绝了神——神本来是有意向他们施恩的——又因为他们故意撇弃一切良药，宁愿求死，正如那些绝望的人常有的情形。这样，他为神辩护，却同时严厉地控告这百姓，因为他们以自己的忘恩负义弃绝了他，滥用了他慈父般的良善。然而，正如我在前面稍微提过的，他提这些事，与其说是为神辩解，不如说是要发出痛切的哀诉：他的同胞竟合谋自取灭亡；因为他们仿佛是有意如此，把自己投入许多灾祸之中。那么，我们今日若看见教会处于荒凉可憎的境况，就当归咎于我们自己的罪孽与过犯，因为我们不容神向我们施恩。

连接词 <span style="color:#008080">ו</span> *(vau)* 有人译作*所以*；但我宁愿译作*但*；因为此处所陈述的，与耶和华所宣告的那愿望正相对照——祂本愿保护祂的百姓，若他们肯容许的话。我选择把 <span style="color:#008080">הפח</span> *(hapheach)* 解作动名式分词，*将被陷在网罗中的*；因为他所论及的，是一个将被掳去的民族。至于 <span style="color:#008080">בהורים</span>（*bahurim*），我认为此处所用的乃是两个词而非一个词，意思是*在洞穴中*；因为把这词译作*少年人*，在我看来与上下文不合。

<!-- PAGE 140 -->
<span style="color:#800000">*都成为掠物。*</span> 有些人把这话解释为关乎全人类，说他们除基督以外别无救主（约翰福音 8:36），但他们所提出的与先知的原意毫不相符；因为先知不过是宣告：这百姓必要灭亡，毫无得拯救的指望，因为他们弃绝了神的恩典。让我们由此推想：我们若不趁时领受向我们所赐下的神的恩典，将会临到我们身上的是何等的结局。我们必定该当被剥夺一切的援助，被弃置为掳物、为掠物，并且全然灭亡。

**23.** <span style="color:#800000">*你们中间谁肯……？*</span> 以赛亚继续同一主题；因为他的意思是：犹太人是何等愚顽，将来也必如此愚顽，以致虽然受了警戒，仍旧不肯看见；他特特地对他们说话，因为他们本该比别人受更好的教导与教训，然而他们却一无所悟，也不留意神的审判，纵然那些审判是极其显明的。

<span style="color:#800000">*谁肯留心听，以防将来呢？*</span>就是说，谁终于被苦难所制伏，虽然为时已晚，却仍悔改呢？由此可见，这种惊愕何等加重了他们疯狂的罪责，因为他们始终不肯受教。然而，让我们学习威吓与刑罚的用处何在；因为神责备我们的罪过，或为此惩罚我们，并非因为他喜爱报复，或索取某种赔偿，而是要我们「以防将来」，谨慎自守。

**24.** <span style="color:#800000">*谁将雅各交出当作掠物？*</span>以赛亚在此所抱怨的，正是犹大人所不留意的事；因为他们或以为自己所受的苦难乃是偶然发生的，或以为自己没有列祖那样的抵抗之力，因此才被仇敌所胜。总而言之，他们的心思全被外在的原因所占据，同时既不留意先知们屡次宣告的威吓，也不理会神的审判；因此先知宣告神就是这些审判的作者，将他们拖到天上的宝座前。

<span style="color:#800000">*岂不是耶和华么？*</span>他们不肯相信自己所受的灾祸乃是出于神，作为对他们罪恶的公义惩罚；我们也知道，今日再没有什么事比这一点更难说服人相信了。人人都承认神是万物的作者，但你若问他们，一切逆境是否都是神的管教，他们就羞于承认了；因为人的心被各种各样的思虑所扰乱，又被自己对「命运」的成见所左右，便把心思意念转向这个或那个原因，而不转向神。

<!-- PAGE 141 -->

<span style="color:#800000">*因为我们得罪了他。*</span> 以赛亚接着指出这如此惨重的毁灭之缘由，就是这百姓的罪，耶和华公义地惩罚了这罪。摩西也照样曾指明说，

<p style="text-align:center" markdown="1"><span style="color:#000080">“若不是他们的磐石卖了他们，若不是耶和华交出他们，一人焉能</span> <span style="color:#000080">追赶他们千人？”</span> <span style="color:#000080">(</span><span style="color:#000080">申命记 32:30。)</span></p>

我们天天为许多出乎我们所料之外的事惊讶，却不承认缘由就在我们自己身上。因此，必须逼迫我们、以强力迫使我们承认自己的过失；这教义也因此必须常常宣讲、反复申明。

为免有人指责神残酷，先知补充说，神如此行乃有公义的缘由；因为若非出于必要，他并不急于[^f762]施行刑罚，他也不以我们的苦难为乐。因此，我们在此必须留意两件彼此有别的事。第一，凡临到我们的祸患，无不出于耶和华，所以我们绝不可以为有什么事是偶然发生的，或是由某种外在原因而来的。第二，我们所受的一切祸患，无不有公义的缘由，因为我们得罪了神。所以，人指责神残酷，实属徒然；因为在他理当施行的管教之中，我们理应承认他公义的审判。

<span style="color:#800000">*他们也不肯遵行他的道。*</span>先知在此加重犹大人的罪责，却更换了人称；因为他先前把自己与众人一同包括在内，视自己为那身体的一部分，并承认自己的罪。这并非因为他与那大多数民众相似，或赞同他们的罪行；而是因为在如此庞大的恶行堆积之中，他不能不像身体的其他部分一样，在某种程度上受那传染所染污。既然他与那大多数民众截然不同，他便更换人称，加上说「**他们**也不肯」；藉此他声明，这样根深蒂固的顽梗使他厌恶，以致他决不能以任何方式加以掩饰，或表示赞同；因为如今所论的并非寻常的恶行，而是藐视神、弃绝神，凶暴而傲慢地摆脱他的轭。这就是以赛亚把自己排除在他们数目之外的缘故。

<!-- PAGE 142 -->

这些事若是公义地临到了犹大人，我们就当知道，同样的刑罚也悬在我们和全世界的头上，除非我们受警戒而悔改。我们看见主如何慈爱地邀请我们到他那里来，如何以许多方式向我们表明他的美意，如何恩慈地见证说，他虽曾被触怒，仍愿与我们和好。如今我们既已如此屡次、如此慈爱地被神邀请，又已经历他的怜悯，若我们仍不肯听从他，就必确实地感受到：他们所经历的毁灭，同样归于一切叛逆的人。

**25.** <span style="color:#800000">*所以，他将......倾倒在他身上。*</span>因为耶和华已经开始、并将继续用以惩罚犹太人的那些管教极其严厉，先知便用比喻的言辞来表达其猛烈。他说耶和华<span style="color:#800000">*倾倒他的烈怒*</span>，仿佛雷霆猛然击下，又仿佛洪水暴涨而出，将四围之地大肆毁坏，正如在洪水之时，那时

<p style="text-align:center" markdown="1"><span style="color:#000080">「</span><span style="color:#000080">大渊的泉源都裂开了，天上的窗户也敞开了。」（</span><span style="color:#000080">创世记 7:11）</span></p>

众水便以惊人的力量与猛烈之势奔涌而出。

<span style="color:#800000">*战争的猛威。*</span> 他接着采用了另一个比喻，就是神调集他的军队来作战，好以毫不留情的敌意攻击这百姓。若有人认为这是指耶和华兴起来攻击犹太人的仇敌，我也不十分反对这种解释；因为他们确实是照神的审判被兴起的。尼布甲尼撒岂不正是神的刑杖吗？（耶利米书 51:20）不过就我而言，我认为这里也当视为比喻性的语言，意思是：「神猛烈地冲出来，如同一位全副武装的仇敌，将他的烈怒倾倒在百姓身上。」他有各样争战的方式；因为他管教他的百姓，有时藉着饥荒，有时藉着刀兵，有时藉着瘟疫；所以我认为他在此包括了耶和华击打他百姓的各样刑罚。若我们有时觉得这些刑罚过于严厉苛刻，就当思想我们的罪何等可憎；因为我们必不会发现他在施行刑罚上有丝毫过度或过分严厉。

<!-- PAGE 143 -->

<span style="color:#800000">*他还不知道。*</span> 先知再次痛斥犹太人所受的那种极深的愚昧，以致他们不觉察自己所受的苦难，也不举目望天，好承认耶和华乃是施行报应者，是这一切的作者。[^f763]

<span style="color:#800000">*他也不介意。*</span> 「将一件事放在心上」就是留心而殷勤地思想；因为倘若这个念头进入我们心中，并深深铭刻在我们心版上——「神是审判者，他公义地惩罚了我们」——我们就必立刻悔改。如今全世界被如此众多的灾祸所压制，几乎没有一处能脱离神的忿怒；然而无人留意，反倒众人都凶暴悖逆地与他相争；所以我们不必希奇，当世人以顽固的悖逆抗拒他时，他就降下如此可怕的刑罚在人身上，四面倾倒他的忿怒。
