# 第五十四章

<p style="text-align:center" markdown="1"><span style="color:#000080">前往 以赛亚书 54:1-17</span></p>

**1.** <span style="color:#800000">*你要歌唱。*</span> 先知在论述了基督之死以后，理由充分地转而论到教会；这是为要使我们更深切地在自己里面体会到基督之死的价值与功效。若单就基督本身来看，我们无法在祂身上看见这功效；因此我们必须来到祂的身体，就是教会；因为基督是为教会受苦，不是为自己受苦。我们《信仰告白》[^f904]中的次序也是如此：我们先承认我们信基督，祂为我们受苦、被钉十字架，随后便加上我们信教会，[^f905]因教会仿佛是从祂的肋旁流出来的。所以，先知在论述了基督的受死、复活与得胜之后，便恰当地下到教会，因教会绝不可与她的元首分离，好使每一个信徒都能凭自己的经历得知：基督并非徒然受苦。倘若他没有提到这一教义，信徒便不能这样凭着教会必得复兴的希望坚固自己的心。这一庆贺清楚表明：当基督以胜过死亡的得胜者身分显现时，祂不仅是为自己一人得胜，而且要同时将生命吹入祂的身体之中。

<span style="color:#800000">*你这不怀孕、未生养的。*</span>他称教会为「不怀孕的」，因为只要她还在可悲的奴役之下呻吟，就无从期望她有任何子嗣；倘若有人按她外在的境况来判断她，必会断定她已濒于灭亡。而且，除了外在的凄惨之外，她里面也毫无纯洁可言；一切都被迷信所败坏污染，因为他们已堕落到外邦人拜偶像的仪式中去了。

<span style="color:#800000">*寡妇的儿女。*</span>他不仅称教会为「不怀孕的」，更称她为「寡妇」，虽然这两者中任何一样都足以断绝生育子嗣的希望；但当这两样叠加在一起时，除了可悲的灭亡之外，还能期待什么呢？然而，面对这样重重相加的苦难，他却吩咐她要放胆壮胆，因为她的儿女要比有丈夫的更多。

<!-- PAGE 403 -->

这段经文可以有两种解释：或是将教会与如「有丈夫的妇人」一般兴盛的外邦人相比，或是与教会被掳之前的境况相比。这两种意思都完全说得通，但我宁愿采取较为简明的看法；因为我不认为这是教会两种境况之间的比较，而认为这是先知所用的一种通常的表达方式，为要指出教会这种非凡的多产将与通常所发生的情形相违，使人不至于按自然的常轨来判断她的境况；因为神的作为将是非凡而奇妙的。不过我也承认，她当时确是处于孀居之中；因为神早已藉着他的仆人给了她休书，并且实在藉着把那国赶入被掳之地而与她离绝了。但先知宣告说，这刑罚只是暂时的，我们随即会更清楚地看到这一点。

**2.** <span style="color:#800000">*要放大你帐棚之地。*</span>他继续以别的隐喻推进他的论证，并应许耶和华不但要复兴他的教会，更要赐给她远为卓越的境况。有人以为本段是把教会与会堂相比，我认为他们是错了，他们只不过增加了犹太人的顽梗，因为犹太人看出先知的意思被曲解了。我固然承认这些事与基督的国有关，且在福音开始被传扬之时终得应验；但由此并不能推论说，先知没有同时注目于基督降临之前的那段时期。

<!-- PAGE 404 -->
这预言在古列的时代开始应验，他准许百姓自由归回，其后延伸至基督，在他身上得着完满的成就。所以，当百姓返回本国之时，教会就怀了胎；因为那要生出基督的百姓之全体已被聚集起来，为要使对神纯正的敬拜与真宗教再度复兴。诚然，直到那时这生育之能还看不见；因为所怀的胎仿佛还隐藏在母腹之中，外面全无迹象可见；但其后百姓增多，而在生产之后，教会便从婴孩长成人，直到福音被传扬。这才是教会真正的青年期；接下来是成年期，直到基督最后的降临，那时万事都要完全成就。

若我们愿意明白先知真正的意思，这一切就必须合起来看。撒迦利亚（撒迦利亚书 2:5）、玛拉基（玛拉基书 4:2）和哈该也是这样，当他们看见建殿的工程进展甚微时，就用将来境况的盼望鼓励百姓；因为他们应许说：「这殿后来的荣耀必大过先前的荣耀。」（哈该书 2:9）这荣耀丝毫看不见，因此他们把那些应许延伸到基督；百姓必须因对他的盼望和信靠而受激励去建殿。所以，这安慰是活在律法之下的犹太人与我们所共有的，只是我们在基督里更清楚地看见教会的这一复兴。

<span style="color:#800000">*你帐幕的幔子。*</span>这个比喻取自帐棚，那地方的人广泛使用帐棚。教会被比作帐棚，因为它在世上没有稳固的建筑；由于种种变迁，它必须从一处迁往另一处，故此显得漂流不定、居无定所。但我仍深信，先知心中所想的是从前那次拯救（正如我们所说，这是众先知惯常的作法）：那时以色列人被领过旷野，四十年之久住在帐棚里；为此缘故，他们照神的吩咐每年守一次公共的节期。（利未记 23:39-43）

或有人反对说，藉圣道的仆人所建立的建筑是何等坚固，不应当被比作「帐棚」。但我回答说，「帐棚」这个比喻所指的，乃是教会的外在光景，而非它属灵的、（可以称之为）内在的景况；因为教会真正的建筑无非就是神的国，而神的国并非易朽的，也不像帐棚。然而教会仍不免从一处被迁到另一处，因为它没有安定或永久的居所。总而言之，它坚固稳当，甚至胜过防守最严密的城堡；因为它倚靠神那不能被战胜的能力，藐视一切危险。另一方面，它又像「帐棚」，因为地上的财富、军力和强盛并不是它的支柱。

<!-- PAGE 405 -->

**3.** <span style="color:#800000">*因为你要增多。*</span>如今接着说明，他为何吩咐要放长绳子以扩张帐棚。理由就是：狭小的地方容不下众多的百姓，就是主要从四方聚集归一的百姓。而因为犹大地满目疮痍、荒凉可怖，所以他说，那些被撇弃的城邑必有人居住。

**4.** <span style="color:#800000">*不要惧怕！因你必不致蒙羞。*</span> 先知在此如同先前一样，坚固信徒的心，并向全教会说话；因为那灾难是普遍的，教会看来已全然倾覆。他吩咐她欢欣，随即陈明理由：她诸般患难的结局必是她"必不致蒙羞"；仿佛他说："虽然你暂时困苦，你的境况终必兴盛。"正如别处所说："等候你的必不羞愧。"（诗篇 25:3）

<span style="color:#800000">*也不要抱愧；*</span>意即"要存美好的指望，要笃定信靠。"那些"抱愧"的人乃是蒙羞的人，他们的指望既落空，就任凭自己的心沉沦丧胆。他随即陈明同样的理由，"因你必不致受羞辱。"我认为此处如同先前一样，<span style="color:#008080">כי</span>（*ki*）意为*因为*；因此同一句话以不同的措辞重复了两次，只是前一句或许关乎内心的情态，后一句关乎外在的缘由。但两句更浅白的意思乃是：这是一个关于成功与兴盛的应许，仿佛他说那灾难必要终结。

<span style="color:#800000">*你必忘记幼年的羞愧。*</span> 这是对前一句的印证。他所指的是教会尚在幼年时所遭遇的诸般灾难，而这些灾难的记念，必被她此后所享的兴盛全然涂抹。我们稍前曾提及，*寡居*一词是就她而言的，因为神曾离弃她，可以说是与她离绝了。

<!-- PAGE 406 -->
**5.** <span style="color:#800000">*因为造你的是你的丈夫。*</span> 他在此说明她必忘记从前所受的一切困苦与灾祸的缘由，就是神必重新悦纳她；因为被掳可称为一种休离，正如我们从前所见的（以赛亚书 1:1）。他现今说：「那创造你的，必作你的丈夫」；原文的意思正是如此。他称自己为祂教会的「造作者」，不仅因为祂创造了教会如同创造其他人一样，更因为祂屈尊俯就，收纳她作自己的产业；这特权可视为一种新的生命。虽然犹太人从他们的尊荣中堕落了，因为人若不被大能的圣灵更新，就极易背道，[^f906] 然而他们属灵的受造却未全然熄灭，因为约的记念仍存留，故此神也重新创造了他们。

<span style="color:#800000">*祂的名是万军之耶和华。*</span> 这是指着祂的能力说的，好叫我们既是祂的儿女，就得以此夸口；因为神的能力越大，祂的名越尊荣，我们的夸耀也就越大——只要我们确是祂的儿女，并非夸耀一个空洞的名号。如今，先知高举神这样的恩慈，就是祂屈尊俯就，以我们代替妻子的地位，使我们能以祂的权能与力量夸口。

<span style="color:#800000">*你的救赎主。*</span> 祂称自己为「救赎主」，为要更充分地坚固百姓存这盼望：虽然先前的拯救看似已被取消，因为百姓再度被掳，然而他们必要如此蒙复兴，以致晓得神的恩典并非徒然无效。

<span style="color:#800000">*必称为。*</span>动词 <span style="color:#008080">יקרא</span> *(yikkare)*「必称为」，可指「救赎主」这名号，也可指「圣者」这名号，或兼指二者。我乐意将二者如此联结起来：「以色列的圣者必称为你的救赎主，也称为全地的神。」 [^f907] 他之所以用「全地」这说法，是因为神的名从前在某种意义上局限于犹大，但借着福音的宣讲，外邦人已被召来同得这救恩的指望。（诗篇 76:2）主既是「犹太人的神」，也是「外邦人的神」（罗马书 3:29）；因为外邦人从前虽然「远离」（以弗所书 2:13），如今已在他的治权之下与犹太人联合为一。

<!-- PAGE 407 -->
**6.** <span style="color:#800000">*因为你曾如被丢弃的妇人。*</span>他在此回应信徒在如此惨痛的灾祸中心里可能生出的疑虑。看来主似已弃绝他们，以致他们除了灭亡再无可期待的。因此先知提醒他们：不可因这样被丢弃就绝望；因为神照他的怜悯已预备好与人和好，甚至愿意使他们从死里复活。 [^f908]

<span style="color:#800000">*且是幼年所娶的妻。*</span>他用这说法，是要借这比喻更充分地坚固他们心中的那份指望；因为年轻丈夫的心比年长丈夫的心更容易与妻子和好，乃是被青春年岁与柔情爱意所吸引，甚至可说是所催逼。他照样表明，神必轻易地与人和好。「诚然，你曾被离弃；但这离弃不会长久。主必显明自己乐意与你和好，甚至主动率先邀你来与他和好。」

**7.** <span style="color:#800000">*我离弃你不过片时。*</span>先知更充分地解释了前面的话，并指明这离弃究竟是怎样的性质，就是：她必迅速被恢复到先前的境况。他高举神的怜悯，并减轻那可能压伤信徒心灵的忧愁。对信徒而言，仅仅盼望某种复兴是不够的，除非他们确信神的忿怒只是短暂的。倘若主不临近，倘若他不速速向我们伸手，我们便会迅速丧胆昏倒。为此，以赛亚在论及教会的复兴之后，又补充说这离弃只持续「片时」，而<span style="color:#800000">*他的怜悯却是永远的*</span>。

<!-- PAGE 408 -->
当他说他*离弃*了他的百姓时，这可算是一种对事实的承认。[^f910] 我们既被神收纳为儿女，就不能因人的不忠而被他弃绝；因为他是信实的，必不丢弃、不离弃他的百姓。因此，先知在这里所说的，必须归于我们的感受和外在的表象，因为当我们察觉不到他的同在与保护时，我们就好像被神弃绝了。我们确实有必要如此感受神的忿怒——正如一个被丈夫离弃的妻子哀叹自己的处境一样——以致我们知道自己受管教是理所应当的。但我们也必须体会他的怜悯；既然那怜悯是无限而永恒的，我们就会发现一切苦难与之相比都是轻省而短暂的。所以，每当我们被患难压迫时，就当投奔于这安慰。同时也当注意，这话就全体百姓而言实在是真的，他们因自己的罪恶被离弃了；虽然神并非不加区别地把他们全体都收纳在他的恩宠中，而只收纳那蒙拣选的余民，然而他这样发言，仿佛是对同一批人说的，其中并无任何荒谬或不当之处。[^f911]

**8.** <span style="color:#800000">*我的怒气涨溢。*</span>他再次重复并强调这句话，为要将它更深地印在信徒心里，使他们不至因患难而灰心丧志；这是有充分理由的，因为在那可怕的黑暗之中，被掳的人不容易看见神的笑脸。虽然此处所说「怒气」只存留「片时」[^f912] 的字面意思，是指神在适当的时候将被掳的人带回本土，然而我们从中可以引出一个普遍的教义：当我们举目仰望教会永恒的福乐时，教会的苦难总是片时的。我们当记得保罗所教导我们的（哥林多后书 4:17），信徒一切的苦难都是至轻至暂、容易忍受的，当他们注目于那「极重无比永远的荣耀」时，这些苦难理当被看作片时的；因为我们若不留意这个对比，一日在我们看来就如一年。若不是与神恩典那不间断的进程相对照，把犹太人七十年的被掳称为「片时」，就毫不恰当了。

**9.** <span style="color:#800000">*这事在我好像挪亚的洪水，*</span>或译作，*如挪亚的日子。*这一段有两种读法；若读作 <span style="color:#008080">כי מי</span> *(ki me)*，则 <span style="color:#008080">כי</span> *(ki)* 当译为*因为*；若读作 <span style="color:#008080">כימי</span> *(kime)*，则 <span style="color:#008080">כ</span> *(caph)* 当译为*如*，而 <span style="color:#008080">ימי</span> *(yeme)* 当译为*日子*。[^f913] 就总的意思而言，二者相差无几；因此我们主要应当思想先知的原意，因为在我看来，解经者们并未领会他的意思。他们一般解释说，主曾向挪亚起誓应许，永不再有洪水，而这誓言必永远有效。（创世记 9:10）不然的话，这位善人或许会战兢，一见雨来就惧怕类似的灾祸临到，若非主起誓说这事必不再有。照样，当患难临近时，我们也会惧怕自己将要灭亡，若非主应许教会必得保全。

<!-- PAGE 409 -->

但我认为，这应当限定于巴比伦被掳的时期。他把那次被掳比作洪水，因为洪水毁灭了地面；当时教会看起来似乎已彻底倾覆。这百姓几乎全数迁到了另一个国度，既没有自己的国度，也没有自己的政权；他们受着极其艰苦的奴役，以为自己的名号已被完全抹去。那时，先知从前所宣告的话确实应验了，

<p style="text-align:center" markdown="1"><span style="color:#000080">「若不是万军之耶和华给我们稍留余种，我们早已像</span><span style="color:#000080">所多玛、蛾摩拉的样子了。」（</span><span style="color:#000080">以赛亚书 1:9</span><span style="color:#000080">）</span></p>

因此，他把那场灾祸比作「挪亚的洪水」，即那次大洪水，实在是恰当的；正因如此，我宁可赞同那些读作 <span style="color:#008080">כי מי</span> *(ki me)*，即「因为水」的人；因为我认为这种读法比另一种读法有更充分的根据，并且犹太作者也普遍采用它。

<span style="color:#800000">*这事在我好像挪亚的洪水。*</span> 我认为，我们应当仔细查考这些话的意思，因为解经家对此略略带过。他的意思是，这场灾祸将与那洪水相似；正如他既以一次洪水为满足，绝不再降下另一次，照样，他也以教会这一次的毁灭（姑且这样说）为满足，绝不再容许教会的面貌被毁坏。所以我认为，我们应当这样解释这段经文并应用这个比喻：犹大的荒凉在神看来，就如「挪亚的日子」所发生的洪水一样；因为正如他那时起誓，此后绝不再因那使全地失去居民的罪恶而施行这样的刑罚，照样，他也不会再像在巴比伦被掳时那样毁灭他的教会。的确，无论此后局势何等纷乱，教会仍保有某种名分，仍存留某种形态，直到基督在肉身中显现之时，福音的种子撒遍各处，好从万民中为神生养儿女。总而言之，主应许说，从今以后他必抑制他的忿怒，不再以如此严厉的刑罚责罚他的子民。

有人会反驳说，自那时以后教会曾遭受极其惨重的灾祸；由此可以推论，或是这誓言未曾应验，或是这并非先知的原意。我回答说：<!-- PAGE 410 -->教会所遭受的灾祸，从未惨重到面目全然被毁的地步，如百姓被掳到巴比伦之时那样。因为虽然安提阿古和其他暴君给教会带来了可怕的灾祸，虽然后来又发生了保罗所预言的那些背道之事（帖撒罗尼迦后书 2:3；提摩太前书 4:1），一切都被无数的迷信所污染，以致基督的名几乎被埋葬；然而仍旧存留着教会的某种形状，尽管已被毁容；那建筑也未曾败坏到这样的地步，以致在洪水之上竟无基督教的一些余存——如此，这誓言便是完全有效的。

<span style="color:#800000">*我也不再向你发怒。*</span>这话不可按绝对的意思领会，而当按相对的意思领会。他将这一句与前一句相对照；因为他应许说，他惩治他百姓，绝不会严厉到不减轻刑罚的严酷。所以，虽然暴君们任意放肆、狂怒无度，撒但竭尽全力攻击教会，主也放松缰绳，为要惩罚我们的忘恩负义，然而他绝不容许教会被毁灭。

**10.** <span style="color:#800000">*大山可以挪开。*</span>他确认前面所说的，并宣告说：全世界倾覆颠倒，也快过他的怜悯止息。在此若追问“大山如何挪开，小山如何迁移”，那是徒然的；因为这比喻取自那些看来最坚固、根基最深的事物，为要显明教会的根基远为持久。“大山”极其坚固，地震在山中不像在平原上那样频繁发生；因此主宣告说，纵然那广大厚重的“大山挪开”，或天坠落，他的约却要长存，他向教会的怜悯也不止息。诗篇中就是照这意思说：“耶和华作王……世界就坚定，不得动摇。”（诗篇 93:1）在另一处甚至说：

<p style="text-align:center" markdown="1"><span style="color:#000080">「天地都要灭没，唯有神的教会必屹立</span> <span style="color:#000080">不动摇。」（</span><span class="ages-code">&lt;19A226&gt;</span><span style="color:#000080">诗篇 102:26, 28）</span></p>

<span style="color:#800000">*我的慈爱。*</span> 在「慈爱」一词中，当留意这约的根基是何性质；因为我们与神不可能有任何友谊：除非他怜悯我们，并以白白的恩典接纳我们。 [^f914]

<!-- PAGE 411 -->

<span style="color:#800000">*我平安的约。*</span> 他称之为「平安的约」，因为主将一切属于完全福乐的事物都赐给我们；正如希伯来作者也在「平安」一词之下，包含一切后裔。既然这约包含坚固而完全的福乐，那么随之而来的就是：凡被排除在此约之外的人，都是可怜的。

<span style="color:#800000">*这是耶和华怜恤你的说的。*</span> 他既说是他"怜恤"她，就再次确证了先前所说的：他必不以别的方式、也不为别的缘故与人和好，惟因他有怜悯、乐意赦免。

**11.** <span style="color:#800000">*你这困苦的。*</span> 他继续同一个主题，不但应许教会必复归昔日的荣美，更应许神必使她佩戴更为华贵的装饰，仿佛全是宝石所造成的。这一切，哈该用一句话就表明了，他说：

<p style="text-align:center" markdown="1"><span style="color:#000080">"这殿后来的荣耀必大过</span> <span style="color:#000080">先前的荣耀。"（</span><span style="color:#000080">哈该书 2:10）</span></p>

至于先知在此所描述的宝石名称[^f915]，就连希伯来文的作者们也彼此不一致，只要我们明白这段经文的意思，就无须为此多费心力。

这诚挚的话语极其适于安慰信徒的忧伤；因为它把那本将被淹没的教会，描绘为如今已被祂从沉船之难中救出。因此，每当我们看见她被风暴猛烈摇动，被重重患难所压，且被夺去一切安慰之时，就当记念：正是这样的处境促使神施行帮助。

**12.** <span style="color:#800000">*我又要以红宝石造你的女墙。*</span> 他用这些隐喻表明，如前所述，教会的境况将远胜于以往任何时候。教会被比作一座建筑，这在圣经各处都是常见的（耶利米书 24:6；马太福音 16:18）。因此他现在描绘出一座华贵宏伟的建筑。但当注意的是，先知乃是把神描写为这建筑的工程师；因为这工作当完全单单归于祂。

<!-- PAGE 412 -->

但或许有人要问，先知所说的「红宝石、蓝宝石、珍珠」以及其他各类宝石是何意；因为保罗也曾用相似的隐喻来指教义。他说：「我照着神所给我的恩，好像一个聪明的工头，立好了根基。」又说：

<p style="text-align:center" markdown="1"><span style="color:#000080">「若有人用金、银、宝石、草木、禾楷在这根基上建造，</span> <span style="color:#000080">各人的工程必然显露。」</span> <span style="color:#000080">(</span><span style="color:#000080">哥林多前书 3:10-13)</span></p>

先知是否有此意，从下一节便可看明。

**13.** <span style="color:#800000">*你的儿女。*</span> 我认为这里的连接词 <span style="color:#008080">ו</span> *(vau，)*「和」，如同在许多别处经文中一样，是表示*因为*；由此我们便可以轻易断定，以赛亚在此所说的不是教义，而是人，教会这属灵的建筑正是由人所建成的。诚然，教会是藉着教义被建立的；但这建造乃是藉着将人聚集起来，使他们归于顺服神的状态而成就的。那么，保罗与以赛亚的区别在于：保罗使那些「宝石」与教义相关，而以赛亚使它们与圣灵所赐给人的恩赐相关，为要教会由这些人建成。我们应当留意主装饰其教会所用的各种不同恩赐；因为并非人人都是「绿宝石」，也并非人人都是「红宝石」，主乃是按自己的美意分派各人的地位。（以弗所书 4:11）

<!-- PAGE 413 -->
<span style="color:#800000">*受耶和华的教训。*</span> 值得注意的是，凡属于教会装饰之物，无不出于神的恩典这唯一的源头；因为倘若我们成为「红宝石」和「蓝宝石」是由于受了主的教训，那么这就不是出于本性。如今主教导我们有两种方式：藉着外在的宣讲，以及藉着圣灵隐秘的启示。先知所指的是哪一种教导，基督在引用这段经文时已作了解释；因此我们不当另寻更好的解释者。他说：「先知书上写着说：『他们都要蒙神的教训。』凡听见父之教训又学习的，就到我这里来。」（约翰福音 6:45）倘若这段经文当理解为关乎外在的宣讲，那么基督由此所作的结论便没有稳固的根据；因为不能推论说：「福音既被传讲，所以众人都信。」许多人抗拒，另有些人公然嗤笑，还有些人是假冒为善的。惟有那些「预定得永生的人」（使徒行传 13:48）才真诚地可教，才配被列在门徒之中。福音是不加区别地向选民与被弃者宣讲的；但惟有选民到基督那里来，因为他们「蒙了神的教训」，因此先知无疑是指着他们说的。

这就清楚显明，我们是怎样成为建造神殿的活石和宝石的。乃是当主藉着他的灵塑造并琢磨了我们，并在外在的道之宣讲上加添了圣灵内在的功效。由此我们得知人心的败坏何等之大，若非主用他圣灵的能力与功效来推动它，它就不能被扭转、被重新塑造。以赛亚将内在与外在这两种教导方式联结起来；因为他把那些「蒙主教训的人」称为「教会的儿女」。他们既是她的儿女，就必是在她的腹中受孕、由她所哺养的，正如保罗所说，起先「用奶」，随后用干粮（哥林多前书 3:2），直到他们「长大成人，满有基督长成的身量」（以弗所书 4:13）。

因此，我们若愿作门徒，圣道的外在施行乃是必需的；这就显明那些狂热派的极度疯狂，他们滥用这段经文，为要推翻圣道的宣讲和教会所享有的职事。因为他们若不肯让自己在教会里受教，就不能作教会的「儿女」。他们夸耀隐秘的启示，必是徒然；因为圣灵只教导那些顺服教会职事的人，所以那些弃绝神所设立之秩序的人，乃是魔鬼的门徒，而非神的门徒。我们看见，「教会的儿女」与「受教于神」这两件事如此紧密相连，以致凡拒绝在教会中受教的人，就不能作神的门徒。同样，这两者也当适当地加以分辨，正如以赛亚所分辨的那样，免得我们把当归于圣灵功效的事归给人；但与此同时，二者又当彼此联合，好使我们知道，神在这事上乐意使用人的服事。

<!-- PAGE 414 -->
此外，这段经文教导我们：神的呼召在选民身上是有功效的。奥古斯丁明智地考察了这段经文，并巧妙地用它来驳斥伯拉纠派——他们高举人的自由意志，与神的恩典相对抗。他们表面上似乎也把某些事归于神的恩典，但其方式却是：当他们提出恩典时，却把它置于人的自由意志之下；正如今日的教皇派一样，他们断言任何人都能随意接受或拒绝恩典。「但是」（奥古斯丁说）「他们都要蒙神的教训。神的门徒既被有功效地教导，就必跟随他的呼召。」他又加上我们所引用的约翰福音那段经文。这就清楚显明，这并非出于人所作的、可以左右摇摆的自由抉择。

从这些话也当留意，主何等看重他的教义，藉着这教义他把我们纳入他的建筑之中，使我们成为「珍珠、蓝宝石和红宝石」；因为那些弃绝圣道的教义而想建造教会的人，所建的乃是猪圈，而不是神的教会。我们也看见，对于教皇派所吠叫的「隐含的信心」（implicit faith），我们当持怎样的看法；他们要人成为愚昧人，好任凭自己被欺哄。既然我们必须受教于神，我们就不应当像畜类一样，这是理所当然的。

或许有人要问：难道众先知、列祖，以及律法之下的其他信徒，不是神所教导的吗？他们无疑是神所教导的；但先知在此是以比较的方式说话，因为在基督里有更丰盛的启示，主已如此明明白白地说话，以致公开彰显出祂乃是教会的教师，并且也招聚了众多门徒。这段经文与先知耶利米书中的一处经文相合。

<p style="text-align:center" markdown="1"><span style="color:#000080">「他们各人不再教导自己的邻舍和自己的弟兄说：『你该认识耶和华』，因为</span> <span style="color:#000080">他们从最小的到至大的都必认识我。这是耶和华说的。」（</span><span style="color:#000080">耶利米书 31:34）</span></p>

因此，若在古时神的众儿女都必须作圣灵的门徒，那么在今日就更当如此了，因为这预言严格说来是关乎基督的国度的。

<!-- PAGE 415 -->
<span style="color:#800000">*大有平安。*</span>他用「平安」一词表示福乐，即一切的兴盛。由此我们可以推知，人真正的福乐是什么。那就是：当神光照我们的悟性，使我们领受在基督里向我们所显明的救恩；因为只要我们缺少这知识，我们就离福乐无比遥远；因为连神的赐福，若未被信心分别为圣，也都变成我们的咒诅。

**14.** <span style="color:#800000">*你必因公义得坚立。*</span>他的意思是，神必作他教会的建造者与设计者。我知道有些人作别样的解释，认为「公义」是指「善行」。这解释确有几分说得过去，因为先知先前谈到教训；而我们受教正是为此目的，就是叫我们过敬虔圣洁的生活。但先知的意思却不同，乃是说：教会必在神的引导之下得以复兴，因为神愿作她的守护者与保卫者。他将「公义」与那推倒教会的暴力和欺压相对；或者至少他所表达的是「稳固」，仿佛说：这将不是一座脆弱的建筑，也不是那种只凭外表的虚假在短时间内欺骗人的建筑；因为神必真诚地保卫他自己的工作，并且既是「公义的」，他就不仅要将它完全复兴，而且此后要长久地保守它安然无恙。因此，虽然人千方百计结盟要毁灭教会，他们却一无所得；因为主用他的「公义」护卫她。我们从前 [^f916] 已见过这种表达方式；因此我认为我所给出的解释更为简明，纵然有些人以为另一种解释更为说得过去。

**15.** <span style="color:#800000">*看哪，他们必聚集。*</span>总意是：虽然许多人兴起要压倒教会，然而他们一切的图谋与攻击都必失败；他似乎不仅应许神必帮助抵挡外来的仇敌，也必帮助抵挡家内的、内部的仇敌。有许多人在教会的怀中「聚集」，好像愿意与她联合，其后却挑起内战。这些话通常译作「他们必聚集攻击你」，一般也被理解为指教会各类的一切仇敌。那种解释最为众人所赞同；我也不反对，只要承认其中包括那攻击教会所用的诡诈、埋伏与背信。然而我毫不怀疑，此处的意思与诗篇 2:1 相同，即<!-- PAGE 416 -->外邦人聚集反抗基督和神的教会，图谋作乱；因为兴起攻击她的，不只是一国，而是列国。

然而，这里他很可能是特意将内部的仇敌与那些从外面侵入、甚至深入她怀中的仇敌并列在一起；因为他说<span style="color:#800000">*在你中间，攻击你*</span>，就是说：「他们必在你里面、在你中间攻击你。」总之，他表明教会不会享有那样的平安，以至无人前来攻击。但也许有人认为这些话彼此矛盾；因为他先前说她必远离惊恐与欺压，如今却说在她怀中必有阴谋。我回答说，先知立刻补上这句话，是为叫信徒不要以为自己在世上可以指望一种平安的状态，仿佛不必再受恶人与假冒为善之人的搅扰。教会得蒙保护、免受欺压与谗谤，其方式并不是使她免于与仇敌争战不息；因为撒但每日都要兴起新的攻击来对付她，以致她永不得安逸。因此这些话可视为对前面所说的一种补正，好使信徒常常佩带争战的兵器，不要指望安枕无忧。

<span style="color:#800000">*不由于我。*</span>此处加上一个应许：耶和华仍必在危难之中保守他们。「不由于神」意即「徒然」或「不能成功」；因为他的意思是，恶人的攻击，纵然他们竭尽全力 [^f917]，也必完全失败。他们凭着盲目的狂怒向前冲杀，然而赐下顺利成功的，唯有耶和华的手。他在此暗指先前所说的话（以赛亚书 41:25），即巴比伦人必在神的引导之下前来毁灭犹大。那时百姓遭了倾覆，因为神与他们为敌；但如今，因为仇敌攻击她乃是「不由于神」，就是没有他的引导，他们必蒙羞而退。这一点在紧接着的话中说得更为明白——

<!-- PAGE 417 -->
<span style="color:#800000">*凡聚集攻击你的，必因你跌倒。*</span>意思是：「凡他所图谋攻击你的，都必归到他自己的头上。纵然全世界都起来攻击你，它也必被自己的重量压碎。」「在你中间」这句话值得留意；因为当耶和华把我们的仇敌赶得远离时，我们便有信心，但他们若临近我们，我们就陷入绝望。所以他说：「他们纵然深入你的腹中，耶和华也必灭绝他们，并且拯救你。」

**16.** <span style="color:#800000">*看哪，是我创造匠人。*</span>耶和华在此表明，他何等轻易、何等迅速地拯救他的教会脱离恶人卑劣的攻击；因为除了耶和华所许可的，他们什么都不能作，尽管他用他们作管教他百姓的器具。此外，这话既可适切地看作指巴比伦人，也可看作指后来苦害那被拣选之民的其他仇敌。若采前一种意思，神便是要证明：他能轻而易举地赶走那些他曾引来攻击他们的人，能拆毁那些他曾兴起的人。若认为是指安提阿古及其同类之人，意思也相差不多；就是说，他们同样不得被容许伤害他们，因为若非神的指示，他们连一根指头都不能动。

但也许有人会认为先知自相矛盾；因为在前一节他说恶人攻击教会是「非我所使」（without the Lord），如今却说他们是以神为元帥而争战，是在他的引导与指挥之下施行毁坏与灭绝。我回答说，我们必须留意其中的对比；就是耶和华曾兴起巴比伦人来毁灭教会。我们要注意「洪水」这一比喻，他借此表明彻底的灭绝；因为在那时候，教会可说是被水淹没了，而神就以巴比伦人为他成就此事的执行者。但他郑重宣告：此后他决意约束自己的忿怒，以致虽然他亲手管教教会，却绝不容许教会被仇敌毁灭。教会的仇敌所瞄准的目标，也是他们竭尽全力要成就的事，就是败坏并毁灭教会；然而耶和华约束他们的攻击，因为「非我所使」，即没有他的命令，他们就一无所成。有些人解释说，其意乃是「匠人为他自己的工作而被造」，即是说，他被造是要成就他自己的毁灭，那毁灭者被造是要毁灭他自己。但前一种意思在我看来更为浅白直接。

<!-- PAGE 418 -->
<span style="color:#800000">*又造毁灭的人。*</span>当耶和华说他「造毁灭的人」时，这并非仅仅指人生来所有的本性，而是指「毁灭」这一行动本身。然而我们却不可因此归咎于神，仿佛他是那唯独存在于人里面的不义残暴的作者；因为神并不认可他们邪恶的倾向，而是以他隐秘的护理管制他们的作为，并使用他们作他忿怒的器具。但这题目我们已在解释其他经文时讨论过了。

**17.** <span style="color:#800000">*凡为攻击你造成的器械。*</span>他再次推论出前面已经说过的道理：恶人纵然竭尽全力，也必一无所得；因为他们的攻击乃是被神隐秘的旨意所引导、所约束。他用了「凡」这个字，意思是说，恶人虽有种种手段去尝试许多不同的方法来毁灭教会，然而他们一切的努力都必徒然无果， [^f918] 因为耶和华必拦阻他们。的确，天意在相当程度上容许他们放手而行，为要试验信徒的忍耐；但当神认为合适的时候，他就剥去他们的力量与军装。

<span style="color:#800000">*凡在你兴起用舌攻击你的。*</span>他既已论到恶人攻击教会所用的「器械」，便特特提到「舌头」；因为再没有别的「兵器」像它这样致命而毁灭性。他们不但辱骂、诽谤、污蔑神的仆人，而且尽其所能地要熄灭神的真理，使人的心背离真理；这比夺去我们百次的性命更当使我们痛心。此外，善良正直的人发觉诽谤比任何肉身的打击更令人苦恼，所带来的痛苦更为剧烈；因此，提到这致命的「兵器」是极有理由的。

<!-- PAGE 419 -->
<span style="color:#800000">*在你兴起用舌攻击你的，你必使他显为有罪（原文作「在审判中兴起攻击你的」）。*</span>他说舌头「在审判中兴起」，意思是恶人如此胆大妄为、蛮横无礼，竟公然攻击并搅扰神的儿女。他又加上说这是「在审判中」行的；因为他们提出貌似合理的借口，使自己显得有正当的理由。照样，教皇党人称我们为异端、分裂教会者、狗类时，也仿佛是「在审判中」控告我们，并愿被人看作大公真理的捍卫者，尽管他们所维护的是虚谬与偶像崇拜。然而他们用来掩盖诽谤的借口如此貌似合理，以致在那些不明白我们缘由的人中间，激起对我们极强烈的憎恨。但他们虽用刀剑、用「舌头」、用各样的「器械」攻击我们，我们却当倚靠这个预言，盼望自己必得胜；因为这里已将胜利应许给我们，既然我们对此确信无疑，就当奋勇争战，心志毫不动摇。

<span style="color:#800000">*这是……的产业。*</span>他表明，主已将此赐给信徒，仿佛是凭着「产业」的权利，使他们永不被夺去；因为正如没有什么名分比承受产业者的名分更确实，照样，他表明主的仆人们最当确信的，莫过于祂那不断的看守与保守，藉此祂护卫他们脱离一切危险。

<span style="color:#800000">*他们的义……是从我而得。*</span>此处「义」所指的，正是我们日常用语（*Leur droit*，「他们的权利」）所表达的意思。总之，他的意思是：主必护卫祂的百姓，以保全他们的无辜。所以，每当我们受人攻击、遭人损害时，就当学习立刻投奔于主；因为当我们寻求别的援助时，其结果便是我们被剥夺了祂的看守与保护。
