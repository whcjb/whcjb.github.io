# 第六十二章

<p style="text-align:center" markdown="1"><span style="color:#000080">前往 以赛亚书 62:1-12</span></p>

**1.** <span style="color:#800000">*我因锡安必不静默。*</span>那可悲的被掳既已临近，几乎要涂抹整个民族的名号，因此就必须用许多话来坚固并激励信徒，使他们在十字架的重担之下，能以刚强笃定的信心依靠这些应许。所以先知在此履行所受托付的职分，公开宣告他必不懈怠于本分，也不停止说话，直到他以将来得救的指望鼓舞信徒的心，使他们知道并深信神必作他教会的拯救者。他自己本也可能因那民的不信而沮丧，眼见事情日益败坏，又预见那可怕的报应，便可能失了勇气。然而，纵有如此重大的艰难，他仍要坚守本分，使众人知道：无论那民遭屠戮，或是他们的不信，都不能阻止神在适当的时候成就他的应许。

<span style="color:#800000">*为耶路撒冷的缘故，我必不静默。*</span>这些话有必要反复重申，因为我们心思如此败坏，极容易忘记神的应许。当他说他必不停止说话时，他同时也在提醒众人各尽其分，叫他们壮胆，以确定的信心期待自己的复兴，纵然这复兴迟延甚久；甚至叫他们孜孜不倦的专注，能与那不断向他们说话的神的声音相称。我们每日凭经验都晓得这是何等必要，因为撒但正竭尽一切方法要使我们偏离正路。

同时，他也指明敬虔教师所当有的目标，就是为教会的益处完全耗尽并奉献自己；因为当他说「为锡安的缘故」时，他的意思是：我们首要的关切当是教会得蒙保守；惟有那些如此珍视教会的救恩、以致不惜任何劳苦的人，才是良善忠信的教师。有些人把这话解作与祷告有关，但我宁愿把它归于教导；把它理解为 <!-- PAGE 557 --> 没有任何不便或烦扰能磨尽他的忍耐，也没有任何敌挡能阻延他继续执行神所吩咐他关乎教会救赎的教导职分，这更为自然。因为倘若他曾在那极其惨痛的灾祸之后仍存活，那不信的众人无疑会像对待其他先知一样，以许多辱骂迫害他；然而无论遭遇什么，他都说自己已被不可动摇的坚定所坚固，绝不因羞辱而缄默，反要以不懈的热切在他的路程上前行。此外，他借这种说法为自己的预言取得凭信，并维持其权威，以致即使他死了，这些预言仍不停在信徒耳中回响。

<span style="color:#800000">*直到她的公义如光辉发出。*</span>他以「公义」指教会的权利；因为在灾祸的时期，她显得像是被定了罪。因此，当她完全得着复兴、重获昔日的境况时，她的「公义」就「发出」了；因为在被掳期间，那公义原是隐藏不显的。

<span style="color:#800000">*她的救恩。*</span> 他在「义」之后又加上「救恩」，因为凡神所称为义的，或神向其恢复其权益的，也必同样重得他们的「救恩」。由此我们可以推论：只要神因我们的罪而向我们收回祂的恩典，我们便是可怜的、毫无援助的；因此在别处经文中，祂常将此处所称为教会之义的，称为「神的义」。故此，当我们缺乏神的义时，我们就是败亡的；就是说，当我们沉睡在自己的罪中，而神藉着为这些罪惩罚我们，显明祂是严厉的审判者时，我们就是败亡的。

「发出」一语意味着教会的义曾一度被隐藏，仿佛被埋葬了：她在神眼中不配得任何恩眷；相反地，她那说不尽的罪孽如此猖狂，以致除了神公义的报应之外，别无所存。但在此处，先知的眼目乃是注视那些已经视受苦的教会为已丧亡之人，他们以自己的骄傲与辱骂几乎把她抛落阴间。

<!-- PAGE 558 -->
<span style="color:#800000">*如明灯发光。*</span> 最后，他将她与世界相比，说：当神除净她的罪、担起她的案件时，她在世人面前必显为义。先知藉这些话教导我们：即使教会陷于幽暗深处、置身坟墓之中，我们仍当常存美好的指望，盼望她得复兴；因为她虽一时被淹没、被隐藏，却在天上有神作她的报仇者，祂在适度地管教她之后，终必显明她一直是祂眷顾的对象。的确，祂的义必要辉煌而显明，而这正是为了那些祂所拣选作自己百姓和产业之人的救恩。

**2.** <span style="color:#800000">*列国必见你的公义*</span>先知在此更明白地陈述先前所说他必不静默的缘由，就是要使信徒确信，救恩应许于他们并非徒然。

<span style="color:#800000">*众王必见你的荣耀。*</span>他在此用「荣耀」一词来指「救恩」。我们从这里看见先知们必须借以坚固自己、以致能够恒忍的理据，就是：主是信实的，凡他一次所应许的，虽暂时延迟，终必成就。「众王」一词是为了加强语气；仿佛他说，不但卑微之人与最低微者要看见并惊叹神的荣耀，连「君王」自己也要如此——他们通常轻视一切在别的方面本当受尊重与敬重的事物；因为他们被自己的荣华所蒙蔽，被自己的尊位所迷狂，以致除了自己的尊位以外，不肯甘心看重任何尊位。

<!-- PAGE 559 -->
<span style="color:#800000">*你必得新名的称号。*</span>他以「新名」指「密集聚拢的会众」；因为这百姓曾如此彻底地被分散，以致没有可见的身体，看来是完全毁灭了。虽然有极多的人被掳去，但既分散在巴比伦人中间，就如一个被打碎之身体的肢体那样被驱散各处，几乎不再保有「一个民族」的名分；这也是早已向他们预言过的。他们从被掳之地被带回以后，才重新开始联合成为一个身体，于是重得那曾被夺去的「名」。然而「新」表示不寻常的事；仿佛先知说，这百姓的荣耀将是非凡的，是前所未闻的。我们知道这事是在时间的进程中成就的；因为那一小群人，当他们蒙容许住在本国之时，不可能凭任何非凡的尊荣达到如此大的声名；但到末后，当福音的教义被传扬开来，犹太人之名就为人所知、为人所称扬了。

<span style="color:#800000">*是耶和华亲口所起的。*</span>这话本来是难以相信的，但先知却藉着应许神必是这荣耀的创始者来加以确证；因为凭人的力量断不能将一个已经沉沦、满被羞辱的教会如此高举，然而对于那位「从粪堆中提拔穷乏人」（<span class="ages-code">&lt;19B307&gt;</span>诗篇 113:7）的神，以新的荣名来装饰他的教会并不是难事。四十年之久教会毫无形迹可见，虽然主仍保存了些种子，然而其境况如此混乱、如此败坏，以致看不见有神的子民；如今当他藉福音的道将教会招聚起来时，就把名号重新赐还给教会。因此，神这威严的作为当在这一点上坚固我们，使我们知道他决不离弃他的教会；虽然恶人以谗言撕裂我们，殴打我们、向我们吐唾沫，并千方百计要使我们被众人厌恶，我们却当记得，神并未丧失他在世上为我们伸冤的权柄，因他已恩待我们，将我们的名字记录在天上。

另有人以较为巧妙的方式解释这段话，即他们不再称为以色列人，而要称为基督徒。但我认为前一种解释更合乎上下文，也更合乎先知惯用的语言；我们当留心细察那些先知特有的表达方式，好使我们熟悉他们的文体。总之，这百姓虽看似已被剪除，却必得复兴，并且要得着一个新名，这名不是从人而来，乃是从神而来。

<!-- PAGE 560 -->
**3.** <span style="color:#800000">*你在耶和华的手中要作为华冠。*</span>以赛亚继续论述同一主题，这并不足为奇；因为凡凭肉体判断的人，都不可能有如此宏大的构想与期望。此外，他的意图是要将信徒的心系于基督的国度上，而用这些卓越的称号来装饰、来颂扬这国度就更显必要，因为这国度直到那时不但隐晦不明，而且相距甚远。有两重危险必须防范：一是犹太人看见自己离从前的尊荣仍极其遥远，便可能藐视神的恩典；二是他们可能满足于那些起初的果效，从而忽视基督，将全副心思专注于地上的好处。因此先知提醒他们，归回本国只不过是那崇高地位的先导，那地位是要在基督显现之时才可期待的。

就前一句而言，被掳的人与作奴仆的人一看外在的境况，除了绝望之外别无所见，因为他们归回、重返故土之后，在建造圣殿的事上进展甚微。因此，先知吩咐他们仰望神，好叫他们从神那里期待那向肉体的眼目所隐藏的荣耀；并且既知道自己在神眼中是可爱、宝贵的，就以此为满足，直等到他藉基督的手更丰盛地装饰他们。

<span style="color:#800000">*华冠。*</span>他称教会为神的冠冕，因为神愿意他的荣耀在我们身上照耀；在这事上，我们理当仰视并惊叹神那不可思议的良善，因为尽管我们按本性是污秽败坏的，比街上的泥土更为可憎，他却如此装饰我们，甚至愿意我们成为「他国度的华冠」。所以，让我们因神这样的良善被激励，渴慕过圣洁的生活，使他的形象在我们里面日益重新形成。

**4.** <span style="color:#800000">*你必不再称为撇弃的。*</span>他在此解答一个可能浮现在信徒心中的难处：他们既被撇弃、被丢弃，怎能同时被称为「华冠」与「冠冕」呢？既然他们被万民所恨恶憎厌，有时甚至伏在仇敌脚下，又看不见任何帮助，那么他们得着这些称号、被高举到天上、被安放在神的手中，似乎是可笑的事。因此先知的意思是：这百姓虽然一时如同被离弃、被撇弃的妇人，终必得着复兴，以致境况与名称都要改变；仿佛他说：「这离弃不是永久的；神终必接纳你归他自己。」照样，教会虽似「被撇弃」，有被离弃之妇人的样子，主却必终止她的苦难与愁苦。

<!-- PAGE 561 -->
<span style="color:#800000">*你必称为「我所喜悦的」*</span>。他教导说，这乃是出于「神的美意」，就是出于他白白赐下的恩眷，好使人的功德或优越毫无可夸之处；正如他在何西阿书中所说：

<p style="text-align:center" markdown="1"><span style="color:#000080">「也以慈爱和怜悯聘你归我。」</span> <span style="color:#000080">（</span><span style="color:#000080">何西阿书 2:19）</span></p>

他由此表明，他们之所以蒙福，别无他因，惟因神出于他无限的美善，甘愿俯就，将他先前所弃绝的人重新纳入恩眷之中。这话虽严格说来是指着教会说的，然而让我们从中普遍地学知：城邑与邦国得以复归昔日的光景，乃是出于神的恩眷与厚赐；而当他发怒不悦之时，这些城邑与邦国看来已然倾覆。因此，先知在此把他们所受一切灾祸的根源摆在犹大人眼前，他见证说：当神与他们和好之时，他们必然有福；因为我们可以从此推知，从前当他们的境况凄惨可怜之时，神是向他们发怒的。

<span style="color:#800000">*你的地也必称为有夫之妇。*</span>先知用这个隐喻来表明百姓的复兴，极其优美，并传达了双重的教训。他指出神与教会之间不和的状态将要终止：第一，因为她被那已息怒的丈夫重新接纳为妻；第二，因为众多的人口将除去她寡居的羞辱。地在某种意义上与其居民成婚，正如树与葡萄藤一样；反之，当地被剥夺了居民，就被称为寡妇。

<span style="color:#800000">*因为耶和华喜悦你。*</span>他再次重述并确证前面已经说过的话：教会得以复兴，得以保守其地位，地得以领受其居民，全然出于神白白的恩慈；因为当神转脸不看我们、向我们发怒时，我们所能期待的只有毁灭，从人的帮助或力量上也一无可望。

<!-- PAGE 562 -->
**5.** <span style="color:#800000">*少年人怎样娶处女。*</span>这一节所包含的，无非是对上一节的解释与确证。不过在这一点上似乎有些矛盾：在后半句中他使神成为教会唯一的丈夫，而在前半句中他却给她许多丈夫。但解答并不难；因为当论及教会这婚姻时，只有一位丈夫，就是神，他始终为自己保留这称号；这在基督身上得着应验，正如保罗所说，牧者们「把你们如同贞洁的童女，献给基督」（哥林多后书 11:2）。然而这并不妨碍以婚姻的隐喻来描述神一切的儿女与他们的母亲——教会——所共有的那信心的合一。不但如此，神作他教会的丈夫，正与他将一切聚集到她那里的列邦嫁娶给他的教会相合；因为当她没有儿女时，可以说她是寡居孤独的。所以这话即使就神而言也是如此说的，因为他以自己的引导确立了教会众肢体之间那圣洁的相爱，从而把婚姻的效力扩展到全体。

由此应当推论：神的教会唯有与她的丈夫神联合时，才真正人丁兴旺，就是有众多的儿女；因为我们必须从神开始，好叫他掌管他的教会，并在他的引领之下，我们得以被聚集到她的怀中；那时这婚姻才真正是圣洁的。然而若无此，人数众多也不能构成一间教会，反倒成为可憎的娼寮；正如我们看见教皇制中夸耀着神的名，然而神的威荣却在其中被可怕的渎圣所亵慢。

**6.** <span style="color:#800000">*在你城上。*</span>先知既有意描绘基督国度的完全福乐，就把凡属一国或一城兴盛景况的一切都汇集起来。除其他好处之外，他又加上守望者与守军；因为纵有一切美物的极大丰盛，若我们不能免受仇敌之害，也于我们无益；因此他宣告说，主不但要将一切必需之物供给教会，也要设立忠信的守望者，抵御仇敌与强盗，使他无论在内在外都被认作幸福生活的作者。

<span style="color:#800000">*昼夜不停地呼求。*</span>他以「静默」意指「安逸歇息」；仿佛说：「他们必不断守望，以致远远就能预见威胁他们的危险。」

<!-- PAGE 563 -->
<span style="color:#800000">*你们题醒耶和华的。*</span>接着他解释这些守望者是谁，就是那些「题醒耶和华」的人，也就是传扬祂名之记念的人。虽然把天使算在这些守望者之列并无不当（诗篇 91:11；希伯来书 1:14），因为我们知道这职分也交托给他们，但既然他们甘心乐意地看守教会的安全，无需劝勉来催逼，故此先知在这里是向另一些守望者说话。

他所用的那个词含义模糊。<span style="color:#800000">F1012</span>有时它意为「记念」，有时意为「使人记念」；这两种意思在此都不算不合适。但我认为他只是要说，这些守望者将作神的仆人，来传扬祂的名。有人译作「使人认识耶和华」，但这样译并不自然，且突然截断了先知的思路；这类注释者没有留意先知在此所用的、关乎城的守望者的类比。

虽然先知的用意只是教导我们：教会必在一切危险中得保安全，因为有神看守她的安全；然而我们总当思量基督国度的性质如何，因为它不是靠战争的兵器或武力来护卫的，它既是属灵的，就受属灵的兵器与守望者的保护。因此，主必有祂的仆人，祂要藉他们的服事，用道的宝剑护卫教会，使她得保安全；这保守不是靠地上的守卫，而是靠神隐秘而属灵的能力。先知随即自作解释，说：「你们题醒耶和华的。」这话虽然关乎一切敬虔人——他们受命尽其所能在各处传扬神的名——但主要是向祭司们说的，因为他们担负公职，理当为众人作榜样，并全心竭力献身于赞美神。

<span style="color:#800000">*昼夜都不…*</span>这里牧者被提醒当尽的本分；因为单单牧养主的羊群还不够，他们还必须护卫羊群，抵御强盗与豺狼的侵袭。所以，若要恰当地履行职责，他们必须「昼夜」守望看顾。

<!-- PAGE 564 -->
<span style="color:#800000">*总不静默。*</span>主禁止他们静默；因为祂愿他们殷勤警醒；祂在此显明祂何等看重教会的安全。这段经文见证了：当我们有忠心的牧者看顾我们时，这乃是神格外的恩慈；因为我们暴露于各样的危险之中，若主不藉着祂所设的守望者保护我们，我们就落入撒但的网罗。因此我们当常常祈求，愿祂以祂所看为我们所需的守望者环绕我们。

**7.** <span style="color:#800000">*也不要使祂歇息。*</span>先知至此所讲的是教导的职分与本分；但若不加上祷告，这仍不足够，所以他劝勉传道的仆人要祷告；因为我认为 <span style="color:#008080">לו</span>（*lo*，「向祂」）是指着神说的。因此，我们当向神恳求，以切切的祷告祈求祂使我们的劳苦有些成效，否则我们的劳苦便是徒然。既然我们全然献身于宣讲真道，奋力抵挡撒但一切的诡计，就让我们同时学会将心思转向神，求祂不容我们的劳苦归于无效。正如他在本章开头说「我必不静默」时，将「静默」一词用于教导，照样在这里他将它用于祷告，我们藉着祷告从神得着教导的果效。就连天使也以他们的榜样激励我们如此殷切祷告，正如我们在撒迦利亚书中读到，那天使热切地为教会的复兴祷告。（撒迦利亚书 1:12）

<span style="color:#800000">*直等他建立。*</span>由此可以推知，这里有两样彼此有别的恩惠：第一，得着忠心的牧者看守教会的安全；第二，教会藉着他们的服事得以扶持、得以保全其光景。然而在此说话的神，宣称这些恩惠都是出于他自己；他在许多别处也是这样宣称。保罗说：“若没有奉差遣，怎能传道呢？”（罗马书 10:15）所以，设立牧者乃是单单属乎神的事；因为若非如此，无人能“当得起”（哥林多后书 2:16）这样重大而艰难的职分；也惟有他藉着他们的服事推进教会的复兴；因为倘若主不赐下顺利的成效，他们的一切劳苦都必徒然无果。在此我们看见，人外在的服事与圣灵的功效是联合在一起的；因为虽然惟独主是这工作的创始者与成终者，他却仍然兴起器皿，用以建造教会这座殿宇。这提醒我们：即使眼前所见尽是废墟、困苦与荒凉，我们也不当丧胆；反倒当尽本分祈求主使教会复兴，这也正是他所应许要成就的。

<span style="color:#800000">*直等他使耶路撒冷成为可赞美的。*</span>这意思是使教会成为荣耀的，使喜乐的根基从她里面发出光辉；因为当我们所感受到的只有神的严厉时，我们就变为哑口，被羞愧所淹没；但当他救我们脱离苦难、使我们得以复兴时，他也同时开启我们的口；因为他赐给我们赞美与感恩的根基。

**8.** <span style="color:#800000">*耶和华……起誓。*</span>他继续沿用先前所用的比喻；因为既然由于我们本性的败坏，基督的国无法照着我们的领悟力被描述出来，就必须用形象来加以表明。正如他先应许万物的丰足，其次应许忠心的守护，使信徒的处境得以安稳；照样，他在此也应许平静与安息，使他们可以安然享用自己所得的福分，将来也不再被人夺去。仿佛他说：“你从前手中所有的一切，都任凭掠夺抢劫；但如今你所有的一切都必稳固，你可以自由地享用你的五谷和你的新酒；总而言之，你必在平安中享受你的兴盛。”

但我们本性败坏至此，以致神虽丰丰富富地大施应许，我们仍不肯信靠他；因此先知在此描述他起誓。原来主如此俯就我们，甚至使用誓言，为要更进一步纠正我们的不信与顽梗。如今，主「指着自己起誓」，因为（如使徒所说）「他不能指着比自己更大的起誓」（希伯来书 6:13）。

<span style="color:#800000">*耶和华指着自己的右手和大能的膀臂起誓。*</span> 他题到自己的「右臂」，即神的能力；因为这与当前的话语正相称。这就如同他说：「我若有何等能力，我必显在你们的拯救上；免得在这艰难之事上你们的心懈怠昏沉，我指着我那无可抗拒、胜过万有的手起誓：无论有何等艰难兴起，你们在我的保护之下必然平安。」所以每逢他应许拯救，我们就当思想他的力量与大能。

<!-- PAGE 566 -->

<span style="color:#800000">*我必不再……*</span> 这是一种省略的说法；我们从中受教，晓得誓言的神圣与庄严。这话的意思，就如同他说：倘若这些应许不藉着事实的应验得着证实，他愿从今以后不再被人相信。当他应许人可以安然享用五谷与新酒时，他的意思是：教会被夺去五谷与新酒，乃是出于他公义的审判，并非偶然临到；因为每逢仇敌掳掠抢夺，这无疑是出于神的许可，正如他在律法中所警告的（申命记 28:33）。另一方面，各人得以安然享用所得的，乃是他特别的赐福。

<p style="text-align:center" markdown="1"><span style="color:#000080">「在自己葡萄树下和无花果树下」（</span><span style="color:#000080">列王纪上 4:25）</span></p>

**9.** <span style="color:#800000">*收割的人必吃这粮。*</span> 这是对前面话语的解释与确证；因为先知既已见证他不再容许教会所拥有的成为掠物，便随即补充说，她必享用自己的产业。然而他表明，唯当我们以正当的勤劳得着「五谷与新酒」时，它们才可正当地称为我们自己的；因为那些强夺他人之饼，或以不法手段得着之人，并非从主而得，也不能将其归于他的祝福，好像自己是合法拥有一般；与此相应的，正是诗篇中所说的：

<p style="text-align:center" markdown="1"><span style="color:#000080">「你要吃劳碌得来的；你要享福，</span> <span style="color:#000080">事情顺利。」（</span><span class="ages-code">&lt;19C802&gt;</span><span style="color:#000080">诗篇 128:2）</span></p>

<span style="color:#800000">*并赞美耶和华。*</span>然而，他既应许耕种土地的人必得食物，为何说他们要向神称谢呢？倘若人靠自己的劳力收聚五谷、酿取新酒，为何要赞美神呢？若把这些归于人的辛劳与勤勉，那称谢似乎只是虚假的；而人若靠自己的劳力得着食物，神便不配得称赞了。但当注意，先知在指明求取食物的正当方法之后，同时又补充说：倘若主不将食物供给我们，我们的劳力必归于虚空；因为我们所有的一切都属于神，凡我们所得的都当单单归于他。

<!-- PAGE 567 -->
<span style="color:#800000">*在我圣所的院内喝这酒。*</span>他在此暗指献祭这一庄严的举动；因为他们本可在别处喝酒，各人也可在自己的居所吃饭。然而这里所暗指的，乃是在分别为圣时所遵行的那礼仪，就是律法所要求的，将初熟之物献为供物（利未记 2:12；23:10），使那一年的出产得以奉献给神；在摩西的著作中，我们屡次读到这样的话：

<p style="text-align:center" markdown="1"><span style="color:#000080">「在耶和华你的神面前吃，并要欢乐。」</span> <span style="color:#000080">(</span><span style="color:#000080">申命记 12:18。)</span></p>

**10.** <span style="color:#800000">*你们当从城门经过，经过。*</span>他从前面的宣告推出结论：昔日或紧闭、或倾颓的城门，如今必有自由的通行。当城被仇敌围困之时，城门是紧闭的；当城被拆毁、与地平齐之时，城门是倾颓的。他的意思是，这城必如此得着重建，以致居民众多，进出往来络绎不绝。

有些人认为这些话是对牧者说的，叫他们进入城门，作众人的引路者，走在别人前头。但这是一句普遍性的、比喻性的宣告，藉此他把教会比作一座人烟稠密的城，尽管它一时曾如耶路撒冷那样荒凉倾颓。另一些人则作更为巧妙的推论，说当教会中宣讲罪得赦免、神藉这信息呼召万人归向祂时，教会的门便敞开了。但我们若要把握先知的本意，就必须认定：这一切都是照我们前面所说的，用比喻的方式讲的。

<span style="color:#800000">*为百姓预备道路。*</span>严格说来，这是教师的职分；但先知在此是笼统地说，向一切被主用来为百姓预备道路的人说话。诚然，在当时他是向玛代人和波斯人说的，主藉着他们为犹太人开了道路，使他们得以返回故土；但接下来，他也把主用以复兴祂教会的一切其他人都包括在内。

<!-- PAGE 568 -->
<span style="color:#800000">*修平，修平道路。*</span> 他以权柄命令众人「清除并修平道路」，为要使犹太人知道，一切阻碍都必轻易被除去，而所有的人，无论其敌意何等根深蒂固，都必立即听从神的命令。他就这样吩咐信徒刚强壮胆地束腰做工，如同有许多工人已预备好前来相助；而这词的强调重复（「修平，修平」）值得注意，其意在表明确定无疑。

<span style="color:#800000">*用石头铺平它。*</span> <span style="color:#008080">סקל</span>（*sikkel*）有时指除去石头，有时指用石头铺路；我认为在此处宁可取后一意义来理解，尽管注释家们大都持不同看法。<span style="color:#800000">F1013</span>

<span style="color:#800000">*为万民竖立大旗。*</span> 这与前一句意思相同；因为先知的意思是，万民必听从神的命令，正如臣民惯常服从君王一样；因为「大旗竖立」之时，他们必聚集奔赴，出力协助将这民带回。他就这样以崇高的言辞称扬神的能力，为使犹太人深信他们有一天必得复兴。<span style="color:#800000">F1014</span>

**11.** <span style="color:#800000">*看哪，耶和华曾宣告。*</span>他的意思是，主要以奇妙的方式行事，超乎肉体的判断与期望，使万民都知道这事乃是出于他的命令。或许有人反对说：如今这些百姓仍激烈地抵挡神，怎能使他们顺服他呢？先知说明了缘由：「因为主必宣告你们的归回，以致他们要承认你们乃是奉他的命令而得复兴。」

<span style="color:#800000">*要对锡安的居民说。*</span>这无疑是按字面指着圣道的仆人和先知说的，主将这职分交托他们，就是向教会应许拯救与救恩。由此我们断定，这些应许并非仅限于某一个世代，而当延伸到世界的末了；因为从巴比伦归回犹大开始，我们必须一直推进到基督的降临，这预言在基督里终于得着成就，救赎也得以完成；因为当神的恩典藉福音被宣扬时，救主就来了。总而言之，他预言神的声音有一天要从日出之地响彻到日落之处，并且不仅一国要听见，万国都要听见。

<!-- PAGE 569 -->
<span style="color:#800000">*看哪，你的拯救者来到。*</span>我们知道，这是特别属于福音的话语；因此他吩咐教会的教师们，要以对主降临的坚定盼望来激励信徒的心，虽然他似乎远离他的百姓。但这应许主要关乎基督的国度，在其中这些事得着了完全而全备的成就；因为他实实在在地显明自己为他教会的「拯救者」，正如我们前面在第四十章所看见的。

<span style="color:#800000">*看哪，他的赏赐在他那里，他所作成的果效在他面前。*</span>为要使他们不再为任何疑惑所困扰，先知在此宣告：当神——救主——显现之时，他要以能力披戴他，正如以赛亚书 40:10 所言；因为先知在此重复了我们在那处经文中所见的同样话语。这好像他说：「一旦神喜悦伸出他的手，果效必迅速而突然地临到；因为只要他停止不动或延迟不行，肉体的判断就断定他是闲懒无为的。」我们看见，何等众多的狂热之徒臆想出一位并不存在的神，仿佛他们在描绘一幅死的图像。因此，先知理当宣告神的「工作和赏赐都在他面前」，为要使他在必要之时显明：他是世界公义的审判者。

**12.** <span style="color:#800000">*人必称他们为圣民。*</span>他在此描述主降临所带来的益处；就是说，因为神既显明他看顾他的选民如同看顾自己的产业，他就要向全世界表明：他与亚伯拉罕所立的收纳为儿子之约并非虚谎。因此他称他们为「圣民」，因为主已将他们从万民中分别出来，使他们成圣归于自己；因为，虽然他治理万国，他却俯就拣选了亚伯拉罕的后裔，使他们成为他特别看顾的对象。（出埃及记 19:6）

<!-- PAGE 570 -->
<span style="color:#800000">*耶和华的赎民*</span>。按上文所述的意义，神宣告：当他以他们的救主与救赎主的身分显现时，他们必作圣民；因为，正如百姓在污秽中躺卧、被恶人的辱骂所苦所困时，被称为「受了污亵」，照样，当主实际显明他亲自主掌他们的救恩时，他们就被称为「成圣的」。这是藉着一次奇妙的救赎成就的；在那时神也见证他记念自己的产业，就是在人眼中他似已弃绝、不加眷顾的产业；因为在这些话「被眷顾的（Sought out）<span style="color:#800000">F1015</span>，不被撇弃的」之中，标示出一种对照：一面是神与他百姓离绝的时候，一面是他重新使他所丢弃的人与自己和好的时候。
