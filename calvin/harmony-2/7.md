<a class="verse-anchor" id="matt-17-1"></a>

**马太福音 17:1。** *过了六天。* 我们首先要问的是，基督为何要在短暂的时间内披上属天的荣光，又为何只允准三个门徒作目击者。有人认为，他这样做是为了使他们能够抵挡因他将要面临的死亡所带来的试炼。这在我看来似乎并不是一个合理的理由；因为若如此，他为何要剥夺其余门徒同样的安慰？或者更确切地说，他为何明确禁止他们将所见之事传扬出去，直到他复活以后，岂不正是因为这异象的果效要在他死后才显明吗？我毫不怀疑，基督的本意是要表明：他并非被迫赴死，乃是甘心情愿地前去，将顺服的祭献给父。门徒们直到基督复活才明白这一点；他们也无需在他临终之际就察觉基督的神性大能，以承认他在十字架上得胜；然而他们此时所受的教导，乃是要在将来对他们自己并对我们都有益处，使任何人都不致因基督的软弱而跌倒，仿佛他是被强迫、被必然性所驱使而受苦的。[^477] 显而易见，基督若要保守他的身体免于死亡，原本与他披上属天荣光一样容易。因此我们得知：他甘愿伏在死下，因这是他所愿意的；他被钉十字架，因这是他自己献上的。那在十字架上献为祭、安卧坟墓中的同一肉身，原本可以免于死亡和坟墓；因为它早已分享过属天的荣光。我们又得知：当基督仍在世上、以仆人的形像存留之时，当他的尊荣仍隐藏在肉身的软弱之下时，他丝毫没有失去什么，因为他是出于自愿*虚己*（腓立比书 2:7）；如今他的复活已经揭开了那一度遮蔽他大能的帕子。我们的主认为选*三位见证人*已经足够，因为这是律法所规定的证实事实的人数：凭两三个人的口可以定准（申命记 17:6）。时间上的差异不应使我们困惑。马太和马可计算两件事之间整整过了*六日*；路加则说*约过了八天*，是把基督说这话的那一日和他变像的那一日都算在内。可见，虽然表达有别，意思却完全一致。

<a class="verse-anchor" id="matt-17-2"></a>

**马太福音 17:2.** *他就在他们面前变了形像。* 路加说，这事发生在*他祷告的时候；*从时间与地点的情境，我们可以推断，他正是为了如今所得的事祈祷过，好使他的神性能藉着非常形像的光辉得以彰显；这并非因为他需要藉祷告向他人求取自己所没有之物，亦非因为他怀疑父的心意，乃是因为在他屈辱的全过程中，他始终把自己作为神性位格所行的一切归于父，并且他要以自己的榜样激励我们祷告。他的*变形*并未使门徒得以完全看见基督如今在天上的样子，而是使他们尝到了他无穷荣耀的滋味，达到他们所能领会的程度。当时*他的脸面*明亮*如日头；*但如今他的光辉远胜过日头。在他的*衣服*上显出非凡夺目的洁白；但如今不需要*衣服*，神性的威严已在他全身放光。古时神向众圣祖显现也是如此：不是按他自己本相，而是按他们所能承受他无穷光辉的程度；因为约翰宣告说，惟有当我们像他时，才能看见他的真体（约翰一书 3:2）。在此无需对他*衣服*的*洁白*或他*面容*的*光辉*作过分精巧的探究；因为这并非基督属天荣耀的完全展示，而是藉着适合肉身领受能力的象征，使他们部分地尝到那无法被完全领会之事。

<a class="verse-anchor" id="matt-17-3"></a>

**马太福音 17:3。** *看哪，有摩西和以利亚向他们显现。* 有人问：*摩西和以利亚* 是真的亲身在场，还是仅仅向门徒显现一种异象——正如先知们也时常看见那些不在场之事物的异象？尽管这一问题如我们所说，正反两方皆有论据可陈，但我认为更有可能的是：他们确实被带到那地方。这一推断并无荒谬之处；因为神将身体与灵魂都掌握在手中，按其意旨，凡见为必要时，可随时使死人复活。 *摩西和以利亚* 此时显现并非为他们自己的缘故， [^478] 乃是为侍奉基督。其次有人问：使徒们从未见过 *摩西和以利亚* ，何以认得他们？答覆甚为简单：那位将他们带至此地的神，也赐下记号与凭据，使使徒得以认出他们。如此，乃是借着非常的启示，他们方才确知所见的就是 *摩西和以利亚* 。然而，为何独是这两位显现，而不是同属众圣先祖之列的其他人？这是为要表明：基督独自是律法与众先知的终极归宿；这一个理由就足以使我们满意：因为对于我们的信仰而言，至关重要的乃是基督来到世间并非无凭无据，而是带着神先前所赐下的种种印证。不过，我也不反对一般人所提出的解释：之所以拣选 *以利亚* 而不选他人，是因他作为众先知的代表——因他虽未留下任何著作，却次于摩西，在众先知中最为卓著；他恢复了已被败坏的敬拜，在维护律法与当时几近消亡的真敬虔上，殚精竭虑，无人能及。 *他们与耶稣谈论。* 当他们与基督一同 *显现* ，并与他 *谈论* 时，这表明他们彼此意见一致。所谈论的话题，唯路加福音有记载：他们 *谈论* 基督 *在耶路撒冷将要成的去世* 。这不可理解为他们个人之事，乃是关乎他们昔日所领受的差遣。虽然他们离世、走完蒙召的路程已有许多时日，然我们的主再一次借他们的口印证他们在世时所传讲的道，使我们得知：藉基督献祭所得的同一救恩，与众圣先祖一同赐给我们。当古时先知发出关于基督受死的预言之时，他自己——那位神永恒的智慧——正坐在他不可见的荣耀宝座上。由此可见：当他披戴肉身之时，他承担死亡之必然，全然出于他自己甘愿的顺服。

<a class="verse-anchor" id="matt-17-4"></a>

**马太福音 17:4。** *主啊，我们在这里真好。* 路加告诉我们，彼得说这话时，*摩西和以利亚正要离开；* 由此我们可以推断，他担心他们一旦离去，那令人愉悦欢喜的景象便会消逝。彼得如此被所见之美所吸引，以致忽略了其他任何人，仅以单纯享受此景为满足，这并不足为奇；正如诗篇所说："在你面前有满足的喜乐"（诗篇 16:11）。然而他的渴望是愚拙的：首先，他没有领悟这异象的目的；其次，他荒谬地将仆人与他们的主置于同等地位；第三，他错误地提议为那些早已被接入天堂与天使荣耀中的人建造转瞬即逝的棚子[^479]。我说他没有领悟这异象的目的；因为他正从*摩西和以利亚*口中听见基督受死的时候临近，却愚昧地梦想这暂时的景况将永远存留。倘若基督的国度就这样被局限于二三十英尺的狭窄范围内，那么普世的救赎将在何处？永恒救恩的传扬又在何处？将*摩西和以利亚*设想为神儿子的同伴，也是极其荒谬的，仿佛不应使众人皆居于较低的地位，唯独让祂得着首位。况且若彼得对当前的境况已感满足，他为何还以为那些人需要属地的支撑——单单看见他们就足以使他幸福，这不是他自己所想象的吗？因此，两位福音书作者公正地指出他*不知道自己所说的是什么*；马可则给出了原因：*他们都甚惧怕*；因为神在那时并不打算让使徒们从中得着别的益处，只是让他们片刻之间如在明镜中得见祂儿子的神性。日后，祂才向他们指明这异象的果效，并纠正他们判断上的错谬。因此，马可所记的必定是说，彼得被一种狂喜冲昏了头，说话好像一个失去理智的人。

<a class="verse-anchor" id="matt-17-5"></a>

**马太福音 17:5。** *看哪，有一朵明亮的云彩遮盖他们。* 他们的眼睛被*云彩*遮住，是要告诉他们：他们尚未预备好去仰望天上荣耀的光辉。因为当主显出祂同在的征兆时，祂同时也使用某种遮蔽，以抑制人心的狂傲。所以现在，为了教导门徒一个谦卑的功课，祂从他们眼前收回了那天上荣耀的景象。这警戒也是对我们说的，叫我们不要窥探那超出我们感官之外的奥秘；反之，各人当照着自己信心的程度，谨守清醒的界限。一言以蔽之，这*云彩*应当作我们的辔头，使我们的好奇心不至放纵无度。门徒们也被警告：他们必须返回从前的争战，因此不可在时候未到之先就指望凯旋。

*看哪，有声音从云彩里出来。* 值得我们注意的是，神的*声音*是从*云彩*中发出的，却既不见身体，也不见面容。所以让我们记住摩西所给我们的警告：神没有可见的形象，免得我们自欺，妄想他与人相似（申命记 4:15）。诚然，神在古时曾以各样的形象向众圣祖显现自己；但他在一切情形下都避免使用那些会引诱他们为自己造偶像的记号。诚然，因为人的心思过于偏向愚妄的幻想，根本无需再火上浇油 [^480]。神荣耀的这次显现远胜于其他一切显现。当他使云彩横亘于他与我们之间，并以他的声音呼召我们归向他时，我们竟想凭一块木头或石头将他摆在自己眼前，这是何等的狂妄？因此，让我们竭力单凭信心、而不凭肉眼，进入神所居住那不能靠近的光中。*声音*从*云彩中*发出，是为了让门徒们知道这声音来自神，便以应有的敬畏来领受。*这是我的爱子。* 我乐意赞同那些认为此处暗含*摩西和以利亚*与基督之对比的人的看法——神自己儿子的门徒们在此被吩咐不要再寻求别的教师。"*儿子*"这个词是着重强调的，将他高举于仆人之上。这里赐给基督两个称号，它们既适合尊荣他，也同样有助于我们的信心：*爱子*与师傅。父称他为*我的爱子，我所喜悦的*，借此宣告他是中保，神借他叫世人与自己和好。当父吩咐我们*听他*时，便指派他作他教会至高且唯一的教师。父的心意是要将基督与其余一切分别出来；我们由此真实而严格地推论出：按本性他是神的*独生子*。同样，我们也明白唯有他被父*所爱*，唯有他被指派作我们的教师，使一切权柄都居住在他里面。但或许有人反对说：神岂不也爱天使和世人吗？答案很容易：神那遍及天使与世人的父爱，是以他为源头流出的。*子*被父*所爱*，并不是要使其他受造之物成为他憎恶的对象，而是使他将属于自己的分赐给他们。诚然，我们的处境与天使有所不同；他们从未与神疏离，因此不需要他来使他们与自己和好；而我们因罪的缘故是仇敌，直到基督为我们求得他的恩宠。然而，仍有一条确定的原则：唯有当神在基督里接纳我们时，他才向二者施恩；因为即便是天使，若基督不作他们的元首，也不能与神牢固地联合。还可以观察到：既然父在此说自己有别于子，那就有位格的区分；因为他们在本质上为一，在荣耀上相同。*你们要听他。* 我刚才提到，这些话的用意是要将教会的注意力引向基督，将他作为唯一的教师，使教会单单倚靠他的口。因为基督虽然来是为了维护*律法和先知*的权威（马太福音 5:17），他却居于至高之位，以致他福音的光辉使旧约中曾闪烁的那些火花归于消失。他乃是*公义的日头*，他的来临带来了完全的白昼之光。这就是为什么使徒说（希伯来书 1:1），神既在古时藉着先知多次多方地晓谕列祖，就在这末世藉着他的爱子向我们说话。

简言之，今日在律法与众先知中所听见的基督，与在他福音中所听见的同样真实；因此在他里面住有*师傅*的权柄——这权柄是他单单为自己所宣告的，他说：*只有一位是你们的师傅，就是基督*（马太福音 23:8）。然而，除非众人的口舌都缄默，他这权柄就不能得到完全的承认。我们若愿顺服他的教训，凡人所发明的一切都必须被推倒、被毁灭。诚然，他每日都差遣教师出去，但这是要他们纯正而诚实地传讲他们从他所领受的，而不是用自己的附加之物玷污福音。一言以蔽之，凡不亲自作基督门徒、不引领他人受教于他的，就不可被视为教会忠心的教师。

<a class="verse-anchor" id="matt-17-6"></a>

**马太福音 17:6.** *他们听见* 神有意使门徒被这种惧怕所震慑，好叫这异象的记忆更深刻地铭印在他们心中。然而我们看见，我们本性何等软弱，竟至于听见神的声音便如此战兢。不敬虔之人若嘲笑神，或漫不经心地藐视神，那是因为神并未以使他们感受到他同在的方式向他们说话；但神的威严，我们一旦察觉，便不可避免地要使我们俯伏于地。

<a class="verse-anchor" id="matt-17-7"></a>

**马太福音 17:7。** *耶稣进前来，摸他们。* 当他们仆倒时，基督扶起他们，藉此尽他的职分；因为他降到我们中间，正是为了这个目的，叫信徒在他的引导下能坦然无惧地进到神面前，叫他的威严——这威严本要吞灭一切血肉之躯——不再使他们惊惶恐惧。他不仅以话语安慰他们，更以*抚摸*坚固他们。

<a class="verse-anchor" id="matt-17-8"></a>

**马太福音 17:8.** *不见一人，只见耶稣。* 经文说他们最终*只*看见基督，这意味着律法和先知具有暂时性的荣耀，惟有基督当完全留在我们眼前。我们若要正确地借助摩西的帮助，就不可停留在他那里，而当努力借他的手被引到基督面前，因为他和其余众人都是基督的执事。这段经文也可用来谴责那些迷信之人的错误——他们不仅把基督与先知和使徒混为一谈，甚至把祂与最低等级的圣徒相混淆，以致使祂不过是他们中间的一员。但神的圣徒们在恩典上出类拔萃，其目的与他们夺取基督一部分尊荣并据为己有恰恰相反。我们可以从门徒身上看出这种错误的根源：当他们被神的威严所惊吓时，他们的心思就四处寻找人；但当基督温柔地扶起他们时，他们就*只*看见祂。我们若蒙基督以那能解除我们恐惧的安慰来扶持我们，那些从四面八方搅扰我们的愚妄情感便都要消散。

<a class="verse-anchor" id="matt-17-9"></a>

**马太福音 17:9.** *他们下山的时候。* 我们已经说过，宣告*这异象*的时候尚未完全来到；事实上，门徒们也不会相信，除非基督在他复活时给出他荣耀更为显著的证据。但当他的神性大能已被公开彰显之后，那暂时显现的荣耀便开始被人接受，从而使人完全清楚：即使在他*虚己*（腓立比书 2:7）期间，他仍然完整地保有他的神性，尽管这神性隐藏在肉身的帷幕之下。因此，他吩咐门徒要保持缄默，直到他从死里复活，是有充分理由的。

<a class="verse-anchor" id="matt-17-10"></a>

**马太福音 17:10。** *他的门徒问耶稣说。* 一提到复活，门徒就立刻以为基督的国度已经开始了；[^482] 因为他们把这个词理解为：世人将承认祂就是弥赛亚。从马可所记载的可以明显看出，他们所设想的复活与基督所指的截然不同，因为马可说*他们彼此议论"从死里复活"是什么意思*。或许他们当时也已受到那种幻想的影响——这种幻想如今在拉比们中间被视为不容置疑的神谕，即弥赛亚有两次降临：在第一次降临中，祂是卑微而受人藐视的；但紧接着便是祂君王般的尊荣。诚然，这种谬误也有几分貌似有理之处，因为它源于一个真实的原则。圣经的确也提到弥赛亚的两次降临；因为圣经应许祂将作救赎主，藉祂的祭赎清世人的罪。[^483] 以下经文的含义正是如此："锡安的女子啊，应当大大喜乐！看哪，你的王来到你这里，祂是公义的，并且施行拯救，谦谦和和地骑着驴"（撒迦利亚书 9:9）。"祂无佳形美容；我们看见祂的时候，也无美貌使我们羡慕祂。祂被藐视，好像被人掩面不看的一样"（以赛亚书 53:3,4）。另一方面，圣经也描绘祂胜过死亡，使万有都服在祂的权柄之下。然而我们看到，拉比们如何用他们的臆造之说败坏了神纯洁的话语；并且既然在我主的时代万事都已大为败坏，那么民间也接受了这种愚昧的观念，也就不足为奇了。*文士为什么说以利亚必须先来？* 他们对*以利亚*这个人物所犯的严重错误，已在两三处地方指出过。[^484] 或许他们也狡猾恶毒地企图借提出*以利亚*来削弱基督的权威；因为既然应许说*以利亚*要作弥赛亚的先锋，*在祂面前预备道路*（玛拉基书 3:1；4:5），那么只要说基督来时没有*以利亚*相伴，就很容易激起对基督的偏见。藉着一个极为类似的诡计，魔鬼如今迷惑教皇党人，叫他们以为审判之日要等以利亚和以诺出现之后才会来到。[^485] 通常不会有人猜测文士是有意采用这一手段，以便使基督显得不值得信赖，因为祂缺乏弥赛亚的合法标志。

<a class="verse-anchor" id="matt-17-11"></a>

**马太福音 17:11。** *以利亚固然先来。* 我们在别处已经说明了犹太人中流行的这一错误的来源。施洗约翰要像*以利亚*那样，借着恢复教会衰败的光景来与他相似，先知玛拉基（玛拉基书 4:5,6）甚至将*以利亚*的名字赋予他；而文士们却轻率地解释这话，仿佛*提斯比人以利亚*（列王纪上 17:1）要再次回到世上来。基督现在宣告说，玛拉基所说的一切都是真实的，但他的预言被误解，并从其真正的含义中被扭曲。他说："关于*以利亚*要来的应许是真实的，并且已经应验了；但文士们已经拒绝了以利亚，他们却空洞而虚假地借用他的名字来反对我。" *他要复兴万事。* 这并非意味着*施洗约翰*已完全*复兴*了它们，而是说他将这些事传递并交付给基督，基督要完成他所开始的工作。既然文士们如此可耻地拒绝了约翰，基督就提醒他的门徒：这等人的欺骗不应使他们不安，而且也不应被视为奇怪——既然他们拒绝了仆人，他们也会以同样的轻蔑拒绝他的主人。为了使无人因这等怪事而忧愁，我们的主提到圣经包含了对这两件事的预言：就是世界的救赎主和他的先驱以利亚都要被虚假和邪恶的教师所拒绝。

<a class="commentary-anchor" id="matthew-1714-18-mark-914-27-luke-937-43-comm"></a>

由于马可的记载更为详尽，对各种情形描述得极为细致，我们将依照他叙述的顺序来追述。首先，他清楚地指出基督为何一反常态、严厉地宣告说：犹太人因其顽梗的恶意，不再值得被宽容。我们知道，平常即使他们的请求过于强求，基督也是何等温和地接纳他们。[^486] 这里有一位父亲为他的独生子代求，情况极为紧急，所发出的是谦卑恳切的呼求，求基督施怜悯。那么，他为何一反常态，突然震怒，宣告说不能再忍受他们了呢？由于马太和路加的叙述无法使我们看出这般严厉的缘由，有些注释家便误以为这斥责是针对门徒，或是针对那受苦孩子的父亲。但若我们按照马可的记载仔细思想一切情形，便不难得出结论：基督的愤怒乃是针对文士们的恶意，而非要如此严厉地对待无知软弱之人。在基督不在场时，一个*癫痫患者*的孩子被带来。文士们将此视为找碴的好机会，便急切抓住不放，要求门徒说：他们若有任何能力，就当施展出来医治这孩子。门徒大概是尝试过了，却归于徒劳；于是文士们扬声欢呼自己得胜，不但讥讽门徒，更对基督发作，仿佛在门徒身上他的能力已被挫败。这真是骇人的不敬虔，又夹杂着同样卑劣的忘恩负义——他们恶意地将自己亲眼所见的诸般神迹（基督那惊人的大能正是借这些神迹彰显的）一概抛诸脑后；他们分明是企图扑灭摆在他们眼前的亮光。因此，基督理所当然地宣告说：他们不能再被容忍了；并称他们为*不信悖谬的世代*；因为他们先前所见的众多明证，至少本应使他们不再寻找贬损的把柄。[^487]

<a class="verse-anchor" id="mark-9-14"></a>

**马可福音 9:14.** *他看见许多人围着他们。* 门徒无疑成了众目睽睽之下的笑柄，正如真理的仇敌惯于借小事大肆张扬以炫耀得胜，纠集众人围观。文士将此事闹得沸沸扬扬，致使门徒招来许多人的讥讽。然而，看来其中也有一些人并非心怀恶意；因为他们一见耶稣，便上前问安；甚至文士的傲慢气焰也因主的临在而有所收敛，当主问他们所争论的是什么事时，他们竟一言不能答。

<a class="verse-anchor" id="matt-17-17"></a>

**马太福音 17:17。** *夫子，我带了我的儿子到你这里来。* 马太所描述的疾病与马可所描述的有所不同，因为他说这人是 *害癫痫的*。但两位福音书作者在以下两点上是一致的：他是 *哑巴*，且每隔一段时间就会狂躁发作。*害癫痫的*（lunatic）一词用来指那些在 *月* 亏之时癫痫发作或受眩晕折磨的人。我不接受屈梭多模（Chrysostom）那种臆想的说法，即 *lunatic* 这个词是撒但耍的花招而捏造出来的，目的是羞辱神所造的美好之物；因为我们从确凿无疑的经验中得知，月亮的运行确实影响这类疾病的加剧或减退。[^488] 然而，这并不妨碍撒但将其攻击与自然手段掺杂在一起。因此我认为，这人并非天然就是 *聋* 和 *哑* 的，而是撒但占据了他的舌头和耳朵；又因他大脑和神经的软弱使他易于患癫痫，撒但便利用这一点加剧了疾病。其结果是，他四面八方都暴露于危险之中，被剧烈的抽搐所折磨，发作之后倒卧在地，昏迷不醒，如同死人一般。我们当从此学到一个教训：若不是被神的手所拦阻，撒但有多少加害于我们的途径。我们灵魂与身体上数不胜数的软弱，正是撒但用来伤害我们的箭矢。倘若这般凄惨的处境还不能激发我们祷告，那我们便比愚顽更甚了。但我们在此也看见神慈爱的奇妙彰显：尽管我们身处如此种种的危险之中，[^489] 祂却以祂的保守环绕着我们；尤其是当我们想到我们的仇敌何等急切地谋求毁灭我们时，就更当如此。我们也当回想这一安慰人心的真理：基督已经降临，要遏制撒但的愤怒，使我们虽身处众多危险之中仍得平安，因为我们的疾病已被天上的良药有效地抵消。我们也必须留意时间这一情况。父亲回答说，他儿子自 *幼年* 起就患了这种可怕的疾病。倘若撒但被许可在这般稚嫩的年龄上如此施展其权势，那么我们这些以自己的罪行不断使自己暴露于致命打击之下、甚至将箭矢供给我们仇敌的人，岂不更当惧怕么？若不是被神奇妙的良善所约束，撒但本可以理所当然地被许可向我们倾泻其愤怒。

<a class="verse-anchor" id="matt-17-17"></a>

**马太福音 17:17。** *不信悖谬的世代。* 基督的话表面上是向那*癫痫病*孩子的父亲所发，但毫无疑问，他真正所指的是文士们，正如我刚才所解释的；因为可以肯定，这一斥责并非针对无知软弱之人，而是针对那些怀着积久的恶意、顽固抵挡神的人。这就是为什么基督宣告他们再不配被容忍，并威胁说他不久就要离开他们。然而再没有什么比基督离弃他们更糟糕的事了；他们如此轻蔑地拒绝眷顾之恩典，这是何等沉重的责备。我们在此还要留意，待人当因其本性气质之不同而有不同的方式。因为我们的主以极大的温柔吸引那些可教之人，扶持软弱者，又温和地激励懒惰者，但对那些他看出无药可救的弯曲蛇类，则毫不姑息。

<a class="verse-anchor" id="mark-9-20"></a>

**马可福音 9:20.** *他一看见耶稣。* 当这个人被带到基督面前时，魔鬼以远超寻常的凶残向他发作，不必为此惊讶；因为基督的恩典越是显得临近、运行越是有能力，撒但的狂怒就越是被激起。基督的同在唤醒它，犹如号角之声。它尽其所能掀起最猛烈的风暴，竭尽全力与之抗争。我们当预先以这样的默想作准备，免得当基督恩典的临近遭遇仇敌远超寻常的暴烈时，我们的信心被搅扰。我们也不可忽略另一要点：我们得医治的真正开端，乃是当我们的苦难沉重到几乎临于死地之时。还需思想这一点：藉着撒但的猛烈攻击，我们的主点燃了一支火炬，使祂的恩典得以被看见；因为当旁观者被那可怕的景象所惊骇时，紧接而至的基督大能的彰显，便愈发显明地被察觉。

<a class="verse-anchor" id="matt-17-21"></a>

**马太福音 17:21.** *从小的时候。* 由此我们可以推断，这种惩罚并非因这个人本身的罪而加诸于他，而是出于神隐秘的审判。诚然，即使是婴孩，一出母腹便在神面前并非无辜，也并非毫无罪咎；然而神的管教有时具有隐藏的缘由，是为要试验我们的顺服。除非我们以敬畏和谦卑来敬拜神那隐藏不显的公义，否则我们便没有将当得的尊荣归给祂。凡愿对此点获得更详尽阐述者，可参阅我对《约翰福音 9:3》"也不是这人犯了罪，也不是他父母犯了罪"一节的*注释*。

<a class="verse-anchor" id="matt-17-22"></a>

**马太福音 17:22.** *你若能作什么，求你怜悯我们，帮助我们。* 我们看到他对基督何等地不敬；因为他以为基督只是某位能力有限的先知，故而带着犹疑前来。然而，信心的首要根基乃是拥抱神无限的大能；祷告的第一步乃是以坚定的信念——确信我们的祷告不致徒然——将祷告高举于一切阻碍之上。由于此人并不认为基督与其他人有任何分别，他这错误的看法便被纠正了；因为我们的信心必须如此塑造，才能有能力、有准备地领受所求的恩惠。基督在回答中并未直接斥责，而是间接地提醒此人他所说错的话，指出他的过失，并告诉他如何能得着救治。

<a class="verse-anchor" id="matt-17-23"></a>

**马太福音 17:23.** *你若能信。* 他说：“你求我尽我所能帮助你；但你必发现我里面有一座取之不尽的能力之泉，只要你所带来的信心足够大。”由此可学到一个有益的教义，同样适用于我们所有人：使主的恩惠不能丰盛地涌向我们的，并不是主自己，而应归咎于我们信心的狭小，以致它只是点滴临到我们，且我们常常连一滴也感受不到，因为不信封闭了我们的心。要证明基督的意思是人凭自己能信，这是徒劳的逞智之举，因为他无非是要将责任归还给人，让他们承担自己贫乏的过错，因为每当他们以不信贬抑神的大能时，过错就在他们身上。*在信的人，凡事都能。* 基督无疑是要教导我们：父已将一切福分的丰盛赐给了我们，凡各样的帮助都当单单仰望他，就如同我们仰望神之手所赐的一样。他说：“你只要坚信，必能得着。”至于信心究竟以怎样的方式为我们取得什么，我们随后即可见到。

<a class="verse-anchor" id="matt-17-24"></a>

**马太福音 17:24。** *主啊，我信。* 他宣告自己*信*，却又承认自己有*不信*。这两种说法看似互相矛盾，然而我们没有一个人不在自己里面同时经历这两者。既然我们的*信心*从来不是完全的，那么我们就在某种程度上是*不信的人*；但神饶恕我们，以这样的宽容待我们，竟因我们那一点点的信心就将我们算作信徒。与此同时，我们的责任乃是殷勤抖落那仍粘附在我们身上的不信余渣，与之争战，并求神矫正这些不信；每当我们投身于这场争战，就要奔向祂寻求帮助。我们若细察各人所领受的份量，就会清楚地看见：在信心上卓越者甚少，有中等程度者亦少，而所得份量微小者却甚多。

**马太福音 17:19.** *门徒进前来。* 门徒惊讶他们曾经拥有的能力如今被夺去；但这能力的失去是出于他们自己的过错。因此，基督把这种无能归因于他们的不信，并更为详尽地重复并阐明他先前所作的论述，即*在信的人凡事都能*。无疑，他宣告信心*能挪移树木与山岳*，乃是一种夸张的说法；然而其意义不外乎：只要我们为领受神的恩典敞开门户，神就绝不会撇弃我们。他并不是说神会赐给我们一切我们随口提及、或一切随机闪现于我们脑中的事物。恰恰相反，因为没有什么比我们肉体那愚妄无序的欲望更与信心相违背，所以信心在其中作王的人不会不加分辨地渴求一切，而只渴求主所应许要赐下的。因此，让我们保持这样的节制：除了他所应许给我们的，别无所求，并将我们的祷告限定在他所定下的规矩之内。但有人或许会反驳说，门徒并不知道主是否乐意医治那*被鬼附的*。回答很简单：他们之所以不知道，乃是他们自己的过错；因为基督此处所论的特别是*特殊的信心*（special faith），它有其隐秘的感动，正如当下情形所需要的。这也正是保罗所论到的*信心*（哥林多前书 12:9）。那么，使徒们何以丧失了他们从前在行神迹时所运用的圣灵的能力？岂不是因为他们因怠惰而把这能力浇灭了么？然而基督就此特定事件所论及关乎*特殊信心*的话，也可推及至全教会所共有的*普遍信心*。

<a class="verse-anchor" id="matt-17-21"></a>

**马太福音 17:21。** *这一类的鬼……若不……总不出来*，[^492] 基督借这话责备某些人的怠惰，要让他们知道这里所需要的并非寻常的*信心*；不然，他们或许会回答说，自己并非全然没有*信心*。所以其意思是：当我们要与撒但展开严峻的争战时，并非任何信心都足够，乃必须有刚强奋勇的努力。针对*信心*的软弱，祂开出*祷告*为药方，又加上*禁食*为辅助。祂仿佛在说：“你们这些柔弱无力的赶鬼者，看起来像是在演一场逗趣的假打；[^493] 但你们所对付的是强大的仇敌，不打到底牠绝不退让。所以你们的*信心*必须靠*祷告*被激发；既然你们在*祷告*上又迟钝又怠惰，就必须借助*禁食*来助力。”[^494] 由此可见，教皇党人何等荒谬，竟把*禁食*说成是驱赶魔鬼的特定方法，因为我们的主提到它，无非是为了激发祷告的恳切。当祂说*这一类*的鬼*若不靠祷告和禁食，就不能赶出来*时，意思是：当撒但已在某人身上深深扎根，并因长期盘踞而稳固立足，或当牠肆无忌惮地狂怒咆哮时，得胜便是艰难而痛苦的，所以这场争战必须竭尽全力地坚持到底。

**马太福音 17:22。** *他们还住在加利利的时候。* 越是临近受死的日子，基督就越频繁地警告门徒，免得那悲惨的景象猛烈地动摇他们的信心。这段话是在那神迹刚刚行完之后说的；因为马可说，他从那地方往加利利去，为要在那里私下度过中间的时日；因为他已定意要在每年献祭的日子上到耶路撒冷，因为他必要在临近的逾越节被献为祭。门徒先前已经多次得过关于这事的提示，然而他们仍然惊惶失措，仿佛从未听闻过此事一般。先入为主之见的影响竟如此之大，以致在最清晰的光中也使人心灵昏暗。使徒们曾想象基督国度的光景必是兴盛欢愉的，他一旦显明自己，就会普世皆以最高的赞许接纳他。他们从未想过祭司、文士以及教会的其他领袖会反对他。在这种成见的影响下，他们对相反方面所说的一切都置之不理；因为马可说他们*不明白*我们主所讲的是什么意思。一段如此清楚明白的话语为何竟未被理解？无非是因为他们的心思被一层愚昧想象的厚帕子蒙住了。他们不敢进一步追问。这部分固然是出于他们对夫子的敬畏；但我毫不怀疑，他们因听见这话而生的忧愁与惊愕，使他们沉默不语。这种羞涩并非完全值得称赞；因为它使他们停留在疑惑、犹豫和有罪的忧伤之中。同时，一种朦胧的敬虔原则——而非对真理的清晰认识——使他们依附于基督，不致离开他的学校。在他们心中已栽下了某种信心和正确理解的开端，使他们跟随基督的热心与教皇党人的*盲信*相去不远；但因他们尚未长进到认识神国的性情和那应许在基督里要成就的更新，我说他们乃是被敬虔的热心而非清晰的知识所引导。如此我们就看出，他们身上有哪些是值得称赞的，又有哪些是当受责备的。但虽然他们的愚钝不能完全得到原谅，我们也无须惊讶：他们的夫子受死及所要受的羞辱，那样明白清楚的宣告，在他们看来竟如同一个谜；不仅因为他们以为神子被弃绝、被定罪与他的荣耀不相称，也因为他们觉得，那特别应许给犹太人的恩典竟被本族的领袖弃如敝屣，这事看起来极不可能。但因那骤然临到他们身上对十字架过度的惧怕，关闭了那紧随其后所加的安慰之门——即出于复活之盼望的安慰——让我们学习：每当提及基督的死，我们都当同时一并思想那完整的三日，使他的受死与埋葬引导我们进入蒙福的得胜与新的生命。

<a class="verse-anchor" id="matt-18-1"></a>

**马太福音 18:1。** *那时，门徒进前来到耶稣面前。* 从另外两位福音书作者的记载可以清楚看出，门徒并非自愿前来见基督，而是在路上私下*争论*之后，被从他们的藏身之处带出来，拖到光中。马太的记述与此并无矛盾之处，他急于记录基督的回答，并未叙述事件的全部细节，而是略过开端，简要地说明基督斥责门徒愚蠢地野心争夺最高地位的原因。当基督询问他们暗地里的谈话，迫使门徒承认他们本想隐瞒之事时，这教导我们：无论多么小心地隐藏，凡野心都当提防。我们还必须留意这事发生的时间。基督预言自己的死，使他们悲伤困惑；然而仿佛他们从中得到了纯粹的欢乐，仿佛他们尝到了诗人所虚构的那种甘露[^497]，他们立刻就最高地位争论起来[^498]。他们心中的痛苦怎能瞬间消散呢？只因人心是如此沉迷于野心，竟忘却自己目前正处于争战状态，不断地在虚妄想象的迷惑下奔向凯旋。如果使徒们这么快就忘记了不久前听见的话语，那么我们若长时间撇下对十字架的默想，纵容自己冷淡懒散或沉溺于虚妄的玄想，又将如何呢？但有人会问：是什么引发了门徒之间的争论？我回答说：肉体既乐于摆脱一切不安，他们就把一切引起忧愁的话语置之不理，专注于关于复活所说的话；闲散之人由此引发了一场辩论。他们既拒绝肉体所不喜欢的那部分教义，神就任凭他们对复活的事产生误解，幻想从未发生之事——以为基督仅靠传道就能得国，得一个属地的国度，立刻飞黄腾达，享受至高的荣华富贵。这场辩论中有两个过错。首先，使徒们的过错在于他们撇下对所蒙召之争战的关切，竟提前要求安息、酬劳和荣誉，仿佛他们已是服满兵役的战士。第二个过错是：他们本应同心合意地相互帮助，使弟兄们与自己同享尽量多的荣誉，却怀着邪恶的野心彼此争胜。我们若希望自己的生活蒙主悦纳，就当学会忍耐地担当主所放在我们身上的十字架的重担，直到得冠冕的合宜时刻来临；并且如保罗所劝勉的，*恭敬人，要彼此推让*（罗马书 12:10）。与第一种过错紧密相连的，是今日某些人的虚妄好奇——他们撇下本职的责任，急切地想飞越云霄。主在福音中召我们进入祂的国，并指明我们当走的道路。那些反复无常的人，对信心、忍耐、求告神和其他敬虔操练毫不关心，却争论天上正在发生的事；这就如同一个将要出门旅行的人打听住宿之处在哪里，却不动一步。既然主吩咐我们在地上行走，那些热衷于辩论已故圣徒在天上情形的人，恰因此而阻碍了自己向天迈进的脚步。

<a class="verse-anchor" id="matt-17-2"></a>

**马太福音 17:2.** *耶稣便叫一个小孩子来。* 这段话的总体意思是：凡想要凌驾于弟兄之上、追求显赫地位的人，不但得不到所求的，反倒连最卑微的角落也不配占据。基督在此从反面立论，因为唯有谦卑能使我们升高。由于眼见的形象更能打动我们，他便以*一个小孩子*作为谦卑的象征摆在他们面前。他吩咐跟随他的人要变得*像小孩子*，这并非毫无分别地适用于一切方面。我们知道，孩子身上有许多缺点；因此保罗劝我们要作*小孩子*，不是在*心志*上，而是在*恶事*上（哥林多前书 14:20）；他在另一处又劝勉我们当竭力达到*完全人*的地步（以弗所书 4:13）。然而，由于*小孩子*并不晓得谁该被高看，也不晓得争夺最高位次，基督就愿他们的榜样能从跟随他之人的心中赶出那种对显赫地位的热切渴求——这正是恶人与世俗之子不断纵容自己的事——免得他们被任何形式的野心所诱惑。或许有人会反驳说，孩子从在母腹中开始就有一种天生的骄傲，使他们追求最高的荣誉与地位；但回答显而易见：比喻不可被过于紧扣或过于精确地推演，以致在每一点上都要一一对应。小孩子稚嫩的年龄以一种单纯为标志，他们既不晓得尊荣的等级，也不知任何撩动骄傲的诱因；因此基督正当而合宜地把他们举为榜样。

<a class="verse-anchor" id="matt-17-3"></a>

**马太福音 17:3.**[^译注] *你们若不回转。* 此处所说的*回转*，须参照前面*小孩子*的例子来理解。他们至此一直过分习惯于世人通常的方式；若要达到所追求的目标，就必须走一条截然不同的道路。[^499] 各人都为自己谋求头等或次等的地位；但基督却不肯将哪怕最末的位分赐给任何不肯撇下尊卑之别、不肯*自卑*的人。相反，祂说，**4.** *凡谁像这小孩子般自卑的，他在天国里就是最大的。*这是要防止我们以为：自愿放弃一切尊位，就在某种程度上贬低了自己。由此我们可以得到关于谦卑的一个简短定义。[^500] 真正谦卑的人，既不在神面前自夸有任何个人功德，也不骄傲地藐视弟兄，或图谋被人看为高于弟兄，而是以自己作为基督肢体中的一员为足，别无所求，惟愿独尊那元首。

<a class="verse-anchor" id="matt-17-5"></a>

**马太福音 17:5.** *凡为我名接待一个像这小孩子的。* 基督在此用"小孩子"一词比喻那些放下高傲眼目、以谦逊卑微行事的人。此言乃为安慰之语，使我们不至于把操练谦卑视为烦扰或令人不快之事；因藉着谦卑，基督不仅将我们置于祂的保护之下，也使我们蒙人所喜悦。由此信徒受教，当如何彼此看待：就是各人*谦卑自己*。世人之间的友谊通常是如何维持的呢？岂不是各人迎合他人的心意？人越渴望博取名声，就越蛮横地攫取权力，欲使自己被高举到尊贵的地位，而使别人受人嘲笑或轻视；但基督却吩咐说，人越是自卑，就越要被高举。路加福音所记的话也是同样的意思：*你们中间最小的，他便为大；* 因为我们的主并非吩咐我们要更加看重那些本当受轻视之人，乃是要看重那些卸下一切骄傲、甘愿屈居末位之人。

<a class="commentary-anchor" id="matthew-1724-27-comm"></a>

**马太福音 17:24** *他们到了迦百农。* 我们首先必须留意这段叙述的目的——基督借着主动缴纳丁税，宣告了祂的顺服，正如祂*取了奴仆的形像*（腓立比书 2:7）；然而同时，祂也借着言语和神迹表明，祂将自己降卑到这般地步、以致世人将祂看作不过是普通人中的一员，并非出于义务或必要，乃是出于自由、自愿的顺服。这并不是过海时通常要求缴纳的过路费，[^577] 而是按人头每年向每一个犹太人征收的丁税，以致他们将本来惟独应当献给神的款项缴给了暴君。我们知道，这项税是律法所规定的：他们每年缴纳半舍客勒（stater，斯达特银币）（出埃及记 30:13），以此承认那救赎他们的神乃是他们至高的君王。当亚细亚诸王将这税据为己有时，罗马人便效法他们的榜样。如此，犹太人仿佛否认了神的统治，将律法所要求的圣税缴给了亵渎神的暴君。然而，基督作为祂百姓的救赎主显现时，若祂自己竟也*缴纳丁税*，这似乎是不合理的。为了除去这种冒犯，祂用言语教导：祂之所以受这约束，纯粹是出于祂自己的意愿；并且祂以神迹证明同一件事——那位掌管海与鱼的主，本可使自己免于地上的政权管辖。[^578] *你们的先生不纳税吗？* 有人认为收税的人有意要找基督的把柄，仿佛祂在声明自己可以豁免于通用的法律之外。我个人看来，由于这一类人多半傲慢无礼、口出恶言，我把这句话解作带有讥讽意味的责难。按惯例，每个人都要在自己本城登记入册；但我们知道，基督在某一处并无固定的居所。因此这些人盘问祂：是否因祂频繁往来各地，便可豁免于这条律法之外。[^579]

<a class="verse-anchor" id="matt-17-25"></a>

**马太福音 17:25。** *他说：纳。* 彼得的回答含有一种谦逊的辩解 [^580]，以使他们满意：他说"他会纳的"[^581]；由此我们推断，基督从前一向是纳税的，因为彼得是把它当作毫无疑问的事来应承的。他们向彼得而非其他门徒提出要求，依我推测，是因为基督与他同住；倘若众门徒都住在同一处所，则要求会一视同仁地向所有人提出。因此，教皇党人凭如此轻浮的借口便把彼得抬举为基督尊荣的同伴，实在荒谬可笑。他们说："基督拣选他作自己的*代理人*（vicar），并赋予他同等的尊荣，使他在纳税之事上与自己平等。"但照此说来，他们就要把所有牧猪人都当作基督的*代理人*了，因为他们所纳的与基督一样多。再者，若彼得的首位身份是借纳税显明的，那么他们自己所主张的豁免又从何而来呢？然而这正是那些随己意曲解圣经者所作无耻儿戏的必然后果。*西门，你的意思如何？* 在这里基督显出了祂的神性的凭据，因祂表明没有什么是祂所不知的。但祂这番话的目的何在？是要使祂自己和祂的门徒免于服从律法吗？有些人这样解释：基督徒原有权得豁免，但他们自愿服从常规的治理，因为否则人类社会便无法维持。然而在我看来，其意更为简明；因为存在这样一种危险：门徒可能以为基督是徒然而来的，因祂借纳税之举切断了拯救的盼望；故此祂只是断然申明：祂之所以纳税，纯粹是因祂自愿不行使祂的权利与权能。由此可推断，这丝毫无损于祂的国度。但祂为何不公开主张祂的权利呢？因为祂的王权乃为收税者所不识。因为，纵然祂的国是属灵的，我们仍当坚持：作为神的独生子，祂也是全世界的继承者，因此万有都当服从祂，承认祂的权柄。故此其意乃是：神设立君王，在人间设立政府，并非将那位作儿子的与众人无别地同列一等；然而祂还是甘愿自降为仆与人同列，直到祂国度的荣耀彰显之时。教皇曾愚蠢却得逞地滥用这段经文，使其神职人员豁免于律法；仿佛剃发就使他们成了神的儿子，便可豁免于贡赋税捐。然而基督的本意无非是为自己主张一位王子的尊荣，使祂至少有一个享有特权、豁免于普通律法的家。因此，重洗派曲解此段经文以颠覆政治秩序，也同样极其愚妄；因为再没有比这更确定的了：基督在此并未谈及信徒所共有的某种特权，而仅仅是从君王之子（连同其家臣）享有豁免一事中引出比拟。[^582]

<a class="verse-anchor" id="matt-17-27"></a>

**马太福音 17:27。** *投下钩子。* 虽然我承认基督并非常常有充足的银库，然而我认为，祂吩咐彼得这样做，并非因贫穷所迫，而是要藉一个神迹证明：祂的统辖比一切地上的君王更为广远，因为连*鱼类*也是祂的进贡者。我们读不到此事曾发生过第二次，因为一次证明已足以贯穿祂的一生。*你必得着一块钱。* 一块钱（*stater*）与一舍客勒等值，即四个得拉克玛，或两个双德拉克马。[^583]
