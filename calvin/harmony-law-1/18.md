<p class="title-block-h1" style="text-align:center; font-size:22px; font-weight:bold; margin:18px 0 12px;" markdown="1"><span style="color:#0000d4">出埃及记 18</span></p>

<p style="text-align:center; margin:18px 0;" markdown="1"><span style="color:#000080">前往 出埃及记 18: 1-12</span></p>
**出埃及记 18:1** <span style="color:#800000">*当米甸的祭司叶忒罗。*</span> 本章分为两部分。首先记述叶忒罗来到营中，为摩西事业的顺利成功向他道贺，并向神献上颂赞与祭物。其次，陈明他为百姓所建议的治理体制，因此拣选了审判官与官长，免得摩西在繁重的重担之下不支倒下。大多数注释家认为，西坡拉因儿子受割礼一事被激怒，途中折返，回到父亲那里居住；但在我看来这并不可信。因为摩西绝不会容许自己的儿子被剥夺那救赎，而他正是这救赎的执事；他的儿子日后既被立为祭司，若神不是他们的救赎主，这也说不通。此外，倘若他把妻儿安置在稳妥之处，独自一人前往那场争战，他就理当被人怀疑心怀诡诈，或过于怯懦。因此我毫不怀疑，他与全家一同担负了那使他们长久受压的悲惨奴役之轭，借此为证显明自己的忠信，好叫他的呼召更具权威。至于第二节中「打发她回去之后」这句话，我理解为指摩西：他曾把妻子从旷野打发回去探望她父亲，或是顺应了她作为妇人天然的愿望，或是出于自己敬虔的心意，愿意借此向这位与他亲近的老人表示尊敬。有些人补上「打发礼物回去之后」的说法，读来牵强而冷淡。经文这样读来才通顺：摩西打发妻子回去之后，他岳父又把她带了回来，如此往还，报答摩西的恩情。

<!-- PAGE 224 -->
**出埃及记 18:3** <span style="color:#800000">*又带着西坡拉的两个儿子。*</span> 在合宜之处已经论及，摩西给他两个儿子起这些名字时，所彰显的不仅是信心，更是何等卓越的一份心胸恢宏与坚定不移的凭据。因为我们不能怀疑，他给其中一个（革舜）起名叫「在外邦作了寄居的」，因而招致了姻亲的嫌恶，仿佛他藐视妻子的本国；而他儿子的名字则不住地宣告：他虽住在米甸，心里却仍是个外人；虽暂且寄居，日后却要另寻居所。由此我们也可以推想，他宁可把这两个儿子带进埃及，也不愿因妻子一时的忿怒与责备，就把这两个虔诚的凭据从自己身边打发走；因为借着他们的名字，他每日都被提醒：神的约当被高举在一切属地的好处之上。

**出埃及记 18:5** <span style="color:#800000">*叶忒罗，摩西的岳父。*</span> 促使这位年迈、被岁月压弯了腰的老人[^f195]离开家乡、进入旷野的，与其说是对摩西的爱，不如说是那些神迹的名声；因为下文将从上下文中显明，他并非出于野心而来；因为他向神献祭之后，又在庄严的感恩中见证他将一切荣耀单单归于神，随后便怀着与来时同样的质朴回到了家中。摩西自己在本章开头也已陈明他来的缘由，因为他并没有说叶忒罗听闻了女婿的到来，而是听闻神在拯救摩西与百姓时的良善与大能是何等奇妙。因此，他渴望亲眼目睹几分他所听闻之事，不愿因留在家中而错过神慷慨恩惠的这些辉煌明证。我已经解释过为何何烈山被冠以「神的山」之名。诚然，摩西先前在那里所蒙的异象，已使它配得这尊贵的称号；但在此处，如同先前一样，所指的更是律法的颁布——神藉此将这山分别为圣归于自己。

<!-- PAGE 225 -->
**出埃及记 18:7** <span style="color:#800000">*摩西迎接他的岳父。*</span> 在前一节中，他叙述了最后发生的事，即叶忒罗说：我来了，把你的妻子和儿女都带到你这里；但这种前后倒置在希伯来文中是常见的。如今他接着说，摩西出去迎接岳父，向他致敬；二人彼此以恩慈相待，各尽亲情之谊。「彼此问安」[^f196] 无异于探问对方是否平安顺遂。但要点在于，摩西向他述说神何等恩待祂的子民；因为他整段陈述的主旨就是：当他离开岳父时，并非出于轻率的冲动，而是顺服了神的呼召，正如后来藉着神非凡的帮助与天上的奇事所证实的那样。

**出埃及记 18:10** <span style="color:#800000">*叶忒罗说：耶和华是应当称颂的。*</span> 由此可见，虽然当时对神的敬拜到处被种种外来的添加所玷污，叶忒罗却并未沉溺于迷信，以致不认识、不尊崇那位真神。然而，他随后所作的对比——「耶和华比万神都大」——却表明他并非纯全、毫无谬误。因为，虽然众先知也常这样说，其含义却截然不同；有时神被高举在众天使之上，为要显明惟有祂至尊，使一切属天的尊贵各归其位；有时神也被不甚恰当地称为「更大」，并非好像那些假神有何等级可言，乃是要使世人虚妄愚昧地归给它们的那种「伟大」归于无有。但叶忒罗在此却按着流俗的观念，设想有一大群次等的神明从属于至高者之下。因此，凡是神纯全的真理不发光照的地方，宗教就从来不是纯净清明的，总掺杂着一些渣滓。与此同时，叶忒罗似乎有所长进；因为他既宣称自己如今知道了神的大能，就暗示他比先前得着了更正确的教导；除非，或许有人宁愿把这理解为那种经历性的认识——这认识连信徒也得着坚固，使他们更甘心地降服于那位他们早已认识的神。同时，毫无疑问，他以「耶和华」这名所指的乃是以色列的神；因为，尽管各处的人都夸口说自己敬拜永恒的神，他却藉着确认独一真神的真实神性，把一切别神都置于祂之下。无论如何，他承认自己藉着他们蒙拯救的历史，确信了那在以色列显明自己的神有何等无量的大能；以致与祂相比，世上别处所尊崇的一切神明都不足挂齿。第 (11) 节后半句 [^f197] 尚未完结；因为原文如此：「照着他们向他们发狂傲所凭的话（或缘由）」；这样，用以表明神照埃及人残忍所当得的报应施行报还的那个主要动词便阙如了；正如祂向一切狂傲无怜悯地苦待邻舍之人宣告「审判是没有怜悯的」（雅各书 2:13），这与我们主耶稣基督的宣告一致：「你们用什么量器量给人」云云（马太福音 7:2）。

<!-- PAGE 226 -->

有些人给出的解释似乎太过局限，即：那些曾把婴孩淹死在河里的埃及人，自己也在红海中被淹死。因此，我更愿意将其推广到他们所受的每一样刑罚上。

**出埃及记 18:12** <span style="color:#800000">*摩西的岳父叶忒罗。*</span> 我虽然并不认为叶忒罗从前曾向偶像献祭，但因他所敬拜的乃是一位未识之神，其信心含混而晦暗，看来这乃是自以色列的神更清楚地向他显明之后，他头一次真诚而合宜的献祭。我们由此可以推断，这祭是按正道献上的，因为摩西、亚伦和众长老都公开表明自己与他为伴，并与他一同用饭；经上不单说他们来与他吃饭，更说是「在神面前」吃饭——这话所描述的乃是一场神圣而庄严的筵席，是献祭与敬拜神的一部分与附随之事。他们断不肯为讨好一个不虔之人，甘愿沾染外邦人的污秽。既然如此，可见这乃是他敬虔的凭据，因为他们毫不迟疑地与他一同领受。诚然，我们每逢领受神的恩惠时，都当将神摆在眼前；但下文我们将会看见，这话尤其用于献祭之事，就是信徒在其中将自己置于神面前。然而，我并不承认叶忒罗是凭着他在米甸地所行使的祭司职分宰杀祭牲；乃是因为在神颁布律法以先享有更大的自由，此点将在合宜之处加以说明。我坚定地认为，「饼」这个词无疑是指吗哪而言。

**出埃及记 18:13** <span style="color:#800000">*事情就这样成了。*</span> 这里引入了一件值得纪念、也极值得认识的事。在这个由神亲自掌管、并以祂荣耀的非凡彰显所尊荣的治理体制中，竟有当受责备之处，是叶忒罗所纠正的；而且摩西自己——那位大能的先知，是唯独神如此与之亲密来往的人——也理当受责，因为他不加思量地以过度的劳碌耗损了自己，也耗损了百姓。他承受如此众多的患难，忍耐如此深重的疲乏，日复一日地投身于新的辛劳而不被困乏所压倒，这诚然是他卓越美德与心志英勇的明证。他甘愿为这悖逆邪恶的百姓无偿地劳苦，虽然他良善的努力所得的回报是不配的，他却始终不肯放弃自己的目标——这也显出一种再怎么称赞也不为过的宽宏气度。因为我们已经看见，他屡屡遭辱骂与凌慢的攻击，又被斥责与恐吓所侵扰；因此，他的忍耐虽如此不断地被人辜负，却没有被完全磨尽，这实在超乎寻常地可惊叹。在这里，确实可以发现许多配得最高称赞的美德；然而叶忒罗正是在这些可赞之处找到了当责的把柄。由此我们受到警戒：在人最优秀的行为中，总有某种缺陷潜伏其间，几乎没有一件事在各方面都完美到毫无瑕疵。所以，凡蒙召作人类治理者的，都当知道：无论他们如何殷勤地履行自己的职分，若把他们所采用的最佳方案拿来受审察，仍会有所欠缺。因此，无论君王、官长，还是教会的牧者，都当知道：当他们竭尽全力去尽自己本分时，总仍会留下某些可加以纠正与改进之处。在此也值得留意：没有哪一个必死的人能够独自完成一切，无论他所擅长的恩赐何等繁多、何等多样。因为谁能与摩西相比呢？可我们仍看见，当他独自担起治理全体百姓的重任时，尚且不胜其负。那么，愿神的仆人们学会谨慎地衡量自己的能力，免得因野心勃勃地揽下过多的事务而致耗竭。因为这种想要涉足过多事务的倾向（<span style="color:#0000d4">πολυπραγμοσύνη</span>，好多事）是一种极普遍的病症，许多人被它所裹挟，以致难以约束。因此，为叫各人都持守在自己的本分之内，让我们明白：在人类当中，神如此安排了我们的处境，使个人只被赋予一定分量的恩赐，而职分的分派正取决于此。因为正如太阳的一道光线并不能照亮全世界，乃是众光合力仿佛化为一体般运作；照样，神为要以神圣不可解的纽带将人保守在彼此的团契与善意之中，便以各样不同的方式分派祂的恩赐，使人彼此相联，而不叫任何人凭其全备的完美被高举过度。所以奥古斯丁 [^f198]真确地说，神藉此举使祂的仆人谦卑下来；正如保罗所述，有撒但的差役加诸他身上的击打，免得他因所得启示的伟大而被高举太过。（哥林多后书 12:7）

**出埃及记 18:15** <span style="color:#800000">*摩西对岳父说。*</span> 摩西的回答坦率诚恳，仿佛这是一件极值得称许的事，像一个对自身过失毫无察觉的人；因为他自称是神的仆役，是祂圣灵的器皿。诚然，他的忠信与正直是无可指摘的。他惟一的过失，乃在于以过多的劳苦压垮自己，既未顾及自己的私事，也未顾及众人的公务。然而，从他的话中仍可拾取一条有益的教训。他说，争讼者前来「求问神」，又说他使他们晓得神的律例和法度。由此可见，政治治理的目的正在于此：要在地上设立神的审判台，好叫祂在其上行使审判者的职分，使审判官与官长不至僭取一种不受任何律法约束的权力，不容自己任意妄为地判决任何事，一言以蔽之，不至将本属于神的据为己有。惟有那时——也惟有在那时——官长才算尽了本分：就是当他们记得自己乃是神的代表（*vicarios*）之时。这里也对一切平民百姓课以一项义务，就是他们不可鲁莽地诉诸审判官的权柄或帮助，而当以纯洁的心亲近他们，如同求问神一般；因为凡怀有别的目的、而非要从官长口中领受何为正、何为义之人，都是放肆而亵渎地玷污了那奉献给神的职位。

**出埃及记 18:17** <span style="color:#800000">*摩西的岳父说。*</span>他并非像那些乖僻、执拗或好高慕名之人那样，对摩西先前所采用的整套办法一概加以谴责——这等人惯于抓住些许琐事吹毛求疵，从而掩没他人的高尚作为；相反，他只求纠正其中一部分，丝毫无损于摩西当受的称赞，也毫不触动神所赋予他的权柄。他这份持守分寸的态度值得留意，因为他并未借着某一处具体过失为由，去搅乱事物应有的秩序，而只是劝导摩西如何能有益地履行神所托付给他的职分。

<!-- PAGE 229 -->
**出埃及记 18:19** <span style="color:#800000">*我要给你出个主意。*</span>叶忒罗固然敢于应许必获成功——只要摩西肯听从他的主意；然而他并不骄傲地夸口说这将是他自己审慎的果效，反倒把它归于神的赐福与恩典，因为纵使一切都建立在最完善的制度之上，若得亨通，也仍出乎神。这正是此语的含义：他心中生出一个主意，摩西若照着行，神必赐福与他。他也并非责备摩西，仿佛神此前未曾与他敬虔的热心和勤劳同在，反倒暗示神才是这主意的创始者，并且神必以祂的恩典成全之。总而言之，他绝无意丝毫削减摩西早已经历过的恩典，只是要指出一个计划，神必藉其结果显明祂的嘉许。接下来便是我先前提及的另一要点，就是：他并不剥夺摩西的权柄，以致推翻摩西从神而来的呼召，反倒藉着劝勉他继续前行，期望神一次所命定的事得以坚立、不可侵犯。我们也当殷勤思想：所定的主意须照着处境与合宜而定，却不可偏离神的典章；因为若心里盘算究竟当不当顺服神，这本身就是罪。因此，凡在商议中提议要更改神话语中的任何事，或要使我们脱离所蒙呼召之界限的，都是可咒诅的。我们已经说过，压在摩西身上的重担并非神所加的；他不过是照着自己能力所及，被立为百姓的领袖。叶忒罗对此丝毫不加更动，如此便仿佛在天上的谕旨上签名附署，予以确认。因摩西蒙拣选作解释者，且神亲切地准许他作神与祂百姓之间的中保，叶忒罗便嘱咐他继续履行这些职分。但因执掌最高治理之权并不妨碍先知的职分，他也愿那更重大的事仍归摩西裁断；因我这样解释这些话：摩西要「向着神」，负责传递敬虔的准则，并履行先知的职分，而那些更重大的案件则由官长转呈给他，好使各人都得着公义的裁断。

**出埃及记 18:21** <span style="color:#800000">*此外，你要*</span> [^f199] <span style="color:#800000">*从百姓中拣选*</span>。字面直译作「你要供备」，意思是你要挑选出来，选取最配得的人，免得这样的职分被草率地托付给任何自荐之人。然而在一个自由的民族之中，这原是最合理的：审判官不应因财富或地位被选立，而应因德行的卓越被选立。可是，尽管理当以德行为首要考量——以致若有出身低微者比别人更为合适，就当使他优先于贵胄或富人——但倘若有人执意要把这立为一条永久必守的规条，他就理当被算为好争竞的人。叶忒罗列举了在设立审判官时必须首先看重的四项资格，即：办事的才干、敬畏神、正直，以及轻看钱财；这并非要排除其他资格（正如我们不久将看到的，申命记第一章便题及别的资格），而是要表明并非人人都够格，甚至可说，所需要的乃是超凡的德行，他借提喻法将这些德行囊括于这四项之中。我们译作「勇敢的人」[^f200]（*viros fortes*）的字眼，在希伯来文中作「有勇力的人」（*viros fortitudinis*）；有些人认为这一称号是在描述强壮而勤劳之人。但依我之见，摩西所指的乃是奋发而有胆量的人，他将这等人不仅与懒惰之辈相对，也与胆怯懦弱之辈相对。但因心智与身体的强健若无敬畏神便是脆弱的，故他在第二项加上了敬虔，使他们在履行职分时如同要向神交账一般。「诚实」不仅与欺骗和露骨的谎言相对，也与沽名钓誉、阿谀的许诺以及其他扭曲公义的诡诈手段相对。最后，所要求的乃是憎恶贪婪；因为没有什么比贪图私利更与公义相悖的了；既然审判官时常被钱财之利的引诱所设的网罗环伺，他们若不痛恨贪婪，便无法妥善地防备这种腐败的手段。

**出埃及记 18:23** <span style="color:#800000">*你若这样行。*</span> 紧接着的话「神也这样吩咐你」，可以与本节开头联系起来理解，仿佛叶忒罗在自我修正，作出限定：他并不愿自己的建议被采纳，除非神认可。另有人把它作更宽泛的理解，即摩西若在凡事上遵行神的吩咐，这样节制自己的职责便有益处。无论怎样理解，叶忒罗都声明：他绝不愿有任何让步而有损神至高的权柄；然而，摩西大可像先前一样，仍以神为自己的领袖去跟随，同时又采纳这所提的方案。不过他也表明这只是暂时之举，因他随后补充说，百姓好平平安安地或顺顺利利地进入迦南地。可见叶忒罗无意为后世立定一条律法，而只是为眼前的不便指出补救之法，作一项临时性的安排，[^f201] 直到百姓得着安歇之所。

**出埃及记 18:24** <span style="color:#800000">*摩西听从了。*</span>这里有一个关于谦卑的显著例证，即摩西并不排斥顺服他岳父的谋划。因为虽然叶忒罗在年岁上、在姻亲的辈分上高于他，但在其他方面却远逊于他。摩西如此屈从于叶忒罗的权柄，为一切最伟大、最卓越的教师立下了一条准则：他们不当拒绝接受那些他们承认其教导正确之人的劝诫，纵然这些人并没有那样崇高的尊位。因为居普良（Cyprian）[^f202]真确地宣告说：凡不肯受教的，就不是好教师。这位老人多半是随即返回家中，并非出于轻慢，也不是因为厌恶劳苦或疲乏，而是[^f203]因着他的年岁；然而我们此后将在适当之处看到，他的儿子仍留在营中。
