<p class="title-block-h1" style="text-align:center; font-size:22px; font-weight:bold; margin:18px 0 12px;" markdown="1"><span style="color:#0000d4">申命记 4</span></p>

<p style="text-align:center; margin:18px 0;" markdown="1"><span style="color:#000080">前往 申命记 4: 5-14</span></p>
**申命记 4:6** <span style="color:#800000">*所以你们要谨守遵行。*</span> 为要使他们更加欢欣地投身于守律法，并在这努力中更加坚定不移地前行，他提醒他们：再没有什么比这对他们自身更美好、更可羡慕的了。因为惟有以甘心的心志和自愿的顺服，神才得着当得的尊荣；而我们乃是被喜乐所吸引去如此行，而非被严苛与强力所逼迫。既然人人都渴望出类拔萃，他便说，以色列首要的卓越之处，就在于他们有神作他们的立法者与师傅。倘若有人反对说，他这话可用两个论据来驳斥，即：神的律法为外邦列国所不知；且其中所规定的敬拜神的样式，以及整个犹太宗教，不仅被他们藐视，更被他们憎恶；我的回答是：这里并非绝对地断言别国要作审判者或仲裁者，而是这话当如此理解，就是说：若有哪一国得着正确的领悟，断不敢将自己与你们相比，更不敢将自己置于你们之上；因为单凭这一比较，它就必承认神已将你们高举到何等尊贵的地步。所以，纵然律法的教训几乎为全世界所忽视，甚至所憎恶，摩西仍真实地宣告：既然神屈尊将生活的准则赐给犹太人，就等于在列国面前搭起了一座舞台，好叫这一民族的尊贵在其上显为夺目。因为神的荣耀岂可因瞎眼之人的无知而被玷污或熄灭，这是断不合理的。然而我们从这段经文可以看出：惟当我们倚靠神的话语、使自己的感受降服于祂的启示时，我们才是真正有智慧的。我把这几个字译作「这民实在 *(certo)*」，其中所用的希伯来小品词 <span style="color:#008080">רק</span>，[^f226] *rak*，常带排他之意，故也可恰当地承载这层含义：「惟有 *(Only)* 这民」云云。无疑，这里所指的，乃是这民因蒙恩的特权而享有的卓越地位。

**申命记 4:7** <span style="color:#800000">*因哪一大国的人有神与他们相近？*</span> 摩西如今以自己的名义重述他先前借他人之口所讲的话，仿佛要以更多理由表明：犹太人得以在普天下受人称颂，绝非无因，因为事实必要显明，无一民族能与他们相比。他提出两点：第一，凡他们呼求神的时候，神必乐意施以帮助；第二，神已将全备的义教导他们，此外再无可求的了。因为当他说神「与他们相近」时，我把这句理解为神大能同在的临格，这大能已借着许多神迹充分彰显出来。他理所当然地否认外邦人曾从他们的神明得着这样的帮助，因为他们的祈祷与呼求都是献给聋哑死寂的偶像的。

**申命记 4:9** <span style="color:#800000">*你只要谨慎*</span> 此处所用的仍是我方才所说的那个虚词 <span style="color:#008080">רק</span>，*rak*，它在这里的意思，就好像摩西说：这是*惟一*剩下当行的事；除非有人更愿把它译作*然而*。接下来的话，直译是「看守 *(custodi)* 你自己，看守你的心灵」；摩西在此层层递进，提醒他们所需的并非寻常的谨慎，而是必须以极大的警醒与殷勤加以防备，免得因缺乏这些而失足；因为肉体的懒惰必须借这类激励加以鞭策，同时我们的软弱必须得着坚固，我们也必须防范自己的不坚定；因为再没有比这更容易的事：我们一切的热心会突然被忘却，或渐渐变冷。神已按其所需，为那心存感恩、专心留意的人确立了祂律法的确定性，然而祂盼望百姓记念人是何等疏忽，这并非没有缘由。祂所吩咐要记念的，不单是那些亲眼见过的人，更要他们把（所见的事）传给自己的子子孙孙，好叫这等奇妙之事的记忆得以留存。

<!-- PAGE 268 -->
**申命记 4:10** <span style="color:#800000">*就在你站立的那日。*</span> [^f227] <span style="color:#800000">*那日你站立。*</span> “日”（*day*）一词或可作宾格解，视为同位语。无论如何，显而易见，他是在更充分地阐明先前所简略提及的内容，因为他召唤百姓作亲眼见证的人，免得他们或许会反对说，他们无法确知摩西是从何处得来他所宣称是神所吩咐他的教训。因为他们都清楚知道，凡他所行的，无不出于神明确的命令。最后，他从这教训本身的目的与宗旨来证明，神乃是它的创始者，因为这教训所指向的无非是要人纯正地事奉神，并使祂的子民顺服——再没有什么比这更公义、更正当的了。

**申命记 4:11** <span style="color:#800000">*那时你们近前来，站在山下。*</span> 这段解释性的叙述意在证明同一件事，即摩西不过是神的使者和仆人，因为那山在众百姓眼前焚烧，好叫神彰显自己，从火中说话。摩西说他们只听见声音，却没有看见任何形像，这可以理解为一种让步的说法 *(concessionis，让步)*。这样，这两个分句便当作转折句来读：「虽然没有形像显现，却有声音直达你们的耳中。」但我认为，这句话之所以被明白地陈述出来，乃是为要更清楚地表明这是神的声音，并非出于人；因为没有人能用巧计如此隐藏自己，以致说话时不被人看见，然而他们却看见那声音从火中发出，并无任何外在的凭借。

**申命记 4:32** <span style="color:#800000">*你且考察。*</span> 摩西在此更加有力地颂扬并盛赞那些神迹——他先前只是较为简略地叙述这些神迹曾在律法颁布之时发生——其用意在于使人更充分地确信律法的尊荣。他也藉着比较来彰显那些确证律法权威的凭据，即：从未有过任何与之相似的事；因为倘若先前曾发生过任何此类的事，律法便会因此失去一部分它的珍贵或尊荣。然而，既然从世界之初，神只曾一次如此辉煌地彰显祂的大能，这便更加坚立了律法的权威。他还补充说，纵使他们遍寻全地，也无处能找到任何类似的事。因为我不赞同某些人对这一句所作的那更为精巧的解释，仿佛他是说，天上地下一切受造之物都可作见证：神的能力从未藉着如此众多、如此辉煌的神迹显明过；同样，另一些人所给的意思在我看来也过于狭隘，他们把「已过的日子」理解为编年史或年鉴；因为我毫不怀疑，摩西不过是要他们查考、察验：自从世界受造以来，或在任何最遥远的地区，是否曾有任何这样的事发生过。

<!-- PAGE 269 -->

**申命记 4:33** <span style="color:#800000">*曾有何民听见？*</span> 他更明白地指出他方才所提之事的伟大与超凡卓绝，即他们听见了　神从火中说话的声音。诚然，外邦人的种种迷信自古以来曾借着许多显现得着印证，然而在这些可悲之人为了甘愿自欺而杜撰出来的奇象之中，没有一样能与此神迹相提并论。许多人各自撒过谎，他们虚妄愚拙的传说也被人轻率地信以为真；但我们在此所论的，并非毫无根据、零散流传的谣言，也非某一个人的梦幻，乃是摩西举出了超过七十万的见证人，　神的荣耀曾向他们清楚而确凿地显现；因此他补充说，　神从未尝试行过同样的事，只赐下这独一无二的实例，使祂的律法在万世中显为荣耀。[^f228] 然而在这一节中，他不仅提及律法的颁布，也提及他们蒙拯救的全部经过，因他笼统地题到祂的「试验和神迹」。他说　神「从别国中将这一国的人民领出来」，因祂以无与伦比的大能拯救了亚伯拉罕的后裔；他们虽分散在埃及各处，仿佛被困在其腹中，却不过是一个极其著名之国里默默无闻、微不足道的一部分；这样的事再无相似的先例可寻。[^f229]

<!-- PAGE 270 -->
**申命记 4:35** <span style="color:#800000">*向你显现这事。*</span>他首先说，神已藉着神迹与奇事如此证明了祂的神性，使以色列人可以确知祂就是神。由此他也断定，祂是独一的真神；因为尽管神的圣名被众说纷纭撕扯得支离破碎，人人都为自己制造各样的神明，然而仍可确知，神的权能与统治不能从祂身上被夺去，乃是存于逻辑学家所谓的单一*主体*之中。所以，独一之神的本质推翻并消灭了我们愚昧地为自己所杜撰的一切其他神祇。这一点我们必须谨慎留意，因为寻求众神杂糅乃是各世代共有的通病，然而这一切的臆想都应在真神的荣光面前消散无踪。在下一节中，他坚固了这一宣告，因为神是从天上、在火中教导祂的百姓。然而或有人问：这两点看似彼此相悖，即神的声音既从天上、又从火焰中间发出，这如何能相合呢？我回答说，摩西无非是要表明，那从火中流入百姓耳中的声音，因带着分明的凭据而与众不同，证明其确是从天而来的。

**申命记 4:37** <span style="color:#800000">*他既是爱。*</span> 这几个字有两种解法；因为连接词「和」既出现在本节开头——「*又*因他爱你的列祖」，也出现在下一分句之前——「就拣选他们的后裔」；因此这里所陈明的理由，可以与上文连起来理解，即：如此多的神迹得以成就，是因为神拣选了亚伯拉罕和他的后裔。另有人则作别样解释，认为这民之所以蒙神赐予如此众多的福分，乃是因为祂爱他们的列祖。这样解时，他们便略去本节中间的那个*连接词*，正如许多地方常须如此处理的一样。就大体而言，二者出入甚微；因为摩西所要表明的是：凡神赐给祂子民的美善之物，无不是白白赐下的，藉此他愈发高举神的恩典。他先前说过，这民是藉着非常之恩宠从别民之中被取出来的；如今他又补充说，这事之所以成就，别无他因，唯独因为神以祂的爱拥抱了亚伯拉罕、以撒、雅各，并将同样的爱持续施于他们的后裔。但我们必须留意，「*爱*」这字所表达的，是那纯出于慷慨的恩宠，以致排除了所爱之人身上的一切配得——这从别处经文可以更清楚地看出，即申命记 7:8 与诗篇 78:68，也从此处的上下文相当明显，因为他将这民的蒙拣选归因于神所加于他们列祖之上的爱。若有人反驳说神的拣选乃是永恒的，这反驳很容易化解，因为亚伯拉罕的后裔之所以从万民中被分别出来，正是由于神白白地收纳了他们的先祖为义子。如今我们明白摩西的意思了，就是：这民得蒙拯救唯独当归于神的良善。他又藉另一情形来放大这一恩典，即：神竟高看这卑微的民过于那些强盛有力的列国，而这民凭自身的配得原是无从赢得祂恩宠的。

<!-- PAGE 271 -->
**申命记 4:39** <span style="color:#800000">*所以，今日你要知道。*</span> 他再次谆谆重申我们方才所论的，即独一真神的荣耀已借着神迹得以证实，只是这次他以劝勉的方式提出。因为他愿他们殷勤专注地思想神向他们所显明的事，因为在如此明白的事上，任何错误或无知都无可推诿。所以他从前面所说的推论出：百姓务要谨慎，切勿在神大能如此清晰的启示面前闭目不视，故此他敦促他们将此存记在心，因为人的忘恩负义极易流于健忘。随后他提醒他们神为何愿被人认识，即为要他们遵守祂的律法、顺从祂的律例。总意就是：他们若不肯顺服领受这明知出于神的律法，就无可推诿；因为神的威严既已借如此众多的凭据被人认识、明白，若这仍不能唤起他们的敬畏，他们就必比愚顽更甚。又恐怕他们轻看这道理，以为它不过出于一个必死的凡人，他便明明承认自己确是那执事者，然而他在他们面前所摆出的，无一不是从神所领受的。
