<p class="title-block-h1" style="text-align:center; font-size:22px; font-weight:bold; margin:18px 0 12px;" markdown="1"><span style="color:#0000d4">诗篇 29 篇</span></p>

大卫为要使万人在神面前谦卑下来，无论尊卑贵贱，便藉着自然界中种种奇妙的作为，颂扬神那可畏的大能；他断言，这些作为激发我们将荣耀归给神，其力量丝毫不逊于神亲口宣告自己的主权与威严。他先使那些心存骄傲、不肯降服的人心生畏惧，向他们发出劝勉，其中夹带温和的责备；随后又甘甜地邀请信徒甘心乐意地敬畏耶和华。

<p style="text-align:center; color:#000080; margin:14px 2em;" markdown="1"><span style="color:#000080">*大卫的诗。*</span></p>

<h2 class="scripture-anchor" id="psalm-29-1-4" data-ref="PSALM 29:1-4" style="display:none">诗篇 29:1-4</h2>

<div class="scripture-box" markdown="1">
<p class="scripture-ref"><span class="ages-code">&lt;192901&gt;</span><span class="book-name">诗篇</span> <span class="verse-range">29:1-4</span></p>

<strong>1.</strong> 神的众子啊，你们要将荣耀、能力归给耶和华，归给耶和华。<strong>2.</strong> 要将耶和华的名的荣耀归给他；要在耶和华圣所的荣光中敬拜他。<strong>3.</strong> 耶和华的声音发在水上；荣耀的神打雷；耶和华打雷在大水之上。<strong>4.</strong> 耶和华的声音大有能力；耶和华的声音满有威严。

</div>

<!-- PAGE 446 -->
**1.** <span style="color:#800000">*民中的勇士啊，你们要将荣耀能力归给耶和华。*</span> 大卫无疑意在引导世人敬拜、敬畏神；但既然那些身居尊位的大人物[^fa569]更难被约束就范，他便特意向他们发言。显然，七十士译本把此处译作*公羊之子*[^fa570]，是被希伯来文词形的相近所误导。至于这词的含义，犹太释经家们其实意见一致；但一论到它的意旨，他们便以最令人索然无味的注解将其扭曲、遮蔽。有人解作天使[^fa571]，有人解作星辰；还有人主张，所指的伟人乃是列祖圣徒。然而大卫的用意，不过是要挫抑这世上的君王——他们被骄傲灌醉，向神高举自己的角。因此，这正是他何以引入神：神以可畏的声音，藉雷轰、冰雹、暴风与闪电，制伏这些顽梗僵硬的巨人；这等人若不被惊恐击打，便不肯敬畏天上的任何权能。由此我们看出，他为何撇开众人，单单向勇士之子发言。原因在于，他们最惯常之事莫过于以不虔的行径滥用其崇高地位，同时狂妄地将一切属神的特权据为己有。至少，为叫他们谦卑地降服于神，并顾念自己的脆弱、倚靠祂的恩典，就必须仿佛以强力相逼。因此，大卫吩咐他们*将能力归给耶和华*，因为他们被自己诡诈的臆想所欺，以为自己所拥有的权能出自天以外的别处。总之，他劝他们撇下傲慢与对自身力量的虚妄看法，照神所配得的荣耀祂。他所说的<span style="color:#800000">*神名的荣耀*</span>（第2节），是指与祂威严相称的荣耀，而这世上的伟人惯于将其从祂夺去。这重复的言辞也表明：非得极力催逼，才能从他们口中逼出一个恰当的承认。<span style="color:#800000" markdown="span">*神圣所的光辉[^fa572]*</span>，并非如某些人所想指诸天，而是指约的帐幕——其上装饰着神荣耀的表记，这从上下文可以看得明白。先知特意提起这地方，即真神曾在其中显明自己之处，为叫众人辞别一切迷信，归向对神纯正的敬拜。敬拜天上任何一种权能都是不够的，唯独那独一不变的神当受敬拜；而这一点，非等到世人从人脑中臆造的一切愚妄发明与礼仪中被挽回，便不能实现。

<!-- PAGE 447 -->
**3.** <span style="color:#800000">*耶和华的声音发在水上。*</span> 大卫此处历数我前面已经提到的自然界的奇妙作为；他在神的工作中，既颂扬神的大能，也颂扬神的良善，实在颂扬得极好。在天地这整个架构之内，寻常的自然进程中没有一样不是在邀请我们默想神；因此他本可以像诗篇 19:1 那样，举出日头、众星、天上的万象，以及大地和它的丰富；然而他只拣选神那些作为——这些作为不单证明世界起初是由他所造、如今由他的大能所治理，更能唤醒那些麻木的人，几乎是不由他们自主地把他们拖来，使他们谦卑敬拜神；正如贺拉斯（Horace），虽然他不但是一位异教诗人，且是伊壁鸠鲁派之徒，是对神明卑劣的藐视者，也不得不在他的一首颂歌中如此说到自己，——（第一卷，颂歌三十四）

<p style="text-align:center; color:#000080; margin:14px 2em;" markdown="1"><span style="color:#000080">*「我曾逃离上天与祷告，*</span> <span style="color:#000080">*嗤笑一切敬虔的畏惧，*</span> <span style="color:#000080">*深究疯狂哲学*</span> <span style="color:#000080">*那迷宫般的学问；但如今*</span> <span style="color:#000080">*我扬起帆来，掉转航程*</span> <span style="color:#000080">*驶回我先前离弃的那蒙福港湾。」*</span></p>

<p style="text-align:center; color:#000080; margin:14px 2em;" markdown="1"><span style="color:#000080">*“看哪，那可畏的天上君父，*</span> <span style="color:#000080">*屡屡以烈火劈开层云，*</span> <span style="color:#000080">*白昼之父，不死的朱庇特（Jove）；*</span> <span style="color:#000080">*近日竟穿越浮荡的空中原野，*</span> <span style="color:#000080">*当天容澄澈明净之际，*</span> <span style="color:#000080" markdown="span">*驱着他轰雷的骏马与飞翼的车辇[^fa573]，”……*</span></p>

经验也告诉我们，那些最胆大妄为、最藐视神的人，恰恰最惧怕雷轰、暴风以及诸如此类的猛烈震动。因此，先知极为恰当地把我们的注意力引向这些事例——它们能叫那些粗鲁麻木的人略略感到神的存在[^fa574]，并且叫他们无论何等怠惰、何等漠不关心，也不得不有所警醒。他没有说太阳日复一日升起，遍照其赐生命的光辉；也没有说雨水轻轻降下，以其滋润使大地肥沃；而是举出雷轰、猛烈的暴风，以及那些以其威势震慑人心的事物。诚然，神在他一切受造物中说话，但先知在此提及的，是那些以其巨大响声把我们从昏睡中——或不如说从麻木中——唤醒的声音。我们已经说过，这番话主要是针对那些顽梗妄为、竭尽所能把一切关乎神的思念从自己身上抛开的人。他所用的这些意象本身已充分表明，大卫的用意是要以惧怕制伏那种否则决不甘心退让的顽固。他三次重复说，神的声音在大而猛烈的暴风中被人听见；在随后一节又补充说，这声音满有能力，满有威严。

<h2 class="scripture-anchor" id="psalm-29-5-8" data-ref="PSALM 29:5-8" style="display:none">诗篇 29:5-8</h2>

<div class="scripture-box" markdown="1">
<p class="scripture-ref"><span class="ages-code">&lt;192905&gt;</span><span class="book-name">诗篇</span> <span class="verse-range">29:5-8</span></p>

**5.** 耶和华的声音震破香柏树；我说，耶和华震破黎巴嫩的香柏树。**6.** 他使黎巴嫩跳跃如牛犊，使西连跳跃如野牛犊。**7.** 耶和华的声音击出[或砍出]火焰。**8.** 耶和华的声音使旷野震动，耶和华的声音使加低斯的旷野震颤。

</div>

<!-- PAGE 449 -->
**5.** <span style="color:#800000">*耶和华的声音震破香柏树。*</span>我们看见，先知为要制伏人的顽梗，便用每一个字表明神是可畏的。他似乎也顺带责备骄傲之人、并那些因虚妄自负而膨胀之人的癫狂，因为他们不肯侧耳听神在雷中的声音——那声音以闪电撕裂长空，震撼崇高的山岭，将最高大的树木倾覆推倒。何等怪异之事：受造之物中一切无理性的都在神面前战兢，惟独禀有知觉与理性的人却毫不动容！不但如此，他们虽有天资与学问，却用法术塞住自己的耳朵，抵挡神的声音，任凭那声音何等有力，总不容它达到他们心里。哲学家们以为，若不把神远远地与他的作为分开，便算不得对次因推论得精妙。然而这乃是魔鬼的学问：它把我们的默想钉在自然的作为上，却使我们转离神。倘若有人想认识一个人，却不看他的面容，只把眼目盯在他的指甲尖上，人尽可讥笑他的愚昧。但那些哲学家的愚昧却远过于此：他们用中间因与近因替自己织成幔子，免得被迫承认神的手，而这手明明在他的作为中彰显自己。诗人特别提到<span style="color:#800000" markdown="span">*黎巴嫩的香柏树[^fa575]*</span>，因为那里有高大秀美的香柏树。他也提到*黎巴嫩*与*黑门山*，以及<span style="color:#800000">*加低斯的旷野*</span>，因为这些地方是犹太人最熟悉的。诚然，当他说<span style="color:#800000" markdown="span">*黎巴嫩因神的声音跳跃如牛犊[^fa576]*</span>、*西连*（也称黑门山）*跳跃如野牛*时，他用的是极富诗意的修辞，并带着夸张——我们知道野牛是跑得最快的走兽之一。他也是在暗指雷霆那可怖的轰响，那响声几乎要把众山从根基上摇动。当他说<span style="color:#800000">*耶和华的声音使火焰分岔*</span>时，所用的比喻也相仿；这事之成就，乃是当水气仿佛被他的锤子击打，便迸发为闪电与霹雳。亚里士多德在他论天象的书中，就近因而论，对这些事推究得极为精细，只是他略去了首要的一点。诚然，若我们借此被引到自然的创造主自己那里去（这本是应当的），探究这些事便既有益又愉悦。但最悖谬的莫过于[^fa577]：我们一遇见中间因，无论其数多少，便被它们绊住、迟滞，如同被许多障碍拦阻，以致不得亲近神；因为这与人终其一生停留在事物的初阶而不再前行，并无二致。总而言之，这样的求学，乃是叫你永不能真知道什么。所以，惟有那种精明才配得称赞，就是借着这些途径把我们高举，直到天上，使我们的耳朵所听见的不只是一片混杂的响声，乃使耶和华的声音穿透我们的心，教导我们祷告并事奉神。有人把希伯来文<span style="color:#008080">יחיל</span>（*yachil*，我们译作*战抖*）作另一种解释，即：*神使加低斯的旷野经历产难[^fa578]*；因为以色列人经过那旷野时，其中显出了许多奇事。但这个意思我不赞同，因为它过于精巧牵强。大卫似乎倒是指着人共有的感受说的；因为旷野本身已是可怖的，何况其中充满雷霆、冰雹与暴风。不过，我并不反对把旷野按提喻法理解为栖息其中的野兽；这样，下一节提到母鹿，便可视为补充的解释。

<h2 class="scripture-anchor" id="psalm-29-9-11" data-ref="PSALM 29:9-11" style="display:none">诗篇 29:9-11</h2>

<div class="scripture-box" markdown="1">
<p class="scripture-ref"><span class="ages-code">&lt;192909&gt;</span><span class="book-name">诗篇</span> <span class="verse-range">29:9-11</span></p>

**9.** 耶和华的声音惊动母鹿落胎，树木也脱落净光[或作：使林木赤露]。凡在他殿中的，都称说他的荣耀。**10.** 洪水泛滥之时，耶和华坐着为王；耶和华坐着为王，直到永远。**11.** 耶和华必赐力量给他的百姓；耶和华必赐平安的福给他的百姓。

</div>

<!-- PAGE 450 -->

**9.** <span style="color:#800000">*耶和华的声音惊动母鹿落胎*</span> 正如我所说的，这里有一个暗含的比较。神的声音对野兽既有如此的能力与影响，人却在神的声音面前毫不动容，这就不只是无理性，简直是骇人听闻的。人不能在整个自然的运行中看出他的护理与治理，这固然已是可耻的忘恩负义；但连他那些非常的、超乎寻常的作为——就是那些迫使野兽都顺服他的作为——也不能教他们得着智慧，这就是一种可憎的麻木不仁了。有些解经者认为，此处提到*母鹿*而非别的野兽，是因为它们生产时格外艰难；我并不反对这种看法。<span style="color:#800000">*耶和华的声音*</span>又被说成是*显露*，或<span style="color:#800000">*把树林剥得赤露*</span>，这或是因为没有什么遮盖能拦阻它穿透最隐秘的深处与洞穴；或是因为闪电、暴雨与狂风把叶子打落，使树木赤露。两种解释都说得通。

<!-- PAGE 451 -->
<span style="color:#800000">*在他的殿中。*</span> 神的声音充满全地，遍及地极；但先知宣告说，惟有在他的教会中他的荣耀才被称颂，因为神不但在那里清晰明白地说话，也在那里以温柔吸引信徒归向自己。他那可畏的声音在空中以各样方式轰鸣，震撼人的耳朵，使人心颤栗，以致他们宁可退缩而不肯亲近他；更不必说有相当一部分人在风暴、暴雨、雷电之中，对这声音充耳不闻。所以，人既在这普遍的学校里得益不多，不足以使自己降服于神，大卫便明智地特别指出：信徒是在神的殿中歌颂神，因为他们在那里被他慈父般的声音亲切地教导，就把自己完全献上、分别为圣归他使用。惟有甘心敬拜神的人，才能正确地宣扬神的荣耀。这话也可以理解为一种控诉：大卫责备全世界在关乎神荣耀的事上缄默[^fa580]不言，并叹息说，虽然他的声音响彻各地，然而除了在他的殿中，别处都无人歌唱他的赞美。但看来，他是效法一切敬虔人的榜样，劝勉全人类都来赞美神的名，并特意建造一座殿宇作为承载他荣耀的所在，为要教导我们：若要真正认识神、照他所配得的赞美他，我们所需要的乃是另一种声音，而非那在雷轰、大雨、空中的风暴里，在群山与森林中所听见的声音；因为他若不用明白的言语教导我们，也不藉着使我们尝到他慈父之爱而亲切地吸引我们归向自己，我们就必仍旧缄默无声。所以，惟有救恩的道理，藉着向我们清楚显明他的恩典和他全部的旨意，才使我们心中欢畅、开口称颂他。我们当如何赞美他，也必须从这里学。我们同样可以毫无疑问地看见，在那个时代，除了犹大地以外，全世界都毫无敬虔之光。就连那些看似最接近认识神的哲学家，也丝毫没有贡献出任何真能荣耀他的东西。他们论及宗教所说的一切，不但冷淡无力，而且大半淡而无味。所以，惟独在他的话语中，才闪耀着[^fa581]那能引我们进入真敬虔、并正确地敬畏事奉神的真理。

**10.** <span style="color:#800000">*洪水泛滥之时，耶和华坐着为王。*</span> 有些人认为，大卫在此暗指神施行报应的那件可记念的事，就是他曾用洪水一举淹没全地[^fa582]，从而向万代作见证：他是全人类的审判者。我部分同意这一看法，但要把他的意思引申得更远。依我之见，他是在接续前面的主题，提醒我们：那些至今仍以毁灭威胁大地的洪水，乃是被神的护理如此掌管，以致显明惟有他在万时万代治理万有[^fa583]。因此，大卫把这一点与神大能的其他明证一同提出：即便众元素似乎被最狂暴的天候搅混淆乱在一起，神仍从他天上的宝座掌管并节制这些骚动。故此他为着解释加上一句：<span style="color:#800000">*耶和华坐着为王，直到永远。*</span>

<!-- PAGE 452 -->
**11.** <span style="color:#800000">*耶和华必赐力量给他的百姓。*</span> 他回到先前的教义，就是说：虽然神将祂可见的能力无分别地展示在全世界眼前，祂却以一种特殊的方式为祂的选民施行大能。此外，他在此描述神的方式，与他先前的描述截然不同；也就是说，神不是那位以惊恐战兢压倒祂所对之说话的人，而是那位扶持、眷养、坚固他们的神。*力量*一词当理解为人的全部处境。他因此暗示：凡保存敬虔人性命所必需的一切，都全然倚赖神的恩典。他用*赐福*一词加以扩充；因为神被称为*赐平安的福*给那些祂宽厚仁慈相待的人，以致他们一生顺利的路程和完满的福乐一无所缺。由此我们可以学到：我们当敬畏神的威严，然而同时也要盼望从祂得着一切为我们福乐所必需的；并且让我们确信不疑：既然祂的能力是无限的，我们便有一座不可攻破的堡垒护卫着我们。
