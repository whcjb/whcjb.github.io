# 第二十三章

<p class="title-block-h2" style="text-align:center; font-size:16px; font-weight:bold; margin:18px 0 12px;" markdown="1"><span style="color:#000080">前往 约书亚记 23:1-11</span></p>

这里记载的是约书亚临近离世之时所作的郑重宣告，好叫他身后仍能留存对神纯正的敬拜。虽然以色列人在迦南诸民族中所得的太平安稳被描述为神赐下的极美福分，我们却必须谨记我先前所教导过的：他们之所以住在仇敌当中——其实要击溃并剿灭这些仇敌本非难事——乃是出于他们的怯懦。然而，神既宽赦了他们的忘恩负义，我们理当为他这份良善向他献上感恩。

这里也陈明了约书亚敬虔的挂虑，作为一切在位掌权者当效法的榜样。因为，一家之父若只顾念自己的儿女到他自己生命的尽头为止，而不将他的照顾延伸得更远，不尽其所能地即使在他死后仍设法使他们得益处，就不能算作是有足够远见的父亲；照样，善良的官长和治理者也当殷勤筹划，使他们所留下的、井然有序的局面得以坚立，并延续到久远的年代。为此缘故，彼得写道（彼得后书 1:15），他要竭力使教会在他离世以后仍能记念他的劝勉，并能从中得益处。

经上先说他招聚了以色列众人，紧接着又说他招聚了他们的长老、族长、审判官和官长，我由此理解其含义为：众人固然都获准前来，但这召集令是特别向那些首领和官长发出的。因此，在我看来，后一句是对前一句的解释性说明。而且，说全体百姓都受邀，实在难以置信，因为这样的聚会根本无法举行。所以，百姓受邀的意思仅仅是：长老、审判官及其他人受命前来，并可带同任何愿意随行的人一同前往。

所引约书亚的这番话是分为两段的；但在我看来，作者乃是先按惯常的做法，简要概述整篇讲论的大意，随后再更详尽地展开，补入他先前略去的细节。[^f183] 在最先给出的那段话里，约书亚简短地激励百姓，勉励他们要笃定地信靠神那持续不倦的恩典。因为他们既已亲历神在万事上都是真实的，就再无可疑，可以稳妥地盼望在此后争战、剿灭仇敌之事上必得同样的成功。他又将自己所划分、用以分配那余下之地的地界摆在他们面前，作为他们必得享用之产业的凭据或保证；因为他不是随意，而是照着神的吩咐，划定各支派的地界、定准他们的疆域的。

**6.** <span style="color:#800000">*所以你当刚强壮胆*</span>等等。他现在向他们指明得胜的方法——不是像常见的那样纵情于粗糙的安逸，以此冒充真正的信靠。他确认神必向他们施恩，并应许说，只要他们坚定地遵行律法，他们所行的一切都必亨通。假冒为善的人无论怎样满有把握地藐视、讥诮神，却仍愿意把神捆绑于己；不但如此，他们还常常大张声势地夸口神的应许。然而真信心一面倚靠神，一面使拥有它的人常存敬畏神的心。总之，凡要寻见神的，必须诚心寻求；我们若渴望蒙他眷顾，就当谨慎，不可背弃他。「你当刚强壮胆」这句话，正如别处所说，表明认真殷勤的操练；因为在我们本性极大的软弱之下，人若不竭力超乎自己的力量而奋勉，就无人能着手彻底遵行律法。也当留意此处从摩西（申命记 5:32）重述的真顺从的定义，就是不偏左右。

<!-- PAGE 165 -->
**7.** <span style="color:#800000">*免得你们与这些国民搀杂*</span>等等。他明确警诫他们：若不谨慎防备一切败坏的源头，就不可能正确地履行自己的本分。这一点极有必要向他们强调。因为他们四面都被撒但的网罗所环绕，而我们知道他们何等易于陷入迷信，或者说，何等急切地一头栽进迷信里。所以，他首先警告他们：与列国亲密来往，可能使他们卷入罪的团契；因为本段所用的*搀杂*一词，正相当于圣保罗所说的*同负一轭*（哥林多后书 6:14）。简言之，他先除去引诱人拜偶像的诱因或勾引，然后宣告自己对拜偶像本身的憎恶。然而当留意，他并未明确提及屈膝、献祭或其他仪式，而是用*题*偶像的*名*、指着它们*起誓*这两个说法来指代一切悖谬的敬拜方式。由此我们推断：只要将神为自己所要求的一切之中的任何一分，哪怕极小的一分，转移给偶像，神的荣耀就被剥夺了。因此他总结说，他们必须单单持守神；换言之，他们要完完全全地归属于他。

**9.** <span style="color:#800000">*因为耶和华已经把……从你们面前赶出去*</span>，等等。他暗示，只要他们自己不改变，神那一方也断不会有任何改变。因此他断言，只要他们蒙得神的恩眷，就必享有连绵不断的胜利。最后，他再次劝勉他们，若还看重自己的性命与安全，就当谨慎持守对神的爱。一切真实的顺服都从这源头涌出；因为我们若不以自由而炽热的情感紧紧依附于他，纵然竭力照着律法的外在形式来规范自己的生活，也只是枉然。

<!-- PAGE 166 -->
**12.** <span style="color:#800000">*不然，你们若稍微转去*</span>等等。按照律法中惯常采用的方式，他加上了警告，好叫他们若不足以被神的良善所吸引，就至少被惧怕所激动去尽本分。诚然，当神施恩俯就、邀请人时，人竟不立刻奔向前去、以敏捷警醒的顺服迎接这邀请，这实在是人的羞耻；然而肉体是如此怠惰，以致总需要被警告所刺激。因此，约书亚采用了律法惯常的方式，提醒以色列人耶和华的可畏，倘若他们不甘心乐意地接受祂所赐下的恩惠。此外，他不止一次向他们宣告：迦南各族若与他们混杂相处，就必成为他们肋下的鞭、眼中的刺。*第一*，因为神已将这地分别为圣归给自己，祂愿这地洁净、除去一切污秽；*第二*，因为祂看见这百姓何等容易被恶劣的榜样所败坏，祂也愿为此祸患预备医治之法。既然一方面这百姓毫不在意这地被不虔的迷信所玷污、被偶像取代真神而受敬拜，另一方面又急切地沾染他们的恶行，那么，他们因这般粗暴的藐视而遭受本不该[^f184]留下之人的搅扰与敌视，就不过是公义的刑罚罢了。

摩西与约书亚如此宣告的那些威吓警戒确曾公然应验，这从《士师记》中看得再清楚不过了。然而，这样宣布神的报应并非全然无用；因为约书亚死后，他们尚有足够的勇气投入争战。可惜他们的热忱转瞬即逝，[^f185] 不久便沾染了外邦人那些邪恶的礼仪。由此我们看出，人心对悖谬敬拜怀着一种无法节制的渴慕，这渴慕是任何缰绳都无力约束的。

现在我们应当思想这一教训在何等程度上适用于我们。诚然，古时神曾赐下特别的命令，吩咐那古时的民要灭绝迦南诸族，远离一切污秽亵渎之事。然而在今日，并没有划定某一特定的地域来标明我们确切的界限；我们也未曾配上刀剑去击杀一切不敬虔的人；我们所当谨慎的，唯是不可因与恶不保持足够的距离，而任凭自己卷入与恶的相交之中。因为若我们与恶相混，几乎不可能不自然而然地沾染上某种污点或瑕疵。不过，这一点既已在别处阐明，我此处便只是顺带一提。

<!-- PAGE 167 -->
**14.** <span style="color:#800000">*看哪，我现在要走*</span>等等。既然按着定命，人人都有一死，（希伯来书 9:27）约书亚便说，就他自己而言，那众人共同的结局已经临近，因为他也是生而必死的。这些话显然是为了安慰百姓，免得他们在他被取去、痛失所依时过度忧伤。因为毫无疑问，他的离世必使百姓陷入最深的哀恸，眼见自己仿佛失去了头，成了残缺的躯干。因此他劝勉他们：既然生命的赛程已到达终点而告结束，他们就不当求他的境遇与全人类有所不同。与此同时，他并非暗示众人死的样式都相同，因为领受属天教义的信徒藉着不朽坏的种子与不信者有别，不容他们照样灭亡；他所指出的，不过是那共同之事，就是在生命的路程走完之后离开这世界。他整篇讲论的要旨归结为一点：正如神藉着他的恩惠和应许的成就证明了自己是信实的，照样，他的警告也绝非虚言或徒然，他必要藉着他们最终的灭亡，追讨他们亵渎他敬拜之罪。[^f186]

[^f183]: 按照这种看法，《约书亚记》第 23 章与第 24 章所记的细节仅指同一次聚会。或许如此，但只要平实地通读这两章，所得的印象必定是：它们所指的是两次各不相同的聚会，其间必然相隔了一段时日。惟有借着刻意雕琢的考据，并辅以某种程度的牵强附会，某些释经者才得出了不同的结论。可是，何以要认为为此目的而运用这等考据乃是必要的呢？约书亚在一切战争的纷扰止息之后，眼见自己离世的时候临近，不止一次从隐退之处出来，召集百姓的首领、乃至召集全体会众来领受他的劝勉——这本身实在没有什么先天的不可能。此外，还当留意：每一次聚会都各有其相称的引言开端，也各有其特定的事务。在头一次里，约书亚是以自己的名义说话，传达他自己的信息；在另一次里，各支派都按规矩聚集，并被称为「站在神面前」，因为约书亚虽仍是那位发言者，却不再以自己的名义说话，而是带着神的使者的权柄，用那已放在他口中的确切言辞说话。所以，他所说的头一句话便是：「耶和华以色列的神如此说。」这样正式而庄严地宣告于《约书亚记》24:2 的信息，一字不易、毫无间断地延续到《约书亚记》24:13 的末了。—— *编者*
