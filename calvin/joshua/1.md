# 第一章

<p class="title-block-h2" style="text-align:center; font-size:16px; font-weight:bold; margin:18px 0 12px;" markdown="1"><span style="color:#000080">前往 约书亚记 1:1-4</span></p>

**1.** <span style="color:#800000">*现在，在……之后*</span>等等。在这里，我们首先看见神在看顾祂子民、供给他们安全上的坚定不移。约书亚借着更新的委任被立为新领袖，这一确立所得到的批准，[^f13] 意在表明神恩宠的延续，并防止百姓因摩西之死而以为自己遭了撇弃。诚然，约书亚早已被拣选来治理百姓；他不但受了这职分，也被赋予属灵的恩赐。然而，即便是最勇猛的人，无论装备何等齐全，一到行动的时刻也难免踌躇或摇摆，所以吩咐约书亚立即预备起行的这番劝勉绝非多余。不过，如此正式发出的呼召，与其说是为约书亚自己，不如说是要激励百姓，使他们满有信心地跟随一位他们眼见正一步步行在神为他所划定之路上的领袖。[^f14]

<!-- PAGE 11 -->
**2.** <span style="color:#800000">*我的仆人摩西*</span>等等。这里可以引申出两重含义——其一，既然摩西已死，如今整个重担便都落在你身上，你要接替这位你被指定为其继承人的职分；其二，虽然摩西已死，你却不可停下，仍要向前迈进。我更倾向于前一种解释，因为它蕴含着这样的推论：约书亚应当凭继承之权，接过摩西所留下的空缺职分。[^f15] 加在摩西身上的称号或尊称——*仆人*——是就他治理百姓和他的功业而言的；因为这称号应当与实际处境相称。[^f16] 这里所指的并非律法，而是那随着摩西去世而移交给约书亚的领导权柄；神如此承认他的仆人，与其说是为了称赞摩西，不如说是为了坚固接替他之位的约书亚的权柄。又因百姓单凭一道命令或许未必能充分顺服，神便在吩咐他们过约旦河的同时，应许要将全地、并他们脚掌所踏之地的每一处，都赐给他们安然为业。因为正如没有什么比疑惑更使我们懒惰无用，照样，当神摆出美好的结局时，信心便激励我们去奋力尝试任何事。

还可以补充一点：他此刻并非头一次开始给他们美好的盼望，仿佛在赐下一个他们从前未曾听闻的应许，而是唤起他们记念摩西从前所见证过的事。因此他说，如今时候已到，那从前应许给摩西的，如今要显明并成就了。或许有人反驳说，同样的话早在摩西出生之前就已对亚伯拉罕说过；不但如此，那存留在亚伯拉罕手中的永约，已经涵盖了四百年后摩西所听见的一切；[^f17] 我的回答是：这里并未提及那早已家喻户晓、广为传诵的古老应许，而是把摩西立为见证人，因他的记忆更为晚近，且他一死，百姓的信心本可能因此动摇，若不是神宣告说，他所说的一切都必成就，且近在眼前。

<!-- PAGE 12 -->
**4.** <span style="color:#800000">*从旷野和这利巴嫩*</span>，等等。这应许的真实与成就如何胜过了因百姓的邪恶而横加的一切拦阻——尽管他们并未立即得着全境为业——我已在《绪论》中说明。因为神虽然立他们为那地的主，已经展开了祂恩慈中不可估量的珍宝，却并不因此就不追讨他们的过犯。不但如此，摩西所宣告的那威吓必要应验，就是：那些注定要灭绝的邦国若不被灭绝，便要成为他们眼中的荆棘、肋下的刺。然而，正如这应许绝不因那四十年的耽延——其间他们被领着在旷野飘流——而废弃或落空，照样，那全然为业的产业虽久被悬置，却证明了那判定此业之谕旨的信实。

百姓本有能力在适当的时候取得所规定的疆界，他们却不肯去做。为此，他们本该被彻底赶逐出去。[^f18] 然而，神的宽容仍赐给他们足够宽广的领土，可供安居；虽然早已预言，作为公义的刑罚，他们所存留下来的余剩列国必成为他们的祸患，但只要他们不因自己的背信和几乎持续不断的背道而惹动神的愤怒，就未曾遭受搅扰：因为每逢他们境况顺遂，便偏行放纵。尽管如此，靠着神奇妙的良善，当他们被仇敌的暴力所压制、仿佛被推入坟墓之时，仍在死亡中得以存活；不仅如此，更是不时兴起拯救者，出乎一切指望地将他们从灭亡中挽回。[^f19]

<span style="color:#800000">*大海*</span>是指地中海，赫人之地则与其相对，构成另一边的疆界；同样，利巴嫩与伯拉大河相对；但须注意，利巴嫩之下也涵盖了旷野，正如另一处经文所显明的。[^f20]

<!-- PAGE 13 -->
**5.** <span style="color:#800000">*必无一人*</span>等等。既然即将与众多好战的仇敌交战，就有必要如此使约书亚满怀特别的信心。否则，那要将神所赐之地交付于他们的应许，便会不时变得晦暗不明；因为要倾覆如此众多的邦国，是何等浩大的事业！因此，这一疑虑被除去了。为了更好地使他脱离一切疑惑，神提醒他摩西所得的诸般胜利，藉此神已显明：对他而言，再没有什么比彻底击溃任何军队——无论其何等庞大强盛——更为容易的了。所以，约书亚受命要从神赐给摩西的帮助中，看见他将在同样的引导与保护之下所要进行之战争的将来结局。因为这一连串的恩眷，毫无间断地延续到了继任者身上。

接下来的话意思相同，只是借着 <span style="color:#800000">*我总不撇下你*</span> 等语表达得更为充分。故此，使徒（希伯来书 13:5）在劝勉信徒远离贪婪时，便引用这些话来平息一切忧虑，压制一切过度的惧怕。事实上，那由焦虑而生的疑惑，在我们里面激起如此汹涌的情绪，以致稍有危险的迹象，我们便惶惑不安，可怜地折磨自己，直到我们确信神必与我们同在，且绰绰有余地保护我们。的确，他没有为我们的胆怯开出别的良方，只提醒我们：当以他此刻的帮助为满足。

**6.** <span style="color:#800000">*你当刚强*</span>等等。这里加上了一段勉励人刚强壮胆的话，并且予以重复，好使它留下更深的印象。与此同时，应许也以不同的措辞被引入，藉此使约书亚确知自己蒙了神的呼召，好叫他在承担那神所托付给他的职分时毫无迟疑，也不至于在被迫与重重阻碍争战时半途动摇。倘若他只在起初殷勤束腰预备，却没有充分装备自己坚持到底，在争战中持守下去，那是远远不够的。

虽然信心的特性乃是激励我们奋力竭力，正如不信总以怯懦或止步不前显露自己，然而我们仍可从这段经文推断：单单的应许，若无劝勉从旁鞭策，其力量尚不足够。因为约书亚素来以敏捷进取著称，尚且需要被激励去尽本分，那么我们这些深陷懒惰之人，岂不更加需要被鞭策向前吗？

我们还可以补充说，对约书亚要求刚强与坚定，并非只提一次，也不是用单一的说法，而是反复地、以各样不同的措辞加以坚固他，因为他将要投身于许多各样的争战之中。他被吩咐要有刚强、不可战胜的勇气。虽然这两个称谓已足以表明神所吩咐的乃是极其严肃之事，然而神仍不以这种重复为满足，紧接着又重申这句话，甚至加上「*大大*」这个副词而予以加强。

<!-- PAGE 14 -->

因此，让我们从这段经文学到：除非我们竭尽全力，否则我们永远无法胜任那些艰难繁重的事务；这既因为我们的能力本就软弱，撒但又粗暴地攻击我们，而且我们最容易做的莫过于松懈自己的努力。[^f21]

但是，正如许多人徒然耗费气力，作出种种错误或散漫无章的尝试；这里补充了一个真正的力量之源，就是约书亚要恒常专心遵守律法。由此我们得知，我们唯一能真正成为不可战胜之人的途径，就是竭力向神献上忠实的顺服。否则，与其被冒失的鲁莽所裹挟，倒不如懒散怠惰、软弱无力还更好些。

此外，神不但要祂的仆人在遵守律法上刚强，更吩咐他要勇毅争战，好使他不至在其艰巨职分的重担下疲乏丧胆。但由于约书亚在处境为难之际，或许会对如何脱困、当采何策心生疑惑，神便指引他归回律法的教训，因为只要以律法为向导来遵行，他就足以应付万事。神说，你凡事必行事精明，只要你以律法为师；不过希伯来文 <span style="color:#008080">lkç</span> 一词，不单指*精明*行事，也指*亨通*成功，因为鲁莽妄为通常都要付上失败的代价。

无论如何，约书亚既完全顺服律法的教导，就更确实地被激励去盼望神的帮助。因为当我们因面临的危险而心生惧怕时，若能确信自己无论做什么都蒙神的嘉许，这是极其要紧的，因为我们别无他求，只求遵行祂的命令。此外，仅仅以某种方式顺服神还不够，[^f22] 约书亚受劝勉要持守一种谦逊与自制，使他约束在单纯顺服的界限之内。

<!-- PAGE 15 -->
许多人虽存着正意，却有时自以为比所当有的更聪明，因而或因疏忽而遗漏许多事，或将自己的谋算掺入神的诫命之中。因此，律法中所包含的那条普遍禁令——禁止一切人对它有所增添或删减——神如今特特地施加在约书亚身上。因为若是私人在筹划自己的生活方式时都当顺服神，那么对于那些在百姓中掌权的人，这就更为必要了。但既然连这位伟人都需要这谦卑的约束，好使他不越出自己的界限，那么我们这些远远不及他的人，若擅自给自己更大的放纵，岂不是狂妄得令人无法容忍吗？然而神之所以格外为他仆人立下这条规矩，尤其是要使那些尊荣超群的人知道：他们受这律法约束、当服从它，与百姓中最卑微的人并无二致。

**8.** <span style="color:#800000">*这律法书*</span>等等。这里也吩咐要恒切默想律法；因为律法的默想一旦中断，哪怕只是短暂的间断，许多谬误便乘虚而入，记忆也会生锈，以致许多人在停止对律法的持续研读之后，一投身于实际事务，便像全然无知的初学者一样。因此神吩咐他的仆人要天天长进，终其一生都不停止在律法上得益处。由此可见，那些轻看这项研读的人，乃是被无可容忍的骄傲弄瞎了眼。

但他为何吩咐约书亚不可让律法离开他的<span style="color:#800000">*口*</span>，而非离开他的眼呢？有些注释家认为，此处的<span style="color:#800000">*口*</span>是以提喻法代指*脸面*；但这种解释未免冷淡无力。我毫不怀疑，此处所用的字眼，尤其适用于一个不单为自己个人、也为其治下全体百姓而肩负研读律法之责的人。因此，这乃是命令他专心于律法的教导，好叫他照着所交托给他的职分，将自己所学的拿出来，使百姓得着共同的益处。同时，这也是吩咐他要以自己的受教之心，作众人顺服的榜样。因为有许多人只在口头谈论、讲说，把律法挂在嘴上，自己却是极坏的守律法者。所以这两件事都在所命之列：他既教导别人，也要使自己的行为与全人的品格都合乎同一准则。

<!-- PAGE 16 -->
本节第二个分句所述之内容表明：凡属世之人在藐视神的话语时所竭力图谋的一切，最终必归于失败；无论其起初看似何等顺利，结局却必是灾祸。因为顺遂的结果唯独可指望于神的恩眷，而神公义地将这恩眷从那些轻率所定的谋算中收回，也从一切狂傲——就是那通常伴随着藐视神本身的狂傲——中收回。所以，愿信徒们为使自己的事务如愿成就，既以勤勉学习、又以忠信顺服，来求得神的祝福。

在本节末尾，因为如我先前已指出的，所用的词语含义模糊，故此句或是重复，或是加上第二个应许。我采取后一种看法。因为最合宜的是：在应许约书亚必得成功之后，要提醒他——人惟有肯让自己被神的话语所管治，才能行事精明而有条不紊。所以，信徒从神的话语中所学的智慧，正与那些自以为凭一己见识便足以引导自己走正路之人的自信相对立。[^f23]

**9.** <span style="color:#800000">*我岂没有吩咐你吗*</span>，等等 尽管在希伯来文中，单纯的肯定往往以疑问句的形式表达，这种句法极为常见，但此处的疑问却带有强调意味，为的是要印证先前所教导的内容；主借着清楚地彰显自己的权柄，使他的仆人从忧虑和迟疑中得着释放。他问道：吩咐你的岂不是我吗？我也必与你同在。请注意这里的强调：因为抗拒他的命令是不合法的。[^f24] 这段经文也教导我们：再没有什么比这更能生出信心了——就是当我们信靠神的呼召与命令、并在自己良心里对此确信无疑时，便甘心跟随他，无论他乐意领我们往何处去。

<p class="title-block-h2" style="text-align:center; font-size:16px; font-weight:bold; margin:18px 0 12px;" markdown="1"><span style="color:#000080">前往 约书亚记 1:10-18</span></p>

**10.** <span style="color:#800000">*于是约书亚吩咐*</span> [^f25] 等语。这道命令究竟是在探子被差派之后、即在他们回来之时才发出的，或许尚有疑问。而我的确认为，这不仅是可能的，我更深信：唯有当探子的报告向他提供了他所需的信息之后，他才决意拔营起行。若在尚未熟悉的道路上仓促赶行，而他自己却认为在踏入敌境之前理当先在诸多事上有所了解，那便是荒谬的急躁了。何况先略去时间的次序、事后再把所遗漏的穿插补叙进来，这也并非什么新奇的写法。因此，第二章应当被视为一段插入的旁白，向读者更充分地说明此前所发生的事，之后才接续记述约书亚终于吩咐百姓预备器具（收拾食物）的经过。

<!-- PAGE 17 -->

在一切必要之事都查明之后，他看出正是当进军的时候，便发出号令，吩咐百姓预备出战。他满有把握地宣告：再过三日，他们就要过约旦河。若非圣灵的默示，他断不敢如此宣告。当时无人尝试涉渡，似乎也没有任何指望可以过去。[^f26] 既无桥梁，也无船只可供渡河之用；而对仇敌而言，再没有比拦阻这次过河更容易的事了。因此，剩下的惟一途径，就是神以神迹将他们运送过去。约书亚存此指望，并非出于臆测，也非凭己意妄断，乃是因为这是神所启示的事。百姓的信心也在他们迅速的顺服上显明出来；因为，面对当前重重的艰难，他们若不是将自己的挂虑卸给神，断不会如此爽快地听命。毫无疑问，是神将这份踊跃之心感动在他们心里，为要挪去一切可能延迟应许成就的拦阻。

**12.** <span style="color:#800000">*约书亚对流便人*</span>等等。约旦河东之地已赐给他们为业，条件是他们必须继续与弟兄们一同从军，将迦南诸族逐出。因此，约书亚现在劝勉他们履行自己的承诺：撇下妻子、儿女和一切财物，过约旦河去，不停止争战，直到使弟兄们安然得地为业。为催促他们如此行，他用了两个论据，一个出于权柄，一个出于公义。因此，他提醒他们摩西所吩咐的命令；摩西的裁决是不容违背的，因为众人都清楚知道，他所说的没有一句出于自己，唯有神藉他口所吩咐的。同时，约书亚虽未明言，却间接暗示他们受约束，因他们曾立约应许要如此行。[^f27] 他接着以公义的理由激励他们，好使那些同得一份产业的人，境遇上不致有不平等。他说，若你们的弟兄冒着危险，或至少辛劳征战，而你们却安享一切平安定居之福，这实在极不相称。

<!-- PAGE 18 -->

当他吩咐他们要在弟兄前头过去（precede or pass before）时，其意思并不是说他们必须率先与仇敌交战，也不是说在可能临到的一切危急关头，要比别人担负更重的分量；他这样吩咐，只是催促他们踊跃前行，因为若落在后头、慢吞吞地随着别人的脚踪而行，那便是一种推诿逃避了。因此，<span style="color:#800000">*在你弟兄前头过去*</span>这话，并不是说要站在战阵的最前排，而不过是要他们各守自己的行列，藉此显出甘心乐意的热忱。因为可以确定的是，他们既分为四营，便也照样按次序前进。他既称他们为战士，我们便可推断（这一点在别处会更清楚地显明），那些年迈的，以及其他身体不强健的人，是获准留在家中看守众人的公共福祉，或者若因某种缘故不能履行公职，便完全免去这职责。

**16.** <span style="color:#800000">*他们回答说*</span>，等等。他们不但顺服，更是心甘情愿地承认、并明确详述他们所当尽的顺服。惟有我们乐意地、而非如保罗所说的忧愁地履行本分时（哥林多后书 9:7），我们的义务才算真正尽到了。若有人反驳说，他们自夸曾顺服摩西——而他们从前却屡屡顶撞他——这样的夸口未免有失谦逊；我的回答是：尽管他们并不总是带着当有的热忱跟随，但他们顺服的心是如此殷切，以致若考虑到他们的列祖何等骄傲地悖逆、何等乖僻地竭力挣脱神所加给他们的轭，他们这般的中正温和便不仅可以容许，更是配得最高的称赞。因为这里说话的人，并非神所抱怨（诗篇 95:8-11）那些惹他发怒的悖逆之辈，而是那些因刑罚的鉴戒而受管教、已学会安静顺服的人。[^f28]

<!-- PAGE 19 -->
诚然，他们如此声明，说要待约书亚如同待摩西一样，与其说是在颂扬自己的美德，不如说是在高举约书亚的权柄。与此同时，他们信心的根基也在其愿望或祷告中表露出来，就是求神与祂的仆人约书亚同在、扶助他，正如祂从前扶助祂的仆人摩西一样。他们表明，自己甘愿在这位新领袖的率领下争战，因为他们深信约书亚已得着能力的装备，并盼望他必藉神的帮助得胜，正如他们从经历中所领悟的，神曾藉摩西的手何等奇妙地扶助了他们。此外，我们还可以推知，他们确实怀有这样的信心：一则因为他们追念神向他们施恩的种种经历，以此激励自己；二则因为他们把约书亚看作摩西的继承者，深信也必同样得着亨通的结局。

<span style="color:#800000">*你的神*</span> [^f29] 这一称谓并非无关紧要，它显然指向神持续不断的恩眷。这一表达方式也介于信心的确信与祷告之间。 [^f30] 因此，他们一方面表明自己心里怀着美好的盼望，同时又因深知这工作的艰巨而诉诸祷告。紧接着，当他们主动劝勉他要坚定不移时，就表明他们已预备好在他的确信上跟随他、效法他。这里当留意的是：约书亚虽是勇敢的典范，又以行为和训诲激励众人，他自己反过来也受到激励，好叫他自己的奋勇更有效地激发百姓的奋勇。
