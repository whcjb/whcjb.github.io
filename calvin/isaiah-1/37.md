# 第三十七章

<p style="text-align:center" markdown="1"><span style="color:#000080">前往 以赛亚书 37:1-38</span></p>

**1.** <span style="color:#800000">*希西家王听见就撕裂衣服。*</span> 先知宣告说，这位敬虔的君王所剩下的唯一得救指望，就是向神这位公义的审判者陈明自己的哀诉；正如诗篇所说：

<span style="color:#000080">「正如仆人或使女受人欺压时，仰望主人或主母的保护，信徒的</span> <span style="color:#000080">眼目也照样定睛于神的帮助。」——</span> <span style="color:#000080">(</span><span class="ages-code">&lt;19C302&gt;</span><span style="color:#000080">诗篇 123:2。)</span>

因此，当耶路撒冷看来已濒于彻底毁灭之际，希西家既失去一切地上的援助，便投奔于神的保护之下，如此承认在沉重的患难中别无他法可医。由此神的恩典也就更加辉煌地照耀出来，以致当这敬虔的君王从那狮子口中被救出来时，显然是一件奇事。所以我们应当留意这一情形，好使我们更明白神作为的极其卓越。这里也教导我们，在最绝望的境况中当作什么：不可懈怠疲懒，不肯恳求神的帮助，因为神自己邀请我们到他那里去。我们不可颤抖失望，反倒当被那压迫我们的困境所激励，去寻求他的帮助；正如我们看见希西家所作的，他立刻投奔圣殿，如同奔向避难所一样，使他自己和他的全体百姓都可以在神的荫下寻得庇护。

<!-- PAGE 828 -->
<span style="color:#800000">*希西家王便撕裂衣服。*</span> 他同样加上悔改的外在表现，就是「撕裂衣服、身披麻布」、撒灰以及其他同类的举动；因为这些都是悔改惯常的记号，即当他们在所受的任何灾祸的重压之下，在神面前承认自己的罪，并求他赦免的时候。这位圣洁君王的谦逊何等奇妙：他在成就了如此众多卓著的事业之后，在被如此众多美德的卓越所装饰之后，仍毫不迟疑地谦卑俯伏在神面前；另一方面，他的勇气与信心的坚定也何等奇妙：他并不因这如此沉重的试炼的重压而受阻，仍坦然寻求那如此严厉击打他的神。我们几乎在百人中找不出一人，在神以任何程度的严厉对待他时不发怨言，不把自己的善行摆出来作为抱怨的根据，不申诉说自己所得的报答不公。另有些人，当神不顺从他们的心愿时，就抱怨说他们敬拜神毫无益处。

在希西家身上，我们看不到任何这类的情形；他虽自知有非凡的敬虔，却不回避认罪。因此，我们若想转移神的忿怒，并在患难中经历他的恩宠，就必须表明我们的悔改，诚实地承认自己的罪；因为患难并非偶然临到我们，而是神唤醒我们悔改的方法。诚然，麻布与炉灰若没有内心真实的情感在先，便毫无益处；因为我们知道，假冒为善的人在使用外在礼仪上极其大方。但正如我们从前所说的，圣灵理当称许这些操练，只要它们是指向其本有的目的。的确，这位敬虔的君王与全国百姓以这样的方式激励自己敬畏神，并且他甘心情愿地在一种伴随着可怜污秽的形式中承认己罪，这正是非凡的敬虔与谦卑的证据；因为我们知道君王们是多么不愿从自己的尊位上降卑下来。

**2.** <span style="color:#800000">*就打发以利亚敬*</span>。这信息的用意，不仅是要请以赛亚与他一同哀哭，更是要从他的教义中求得些安慰。的确，祷告若不倚靠神的话语，便只是徒然向空气倾吐。因此我们看见，不信的人在祷告中固然喧嚷不已，却因藐视或漠视神的应许而远离神。所以，希西家一面殷勤祷告，一面又加上对其盼望的坚固，免得屈服于试探，这正是他真实敬虔的证据。

<span style="color:#800000">*去见亚摩斯的儿子先知以赛亚*</span>。他愿意听神藉「先知」的口说话（申命记 18:15；玛拉基书 2:7），便是遵循神所定的方法。他虽单单倚靠神，却不弃绝一个必死之人的见证；因此他明明加上这称号，并非没有缘故

<!-- PAGE 829 -->

*先知*；因为他打发人去见以赛亚，为要藉着某个新的预言得着坚固；他称他，不是称为一个平民，而是称为神的仆人，其职责就是以某些安慰来抚慰这位敬虔的君王。

因此有两种补救之法值得我们留意，我们在患难中藉此得着抚慰。第一，我们当求告神拯救我们；第二，我们当求问先知——至少在我们能寻得他们的时候——好叫他们从神的话语中给我们带来些安慰；因为以应许来激励、安慰受苦之人，正是他们的职责，而即使他们未能如此行，仍有丰盛的安慰从神的话语中传给我们。我们也当求问先知，他们的受命不单是为他们自己那一世代，也是为后世并为每一世代；因为虽然这些人已经死了，他们的书卷却存留下来；他们的教义活着，且永不消亡。所以，只要我们不弃绝这些真正的补救之法，我们就绝不会缺乏它们；总而言之，我们当常常求问神。

或有人问：「希西家岂不是已经从神的应许中得着丰足的供应与坚固么？向先知寻求新的应许，岂不是不信靠的表现么？」我回答说，他寻求新的应许，不当归于不信或不信靠；因为他自知自己的软弱，便毫不迟疑地求取新的坚证。肉体总是激动我们去疑惑，因此我们不当轻看额外的帮助；相反，我们当常常寻求各样的援助，藉此抵挡种种试探；因为撒但四面攻击、围困我们，以致我们若不坚固地设防，几乎无法直到末了脱离他的网罗与诡计。所以，虽然我们已从神的话语中受教，知道他必在患难中扶助我们，然而当我们身处任何艰难的争战中时，一再地求问于主的口，并寻求新的坚证以坚固我们的信心，乃是合宜的。诚然，今日并没有同类的预言赐给我们；但我们当把那些也是为我们的益处而写的普遍预言应用在自己身上。（罗马书 15:4）

<!-- PAGE 830 -->
至于希西家为何派遣使者，而不亲自前往以赛亚那里，显然是因为他正在圣殿中祷告；因为众长老和谋士都身披麻布这一情形，清楚表明这是全国性的哀恸；并且很可能是照着王的命令公开举行了祷告。然而应当注意，先知留在家中并非为着自己的安逸或享乐，乃是神藉着他的缺席，要试验这敬虔君王的信心。

**4.** <span style="color:#800000">*或者耶和华你的神听见*</span> 希西家看似在怀疑主是否愿意垂听他；因为 <span style="color:#008080">אולי</span> *(ulai)* 这个虚词被译作*或者*，而这也是它在圣经中常有的意思。但应当注意，信徒纵然确知主必帮助他们，却往往因事情的艰难而心中困惑，遂如此说话。若单就事情本身而论，希西家有理由踌躇；然而当他转眼注视神的话语时，他便对神的旨意确信无疑，以致不再战兢。但既然肉体不可能不拖累信徒，使他们的脚步蹒跚摇晃，[^f648] 他们有时便照着眼前情势的表象来措辞。

在圣经其他经文中也可看到，圣徒们即使在论及确定无疑之事时，也如此说话；因为彼得劝勉西门时说：

<p style="text-align:center" markdown="1"><span style="color:#000080">“</span><span style="color:#000080">*或者*</span> <span style="color:#000080">*你心里的意念可蒙赦免*</span> <span style="color:#000080">。”</span> <span style="color:#000080">（</span><span style="color:#000080">使徒行传 8:22）</span></p>

他并不是劝西门在祷告中战兢犹疑，因为那样的祈求是徒然的；他乃是要指明这罪的可憎，使他心中受更深的击打，最终迫使他奋起，带着真实的悔改来亲近神。所以这「或者」一词并不含疑惑之意，而相当于我们平常所说的「若是可能」，就是当我们敢于盼望、并对自己有所期许的时候所用的说法。希西家说这话，并不是以为神对不敬虔之人的言语充耳不闻，或以为有什么事能瞒过他；乃是因为他心中已确立一个原则，即「凡求告他的，凡诚心求告他的，耶和华便与他们相近」（<span class="ages-code">&lt;19E518&gt;</span>诗篇 145:18），因此他决意与灰心丧胆相争，并以祷告武装自己；又因他知道这胜利来得不易，就说：*若是或者*。[^f649] 此外，他提到两种「听见」，这在某种程度上消除了这个难题。

<!-- PAGE 831 -->

<span style="color:#800000">*或者耶和华你的神听见，就是耶和华你的神所听见的话。*</span> 乍看之下，这话似乎有些矛盾；但这种说法极为恰当，因为希西家确实无疑、毫无争议地深信没有什么能向神隐藏；他心中所思量的只是这一点：神是否决意追究这条污秽的狗所说的亵慢之言；因为神常常延迟、并暂时隐藏他的报应，以致看似闭目不视、置之不理。总之，他既已确定这一点：

<p style="text-align:center" markdown="1"><span style="color:#000080">“万物</span> <span style="color:#000080">在神面前都是赤露敞开的，”</span> <span style="color:#000080">（</span><span style="color:#000080">希伯来书 4:13）</span></p>

他只是恳切地求问：神是否真的显明他如此被拉伯沙基的褻慢话所触怒，以致决意不容这些话不受惩罚。总之，他愿神有效地垂听，就是藉着复兴那些被分散、混乱的事，并显明自己为审判者；因为那时我们才知道，他确实看见并察看万事。希西家就是以这样的方式求问：「耶和华岂不曾听见拉伯沙基的褻慢话，好向他们施行报应，并显明他顾念自己名的荣耀吗？」

<span style="color:#800000">*耶和华你的神。*</span> 希西家称他为「以赛亚的神」，并不是说只有一个人敬拜神，也不是把自己排除在敬虔人之外；而是因为祷告乃是从教义中涌流出来的，这位敬虔的君王愿意称赞先知的职事，并作见证说他是神真正的仆人。这种关系还有更宽广的一面；因为一切信徒都呼求神，另一方面，神也把他们算在自己的百姓之中；但神被特别地称为以赛亚和保罗的神，因为他们有特殊的呼召。总之，这些话明确地包含了对以赛亚呼召的赞美与称许。

<!-- PAGE 832 -->
<span style="color:#800000">*所以你要扬声祷告*</span>（原文作「举起祷告」）。这是希西家打发人去见以赛亚的第二个理由，就是要他也与众人一同祷告。由此我们学到，先知的职分不仅在于用主的话安慰受苦的人，也在于为他们的得救献上祷告。因此，牧师和圣道的仆人不可以为自己既已劝勉、既已教导，就算完全尽了本分，若他们不加上祷告的话。这固然是众人都当行的；但希西家特特打发人去见以赛亚，因为他理当以自己的榜样引领他人。此外，「举起祷告」不过就是「祷告」，然而这说法值得留意，因为它显明我们祷告时心中的情感当如何调整。圣经处处吩咐我们「向天上的神举起心来」（耶利米哀歌 3:41），否则我们便不会敬畏神。而且我们的愚昧如此之大，以致立刻被那些关乎神的粗鄙想象所掳去；所以若非他吩咐我们仰望天上，我们宁愿在自己的脚下寻找他。因此，「举起祷告」就是这样祷告：使我们的心不匍匐在地上，不对神存任何属地或粗鄙的念头，乃将合乎他威严的一切归给他，并使我们炽热恳切的情感高飞上腾。诗篇正是在这意义上说：

<p style="text-align:center" markdown="1"><span style="color:#000080">「愿我的祷告如香陈列在你面前！</span> <span style="color:#000080">愿我举手祈求，如献晚祭！」（诗篇 141:2）</span></p>

<span style="color:#800000">*为余剩的民。*</span> 当他愿人「为所剩下的余民」献上祷告时，这一情形极有力量能感动主；这并不是说神像人一样被感动，而是他以这样的方式对待我们，并俯就我们的软弱。所以当我们的境况被逼到如此极处、离灭亡已不远时，我们就当把自己的困苦陈列在神面前，使我们的心得着些安慰；因为神宣告说，他顾念「困苦受难的人」（诗篇 22:24）。我们看来离灭亡越近，就越当更加热切恳切地求他施以援手，正如我们在此看见希西家在事势绝望之时所行的。

**5.** <span style="color:#800000">*希西家王的臣仆就去见以赛亚。*</span> 先知先前既已述说这敬虔的王除了求问耶和华的口以外别无避难所，如今他便表明他求问并非徒然；因为他得着了他所渴望的安慰。我们既从这榜样受教，若将我们的挂虑与焦急倾倒在神的怀中，向他寻求解救，我们的盼望必永不落空；纵然世上不会常有以赛亚那样的先知，然而他仍必及时兴起，以合宜的方式施行帮助。

<!-- PAGE 833 -->
**6.** <span style="color:#800000">*耶和华如此说。*</span> 以赛亚起首便声明，他是奉神的名作此回答，并明确宣告这神谕出于神；这既因为先知总当谨防提出任何属自己的东西，也因为在如此艰难的事上，必须有神的权柄。先知也以此方式表明，他是回应这敬虔君王的祈祷。诚然，连假先知也夸称神的名，却是虚谎的。以赛亚真是圣灵的器皿，因此他有权提说那差他来者的圣名。

<span style="color:#800000">*不要惧怕。*</span> 他吩咐他「不要惧怕」，是劝勉希西家要有刚勇的心志，或至少要有安静的心志。每当我们听见这话，就当记得我们是被吩咐去培养那由信心在我们心里所生出的平安；因为凡信靠神、并盼望从他得着脱离困苦之拯救的人，都藉着操练忍耐而超越一切惧怕，以致即使在患难之中也有平安。此外，为使这敬虔的王能欢然持续期待喜乐的结局，他明白宣告说，神是在维护他自己所担起要护卫的案件，因为他不能容许恶人亵慢他的名而不受刑罚，却终必显明他是公义的审判者。[^f650]

<span style="color:#800000">*亚述王的仆人。*</span> 他称他们为*仆人*，是要更强烈地显出这行为的卑劣；因为纵然是那王自己如此说话，主竟被一个必死的人藐视、如此可耻地攻击，也已经是不可容忍的了。因此可以容易地推断：主更不会容忍自己被「仆人」这样极度地侮辱，[^f651] 所以那人的身分地位使这攻击的罪恶更为加重。

**7.** <span style="color:#800000">*我要使他起意念。*</span>（按原文作「看哪，我要使风临到他身上」）有人译作「我要将我的灵放在他里面」，仿佛先知是在讲论心中隐秘的感动；但这是牵强的解释。这是一个极为贴切的比喻：在神的手中有一阵风或旋风，可以把西拿基立驱往别的方向。将恶人比作「糠秕或碎秸」（诗篇 1:4），是圣经中常用的说法，因为当他们自以为站立得极稳的时候，神却轻易地把他们驱往他所认为合适的任何地方。先知把西拿基立国中所生的骚动比作一阵「风」或「暴风」，将他从犹大赶出去；接着他表明，主要击退这仇敌，并不比他要吹动一根碎秸或糠秕更为困难；对一切暴君，无论何等强盛，也都可以照样说。

<!-- PAGE 834 -->

<span style="color:#800000">*因为他必听见风声。*</span> 「他必听见」这几个字显然是为解释的缘故而加上的，因此我宁愿把它们解释为陈明理由：「因为他必听见。」[^f652] 这就是那阵风，藉着它的兴起，西拿基立忽然被驱走了；因为他所听见的关于埃及王和古实王的风声，迫使他返回本国。

<span style="color:#800000">*我必使他在本地倒在刀下。*</span>这话的意思仿佛是说：「他如今扰害欺压别人，竭力开拓自己帝国的疆界；但我要在他本国的腹地之中兴起仇敌来击溃他。」有些人解释为以色列地，但这是过于牵强的解释；因为先知所说的是亚述王本国之地，其中含有一层隐含的对比：「他曾攻取别人的城邑和国度，却不能保守自己的国土，反要在其中被毁灭、灭亡。」

**8.** <span style="color:#800000">*拉伯沙基回去。*</span>先知现在宣告拉伯沙基一无所成便回到他王那里，却不是回到他离开他时的原处；因为他得知他已撤了拉吉之围，转往埃及，为要攻打立拿。有些人认为这城就是佩鲁西乌姆（Pelusium），另有人宁愿把它归于犹大地。诚然，很可能是因有仇敌逼近的消息传到他耳中，他便将营移向埃及，好迎击他们，阻止他们前进。虽然神藉着一场新的战争约束了这暴君的暴虐，为要使犹太人稍得舒缓，然而祂并不愿藉人手制胜这暴君，只愿公然显明，仿佛在戏台上摆出他那不可克制的骄傲；因为即使他身处极大的危险之中，仍不住吐出同样的亵慢之言，这是我们下面就要看见的。

<!-- PAGE 835 -->
**9.** <span style="color:#800000">*亚述王听见人论古实王吐哈加。*</span>从下文我们可以推想亚述王为何突然离开犹大地；因为埃及王与古实王彼此结盟对抗西拿基立，缘由是他们看见他的势力日渐膨胀，侵略他国毫无止境，因此他们理所当然地断定：若不及早抵挡他的暴虐，他们自己也必大祸临头。这两位王并非有意牺牲自己来保全犹大的平安，而是为自己打算；因为一人手中握有如此强大的权势，向来会引起别的君王与列国的疑惧，这也是理所当然的。因此他们联合军力、及早迎敌，实为明智之举；因为若各自为战，他们便轻易被征服、被毁灭了。为此，这两王一同举兵，为要击退那暴君的权势与暴虐。

<span style="color:#800000">*就差遣使者去见希西家。*</span>亚述王身陷如此危险的战事之中，却「差遣使者去见希西家」，要用恐吓和威胁逼他投降；因为暴君被野心和对自己伟大的虚妄自负冲昏了头脑，于是自以为他们的言语、他们名声的传闻，甚至他们的影子，都能使众人惊惧。他既已卷入一场凶险的战争，仍想制伏犹大——他曾被迫从那里撤退，以未能持续围城为耻，但或许他以为，凡在他亲临时未能成就的，如今在他离开时倒可得着。然而，耶和华奇妙地帮助了他那看似濒临灭亡的百姓。首先，为要遏制这暴君的凶暴，他设下拦阻与障碍，使他不能迅速脱身；正如先知后面所说的，好像给一只狂野凶猛的野兽「口加嚼环、鼻穿钩子」一样。（以赛亚书 37:29）他的暴怒与残忍诚然并未减退，却被约束住，以致不能加害于人。

<!-- PAGE 836 -->
我们今日看见同样的事。有多少残暴的君王巴不得神的教会被毁灭！为达此目的，他们施展何等的诡计！他们所定的计谋何等繁多！他们从四面八方调集何等的军力！然而，当他们以为必能有所成就时，耶和华却忽然兴起仇敌攻击他们，有时甚至使他们彼此争战，并将他们本要向神的儿女施行的残忍，转回到他们自己身上。他们却仍旧行其残暴，不住地尝试这样那样的手段；正如这西拿基立，虽被重重困境围困，却不停地搅扰希西家，从他王者的宝座上向希西家发话，仿佛希西家是个卑贱的奴仆，又像吩咐自己的属臣一般命令他，甚至向神自己说出狂傲侮慢的话，其骄横竟超过他的臣仆拉伯沙基；因为拉伯沙基的话虽有同样的意思，这人却以更无耻的方式，可以说是更肆无忌惮地辱骂神。

**10.** <span style="color:#800000">*不要听你所倚靠的神欺哄你。*</span>这是何等骇人的亵渎，竟论到那真理之源的神，控告他虚谎欺诈，仿佛他真的欺骗了自己的百姓！倘若夺去神的真实，还给他留下什么呢？因为没有什么比真实更绝对属乎他。神从这恶人口中逼出了这句话，尽管他从前佯装敬畏某位神明；因为正如我们从前所说的，这样的不敬虔，神不容它再继续隐藏下去。

<span style="color:#800000">*说：耶路撒冷必不交在……手中。*</span> 这里引述了神自己所说的话，就是「耶路撒冷必蒙保守」，因此有些人推测，以赛亚的预言是被叛徒舍伯那泄露给亚述王的。然而并不需要这样的推测；因为那亚述人清楚知道希西家把希望寄托于神，也并非不晓得那些既向希西家、也向大卫所作的应许，

<p style="text-align:center" markdown="1"><span style="color:#000080">「这</span> <span style="color:#000080">是我永远安息之所；我要住在这里，因为我喜欢这地方。」</span> <span style="color:#000080">(</span><span class="ages-code">&lt;19D214&gt;</span><span style="color:#000080">诗篇 132:14。)</span></p>

这并不是说他对属天的神谕有什么关切，而是因为人人都知道并谈论这些话，而犹太人也以此夸耀不已，屡屡在敌人面前夸口说有神的帮助与保护。

所以，这暴君就用这句褒渎的话来抵挡这些应许——「不要让你的神欺哄你。」他就这样自高自大，抵挡神，仿佛神没有足够的能力保护耶路撒冷，仿佛他自己的权势不但超过世上一切人的权势，甚至超过神自己的权能。他试图用实例来证明这一点，因为他已经征服了那些受别神庇护的列国；他又从列祖的势力上引出论据——「他们既胜过了别国的神，而我又远远胜过我的列祖；所以以色列的神也必不能胜过我。」

<!-- PAGE 837 -->
恶人在顺境中往往就是这样越发自高自大，以至终于忘记自己不过是人，不但为自己僭取神的尊荣，甚至以为自己超越了神的威严。他们把是与非之间的一切分别都置于不顾，只以能够加害于人的势力为满足，反倒以自己和列祖的罪行为荣，并且极其自夸自己乃是出于强盗与声名狼藉之人的后裔；因为最有权势的君王往往最有资格被称为大盗的富有之子。这暴君并不思量，这许多邦国究竟是以正当或不正当的方式落入他列祖的权下；因为他们既志在伟大，就毫不顾念公义或不义；只要能用任何方法——无论合法或不合法——将别人置于自己的轭下，他们就以此为足。他们如此以为，凡自己所能行的都可以任意而行。他们持守那句俗谚，(<span style="color:#0000d4">eij ἀδικητέον</span> <span style="color:#0000d4">τυραννίδος περὶ ἀδικητέον</span>)「若必须违背公义，就当为着掌权而违背公义」；这恶习并非只属于某一个时代，就是如今我们也觉得它泛滥无度。

**11.** <span style="color:#800000">*你必听说*</span>。这里我们应当注意双重的比较；因为他把希西家与在他以前的其他犹大诸王相比，说希西家不如他们，而他们尚且被亚述诸王所败；另一方面，西拿基立既得了超乎众人的权势，就更加胆大而狂傲。由此推论，希西家绝无法抵挡他。另一重比较，是把亚述诸王和西拿基立本人与列国的偶像相比；因为那些偶像既不能保护敬拜它们的列国，那么以色列的神也照样不能保护敬拜他的国民。

当我们这样读到有非凡的试探攻击临到希西家的信心时，就让我们也披上同样的军装，预备自己迎战。趁着还有安闲的时候，让我们及早努力坚固自己，好使我们进入这样的战场时，能勇敢作战。倘若撒但以许多国家的毁灭来讥讽我们，我们就当留意我们处境的不同；因为虽然我们同样难免遭遇类似的灾祸，我们却对自己的救恩有确实的盼望，而他们全然没有这盼望。

<!-- PAGE 838 -->
**12.** <span style="color:#800000">*歌散。*</span>这地方在列王纪下 17:6 和 18:11 都有提及。我们可以推断它是玛代的一座城，虽然有人认为它位于别处；但只要知道，就耶路撒冷而言，它位于东方，这就够了。*哈兰*在圣经中常被提到。普林尼把这城置于阿拉伯；但更普遍的看法是它在美索不达米亚，这也为亚伯拉罕的行程所证实：他离开本乡迦勒底之后，与他父亲一同来到那里。（使徒行传 7:24；创世记 11:31。）外邦历史学家称它为 Charrae（哈兰，复数形式），他们也提到克拉苏和他的儿子在那里被杀。

**14.** <span style="color:#800000">*希西家从使者手里接过书信来。*</span>先知现在指出，希西家在如此深重的灾祸之中有怎样的避难所。他立即进入圣殿，为着自己无力挪去的灾祸在耶和华面前哀哭，并将他的忧伤与焦虑「卸给」祂（诗篇 55:22）。[^f653] 这也不是盲目或杂乱无章的哀哭，这敬虔的王乃是要以眼泪和申诉感动神施行拯救。他的榜样教导我们：当我们被重压所困时，最好莫过于将我们的重担投入神的怀中。若单单缺了这一法，一切别的解困之法都是徒然无益的。

<span style="color:#800000">*在耶和华面前展开。*</span>他「将信在耶和华面前展开」，并非因为耶和华不知道信中所写的是什么，乃是神俯就我们的软弱，容许我们以这样的方式向他行事。祈祷、眼泪、哀诉，都不是要让神知道我们需要什么；因为他

<p style="text-align:center" markdown="1"><span style="color:#000080">「你们没有祈求以先，你们所需用的，你们的父早已知道了。」（</span><span style="color:#000080">马太福音 6:8）</span></p>

然而在此我们更当思想的，乃是何为我们所必需的，就是：神要显明他知道敌人的褻慢之言，并且那些出此狂言的人必不能免于刑罚。因此，希西家「将」那恶暴君的「信在耶和华面前展开」，其缘由与用意就在于此：为要激发自己的殷勤，点燃自己在祈祷中的热切。

<!-- PAGE 839 -->
**15.** <span style="color:#800000">*希西家向耶和华祷告说，万军之耶和华啊。*</span> 因为西拿基立是撒但所用的爪牙，要动摇希西家的信心，所以他以这道壁垒自卫，就是：神拥有无限的权能；因为他将这等崇高的赞美归给神，无疑是在激励自己在祈求中生出信靠。为使我们的祷告不至落空，我们当始终确信神「赏赐那寻求他的人」（希伯来书 11:6）。这位敬虔的君王尤其需要相信：虽然恶人讥笑并轻看神的权能，神的权能却丝毫无损；如此他才能勇敢无畏地挪去撒但企图用以拦阻他信靠之路的障碍。这位敬虔君王的英勇气概显明出来，不仅在于他与一位邪恶的君王争辩、维护神的权能，更在于他在自己心里高举神的权能，并呼求神作他内心情感的见证。因此，在提出任何祈求之前，他先推翻了撒但用以动摇他勇气的种种诡诈。

**16.** <span style="color:#800000">*你—惟有你是天下万国的神。*</span> 他不仅宣认神的全能，同时也坚持神对全世界所行使的权柄。这位敬虔的君王作这些宣告，目的是要在他所持守的信心上坚固自己，即相信神的护理——神藉此治理世界及其每一部分。众信徒尤当相信这一点，免得以为自己的祷告是徒然的。这位君王的祷告若只说「耶和华啊，求你侧耳而听」或诸如此类的话，便不会有如此的功效；唯有当他相信主看顾自己手所造的工时，才有这样的力量。他确信神必担起这案件。若治理并管辖全世界是神的职分，他就不会容许这暴君如此蛮横行事而不加抑制其狂傲；因为西拿基立把属神的据为己有，终必不能免于刑罚。

「天下万国都在神的权能与权柄之下」这一宣告，尤其适用于眼前的题目。然而，虽然「治理万国」这称号始终单单属乎神，先知却不否认君王、首领和官长也各持有他们的治权，只是他们须服在神之下，并将自己一切的权力与权柄都归于神。同样，保罗断言治权单单属乎神（提摩太前书 6:15），并非要废掉君王和官长，而是表明众人无论何等尊大、何等有权势，都单单倚赖神，好使他们不至自以为与神平等或与神为伴，反倒承认他是他们的主、他们的元首。因此，君王若守住介乎神与人之间的地位，不图升到更高之处，就必保有他们的权柄。

<!-- PAGE 840 -->
<span style="color:#800000">*你造了天地。*</span>希西家从创造本身推出同样的结论；因为那位创造天地的上帝，绝不可能弃绝祂自己的工作；恰恰相反，祂以自己的护理治理人类——世界中最主要的部分。若把创造局限在如此狭窄的界限之内，仿佛它只是上帝权能一时突发而短暂的施展，那是荒谬的；我们必须把它延伸到永恒不断的治理。由此可见，那些想要任意妄为、随己心意统治的暴君，乃是夺去了上帝的荣耀，因此他们的骄横受到公义的惩罚，是理所当然的。

<span style="color:#800000">*坐在二基路伯上万军之耶和华以色列的神啊。*</span>这里是希西家为坚固自己的信心所用的其他称号。首先，他称祂为「万军之耶和华」，再次颂扬祂的权能。但当他加上「以色列的神」时，他就使祂靠近了自己，并以亲密的关系相待；因为将那一族收在祂的保护之下，绝非寻常的爱的凭据。「坐在二基路伯上」的含义也是如此；仿佛他说：「你已在此设立你的宝座，并应许你必作那些在约柜前求告你之人的保护者。我倚靠这应许，逃奔到你这里，以你为我的守护者。」

我毫不怀疑，希西家心中所想的是约柜的形制，它的两旁有两个基路伯环护。也有人把基路伯解释为天使，仿佛这话是说，上帝在天上作王，坐在众天使中间。但这样的解释并不恰当；因为说祂「坐在二基路伯上」，乃是因着约柜的形制，它正是照这样子造成的（出埃及记 25:18）。我们知道，约柜是上帝临在的象征，虽然祂的权能并不局限于其中；希西家提到它，是要表明他坚定地相信上帝与他同在，并且已定意藉着——可以这样说——向祂的百姓展开双翼，将他们招聚归于自己。既然上帝与我们之间有极大的距离，希西家便紧紧握住那收纳为儿子的凭据。然而他对上帝的观念中并无任何粗俗或属地的成分，不像迷信之人恨不得把祂从天上拉下来；他既以所领受的应许为满足，就表明他坚信：我们不必远行去寻求上帝的恩典。

<!-- PAGE 841 -->
因此，这种表达方式值得我们留意，它教导我们：当我们借着引路的圣道之光渐渐上升到天上时，为了得着帮助，我们仍不可将神看作是缺席的；因为他已选择在我们中间居住。既然他的威严远超天地，我们就不可把他限制在我们理解力的范围之内；然而，既然他已借着圣道向我们启示自己，我们便可按着我们那微小的能力和理解的分量来认识他——这并非要把他从他天上的宝座上拉下来，而是要使我们本性上软弱迟钝的悟性得以逐步亲近他；因为我们理当努力去接近他的崇高，既然他借着圣道与圣礼邀请我们。倘若我们是善于领悟的解释者，对神的属灵知识必常在我们中间兴旺；我们必不把石头、木头或树木称为神；我们对他的观念中也必无任何属地或粗鄙之物；然而他越是降卑临近我们，我们就越当竭力恰当地使用他所伸出的这些帮助，免得我们的心思匍匐于地；因为神迁就我们的软弱，其唯一的缘由乃是要圣礼对我们起到梯子的作用，[^f654] 而迷信却将其滥用于相反的目的。

**17.** <span style="color:#800000">*耶和华啊，求你侧耳而听。*</span> 从这些话我们可以断定希西家的困惑何等深重；因为这祷告中贯彻的迫切，透露出一种惊人的痛苦力量，以致人容易看出，他为脱离这试探经历了极其艰难的挣扎。虽然他在祷告中的热切显明其信心的刚强与卓越，但同时也如同镜子一般，显出内心风暴般的激情。每当我们被召去承受这样的争战时，让我们效法这敬虔君王的榜样，以一切足以坚固我们信心的方法去与我们的情绪搏斗，使这搅扰本身引领我们进入安全与平安；也使我们不因意识到自己的软弱而惊惶，倘若有时我们被恐惧与困惑猛烈攻击。的确，主的旨意是要我们辛劳、流汗、战兢；因为我们不可指望在安逸中歇息便能得胜，乃是在种种争战之后，他应许赐给我们美好的结局，这是他必定要成就的。

<!-- PAGE 842 -->
但希西家为何求神垂听呢？难道他以为神睡着了，或是没有听见吗？绝非如此；只是在如此艰难的事上，我们常常这样说话，仿佛以为神不在场，或不顾念我们的苦难。他表明自己被如此深重的困惑所压，几乎以为神已离弃了他；这是按肉体的眼光而言；因为倘若他未曾以信心的眼睛看见神的临在，他早就丧胆了。

<span style="color:#800000">*耶和华啊，求你开眼观看。*</span>这就好像希西家在祈求：那久藏于他心中、交托于盼望看守的神的帮助，如今要实实在在地、公然地显明出来；因此他祈求耶和华「开眼观看」，也就是求他表明自己顾念这些事。希西家清楚地表明他最为焦急的是什么事，即神要为加在他身上的侮辱伸冤；因为他虽然为自己的国和百姓深深忧虑，然而他看重神的荣耀，过于一切其他令他不安的事。诚然，那荣耀的显扬本当胜过万事来激动、感动我们的心，尤其因为我们知道它与我们的救恩紧密相连。

所以希西家在此把这暴君描绘为神的仇敌，他用毁谤和咒骂羞辱神，只因耶路撒冷以神的名和他的保护为荣；希西家由此断定，神若弃绝他所应许护卫的城，就等于同时弃绝了自己的名。既然如此，神既在他无限的良善中乐意将我们的救恩与他的荣耀相连，我们就当抓住这些应许来坚固我们的心；因为虽然恶人一面毁谤神、一面倾吐并呕出他们胸中的毒液，硬着心存那不受刑罚的虚妄指望，然而他们所说的没有一个字是主未曾听见的，也没有一个字是主最终不追讨的。

<!-- PAGE 843 -->
18、19节 <span style="color:#800000">*耶和华啊，这是真的。*</span>希西家在此开始分别假神与真神，这也是我们当极其谨慎去做的。恶人既无光照，就对神怀有某些混乱的想象，而这些想象转瞬即逝，以致他们以为并没有神，或者对他漠不关心。[^f655] 但神不愿他的百姓被一种轻浮而短暂的意见所动摇，而要他们承认他是真神，是以他大能的光辉驱散一切迷信的那一位。[^f656] 因此，我们仅仅相信外邦人所想象为神明的某种东西，是不够的；我们必须以这样的方式信神，就是将他与那些冒名的神分别出来，将真理与虚假分开；实在说来，他一旦照进我们心中，先前占据我们心思的那些虚假宗教就立即让位了。

这教义理当更加谨慎地持守，因为许多人满足于晦暗的思辨，以为只要承认某位神明便足够了。他们显然不知道自己所当敬拜的，究竟是回教徒的神，还是犹太人的神；他们在空中飘荡，正如俗语所说，既不着天，也不着地。没有什么比这种妄想更具毁灭性了；因为它把偶像与神混杂混同，而神的威严若不是在一切假神的废墟之上独尊而治，就不得其应有的地位。因此，真敬虔的开端就在于：我们要从一切众多的假神当中，明智地分辨出那位独一的神，就是我们当全然献身归与的那一位。

<span style="color:#800000">*因为他本不是神，乃是人手所造的，是木头石头的。*</span> 希西家用两个论据证明「他们本不是神」：第一，因为他们是由物质构成的；[^f656] 第二，因为他们是人手所造的。没有什么比人自以为有权创造一位神更荒谬的了，不仅因为他自己有起头，而神却是永恒的，更因为他连一刻也不能凭自己的能力存留。纵使全世界把一切力量都集中在一个人身上，[^f658] 他也造不出一个无花果来。因此，每一个必死的人竟要为自己造一位神或众多的神，这是何等的妄自尊大！[^f659] 既然在我们里面除了脆弱与衰残之外一无所有，我们就永远不能产生出一位神明来。

此外，人竟想凭巧艺的施展，从那败坏无感的物质中塑造出某位神明来，仿佛「木头石头」一经受了形状，就开始成了神——这更是荒谬至极。因此，人所曾发明的一切迷信，都以这样的方式被迅速推翻；因为那些神除了在人自己的脑中之外，别处都无从寻见其存在；实在说来，凡他们自己所构想出来的，都被定为虚空虚假的。

<!-- PAGE 844 -->
**20.** <span style="color:#800000">*耶和华我们的神啊，现在求你*</span>在祷告的结尾，这位敬虔的君王如今超越了他先前所挣扎的惧怕；因为他迄今用以坚固自己的那些凭据，无疑鼓励他放胆加上这简短的一句。虽然神并不总是搭救祂的百姓脱离今生的祸患，然而既然祂已应许要作这城的保护者，希西家便能确信：那恶暴君一切旨在毁灭这城的图谋，都必归于徒然。

<span style="color:#800000">*使天下万国都知道惟有你是耶和华。*</span>当他向神陈明这理由，说这城得蒙拯救必成为彰显祂荣耀的机会时，我们由此断定：没有什么比以一切可能的方式使祂的名得荣耀更为可羡慕的了；这甚至是我们得救的首要目的，若我们愿神向我们施恩，就不可擅自偏离这目的。因此我们断定，那些人不配得祂的帮助，就是那些只以自己的得救为满足，却轻忽或忘记神拣选保守他们之缘由的人。他们不但以这样的忘恩负义羞辱神，也因把神所联合的事物彼此分开而大大损害自己；因为神在拯救祂百姓的同时，也使祂的名得荣耀，而这一点，正如我们已说过的，必须成为我们至高的安慰。此外，希西家不仅愿以色列的神持有某种地位，更愿一切偶像都被废除，惟有祂独自作王；因为那时许多拜偶像的人固然可以容许祂与别神一同受敬拜，但既然祂不容许有同伴，凡人手所造的一切神明都必须被除灭，好叫祂独掌无可分割的主权。

**21.** <span style="color:#800000">*亚摩斯的儿子以赛亚就打发人去见希西家。*</span>这显明了那祷告的结果；因为事情一到了极处，神就立刻藉着先知以赛亚伸手帮助这敬虔的君王。（列王纪下 19:20）祂并非立即伸出膀臂驱逐仇敌，而是藉先知的口应许拯救，如此在此时仍操练祂仆人的信心。以赛亚本身无疑不能提供任何帮助，因此，若希西家未曾深信神差遣了他，他应许这事那事就是愚妄的了。故此，在神显明祂的大能之前，希西家便以这安慰为满足而得安息。

<!-- PAGE 845 -->
<span style="color:#800000">*耶和华以色列的神如此说。*</span>此处教导我们：若愿在忧虑困苦中得着些许宽解，就当常常求问神的口；因为倘若我们弃绝祂借忠信教师之手所传给我们的教义，我们就全然不配领受任何安慰。我们既由此得着喂养滋补，就当不断长进，从其中寻求新的确证，使新的患难常有新的良药，使我们即便在最剧烈的苦难中也不至缺乏安慰；因为即使那些资源与防御之法最为充裕的人，得着这教义也不算过多。在希西家身上，这里显出信心与坚定的显著榜样；然而主并非只安慰他一次，也不只借一个预言安慰他，而是用许多预言坚固他，为要叫我们这些远不及这般坚定的人知道：我们需要许多各样的帮助，才能使我们的信心得着不间断的支持。

<span style="color:#800000">*因你祈求*</span>我。在圣经的历史书中（列王纪下 19:20）用的是<span style="color:#800000">*我已听见*</span>一语；因此在那处经文中，<span style="color:#008080">אשר</span>（*asher*）是关系代词；但在此处，如同许多别处经文一样，它的引入或是为了说明，或是为了指出缘由。[^f660]

像某些注释者那样补上*我已听见*一语，是生硬而不自然的；当神宣告祂应允了希西家的祈求，要挫败那暴君一切的图谋，并制止他的凶暴与忿怒时，整句话本是一气贯通、连绵不断的；仿佛祂说，神的应答与这敬虔君王的祈求正相呼应。的确，凡向祂献上祈祷的人，终必经历祂何等乐意应允；然而祂常常缄默，也不从祂的话语中赐下安慰，因为我们在患难之中默然不语。

<span style="color:#800000">*论亚述王西拿基立。*</span>这预言的要旨是：希西家虽自觉一无所有、软弱无力，眼见这狂傲暴君的凌辱，却没有理由灰心丧胆，因为神必亲自介入其间。西拿基立既这样凌辱可怜的犹太人，神便宣告祂要亲自担当这案件，因为那侮辱乃是针对祂自己而发的。祂藉这些话表明：当祂的恩典被不信者藐视时，祂必施行报应；祂也劝勉信徒，不要因被世人藐视而大大忧伤，只要他们的软弱在天上已有现成的帮助。

<!-- PAGE 846 -->
**22.** <span style="color:#800000">*锡安的处女*</span>。这话是对整个教会说的，比对希西家个人说同样的话更有力量；因为这一点更凸显出那藐视可怜百姓毫无防卫之状的卑鄙，仿佛从天而来的帮助全然无用。因此，他斥责西拿基立的瞎眼，就是不顾念神，狂傲地藐视受苦的教会。城邑常被称为**女子**（诗篇 9:14）。有时候，正如我们从前所见的，娇嫩的城邑被称为**处女**（以赛亚书 1:8 及 23:12）。但在此他要表明耶路撒冷城的软弱，因她好像一个孤苦无依的**处女**，被这卑劣的匪徒、无耻的强盗所凌辱；而神既是这凌辱所加害的父亲，就宣告说，祂深知那恶人有何等诡计，也深知全犹大是何等光景。

**23.** <span style="color:#800000">*你辱骂谁？*</span>在上一节中，他描述那众人都看得见、都可目睹的事实；但如今他将他们的心思提得更高，指明这暴君所侮辱的不只是耶路撒冷，乃是神自己。每当我们看见自己暴露在恶人的讥诮与凌辱之下时，愿这段经文浮现在我们心头；因为纵然我们手无寸铁，纵然无人起来为我们辩护，纵然我们的软弱使仇敌越发骄横，主却仍然临近，必如同用宽大的盾牌护卫我们，因为那攻击我们的人，乃是与永生的神争战。这些话也并非单为一个世代而说，相反，因这应许是永远的，

<p style="text-align:center" markdown="1"><span style="color:#000080">「我是你的神，又是你的盾牌」</span> <span style="color:#000080">（</span><span style="color:#000080">创世记 15:1；</span> <span style="color:#000080">17:7），</span></p>

<p style="text-align:center" markdown="1"><span style="color:#000080">「我</span> <span style="color:#000080">要作你朋友的朋友，作你仇敌的</span> <span style="color:#000080">仇敌」（</span><span style="color:#000080">创世记 12:3；</span> <span style="color:#000080">出埃及记 23:22），</span></p>

故此，我们所存的力量越少，就越当确信神的能力近在眼前。既然主已与我们立约，以承担我们的案件为约的条款，我们就不要怀疑他必真实地成就此事，并且必显明：凡加于我们身上的凌辱，都是加在他自己身上。总而言之，他与我们联合得如此紧密，以致凡属他的和属我们的，他都愿意彼此共有。

<!-- PAGE 847 -->
此外，西拿基立向教会所发的那些辱骂，神都归到自己身上，为要表明恶人大大错了：他们以自己的强盛自夸，仿佛因教会已伏在他们脚下，他们践踏教会便可免受刑罚。我们知道，他们轻蔑神的护理；尤其当他们看见信徒在轭下呻吟时，就认为这些人不配得神的帮助。因此神起来作见证：人对他这可怜羊群所施的轻蔑，使他忧伤，正如他的威严被公然亵慢一样。所以，虽然仇敌看见我们缺乏地上的资源，便以为我们已被神弃绝，因此更加放胆凌辱，仿佛我们已被交与他们作掠物；然而在另一面，神却宣告说，我们的救恩在他看来是宝贵可爱的。

<span style="color:#800000">*你扬声攻击谁呢？*</span> 先知用了各种不同的词句来描绘这狂傲之人的鄙夷与放肆：此人在言语上、在面容上、在举动上、在眼目中，简言之，在他全身的姿态上，都是断然不可容忍的；因为暴君既如此自视，便装出这般气派，轻看众人，仿佛自己是从天上降下来的。

<span style="color:#800000">*攻击以色列的圣者。*</span> 最后他补充说，虽然这民族的境况已衰微至极，然而那庇护他们的神，仍在天上，权能丝毫未减。他因此责斥西拿基立的癫狂：竟单凭地上的外貌来判断一个民族，而不思想他们是奉献给神、归神为圣的。所以，为要我们藉着神的能力得以安然无恙，并使他的膀臂及时施助于我们，我们必须作他的*以色列*；若我们凭靠他的话语，这便会实现，

<p style="text-align:center" markdown="1"><span style="color:#000080">“投靠</span> <span style="color:#000080">在你翅膀的荫下。”（</span><span style="color:#000080">诗篇 36:7）</span></p>

**24.** <span style="color:#800000">*藉你仆人的口。*</span>这话也加重了这侮辱的卑贱与残酷，因为从仆人口中受辱比从主人口中受辱更难忍受，人的卑微使侮辱更加沉重。同样，骄傲无礼之人为使他们的威胁更加刺人、更加冒犯，便夸口说要打发某个仆人或跟役去行这事那事，目的是更强烈地表明他们对所恨之人的轻蔑。因此先知有意藉这一情节更有力地描绘出这亵渎的卑劣：西拿基立不但从自己口中吐出这亵渎的话，还差派*「他的仆人」*拉伯沙基说轻慢的话，攻击神的圣名。

<!-- PAGE 848 -->

<span style="color:#800000">*我要上山岭的高处，登黎巴嫩的旁边。*</span>他如今重述西拿基立所说的这些话，有人认为是泛指他从前所得的胜利，就是如我们已经说过的，他藉此征服了许多国民。但我宁愿采取更简明的看法，将其解作与眼前的围城有关。他见犹大几乎全境都已归服他的权势，四面环绕那地的山冈都已被他占据，便骄横自满，仿佛已经全然得胜，并且威胁说，他必将那些城垛以及黎巴嫩山连其香柏树、松树和别的可悦之物，都攫取在手中；如同说，必没有什么能拦阻他占据那些堡垒、营寨和最坚固的地方，任凭己意摆弄整个犹大。暴君们就是如此：虽然他们承认战事胜负未定，却仍梦想战争的顺利结局已在自己手中。

**25.** <span style="color:#800000">*我必挖井喝水。*</span> 这暴君仍旧夸耀自己的力量，并且威胁说，他要带来如此强盛的军队，以致凭着人数的众多，他必使一切泉源和江河干涸。然而，当他说「我必用脚掌踏干埃及的一切河」时，有些人将*围困之地的众池*[^f661] 理解为西罗亚的泉源，以及那些水池与蓄水池——被围困的犹大人若失去这些，就必因干渴而灭亡。的确，在前一句中他似乎是说，纵然全地干旱，他仍不惧怕缺水，因为他庞大的军队足以掘出井来。在第二句中他又补充说，他必有办法使城中一切的水干涸，好用干渴杀灭犹大人。简言之，他的意思是，耶路撒冷无力抵挡围攻，再也不能坚守，必须立刻投降。然而，恶人如此夸口之时，神却坐在天上，他终必从那里向他们施行审判；因为先知这段叙述的用意，是要引我们思想神对那暴君所施行的可惊可畏的审判。

**26.** <span style="color:#800000">*你岂没有听见吗？*</span> 大多数注释家解释这一节，仿佛主在宣告说：这暴君现今所作的，或从前所作的，没有一件不是他藉先知的口所预言的，因此断言他自己乃是这些事的作者。但我的解释不同，就是说：耶路撒冷必因神的帮助而得保全，因为他是这城的保护者。

<!-- PAGE 849 -->

<span style="color:#800000">*这是我早先所作的。*</span> 为要加强语气，他隐去了城的名字，而使用指示代词*它*，仿佛在神眼中一切其他的城邑都毫无价值。[^f662] 另有人认为代词*它*是指那系于神隐秘定旨的拯救；但凡是审慎察考先知的用意与用词的人，都会承认*它*更是指耶路撒冷。神曾抱怨自己受到卑贱的辱骂而被亏辱；然而在重述西拿基立的话时，他只提到「黎巴嫩」和邻近的地区。如今，为要显明在「黎巴嫩」这名之下，战争其实是向他自己宣告的，他便如同圣经许多别处所言的那样，断言耶路撒冷是由他自己的手所立、按他的指示所建造的，因此，除非他自己先被征服，西拿基立断不能倾覆这城。

这一教义在圣经中随处可见，且屡屡重复（诗篇 48:8；68:69；67:5；以赛亚书 14:32），其中含有极大的安慰，敬虔人在所能遭遇的最严酷的苦难中，可藉此得着扶持；这安慰就是：他们必常在神的保护之下，因为他已拣选了他们。他用这样的论据说：「我建立了教会，所以教会的拯救必永远是我所顾念的；因为我必不撇下我所开始的工作使之半途而废，乃要推动它直到完全。」总之，主见证说，他保卫并保守他自己的工作，因为其中关乎他的荣耀和我们的救恩。然而他被称为「教会的创造者」，其意义与人通常称他为天地的创造主不同；因为我们是他特殊的工作，是「他的工作（<span style="color:#0000d4">τὸ ποίημα</span>，即『所造之物』），藉他的灵重新受造的」，正如保罗所言，也如我们从前在别的经文上所解释过的。[^f663] 因此，这工作比整个世界的创造更为卓越；这样，就没有人可以把自己被收纳进入神的教会归功于自己的努力或能力；因为我们被称为「他的工作」，并非没有充分的理由。

或有人问：「主为何说<span style="color:#800000">*他从古时建立了耶路撒冷？*</span>因为另有别的城邑远比它古老。」我回答说，这不可看作是指城的外在形状或建筑，乃是指他拣选这城作他居所的那永恒的定旨；因为虽然早在约柜造成之时就已宣告说：「这是我永远安息之所；我要住在这里」（<span class="ages-code">&lt;19D214&gt;</span>诗篇 132:14），摩西也曾再次宣告说，

<!-- PAGE 850 -->

<p style="text-align:center" markdown="1"><span style="color:#000080">「凡记下我名的地方，我必到那里</span> <span style="color:#000080">赐福</span> <span style="color:#000080">给你。」（</span><span style="color:#000080">出埃及记 20:24）</span></p>

然而这早在万古以前就已被神所命定。正如保罗也告诉我们的，我们「蒙拣选」，

<p style="text-align:center" markdown="1"><span style="color:#000080">「就在创立世界以前，」</span> <span style="color:#000080">(</span><span style="color:#000080">以弗所书 1:4；)</span></p>

雅各也宣告说

<p style="text-align:center" markdown="1"><span style="color:#000080">「他按自己的旨意，用真道生了我们，叫我们在</span> <span style="color:#000080">他所造的万物中好像初熟的果子。」</span> <span style="color:#000080">（</span><span style="color:#000080">雅各书 1:18）</span></p>

因此，他必保守我们超乎万物之上，绝不容我们灭亡；实际上，正是出于同样的缘由，基督被称为「首生的，在一切被造的以先」（歌罗西书 1:15），而「教会是他的身体」（以弗所书 1:22, 23），在全世界中拥有至高的尊荣与地位。至于拉比们的那些幻想——说神在创造天地之前，就先造了弥赛亚与耶路撒冷，并为之预备荣耀的宝座——我且任凭他们去说。但我们必须坚守这一教义：神必作他教会忠信的保护者，因为他甘愿使她高于全世界。

<!-- PAGE 851 -->
<span style="color:#800000">*我现在却使这城荒废，*</span>有些人对这些话作了另一种解释。我承认先知的用语是过去式，<span style="color:#800000">*我如今已成就了、已安置了；*</span>但因希伯来文中时态的转换十分常见，先知既已说明神是他教会的创立者，且教会是他一切作为中最为卓越的，那么他无疑是由此推论：神绝不可能使他的教会陷入与寻常事物同样的毁灭。所以我们必须把这话读作一个问句：「我现在岂要使它如此吗？」或「我岂已使它如此吗？」仿佛他说：「难道我要容它像其他被倾覆、被拆毁的城邑一样遭毁灭吗？」[^f664] 因为他是把耶路撒冷与那些被亚述王所推翻、被置于他权势之下的其他城邑相比，免得有人以为那暴君能同样轻易地倾覆她；因为她所处的地位与那些被毁坏、被平为荒场的城邑截然不同。所以，她甚至不该与那些防守最坚固的城邑相比，因为那些城连同它们地上的力量都迅速倾倒；而教会虽然微小软弱，却在神的拣选中有坚固稳妥的根基，任何波涛风暴都不能将她倾覆。

我们看见，全世界各处常有惊人的变迁：共和国被颠覆，帝国被推翻，极强盛的邦国被制伏，其名被灭，其荣耀被抹去。如今罗马帝国的威严何在？那位曾为普天下之主母的民族，其伟大何在？若还留下些许残余（其实所余无几），岂不是正助长那可憎之兽——敌基督——的悲惨奴役么？他的暴虐岂不正施行于全世界么？如今罗马的自由何在？那声名显赫的共和国，其美丽何在？罗马岂不可以正当地被称为罪孽的作坊、万恶的客栈么？

然而在这些可怕的变迁之中，主宣告说，祂必扶助耶路撒冷，就是祂的教会；虽然在这些变迁之中，教会或被苦待、被多方颠簸，她却必挺立而不倒；纵然她所受的震动与压迫，也拦阻不住她世世代代藉着各样的复兴而得以更新、得以增多。虽然世上并非始终是教会的同一批肢体，但那身体却是同一个身体，与同一个头，就是基督，联合为一。因此主必保卫祂的城，并且使

<p style="text-align:center" markdown="1"><span style="color:#000080">“你</span> <span style="color:#000080">仆人的子孙要长存；他们的后裔要</span> <span style="color:#000080">坚立在你面前。” (</span><span class="ages-code">&lt;19A228&gt;</span><span style="color:#000080">诗篇 102:28。)</span></p>

**27.** <span style="color:#800000">*其中的居民力量甚小。*</span> [^f665]先知在此更充分地表明他先前只是略略提及的事，就是我们不可凭这世界的稳固来判断教会的处境；因为虽然坚固的城池被攻取，最强壮的人也丧胆而落在仇敌手中，教会却必屹立并昌盛，因为她不是靠自己的力量站立，她的根基不在地上，乃在天上。这里隐含着一个对比：一面是坚固的城池，其惊惶恐惧的居民无力守卫；另一面是神的教会，她单单倚靠他的恩典，因此能抵挡一切攻击，永不倾覆；因为教会将一切都归于独一的神，从他领受生命的起始、不间断的力量、坚忍、救恩的每一部分以及一切的祝福。

<!-- PAGE 852 -->

由此我们学到，倘若耶和华的手不施帮助，一切堡垒都归于无用。人一切的力量若不靠他的能力扶持，必被折断、必致衰败；没有他，城堡、壁垒和最强大的军队都毫无用处。这一点借着以下的比喻更充分地表达出来，

<span style="color:#800000">*他们像野草，像青菜。*</span> 引导信徒惊叹神向他们所施的奇妙恩典，使他们不至于羡慕不敬虔之人所拥有的地上财富，这是极其重要的。他们的权势虽然炫目而堂皇，先知却指明他们不过像「青菜和野草」，虽然一时茂盛，却迅速枯干。他又加上另一个比喻，把他们贬得更低，

<span style="color:#800000">*房顶上的草。*</span>它固然长在高处，为众人所见，但它的位置越高，就越靠近炎热，也就越快枯干，且毫无用处；诗篇中也说，

<p style="text-align:center" markdown="1"><span style="color:#000080">“过路的</span> <span style="color:#000080">也不说：愿耶和华所赐的福归与你们！”（</span><span class="ages-code">&lt;19C908&gt;</span><span style="color:#000080">诗篇 129:8）</span></p>

教会的仇敌[^f666]虽然高大，仿佛高举到天上，虽然兴盛、财富丰足，却必速速倾倒。因此，正如躺在我们脚下地上的麦子，比那生在房顶上不结实的野草更有价值；照样，主表明祂仆人的卑微光景，远比那些倚靠自己的力量、在别人之上自夸、甚至向神自夸之人的境况更为可羡。[^f667]

<span style="color:#800000">*未长成而枯干。*</span> 有些人认为这是第四个比喻，但我认为先知加上这句是为了解释的缘故；仿佛他说，这一类的草在未长成茎秆之前，就是在未完全成熟之前，就枯干了；正如诗篇所说：「未长成而枯干」（<span class="ages-code">&lt;19C906&gt;</span>诗篇 129:6）。

<!-- PAGE 853 -->
**28.** <span style="color:#800000">*你坐下，你起来。*</span> 他重新回到那暴君那令人无法容忍的骄傲上：那人把一切都归给自己，好像他不隶属于任何人，竟敢与自己相比而藐视神，并用毁谤加于神身上。先知责备那人的骄傲与狂妄：「但我知道你坐下。」恶人之所以如此凶暴，原因就在于他们以为无人在他们之上，甚至以为自己不受神护理的管辖；因此先知指明，除了神所许可的以外，他们绝对什么都不能作。此处「坐下、起来」是指他们的商议、计谋与筹划。恶人与不虔的人进行各种商议，图谋如何能压制并毁灭神的百姓；但无论他们转向哪一边，无论他们沿哪条路追赶，若非神的旨意，他们一无所成。神的护理约束他们，驱赶他们东奔西走，以致常常与他们的本意相反，反被引向极美好的结局，正如神所看为合宜的；因为「人心筹算自己的道路，惟耶和华指引他的脚步」（箴言 16:9），这本是专属于神的。

<span style="color:#800000">*并你向我发的烈怒。*</span> 他警告西拿基立说，他对他的怒气一清二楚；并且宣告说，当恶人在地上狂暴喧嚣时，他却保持平静的沉默，并戏笑他们的疯狂。因为西拿基立正在暴怒，且以为自己不会因此受罚，先知便特意加上这句话，好使信徒不至以为这事对神是新奇的或未知的，或以为神并不留意他们。

**29.** <span style="color:#800000">*因你向我发烈怒。*</span> 恶人越是狂暴地起来敌挡神，激动他们的暴虐越是猖狂，神终必越发与他们为敌。诚然，祂暂且容许他们作威作福、事事如意，但在长久宽容之后，祂便加以约束，仿佛给他们的颈项套上嚼环，使他们不至以为万事都在自己掌握之中。西拿基立便是这方面显著的例证；因他向神发怒，越是傲慢自夸，就越发觉神的忿怒沉重地临到他身上；这也是一切恶人所当预料的。

<!-- PAGE 854 -->
<span style="color:#800000">*所以我要将我的钩子*</span>（或作*我的环子*）<span style="color:#800000">*放在你鼻子里。*</span> 这是对愚顽与放肆的痛快讥讽；仿佛祂说：「我看出事情如何了：温和柔顺地待你，于我毫无所得，因你的怒气永不知足。但既然你不受驯服，我就要像制伏野兽一样勒住你。」祂借此更清楚地宣告：神不但看见并知道恶人所图谋筹算的，更是这样制服并约束他们的凶暴，以致祂随意将他们勉强拖往任何地方，如同人用嚼环或环子牵着野兽一般。<span style="color:#008080">חח</span> *(chach)* [^f668] 有些人译为*钩子*，但我宁愿译为*环子*；因为*钩子*是用来钓鱼的，用在野兽身上便不甚贴切。

西拿基立被迫<span style="color:#800000">*从来路转回去，*</span>因为当他正筹划征服犹大与埃及各处之时，却仓促地一无所成，取了最快捷的途径回归；倘非神以不可见的方法将他拉回，他绝不会自愿如此行。

**30.** <span style="color:#800000">*这要给你作证据。*</span>他现在把话转向希西家和全国百姓；因为他先前对西拿基立说话，并非期望西拿基立会听，而是要藉着轻蔑地嘲讽那不在场的暴君，更有力地激发信徒的心，使他们更加坚定地信靠。假如他只是简单地说：「希西家啊，你当刚强；虽然西拿基立狂傲，我到了时候必制止他」，这样的话就不如他直接向暴君说话、向他发出雷霆之声，从而鼓励信徒藐视那暴君的僭妄来得有力。[^f669]因此，在对暴君所发的言语之后，随即适时地转向希西家和全国百姓，向他们应许拯救；不但要把他们从凶猛野兽的口中救出来，而且希西家必得享太平的国度，余下的百姓也必得着一切所需之物，以过安稳幸福的生活。他这样详述拯救所带来的益处，是要表明他有意不只以一种方式，而是以各种各样的方式促进他百姓的福益；因为他不仅一次而立即地把他们从危难中救出来，更是丰富慷慨地将他的慈爱赐给他们，以致其果效在很久以后仍然可见。

但是，把一件发生在拯救之后的事作为「证据」，似乎有不合宜之处；因为他若有意鼓励被围困的人怀抱美好的希望，就当预先给他们看某种表征，而不是叙述他此后要作的事。[^f670]

<!-- PAGE 855 -->
我的回答是：证据有两种。有些是在事情之先，如同牵着我们的手引我们到那事上；另有些则是随后而来，为要坚固那事，使它更深地印在我们心里，永不从我们的记忆中被抹去。例如，当耶和华将他的百姓从埃及领出来的时候，他预先赐给摩西许多的记号；但他也另定了一个在拯救以后的记号，

<p style="text-align:center" markdown="1"><span style="color:#000080">「三日之后，你们要向我献祭。」</span> <span style="color:#000080">(</span><span style="color:#000080">出埃及记 3:12, 18。)</span></p>

其用意乃是要他们不忘记如此重大的恩惠，而是在领受了这额外的恩眷之后向神献上感谢。以赛亚在此所描述的，正是这一类的兆头；确实，将神向我们所施恩惠那连绵不断的历程摆在我们眼前，使我们思量这些恩惠何等纷繁多样，这大有助于坚固我们的信心。

仇敌既被击退，随之而来的危险便是饥荒，因饥荒通常紧随战争而至；田地既遭蹂躏掳掠，粮食的极度匮乏必接踵而来。在这看来势必临到的大缺乏之中，耶和华应许必不缺粮，并且将此举出，作为拯救的极明显的兆头，为要使他们更加确信祂必是那拯救的作者，或至少要使这确信更深地铭刻在他们心上。这事实在难以置信，超乎一切的期望与信念；然而必须如此激励希西家和百姓的信心，使他们听闻这般浩大的慈爱之后，更愿意存美好的盼望；其次，也要使事情的结局显明：神那些辉煌的作为绝不能归于偶然。

因此，其意思是：「在赶出仇敌之后，神必约束他，使他不能再带新军前来，你必平安地拥有你的地土；祂也必供给你食物与养分，使你一无所缺。」但因为照常理所发生的，他们已消耗了大部分收成，并毁坏了其中一部分，又因被围困者或逃亡者无力从事农耕之工，所以先知应许他们必有食物，直到第三年他们撒种为止。

<!-- PAGE 856 -->
**31.** <span style="color:#800000">*犹大家所逃脱余剩的。*</span> 他继续申述前面的话；因为他宣告主必拯救耶路撒冷，且此后不会撇弃对她的看顾，而要作她的救主，直到末了。诚然，主赐给我们的一切恩福，都是祂向我们持续施恩的记号与见证，使我们知道自己永不被祂离弃。但在此我们首先当记得先前所论的一点：保卫耶路撒冷本是属乎神的事，因为祂已拣选那城作祂的圣所，又因为弥赛亚必从那里而出。

<span style="color:#800000">*所逃脱余剩的。*</span> <span style="color:#008080">פליטה</span> *(peletah)* 字面意思是*拯救*；但在此处它是一个集合名词，指「得蒙拯救的人」，正如在别处「被掳」用以指「被掳的人」一样。（诗篇 14:7，53:6；耶利米书 29:14）他应许这微小的余民必得增多，并非没有缘故；因为虽然围困已经解除，然而百姓大大减少，喜乐的缘由甚为微弱，而如此稀少的人数也难以指望得着完全的复兴。因此，为要抚慰这样的忧伤，他宣告那地必满有居民，仿佛极其丰盛的收成必要填满从前空虚的仓廪。

使犹大地荒凉的，并非唯一能叫信徒的心灰丧、或以忧伤刺透他们的事；还有那更大的削减，即十支派被掳去为奴（王下 15:29；17:6）。虽然他们已如此被砍伐，以赛亚却宣告说，耶和华必使他们恢复先前的境况，并使极大的众数生发出来；因为耶和华容许祂的百姓这样被削减、被降至极卑微，为要使祂的荣耀日后在他们的拯救中辉煌地显明。祂那时所成就的，在今日也当照样期待；因此，我们越看见教会的力量被削弱、被降卑，就越当深信：神手中握有使少数人繁增的方法；因为这样的复兴断不可用我们的判断能力来衡量。

<!-- PAGE 857 -->
<span style="color:#800000">*犹大家所逃脱余剩的，仍要往下扎根。*</span>他宣告说，必有如此大的荒凉，以致看来教会好像已被拔出根来、彻底灭亡了；实在，以色列国的倾覆乃是一幅极其可悲的剪除之景象。但先知说，必有这样的增长，使那几乎被拔起的树要深深「扎下它的根」；因为教会虽不像世上的掌权者所惯常夸耀的那样自称高大耸立，耶和华却赐下一种隐秘的活力，使它超乎人的期望而萌发生长。所以，当我们看不见根，或以为根已枯死的时候，不要惧怕；因为祂已应许要使它「往下扎根」。

<span style="color:#800000">*向上结果。*</span>加上这句，是因为教会不仅像草一样茂盛（这从前是论恶人的境况所说的，[^f671]），而是结出丰盛的果子；耶和华就这样在她身上成全祂曾一度开始的工作。

**32.** <span style="color:#800000">*必有余剩的民从耶路撒冷而出。*</span>先前他以根和果子的比喻预言教会的拯救；如今他不用比喻，直陈同一件事。他所指的是那围困——城中所剩下的少数人被囚禁其中如同在监牢里，陷于极大的困迫之中；他说他们如今必要出去，全地都要向他们敞开，他们可以随意往来，无所畏惧。这**出去**乃是与犹太人因惧怕仇敌而被迫自我拘禁的狭窄范围相对照。然而他用这个词所表达的，不仅是出去的自由，也是这已减少到极少数的民族的增长。当犹大不但再度布满众多的人民，而且从这余剩之民中兴起了广大的群众、散布于世上各地时，这事若非主从那小小的数目中不仅造出一个民族、而是造出许多民族，就断不能成就。

<span style="color:#800000">*万军之耶和华的热心必成就这事。*</span>他将「神的热心」与人的谋算相对照，不仅是为了高举这工作的卓越，更是宣告：神既要惊人地彰显他的大能，这热心就足以成就一切。正如我们所说的，这事乍看之下是难以置信的；四面都是拦阻，毫无解救之途；因此他宣告神以何等炽热的爱看顾他的教会，以致他不迟疑地以非常的方式作工，以促成她的拯救。在类似的场合，他也曾用同样的说法（以赛亚书 9:7）。

<!-- PAGE 858 -->
**33.** <span style="color:#800000">*所以耶和华论……如此说。*</span>他现在回到先前所论及的拯救；因为神所应许的，第一是他要赶逐西拿基立；第二是他要赐下粮食与养生之物来供养百姓，虽然这地已被蹂躏劫掠；第三是他要使那小小的数目增长为浩大的群众。既宣告了这些，他就回到第一件事上，因为若没有这一件，其余的一切都似乎归于徒然；就是说，若百姓不从那暴君的手中被救出来。

<span style="color:#800000">*他必不得来到这城。*</span>神威胁说，他必如一座堡垒，阻挡他「来到这城」，甚至要迎面拦阻他，使他不能靠近，也不能与这城争战；因为他说，他必不「射箭」，也不筑「垒」。我认为在这一处，<span style="color:#008080">סללה</span> *(solelah)* 所指的是弩炮，或某种投掷标枪的机械，而非「土垒」；因为「土垒」不是被投射或倾泻的。

**34.** <span style="color:#800000">*他从哪条路来，必从那条路回去。*</span>我们从前已解释过，从原路返回是什么意思，就是一无所成而离去，正如我们常说的（*Il s'en est retourne comme il est venu*，「他来时如何，去时也如何」），意即毫无成就，一切努力尽归徒然。为要坚固此言，他又加上「这是耶和华说的」；因为那位「无谎言」（提多书 1:2）的神一旦发言，我们就当拥抱、亲吻他的话语，如同一切障碍都已除去，结局已成定局。

**35.** <span style="color:#800000">*因我必保护这城。*</span>这是前面所说的缘由，即西拿基立为何不得进入这城；因为耶和华必保护它。所以先知吩咐希西家和全国上下将眼目转向神，因为那暴君的形貌是如此可怖，以致他们可能因之战栗。同样，我们如今若默想仇敌的势力，便必被惧怕所压倒，几乎不留丝毫指望的余地；然而我们当直接仰望神，并拥抱他的应许，我们藉此得蒙护庇，如同有盾牌遮盖；既然神有足够的能力约束一个必死的人，我们就当转眼望他；因为这应许不可局限于那个时候，而当推及一切世代。然而先知所用的说法更为宽广，含义更为丰满；因为神确言他必作这城的守卫者与保护者；也就是说，因他已亲自立约起誓要护卫这城。故此他推断这城必得保全，因为神的保护使它的保全成为确定无疑的事。

<!-- PAGE 859 -->
<span style="color:#800000">*因我为自己的缘故。*</span>当祂说要「为自己的缘故」行这事时，祂是呼召希西家和一切信徒记念祂那恩慈的约。因为犹大人虽屡次受到严厉的管教，却仍固执地激动神的忿怒攻击他们，因此他们所当得的，不仅是神撤去一切帮助，更是神向他们施行最可怕报应的极刑。所以，为了不叫他们绝望，祂表明神必作他们的保护者，并非因为在他们身上找着什么缘由，乃是因为祂首先顾念自己，为要坚定不移地持守祂的旨意：不弃绝祂所拣选为嗣的亚伯拉罕的后裔，不废去敬虔的敬拜，不藉毁灭祂的圣所而在地上涂抹祂名的记念；其次，也不将祂的名交与外邦人的讥笑和亵慢。这些话中含有一种默然的责备，那百姓本当深觉其严厉，且是理所应当的；因为这位良善的君王安抚他们，比击退仇敌更为艰难；他们不信、暴躁，以为再无一线得救的指望。因此，主并不看百姓或任何别人的功劳，只顾念祂自己的荣耀；因为以西结所表达的那种对比，在此处必须领会：「以色列家啊，我行这事不是为你们，乃是为我的圣名。」[^f672]（以西结书 36:22）如今，既然我们今日也有同样的理由可以申辩，就不要迟疑用这面盾牌抵挡我们的罪：「我们虽然万分该死千次，然而神只要顾念祂自己的良善与信实，成就祂所应许的，这就够了。」神既永远作教会的保护者，这对假冒为善的人虽无益处，然而选民却始终以此为极安全的避难所：他们虽全然无可献上以息神的忿怒，但神既单单被祂无限的良善所感动，建立了祂的教会，并定意保护她，就必不容她灭亡。

<!-- PAGE 860 -->
<span style="color:#800000">*又为我仆人大卫的缘故。*</span>这一点极其值得留意；因为神虽无须在别人身上、而只在祂自己里面寻找祂以恩眷环抱那民族的理由，然而祂提出*大卫*作为祂慈爱极确实的凭据，并非没有充足的缘由；祂曾藉大卫的手立约，也曾应许要作他的父（撒母耳记下 7:12）。先知在此论到大卫，并非把他当作一个私人，而是当作一位圣洁的君王，他的宝座是由神的手所坚立的，在他的治理之下教会必得保全；简言之，他是神与教会之间的中保；因为在这职分上，他甚至超越了天使自己，就他代表基督的身位而言。诚然，他的宝座不久之后就被推倒，他的冠冕被撕碎，然而这仍不是毫无意义的确证，即神有意暂时保护那城，因为祂定意不废去祂向大卫所见证关乎他国度永存的话。我们也知道，百姓被掳并未完全废除大卫后裔中的王权，直到基督最终来临；因此在别处经文中，基督也被称为*大卫*（耶利米书 30:9；以西结书 37:24；何西阿书 3:5）。

这就显明教皇党人极大的荒谬，他们主张神赦免我们是藉着圣徒的功劳；因为在此处，大卫的情形与其他圣徒的情形大不相同，乃是因着那向他所作的应许。祂本可以举出亚伯拉罕，或任何别的在教会中拥有不小权威的人；但既然祂此时所论的是教会的保存和基督国度的永存，祂就以特别的方式题出那位与别人一同、且明确领受了这应许的人：「这是我永远安息之所；我要住在这里。」（<span class="ages-code">&lt;19D214&gt;</span>诗篇 132:14）因此，既然这段经文所关乎的是应许，而非那人本身，教皇党人以为它支持他们自己臆造的圣徒代求，就是双重的愚昧了。反倒是他们为自己所辩护的这一点，绝对与他们的谬误相反；因为大卫在此被表明为那独一中保的预表，而这位中保正废除了他们所发明的种种代求。

**36.** <span style="color:#800000">*耶和华的使者出去。*</span>先知现在叙述亚述人所遭遇的事，免得我们以为耶和华的话是徒然说的。因此他表明，他的预言已由事实得着证实，为使人清楚看出：神确实差遣了他，他也未曾轻率地说过什么。然而我们不当把神这样非凡的作为局限于一个预言而已；乃是先知的权威因此得以坚立，他的呼召也就其全部教义的整个进程得着印证。他叙述了一件新近发生、独特而众所周知的事件，藉此向直到世界末了的人证明：神曾藉他的口说话。

<!-- PAGE 861 -->
那场屠杀是在何处由使者施行的，并不十分清楚。一般所持的看法是，它发生在围困耶路撒冷之时；但也可能是发生在西拿基立军队行军途中，就是他正前来围城的时候。我把这事留作未定，因为这无关紧要。从上下文看，我们确可清楚得知：那暴君并未逼近到能向城里投掷一枝箭的地步。

我们实在必须弃绝那种虚构之说——撒但藉着世俗史家企图用它来遮蔽神这非凡的审判——即：因着军队的一部分在埃及战役中被瘟疫所灭，西拿基立便退回本国。一夜之间死了这么多人，不能归因于瘟疫；那说谎之人的父亲照他惯用的诡诈，把神赐给他教会的福气挪移到埃及去了。事件本身大声宣告：耶路撒冷是奇妙地、仿佛从灭亡当中被救出来的；尤其因为以赛亚早已传了那信息，神藉此以不容误解的方式作见证，说他要将这拯救赐给犹大人，而不是赐给埃及人。

<!-- PAGE 862 -->
<span style="color:#800000">*在亚述营中杀了。*</span>为免有人将这奇迹归于自然的原因，经文特意补充说：如此众多的人乃是被*天使*的手所杀。主使用天使的服事来促成信徒的安全，并非新事，因为他为信徒的益处设立了天上的全军；当我们晓得有无数的护卫者看守我们时，这对坚固我们的信心大有帮助。（诗篇 91:11）诚然，唯独主自己就有能力，且无疑唯独他保守我们；因为天使可算为他的手，故此他们被称为「执政的、掌权的」。（罗马书 8:38；以弗所书 1:21）但他派定天上的使者作我们的保障与守卫，这对扶助我们的软弱大有裨益。然而一切赞美只归于神，天使不过是他的工具；因此我们必须谨防落入教皇党人的迷信，他们以荒谬的敬拜天使，将唯属神的能力归给天使；我们晓得历代以来有些极博学的人也难免此错。这事是藉一位天使的手还是藉许多天使的手成就的，我们不能绝对断定，这也不是极要紧的事；因为主藉一位天使成就此事，与藉一千位天使一样容易，他使用天使的效力，并非因为他需要别人的帮助，倒不如我们从前所说，是为要扶持我们的软弱。然而更可能、也更合乎先知的用词的是：只有一位天使受命执行这审判，正如在古时的救赎中，有一位天使遍行埃及全地击杀长子。（出埃及记 12:29）虽然神有时藉恶天使施行他的报应，但此处他却选用一位甘心服事他的仆人，好藉着他保守教会的安全。

<span style="color:#800000">*十八万五千人。*</span>那军队如此庞大，不必使我们惊奇，像无知之人那样；他们一听见有如此众多的人上阵作战，便认为不可置信、乃是虚构，因为我们习惯以远为少得多的军队打仗。但东方各国的情形大不相同，历史家的记载与今日众所周知的事迹都充分作证。他们率领庞大的兵力上阵，也不该叫我们诧异，因为他们远更能忍受炎热、劳苦与饥饿，以远少得多的食物为足，并不看重那些今日败坏我们兵士的奢华享受。

至于屠杀的方式与情形，这段经文并未作明确的说明。犹太人猜测这些士兵是被雷击死的，但他们这样说毫无根据，也无可信的凭据；因为他们大胆编造寓言，凡心里想到的便擅自断言为确实，好像有某段历史作支持一般。

<span style="color:#800000">*不料，都是死尸了。*</span>这场屠杀并非如犹太人所主张的那样公开发生，从这段叙述便极为明显，因为经上说他们躺卧着已经死了。倘若他们是被雷电击杀，人人都必知道，先知也不会将此略去不提。这一点足以驳倒犹太人的推测，然而我宁愿让此事存疑。只要知道这一点就够了：主既已定意从亚述王手中救出耶路撒冷，就不藉任何人的作为，以突然的死亡剪除了他的军队。

<!-- PAGE 863 -->
**37.** <span style="color:#800000">*亚述王西拿基立就拔营回去。*</span>他现今指明这骄横的暴君撤退得何等可耻——此人在心中的意愿里早已吞灭了全犹大，从前更敢自夸比神自己更有能力。先知用多个词语来表述他的离去，乃是间接责备这可耻的逃窜；因为「他拔营、他离去、他回去」这样的重复并非多余。「王」的称号加上去，是为使他更加羞辱：「看哪，这就是拉伯沙基极力夸耀其权势的那位大王。」

<span style="color:#800000">*住在尼尼微。*</span>他进入犹大，原不是为要如此可耻地离开；因此是神的手将他抛回，正如草秸被风吹散一般。他住在尼尼微这一情节也提醒我们，他不但丧失了兵力，也丧失了勇气；因为若非绝望如锁链一般缚住他，他决不会甘心安坐无为。所以这意思是说，他满足于自己旧有的疆域，而尼尼微是其中的首城与王宫所在。到了后来，亚述人被迦勒底人征服，政权的所在便迁到巴比伦，那是在西拿基立死后十年，正当此处所提及的、他的继任者以撒哈顿在位的时候；因为杀父之人不缺乏拥护者，一个为党派所撕裂的国家，便容易被外邦仇敌所制服征服。米罗达趁此机会侵入亚述，将他们收服在自己的权下。

**38.** <span style="color:#800000">*一日在……庙里叩拜。*</span>此处犹太人任凭自己发挥他们素来惯于纵情的臆测之能。他们编造了一个故事：说西拿基立求问神谕，问他为何不能征服犹大人；所得的回答是，亚伯拉罕曾愿意将自己的儿子献给神；于是这暴君效法此例，决意杀死自己的儿子，为要使他的神息怒；他的儿子们因父亲这残忍的图谋而激怒，就在他偶像的庙中把他杀了。然而，不必在这类臆测上耗费时间，犹太人在其中显出极大的放肆。

<!-- PAGE 864 -->
在此，极为重要的是要如观画一般看见暴君们不幸的死亡：当一切似乎都将被他们的暴力所倾覆之时，主竟不藉人手将他们灭绝，并把他们连同其全部权势一同暴露于普世的嗤笑之下。西拿基立率庞大军队来到犹大，归回本国时却只剩少数兵士，仿佛被神作为胜利者牵着夸胜而行。但事情并未止于此；因为就在他帝国的心腹之地，在京都，在庙宇之中——那地方的可敬本足以庇护最卑微的人免受众人之害——他被杀了，不是被外邦仇敌所杀，不是被叛乱的百姓所杀，不是被叛徒所杀，一言以蔽之，也不是被仆人所杀，乃是被他自己的儿子所杀，使这凶杀更为可耻。当注意的是：那些贪得无厌的饕餮之徒，任意在别人的血中翻滚，最终却被自己的随从所杀，并被那些他本该最可安然倚靠之人所刑罚。这比死在外人手中更为骇人；但神就这样惩罚那些人的残暴，他们在急切贪恋权势之时，连无辜的人也不肯放过。甚至在世俗史家的著作中，我们也能找到此类的各种事例，在其中我们可以轻易看见主的审判。

再者，西拿基立那贪得无厌的野心也得了应得的报应：因为当他一心扩张自己疆域之时，却不能藉着引导儿女和睦相处来保守自己家中的平安；因他对某些儿子疏忽不顾，对另一些又偏爱过度，那阴谋便由此而生。不但这暴君被杀，如我们已经说过的，他的国不久之后也被倾覆；同时，为使他的继位者不敢对犹大人有任何图谋，神也用国内的纷争把他拘限在本国之内。
