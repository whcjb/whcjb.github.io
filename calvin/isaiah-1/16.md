# 第十六章

<p style="text-align:center" markdown="1"><span style="color:#000080">前往 以赛亚书 16:1-14</span></p>

**1.** <span style="color:#800000">*你们当将羔羊奉给。*</span> 先知在此讥讽摩押人，因为他们不肯在当认识神的时候认识他，反而肆无忌惮地等候他的手降下击打，直到被彻底毁灭。因此，这是对迟来的悔改的责备——人无论受何等警告都不肯归向顺服，仍旧顽梗地抵挡神。在疾病已无可救治之处，这样的劝勉正合其宜；这一点务要仔细留意，因为犹太人和基督徒都误解了这段经文。

耶柔米将此解释为指着基督说的，因为祂的降生源出摩押人（路得记 1:4；马太福音 1:5），路得便是摩押人的后裔；这一见解几乎为一切基督徒所采纳；仿佛先知是说：「主啊，虽然如此严厉的审判临到摩押人，你却不会将他们全然灭绝；因为他们要给你送来<span style="color:#800000">*一只羊羔，就是世界的统治者。*</span>」但这一解释既毫无可信之处，就无需驳斥了。

另一方面，犹太人认为说这些话，是因为当犹大人处于卑微境地之时，摩押人停止缴纳他们所该缴的贡物；而以赛亚在预言犹大国将得复兴之后，又随即加上一番劝勉，提醒他们要承认自己的君王。他们甚至说，这话有如一道王家谕令，责备他们的不忠：「把你们所欠的贡物送来。」然而我们在任何地方都读不到摩押人曾臣服于犹大人或向他们纳贡，这样的推测毫无可能。他们所引的那段经文（列王纪下 3:5, 6）也丝毫不能支持他们；因为那段经文所说的是*以色列王*，并明明提到*亚哈*和*撒玛利亚*，而我们知道，他们对犹大人怀着极深的仇恨。

<!-- PAGE 407 -->
因此我坚持我起初所提出的解释，视之为真实而自然的解释；因为先知的用意乃是要责备摩押人未曾及时悔改，并告诉他们：他们如今所要作的，乃是徒然；这事从前本可轻易而行，且大有益处。所以我们当把这话看作是以讽讥的口吻（<span style="color:#0000d4">εἰρωνικῶς</span>）说的——*要打发*；仿佛他是说：已无蒙赦免的希望，他们*打发*也是徒然。恶人受警戒的时候，懒惰地轻忽一切劝诫；及至受刑罚的时候，便面带愁苦四顾张望，向各方求援，试尽一切救助之法，却终归无成，因为他们一无所得。所以以赛亚责备他们的顽固与叛逆，并指明当他们遭遇自己所当受的毁灭时，悔改之时已不复存在。

<span style="color:#800000">*给那地的掌权者。*</span>犹太人认为这是指希西家，此说与一切道理相悖；因为<span style="color:#008080">xra</span>（*eretz*）在此并非指某一特定的地土，乃是指整个*世界*，先知是就普遍而言的。因此，*掌权者*这一称呼必须视为指着神自己说的。他说*羊羔*，意思就是那要献为祭物的；因为连外邦人也承认，他们献祭之时就是在敬拜神。

<span style="color:#800000">*从旷野的磐石。*</span>[^f240] 他把<span style="color:#800000">*旷野的磐石*</span>这名称加给那城，据信那城乃是摩押人的都城；[^f241] 不过也可能他有意把全境都包括在内，如此便是以部分代全体。

<span style="color:#800000">*到锡安女子的山；*</span>就是说，到神所认可的殿那里，在那里照着律法的吩咐献祭。（申命记 12:5、6、7；历代志下 7:12）对那些顽梗之人而言，这是一段何等值得注意的经文；他们把一切的教训都置之不理，肆无忌惮地藐视神，直到神的审判临到他们身上。

**2.** <span style="color:#800000">*必像游飞的鸟。*</span> [^f242] 先知现在说明他先前那番讥讽的用意：摩押人在那时不该再想着*献*祭物，因为除了离弃本乡之外，他们再无别法保全自己。他用*飞鸟*的比喻描写他们将要遭受的惊恐，以致连一片树叶的响声也要使他们逃窜。他警告说，那些滥用安逸的摩押人，将要战兢奔逃，疲于流亡。

<!-- PAGE 408 -->
**3.** <span style="color:#800000">*求你献谋略。*</span> [^f243] 他继续同一主题；因为我们若要正确领会这段经文，就必须把摩押人那可怕的倾覆摆在眼前。他们的罪行被提起，为要使众人更清楚地看见，他们所受的刑罚是何等罪有应得。当万事都在他们掌握之中时，他们放纵无度，不肯听任何责备；但如今，当他们被剥夺一切，就哀号呻吟，四处寻求那无处可寻的救法。主对付被弃绝的人，其方式乃是这样：为要使他们无可推诿，他将他们所需的一切都赐给他们，交在他们手中；但当他们出于邪恶的私欲，滥用一切、将一切转作恶用之后，他就撤去一切帮助与扶持，将他们彻底毁灭。

<span style="color:#800000">*行公平。*</span> 当摩押人享受兴盛之时，他们毫不在意什么是善的、正的；当他们有权柄按公义治理、建立自己的国度之时，他们却滥用权力，行暴虐之事。如今他们既被剥去一切权柄，成了被掳的流亡者，以赛亚就讽刺地劝他们*献谋略*、*行公平*——就是他们从前藉着诡诈与不义所颠覆的事。以赛亚所指的乃是摩押人一切权势与权柄都被夺去的那个时候。这种责斥与主对亚当所说的话相似（创世记 3:22）：*那人已经与我们相似*，主用这尖锐的讥讽嗤笑他，因他不满足于自己所得的崇高地位，竟想与神自己比肩。

照样，摩押人不满足于自己的装饰与财富，竟可悲地扰害掠夺以色列人与犹大人，并对他们图谋恶事。他们既滥用了神美好的恩赐，就理当受这责备的话；这话同样适用于一切被弃绝的人，他们在兴盛中骄傲自夸，又野蛮地滥用兴盛去扰害敬虔人。既然他们卑贱地污秽了主本已分派作正当用途之物，他们被剥夺这些恩赐、落到极穷之地，就是公义的。这样的事例我们天天可见。那些被高举到最尊贵地位的人，为何一头栽下去呢？岂不是因为主惩罚他们暴虐的统治与他们的罪行吗？主也讥笑他们那些咒骂责难的言语、他们的哀号，甚至他们的怨诉；正如他们喊着说：「但愿我还有从前所享的财富！但愿我能恢复从前的境况！」因为那时悔改已经太迟了。

<!-- PAGE 409 -->

<span style="color:#800000">*使你的阴影。*</span> 正如我先前所暗示的，当那些可怜的犹大人被亚述人扰害时，摩押人本可给他们些许帮助；或者至少，若他们还有一点人性的怜恤，就当护庇那些逃难的人；然而他们反倒逼迫他们，使他们本已沉重的苦难更加沉重。摩押人向别人所施的残忍，如今归到自己身上，这是完全应当的：当他们被赶离家园、成为被掳流亡漂泊之人时，他们无论到哪里都找不着任何慰藉，找不着任何*阴影*可以遮蔽炎热；因为他们既野蛮地拒绝将安慰给别人，为何还该享受安慰呢？

<span style="color:#800000">*如同正午的黑夜。*</span> [^f244] 此处所说的*正午*，是指最炙热的暑气。这个比喻在圣经中屡屡被使用，说主*白日像云彩，夜间像火柱*；因为祂从前在旷野中正是如此。（出埃及记 13:21, 22；民数记 14:14；申命记 1:33。）这种说法既已成为惯用之语，先知们便沿用它，虽然他们并非在叙述那段历史。

<span style="color:#800000">*藏匿被赶散的人。*</span>他所指的是犹太人，亚述人逼迫骚扰他们，摩押人同时也残酷地对待他们。摩押人本当收容并救济这些逃亡者，尤其是那些逃到他们那里寻求庇护的人；然而他们既然把这些人赶了出去，他们自己照样被赶出去、被剥夺一切援助与支持，也就是理所当然的了；因为耶和华所宣告的乃是公义的判决，就是他所吩咐的：*各人用什么量器量给人，也必用什么量器量给他*。（申命记 19:19, 21；马太福音 7:2）如今先知呼召摩押人承认自己的罪，好叫他们承认自己因残暴而受刑罚是公义的。然而他心中所念的更是犹太人，为要叫他们知道，神并未漠视他们所受的苦难，因为他们已得着宣告：神必为他们伸冤。

<!-- PAGE 410 -->
**4.** <span style="color:#800000">*求你容我这被赶散的人和你同居。摩押啊。*</span>先知向*摩押人*说话，仿佛他代表全体百姓在谦卑地恳求他们：「你们是邻邦，与我们有血脉之亲；求你们接纳并帮助这些落难的人；纵然你们不愿帮助，至少不要加害于他们。」神通常亲自担当他百姓的案件，此处却被先知描绘为仿佛他扮演了一个恳求者的角色。可以确定的是，摩押人对犹太人绝没有如此行，反倒与犹太人的仇敌联手加害他们。但正如我在稍前所说的，先知把连本性也要求的公义摆在我们眼前，为要叫人更加憎恶那残忍的践踏。

这段经文当仔细留意；因为神在此显明他何等看顾他的百姓，以致加在他们身上的伤害，触动他就如同加在他自己身上一般；正如他藉着撒迦利亚宣告说，*凡触摸他们的，就是触摸他眼中的瞳人*。（撒迦利亚书 2:8）他*垂听叹息*（<span class="ages-code">&lt;19A220&gt;</span>诗篇 102:20），也看顾那些呼求他之困苦人的眼泪（诗篇 12:5, 38:9）；这虽不总是我们所能看见的，然而到了合适的时候，他必显明他已垂听了他们。

祸哉！你这毁灭人的，自己倒不被毁灭。（以赛亚书 33:1）

信徒得知这一点，乃是极大的安慰：他们若被逐出本国，神必看顾他们，并要在最大的混乱之中为他们寻得庇护之所。先知在此警戒他们不要怀疑神必为他们预备藏身之处，这并非没有充分的理由；因为以色列人既被四邻如此憎恶，还能指望什么人的援助或保护呢？故此他表明，他们若信靠神，就当怀有最坚定的盼望，纵然在地上看不见任何援助，也不应陷入绝望。

**5. 必有宝座因慈爱坚立。** 他现在转到亚伯拉罕的后裔——这后裔虽几乎被削减到荡然无存，却仍要作神怜悯的见证人；先知在威吓了绝大多数百姓之后，便提出些安慰，为要激励敬虔人的心。因此，虽然摩押的灭亡必是确定而可怕的，虽然犹太人也要受许多苦难，然而为免对这些事的惧怕压倒信徒的心，他表明神必在这些灾祸之中保守他的教会，并且他向大卫和他后裔所作的应许必不落空。

<p style="text-align:center" markdown="1"><span style="color:#000080">因为那不怜悯人的，也要受无怜悯的审判。</span> <span style="color:#000080">(</span><span style="color:#000080">雅各书 2:13。)</span></p>

当神称他们为*我被赶散的人*时，这话若视为指着刑罚而言，也无不妥，好像他说，按着公义的审判，他们已从迦南地被*赶散*（申命记 28:64），正如他屡次向他们所警告的。然而毫无疑问，他同时也是说，他们仍在他的护卫与保守之下，因为，虽然他们被赶散、被逐出本乡，他仍旧承认他们是他的百姓。犹太人所受的灾祸，或可被看作他们已被弃绝的凭据；然而<!-- PAGE 411 -->耶和华却承认他们是*他的儿女*，尽管他严厉地管教他们。由此我们得着一个满有安慰的教义：即便沉重严厉的鞭打加在我们身上，我们仍被算在他儿女的数目中。

<span style="color:#800000">*因势力的人已经消灭。*</span> [^f245] 他现在将话转向犹大人，如同先前一样，继续安慰他们，指明当他们的仇敌从他们中间被除去时，仇敌的被逐或败亡也必解除他们自己的灾祸与困苦。然而前面所说的，主要仍是关乎犹大人，虽然先知明明是向摩押人说话。不过那时他只是威吓要报应仇敌，而在此他更清楚地应许安慰他的百姓；好像他说：「摩押啊，你以为我的百姓已全然毁灭了，但我要制止那些仇敌，使那苦难止息。因此你必灭亡，而我的百姓终必从那些可怕的灾祸中得着拯救。」

或许有人宁愿认为这里有时态的变换；如此一来，我们译作 *For*（因为）的那个词 <span style="color:#008080">yk</span>（*ki*）便当解作「直到」；[^f246] 而这一分句便应与前半句紧接相连而读：<span style="color:#800000">*摩押啊，容我逃亡的人和你同居；求你作他们的隐密处，脱离灭命者的面，直到那勒索人的止息*</span>。但既然这种解释可能被视为牵强，我便宁愿持守其自然的意思。

**5.** <span style="color:#800000">*必有宝座因慈爱坚立。*</span> [^f247] 犹太人把整节都解作指希西家，但这是全然不合宜的；因为先知在此所论的是教会一次更重大的复兴，而摩押人并未在希西家治下昌盛之时受刑罚；况且神的祝福那时也重新向犹大人涌流出来。这好像是说：「凡选民的仇敌都恶意图谋倾覆那国度，就是神所应许*要坚定永远*的国度。」（撒母耳记下 7:13）为使敬虔人不至在这不幸的混乱中陷于沮丧，他们被提醒记起这国度的永存，而这乃是他们藉着那众所熟知的预言早已得着确信的。

<!-- PAGE 412 -->
因此，这话不能解作指着别的，只能是指基督；虽然我承认希西家是基督的一个预像，正如大卫和他其余的后继者也是如此。但他们乃是引领我们到基督那里去，惟有基督是他百姓的保护者与领袖（约翰福音 10:16），并且*将神四散的子民都聚集归一*（约翰福音 11:52）。为此，先知打发敬虔人回到基督那里，仿佛说：「你们知道自己所敬拜的是何等的神。他已宣告他必看顾你们的安全，使你们在他的保护之下永远得保全无损；倘若你们有时遭遇逆境，他也已应许赐给你们一位救赎主，在他之下你们必享重得的、稳固的兴盛。虽然你们暂时可能哭泣，然而教会的保护者必要来到，必使你们复归自由昌盛之境。所以，你们当全心倚靠对他的期待，即便你们看见教会正处在混乱可悲的境况之中。」

这一点务须仔细留意；因为若我们不将一切安慰都归于基督，则其余的安慰尽属短暂易逝。所以，我们若愿蒙福亨通，就当定睛仰望他；因为他已应许我们，即便在十字架之中我们也是有福的（马太福音 5:10,11），痛苦与折磨必为我们开通那通往有福之生命的道路（哥林多后书 4:17），我们所要受的一切苦难都必增添我们福乐的分量（罗马书 8:28）。

<span style="color:#800000">*凭慈爱。*</span>以赛亚指明，此事并非藉人的作为而成，乃是出于神的恩慈，他是这*宝座*的建造者；因此我们当承认，这神圣的*宝座*得以在我们中间坚立，全然是出于他白白赐下的美善。先知明确地印证这一点，说其缘由不可在别处寻求，只可在神那绝对的*慈爱*中寻求。也确实找不出别的缘由；因为神断不能因人品格上的任何优美，或因功德（其实一样也没有），被动而重新扶立那因百姓的过失与罪行而倾倒的宝座；然而当他看见他所收纳为儿女的人已然败亡，他就愿意显明他无限恩慈的明证。如今，若这宝座是神所建造的，谁能将它倾覆呢？恶人岂能比他更强吗？

<!-- PAGE 413 -->
<span style="color:#800000">*他必在大卫帐幕里坐在其上。*</span>此处几乎每一个词都含着重的意味，故此这一节值得我们不断默想。有人认为*帐幕*一词暗指这样的意思：大卫在*被召坐上宝座*之先，只是一个平凡之人（撒母耳记上 16:11,12；撒母耳记下 7:8）——我并不反对这看法。先知的用意是要描绘教会的图画，这教会与君王和王子的宝座毫无相似之处，也不以金子或宝石闪耀。虽然他是以卑微可鄙的形态呈现基督属灵的国度，但他同时也表明，这国度必在地上、在人间被人看见。他若只说基督的*宝座*必被立起，我们便可以问：他的*宝座*是在天上呢，还是也在地上呢？但现今他既说<span style="color:#800000">*在大卫帐幕里*</span>，就表明基督不单在天使中间作王，也在人间作王，免得我们以为，为要寻求他，我们必须进入天上。恶人讥笑我们所传关于基督国度的道，仿佛那只是我们自己想象出来的幻影。他们愿意用肉眼看见它，愿意有感官的证据；但我们绝不可将它想成属肉体的，而当以他的膀臂、以他的能力为满足。

<span style="color:#800000">*凭诚实。*</span> <span style="color:#008080">tma</span> (*emeth*) 一词不仅指 *真实*，也包含各样的 *确定坚固*。先知的意思是，基督的国将是坚固而稳定的，正如但以理所宣告的（但以理书 2:44，7:14）。福音书作者也说：*他的国也没有穷尽*（路加福音 1:33）。在这一点上，基督的国有别于列国通常的光景；列国即或建立在极其庞大的财富之上，仍会崩塌，甚至被自身的重量压垮，以致其存留不过如转瞬即逝的图画。但以赛亚宣告说，基督的国虽屡屡摇动，却必有神的手扶持，因此必存到永远。当基督的国受到如此众多而强大的仇敌攻击，以致我们几乎要以为它转眼就要被毁灭时，各样的试探便随之而起；这些凭据正当坚固我们的心，抵挡那些试探。无论世界动用怎样的兵器，纵使阴间自身要喷吐烈焰，我们仍必持守这应许，

<!-- PAGE 414 -->
<span style="color:#800000">*施行审判。*</span> 我理解 <span style="color:#008080">tpç</span> (*shophet*) 为 *治理者*，仿佛他是说：「必有一位 *治理* 的。」我们常见宝座何等华美，却无人坐在其上；也常有这样的事：君王不过是偶像或是牲畜，毫无判断、才干或智慧。但此处先知说，必有一位坐在其上，履行良善 *治理者* 的职分；加上这话，是要使我们确信基督必作我们的保护者。

<span style="color:#800000">*寻求公平，速行公义。*</span> 归给他的 *公平* 与 *公义*，无非就是他接纳我们进入其中的那护庇，是他绝不容人侵犯的；因为当我们忍耐安静地把自己交托于他的保护之下时，他必不容那些加害我们的恶人逍遥而不受罚。他用 *速行* 一词表明，他必快快地、迅速地为我们伸冤。这话当视为对我们急躁的责备，因为我们总以为他的帮助来得不够快。然而当我们被激情的猛烈冲动裹挟时，让我们记得，这乃是出于不肯降服于他的护理；因为按我们肉体的判断，他固然是迟延了，其实他却按着他自己所深知的时候，以最美好的方式安排他的审判。所以让我们顺服他的旨意。

**6.** <span style="color:#800000">*我们听说摩押人骄傲。*</span> 先知加上这句话，是为了预先解答异议。有人可能会认为，人们无法相信他所应许的事，就是关乎重建君王*宝座*、毁灭摩押人的话；因为摩押人当时财富兴盛，有坚固的堡垒作防卫，并且因所享的繁荣而自我膨胀，极其*骄傲*。此外，他们那藐视不幸犹大人的傲慢态度，也是一种令人难受而有力的武器，足以使犹大人的心灰冷动摇。为了防备这一试探，先知述说他们的夸口是众所周知的，但他们的*骄傲*并不能阻止神倾覆他们；因为无论何等军力的排列、何等丰厚的财宝、何等众多的人数，都不能抵挡神。以赛亚提及此事，视之为人所共知的：摩押人自我膨胀到这种程度，以致无所惧怕；正如那些财富与兵力充足的人常有的情形，他们徒然自高，凌驾于神与人之上。然而不论他们的傲慢如何，主必轻易将它压制。

<!-- PAGE 415 -->
<span style="color:#800000">*他狂妄。*</span> [^f248] 希伯来文 <span style="color:#008080">hrb[</span>（*gnebrah*）最常指*忿怒*；但它在此处所处的上下文似乎要求一个更为确切的意思。这个名词源于动词 <span style="color:#008080">rb[</span>（*gnabar*），意为*越过*或*超出*，相当于拉丁文 *excessus*（越界、过分）；因此我认为译作*狂妄*更为妥当。在一处平行的经文中，在*骄傲*与*傲慢*之后，紧接着是*心中自高*这一说法（耶利米书 48:29）。我毫不怀疑，以赛亚与耶利米二人的意思都是：摩押人因其顽梗轻蔑的行径，以及奢华的生活方式，变得如此残暴，以致为着最微不足道的缘由便勃然发怒，凶猛地起来攻击别人。这一恶习总是伴随着心中的自高；因为*骄傲*之后随来的，就是对他人的轻视与蔑视，而那些索求超过自己所当得之分的人，极易动怒，为极小的冒犯便发狂。总而言之，他们什么都不能忍受，不但性情暴烈，更是横行无理。他们愿望人人都向他们退让，而自己却不向任何人退让。若众人不照他们的吩咐退让，他们便以为自己受了不公。这种暴烈的性情，在骄傲之人身上极易显露。反之，谦卑的人则怀有慈爱，并伴以相称的温和，且轻易地饶恕那些得罪他们的人。

<span style="color:#800000">*他夸大的话。*</span> 希伯来文 <span style="color:#008080">µydb</span>（*baddim*）或指*人的肢体*，或指*树的枝子*，有时也用以指*占卜*。因此希腊文译者 [^f249] 将它译作 manteia，即*占卜*，在别处的经文中它确有此义。有人认为此处是隐喻地用来指*儿女*；有人译作*言论*或*思念*；也有人译作*力量*或*筋脉*。但依我看来，它在此处更是指*虚妄的夸口*；因为这个词常表示*虚谎*，而我们随即就要看见，这一含义如何贴切地适用于本段经文。

关于 <span style="color:#008080">ˆk</span>（*ken*，）*如此* 这个词的解释，分歧同样很大。多数人认为它的意思是「谎言不正」，或「言语不正」，另一些人则认为是「谎言不真」；就事情的实质而言，我几乎赞同他们的看法。我毫不怀疑先知的意思是：摩押愚妄地夸口，说些虚妄的大话，因为他所设想的必不能成就。至于字句，其含义可从耶利米书 48:30 更确切地得知。在使用了与以赛亚此处 <!-- PAGE 416 --> 相同的话之后，他随即为解释这些话而加上 <span style="color:#008080">ˆk al</span>（*lo ken*，）<span style="color:#800000">*并不如此*</span>；[^f250] <span style="color:#800000">*他的谎言必不成就*</span>。仿佛他说：「他们心中所定的必不得成就。」然而我并不认为，在前一分句中 <span style="color:#008080">ˆk</span>（*ken*）表示比较，倒不如说是表示一种确认——姑且这样说——但却是否定性的确认；因为他宣告说，在摩押的谋算中必没有坚固或稳固可言，<span style="color:#800000">*他的占卜或谎言必不生效*</span>。骄傲的人安排一切，仿佛万事都在他们权下，仿佛万事不受神护理的支配。以赛亚说，这样的**傲慢**必被贬抑，他们凭自己力量所夸下的一切必都归于虚空。这提醒我们：骄傲在神眼中极其可憎，人越因财富自高自大，就越临近灭亡。

**7.** <span style="color:#800000">*因此，摩押人必为摩押人哀号*</span>。[^f251] 他更清楚地宣明前面已说过的话：这**骄傲**，以及由此而生的残忍，将成为他们灭亡的缘由。既然主**阻挡骄傲的人**（雅各书 4:6；彼得前书 5:5），他就断不能不使这狂傲低落——教会正是被这狂傲卑贱可耻地践踏在脚下；照着这个例子，一切骄傲之人的结局必是悲惨的。当他加上「摩押人为摩押人」时，他的意思是，在他们中间将有一种可称为凄凉的合唱，他们彼此诉说自己的灾祸，在彼此之间为自己的困苦哀哭。另有人译作「为着摩押的缘故」，但这是软弱无力的解释；因为紧接着就说，这**哀号**将是普遍的，或说要遍及全民。

<span style="color:#800000">*为吉珥·哈列设的葡萄饼（原文作「根基」）*</span>。这显然是一座首要的王城；但有人认为它是专有名词，有人则认为它是普通名词。毫无疑问，这词的字源出于它是用泥土材料建造的。也有可能它得此名是因城墙的性质，城墙乃是用砖砌成的。它在那地是一座著名的城。他提说<span style="color:#800000">*根基*</span>而非城本身，因为它将被彻底倾覆；仿佛他说：「你们所要哀哭的，不是城被掳掠或房屋被毁坏，乃是它的全然倾覆；因为它必无一部分存留。」

<!-- PAGE 417 -->
<span style="color:#800000">*你们必哀号，只是受了击打。*</span> [^f252] 有些人把 <span style="color:#008080">µyakn</span>（*nechaim*）译作*瘸腿的*；但我更愿意把它理解为<span style="color:#800000">*受击打的*</span>。此处置于其前的小品词 <span style="color:#008080">˚a</span>（*ach*），有时意为*确实*或*真实地*；有时则用作*但是*或*然而*。那些作肯定语气解释的人认为其意思是：<span style="color:#800000">*你们必哀号，实在是*</span><span style="color:#800000">*受了击打*</span>；即，「你们不必雇人代你们假意哀哭，像人们在丧事中通常所作的那样，你们乃要真实地哀哭。」但我更愿意把 <span style="color:#008080">˚a</span>（*ach*）解为*只是*；即，「凡存留下来的都必受伤；无一人得以安全。」先知借这样的说法描述那城的彻底毁灭，并暗示那些余剩的人不但要为别人的苦难哀哭，也要为自己的哀哭。他们自己也必受伤。既然*骄傲*的人要受这样严厉的刑罚，就让我们学习以谦卑和谦逊顺服自己，甘心*自卑，服在神大能的手下*。（彼得前书 5:6）

**8.** <span style="color:#800000">*因为希实本的葡萄树已被砍下。*</span> [^f253] 先知在此以比喻的方式描述全地的荒凉。有理由相信那地盛产最上等的*葡萄树*， [^f254] 从本段以及那平行的经文（耶利米书 48:32）便可轻易推知。先知们威胁各国要遭毁灭时，通常会描绘出这些地方较为显著的特征。譬如，我们若谈到皮卡第，断不会提及*葡萄树*，正如我们谈论奥尔良或勃艮第时那样。而先知在此所提的那些城，乃是摩押的主要城邑。

<span style="color:#800000">*列国的君主已践踏了它上好的枝子*</span>或<span style="color:#800000">*枝条。*</span> [^f255] 先知说，他们葡萄园中*最宝贵的枝子*被<span style="color:#800000">*列国的君主*</span>拔出，就是被那些征服者，他们在战争中制服了万国，掌握广大的统治权。

<span style="color:#800000">*一直到雅谢。*</span> [^f256] 这是要指明荒凉的范围；因为这城位于摩押人地界的边缘；仿佛他说：「不但葡萄园的一部分要被砍下，全地四境都要广遭荒废。」有人把这话指向仇敌自己；但我宁愿补上关系词 <span style="color:#008080">rça</span>（*asher*），即 *which*（那……的），并将其归于 *葡萄树*，就是那些蔓延甚广、以致 <span style="color:#800000">*一直到雅谢*</span> 的葡萄树。这样，意思便是：「这些葡萄园虽 <span style="color:#800000">*一直到雅谢*</span>，遍布极广大的地带，然而从那里直 *到* <span style="color:#800000">*旷野*</span>，都要被 *列国的君主* 践踏。」这与本段的主旨最为相合；因为紧接着又说葡萄园 <span style="color:#800000">*延到旷野*</span>，甚至 *到海*；他借此表明那地极其肥沃，<!-- PAGE 418 --> <p style="text-align:center" markdown="1">尤其盛产 *葡萄树*。他说它们 *过了海*，[^f257]</p>

因为当土壤肥沃时，人惯常用堤坝护住临海之地，为要扩展耕作，并以木桩和堤岸抵挡波浪的冲击，好得着大片可用之地。

**9.** <span style="color:#800000">*因此，我要……哭泣。*</span> 先知在此扮演另一个人的角色，正如我们先前所说的；因为他是以摩押人的名义在哀哭悲叹。无疑，信徒总是因神的审判而战兢，也不能撇下人性的情感，以致对恶人的灭亡毫无怜悯之情。然而他在此并非描述自己的感受；他的用意乃是使自己的教训更有分量，免得有人对其应验存疑。因此他以一个摩押人的身分，如同在舞台上一般，表现那灾祸之后众人所要感到的哀恸与忧伤，为要向犹太人坚固这应许，否则这应许或许会被认为难以置信。

<span style="color:#800000">*因为你夏天的果子和你收割的庄稼都有喊杀之声，*</span>或作*必降临*。[^f258] 本节末句注释家们解释各异。<span style="color:#008080">lpn</span>（*naphal*）意为*降下*或*闯出*。将其译作*闯出*的人，认为<span style="color:#008080">ddyh</span>（*hedad*）即*喊杀之声*，是指仇敌自身；仿佛他说：「仇敌的*喊杀之声*闯入你的庄稼中」；如此，这<span style="color:#800000">*喊杀之声*</span>与他后面所要说的*欢乐*之间，便暗含着一种对比。另有人解释说，意思是<span style="color:#800000">*喊声必止息*</span>；即「再无<span style="color:#800000">*喊声*</span>，收割的人在收成之后彼此欢庆的欢畅愉快之声，也不再被听见。」但我宁愿将它归于仇敌的<span style="color:#800000">*喊杀之声*</span>；在这一点上，我随从本段最忠实的解释者——先知耶利米，他说*那行毁灭的已经临到*（耶利米书 48:32），而以赛亚在此所说的乃是仇敌的<span style="color:#800000">*喊杀之声*</span>；仿佛他说：「当你预备收聚你的庄稼和你的葡萄时，仇敌必*闯*进来，那时所听见的不是欢乐与愉悦的歌声，而是他们的*喊杀之声*，这声音必把你远远赶走。」

<!-- PAGE 419 -->
**10.** <span style="color:#800000">*喜乐都被夺去。*</span> 他用不同的言辞，坚固他方才所说的：全地必荒凉被弃，以致其中再不会有收割，也不会有葡萄的收成。当他威胁说神必使修理葡萄园的人止住歌唱时，他所指的是一项古时的习俗；因为他们收葡萄的时候，惯常以舞蹈和歌唱来表明他们的喜乐。故此维吉尔有言：*那疲乏的修理葡萄园的人，此时以歌声向他最远的一行葡萄致意*。[^f259] 同样，水手们靠近港口时，便发出他们欢乐的呼喊（keleusma），因为劳苦已毕，危险已过，他们看见有指望得着些安歇或复苏。这好像先知说：「当收割的出产被夺去时，他们所剩下的，只有为自己的贫穷哀哭了。」

**11.** <span style="color:#800000">*因此，我心腹为摩押哀鸣如琴。*</span> 先知再次以一个摩押人的身分，描述那出于极深忧伤的过度哀恸，忧伤如此剧烈，甚至连心腹都发出凄惨之声；因为他有意藉这征象指出事情的实况。我们从前已经解释过这些生动描写的用意，就是要把那些事件如同摆在我们眼前，并引我们对那些看来全然难以置信之事，抱持更坚定的盼望。他再次提名那首要的城*吉珥哈列设*，如此以部分代全体，藉此描述全地的毁灭。

**12.** <span style="color:#800000">*必有这事。*</span> 他再次回到先前所提及的那句话，就是拜偶像的人在遭患难时便投奔他们的偶像，指望从偶像那里得着些许缓解。然而这里的含意还要更多一层；因为拜偶像的人虽有他们平常的庙宇与敬拜之所，一旦有非常之灾祸临到他们，他们就往另一座比其余更为神圣的庙宇去，期望在那里更丰满地蒙他们的神以其临在眷顾。照样，今日的天主教徒，每逢陷入什么非常的危险（因为这毛病历世历代都存在），就以为若奔往圣克劳德（St. Claude），或奔往罗雷托的马利亚（Mary of Loretto），或奔往任何别的著名偶像，就必比聚集在邻近某座教堂里更容易得着他们所求的。他们决意要在一座相距甚远的教堂里献上他们那非常的祈求。先知正是在这个意义上，把 *圣所* 一词用于摩押人中间最为著名的那一处，并且说他们必往那里去，却毫无益处。如今从圣史可以明显看出，他们最著名的庙宇是献给 *基抹* 的。（列王纪上 11:7）

<span style="color:#800000">*也不得益处。*</span> [^f260] <span style="color:#008080">lkwy al</span>（*lo yuchal*），*他们必不能*，有人如此解释：他们终必疲乏至极，以致再没有足够的力气走到庙里去。但我认为这样译更好：<span style="color:#800000">*他必不能得益*</span>；因为他借着说他们连在自己的神那里也找不到庇护，就断绝了摩押人一切得救的指望。

<span style="color:#800000">*当这被看见的时候。*</span> <span style="color:#008080">harn</span>（*nirah*），*被看见*，这个字是有强调意味的。它的意思是：拜偶像的人并不受理性引导，倒是受他们感官所得的印象引导，如同畜类一般；因为兽类既凭触觉、嗅觉、视觉来判断，拜偶像的人也照样除了肉体的判断以外别无引导。所以，若有人向他们指明他们所行的不对，也是徒然无功。他们虽屡次凭经验得知，那许多劳苦的操作于他们毫无所得，却仍不肯罢手，反倒要设计新的方法，引进新的敬拜礼式，指望神会悦纳。倘若事情如他们所愿而成，他们就把一切都归功于自己的迷信，并且越发顽固。倘若他们察觉自己毫无所得，就弃绝自己的设计，定罪那迷信的敬拜，咒诅自己的神。总之，他们全然倚赖事情的结局，无论凭理性或凭神的话都不作任何判断。其结果就是，他们既受所遭遇之事的引导，便不断更改自己的计谋。但先知似乎还有更多一层意思，就是：当他们迄今劳苦而毫无所成的愚昧被公然显明、暴露出来之后，摩押人来到基抹的庙中，与其说是出于判断，不如说是出于羞愧。

**13.** <span style="color:#800000">*这是……所说的话。*</span>这结语乃是这预言的确证。其意是说：他所宣告的乃是神自己的判决，他所提出的一切无不出于耶和华；因此他撇下了人的身份，让神以这样的方式说话。

<!-- PAGE 421 -->
**14.** <span style="color:#800000">*三年之内。*</span>时间被定下，不仅为了确定无疑，也为了使信徒不因久延而灰心。他在此暗指人与人之间的契约，其中惯例是订明约定的期限，双方都不得逾越。这在*雇工*的劳役上尤其如此，圣经常在这一点上取此为比：他们殷切盼望那领受工价的既定之日；因为他们仿佛在重担之下呻吟，极其厌恶每日的苦工（约伯记 7:1, 2, 14:6；以赛亚书 21:16）。耶和华就这样说，他为摩押人定下一个日子，在那日他们必不能逃脱其势力的全然毁灭。

<span style="color:#800000">*和他所有的群众。*</span>他特意提到*群众*，因为他们人数众多，又以此夸口，自以为无人能敌。当他接着说<span style="color:#800000">*所遗留的人必稀少*</span>，其意是说：将有如此巨大的变迁，以致他们与从前的境况毫无相似之处；因为除了一幅可悲可怖的景象之外，别无所留。
