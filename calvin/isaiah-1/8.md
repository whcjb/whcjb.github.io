# 第八章

<p style="text-align:center" markdown="1"><span style="color:#000080">前往 以赛亚书 8:1-22</span></p>

**1.** <span style="color:#800000">*耶和华对我说。*</span> [^f109] 这段预言并没有加上什么新的内容，而是对前面那段预言的确证；在前面那段预言中，以赛亚预先宣告了以色列国与叙利亚即将来临的荒凉。他曾预言这两国都要失去它们的君王，而这事必在那些不久之后要出生的孩子还不能分辨善恶以先，就是说，在他们长大成人以先，就必成就（以赛亚书 7:16）。然而，因为恶人不为任何威吓所惊惧，所以就必须将这预言再度重申，并且藉着某些外在的记号加以印证。

首先，为要更有效地唤醒这个民族，神吩咐将这预言用文字公开宣布出来，使众人都能明白。我们从前已经说过，[^f110]先知们的惯例是：在受命向百姓传达某一信息之后，便将所说之话的要旨用几句话总括出来，贴在圣殿的门上；这从 哈巴谷书 2:2 可以看出；因为若将那段经文与本处相比，事情就足够明显了。但此处所表达的却有些特别之处；因为神不只是吩咐他**写下**这预言，而是要求<span style="color:#800000">**一个大牌**</span>，以便可以从远处读到。字写得越小，就越模糊，越难以辨读。紧接着所说的也是同样的意思，<span style="color:#800000">**拿人所用的笔**</span>，[^f111]因为<span style="color:#008080">çna</span>（*enosh*，以挪士）指任何寻常身分的人；其意思是：连最无知、最未受教育的人也不至于读不出这文字。

<!-- PAGE 226 -->
<span style="color:#800000">**掳掠速临，抢夺快到。**</span>[^f112]这样简洁的短语比长篇大论更为有力；因为任何人都能把这四个字带回家去，从其中察觉神忿怒的迅速，并真实而深切地被神的审判所触动，如同有指头把它指点出来一般。总之，神决定不让他浪费言语，因为已没有争辩的时间了，而要他用一个外在的记号把这事表明出来。先知们既已多次警告刑罚将临，却毫无果效，神便借着一个实例把它极其鲜明地展示出来，使它在他们心中留下更深的印象，并铭刻在他们的记忆里。每逢提起<span style="color:#008080">llç rhm zb çh</span>（*Maher-shalal-hash-baz*，玛黑珥沙拉勒哈施巴斯）这些字，就会使他们回想起以色列与叙利亚的毁灭，并使他们对此更加确信无疑。

以赛亚既在前一章预言了基督的降临（以赛亚书 7:14），许多人便不适当地把这一处也解作论及同一主题，即：基督既得着从天而来的能力，就前来掳掠**这世界的王**（约翰福音 12:31），因此就<span style="color:#800000">**抢夺快到**</span>。这种巧思固然足够动人，却与经文毫不相合；因为上下文真实自然的意思表明，先知在这段话中并没有提出任何新事，而是在支持他先前所说的。

**2.** <span style="color:#800000">*我用可靠的见证人。*</span> 先知所用的名词 <span style="color:#008080">µyd[</span>（*gnedim*，见证人）与动词 <span style="color:#008080">dy[a</span>（*agnid*，作见证），出于同一字根，这种用法极为雅致，仿佛我们说：「我召见证人来作见证。」[^f113] 因这是极其重大的事，所以他<span style="color:#800000">*为自己取了见证人*</span>，正如人在重大场合通常所行的那样。

<span style="color:#800000">*可靠的见证人。*</span> 他称他们为*可靠的*，即真实而可信的；然而其中一人却是不敬虔、卑劣的背道者，他为讨好君王，仿造大马士革的坛筑了一座坛，公然维护不敬虔与非法的敬拜方式。我知道有些注释家认为这是另一个人；但只要仔细察考各样情形，任何人都会确信，这正是那位*乌利亚*，圣经的历史记载宣告他奴颜婢膝地屈从于王的不敬虔与无法无天的私欲（列王纪下 16:11）。至于那些因以赛亚在此称此人为*可靠的*便断定另有其人的人，这种论据分量甚微；因为先知所看的不是那人，乃是他所担任的职分，这职分使他成为合宜的作见证之人。所以，他的意思并非说此人善良卓越，乃是说他的职分使他具有这样的地位，以致无人能弃绝他，他的见证正如人所说的，是无可指摘的。

<!-- PAGE 227 -->

<span style="color:#800000">*祭司乌利亚和耶比利家的儿子撒迦利亚。*</span> 我认为这预言是钉在殿门上的，并<span style="color:#800000">*取*</span>了<span style="color:#800000">*乌利亚和撒迦利亚*</span>为*见证人*；因为他所说的不是异象，而是神的命令，这命令他实际遵行了，为要使这些话如同通行的谚语一般，被众人反复传诵。

**3.** <span style="color:#800000">*我以赛亚就与妻子同室。*</span>接下来所发生在先知身上的事，我毫不怀疑是藉着异象成就的，其目的在于印证前面的预言。以赛亚所得的异象是：他从妻子生了一个孩子，并且受命给他起这名字。诚然，若有人认为先知实际上从妻子得了一个儿子，并给他起了这名字，这也并非荒谬之说；对持此见者，我不打算力争。但既然把这名字起给任何人都不像是可能的事，又没有证据可以证实，我便更倾向于认为这是向先知显现的异象，为要坚固前面的预言。他称自己的妻子为**女先知**，并非如同君王的妻子为着尊荣之故被称为王后那样，而是因为在这异象中她担负了一种公众性的职分。[^f114]

**4.** <span style="color:#800000">*因为在这小孩子不晓得叫父叫母之先。*</span>这既是那隐晦之语的解释，也是对随之而加的异象的解释；因为神虽不愿以直白的言语说话，然而那晦暗之处仍当被除去。我把 <span style="color:#008080">r[nh</span>（*hannagnar*，那小孩子）解释为并非指先知的儿子，而是指此后不久所要生的一切孩子。他宣告说，在他们长大之先，以色列和撒玛利亚 [^f115] 的两个王必被毁灭。

<span style="color:#800000">*在亚述王面前。*</span>意思是，任凭<span style="color:#800000">**亚述王**</span>处置、随其心意；这或许是暗指一种古老的习俗，即在得胜受公开凯旋礼者的战车**之前**抬着仇敌的掠物。照样，撒玛利亚和大马色的财宝也必被抬在<span style="color:#800000">**亚述王面前**</span>。

<!-- PAGE 228 -->
这就更加清楚地表明，先知别无他意，只是要预言以色列国与亚兰国的荒凉。他这样做，是为了安慰敬虔人，同时也是为了嗤笑那愚昧之王的无谓惧怕；这王竟不能容忍耶和华帮助他，因为他所弃绝的不但是那些应许，连所赐的兆头也一并弃绝了。因此，先知越发进一步责备他的邪恶，以及全国的邪恶。「你固然什么都不信，然而耶和华必帮助属他的人；你必快快看见突然而意外的转变，耶和华要藉此拯救他的百姓。」然而这些话与其说是对王说的，不如说是对敬虔人说的；由此我们应当推知，神的仆人说话并不总是为要叫听者相信，因为以赛亚在此对恶人说话，却在他们心里毫不生出确信。那么，他为何还向他们说话呢？为要越发定他们不信的罪，并为此责备他们；其次，为要使神的良善更加显明：因为谁不会以为，如此深重的邪恶必然完全向神的怜悯关上门呢？然而耶和华以他的良善，胜过了王与百姓双方的邪恶。所以先知的目的，是要责备不敬虔的人的悖逆，同时表明神始终如一。

**6.** <span style="color:#800000">*因这百姓厌弃西罗亚的水*</span>*（或译作「藐视」*[^f116]）。为免亚哈斯在毫无根据的期望中沉睡，先知突然中止了他关于敬虔人普遍得蒙保全的论述，接着便向不信者宣告刑罚。有些人认为，他所针对的是那些盼望变革的人；因为常有这样的事：众人对自己现今的处境不知满足，反倒想要另立新王。患病的人往往期望换个地方就能好些。人的意志是如此乖僻，以致事情不合己意时，便寻求处境的改变，急切地抓住它，并盼望从其中得着某些缓解。

但我认为先知的意思更为广泛，并非单指那些想要变革的人；他的话是笼统的，包括各等人在内；因为不敬虔与轻蔑神的风气几乎已经普遍盛行，他所说的不是少数几个人，也不是某一党派，而是这国的绝大部分人。我固然承认，他把少数几个人、就是神的仆人排除在外（这在后面会提到）；但这并不妨碍以赛亚的责备是针对全国而发的；因为既然几乎所有人都已败坏，他就理当责备他们众人。他们的过犯在于：这百姓不信靠自己的软弱，反去寻求增添财富、增添兵力。所以他说，他们<span style="color:#800000">*厌弃西罗亚的水*</span>，因为犹大人**轻视**、**鄙弃**自己的处境。

<!-- PAGE 229 -->

<span style="color:#800000">*且喜悦利汛和利玛利的儿子。*</span> [^f117] 有人译作「与利汛同乐」，但介词「向」（*to*）更充分地表达了那种悖谬的欲望。他的意思是：犹大人察觉自己没有坚固的堡垒，便转眼他望，贪慕以色列国的财富。他们看见自己人数稀少、境况贫乏，就战兢惧怕，不倚靠神，单单倚靠外来的援助，心想若能有像以色列人那样强盛的君王，自己就必万无一失了。他们就这样*喜悦*别人的财富，并且贪慕这财富。

**7.** <span style="color:#800000">*因此，看哪。*</span> 他用现在时说话，为要使众人更加留心：*看哪，主必使大河翻腾的水猛然冲来*。我们必须留意先知所用的比喻，因为这样的文体远比平铺直叙、毫无修饰的说法更为优美。这好像他说：「因为这百姓不满足于自己的境况，反倒贪慕别人的财富，我就要叫他们看看，有一位强盛的君王究竟是怎么回事。」譬如，若有一个小邦，其君王卑微、不受敬重，而邻邦强盛、有显赫的君王在其上掌权，这小邦便说：「若能服事那昌盛的君王，作皇帝或法兰西列王的臣民，那该多么快意，因为他们的权势无人能敌！」神岂不公义地惩罚这种非法的贪欲吗？君王越强盛，压制百姓也越沉重；他们无所不为，一切都随自己的任意妄为而行。何况他们不知自己权力的界限，权势越大，就越肆无忌惮地放纵自己。主责备犹大人这种疯狂的欲望：他们不以自己的境况为足，不仰望耶和华，反倒仰望强盛君王的资源；而这责备藏在这些比喻之下，远比用平白直接的言语来说更为优雅有力。

<!-- PAGE 230 -->
据耶柔米告诉我们，<span style="color:#800000">*西罗亚*</span> 是一处小泉源，从那里流出一条小河，缓缓穿过耶路撒冷城中。那狭窄的河流给他们的保护甚微，因此他们轻看它，反倒渴望得着那些大江大河——城邑通常藉此得着防卫，也大得富庶；因为使一个国家扩张、迅速致富的，没有什么比得上那些宽阔可通航的江河，藉着它们，各样货物的输入输出都变得容易。所以他把幼发拉底河——东方全地最著名的河流——与*西罗亚*相比，并且沿用同一比喻，用那河中湍急的水指亚述人，他们必毁灭全犹大，如同洪水泛滥一般使它荒凉。（列王纪下 18:13, 17）主说：「我要叫他们看看，贪慕那湍急凶猛之水，究竟是怎么回事。」

<span style="color:#800000">*他必上来。*</span>这段经文应当仔细留意；因为我们心中都有一种可谓与生俱来的不信，以致当我们看见自己失去人的帮助时，便丧了胆。无论神应许什么，我们总是丝毫不能振作起来，只把眼目盯在自己的赤裸无依上，在惧怕中如同茫然失措的人一般坐着；因此我们应当为这毛病寻求医治。所以，*西罗亚*——就是神所赐给我们、带着应许的呼召或分——虽然我们肉眼看不见，却当作我们的保障，我们也当宁取它而不取世上一切君王的至高权势。因为我们若倚赖人的帮助，把自己的力量安放在庞大的军队和丰盛的财富上，就必要遭受先知在此所警告的刑罚。

圣经的历史向我们确证这些事已经应验了，因此凡读过这段历史的人，都不需要对本段作冗长的解释；因为犹大人所召来相助的亚述人，反而毁灭了他们。这正是他们不信所受的公义刑罚；我们从其中也看见一个显著的例证，说明人那种邪恶的贪求，竟不能以神的应许和帮助为足。

让我们从犹大人这场毁灭中学会顾念自己的益处。教会几乎总是处在这样的境况中，就是缺乏人的帮助，免得我们若装备得过于丰足，便会被自己的财富和资源所迷惑，忘记我们的神。我们对自己的软弱应当如此满足、如此欣喜，以致完全倚靠神。那微小柔缓的水，在我们看来应当比万国那浩大湍急的江河更为宝贵，我们也不当羡慕不敬虔的人的强大权势。诗篇中所写的，正是这个意思：

<p style="text-align:center" markdown="1"><span style="color:#000080">「有一道河的分汊，使神的城欢喜；</span> <span style="color:#000080">这城就是至高者居住的圣所。</span> <span style="color:#000080">神在其中，城必不动摇；到天一亮，神必帮助这城。</span> <span style="color:#000080">外邦喧嚷，列国动摇；</span> <span style="color:#000080">神发声，地便熔化。万军之耶和华与我们同在；</span> <span style="color:#000080">雅各的神是我们的避难所。」（</span><span style="color:#000080">诗篇 46:4-7）</span></p>

<!-- PAGE 231 -->

若有人反驳说，我们不当弃绝人的帮助，答复是不难的。先知并非责备人的帮助，他所责备的乃是那种邪恶的惧怕——我们因此陷入不信、战栗发抖，以致神的任何应许都不能把我们约束在合理的界限之内。如今我们当把这样的尊荣归给神：即便万事尽都落空，我们仍单以他为满足，并确信他就在近旁。在这种情形下，我们有没有外在的援助，其实无关紧要；有，我们尽可自由使用；没有，就当以忍耐承受这缺乏，让神独自成为我们一切所需的满足；因为他必能成就自己的应许，既然他并不需要任何外来的助力。只要我们全然倚靠他的能力与护庇就够了。

**8.** <span style="color:#800000">*必冲入犹大*</span>。动词 <span style="color:#008080">plj</span>（*chalaph*，哈拉弗）有时意为*穿过*，此处的意思却是*攻击*、*砍除*：就是说，它不只要浸润犹大，更要泛滥其上，直至将它彻底淹没；因为它必四面广泛漫延。他又加上——

<span style="color:#800000">*直到颈项。*</span>这一比喻取自一个人涉入江河：他渐渐深入其中，直到水漫*到颈项*。犹大也必如此被那湍急的河水泛涨淹没，就是被亚述人淹没，直到他淹没*到颈项*。他所指的是耶路撒冷，那是全地的京都；亚述人一到那里，犹大离毁灭便不远了。

<span style="color:#800000">*你国的宽阔之地。*</span>这就是说，四方八面无处不至；因为他在预言中继续沿用这个比喻，显明亚述人将何等凶暴，并用同一个比喻扩大对他强力与暴虐的描绘；这就是把他比作一条汹涌的河流，冲决堤岸、漫过两岸，四散奔流，以其猛势倾覆并毁坏一切。他继续如前两节所已开始的那样，向犹大人发言；因为他既已预言以色列人和亚兰人的毁灭，也就同样警告犹大人，轮到他们时，必因他们的不信而受惩罚。

要更好地明白这一点，就必须细察以赛亚这段极其优美而又前后紧密相连的言语。首先，他转过来对别人说话，因为亚哈斯不配蒙他对之说话。<span style="color:#800000">*主要给你们一个兆头*</span>；这已在前一章宣告了。其次，他又加上耶路撒冷得保全的方式，就是藉着<!-- PAGE 232 -->亚兰和撒玛利亚将要突然发生的变故。这在本章开头，既藉一道命令，又藉一个异象得了印证。现在他转向犹大人自己，免得他们指望自己可以不受惩罚而逃脱，或因仇敌的毁灭而过于自高；因为他宣告说，为他们也预备了报应，他们也必因自己的邪恶与奸诈受惩罚，因为他们藐视了主，不肯以他丰丰富富、慷慷慨慨所赐的应许、兆头和恩慈为满足。

<span style="color:#800000">*以马内利啊。*</span> 有人可能会问，先知为何将他的话语转向基督，而不单单称那地为「神的圣地」呢？因为毫无疑问，他以<span style="color:#800000">*以马内利*</span>之名所指的就是基督。有人或以为，用此称呼是为要更强烈地表明那羞辱；因为犹大不仅被分别为圣归给神，而且在中保的身上有神作她安全的守护者，如此竟被一位外邦君王所毁灭，实为羞辱。但我倒认为，先知加上这名，乃是为要向善人存留些许指望的余地，并在如此大的灾难中安慰他们；因为当这地被荒废、被残暴地撕裂时，他们的勇气可能就丧尽了。因此他的意思是：那荒凉并不能阻止那位救赎主的降临，就是他先前所论到的那一位。仿佛他说：「以马内利啊，然而这地终必是你的；你必在其中有你的居所和住处。」所以这话是作为一种安慰而加上的，为要暗示这地虽被撕裂、被荒废，仍是属神的，而不属人。这突然转为直接呼语（<span style="color:#0000d4">ἀποστροφὴ</span>，阿波斯特罗菲，即「转呼法」）也是极有力的；因为先知借此郑重宣告他对救赎的信心，好使主为这些可怕的灾难定下界限。

<!-- PAGE 233 -->
**9.** <span style="color:#800000">*列国的人民哪，任凭你们喧哗〔或作「结盟」〕。*</span> 动词 <span style="color:#008080">wgr</span>（*rognu*，罗努），无论是出自 <span style="color:#008080">[wr</span>（*ruang*，鲁昂）或出自 <span style="color:#008080">h[r</span>（*ragnah*，拉尼亚），都有*压碎*之意。但因 <span style="color:#008080">h[r</span>（*ragnah*）有*结盟、联合*之意，有些人宁取此义，这确实与先知的意旨和论证更为相合。有人译作 <span style="color:#800000">*你们压碎吧*</span>，即压碎犹大国，或压碎亚述人；但这似乎不自然，或过于牵强。这话乃是描写他们企图压毁神教会的计谋与行动，这从先知紧接着说、又第二次重复的话就显明了：<span style="color:#800000">*束起腰来*</span>，即「订立计谋」。因此，*结盟*一词最为合适；除非有人以为更好是把动词 <span style="color:#008080">w[r</span>（*rognu*）取比喻之义；我也乐意赞同那种看法，即取*堆聚*之意 [^f118]；因为凡被*压碎*的，必然是被猛力挤压、榨迫在一起的。所以他的意思不仅是*聚集*，也是*紧紧挤压在一起*；仿佛他说：「你们彼此靠紧吧，如同一团密不透风的整块。」我认为，这层意思与本段的意旨极为相称；因为他随即所加的话也是同一目的：「你们武装起来，*束起腰来*。」

先知在提到*以马内利*，就是那位要帮助祂百姓的神之后，便振作起信心来；同时他也怀着更大的指望与仇敌对抗：仇敌虽在使这地人口凋残之后可能自以为已经达到目的，然而主必得胜，必保守祂的百姓脱离仇敌的残暴。因此，他把心思从那灾难的景象中收回，转向基督；藉着仰望祂，他获得如此的勇气，甚至敢于讥笑他的仇敌，如同他已经胜过了他们一样。我们必须把先知看作站在守望楼上，从那里观看百姓困苦的境况，以及那些得胜的亚述人如何骄傲地夸耀踩踏他们。他因基督的名和基督的显现而得着更新，就忘却了自己一切的苦难，如同从未受过什么苦一样；他脱离了一切的悲惨，起来抵挡那些主即刻就要毁灭的仇敌。这一点应当仔细留意：既然在教会所忍受、几乎被其重压所压倒的患难中，我们仍要与同样的试探争战，那么我们就当把眼目转向基督；藉着仰望祂，我们就能胜过撒但，也能胜过各类的仇敌。

<!-- PAGE 234 -->
<span style="color:#800000">*列国的人民哪。*</span> [^f119] 既然只有亚述人要蹂躏犹大，他为何称他们为 <span style="color:#008080">µym[</span>（*gnammim*），即*众民*呢？我回答说，亚述的军队是由各样的*民*组成的；因为他不但制伏了迦勒底人，也制伏了许多别的*民*；因此，那国乃是由列族所构成。然而先知也可能是指以色列人、叙利亚人和埃及人，以及一切与神的教会为敌的人；因为他所说的并非教会所受的一次打击，乃是选民必须持续忍受的连绵争战。但为要更明白这一点，我们必须把下一节连起来看，那节的末了有这话：<span style="color:#800000">*因为神与我们同在*</span>，就是说，*因为神与我们同在*；这就是我们得拯救的保障。任凭人彼此联合、图谋、定计、决意，他们也不能成就什么；

<p style="text-align:center" markdown="1"><span style="color:#000080">没有人能以智慧、聪明、谋略敌挡耶和华。（</span><span style="color:#000080">箴言 21:30）</span></p>

<p style="text-align:center" markdown="1">因此，我们若愿站立得稳，就必须从这根基起头。</p>

但我们必须查明，是否人人都有权凭此夸口，因为恶人也自夸<span style="color:#800000">*神与他们同在*</span>，并且假借他的名毫不迟疑地放肆骄横；然而他们的夸口是虚妄而无根据的。敬虔人的勇气乃是立在神的话语之上，出于真实的信心；这信心若住在我们心里，我们就可以胜过一切仇敌而夸胜；正如保罗也用这教义鼓励敬虔人时所教导的，

<p style="text-align:center" markdown="1"><span style="color:#000080">神若帮助我们，谁能敌挡我们呢？</span> <span style="color:#000080">(</span><span style="color:#000080">罗马书 8:31)</span></p>

所以，我们首先当确知*神与我们同在*，而这非藉着信心持定应许不能成就；我们若有信心，我们的夸口就不是徒然的。至于他向如此遥远、那话语所不能传及的国民说话，其缘由是显而易见的，就是要叫不信的人认识这话语的效力，并叫他们知道：亚述人虽远在天边，且全副戎装、军备齐全，神也必拦阻他们；仿佛他说：「你们固然藐视神，但他要把你们挡在远处、遏止你们一切的暴怒，乃是轻而易举的事。」

<span style="color:#800000">*要束起腰来。*</span>这并非多余的重复；因为我们既已一次蒙拯救，再次期待神的帮助，比接受一次单独拯救的应许要困难得多。此外，虽然仇敌最初的攻击不至于令我们大为惊惶，然而当我们看见他们在恶毒中变得刚硬时，他们的顽固就把我们逼到软弱里。这是我们天天所经历的；因为若有什么危险威胁我们，我们尚能期待主的帮助；但若我们再次陷入危险，就退缩了；我们的忘恩负义如此之大，以致我们几乎不信神会第二次帮助我们。因此，若我们屡次被带入危险，就灰心丧胆，而不思想神从不厌倦于恩待我们、不断地帮助我们。

<!-- PAGE 235 -->

所以，以赛亚的用意是要抵挡人这一软弱，使我们在武装的仇敌一再攻击我们时，仍能站立得稳。倘若他们被击败或削弱之后，又重整兵力，不停地扰害我们，我们不要沮丧；因为明日、后日，无论他们联合起来多少次，神都能使他们的图谋落空并将他们毁灭。因此，我们也在此被提醒自己的处境，要时刻预备忍受更多的争战，不要以为一次抵挡了，就已尽了当尽的本分；因为撒但在他的作为上从不疲倦，持续不断地劳力谋求我们的灭亡；他激励他的兵卒，用新的热望煽动他们。但虽然争战必须屡次进行，我们的得胜却是确定的，因此我们应当勇敢作战，坚定不移地留在战场上。

**10.** <span style="color:#800000">*同谋。*</span>他既已论到仇敌的兵力，现在就转到他们的*计谋*；如同他说：「仇敌纵然不仅在军械和力量上富足，且在*计谋*和智慧上也富足，他们仍将一无所成。」这一警戒是极其必要的；因为常有这样的事：我们轻看仇敌，虽然他们强大且装备精良，只因他们缺乏*计谋*，是被盲目的暴力而非理性所引导。所以他预先告诉他们：仇敌的诡诈，以及他们藉以图谋胜过神百姓的一切手段，终必不能成功；因此，纵然他们一无所缺，纵然他们万事、兵力、*计谋*与诡计都极其丰足，他们仍将一无所成。他接着说——

<span style="color:#800000">*同谋。*</span>为使意思更加清楚，我将它译作*定谋定策*。这与他们的骄横有关，或者说这是那场商议的结论；因为经过一番商讨之后，通常就随之有一项*决议*。他宣告，这一切都要化为烟云。因此，先知的意思，以及这段经文当作何应用，已足够明显；因为它可以被视为一面盾牌，藉此我们能驱散仇敌一切的恐吓——无论他们一面在兵力、财富、权势、影响与地位上占优，或者另一面在智慧、谋略、诡诈、机敏与发明上过人，总而言之，在骄横上胜过我们。因为若*神与我们同在*，我们便是全副武装、极其有力的；因此，敌人一切的图谋或决议都必立即消散。

<!-- PAGE 236 -->

<span style="color:#800000">*因为神与我们同在。*</span><span style="color:#008080">La wnm[ yk</span>（*ki Immanu-el*，基以马内利），字面意思是*因为以马内利*。我们已经解释过这一论据的力量。[^f120] 就我个人而言，我毫不怀疑他在此暗指他先前赐给基督的那名号；因为虽然他的意思是神扶助他的百姓，然而既然神的威严本身不足以支撑我们，他便在中保的位格里默想神自己，唯独在这位中保里神应许扶助我们。

**11.** <span style="color:#800000">*因为耶和华曾如此对我说。*</span>先知在此与另一类试探争战，就是与百姓的不信争战；为使这一点更加明显，当留意有两种显著的试探，一是外在的，一是内在的。外在的试探来自公开的仇敌，例如亚述人；当百姓看见他的掳掠与残暴，就以为自己完了，因为他几乎把他们带到了彻底毁灭的地步。另一种试探是内在的；因为那自夸蒙神拣选的圣洁子民，所倚靠的是人的帮助，而不是神的帮助。这实在是极其危险的试探；因为看起来这民似乎藉着自己的不信，拒绝接纳那天天摆在他们面前、不断在他们耳中回响的神的应许。在如此重大的困惑之中，先知除了想到这恶民——他们不停地恶意弃绝神的恩典——的毁灭已经临近，还能想什么呢？因此，主定意要使先知和他的门徒都得着装备，以抵御这一类的试探。

<span style="color:#800000">*仿佛握住我的手。*</span> [^f121] 这是一个极美的比喻，我认为诸注释家并未领会其意。他所指的是父亲或教师：当他们的话语不足以生效时，就抓住儿女或学生的手，紧紧握住，好强使他们顺从。主的仆人有时也想把一切都抛下不管，因为他们以为自己的劳苦全然徒然；但主却仿佛将*他的手*按在他们身上，紧紧握住他们，使他们能在职分上继续前行。人人都清楚这是极其必要的，凡忠心事奉主的人也确实亲身经历过这事；因为没有比这更严厉的试探：本该有信心存在的人竟然背道；简言之，信心似乎从世上被赶了出去。

<!-- PAGE 237 -->

因此，这样的<span style="color:#800000">*握住手*</span>是极其必要的，因为我们不但反复无常、易于动摇，而且即使无人诱惑，我们的本性也过于偏向邪恶。若再加上习俗的力量，我们就几乎不能自主。倘非我们被神有力的治理所握住，并将恒久不变的锚抛在坚固的地基上，我们无疑每一刻都会被驱来赶去。我们各人都当认真默想这个思想；因为我们虽有确信，但一到试炼来临，我们就失败了，只看人而不看神。所以我们当更加留心这教义，并祈求神握住我们，不仅藉着他的话语，也藉着将*他的手*按在我们身上。

此外，还当留意，我们极容易倾向于对邪恶的效法。当我们看见恶劣的榜样时，就被大力吸引过去，把榜样当作律法；因为当别人在我们前面行，我们便以为自己有权照样行，尤其当带头者不只是一个人或少数人，而是那习俗已成为普遍风气的时候。凡本身显然是错的，都被公众舆论那看似有理的外衣所掩盖；不仅如此，众人还仿佛被旋风的猛力卷去，采纳既成的习俗，好像民众的意愿就有律法的效力，能为他们的败坏背书。这并非某一个时代独有的过失，直到今日，这弊病依然如故，甚至比从前更甚；因为这乃是因本性败坏而深植于众人心中的祸患，就是把流行的谬误当作律法。历代的迷信由此而生，今日教皇制中所存的迷信亦由此而来；若追查其源头，便会发现无非是有些人把别人也拖入同样的谬误之中；于是几乎所有的人都愚昧地落入撒但的网罗，而众人的普遍认同至今仍是那些迷信的主要根基。人人都用这兵器为自己辩护。他们说：「我们不是孤单的，我们是随从极大的群众。」

<!-- PAGE 238 -->
**12.** <span style="color:#800000">*不要说有奸党。*</span>首先，我们必须思量那百姓当时的处境；他们看见自己兵力不足，无力与如此强大的仇敌交战。他们渴慕外邦的援助，急切地想要得着，因为他们以为若不得着别人的帮助，就必彻底灭亡。照这意思，我理解<span style="color:#800000">*奸党*</span>一词是指：他们认为必须有同盟的援助。希伯来人使用<span style="color:#800000">*奸党*</span>一词有不同的含义，有时指*盟约*，故我按正面的意思来取。但有些人按负面的意思来取：「看哪，你的仇敌以色列王和亚兰王已*同谋*了。」不过我更赞同那些将它应用于许多不信者所渴望与亚述人缔结的联盟与友谊的人。因此，主警戒以赛亚不要理会恶人的谋算，纵然全体百姓都争先恐后地留意这些谋算。

<span style="color:#800000">*也不要怕他们所怕的，也不要畏惧。*</span>这里也可有两种解释；因为有些人把它分开来读，仿佛先知在这后半句中是笼统地责备百姓败坏的习俗。但这两句应当宁可连在一起：「若你们的同胞今日谋划那些不合法的联盟，你们不要因此困扰，也不要附从他们。」如今，虽然先知本人也属于那些需要被警戒、免得愚昧地劝阻他人凭信心跟从的人之列，然而复数的说法——*你们不要说*——表明众敬虔人都在他身上受了教导。

<!-- PAGE 239 -->
<span style="color:#800000">*他们所怕的。*</span>由此我们看出，那搅扰人心、摇摆不定的*谋算*源于何处；乃是因为他们的心被*惊恐*所淹没，以致毫无节制地被猛烈地冲走。他描述了这一切的缘由，就是为何犹大人如此急切地渴望以亚述人为同盟。乃是因为他们惊惧过度，不指望能藉别的方法得保全，又因他们盲目的*惧怕*不容他们仰望主的帮助。这就是他们如此急切渴望结盟的缘故。同样的惧怕之因摆在敬虔人面前，也摆在不敬虔的人面前；但众人惧怕的样式并不相同，因为敬虔人安定自己的心，知道神顾念他们的保全，又以神的应许为兵器，每逢提到*以马内利*的名，就使自己的心欢畅。而不敬虔的人被惊恐所胜，心中所想的无非是亚述人的援助，不思念在神那里有帮助，也不投奔于他。主固然并不禁止敬虔人*惧怕*，因为他们无法全然免去；他所吩咐的乃是要胜过那吞灭不敬虔之人的过度惊恐。因此，我们不可效法他们，四面张望，冒然奔去寻求不合法的援助；尤其要谨防*惧怕*夺去我们的判断力。治这病只有一味药，就是以神的话语约束自己，真正的心灵安宁正由此而出。将那百姓的处境与我们自己的相比，让我们学会投奔*耶和华的名*，那名对我们必成为坚固的台。（箴言 18:10）

耶和华并非单独对先知说话，这也从所用的复数形式可以看出，<span style="color:#008080">al waryt</span>（*lo thireu*，意为「你们不要惧怕」）。彼得也从此处引出了一个普遍的教义（彼得前书 3:14），警戒我们不要以不敬虔之人所存的**惧怕**去惧怕，而要将一切的信靠都安置在神身上，并将我们的眼目不断定睛于他，好使我们坚定不移，即便天地相混也是如此。彼得这一警戒若在任何时候是必要的，那么在今日尤为必要，因为我们看见万事上下颠倒，混乱得可怕。为使我们不至惊慌，主使我们的目光从人身上转开，好叫我们借着专注于他的话语，稳固地守住自己的位置。诚然，彼得是以被动的意义来理解这**惧怕**，而以赛亚是以主动的意义来理解；因为彼得劝勉信徒要恒忍，不因不敬虔之人的威胁与恐吓而动摇；但以赛亚所谴责的是那使犹大人去寻求外邦联盟的**战兢**。然而，既然彼得的用意并非解释这段经文，甚至也不是逐字引用，而仅仅是要引用这一宣告的大意，那么我们对这样的差异就不必惊讶。

<!-- PAGE 240 -->
**13.** <span style="color:#800000">*但要尊万军之耶和华为圣*</span>。我们已经说过，危难之所以引人陷入过度的惊惶，乃是因为可怜的人不肯将眼目与心思举向天上。因此，先知现在提出一个合宜的良方来平息恐惧，好使那些惧怕临头之祸的人学会将当得的尊荣归给神。<span style="color:#800000">*尊万军之神为圣*</span>，意思就是把他的权能高高地举起，从而记念他掌管着全世界的治理，一切善恶行为的开端与结局都在他的支配之下。由此可见，当我们在困境之中不立刻投奔于他时，在某种意义上，神的圣洁就被夺去了。所以这种说法极具力量；因为它向我们表明，再没有比屈从于**惧怕**更大的冒犯可以加于神的了，仿佛他并未被高举于一切受造之物之上，以至不能掌管万事。反之，当我们倚靠他的帮助，并借着信心那得胜的坚定藐视危难时，我们才实实在在地将合法的治理权归给他；因为我们若不深信有无数拯救我们的方法在他手中——尽管这些方法为我们所不知——我们就把他当作一个死的偶像了。

<span style="color:#800000">*当以他为可畏，以他为可怕*</span>。他恰当地补充说，*神自己*应当作这百姓的**可畏**与**可怕**，为要告知他们：当他们如此在困苦惊惶中因危难而战兢时，等着他们的乃是对他们罪行以及藐视神的公义合法的报应。他虽不仅说**畏惧**，也说**惊怕**，然而他的意思并不是要犹大人一听神的名就充满恐怖，以致想要逃离他，而只是要求他们对神存敬畏，并用这两个词来表达那敬畏的持续不断。因此他的意思是：若对神真诚的敬畏深深铭刻在他们心上，且永不离开他们，他们就必得着自由，脱离心中的忧惧；实在说来，凡甘心将自己献给神，并立志单单敬畏他、以此自我约束的人，都必发现没有哪个港湾比他的保护更为安稳。但既然不敬虔的人不断以无耻的过犯激动他的怒气，他就以持续的不安搅扰他们的心，如此对他们的漠然轻忽施行最恰如其分的报复。

**14.** <span style="color:#800000">*他必作为圣所。*</span> 他应许神的真敬拜者必享心灵的安宁，因为主既如在自己的翅膀底下遮蔽他们，就必速速驱散他们一切的惧怕。这里暗指他刚才所用的*成圣*一词；因为<span style="color:#008080">çdqm</span>（*mikdash*，米克达什）一词，有时指*圣所*，有时指*避难所*，乃是出于同一字根。[^f122] 所以其意思是：神所要求的一切，无不同时以相应的赏赐相报，因为凡*尊他为圣*的人，必定发现他就是自己的*避难所*。如今，虽然在这成圣之事上，我们与神之间有相互的关系，其中却有分别：我们*尊他为圣*，是将一切颂赞与荣耀都归给他，并全然倚靠他；而他*使我们成圣*，是保守看顾我们脱离一切的祸患。因信而倚靠他应许的人既少，先知便愿敬虔人得以坚固，抵御这一类的试探；因为有危险，就是他们恐被这等恶劣的榜样如被狂风一般卷去。

<!-- PAGE 241 -->
所以先知的意思是：「主必作你们至善至信的守护者。虽有别人向他绊跌，你们却不要惊惶；要在你们的呼召中坚定不移。」这里含有一层对比，虽未明言；因为*圣所*可说是坐落高处的一座城堡，是保障，用以护卫看守敬虔人，却也毁灭倾覆不敬虔的人，因为他们轻率地向它撞去。我们以后要更清楚看见这话如何得了应验：一部分在希西家在位之时，一部分在被掳往巴比伦之时；而同时基督也在此被预表，他对以色列人不是避难所，反倒成了<span style="color:#800000">*绊脚的石头*</span>。以赛亚预先警告他们有这*绊跌*，好叫敬虔人对此有所知觉。

<span style="color:#800000">*向以色列两家。*</span> 犹太人无知而不当地将这节经文撕裂，而非加以区分。他们说：「神一面要作*圣所*，一面要作<span style="color:#800000">*绊脚的石头*</span>」；仿佛他是以这两家区别敬虔人与不信者。相反地，他是吩咐信徒：纵使两国几乎全体众民都劝阻他们不要顺服神，他们也不可丧胆，倒要不顾其余一切，冲破一切的阻拦。先知本可单单说，*他必向以色列作绊跌的缘由*；但他有意表达更多，因为他把全民都包括在内，并宣告神必作他们的败亡。这民分为两国，以法莲与犹大；因此他把两者都提及了。诚然其中有些例外，但他在此是就全体而言。

这是一段值得注意的经文，无论怎样常常提念都不为过，尤其在今日，当我们眼见整个基督教世界的宗教景况几近倾覆之时。许多人夸口自己是基督徒，实则大大远离神，基督对他们乃是*绊脚的石头*。教皇党人狂妄骄傲地夸耀祂的名，却以种种迷信玷污了对祂的全部敬拜，使之蒙受羞辱与毁谤。即便在那些已蒙恢复较纯正敬拜的人当中，以真诚之心接受神福音的也寥寥无几。无论我们目光转向何处，四面八方都有极其严酷的试探迎面而来；因此，我们应当记住这极有益处的教训：若有极大群众——几乎所有夸口自己属乎教会的人——*绊跌*在神身上，这并非新事。然而，无论我们人数何等稀少，都当恒常紧紧依附于祂。

<!-- PAGE 242 -->

<span style="color:#800000">*向耶路撒冷的居民必作为圈套。*</span> 这是所引入的第二重情节，为要加深这幅图画的分量；因为在提及那两个国度之后，他又指名京都本身。虽然全地都已残破，神却似乎仍在那里存留祂的居所。因此他的意思是：神不仅向那分散在田野乡村中的平民百姓成了*网罗*，也向那些住在*耶路撒冷*的贵胄和祭司成了网罗——他们住在那圣所之中，神本定意要在那里首先保存对祂名的记念。大卫也曾为此作见证，说神所指派的*匠人所弃的石头，已成了房角的头块石头*。（<span class="ages-code">&lt;19B822&gt;</span>诗篇 118:22）基督引用这段经文来责备犹太人，并指明它应验在祂自己身上。（马太福音 21:42；马可福音 12:10）这事诚然在以赛亚的时代已经发生，但在基督的时代更是如此；因为不敬虔与悖逆逐渐增长，直到登峰造极。因此，无论至尊的还是至卑的，素来顽梗悖逆神的人，在那时更是肆无忌惮地向祂爆发，所以他们的毁灭也达到了极点；因为他们既弃绝了神的儿子，就被神全然弃绝了。由此我们也推知基督永恒的神性，因为保罗指明先知在此所论说的乃是神。（罗马书 9:33）如今，他所说的不是一位虚假的神，乃是那创造天地、并向摩西显现启示自己的神。（出埃及记 3:6）所以，这正是那位历世历代治理教会的同一位神。

**15.** <span style="color:#800000">*许多人必在其上绊脚跌倒。*</span> 他继续如先前所起的头那样威吓不敬虔的人，并宣告那些不肯倚靠神的人必不能逃脱刑罚。这威吓是这样说的：“他们*绊跌*之后，就要*跌倒*，随后要*跌碎*。”这与前面的比喻相符，在那里他把神比作一块石头。基督曾暗指这个比喻，并把两方面都包括在内。

<p style="text-align:center" markdown="1"><span style="color:#000080">「谁掉在这石头上，必要跌碎；这石头掉在谁的身上，</span> <span style="color:#000080">就要把谁砸得稀烂。」</span> <span style="color:#000080">（</span><span style="color:#000080">马太福音 21:44）</span></p>

<!-- PAGE 243 -->
<span style="color:#800000">*作为圈套，作为陷阱。*</span> 这与后一个比喻相合，就是他把神比作*圈套*和*陷阱*。所以，不敬虔的人不要幻想自己比神更强或更聪明；因为他们必发觉神在能力和智慧上都远超他们，而这乃是叫他们灭亡。因此，他们必不能免于毁灭；因为他们或是被彻底*砸碎*，或是被*缠住*，以致永不能脱身。

这警告也是针对敬虔人说的，使他们不迟疑地从与众人的相交中退出来，也不至于刚硬地轻看背道的罪恶。如今，这事严格说来并不属于神，倒不如我们所说的，是偶然附加的；因为神的本分乃是接纳人进入他的恩宠，并赐给他们救恩的确实保障。这在基督身上更清楚地显明出来，并且至今仍在显明；因此，彼得提醒我们说，虽然许多不信的人*跌倒*，但这并不构成理由使他们的*跌倒*妨碍我们信心的进展；因为基督仍然是*所拣选、所宝贵的石头*。（彼得前书 2:4）

**16.** <span style="color:#800000">*你要卷起律法书。*</span>耶和华如今将祂的话转向先知，激励他：他既必须与背道者和悖逆者争战，就当刚强忍耐地履行自己的职分。这实在极为必要，因为以赛亚在这百姓身上遇见了极大的顽梗；以致他若只看眼前的光景，就是百姓的不信，和自己劳而无功、毫无果效的辛劳，他必然全然灰心丧志。因此，耶和华定意要坚固并*封住*他的呼召，不单为他自己的缘故，也为一切要顺服他教训之人的缘故；纵然信这先知之言的人极其稀少，耶和华仍见证说，祂的教训已向他们封缄印证，所以先知既不可停止教导的职分，他们也不可停止献上信心的顺服。

<!-- PAGE 244 -->
<span style="color:#800000">*在我门徒中间封住训诲。*</span>他将话语的教训比作一封*封缄*的书信：这书信固然可被许多人摸着、拿在手中，然而读它、明白它的却只有少数人，就是那些书信所寄、所写给的人。照样，神的话虽向众人无分别地伸出，领受的却只有少数人，就是蒙拣选的人。所以，话语对那些从中得不着益处的人乃是*封住*的，且是这样地被*封住*，以致耶和华藉着圣灵向祂自己的子民解封开启。有人将动词 <span style="color:#008080">rwx</span>（*tzor*）溯源于 <span style="color:#008080">rxn</span>（*natzar*），译作*保守*。虽然这对整体意思影响不大，但我所采用的译法[^f123]之优越，可从另一动词*封住*得着证明；因为古时的惯例，乃是先用线绳把书信捆扎起来，然后*封*上印。

我们从中汲取这极有益处的教义，就是：话语的教师与仆人应当恒久不懈地履行自己的职分，纵然看来众人都背弃了，除了顽梗悖逆之外别无表现；因为耶和华必为自己留下一些门徒，他们读祂的书信必得益处，虽然这书信对别人是封闭的。先知后来也用了同样的比喻，说*这话语好像封住的书卷*（以赛亚书 29:11）；但在那里他只提到恶人，而在此处他提到门徒，对他们而言话语的教训并非无益。

或有人反驳说：难道先知的本分就是撇下百姓，退隐起来，把自己与那些略有果效的门徒关在一处么？我回答说：先知的意思并非如此；因为主的旨意乃是要以赛亚公开露面，高声呼喊，向众人显明祂的旨意。但因他是向聋子说话，眼见自己劳苦全无果效，恐怕会灰心丧胆，所以主定意要激励他、坚固他，使他在事情已陷入绝境之时仍然前行，并且以他的门徒为满足——纵然人数稀少——日复一日愈发刚强壮胆。

**17.** <span style="color:#800000">*我要等候那掩面不顾雅各家的耶和华。*</span> [^f124] 我选择把 <span style="color:#008080">w</span>（*vau*）这个虚词译作*因此*；因为先知在领受了我们方才所见主所赐的安慰之后，重新振作起来。「既然主乐意有门徒，向他们印证祂的教训，<span style="color:#800000">*我就要等候祂*</span>，纵然<span style="color:#800000">*祂向雅各掩面*</span>，就是弃绝并丢弃了祂的百姓。」这是一段非凡的经文，我们若不住地默想，必大得激励；因为纵然看似举世都已背叛，我们仍当勇敢坚持；纵然神向祂的百姓*掩面*，那些自称属祂名下的人已被丢弃，我们仍当以毫不动摇的盼望*等候祂*。这是我们所剩的唯一良药。

<!-- PAGE 245 -->
*等候*一词极有力量；仿佛他说：「我仍不偏离神，我要在信心中持守到底。」他又加上<span style="color:#800000">*我要仰望祂*</span>，使语气更为加强；因为凡遇绊脚之事，常使我们的信心摇动衰微，而当我们看见自己失去了同伴，又有公开的仇敌大胆自称为教会时，信心受的震撼最为惨重。这些绊脚石通常使我们偏离神，叫我们困惑不解，甚至怀疑圣道的真实性。所以，无论教会是被外来的灾祸所压制，还是因众人的背信而陷入混乱，这样的安慰都是极其必需的。

**18.** <span style="color:#800000">*看哪，我。*</span> 先知在此不仅见证他必耐心等候，也表明他的勇气：他与那些他为神所赢得、至今仍存留的门徒一同公开站立。这就如同他说：「纵然别人退去，我却预备好顺从你，并且我带着那些你乐意藉我的服事而以奇妙方式保守下来的人一同前来。」因此，他用这些话宣告他毫不动摇的勇气，并应许即使众人都背道，他仍要在信心和顺服主的事上持守到底。

<span style="color:#800000">*与……儿女。*</span> 按希伯来文以及拉丁文的通常用法，*儿女*一词指各等仆人。[^f125] 他所说的，就是他先前所提到的门徒。由此我们看见，凡愿被算在主的真门徒之列的人，当具备什么。就是要与以赛亚一同宣告：他们是顺服的、乐意聆听的，主一开口，他们就立刻顺从。如今，教师应当带着门徒同行，而不仅仅是打发他们先去；我说，他们应当走在门徒前头，以自己的榜样指出道路，正如前面所解释的（以赛亚书 2:3）；否则他们的教导就毫无权柄。希伯来书的作者将这段经文应用于基督（希伯来书 2:13），并从中引出一项教训，这教训极当激励我们：既然我们所跟随的不仅是以赛亚，更是基督自己，他是我们的元帅和导师，我们就当以更大的踊跃向前奔跑。

<!-- PAGE 246 -->
<span style="color:#800000">*就是*</span> <span style="color:#800000">耶和华</span> <span style="color:#800000">*所给我的。*</span> 先知藉此指明我们的信心当归功于谁。乃是归于神，归于他白白的拣选；因为以赛亚公开施教，警戒各人，毫无例外地邀请众人归向神，然而他的教义只对那些神所赐给他的人有益。他说*给*，是指那些神藉着他的灵内在而隐秘的运行所吸引的人，那时外在声音的响声临到众人的耳中，却未产生任何良效。照样，基督也宣告说，选民*是父赐给他的*（约翰福音 17:6）。这样我们看见，信的预备并不在乎人的意志；乃是众人中有些人相信，正如路加所告诉我们的，因为*他们是预定得永生的*（使徒行传 13:48）。如今，*预先所定下的人又召他们来*（罗马书 8:30），并在他们里面有效地印上他们得儿子名分的凭据，使他们成为顺从、驯服的人。所以，以赛亚在此所说的*赐给*，正是这个意思。这话严格说来适用于基督，父将门徒呈献并赐给他，正如约翰福音所说：

<p style="text-align:center" markdown="1"><span style="color:#000080">若不是差我来的父吸引人，就没有能到我这里来的。</span> <span style="color:#000080">(</span><span style="color:#000080">约翰福音 6:44。)</span></p>

由此可见，他也被立为我们的守护者，将我们保守在他的护庇之下，直到末了。（约翰福音 10:28。）因此他说：

<p style="text-align:center" markdown="1"><span style="color:#000080">你所赐给我的人，其中除了那灭亡之子，没有一个灭亡的。</span> <span style="color:#000080">(</span><span style="color:#000080">约翰福音 17:12。)</span></p>

<span style="color:#800000">*为预兆和奇迹。*</span> 有人认为这段话是指神迹，但这并不适切，因为其含义完全不同，即：一切敬虔人不但被人恨恶，甚至被人厌憎，如同他们是怪物一般；而且这厌憎不只出于外邦人或公开的敌人，甚至出于**以色列**。今日我们也亲身经历这事；因为教皇党人看我们，比看回教徒或犹太人，甚至比看狗或怪物，更加憎恶。虽然这极其可耻，我们却不必大惊小怪；因为这预言必须在今日也得着应验。以赛亚从他本国同胞身上经历了这事，凡跟从他教义的人也都经历了这事。

<!-- PAGE 247 -->
我们不只在教皇党人身上看见这事，也在那些愿被人视为与教会关系极密切的人身上看见：他们中大部分人或是深恶我们，或是讥笑我们，简言之，视我们为怪物，因为我们为教会的救恩、神的荣耀和永生如此挂心、如此焦急不安；又因为我们毫不迟疑地经受如此多的危险、如此的恨恶、责难、辱骂、放逐、贫穷、饥饿、赤身露体，简言之，甚至死亡。这些事在他们看来是怪异的；因为他们既如此谨慎地保全自己的皮肉，怎能领略那至高的福分呢？但为使我们不因他们的辱骂而心生动摇，我们必须以先知这番劝勉武装自己。

<span style="color:#800000">*出于*</span><span style="color:#800000">万军之耶和华</span><span style="color:#800000">*。*</span> 为要显明恶人群众的同谋是何等琐屑无用，他将**万军之神**与全世界的骄傲相对照，发出一种崇高的挑战；仿佛他说，即使自己被众人厌憎也毫不在意，因为他知道神在他这一边。

<span style="color:#800000">*那住在锡安山的。*</span>加添这几个字大有分量；因为那百姓虽然充满各样的罪恶与暴行，却仍夸口自己是归属神的，并且滥用神的应许，定罪那些责备他们的神的真仆人。反过来，众先知为要摇撼他们虚假的自信与骄傲，便宣告自己乃是那独一真神的仆人，就是这百姓虚谎地夸口在<span style="color:#800000">*锡安山*</span>所敬拜的那一位。神拣选那地方作他的居所，并非因为他被拴在那地点上，就要悦纳虚假伪冒的敬拜，乃是他愿意人照着他话语的准则来寻求他、敬拜他。

因此，当以赛亚宣称神是<span style="color:#800000">*那住在锡安山*</span>的神，作他自己的神时，他是在尖锐地责备假冒为善之人，因为他们凭着虚假的夸口沉溺于愚昧的骄傲，动辄说：*这些是耶和华的殿*（耶利米书 7:4）；其实他们所夸口的，反倒是一个违背神话语的偶像。他们虽然攫取应许，却虚谎地扭曲这些应许来敌对神的真仆人，正如今日教皇派惯常扭曲经文来敌对我们一样。所以，众先知用这称号来称呼神，为要撕下假冒为善之人的面具——这些人惯于单单援引*圣殿*之名，来对抗神明明白白的话语。为此缘故，以赛亚现在说：「你们若愿意，尽可以把我们当作怪物，然而神却承认我们是属他的；你们若不同时憎恶亚伯拉罕和大卫的神，就不能憎恶我们，因为我们是他的仆人。」

<!-- PAGE 248 -->
**19.** <span style="color:#800000">*有人对你们说。*</span>以赛亚继续先前的主题，就是：一切敬虔人不但要以神的权柄为盾牌，更要以此为铜墙来坚固自己，去抵挡一切不敬虔。因此他恳切劝勉他们，若有人引诱他们归向迷信与不法的敬拜方式，就要刚强抵挡。他在此用复数，为要表明这是一种弥漫于各阶层、随处泛滥的恶习；仿佛他说：「我看见将要发生的事；你们必陷入极大的危险，因为你们的同胞要竭力拉你们离弃真神；他们既是不敬虔的，就愿你们与他们一样。」同时他也指出，他们竟厚颜无耻地把交鬼的和行巫术的推到前面来——这等人的名字本该为他们所憎恶——由此可见他们已何等邪恶地背离了神的律法与盟约。

<span style="color:#800000">*百姓不当求问自己的神吗？*</span>有些人把这句话与上文连起来读，将它归给不敬虔的人，仿佛这是他们所滥用的借口，用来欺骗单纯的人；因为没有一个民族是没有神谕与启示的，各族都*求问自己的神*，或者以术士和占卜的人代替神明。但我认为较为正确的看法是：以赛亚在劝告他的门徒，若他们万一被诱惑去行邪恶的敬拜方式，就当以此作答。然而其意思仍未完全明朗；因为这段经文通常被解释为一种从小到大的比较：「什么！外邦人既求问他们的神，而那些神还是假的，难道我们不当更加尊重我们所认识的真神吗？他既已藉着如此众多的凭据向我们显明自己。若外邦人看重他们的偶像过于我们看重神，那是何等的羞耻！」

<!-- PAGE 249 -->
但我把这话解释为指犹大人自己，他们被称为（<span style="color:#0000d4">κατ' ἐξοχὴν</span>，卓越地）*百姓*，因为神已收纳他们为儿女。先知在此用了复数形式 <span style="color:#008080">wyhla</span>，[^f127]（*elohaiv*）也无关紧要；因为 <span style="color:#008080">µyhla</span>（*elohim*）是当作单数用的。这是一面盾牌，凡不知不觉侵袭我们的一切迷信，都当以它挡回去。当有些人思量、犹疑是否可以求问占卜的人时，让我们把这答案预备好：唯独当求问神。先知在此暗指申命记那段话，主在其中禁止他们去找术士和占卜的人；又恐怕他们以「各族都有自己的解释者或算命者」为借口来推托，便加上说：他们必不至于没有*先知*，也不至于缺乏必需的教导（申命记 18:10-15）。因此主的心意是要他们完全依靠他的话，只从这话中学习一切他们所当知道的有益之事，并向他献上顺服。

<span style="color:#800000">*为活人求问死人吗？*</span>介词 <span style="color:#008080">d[b</span>（*begnad*）有各种译法：常被译作*为*；如此则意思是：「岂当*为活人*的事求问<span style="color:#800000">*死人*</span>呢？」但因这意思略显牵强，或许这样解释更好：「主愿意作我们的教师，并为此设立了先知，使我们从他们身上学知他的旨意，因为先知是主的口。所以去求问<span style="color:#800000">*死人*</span>是不合法的，他们并未被指派作此用途；因为神无意用*死人*来教导我们。」

但我更仔细地考究全事之后，宁愿认为 <span style="color:#008080">d[b</span>（*begnad*）的意思是**从**，即 <span style="color:#800000">*从活人到死人*</span>；仿佛他说：「一位神对我们就够了，无论是<span style="color:#800000">*活人还是死人*</span>。你若搜遍天上、地上、阴间，必发现独一的神对我们已然足够。」我认为这是最好的解释，也顺理成章。因此，先知以此劝勉武装敬虔人，使他们抵挡恶人的诡计与图谋（他们本可能因此被诱惑背道），教导他们当以神独自作他们的教师为满足，不可如此侮辱他，以致轻忽他的教训而另寻别的教师，倒要撇下其余一切，单单倚靠他的真理；这一点他随即又重申并加以证实。

<!-- PAGE 250 -->
**20.** <span style="color:#800000">*人当以训诲和法度为标准。*</span>诚然，解释这段经文的方式各有不同。有人认为这是一种起誓的形式，仿佛先知是<span style="color:#800000">*指着律法*</span>起誓，说他们是背道之人，并且要引诱别人同样背道。但我的看法不同，我认为他是把我们的注意力引向<span style="color:#800000">*律法与法度*</span>；因为介系词 <span style="color:#008080">l</span>（*lamed*），即「向」、「归于」，清楚表明这就是其含义。如今，<span style="color:#800000">*法度*</span>与*律法*连在一起，并非因为它是另一样东西，而是为了作解释，即「*归于律法*」，律法中含有神向我们所存心意的<span style="color:#800000">*法度*</span>或*宣告*。简言之，我们当把<span style="color:#800000">*法度*</span>一词看作是描述一种性质，好叫我们晓得从*律法*所得的益处；就是神在*律法*中向我们启示他自己，宣告他愿意与我们保持怎样的关系，并定下他向我们所要求的，总之，一切必需知道的事都在其中。

因此，这是对*律法*极高的称许：它含有救恩的道理，以及美善蒙福生活的准则。为此缘故，他也理当禁止我们丝毫偏离律法；仿佛他说：「要撇弃他们所疯狂痴迷的一切迷信；因为他们不以单单有神为满足，反倒招来无数自己捏造的东西。」基督也照样说：

<p style="text-align:center" markdown="1"><span style="color:#000080">他们有摩西和先知的话可以听从，</span> <span style="color:#000080">（</span><span style="color:#000080">路加福音 16:29）</span></p>

因为虽然那里是以亚伯拉罕为说话者被提出来的，然而这仍是由神的口所发出的永久神谕。所以我们被吩咐要<span style="color:#800000">*听律法和先知*</span>，免得我们受那急切的好奇心所左右，或想从*死人*那里学到什么。假如<span style="color:#800000">*律法和先知*</span>不够充足，主就不会拒绝准许我们得着别的帮助了。

由此我们得知：凡在圣道之上所添加的一切，都必须被定罪、被弃绝。主的心意是要我们完全倚靠他的话，并要我们的知识被限制在他话语的界限之内；因此，我们若把耳朵借给别人，就是擅取了他所禁止的自由，并且是对他极大的侮辱。凡人凭自己的权柄所引进的一切，无非是圣道的败坏；因此，我们若愿意顺服神，就必须弃绝一切其他的教师。他同样警告我们：我们若持守主的*律法*，就必得保护，不至陷入种种迷信与邪恶的敬拜方式；因为，正如保罗称

<p style="text-align:center" markdown="1"><span style="color:#000080">拿着圣灵的宝剑，就是神的道，</span> <span style="color:#000080">（</span><span style="color:#000080">以弗所书 6:17）</span></p>

照样，撒但和它一切的诡计也都被神的道击溃逃散。因此，每逢我们受仇敌攻击时，都当逃往神的道，好叫我们既以此为武装，就能奋勇争战，终必使他们溃逃。

<!-- PAGE 251 -->
<span style="color:#800000">*人若不说……*</span> 我不打算把这段经文的各种解释一一列举，因为那未免过于冗长；我认为那真确的解释根据充分，足以驳倒其余诸说。通常人的解释是：恶人以自己的臆造戏弄人，把他们的欺诈拿出来兜售，<span style="color:#800000">*因他们没有光*</span>，就是说，因为他们连寻常的悟性也没有。至于我自己，我认为这是激励信徒持守到底的理由：恶人若离弃真道，他们所显明的不过是自己的瞎眼与黑暗罢了。我们理当藐视他们的愚妄，免得它成为我们的拦阻；正如基督也教导我们，要放胆撇开这等人，丝毫不受他们的瞎眼或顽梗所影响。他说：「*他们是瞎眼领路的*；」你岂愿甘心与他们一同灭亡吗？（马太福音 15:14）

因此，先知吩咐我们要将如此崇高的权威归给神的话，以致若全世界都与这话对立，我们也敢于放胆藐视全世界；因为即使天使这样行，我们也可凭这话的权威定他们的罪。

<p style="text-align:center" markdown="1"><span style="color:#000080">保罗说，但无论是天上来的使者，若传福音给你们，与我们所传给你们的不同，</span> <span style="color:#000080">他就应当被咒诅。（</span><span style="color:#000080">加拉太书 1:8, 9）</span></p>

既然如此，对于那些起来抵挡神的人，我们岂不更当放胆定他们的罪吗？这说法极有力量：<span style="color:#800000">*他们若不照这话说*</span>。凡不立即、毫无争辩地接受这一原则——即我们不当在神的*律法*之外自作聪明——的人，先知都控告他为瞎眼的。

<!-- PAGE 252 -->
**21.** <span style="color:#800000">*他们必经过这地。*</span>为了不让信徒被那些流行的谬误所缠住，他补充说：不敬虔的人一旦背离了神，又竭力引诱别人同陷于这样的背叛，等待他们的刑罚是何等可怕。这段经文略显晦涩；然而这晦涩乃是出于人们查考字词时不够留意。动词 <span style="color:#008080">rb[</span>（*gnabar*）是强调性的；因为他以<span style="color:#800000">*经过*</span>一词所指的，乃是那种*漂泊无定*的状态——人在其中上下流荡，找不到安歇之处，也无长久的居所。这个不定式的动词须补上一个主词：<span style="color:#800000">*犹太人必经过*</span>。他用代名词 <span style="color:#008080">hb</span>（*bahh*）*在其中*，[^f128] 所指的乃是犹大地，就是主看重过一切别国的那地；因此，虽然先知没有明说，意思也不难明白。这好像他说：「我确曾应许那地要作我百姓永远的产业（创世记 13:15；17:8）；但他们却要过漂流不安的生活，正如那些被赶离家园、受饥荒瘟疫和各样灾祸折磨的人一样，他们四处寻求较好的境况与安身之所，却处处寻不着。」所以这些话与神那非凡的恩慈形成对照——摩西屡次提到这恩慈，就是他们必在犹大地有固定的居所；而先知在此却警告说，他们要作流离飘荡的人，且不是在本地，而是在异邦；以致他们无论走到哪里，都要被无数的祸患攻击追逼。

<span style="color:#800000">*受饥饿的时候。*</span>先知似乎在指明犹太人的归正，好像他说：「当他们被苦难压伤之后，终必悔改」；无疑这正是主惯常用来医治顽梗之病的良药。不过，倘若有人认为*饥饿*一词所描写的，是恶人不肯悔改而生的愤恨与咆哮，那也可以说，这词不但包括饥与渴，而且照那以部分代全体的修辞（<span style="color:#0000d4">συνεκδοχικῶς</span>），也包括其他各样的灾祸。

<span style="color:#800000">*心中焦躁。*</span> [^f129] 他们要开始厌恶自己，也厌弃自己从前所倚赖的一切支撑；这就是悔改的起头；因为在顺境中我们自我夸耀，但在极大的患难中我们却厌弃身边的一切。然而，若有人认为把这话归于被弃者更为可取，那么这词所指的便是那种苦毒——它丝毫不能引他们归于谦卑，反倒更加激起他们的怒气。

<!-- PAGE 253 -->
<span style="color:#800000">*并且咒骂自己的君王和神。*</span>有些人认为，他所说的**君王**是指**神**。西番雅正是在这个意义上使用了<span style="color:#008080">µklm</span>（*malcham*）这个词，即**他们的王**。（西番雅书 1:5）但在此处，我把**君王**与**神**区分开来；因为恶人首先被对偶像的虚假倚靠所蒙蔽，其后又把自己的保障寄托在地上的事物上。犹大人有**王**的时候，就以王的荣耀和权势自夸；以赛亚宣讲之时，恶人激动**那王**与他为敌，甚至煽动全国的人跟随**那王**如同跟随他们的旗手。因此，既然他们虚妄的自夸一部分在偶像身上、一部分在**王**身上，先知就警告说，他们必遭受如此众多的灾祸，以致被迫厌恶<span style="color:#800000">*他们的神和君王*</span>二者。而这正是悔改的起点：憎恶并远远驱除一切拦阻我们、或引我们离开神的事物。

<span style="color:#800000">*仰面向上*</span>。他在此描述可怜之人心中的战抖与不安，这搅扰要折磨他们，直到他们学会坚定不移地向上仰望。诚然，正如我刚才所提到的，当我们因苦难与管教而受教，抛弃自己的麻木冷淡、竭力寻求医治之方时，这已是有些进步了。但我们还必须更进一步。我们的眼目必须单单定睛于神，不可四顾张望，也不可因心志摇动而被**摇动飘来飘去**。（以弗所书 4:14）无论如何，以赛亚在此警告犹大人必彻底灭亡；因为他们刚硬到了这样的地步，以致神手中轻微适度的管教已无法制伏他们的叛逆。不过，这话也可以从正面的意义来领会，即犹大人终必举目望天；但若如此，我们就必须把下文分开来读——

**22.** <span style="color:#800000">*俯察下地*</span>。那么，意思便是：犹大人必归向神，因为他们在**地上**的一切帮助都被剥夺了，无论转眼望向何方，所见的除了可怕的灾祸别无他物。

<span style="color:#800000">*不料，只见黑暗艰难。*</span>这些话一部分是比喻性的，一部分是字面的；因为他所说的*幽暗*与*黑暗*，按圣经的惯例，无非是指患难。但他又加上：<span style="color:#800000">*被赶入幽暗中去*</span>。这使灾祸加重到惊人的地步；因为人若身在<span style="color:#800000">*黑暗*</span>之中，又被<span style="color:#800000">*驱赶*</span>或*推逼向前*，他比先前更容易跌倒。他借此表明，在沉重的灾祸之上还要加添更沉重的灾祸，好叫他们更彻底地败亡；因为他的意思无非是说，神的审判将何等可畏，刑罚将何等严厉，以致他们无论愿意与否，都必被迫仰望上天。
