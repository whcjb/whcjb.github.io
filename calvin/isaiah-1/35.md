# 第三十五章

<p style="text-align:center" markdown="1"><span style="color:#000080">前往 以赛亚书 35:1-10</span></p>

**1.** <span style="color:#800000">*旷野和干旱之地必然欢喜。*</span>先知在此描述一种奇妙的变化；因为他在前一章既描述了以东的毁灭，又说它必变为旷野，如今他反倒应许旷野必有丰饶，使荒芜不毛之地变为极其丰产。这乃是神自己的作为；因为，正如他赐福全地，他也照自己的祝福，浇灌某些地方较为稀少，浇灌另一些地方较为丰厚，其后又因人的忘恩负义，将祝福收回、全然撤去。

这段经文有各种不同的解释。犹太人的梦想我且不论，他们把一切这类经文都应用在弥赛亚的地上国度上，那是他们凭自己的想象虚构出来的。有些人解释为指着犹大地，也有人解释为指外邦人的被召。但让我们思想，是否更恰当的是将全世界与犹大地一同包括在内；因为他所预言的全世界之毁灭，其说法并不豁免犹大，不仅如此，因为「时候到了，审判要从神的家起首」（彼得前书 4:17），所以圣地那格外可悲的荒凉被预先宣告，好作一个显著的鉴戒。因此，他适当而公正地从犹大开始，称全世界为*旷野*，因为神的忿怒到处充满；故此，我乐意视这段经文为先指犹大，其后指世界其余各处。仿佛他说：「主惩罚了人的邪恶与罪行，向犹太人和外邦人施行报应之后，旷野就必变为可居之地，全地的面貌都要更新。」如今这复兴乃是神美善的显著例证；因为人既以背叛惹动他，便理当全然灭亡、被彻底毁灭，尤其是那些他所收纳为自己特选之民的人。以赛亚的眼目主要注视着犹太人，使他们在困苦的境况中不至丧胆。

<!-- PAGE 794 -->
现在让我们看看这预言何时应验了，或何时将要应验。主领他的百姓出巴比伦时，就开始了某种复兴；但那只是略微的预尝，因此我毫不迟疑地说，这段经文以及其他类似的经文，都必指着基督的国；若我们将它与其他预言相比，也不能作别的看法。我所说的「基督的国」，不仅指在此世已开始的那国，也指在末日将要成全的那国，因此那日被称为「万物复兴的时候」（使徒行传 3:21）；因为信徒在那日来到之前，永不得完全的安息。先知们之所以用如此崇高的言辞谈论基督的国，乃因他们注目于那结局——那时信徒真正的福乐将最完满地得以恢复。

先知既已讲论了可怕的灾祸，预言了全世界可悲的败亡，就用这应许安慰信徒，在其中预告万物都必得复兴。这是藉基督成就的，唯独藉着他，他们才能得以更新、得以欢喜；因为唯独他更新万物，使之归回正当的秩序；离了他，天上地下就只有污秽与荒凉，只有最可悲的败亡。但当留意的是：世界需要藉这类的管教得以预备，好叫它合宜、有资格领受这样卓越的恩惠，也叫基督的恩典更充分地显明出来；倘若万事都保持在原初的状态，这恩典就会隐而不显。因此，人心中的骄傲与凶暴必须被打倒、被制服，他们才能尝到基督的仁慈，得以有分于他的能力与力量。

**2.** <span style="color:#800000">*必开花繁盛。*</span> 他更充分地描述基督恩典的果效何等浩大，藉着这恩典的能力与大能，那些曾长满污秽有毒野草之地，如今极其「开花」，重得生气。此处的重复是为了加强语气。「开花」一词的重叠可有两种理解：或是指时间的延续，表明生长不息；犹如说：「它必不是以短暂或凋残的花朵开放，以致立刻又归回从前的污秽光景，乃是以持续、不间断、长久的花开，永不凋谢、永不消逝。」或是指日益或年年增长的进步；因为基督如此丰富我们，使祂的恩典在我们里面日日增加。

<!-- PAGE 795 -->

<span style="color:#800000">*黎巴嫩的荣耀，迦密与沙仑的华美。*</span> 这些比喻更充分地表明前面所述的丰饶；因为先知不满足于说：从前是阴森的旷野之处，如今必见欢笑的田园，干旱之地必披上花朵的华美，更加上说：那里必有如「黎巴嫩、迦密和沙仑」素来所着称的那般繁茂华美。*Carmel*（迦密）虽有耕作肥沃之田的意思，但此处与其余二者一样，乃是专有名词。我们在别处经文中已经看见 [^f624]，这些山素负盛名，在全犹大地无论就其可悦或就其果实丰盛而言，都无可争议地居首。

<span style="color:#800000">*他们必看见耶和华的荣耀。*</span> 他先前以比喻所说的，如今清楚地、不用象征地加以解释。人若未学会认识神，就是荒瘠的，一切美善皆无；因此我们丰饶的开端，乃是被神的同在所苏醒，而这同在若无信心内在的知觉便不能有。先知无疑是要把我们的心思提升得更高，使我们得以默想属天恩惠的丰盛与充裕；因为人可能饱得五谷美酒并诸如此类之物，却不承认神是这一切的赐予者，也不脱离其可怜的光景；实在说来，人往往因享受丰足反倒瞎了眼、更加凶暴。但当神使自己在我们眼前显明，叫我们得见*祂的荣耀与华美*时，我们便不单是拥有祂的恩福，更是真正得享这些恩福以致得救。

<!-- PAGE 796 -->
**3.** <span style="color:#800000">*要使软弱的手坚壮。*</span>我们可以笼统地解释这段经文，好像他是说：「凡手软弱的，当使自己的手坚壮；凡双膝战抖摇晃的，当安定并振奋自己的心。」但接下来的一节表明，这整段经文都与圣道的仆人有关；因为他是对教会的教师说话，吩咐他们去劝勉、激励、鼓舞那些心里忧伤或沮丧的软弱之人，使他们变得更加坚定、更加欢畅。这一劝勉在此处出现得正合时宜，因为他看见自己所提到的那许多神发怒的兆头，必然使连最刚强的心也充满惊恐战兢；因为，既然我们向来一遇逆境就衰弱，那么当神自己因我们的罪而向我们宣告可谓公开的战争时，谁能不战抖呢？但先知吩咐要使那些沮丧、几乎气息全无的人得着生气，而这样做的方式，他在下一节中作了说明。

**4.** <span style="color:#800000">*对胆怯的人说。*</span>他所说的那力量，是神藉着他的话吹入我们心中的，因为「你们是因信才站立得住」（哥林多后书 1:24）并且得以存活；因此他随即加上了那将要来临之恩典的应许。

<span style="color:#800000">*看哪，你们的神必来。*</span>首先应当注意，神并不愿意他的恩典隐藏不为人知，反倒愿意它被宣扬、被传递，使那些摇晃战抖的人可以安定并振奋自己的心。这也是我们的心在沉重的患难中得以欢畅的一条途径；因为我们若不被主的话所扶持，就必昏倒绝望。所以，这就是分派给圣道教师的职分：扶起那跌倒的人，[^f625] 坚固那软弱的人，扶持那摇摇欲坠的人。

我们也当留意，神的话语在「使软弱的手坚壮，使无力的膝稳固」这事上有何等大的功效；因为倘若话语不是传递这力量的有力器皿，先知就绝不会如此说话。的确，若神只用祂的话敲击我们的耳朵，却不刺透我们的心，这些话便是徒然说的了。既然主将这职任交给话语，我们就当知道，祂也将这能力赋予话语，使它不至于徒然被传讲，而是能在内里感动我们的心——固然并非总是如此，也不是不加分别地如此，唯在神喜悦藉祂圣灵的隐秘能力这样运行之处才是如此。由此我们推知：正是同一话语使我们甘心顺服祂；否则我们必是懈怠愚顽的，我们一切的知觉都要衰残，我们不但要摇摇欲坠，更要全然因不信而麻木不仁。因此，我们需要从主领受帮助，好叫我们的惧怕被除去、我们的软弱得医治，使我们能轻快地行走。

<span style="color:#800000">*不要惧怕，看哪，你们的神必来。*</span> 这警语若深深铭刻在我们心中，必驱除懈怠。人一旦察觉神与他们相近，就或是不再惧怕，或至少能胜过那过度的惊恐。

<p style="text-align:center" markdown="1"><span style="color:#000080">保罗说：</span><span style="color:#000080">「应当一无挂虑，因为主已经近了。」</span><span style="color:#000080">（</span><span style="color:#000080">腓立比书 4:5, 6）</span></p>

<!-- PAGE 797 -->

关于这题目，我们在别处已有详论；希伯来书的使徒似乎正是暗指这段经文，因他劝勉他们不可疲倦灰心之后，便引用了先知的话（希伯来书 12:3、12）。然而，他把这番话对每一位信徒说，为要激励他们持守到底，并且因他们有许多争战要打，就当坚定不移地前行。他加上「*你们的神*」一语也并非多余；因为我们若不知道他是我们的神，他的临近只会带来惊恐，而非喜乐的缘由。这里所显明的，不是那足以挫折肉体骄傲的神的威严，乃是那足以安慰惧怕困苦之人的恩典；因此，他被描绘为一位守护者，以他的保护作他们的盾牌，实在不是没有缘故的。

若有人反驳说，他来施行报应时是带来惊恐的，我回答：这报应乃是向恶人和教会的仇敌发出的威吓。所以，对后者他必是惊恐，对信徒他却是安慰；因此他接着说，他要来拯救他们，否则或许有人要反驳说：「我们的仇敌受刑罚，与我们何干？这对我们有什么益处？难道我们必须以仇敌的患难为乐吗？」故此他明确宣告，这必促进我们的「拯救」；因为神在恶人身上所施行的报应，是与敬虔人的得救相连的。敬虔人如何藉着神的恩眷、藉着对他帮助的期待，得以脱离忧虑与惊惧，这在前面一处经文中已经解明[^f626]（以赛亚书 7:4）。此处当留意的是，神已预备妥当、以报应为兵器，好叫信徒学会倚靠他的帮助，不要幻想天上有一位闲置无为的神明。「他必来」这话的重复，也正是为此目的；因为人心中的疑惑并非一下子就能除尽。

本节末了可译作<span style="color:#800000">*神必亲自带着报应而来*</span>，或译作*他必带着神的报应而来*；但既然意思相同，读者可自行取舍。不过，若认为把<span style="color:#008080">אלהים</span>（*elohim*）视为属格「*神的*」更为可取，那么「神的报应」便着重指那专属于神的报应，好叫信徒确信：他既真是神，也照样真是那「赏赐人的」。[^f627]

**5.** <span style="color:#800000">*那时,瞎子的眼必睁开。*</span> [^f628] 他继续讲述有关教会复兴的应许,为要坚固敬虔人的心;因他先前所预言的可怕灾祸,必使他们大大惊惶。既然真正的复兴是藉基督成就的,所以我们若想明白以赛亚在此所用之言的含义,就必须来到他面前;实在说来,唯有藉着他的恩慈,我们才得以重新起来,盼望那属天的生命。以赛亚大概是暗指前面的一个预言(以赛亚书 29:10),在那里他警告犹大人必遭可怕的瞎眼、疯狂,以及心灵的全然麻木。如今他应许说,当基督显现的时候,他们一时被夺去的那些知觉,必得更新光照,进入新的生命。副词「那时」是有分量的;我们当由此推知:只要我们仍与基督隔绝,我们就是哑的、瞎的、瘸的,简言之,我们全然没有行善的能力;唯有被基督的灵更新,我们才得享真正的健全。

他用「舌头」、「耳朵」和「脚」来指我们灵魂的一切官能;这些官能本身既已如此败坏,以致在基督的恩慈使之复原以前,从其中得不出任何善来。眼不能看见正直的事,耳不能听,脚也不能引导我们走正路,直到我们与基督联合。虽然人的知觉一旦被罪恶的情欲所驱动,便格外敏锐;虽然舌头在诽谗、起假誓、说谎和各样愚妄的言语上极其伶俐;虽然手在偷窃、勒索和残暴上过于灵便;虽然脚飞跑行恶;简言之,虽然我们的全然本性不仅甘愿、且强烈倾向于作恶;然而我们在行善上却全然懒惰迟钝。因此,我们里面的每一部分都必须藉基督的能力重新被造,才能开始正确地领悟、感受、说话,并履行其职分;因为

<p style="text-align:center" markdown="1"><span style="color:#000080">「若不是被圣灵感动的,也没有能说耶稣是主的。」</span> <span style="color:#000080">(</span><span style="color:#000080">哥林多前书 12:3)</span></p>

<!-- PAGE 799 -->
这更新唯独出于基督的恩典，因此，那些归向基督的人重新得着健全的力量；他们从前在各方面都是无用的，与死人无异；因为我们既与基督隔绝，就或是全然缺乏一切美善，或是那美善在我们里面已败坏至极，以致无法用于正当的用途，反倒因被滥用而遭污染。基督在使哑巴说话、瞎子看见、软弱瘸腿的得着完全的力量时，已丰丰富富地为此提供了明证与实例；然而他赐给他们身体的，仅仅是一个记号，表明他赐给我们灵魂的福分远为丰盛、远为美好。

**6.** <span style="color:#800000">*因为必有水被挖出。*</span> 接着他又加上信徒一旦基督的国被建立便要丰丰富富得着的其他福分；仿佛他是说，当我们藉着基督与神和好之后，就再无缘由惧怕匮乏或缺少，因为完全的福乐都从他流到我们身上。但他是用隐喻的说法向我们描绘这福乐；首先，他说「必有水被挖出」；因为从前一片荒芜之处，如今必见极大的丰饶。如今，若神不藉着基督赐福与我们，我们便是贫穷荒芜的；因为唯有他将父的祝福带来，并将这祝福赐给我们。恶人固然常常大有美物的丰足，然而他们的财富是可悲的；因为他们没有基督，而唯独从基督才涌出一切福分真实而有益于救恩的丰盛。若那酒食的丰盛竟使我们同时把神的咒诅一并吞下，那么死无疑比这样的丰盛更可羡慕。所以，当基督荣耀地兴起之时，江河与众水必涌流而出，并生出真实而宝贵的益处。

**7.** <span style="color:#800000">*干旱之地要变为水池。*</span> 他确证了前面的话，即基督来是要用一切丰盛的福分使他的百姓富足；因为众水必从「干旱之地」涌流而出。[^f629] 我们必须记住稍前所提到的：先知在此为我们描绘的，可称为幸福生活的一幅图画；因为虽然在基督降临之时这变化并未公然显现，先知却有充足的理由断言，在他掌权期间全地必然结实累累；因为他先前已经说过，若没有基督，万物对我们都是被咒诅的。

<!-- PAGE 800 -->
<span style="color:#800000">*野狗躺卧之处。*</span>因此，直到基督的国被建立之前，整个世界都好像干旱的旷野，其中有狮子、「野狗」和其他野兽出没；反之，当祂被立在祂的宝座上时，敬虔人必一无所缺。当主拯救祂的百姓、领他们出巴比伦时，此事曾有一次预表；但这预言的成就，必须在基督里寻求，惟藉着祂，他们败落的境况才得以修补与复原；因为那次的拯救只是它微弱的表征。然而，这应许的完全成就不当在今生期待；因为我们既是在指望中得救的（罗马书 8:24），所以我们的福乐——如今在某些方面仍是隐藏的——必须是所盼望的，直到末日；只要在这世上得以稍尝其滋味，就已足够，使我们更加热切地渴慕那完全的福乐。

**8.** <span style="color:#800000">*在那里必有一条大道。*</span>这里向犹太人应许，他们必得允许返回本国，免得他们被掳到巴比伦时，以为自己是被带入永远的流放之中。然而依我看来，先知在此所说的意思远为宽广；因为正如他在稍前应许，在从前荒芜之地必有丰盛充足的粮食，如今他也说，那些从前无人居住之处，必有极多的人来往行走、居住其间；简言之，全犹大之地必与别国有这样的和睦与太平，以致人可以毫无惧怕地从一国往另一国去；因为无人居住之处，就没有交通往来，也没有道路。所以他的意思是，犹太人被带回、复归本地之后，必与别国有交往和贸易。

<span style="color:#800000">*称为圣路。*</span>先知加上「这路必称为圣路」，并非没有缘故；因为凡有大群人聚集之处，必有无数的罪恶与败坏丛生。众人聚集所行的，除了以彼此相染的污秽玷污那地之外，还有什么呢？所以先知的意思是，不但地被基督的恩慈更新，人的心也被更新，以致他们使这地成圣，而从前他们却惯以自己的污秽败坏它。然而我简略所说的仍当记念，就是这路要为犹太人所分别为圣，他们必回归本国，好在其中以圣洁的方式敬拜他们的救赎主；如同他说，这地必被洗净，除去恶民那可耻的乌合之众，好使真敬拜神的人居住其间。

<span style="color:#800000">*污秽人不得经过。*</span>他现在加上更为完整的解释；因为被污染的人不得踏足神为他儿女所分别出来的地；仿佛他说，主必如此将信徒分别出来，使他们不与被弃绝者混杂。这无疑当被列为教会最宝贵的福分之一；然而它在今生并未成就；因为藐视神的人和假冒为善的人都不分彼此地涌入教会，并在其中占有地位。但每当神以各种方法洁净他的教会时，这恩典的某些明证便显露出来；只是教会的完全洁净必须等到末日。甚至那些神藉他的圣灵重生了的敬拜者，也仍有许多不洁伴随着他们。虽然他们已被神分别为圣，然而他们的圣洁不能是完全的；他们的肉体并未全然死去，只是被制服、被约束，以致顺服圣灵。如今，正因为主在他们里面掌权，制服他们本性的倾向，所以就他们里面那最重要的部分而言，他们被称为圣徒。

<span style="color:#800000">*他必为他们作那行路的。*</span>这一句被注释家们以各种方式加以曲解。有些人译作：「这必是他们的道路；那些熟悉此路的人，和那些不认识此路的人，都不致失迷。」另有人译作：「这必是以色列人的道路，行路的人虽不认识此路，也不致失迷。」但依我看来，指示代词 <span style="color:#008080">הוא</span>（hu），*他*，更正确地是指着神说的；仿佛他说，神必走在他们前面，引领并指示道路。上下文也绝对要求如此；因为若神不走在前头引导他的百姓，单单开通道路是不够的。因此，先知在描述神与他的百姓一同前行时，是在颂扬这无可估量的慈爱；因为若他不指明道路，我们的脚必总要走差，因我们全然偏向虚妄。此外，纵然道路就在近处，纵然它明明摆在我们眼前，我们仍不能将它与错路分辨出来；而且我们即便开始行在其上，我们的愚昧也会迅速使我们偏离左右。但先知表明，当我们跟随神作道路的引领者时，我们便毫无失迷的危险；因为他俯就自己来担任这职分；并且他大概是在暗指头一次救赎的历史，因为那时神引导他的百姓

<p style="text-align:center" markdown="1"><span style="color:#000080">「日间在云柱中，夜间在火柱中。」</span> <span style="color:#000080">（</span><span style="color:#000080">出埃及记 13:21）</span></p>

<!-- PAGE 802 -->

同时，他也指出神掌管我们是何等必要，因为他随即直接指控我们的愚昧，说——

<span style="color:#800000">*愚昧人也不得在其上走迷；*</span>因为那些自以为有智慧、依靠自己引导的人，神必任凭他们在不定的路途上飘荡。所以，我们若愿意他与我们同行，就当知道我们需要他的引导。然而他又将这至美的赏赐赐给我们：凡跟从他的人，即使从前并无任何智慧，也必无走迷路的危险。不过先知的意思并非说，主既已牵着信徒的手，他们仍是无知的；他乃是指出，在主成为他们的领路者之先，他们是何等光景。

**9.** <span style="color:#800000">*在那里必没有狮子。*</span>他又加上神另一样的恩惠，就是这百姓虽行经旷野，却必蒙保护，免受一切仇敌的攻击。他从前曾提到（以赛亚书 34:14），神的咒诅之一，就是犹大人无论往哪里去，野兽都必迎着他们；但如今他宣告说，他们既已蒙恩得纳，便再无狮子、再无猛兽攻击他们；因为主必为他们抵挡这些，好为他百姓开出一条脱离一切危险、脱离一切惧怕的道路。因为他们虽已得着归回的自由，仍可能遭遇许多阻碍；所以他说，主必除去一切的困扰与拦阻。

我们可以从这里得出一个有益的教义，就是：神不但开始我们救恩的工作，也引导它直到末了，使他在我们里面的恩典不至于徒然无益。他既开辟了道路，也铺平这道路，除去各种各样的障碍，并且在整个旅程中亲自作我们的领路者。总之，他如此持续地将恩典施于我们，以至终于使之完全。这一点也当应用于我们一生的全程。我们在此如同行走在路上，向着那有福的基业前行。撒但设下无数的阻碍，危险从四面围绕我们；但主既在前头行，又亲手牵引我们，他必不在旅途中途弃我们于不顾，而是终必藉着他的圣灵，将他在我们里面所开始的善工完全成就。（腓立比书 1:6）然而也当注意，藉着神的慈爱，连野兽也必被驯服，不再向我们发出它们的凶暴与残忍，正如经上所说：

<!-- PAGE 803 -->

<p style="text-align:center" markdown="1"><span style="color:#000080">「当那日，我必为我的民，与</span> <span style="color:#000080">田野的走兽和空中的飞鸟，并地上的昆虫立约。」（</span><span style="color:#000080">何西阿书 2:18）</span></p>

**10.** <span style="color:#800000">*耶和华救赎的民必归回。*</span>先知在此坚固前面的教义，就是神已定意要救赎他的百姓，因此没有什么能抵挡他的旨意。他称他们为「耶和华救赎的民」，为叫他们思想他的能力，不要按人的方法来衡量他所应许的归回。他又说*他们必来到锡安*，因为神并非徒然愿意领他们出巴比伦，而在他们才起程时就撇下他们。同时也当注意，除了藉着神的救赎，我们绝无进入教会的门路；因为在古时百姓的例子之下，有一幅普遍的图画摆在我们眼前，使我们知道：除非神的恩典先行，无人能从我们众人所服在其下的魔鬼暴政中被救出来，因为无人能救赎自己。既然这救赎是基督国度所独有的恩赐，那么随之而来的便是：唯有他是我们的拯救者，正如这句话所证实的：

<p style="text-align:center" markdown="1"><span style="color:#000080">「所以天父的儿子若叫你们自由，</span><span style="color:#000080">你们就真自由了。」（</span><span style="color:#000080">约翰福音 8:36）</span></p>

然而，我们仅仅一次得蒙救赎还不够；因为神的目的乃是要我们住在神的教会中，并日日长进。所以，既然我们已被基督拯救，我们就当竭尽全力，不断竭力追求那目标。倘若有人说：我们不需要走一段长路才得以被接纳进入神的教会（因为我们藉着洗礼被收纳进去），我回答说：先知在此是以比喻的方式论及人一生的全部行程；因为「耶和华救赎的民」实际「归回锡安」之时，乃是人生的路程结束、他们进入有福生命之时。也当注意：我们在神的恩典中越有长进，与教会的联合越紧密，我们就越接近锡安。

<!-- PAGE 804 -->
<span style="color:#800000">*必得着欢喜快乐。*</span> 藉着「欢喜快乐」这几个字，他的意思是：在基督的国度之下必有如此大的福乐，以致我们有充足的理由欢喜。的确，欢喜的真实而唯一根基，乃是知道我们已与神和好；祂的恩眷足以使我们得着完全的福乐，「就是在患难中也是欢欢喜喜的」（罗马书 5:3）；反之，当基督不光照我们时，我们就必被忧愁所笼罩。此外，敬虔人若不同时向神表达感恩，就断然不能以正当的方式欢喜；因此，这属灵的喜乐必须与不敬虔的人所纵情的那种寻常喜乐区分开来；因为被弃绝者也欢喜，但他们的结局终究显明：肉体的放荡是何等毒害人，以致使他们以轻蔑神为乐。保罗恰当地称这一种「喜乐」为属灵的（罗马书 14:17；加拉太书 5:22）；因为它不倚赖那些必衰残之物，如尊荣、产业、财富以及其他速速消逝之物；乃是隐秘的喜乐，安置在人心里，无论撒但用尽各样方法搅扰苦害我们，也不能以任何方式将它摇动或夺去；因此先知恰当地补充说——

<span style="color:#800000">*忧愁叹息尽都逃避。*</span>这喜乐是永远的，一切「忧愁尽都逃避」；因为虽然神的儿女每日忍受许多苦涩的悲痛，然而他们所得安慰的能力与力量如此之大，竟将一切忧愁吞灭了。保罗说：「就是在患难中也是欢欢喜喜的」（罗马书 5:3）；而这样的夸耀不可能没有喜乐。使徒们

<p style="text-align:center" markdown="1"><span style="color:#000080">「他们离开公会，心里欢喜，因被算是配为</span> <span style="color:#000080">这名受辱。」</span> <span style="color:#000080">（</span><span style="color:#000080">使徒行传 5:41）</span></p>

然而敬虔人常常遭受沉重的苦难，也并非免于忧伤。这无疑是真的，但他们不被压倒；因为他们直视神，藉着祂的能力得胜；正如一个人站在高山之上，仰望太阳，享受祂的光辉，却看见别人在低谷之中，被云雾与黑暗围绕，那光辉照不到他们身上。
