# 第十二章

<p style="text-align:center" markdown="1"><span style="color:#000080">前往 以赛亚书 12:1-6</span></p>

**1.** <span style="color:#800000">*到那日，你必说。*</span> 以赛亚现在劝勉一切敬虔人当感恩。然而这劝勉还有另一目的，就是使那应许更被人确信；因为他以这劝勉为那应许加上印记，好使他们确信这应许是可靠的，不至以为自己是被虚妄的盼望所欺哄——如今既有一篇感恩的祷词赐下，仿佛放在他们口中，若无公义而坚实的根据，断不会如此。同时，他也指出主在祂教会中施恩所存的目的：乃是要祂名的记念得着称扬；这并非因祂需要我们的赞美，而是因这对我们自己有益。我们也当思想祂加给我们何等的尊荣，就是祂竟俯就使用我们的事奉，来称扬并传扬祂名的荣耀，虽然我们全然无用、毫无价值。

<span style="color:#800000">*你必说。*</span>他向全体百姓说话，却如同向一个人说话，因为他们本当如此合一，以致成为一体。我们也从同一榜样受教：我们既愿自己的祈求与感谢为神所悦纳，就当彼此联合，好使我们**一心一口**（罗马书 15:6）。

<span style="color:#800000">*你虽然向我发怒。*</span>这篇颂歌的主旨是：神虽然理当向他的百姓发怒，却以施行适度的管教为足，并且表明他愿意与他们和好。<span style="color:#008080">yk</span>（*ki*）这个虚词有时表示原因，故有人译作：*耶和华啊，我要称谢你，因为你虽曾向我发怒，却立即与我和好*；但既然它有时也作「虽然」解，[^f184] 我便采用了我认为最合本段文意的译法。

<!-- PAGE 340 -->
所以，信徒首先承认自己的罪责，其次将自己得脱苦难归于神的怜悯。既然这些动词是未来式，也可采用下述解释：「暂时的管教不会拦阻你终必怜恤我，也不会拦阻你赐我喜乐与安慰的凭据。」无论采取哪一种看法，这一意念都当被小心留意；因为一旦对神怒气的意识攫住我们的心，它便催逼我们绝望，若不及时加以抵挡，就必迅速将我们淹没。撒但也用尽各种方法试探我们，动用一切手段迫使我们绝望。因此，我们当以这教义坚固自己：我们虽感受到主的怒气，却可知道那怒气不过是转眼之间（诗篇 30:5），并且他一管教了我们，我们就必得安慰。

当我们从困苦中得着舒解时，让我们记得：我们的刑罚之所以止息，并非因为我们已向神的公义偿付了我们所当受的，乃是因着他慈父般的爱怜恤我们的软弱。这样的承认本是敬虔人和蒙拣选者所独有的；因为敬虔人与不敬虔的人所受的管教，虽然表面看来一样，其缘由却截然不同。主向不敬虔的人所发的忿怒是永久的，加在他们身上的责罚乃是永远沉沦的先兆：没有丝毫的减轻或安慰应许给他们。但敬虔人却觉得神的忿怒是短暂的，并以盼望和信靠坚固自己的心；因为他们知道神必向他们施恩，既然他已宣告，他惩治他们的罪，无非是要操练他们悔改，*免得他们和世人一同定罪*。（哥林多前书 11:32）

**2.** <span style="color:#800000">*看哪！神是我的拯救。*</span>虽然在患难之中凭信心仰望神的拯救乃是合宜的，然而以赛亚在此所说的，乃是从经历中得来的认识；因为他在此立下一篇欢乐之歌的样式，其中神藉外在的记号显明他已向他的教会息怒。<span style="color:#008080">hnh</span>（*hinneh*，希伯来文「看哪」）这词的含意也正在于此；因为如今神的荣面，就是曾一时隐藏的，重新照耀出来，以致他们能用指头指着它。所以，既然我们的刑罚使我们充满惊惧，而我们的心思也不可能不因我们的罪而蒙上阴霾，仿佛我们与神的拯救毫无干系，或仿佛这拯救已从我们收回了，先知就在此描述当神与我们和好时那心情的转变。但这预言主要是关乎基督的降临，惟有基督的降临才首次完满地显明了神的拯救。

<!-- PAGE 341 -->

<span style="color:#800000">*我要倚靠他，并不惧怕。*</span>他补充说，当我们深信拯救已为我们存留在神那里时，这便是十足确信的坚固根基，也是平息恐惧的最佳良药。若非如此，我们必然战兢不安，忧愁困扰，被痛苦的情绪所折磨。由此我们断定，确信乃是出于信心，如同果效出于其原因。藉着信心，我们看出拯救已为我们存留在神那里，心中便生出安宁平静的境况；但信心一旦缺乏，良心便不能有平安。所以，我们当知道：当我们被赋予先知在此所描述的那种确信时，我们在信心上便大有长进了。

此外，这确信应当在我们心里**居首位**（歌罗西书 3:15），以致驱除一切惧怕与惊恐；这并不是说我们全然免于痛苦和不安，而是说这确信终必得胜。然而我们必须记住我先前所说的：先知在此所论的，乃是那些从前几乎被试炼的重担所压倒的信徒，在神与他们和好之后所得的欢畅。

<span style="color:#800000">*因为主*</span> <span style="color:#800000">耶和华</span> <span style="color:#800000">*是我的力量*</span>。他更清楚、更明确地宣告，信徒必大有理由歌唱，因为他们已从经验中知道，他们**在其神里面是刚强的**；实在说来，那救赎正是神大能的辉煌显明。既然以赛亚所描述的不是一日之恩惠，而是神所定意要一直推进、直到基督降临的恩惠，那么随之而来的结论便是：唯有那些深知自己软弱、并借着祈求单单从神求得力量的人，才是真诚而衷心歌颂神的人。而且他在此并非被称为我们力量的一部分或一种辅助，乃是被称为我们完全的**力量**；因为我们之所以刚强，全在乎他将力量供给我们。

<!-- PAGE 342 -->
<span style="color:#800000">*也是我的诗歌*</span>。他被称为**敬虔人的诗歌**，其缘故乃是：他将如此丰盛的恩慈赐给他们，目的是激励他们尽感恩的本分。由此我们断定，喜乐的起头出于神的恩眷，而其终局则是**赞美的祭**（诗篇 50:23；希伯来书 13:15）。因此，敬虔人的心当受训练以致忍耐，好使他们不停止称颂神；而在喜乐与顺境之中，他们的口便张开，高声传扬神的恩惠。但因不敬虔的人恣意藐视神，把良心哄睡，像畜类一般在醉酒的欢乐中放荡，从不醒起来赞美神，所以基督公义地咒诅他们的喜乐。

<p style="text-align:center" markdown="1"><span style="color:#000080">你们喜笑的人有祸了！因为你们将要哀恸哭泣；你们的喜乐要变为</span> <span style="color:#000080">忧愁，你们的欢笑要变为切齿。</span> <span style="color:#000080">（</span><span style="color:#000080">路加福音 6:25）</span></p>

<span style="color:#800000">*他也成了我的拯救。*</span> [^f185] 若认为把这一句作过去时来理解更好，其意思便是：信徒欢然歌唱，<span style="color:#800000">*因为神已拯救了他们*</span>。但最恰当的还是取将来时，<span style="color:#800000">*他必成为我的拯救*</span>；就是说，神不但<span style="color:#800000">*曾作*</span>他百姓的<span style="color:#800000">*拯救*</span>，并且要如此直到末了；因为信徒不该把注意力局限于眼前的恩惠，乃当把盼望延伸到他恩眷不间断的进程之上。

**3.** <span style="color:#800000">*你们必从救恩的泉源欢然取水*</span>。在这一节里，他证实了我们已经指出的一点，就是本章可视为一个印记，用以确认他先前所赐关乎救赎其子民的应许。仿佛他说：“神的救恩已摆在你们面前，如同一道长流不息的*泉源*，你们可以从其中<span style="color:#800000">*取水*</span>，取之不尽。”这是一个极其优美的比喻；因为在今生没有什么比*水*更为必需，以致没有哪一种缺乏比缺*水*更叫我们不安、更叫我们困苦。因此，他借着以部分代全体的修辞手法宣告：一切维持生命所必需的，都是从神白白的美善中流向我们。既然我们空虚匮乏、一无所有，他就恰当地把神的怜悯比作一道*泉源*，使干渴焦躁的得饱足，使受炎热炙烤的得清凉，使疲乏困倦的得苏醒。

<!-- PAGE 343 -->
<span style="color:#800000">*从救恩的泉源。*</span> [^f186] 此处用这个词比说「从**神**的**泉源**」更为贴切；因为当我们知道他是我们救恩的创始者时，这带来更大的安慰，所以先知巧妙地将这个称号安置在此处，使之与上下文相称。既然这应许包含基督整个国度的统治，我们就当时时将它应用在自己身上。因此，让我们知道神的美善已向我们伸展出来，为要使我们以此为满足；因为我们应当像诗人所说的「*干旱之地*」（<span class="ages-code">&lt;19E306&gt;</span>诗篇 143:6），好叫我们渴慕耶和华的活水。神这样的美善实在奇妙，超乎人所能相信：他不容我们的渴望得不着满足而焦灼，反倒摆出一个*泉源*，使我们可以从其中丰丰足足地*取*用。那*泉源*就是基督，神一切的恩惠都在他里面赐给我们；正如约翰所说：*从他丰满的恩典里，我们都领受了*（约翰福音 1:16）。所以，剩下的就是：每当我们觉得自己的缺乏时，就要直接到他那里去。

**4.** <span style="color:#800000">*在那日，你们要说。*</span> 他现在劝勉他们，不但要各人自己歌颂称谢神，也要激励别人同样如此行。正如他先前所说：

必有许多国的民前往，说：来吧，我们登耶和华的山（以赛亚书 2:3），就是说，他们彼此劝勉、互相激发，去接受对神纯正的敬拜；照样，他既已吩咐他们各人向神感恩，如今也命令他们彼此激励，同献感谢。他的意思是，他们不当只向一个人说，而要向众人说；也不当只在一时说，而要终其一生如此说。

<span style="color:#800000">*要求告他的名。*</span> [^f187] 他在此简要地描述了将赞美正当地献给神的方式，就是吩咐我们

<p style="text-align:center" markdown="1"><span style="color:#000080">求告他，使我们不至夸耀别的。</span> <span style="color:#000080">(</span><span style="color:#000080">耶利米书 9:23,24。)</span></p>

因此，圣经也常以部分代全体（<span style="color:#0000d4">συνεκδοχικῶς</span>，提喻法），用*求告神*一语来描述敬拜的全部。我们借此表明自己的信靠是安置在神身上；这也正是他向我们首要索求的。同样地，我认为先知在此将*求告*神与赞美相连，是为要涵括敬拜神的全部。

<!-- PAGE 344 -->
<span style="color:#800000">*将他所行的传扬在万民中。*</span> [^f188] 他的意思是，这拯救的工作如此卓越，以致不当只在一个角落里宣扬，而当在全世界宣扬。他固然愿意这事首先*传扬*给犹大人，但随后要广传给万民。犹大人藉这劝勉表明他们的感恩，这劝勉可视为福音宣讲的先声，那福音的宣讲后来按合宜的次序随之而来。犹大人既在玛代人、波斯人以及其他邻邦中宣扬他们所蒙的恩眷，那么当基督显现时，他们更当作传报者，将神的名高声传遍世上各地。由此可见，凡敬虔人中间当存的是何等样的心愿：就是愿神的美善*传扬*于众人，使众人一同敬拜这位神。我们尤其当被这心愿点燃，特别是在脱离某种可怕的危险之后，最要紧的是在脱离魔鬼的暴政与永远的死亡之后。

**5.** <span style="color:#800000">*你们要向耶和华歌唱。*</span> 他继续他的劝勉，指明这感恩当出于何等样的心情；因为他表明，将神的美善向万邦宣扬乃是我们的本分。我们既劝勉激励别人，自己就不可同时安坐于懒惰之中，而当在众人面前作出榜样；因为再没有比看见懒惰迟钝之人去激励他人赞美神更为荒谬的事了。

<span style="color:#800000">*因他所行的甚为美好。*</span> 当他断言神*所行的甚为美好*时，他的意思是，歌唱的理由极为充足。主并不愿人无缘无故地传扬他的赞美，而是当他救他的百姓脱离极其艰苦的奴役时，就摆出极其丰富、极其充足的赞美题材。我们已经说过，这首歌并不限于一段短暂的时期，反倒延及基督整个国度的统治。因此这工作真是荣耀的，就是*神赐下他的儿子*，使我们与他自己和好（约翰福音 3:16、17），并且败坏死亡与魔鬼的权势（希伯来书 2:14）。所以，我们若照所当有的那样思量我们得拯救的这工作，就必有极其丰富的理由来赞美神。

<span style="color:#800000">*这事已传遍全地。*</span>当他说这事*已被传扬*时，他暗指外邦人的蒙召，并且证实前面已经陈明的：这工作乃是不当隐藏在角落里的，而应当处处传扬。

**6.** <span style="color:#800000">*当扬声欢呼。*</span>他再次劝勉敬虔人在主里喜乐，同时提醒他们真正的喜乐是何等性质、又建立在什么根基之上。除了有神住*在我们中间*以外，我们别无其他的福乐。若非如此，纵然我们享有丰盛的其他恩惠、各样的财富，我们的生命仍是可怜而不幸的。

<!-- PAGE 345 -->

如今，我们的心若系于我们的*财宝*（马太福音 6:21），这福乐必吸引我们全部的情感。

<span style="color:#800000">*以色列的圣者*</span>。他称他为<span style="color:#800000">*圣者*</span>，是要使我们明白：当他与我们同住时，他愿向我们显明自己是怎样的一位。这就是说，不单要他的威严充满我们的心，使我们对他存敬畏之心——因为那威严同时也会以惊惧压倒我们——更是要他俯就我们，使我们虽与世上其余的人分别出来，却成为他特别看顾的对象。他称他为<span style="color:#800000">*圣者*</span>，是就其所生的果效而言；因为他把我们招聚归于自己（以弗所书 1:10），并以他的恩典拯救我们，就可以说是*分别我们为圣*，作他自己的产业。因此，若神与我们同在，深信他的同在便必使我们满有难以言喻的喜乐。由此可见，当他不在时，我们便仍旧陷于忧伤愁苦之中。

他用<span style="color:#800000">*当扬声欢呼*</span>这话，意思是：当神在<span style="color:#800000">*我们中间*</span>彰显他的大能时，他就赐给我们非比寻常的欢乐之由。再者，他直接称呼<span style="color:#800000">*锡安的居民*</span>，暗示并非人人都能领受这样大的福分，同时也间接劝勉他们要持守信仰的合一，好叫我们因与教会联合，得以分享这有福的喜乐。
