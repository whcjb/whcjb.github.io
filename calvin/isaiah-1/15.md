<p class="title-block-h1" style="text-align:center; font-size:22px; font-weight:bold; margin:18px 0 12px;" markdown="1"><span style="color:#0000d4">第十五章</span></p>

<p style="text-align:center" markdown="1"><span style="color:#000080">前往 以赛亚书 15:1-9</span></p>

**1.** <span style="color:#800000">*论摩押的默示。*</span>先知在此说预言攻击*摩押人*，他们与犹大人邻近，且有血脉之亲；因为我们知道*摩押人*出于罗得，而罗得是亚伯拉罕的侄儿。（创世记 11:31，19:37。）这些民族既有如此密切的亲属关系，至少按人情而论，理当彼此保持某种友好的往来。然而这一切亲属关系都未能阻止*摩押人*怀藏对犹大人的敌意，甚至一有机会便加以搅扰；这就显明了一种野蛮凶残的性情。因此，先知也向他们宣告毁灭，因他们残酷对待神的百姓——对这百姓，他们本当以弟兄之爱相待。

我们应当记住这些预言的目的。我们不能认为它们对**摩押人**有什么益处，即便他们曾亲耳从先知口中听见我们如今所读的这些话；但先知既没有用口向他们宣讲，也没有把书信送给他们。因此，先知所注目的乃是信徒，而非摩押人，这有两个理由。第一个理由是：当他们看见如此众多的变动发生——城邑倾覆，列国毁灭，一个接着一个更替——他们就不至于以为这世界是受命运盲目的暴力所支配，反倒可以认识神的护理。倘若什么都未曾预先宣告，人的心思既极易趋向愚昧，又对神的作为出奇地盲目，就会倾向于把这一切都归于偶然；然而当他们已经借着先知得了预先的警告，他们便如同从高耸的守望楼上观看神的审判。就是对今日的我们，以赛亚也仿佛用手指点出了当时所隐藏的事。在他的预言中，我们看见神坐在审判台上，按自己的美意安排万事；虽然恶人以各种方式发泄他们的狂怒，主却仍然借着他们的作为施行自己的审判。众先知所存的第二个目的是：在全世界都被震动之时，犹大人可以知道<!-- PAGE 400 -->神顾念他们的平安，并且神藉着向那些曾野蛮对待教会的仇敌施行报复，来见证祂对教会那炽热的爱。

<span style="color:#800000">*亚珥·摩押。*</span> 希伯来文 <span style="color:#008080">r[</span>（*Ar*，亚珥）意为*城*；正如 <span style="color:#008080">ryq</span>（*kir*，基珥）意为*墙*；但因 <span style="color:#008080">bawm r[</span>（*Ar-Moab*，亚珥·摩押）是**摩押人**的主要城邑之一，这里就被视为专有名词。我们固然可以把这两个字都解作普通名词，用以传达一个威胁，即摩押人所夸耀的坚固城邑必要倾覆；但我宁愿采用通常的解释。因此以赛亚在此作了一幅描绘，使我们可以从其中看见摩押人的倾覆——就在他们主要的城邑被毁之时。

<span style="color:#800000">*一夜之间。*</span> 他以*夜*表示一件突然而意外的事，是摩押人素来所不惧怕的。既然*夜*是为安歇而设的，若有事在那时发生，便被看作是突如其来、意料之外的，因此激起剧烈的惊恐。此外，他也有意责备摩押人的无忧无虑：他们自以为四面都有防御工事作屏障，远离一切危险之外。

<span style="color:#800000">*归于无有。*</span>就是说，*被毁灭了*；因此「静默」（Silence）有时也指死亡。有人不理会这个隐喻，宁愿译作<span style="color:#800000">*她被剪除了*</span>；这一点我不作定论。以赛亚在此论到*摩押人*所宣告的，圣经也照样论到被弃绝之人：毁灭已经临近，且在他们全然料想不到之时，必可怕地将他们淹没。（耶利米书 23:19；帖撒罗尼迦前书 5:2, 3）

**2.** <span style="color:#800000">*他要上到殿里。*</span> [^f227] 就字句而论，有些人略过希伯来文名词 <span style="color:#008080">tyb</span>（*baith*）；但既然它兼指*房屋*与*殿宇*，很可能这就是当时通用来指*殿*的字眼，正如在许多别的经文中，*神的殿*即指*圣殿*。[^f228]（出埃及记 23:19，34:26；申命记 23:18；约书亚记 9:23）先知描绘摩押人俯伏在他们的偶像面前，同时也就定了他们敬拜偶像基抹的迷信之罪，这从列王纪上 11:7、耶利米书 48:7, 13 不难推知。以赛亚说：「摩押人在事情如此绝望之际，必投奔他们的神，却是徒然；因为他们在他身上找不着任何帮助。」

<span style="color:#800000">*又上到底本的高处。*</span>这就更加显明他是在讲那庙宇；毫无疑问，摩押人有一座比其余更为显赫著名的堡垒，他们在其中为自己的偶像筑了*邱坛*。他们既不认识真神，无从在患难中投奔于他，那么他们照着素常的习惯投奔偶像，也就不足为奇了。他们这样行，反倒加增了自己的愁苦，把一切祸患堆积在自己身上；因为他们正是用那些自以为足以平息神忿怒的方法，反倒更加激动了神的忿怒。所以先知愿意更明白地陈明不敬虔之人的光景：他们在患难中毫无避难所；因为那些他们以为对症的良药，对他们再没有比这更具毁灭性的了，因这些反倒愈发激起了耶和华的震怒。

<span style="color:#800000">*摩押人必在尼波和米底巴哀号。*</span> *尼波*也是*摩押人*的一座城。先知先前已提过其中两座，*亚珥*与*基珥*；现在又加上第三座，*尼波*；最后还提到第四座，*米底巴*；仿佛在说，这毁灭不仅要临到那地的边界，更要深入其最里面的隐僻之处，以致没有一个角落可以幸免。

<span style="color:#800000">*各人头上。*</span> 各国都有自己表示哀伤或欢乐的独特礼俗。意大利人和其他西方民族在居丧时任凭须发生长，因此便有<span style="color:#800000">*留长胡须*</span>这一说法。相反，东方民族则剃去他们视为妆饰的头发与胡须；他们一旦颠倒平日的习惯，那就是哀悼的标记。[^f229] 因此，这里所指的无非是：全国的境况将如此凄惨，以致欢乐的表征都要撇下，众人都要显出悲伤哀哭的记号。

<!-- PAGE 402 -->
**3.** <span style="color:#800000">*在街市上。*</span> [^f230] 他继续同一主题，更加详尽地描述那些哀悼的表征；东方民族在这类表征上比别的民族更为繁多，因为他们悟性较敏锐、情感较强烈，故比别人更多以外在的记号表达内心的激动；而那些领悟迟缓的民族，在举动与姿态上也同样迟缓。他们沉溺于如此众多的礼节与手势，无疑是有过失的；但先知提及这些，只是当作人所熟知而通行的事，为的是描写那地荒凉之后随之而来的悲哀。

<span style="color:#800000">*各人都必哀号，眼泪汪汪。*</span> [^f231] 他加上这一番描绘，实在是有道理的；因为预言若非主把它们摆在我们眼前，我们绝不会因之动容。为免犹大人以为这些事可以轻轻放过，他在描述那场毁灭之时，就决意也提及*悲哀、哭泣与哀号*，使他们几乎能亲眼看见那些看似难以置信的事；因为摩押人当时正处于深深的太平之中，而信徒更需要得着坚固，免得他们对这预言起了疑问。他用同样的方法指出不信者在患难中难免陷入的绝望，因为他们所倚靠的支撑本是不稳固的。

**4.** <span style="color:#800000">*希实本和以利亚利悲哀的声音达到雅哈斯。*</span> 这里他题出别的城邑；因为他的用意是要把那地所有的城邑，仿佛捆成一束，使它们都被卷入这普遍的毁灭之中；如同他说，绝没有一处得以免脱。

<span style="color:#800000">*所以摩押带兵器的必高声喊叫。*</span> 虽然 <span style="color:#008080">ˆk l[</span>（*gnal ken*）按字面意思是*所以*，但有些人认为这里并非在陈明缘由；不过这一点无关紧要。先知表明必没有一人不*哀号*；因为他宣告，就连勇武刚强的人也要悲哀。接着他又加上：<span style="color:#800000">*人人的心都必战兢。*</span> [^f232] 各人都要如此被自己的愁苦所占据，以致无暇顾念邻舍。

<!-- PAGE 403 -->
**5.** <span style="color:#800000">*我心为摩押哀号。*</span> 他终于取了哀哭者的口吻。但有人也许以为，他为摩押人的灾祸哀哭，是奇怪而不相称的事；因为他理当哀悼教会的毁灭，反倒为教会仇敌的倾覆而欢喜。然而，先知们惯常如此取用那些将遭灾祸之人的口吻，如同在舞台上把他们的处境活现出来；这样一来，比直截了当地施教更能激起人心的震动。不过，毋庸置疑，先知们对神的审判——甚至是对恶人的审判——是战兢畏惧的；只是我上面所述的意思更为简明贴切，并且从先知书中屡见的用法就可轻易推知。

<span style="color:#800000">*所以他的贵胄逃到琐珥，*</span> [^f233] <span style="color:#800000">*像三岁的母牛犊。*</span> 他称那些从其中逃脱之人为**逃亡者**；因为他的意思是，凡从摩押逃脱的必一直来**到琐珥**。 [^f234] 如今他把**琐珥**比作<span style="color:#800000">*三岁的母牛犊*</span><span style="color:#800000">，</span>正当壮盛之年，未曾经历生产之苦、未受劳役、未负轭，只在欢乐与放纵的畅快中恣意而行。人被入侵之军紧紧逼迫时，便逃往那些尚未受攻击、看来离危险最远的城邑。**琐珥**正是这样的城，因为它从未被仇敌攻击过。不过，若有人认为更好是把这话看作指整个地区，我也不反对；因为耶利米似乎是笼统而言，尽管他从以赛亚那里取用了许多话语。（耶利米书 48:34）但或许在那处经文中，他也同样提到**琐珥**与**何罗念**，或更确切地说，是指二者之间的全境。

你若把它推及全国，意思便是：「摩押人一向享尽奢华，样样丰裕，至今未受过困苦。由此生出他们的顽梗；为要制服他们，就必须把他们放逐、驱赶，直到**琐珥**。」如今**琐珥**是离摩押人极远的一座城；因此他的意思是，他们除了**逃**往远方之外，无从保全自己。这里凡蒙主温柔相待的人都受了教训：不可自高，不可以放纵激怒神，倒要在最高的兴盛之中仍存谦抑，并且预备好面对一切变迁，以待主喜悦将他们从兴盛中抛下的时候。

<span style="color:#800000">*人上鲁希坡。*</span>他描述摩押境内其余的地方，并刻画那要遍及全地的逃亡与哀号的景象。

<!-- PAGE 404 -->
<span style="color:#800000">*在何罗念的路上，他们必发出毁灭的哀声。*</span>我们译作*他们必发出哀声*的这几个字，有人译为*他们必因哀号而使自己受伤*或*折断自己*，认为字母有换位，且<span style="color:#008080">[</span>（*ain*，阿因）重复了一次；如此，这动词的字根就当是<span style="color:#008080">h[r</span>（*ragnah*，拉格纳）。但因这对经文的意义无甚差别，我便沿用一般公认的看法，即<span style="color:#008080">wr[[y</span>（*yegnogneru*，耶格诺格努）出自动词<span style="color:#008080">rw[</span>（*gnur*，格努珥）。倘若有人更喜欢把这动词解作*折断*，其意思便是：「必有震颤，肢体仿佛*折断*，臂膀彼此相撞。」

**6.** <span style="color:#800000">*宁林的水。*</span>他以夸张的说法，更加扩大地描绘这场荒凉。他说*青草枯干了*，这是在神使某处土地失去一切滋养时所发生的事。*水*必被夺去，而这水对那干旱焦渴之地想必是极为必需的；因为那样的土壤若无灌溉，便一无所出。虽然文体是夸张的，所陈述的却无一不是严格真实的；因为先知并未越过合宜的界限，只是为迁就百姓的愚昧，不得不使用大胆的措辞，好叫他们知道：一块被夺去神赐福的土地，必如旷野一般，毫无美丽可言。

**7.** <span style="color:#800000">*因此，他们所积蓄的。*</span> [^f235] 这与通常的说法相符，(*Ce qu’il aura espargne*，)即*凡他所省下的*。他所指的是储藏起来的财富，并且描述了那些被敌人侵入的国家中常有的情形。一切居民都习惯把自己的财富运往别处，藏在某个安全的地方，以便日后和平恢复时再取回来。

<span style="color:#800000">*到柳树河。*</span> 他的意思是，他们将没有仓库，没有堡垒可以让他们安然存放这些财物；以致他们被迫把这些藏在*柳树*之间。当敌人正攻击我们，而我们竟找不到一个仓库来存放那些我们极其辛勤积攒之物时，这实在是最深的悲惨。这些*柳树*大概长在某个偏远隐僻之处。另有人解释为指着敌人说的，就是他们要把掠夺所得的果实带*到河边*，好在那里彼此分取公共的掳物。

**8.** <span style="color:#800000">*哀声遍闻摩押的四境。*</span> [^f236] <span style="color:#008080">yk</span>，(*ki*，)即*因为*，是为文辞的修饰而加上的。他的意思是，那地四围的每一处都将充满*哀声*与*哀号*；因为那毁灭从一端延伸到另一端。除了*哀声*之外，他两次提到*哀号*，为要表明忧伤之极，正如陷于绝望中的人全然把自己交付于哀哭一样。

<!-- PAGE 405 -->

**9.** <span style="color:#800000">*底们的水充满了血。*</span> [^f237] 这里他所描述的，不仅是*悲哀*与哀号、逃亡或战兢，也不仅是仇敌贪图掠夺他们财物的贪婪，而是人的被杀。当那些又大又壮丽的河流——如<span style="color:#800000">*底们*</span>——都<span style="color:#800000">*充满了血*</span>时，这杀戮该是何等巨大！

<span style="color:#800000">*我还要加增底们的灾难。*</span> [^f238] 他所说的*加增*，意思是：那位藉他之口说话的耶和华，必使杀戮倍增，以致尸首堆积如山，残酷与屠杀永无止息。如今，虽然亚述人在这场杀戮中甚是残忍，耶和华却并不残忍；因为他公义地惩罚摩押人的野蛮，他们本当怜恤犹大人，却卑劣地如此待他们。他们从前如何加害于人，如今理当受同样的惩罚。

<span style="color:#800000">*叫狮子来追上摩押逃脱的民。*</span> 这些也是他所说的那些*加增*的灾难，或至少是其中的一部分。这可视为那场灾祸的最后一击；以致若有敌军中的零散人马企图逃走，从杀戮中脱身，他们就要遭遇*狮子*[^f239]和野兽，被它们所吞吃。他说：「他们固然要从杀戮中逃出性命，但并不因此就得安全，也不能逃脱神的手。」若我们仔细察看整段的旨意，这正是先知真正的意思；因为他要加深那场惨痛灾祸的描绘，便补充说：即便从杀戮中被救出的那一小群余剩之人，也必落入*狮子*的口中。耶和华的手如此追讨恶人，使他们无路可逃；因为他们若躲过一样危险，立刻就遇上另一样。让我们记住，先知说这些话是为了安慰敬虔人，使他们的心得着某种应许作坚固，以抵挡仇敌的残忍；这些仇敌终必被灭，无论在他们的众神那里、在堡垒中、在藏身之处，或在逃亡之中，都寻不到避难所。
