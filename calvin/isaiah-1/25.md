# 第二十五章

<p style="text-align:center" markdown="1"><span style="color:#000080">前往 以赛亚书 25:1-12</span></p>

**1.** <span style="color:#800000">*耶和华啊，你是我的　神。*</span> 直到此处，以赛亚一直在预言神的审判，那些审判所威胁的不只是一个民族，而几乎是全世界。既然如此，他所预见的那些惨烈无比的灾祸，其思想不可能不使他大为不安；因为敬虔人愿意全人类都得救，他们既尊崇神，也愿意爱一切属乎他的；简言之，一个人越是真诚敬畏神，他对神的审判就越有强烈而活泼的感受。恶人面对神的审判虽惊愕失措，却不因任何恐吓而动心；敬虔人却因他忿怒最微小的兆头而战兢。我们尚且如此，何况这位先知——他所预言的那些灾祸几乎就在他眼前——我们想他心中的感受又当如何呢？因为，为使圣道的仆人们确信自己所传讲之事的确实性，他们所受的感动必须比一般人更为深切。

所以，既然主如同在一幅图画中把那些可怕的灾祸摆在以赛亚眼前，他在悲痛与忧虑的压倒性重压之下，就不得不投奔于主；否则他心中纷乱的情绪必要使他不胜其扰。因此，他从这一信念中得着勇气：在这些风暴之中，主仍定意促进祂教会的益处，并使那些从前疏远祂的人归服于祂。所以以赛亚在他的呼召上坚定不移，不容自己被引离本分，反而不断倚赖对怜悯的期待，因此持续不懈地颂扬神的赞美。由此我们看出，这段感恩与前面的预言是相连的，以赛亚所思量的不只是他所预言的事，更是主为何如此行；就是说，主为何以各种灾祸击打这么多的国民。这是为要制服那些从前不可救药、以禽兽般的贪欲横冲直撞、心中不惧怕神、毫无宗教与敬虔之感的人。

<!-- PAGE 558 -->

<span style="color:#800000">*你是我的神。*</span>他仿佛在困惑与纷乱之中，忽然把思念举向神，正如我们已经说过的。由此我们当引出一条极有用的教义，就是：当我们的心因每日临到的许多苦难与患难，被种种不安的思虑所困扰时，我们当立即投奔于神，倚赖祂的护理；因为若我们不投奔于祂，不用这教义扶持自己的心，就连最小的灾祸也必压倒我们。为要更充分地表明先知的意思，可以适切地插入「但是」或「然而」一词，如此说：「无论从那方面来的试探怎样搅扰我，然而我要承认你是我的神。」他这样应许要把当归给神的赞美归给祂；而这是不可能的，除非对祂恩典的坚定信念住在我们心里并且占据上风；从这恩典生出喜乐，当我们确知自己的救恩、并完全确信主是我们的神时，这喜乐就为我们提供了最丰富的赞美之根据。因此，凡毫无渴慕赞美神之心的人，就是未曾相信、未曾尝过神恩慈之味的人；因为我们若真正信靠神，就必被引导以颂赞祂的名为极大的喜乐。

<span style="color:#800000">*因为你已经行过奇妙的事。*</span>他用<span style="color:#008080">פלא</span>（*pele*，「奇妙」）一词，是以单数代替复数。先知并不把眼光局限于事物目前的状况，而是注目于结局；因为就连在别的方面属于外邦人的人，也在世界的治理中看见惊人的事件，那景象使他们惊骇不已；这无疑曾发生在推罗与西顿的居民，以及巴比伦人和摩押人身上。但唯有那些尝过祂恩慈与智慧的人，才能从神的作为中得益；因为不然的话，他们就轻看、藐视祂的作为，也不明白其中的卓越，因为他们看不见其结局，就是：神奇妙地从黑暗中带出光明（哥林多后书 4:6），使祂的教会从死里复生，并以最美善的方式安排、以最宝贵的目的引导那些在人眼中看来纷乱无序的事。

<!-- PAGE 559 -->
<span style="color:#800000">*古时所定的旨意。*</span> [^f393] 如今，为了更高地称颂神的护理，他补充说，这些「旨意是古时早已定下的」；仿佛他是说，在神那里没有什么是突然的或未曾预见的。诚然，虽然祂有时在我们看来是突然行事，然而万事无疑在创世以先就已被祂命定了。（使徒行传 15:18）因此，使徒用这句话的意思是：一切出乎人意料而发生的奇事，都是神治理世界时所维持之定序的结果，祂从始至终安排一切。既然我们不明白那些隐秘的旨意，我们的悟性也无法升到那样的高度，所以我们的注意力必须转向这些旨意的显明；因为它们向我们隐藏，超出我们的领悟，直到主藉着祂的话语将它们启示出来，在其中祂俯就我们的软弱；因为祂的旨意乃是（<span style="color:#0000d4">ἀνεξεύρητον</span>，不可测度的）难以查究的。

<span style="color:#800000">*坚定的真实。*</span> [^f394] 先知就这样从神永恒的旨意进而论到教义与应许，他无疑是用**真实**一词来指明这些；因为若这词不含某种关联的意思，这种重复就成了轻浮无益的了；因为当神向我们启示了祂的心意，我们若信祂所说的话，祂便实在显为真实。当他说这是「坚定的真实」时，他是在称许这话语的坚固与确定；也就是说，凡从神而来的、凡由祂所宣告的，都是坚定不移的。

**2.** <span style="color:#800000">*你使城变为乱堆。*</span> 有些人把这话归于耶路撒冷；但我认为这里有单复数的转换，正如众先知常有的习惯；因为先知并非单指一座城，乃是指许多城，他说这些城必变为乱堆。至于有些人所持的看法，说罗马人使耶路撒冷成了宫殿，这与先知的意思毫不相干。先知的意思若我们记住前面已经说过的，就不难明白，就是：先知并不把他的思想局限于主用来击打列国的那些灾祸，乃是把眼光延伸到这些管教的终局。主定意要用这样的方式驯服并制伏人的顽梗；若不是被各样的苦难压碎，祂断不能使他们降服于祂。

<!-- PAGE 560 -->
<span style="color:#800000">*使外邦人宫殿的城，*</span> [^f395] <span style="color:#800000">*不再为城。*</span> 先知的意思并非仅仅是说：当本地居民被赶出之后，「外邦人」将要居住在那些被攻取的城中；因为这与他紧接着所补充的「不再为城」并不相合；他的意思乃是说，那些四处流荡、无处栖身的人群，将在那里找到宽阔的地方，因为已不再有居民留下。既然 <span style="color:#008080">ארמון</span> （*armon*）指的是华美的宫殿，先知便以讽刺的口吻说，由于那将要荒废之地极其广大，强盗劫掠之徒竟要如住在宫殿中一般安居其间。

**3.** <span style="color:#800000">*所以，刚强的民必荣耀你。*</span> 这就是我先前所提到的目的；[^f396] 因为若耶和华只是毁灭世界，便不会有什么美善的结果，实在说来，毁灭除了叫人惊惧之外不能生出别的情感，我们也决不会因此被引导去歌唱祂的赞美；反倒是，当我们所看见的只有忿怒时，我们必定要丧尽一切知觉。然而赞美却是从对恩典与良善的体会中涌流出来的。所以这就好像他说：「主啊，你不只是击打人、使人受苦，你还要使这些管教不至于徒然无效；因为你要藉着这些管教制伏人的凶暴，使那些从前与你疏远的人向你屈颈顺服。」这段经文应当引导我们思想：我们何等需要管教，因为管教训练我们顺服神；我们被顺境带偏到这样的地步，以致自以为凡事都可任意而行，甚至当神以温柔待我们时，我们反倒放纵狂傲、目无所畏。

<span style="color:#800000">*强暴之国的城必敬畏你。*</span> 先知接着提到*敬畏*，就表明这赞美并不在于言语或外表的姿态，而在于内心真诚的情感。由此我们推知，他此处所论的是对神全备的敬拜；但因为许多人以为自己一旦口里作了承认，便已完全尽了本分，他就为着解释的缘故补充说：「列国必敬畏你。」当他称他们为刚强有力的时候，他是用这些形容词来指出他们的骄傲与自大；因为他们因自己的顺境而自高自大。他们悖逆神，若不是被剥夺了一切，就不能被造成谦卑或顺服的人。因此，在我们所看见的那些灾祸之中，我们的思想正当被引向这样的领悟。人的凶暴必须被约束、被制伏，好使他们预备好领受教义、献上真实的顺服。只要他们仍被自己的财富与虚妄的自信所蒙蔽，他们就要毫无惧怕地讥笑神的审判，永不肯降服于祂。

<!-- PAGE 561 -->
**4.** <span style="color:#800000">*因为当穷人受欺压的时候，你作他的保障。*</span> 由此我们看见归正的果子，就是主叫我们从死里复起，仿佛把我们从坟墓中带出来，从天上向我们伸出手来，甚至把我们从阴间救拔出来。这就是我们初次得以亲近祂的途径，因为唯有在我们的贫穷中，祂才寻得施展祂慈爱的机会。因此，我们这一面也必须成为贫穷困乏的，才能从祂得着帮助；在祂为我们施展大能之前，我们必须撇下一切对自己的倚靠与自信。这就是祂用管教和十字架来眷顾我们的缘故，祂借此操练我们，好叫我们能够领受祂的帮助与恩典。

<span style="color:#800000">*作躲暴风之避难所，作避炎热的阴凉。*</span> 以赛亚用这些比喻来润饰这段描述，并非没有充分的理由；因为试探众多且形形色色，为要刚强地忍受这些试探，人软弱的心思必须得着坚固与强化。因此他说，神必"作穷人的保障，作躲暴风之避难所，作避炎热的阴凉"；因为无论威胁他们的危险与攻击具有何等性质，主必保护祂的百姓抵挡这一切，并供给他们各样的军装。

<span style="color:#800000">*强暴人（或凶暴者）的气息。*</span> 在本节中，正如在许多其他经文中一样（创世记 8:1；出埃及记 15:10；列王纪上 19:11），<span style="color:#008080">רוח</span>（*ruach*）意指"风的吹动"，表明恶人以何等可怕的猛烈之势冲击神的儿女；因为他们不但"口吐威吓凶煞的话"（使徒行传 9:1），甚至似乎要吐出火来。

<span style="color:#800000">*暴风雨*</span>或<span style="color:#800000">*催逼墙壁的洪流。*</span>这与前面所说的意思相同；因为先知借这比喻表明，恶人一旦得着为恶的机会，便如此猛烈地冲来，把一切拦阻他们的都推倒；因为倾覆并毁坏墙垣，比水仅仅漫过田地要厉害得多。

**5.** <span style="color:#800000">*好像干燥地的热气。*</span>当强暴的人向我们冲来时，若耶和华不施帮助，我们的性命便危在旦夕；因为我们看见恶人的暴怒何等厉害，而耶和华若使墙垣倾倒，一个软弱的人又能与他相抗吗？所以加上这些话，是为要显大神的恩典，使我们思想：若耶和华不施援手，我们将成为怎样。

<!-- PAGE 562 -->

然而解经者对这段经文有两种解释。有些人认为其意是：恶人必被神的忿怒所吞灭，正如炎热的猛威烧尽那本来就干旱不生的田地。另有人将其译为夺格，作<span style="color:#800000">*仿佛被热气所胜*</span>，并使其意思成为：「虽然恶人倚仗自己的势力如此猛烈，耶和华却必转眼将他们打倒，如同他们『在干燥之地被热气』所制服一样。」但我认为其意乃是另一层，因为先知在指明恶人向信徒所发的暴怒何等厉害之后，便接着说：

<span style="color:#800000">*耶和华啊，你必使他们降卑。*</span> 他借用先前所用的洪水之喻，说：“你必熄灭他们的炎热，那炎热本要吞灭我们，正如雨水或甘霖从天而降，浇灭那炙烤干渴田地的暑气。”这样，这段经文便畅然贯通；而另一种解释则是牵强附会，如俗语所说，是对字句的强解。

<span style="color:#800000">*他必使强暴人的喧嚷低微。*</span> [^f397] 这一句被人以各种方式曲解。有人认为 <span style="color:#008080">זמיר</span> (*zemir*) 意思是*种子*；另有人认为是*根*，好像他说，神不但要毁灭恶人，更要将他们连根拔除。若不是与「炎热」的比喻相抵触，这个意思本是可取的。因此，依我之见，另有些人解作「歌唱与呼喊」或「剪除」，倒更为正确，尽管那些解经者也未能完全把握先知的原意。所以，他是在确证前面所说的：恶人的暴虐，或他们狂傲放胆所发的喧嚷，转眼之间必被压下，正如烈日的炎热被降下的雨水所胜过，这就是*密云的影子*所指的意思。

<!-- PAGE 563 -->
**6.** <span style="color:#800000">*万军之耶和华必……设摆。*</span> 这段经文得着了各样不同的解释。有人认为，先知是在威吓犹太人，而其威吓的方式，乃是邀请列邦赴筵席。这种说法在别处经文中也可见到，因为经上说神养肥恶人，为要留到宰杀的日子。那些注释家认为，犹太人因其不敬虔，就如同被丢弃作外邦人的掠物，于是外邦人被邀赴筵；仿佛主说：“我已为外邦人预备了丰盛的筵席；罗马人必掳掠犹太人，以他们为食。”但依我之见，这样解释此段是不可接受的；既已提出真正的解释，我也就无须长篇驳斥了。另有人解释说，以赛亚在此讲论神的忿怒，其意如此：“主必为万国预备筵席；他要给他们喝他忿怒的杯，叫他们喝醉。”

但先知的意思却全然不同，因为他继续宣告神的恩典，就是那要借着基督降临而显明的恩典。他所用的比喻，与大卫描述基督国度时所用的相同，大卫说：

<p style="text-align:center" markdown="1"><span style="color:#000080">「谦卑的人必吃得饱足，</span> <span style="color:#000080">……地上一切丰肥的人必吃喝而敬拜。」（</span><span style="color:#000080">诗篇 22:26, 29）</span></p>

他用这比喻性的言语，是要表明没有哪一等人会被排除在这丰盛的供应之外。从前神似乎单单养育犹太人，因为惟独他们被收纳为子，可以说是被邀请赴他为自己家人所预备的筵席；但如今他也接纳外邦人，将他的恩惠广施于万国。

<span style="color:#800000">*为万民摆设丰盛的筵席。*</span>他说*为万民*，其中含有暗示的对比，因为从前他只被一国所认识（诗篇 76:1）。「丰盛的筵席」是指用肥美牲畜所摆设的宴席。

<span style="color:#800000">*用陈酒作成的。*</span> [^f398] 有些人将希伯来文 <span style="color:#008080">שמרים</span>（*shemarim*）译作*渣滓*，但这并不准确，因为它的意思是「陈年的酒」，就是法国人所称的 *vins de garde*（「久藏之酒」），这样的酒胜过普通的酒，在东方地区尤其如此，因为那里的酒更耐存放。他称之为不含渣滓或沉淀的清液。

<!-- PAGE 564 -->
总之，这里显然可见，他并非在此威吓外邦人或犹太人必遭毁灭，而是邀请双方一同赴极其丰盛的筵席。从基督自己的话中，这一点更加明显；他将天国比作君王为儿子摆设的婚筵，无一例外地邀请众人，因为起先被请的人不肯来（马太福音 22:2, 3）。我也毫不怀疑他所说的是福音的传扬；因福音从锡安山而出（以赛亚书 2:3），所以他说外邦人必来赴筵；因为当神将喂养灵魂的属灵食物摆在全世界面前时，其含义正如同他为众人预备了一席。今日主也邀请我们，要将美物充满我们、使我们饱足；他兴起忠心的仆人为我们预备那筵席，并赐他的话语能力与功效，使我们因此得着饱足。 [^f399]

<span style="color:#800000">*在这山上。*</span> 至于*山*这个字，虽然神的仆人如今不再从山上出来喂养我们，然而我们必须以这名称来理解教会；因为除此以外，无人能在别处得享这食物。那筵席并不摆设在街市与大道上，那桌子并非到处都摆着，这盛筵也不是在各处预备的。我们若要赴筵，就必须到教会里来。之所以提到那地方，是因为惟独在那里神受敬拜，启示也从那里发出；正如福音也是从那里传出来的。他说这筵席必是肥甘丰盛的，其用意乃是称许福音的教义；因为这是我们灵魂所得的属灵食物，其甘美精妙，以致我们再不需要别的。

**7.** <span style="color:#800000">*他必除灭那遮盖之物的表面。*</span> [^f400] 在此解经者们也有分歧，因为有人以*遮盖*一词指信徒在今世所蒙受的羞辱，以致神的荣耀在他们身上不得显现；仿佛他说：「虽有许多辱骂压制敬虔人，然而神必除去那些羞辱，使他们的境况变为荣耀。」我略过其他的解释；但依我看来，真正的意思乃是：主应许祂必除去那使他们停留在瞎眼无知之中的帕子；因此正是藉着福音的光，这黑暗才被驱散。

<!-- PAGE 565 -->
<span style="color:#800000">*在这山上。*</span> 他说这事必在锡安山成就，正如我们已经看见的，道的光也是从那里照亮全世界。（以赛亚书 2:3）所以这段经文必然要归于基督的国度；因为直到公义的日头基督兴起（玛拉基书 4:2），光才照在万人身上，是祂除去了一切的帕子、包裹与遮盖。在此我们又得着福音的一项称许，就是它驱散黑暗，除去我们眼上谬误的遮盖。由此可见，在我们未被福音的教义光照之先，我们乃是被无知的黑暗所笼罩、所蒙蔽；惟独藉着福音，我们才能得着光与生命，得以完全复原。在此我们也得着外邦人蒙召——就是我们蒙召——的确证；因为不但犹太人，连从前埋没在各样谬误与迷信之中的万国，也都被邀赴这筵席。

**8.** <span style="color:#800000">*他已经吞灭死亡直到永远。*</span> [^f401] 先知继续他的主题；因为他总体上应许说，在基督的国度之下必有完全的福乐，并且为要更充分地表达这一点，他运用了各种极为贴切的比喻。那福乐是真实的，而非暂时或衰残的，甚至连死亡也不能夺去；因为即使在最兴盛的境况中，一想到这福乐不能长存，我们的喜乐便大为减少。因此他把两件使福乐得以丰满完全的事联结起来。第一是生命是永存的；因为对那些在其他方面暂时享福的人而言，终必死亡是可悲的事。第二是这生命伴随着喜乐；否则人或许会以为，与一种忧愁困苦的生活相比，死亡倒是更可取的。他接着又补充说，当一切羞辱都被除去之后，这生命将是荣耀的；否则，鉴于这百姓所受的悲惨压迫，人对这预言便不会那样信服了。

但有人要问，这些应许应当归于哪一个时期呢？因为在这世上我们必须与各种苦难争战，必须不断地打仗；我们不但「终日被杀」（诗篇 44:22），而且「天天冒死」（哥林多前书 15:31）。保罗为自己和教会的柱石们诉苦说，他们「成了一台戏，给世人观看」，忍受各种侮辱，甚至被人看作（<span style="color:#0000d4">καθάρματα</span>）「污秽之物」和（<span style="color:#0000d4">περιψήματα</span>）「擦拭之物」，或「渣滓」。[^f399]（哥林多前书 4:9, 13）那么，这些事在何处、何时得着应验呢？毫无疑问，它们必须归于基督普世性的国度；——我说「普世性的」，因为我们不但要看它的起头，也要看它的成全与终局：如此，它就必延伸至基督的第二次降临，因此那日被称为「得赎的日子」和「万物复兴的时候」；因为现今看来一切混乱的事，那时都要完全得着复兴，并呈现新的形态。（路加福音 21:28；使徒行传 3:21；罗马书 8:23；以弗所书 4:30）这预言无疑与从巴比伦得释放有关；但因那次拯救可视为另一次拯救的凭据与预尝，所以这应许必须延伸至末日。

<!-- PAGE 566 -->

因此，让我们把一切盼望与期待都指向这一点，并且不要怀疑，当我们跑完当跑的路程时，主必在我们身上成就这一切事。我们如今若「流泪撒种」，将来必定要「欢呼收割」，满心欢喜。（<span class="ages-code">&lt;19C605&gt;</span>诗篇 126:5）我们不要惧怕人的侮辱或辱骂，这些将来有一日必为我们博得最高的荣耀。既然我们在此已经得着这福乐与荣耀的初步——藉着被神收纳为儿子，并开始承载基督的形象——就让我们坚定不移、毫不动摇地等候末日那完全的成全。

<span style="color:#800000">*因为这是耶和华说的。*</span>在经历了如此众多可怕的灾祸之后，人或许会认为这样的事情实在难以置信；因此先知指明，这话不是出于人，乃是出于神。当耶路撒冷被倾覆、对神的敬拜被夺去、圣殿被毁坏、余剩的百姓遭残暴的暴政压迫之时，没有人会相信万事竟能恢复到起初的光景。人心极易倾向于这种不信，故此必须与之争战；所以先知坚定并印证这些应许。

<p style="text-align:center" markdown="1"><span style="color:#000080">「要知道，这些宣告乃是神传给我的；所以当将你们的心思定在他身上，而不是定在我身上；愿你们的信心倚靠那位</span> <span style="color:#000080">『不能说谎』、不会欺骗的神。」（</span><span style="color:#000080">提多书 1:2）</span></p>

**9.** <span style="color:#800000">*到那日，人必说。*</span>动词 <span style="color:#008080">אמר</span>（*amar*）是不定式的，即「他必说」；但因这段话所论的不是某一个人，而是众人，故我选择以被动的形式来翻译。[^f403] 这是极美的结语；因为它显明神的恩惠绝无任何可疑或不确定之处，乃是真实地为人所领受、所享受的。先知宣告，他先前所说的筵席（第6节），神预备它绝不徒然；因为人必在其上享受盛筵，并得着永远的喜乐。

<!-- PAGE 567 -->
<span style="color:#800000">*看哪，这是我们的神。*</span>他所宣告将成为公开之事的那欢呼之声，可以说正是对神恩典之经验的实际检验与凭证。这段话应当仔细留意；因为先知表明，将有这样一种启示，能使人的心思定在神的话语上，以致他们毫无迟疑地倚靠它；而这些事若确实属于基督的国度——它们无疑是属于的——我们便从其中得着这宝贵的果子：基督徒除非亏负自己、弃绝神的恩典，否则便拥有确凿无疑的真理，可以安然倚靠。神已除去一切可疑之地，并这样向他们启示了自己，使他们可以坦然宣告：他们确知何为神的旨意，并可以真实地说出基督对撒玛利亚妇人所说的话：「我们所拜的，我们知道。」（约翰福音 4:22）我们既从福音得知那藉基督所赐的恩典，如今就不再像别人那样在不确定的意见中漂流，而是拥抱神和对他纯正的敬拜。让我们放胆宣告：「一切人的臆造，都当除去！」

我们应当留意这一对比：列祖在律法之下所享的那种幽暗而微弱的知识，与在福音中向我们照耀的那种丰盛。神虽俯就他古时的百姓，赐下属天教义之光，然而他却藉着基督更亲切地使人认识他，正如经上所说：「从来没有人看见神，只有在父怀里的独生子将他表明出来。」（约翰福音 1:18）先知在此高举神的儿子藉他降临所带给我们的那种确定性，就是当他「将父显给我们看」的时候。（约翰福音 14:9）然而，我们在这方面虽胜过古时的百姓——即藉基督所成就的和好使神仿佛对我们更加恩慈——但除了藉着基督，就再无别路可以认识神，因他是「神本体的真像」。（希伯来书 1:3）「不认识子的，就不认识父。」（约翰福音 14:7）犹太人、回教徒和其他不信者虽夸口说他们敬拜创造天地的神，实际上他们所拜的却是一个想象中的神。他们无论怎样固执，所随从的都是可疑而不确定的意见，而非真理；他们在黑暗中摸索，敬拜自己的臆想，而不是敬拜神。总而言之，离了基督，一切宗教都是虚假的、转眼即逝的，一切敬拜都当被厌弃并放胆定罪。

<!-- PAGE 568 -->
先知不但用副词*看哪*，也用指示代词*这*，[^f404] 这并非没有充分的理由，乃是为要更充分地证实神的临在；正如稍后他又重复那确定与信靠的宣告，藉此表明那些将要藉基督敬拜神之人身上所必有的坚定不移。诚然，我们不能在神的威严中领会他，因他「住在人不能靠近的光里」（提摩太前书 6:16），我们若试图上升到那光中，立刻就要被压倒；因此他俯就我们的软弱，藉着基督将自己赐给我们，并藉着基督使我们得以有分于智慧、公义、真理和其他福分。（哥林多前书 1:30）

<span style="color:#800000">*这是耶和华。*</span> 值得注意的是，当他称基督为信徒的神时，他将「耶和华」之名归给他；由此我们推断，神真实的永恒性乃属乎基督的位格。此外，既然基督已藉着福音如此向我们显明自己，这就证明那些人是何等可耻地忘恩负义——他们不以如此丰full的启示为满足，竟敢在其上添加自己无谓的臆测，正如教皇制所行的那样。

<span style="color:#800000">*我们素来等候他。*</span> 他表达了那些一旦在基督里持定神之人的坚定与恒忍；因为这不该是一时的认识，我们必须坚定不移地持守到底。如今，以赛亚是以古时教会的名义说话，那教会当时严格说来仅设立在犹太人中间；因此，他仿佛藐视其他各国所敬拜的一切神明，大胆宣告：唯有那位向亚伯拉罕显现（创世记 15:1）、并藉摩西的手颁布律法（出埃及记 20:1, 2）的，才是真神。其他陷在无知黑暗中的列国并不「等候」耶和华：因为这「等候」乃出于信心，而信心又与忍耐相伴，且没有道就没有信心。

如此，他警戒信徒：他们的救恩系于盼望与等候；因为神的应许在基督降临之前，仿佛悬而未决。此外，我们应当留意当时的光景；因为那时看来，神的应许似乎已归于虚空，或神已弃绝了亚伯拉罕的后裔。诚然，尽管他们极目远望，神在那时却未向他们显现；因此，他们必须被赋予惊人的忍耐，方能忍受如此沉重而尖锐的试探。故此，他吩咐他们安静等候基督的降临；因为那时他们必清楚看见，神与敬拜他的人是何等亲近。

<!-- PAGE 569 -->
今日同样的教义也当抚慰我们，使我们虽然救恩尚被隐藏，仍能以坚定不摇的盼望「等候耶和华」，甚至在他远离之时，也常说：<span style="color:#800000">*看哪，他在这里*</span>。在极其混乱的时候，我们要学会凭这记号认出他来：<span style="color:#800000">*这是他*</span>。[^f405] 至于用词，虽然他用的是过去式，[^f406]「我们必因他的救恩欢喜快乐」；然而这些字眼表示一种持续不断的行动；而且稍前他曾用将来式说：「他必拯救我们。」其要义可归纳如下：「基督绝不叫他子民的盼望落空，只要他们忍耐呼求他。」

**10.** <span style="color:#800000">*耶和华的手必按在这山上*</span>。我毫不怀疑，先知在本节开头的用意是要安慰敬虔人；若非如此，他们必以为神已离弃、撇下他们了。有人认为这是描述主将要施行在犹太人身上的审判，此见解全无根据；这里的意思无异于说：主必永远扶助他的教会。我知道「神的手」也按在被弃绝的人身上，因他不停止以报应追讨他们，直到将他们完全倾覆；但此处「手」字乃指帮助，而非管教，因此「按在」（rest，安歇）一词乃指防卫或保护的不间断持续。

我们由此得着一项有益的教义：神虽将无数恩惠遍施于全世界，甚至恶人也分得其中一份，然而他的「手」并不「安歇」于别处，或说并非时常临在别处，唯独在那圣*山*上，就是在教会中，在敬拜他的地方。也当注意，耶路撒冷在领受这些福分之前，曾受过管教；因为他先前曾威吓要施行管教与刑罚，随后才加上这安慰。

<!-- PAGE 570 -->
<span style="color:#800000">*摩押必被践踏在他下面。*</span> 在这一句中，他进一步展示了神的恩典；因为神藉着刑罚教会的仇敌，要显明他何等珍视教会的拯救。犹太人没有比摩押人更凶恶的仇敌，虽然他们的先祖 [^f407] 本是近亲。他用提喻法（<span style="color:#0000d4">συνεκδοχικῶς</span>，以部分代全体），在这名下包括了教会一切的仇敌，尤其是那些与他们有些亲缘关系、却比众人更为毒害的人。他表明，虽然这些人一时得胜、欺压教会，但最终必受刑罚。他的用意是，叫信徒在患难之中不要灰心丧胆，仿佛自己的境遇甚是不幸，而恶人却欢欣亨通；因为此处所说的「践踏」很快就要临到。所以，倘若我们今日看见教会被那些与我们有些亲缘关系、甚至僭取教会之名与称号的人所搅扰、所压制，就让我们以这应许来安慰自己的心。

<span style="color:#800000">*好像干草被践踏在粪池中。*</span> [^f408] 我们译作「粪堆」的 <span style="color:#008080">מדמנה</span>（*Madmenah*，玛得米那）一词， [^f409] 有些人认为是一座城的名字，耶利米书中也曾提到（耶利米书 48:2）。但我们何不这样说：先知在此暗指那座城——它极可能座落在肥沃之地——因而所传达的责备更为严厉，对摩押人的压迫也更为沉重？就好像他说：「正如干草在他们的田间被践踏，耶和华也必如此践踏摩押人。」我并不反对别的解释，但认为他暗指那城所在之地的肥沃，并非不可能。不过在我的译文中，我仍毫不迟疑地采用了通行的看法。

**11.** <span style="color:#800000">*他必伸开手。*</span> 先知现在解释并印证前面的话；但他所用的比喻不同，藉此表明耶和华必将他的手伸到摩押境内最深之处，而不仅仅是伸到其边界。有人这样解释这比喻：「如同人游泳时伸展双臂，耶和华也必从四面管教摩押人。」另有人认为这是表达刑罚的加倍，就好像他说：「耶和华不但要刑罚摩押人，并且要一再地为他们向神的儿女所行的残暴施行报应。」

不过，我们也可以用另一种方式来解释这个比喻。游泳的人并不是以极猛烈的力量向前冲，而是轻缓地张开双臂，又迅速地收回，然而他们却划开并制伏了水流。照样，主并不总是施展大能来剪除恶人，乃是毫不费力，不用军队，不发任何声响与喧嚷，就毁灭他们、使他们溃逃，无论他们看来何等勇猛、何等严阵以待。我赞同这一解释，因为它丝毫无损于前面所讲的意思，并且更清楚地说明：恶人常常在神的手下归于无有，虽然祂并未从天上公然发出雷声。当祂说「<span style="color:#800000">*在其中*</span>」时，就表明必无一处能隐藏得住，以致不被这刑罚追上。

<!-- PAGE 571 -->

**12.** <span style="color:#800000">*你墙上的堡垒。*</span>先知现在把话转向摩押地。那地防御森严，以其城墙和堡垒为夸耀；先知却断言，那些高台和其他防御工事，无论何等坚固、看似何等不可攻破，都必毫无用处。众所周知，古人筑城设防的方法与我们今日所行的大不相同。

<span style="color:#800000">*祂必使之倾倒、坍塌、坠落于地。*</span>此处所用的三个词，为要更有力地传达其意，并非多余；因为必须打掉那使摩押人心中膨胀的骄傲，正如我们从前所见的[^f410]，这骄傲使他们令人难以忍受。所以先知讥讽他们说：「仿佛耶和华不能把你们所夸口的那份高傲拆毁似的！」

<span style="color:#800000">*成了灰堆。*</span>这一句的意思，仿佛他说：「祂不但要将它夷为平地，更要使它化为*灰尘*，甚至连昔日废墟的痕迹也不复存留。」这段经文包含着极佳而又极合时宜的安慰；因为今日教会的仇敌何等骄横，他们不但讥诮世人，甚至讥诮神自己，又因自己的势力而膨胀自满，自以为不可战胜；然而，面对他们的堡垒与防御，我们当高举先知的这一宣告：「主必迅速将他们倾覆，使他们卑微。」不过，在他们毁灭的时候未满之先，我们必须存忍耐的心，看着他们强盛有力。
