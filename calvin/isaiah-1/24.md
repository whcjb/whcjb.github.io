# 第二十四章

<p style="text-align:center" markdown="1"><span style="color:#000080">前往 以赛亚书 24:1-23</span></p>

**1.** <span style="color:#800000">*看哪，耶和华使地空虚。*</span> 据我所能判断，这段预言乃是自第十三章以下所有描述的总结；在那些章节中，以赛亚不但向犹大人和以色列预言毁灭，也向摩押人、亚述人、埃及人以及别的列国预言毁灭。简言之，他仿佛已巡视了犹大人邻近并为他们所知的一切邦国，如今便将全部内容作一简要的总括。有人认为这是指以色列说的，有人则认为是指犹大人说的，以为这里所预言的是他们的毁灭；但既然他提到*世界*，我就只能视之为他先前在不同时候论到各国之事的总括性宣告。他随即提到*祭司*，这似乎会使我们以为这些事只关乎神的百姓，然而这并不与上述看法相抵触；因为他虽论及万国，但犹大人始终居于首位，以赛亚必定特别注目于他们，因他是奉差遣向他们说话的。可以说，他提到别国乃是附带的；因此，我们不必希奇，他在提及列国之后，又用一句话特别论到自己的百姓。

<!-- PAGE 538 -->
另有人认为他所指的是「全世界」，但以为他所论的是末日，我看这解释未免过于牵强；因为先知在威吓犹太人和列国之后，随即加上安慰的话，说主有一日必兴起他的教会，使她更加兴旺；这显然不能指末后的审判。至于**地**这个词，我认为先知并非指整个世界，乃是指犹太人所熟知的那些地区；正如今日我们谈论世上所发生的事时，几乎从不越出欧洲之外，也不想到印度正在发生什么；因为这可以说就是我们的世界。因此，以赛亚所说的「地」，是他自己和他所对之说话的众人所知道的地，是居住在邻近各地的百姓。简言之，我们可以把「世界」一词限定为埃及人、亚述人、摩押人、推罗人及诸如此类的民族；仿佛他说：「到此为止我已论及各样的灾祸，威吓许多国民；其中有些至今仍在威吓之下；但我可以一言以蔽之：『耶和华必使地倾覆，剥去地面一切的妆饰。』」

<span style="color:#800000">*使地荒凉。*</span> [^f378] 有人把 <span style="color:#008080">בלקה</span>（*bolekach*）译作*他揭开地*，好叫仇敌得以长驱直入。但我宁愿译作「他使地赤露」，因为当地上住满众多的人、五谷丰登、牛羊遍野时，就说地被「遮盖」；而当地上的居民被除去、遮盖它的被夺去时，就说地被「揭开」或「赤露」，好像一个人被剥去了衣裳与装饰一般。如今这事不单临到犹太人，也临到亚述人、埃及人，以及他所提及的其他国民；因此他向他们众人一同宣告毁灭。

**2.** <span style="color:#800000">*那时。*</span> 他用这些话表明极度的荒凉，其中再无尊卑等级之分，也无国家政体的形迹；因为只要政体尚存些许秩序，「百姓」与「祭司」之间总还保持某种区别。他借提喻法（<span style="color:#0000d4">συνεκδοχικῶς</span>，以部分代全体）举出一类以代整个阶层，这在圣经中是常见的；不过我们也可以把 <span style="color:#008080">כחנים</span>（*kochanim*）理解为居高位的人，因为希伯来作者常以此名称呼首领，尤其是那些出于王室血脉的人；但我并不反对视之为我上面所说的那种修辞用法。

<!-- PAGE 539 -->
既然以赛亚将这种混乱列在神的咒诅之中，并宣告说：当尊卑的分别被废弃时，这正是神报应的可怕显现；那么在另一方面，我们就当由此推断，神是何等喜悦正当的治理与社会的良好秩序，并且这秩序得以在我们中间保存，是何等大的恩惠。因为当秩序被除去时，人的生活与牛群和猛兽的度日就相差无几了。因此，每当神拆毁秩序、除去教导和法庭之时，我们不但当承认神那可畏的报应，也当归咎于我们自己的罪；因为这些一旦倾倒，文明本身也随之倾倒。还当思想：当主施行审判时，他不宽容任何等级，连最神圣的等级也不例外。祭司这一等级究竟是什么？主曾如此荣耀地装饰它，定意将它分别为圣归给自己，百姓也以它自夸，仿佛它是不可变更、永远长存的。然而连祭司的职分也被卷入神的审判之中，因为神并不以貌取人；恰恰相反，凡蒙恩越大、被高举的地位越尊的，若显出忘恩负义、滥用他的恩惠，他刑罚他们也必越严厉。

<span style="color:#800000">*仆人怎样，主人也怎样；买物的怎样，卖物的也怎样*</span>这句话与前面所说的意思相同；因为这些等级显然是合法的，而且通常不会被废除，除非主定意以可怕的报应管教他的百姓，正如我们已经说过的；因为在秩序良好的社会中，主人与仆人之间的分别必须得以维持。同样，没有商业往来，任何公共政权都不能长久；因此，当贫富之间的分别被除去时，人们赖以维生的一切营生也就毁灭了。先知的意思是：一切公民治理都将瓦解，因为在这样的灾祸中，从前最富足的人也沦为极度贫穷。总之，他所描绘的是最令人惊骇的荒凉，随之而来的乃是前所未有的变动。

**3.** <span style="color:#800000">*地必全然空虚*</span>他证实先前所说的话，并宣告这些变动并非偶然发生，乃是神的作为。在第一节中，他已明确指出神正在预备使地空虚；如今他断言这事必要发生，并加上理由：因为神已定意、已决意如此行。

**4.** <span style="color:#800000">*地上悲哀。*</span> 以赛亚继续他的主题；因为这一切都是要说明全地的荒凉，就是犹太人所知的那个世界的荒凉。照他惯常的作法，他用比喻更清楚地描绘神的审判，因为这些比喻最能触动迟钝的心。

<!-- PAGE 540 -->
<span style="color:#800000">*地上居高位的人。*</span> [^f379] 所谓「居高位的人」，我们当理解为那些地位比别人尊贵的显要人物；因为这比平民百姓的倾覆更为惊人。不过，若有人认为把它专指犹太人更为可取，我也不反对；因为虽然亚述人和埃及人在财富与权势上胜过他们，但犹太人在这一点上却居于最高的地位，就是他们已蒙神收纳为儿子。然而我更倾向另一种解释，即其意思是：耶和华不但要刑罚平民百姓，也要刑罚那些在地位与荣华上超越众人的人。

**5.** <span style="color:#800000">*地被其上的居民污秽。*</span> [^f380] 另有人译作「被玷污」或「被污染」，因为 <span style="color:#008080">כנף</span>（*chanaph*）意为「行邪恶」。两种译法都可以说得通；但下一节似乎要求我们把它解作*虚假*；因为他随即似乎更充分地阐明并展示了这一点，就是当他说「地被咒诅吞灭」的时候。

<span style="color:#800000">*在其上的居民之下。*</span> 无论把 <span style="color:#008080">תהת</span> (*tahath*) 译作「<span style="color:#800000">*在其上的居民之下*</span>」，或译作「*因着*其上的居民」，都无关紧要。土地与耕作者之间有一种彼此的契约，就是土地要把所领受的连本带利归还；若不如此，就是欺骗了那些耕种它的人。但先知说明了缘由，把罪责归于他们，因为是他们以自己的罪恶使地荒芜不产。地不供养我们、不结出果实——本来神已按自然的常序定规它当如此行——这乃是出于我们的过犯；因为神愿意地对我们如同母亲一般，供给我们食物。若地改变了它的本性与次序，或失去了肥沃，我们就当归咎于自己的罪，因为是我们自己颠倒了神所设立的次序；否则地绝不会欺骗我们，乃必尽它的本分。

<span style="color:#800000">*因为他们犯了律法。*</span> 他随即说明地何以对居民不忠、何以欺骗他们：这是因为那些不肯尊荣神——他们的父与养育者——的人，理当被夺去食物与养分。这里他特别使本国的背叛蒙羞，因为它比一切从未在神学校中受教之人的过犯更为可耻、更无可推诿。<span style="color:#008080">תורה</span> (*torah*) 一词被用来指「律法」，因为它含有教导之意；但此处用的是复数 <span style="color:#008080">תורת</span> (*toroth*)，指「律法」中所包含的一切教导。然而，既然「律法」既含命令又含应许，他便加上两部分加以解释。

<!-- PAGE 541 -->
<span style="color:#800000">*废了律例。*</span> 希伯来文 <span style="color:#008080">חק</span> (*chok*) 意为「律例」，因此有人认为它指礼仪，有人则认为它指道德。我们可以译作「诫命」；我理解它不仅指礼仪，也指一切属于圣洁生活准则的事。

<span style="color:#800000">*背了永约。*</span> 他所用的第三个词是 <span style="color:#008080">ברית</span>（*berith*），意思是盟约与契约。这个词专指那些「约定」，就是主藉以收纳祂的百姓、应许要作他们的神的约。（出埃及记 19:6；29:45；利未记 26:12。）因此，他指控他们忘恩负义，因为主既用这一切方法向他们显明自己，又赐下祂慈爱的凭据，他们却悖逆抗拒，「犯了律法」，「背了圣约」。

但他为何向犹大人说话呢？因为他知道自己蒙召作他们的先知，为要特别教导他们。由此我们可以推知，圣洁生活的准则是什么。它就包含在那律法之中；我们若愿意神悦纳我们的生活，就当遵行这律法；我们若偏离它，就必成为恶人与被弃绝的人。我们也当留意，神的旨意是要我们在祂的话语中不单思想祂的诫命与律法，也要思想祂的约；因为话语的主要部分乃在于应许，祂藉此收纳我们、接纳我们作祂自己的子民。此外，先知无疑有意使用多样的词语，为要更有力地表达他的意思；仿佛他说：「我们身上没有一样是健全纯洁的；样样都被玷污、都已败坏。」

他称之为「永远之约」，或「永约」，因为它本应是长存不变、不可破坏的，在每一世代都当有效力。它本当父传子、代代相承、绵延不绝，使它永不从人的记忆中被抹去，而得以纯全无缺地保存。因此他以强烈的措辞刻画他们的背信与恶行，因为他们竟敢违背神与他们所立的约，竟敢推翻主定意要坚立永存的事。这是骇人可憎的；所以我们不必希奇，地为这恶行施行报应，不肯再将食物供给世人。

<p style="text-align:center" markdown="1">6. <span style="color:#800000">*所以地被咒诅吞灭。*</span> 有些人将其译作*背誓*，[^f381]</p>

<!-- PAGE 542 -->
但因 <span style="color:#008080">אלה</span> (*alah*) 一词也有「咒诅」之意，我毫不怀疑先知在此是用它来表示「咒诅」，并且暗指摩西在律法中向恶人和违犯律法之人所宣告的那些咒诅（利未记 26:16；申命记 28:15）。我们知道，地因我们初祖的过犯而受咒诅，以致它不生果实，反长出荆棘和蒺藜（创世记 3:17,18）。主减轻了这咒诅，使地虽然向着忘恩负义、不配蒙恩的人，仍旧出产食物供他们享用。然而，当我们不肯停止犯罪，反而罪上加罪时，地变为荒瘠不结果实，岂不是最公义的报应吗？如此我们才可以更清楚地看见这咒诅，并使它更深地印在我们的感官之中。

<span style="color:#800000">*其中的居民受咒诅。*</span> 我认为此处 <span style="color:#008080">אשם</span> (*asham*) 的意思是「使之荒凉」，而非「离弃」；从上下文即可看出这一点，因此我将它译作「变为荒凉」。但或许有人认为，把连接词 <span style="color:#008080">ו</span> (*vau*) 解作*因为*更为可取，那么意思就是：「受神咒诅的地被烧毁，*因为*其中的居民行了恶事。」

<span style="color:#800000">*所以地上的居民被火焚烧，剩下的人稀少。*</span> <span style="color:#008080">חרו</span>（*charu*）这个词可以按隐喻来理解，我更倾向于这种看法，其意思乃是：凡被神的忿怒所吞灭的人都被烧尽了；因为这毁灭被比作一场大火。当他加上「剩下的人稀少」时，我们从中得知：这预言不可解释为指着末后的审判之日，恰恰相反，先知是在预言并确证那些威胁各邦国的荒凉，而他这样做，是为要使敬虔人存敬畏之心，被引至悔改，并预备好忍受一切。

<!-- PAGE 543 -->
**7.** <span style="color:#800000">*新酒枯干。*</span> 这里继续同一主题，先知主要是针对犹大人，威胁那地必成荒凉。他作了长篇的描述，为要更深地打动他们，使他们确信神的审判。他迅速地扫视了他们的奢华、无节制与宴乐，因为他们在如此丰盛之中竟骄傲地违逆神。这样的忘恩负义并非犹大人或那个时代所独有的，而是普遍可见的：凡享受丰盛的人都起来悖逆神，并过分地放纵自己。因此先知责备他们；如同他说：「直到如今你们一直沉溺于奢华与逸乐之中，但耶和华必使你们过一种截然不同的生活。」以赛亚将未来的事说得如同已经发生，为要更清楚地摆在他们眼前。

**9.** <span style="color:#800000">*人必不得饮酒唱歌。*</span> 饮酒本身并非恶事，因为神已将酒赐下供人使用；但先知在此所描述的，乃是醉酒之人的筵席，那里充满放荡、歌唱与狂傲。再者，因为他们滥用了丰足的享受，先知便以缺乏来威吓他们；当人以奢华放纵滥用神的美善时，几乎是自招缺乏。

<span style="color:#800000">*喝浓酒的，必以为苦。*</span> 他又补充说，他们即或饮酒，那酒对他们也必是"苦"的，因为忧愁通常使人对所吃的和所喝的都失去滋味。其意可归纳如下："他们纵有丰富的酒，也必被夺去享用之乐，因为他们所感受的忧愁，必夺去一切滋味。""喝浓酒的，必以为*苦*"；就是说，你们必不再享受那些迄今所纵情其中的欢愉与逸乐。

**10.** <span style="color:#800000">*荒凉的*</span> [^f383] <span style="color:#800000">*城拆毁了。*</span> 我不反对把这话特别理解为指耶路撒冷的荒凉。然而从上下文可以推知，这话也适用于别的城邑；因为紧接着他就用复数，召唤列国到同一审判台前受审。但因先知心中所念的主要是他本国的百姓，我们大可视之为指耶路撒冷；他称之为"荒凉的城"，或因其中毫无坚实的德行，或因它已遭毁灭。

<span style="color:#008080">תהו</span>（*tohu*）一词，或可指毁灭本身，或可指他们的罪行——正是这些罪行激动了神的忿怒攻击他们。若认为解作他们的罪行更为妥当，那么它所指的便是「混乱之城」，其中毫无规矩秩序，凡事都不得其位；我赞同这一解释。然而它也可指刑罚；因为依我看来，它宣告了毁灭的缘由，将这城交付倾覆，因为公义与良好的治理已从其中被逐出。

<span style="color:#800000">*房屋都关闭无人。*</span>这是荒凉的明证；加上这句话的唯一缘由，就是要表明那城的荒废。

<!-- PAGE 544 -->

**11.** <span style="color:#800000">*人必因酒喊叫。*</span>他的意思是，酒必稀少；因为凡有缺乏或饥饿之处，就必伴随着不止息的怨叹，不仅在私下，也「在街上」和公共场所。因此他一面指出那些悲哀的声音与怨叹，一面同时责备他们的奢侈与放纵；因为他们并不以必需之物为足，反倒贪婪地灌酒，任凭自己沉溺于各样的享乐。我们必须补上其中的对照：「直到如今，你们酒食丰足，却因此得着机会向神放肆狂傲；因此你们被夺去这些，是理所当然的；你们的放纵宴乐，必变为街上所闻的哀号与悲叹。」

<span style="color:#800000">*一切喜乐变为昏暗。*</span>这后半句中的比喻值得留意；因为正如我们说喜乐得着它所求的对象时便发出光亮，先知在此说「喜乐变为昏暗」，因为忧愁可说是笼罩其上的一片乌云。*欢乐*本身并非恶事，正如饮酒本身并非恶事；先知所责备的并非单纯的欢乐，乃是过度无节的欢乐。人在欢乐之时，因着他们天性中的那种放荡或喜好混乱（<span style="color:#0000d4">ἀταξίαν</span>），便不加约束。犹太人既行事狂傲、生活奢靡，就理当受神报应的威吓，因为当我们不知道如何正确使用主的恩惠，也不知道如何在祂里面欢喜时，喜乐从我们中间被夺去乃是极其公义的。因此，祂必须夺去我们的欢愉和乐趣，迫使我们叹息哀哭。

**12.** <span style="color:#800000">*城中只有荒凉。*</span>他以一种优美的表达方式描述耶路撒冷或其他许多城邑的荒凉。城邑的荣美与完全在于人；因此，当居民被迁走之后，城邑就被称为荒废了。先知带着讽刺的语气说，所剩下的是「废墟」；不过<span style="color:#008080">שמה</span>（*shammah*）一词，有人译作*荒凉*，二者意思相同。

<!-- PAGE 545 -->
<span style="color:#800000">*城门拆毁净尽。*</span>他提到*城门*，因为城中拥挤的人群正是在城门口显现出来，百姓在那里聚集，审判也在那里进行。所以他先提到整座城，接着又指出城中的一部分，目的是要把这事描绘得更加鲜明；因为城邑纵然失去了居民，城门口总还能见着几个人；但若连城门都全然空无一人，那么全城必定是一片可怕的荒凉。

**13.** <span style="color:#800000">*在地中，*</span>由于这句话夹在威吓与安慰之间，先知似乎是向蒙拣选的百姓说话，而不是笼统地向万国说话；除非我们宁可说，他所描述的是那使犹大人仿佛被分散为许多国民的分散。但这种解释既生硬又勉强，我便简单地解释为：仍有些指望留给那些毁灭了的列国；而这预言确实严格地指向基督的国；因此我们不必惊奇，救恩的某一部分也应许给外邦人。

<span style="color:#800000">*好像打过的橄榄树。*</span>先知在别处也用过同样的比喻，只是那时他单单论到教会。（以赛亚书 17:5, 6）在那里他说，神必留下些种子，免得信徒以为教会已全然败亡；因为「橄榄树被打」之后，仍剩下几个橄榄，摘完葡萄之后仍剩下几粒葡萄；照样，在那将临到教会的可怕毁灭之后，也必剩下少数敬虔人。但如今他把同样的应许延伸到世界其他各处，因为他们要藉着基督同得这恩典。然而其中仍夹杂着威吓；仿佛他说，地上的居民必被除灭，正如树木和葡萄树的果子被摘净一样。

**14.** <span style="color:#800000">*这些人要高声欢呼，*</span>他继续并加强他先前简略勾画的安慰；因为他从前（以赛亚书 10:19-22）曾说，从那庞大的群众中只剩下几滴，这几滴却要漫溢全世界，照样他现在说，从丰盛的葡萄收成中所剩下的少数敬虔人，仍要欢呼，并且发出如此宏大的声音，以致在极远之地也能听见。这是藉着福音的传扬而成就的；因为就犹大的境况而论，它似乎因此全然荒废了：国家的政权被夺去，他们又因外患与内战而崩溃，以致永不能再兴起。世上其余的人在歌颂神的赞美上是哑的，在听祂声音上是聋的；但既然<!-- PAGE 546 -->犹大人是初熟的果子，我便甘愿承认他们在此被列在最高的位置。

由此我们得着一个非凡的安慰：主能在顷刻之间复兴祂的教会，使之极其兴盛；或更确切地说，祂能仿佛从无有中创造出教会来；因为正如我们所看见的，祂甚至能从死亡中带出生命。这与自然常理、与惯常的情形都相违背：如此稀少的人数竟能扬声，且声闻远方；因为人少之处便是寂静，人多之处才通常有喧声。所以这是神的作为，超乎自然的进程与人的能力；否则先知所说的岂不成了自相矛盾——全犹大既已荒凉，世界已被倒空，所剩之人寥寥无几、几乎无存，然而他们的欢呼却处处可闻。这事本身实在难以置信，甚至可说是荒谬；然而正如我们已经说过的，这是神奇妙的作为。

<span style="color:#800000">*他们要从海上扬声。*</span> 他所说的这些传报者，不仅指那些按肉体从犹太人所生的，也指那些藉信心从他们而出的。这**扬声**不仅表示欢畅的声音，流露欢欣喜乐，也表示信心的笃定；因为他们要坦然无惧、放胆扬声传扬神的赞美。同时他指出，信徒理当致力于高举神的全备美德，而非高举自己可称许之处。他所说的**海**，显然是指遥远的国度，就是那些海外之地、犹太人素不认识的地方。

**15.** <span style="color:#800000">*因此你们要在山谷中荣耀耶和华。*</span> [^f384] 神的恩惠理当激励我们感恩，而我们藉着歌颂祂的赞美来表明这感恩。正如大卫所说：「我拿什么报答耶和华向我所赐的一切厚恩？我要举起救恩的杯，称扬耶和华的名。」所以先知遵循这样的次序：既已论及教会的复兴，便劝勉我们献上赞美的祭。

<!-- PAGE 547 -->
他所说的*山谷*，是指那些隐蔽的、仿佛与外界隔绝的地方；因为凡被群山环绕之处，天然就被分隔阻断。其结果是，山谷中的居民较为鄙陋不化，因为他们彼此往来交谈的机会较少。其含义与先知这样说无异：必没有一个角落如此偏僻幽隐，以致神的颂赞不能传到那里。

<span style="color:#800000">*以色列神耶和华的名。*</span>他用「以色列神的名」这一说法，是要表明万国都必求告真神；因为，正如万国对神都有一种与生俱来的认识，照样，万国也都轻易偏向迷信与虚妄的敬拜（罗马书 1:19）。但他在此所说的，乃是真宗教遍传全地；这就更加清楚地表明，这预言乃是关乎基督的国度，在祂的国度之下，真宗教终于渗透进入了外邦异教之民中间。

**16.** <span style="color:#800000">*我们听见从地极*</span> [^f385] <span style="color:#800000">*有歌唱的声音。*</span>本节包含两项陈述，表面看来彼此似有抵触。它以欢欣地描述对神的颂赞开始，随即转入哀叹与悲鸣，先知在其中痛惜奸诈之人的诡诈，他们倾覆了宗教与敬虔。就颂赞而论，我们已经说过，除非神向我们启示祂自己，并使我们尝到祂的良善，以致我们能怀抱生命的盼望与确信的期待，否则我们既不能颂赞神，也不能求告祂。故此大卫有这样的话：

<p style="text-align:center" markdown="1"><span style="color:#000080">「因为在死地无人记念你，</span> <span style="color:#000080">在阴间有谁称谢你？」（</span><span style="color:#000080">诗篇 6:5）</span></p>

当我们所感受到的除了神的忿怒别无他物时，我们对他的赞美便成了哑口无言；所以，当他说必听见对神的赞美时，他的意思是：福音要传遍全世界，使人得以承认神是他们的父，因而发声赞美他。「从地极」这一措辞值得留意；因为在那时，对神的赞美仅限于犹大之地，远方无人听闻；但此后却开始处处响彻。（诗篇 76:1, 2）

<!-- PAGE 548 -->
<span style="color:#800000">*荣耀归于义人。*</span> 有些人认为这是众信徒所唱的，仿佛那歌是说：「神因他的义而得荣耀。」另有些人把两个分句读作一句：「我们听见荣耀归给公义的神。」那些认为宣扬神之赞美的人被称为「义人」的，所得出的意思固然极好，却没有留意「荣耀」一词，或者至少不得不将 <span style="color:#008080">צבי</span>（*tsebi*）一词译作*喜乐*。[^f386] 他用过去式「我们听见」代替将来时；他这样做的缘由是，他有意以某种安慰来振奋敬虔人的心：「我们必再听见对神的赞美」；因为这样说比说「人必听见」更有力。他又用第一人称说话，为要把教会的全体都包括在内，从而唤起敬虔人的注意。

神被称为*公义的*；我们知道这一说法在圣经中屡屡出现，但它归于神的方式与归于人的方式不同；因为人被称为"义人"，是由于那传通给他们的"义"；而神既是义的泉源，被称为"公义的"，乃是由于祂所行的作为。（申命记 32:4；诗篇 7:9；11:7。）而这正是这称颂与感谢的凭据，因为我们从这义的传通中得着救恩与生命；因此，凡有神的义之处，必随之而有赞美与感谢。

当先知预言这些事的时候，它们看来是何等难以置信！因为惟独在犹太人中间，耶和华是被认识、被赞美的。（诗篇 76:2。）如今向他们预告的是毁灭，接着是道的传扬，是神的颂赞被歌唱；然而当神的子民已被剪除时，这些事怎能成就呢？由此我们可以推知，相信这些预言的人是何等稀少。但如今这些事既已成就，我们便当以惊叹的心来仰望神如此伟大的奇迹，因为当犹太人不但被击垮、且几乎被灭尽之时，仍有一点火星从他们中间迸发出来，照亮了全世界，凡被它点燃的人都迸发出对真理的承认。

<!-- PAGE 549 -->
<span style="color:#800000">*我消瘦了。*</span> [^f387] 这一段有各样不同的解释；因为有人把 <span style="color:#008080">רזי</span>（*razi*）译作*奥秘*，另有人译作*消瘦*。那些译作*奥秘*的人，认为先知的意思是：有双重的奥秘向他显明了，因为主已定意赏赐善人、刑罚恶人；因为当人只看事情的外表，看见恶人诸事顺遂、称心如意，而敬虔人却被患难压倒时，他们就心里困苦，怀疑人间的事究竟是由神的手所治理，还是万事都出于偶然；所罗门指明，这一类的思想乃是不敬虔的种子。（传道书 8:11。）为此，诗篇的作者也说，他"进了神的圣所"，好使他能以不同于人的理性的方式来省察这件事。（诗篇 73:17。）我们若采用那种解释，其意思便是："虽然看来义人似乎没有赏赐，我却持定这向我显明的奥秘：他们必得福乐；恶人虽以为自己必得脱逃，我却知道他们必不能免受刑罚。"但因这种巧思显得过于牵强，我更喜欢一个较为简明的解释；何况紧接着就有一个表达哀恸的叹词 <span style="color:#008080">אוי</span>（*oi*）*祸哉！*所以我不认为以赛亚在此是论到义人或他们的赏赐。

另一些人更正确地将其解释为*消瘦*；仿佛他是说，他因忧伤而枯槁消瘦；因为正如那百姓兴盛繁荣的境况可称为「肥壮」，其可怜困苦的境况也可称为「消瘦」。先知在此站立出来，作全族的代表；当耶和华剪除这族时，他理当为自己的「消瘦」而哀叹。我说过，这解释是可取的；因为先知看见百姓人数日渐减少，他大有理由为这减少而悲哀。我们知道，当神的恩典极其丰盛地浇灌下来时，古时的百姓却大大减少，亚伯拉罕的后裔几乎归于无有。

但我们必须察看，先知是否所望的比他本族被弃更为深远，以致他哀叹自己肺腑的境况，因为他预见教会将要遭受沉重的困苦；因为 <span style="color:#008080">רז</span>（*raz*），有人译作*隐秘*，也可恰当地理解为指身体的内部；照这样，这呼喊便是：「我的肺腑，或我的脏腑，疼痛了；」因为在一段动人心肠的话语中，假定有一个字被省略而须补足，并无不合理之处。当耶和华扩张祂的教会时，教会看似处于兴旺之境，脱离一切危险；但当它的内里、它的肺腑，就是它自己的肢体使它不安时，它便备受痛苦的煎熬。假冒为善者兴起，教会受他们的搅扰，比受「在外面」的仇敌搅扰更甚。（启示录 22:15）

<!-- PAGE 550 -->

那些叹息之声 <span style="color:#008080">אוי</span>（*oi*），*我有祸了*，其含义也是如此；我毫不怀疑，以赛亚有意表明：敬虔人不当以为自己在今世必得幸福，反当相信自己必须持续争战，纵然他们或以为已无任何拦阻，可以享受不受搅扰的安宁与平安。他要表达那在教会内里、甚至在她肺腑之中折磨她的剧痛之情；而这苦难更是深可哀叹，因为它无从躲避；因为正如某人所说，教会既不能逃离内部与家中的仇敌，也不能将他们赶走。以赛亚几乎找不到足够的言辞来表达这般的悲惨。

<span style="color:#800000">*诡诈人行事极其诡诈。*</span>这些话充分证实了前面已经作出的解释。这一灾祸何等沉重，何等应当哀恸，我们自己已经充分体验过，直到今日仍天天体验着。教皇制度及其一切败坏，若非出于这内部之恶，又是从何而来呢？因为那是在教会腹中所生的一个脓疮（<span style="color:#0000d4">ἀπόστημα</span>，阿波斯特马，脓肿），排出秽恶患病之物。还有，当教会开始复兴之时，我们何以看见教义被败坏、纪律被推翻，而且不仅是被平民百姓，乃是被那些本当为他人立好榜样的人所败坏所推翻呢？岂不是因为教会总是免不了这样的祸患么？

**17.** <span style="color:#800000">*恐惧、陷坑、网罗。*</span>先知在此针对百姓的罪恶发言。他先前曾宣告，不单一国，乃是许多极其遥远的邦国，都要有丰盛的理由献上感恩。如今他转到另一教训；因为我认为这些话当与前文分开，缘由是以赛亚再次威吓恶人，好叫他们知道，即使在教会最兴盛的时候，他们仍必是可怜的。恶人惯于纵容自己的漠然，轻率地把神的应许挪来应用在自己身上，虽然那些应许与他们全无干系；故此众先知通常把威吓的话掺杂其中。也有可能以赛亚是在另一场合、与其余的话分开来传讲这段信息；因为无论是众先知自己，还是别的学者，都不曾划分章节。我们常见不同的主题被合在一处，而本当合在一处的却被分开，这无疑是出于无知所致。无论如何，<!-- PAGE 551 -->先知又回到恶人身上，向他们威吓严厉可畏的审判。

这「恐惧、陷坑、网罗」的描述，意在打动人的心；因为他若只用一句话说毁灭正等候着恶人，他们必不会大受震动。但这里可以质疑的是，他是否单单对犹太人说话。就我自己而言，我不太愿意在这事上争辩；不过我认为更为可信的是，这些威吓也关乎其他列国，甚至关乎他先前所预言的全世界。

<span style="color:#800000">*地上的居民哪。*</span>我们理解「世界」是指犹太人所知晓的那些地方，正如我们前面已经解释过的。其意思是：「你被如此纷繁多样的灾祸所困，以致无路可逃。」阿摩司也作了类似的描述：「景况好像人躲避狮子又遇见熊，或是进房屋以手靠墙，就被蛇咬。」（阿摩司书 5:19）以赛亚先前说过，狮子必被差来攻击那些从战场逃脱的摩押人。（以赛亚书 15:9）神有无穷无尽的各样鞭子来刑罚恶人。这就好像他说：「要知道你们逃不出神的手；因为他有各样的方法来报应他们的罪行，如此便追上了那些指望用种种诡计脱身的人。逃出战场的必受饥饿的折磨；及至脱离饥饿，又要遭遇别的灾祸，仿佛四面都布下了网罗要捉拿你们。」

<span style="color:#800000">*因为天上的窗户都开了，地的根基也震动了。*</span>这一论据证实了前面所说的：他们绝不可能逃脱神的报应，因为神已在天上地下为报应预备了畅通无阻的道路，从至高的天直到地的深处。有些人认为他是在暗指洪水（创世记 7:11）；但依我看来，其意思更为简单，即神的愤怒必在上下显明；这就好像他说：「主必装备天和地，来向世人施行他的报应，使他们无论转眼看何处，所见的只有毁灭。」

<!-- PAGE 552 -->
**19.** <span style="color:#800000">*地全然破坏。*</span>他用各样的说法加重了他对刑罚的描述。稍后他要指出这「震动」的缘由，就是人因自己的罪，把这样的毁灭招到自己身上。他现在宣告这祸患是无法医治的。我们从前说过，先知用各样的方式阐明同一件事，为要震撼并唤醒那些本性极为迟钝的心思；因为肉体中有一种漫不经心，由此生出对神的藐视，而我们在自己和别人身上对此都有太多的经历。因此，为要唤醒那些在恶行中漫不经心、沉睡不醒的人，众先知便修饰他们的文体；这并非因为他们在意被人视为雄辩，乃是要使听众更加留心，并深深刺透他们。这些经节中充满的种种暗喻由此而来；文体中光彩夺目的比喻由此而来；以各样方式宣告的威吓与恐吓也由此而来；其目的无非是要唤醒那些漫不经心的人。

如今，这教义应当限于恶人；并非因为敬虔人得免这些灾祸，因为他们也和别人一样受苦；而是因为敬虔人既投奔于神，全然倚靠他，就不至这样动摇，反而在一切攻击之下屹立坚定；而恶人既藐视神的审判，肆无忌惮地犯罪，就必惊惶恐惧，永不得安息。

**20.** <span style="color:#800000">*又要被挪去，好像帐棚。*</span> 这并不是说地的位置会发生什么变动；正如我们前面所说，这些话必须归于人；仿佛他说，将不再有君王的权柄，也不再有正常的治理。总之，他有意描述他在第十章所提及的那些变动。

<span style="color:#800000">*地的罪过在其上沉重。*</span> 当他说「地因自己的罪孽而负重担」时，他极为恰当地指出了这个缘由，使我们明白神从不无故向人发怒；因为我们所受的一切灾祸，都是我们自己招来的。神按其本性乃是乐意施恩的，以父亲的慈爱看顾我们；因此，我们受到严厉痛切的对待，乃是我们自己的过错，我们没有理由归咎于他。[^f388]

<!-- PAGE 553 -->
<span style="color:#800000">*且必倾倒，不能再起。*</span>他终于重述了稍前简略提到的话，就是这些灾祸必无医治之法。有人认为这是指犹太人而言，他们的政体被全然除去，以致破碎四散，几乎不再算在人的行列之中。但我作更广泛的解释：世界所遭遇的患难必极其严重，以致无法恢复其原初的光景。人总是与逆境相争，心中充满自信。他们既忍受了灾祸，便以为总会有喘息之地，心中因虚妄的盼望而自高；因此先知除去这盼望，免得他们日后再以无根据的期待自欺。然而当留意，这一普遍的宣告并不废除以赛亚先前所作的例外。

**21.** <span style="color:#800000">*到那日。*</span>这段经文使许多注释家绞尽脑汁，各家提出了种种不同的解释。有人认为这是指日头和众星；另有人认为是指魔鬼，它们将与恶人一同受刑罚。还有人将其归于犹太人，因神曾赐给他们特殊的权利。但这些解释我都不能采纳。[^f389] 因此在我看来，简明而真确的意思乃是：没有任何权势高到可以免去神这些鞭挞；纵然他们把自己高举到云端之上，神的手仍必追上他们；正如诗篇所说：

<p style="text-align:center" markdown="1"><span style="color:#000080">“我往哪里去躲避你的灵？我往哪里逃、躲避你的面？我若升到天上，你在那里；我若展开清晨的翅膀，飞到海极居住，在那里你的手必引导我。”</span> <span class="ages-code">&lt;19D907&gt;</span><span style="color:#000080">诗篇 139:7-10。</span></p>

<span style="color:#800000">*耶和华必惩罚高处的众军。*</span> [^f390] 这是一个隐喻，藉此他指明君王与首领，他们在世上闪耀发光如同星辰；随后他又用直接的言语解释这隐喻，加上*地上的诸王*；因为我并不认为二者当分开，仿佛他在讲论不同的对象，而是同一宣告的重复，以致后一句解明前一句。不过或许有人认为这样解释更好：「他必惩罚地上的诸国」，甚至惩罚那些看似超乎人的等次之上的事物；因为有些事物远远高过其他，以致显得仿佛不属于寻常的等次。「惩罚」（visit）一词必与刑罚有关，正如上下文也足够清楚地表明。

<!-- PAGE 554 -->

**22.** <span style="color:#800000">*他们必被聚集……并要囚在监内。*</span> 他在本节起首继续先前的题旨。这说法是隐喻性的；因为他们并非全都作了俘囚，乃是神使他们沦为奴役，如同人把他所征服的仇敌握在手中。因此他把神呈现为得胜者，将仇敌关进监牢，正如俘囚通常被关押那样。我们知道，人只要蒙神宽容、蒙他略施忍耐，就仿佛逃离神、藐视神；也正因这缘故，他警告说他们必成群大批被投入监牢，使他们不能以自己的人多势众自慰。

<span style="color:#800000">*多日之后必被眷顾。*</span> 当他加上说，过了一段时候「他们必被眷顾」，这并非单纯的应许，也含有这样的警告：「正如他们从前以顽梗戏弄神，过分延长犯罪的时日，神也必不急速地施行刑罚，直到最终他们虽然迟了，却承认自己灾祸的缘由。」正如地上的审判官常常不屑让那些触犯了他们的罪犯来到自己面前，反倒把他们投入黑暗污秽之中，渐渐消磨他们，为要制服他们的顽梗。再者，神眷顾世界有两种方式：或是刑罚恶人，或是向选民显明父亲慈爱的凭据；此处「眷顾」一词意为「垂顾」；先知就这样缓和了那警告的严厉。在这些患难之中，敬虔人的心必须得着扶持，免得他们疲乏丧胆；因此为他们的缘故，先知们在种种警告之后，惯常加上安慰的话。既然这些宣告是为扶持信徒而说的，它们无疑是对犹大人说的，因为信心主要是在他们中间才寻得着，或更确切地说，在别处根本无处可见。

<span style="color:#800000">*多日以后。*</span>这一点也值得注意。这是为要试验敬虔人的信心；[^f391]因为我们在自己的愿望上性急，巴不得神立刻成就祂的应许；我们埋怨祂迟延，丝毫不能忍受耽搁。因此我们的本分乃是耐心等候那怜悯；无论延迟多久，都不该使我们灰心丧志。然而也当注意，这并不是指着所有人说的；因为正如我们稍前所见，神已定意只拯救为数不多的余民。这更应当激励我们，好叫我们因那缓慢而长久的刑罚受了谦卑，得以迎见那眷顾我们的神。

<!-- PAGE 555 -->

**23.** <span style="color:#800000">*月亮要蒙羞。*</span>许多解经者认为，先知在此对犹大人更加发怒，甚至说日、月、星辰都因他们的不信而羞愧，不但人，连无言语的受造之物也都憎恶他们；但这似乎与先知的意思和目的相去甚远。我毫不怀疑，他仍在继续前一节中已略微提及的安慰：「当主眷顾祂的百姓，洁净教会的污秽时，祂必建立一个极其荣耀的国度，其光辉必使日月星辰黯然失色。」这种表达方式是众先知常用的，我们从前也曾见过。因此，既然神要在锡安山上建立祂的国，那么在百姓复兴之时，其荣光何等浩大，以致那些令人目眩神迷之物，与之相比也成了黑暗；为要表明这一点，祂便题起那些在光辉上超越万物的对象。

<span style="color:#800000">*因为万军之耶和华必在锡安山作王。*</span>有些人认为「作王」一词是指神的报应；但这并不确切，因为虽然当主执行审判者的职分时，也说祂作王，然而「神在锡安山作王」这一完整的说法，向来是指怜悯与拯救。他所论的是教会的复兴，由此可见，这一切唯有在基督里才得以成就。

<!-- PAGE 556 -->
<span style="color:#800000">*在他长老面前必有荣耀。*</span>他特意提到「长老」，乃是使用了圣经中常见的一种修辞手法，即以教会中最尊贵的部分代表全体。然而他以「长老」一词不单指祭司，也指其他掌管纪律与道德、并当以其节制与智慧引导众人的治理者，这并非没有特别的用意。他在长老的名下包括了整个民族，不仅因为他们代表全体，也因为平民百姓在某种意义上隐藏在他们的荫庇之下，更是为要叫信徒怀抱将来复兴的盼望；否则，若只剩下一群四散的人，如同残缺的肢体或杂乱的一堆，那就毫无益处，或益处甚微。他用「在他长老面前」这话，绝非无故，乃要叫犹太人知道，神的能力必要显明可见、令人震撼地彰显出来；这并非说肉身的感官能觉察，乃是凭信心觉察。他如此作王，以致我们感到他与我们同在；我们若不明白这一点，这对我们就毫无安慰可言。

<span style="color:#800000">*荣耀。*</span> [^f392] 有人不译作「荣耀」，而译作「荣耀地」，又有人译作「荣耀的」。我宁愿单纯地将它看作名词，虽然在意义上差别甚微。他表明，当基督的国度建立之时，神的光辉与荣耀何等浩大，因为一切光耀夺目的都必黯然失色，唯独基督的荣耀必居于崇高显赫的地位。由此可见，唯有当一切受造之物都被置于顺服之下，唯独他在我们眼前发光之时，神才得着他当得的权利与当得的尊荣。
