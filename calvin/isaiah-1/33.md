# 第三十三章

<p style="text-align:center" markdown="1"><span style="color:#000080">前往 以赛亚书 33:1-24</span></p>

**1.** <span style="color:#800000">*祸哉！你这毁灭人的。*</span> 若将这些话解释为指着巴比伦人说的，文意便流畅自然；因为在应许被囚者得释放之后（以赛亚书 32:15），他此处恰当地讥讽那些征服者。此外，他们尤其需要得着坚固，好使他们相信一个看似难以置信的预言；因为他们无法认为这是可能的，即如此庞大的势力竟会被摧毁、被倾覆，而那些如今陷于绝望之中的可怜囚徒竟会迅速得允归回本土。因此，在这般苦难之中，倘若先知不以这些劝勉来迎向他们，他们或许早已灰心丧胆，对得救全然绝望。故此，他预先应对那些疑虑——就是在他们被巴比伦人掳去、沦为奴仆之后，可能折磨他们心思、诱使他们绝望的疑虑；因为他们看不见此处所应许的任何一件事，反倒所见的尽是与此完全相反的光景。

然而，既然几乎众口一致认为此处是新一段讲论的开端，且是对西拿基立及其军队所发的，我也不反对相信：先知在此向亚述人宣告威吓之言——他们不义地欺压四邻——而这威吓的用意，是要缓解百姓的困苦与忧虑。因此他的意思是：必有奇妙的局势翻转，倾覆尼尼微兴盛的境况，虽然它看似不可战胜；因为巴比伦人必以敌意前来，为着他们向别国所施行的残暴而施行报应。

为使这段讲论更具力量，他直接对亚述人说话：「**祸哉！你这抢夺人的**；你如今尽可肆意掠夺而不受惩罚；无人有能力抵挡你；但有一日必有人反过来掠夺你，正如你掠夺别人一样。」他用单数称呼他们，却是集体的意义，这是极常见的用法。另有人将其读作疑问句：「你岂不被抢夺吗？你以为你永不因那强暴受惩罚吗？有一日必有人照样报应你。」

<!-- PAGE 748 -->

但我们不妨遵从通常的解释，据此解释，先知以鲜明的笔法揭露敌人的不义：他们如此贪图掠夺，以致谁也不放过，连从未加害他们的无辜者也不放过；因为这正是极度残暴的明证。故此我更倾向采纳这一解释，据此，他在头一句中描述亚述人的本相，指明他们是卑劣残暴的强盗，并强烈地展示他们的残忍——搅扰并掠夺那些无害无犯的人；如此，当犹大人看见这般毫无节制的不义时，便可思想神是公义的，这样的行径不会永远不受惩罚。

<span style="color:#800000">*你钞掠够了。*</span>这是这句话的第二个分句，先知借此宣告：亚述人如今之所以钞掠，乃因神放松了缰绳任凭他们；但有一天神必勒住他们，使他们再无力加害。若我们把这话理解为"当他们不再愿意钞掠时"，那便是软弱无力的解释；先知所说的却更为深远，他宣告那时候必要来到，就是"他们钞掠完毕"的时候，因为耶和华必约束他们、制伏他们。因此，其含义无异于说："当你达到顶点之时"；因为我们看见，暴君有其被指定的界限，是他们不能越过的。只要他们仍在跑道上，他们的路程便疾速前行；但一到了终点，就是他们的极限，他们就必须止步。

当我们看见暴君狂傲凶暴地攻击神的教会时，让我们以这样的安慰来欢畅我们的心；因为耶和华终必迫使他们止步，而他们越是残暴，所受的刑罚就越发严厉。耶和华必顷刻之间毁灭他们；因为祂必兴起仇敌来攻击他们，使他们立时倾覆，并因他们的罪孽刑罚他们。

在此我们也当承认神在列国倾覆之事上的护理；因为恶人以为万事都是偶然运行，出于命运盲目的暴力；但我们当持全然不同的看法，因为耶和华必按他们所当得的报应他们，使他们知道：他们向那无辜之人所施的残暴，并非不受报复。而事实的发展证明了这预言的真确；因为不久之后，尼尼微就被<!-- PAGE 749 -->巴比伦人所征服，丧失了王权，甚至被彻底毁灭，以致连名字也消失了。但那接续她地位的巴比伦，同样是一个"钞掠者"，故此先知理所当然地预言：必有别的强盗来抢夺她；巴比伦人的王权一旦倾覆，他们自己也必被人钞掠，就是被夺去他们从别人那里所强取豪夺之物。

**2.** <span style="color:#800000">*耶和华啊，求你施恩于我们。*</span> 先知加上这句话，是为了提醒敬虔人：在这样的患难之中，甚至在他们看来一切得救的盼望都被剥夺之时，他们当往何处去；就是当他们最为凄惨、仇敌残暴压制他们的势力极其可畏之时，他们仍当投身于祷告，恳求神成就这些应许。在此我们当留心观察先知所遵循的次序：他先陈明神的应许，随即劝人祷告。不但如此，他还中断了自己论述的流势，忽然迸发出祷告来；因为主虽急于成就祂所应许的，却仍暂时延迟，为要操练我们的忍耐。然而当我们本该等候之时，在我们里面却找不到坚定或恒忍；我们的心立刻就疲乏消沉了。因此我们当求助于祷告，唯有祷告能扶持并使我们的心欢喜，使我们切切仰望神；唯有藉着祂的引导，我们才得脱离患难。但愿我们以不动摇的盼望与信靠，忍耐等候祂向我们所应许的；因为祂终必显明自己是信实的，绝不叫我们失望。

与此同时，先知吩咐我们不仅要笼统地思想神对亚述人的审判，更要思想神对祂选民的慈父般的良善；仿佛他是说，亚述人被毁灭，不单是要他们为自己的贪婪与残暴受当得的报应，更是因为神喜悦借此方式眷顾祂教会的安全。但他一面劝我们祈求怜悯，一面也宣告我们必是可怜的。

<span style="color:#800000">*我们等候你。*</span> 为要坚固得蒙恩眷的盼望，信徒接着宣告，他们如今所呼求的这位神，正是他们「所仰望的」；的确，我们的祷告若不建立在这一原则之上，便必是徒然无益的。

<!-- PAGE 750 -->

<p style="text-align:center" markdown="1"><span style="color:#000080">大卫说：</span><span style="color:#000080">“耶和华啊，求你照着我们所仰望你的，向我们施行怜恤。”</span><span style="color:#000080">（</span><span style="color:#000080">诗篇 33:22）</span></p>

因为倘若神不藉着他的话为我们开路，我们竟要进到神面前，那就是极大的鲁莽；所以，正如他慈爱温柔地邀请我们，我们每逢亲近他的时候，也当持守他的话。此外，忍耐必须加在信心之上；因此，当信心被夺去时，我们就不配主垂听我们，因为我们乃是凭着信心呼求他。如今，唯有信心才是呼求神之母，正如圣经许多经节所屡屡宣明的；倘若缺了信心，我们里面所剩下的就只有假冒为善，而没有什么比这更为神所憎恶的了。（罗马书 10:14）

由此可见，整个教皇制中毫无基督教的实质；因为若敬拜神的首要部分在于祷告，而他们却不知何为祷告（因为他们吩咐我们不断地疑惑，甚至指责敬虔人的信心为鲁莽），那么他们算是哪一种敬拜神的人呢？那被疑惑所困扰、不以坚定的信靠倚赖神应许的祷告，岂能是合法的？那些愿意被算为神学家的拉比们，岂不是显明自己不过是孩童吗？我们的孩子在知识上、在真正敬虔之光上，实在都胜过他们。[^f603]

我们也当从这些话学到，我们的信心是借着患难得以证实的；因为信心真正的试验，就是当我们以不动摇的忍耐抵挡一切的危险与攻击时，仍旧继续倚靠神的话语与应许。这样，我们就以实际的凭据表明我们是真诚地相信了。

<!-- PAGE 751 -->
<span style="color:#800000">*愿你仍如从前那样，作他们的膀臂。*</span> 有些人把这句译作一段连续的祷告：「求你每早晨作我们的膀臂，在患难时作我们的拯救。」至于信徒在此以第三人称说话，他们认为这是希伯来人常用的一种转换。但我认为先知的意思有所不同；因为他有意表达那种因从前所领受的恩惠而愈发热切的渴望；因此，依我看来，「每早晨作他们的膀臂」这一句是恰当地插入的，我在其中补上「你曾作」这几个字，为要提出神从前赐给列祖的古时恩惠。「主啊，你曾垂听我们列祖的祈祷；当他们投奔于你，你就赐给他们帮助；如今也求你作我们的拯救，救我们脱离苦难。」

「膀臂」与「拯救」的区别在于：「膀臂」是指主为保卫祂的教会所施展的能力，且是在她受苦之前所施展的；而「拯救」则是指主搭救教会的作为，甚至在她看来已经败亡之时。所以他把主从前赐给列祖的古时恩惠记录下来，好叫主也被感动，向儿孙施行同样的怜悯。仿佛他是说：「主啊，你从前曾使那威胁你教会的危险转离；她倚靠你的恩眷而兴盛昌荣。你也曾在她被压制时搭救她。照样，你必为我们如此行，尤其因为在事情绝望、极其危急之时施以帮助，正是你的本性。」[^f604]

<span style="color:#008080">אף</span>（*aph*，即「也」「甚至」）这个虚词极富强调之力，为要坚固我们的信心，使我们不致怀疑：那位始终与自己相符、从不背离其本性、也不偏离其定旨的神，也必作我们的拯救者；因为信徒们一向就是这样认识祂的。因此，我们应当常将主从前如何帮助并拯救列祖的方式摆在眼前，好使我们深信不疑：我们也必同样从祂得着帮助与拯救。

**3.** <span style="color:#800000">*喧嚷的响声一发，众民奔逃。*</span> 他现在回到先前的教义，或者说，在插入一句简短的呼喊之后，他继续原来的论述。他先前已经指明，亚述人虽然看似远离一切危险，却必被击溃；如今他吩咐犹大人视此事如同已经成就；因为亚述的势力极其庞大，众人都惧怕他们，并以为他们不可战胜。所以以赛亚将亚述人可怕的败亡摆在犹大人眼前，仿佛这事已经成就了。他使用复数，说他们是*众民*；因为亚述的国度是由各族「众民」所构成，他们的军队是从各邦各国中招集而来；因此他断言，虽然他们的数目庞大无边，却仍要惨然灭亡。

<!-- PAGE 752 -->
<span style="color:#800000">*因你兴起。*</span> 「兴起」一词，有人解释为「显现」，即主藉此荣耀地彰显出祂所能行的事。但我用更简单的方式来解释：主从前似乎安然静止不动，容许巴比伦人肆意掠夺而不受惩罚，现在却忽然公开显现出来；因为祂的迟延无疑被仇敌骄傲地嗤笑，仿佛以色列的神已被贬抑、被征服；然而祂终于起来，坐在审判台上，为不敬虔之人的罪行施行报应。因此这里暗含一个对比：「兴起」与主容许祂的百姓受苦、被分散之时所显出的那种软弱之间的对比。[^f605]

有些人认为「喧闹的声音」是指主只需发出声响，就使仇敌溃逃；但我恐怕这种解释虽巧妙却不够扎实。因此我宁愿把「声音」一词解作玛代人和波斯人将要发出的巨大喧嚷。

**4.** <span style="color:#800000">*你所掠的必被敛尽。*</span> 此处他是对亚述人说话，除非有人认为更宜指犹大人，并将「掠物」一词取主动之意。然而前一种看法更为*恰当*；这种突然转为直接称呼的语气，赋予这预言极大的力量，因为他公开而明确地讥讽那些骄傲的敌人。不过尚有疑问的是，这是指该国的最终倾覆，还是指西拿基立王的溃败——那时他的军队在耶路撒冷城墙前被天使之手所灭（列王纪下 19:35）。后一种看法几乎为所有注释者所采纳，但在我看来过于狭窄；因为我认为，先知从本章开头论到那国的毁灭时，其意所指更为宽广。正如我稍前所提示的，这预言甚至可以延伸得更远，以致把巴比伦人也包括在内，他们是教会后来的敌人；但撇开这点不论，已足够明显的是，他笔锋所向乃是尼尼微的王权。

<!-- PAGE 753 -->
<span style="color:#800000">*人蝗聚集怎样跳在其上。*</span> 他把那好战的民族比作「蝗虫」，因为他们将无力抵抗，反倒都要战抖发昏，以致被聚成大堆而遭毁灭。这比喻极为贴切，先知那鸿也曾使用（那鸿书 3:15），只是意思略有不同；因为我们知道，那种昆虫对树木极其有害，破坏力极大，故可正当地称之为大地的灾祸。但它们虽数量庞大，却毫无自卫之力，甚至孩童也能轻易将它们摇落、收拢，随处遇见就成堆击杀。先知宣告说，这也必临到那些贪得无厌的强盗；因为他们虽长期以掠夺行了许多损害，最终却毫不费力地被杀被灭；因为他们既失去了男子的气力，几乎连生命也失去，就必落在敌人手中；而尼尼微藉抢夺积聚的财富，也必被运往巴比伦。

<span style="color:#800000">*如同蝗虫的乱跳。*</span>他现在又加上另一个比喻，就是巴比伦人必"如蝗虫乱跳"，吞吃全地；因为那些生物极其贪食，前进时毫不间断，跳跃之快令人惊异，把地上一切果实尽都吃光。有些人把这话解作同一批亚述人，仿佛先知把他们比作"蝗虫"，是因为他们必轻易被驱散；但这样的解释并不合宜，因为先知在此排列出一支"蝗虫"的大军，使它行进之处完全遮盖全地；他又极其优美地把"蚂蚱"与"蝗虫"作了对比，因它们贪得无厌，且数目庞大。

5<span style="color:#800000">*. 耶和华被尊崇。*</span>他更充分地阐明我们稍前简略提到的、关于神被高举的事，并接续我们从前所说的题旨，就是如此强盛之君国的倾覆，必显明神何等看重祂教会的拯救；为着教会的缘故，祂要彻底毁灭那城中之后尼尼微和她的居民。这一教训极其有益：神并不宽容被弃绝的人和不敬虔的人；因为祂抵挡他们非法的欲望，其目的正是要见证祂何等爱祂的选民；而神的荣耀在教会的拯救中最为明亮地照耀出来，这也是非同小可的安慰。

<!-- PAGE 754 -->
<span style="color:#800000">*因祂居高处。*</span>首先，他宣告神被高举"在至高之处"，而恶人却以为神因祂百姓的毁灭而被抛下、被降卑了。其次，免得有人以为神不过是收回了祂所失去的——世上常有这样的事：那些已被击败的人，一旦局势转为有利，便重新振作起来——所以他明明地宣告，神在人眼前被"尊崇"，因这原是祂配得的，缘于祂的伟大，因为祂居住在诸天之上。由此可见，虽然祂时常隐藏自己的能力，却从未失去祂的权柄；每当祂认为合宜，就公开彰显祂的至高地位；因为"住在天上"，如我们所知，乃是指最高的权柄，全世界都服在其下（<span class="ages-code">&lt;19B503&gt;</span>诗篇 115:3）。他这样不仅表明神能轻易迅速地拆毁世上一切高傲之物，更从神永恒的本性加以论证：当神被恶人藐视时，祂终究不能不彰显祂的荣耀；否则祂就是"背乎自己"了（提摩太后书 2:13）。

<span style="color:#800000">*他以公平公义充满锡安。*</span>他借此再次证实前面所说的：当犹太人从巴比伦人的暴政之下得蒙拯救时，这必成为神奇妙慈爱的凭据。把如此大福的赐予者摆在他们眼前，实属合宜；因为我们看见，他的荣耀何等可耻地被我们的忘恩负义所遮蔽。如今，「公义与公平的丰满」意思是，神在复兴教会之时，必丰盛而充沛地倾倒他的慈爱。然而，若把这些话理解为指合法的秩序，即万事都得着公正妥善的治理，也并非不合宜；因为若没有这秩序，教会绝不会享受兴盛，纵使其余一切都称心如意。所以，圣洁而井然有序的次序，而非会朽坏的财富，才是衡量我们兴盛与否的准绳。

<!-- PAGE 755 -->
**6.** <span style="color:#800000">*你一生一世必得安稳。*</span>他应许在希西家治下，国度的光景仍将是幸福兴盛的；尤其是当他把这光景与亚哈斯治下那可悲、毁坏、荒凉的景象相对照时，更是如此；因为纵然仇敌已被赶出，几乎无人会指望那受过如此沉重压迫的犹太人，能被恢复到从前的秩序。至于这些字句，有人译为：「真理、力量、拯救必在你的年日之中」，仿佛先知是在描述这民在敬虔君王之下所要享的兴盛；他们认为这些词各自表明神的诸般恩惠。另有人认为 <span style="color:#008080">אמונת</span> *(emunath)* 表示「信实」，仿佛先知说这信实必成为「拯救与力量」。还有人从中引出稍有不同的意思，即在希西家治下，「力量、拯救与知识」必「安稳」。但当我细察先知的字句时，我宁愿作另一种区分，即在希西家在位之期，「安稳、力量与拯救必藉智慧和知识得以坚立」。

<span style="color:#800000">*敬畏耶和华是他的珍宝。*</span>当他说「敬畏神」是敬虔君王的「珍宝」时，这与我们方才所作的解释正相吻合；因为在太平之时，人人都想过安稳舒适的生活，却少有人顾念自己当如何享用这等卓越的恩惠。事实上，大多数人巴不得像一群猪一样养肥自己；于是，当众人都被盲目的私欲驱使去追求外在的好处时，那无价之福——属天教义的光——却几乎被弃如敝屣。因此他的意思是：当「智慧与知识」在教会中掌权时，教会的兴盛必「安稳」[^f606]；当对神的「知识」得以通行时，教会的「力量」必长存；当人在认识神的事上得着良好的教导时，教会的拯救必存到永远。

这是一段极其值得注意的经文；它教导我们：当我们轻忽赐福之主，沉溺于粗俗而属地的欲望时，我们的忘恩负义便向神的祝福关上了门；并且我们所能渴慕或想象的一切福益，纵然实际得着了，若不用信心与知识的盐调和，对我们的救恩仍毫无益处。由此可见，除非教会一切的特权都以认识神的光为先导，教会便不处于健康的状态；唯有当神赐给它的一切恩赐都归给祂为其创始者时，教会才得兴盛。但当认识神的知识被夺去，当对神的正确认识被扑灭或埋葬时，任何一种繁荣都比一切灾祸更为可怕。

<!-- PAGE 756 -->
因这些缘故，我认为*稳固*、*力量*与*救恩*都指同一件事，就是当人的瞎眼与无知得了医治，开始认识神时，教会的境况便得安稳。由此我们也看出教皇党人所有的是何等的教会：它固然以排场与华丽著称，却缺少这「知识」，因此它不可能稳固或安稳，也不是神的教会。所以，倘若主将这福分赐给我们，使信心的光辉真实地照耀在我们中间，其余的祝福便会自然随之而来；即使我们被各样风暴摇动颠簸，我们也必始终有神的膀臂扶持。

<span style="color:#800000">*你一生一世*。</span>他对希西家说话，不是把他当作一个私人，而是当作全民的元首；他在这描述中把全体百姓都包括在内。但正如我们先前所论的，希西家的国度只是基督国度的一点微薄影儿，因此这些话必须归于基督，因为一切真智慧和知识都在祂里面。（歌罗西书 2:3）

我们应当留意此处所用的称谓，它们是为了称扬神的话语与福音。保罗在提到「用诸般的智慧」教导人时，也用了同样的称谓；因为他借着这样的称扬，高举福音的尊贵（歌罗西书 1:9, 28）。由此也当推论：凡不认识基督之处，人便缺乏真智慧，纵使他们在各门学问上受过最高的教育；因为在他们真正「认识神」以前，他们一切的知识都是无用的（约翰福音 17:3）。

<span style="color:#800000">*敬畏耶和华是他的至宝。*</span> [^f607] 我认为「敬畏耶和华」这一说法，是先知为了作解释而加上的，为要更充分地表明：他所论的知识乃是敬虔的教师，并非冷淡无生气的，而是大有能力地渗入我们的心，塑造我们「敬畏神」。因此，在圣经其他经文中，这「敬畏」也被称为「智慧」，或更确切地说，是「智慧的开端」，即智慧的本体与首要部分（箴言 1:7 和 9:10）。若以为「开端」一词指的是初阶或基本要素，那就错了；因为所罗门用它来指首要部分与目的。理由在于：正如人在顺服神的话语以前尽是愚昧，智慧的完全也是从信心的受教之心或顺服中生发出来的。所以「敬畏神」被称为「至宝」，若无此宝，一切的兴盛都是可悲的；这也更充分地显明本段的要旨，即幸福生命的全备完全在于对神的知识，而这知识是我们借信心得着的。

<!-- PAGE 757 -->
这样，他借着君王这个人物表明：以当有的敬虔和敬畏来敬拜神，乃是无价的福分。凡缺乏「敬畏神」之心的人，他都断定为可悲而败亡的；反之，凡「敬畏耶和华」的人，则被宣告为大有福气的，纵然在别的方面按人的判断他们被算为极其可悲的。他所说的这「敬畏」，是内中含有真实顺服、并更新我们内心的敬畏；因为还有另一种敬畏，甚至连恶人也受其影响，使他们惧怕神，如同罪犯惧怕审判官一样。那种「敬畏」不配得如此高的称赞；因为它既不是出于对神的真知识，也不是出于欢然敬拜他的愿望，因此与以赛亚所描述的智慧大相径庭。他说这些话是指着希西家说的，但正如我们已经说过的，这也关乎全体百姓；由此我们推论，这些话既适用于寻常地位的人，也适用于君王，但尤其适用于基督——正如我们先前所看到的，他被「敬畏耶和华的灵」所充满 [^f608]（以赛亚书 11:2），使我们可以有分于此。

**7.** <span style="color:#800000">*看哪，他们的豪杰* [^f609] *在外头哀号。*</span>究竟以赛亚在此是以历史的笔法叙述犹大人当时所陷入的可怕困惑与临近的危险，为要更鲜明地衬托出蒙拯救的恩惠，抑或是预言将来的灾祸，使敬虔人的心不至于在灾祸临到时立即消沉，这是难以断定的。就我而言，我认为这多半不是记述已过之事，而是因为沉重严酷的试炼已经临近，故此意在坚固信徒的心，使他们在境况最恶劣之时仍能忍耐等候神的帮助。无论如何，这里所描绘的是教会可悲可叹的荒凉，为使信徒即使在困惑之中也不停止怀抱美好的盼望；并且当他们脱离危险之后，可以知道这是靠神奇妙的大能所成就的。

<!-- PAGE 758 -->
<span style="color:#800000">*求和的使臣痛痛哭泣。*</span>那些被派去安抚暴君的使臣未能成功，这被视为绝望的标记；因为希西家曾尝试一切求和的途径与方法，却毫无成效。因此，「使臣」忧愁沮丧地回来，甚至在路上也无法掩饰他们的悲伤——当事态如此凄惨时，那悲伤是难以藏在心里的。他无疑是说，西拿基立傲慢轻蔑地拒绝讲和，以致「使臣」仿佛忘记了自己的身分，不得不在公开之处倾吐他们的忧伤与哀哭，甚至还未回到他们的王面前禀报使命，就已公然宣告他们从那残暴的君王那里得着了怎样的答复。[^f610] 另有人认为，「求和的使臣」是指那些素常宣告和平的人；但这种解释在我看来软弱而牵强。因此，我理解「求和的使臣」是指那些被派去平息那王的怒气、盼望能以某种条件换得和平的人。

**8.** <span style="color:#800000">*大路荒凉。*</span>他现在又补充说，「道路」将被封闭，以致无人出入；这是宣战之后常有的情形。先知似乎是描述使臣们宣告说，此后再无经商贸易的机会，甚至连大道也不再安全。[^f611] 紧接着又说——

<span style="color:#800000">*他们背了约。*</span>有些注释者认为这话是假冒为善之人的抱怨，怨神不履行他的应许。若有人以为宜将这话解作指着神说的，也不必因此断定这样的抱怨只出于恶人；因为有时信徒也会这样与神争辩。但我不能赞同那种解释；因此我认为这是先知描述西拿基立残暴与贪得无厌之怒的一部分，即他诡诈地背弃了先前与希西家所立的约；因为他虽曾应许维持和平，然而一有机会侵入犹大，他就违背应许，预备争战。本节末尾的话也是同样的意思：<span style="color:#800000">*他藐视城邑，不顾人民。*</span>这意思是说，他的残暴如此之大，以致羞耻或惧怕都不能拦阻他。

<!-- PAGE 759 -->
**9.** <span style="color:#800000">*大地悲哀衰残。*</span>先知在此更充分地描述犹大人将如何看自己的处境为可悲而绝望，为要使他们的信靠仍能从深渊中涌出。他也指名了那些地方：*黎巴嫩*、*巴珊*、*迦密*，这些地方彼此相距甚远，几乎构成圣地最远的边界，为要表明这地没有一处能保全无损。他描述这灾难的方式，是把各地所特有的归给各地。他把混乱归给「黎巴嫩」，因为别处提到它是美丽荣耀的，缘于其上长满高大而贵重的树木。他宣告「沙仑」这平坦肥美之区将「像旷野」，而盛产「果实」的「巴珊和迦密」将被「摇落」。他这样提及各地的天然特性，并这样描述那困苦愁烦，为要显大并阐明神的恩慈——他们虽似已全然败亡，神却仍要拯救他们；因为我们在此可以看见神的手公然显明出来，除非有人认为宁可视先知是在述说一件已过的事，为要激动他们感恩。

**10.** <span style="color:#800000">*现今我要兴起。*</span>「现今」这小词大有力量，随后所加的重复也是如此：「我要被尊崇，我要被高举。」我们当留意这些话所指的时候，就是教会显得已全然败亡之时；因为神宣告他要判定那时候乃是施行帮助最合宜的时候。所以这是彼此相反之事的对比；因为他向信徒摆出那将要压迫他们的沉重痛苦的灾难，若非有些安慰扶持他们，他们在其下必轻易沉沦。他仿佛是说：「主必容你们被降到极低，但当你们的境况坏到极处，当你们徒然试尽各种良方之时，主必兴起帮助你们。」因此，即使我们受苦、被降到极低，我们也当承认我们的拯救惟独从神而来。

因此，*现在*一词表明这是最深重苦难的时刻。人或许觉得这极其奇怪，但我们清楚看见神如此迟延施行帮助的最好理由。这是因为操练敬虔人的忍耐、试验他们的信心、制伏肉体的私欲、激发他们恒切祷告、坚固他们对来生的盼望，都是有益的；所以他加以约束，免得他们凭着轻率的急躁抢先于神已为他们所定的时候。这重复的说法极有力，是为了坚固这宣告而加上的；因为当我们的处境陷入绝望时，我们以为自己已经完了，然而正是在那时候我们尤其应当有盼望，因为主通常正是选择那时候来显明他的能力。为此，他借着高举自己的崇高，激动信徒奋勇，使他们能坦然无惧地藐视仇敌的狂傲。[^f612]

<!-- PAGE 760 -->

**11.** <span style="color:#800000">*你们要怀的是糠秕。*</span> 他现在将话语转向教会的仇敌，说他们的狂傲是愚妄的、徒然的；因为当神辉煌地显明他的能力时，他们就必知道自己的努力毫无果效，纵然结成庞大的联盟，也一无所成。主嗤笑他们的疯狂，因他们以为万事都在自己掌握之中，而其实主随时只需以他心意最微小的表示，就能约束他们、毁灭他们，纵然有极强大的军队护卫他们也无用。

圣经中惯用*怀胎*一词来表示人的计谋与努力。（约伯记 15:35；诗篇 7:14；以赛亚书 26:17 及 59:4。）这比喻取自怀孕的妇人。人图谋什么事，就说他们「怀胎」并「生产」；但先知宣告说，他们的「怀胎」必无果效，他们的「生产」也必徒然，因为凡他们所着手的都不能成功。所以，我们的对手那辉煌的军力并没有什么当叫我们惊惶的；因为，虽然神容许他们暂时忙乱、劳苦、发怒，然而神终必将他们一切鲁莽狂妄的图谋都变为*「糠秕」*。让我们晓得，以赛亚论到西拿基立所预言的，也关涉信徒与教会的一切敌人。

<span style="color:#800000">*你们自己的气要成火将你们烧灭。*</span> 「他们必被自己气息的火烧灭」，通常被解释为：「你们的气息如火一般，必吞灭你们。」但这是一个不恰当、甚至荒谬的比拟；真正的意思其实一目了然：「由你们气息所燃起的火，必吞灭你们。」我们通常是靠吹气把火点起来的，因此先知宣告说：恶人以其恶谋所吹起的火，必反过来毁灭他们，因为那火要把他们烧尽。这与圣经中常以各种隐喻所表达的，乃是同一个道理。

<p style="text-align:center; color:#000080; margin:14px 2em;" markdown="1"><span style="color:#000080">「他掘了坑，自己反掉在其中。他们</span> <span style="color:#000080">陷在自己为别人所预备的网罗里。他们所拔出的刀</span> <span style="color:#000080">刺入自己的心腹。他们的</span> <span style="color:#000080">箭反射回来，刺透自己的心。」</span> <span style="color:#000080">（</span><span style="color:#000080">诗篇 7:15; 37:15; 57:6。）</span></p>

<!-- PAGE 761 -->
如此，先知表明：那蹂躏犹大、率大军围困耶路撒冷的凶暴暴君，以及一切照样与教会为敌的人，都是自招灭亡，终必被毁灭；总而言之，他们必被自己所点起的那「火」烧尽。

**12.** <span style="color:#800000">*列邦必像已烧的石灰。*</span> 他把他们比作「已烧的石灰」，因为他们的刚硬必被压碎，正如火使石头变软，以致轻易化为粉末；毫无疑问，恶人越是被伤害人的欲望所猛烈点燃，就越是因自己的骄横而压碎自己。

<span style="color:#800000">*像已割的荆棘。*</span> [^f613]这个比喻同样贴切；因为荆棘虽以刺伤人手的痛苦阻止人触摸它们，然而没有一种木柴烧得比它更猛烈、也更快被烧尽的。我们已说过，「石灰」也有相似之处：起初坚硬，却被火烧软。先知宣告，同样的事必临到巴比伦人身上；主必轻易毁灭他们，尽管他们起初看来可畏，尽管人或以为他们不可能被任何烈火烧尽。因此，每当我们看见教会的仇敌聚集各样财富、军力和军备，要毁灭我们、焚烧全世界的时候，我们当知道，他们所点起的火，正是要惨然毁灭他们自己的火。

我们知道这话在西拿基立身上得了应验，因为事情的结局证实了这些预言的真实，虽然它们当时看来全然难以置信。让我们盼望，凡效法这暴君行径的人，也必遭遇同样的事；让我们在患难与困苦之中，以这个例子和无数其他的例子安慰自己，因为随之而来的必是确实的拯救，以及对我们仇敌可怕的报应。

<!-- PAGE 762 -->
**13.** <span style="color:#800000">*近处的人哪，你们远方的人。*</span>以赛亚在此作了一段序言，仿佛他即将论述一件极其重大的事；因为他吩咐听众要专心留意，这乃是在处理某件重要而非凡的题目时常有的做法。他既向<span style="color:#800000">*近处的人*</span>说话——他们将亲眼目睹这事——也向最遥远的列国说话，因为这消息必传到他们那里；这好像是说，神的能力将是这样的，以致不但少数人或近处的人能觉察，就连远在极遥远之处的人也必觉察。因此他的意思是：这将是神的能力一次惊人而非凡的显明，因为恶人从前漫不经心、无忧无虑，好像自己脱离了一切患难与烦扰的危险，如今却要因惊恐而战抖。

**14.** <span style="color:#800000">*锡安中的罪人都战兢。*</span>但或许有人会反驳说，这里所论的事并不那么重大，以致需要那样崇高的序言来唤起全世界。恶人受惊恐所击打，难道是何等重要的事吗？然而若细察便可看出：当恶人从他们的懒惰中被惊醒，以致无论愿意与否，都察觉神是他们的审判者，这绝非神能力的寻常显现，尤其当对神的轻蔑还伴随着假冒为善的时候。因为虽然当帕子蒙在不敬虔之人心上时，[^f614] 要惊醒他们是难事，然而假冒为善之人的顽固更甚，他们竟以为神欠他们的债。这样我们看见，人被疯狂所迷惑，以致轻看一切威胁与恐吓，讥笑神的审判，总之，用巧妙的戏谑把一切预言置之不理，因此那样抗拒的人竟被推翻，理应被视为一件奇事。所以以赛亚有充足的理由向他们发出义愤；因为当他用「锡安」一词时，他无疑是在责备那些堕落的犹大人，因为他们既被圣所的荫庇所覆盖，就以为自己占据了一座不能被攻取的堡垒；无疑，正如我稍前所指出的，在众人中最傲慢、最骄横的，正是那些躲藏在神的名下、并以教会的名号自夸的人。

<!-- PAGE 763 -->
<span style="color:#800000">*不敬虔的人被战抖抓住。*</span><span style="color:#008080">הנפים</span>*（chanephim）*被译作「假冒为善的人」，但更常见的，可视为指「*背信*的叛逆者，以及全然卑劣的人」。既然他们如此邪恶，讥笑神与众先知，先知就恐吓他们说，神必作一位如此尖锐严厉的审判者，以致他们再也不能以自己的诡诈为乐。接着又加上一段带有谦卑外貌的认罪，为要更清楚地表明：假冒为善之人既不肯甘心顺服神，最终却要从经验这位教师学到神的审判是何等可怕。所以，他们的「喜笑」一旦变为「切齿」，他们就开始承认自己全部的力量不过是糠秕或碎稭。（路加福音 6:25；马太福音 8:12）

<span style="color:#800000">*我们中间谁能与吞灭的火同住呢？*</span> 至于这些字句的意思，有人译作：「谁能*代替我们*同住呢？」另有人译作：「我们*中间*谁能同住呢？」若我们单单按「向我们」或「为我们」的意思来看，其含义可如此解释：「谁能迎着这火，或站在中间，使火焰不至临到我们呢？」此外还有别的解释，意思大同小异；但注释家的分歧在于：有人认为这话是指亚述王说的，有人则认为是指神说的。我更赞同后一种看法，理由前面已经说明；因为亚述王固然可被视为一团「火」，以其烈焰焚烧全地，然而先知所要表达的乃是远为可怕的事，就是不敬虔的人内心所受的痛苦煎熬、无法平息的良心刺痛、以及那超乎一切酷刑的、罪恶所燃起的不灭之火；因为不敬虔的人无论行的是什么路，他们必发觉神向他们的作为也正是如此。

因此，为着他们的缘故，神被称为*吞灭的火*，这是我们从摩西可以学到的（申命记 4:24 和 9:3）；正如我们屡次指出的，众先知的教义乃是取自摩西，使徒也照样跟随他（希伯来书 12:2、9）。这一解释又为先知自己所证实，他指出那惊恐的缘由何在。有人或许反驳说，神未免过于严厉，把他们吓得过了分；但神向敬虔人通常是慈爱温和的，惟有恶人才感到祂严厉可畏。有些人认为，先知的用意是要叫万人知罪，好使他们撇弃一切对自己行为的倚靠，谦卑俯伏地投奔神的恩典，仿佛他说：「除非是全然公义的人，无人能站在神的审判台前，因此众人都在咒诅之下。」

<!-- PAGE 764 -->
但他其实是以那些从前藐视一切威吓之人的口吻、按着他们的心情说话；如今他把这些人描绘成战兢惊惶地发问：「谁敢进到神的面前呢？」这哀恸的怨言，正显明那新近攫住他们的恐惧；当他们深知自己的脆弱时，便忧伤地喊着说：「谁能忍受神的面呢？」然而，尽管神迫使他们不情愿地说出这些话，他们仍旧向神发怨言；因此，先知在另一方面为要止住他们邪恶的吠叫，便回答说：神本性上并非叫人恐惧惊慌的对象，这恐惧乃是因他们自己的过犯而生的，因为神不容良心闲懒不动，良心便以他们的罪行惊吓他们。

**15.** <span style="color:#800000">*行事公义的。*</span>因此，他如今更充分地解释了我们方才简略提及的：那些惹动他忿怒、从而把他的宽容驱离自己的人，无权抱怨神过于严厉。他这样使他们知罪，并劝他们悔改；因为他表明，人若愿意追求并实行「公义」，若持守真理与正直，若脱离一切败坏、待邻舍无可指摘，神与人之间便有友谊的关系。但因为他们充满各样的邪恶，放纵自己去行恶毒、毁谤、贪婪、抢夺和其他罪行，主就不能不以显明自己是可畏的，来使他们惊惶。总之，先知的用意是要堵住恶人饶舌的口，免得他们在自己灭亡时控告神残忍；因为一切的过咎全在他们自己身上。他们企图用推诿来逃脱定罪。然而先知宣告说，神对敬拜他的人总是施恩的；摩西正是在这个意义上称他为「烈火」（申命记 4:24，9:3），免得人藐视他的威严与权能；但凡以真诚敬虔亲近他的人，都必凭实际的经历知道，没有什么比他的同在更甘美、更喜乐。所以，既然神以慈颜光照信徒，他们就藉着无亏的良心与他享有安稳的平安；由此可见，神本性并非可畏，乃是我们的邪恶迫使他如此。

<!-- PAGE 765 -->
这段话主要是针对假冒为善之人而发的；他们用虚假的敬虔面纱遮盖自己隐藏的污秽和罪行，滥用神的名，好使自己更放肆地作恶。先知藉着所举出用以说明「公义」的例证，更公开地责备他们的罪。他列举生活中主要的行为，我们藉这些行为显明自己是怎样的人。在这里，正如在许多其他经文中一样，他论到律法的第二块法版，敬虔的真诚就是由此受试验的；因为金子怎样在火中受试验，我们对神所存的心志，也照样从我们日常的生活方式中显明出来，就是当我们的真诚藉着彼此当尽的本分显露出来的时候。

**行**这个词是众所周知的「道路」隐喻，圣经常用它来描述人的生活方式或惯常的行为。他所说的公义，并非指全然遵守律法，而是指第二块法版所包含的公平；因为我们不可想象这里所要讲的是关于「义」的精微辩论。

<span style="color:#800000">*说正直话的。*</span> 他现在列举那当持守之正直的几个主要方面；因舌头是人用以规范自己行为的首要器官，故他将它置于「公义」之后的第二位。凡约束自己的舌头，不出诽谤与恶言，不行诡诈、伪誓与虚谎，以致在任何事上都不亏负弟兄的，就被称为「说正直话的」。接着又加上另一方面，

<span style="color:#800000">*憎恶欺压的财利的。*</span> 他本可以用一句话说「藐视钱财的」；但他采用了更为通俗的言语，迁就人的无知。凡贪恋财富的人，必不禁止自己行抢夺，也不禁绝卑鄙不法的求利之途，反倒搅扰并欺压贫穷软弱之人，除了从各方各面、用一切或正或邪的手段攫取钱财以外，别无所顾。他接着更进一步，描述各样的败坏。

<!-- PAGE 766 -->
<span style="color:#800000">*摆手不受贿赂的。*</span> 他以**贿赂**为名——审判官正是因此被收买——同时也把其余一切都包括在内。没有什么比这更能扭曲人的心志与公正的判断；因此他吩咐他们「摆手」，藉此表明这等事当受何等的憎恶，众人当何等谨慎地躲避，免得他们仅仅经手，或仅因轻轻一触而被玷污，就被引离公平正直之道；因为「贿赂」有奇异的迷惑之力，以致审判官极难保守自己的手全然洁净、不被它沾染。那么，对于那些始终伸出手随时准备收受、张着弯曲的爪随时准备攫取的人，我们又当作何看待呢？不但如此，他们还像妓女一样，公然为财利出卖自己。若神以毫不宽贷的报应向他们发出雷霆之怒，我们何必希奇呢？

<span style="color:#800000">*塞耳不听流血的话。*</span>最后，他要求正直的表现也当显在**耳**中。他所说的**血**，是指凶杀与残害，但同样也包括各样邪恶的阴谋，使我们的"耳朵"不向这些事敞开，以致我们竟予以赞同。他的意思并不是说，当穷人受欺压凌辱而哀求时，我们当塞住"耳朵"；乃是说，我们当憎恶那些无耻之徒图谋陷害无辜之人的恶计，甚至连"耳朵"也不出借给他们的言谈，也不容自己被他们以任何方式怂恿去行恶。

<span style="color:#800000">*闭眼不看邪恶事的。*</span>最后，他要求"眼目"也当有同样的圣洁。总之，他教导我们：若要逃脱神的忿怒，逃脱他先前所说的那可畏的焚烧，我们就当约束自己一切的感官，不给恶人任何表示赞许的记号。

**16.** <span style="color:#800000">*他必居高处。*</span>为要使犹太人晓得神所加于他们身上的管教乃是公义的，并使他们努力重得神的恩眷，他说神的祝福已预备好要赐给善良正直之人，就是他在前一节中所描述的那等人；这些人不遭遇任何危险，也无须惧怕他所提及的那焚烧，因为他们必被安置在极其稳妥之处。至于恶人、毁谤者、强盗和诡诈之徒，他们不能约束自己的舌头、手、耳、目，不去行卑劣邪恶之事；先知则表明：若神严厉地对待他们，我们不必希奇；并且当神作他们审判者的同时，他们自己的良心也作了他们的刽子手；因此，唯一能使他们不惧怕神同在的办法，就是甘心自愿地持守敬畏神的心。他所说的"高处"，是指极其安稳、脱离一切危险、仇敌的攻击不能及之处，这一点他随即以"坚垒的磐石"作他们的居所，说得够明白了。

<span style="color:#800000">*他的粮必赐给他。*</span>在稳妥的居所之外，他又加上丰盛的美物；仿佛说，那圣洁正直敬拜<!-- PAGE 767 -->神的人必一无所缺，因为神不但要保护他们，使他们脱离一切危险，得蒙安全，也必丰丰富富地供给他们维持生命所需的一切。他用「粮」和「水」二字，指日用一切的必需之物。

<span style="color:#800000">*他的水必是确实的。*</span>恶人虽暂时丰足，日后却必饥饿；正如神在律法中所威吓的，他们必遭饥荒饥饿。（利未记 26:19；申命记 28:23, 48）关于「粮」也可作同样的解说，因为「确实」一词是兼指二者的；仿佛他说，凡信的人，他们的食物都必得着「确据」。「少壮狮子还缺食忍饿，但敬畏神的人什么好处都不缺」（诗篇 34:10）；因为神本性乃是丰厚施与的，他并不因慷慨赐予而困倦，也不因施行恩慈而耗尽他的丰富。

此外，既然人的生命暴露在种种危险之下，又既然单有丰盛的饮食并不足以维系我们，除非主用他的大能护卫我们，因此我们就当细心留意他先前所提的：信徒是被安置在稳妥的居所中。主执行牧人的职分，不但供给他们食物，也保护他们免受强盗、仇敌与豺狼的侵袭；总之，他将他们保守在自己的庇护与看顾之下，不容任何祸患临到他们。所以，每逢仇敌搅扰我们的时候，我们当思想：这是我们因自己的罪所当受的公义刑罚，我们被剥夺神的帮助，乃因我们不配得着；因为凡我们所忍受的一切灾祸，都当归咎于我们自己的罪。

<!-- PAGE 768 -->
然而，那些自知自己正直的人，切不可以为神已离弃他们；他们当到人生的最后一日，仍倚靠那些应许，就是主向自己的百姓保证要作他们极稳妥避难所的应许。诚然，无人能圣洁或正直到可以承受神眼目鉴察的地步；因为正如大卫所说：「主耶和华啊，你若究察罪孽，谁能站得住呢？」（<span class="ages-code">&lt;19D003&gt;</span>诗篇 130:3。）所以我们需要一位中保，藉着他的代求，我们的罪得蒙赦免；先知并非有意撇开圣经在这题目上一贯的教训，乃是要使恶人惊惧，他们时常被邪恶的良心刺痛追逼。[^f615] 我们必须格外留意这一点，以驳斥教皇派的博士们，他们滥用这类推崇善行的经文，为要摧毁信心之义；仿佛我们藉基督的祭所获得的赎罪，理当被撇在一旁。

**17.** <span style="color:#800000">*王的荣美。*</span> 虽然先知在此转换了人称，这一节却必须与前一节相连；因为他是向那些真诚敬拜神的人说话，向他们应许这额外的福分：<span style="color:#800000">*你的眼必见王的荣美*</span>。当犹大的局势如此可悲、如此绝望之时，这应许对于扶持信徒的心是极其必要的。当耶路撒冷被围困，王被困在城中、四围尽是奸诈的谋士，百姓摇摆不定、纷乱背叛，一切都急速趋于灭亡，似乎再无指望存留。然而大卫家中的王权，仍是神慈爱的一个显著凭据。因此，以赛亚针对这危险宣告说，他们虽看见自己的王身穿污秽的衣服，他却必被复归于从前的尊位与荣耀。

首先，我们当留意，当国家太平、享有良善的君王，凡事都被公正忠信地治理时，神的恩慈是何等无价；因为神是藉着他们的职事来治理我们。既然这样的福乐并非小事，先知在向敬拜神的人应许兴盛时，就不愿略去这一部分。然而也当留意，那国度乃是基督国度的预表，希西家所承载的正是基督的形像；因为若我们不将这应许追溯到基督——这一切都当被理解为指向他——那么这应许的应验就微不足道了。切勿有人以为我在此追求寓意解经（我素来厌恶寓意解经），并以为这就是我不把这段经文直接解作指基督的缘故；乃是因为唯独在基督里才能寻见那脆弱国度的稳固，所以希西家所承载的相似之处，就仿佛牵着我们的手，引我们到基督那里。因此，我愿意将希西家看作基督的表记，好叫我们晓得他的荣美将是何等浩大。总而言之，以赛亚在此应许教会的复兴。

<!-- PAGE 769 -->
<span style="color:#800000">*看见辽阔之地。*</span>教会的复兴包含两个部分：其一，「必得见王的荣美」；其二，国度的疆界必得扩张。我们知道基督的形貌是如此毁损，以致在世人眼中被藐视，因为在他身上看不见「佳形美容」（以赛亚书 53:2）；然而到了终局，他的威严、荣光与荣美必公然显明，他的国必兴盛，必广远地扩张。虽然如今恶人手中掌握一切，压迫神真实的仆人，以致他们几乎找不到一块可以安然立足之地，我们仍当以坚定的盼望仰望我们的王，他终必坐在他光辉华美的宝座上，荣耀地使他的百姓富足。

**18.** <span style="color:#800000">*你的心必思想那惊吓的事。*</span>此处再次告知信徒有何等的灾祸临近，免得他们因忽然遭遇如此沉重的苦难而在其下沉沦。<span style="color:#008080">יהגה</span> *(yehgeh)* 有人译为过去时「思想了」，有人译为将来时「必思想」；因为希伯来文中时态如此互换乃是常事。就我个人而论，我认为先知是在警告百姓有患难将临，而非叙述他们从前所忍受的患难，故我乐意保留将来时，这也是先知所用的时态：「必思想」。

<!-- PAGE 770 -->
<span style="color:#800000">*记数目的在哪里呢？*</span>他以戏剧化而生动的方式（<span style="color:#0000d4">μιμητικῶς</span>）述说那些被惊吓所胜之人的言语，他们发出这样的呼喊：<span style="color:#800000">*记数目的在哪里呢？平银子的在哪里呢？*</span>这样便表达出他们心中所受的强烈震撼。倘若有人以为思路在此突然中断，因为先知在前一节讲论「王的荣美」，如今却提出惊吓之事；我却毫不怀疑他是借着对比来彰显神的恩慈，使信徒在得蒙拯救之后，更加珍视他们所达到的境况。人在评断神的恩惠时是善忘而吝啬的，一旦得了释放，便不再思量自己先前的苦难有多深。这样的人需要被提醒那些困苦悲惨的时日，就是他们曾大受痛苦的时日，为要使他们更充分地领会神所赐给他们的恩惠是何等浩大。我们也当留意另一个理由，说明为何预先警告百姓那惊吓之事是有益的。这是为了叫他们听闻王的荣华之后，不至于自以为可以免除一切的困扰，而是预备好承受各种患难与愁苦；并且即使他们仍在纳贡、仍被围困之中，也可以知道犹大国乃是神眷顾的对象，必从暴君的手中被救出来。

先知在此所描述的，是极其可悲的境况：一个自由的民族竟被如此残暴的暴政所压制，以致他们一切的财产都被估价，他们的房屋、产业、家眷、仆婢都被逐一登记入册。这种奴役何等沉重，在我们的时代，许多素来不曾经历过的人如今已亲身体验到了：他们的财产被估算到最后一文钱，不但确实的收入被估价，连预期的进益也被估价；不但他们的银钱与产业，连他们的名字都被登记在册；同时又发明新的征税办法，不但加在食物上，甚至加在最微小的物品上，以致暴君夺去了那些可怜百姓不可缺少之物的大部分。然而这些灾祸仍不能约束人的骄横、放荡与叛逆。那么，当他们得着自由、完全无拘无束的时候，又将如何呢？他们岂不要忘却自己一切的苦难，不记念神的恩慈，比从前更放纵地投身于各样的纵欲与放荡之中吗？因此，先知将那可悲的境况摆在这百姓眼前，并非没有充分的理由：好使他们得蒙拯救之后，不再任凭自己不法的私欲，而是认识那拯救他们的主，并全心爱他。

有些人错误地想象保罗（哥林多前书 1:20）引用了这段经文；因为那样便会破坏先知的原意，并把他的话曲解为另一种用途。他们之所以陷入这错误，只是因为「文士」一词的用法，而在那里这词是指「教师」。以赛亚称那计算人口、家眷、田地、房屋，简言之，就是保管税册的人为「文士」；他所说的「秤银子的」，是指收取税银的人，因为他要「秤」所缴纳的银钱。这职务在今日是由那些被称为财政官的人所担任的。

<!-- PAGE 771 -->
<span style="color:#800000">*数点高台的在哪里呢？*</span> 他现在又加上一类极其麻烦、极其令人憎恶的人，就是「描述高台的人」，即描述那些较为显赫的建筑物的人；因为他们逐家察看查验，为要知道谁比别人更为富有，好向他们索取更多的银钱。这样的人，好像猎犬一般，常被暴君所使用，去嗅寻银钱的踪迹，以便在寻常的税项之外再加上某些非常的征敛。这等人的到来，必定使百姓极其苦恼，因为他们不吸尽人的血、吮尽人的骨髓，就绝不停手。若有人宁愿把这词看作是指王自己的臣仆，就是那些奉命拆毁靠近城墙的房屋的人，也就让他持守自己的看法吧。至于我自己，我认为先知所说的很可能是那些收税之人，就是征服者为了维持自己的权威而设立在被征服之国之上的人。

**19.** <span style="color:#800000">*你必不见那强暴的民。*</span> <span style="color:#008080">נועז</span> *(nognaz)* 一词，有人译作「强壮的」，有人译作「无耻的」；但毫无疑问，先知在此是要表达亚述人的凶暴，这一点他随后又加以确证，说他们与这民毫无往来，因为他们所说的是另一种语言。没有什么比言语的往来更能激起人的怜悯了，因为人藉着言语彼此诉说自己的苦难。当这一点缺失时，就无从赢得他们的心；彼此都是化外之人，从他们身上所能得着的，不过如同与野蛮凶残的走兽打交道一样。所以，先知详细描述这百姓可悲的光景，为的是从另一面显明：神救他们脱离如此可怕的恐惧，其恩慈何等浩大。照样，圣灵也高举神的恩典，就是祂在埃及保守祂的百姓，虽然

<p style="text-align:center" markdown="1"><span style="color:#000080">「他们</span> <span style="color:#000080">不明白那国的言语。」</span> <span style="color:#000080">（诗篇 131:5）</span></p>

<!-- PAGE 772 -->
**20.** <span style="color:#800000">*你要看锡安。*</span> 有人将此读作呼格：「锡安哪，你要看」；但读作宾格更为可取。他在此提出教会必得复兴的应许，这应许对一切敬虔人都当有极重的分量；因为当教会动摇或倾覆时，就再无兴盛的盼望。他宣告教会必得复兴，其说法乃是将此事摆在我们眼前，如同已经成就了一般，尽管他所讲的是将来的事；他的用意是使他的文体更具力量，仿佛说：「你必再看见锡安得着复兴，耶路撒冷繁荣兴旺。」信徒虽然眼见万事尽都毁坏离散，虽然对她的安全已经绝望，然而在耶路撒冷必有安静稳妥的居所。

<span style="color:#800000">*我们守圣节的城，*</span>或作*我们聚集之城*。他用这称呼表明，我们判断锡安的复兴主要应当基于这一点：百姓在那里「聚集」，为要听律法、坚立耶和华的约、求告他的名、并献上祭物。当百姓被夺去这些的时候，他们就分散、几乎灭亡，显得与他们的元首隔绝、被全然弃绝了。因此，敬虔人被掳在巴比伦时，最深切哀恸的莫过于被赶离本乡，同时又被夺去这些福分；从许多经文可以极其明显地看出，这乃是众信徒最主要的哀怨。（<span class="ages-code">&lt;19D704&gt;</span>诗篇 137:4）

他称「锡安」为「城」，因为它位于城的中心，也称为「大卫的城」（以赛亚书 22:9）。耶路撒冷的范围则不同、更为广大；因为，正如我们在解释另一处经文时所提到的，[^f616] 那里有双重城墙，这在许多城中是常见的。此处当注意：教会的复兴乃是一切福分中最宝贵的，理当在万事之上被渴慕；若单缺这一样福分，其余一切纵然极其丰盛也毫无益处；反过来说，只要耶路撒冷——就是教会——兴盛，我们就不可能不幸。如今，当神在我们的聚会中掌权、当我们奉他的名聚集因而紧紧依附他时，教会便得复兴、便得兴盛。恶人固然也躲藏在神的名下，仿佛他们是奉他的命令聚集的；然而这只是空洞的假面，因为他们的心与他离得甚远，所行的一切也毫不出于顺服他的权柄。

<!-- PAGE 773 -->
<span style="color:#800000">*耶路撒冷是安静的居所。*</span>他说，那些长久在无数惊恐中动荡不安的信徒，将在神的教会里得着安全「安静的居所」。虽然神在希西家治下曾使他的百姓略尝那平安的滋味，然而唯有在基督里，这平安才得以成就显明。这并不是说，自那时以来神的儿女在世上就有了安静的居所；即使在今日，这份安静仍是隐藏的；因为我们所过的生活极其漂流不定，被各样的狂风暴雨颠簸摇荡，受无数仇敌攻击，必须打各种仗，以致几乎没有一刻得安息。所以，所应许的平安并非我们肉身感官所能觉察的，我们必须进到那已被神的灵更新的内心情感里，好叫我们享受那人的悟性无法测度的平安；因为正如保罗所说，它「出人意外」（腓立比书 4:7）。倘若我们住在教会中，主必定将这平安赐给我们。

<span style="color:#800000">*不动的帐幕，其中的钉子永不拔出。*</span>先知借着「帐幕」与「钉子」这些比喻，准确地描写了教会的处境。他本可称之为根基稳固的城邑，却说它是「帐幕」；帐幕按其本性乃是能够迅速迁往别处之物。这样，我们虽然看教会的处境为不定、易受诸多变动，却仍可知道它不能被移动、不能被摇动；因为纵有狂风暴雨，纵有一切仇敌的攻击，即使与它外表的本性相违、与我们理智的判断相反，它仍必存留。这两个说法看似彼此矛盾，唯有信心能使它们和谐，因信心坚持说：住在这「帐幕」之中，比住在最坚固设防的堡垒里更为安全。

每当我们看见教会不但被摇动，甚且被猛烈地驱赶到四面八方，我们就当以此为盾牌抵御试探，否则那些试探必迅速摧毁我们的信心。在那样猛烈的风暴之中，谁会说这「帐幕」是安全的呢？然而神既不愿他的百姓完全定居于地上，好使他们更单单倚靠他自己，那么他所应许给我们的护庇，就当被看为胜过百重、胜过千重的支撑。

<!-- PAGE 774 -->
**21.** <span style="color:#800000">*因为耶和华在那里必与我们同在，大有威严。*</span>这两个小词 <span style="color:#008080">ים</span> <span style="color:#008080">כי</span>（ki im）常起双重肯定的作用，但此处是说明缘由，甚至可以恰当地译作「因为若是」；不过我宁愿保留较为明晰的译法。先知在此说明，为何看似一座可移动的「帐幕」的教会，其稳固却胜过根基最牢的城邑。这是因为「神在其中」，正如诗篇也说：（诗篇 46:5）「必不动摇。」我们若把教会与神分开，它立刻就要倾倒，无需任何攻击；因为那时它只由人所组成，而再没有什么比人更软弱、更脆弱的了。

<span style="color:#800000">*必给我们作江河宽阔之处。*</span> 当神与我们同住时，祂便坚固并扶持那本性软弱的，为我们作极坚固的堡垒、极宽阔的壕沟，作四面环绕城邑的城墙与「江河」。他此处暗指耶路撒冷城的位置，那城只有一道细小的溪流，而没有像巴比伦及其他城邑所有的宽大湍急的江河；因为在另一处经文（以赛亚书 8:6）中，他吩咐他们单单以神的能力为满足，不可贪恋那些宽阔的江河。仿佛他说：「若神掌管我们，我们的力量必是不可战胜的；因为在祂的引领与指教之下，我们必得丰盛的保障。」

<span style="color:#800000">*其中必没有荡桨摇橹的船来往。*</span> 大江大河常带来这样的不便，就是可能给仇敌开路，使他们能驾船逼近到不合宜的距离；因此，常常那看似有益的，反倒被发现是有害的。但当主说祂必作「江河」时，祂也说必无须惧怕这样的不便，仇敌必不得靠近。他提到两类船只——长船与货船——为要表明仇敌必被彻底拒之门外。由此我们当汲取一个极有益的教义，就是得救的盼望不当从别处寻求，唯当单单求于神；若祂不与我们同在，收集各样防御的手段乃是徒然的，那些手段不但无用，甚至有害。

**22.** <span style="color:#800000">*因为，耶和华是审判我们的。*</span> 先知现在解释神如何住在教会之中。就是：祂在那里被敬拜、被承认为*审判者*、*设律法的*和*君王*；因为那些顺服神、甘心以祂为王而降服于祂的人，必凭经历知道祂是他们救恩的守护者；但那些假意以祂的名夸口的人，指望祂帮助乃是枉然。我们只要顺服祂的权柄，听祂的声音，遵行祂的话；反过来，祂必显明祂是我们的保护者和最信实的守护者。但当我们藐视祂的声音、悖逆祂的话语时，我们无疑没有理由希奇祂在危难中撇弃我们、离弃我们。

<!-- PAGE 775 -->

由此我们也应当留意，何为神的真教会。真教会乃是承认神为「立法者」与「君王」的那一群人。既然教皇派弃绝了摩西、众先知与基督所命定的合法治理，反而以人的发明和卑贱的买卖来取代它，他们竟还敢自夸是神的教会，其厚颜无耻何至于此！他们对良心施行残暴的专制，夺去基督所赐给我们的一切自由，可怜地折磨人的灵魂，引他们走向沉沦；然而唯有神有权柄管治良心，因为唯有他是「立法者」与「审判者」，也唯有他当以他的话语来治理并引导我们。他在此把「审判者」、「立法者」和「君王」三个称号连在一起，因为这题目极其重要，不可轻忽置之。所以，倘若我们容让自己被他的话语引导，他必永不离弃我们；这也是得救的唯一道路。

**23.** <span style="color:#800000">*你的绳索松开。*</span> 他将话语转向亚述人，并借着他们的名义，同时也向教会一切的仇敌说话。他既已应许教会必得永不动摇的稳固，如今便责备不敬虔的人所自夸的愚妄倚靠；他们仿佛已深深扎根，直达地心。虽然他们在兴盛的迷醉中，自以为财富极其牢靠，先知却预言毁灭必速速临到他们，因为他们并没有神的手扶持。

他继续沿用起初所用的比喻。他先前说，教会好像一座设有防御、四围环绕着极宽阔江河的地方，使仇敌无法靠近；如今他把恶人的境况比作船只，意思是他们虽显得可畏，虽狂暴急切、凶残暴虐，自以为无人能抵挡他们的怒气，却并无稳固的根基。所以，他们纵然有长船和货船，藉此似可使相隔遥远的各国彼此相通，并作海洋与陆地的主宰，他们仍必没有长久，也没有稳固。主必使他们的船沉没，除去他们的缆索和桅杆，使他们陷入全然的船破之中。因此，我们不要因他们的暴怒和骄横而惊惶，倒要仰望主的日子，那时他必使他们的怒气与凶暴归到他们自己的头上。

<!-- PAGE 776 -->

**24.** <span style="color:#800000">*其中的居民必不说：我病了。*</span>先知在此又回到教会的题目上；因为他所宣告要临到亚述人的毁灭，同样也是为了安慰敬虔人，因为教会的安全若非主赐下保护，抵挡那从四面八方攻击、扰害她的众多敌人，便无法维持。所以，他既已简略地指出一切苦害神儿女的被弃者都必败亡，便合宜地继续他的主题，肯定神必不遗漏任何足以促进敬虔人得救的事。因此他说，教会的居民必脱离一切苦患，因为他们藉着神的恩眷必享安泰。

<span style="color:#800000">*其中居住的百姓，罪孽都赦免了。*</span>本节后半句解释了前半句；因为它表明，当我们的罪得了赦免，就再没有什么能阻挡我们丰盛地享受神的祝福。由此我们也断定，一切压迫我们的苦难都不出于别的源头，只出于我们的罪。若不这样看，他所提出的理由似乎就显得牵强而不切题；但我们必须持定这一原则：神加在我们身上的一切灾祸，都是他忿怒的诸般标记。由此可见，罪责一经除去，所剩下的便只有神以父亲的慈爱看顾我们，并恩慈地将我们一切所需的赐给我们。所以，我们若渴望脱离苦难，就当遵循这样的次序：先求与神和好；因为原因一除去，结果也必随即除去。

但既然我们的愿望乃是失序的，既然我们只急于逃避刑罚，却对我们苦难的根源闭目不看，那么我们得不着丝毫的减轻，也就不足为奇了。所以，那些放纵自己恶行、却又想免去各样苦难的人，实在是大错特错。他们即使不受患难困苦，仍不会不是可怜的，并且只要良心因自己的罪行而受追讨，他们就无法享受心中的平安。因此，真正的福乐在于：我们已从神那里得着赦免，并诚实地相信，凡我们从他手中所领受的一切恩福，都是出于他慈父般的恩慈。

<!-- PAGE 777 -->

我们也当学到：除了神不再将我们的罪归给我们之外，我们别无他途可以取悦神，或得着被算为他儿女的尊荣；因此，唯有我们借白白的恩典所得的和好，才使神向我们息怒，并开通道路，使我们得享他的美善。虽然在免受苦难一事上并无可见的明证，这也丝毫不减损应许的真实，因为信徒在患难中已充分满足于这样的安慰：即便他们受神的手管教，他们仍是他所爱的儿女。就他们已被他的圣灵更新而言，他们已开始尝到那在亚当堕落之前完全无缺的福分；但因他们仍负着许多罪，就不断需要被洁净。然而，神仍怜恤他们的软弱，减轻他们的刑罚；即使不是全然除去，至少是缓和、抚慰他们的忧伤，以此表明他促成他们的福乐。所以先知宣告教会得免于寻常的灾祸——就其出于神的咒诅而言——并非没有充分的理由。

由此我们也清楚看见，教皇党人的那种区分何等幼稚，就是说罪咎的除去毫无功效，仿佛我们还须满足神的审判。然而众先知所教导的却大不相同，这从许多经文中都容易看出；即便除这一处经文之外别无其他，还有什么比这更明白的呢：疾病得以终止，是因罪孽已蒙赦免。其意思无疑等于说，刑罚止息，是因罪已得赦。诚然，神虽已向他们息怒，[^f617] 他有时仍加刑罚于信徒；其目的乃是要藉父亲般的管教，使他们在将来受更充分的教导，而不是要向他们施行报复，好像他只是半和好了一般。但教皇党人以为他们的刑罚具有补赎的性质，以为藉着付上这些，罪人在某种程度上赎回自己，除去自己的罪咎；这与白白的赦免绝不相容。这样，他们关于补赎、关于炼狱之火的可憎发明，就都一并倾倒了。

<!-- PAGE 778 -->
同样值得注意的是，唯有教会的citizens——教会的子民——才享有这特权；因为在基督的身体之外、在敬虔人的相交之外，与神和好便毫无指望。因此，我们在信经中承认信「大公教会，罪得赦免」；因为神所包含在他慈爱对象之内的，唯有那些他算为他独生子肢体的人；照样，他也不将白白归算的义延及任何不属他身体的人。由此可见，那些自行脱离教会的外人，除了在自己的咒诅中腐烂之外，别无所存。因此，离弃教会也就是公然弃绝永远的救恩。
