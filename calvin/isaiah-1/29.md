# 第二十九章

<p style="text-align:center" markdown="1"><span style="color:#000080">前往 以赛亚书 29:1-24</span></p>

**1.** 这似乎是另一篇讲论，其中以赛亚威胁耶路撒冷城。他称之为「祭坛」[^f508]，因为这城主要的防卫就在于「祭坛」[^f509]；因为虽然城中的居民倚靠别的堡垒——这类堡垒他们极其众多——他们却更倚赖圣殿（耶利米书 7:4）与祭坛，过于倚赖其余的防御工事。当他们自以为在势力与资源上无人能敌之时，他们认为自己最坚固、最不可攻破的营垒，乃在于有神的保护为他们的屏障。他们断定：只要他们仍有祭坛与祭物，神就与他们同在。有人认为，圣殿在此被称为「亚利伊勒」，是因它的形状像狮子，前宽而后窄；但我认为，更好的是径直将它理解为指「祭坛」，因为以西结（以西结书 43:15）也这样称呼它。这预言固然是针对全城而发的，但我们必须留意先知的用意；因为他要剥去犹大人那愚妄的自信，就是他们妄想只要祭坛与祭物尚能存留，神就必帮助他们。他们以此虚假地夸口，自以为已经完全尽了本分，虽然他们的行为卑污可憎。

<span style="color:#800000">*大卫安营的城。*</span>他现在转向那城，以其昔日曾为大卫所居而称赞其崇高的地位，但他这样承认，意在吹散他们虚荣的烟雾。有些人把它理解为较小的耶路撒冷，即内城，那里也有城墙环绕；因为耶路撒冷仿佛有两重，因它扩展了，把城墙推到了原初所立之处以外；但我认为这段经文必须理解为指整座城。他提到*大卫*，因为他们以他的名夸口，自夸神的祝福常住在他的王宫中；因为耶和华曾应许说：「大卫的国位必要坚定，直到永远。」（撒母耳记下 7:13；诗篇 89:37）

<!-- PAGE 653 -->
由此我们可以推知，今日教皇党人何等荒谬，竟以为教会被系于彼得的座位，仿佛神在全世界除了罗马教座以外，别无可寻的居所。我们现在不争论彼得是否曾作罗马教会的主教；但即便我们承认这已被充分证实，难道有什么应许曾赐给罗马，如同赐给耶路撒冷的那样吗？「这是我永远安息之所；我要住在这里，因为我拣选了它。」（<span class="ages-code">&lt;19D214&gt;</span>诗篇 132:14）而即便连这一点也被承认了，难道我们看不见以赛亚论到耶路撒冷所宣告的话吗？就是当教义无处容身、当神的敬拜被败坏时，神就被赶离那城。那么对罗马又当怎么说呢？她并没有这样的凭据。难道她能夸口有什么胜过耶路撒冷之处吗？既然神对那至圣的城，就是他以特别的方式所拣选的城，宣告咒诅，那么对其余那些倾覆了他神圣律法和一切敬虔典章的人，我们又当怎么说呢？

<span style="color:#800000">*年百年地循环。*</span>先知加上这句话，是因为犹大人以为，只要稍得延缓，他们就已逃脱了刑罚。恶人看不见毁灭临近，就以为神已与他们讲和；因此，只要耶和华容许他们享受平安宁静，他们就自许必永享兴盛。为了对抗他们这种自以为安稳的心，先知警告说，纵然他们继续「献祭」，[^f510] 纵然他们年年重复献祭，耶和华仍必施行他的报应。我们当从此学到：当耶和华延迟刑罚、延迟报应时，我们不可因此就抓住这机会拖延悔改；因为虽然他暂时宽容忍耐我们，我们的罪却并未因此涂抹，我们也没有理由自许可以与他讲和。所以，我们不要滥用他的忍耐，倒要更加迫切地寻求赦免。

**2.** <span style="color:#800000">*我终必使亚利伊勒困难*</span>。我认为此处的 <span style="color:#008080">ו</span>（*vau*）当作转折连词来理解：「然而我必施行我的审判，加以报应，虽然我暂时延迟，看似已经赦免了。」接着他警告说，他要以*愁苦*和*哀号*代替节期的欢乐。<span style="color:#008080">אניה</span>（*aniah*）有些人视之为形容词，[^f511] 但这并不恰当；因为耶利米也是以同样的方式使用这个词。[^f512]（耶利米哀歌 2:5）他宣告耶和华必使那城陷入困境，好叫犹太人知道他们所敌对的是神，而非人；虽然战事是由亚述人发动的，他们仍当看出神才是那统帅。

<!-- PAGE 654 -->

<span style="color:#800000">*我却仍以她为亚利伊勒。*</span>这一句不能单单指圣殿而言；因为他的意思是：耶路撒冷所要发生的屠杀必使万物都染满血污；[^f513] 因此他把它比作一座「祭坛」，各样祭牲都在其上被宰杀，正如那些注定被屠戮的恶人常被比作祭物一样。总之，他在此借用「祭坛」一词，说全城都要「如同亚利伊勒」，因为它必被被杀之人的血所漫溢。由此可见，外在的敬拜表白、礼仪，以及神施恩的外在凭据，若我们不诚心顺服他，便都毫无益处。他以讽刺的口吻对那些假冒为善的人说（他们心地污秽，却将牲畜的祭物献给神，仿佛这些供物足以平息他的忿怒），他们的劳碌是徒然的；既然他们已玷污了圣殿与祭坛，那么除非在全城各处宰杀祭牲，就不可能向神献上合宜的祭，仿佛他说：「必有屠戮遍及各处。」他以比喻的方式使用「祭」这个词，来表明那些不肯甘心将自己献与神之人所要遭受的暴烈屠杀。

**3.** <span style="color:#800000">*我必四围安营攻击你。*</span>他用 <span style="color:#008080">כדור</span>（*kaddur*）[^f514] 一词，是暗指球的圆形；这一表达与人们常说的一句话相符（“Je l’environneray”），意即「我要把它围住」。他借此表明，一切逃脱之路都必被断绝。

<span style="color:#800000">*筑垒攻击你。*</span> 这里暗指另一种侵袭城邑的方式；因为攻城或是从各处发动突击，或是正式围困。他确认了前一节的教训，表明这场战争乃是在神的指挥之下进行的，亚述人虽被自己的私欲和权力的贪念所驱使，却除了照神的命令之外，别无所能作为。他认为极要紧的是使犹大人心中确信无疑：凡临到他们身上的一切灾祸都是神所降的，好叫他们由此被引导去省察自己的罪行。这教义既在圣经中屡屡出现，就更当谨慎地刻在我们心里；因为圣灵如此频繁地重复并反复灌输这教义，绝非无因。

<!-- PAGE 655 -->
**4.** <span style="color:#800000">*你必败落。*</span> 他以嘲讽的口吻描述那种傲慢——它使犹大人在享受繁荣之时藐视一切的威胁与劝戒，正如一切假冒为善的人所惯行的。故此他说，当他们的骄傲被除去之后，他们就会较为顺服；这并非说他们的性情已经改变，而是因为羞耻会约束他们从前所纵容的那种放荡。因此我们当在此补上一个隐含的对比。他所对之说话的人，是那些被野心所膨胀、高抬着头、藐视众人的人，仿佛他们连神也不必服从；因为他们竟敢咒诅、侮辱神自己，戏笑祂的圣言。以赛亚说：「这骄傲必被降卑，这傲慢必要止息。」

<span style="color:#800000">*你的言语必微细出于尘土。*</span> [^f515] 他从前所说的，如今借一个比喻更充分地表达出来，就是他们将如同从洞穴中发出低沉而含糊的声音。 [^f516] 那些从前如此高傲凶猛之人的声音，被他比作*占卜者*的言语——他们在地下某个幽深黑暗的洞穴中发出神谕时，作出某种含糊的咕哝；因为他们并不清晰地说话，只是低声细语。他宣告这些自夸者（<span style="color:#0000d4">ἀλάζονες</span>）必与他们相似。有人解释这话，以为先知的意思是他们从这管教中得不着任何益处；但原文并无此意，况且他后面又说犹大人必被引至悔改。然而他先施以恐惧，为要压制他们的狂傲；因为他们曾骄横悖逆地讥笑先知一切的警告。因此，他们「被降卑」，所指的不过是他们必被羞辱笼罩，以致不敢再如从前那样从高处发出骄傲空洞的夸口。

**5.** <span style="color:#800000">*你的仇敌众多，成如细尘。*</span> [^f517] 我先陈述别人的看法，然后再提出我认为更可取的意见。几乎所有的注释家都认为这话是指犹太人的敌人；因为他们把「外邦人」解作「仇敌」，并主张压迫犹大人的那群人必「如细尘」，就是说，多得不可胜数。但当我细察全段经文时，我更倾向于采取相反的看法。我认为先知是在轻蔑地论到犹大人所愚昧倚靠的驻防军，因为他们雇用了外邦的兵丁，都是强壮的人。

<!-- PAGE 656 -->

<span style="color:#800000">*强暴人的群众。*</span> 这就是我对 <span style="color:#008080">עריצים</span>（*gnaritzim*，强暴者）所作的解释，这也是它字面的意思；我看不出为什么有些犹太人要把它解作不敬虔的人或恶人。既然犹大人从远方招来各种驻防军，他们就以为自己防守稳固，不惧怕任何危险。先知威胁说，他们的援军虽然人数极多，却将徒然喧闹一场，因为他们必如「细尘」或「碎秸」，就是无用的渣滓，因为他们必毫无功效。[^f518] 由此我们当推知：我们的财富与资源无论何等丰厚，一旦耶和华定意照祂的权柄待我们，这一切必归于无有。人的帮助固然可存留一时；但当耶和华认真举手之时，他们的力量必崩溃瓦解，必成为碎秸。

<span style="color:#800000">*这必顷刻之间忽然临到。*</span> 有些人解释本节末句的意思是：仇敌攻击的喧嚷必忽然发生，仿佛在顷刻之间。但我认为 <span style="color:#008080">והיח</span>（*vehayah*，*这必成为*）是关乎持续的时间，先知宣告说那时间只是一瞬；就是说，那些军事的援助必不长久，而要迅速消散。[^f519] 人夸耀这些乃是徒然的，因为神与他们为敌。

**6.** <span style="color:#800000">*从万军之耶和华那里必受惩罚*</span>。接着他说明为何这一切众多的守军都要「如同碎秸」；他用一个相反的隐喻来表达这一点，因为他把耶和华的怒气和「惩罚」与那些兵丁相对而言。在「吞灭的火焰」面前，「碎秸」算得什么？在「旋风」的猛烈势力面前，「尘土」算得什么？他指明，神的报应必是如此，以致他们一切的预备都无法抵挡。依我看，这样的意思使这段经文读来通顺；若采别种解释，各分句之间就不那么协调了。

由此我们学到：那些攻击我们的人，除了耶和华所容许他们做的以外，什么也不能做。所以，若耶和华定意要救我们，仇敌就必一无所成，纵使他们激动全世界来与我们为敌。反之，若他定意要管教我们，我们就无法凭任何势力或堡垒挡住他的忿怒；这些必迅速被推倒，如同被「旋风」吹倒，甚至被吞灭，如同被「火焰」烧尽。

<!-- PAGE 657 -->

**7.** <span style="color:#800000">*又必像夜间的异象、梦境*</span>。这一节我的解释也与别人不同；因为他们认为先知的用意是要安慰敬虔人。这种看法无疑颇有道理，其中也包含一个极佳的教义，就是：教会的仇敌在这一点上正如「作梦的人」，即当他们以为几乎已达到目的时，耶和华却使他们的希望落空。[^f520] 然而这种解释在我看来与经文的脉络不甚相合。有时会发生这样的情形：一句话说得美妙，就吸引我们归向它，使我们不觉间偏离了真正的意思，以致我们不紧紧扣住上下文，也不肯多费工夫去探究作者的原意。因此，让我们来查考这是否先知真正的意思。

既然他随后又继续发出威胁的话，我毫不怀疑他在此仍是承接同一主题，否则这段话便会不恰当地打断了论述的连贯。他责备犹大人，斥责他们的顽梗，因他们竟放胆藐视神和他一切的威胁。简言之，他用一个极为贴切的比喻，责斥他们虚假的自信与自负；他警告说，仇敌必忽然出乎意料地临到，而那时犹大人还自以为享受着深沉的平安，远离一切危险；并且那事的发生如此突然、如此出人意外，以致看起来竟像是「一场梦」。因此他说：「虽然你怀着永享安逸的指望，主必快快惊醒你，赶散你的自负。」

先知机智地说，犹大人正在「作梦」，因为他们沉溺于宴乐之中，既看不见也感觉不到什么，反在那令人昏眩的旋涡中愚顽地自以为幸福。因此他推论说，仇敌必如在「梦中」一般临到，使那些睡着的人陷入惊恐；正如常有的事，甘美安舒的睡眠被可怕的梦境所扰乱。由此可见，那使他们沉睡的宴乐对他们毫无益处；因为，尽管他们丝毫未曾想到，扰乱却必忽然兴起。若他不在下一节中更充分地解释这一主题，这话或许仍会稍显隐晦。

<!-- PAGE 658 -->
**8.** <span style="color:#800000">*就必像饥饿的人梦中吃饭*</span>他把犹大人比作「饥饿的人」，这些人虽然睡着了，但空腹却渴求食物；因为人在缺乏饮食筵宴时，自然会梦见饮食筵宴。因此，犹大人在醒着的时候，正如「饥饿的人」。主不断藉着他的众先知警戒他们，邀请他们来赴圣道的神圣筵席；但他们藐视这些筵席，宁愿全然逃避到自己的罪恶之中，在其中沉睡，也不肯饱享那些神圣的筵席。所以，他们在使自己的良心得着安宁之时，便幻想自己万事丰足，毫无缺乏与困苦。以赛亚宣告说，他们极像这「梦」和这虚空的「异象」；因为，当他们被忽然而至的灾祸惊醒时，就必觉出那些「梦与异象」何等空虚、何等虚幻，也必觉出他们自以为丰足的看法何等虚假、何等迷惑人。正如那些作过这类梦的「饥饿的人」因此更加虚弱无力，照样，这百姓既曾被虚假地说服，以为一切都顺利，就必比他们心中从未存过这种念头、反倒察觉自己的贫穷与赤身露体时，忍受更大的不安。

<span style="color:#800000">*那许多国的群众也必如此。*</span> 乍看之下，当他说「攻击亚利伊勒之人的群众必如梦」时，这话似乎显得生硬；但当如此解释：——「当犹太人凭虚妄的盼望自许必得拯救，以为仇敌必被远远驱逐时，他们必快快察觉自己受了欺骗；正如人因饥饿而梦见自己大宴丰筵，一醒来却觉饥饿比先前更甚。」因此，我在此看不出有什么足以带来安慰的话，因为先知继续追论同一主题，痛斥犹太人的藐视与悖逆，先知无论用劝勉或恐吓都无法打动他们。[^f521]

<!-- PAGE 659 -->
**9.** <span style="color:#800000">*你们等候惊奇吧！*</span> 以赛亚继续追论同一主题，更尖锐地攻击这百姓粗鲁的愚顽。有人不译作「等候」，而译作「你们要惊愕」；但我所取的看法可如此表达：「他们纵然在这事上反复长久思量，结果也不过是：因长久思想，心思陷于惊愕。」总之，他的意思是：神的审判必如此彻底地压倒他们的心思，以致他们虽苦苦思索揣摩，仍找不出任何出路或结论。

<span style="color:#800000">*他们醉了，却非因酒。*</span> 他现在指出为何专注的思想无助于他们胜过自己的迟钝。缘由乃是：他们就像*醉汉*。所以，当他们在神的作为中既看不见也不明白什么时，他表明这是出于他们的懒惰与愚顽。每日在许多人身上都可见到这事的明证；因为属灵的「醉酒」如此占据并麻痹他们一切的感官，以致他们对最浅显的事也瞎眼无见；当神显出公义与公平最明亮的光时，他们竟完全被眩惑，昏花的目光使他们愈发迷乱。这种愚顽乃是主因他们的不信而施加于他们的公义刑罚。

为使我们能将先知这句话应用在自己身上，应当留意：先知这些话不可理解为命令，仿佛他吩咐他们停下来多思想一番；恰恰相反，正如我们已经说过的，他是在讥讽并责备他们的愚顽。（Pensez y tant que vous voudrez, vous n'y entendres rien）「你们尽你们所愿地去思想吧，却终究一无所悟。」

<span style="color:#800000">*他们被蒙蔽了，也蒙蔽人。*</span> [^f522] 他的意思是，他们毫无判断力与悟性，因此他们默想神的这些作为也是徒然；因为正如日头的光辉对蟾蜍毫无益处，一个被蒙蔽的悟性尽其全力也无法领会神威严的作为。当他说「他们被蒙蔽了」，他的意思是：按本性而言，我们受造时是被赋予理性与悟性，为要默想神的作为；我们之「被蒙蔽」可以说是一种偶发的败坏，那醉酒的状态并非我们本性所固有的，乃是出于人的忘恩负义，主公义地责备这忘恩负义。

<span style="color:#800000">*他们摇晃。*</span> 他以心思的这种「摇晃」与理性平静安稳的运用相对照；因为他所指的是那搅扰心思、使之动摇踉跄的情欲之暴烈。

<!-- PAGE 660 -->
**10.** <span style="color:#800000">*因为耶和华将沉睡的灵浇灌你们。*</span>为要更清楚地显明这瞎眼的根源，他将其归于神的审判，因神定意要以这种方式惩罚百姓的邪恶。正如赐人眼目使之能看见、以判断和聪明的灵光照人心，乃是属乎他的，照样，当他看见我们出于对真理的邪恶败坏之恨恶而自甘于黑暗时，也唯有他夺去我们一切的光。因此，当人瞎了眼——尤其在如此明白显然的事上瞎了眼——我们便看出他公义的审判。

<span style="color:#800000">*你们的先知和你们的首领，就是那些先见。*</span> [^f523] 他又补充说，百姓被剥夺了那些本应赐悟性以光照、并为他人指引方向的帮助与扶持。 [^f524] 这正是先知的职分，他用这两个名称来描述他们：<span style="color:#008080">נביאים</span>（*nebiim*，「先知」）和 <span style="color:#008080">חזים</span>（*chozim*，「先见」）。简言之，他的意思是：不但那些本有理性和悟性的人要丧失常识，连他们的教师——那本当光照他人的——也要全然愚昧，以致不认得道路，被无知的黑暗笼罩，可耻地迷失；他们非但不能引导别人，甚至连自己也无力引导。

**11.** <span style="color:#800000">*所有的默示，你们看如封住的书卷。*</span> 先知更加清楚地表明他先前所说的：犹太人的瞎眼将何等严重，以致主虽用他话语最明亮的光照耀他们，他们却一无所知。他并不是说这只临到平民百姓，甚至也临到那些本当比众人更有智慧、当为众人作榜样的官长和教师。 [^f524] 简言之，他的意思是这种愚钝要弥漫各个阶层；因为他宣告说，无论「学问人」还是「不识字的人」，都要如此迟钝愚昧，以致在神的话语面前完全昏花，看它不过如同一封「封住的书卷」一般。他用不同的措辞重述了前一章所说的同一件事：主对他们必成为「命上加命，令上加令，律上加律，例上加例」；因为他们将永远停留在最初的蒙学阶段，永远不能达到坚实的教义。（以赛亚书 28:13）

<!-- PAGE 661 -->
如今他以同样的意思表明，从最尊贵的到最卑微的，他们都不能从神的话语得着益处。他并未说教义要被夺去，而是说，纵然教义仍在他们手中，他们却毫无理性与悟性。主以两种方式惩罚人的邪恶：有时他完全夺去话语的使用，有时他虽留下话语，却夺去悟性，使人的心思瞎了眼，以致「看是要看见，却不晓得」（以赛亚书 6:9）。所以，首先，他剥夺他们诵读的机会，或是藉恶人的暴政将书卷夺去（这是常有的事），或是藉着人的错谬定见，使他们以为这些书卷并非为着众人普遍诵读而赐下的。其次，他虽容许他们经手并诵读这些书卷，然而，因为人滥用它们，忘恩负义，并不专一仰望神的荣耀，他们就成了瞎眼的，所看见的不比话语的一线光辉从未照耀过他们更多。因此，我们不可夸耀话语外在的宣讲；因为除非它藉着照亮我们的心思而结出果子，否则毫无益处。这就好像他说：

<p style="text-align:center" markdown="1"><span style="color:#000080">「因着他与你们列祖所立的那约，</span> <span style="color:#000080">主必将那约的册子留给你们；但对你们，它们却要成为『封住的书卷』，</span> <span style="color:#000080">因为你们从其中什么也学不到。」</span> <span style="color:#000080">（</span><span style="color:#000080">申命记 4:20, 37；7:6。）</span></p>

当我们看见这些事正如以赛亚所威胁的那样临到犹太人身上，又当我们思量那被神所收纳、所分别出来的百姓的处境时，我们对如此可怕的报应，绝不可能不浑身战栗。他们既受过律法与先知的教导，又被那超乎寻常之明亮的光所照耀，却仍陷入可怖的迷信与骇人的不敬虔；对神的敬拜被败坏了，一切宗教都被打散、被倾覆，他们被撕裂、分成种种怪异的宗派。到末后，当那最邪恶的撒都该人掌握大权，当一切关乎复活、甚至关乎不朽的信心与盼望都被夺去时，我且问，他们所像的除了牛畜或猪猡还能是什么呢？因为若把有福的永生的盼望从人身上夺去，人还剩下什么呢？

<!-- PAGE 662 -->
然而福音书作者们（马太福音 22:23；马可福音 12:18；路加福音 20:27；使徒行传 23:8）明明告诉我们，当基督降临时确有这样的人；因为那时这些事正应验了，正如先知所预言的，好叫我们知道这些威吓之言并非随意抛出或出于偶然，也没有落空，因为在那时它们被恶人顽梗悖逆地藐视和讥诮。所以在那时，他们的不信与愚昧就昭然若揭了，因为那时真光已向全世界显明，就是基督，那真理独一的光，律法的灵魂，众先知的总归。我说，正是在那时，「摩西脸上的帕子」（出埃及记 34:30）特特地摆在犹太人眼前——因摩西面皮过于发光，他们不能定睛看他；这在基督身上真正应验了，正如保罗告诉我们的，除掉并废去那帕子乃是属乎基督的事（哥林多后书 3:16）。所以直到如今，他们诵读摩西书的时候，帕子还在他们心上；因为他们弃绝了基督，而摩西本当被看作是指向基督的。在那段经文中，「摩西」当理解为指律法；若把律法归回其终极目的，就是归于基督，那帕子便必除去。

当我们思想神这些审判时，也当承认：那位从前作审判者的，如今仍是审判者，并且同样的报应也预备给那些不肯侧耳听从祂至圣警戒的人。当祂特特题到「有学问的和没有学问的」[^f525] 时，我们应当留意：我们并不是因着拥有敏锐的悟性，或在学校中受过更高的教育，就能明白属灵的道理。学问并不能拦阻他们被弄瞎了眼。因此，我们若愿逃脱这报应，就当真诚而恳切地领受这道；这报应不单威吓无知的人，也威吓「有学问的」人。

**13.** <span style="color:#800000">*所以主说。*</span> 先知指明，主如此严厉地对待祂的百姓，乃是本着最公义的理由而行；虽然他们的心思被神的手弄得麻木迟钝，实在是极其严厉可畏的管教。[^f526] 如今，既然人如此鲁莽顽梗，甚至毫不迟疑地与神争辩，好像祂严厉得不公义，先知便指明神所行的乃是公义审判者的本分，一切的罪咎全在于人，是他们以自己的卑劣与邪恶惹动了祂的怒气。

<!-- PAGE 663 -->
<span style="color:#800000">*因为这百姓亲近我，用嘴唇尊敬我。*</span> 他表明，这百姓之所以配受这刑罚，主要是因着他们的假冒为善与迷信。当他说他们「用*嘴*、用*嘴唇*亲近」时，他所描绘的正是他们的虚伪。这就是我对 <span style="color:#008080">נגש</span>（*nagash*）一词所作的解释；虽有人持不同看法，但在我看来这读法更为可取。有人把它译作「被强迫」，也有人译作「自高自大」；然而他随后所用的与之相对的词——*远离* [^f527]——清楚表明，最为普遍接受的那种读法才是正确的。

<span style="color:#800000">*他们敬畏我，不过是领受人的吩咐。*</span> 他用这些话责备他们迷信与拜偶像的行径。这两件事几乎总是相连的；不但如此，假冒为善从来不能脱离不敬虔或迷信，反过来，不敬虔或迷信也从来不能脱离假冒为善。他以*嘴*和*嘴唇*指外在的宣认，这是善人与恶人所共有的；但两者的分别在于：恶人所有的不过是虚浮的夸耀，他们以为只要开口尊崇神，就已尽了一切本分；而善人却出于内心至深的感受来到神面前，他们一面顺服，一面承认并自知离完全尽本分还相去甚远。

因此他在此使用了圣经中极常见的一种修辞，即以部分或某一类代表全体。他所选取的这一类极其贴切，与眼前的主题十分相合，因为敬虔的外貌主要是借着舌头和嘴唇装出来的。所以以赛亚也把假冒为善之人用以伪装欺骗的其他部分包括在内，因为他们在各方面都倾向于谎言与虚假。我们不必寻求比基督自己更好的解释者；祂论到洗手一事——法利赛人视之为圣洁的表现，并因门徒忽略此事而加以指责——为要定他们假冒为善之罪，就说：

<p style="text-align:center" markdown="1"><span style="color:#000080">「假冒为善的人哪，以赛亚指着你们说的预言是不错的。他说：这百姓用嘴唇尊敬我，</span> <span style="color:#000080">心却远离我；」</span> <span style="color:#000080">（</span><span style="color:#000080">马太福音 15:7、8。）</span></p>

<!-- PAGE 664 -->
所以，先知将「嘴唇」和「口」与「心」相对；神所吩咐、所要求于我们的，正是这心的真诚。若缺了这一样，我们一切的工作，无论外表何等辉煌，都必被祂弃绝；因为「神是个灵」，所以祂拣选人「用心灵」和内心来「敬拜」、来尊崇祂。（约翰福音 4:24。）我们若不从这里开始，人以外在的姿势与仪态所表白的一切，不过是虚空的排场。由此我们不难断定，教皇党人自以为献给神的那种敬拜，究竟有何等价值——他们以无用的摇铃、含糊的诵念、蜡烛、香、华美的衣袍，以及千百样同类的琐屑之物来敬拜神；我们看见，神不但弃绝这些，甚至憎恶这些。

论到第二点：当人以自己所发明的方式敬拜神时，神便定这「敬畏」为迷信，纵然人竭力用宗教、虔诚或敬虔的堂皇借口来加以掩饰。祂陈明理由，就是这敬畏乃「是领受人的吩咐」。我认为 <span style="color:#008080">מלמדה</span>（*melummadah*）[^f528] 具有被动的含义；因为祂的意思是：以「人的诫命」而非神的话语作为敬拜祂的准则，乃是颠覆一切秩序。[^f529] 然而主的旨意是：我们的「敬畏」，以及我们敬拜祂时所存的虔敬，都当以祂话语的准则为规范；祂所要求的，无非是单纯的顺服，使我们照着话语的准则来规正自己和自己一切的行为，不偏离左右。

由此可以充分看出，那些从「人的发明」中学习该如何敬拜神的人，不但显然愚昧，更是以毁灭性的劳苦耗尽自己，因为他们所作的无非是激动神的忿怒；因为神再不能有比藉着这管教的可畏严厉更清楚的明证，来表明祂何等憎恶虚假的敬拜。肉体认为这是不合理的：神竟不但把那些出于无知与错谬、劳苦操心要讨神喜悦之人的努力视为虚妄，甚至还严厉惩罚他们；然而，祂如此维护自己的权柄，我们不该以为希奇。基督自己解释了这段经文，说：「他们将人的吩咐当作道理教导人，所以拜我也是枉然。」（马太福音 15:9）有些人选择加上一个连词，作「教导人道理**和**人的吩咐」，仿佛原意还不够清楚似的。但祂的意思显然不同，就是说：当我们把「人的吩咐」当作自己的道理和生活准则来遵从时，我们的行事乃是荒谬的。

<!-- PAGE 665 -->
**14.** <span style="color:#800000">*所以，我要行奇妙的事。*</span> [^f530] 祂威吓说，祂要以瞎眼来惩罚的，不只是那些无知的人或普通阶层，更是那些为百姓所仰慕的智慧人。从这刑罚中我们可以轻易看出，假冒为善是何等可憎的恶，何等为神所厌恶，正如先知稍前论到人的发明时所说的；因为还有什么刑罚比心思的瞎眼与愚顽更为可怕呢？这一点人通常并不察觉，他们也不晓得这祸患何等重大；然而这却是一切祸患中最大、最可悲的。

<span style="color:#800000">*他们智慧人的智慧必然消灭。*</span> 祂所说的不是寻常百姓，而是他们的领袖，就是那本该如同眼目的人。寻常百姓自己本是瞎眼的，如同身体其余的肢体；而当眼目瞎了，身体其余部分又当如何呢？基督问道：「你里头的光若黑暗了，那黑暗是何等大呢！」加上这话，是为要把那刑罚更鲜明地显明出来。

由此我们也可以推知，教皇党人的自夸何等虚妄、何等愚昧；他们以为只要抬出「主教」的名号，或其他同类的头衔，如博士、牧者、或使徒的座位，就已经堵住了众人的口。或许他们所有的智慧与犹太人所拥有的不同；然而这智慧是从何而来的呢？他们假称是从神而来；但我们看见，先知在此并非论到迦勒底人或埃及人的智慧人，而是论到神所设立的祭司职分，论到蒙拣选之民、唯一教会中的教师、首领和执旗者；因为在「智慧人」这一称呼之下，他包括了民中一切卓越的地位与权柄。

**15.** <span style="color:#800000">*祸哉！那些向耶和华深藏谋略的*</span> 先知再一次向那些邪恶、亵慢、藐视神的人发出斥责；他先前曾称他们为 <span style="color:#008080">לצים</span>（*letzim*），即「亵慢人」，这些人以为除了善于讥笑神以外，别无智慧可言。他们把敬虔看作愚蠢的头脑简单，又躲藏在自己的诡诈中，如同藏身在迷宫里；因此他们讥笑一切的警戒与威吓，简言之，讥笑敬虔的全部教义。从这一节经文可以充分看出，那后来更加蔓延的瘟疫，在当时的世界上就已流行，就是：假冒为善的人喜欢在心里讥笑神，喜欢藐视预言。因此先知向他们发出斥责，称他们为 <span style="color:#008080">מעמיקים</span>（*magnamikim*），即「挖掘者」，[^f531] 好像他们为自己「挖掘」 <!-- PAGE 666 --> <p style="text-align:center" markdown="1">隐匿之处与藏身之所，为要借此欺骗神。</p>

<span style="color:#800000">*为要将谋略暗中隐藏*</span> 这一句是为了解释前句而添加的。有些人这样解释本节的开头，仿佛先知在此谴责那种过度的好奇，就是有些人以过分的胆大妄为窥探神隐秘的判断。但这种解释是不可接受的；先知清楚地表明他所指的是谁，因为他紧接着就提到那些人的讥笑——他们以为自己的恶行行得如此隐秘、如此隐藏，以致无人能查出。所谓「隐藏谋略」，无非是在作恶上的胆大妄为，恶人借此以密云环绕自己，遮蔽光亮，使他们内心的污秽不被看见。由此便产生了那放胆的质问——

<span style="color:#800000">*谁看见我们呢？*</span>因为，虽然他们自称是敬拜神的人，却以为凭着自己的诡辩，不但已经驳倒了先知，甚至已经推翻了神的审判；当然，他们并非公然如此，因为连恶人也愿意保留几分宗教的外貌，好更有效地行欺骗之事，然而在他们心里，除了自己所捏造的神以外，并不承认有神。因此，恶人所喜好、所自夸的这种狡诈，被以赛亚比作藏身之处，或比作遮蔽物。他们以为自己被幔子遮盖了，甚至连神自己也不能看见并惩罚他们的罪恶。既然当权者最容易犯这毛病，我认为先知的责备主要是针对他们的；因为他们若不讥笑神、藐视祂的教义，总之，若不是只信自己所愿意信的，就自以为不够敏锐、不够精明。他们不敢将神的教义全然弃绝，或者更该说，他们是违背己愿地被迫持守某种宗教；但他们持守的限度，只在于他们认为可以促进自己利益的范围之内，并非出于对真神的任何敬畏。

<!-- PAGE 667 -->
在今日，这种邪恶已充分显露出来，尤其自福音显明以来。在教皇制之下，人们发觉与神打交道极其容易，因为教皇捏造出一个神，这神会自行变化以迎合每一个人的性情。人人都有各自洗除罪污的方法，并有许多种敬拜来平息自己的神明。因此，无人应当稀奇那时候罪恶未被看见，因为它是被那类遮蔽物所掩藏的；而当这些遮蔽物被除去以后，人们就公然显明了他们从前的真面目。然而以赛亚为本国所哀叹的这疾病，在我们这时代也同样普遍；因为人们以为，只要摆出自己巧妙的伎俩，就能向神隐藏自己，好像「万物在祂眼前都是赤露敞开的」（希伯来书 4:13）这话并不真实，又好像有人能欺骗祂或向祂隐藏。为此，他以解释的方式说——

<span style="color:#800000">*他们的作为是在暗中。*</span>他在此指出那使不敬虔的人陶醉的愚妄自信之根源。他们虽被光围绕，却如此迟钝无知，以致当他们看不见光的时候，就企图逃离神的面。他们甚至向自己保证必能完全逃脱刑罚，并且犯罪如此放纵，仿佛四面都有屏障与堡垒可以抵挡神。他们的问话正是这个意思：<span style="color:#800000">*谁看见我们呢？*</span>如我们所说，这并不是说恶人敢公然把这些话说出口，而是因为他们心里如此说、如此想，这从他们的放肆与虚妄的自信中显明出来。他们放纵自己行各样的恶，藐视一切的警戒，仿佛神的审判永不会来。所以，先知所面对的是不敬虔的人，他们在外表和名义上自称对神有些认识，实际上却否认祂，并且是纯正教义最刻毒的仇敌。如今，这无非就是断言神不是审判者，是把祂从祂的宝座和审判台上推下来；因为人若无教义就不能认识神，而教义被弃置、被拒绝之处，神自己也必被弃置、被拒绝。

<!-- PAGE 668 -->
**16.** <span style="color:#800000">*你们的颠倒岂可算为窑匠的泥吗！*</span> 解释这节经文有多种方式，而且由于 <span style="color:#008080">אם</span> (*im*) 和 <span style="color:#008080">כי</span> (*ki*) 这两个虚词，确实存在一些困难。<span style="color:#008080">אם</span> (*im*) 常用于提问，有时也用于断言；因此有些人把它译为*的确*。<span style="color:#008080">הפך</span> (*haphach*) 一词被有些人理解为「翻转倒覆」，[^f532] 好像他说：「你们的倾覆岂算为泥吗？」另有些人把它译为「转向」，即心中所立定的图谋。但最为通行的译法是「翻转倒覆」或「毁灭」。仿佛他说：「我毁灭你们，正如窑匠翻弄泥土一样不足介意；因为你们就像泥土，因我是用我的手造了你们。」

但既然先知似乎是把 <span style="color:#008080">אם</span> (*im*) 与 <span style="color:#008080">כי</span> (*ki*) 这两个虚词彼此对照，我便更倾向于另一种见解，尽管我并不反对前一种解释，因为它在别的方面也包含有益的教义。所以我的看法是这样：「你们的转向，就是你们心中所盘算的图谋，岂可像窑匠的泥吗？这岂不像是那器皿对窑匠说：你没有制作我？你们的骄傲实在令人惊愕；因为你们的行事，好像是你们自己创造了自己，好像万事都在你们自己的掌握之中。我本有权柄按我所看为合宜的一切来定夺。当你们胆敢擅取这样的权能与权柄时，你们实在太不认识自己的处境，也不知道自己只是人。」[^f533]

诸般解释上的差异，对先知的意思并无影响；因为他此处别无他求，只是要确证前一节所教导的教义。他仍旧在抗斥那些骄傲之人，他们自居极大的权能，以至无法忍受神的权柄，又对自己怀着虚假的看法，因而藐视一切劝戒，仿佛他们自己就是神。他们如此就是否认神创造了他们；因为人无论把什么归于自己，都是从神那里夺来的，是剥夺了那本当归给他的尊荣。

唯有在第一个子句上，意思才略有差异；因为那些将 <span style="color:#008080">אם</span> (*im*) 解作肯定语气的人，认为这节经文的意思是：「*我实在*要毁灭你们，如同陶匠打碎他自己所造的器皿。」但先知所面对的乃是骄傲之人，他们寻求隐匿之处，好欺哄神；因此我宁愿视之为一个质问：「难道你们是如此高明的工匠，以致你们脑中的种种盘算竟能造出这个那个，如同陶匠转动轮子、随自己的意思塑造器皿么？」愿各人各持己见：我则遵从我所认为可能的。

**17.** <span style="color:#800000">*不是只有一点点的时候吗？*</span> 主如今宣告，他必使那些恶人认清自己究竟是谁；仿佛他说：「你们现今在骄傲中沉睡，但我要速速唤醒你们。」人总是自我放纵，直到感受到神大能的手；因此先知警告说，神的审判必要临到这般深沉的麻木之上。

<!-- PAGE 669 -->

<span style="color:#800000">*黎巴嫩必变为迦密。*</span> [^f534] 他用「黎巴嫩」与「迦密」之名，意在表达世界的更新与局势的变迁。但至于这比喻所指的对象，注释家们彼此的看法大相径庭。因「黎巴嫩」山满布树木森林，而「迦密」则有丰美肥沃的田地。许多人认为，犹太人被比作「迦密」，因为他们将成为不结实的；而基督徒被比作「黎巴嫩」，因为他们将产出极丰盛的果子。这种见解固然似乎可取，因为人素来喜欢一切巧妙的说法；但我们后面将要看到的一处平行经文（以赛亚书 32:15）将表明，先知在此运用这比较，乃是为了称扬神的恩典；因为当他再次开始赐福他的百姓时，一切福分的极大丰盛，将使「迦密」失去它素来所享的盛名。因此他警告说，他要使「黎巴嫩」变为「迦密」，就是说，森林要变成耕种之地，出产五谷；而那些耕地要出产如此丰盛的果实，以致若将它们现今与将来的光景相比，如今便可称之为不结实、荒芜的了。这一表达方式，等我们讲到以赛亚书 32:15 时，将有更充分的解释。

另有人把「迦密」看作普通名词，但我更愿意视之为专有名词；因为其意是说，与那新奇非常的丰饶相比，那些肥美的田地如今竟可算作未曾耕种、荒芜不生的了。又有人作寓意解释，以「利巴嫩」指骄傲之人，以「迦密」指卑微平常之人。这或可视为敏锐精巧之说，但我宁愿采取前面已述的那更为朴实的解释。为使敬虔人不至丧胆，他从威胁转而宣告恩典，并声明：当他们稍稍忍受所加于其身的十字架，藉此显明信心的顺服之后，突如其来的更新便近在眼前，要使他们满心欢喜。然而，他既将不敬虔的人排除于这指望之外，就是暗示：当他们安逸自得、自许平安或休战之时，毁灭却已极近；因为正如保罗所告诉我们的，「人正说平安稳妥的时候，灾祸忽然临到他们」（帖撒罗尼迦前书 5:3）。

<!-- PAGE 670 -->
**18.** <span style="color:#800000">*那时，聋子必听见。*</span> 他应许说，如我们所言，神的教会在那些灾祸之中仍必蒙保存。世界纵被无数风暴摇动，上下颠簸，天地纵然混杂相冲，主仍必保守敬虔人的众数，且必从死亡之中，可以说，兴起他的教会。这理当非同寻常地坚固敬虔人的信心；因为在各处此起彼落的帝国与王朝那众多而广大的废墟之中，敬虔人的后裔竟得保存，在他们中间同一的宗教、同一的敬拜神、同一的信心、同一的救恩之道得以延续，这实在是神格外的奇迹。

<span style="color:#800000">*瞎子的眼必得以看见。*</span> 但以赛亚在此似乎自相矛盾；因为他先前曾预言，在神的百姓中间将有极大的愚顽，以致无人明白，而如今他却说，连「聋子」也必明白，「瞎子必看见」。因此他的意思是：教会必须先受管教、被洁净，而且不是以寻常普通的方式，乃是以如此非常的方式，以致看来它已全然灭亡了。所以他说，*那时*，就是在惩罚了恶人、洁净了他的教会之后，他不但要使地上五谷丰盈，而且藉着更新地的面貌，同时也要「使聋子听见」、「使瞎子看见」，好叫他们领受他的教训。当这可畏的刑罚持续之时，人是无耳无眼的；众人的心思都昏迷混乱，什么也不明白。及至灾殃与患难终止之时，主必开他们的眼，使他们得见并接受他的良善与怜悯。

<!-- PAGE 671 -->
这才是复兴教会的真正方法，就是使瞎眼的看见、使耳聋的听见；我们看见基督也如此行，不但医治身体，也医治灵魂（约翰福音 9:7,39）。我们在自己的时代也经历了这事：我们从原先所笼罩的无知黑暗中被带出来，得以复归真光；从前闭塞不通的眼睛得以看见，耳朵得以听见，因为主"开通"了它们（诗篇 40:6），为要使我们顺服他。他在更新大地时所应许的祝福，固然是和好的一种凭据；但他此处所说的那光照，却远为卓越，若没有这光照，神一切的恩惠不但归于虚空，反而转成我们的败坏。神理当将这样荣耀卓越的工作归给自己，因为再没有什么事比瞎子靠自己的力量重见光明、聋子靠自己的力量重新听见更加毫无指望的了。这显然是以特殊的方式单单应许给蒙拣选者的，因为大多数人始终停留在他们的黑暗之中。

**19.** <span style="color:#800000">*谦卑人必因耶和华增添欢喜。*</span>我如此翻译本节，而别人则译作"他们必增添"或"继续欢喜"；因为先知所描述的并非一种延续的"喜乐"，而是一种新的"喜乐"。仿佛他说："虽然他们现今忧苦愁烦，我却要赐给他们欢乐的缘由，使他们再次充满'喜乐'。"他提到"谦卑人"；由此当留意，我们所受的苦难乃是预备我们领受神的恩典；因为主使我们卑降、使我们受苦，为要在此后将我们扶起。因此，当主管教他的百姓时，我们不当丧胆，反当追念这些宣告，使我们总能盼望更美的事，并且相信：在这样的灾祸与困苦之后，他终必将喜乐赐给他的教会。然而我们再次从此学到我稍前简略提及的一点，即光照的恩典并非毫无区别地属于众人；因为虽然众人一同受了管教，却不是人人的心都被苦难所折服，以致真正成为"虚心的"或"温柔的"人（马太福音 5:3,5）。

**20.** <span style="color:#800000">*因为强暴人已归无有。*</span>他更清楚地说明我们在前一节已经提到的事，就是：教会的复兴在于主将被抛弃的人扶起，并怜悯贫穷的人。但我们已经论及的那教会的洁净，乃是首先必需的；因为只要主不施行他对恶人的审判，坏人与好人混杂在一起，甚至在教会中据最高的位分，那么一切都被污染腐化，神不受敬拜、不被敬畏，连敬虔也被践踏在脚下。所以，当不敬虔的人被除去或被制伏时，教会便恢复其光辉，而敬虔人也从困苦灾祸中得释放，欢欣踊跃。

首先，他称他们为 <span style="color:#008080">עריצים</span>（*gnaritzim*），即「强暴的人」。对这个词有各样的解释；但我认为先知是在区分两种人：一种是公然作恶、毫无羞耻的人[^f535]，另一种是外表尚有几分良善、其实并不比别人更好的人，因为他们心里讥诮神。不过，或许他用这两个形容词——

<!-- PAGE 672 -->

「强暴的」与「亵慢的」——所描述的乃是同一班人；因为他们如同人间的强盗，抢夺、欺压、残酷相待，行各样的暴虐，却毫无敬畏神之心的约束，因为他们把宗教看作虚构的故事。

<span style="color:#800000">*并一切熬夜作孽的。*</span> [^f536] 在这一类之下，他把其他的罪恶也包括进来。他所说的并非迦勒底人或亚述人，乃是那些愿意被算在敬虔人之列、并夸口自己是亚伯拉罕后裔的人。

**21.** <span style="color:#800000">*他们因一句话陷害人。*</span> 我们先前已说明先知所要对付的是何等人，就是那些假冒为善的人和亵慢的讥笑者：他们把先知一切的责备与警戒都视为无物，又想按自己的幻想造一个神。这等人渴望毫无拘束的放纵，好使自己可以随意沉溺于快乐与罪恶之中，因此极不耐烦地忍受先知们尖锐的责备，也不肯安静地受约束。为此，他们仔细窥察、守候先知的言语，好趁其不备加以捉拿，或加以曲解。我毫不怀疑，他在此责备那些恶人，他们抱怨先知们说话太过自由、责备太过尖刻，仿佛先知有意攻击百姓、攻击贵族、攻击祭司；因为由此便生出种种毁谤与诬告，甚至连神忠心的仆人也不能免。由此也生出那些模棱两可、设下圈套的问题，像网罗和罗网一样张开，或要使义人的性命陷于危险，或要在他身上行某种诡诈。我们看见法利赛人和撒都该人也如此对待基督自己。（马太福音 21:23；22:17；约翰福音 8:6。）

<!-- PAGE 673 -->
<span style="color:#800000">*为要陷害在城门口断案的。*</span> 后面这一句是为解释前句而加上的，它不容我们把这节经文泛泛地解作指毁谤，以及狡猾之人用以捕捉毫无防备者的其他手段；因为先知在此更公开地定罪那些恶人的邪恶计谋，他们借此想要逃脱一切的责备与斥正。因为公开的集会与审判都是在「城门口」举行，众人也聚集在那里，所以先知们公开责备所有的人，甚至连审判官也不宽容；因为那时政权掌握在一些必须受严厉警戒与责备之人的手中。他们受警戒时，本当悔改，却反而变得更坏，向先知发怒，并为他们设下网罗；因为正如阿摩司所说：「你们怨恨那在城门口责备人的，憎恶那说正直话的。」（阿摩司书 5:10。）这话与众人有关，但主要是与审判官和执掌治权的人有关，他们更难接受、更加不悦，以为自己竟要受这样的责备；因为他们愿意与众人的地位有所分别，愿意被算为万人中最尊贵的，即便他们实际上是最恶的。

<span style="color:#800000">*为要陷害。*</span> 注释家对这词的意义看法不一！<span style="color:#008080">יקשון</span>，(*yekoshun*；)因为有些人译作「责备」，有些人译作「辱骂」，仿佛先知是在责斥那些人的顽梗，他们诉诸毁谤，为要把责备他们的人赶得远远的。但我相信读者会赞同我所采取的意思。

<span style="color:#800000">*用虚无的事屈枉义人，*</span>就是说，在毫无缘由的情形下。[^f537] 他们以邪恶诡诈的伎俩，力图使义人被众人憎恨厌恶，被算为万人中最恶的；然而，他们这样戏弄世人之后，终必灭亡。这就是主所赐的安慰：祂必不容不敬虔之人的罪恶不受刑罚，纵然他们一时得以纵情欢乐、放荡不羁，主终必制止他们。只是「我们必须忍耐，好得着所应许的。」（希伯来书 10:36）

**22.** <span style="color:#800000">*所以耶和华如此说。*</span>这是前文的结论；因为他安慰这百姓，使他们在将要陷入的那可悲可怜的境况中不至绝望。我们当留意这些话所指的时候，就是当这百姓已被掳为奴、圣殿倾覆、祭祀止息，那时人可能以为一切敬拜已经倒塌，再无得救的指望了。因此，信徒的心必须靠这预言得以扶持，使他们在船只破碎之时，仍存留这一块木板，可以紧紧抓住，藉此被带进港口。我们也当抓住这些应许，即使在最绝望的境遇中，也要全心倚靠它们。

<!-- PAGE 674 -->

<span style="color:#800000">*论雅各家。*</span>这向他们所发的话，当使我们留意：神言的能力是永存的，且如此有效，以致只要还有一群敬畏敬拜祂的百姓，它就必施展其能力。主总是为自己留下一些人，祂不容敬虔人的后裔灭绝。既然主已经说了话，我们若信祂的话，就必定从中得益。祂的真理坚定不移，因此我们若倚靠祂，就永不缺乏安慰。

<span style="color:#800000">*就是救赎亚伯拉罕的。*</span>他加上一句：如今宣告要恩待雅各子孙的，正是那位「救赎亚伯拉罕」的神——这并非没有充分的理由。他要把百姓的注意力唤回到教会最初的起头，使他们得见神的大能；这大能从前已藉着许多显赫的凭据显明出来，以致不该再有任何疑惑。他们若以亚伯拉罕的名为荣，就当思想：耶和华起初是从何处拯救他出来的，就是从他和他列祖所敬拜之偶像的服事中（创世记 11:31；12:1；约书亚记 24:2）。然而在许多别的场合，神也「救赎」了他：当他在埃及因妻子的缘故遭遇危险时（创世记 12:17），又在基拉耳时（创世记 20:14），又当他制胜诸王时（创世记 14:16），同样在他过了生育之年却仍得着后裔时（创世记 21:2, 5）。虽然先知所着眼的主要是神的收纳，即耶和华吩咐他离开「父家」的时候（创世记 12:1），但在「救赎」一词之下他也一并包含了一切的恩福；因为我们看见亚伯拉罕不只一次被「救赎」，就是从极大的危难中、从性命的危险中被救出来。

如今，倘若耶和华单从亚伯拉罕一人、且在他尚无儿女的时候，便兴起了一个他日后要保守的教会，那么当人们以为教会已经灭亡的时候，他岂不永远保护她么？后来的事如何呢？基督降临之时，那分散何等凄惨，敌对他的仇敌何等众多、何等强盛！然而，尽管有这一切，他的国仍被兴起、被建立，教会兴旺起来，引得万人惊奇。因此，没有人该怀疑：每当有必要时，耶和华必施展他的权能，护卫他的教会抵御仇敌，并使她复兴。

<span style="color:#800000">*雅各必不再羞愧。*</span>他的意思是：常有这样的事，善人被羞耻所迫而垂头丧气，正如耶利米所说：「口贴在尘埃。」（耶利米哀歌 3:29）弥迦也说：「智慧人当把口藏在尘土中，这是时候了。」（弥迦书 7:16）[^f538] 因为当耶和华如此严厉地管教他的百姓时，善人必然「羞愧」。而先知在此宣告，这样的情形不会永远持续。所以我们在患难中不当绝望。虽然恶人讥笑我们，将各种辱骂加在我们身上，耶和华终必使我们脱离羞耻与羞辱。然而先知同时也提出警告：这恩惠并不属于那些骄傲顽固、不肯在神的管教下屈颈的人，只属于卑微的人，就是那些被羞耻所迫而垂头、忧伤沮丧而行的人。

或有人问：他为何说「雅各必不羞愧」？因为「雅各」早已死去，这样说似乎是把感觉归给死人，以为他们能知道我们的事。[^f539]

教皇派也因此认为死人是我们行为的观看者。但此处所用的是拟人法，这在圣经中屡见不鲜。耶利米也照样说：「在拉玛听见号咷痛哭的声音，是拉结哭她儿女，不肯受安慰，因为他们都不在了」；他是借「拉结」的哀哭来描写便雅悯支派的败亡，而拉结正是他们远祖之母。（耶利米书 31:15）

<!-- PAGE 676 -->
以赛亚在此使雅各出场，因他后裔滔天的罪行而心生羞愧；因为所罗门告诉我们：「智慧之子使父亲欢乐；愚昧之子使母亲担忧。」（箴言 10:1）母亲虽多有忍耐，仍要因儿女的恶行而面红耳赤。那么父亲又当如何呢？他们对儿女的慈爱较少夹杂愚昧的溺爱，而主要在于训练他们行善守正；难道他们不因此在儿女行恶行丑之时感受更深的痛苦吗？然而先知在此的用意，是要刺透这百姓的心、使他们伤痛入骨，就在他们面前举出他们自己的先祖来——神曾将何等众多、何等重大的祝福赐给他，如今他却被后裔所羞辱；以致他若在场，必要为他们深深地脸红。因此他控告这百姓的忘恩负义：他们本当尊荣列祖，却反使列祖蒙羞。

**23.** <span style="color:#800000">*因为他看见他的众子。*</span> 这里的助词 <span style="color:#008080">כי</span>（*ki*）是按其本义和原初的意思使用，即「因为」。先知在此说明以色列的羞辱为何要被除去的缘由：因为他将有众子，而那些被认为已经灭亡的人仍然存活。

<span style="color:#800000">*我手的工作在他中间。*</span> 我毫不怀疑，他以这名称呼他们，是有意描述那救赎的奇妙工作；因为凡神收纳为自己儿女、接入与自己相交之中的人，都被祂造成如同新人一般，正如那话所说：

<p style="text-align:center" markdown="1"><span style="color:#000080">「将要受造的民要赞美耶和华。」</span> <span style="color:#000080">(</span><span class="ages-code">&lt;19A218&gt;</span><span style="color:#000080">诗篇 102:18。)</span></p>

在那段经文中，诗人也以类似的方式描述教会的更新；因为正如我们从前屡次所说的，这一描述并非指那涵盖万有的普遍创造，而是引导我们承认他的大能，好叫我们不至于按眼前的光景来判断教会的救恩。在此我们应当留意几重对比：第一，教会荒凉败落的境况与她无比的荣美之间的对比，她的羞辱与她的荣耀之间的对比；第二，神的百姓与列邦之间的对比；第三，「神手所作的工」与人手所作的工之间的对比（因为惟独藉着神的手，教会才能得着重建）；第四，她昌盛的光景与她先前所沦落的荒废凄凉之境之间的对比。「在他中间」这句话，意指完全的复兴，使百姓如此联合相聚，以致他们所居的不仅是国境的边陲，更是这地的心脏与要冲之处。

<!-- PAGE 677 -->
<span style="color:#800000">*必尊我的名为圣。*</span>末了，他指出救赎的目的。我们受造，原是为叫神的良善在我们中间得着颂扬。但既然大多数人已背离了他们起初的地位，神就拣选了一个教会，使他的赞美在其中回响并居住，正如诗人所说：「神啊，锡安的人都等候赞美你」（诗篇 65:1）。如今，既然连羊群中也有许多人堕落了，先知就把这职分交付给神奇妙保守下来的信徒。

<span style="color:#800000">*必敬畏以色列的神。*</span>因为伪善之人，正如我们从前所见的，用嘴唇尊敬神，心却远离他，所以先知在讲论归荣耀与神之后，接着便提到*敬畏*；他的意思是：我们的赞美若不伴随着诚实真挚地顺服神，若我们整个生命不见证我们并非虚伪地称说神的名，这赞美便被算为毫无价值。

**24.** <span style="color:#800000">*心中昏迷的必明白。*</span>他再次重复先前简略提及的那个应许；因为只要人的悟性仍被无知与瞎眼所击打，纵然他们享有各样丰盛的福分，他们仍旧时刻被毁灭所围困、所围攻。因此，主在预备复兴教会之时，就用他的话语照亮自己的百姓，用悟性之光照明他们——这些人从前曾在黑暗中漂流迷失。他藉着圣灵隐秘的运行成就此事；因为若他不同时在我们心里施行内在的教导，单单受外在话语的教训是没有多少价值的。

<span style="color:#800000">*舌头结巴的必说话清楚。*</span>有些注释者将 <span style="color:#008080">רוגגים</span> (*rogenim*) 译作「低声私语的人」，另一些则译作「漂流不定的人」。但其意乃是：那些从前抵挡先知、发怨言、不能忍受先知警戒的人，将变为顺服而柔顺的；故此我选择将它译为**发怨言的人**。由此我们看见神的怜悯何等奇妙，他将那些极不配的人带回正路，并使他们有分于如此浩大的福分。让我们各自在私下里仔细思量这件事。我们中间岂有一人从未向神「发过怨言」、从未轻看过纯正的教义？不但如此，倘若神未曾软化那些顽固的人，未曾以温柔引领他们归于顺服，几乎全人类都要在自己的狂妄中灭亡了。
