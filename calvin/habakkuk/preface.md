# 先知哈巴谷书注释

<p class="title-block-h1" style="text-align:center; font-size:22px; font-weight:bold; margin:18px 0 12px;" markdown="1"><span style="color:#0000d4">译者序</span></p>

本卷虽收录了这几位先知的著作，篇幅却比前几卷小得多；然而最后一卷将绰绰有余地弥补这一不足。

前两位先知，哈巴谷与西番雅，生活在被掳之前；另一位，哈该，则是在大批百姓蒙居鲁士王准许从巴比伦归回约十六年之后，开始其先知的职任。

一般认为，哈巴谷的预言在西番雅**之后**，虽然在我们的圣经中排在他前面。他的时代被定为约雅敬作王之时，约在基督前六〇八年，而西番雅履行其职分则在约西亚作王之时，约早三十年。与其他先知一样，他主要致力于责备百姓极大的邪恶，因此向他们宣告神的审判，同时也不时暗示将有更美的景况，并让人略微窥见福音的诸般福分。

在**第一**章中，他起初为自己所目睹的强暴发出哀诉，预言迦勒底人可怕的入侵，描述他们将要行的残酷，并就此向神呼求。在**第二**章中，他等候答复，得着答复，并预言迦勒底人的倾覆，又提及为神的百姓所存留的福分。**第三**章包含所谓的「哈巴谷的祷告」，是一首体裁独特的颂歌；他在其中简述神过去为祂百姓所行的干预，以坚固信徒的心，最后表明对神满有喜乐的全然信靠，尽管灾祸正临到这民族。

<!-- PAGE 3 -->
「**哈巴谷**的文体，」*罗斯*主教说，「是诗体的，尤其在他的颂歌中，那颂歌实可算作此类作品中最完备的一篇。」<span style="color:#800000">f1a</span> 在*描述*这颂歌的特色时，他说：「先知确实以与其开篇相称的宏伟气象来装饰这整首诗，从如此丰富的奇妙作为中拣选最壮阔者，用意象、修辞和最崇高的辞藻，将它们披上最华美的装束；而这高度的崇高感，又因一个*非凡结尾*的*典雅*而被增益与*提升*：以致此类作品中几乎再无比这首诗更美、更完全的了，若不是其中有一两处晦暗之点——看来是由于其古老所致。」<span style="color:#800000">f1b</span>

西番雅有一部分时期与耶利米同时，即在约西亚在位的前半期。他预言了尼尼微的倾覆（西番雅书 2:13），又提到「巴力所剩下的」（西番雅书 1:4），这两件事证明他是在那王在位的前半期发预言的；因为尼尼微约在约西亚在位第十六年被毁，而巴力的敬拜也是在那之后才被那王除灭的。

犹太人的罪与他们将临的审判占据了*第一*章。*第二*章包含了一篇悔改的劝勉，并以神在祂降灾于邻邦期间必加保护的应许作为鼓励。在*第三*章中，先知逐一列举耶路撒冷的罪，宣告它的刑罚，然后论及神将来白白赐给祂教会的福分。

西番雅的文体有人认为在某些部分近乎散文；*Lowth* 说他「在材料的编排或辞藻的雅致上，似乎并无任何可称道或卓越之处。」<span style="color:#800000">f1c</span> 但 *Henderson* 的看法是：「对他文体所作的许多责难，或是毫无根据，或是言过其实。」就其思想而言，他显得与大多数先知一样富有诗意，在铺陈思想的方式上亦然，虽然他不甚多用对偶句法——而这正是希伯来诗歌的一个显著特征。

先知所处理的题材，*Marckius* 称之为「最配得上神的，无论我们看他严肃的责备，或严厉的威吓，或慈爱的警戒，或恩慈的应许——后者尤其关乎新约的施予。在这一切细节上，他不仅与其他先知一致，也采用他们的措辞。」<span style="color:#800000">f1d</span> 他随即列举以下例证：——<span style="color:#000080">西番雅书 1:6</span> 与 耶利米书 15:6 相比。<span style="color:#000080">西番雅书 1:15</span> 与 约珥书 2:1, 2 相比。

<!-- PAGE 4 -->

<span style="color:#000080">西番雅书 1:18</span> 与 以西结书 7:19 及 耶利米书 *4:*27 相比。<span style="color:#000080">西番雅书 2:8, 9</span> 与 耶利米书 *48:*2 及 以西结书 25:1 相比。<span style="color:#000080">西番雅书 3:3, 4</span> 与 以西结书 22:26, 27, 28 等处相比。

哈该于何时从被掳之地归回，并无明文可考，不过大概是在犹大人于所罗巴伯率领下第一次归回之时，即主前536年。然而他直到约十六年之后才开始履行先知的职任；他书中所载的内容，是在*三个*月之内传讲的。他的信息共有*五*篇，<span style="color:#800000">f1e</span> 都极为简短；因此有人推断，这些只是他所传讲之言的摘要而已。

本书大部分为历史记述，其间夹杂着以诗体表达的内容。先知在**第一**章责劝百姓：他们极其专注于自己的私事，却疏忽建造耶和华的殿；他提及神因此降与他们的审判，鼓励他们兴工，并应许他们必得神的恩眷；随后他告诉我们他所得的果效。在**第二**章，他除去一个表面上令人沮丧的理由，即当时所建之殿不如先前的辉煌，并应许要加添荣耀与它，显然是指着福音的时代说的。接着他警告他们不可在工作上懈怠，也不可以为单单献祭便已足够，向他们保证神的祝福，末了以特别赐给所罗巴伯的应许作结。

*Lowth* 论到这位先知的文体，说它「完全是散文式的」，这话并不十分确实；因其中有些部分极富诗意。参 哈该书 1:6，以及第 8 至 11 节。*Henderson* 论道：「**哈该**的文体并不以任何独特的优美见长；然而当他责备同胞的疏懒、劝勉他们尽本分时，他也并非缺少沉痛与激切之情。」

<!-- PAGE 5 -->
虽然我们这位**注释家**有时未必道出某段经文的确切含义，然而他所提出的，从未有与神圣真理不合之处，且总是有益而切于实用的；他常常显出对人心在此生所遇各种试炼与试探之下如何运作有着深邃的认识；因此他所作的观察总是引人入胜、启人心智。CALVIN（加尔文）从不从一段经文中推出本身谬误或不健全的结论，尽管他未必在一切情形下都推出经文正当所能支持的东西。所以，他所提出的即或未包含在所解释的经文之内，其中也毫无危险。然而在大多数情形下，他在教义上的应用是完全可以站立得住的，且往往极其鲜明有力，足以教导人、建立人。

或有人以为，我们这位作者在解释应许与预言时，并未总是赋予它们那全备的意义范围。这或许可从一个事实中找到缘由：在他之前的大多数注释家，在这一题目上都放纵于极大的过度铺张；而反动往往把人驱向相反的极端。然而加尔文极少可以被公正地指责有这一类的过失；因为他对神的话怀着最深的敬畏，严格遵循他所认定的字句本身所含之意，以及他所领会的一段经文的总体旨趣。或许，在那些想象力极为活跃之人的评判中，他会被认为过于紧守本文与上下文所要求的范围；然而在解释神的圣言时，最当避免的莫过于任凭想象奔驰，最为必需的莫过于具备健全的判断力，并存着敬畏神的心来运用它，且祈求祂的引导与指示。

<p style="margin-left:2em;" markdown="1">*J.O. 特拉辛顿（THRUSSINGTON），1848年10月。*</p>

<p class="title-block-h2" style="text-align:center; font-size:16px; font-weight:bold; margin:18px 0 12px;" markdown="1"><span style="color:#006411">约翰·加尔文</span></p>

<p style="text-align:center" markdown="1">论先知</p>

<p class="title-block-h1" style="text-align:center; font-size:22px; font-weight:bold; margin:18px 0 12px;" markdown="1"><span style="color:#0000d4">哈巴谷书</span></p>

<p class="title-block-h2" style="text-align:center; font-size:16px; font-weight:bold; margin:18px 0 12px;" markdown="1"><span style="color:#006411">加尔文《哈巴谷书》序言</span></p>

接下来是**先知哈巴谷**；[^f1] 但他执行教师职分的时间却不甚确定。希伯来人照其惯常的作法，毫不迟疑地断言他是在**玛拿西**王治下说预言；然而这个推测并无稳固的根据。不过我们有理由认为，这预言的宣告，是在这百姓的悖逆已到无可挽回之时。的确，从我们随即要留意的那段哀诉看来，这百姓在此之前很可能已多次显出其败坏无可救药。在我看来，显然是在别人已徒然尝试矫正这百姓的邪恶之后，这位先知才被差遣的。但既然他宣告审判临近**迦勒底人**，他似乎是在玛拿西治下，或在**西底家**之前的其他诸王治下说预言；只是我们无法确定其准确的年代。[^f2]

本书的内容大致如下：——在**第一章**中，他哀诉这百姓悖逆顽梗，痛惜当时盛行的种种腐败；随后他以神的使者身分出现，警告犹大人他们的毁灭已近；此后他又施以安慰，因为迦勒底人的骄傲一到不可容忍的地步，神就必刑罚他们。在**第二章**中，他以自己为榜样，劝勉敬虔人存忍耐之心，并详论巴比伦行将倾覆；至于**第三章**，我们将会看到，他转而为祈求与祷告。

现在我们要来看这些话语。

[^f1]: 哈巴谷是何人，无从确知。有些人根据第三章19节推断他属利未支派；但前提并不足以支持这一结论。*Adam Clarke* 说：「他大概属*西缅*支派，是伯撒迦（Beth-zacar）人。」至于这一推测的根据，则未加说明。——*编者*

[^f2]: *Newcome* 的看法如下：——「哈巴谷似乎生活在尼尼微被攻取之后，因为他预言迦勒底人，而对亚述人之事却缄口不言。我们也有理由断定，他发预言的时间距犹太人被掳不远。参见第一章5节；二章3节；三章2、6-19节。因此可将他置于约雅敬王在位之时，即主前606年至598年之间。」
