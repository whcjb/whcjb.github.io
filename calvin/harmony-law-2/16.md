<p class="title-block-h1" style="text-align:center; font-size:22px; font-weight:bold; margin:18px 0 12px;" markdown="1"><span style="color:#0000d4">神圣的供物</span></p>

<p class="title-block-h2" style="text-align:center; font-size:16px; font-weight:bold; margin:18px 0 12px;" markdown="1"><span style="color:#006411">利未记 24</span></p>

<p style="text-align:center; margin:18px 0;" markdown="1"><span style="color:#000080">前往 利未记 24:5-9</span></p>
<p style="text-align:center; margin:18px 0;" markdown="1"><span style="color:#000080">前往 出埃及记 29:38-46</span></p>
**出埃及记 29:38。** <span style="color:#800000">*你每天所要献的就是。*</span> 我认为，在众祭之中，理当把首位给那每日献上、称为「常献的祭」的祭；因为神愿意每天早晚各将一只羊羔献给祂，好使百姓能不断地操练自己，记念那将来的和好。但是，尽管在律法之下祭牲不住地反复献上，而这些祭物的献上本身并无赦罪的功效，我们却须留意：正如大祭司每年一次带着血进入至圣所，照样，另有一种祭牲每日陈在百姓眼前，也是有益的，好使他们思想自己时刻需要与神和好。所以，每日都用两只羊羔作挽回，使以色列人从一天之始到一天之终，都被提醒自己的罪咎与定罪，从而学会奔向神的怜悯。所拣选来作这祭的羊羔是无瑕疵、完全的；因为提到它的年岁（一岁），便暗示它的完美或完全。它与用油调和的饼，以及一份奠酒同献；古时的人无疑藉这些象征受了提醒：向神献上任何淡而无味之物都是不合宜的。诚然，神并非因这馨香之气而得着满足，祂也不愿使祭司习于美味佳肴，以致他们借宗教之名成为贪食之徒；因为酒的香气本身绝不能使神喜悦；然而这些调味之物的用意乃在于：叫百姓不停留在那空洞虚浮的表象上，而要承认在这些表象之下另有更美好、更卓越的实底。如此说来，酒与油的香气无非就是属灵的真理；就百姓这一方而言，他们当把信心与悔改带到祭物之上。而外在的仪式若无其实底，断然只是愚妄而已。连外邦列国也部分地仿效了这一礼仪；贺拉斯那句话正由此而来——

<p style="text-align:center; color:#000080; margin:14px 2em;" markdown="1"><span style="color:#000080">*“Utque*</span> <span style="color:#000080">*sacerdotis fugitivus, liba recuso: ”*</span> [^f230]</p>

<p style="text-align:center; color:#000080; margin:14px 2em;" markdown="1"><span style="color:#000080">*「又如那从祭司那里逃走的奴仆，我推辞不受供饼：」*</span></p>

<!-- PAGE 195 -->
他借此暗示：供饼是普遍地献给偶像的。但这不过是盲目的效颦，因为他们眼光不肯往上看，反倒以为他们的神明也像人一样，喜爱甘甜精美的食物；而正如我在上文所暗示的，神的用意却截然不同；因为神乃是要藉那外在的香气来唤醒祂的百姓，使他们被一种真挚的悔改之情、并纯正的信心所感动，从而寻求他们罪的赦免——不是在他们亲眼看见被宰的这些羊羔里，而是在那应许给他们的祭牲里。他们称它为「常献的」祭，因为神吩咐要世世代代不住地献上；但从但以理书看来，它是暂时的，因为它在基督降临时便止息了；因为天使如此说：基督

<p style="text-align:center; color:#000080; margin:14px 2em;" markdown="1"><span style="color:#000080">「他必与许多人坚定盟约一七之久；一七之半，</span> <span style="color:#000080">他必使那常献的祭与</span> <span style="color:#000080">供物（</span><span style="color:#000080">*minha*</span><span style="color:#000080">）</span> <span style="color:#000080">止息。」</span> [^f231] <span style="color:#000080">（</span><span style="color:#000080">但以理书 9:27。）</span></p>

显然他所说的正是这一类的祭。由此我们确实可以断定：藉着这祭，百姓的心思被引向基督。但这既是它在古人身上的功用与目的，如今它的益处便归回到我们身上，使我们得知：凡当日藉预表所显明的，都已在基督里得着成全。神应许说，这祭要在祂面前作「安息的馨香」。[^f232] 因此，我们不可怀疑：祂已藉着祂独生子的祭完全向我们施了挽回，赦免了我们的罪。然而，基督虽只一次献上，好使祂藉这一次的献上使我们永远归神为圣，我们却从律法之下这每日的祭学得：藉着祂受死的功效，赦免总是为我们预备好的，正如保罗所说，[^f233] 每当神在福音里把基督的祭摆在教会面前时，祂便不住地使自己与教会和好。至于 *minha* 这个词，[^f234] 它虽源于 <span style="color:#008080">נחה</span> *nachah*（意为「献上」），我们却仍须认定它特别用于这种供物，就是每日之祭的一种附加物。也有人把它单限于晚祭；但当它与祭牲连用时，它也被广泛地延伸至其他的供物。

<!-- PAGE 196 -->
**出埃及记 29:42。** <span style="color:#800000">*在会幕*</span> [^f235] <span style="color:#800000">*门口。*</span> 这段经文向我们显明：当 <span style="color:#008080">מועד</span> *mogned* 这个词与帐幕连用时，是在何种意义上使用的。有人把它译作「法度」（testimony），有人译作「教会」（church），有人译作「会集」（assembly，*conventum*），有人译作「所定之处」（appointment，*constitutum*）；但它的字源在这段经文里已充分显明；因为，摩西在解释这一称呼的缘由时，用了 <span style="color:#008080">יגד</span> *yagnad* 这个词，它正是此名之所本。那么，何为「会集的帐幕」呢？神自己回答说：它是祂为祂的百姓所拣选、所指定的地方，好使他们在那里彼此*相*会、达成一致。有人以为它的词根是 <span style="color:#008080">עדה</span> *gnadah*，意即以隆重之礼作郑重的声明；但既然这与文法相悖，我便取那确定无疑的说法。在这一构词里，<span style="color:#008080">יעד</span> *yagnad* 一词意为与他人立约或达成协议，或至少是为办理彼此的事务而相聚；因此，在我看来，没有一个词比 *convention*（会集）更贴近地与它对应；因为神邀请他们前来亲切交谈这一事实，对于保守信徒对祭司应有的谦恭敬重，具有极大的分量。在下一节里，祂用第三人称向他们重申：凡愿被算在以色列人中间的，都不可转离、或漂流到别处去；因为有一条律例为以色列众子孙立定：他们当在那里寻求神。随后又附上另一项印证，*即*：这地方理当分别为圣，因为神要在那里荣耀地彰显祂的荣光。总之，从这整段经文看来，神的用意乃是要藉利未祭司职分的纽带，把百姓与祂自己紧紧系在一起；然而我们须留意：惟独神能使那地方、那供物、以及那些人自身成为圣洁。因此，那些僭取过于神所赐给他们之分的人，其夸口实属无稽。若信教皇之言，至圣的圣洁便在他身上；然而，既然他拿不出神的授权来证实此事，只是凭着毫无根据、凭空杜撰的头衔自我夸耀，我们尽可放心讥笑他那愚蠢的无耻。但从这段以及类似的经文，我们得出这样的教义：不可按属人的方式来衡量基督，乃要按祂属天的、神性的大能来衡量祂。由此也驳倒了天主教祭司的夸口，就是他们自称能献上基督；因为我们总要问他们：凭什么权柄？既然神单单为自己保留了使那些执行合法祭司职分之人成圣的权利。

**出埃及记 29:46。** <span style="color:#800000">*他们必知道我是耶和华。*</span> 在这些话里，神表明：祂不只是一度作了祂百姓的拯救者，乃是要主宰他们的福祉，并以实际行动证明祂住在他们中间。此外，祂又设立圣所作为祂同在的象征，仿佛是其凭质；祂愿意敬虔的准则由此而出，也愿意敬拜祂的人在此寻求它。

<p class="title-block-h2" style="text-align:center; font-size:16px; font-weight:bold; margin:18px 0 12px;" markdown="1"><span style="color:#006411">民数记 28</span></p>

<p style="text-align:center; margin:18px 0;" markdown="1"><span style="color:#000080">前往 民数记 28:1-15</span></p>
**民数记 28:1。** <span style="color:#800000">*耶和华晓谕摩西说。*</span> 摩西将要再次论到那「常献的」祭，便先总括地立下：百姓在他们的供物上，当殷勤遵行神所吩咐的一切；因为「谨守」（*custodiendi*）这个词所表达的，不只是殷勤，也包括顺服。但为使他们更加恳切地防备一切的干犯，神把那每日惯常摆在桌上的、或那附加于燔祭之上的，称为*祂的*食物，仿佛祂像人一样吃它。这诚然是一种生硬的说法，但祂古时百姓的粗鄙迫使祂如此粗浅地说话，好叫他们一方面得知这礼仪蒙神悦纳，正如食物为人所悦纳；另一方面，也叫他们竭力更加纯洁贞正地献上自己的祭物。

**民数记 28:3。** <span style="color:#800000">*又要对他们说。*</span> 他重申我们在出埃及记所看见的：他们当每日宰两只羊羔，一只在早晨，一只在黄昏；不过他更充分地论到相随的面与酒，也提到这种祭的古老，以此作为它的可取之处，因为它是在西奈山开始向神献上的，且是「安息的馨香」。[^f236] 所提到的奠酒，在外邦列国中也曾通行；但既然它没有神的吩咐与应许，就不能不是毫无意义的（*insipidum*，即淡而无味）。[^f237] 而且很可能（正如我们在别处所见），许多外邦的礼仪乃是从古时的列祖传下来的，却不过是一种虚假空洞的效颦；因为当他们忘了这些礼仪的缘由时，他们所行的一切便只能是纯粹戏台上的排场。但我们已经说过：人藉此受了提醒，要在日常的饮食中时常把神摆在眼前；从而在凡事上使自己习于培养圣洁。

<!-- PAGE 198 -->
**民数记 28:9。** <span style="color:#800000">*当安息日。*</span> 前一段所省略的，在此得着补充，*即*：在安息日，那常献的祭要加倍，献两只羊羔以代替一只；因为这是合理的：既然第七日是特别分别归神的，它就当藉某种非常而独特的记号被高举在其他日子之上。祂也吩咐在月朔、就是新月之初，要献上更大的祭，*即*两只公牛、一只公绵羊，以及一只作赎罪祭的公山羊；因为我们知道，每月的头一日都是分别归神的，好使百姓更频繁地重新记起他们敬虔的本分；又加上那作赎罪的公山羊，好叫他们每月都以有罪之身来到神面前，恳求祂息怒。

<p class="title-block-h2" style="text-align:center; font-size:16px; font-weight:bold; margin:18px 0 12px;" markdown="1"><span style="color:#006411">民数记 28</span></p>

<p style="text-align:center; margin:18px 0;" markdown="1"><span style="color:#000080">前往 民数记 28:16-31</span></p>
**民数记 28:16。** <span style="color:#800000">*正月十四日。*</span> 诚然，这里所给的训诲与逾越节有些关联，但既然所公然论及的乃是祭物，而除此处之外并未提到逾越节的其他守节之例，我便把它与那常献的祭相联系，作为它的相随之物或组成部分。摩西确实只是略略提到我们已经看过的，*即*：百姓当七天之久禁绝酵，吃无酵饼；但他随后便切入他在此所要论述的要点，*即*：百姓当宰两只公牛作燔祭，并一只公绵羊、七只羊羔，同献一只作赎罪祭的公山羊；且这祭要在整个七日之间反复献上。如此，为要增添人对逾越节的敬重，这非常之祭便被加在那常献的祭之上，一则叫他们藉此越发被激励，将自己献给神；二则叫他们承认祂何等亲切地以恩眷拥抱了他们，因为祂从他们的羊群牛群中取了这些供物，又要他们从自己的酒窖与谷仓中为祂预备那圣洁的筵席；三则叫他们承认自己应受永死，从而奔向祂求赦免，同时也叫他们明白：和好之路只有一条，*即*：当神藉祭得着挽回之时。

<!-- PAGE 199 -->
**民数记 28:26。** <span style="color:#800000">*在初熟之日。*</span> 摩西就另一个节期，*即*他们献初熟之物的那节，颁下相同的诫命。他也教导他们说，那时那常献的祭要有所增添，加上两只公牛、一只公绵羊、七只羊羔、一只作赎罪祭的公山羊，连同 *minha*（素祭）与一份奠酒，其用意我已经说过了。这里出现了一个令人困惑的难处，因为在利未记 23 章里，提到的是一只公牛而非两只，反过来，又是两只公绵羊而非一只。[^f238] 有人认为在这件事上留给了祭司自行选择的余地；但当我思想神在凡事上所颁的命令是何等精确时，我便怀疑是否真把这样一种取舍交由他们裁量。有人以为神曾一度以一只公牛为足，因为他们在旷野中牛不丰足——这种看法在我看来不过是一种遁词。我承认，我不知如何摆脱这个难处，除非我们或可这样说：既然在其他一切细节上都已作了足够精确的规定，使得凡事都不无缘由地行，那么惟独在这一点上，他们乃是受了提醒——神就其自身而言，并不在乎祭牲的大小多寡。也没有任何出于敬畏的顾虑拦阻我们说：正如在细微之事上有时会发生的那样，一个错误的数目或许因抄写者的疏忽而混入了；[^f239] 而这大概是最自然的解释。依我之见，更正确的读法是：他们当献两只公牛与一只公绵羊；但既然神为何设立这日已在别处解释过，他在此只简略地复述：「当他们将 *fainha* 与初熟之物一同带来时。」

<p class="title-block-h2" style="text-align:center; font-size:16px; font-weight:bold; margin:18px 0 12px;" markdown="1"><span style="color:#006411">民数记 29</span></p>

<p style="text-align:center; margin:18px 0;" markdown="1"><span style="color:#000080">前往 民数记 29:1-39</span></p>
**民数记 29:1。** <span style="color:#800000">*在七月。*</span> 我已经说过，这里所论的并非那些节期（*就其整体而言*），而只是那些用以增添节期庄严的祭物。在七月之初，有所谓吹角的记念日。因为这是一个较小的节期，摩西只吩咐宰一只公牛；但这数目却因别的缘由而增加，因为我们已经看过，每月的头一日要献两只公牛。所以这一日共有三只较大的祭牲，而其余的数目则加倍，以致有两只公绵羊和十四只羊羔。如此，神便将这一日双重地分别归给自己，使这一庆典丝毫无损于那一庆典；否则祂就似乎废掉了自己一度所吩咐的。由此可见，吹角的记念并非废除了月朔，乃是他们同时遵守这两项定例。

<!-- PAGE 200 -->
**民数记 29:7。** <span style="color:#800000">*在初十日。*</span> 这就是赎罪日。因为，他们虽然从不曾不带着求赦之恳求就来到神面前，那时他们却以一种特别的方式认自己的罪，因为有一个禁食之礼被定为他们有罪的凭证。因为利未记 23:29 如此记着说，

<p style="text-align:center" markdown="1"><span style="color:#000080">「当这日，凡不刻苦己心的，</span> <span style="color:#000080">必从民中剪除。」</span></p>

至于祭物，只需一只公牛；其余的与前面相同，只是加上了一项例外，是前几处所省略的。因为除那公山羊之外，另指定了一种挽回之祭，好与他们刻苦己心这一事实相称。因为，若没有和好的盼望，承认罪咎对他们的良心必是可怕的折磨。这祭的缘由不久便要解释。

**民数记 29:12。** <span style="color:#800000">*在十五日。*</span> 在他们的节期中，这末后的一个是最主要的，[^f240] 在这节期里他们住在棚里，共七日；因为，他们在逾越节所记念的，乃是他们脱离埃及诸灾、得着自由而出来的那一夜；而藉着住棚，他们所涵盖的却是整整四十年，就是他们的列祖在旷野中经历神那持续不断、完备无缺之恩慈的岁月。那庄严的聚会也有另一个当前的用途，*即*：为庄稼的收成向神献上感恩。因此，他们天天献祭，且数目更多：第一日十三只公牛、两只公绵羊、十四只羊羔；第二日十二只公牛；第三日十一只；第四日十只；第五日九只；第六日八只；末了，第七日七只；第八日一只。摩西在这番陈述上耗费如此多的言语，并非漫不经心；*第一，* 是要使凡事都不越乎神的吩咐而行；*第二，* 是免得他们因这样大的花费而觉得不悦或沉重——这原是他们乐意躲避的。因此，为使他们能欢然遵行神的命令，他殷勤地反复申明神愿意每日献给祂的是哪些祭牲。但为何这分配如此不均，我承认，我并不明白；与其以过于精微的臆测化为一缕青烟，不如承认自己的无知。[^f241]

<!-- PAGE 201 -->
有一种想法，倒既不算牵强，也不当弃绝，*即*：他们逐日递减数目，末了在第七日归到「七」这个数目，就是完全的象征；至于第八日，不过是作为结尾而额外附加的。最后，摩西补充说：无论在那常献的祭上，还是在这些非常之祭上，他们都当持守神所规定的，使凡事都不照人的臆想而更改。至于那些系于第二块法版诫命的祭物，我有意把它们留待合宜的地方再论。
