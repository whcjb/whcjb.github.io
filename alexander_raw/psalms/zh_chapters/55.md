<span class="ax-vnum">1.</span> *交与伶长。用*（或*配）丝弦的乐器 一篇训诲的诗。大卫作。*此篇被标为*玛斯基拉*（Maschil），因为乍看之下，它似乎只关乎个人所受的虐待与苦难，其实却是对神的子民、或说义人这一类人的苦难的总体描绘——他们受害于假朋友与恶毒的仇敌之手。虽然其中似有指涉作者自身经历之处，既涉扫罗之时，也涉押沙龙之时，但通篇的描绘不能单独归于其中任何一段。此篇唯一自然的分法，乃是由以下事实提示的：第一部分中，受苦者泛泛地控诉他的众仇敌，第 2-12 节（1-11）；第二部分中，他特别挑出一人的情形，此人本似他的朋友，却奸诈地反转过来与他为敌，第 13-16 节（12-15）；第三部分中，他满有把握地预期自己必得拯救，仇敌必被毁灭，第 17-26 节（16-25）。

<!-- PAGE 251 -->
<span class="ax-anchor" id="psalms-55-1"></span><span class="ax-vnum">2 <span class="ax-veng">(1).</span></span> *神啊，求你侧耳听我的祷告，不要向我的恳求掩面。* 这是总括性的引言式祈求，下文再加以铺陈、使之更为具体。末一词严格说来意为呼求，即求怜悯的祷告。参看上文诗篇 6:10 (9) 的注释。「掩藏自己」是律法中所用的说法，指明知有人需要帮助却故意不施援手的行为。参见申命记 22:1-4，并比较以赛亚书 58:7。

<span class="ax-anchor" id="psalms-55-2"></span><span class="ax-vnum">3 <span class="ax-veng">(2).</span></span> *求你侧耳听我，应允我；我要放任我的思想，我要发出声响。* 头一个动词的意思是*留心、注意，*尤指留心听人说话，即倾听、侧耳而听。见上文，诗篇 5:3 (2)，10:17，17:1 的解释。*应允*或*垂听，*是指施恩悦纳祷告。见上文，诗篇 3:5 (4)，38:16 (15) 的解释。下面这几个词的字面翻译是：*我要容让（自己）在思想中游荡，即*我要让我的心思游移，让我的思绪任意漫行。他所决意的，不只是自由地思想，更要把所思的放声说出来。这个希伯来动词的同样用法见于弥迦书 2:12。此处所说的思想或默想，乃是对自己所受苦难的反复思量，那希伯来动词正是专用于此的。全节、尤其是这一分句，可与约伯记 7:11 相比较。

<span class="ax-anchor" id="psalms-55-3"></span><span class="ax-vnum">4 <span class="ax-veng">(3).</span></span> *因着仇敌的声音，因着恶人的逼迫之面前；因为他们要把罪孽倾落在我身上，并在怒中与我为敌。* 他此处说明自己的苦难由何而来。这介词在希伯来文中与在英文中一样，带有原因的意味，至少也暗示因果的关系。*从那声音，即*因它的缘故。*从……面前*或*从……的脸*把同一意思表达得更为有力，因为它把所惧怕的祸患加以某种人格化。*恶人的逼迫：*可比较诗篇 42:10（9）中的*仇敌的欺压。**倾落在我身上，*或说使之滑落到我身上，这是一个鲜明的比喻，指蓄意把祸害加于他人。*罪孽*在此或许如别处一样，用以指向他人施行的实际恶行，即苦难之因，而非苦难本身。此句可与诗篇 41:9（8）相比。*与我为敌，*作我的对头，无论是以抵挡还是以攻击的方式。这个希伯来文动词与 *Satan*（撒但）即*对头*所出的那个字同源。

<span class="ax-anchor" id="psalms-55-4"></span><span class="ax-vnum">5 <span class="ax-veng">(4).</span></span> *我的心在我里面绞痛，死亡的恐怖已落在我身上。*第一个动词用将来时的形式，含有一种忧惧，即这痛楚将持续下去、成为长久的。*在我里面，*即在我内部、在我心中。他不单是陷在外面的患难里，更是心中痛苦。*死亡的恐怖*若严格按字面理解，可指对死亡的惧怕或惊惧；但若取「致死的、要命的恐怖」之义，则与上半节强烈的比喻语言更相称。与此类似的说法有*死荫*或死亡的影子。参看前面诗篇 23:4, 44:20 (19) 的注释。「落下」这一比喻必然令人想到是由更高的权能所施加的。

<span class="ax-anchor" id="psalms-55-5"></span><span class="ax-vnum">6 <span class="ax-veng">(5).</span></span> *惧怕与战兢进入我里面，惊骇遮盖了我。* 前半句的将来时表明动作尚未完成，也可译作「它们正在进入」或「将要进入」。希伯来文动词带这个介词，所含之意不止于*临到；*它所描绘的恐惧不单在他身上，更在他里面。译作*惊骇*的那个词是*战兢*更强烈的同义词，也可译作*发抖*或*一阵颤栗。遮盖了我，即*漫过我或淹没我。

<!-- PAGE 252 -->
<span class="ax-anchor" id="psalms-55-6"></span><span class="ax-vnum">7 <span class="ax-veng">(6).</span></span> *我说，谁能给我翅翎如同鸽子的呢？我就飞去，得安息。*这等于说，我若有鸽子的双翼，我就飞去……。*谁能给*是一个表愿望的惯用语，相当于说*哦，但愿我有，*……。见前面诗篇 14:7 的注释。译作*翅翎*的那个词，本指鸟翼上的 *penna major*（大羽、主翎），此处以诗的笔法代指翅膀本身。末两个动词都用了延长式（paragogic）或加强式，表达强烈的愿望或既定的意向。见前面诗篇 2:3 的注释。末一动词通常意为*居住，*但兼有安歇、安息的本义或引伸义。见前面诗篇 37:3 的注释。首一动词直接承接上一节末尾的动词，这种语法关系在我们的语言习惯里可以这样表达：「惊恐将我遮盖，以致我说」……。

<span class="ax-anchor" id="psalms-55-7"></span><span class="ax-vnum">8 <span class="ax-veng">(7).</span></span> *看哪，我要远远飘流，我要寄居在旷野。细拉。* 这 *看哪* 或 *瞧* 相当于用手指点，或是说 *那里！看那里！* 下一个短语极富希伯来语的惯用语色彩，字面意思是「我要使飘流为远」。此处的 *寄居* 是指安家、居住，与诗篇 25:13 中的用法相同。*旷野，* 不一定是荒芜的沙漠，而是无人居住的地带，这里的要义在于与人类社会隔绝，这是一种虽属间接却极有力的说法，断言其败坏已到极处。催生此愿望的情感之强烈，由一处庄重的停顿标示出来。

<span class="ax-anchor" id="psalms-55-8"></span><span class="ax-vnum">9 <span class="ax-veng">(8).</span></span> *我要速速逃脱，离开狂风，离开暴雨。*对前一分句的另一种解法，是把那动词看作不及物的，把那名词按其字形看作表地点的，即*我要速速奔向*（到）*我的避难所。*然而更好的是让这动词保有其 hiphil（使役）语干本有的意义；并且此处所用这一形式的名词，不仅指动作发生之处，也指动作本身。*我的逃脱，*字面作*给我的、或为我自己的一次逃脱。*末一分句中的介词，虽本义为*从，*但在希伯来文中常被用来表示或指明比较。若在此处如此解释，则这分句所描述的便是他所切望逃脱的速度，*胜过狂风暴雨。*有些解经者偏取此义；但前一义更为明显平易，并且还有一点支持它：灾祸常以风暴或暴雨为喻；倘若所要传达的仅是极快之意，这暴雨之喻也就不大会与风连用了。

<span class="ax-anchor" id="psalms-55-9"></span><span class="ax-vnum">10 <span class="ax-veng">(9).</span></span> *毁灭吧，主啊，分开他们的舌头；因为我在城中见了强暴与争斗。*首词的本义是*吞灭。*参上文，诗篇 21:10 (9)。所当补出的宾语不是*他们的舌头，而是他们自己。分开他们的舌头，即*混乱他们的言语，使之无从听懂，并由此必然地混乱他们的谋算。此处显然指巴别的变乱口音（创世记 11:7-9），那是一个重大的历史范例，表明神素来如何、也定意如何挫败恶人的图谋而成就自己的旨意。译作*残忍*的那个词指强横的不义，或伴随暴力的不义。参上文，诗篇 7:17 (16)。*在城中*一语，有人以为不过是指在人中间、在人类社会里；但这话对任何希伯来读者都不能不唤起圣城的观念，视之为直接所指之地，虽然这话本身也可用于凡有同样情形的别处。

<span class="ax-anchor" id="psalms-55-10"></span><span class="ax-vnum">11 <span class="ax-veng">(10).</span></span> *昼夜他们必在她城墙之上环绕她；罪孽与祸患必在她中间。* 前一节的强暴与争闹，在此被拟人化为围城的仇敌。与此同时，城内又被罪孽与祸患所据，这二者同样是可畏的仇敌。*她的城墙，*即前一节所提到的*那城*的城墙。罪孽与祸患在此处、并在别处多次，被并列为因与果，后者指一人的恶行加于另一人身上的苦难或祸患。参看上文诗篇 7:15（14）的论述，

<span class="ax-anchor" id="psalms-55-11"></span><span class="ax-vnum">12 <span class="ax-veng">(11).</span></span> *祸患*（在）*她中间，强暴与诡诈不离她的街市，*希伯来文的头一个词必然同时含有*灾祸*与*罪行，即*因他人的罪行而招致的灾祸这两重意思。参看前面诗篇 5:10 (9)、38:13 (12)、52:4, 9 (2, 7) 的解说。译作*街市*的那个词指宽阔之处，尤用于东方城邑城门四周的广场或空地，那里既作市集，也作审断之所。见尼希米记 8:1, 3, 16。因此这个词极近于希腊文的 *agora*（集市广场）与拉丁文的 *forum*（公共广场），在此或是要同时点出司法与商业两方面的不法行径。他们的市场与他们的法庭，从来不曾摆脱这两种极重的不义，就是欺诈与强暴。

<span class="ax-anchor" id="psalms-55-12"></span><span class="ax-vnum">13 <span class="ax-veng">(12).</span></span> *因为*（并不是）*一个仇敌*（在）*辱骂我，若是，我尚可忍受；*（并不是）*一个恨我的人*（曾）*自高*（自大）*攻击我，若是，我早已躲避他了。* 希伯来原文中与*若是*相对应的词，在这两处都是通常的连接词，原来的结构似乎是：*而*（若是如此）*我必忍受，而*（若是如此）*我必躲藏*。参看上文诗篇 51:18(16) 的注释。此处辱骂的举动兼含诽谤与侮辱。前一分句用将来时，暗示将要忍受的某种凌辱或伤害。好像他说：「当我出去行在邻舍中间时，毁谤我的并不是我公开的仇敌。」然而这样的对待他早已领受过了，这一点由末一分句的过去时透露出来。*自高*这个动词在此是作反身或绝对用法，与诗篇 35:26、38:15(16) 中一样。因此不必假定有省略，也不必把这种表达方式与诗篇 41:10(9) 中的那种等同起来。*躲避*，字面是*被隐藏*；但希伯来文的被动形式往往含有反身的动作，如同希腊文的中间语态。本节的否定当然不是绝对的，而是相对的，必须按着事情的情境加以限定。他被公开的仇敌辱骂恐吓，不但别处屡屡成为他哀告的内容，上文第 4(3) 节也已足够地暗示了。这表面上的矛盾，真正的解答在于：他在此从对横行之罪恶的一般描写，转到一桩与他个人感情切身相关的特定情形。在这特定的情形中，毁谤他、侮辱他的并不是一个公开的仇敌。因此就好像他说：「但我所特别哀诉的，并不是这种公开而不知羞耻的恶行，乃是假朋友的背信。」这样理解，本节非但不与第 4(3) 节相抵触，反倒以那里所断言的为前提。

<span class="ax-anchor" id="psalms-55-13"></span><span class="ax-vnum">14 <span class="ax-veng">(13).</span></span> *但你，一个与我同等的人，我的同伴，我的熟人。*希伯来文与英文惯用语之别，在此有一个鲜明的例证：希伯来文在这句开头用的是*和*，而在英文里*但*却是绝不可少的。此处「人」所用的那个词，是表示软弱与必死的那一个。参看上文诗篇 8:5(4)、9:20, 21(19, 20)、10:18 的注释。不过这里用它似乎并无任何着重之意，只是与下文单纯同位，或用作呼格，*你，人哪，与我同等的。*末一语在希伯来文中作*按照我的估价*，所用的名词是摩西律法中的专门用语，指在某些赎回或罚银的案件中祭司所作的官方估定。参看利未记 5:15, 18；27:12。此处所用的整个短语，有人理解为*我所看重的人，即*看重得很高，或更确切地说，*我看重如己的人。*然而更可能的是，它指一个可以（或能够）与我按同一价值估量的人，这正是通行译本*我的同等*所传达的意思，即与我同一等次、同一圈子的人，我的同伴。近代解经者给希伯来文下一个词所定的，正是这末一层意思。旧译作「向导」，所依据的是一个可疑的字源，以及古译本的权威。（七十士译本 *ἡγεμών*（首领），武加大译本 *dux）。熟人*一词似乎比前两个说法为弱；但这个希伯来词向来含有极亲密交往之意。参看上文诗篇 31:12(11)，以及下文诗篇 88:9, 19(8, 18)。

<span class="ax-anchor" id="psalms-55-14"></span><span class="ax-vnum">15 <span class="ax-veng">(14).</span></span> （与）*我们一同甘美地商议的人；在神的殿中我们带着喧哗行走。*这些将来时的形式，只能这样解释：他在此预先说到一桩尚未明显发生的、对友谊之律的违背。他所控诉的这位假朋友，似乎是他至今仍与之亲密往来的人，但他已清楚预见此人的背离。仿佛他说：「我仍须与这人相交，虽然他终必出卖我。」在这一点上，所描述的情形与我们的主和加略人犹大的情形相似，那情形实在也可视为包含在这一般性的描述之内。前一分句的形式是希伯来语所特有的惯用语：*谁*（或*就谁而言）我们一同使商议甘美，*或更确切地说，使亲密的交往甘美；参看前面诗篇 25:14 的注释。后一分句或许可解作*我们行往神的殿。*但也可保留这介词的严格意义，而把整句理解为在会幕的圣院或圣围之内的庄严行列。*带着喧哗，即*带着节期的欢腾。参看前面诗篇 42:5(4) 的注释。

<span class="ax-anchor" id="psalms-55-15"></span><span class="ax-vnum">16 <span class="ax-veng">(15).</span></span> *荒凉*（临）*在他们身上！他们要活活地下到阴间！因为恶在他们的住处，在他们心中。* 大多数译本给这句话加上的祈愿语气，完全是无据添加的。希伯来原文所表达的，不过是一种笃定的预期。通行译本对开头数字的译法（愿死亡临到他们）是依据马所拉的读法 *(מָוֶת יַשִּׁיא)*；但如今最优秀的批评家更倾向于正文中较古的读法（יְשִׁימוֹת），这一读法所呈现的不是一个动词加一个单数名词，而是一个复数名词，意为*荒凉*，与所省略的系动词相配。*在他们身上，*盘旋于其上，悬临于其上。*阴间，*即坟墓，死人所在之境，也就是古英语 *hell*（地狱）一词的宽泛含义。参看上文诗篇 6:6（5）。此处显然暗指神施行报应之审判的另一个重大历史预表，就是可拉一党的灭亡，他们*活活地坠落阴间，*民数记 16:33。通行英译本在这句中所用的 *quick* 一词，是个形容词，与 *living*（活着的）或 *alive*（活的）同义，并非作副词解作 *soon*（不久）或 *swiftly（迅速）。众恶，即* 恶行与恶念。*在他们心中，*或作在其内部、内里，如诗篇 5:10（9）、49:12（11）。这个意思远胜于译作*在他们中间，*即在他们当中。

<span class="ax-anchor" id="psalms-55-16"></span><span class="ax-vnum">17 <span class="ax-veng">(16).</span></span> *我要向神呼求，耶和华必拯救我。*这里的代词是着重的，就我这一面而言。当他们被交于荒凉与死亡之时，我却反倒要向神呼求。若两个神名的并用，除了平行体的需要之外还另有意义，那么其意或许是：「我要向神呼求，而他既是以色列立约的神，就必拯救我。」参诗篇 18:4 (3)。

<span class="ax-anchor" id="psalms-55-17"></span><span class="ax-vnum">18 <span class="ax-veng">(17).</span></span> *晚上、早晨和正午我要默想并低吟*——*而他已听了我的声音。*有人认为前一分句证明一日三次定时祷告的惯例早在大卫的时代就有了；另有人则认为这一惯例正是由这分句本身引出的。但这里提到的一日之内自然而明显的划分，或许既是这分句的由来，也是那惯例的由来。*默想并低吟*是描述祷告的一组搭配，既指心中的构想，也指口中可闻的表达。*低吟*一词或许还不足以传达希伯来动词的全部含义，该词在别处意为发出大声。参上文诗篇 42:6, 12（5, 11）、46:4, 7（3, 6）的注释。某些译者在本节中把两个时态混同或混淆起来，不但是任意的，而且有害于经义。前一分句中作为尚未发生而提及的事，在末一分句中却被记为已经过去。仿佛他说：「我如此立定心意要祷告，而如今我的祷告已经献上，也已蒙应允。」这类转换属于诗篇中独具特色的佳处，不应无故牺牲，更不应以违背用法与语法规则为代价而牺牲之。

<span class="ax-anchor" id="psalms-55-18"></span><span class="ax-vnum">19 <span class="ax-veng">(18).</span></span> *他在平安中救赎我的魂脱离那攻击我的战争，因为与我相敌的人甚多。在平安中，*或作*带着平安，*意即以此为这救赎的结果。*攻击我的，*字面作*归于我的，*即那临到我的战争、我所遭遇的战争。末句在英文读者听来，所传达的意思是他的朋友或卫护者人数众多，但希伯来文的意思恰恰相反，*与我*在这类搭配中乃是用以表明敌对的关系，正如我们说与某人争战、争吵、相争时所用的*与*一样。无论哪一种情形，这个虚词所表达的实在不过是共同或同时的动作，敌意或对抗的意思乃是从上下文中得来的。末句的字面翻译是：*在许多人之中有*（那些）*与我相敌者，即*由许多人所构成。敌对的一方是由许多人组成的。这种*在*字的用法，严格说来只适用于数词。见申命记 10:22，28:62。

<span class="ax-anchor" id="psalms-55-19"></span><span class="ax-vnum">20 <span class="ax-veng">(19).</span></span> *神必听见并回应他们，且* （他）*那住于亘古者*（必听见并回应那些）*无有更替的人，和*（那些）*不惧怕神的人。* 他既以怜悯垂听了我，也必以忿怒垂听他们。他既照上文第 19 (18) 节所描述的方式应允了我的祷告，也必照下文第 24 (23) 节所描述的方式回应他们。在这种情形下，所听见、所回应的不是祷告，而是第 4 (3) 节的*仇敌的声音*，以及第 13 (12) 节他那恶毒的谗谤。*住于亘古，*或照英文圣经的措辞，*那从亘古常存者。*然而希伯来文的第一个动词不能不令人想到它的本义，就是*坐*，尤其是*坐于宝座*，如君王与审判官一般。参看上文诗篇 9:5, 12 (4, 11) 的注释。因此可以说，这句话是把神描绘为从至远的古时就已作王、作审判官的那一位。末句有人认为是指：此处所提到的人并不经历任何道德上的更变，仍旧固执地拒绝敬畏神；另有人认为是指：他们不经历任何外在的变故，没有命运的升沉，因此也就不惧怕他。但由于译作*更替*的那个词在约伯记中屡次用于军旅的意义，或指轮番的服役，例如换班守卫，或指服役中的接替，如一队解散而另一队顶上，所以一些最优秀的释经者认为本句的意思是：凡被征召入这场罪恶之役的人，无从指望这样的轮换或退伍，必须在罪的差役中无休止地当值，其必然的结果便是不能惧怕神。全节的语法结构颇为特别，惟有补出其中的省略才能使之可解。

<span class="ax-anchor" id="psalms-55-20"></span><span class="ax-vnum">21 <span class="ax-veng">(20).</span></span> *他伸手攻击与他和好的人：他亵渎了自己的约。*乍看之下，这似乎是指着神说的；但这样的指代，纵使所列举的行为性质不加禁止，也会与下文相抵触，因为那里的主语无疑是那恶毒的仇敌。数的突然转换，与诗人们提说仇敌时的惯常用法完全相符，或者在此处也可能出于与上文第 13（12）节相同的缘故。参看上文诗篇 10:10 的注释。译作*与他和好的人*的那个词，是一个意为*平安*的名词的复数形式，但此处似是诗体的用法，用以指那些与他相安无事的人，即他的友人或盟友。可比较诗篇 7:5（4）、41:10（9）中类似的说法。*亵渎约*就是把它当作不再神圣之物，并由此引申为背弃它。参以赛亚书 33:8。这是用军事的比喻，对第 13-15（12-14）节所述之事作了变换说法的重述。

<span class="ax-anchor" id="psalms-55-21"></span><span class="ax-vnum">22 <span class="ax-veng">(21).</span></span> *光滑的是他口中的乳酪，而*（然而）*争战*（在）*他心里*；*他的言语柔和，胜过油，而*（然而连）*它们也是出鞘的*（刀剑）。他在强暴的指控之外，又加上奸诈伪善的指控，由此将上文第 12（11）节简练的词语*欺压与诡诈*加以铺陈。英文圣经沿袭若干更早的译本，把两个分句处理成一律，使二者都作比较级：*比奶油更滑，比油更柔*。但要支持前一分句的这种结构，就必须更改一个希伯来词的点符，并另补一个词作那复数动词的主语，因为该动词若与*口*相配，非强解不可。前一个名词所带的前缀字母乃是该词的一部分，并非意为*比*或*胜过*的小品词；整个词所指的是奶油、乳酪、或更确切说是凝乳的制品，而凝乳正是其本源名词的意思。至于这两个分句中*和*字的转折用法，见上文第 14（13）节。*争战*（在）*他的心里*，或更简单地说（因为这样无须补入介词）*争战*（就是）*他的心，即*他所怀抱的心愿与图谋。译作*争战*的那个词是诗体用语，与上文第 19（18）节所用的相同。在末一分句中，除补出「*然而*」外还补出「*连*」，为的是尽可能传达希伯来文代词的强调语气。*而它们自己，即*方才所说那些油滑的话语，乃是出鞘的刀剑。末了这个说法在希伯来文中本是形容词或分词形式，但专用于刀剑，正如英文的 *brandished*（挥舞出鞘的）一样，因此渐渐被绝对地使用，或用作名词，表达*出鞘的刀剑*这一完整的复合概念，即作为攻击的兵器，已经预备停当，或正要立时施用。

<span class="ax-anchor" id="psalms-55-22"></span><span class="ax-vnum">23 <span class="ax-veng">(22).</span></span> *将……卸给耶和华*（就是）*他所给你的，他必抚养你；他必永不容义人动摇。*他所给你去担当的，他所加在你身上的，你当藉着信靠他而卸给他。*他给你*（或*他已给你）*这一短语，也可解作一个带所有格代词的名词，*你的赠与*，不是取主动之义的*你所给的*，而是取被动之义的*所给你的。抚养*一词在此并非指在重担之下扶持或托住，而是指供应食物及其他必需之物以养生、供养，即供给所需。参希伯来文动词在创世记 45:11、47:12、50:21 中的本义用法。上文所引末一分句的通行译法，乃是对原文的正确意译，而原文的形式极富惯用语色彩。按字面直译应作：*他必不将永远的动摇*（或*挪移）给义人。*动词*给*在希伯来文中常用作容许、许可之义。译作*动摇*的那个词，正是屡屡用来指人在亨通之中遭受剧烈震动的那个词。参看上文诗篇 10:6、16:8 等处的注释。

<span class="ax-anchor" id="psalms-55-23"></span><span class="ax-vnum">24 <span class="ax-veng">(23).</span></span> *你，神啊，必使他们下到败坏的坑里；流血诡诈的人必活不到他们日子的一半。* 头一个动词是使役形，照此可译作*你必使他们下去。* 译作*坑*的那个词在希伯来文中本是指*井，*但此处取广义，凡这类掘成的坑穴都包括在内。随后的一词（שַׁחַת）是动词（שחת）败坏或毁灭的派生词。若把它当作从动词（שׁוּחַ）*下沉*而来，取*坑穴*之义，便会使这短语成了软弱的同义反复。参上文诗篇 16:10 的注释。*血与诡诈的人，即*流血的（或行凶的）与诡诈的人，如上文诗篇 5:7（6）。末了几个字的字面翻译是：*他们必不得使自己的日子折半，*英文圣经的旁注正是照此抄录的，七十士译本（ἡμισεύσωσι）与武加大译本（dimidiabunt）亦然。其意思自然是说：他们所活的年日，必不及他们本可活到的一半——若不是因着他们流血诡诈的行径的话。这并非作为一条普遍的事实来断言，乃是作为一句威吓，向诗人当时直接注目的那些凶手与奸徒发出的。
