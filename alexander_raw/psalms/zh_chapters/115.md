神的子民恳求他所伸张的不是他们自己的荣耀，而是他自己的荣耀，第 1, 2 节；这荣耀与偶像及拜偶像之人的无能相对照，第 3-8 节，并被用作理由，叫他的子民信靠他，以得大大的加增，第 9-15 节，又叫他成就自己的旨意，即藉活人而非死人的赞美来荣耀自己，第 16-17 节；为促成这一目的，教会宣告她永远与之同工的决心，第 18 节。如此陈述的全篇大旨，连同其中各项具体内容，使本篇极合于这一组诗篇所设想的写作情形，即归回被掳之后、圣殿尚未实际重建之前的光景。

<!-- PAGE 477 -->
<span class="ax-anchor" id="psalms-115-1"></span><span class="ax-vnum">1.</span> *不要归与我们，耶和华，不要归与我们，惟要将荣耀归与你的名，因你的慈爱，因你的信实。* 这里所说的荣耀，不是昔日作为的荣耀，乃是将来作为的荣耀。其中暗含的祈求是：愿神出手拯救他的子民，不是为叫他们得尊荣，乃是为荣耀他自己，尤其是为显明他的慈爱与信实；因他撇弃了所拣选的百姓，这慈爱与信实似乎受了亏损。参看上文诗篇 79:9 的注释，并比较民数记 14:15，以赛亚书 43:7, 25，48:9, 11，但以理书 9:18。此处所求的恩惠，乃是复兴之工的完成——这工虽已有吉兆地开始，却仍未完全。

<span class="ax-anchor" id="psalms-115-2"></span><span class="ax-vnum">2.</span> *列邦为何要说，他们的神如今在哪里呢？* 为何要让他们有机会如此发问？这一表达的形式借自诗篇 79:10，只是加上了（נָא）*如今，*此词并非表时间的虚词，而是表恳求的语助词，在此处的关联中则带有得胜者质问的口吻。*请问，他们的神在哪里呢？* 本节是对前一节的解释，表明确实需要有什么来堵住外邦人的辱骂，而这一描述恰与犹太人在归回之时的光景相符。

<span class="ax-anchor" id="psalms-115-3"></span><span class="ax-vnum">3.</span> *而我们的神*（却）*在天上；凡他所喜悦的，他都行了。*这个*而*字虽与我们的语言习惯不合，却明显增添了表达的力量。他们如此发问，仿佛我们的神不在场、或根本不存在；然而我们的神自始至终都在天上，在他荣耀崇高的居所。参诗篇 2:4，11:4，103:19。同样的语句，只是用将来时，为所罗门所用（传道书 8:3）。同一思想另以别的话表达，见创世记 18:14，约伯记 23:13。

<span class="ax-anchor" id="psalms-115-4"></span><span class="ax-vnum">4.</span> *他们的偶像*（是）*银和金，人手的工作。*这里开始了真神与一切他神之间的对比。*他们的偶像，*即外邦人的偶像，就是那些以我们神的不在或漠不关心来讥诮我们之人的偶像。关于与那表示*偶像*的词相连的种种意味，见上文诗篇 106:38 的注释。*人的手，*不是*某一个人*的，而是*人类，即*人之手。此整段可与以赛亚书 40:18-20，41:7，44:9-20，46:5-7，耶利米书 2:28，10:3-15 相比较。

<span class="ax-anchor" id="psalms-115-5"></span><span class="ax-vnum">5.</span> *它们有口却不说话；它们有眼却不看见。* 由于*有*这个动词在希伯来文及其同族语言中并不存在（见上文，诗篇 114:5 的注），所以这并非对原文措辞的字面翻译，原文作：（有）*口属于它们，*（有）*眼属于它们。* 此处的将来时所含的不仅是一句单纯的断言——*它们不说话，它们不看见，*——还含有将来与可能的意味：它们永远不会、也不能说话或看见。

<span class="ax-anchor" id="psalms-115-6"></span><span class="ax-vnum">6.</span> *它们有耳却不听见，有鼻却不闻味。*此处的对照，正是诗篇 94:9 所表达的：神是人眼目的造成者、耳朵的栽植者；那么祂自己岂不更能看、更能听么。

<span class="ax-anchor" id="psalms-115-7"></span><span class="ax-vnum">7.</span> *它们有手，却不摸；它们有脚，却不走；它们不在喉中作声。*这一长串列举的单调，其力量在于逻辑而不在于诗意，所幸原文的形式有所变化，使单调稍得缓解，而这种变化在翻译中不易仿效。*它们的手，而它们不摸；它们的脚，而它们不走。*有人把每一分句开头的词看作独立主格：*它们的手*——*它们不摸；它们的脚*——*它们不走。*但在上文描述的各部分中，动词所指的并非某一肢体，而是整个人身。因此更好的办法是补出一个动词——*它们的手*（在那里），*而*（然而）*它们不摸*——*它们的脚*（在那里），*而*（然而）*它们不行。*英文的 *feel*（摸）在此当取其形体的、外在的意义，相当于拉丁文的 *palpo*（触摸），武加大译本与耶柔米在此即用此字。更无歧义的译法当作 *touch*（触）。另一个动词指身体一切向前的动作，皆包含在英文的 *go*（行走）之内。参看上文诗篇 104:8 的注释。末一分句的意思是：它们连最微弱、最含糊的喉音也发不出来，连低等动物尚且不如，更不用说像人那样说话了。参看上文诗篇 35:28、71:24 的注释。

<!-- PAGE 478 -->
<span class="ax-anchor" id="psalms-115-8"></span><span class="ax-vnum">8.</span> *造它们的必像它们一样，凡倚靠它们的也是如此。*末句禁止把前句仅仅应用于工匠本身，而把它系于那些信靠偶像的人，无论偶像是他们自己所造，还是别人为他们所造。这些人如今无论何等可畏，将来必与他们所拜的神一样无能、无知。译作*是*（现在时）则违反希伯来文的惯用法，因这惯用法要求实质动词的现在时略去不表。

<span class="ax-anchor" id="psalms-115-9"></span><span class="ax-vnum">9.</span> *以色列啊，你当倚靠耶和华；他们的帮助、他们的盾牌* （就是）*祂，* 这是对刚才所呈现之对比的实际应用。既然偶像无能而神全能，惧怕偶像或惧怕事奉偶像之人便是愚妄；不倚靠祂则比愚妄更甚。末句取自诗篇 33:20。他在前一分句中直接称呼以色列，到后一分句又回到第三人称，仿佛自言自语一般，说出这劝勉的理由。前一分句可说是高声发出的，后一分句则是低声说的。

<span class="ax-anchor" id="psalms-115-10"></span><span class="ax-vnum">10.</span> *亚伦家啊，你们要倚靠耶和华*；*他们的帮助、他们的盾牌*（就是）*他。*若在被掳之前，这样专向祭司说话会令人诧异。然而在从巴比伦归回之后，这却是极其自然的：那时祭司在人数上所占的比例甚大，不独相对于其余的利未人如此，相对于全民也是如此，并且他们在国事上自然而然地握有极大的影响力。

<span class="ax-anchor" id="psalms-115-11"></span><span class="ax-vnum">11.</span> *敬畏耶和华的人哪，你们要倚靠耶和华；他们的帮助、他们的盾牌* （是）*他。* 他再次转向全体会众，此处称他们为敬畏耶和华的人，并非就其中每一个人实际的品格而言，乃是就这群体崇高的召命而言。参看上文诗篇 22:24（23）、111:5。

<span class="ax-anchor" id="psalms-115-12"></span><span class="ax-vnum">12.</span> *耶和华已记念*我们；*他必赐福，他必赐福与以色列家；他必赐福与亚伦家。*这劝人倚靠神的话，并不是说他至今尚未行过什么。他已经开始赐福与我们，借此显明他满有恩典地记念我们；而且他还要继续赐福与我们；这一层意思，借着动词的重复，表达得朴素而优美，通行译本却多余地补上了*我们*，反把这效果破坏了。

<span class="ax-anchor" id="psalms-115-13"></span><span class="ax-vnum">13.</span> *他必赐福与敬畏耶和华的人，连小带大。* 不必把*大的*解作祭司，把*小的*解作平民。更自然的理解，是把这看作希伯来文一种常见惯用语的例子：将*小*与*大*并举，意即*全体*，正如*不好也不坏*的说法意指既非此亦非彼，*即一无所有。* 参列王纪下 18:24，耶利米书 16:6，启示录 13:16，19:6。

<span class="ax-anchor" id="psalms-115-14"></span><span class="ax-vnum">14.</span> *愿耶和华加增你们，加增你们和你们的子孙！* 这话暗示百姓先前曾有所减少，正如巴比伦被掳之时实际发生的那样。此动词在这里和创世记 30:24 中的祈愿语气，由申命记 1:11、撒母耳记下 24:3 可以看得分明。希伯来文的介词严格说来意为「*在*你们之上」，所传达的累加之意要强烈得多。参看前面诗篇 71:14 的注释，那里有同一结构的一例。

<span class="ax-anchor" id="psalms-115-15"></span><span class="ax-vnum">15.</span> *你们蒙耶和华赐福，他是造天地的主。*你们就是古时在你们先祖亚伯拉罕身上蒙福的那民，至高神的祭司麦基洗德曾说：「愿至高的神、天地的主赐福与亚伯兰」，创世记 14:19。*蒙耶和华，*字面作*归与耶和华，*即作他施福的对象。或者这希伯来文介词，如在其他许多处一样，可简单地相当于我们所说的*藉着。*此处提及神创造者的身分，是要表明他既有赐福与他百姓的心意，也同样有赐福的能力。

<span class="ax-anchor" id="psalms-115-16"></span><span class="ax-vnum">16.</span> *诸天*（是）*耶和华的诸天，而地他已赐给人的众子。*本节提出神要使他们增多的另一个理由，即：他虽为自己留下了天，却定意要地被人充满、被人占据；因此在起初向人类所发的原初祝福中，以及洪水之后重申此福时（创世记 1:28, 9:1），增多的命令总与充满全地的命令相连。既然神的旨意不是要人类减少以至归于无有，那么对于他自己的子民，他就更不会有这样的意图了。首句的措辞形式颇不寻常。英文圣经所取的结构*（天，就是诸天，都属乎主）*全无根据，其中单复数的分别（天、诸天）与那强调性的*就是*，都是译者补加的。希伯来文一词两处皆为复数，而且实际上也只用复数形式。

<span class="ax-anchor" id="psalms-115-17"></span><span class="ax-vnum">17.</span> （乃是）*不是死人*（才）*要赞美耶和华，也不是一切*（那些）*下到静默中的人。*这可视为期待神保护的又一理由。神从地上的列国中拣选了一族子民来赞美他，不是在死时而是在活着时，不是在坟墓的静默中而是在今生用他们的声音赞美。如此理解，本节对于脱离身体之灵魂的职事，或将来之境中灵魂与身体的职事，并无所教导。此处（或许还有其他类似的经文）所断言的，不过是说蒙拣选之民作为选民的颂赞，必限于今生。参看上文诗篇 6:6（5）、30:10（9）、88:11-13（10-12）的注释，并比较以赛亚书 38:18。*静默，*是对坟墓或不可见之境的诗意描写，如诗篇 94:17。

<span class="ax-anchor" id="psalms-115-18"></span><span class="ax-vnum">18.</span> *而*（因此）我们*要从今时直到永远称颂雅。哈利路亚！*既然行这事的不是死人，而我们仍蒙存活，就让我们不负所蒙的呼召，不负我们存在的终极目的。从今世的赞美不着痕迹地过渡到永远的赞美，是再自然不过的。这句*哈利路亚*回指第 17 节的*赞美雅*（yehallelujah）一语。仿佛他说：死人所不能作的，让我们来作，高呼哈利路亚！
