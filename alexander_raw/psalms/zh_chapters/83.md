<span class="ax-vnum">1.</span> *一首歌。一篇诗。亚萨作。*在通用的称谓（mizmôr，诗）之前，这里又冠以一个更具体的称谓（shîr，歌），标明此篇为颂赞或凯旋之歌。同样的组合见于上文诗篇 48 篇的题注；正如我们在那里所见，那一篇大概是因约沙法战胜摩押人、亚扪人及其同盟而作的，事见历代志下 20 章。这与亨斯滕伯格（Hengstenberg）有力主张的假说十分吻合，即本篇所关涉的乃是同一事件：第 47 篇大概是在战场上所唱，第 48 篇是在凯旋回到耶路撒冷之后所唱，而第 83 篇则是在满怀把握地预期得胜之时所作。与这段历史相合之处，将在逐节的解说中一一指出。全篇先是求神相助的泛求，第 2（1）节，继而描述犹大的仇敌如何强暴、诡诈、存心毁灭、结党广布，第 3-9（2-8）节，然后恳切祈求神在从前类似危急中所行的作为再度重演，第 10-15（9-14）节，其目的是在那些不可调和的仇敌被毁灭之事上彰显他的荣耀，第 16-19（15-18）节。按上文所述关于历史情境的看法，题注中的*亚萨*必定是指那位古时先见的某位后裔，正如在前面数篇中似乎也是如此。如今恰有一个奇特的巧合：在那段历史中（历代志下 20:14），正特别提到这样一位后裔雅哈悉，耶和华的灵在会众中临到他，催动他在那一系列预备性的举动中居于领导地位，而这些举动终致犹大得胜（*同上，*第 15-18 节）。可比较关于可拉子孙为诗篇 48 篇作者的类似巧合，见第 213 页。

<span class="ax-anchor" id="psalms-83-1"></span><span class="ax-vnum">2 <span class="ax-veng">(1).</span></span> *神啊，求你不要缄默，不要闭口，也不要安静，大能者*（啊）！这是一个概括性的引言式祈求，求神不要仍旧无所作为、漠视那环绕他自己子民的危险。首句中那特殊的表达方式，*愿你那里没有*（有）*缄默，*为以赛亚所仿用（以赛亚书 62:6, 7）。其次的一语是前面屡次出现过的。参诗篇 28:1；35:22；39:13（12）。第三项祈求，*不要安静*或*宁息，不要歇息，*其与行动的关系，正如前两项与言语或说话的关系一样。此处使用这一神的名称（אֵל，大能者）含有诉诸神全能的意味，以此作为他出手干预的理由。既然他是全能者，当他的子民身处危险、他的仇敌看似得胜之时，他为何还要缄默无为呢？

<span class="ax-anchor" id="psalms-83-2"></span><span class="ax-vnum">3 <span class="ax-veng">(2).</span></span> *因为看哪，你的仇敌喧嚷，恨你的人抬起头来。* 前一节的总括祈求，如今借着对危险的描述得了加强，先从攻击者的凶暴与自恃说起。这 *看哪* 相当于 *你看那里，* 把这段话变成对眼前景象的描绘。以色列的仇敌照例与神的仇敌视为一体，以此作为他当显现施行毁灭的理由。第一个动词意为发出喧声，在诗篇 46:4（3）中用于海的怒吼，在诗篇 59:7（6）中用于狗的嗥叫，在诗篇 39:7（6）、42:6, 12（5, 11）中则用于内心的骚动。*抬起头来，* 是自恃与得胜的自然表征。可参照士师记 8:28 中对被征服之民的描写。

<span class="ax-anchor" id="psalms-83-3"></span><span class="ax-vnum">4 <span class="ax-veng">(3).</span></span> *他们向你的百姓设下狡诈的计谋，彼此商议攻击你所隐藏的人。*在暴虐与骄横这些性质之外，此处的描写又加上了阴险的奸诈。第一个分句的结构是：*他们使*（他们的）*谋算狡诈。*关于这个希伯来名词的含义，见前面诗篇 25:14、55:15（14）、64:3（2）处的解说。*你所隐藏的人，*即你为了妥善看顾而藏起来的那些人，是你施怜悯保护的对象。见前面诗篇 27:5、31:21（20）处的解说。

<span class="ax-anchor" id="psalms-83-4"></span><span class="ax-vnum">5 <span class="ax-veng">(4).</span></span> *他们说，来吧，让我们将他们剪除，使之不再是*（作）*一国，叫以色列的名不再被记念。*他们不单是喧嚣、自负而诡诈，更是怀着恶意、决意要毁灭。第一个动词用过去时，表明这同谋已经结成。*从一国中*这一惯用语，以赛亚不止一次使用（以赛亚书 7:8，23:1）。末句表达彻底铲除之意的说法，取自对亚玛力的咒诅，出埃及记 17:14。*以色列*作为选民之名，在大分裂之后，犹大便有权承用，甚至在那敌对的王国尚存之时也是如此。

<span class="ax-anchor" id="psalms-83-5"></span><span class="ax-vnum">6 <span class="ax-veng">(5).</span></span> *因为他们诚心一同商议；敌挡你，他们立定盟约。* 译作*诚心*的那个词，其实是个名词，意为*心，*但此处用来修饰动词，添上*以心、ex animo（发自内心）、*即诚心、衷心的意思。历代志上 12:38 中译作*一心*的短语则全然不同。末一动词的含义，见上文诗篇 50:5 的注释。过去时与将来时表明这同盟既已结成，又仍在延续。

<span class="ax-anchor" id="psalms-83-6"></span><span class="ax-vnum">7 <span class="ax-veng">(6).</span></span> *以东和以实玛利人的帐棚，摩押和夏甲人。*此处用*帐棚*一词，并不必然意味着游牧迁徙的生活方式，因为它可以指军营的帐幕，或作居所的比喻。参看前面诗篇 78:67 的注释，并比较士师记 7:8、列王纪上 12:16。以实玛利人居住在阿拉伯旷野的一部分（创世记 25:18），夏甲人（Hagarenes 或 Hagarites）亦然；这族人在扫罗作王的时候，被西缅支派逐出他们的地土。见历代志上 5:10, 19-22，并比较历代志上 11:38, 27:31。

<span class="ax-anchor" id="psalms-83-7"></span><span class="ax-vnum">8 <span class="ax-veng">(7).</span></span> *迦巴勒和亚扪与亚玛力，非利士同推罗的居民。* 迦巴勒大概是以东的一部分。亚扪与亚玛力的并列方式，与士师记 3:13 相同，正如非利士与推罗并列于以西结书 38:13，而非利士、推罗与以东并列于阿摩司书 1:6-10。

<span class="ax-anchor" id="psalms-83-8"></span><span class="ax-vnum">9 <span class="ax-veng">(8).</span></span> *亚述也与他们联合。*（这些）*作了罗得子孙的膀臂。细拉。*亚述列在最后，因它最为遥远，对这场联合攻击犹大的行动也最无关切。显然它那时尚未取代巴比伦，成为西亚的霸主。末句所指并非单指亚述——复数动词已足以表明这一点——而是指除罗得子孙以外的一切同盟者；罗得子孙，*即*摩押与亚扪（创世记 19:37, 38），在此被提及，乃是作为这次出征的发起者与主导者。

<span class="ax-anchor" id="psalms-83-9"></span><span class="ax-vnum">10 <span class="ax-veng">(9).</span></span> *待他们*如（你从前待）*米甸，如*（待）*西西拉，如*（待）*耶宾，在基顺的谷中。*这是祈求神施行如以色列古时所经历的那般拯救。此处所选的例证，是基甸胜过米甸人（士师记 7-8 章），以及底波拉与巴拉胜过耶宾和西西拉（士师记 4-5 章）。前一件事与本篇诗所要纪念的事件之间，有一点显著的相似：两次仇敌都是自相残杀而灭亡（士师记 7:22，历代志下 20:23）。可比较以赛亚书 9:4（3）、哈巴谷书 3:7 中对同一事件的提及。基顺在底波拉与巴拉得胜的记载中屡次提到（士师记 4:7, 13，5:21）。

<span class="ax-anchor" id="psalms-83-10"></span><span class="ax-vnum">11 <span class="ax-veng">(10).</span></span> *他们在隐多珥被灭，他们成了地上的粪土。*此处所指的是前一节所提两场战役中的第二场。隐多珥在历史记载中并未明言，但已知其地近于他泊，而他泊在那里屡次被提及（士师记 4:6, 12, 14）。末一分句可借近代某些战场异常肥沃的情形得着说明，尤以滑铁卢为著。参列王纪下 9:37，耶利米书 9:21（22）。

<span class="ax-anchor" id="psalms-83-11"></span><span class="ax-vnum">12 <span class="ax-veng">(11).</span></span> *使他们，*（就是）*他们的贵胄，像俄立和西伊伯；使他们一切的王子都像西巴和撒慕拿。*他所求的不仅是仇敌的群众遭遇米甸众人一样的结局，更是他们的首领要像米甸的诸王与首领被基甸所灭那样被彻底剪除，见士师记 7:25，8:5-21。这一连串耳熟能详的名字的列举，大大加强了对这民族历史记忆的诉求。首词的本义是*安放*或*安置他们，即*使他们落在同样的境地中。

<!-- PAGE 362 -->
<span class="ax-anchor" id="psalms-83-12"></span><span class="ax-vnum">13 <span class="ax-veng">(12).</span></span> *他们曾说，我们要为自己得神的居所*（或作牧场）*为业。*这句所指的不是先前的仇敌，而是以色列当前的仇敌，并说明了他们为何必遭与其前人相同的结局。译作*居所*的那个词具有双重含义，因此格外适合用来描述圣地——神在那里与他的百姓同住，又在那里如牧人一般牧养他们。参看上文诗篇 23:3，65:13（12），74:20 的注释。

<span class="ax-anchor" id="psalms-83-13"></span><span class="ax-vnum">14 <span class="ax-veng">(13).</span></span> *我的神啊，使他们像风前旋转的糠秕。* Make them（使他们），字面作*置他们*，与第 11 节相同。*像那旋转的糠秕，*字面作*像那旋风*（或*旋转之物），像那糠秕。* 参看前面诗篇 77:19（18）的注释，并比较以赛亚书 17:13。

<span class="ax-anchor" id="psalms-83-14"></span><span class="ax-vnum">15 <span class="ax-veng">(14).</span></span> *如火焚烧树林，如火焰点燃群山。* 原文的结构是*如火*（它）*焚烧，如火焰*（它）*点燃。* 这里的*群山*，当理解为覆盖其上或生长其上之物。

<span class="ax-anchor" id="psalms-83-15"></span><span class="ax-vnum">16 <span class="ax-veng">(15).</span></span> *你就必以你的暴风追赶他们，用你的狂飙惊吓他们。* 没有必要把这些将来时译作命令语气。这是希伯来文中极常见的一类情形，在本书中尤甚，即直接祈求的语式与满怀确信的期待交替出现。

<span class="ax-anchor" id="psalms-83-16"></span><span class="ax-vnum">17 <span class="ax-veng">(16).</span></span> *求你使他们满面羞辱，他们（人）*就必*寻求你的名，耶和华！*

抱歉，重作：

*使他们的脸满了羞辱，*（人们）*就必寻求你的名，耶和华！*第一分句可比较诗篇 69:8（7）、89:46（45）。有人把末一分句也指向仇敌；但他们的覆灭在下一节才被预期，而*寻求*神*的名*也很难用来表达一种被迫的屈服。译作*羞辱*的那个词语气极重，意为轻蔑、耻辱或不名誉。

<span class="ax-anchor" id="psalms-83-17"></span><span class="ax-vnum">18 <span class="ax-veng">(17).</span></span> *他们必蒙羞、惊惶直到永远，且要抱愧灭亡。*这里无疑含有祷告或愿望的表达，但同时也含有一种强烈而笃定的预期。因此，若弃去将来时的形式，既削弱了文意，又破坏了这语言的一个特征。第一分句可比较诗篇 6:11（10）。译作*惊惶*的那个词，与第 16（15）节中译作*惊骇*的是同一个词。参看前面诗篇 2:5、6:4（3）、48:6（5）的注释。

<span class="ax-anchor" id="psalms-83-18"></span><span class="ax-vnum">19 <span class="ax-veng">(18).</span></span> *并且*（人）*要知道，你，名为*（是）*耶和华的，*（乃）*独自是全地之上的至高者。* 此处如同第 17（16）节，所指的并非对那些被毁灭之人心中所生的印象，而是对一般旁观其结局的众人而言。参看上文诗篇 59:14（13）的注释，并比较撒母耳记上 17:46、列王纪下 19:19、以赛亚书 37:16, 20。原文的结构颇为独特：「他们要知道，你——你的名耶和华——惟独你——是全地之上的至高者。」那单纯的代词*你*，藉着*你的名耶和华，即*这几个词的添加而得着解释与扩充：你这位已将自己启示为自有永有的永恒之神、并启示为以色列立约之神的。
