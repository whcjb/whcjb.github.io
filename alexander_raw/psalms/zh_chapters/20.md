一篇供古时教会在战时使用的祷告。教会向她有形的元首致辞，愿他得着神的扶助与成功，第 2-6（1-5）节；并表达一种坚定的确信，相信神必应允她的祈求，第 7-9（6-8）节；末了又把这祈求重述并总括起来，第 10（9）节。

没有任何迹象表明本篇是为某一特定场合而作；其内容完全适用于一切这样的情形：蒙拣选的子民在其神权元首的带领下，与神和以色列的仇敌争战。

*交与伶长。*为他之用而作，并交付他演奏。与其余各处一样，这题注表明本篇的写作不是为抒发一己的情感，而是要作神的子民全体敬虔情怀的载体。——*大卫的一篇诗。*这一说法的确实性不但毫无实据可以反驳，而且从全篇的格调与笔法，以及它与下一篇诗的紧密关联，都得着印证。参见下文诗篇 21:1 的论述。

<span class="ax-anchor" id="psalms-20-1"></span><span class="ax-vnum">2 <span class="ax-veng">(1).</span></span> *愿耶和华在患难的日子应允你！愿雅各之神的名高举你！* 神的名，就是他在作为中对自己本性的启示。「愿那些在蒙拣选之民的经历中屡次显明的神圣属性，施行出来保护你。」参上文，诗篇 5:12 (11)。——*雅各的神，*即那位名叫雅各的族长的神，也是他后裔的神。见马太福音 22:32。——*高举你，*把你举起，脱离危险所能及之处。参上文，诗篇 9:10 (9)，18:3, 49 (2, 48)。

<span class="ax-anchor" id="psalms-20-2"></span><span class="ax-vnum">3 <span class="ax-veng">(2).</span></span> （愿耶和华）*从*（他的）*圣所赐你帮助，从锡安扶持你。*提到锡安与圣所，表明此处是向耶和华作为他百姓的王呼求，作为王，他不但有能力，且因约而有义务施以援助。参下文第 10（9）节。*扶持你，*托住你，与诗篇 18:36（35）所用的是同一个动词。两个动词也都可译为单纯的将来时，*必赐、必扶持；*但见下文。

<span class="ax-anchor" id="psalms-20-3"></span><span class="ax-vnum">4 <span class="ax-veng">(3).</span></span> （愿耶和华）*记念你一切的供物，悦纳你的燔祭。细拉。* 第一分句中*记念*一词，似乎暗指祭祀礼仪中所谓的*记念*（אַזְכָּרָה），即素祭中焚烧在坛上的那一部分所得之名。参 利未记 2:2, 6:8（15）。——译作*供物*的那个词虽本是通称，却特用以指律法中的素祭；而译作*燔祭*的那个词，则是主要动物祭牲的专门名称。二者并列，是要概括这两类祭献。参 诗篇 40:7（6）、耶利米书 17:26、但以理书 9:27。——译作*悦纳*的那个动词，在别处意为使之肥美（诗篇 23:5），或除去坛上的灰（出埃及记 27:3、民数记 4:13）。有些人在此取化为灰烬或焚尽之义，另一些人则取宣称其肥美、因而合乎献祭之义。无论取哪一义，都含有蒙悦纳的意思。原文中此动词的祈愿形式，似乎印证了前面那些将来时所已采取的解释。有人从本节推断——这推断不无可能——全诗原是专为以色列人出征或临阵之前所献的祭而作的。（参 撒母耳记上 13:9, 10）。有人在此之上又加一设想，以为本节中的*细拉*，标示诗篇咏唱中的停顿，而祭正是在这停顿之际实际献上的。参见上文 诗篇 3:8（2）的注释。

<span class="ax-anchor" id="psalms-20-4"></span><span class="ax-vnum">5 <span class="ax-veng">(4).</span></span> （愿他）*照你的心赐给你，并使你一切的筹算*（或*计划）得以成就。* 这并非泛泛祈求成功，乃是为诗篇所要用的那一特定场合祈求成功。——*你的心，*即你的所愿。*你的筹算，*即你所定下、并奉神的名承担去施行、为要保护或拯救他子民的那个计划。

<span class="ax-anchor" id="psalms-20-5"></span><span class="ax-vnum">6 <span class="ax-veng">(5).</span></span> *愿我们因你的拯救欢呼，并奉我们神的名展开旌旗！愿耶和华成就你一切所求的！* *你的拯救*一语，可指你所成就的拯救，亦可指你所经历的拯救。极有可能二意兼含。*奉我们神的名，*因此这并非一场纯属世俗的凯旋。第二个动词（נִדְגֹּל）似与一个名词（דֶּגֶל）相关联，摩西用该名词指以色列全军四大营在旷野行进时所随从的旌旗（民数记 1:52；2:2, 3, 10, 18, 25；10:14）。因此有「愿我们竖起（或展开）旌旗」这一推测性的译法。但同一动词的分词形式，在其仅有的另一处出现（雅歌 5:10）中，似乎意为*显赫*或*尊高，*故另有人随从七十士译本与武加大译本译作，*愿我们被高举*或*被尊大。*——末句是一个总括性的祈求，其意与上文第 5 节（4）相当，所包含的不仅是先前已明言的事项，更包括这位神治君王按照神的旨意所可能愿望或图谋的一切，无论其全体随从是否尽知。此句回到本篇开首的主题，从而结束了诗篇的前半部分，而全篇末了又再以此主题作结。参看下文第 10 节（9）的注释。

<span class="ax-anchor" id="psalms-20-6"></span><span class="ax-vnum">7 <span class="ax-veng">(6).</span></span> *现在我知道耶和华已拯救他的受膏者*——*他必从他圣洁的诸天应允他*——*用他右手拯救的大能。*前文所求的，这里说已经蒙允。因此有人设想，其间必须假定有一场战事或别的决定性事件发生。但这样的看法不仅在如此短小的一篇作品中极不可能、且显得牵强，而且随即又回到将来时的形式*他必应允，*也不容如此解释。远为自然的解法是：本节表达一种突然生出的确信或把握，深知前面的祈求必蒙应允。仿佛他说：「这就是我所求的，而我知道耶和华已经应允，所以按他的定旨、并在信心的眼中，他的受膏者已然稳妥，已然得胜。」转为第一人称单数并不表示说话者换了人，不过是把下文放在每一位个别信徒口中，或放在被视为一个理想人格的全体会众口中罢了。

这句的第二个成分最好解作插入语，第三个成分则直接与第一个相连，如上面的译文所示。本节中有两处常见的希伯来惯用语，其中一处极为鲜明。译作*他圣洁的诸天*的那个短语，似可解为*他圣洁之诸天*；但真正的结构是*他的圣洁之诸天，即*那位圣者所居、他的帮助必从那里而出的诸天。参看前面诗篇 2:6 与 11:4 的解说。此处提及圣洁这一属性，是要进一步彰显本篇所论之争战与得胜那神圣而属神的性质。上面所说的希伯来惯用语，另一例便是*他右手的拯救之力*，按字面当译作*他右手之拯救的诸力*。复数的*诸力*或为加强语气，或指此处所述之能力的种种施展。右手之义与诗篇 18:36（35）相同。此处与诗篇 18:51（50）一样，*他的弥赛亚，即受膏者*，包括一切真正神权政体君王的整个世系，也不排除那位他们所预表的君王——君王的世系在他身上既告终结，又得以永存。

<span class="ax-anchor" id="psalms-20-7"></span><span class="ax-vnum">8 <span class="ax-veng">(7).</span></span> *这些靠车辆，那些靠马匹，我们却要靠耶和华我们神的名，夸耀。*所有的宾语都由同一个介词与同一个动词相连，即句末的那个动词。为了保留这个介词——否则就须变换介词，从而使句子的结构晦暗不明——这里用了与介词*在……里*连用的动词*夸耀，*以代替该动词的严格意义，*我们要使之被记念，即*提说或称颂。参出埃及记 23:13，阿摩司书 6:10，以赛亚书 48:1，63:7。英文诸译本在前一分句中插入动词*信靠，*全无根据。*这些和这些*是希伯来语表示*一些人和另一些人*的惯用语。参出埃及记 14:20、以赛亚书 6:3 中的*这个对那个。*——此处所用的动词，或许是有意呼应上文第 4（3）节中的同源形式而选定的。「正如神记念了你的供物，我们也要使他的名被记念。」——*我们的神*再次带有强调意味，意义深远，表明全篇诗都关乎神与他的子民之间的约的关系，而这子民是由他们神权政体的君王所代表的。本节中的对比可参撒母耳记上 17:45，以赛亚书 31:3，诗篇 33:16, 17。

<span class="ax-anchor" id="psalms-20-8"></span><span class="ax-vnum">9 <span class="ax-veng">(8).</span></span> *他们屈身仆倒，我们却兴起站直。* 这里与第 7（6）节一样，过去时表达事件的确定性，或者更确切地说，表达人期待此事时所怀的确信。开头那个着重的*他们*指的是神子民的仇敌与欺压者。*我们已兴起*似乎暗示先前曾被打倒、被制伏。——最后那个动词仅在此处以这一形式出现，其形式本是反身的，可解作：*我们把自己挺直了起来。*

<span class="ax-anchor" id="psalms-20-9"></span><span class="ax-vnum">10 <span class="ax-veng">(9).</span></span> *耶和华啊，拯救！愿王在我们呼求的日子应允我们，*或更贴近原文作，*在我们呼求之日。*七十士译本与武加大译本把*王*归入前半句：「耶和华啊，拯救王」（Domine salvum fac regem，主啊，求你拯救王）。但这样做不仅违背马所拉重音符号——这些符号虽非终极的约束，却作为传统权威理当受到尊重——而且把后半句的动词与它的主语割开了，以致刚才所提的两个古译本都不得不把第三人称改作第二人称（应允我们）。再者，前半句没有*王*字反比有它更有力、更铿锵。再没有比这简短的祈求*耶和华啊，拯救！*更含蓄丰满、更响亮的了。其所求的对象，自然要从第 7 (6) 节、并从全篇的语气中补出。诚然，另一种读法可使本节的*王*与第 7 (6) 节的*受膏者*指同一人。但把所期待的福分归于以色列真正的王——大卫和跟随他的人不过是他的代表——非但毫无不妥，反倒极有力量、极为优美。参申命记 33:5，诗篇 48:3 (2)，马太福音 5:35。——若把末一个动词取作正式的将来时（王必应允我们），本篇便可以一个应许作结，或更确切地说，以对神赐福的笃定期待作结。然而多数释经者宁愿把它看作祈愿语气，使本篇如起首一般，以一句热切的渴求收束。
