一位受苦者描述自己的景况，第 2-5 节（1-4 节）。他表明自己是为神的缘故受苦，第 6-13 节（5-12 节）。因此他祈求得蒙拯救，第 14-19 节（13-18 节）。他再次述说自己的苦难，但更明确地指出其根由，即仇敌的恶毒，第 20-22 节（19-21 节）。因此他祈求他们被剪除，第 23-29 节（22-28 节）。他预见自己的祷告必蒙垂听，且必在他的弟兄身上产生最美好的果效，第 30-34 节（29-33 节）。不仅如此，他更期望看见同样的怜悯施于教会，即蒙拣选的子民，第 35-37 节（34-36 节）。

<!-- PAGE 300 -->
<span class="ax-vnum">1.</span> *交与伶长。调用百合花。大卫的诗。* 这*百合花*大概是指所经历的、或所盼望的那些令人欢欣的安慰与拯救。参看上文诗篇 45:1、60:1 的注释。本篇的主题是一位理想中的人物，代表义人受苦的全类。各样特征唯独汇于一身的，是基督。然而他并非本篇独一的、甚至也不是直接的主题，这从第 6（5）节的认罪可以看得明白。在新约中被引用于他身上最为明确的诗篇，除第二十二篇外，再无别篇。

<span class="ax-anchor" id="psalms-69-1"></span><span class="ax-vnum">2 <span class="ax-veng">(1).</span></span> *求你拯救我，神啊，因为众水已经进来，直到我的性命，即*以致危及我的生命。参耶利米书 4:10、约拿书 2:6。此处表极度困苦的比喻与诗篇 40:3（2）中的相同。

<span class="ax-anchor" id="psalms-69-2"></span><span class="ax-vnum">3 <span class="ax-veng">(2).</span></span> *我陷在深渊的淤泥中*（或*深处）*（那里）*没有立足之地；我进入水的深处，大水漫过了我。*这里的意象是人沉没在海底或河底。*深渊的淤泥*不单是深的淤泥，乃是在深处所见的淤泥。

<span class="ax-anchor" id="psalms-69-3"></span><span class="ax-vnum">4 <span class="ax-veng">(3).</span></span> *我因呼求而疲乏；我的喉咙焦干；我的眼睛失明，等候我的神。* 第一个分句的字面意义是，*我在呼求中疲乏了，即*在呼吁神帮助这件事上已经疲乏。参看上文诗篇 6:7（6）。*焦干，*因过度用声而干裂，或按这希伯来动词本有的更强之义，作*发炎。*他的眼睛被描绘为因不断仰望神而耗尽、衰残。参看下文诗篇 119:82，并比较耶利米哀歌 4:17。分词*等候*并不像在英文里看来那样与*眼睛*相配，乃是与眼睛所属的那个人相配，可以作独立结构来解，*我等候*（me expectante）*，即*当我等候之时。

<span class="ax-anchor" id="psalms-69-4"></span><span class="ax-vnum">5 <span class="ax-veng">(4).</span></span> *比我头发还多的* （是）*那些无故恨我的人；强盛的是那些毁灭我的，是我虚谎的仇敌；我未曾抢夺的，竟要偿还。* 第一分句可参诗篇 40:13（12）；第二分句参诗篇 35:9，38:20（19）；第三分句参诗篇 35:11，撒母耳记下 16:8。*虚谎的仇敌，*字面作*虚谎之仇敌，*其义或泛指奸诈不忠，或更确切地指以毁谤与虚谎为手段以成就其恶念的人。*竟*或作「后来」，乃就他所自陈的先前无辜而言。他起初虽丝毫未取，后来却必须偿还。

<span class="ax-anchor" id="psalms-69-5"></span><span class="ax-vnum">6 <span class="ax-veng">(5).</span></span> *神啊，我的愚昧你是知道的（或作：至于我的愚昧，你是知道的），我的罪愆向你未曾隐藏。*他并不否认自己在神眼前的罪咎，却仍然祈求脱离灭亡。参看前面诗篇 6:2 (1)、38:4-6 (3-5)、40:13 (12)、41:15 (14) 的解释。这好像是说：「不错，我是个罪人，否认也是枉然；神啊，你是知道的；然而……」

<span class="ax-anchor" id="psalms-69-6"></span><span class="ax-vnum">7 <span class="ax-veng">(6).</span></span> *愿等候你的人不要在我身上羞愧。主，耶和华，万军的；愿寻求你的人不要在我身上受辱，以色列的神！*他祈求诗篇 25:3 所立的原则不致落空。*在我身上，*不单是*藉着我，*或*因着我，*而是在*我身上，*即作为这一整类人的代表。*羞愧，*指所存的指望落空、受挫。*等候你，*等候你的显现、等候你应许的成就。*寻求你，即*寻求认识你，并得享你的恩眷。

<!-- PAGE 301 -->
<span class="ax-anchor" id="psalms-69-7"></span><span class="ax-vnum">8 <span class="ax-veng">(7).</span></span> *因为为你*（或*你的缘故）我担当了辱骂，羞耻遮盖了我的脸。* 神一切的仆人都必有分于他所受的羞辱，因为他是他们中的一员，并且正是作为他们中的一员而受苦。首句可参 诗篇 44:23（22）、耶利米书 15:15，末句可参 诗篇 44:16（15）。

<span class="ax-anchor" id="psalms-69-8"></span><span class="ax-vnum">9 <span class="ax-veng">(8).</span></span> *我在我弟兄中成了外人，在我母亲的众子中成了外邦人。*前一分句的字面意思是，*我已被疏远于*（或*就……而言）我的弟兄们。*此处或许暗指耶西的其余众子对大卫出于嫉妒的对待。参撒母耳记上 17:28。至亲好友的丧失或疏离，在诗篇 27:10 中被说成是最严酷的试炼之一。

<span class="ax-anchor" id="psalms-69-9"></span><span class="ax-vnum">10 <span class="ax-veng">(9).</span></span> *因为你殿的热心，*即对圣所之荣耀的切切维护——圣所乃是真宗教可见的中心——*已经把我吞灭了，*这是指情感的极度炽烈；而由于这热心，*辱骂你之人的辱骂都落在我身上。*这样的辱骂者在大卫的时代确实存在，这可从撒母耳记下 12:14 得知。本节的前半句在约翰福音 2:17 被应用于基督，后半句则见于罗马书 15:3。

<span class="ax-anchor" id="psalms-69-10"></span><span class="ax-vnum">11 <span class="ax-veng">(10).</span></span> *我哭泣*（耗尽）*我的魂，*或作：我哭得形销骨立，*在禁食中，而那*（连那也）*成了我所受的辱骂，*连那也成了人恶毒讥笑我的把柄。哭泣与禁食本是相伴而生的两件事，这在大卫实际的经历中并不陌生，从撒母耳记下 12:16, 21, 22 可以看出。前一分句同样容许这样的解法：*而我哭泣，我的魂*（是）*在禁食中，即*禁食了。但这一解法虽与希伯来人的惯用语相合——他们把禁食说成是刻苦己魂（见上文诗篇 35:13 的注释）——却不及上文所给的第一种解法那样自然而有力；那一解法见于巴格斯特（Bagster）1830 年于伦敦出版的一部佚名诗篇译本。

<span class="ax-anchor" id="psalms-69-11"></span><span class="ax-vnum">12 <span class="ax-veng">(11).</span></span> *我又使，*穿上（作）*我的衣服，麻布，于是我在他们中间，成了一句比方，*一句俗语、一句笑谈，或说*成了他们的笑谈。*参看上文，诗篇 35:13 与 44:15（14）的注释。上下文使人有理由认为，本节及前一节所描写的哀恸，并非单指他自己所受的苦难，也是为着全民的罪。

<span class="ax-anchor" id="psalms-69-12"></span><span class="ax-vnum">13 <span class="ax-veng">(12).</span></span> *他们议论我，*心中谋算与我为敌，*那些坐在城门口的人；*（他们编造）*歌曲，*讥讽或讽刺之词，*那些喝浓酒的人。*这里所说的*城门*，是指城邑的门口，东方的审判与集市都在那里举行。因此有人以为其意是说，即便在办理正事之处，他们也以我为笑柄，恣意逞其恶毒的戏谑。但更自然的解法，是把坐在城门口的人单单理解为出入公众场所之人。参看前面诗篇 55:12（11 节）的注释，并参约书亚记 20:4，路得记 4:1, 2，耶利米哀歌 5:14。

<span class="ax-anchor" id="psalms-69-13"></span><span class="ax-vnum">14 <span class="ax-veng">(13).</span></span> *而我，*至于我，与这些讥诮者相对，*我的祷告*（是）*向你，*尽管他们嘲笑，我仍向你祈求，*耶和华啊；*（愿有或愿它来到）*悦纳的时候，照你丰盛的慈爱；应允我，*垂允我的祈求，*按你拯救的信实，*或作你那拯救的真实，即施行那信实，凡信靠它的人必因此得救。参 以赛亚书 49:8, 61:2。

<span class="ax-anchor" id="psalms-69-14"></span><span class="ax-vnum">15 <span class="ax-veng">(14).</span></span> *求你救我脱离淤泥，不容我下沉；求我得蒙拯救，脱离恨我的人，脱离深水。*他在此回到第 2 (1) 节的比喻，那里把深重的苦难描写为沉没于水中、陷入淤泥。这比喻的含义，在本节末句中藉着加上一句字面的说法而得着解明。

<span class="ax-anchor" id="psalms-69-15"></span><span class="ax-vnum">16 <span class="ax-veng">(15).</span></span> *求洪水不要漫过我，深渊不要吞灭我，井*（或坑）*不要在我以上合口。* 在恳切的祈求中，他从海或河的比喻转到井或池的比喻，二者共有的意念乃是深水。

<!-- PAGE 302 -->
<span class="ax-anchor" id="psalms-69-16"></span><span class="ax-vnum">17 <span class="ax-veng">(16).</span></span> *应允我，*垂听我的祈求，*耶和华；因你的慈爱为美善*（或照我们的说法，为大）*；照你怜悯的众多，转向我，*或说转向我这边，意思是他的面先前是转开的。参上文，诗篇 4:7（6），13:2（1）。

<span class="ax-anchor" id="psalms-69-17"></span><span class="ax-vnum">18 <span class="ax-veng">(17).</span></span> *求你不要向你的仆人掩面，因为*（有）*患难归于我，*我正在患难中，*求你速速应允我，即*不迟延地将我所求的赐给我，

<span class="ax-anchor" id="psalms-69-18"></span><span class="ax-vnum">19 <span class="ax-veng">(18).</span></span> *亲近我的魂，*即亲近我这魂、这性命正受威胁的人，*赎它，*救它脱离毁灭；*因为*（或*为了）我仇敌的缘故，救赎我，*免得他们因我的倾覆而夸胜。参看上文诗篇 13:5 (4) 的注释；首句可与诗篇 22:2 (1) 比较。

<span class="ax-anchor" id="psalms-69-19"></span><span class="ax-vnum">20 <span class="ax-veng">(19).</span></span> *你知道，*字面作*你已知道，*视为久已存在之事，*我的凌辱，*即我所承受的藐视，*以及我的羞愧和我的耻辱；在你面前，*在你眼中、为你所知的，（乃是）*我一切的敌人，*即逼迫者或欺压者，不单指他们的人身，也不单指他们一般的行径，而是指他们待我的方式。深信神无所不知，其中便含有一种确信：他必向双方施行公义。参看前面诗篇 1:6 的注释。

<span class="ax-anchor" id="psalms-69-20"></span><span class="ax-vnum">21 <span class="ax-veng">(20).</span></span> *辱骂，*包括谗谤与侮慢，*伤了我的心，*这是形容极度愁苦的常用比喻，*我就病了，*心里病了、灵里病了，但不排除身体受苦的意思，这苦或为愁苦所致的结果，或为愁苦的一部分；*我指望有人怜恤，*字面是哀悼，*即*同情、慰唁，指望从我残忍的仇敌那里得着，*却没有，*或作*一个也没有，我指望有安慰人的，*即（那些）安慰（我）的人，*却寻不着*（他们）。至于我*就病了*一语，参诗篇 6:3（2）。

<span class="ax-anchor" id="psalms-69-21"></span><span class="ax-vnum">22 <span class="ax-veng">(21).</span></span> *并且，*他们非但不怜恤我，反而加重我的苦楚，因为*他们在我的食物中给了，*或作*把苦胆给我作食物，*这里用以表示极度的苦涩，*又为我的干渴，即*为解我的渴，或作*当*（我）*干渴之时，*在我渴时，*他们拿醋给我喝。*苦胆与醋在此并举，表示食物与饮料中最难以下咽的形式。我们主的受难，在神的护理安排之下，竟与本节有一极显著的吻合。罗马人惯于把掺了没药的酸酒给十字架上的囚犯，为要减轻其痛苦。在我们救主的事上也照此而行（马可福音 15:23）。此举本身并非残忍，倒是相反；然而它仍构成那整场杀害性逼迫的一部分。在罗马兵丁一面，这或许是一桩好意；但若视为不信的犹太人的行为，那就是把*苦胆和醋*递给一个已被极度痛苦所压倒的人。所以马太按他一贯的手法，把这事表明为本处经文的应验（马太福音 27:34）。他并未与前面所引马可的记载相抵触，只是提示：如此递上的酒与没药，当视为与这预言中的苦胆和醋是一回事。又为使这一吻合不致被人忽略，我们的主在断气之前说口渴，人就拿醋给他（马太福音 27:48，约翰福音 19:28）。上半节译作*食物*的那个词仅见于此处，其动词字根亦仅见于大卫的史事中（撒母耳记下 12:17，13:6, 10）。

<span class="ax-anchor" id="psalms-69-22"></span><span class="ax-vnum">23 <span class="ax-veng">(22).</span></span> *愿他们面前的筵席，*即他们吃饭、惯常在那里欢乐之处，*成为*（或*变作）网罗，*成为意料之外的危险之机，*又向那些安稳的人，*就是自以为平安的人，（愿它成为、或变作）*机槛。*末句中的第一个词是一个意为「平安」之词的复数形式，但在此处似乎与诗篇 55:21(20) 一样，用以指那些安然无事、安逸、宁静而稳妥的人。参帖撒罗尼迦前书 5:3。古译本给出的意思同样贴切，作*报应，即*作他们过犯的报偿。但这一意思虽可由动词字根（שָׁלַם）推出，并属于若干同源派生词（שִׁלֻּם、שֶׁלֶם、שִׁלֵּם），却不见于我们眼前这个词（שִׁלּוּמִים）的实际用法。英文译本中迂回曲折的结构不但牵强，而且全无必要。本节及以下各节中的咒诅之语，惟有当作怀恨的私欲之表达时才令人反感。若出于神的口，这些话不会震动任何读者的情感；若视为一位理想人物的言语，也同样不应如此——这位人物代表受苦的义人全体，尤其代表那一位：祂虽在临死时为杀害祂的人祷告（路加福音 23:34），先前却已将本段的话应用在不信的犹太人身上（马太福音 23:38），正如保罗后来所行的一样（罗马书 11:9, 10）。护理中报应的总道理，远非旧约所独有，在我们救主的许多比喻中也有清楚的教训。见马太福音 21:41，22:7，24:51。

<!-- PAGE 303 -->
<span class="ax-anchor" id="psalms-69-23"></span><span class="ax-vnum">24 <span class="ax-veng">(23).</span></span> *愿他们的眼睛昏暗，即*变暗或渐暗，*以致不见，*以至于看不见，*至于他们的腰，求你使之弯曲，*即使之软弱、偏斜，*即*瘫痪他们的力量。参见前面诗篇 66:10 (9) 的注释。首一分句大概不是指瞎眼，而或是指死时双目的昏昧，或是以黑暗为灾祸的通称之喻。

<span class="ax-anchor" id="psalms-69-24"></span><span class="ax-vnum">25 <span class="ax-veng">(24).</span></span> *将你的愤怒倾倒在他们身上，愿你忿怒的烈焰，*即你烈烈的忿怒，*追上他们，*在他们久已似乎逃脱、并仍指望逃脱之后，临到他们。

<span class="ax-anchor" id="psalms-69-25"></span><span class="ax-vnum">26 <span class="ax-veng">(25).</span></span> *愿他们的居所荒凉，在他们的帐棚里愿无人居住，*或作*愿无人居住。*所译作*居所*的那个词，其本义似乎是*围圈*，或许特指一处营地或帐棚的聚集（创世记 25:16，民数记 21:10）。英文译本在刚才所引那两处作*城堡*，以及本节旁注所作的*宫殿*，似乎全出于臆测。七十士译本在此处用了一个希腊词（ἔπαυλις），意为过夜之处，尤指牛羊群过夜的地方，由此转指农庄或乡间房舍。这一说法保留在使徒行传 1:20，那里引用了我们眼前这一节，并与诗篇 109:8 相连，应用在加略人犹大身上——并非仅仅视他为一个个人，乃是视他为犹太民族的预表与代表，因这民族对基督怀着恶毒而奸诈的敌意。这并不证明我们的主是全篇独一无二的主题——上文第 6（5）节中的认罪已经排除了这个结论；但它确实表明，祂不单是那一整类在恶敌手下无辜受苦之人中的一员，更是其中为首的一员，甚至是他们伟大的预表与代表。另参马太福音 23:38。

<span class="ax-anchor" id="psalms-69-26"></span><span class="ax-vnum">27 <span class="ax-veng">(26).</span></span> *因为*（那些）*你所击打的，他们逼迫，*从前逼迫，如今仍旧逼迫；*至于你所伤者的痛苦，他们谈论*或议论。前一分句中的代词带有强调意味：「是你，而不是人，或人至多不过是你那盲目无知的器皿。」参撒母耳记下 16:11, 12，约伯记 19:21, 22。被形容为*你所伤者*的正是同一批人，原文所用的词通常指受了致命的伤，因此常被译作*被杀的*。见以赛亚书 66:16，耶利米书 25:33。*痛苦*之前的介词标明言谈的题目或主题，正如它在诗篇 2:7 中与同一动词连用时所表示的那样。述说它或谈论它，就是把它当作无情或讥诮的话柄。见前面诗篇 41:9 (8) 的注释。

<span class="ax-anchor" id="psalms-69-27"></span><span class="ax-vnum">28 <span class="ax-veng">(27).</span></span> *求你将罪孽加（或置）在罪孽上，不容他们进入你的义中。*路德与其他人将上半节理解为一个祷告，求以罪为罪的刑罚（罗马书 1:28）。但此处似乎更像是在借用那个双关之词（עָוֹן）的双重意义：该词本义指罪之为罪、就其自身而言，但有时又似乎指就其后果或效应而言的罪。如此理解，这便是求罪得着罪当有的自然结果的祷告。神的*义*，是他藉称义这一审判性的作为所赐下的，其中包括赦免。*进入*其中，就是进入对它的领受或享有，成为分享其中之人。

<span class="ax-anchor" id="psalms-69-28"></span><span class="ax-vnum">29 <span class="ax-veng">(28).</span></span> *愿他们从生命册上被涂抹*（或作*生者之册），且不要让他们与义人一同被记录，*即登录、列名。此处的*册*不像诗篇 56:9 (8) 那样是记忆的比喻，而是神之定旨的比喻。其首要观念乃是一份名册，上面载有那些要存活、要得保全性命之人的名字。这一比喻出于摩西，显然是借自出埃及记 32:32。古译本所给出的*生者*这一译法，若说未必有诗篇 27:13、52:7 (5) 的类比为据，至少有平行的*义*（人）一语为佐证。但抽象的译法*生命*同样贴切，且新约中*生命册*一语用以指来世的光景，也支持这一译法。见腓立比书 4:3、启示录 20:15。

<span class="ax-anchor" id="psalms-69-29"></span><span class="ax-vnum">30 <span class="ax-veng">(29).</span></span> *而我*（是）*困苦忧伤的；神啊，愿你的救恩将我安置在高处，*使我远在危险所能及的范围之外，这等于说，置于安稳之地。参看前面诗篇 20:2 (1)、59:2 (1) 的注释。此动词也可译作真正的将来时，表达一种笃定的期望，*你的救恩必护我安全。*但把它理解为他为自己所作的祈求，接在前面一连串求神剪除仇敌的祈求之后，似乎更为自然。仿佛他说：「主啊，求你记念我正在受苦，求你施行拯救，正如你施行惩罚一样。」

<span class="ax-anchor" id="psalms-69-30"></span><span class="ax-vnum">31 <span class="ax-veng">(30).</span></span> *我要用歌颂赞美神的名，*或作在歌中，*并要以称谢尊他为大。*在此，如同在其他许多地方一样，事情的确定无疑是借着明言决意要为此感谢神而表明出来的。参看前面诗篇 5:8（7）的注释。

<span class="ax-anchor" id="psalms-69-31"></span><span class="ax-vnum">32 <span class="ax-veng">(31).</span></span> *这比公牛更使耶和华喜悦，*这更讨他的喜悦，*胜过牛*（或）*有角*（且）*有蹄的公牛。*此处的对比并不在物质的祭与属灵的祭之间，而在这两类正当的奉献与仅仅献上一只牲畜之间——后者被当作本身即有功效的 *opus operatum*（事效之功），或好像神能以蹄与角为乐似的，所以才带着轻蔑点出蹄与角来。参看前面诗篇 40:7(6)、50:8、51:18(16) 的注释。末了几个字极富惯用语色彩，几乎无法逐字迻译，原文的形式乃是主动分词，*生角的、生蹄的，即*有角有蹄或长出角与蹄的。

<span class="ax-anchor" id="psalms-69-32"></span><span class="ax-vnum">33 <span class="ax-veng">(32).</span></span> *谦卑人看见就欢喜，*字面作*已经看见，且要欢喜，*即因我的拯救而喜乐，（就是你们）*这些寻求神的人，*寻求神者，*愿你们的心存活！*愿你们因目睹神权能与良善的这一彰显而得苏醒、得欢畅！这一愿望既是祈愿，也含有必将如此的应许，正如诗篇 22:27（26），那里的措辞形式与此相同。

<!-- PAGE 305 -->
<span class="ax-anchor" id="psalms-69-33"></span><span class="ax-vnum">34 <span class="ax-veng">(33).</span></span> *因为垂听的，*即惯常侧耳而听的，（乃）*是耶和华，垂听贫穷人，即*他百姓中的贫穷人，就是那义的、虔诚的、信靠他的穷乏人；*并他被囚的人，*就是那些被他自己置于患难的牢狱中、或为他的缘故被世人所囚的人，*他未曾藐视，*因此也永不藐视。此处由说话者自身的经历所引出的普遍结论，与上文诗篇 22:25（24）所言相同。

<span class="ax-anchor" id="psalms-69-34"></span><span class="ax-vnum">35 <span class="ax-veng">(34).</span></span> *愿天和地赞美他，海与其中一切爬行之物，即*以动物的、或生命的动作而移动者。在他自己所经历的这一特殊怜悯里，他看见了那些配得、也要求普世赞美之恩赐的凭据。

<span class="ax-anchor" id="psalms-69-35"></span><span class="ax-vnum">36 <span class="ax-veng">(35).</span></span> *因为神要拯救锡安，并要建造犹大的众城邑，他们要住在其中，得它为业。*他既对个别的信徒如此信实，就必对全教会也信实。古时圣徒的一个特点，就是把每一样临到自己的怜悯，都看作神必向他全体子民施更大恩惠的凭据。在本处这样的情形下，这尤为合宜，因为这里说话的是一位代表整整一类人的理想人物，而这一类人中最显著的一位，正是弥赛亚自己。无须设想此处暗指犹太人从巴比伦归回，无论是作为预言还是作为史实；更何况第 10（9）节提到圣殿时，它仍然屹立。末句的*他们*就是第 34（33）节的*穷乏人*，*即*义人，或神的子民。

<span class="ax-anchor" id="psalms-69-36"></span><span class="ax-vnum">37 <span class="ax-veng">(36).</span></span> *他仆人的后裔也必承受它，即*犹大或应许之地，*那爱他名的人，*爱他所启示之完美的人，*也必住*（安然稳妥地）*在其中。*前面的应许并不限于某一代人，乃是延及最遥远的后裔。*承受它，*即凭世代相传的继承权占有它。既然在旧约的时代里属地的福与属灵的福是交织而不可分的，那么永远占有巴勒斯坦、永远居住其间的应许，不过是旧约中用以包裹「对教会永远施恩」这一应许的外衣罢了。
