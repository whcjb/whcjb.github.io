<span class="ax-vnum">1,</span> *一篇诗。一首歌。为安息日。* 第二个题称表明本篇是赞美之诗，与其内容严格相符。所赞美的直接题旨，乃是神在其护理作为中——无论是对恶人还是对义人——所显明的能力与智慧。既然安息日的一个主要目的，是提供机会使人得以怀着惊叹默想神的工作与作为，那么眼前这一篇诗在这样的日子便格外合宜，而题注的第三句显然是确切的。

<span class="ax-anchor" id="psalms-92-1"></span><span class="ax-vnum">2 <span class="ax-veng">(1).</span></span> *称谢耶和华，歌颂你的名，至高者啊，*（这）*是善的！* 将要履行的本分，在此被描述为不仅是正当的，也是甘美的。这两个动词的含义，见前面诗篇 7:18（17）的解释。

<span class="ax-anchor" id="psalms-92-2"></span><span class="ax-vnum">3 <span class="ax-veng">(2).</span></span> *在早晨宣告你的慈爱，在诸夜间宣告你的信实。* 本句承接前一节，开首的不定式受*这是美好的*一语所支配。*在早晨，*单独来看，含有殷切与迅速之意；与平行的语句（在诸夜间）合看，则表明不懈的勤勉与恒久。参看前面诗篇 16:7，42:9 (8)，77:7 (6)，88:14 (13)，90:14 (13) 的注释。*信实，*即在应许的成就上的信实。此处信实与慈爱并举，正如诗篇 89:15 (14) 中诚实与慈爱并举一样。

<span class="ax-anchor" id="psalms-92-3"></span><span class="ax-vnum">4 <span class="ax-veng">(3).</span></span> *用十弦，用瑟，用默想配以琴。* 希伯来文的第一个词意为十，即一组或一套十个，继而指十弦的乐器。参上文诗篇 33:2 的注释。在末一分句中，藉着一个大胆却可解的比喻，*默想*被当作一种乐器来提及，与瑟和琴完全并列，而后者与它相连，不过是作为伴奏。

<span class="ax-anchor" id="psalms-92-4"></span><span class="ax-vnum">5 <span class="ax-veng">(4).</span></span> *因为你用你的作为使我欢喜，耶和华；我要因你手的工作欢呼。*本节引出所拟颂赞的主题，即主的工作与作为，*即*他护理的作为。参看上文诗篇 90:16, 17 的注释。末一动词本义是指将内心的喜乐发声表达出来。

<span class="ax-anchor" id="psalms-92-5"></span><span class="ax-vnum">6 <span class="ax-veng">(5).</span></span> *耶和华啊，你的作为何其大，*（何其）*极深，你的意念！*意念与作为是相关的表达，指计划与成就。*深，*不是指奥秘难测，而是指浩大、无量、不可穷尽，与另一分句中的*大*相对应。此节可与诗篇 40:6 (5)、以赛亚书 55:9、罗马书 11:23 相比较。

<span class="ax-anchor" id="psalms-92-6"></span><span class="ax-vnum">7 <span class="ax-veng">(6).</span></span> *畜类之人不会知道，愚顽人也不会明白这事。*开头那个复合词的意思是：一个并不比牲畜高明的人，*即*同样毫无理性。见上文诗篇 40:21 (20)、73:22 的注释，又见下文诗篇 94:8 的注释。*不会*知道，即不能知道，或并不知道。*这事，即*刚才所说的，关乎神护理的计划与旨意之深邃。

<span class="ax-anchor" id="psalms-92-7"></span><span class="ax-vnum">8 <span class="ax-veng">(7).</span></span> *在恶人* （们）*如草萌发，并且* （当）*一切作孽的人开花之时，* （乃）*是要他们被永远毁灭。* 不定式与将来时一样，都标示动作的时间。末几个词的字面翻译*是，使他们被毁灭直到永远。*

<span class="ax-anchor" id="psalms-92-8"></span><span class="ax-vnum">9 <span class="ax-veng">(8).</span></span> *而你*（是）*至高者，直到永远，耶和华！*这一简短却饱含意蕴的命题，是本篇诗的中心，同时也是全篇内容的提要。此处译作*至高者*的最高级表达，所对应的是一个希伯来文单词，其严格的意思是高处或高地，但在这里则指在存有的等级中居于最高位者。关于同一词的其他用法，参看前面诗篇 7:8(7)、10:5、18:17(16) 的注释。

<span class="ax-anchor" id="psalms-92-9"></span><span class="ax-vnum">10 <span class="ax-veng">(9).</span></span> *因为看哪，你的仇敌，耶和华*——*因为看哪，你的仇敌必灭亡；一切作孽的必被驱散。*耶和华必是至高者，因为他的仇敌不但向他屈服，更在他面前灭亡。此处与诗篇 89:11, 52（10, 51）一样，神的仇敌与他百姓的仇敌是合一而论的。末一动词本为反身形，可译作 *他们必四散*（或 *分散）自己，*其中所含的主动与急切，较之单纯的被动式 *必被四散* 更甚。参约伯记 4:11。

<span class="ax-anchor" id="psalms-92-10"></span><span class="ax-vnum">11 <span class="ax-veng">(10).</span></span> *你高举我的角，如同独角兽的角；我以新油膏抹自己。* 他此处将自己的经历与仇敌的、也与神的作为相对照。第一分句的比喻可参诗篇 18:3（2），75:5, 6, 11（4, 5, 10），89:18, 25（17, 24）。*我以油膏抹* 或 *我膏抹*（我的头），因这希伯来文动词在别处一律为主动态。此比喻取自古时在节期场合膏头的习俗。参看前面诗篇 23:5 的注释。*新油，* 字面是*青绿的，即*葱翠的，本属树木的性质，在此转用于树上最宝贵的产物。

<span class="ax-anchor" id="psalms-92-11"></span><span class="ax-vnum">12 <span class="ax-veng">(11).</span></span> *我的眼已看见我的仇敌；那些起来攻击*我，*作恶的人，我的耳必听见。*其意是说，他看见也听见了他们的结局如何。他们的灭亡虽未明言，却已含在其中。此处译作*仇敌*的那个词仅见于本处。按最可能的字源，它的意思是*窥伺者，*即埋伏等候、暗中窥探的人。参看上文诗篇 27:11，54:7(5)，56:3(2)，59:11(10) 的注释，那里出现了一个同源的形式。*我的叛起者，*或那些起来攻击我的人，附带表达出背叛合法权柄的意思。参看上文诗篇 3:2(1)，54:5(3)，86:14 的注释。加上「恶人、作恶者」一语，表明他所以期待仇敌灭亡，并不单单因为他们与他为敌，更是因为他们干犯了神。

<span class="ax-anchor" id="psalms-92-12"></span><span class="ax-vnum">13 <span class="ax-veng">(12).</span></span> *一个义的*（人）*必如棕树抽芽，如黎巴嫩的香柏树生长。* 有人以为这里暗指一件事实，就是这两种树即便在最不利的环境中也能茂盛。然而所须假定的不过是：树木本是兴旺之生命自然而通用的象征，而最尊贵的树种则把同一意思表达得更为有力。至于说这里是指圣殿的装饰，则属无据而牵强。

<span class="ax-anchor" id="psalms-92-13"></span><span class="ax-vnum">14 <span class="ax-veng">(13).</span></span> *栽于耶和华的殿中，在我们神的院宇里他们要开花*（或*兴盛*）。参上文诗篇 52:10 (8)，那里呈现的是同一意象，且形式更为具体，特别提到了橄榄树。

<span class="ax-anchor" id="psalms-92-14"></span><span class="ax-vnum">15 <span class="ax-veng">(14).</span></span> *他们年老时仍要结果子；要肥美而青翠。年老时，*字面作在白发或苍苍之发中。末句中的两个形容词，一个本指动物的属性，另一个指植物的属性。其要旨即前一节之意，在此铺陈于细节。

<span class="ax-anchor" id="psalms-92-15"></span><span class="ax-vnum">16 <span class="ax-veng">(15).</span></span> *要宣告耶和华是公义的*—*我的磐石*—*在他里面并无不义。*参看上文诗篇 18:3 (2)，并参申命记 32:4。*公义*这一称谓指神本质上的正直，其中包括他的真实可信以及对自己所立之约的信实。参看上文诗篇 25:8。*我的磐石*或可径与「耶和华」同位，作*耶和华我的磐石是公义的，*或为第二个谓语，作*耶和华是公义的，*（也是）*我的磐石。*
