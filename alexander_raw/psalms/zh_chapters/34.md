题注记载了历史背景（第 1 节），其后诗人表明心志，要为自己已经经历的神的美善而赞美他（第 2, 3 节〔1, 2〕），并邀人与他一同如此行（第 4 节〔3〕）。接着他简述自己的亲身经历（第 5-7 节〔4-6〕），并以此为据立定一条普遍的道理：神必看顾属他的子民（第 8-11 节〔7-10〕）。随后他取教导者的口吻，为人指明获得这大益处的法则（第 12-15 节〔11-14〕），并在本篇其余部分，将义人即便在受苦之中仍得保全，与恶人必致灭亡两相对照（第 16-23 节〔15-22〕）。

这篇诗显然是一篇教导诗，即*玛斯基拉*（Maschil），因此无须另行明言标出这一性质。参上文，诗篇 32:1。

就其形式而论，这是第二篇字母诗，几乎已达到完全的整齐，所缺的字母仅有 ו 一个。极可注意的是，此处与诗篇 25 篇一样，末节以 פ 起首，与第 16 节相同，似是在字母次序之外另行附加上去的。

<span class="ax-vnum">1,</span> *大卫所作，在*（当）*他在亚比米勒面前改变*（伪装）*他的心智之时；他就把他赶走，他便去了。* 此处所指的事件记在撒母耳记上 21 章。大卫逃避扫罗，进入非利士人之地，被带到迦特王亚吉面前；因昔日所加的损害，他有理由料想亚吉会报复，于是佯装疯狂。这一权宜之计在道德上虽属可疑，神却乐意使其得以成功。大卫对这一己所不配得的拯救心怀感念，同时对自己借以脱险的手段也不无愧疚，似乎在他一生较晚的时期，为教导百姓而写下这篇诗。此诗以其清晰与朴素，并以其字母诗的体裁——这对记诵大有助益——格外适合这一用途。——*在他改变之时*未必是指写作的日期，只是指那引发此诗之事件的日期。通行译本作「举动」，与这希伯来词的用法不合；此词意为滋味、判断、悟性、心智。——*亚比米勒*，意即「王之父」，世袭的君主，乃是当时对王的传统称号。参创世记 20:2，26:1。他本人的名字是亚吉，见撒母耳记上 21:10, 11, 12, 14。

<span class="ax-anchor" id="psalms-34-1"></span><span class="ax-vnum">2 <span class="ax-veng">(1).</span></span> *我要时时称颂耶和华；他的赞美必常*（在）*在我口中。*不住赞美的许诺，暗示有非常的恩惠激发了这赞美。——*在一切的时候，*即在各样的处境中，纵然是最叫人灰心的处境，他也定意要记念神从前为他所行的事。

<span class="ax-anchor" id="psalms-34-2"></span><span class="ax-vnum">3 <span class="ax-veng">(2).</span></span> *我的心必因耶和华夸耀；谦卑人听见就欢喜。* 第一个动词严格说是反身形式，意为*称赞自己，即*可作*夸口*，或作为心中较为持久的情感，意为*夸耀，即*因拥有并享受某一所仰慕、所爱慕的对象而欢欣。夸耀这一举动被归于灵魂，为要表明这是出于衷心的，*ex animo*（发自心底）。——*谦卑人，*与骄傲自恃之人相对，是对神子民的一般描述；他们自然会因诗人所经历的美善而关切，既是为他的缘故，也是为自己的缘故。参上文诗篇 22:27(26)、25:9 的注释。

<span class="ax-anchor" id="psalms-34-3"></span><span class="ax-vnum">4 <span class="ax-veng">(3).</span></span> *当尊大*（称颂）*归与耶和华，与我一同；让我们一同高举他的名。*在诗篇 69:31 (30)，动词*尊大*是直接与其宾语相连的，但此处所带的却是一个与格，*归与耶和华*，这或可视为宾格的诗体等义，或与所省略的名词*称颂*相连，或与从另一分句补出的*名*相连。

<span class="ax-anchor" id="psalms-34-4"></span><span class="ax-vnum">5 <span class="ax-veng">(4).</span></span> *我寻求耶和华，他就应允我，并从我一切的惧怕中搭救我。* 他在此开始说明自己与他人当赞美神的缘由。神既除去了他惧怕的缘由，便是从他一切的惧怕中搭救了他。同样的复数形式见以赛亚书 66:4。

<span class="ax-anchor" id="psalms-34-5"></span><span class="ax-vnum">6 <span class="ax-veng">(5).</span></span> *他们仰望他便容光焕发，愿他们的脸不致发红。*复数的*他们*指诗人所代表的那整个群体。——*容光焕发，*或照我们英文的说法，*焕然开朗，*是解脱与重获欢欣的一种自然表达。在末句中，以祈愿的语气取代了单纯陈述的语气，从而加重了语势。「*愿他们的脸不致发红，*」这一愿望意味着他们有发红蒙羞的危险，也意味着需要神的恩典来加以阻止。

<span class="ax-anchor" id="psalms-34-6"></span><span class="ax-vnum">7 <span class="ax-veng">(6).</span></span> *这受苦者呼求，耶和华就垂听，从他一切的患难中拯救了他。*前一节用的是概括的说法，这里他又转回到自己特定的情形。*这受苦者，*或作受苦之人，是指他自己，正如我们今日措辞中说「说话的人」或「写作的人」，用作人称代词的迂回说法。

<!-- PAGE 154 -->
<span class="ax-anchor" id="psalms-34-7"></span><span class="ax-vnum">8 <span class="ax-veng">(7).</span></span> *安营的*（乃是）*耶和华的使者，在敬畏他之人的四围*——*并且*（如今）*他已搭救了他们。*这使者，不单是集合意义上的众使者，更是其特指的意义，即那位卓越无比的主的使者，就是约的使者、神同在的使者（以赛亚书 63:9），旧约的时代中神性的显现正是藉着他。既然这位使者是耶和华军队的元帅（约书亚记 5:14，列王纪上 22:19），他的临在便含有许多其他使者的临在，因此*安营*一词是极其贴切的。转接将来时表明末一动词所指的动作是前一动作的结果。这种语法关系在译文中只能不完全地表达出来，虽然其大意已足够清楚。

<span class="ax-anchor" id="psalms-34-8"></span><span class="ax-vnum">9 <span class="ax-veng">(8).</span></span> *你们尝尝看，便知耶和华是善的；有福啊，那将要倚靠他的人。*唯一的凭据是经验所供给的。这劝勉似乎暗示筵席已经预备妥当，只等客人到来。参路加福音 14:17，并见前面诗篇 2:12 的解释。

<span class="ax-anchor" id="psalms-34-9"></span><span class="ax-vnum">10 <span class="ax-veng">(9).</span></span> *敬畏耶和华，你们这些属他的圣民，因为敬畏他的人一无所缺。* 此处与别处多次一样，以敬畏神代表全备的虔敬，即真实的宗教；这虔敬必须永远建立在深沉的敬惧与崇敬的根基上。参诗篇 2:11、箴言 1:7、9:10。*属他的圣民，*即那些被分别出来、归于事奉他的人，既是如此，就当按严格的意义成为圣洁。见上文诗篇 16:3 的注释。末一分句表明，这既是神子民的本分，同样也是他们的益处。呼召他们敬畏他，不仅因为敬畏本是他所当得的，也因为这是确保自身安稳、供应自身缺乏的最可靠之法。

<span class="ax-anchor" id="psalms-34-10"></span><span class="ax-vnum">11 <span class="ax-veng">(10).</span></span> *少壮狮子尚且缺乏饥饿，惟寻求耶和华的必不缺少一切* （或 *任何）美物。*第一个动词的本义是*变穷*或陷于贫困，因此严格说来只能用于人，这足以证明此处实在是以狮子为喻而指人，别处也常用狮子来形容强横暴戾之人。见约伯记 4:10, 11，并比较诗篇 57:5（4）、那鸿书 2:12-14（11-13）、以西结书 19:2, 3，38:13。如此，其意便是：纵然人中最有势力、最无顾忌者也可能沦落到缺乏的地步，神的子民却必得丰足而恒常的供养。此处的对比与以赛亚书 40:30, 31 所呈现的相类。

<span class="ax-anchor" id="psalms-34-11"></span><span class="ax-vnum">12 <span class="ax-veng">(11).</span></span> *来吧，众子，听我*；*耶和华的敬畏我要教导你们。* 他既在神的道路上久经历练，如今便向那些尚未得着亮光的人说话，邀他们领受他的教训。*众子*或*孩子们*，乃是就学生与教师的关系而言的一个自然而常见的称呼。参箴言 1:8, 10, 15。教导人敬畏主，就是教导他们当如何敬畏他、为何当敬畏他。因此我们在下文各节中便看见一个为真敬虔辩护的实际论证，乃是从敬虔对那些存守并实行之人所生的美善果效中引出来的。

<span class="ax-anchor" id="psalms-34-12"></span><span class="ax-vnum">13 <span class="ax-veng">(12).</span></span> *谁*（是）*那人，那*（一位）*渴慕生命、喜爱年日*（在其中）*得见福乐的？* 这问句等于说，*凡渴慕生命的人，即*渴望活着，不是单指存在这件事，而是指真正的享受，这一点在末句中由*喜爱年日，即*渴望多有年日或长寿，明白地表达出来；而所渴望的并非年日本身，乃是以其为享福之期。凡真有此愿的人——这愿望自然是人人都有的——就当谨守下面的教训。*得见福乐*就是由经历而知之，得着它并享用它。参看上文诗篇 4:7（6）的注释。

<span class="ax-anchor" id="psalms-34-13"></span><span class="ax-vnum">14 <span class="ax-veng">(13).</span></span> *当禁止你的舌头不出恶言，禁止你的嘴唇不说诡诈。*第 13（12）节中所寻问的那人，在此被直接称呼。无论你是谁，你若愿意如此生活，就当*禁止，*看守、防范，*你的舌头不说恶言，*这是一个概括性的说法，末句则代之以一个更为具体的说法，即*说诡诈，*发出欺骗之言，或说谎。此处对这一罪的强调何等显著——若联系题注所提示的、大卫借以脱离亚吉之手的那番手段来看，就更觉如此——以致唯有作这样的设想方能解释：他视自己那次欺骗之得逞，为神极大的、全然不配得的宽容；这宽容非但丝毫不能使他在别的情形下推荐同样的做法，反倒使诗人负有责任，劝阻他人不可行此事。

<span class="ax-anchor" id="psalms-34-14"></span><span class="ax-vnum">15 <span class="ax-veng">(14).</span></span> *离恶行善；寻求和睦，追赶它。* 不单就这一样罪而言，乃是就一切的罪而言：你若愿意享受生命，就当*离恶，*断绝恶的习行，弃绝对恶的喜爱；而既然单作一种否定既不可行、也不足够，就当藉着积极实行与之相反的事来成就它，*行善。*参以赛亚书 1:16, 17 中的劝勉，*止住作恶，学习行善。*末一分句可以解作由概括回到个别，正如上一节单单拈出虚谎与诡诈，这里单单拈出仇敌之心与恨恶。参罗马书 12:18，哥林多后书 13:11。或者*和睦*也可理解为包括与神和好以及享受他的恩眷。——无论取其中哪一义，或二义兼取，你若愿意享受生命，就当*寻求和睦，*且不是懒散无心地寻求，乃要*追赶它，*追逐它，猎取它，切切竭力去得着它。这命令本身就含示：所求之物既值得追求，也有失去之虞。

<span class="ax-anchor" id="psalms-34-15"></span><span class="ax-vnum">16 <span class="ax-veng">(15).</span></span> *耶和华的眼目*（是）*向着义人，他的耳朵向着他们的呼求。* 顺从前面那些训诲的动机，在于神必保护他的仆人脱离那些既非暴力亦非诡诈所能保全他们的危难。他们无需说诡诈的话，也无需破坏和睦，就可免受伤害。另有一位看顾他们，他的警醒是无法躲避、也无法消耗殆尽的。*主的眼目向着义人，即*向他们睁开，或转向他们，以致他时时看见他们真实的光景；*他的耳朵*也侧向*他们的呼求，*或说敞开着以承接那呼求。这话撇去比喻而言，意思是说：他时刻知悉他们的需用，随时乐意垂听他们的祷告；而在这一确据之中，平安稳妥与丰足有余的确据已尽都包含在内了。

<span class="ax-anchor" id="psalms-34-16"></span><span class="ax-vnum">17 <span class="ax-veng">(16).</span></span> *耶和华的面*（是）*与作恶者同在，要从地上除灭他们的记念。*同样不眠的警醒也施于他人，只是目的全然不同。*主的面与作恶者同在，即*向他们显现、与他们同在，并不亚于向善人。*作恶者*之前的那个介词，与前一节中两次出现、本义表示方向的那个并不相同，而是另一个，意为*在……之中*或*与……同在*。这里以及别处（*例如*耶利米书 21:10，44:11）似乎带有的不利意味，即*敌对*，乃是由上下文提示出来的。在所有这些情形中，有些解经者认为其意是说神的眼目或面容仿佛穿透对象，并停驻其中。——耶和华鉴察作恶者的用意，不是为要干预施行拯救或纾解，而是*要从地上除灭他们的*那*记念，*这是表明彻底铲除的有力说法。参出埃及记 17:14，申命记 25:19，以赛亚书 26:14，并见前面诗篇 9:6, 7（5, 6）的注释。

<span class="ax-anchor" id="psalms-34-17"></span><span class="ax-vnum">18 <span class="ax-veng">(17).</span></span> *他们呼求，耶和华就垂听，从他们一切的患难中搭救他们。* 这话乍看似乎是指上一节中的作恶者，如此则他们被描写为藉着向神谦卑祈求而得脱所应得的审判。但既然恶人在这整段中只是附带提及，仿佛是衬托义人的陪衬或反照，那么总的看来，还是把这里的第一个动词当作泛指为好，*人呼求帮助，*却特指第 16（15）节中的义人。神看顾义人以保护他们——正如他鉴察恶人以剪除他们——每逢他们向他呼求帮助，他就拯救他们。第 17（16）节这种括号式的结构更为可取，因为其中并无限定动词，而第 18（17）节却有三个。

<span class="ax-anchor" id="psalms-34-18"></span><span class="ax-vnum">19 <span class="ax-veng">(18).</span></span> *近的，*（是）*耶和华，向那心里破碎的；那灵里压碎的，他必拯救。*这些比喻性的用语一概取褒义，用于指谦卑的悔罪者。参诗篇 51:19（17），以赛亚书 57:15，61:1，66:2。它们所描绘的，是神的恩典在罪人心中所作成的痛悔。对这样的人，主总是*近的，即*随时施行拯救与保护。见前面诗篇 22:12（11）的注释。

<span class="ax-anchor" id="psalms-34-19"></span><span class="ax-vnum">20 <span class="ax-veng">(19).</span></span> *许多祸患*（临到）*义人，但耶和华必救他脱离这一切。*前面的应许似乎可以理解为全然免于苦难；然而唯有在全然免于罪恶的前提下，这样的福分才可享有。只要罪仍然存在，忧患就必与之并存，即便在真信徒或义人身上也是如此——本书从不把他们描述为绝对无罪的。参看上文诗篇 19:13（12）, 25:7。义人的苦难显明他们是罪人，而他们的蒙拯救则彰显神的怜悯。按我们的语言习惯，两个分句之间的关系要求用一个 *but*（但），而非希伯来作者在此类连接中通常使用的单纯连系词。

<span class="ax-anchor" id="psalms-34-20"></span><span class="ax-vnum">21 <span class="ax-veng">(20).</span></span> *保守他一切的骨头*——*其中一根也不折断。*这句可以补上系动词来补足：（他是）*保守着，即*习惯性地保守；但更简明也更妥当的，是把本节与前一节视为一句，而把那分词按常规看作与*耶和华*相配。——*保守，*取其丰满之义，即看顾并保全。——*他的骨头，*指他的身躯、他的身体。参看上文诗篇 32:3，及下文诗篇 35:10。——末句若按字面译作*其中一根不被折断，*在英文里便有歧义。原文的这一说法亦见于以赛亚书 34:16。本节的教训或应许，与马太福音 10:30 所言相类。

<span class="ax-anchor" id="psalms-34-21"></span><span class="ax-vnum">22 <span class="ax-veng">(21).</span></span> *恶要杀死恶人，恨恶义人的必被定为有罪。*义人所分受的苦难不过是暂时的，恶人的苦难却终必致命。参看上文诗篇 32:10 的注释。*恶*在两处必有同一含义，即身体上的祸患、苦难或不幸。此处所描述的结局并非偶然，乃是由道德上的原因所招致。他们必被毁灭，因为他们被查出*有罪，即*悖逆神之罪，而他们恨恶神的百姓，正是这罪确凿的一个凭据。他们*必被定为有罪，即*被认出、被知道是如此，并照此被对待。「恶人的苦难与义人的苦难不同，是趋向死亡的，因为前者对后者的恨恶，证明他自己是该当灭亡的。」

<span class="ax-anchor" id="psalms-34-22"></span><span class="ax-vnum">23 <span class="ax-veng">(22).</span></span> *耶和华救赎他仆人的魂，必无一人有罪，*（在）*那些倚靠他的人中。* 希伯来文第一句的确切形式是 *耶和华救赎着他仆人的魂，* 这似乎是说，他此刻正在这样行，并且他惯常如此行。之所以提到魂，即生命的原理，是因为此处所关乎的乃是生死之事。凡倚靠他的，必无一人被认定、被当作有罪的看待——这正与前面论恶人所断言的相反。得此豁免的条件与根据，乃是对神的信或倚靠；按两约一致的教训，离了这信，就无从脱离罪责与刑罚。
