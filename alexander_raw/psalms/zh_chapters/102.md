<span class="ax-vnum">1.</span> *一篇祷告。为受苦者所作，当他困乏、在耶和华面前倾吐他的哀怨之时。* 此篇称为*祷告，*因为祈求构成其实质。参看前面诗篇 90:1 的注释。译作*为那受苦者*（或*受苦难者*）在语法上同样可行，也与本篇的实际用意完全吻合。但在诗篇的题注中，这类短语一贯指明作者或演奏者，而当只出现一个这样的短语时，所指的总是前者；因此此处若背离这一惯例，极不可能，而擅自作此假定更属武断。与此同时，*一位受苦者，*或*一个受苦难的人，*这一不确指的说法，似乎是有意采用的，为要使本篇可以不受限制地应用，虽然其首要所指无疑是以色列受苦的君王——百姓的苦难都集中并体现在他们身上。题注中其余各词，都见于大卫的诗篇：*困乏*（或*不胜其苦*）见诗篇 61:3（2）；*哀怨*（或*哀叹*）见诗篇 55:3（2）、64:2（1）；*倾吐心魂*见诗篇 62:9（8）。这与本篇整体上的大卫风格相合，并支持亨斯滕伯格（Hengstenberg）的假设——此假设在别处无从证实，甚至也算不上多么可能——即本篇乃是诗篇 101 篇中敬虔的决志与诗篇 103 篇中欢欣的称谢之间的连接环节，是先知性地预见神权国家将陷入的困境而作；在那困境之中，此处所直接描写的大卫的苦难，仿佛要重新成为现实。本篇可分为两部分：前一部分以哀哭或申诉的语调为主，第 2-12 节（1-11）；后一部分则因思想神的属性、满怀把握地期待他的恩眷，而使那语调得到节制与约束，第 13-29 节（12-28）。

<span class="ax-anchor" id="psalms-102-1"></span><span class="ax-vnum">2 <span class="ax-veng">(1).</span></span> *耶和华啊，求你听我的祷告，愿我的呼号*（求助的）*上达于你。*将本节与诗篇 4:2 (1)、17:1、18:7 (6)、54:4 (2) 比较。就眼前这一处而言，把这些雷同之处看作后世作者的摹仿，其理由并不比在其余各处更为充分。若它们并非摹仿，便正可表明：大卫不过是为将来、或为别人，求那他自己早已寻求过、也早已经历过的恩惠。

<span class="ax-anchor" id="psalms-102-2"></span><span class="ax-vnum">3 <span class="ax-veng">(2).</span></span> *求你不要向我掩面；在日子*（有）*患难临到我，求你侧耳听我；在我呼求的日子，求你速速*（且）*应允我*　参 诗篇 10:1，13:1，17:6，18:7（6），27:9，31:3（2），56:10（9），66:14（13），71:2。大卫在别处用以表达同样意思的词句，几乎都汇聚于此。倘若我们设想他是在为后世子孙预备一篇在至深患难中所用的哀诉与祈求的范本，这就并不足怪了。

<span class="ax-anchor" id="psalms-102-3"></span><span class="ax-vnum">4 <span class="ax-veng">(3).</span></span> *因为我的年日在烟中消尽，我的骨头像焚烧之物一样烧着。*上半节可比较诗篇 37:20。提到骨头，是因骨为力量之所在。参看上文对诗篇 6:3 (2)、31:11 (10)、35:10、42:11 (10) 的解释。这一番描述，固然严格说来适用于个别受苦者的情形，却也可以应用在神权君国的衰微及其大祸临头之上。

<span class="ax-anchor" id="psalms-102-4"></span><span class="ax-vnum">5 <span class="ax-veng">(4).</span></span> *我的心如草被击打而枯干，因我忘记吃我的饭。*首一动词用以描写日头加于草木的作用，诗篇 121:6、以赛亚书 49:10。（参约拿书 4:7。）提到心，是以其为生命之所在。末句的通行译法（以致我忘记）于文法不合。气力的衰竭，毋宁说是直接由缺乏食物所致（撒母耳记上 28:20），而缺食又是由极度愁苦以致不思饮食。参下文诗篇 107:18 的注解，并参撒母耳记上 1:7、20:34，列王纪上 21:4。*忘记吃，*字面作*从吃上忘记，*以致不吃，这是希伯来文中介词「从」一种常见的惯用法。

<span class="ax-anchor" id="psalms-102-5"></span><span class="ax-vnum">6 <span class="ax-veng">(5).</span></span> *因我唉哼的声音，我的骨头紧贴我的肉。* *声音*一词意味着痛苦发为可闻而响亮的表达。前一分句的意思是：因那使我唉哼的剧痛所致。*我的骨头*可指我的每一根骨头，或是集合地用来指全身的骨架、躯体的架构。对这一分句唯一自然的解释，是它描写形体消瘦，乃是极度困苦的结果与征象。参看前面诗篇 22:15, 18（14, 17）的注释。

<span class="ax-anchor" id="psalms-102-6"></span><span class="ax-vnum">7 <span class="ax-veng">(6).</span></span> *我像旷野的鹈鹕*；*我成了如同鸮鸟*（栖于）*废墟。* 这些比喻所传达的简单意思，就是极度的孤寂与荒凉。除了它们栖居于荒僻之处这一点以外，所提到的这些鸟类的博物学知识对解经并无重要意义。

<!-- PAGE 418 -->
<span class="ax-anchor" id="psalms-102-7"></span><span class="ax-vnum">8 <span class="ax-veng">(7).</span></span> *我儆醒不寐，就像一只麻雀独宿在房顶上。*开头几个字使人想到孤身守夜的情景。至于译作*麻雀*的那个词，见前文诗篇 84:4(3) 的注释。末句中的*独宿*一词是译文中补出的，为要保留原文表达的形式，因原文在此是一个主动分词。有人以为这里的意思是一只失去了配偶或失去了雏鸟的鸟。

<span class="ax-anchor" id="psalms-102-8"></span><span class="ax-vnum">9 <span class="ax-veng">(8).</span></span> *终日我的仇敌辱骂我，我那些暴怒的*（敌人）*指着我起誓。*前一分句中的动词含有轻蔑与憎恨、毁谤与侮辱的意思。参上文诗篇 42:11 (10) 的注释。末一分句的第一个词是被动分词，*我那些被激怒的*（或*发狂的）人，*即那些向我发狂*（即*因仇恨而丧失理智）的人。末了的一语并非指*咒骂我，即*以赌咒和诅咒发泄他们的怒气，也不是指*被人指着我起誓*，这两种讲法都不合希伯来文的用法；其意乃是*指着我起誓，即*拿我作咒诅的套语，咒愿别人遭遇与我一样的悲惨。参以赛亚书 65:15、耶利米书 29:22。过去时的形式表明这场狂暴的逼迫在先前已延续甚久，正如*终日*一语表明其暴怒之恒常不息。

<span class="ax-anchor" id="psalms-102-9"></span><span class="ax-vnum">10 <span class="ax-veng">(9).</span></span> *因为我吃过炉灰如同吃饭，又将我所喝的与眼泪搀和。* 他所坐其中、或撒在身上以示哀悼的炉灰，混进了他的食物里，他的眼泪也落进了他的*饮*中。末一个词在希伯来文中是复数，作*饮料*或*饮品*，正如英文 *victuals*（饭食，复数形）不过是 *food*（食物）的单纯同义词一样。而同一惯用语差异的反例，则是译作*炉灰*的那个词在希伯来文中乃是单数。全节是对持续而极深之苦难的有力诗意描写。

<span class="ax-anchor" id="psalms-102-10"></span><span class="ax-vnum">11 <span class="ax-veng">(10).</span></span> *因你的恼怒和你的忿怒；因为你把我举起，又把我抛掷。*前一分句将他的苦难描述为神不悦的果子。参看上文诗篇 90:7 的注释。通行译本在后一分句中所呈现的那种对照（举我起来，又将我摔下），似乎并非原文的意思；原文中大概是暗指暴风或旋风把东西卷起、又把它吹散的比喻。公祷书译本对头一个动词的译法（把我举起）更为确切。

<span class="ax-anchor" id="psalms-102-11"></span><span class="ax-vnum">12 <span class="ax-veng">(11).</span></span> *我的年日*（如同）*倾斜的影儿，我*（自己）*也像草枯干。* *倾斜的影儿*是一个不常见而含义晦暗的说法，但似乎是指一道将近消没、转眼即逝的影子。在末一分句的译文中所用的双重或反身代词（*我自己*），是传达希伯来文代词全部力量所必需的；该代词除非有意加以强调，平常并不明言出来，*我枯干，*正在枯干，或将要枯干。

<span class="ax-anchor" id="psalms-102-12"></span><span class="ax-vnum">13 <span class="ax-veng">(12).</span></span> *而你耶和华，直到永远必安坐，你的记念*（必长存）*到世世代代*。此处代词再次是强调性的，把神的永恒与人的脆弱作了强烈对照。当我如草枯萎之时，你却存到永远；不仅如此，你更是掌权、坐在宝座上。参看前面诗篇 9:8（7）、29:10、55:20（19）的注释。此处用*记念*一词，似是为了它所隐含的对照之意。当我消亡、被人全然遗忘之时，你的存在与你的记念却要存到永远。不过，它也可能与诗篇 30:5（4）中的意思相同，即那与神的名相连、存于我们记念之中的神性完全。你不仅要永远掌权，更配得如此掌权，因你是无限完全的存有。

<span class="ax-anchor" id="psalms-102-13"></span><span class="ax-vnum">14 <span class="ax-veng">(13).</span></span> *你必兴起，必怜悯锡安，因为*（到了）*恩待她的时候，定期已经来到。*此处的代词再次带着强调。你，这位如此荣耀、如此不变的神，必定要从这表面的静默无为中兴起，向你的子民施怜悯或慈悲，当你永恒旨意所定的时候一到。希伯来文小品词（כִּי）作*当……之时*解，虽不甚常见，有时却是绝对必要的，因此在此处可以采用，而且比寻常的*因为*之义更合文意。或者也可将二者归并为一，把全句解释如下：你必定要在合宜的时候兴起，怜悯锡安，因为你已定下一个时候，要在那时施恩给她。关于译作*定期*一词的含义，见前面诗篇 75:3（2）的注释。

<span class="ax-anchor" id="psalms-102-14"></span><span class="ax-vnum">15 <span class="ax-veng">(14).</span></span> *因你的仆人们爱慕她的石头，顾惜她的尘土。*希伯来文中的两个动词都有施恩顾惜之意，更强的语气则是以之为喜乐、以之为乐。参上文诗篇 62:5(4)、85:2(1)。此处的*石头*与*尘土*乃是指废墟或瓦砾，如尼希米记 3:34（4:2）、4:4（10）。本节可理解为她得复兴的条件，或是其先兆：在复兴临到之先，神必使他的仆人们心中满了对她荒凉景况的切切关怀。同样的意思也可以不离开这个小品词的常用义而得出：你必怜恤锡安，因为你的仆人们已经以关切和强烈的渴慕注视她的废墟，这正是复兴将近的确据。

<span class="ax-anchor" id="psalms-102-15"></span><span class="ax-vnum">16 <span class="ax-veng">(15).</span></span> *列国必惧怕耶和华的名，地上诸王必惧怕你的荣耀。* 耶和华属性的这些显明，必然生出敬畏之感，而这感受并不限于以色列，乃要延及列邦，连君王也要彼此争先，在敬畏中惊叹他君王的尊荣。参以赛亚书 59:19 中类似的说法。

<span class="ax-anchor" id="psalms-102-16"></span><span class="ax-vnum">17 <span class="ax-veng">(16).</span></span> *因为耶和华建造了锡安；他已显现在他的荣耀中。*这些不是 *præterita prophetica*（预言性的过去时），即把将来之事当作已过之事来描述；也不可当作单纯的现在时，而是表示一种相对的过去，依附于前一节的将来时。列国与他们的君王要惧怕，因为耶和华建造了锡安（*即*到那时将已建造了锡安）。似乎还可能有另一种解法，即「当耶和华建造锡安时，他必显现在他的荣耀中」。但若如此，按希伯来文的惯用法，纵不要求两个动词都用将来时形式，至少末一个动词必须是将来时。

<span class="ax-anchor" id="psalms-102-17"></span><span class="ax-vnum">18 <span class="ax-veng">(17).</span></span> *他转向赤贫者的祷告，并未藐视他们的祈求。*本节继续说明列国与其君王何以要生出敬畏，即因为这位伟大荣耀的神仿佛转过身来，侧耳听了赤贫者的祷告，并应允了他们的祈求。译作*赤贫者*的那个词只见于此处和耶利米书 17:6；但从其字源上的亲属关系及其强化形式来看，似乎意为赤身露体，继而引申为被剥夺净尽、一贫如洗、一无所有。

<span class="ax-anchor" id="psalms-102-18"></span><span class="ax-vnum">19 <span class="ax-veng">(18).</span></span> *「这必为后代记下，一个将受造之民*（尚未存在而）*必受造的，要赞美雅。*神应许的这一成就、他属性的这一彰显，被留为记录，好叫后世得以学习、受教。参哥林多前书 10:11。*后代，*与诗篇 48:14(13)、78:4 同。意思相当而形式简略的，是这两处所本之经文中的说法，诗篇 22:31(30)。又见诗篇 71:18。*受造的*或可作将来式分词之意，如希伯来文中被动分词常有的用法；或可指（那时）*受造的（而非现今）。*见上文诗篇 22:32(31) 之注。既然动词（ברא）*创造*只用于神的作为，此处的用法似乎表明，所指的不仅是一个将来的世代、一个尚未出现的族类，而是严格意义上的*民*，是日后要由至高的权柄与全能的大力所组成的一个有组织的群体。*要赞美雅，*即承认耶和华拥有、并且就是他名所表明的一切。

<span class="ax-anchor" id="psalms-102-19"></span><span class="ax-vnum">20 <span class="ax-veng">(19).</span></span> *因为他已从他圣洁的高处俯身下望！耶和华从天向地观看。*第一个词也可译作*就是*，而本节则可理解为对第 19 (18) 节开头那个代词*这*的展开。这就是将要为后代写下的；这就是他们将要为之赞美雅（Jah）的；即他已俯身下望……为避免英文动词的重复，同时使描写更为生动，此处的希伯来文动词是按其似为本义的意思译出的。参看上文诗篇 14:2，85:12 (11) 的注释，并参申命记 26:15。

<span class="ax-anchor" id="psalms-102-20"></span><span class="ax-vnum">21 <span class="ax-veng">(20).</span></span> *垂听被囚者的叹息，释放必死之人的众子。*此句的结构承接上一节而来，陈明神如此垂看的目的。译作*叹息*的那个词几乎为大卫的诗篇所独有，按其字源本指窒息。*释放，*字面作*开解，*有时用于解开衣袍以便脱去，如诗篇 30:12（11）；进而用于解开锁链，如诗篇 116:16；再进而用于释放被囚者本人。*必死之子*或*死亡之子，即*那些被定了死罪的人。参看前面诗篇 79:11 的注释。

<span class="ax-anchor" id="psalms-102-21"></span><span class="ax-vnum">22 <span class="ax-veng">(21).</span></span> *为要在锡安述说耶和华的名，在耶路撒冷述说他的赞美。*按希伯来文句法的规则，这句并不一定指神自己的作为，不像前一节相似的结构那样，而可以有一种较宽泛的意思，相当于说*使他的名可以在锡安被传扬。*述说神的名，就是述说那构成其名的大能作为，而对这些作为的称颂便构成他的赞美。锡安在此仍被描绘为耶和华得胜的大舞台，然而不仅是作为以色列或犹大的都城，乃是作为宗教之光与影响向全地发散的中心。

<span class="ax-anchor" id="psalms-102-22"></span><span class="ax-vnum">23 <span class="ax-veng">(22).</span></span> *在万民聚集、列国一同事奉耶和华的时候。* 此节是前一节意思的必要补足与限定。神从天垂看，为要拯救他的子民、领受他们的颂赞，但这并非在他们隔绝孤立的景况中，乃是在他们与归正万邦荣耀的重聚之中。第一个动词在希伯来文中是被动不定词，*在他们被聚集之时。*介词*在*既指召集之时，也指召集这一举动。*事奉耶和华，*不单以他为王，也以他为神，既作他的子民，也作敬拜他的人。参诗篇 2:11。

<span class="ax-anchor" id="psalms-102-23"></span><span class="ax-vnum">24 <span class="ax-veng">(23).</span></span> *他在路上使他的力量衰微；他缩短了我的年日。* 诗人在此重拾哀诉的语调，却只是片刻之间，且是为下文作引。*使……衰微，*即削弱，或使受苦。*在*他护理引导的*路上*，或*藉着*这*路*，与这路所通向的荣耀结局相对。*他的力量*与*我的年日*显然是指同一个人。为避免这种生硬的人称换用（enallage），马所拉的校勘者改动了一个字母，把（כֹּחוֹ）*他的力量*读作（כֹּחִי）*我的力量，*此读法虽为多数译本所采，却显然是对一处设想中的难题的回避。末句可比较诗篇 89:46（45）。另参诗篇 55:24（23）。

<span class="ax-anchor" id="psalms-102-24"></span><span class="ax-vnum">25 <span class="ax-veng">(24).</span></span> *我要说，我的神啊，不要在我年日之半取我上去；你的年数世世代代长存。* *取上去，*使上升，*即*如一些人所设想的，像烟一样上升，这未免牵强附会。另一些人只把它解作取去，这样意思固然通顺，但在用法上缺乏充分的根据。比这两说都好的，是认为此处以一种与以诺、以利亚实际离世相应的比喻，来描写死亡或从今生的迁移。参创世记 5:24，列王纪下 2:1, 3, 5, 10, 11。*在我年日之半（或之中）；*见上文诗篇 55:24（23）的注释，并比较以赛亚书 38:10。*世世代代，即*一切世代，如诗篇 72:5、以赛亚书 51:8。他祈求那年数无穷的神，不要仿佛吝惜赐给受造之物的那几日光阴。见上文诗篇 39:6（5）的注释。

<span class="ax-anchor" id="psalms-102-25"></span><span class="ax-vnum">26 <span class="ax-veng">(25).</span></span> *起初你立了地的根基，你手所造的* （是）*诸天。* 开头的那个短语，本义是*向着面前，*其后作*在……之前，*既可用作时间的副词，也可用作处所的副词；但在此处这样理解则有歧义，因为它可能被当作连词，*在你立地的根基以前，*所表达的便与诗篇 90:2 的意思相同。此处它的意思是很久以前、从古时、在起初。末句可与诗篇 8:4(3)、19:2(1)、33:6 相比较。此处在神的永恒之外又加上他的创造大能，为要加深他的无限与人的渺小之间的对比，并以此作为他怜悯人的缘由。

<span class="ax-anchor" id="psalms-102-26"></span><span class="ax-vnum">27 <span class="ax-veng">(26).</span></span> *它们必灭没，你却长存，它们都要像衣服渐渐破旧，你要像衣裳更换它们，它们就被更换。* 希伯来文中这一对比表达得极其鲜明，乃是借着插入代词*它们*与*你*，而这两个代词在语法上对于表达此意并非必需。*长存，*即站立得稳、持续、存留、延续。*它们都，*无一例外，即便是神最崇高的作品，至少也要失去其现今的形态，在此意义上便是灭没；而这一意思用在平行的动词*过去*或*更换*上，更是顺理成章。英文此动词兼有主动与中性、及物与不及物两种用法，因而恰好可以用来对应希伯来文动词（חלף）的基本形与派生形。本句后半所用的相应动词，不仅意为*变旧，*并且作为其必然的结果，意为*破旧磨损*。参看上文诗篇 32:3 的注释，并参诗篇 49:15（14）。

<span class="ax-anchor" id="psalms-102-27"></span><span class="ax-vnum">28 <span class="ax-veng">(27).</span></span> *而你*（乃）*是他*——*你的年数必不终尽。*前一分句的句法历来有争议。有人读作：*你自己和你的年数都不会终结。*另有人读作：*你是那同一位，*即赋予 הוּא 与希腊文 ὁ αὐτός（那同一位）相同的意思——七十士译本在此处正是用这个词来翻译它的。支持上面首先给出的那种译法的理由是：它既合乎这几个希伯来词的通常用法，又与申命记 32:39 和以赛亚书 43:10 的类比相符，也与此处的上下文相合。如此，其意便是：你就是方才所描述的那位不变者。或者说：唯独是你，而非别的什么，要这样长存。*终尽，*即耗尽、消磨殆尽，这个希伯来词一向就是这个意思。别处按字面用来指人命被强暴毁灭的说法，在此被转用于时间的流逝。

<span class="ax-anchor" id="psalms-102-28"></span><span class="ax-vnum">29 <span class="ax-veng">(28).</span></span> *你仆人的众子必安居，他们的后裔必在你面前坚立。* 这也可以译作祷词，*愿你仆人的众子长存，* 而这层意思其实已包含在那预言之中。*在你面前，* 如创世记 17:1、诗篇 89:37（36）。*坚立，* 如诗篇 89:38（37）、101:7。全诗这一结语可参诗篇 69:36, 37（35, 36）、90:16, 17。
