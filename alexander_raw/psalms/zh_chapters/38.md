一位受苦者，身心俱受剧痛煎熬，又因朋友的疏远与恶人的怨毒而愈加沉重，他承认这一切都是自己罪孽所结的果子，并祈求藉着除去那根由，使这果效止息。

本篇包含三段彼此分明的诉苦，或说对他受苦境况的描述，其间以两次向神的呼求隔开，而全篇的首尾各有一段祷告。题注之后，第 1 节是开篇；继之以第一段祷告，第 2（1）节；然后是第一段诉苦，第 3-9（2-8）节；然后是诉诸神的全知，第 10（9）节；然后是第二段诉苦，第 11-15（10-14）节；然后是对神的盼望与信靠之辞，第 16（15）节；然后是第三段诉苦，第 17-21（16-20）节；最后是收束的祷告，第 22, 23（21, 22）节。

<span class="ax-vnum">1.</span> *一篇诗。大卫作。为提醒，*或作使人记念，*即*提醒神记起这受苦的人——神似乎已将他忘记；无疑也暗指同一动词常用于罪人痛悔时的自我省察。参列王纪上 17:18，以西结书 21:29（24），29:16，民数记 5:15。

<!-- PAGE 176 -->
<span class="ax-anchor" id="psalms-38-1"></span><span class="ax-vnum">2 <span class="ax-veng">(1).</span></span> *耶和华啊，不要在你的忿怒中责备我，也不要在你的烈怒中*（或*炽热的不悦中）惩治我。*那否定词的力量贯及两个分句。*责备，*不只是言语上的，更是行为上的，与另一分句中的*惩治，*即责罚、刑罚相对应。他并非如某些人所设想的，是在祈求刑罚从轻，或祈求出于慈爱而非出于忿怒的惩治，而是祈求脱离一切的刑罚，因为刑罚总是神不悦的表征。参看前文诗篇 6:2 (1) 的注释。

<span class="ax-anchor" id="psalms-38-2"></span><span class="ax-vnum">3 <span class="ax-veng">(2).</span></span> *因为你的箭已没入我中，你的手已沉落在我身上。*本节说明前一节祷告的缘由。*箭，*即尖锐的刑罚，如申命记 32:23、约伯记 6:4。两个分句的动词出自同一字根，一为主动形式，一为被动形式。*没入，*即穿透，并由此引申为*牢牢扎住，*虽然这一特定意思并未明言。*沉落在……身上，*即沉重地降下，或如英文译本所作，*重重地压住我。*参诗篇 32:4、39:11 (10)。

<span class="ax-anchor" id="psalms-38-3"></span><span class="ax-vnum">4 <span class="ax-veng">(3).</span></span> *因你的恼怒，我肉中无完好之处；因我的罪，我骨中无平安。* 这里开始更细致地描述前一节以笼统之词所指明的苦难。首先提到的是他肉身的痛苦，这痛苦既是神忿怒的记号，又是他自己罪的结果，而正是这罪惹动了那忿怒。*肉*与*骨*代表整个身体。译作*完好之处*的那个词，按其字形乃是一个表处所的名词，而非抽象名词（完好）。此词仅见于本处，以及以赛亚对本处的仿效（以赛亚书 1:6）。在那里如同在此处，身体被描绘为一整片伤痕，其中*无完好之处，即*没有一处不疼痛、不溃烂。——*因*，字面意为从……的面前、从……的面上、在……之前，此语原本用以表示在仇敌面前的惧怕或逃遁。*平安*可按广义理解为安泰、康健、身体无恙（见上文论诗篇 37:11）；但更可能是指严格意义上的平安，*即*安息，或脱离因疼痛而生的烦扰。

<span class="ax-anchor" id="psalms-38-4"></span><span class="ax-vnum">5 <span class="ax-veng">(4).</span></span> *因我的罪孽已漫过我的头；如同重担，它们重过我所能担。* 这是对前一节末了几句的铺陈。「我说我的罪，因为我对自己罪孽的感觉如今已难以忍受。」*漫过，*即越过，*即*超过、胜过、高过。*重过我所能担，*或作*比我更重，即*重得超出我所能承担。这里所指的不单是罪的后果，更是对罪本身的感觉，是罪咎的意识，他如今把这意识与自己一切的苦难联在一起。上半节用过去时，把那压倒一切的罪咎感表述为已然经历之事；下半节用将来时，则说到这过重的担子乃是仍要继续下去的。

<span class="ax-anchor" id="psalms-38-5"></span><span class="ax-vnum">6 <span class="ax-veng">(5).</span></span> *我的鞭伤发臭溃烂，都因我的愚妄。*头一个名词并非泛指*伤口*，乃指鞭打所起的肿胀。参以赛亚书 1:6。两个动词都指化脓，前者就其发出的恶臭而言，后者就其脓水的流溢而言。这或可按字面理解，指某一种肉身的苦楚；但似更自然的解法，是把它看作极度痛苦的比喻描写，其中并非毫无羞辱的成分。凡此一切，他都归于自己的*愚妄*或愚昧，而此字取其强义，即罪恶性的昏瞆与悖理。见上文诗篇 14:1 的注释。

<span class="ax-anchor" id="psalms-38-6"></span><span class="ax-vnum">7 <span class="ax-veng">(6).</span></span> *我扭曲了，我极其俯伏下去；终日哀悼而行。* 首词是被动形式，严格说是被扭转、被歪曲之意，别处用作比喻，指道德上的乖僻或悖谬（箴言 12:8，撒母耳记上 20:30），但此处用其本义，指身体因剧痛而扭曲，如以赛亚书 21:8。那俯伏或屈身，或出于同一缘由，或是哀伤的惯常表记。实则在这整段里，忧伤与身体疼痛这两重意思彼此交织。译作*哀悼*的那个词，本义是*黑，*更确切地说，是因尘土而发黑、满面污垢、形容憔悴，乃暗指古时东方人坐在尘土中、把炉灰撒在头上以为哀悼之记的风俗。参看上文诗篇 35:14 的注解。*极其。*希伯来文的说法意思是*直到很多，*或说以至于极。מאד 本是名词，意为*力量，*但除在「尽你的力量」这一成语中以外，一般用作副词，相当于中文的*非常、*大大地或极其。*我行走。*这个希伯来文动词是加强形式，近乎中文的*来回走动。*同一字根更强的加强形式，见上文诗篇 26:3、35:14 的注解；后一处也出现了此处译作*俯伏*与*哀悼*的那两个词。

<span class="ax-anchor" id="psalms-38-7"></span><span class="ax-vnum">8 <span class="ax-veng">(7).</span></span> *因为我的腰满了焦枯，我的肉体无一处完全。* 腰不但没有被脂油遮盖（约伯记 15:27），反倒满了干枯，字面意思是（某种）被烈火*烤焦*或*晒干*之物。在希伯来读者听来，这个词必然还会引出另一层意思，即*被藐视的、可鄙的*，同一词形在别处常表此义（*（例如*撒母耳记上 18:23，箴言 12:9，以赛亚书 3:5）。事实上，此处是否只取这一个意思，也未可知，因为*烤焦*之义在别处一向是用另一种分词形式来表达的（利未记 2:14，约书亚记 5:11）。无论取哪一种解法，英译本所给的意思（一种*可憎的疾病）*即便未曾明言，也已含在其中。末一分句重复上文第 4 节（3）的话，把他带回了起初出发的那一点。

<span class="ax-anchor" id="psalms-38-8"></span><span class="ax-vnum">9 <span class="ax-veng">(8).</span></span> *我麻木、伤损至极：我因心中的低吼而咆哮。麻木，*尤指因寒冷而然，即冻僵、凝冻、麻痹无觉。*伤损*或作破碎。同一动词在下文诗篇 51:18（17）中用以表达心灵的痛悔或破碎；但此处它取其本义，所描述的是身体的状况。参看上文诗篇 10:10 的注释。——*至极，*与上文第 7（6）节所用的是同一词组。末一分句中用了两个词，都指兽类的声音，与我们的 *roar*（咆哮）和 *growl*（低吼）大致相当。在以赛亚书 5:29 中，两个动词都用于狮子，在英文圣经里都译作 *roar*（咆哮）。关于此类比喻的用法，参看上文诗篇 22:2（1）的注释。此处的意思是：他那可闻的怨诉并非仅仅是身体困苦的表达，而是心灵与精神痛苦的表达。他口中的咆哮，只是他心中那低吼的回声。

<span class="ax-anchor" id="psalms-38-9"></span><span class="ax-vnum">10 <span class="ax-veng">(9).</span></span> *主啊，我一切的渴望都在你面前，我的叹息*（或*呻吟*）*并不向你隐藏。*这既是一句郑重的断言，表明他对自身苦难的陈述并无夸张或虚构，同时也说明何以不必再往下细述。「主啊，你知道我所求的是什么、我所需的是什么，知道我困苦的深、也知道我渴慕的切。」

<span class="ax-anchor" id="psalms-38-10"></span><span class="ax-vnum">11 <span class="ax-veng">(10).</span></span> *我的心跳动（或悸动）；我的力量离我而去（或衰竭）；我眼中的光*——*连它们也不与我同在。*此处开始他第二段哀诉，或说对自己所受苦难的悲叹描写，其中因他人行径而生的苦楚被置于显要地位。然而在这引言性的一节里，他先描述这苦难加于自己心情上的果效，然后才进而陈明其缘由。心的悸动表明剧烈的激荡，与力量的丧失、眼目的昏花并举，而眼目昏花正是常被提及的极度衰弱之兆。参看前面诗篇 13:4 (3) 的注释，并参诗篇 6:8 (7)、31:10 (9)、40:13 (12)。末一分句容许两种语法结构。一、「我的力量离我而去，（我眼中的光）也是如此；连它们也不与我同在。」二、「（至于）我眼中的光，连它们也不与我同在。」前者最合乎我们的惯用语，后者最合乎马所拉的断句，因为马所拉以一个停顿重音把*我眼中的光*与其前的动词和名词隔开。——*连它们，*字面作*它们也*。——「不但我的力量尽失，连我的视力亦然，连我的眼目本身亦然。」——*不与我同在，*不在我的掌握之中，不听我的使唤，已离我而去。类似的说法参看前面诗篇 12:5 (4) 的注释。——首一分句中的过去时，表明这悸动与衰弱已经由来已久，或至少已被充分地经历过了。

<span class="ax-anchor" id="psalms-38-11"></span><span class="ax-vnum">12 <span class="ax-veng">(11).</span></span> *我的爱人与我的朋友远离我的灾祸而立，我的邻舍远远地站着。*此处他开始倾吐人情凉薄所带来的痛苦，首先是那些他素来以为是朋友的人所给的。这些人被描写为*远远站开，*字面作*从面前，即*离开视线之外，如创世记 21:16 与以赛亚书 1:16 一样，而*不是对面而立，*仿佛含有敌对或仇视之意。他在此所控诉的乃是冷漠与弃置，这从平行的说法*远远地*可以看出，其字面作*从远处，*这是希伯来文常见的惯用语，即用严格表示运动或方向的词来表达某物所处的位置。例如创世记 2:8，那里的*在东边*，希伯来文作*从东边；*又如习见的说法「从*右手*或*左手*」，我们则说「*在*」或「*于*」其处。因着这种用法，本节虽然也未尝不可补出一词作「他们（望着）从远处而立」，却并无此必要。译作*邻舍*的那个词，指的是与人相近的人，或是居处相邻，或是血脉相亲，因此可以认为也包含了英文译本所用*亲属*一词的意思。除非本句中时态的变换全无意义——无论就其本身而言还是按类比推之，这都极不可能——那么末句便可理解为陈述一件已成的事实，而前句所料想的则不过是可能或必然、却仍属将来的事。仿佛他是说：「我的朋友们必然要远避这场苦难；不，他们早已远远地去了。」——*灾祸*在此泛指天意的或神所降下的打击，并非单指疾病，更不是指某一种特定的病症，如大麻疯——耶柔米竟在他的译本中径直引入了这个病名。参下文诗篇 39:11（10）的注释，并比较约伯记 19:21、以赛亚书 53:4。有人认为，福音书作者之一所记的事——那些从加利利跟随基督而来的妇女，以及*他一切熟识的人，*都远远地站着观看他被钉十字架——乃是暗引本节。见路加福音 23:49，并比较马可福音 15:40, 41。

<span class="ax-anchor" id="psalms-38-12"></span><span class="ax-vnum">13 <span class="ax-veng">(12).</span></span> *而那些寻索我魂的*（或*性命）已埋伏*（或*已设网罗）害我，那些寻求我受害的说出恶事，终日说出诡诈*（或*图谋）。* 当他的朋友与邻舍远远站开时，他的仇敌却忙于图谋毁灭他。*寻索我的性命，*与诗篇 35:4 及出埃及记 4:19 同。此语在大卫受逼迫的历史中尤为常见。见撒母耳记上 20:1，22:23，23:15，撒母耳记下 4:8，16:11。*寻索*这一概念在希伯来文中由两个全然不同的动词表达。首句可与诗篇 37:32 相比。——*恶事，*或说得更重些，*罪行。*见上文诗篇 5:10（9）。所指或是恶毒的密谋，或是毁谤，或兼指二者。末一动词可取其两种意义中的任一种（见上文诗篇 1:2，2:1，37:30），二者在此处皆合宜。*终日*（整日），即不住地。见上文诗篇 37:26。

<span class="ax-anchor" id="psalms-38-13"></span><span class="ax-vnum">14 <span class="ax-veng">(13).</span></span> *我却如聋* （人）*，必不听见，又如哑* （人） *必不开他的口。* 这既是他苦难的加重，也是他在苦难中忍耐的宣告。他不得不听他们的毁谤与亵渎，却仿佛未曾听见一般，因他既不能使他们缄默，也不愿与他们争辩。出埃及记 4:11 把*聋*与*哑*这两个希伯来词同样连用。这一句不仅其意念，连其措辞的形式，都被以赛亚在预言基督受苦的描写中沿用（以赛亚书 53:7）；而当我们的救主在大祭司面前「不言语」时（马太福音 26:62, 63），以及对罗马巡抚「一言不答」时（约翰福音 19:9），这句话似乎也正在他自己心中。

<span class="ax-anchor" id="psalms-38-14"></span><span class="ax-vnum">15 <span class="ax-veng">(14).</span></span> *我就像一个不听见的人，他口中也没有答辩*（或 *辩词）。*同一件事反复申说，是要把这受苦者的忍耐与宽容衬托得更加分明。*不听见，*字面是（是）*不听的。*若依我们的语法惯例，末句本当作*在他口中没有答辩的（人）。*「责备」这一义项是次生的，由「证据」或论据之义引申而来。参约伯记 13:6, 23:4。——这两节的意思是：他忍受仇敌的恶言，像一个无话可为自己辩白、也无话可回答他们辱骂的人。这虽挫伤了他的骄傲，因而加重了他的痛苦，但同时也正是信心与忍耐的凭据，这样便为下一节的自白铺平了道路。

<span class="ax-anchor" id="psalms-38-15"></span><span class="ax-vnum">16 <span class="ax-veng">(15).</span></span> *因为我等候你；你必应允，主，我的神！*他的缄默与忍耐，虽是他重大试炼的一部分，却并非出于软弱，乃是出于对神的信靠，以及对他诫命的顺服。（见上文，诗篇 37:7。）「我不回敬他们的毁谤与讥诮，因为我等候你为我伸冤，你也必如此行，你必定应允。」末一动词并非如公祷书译本所作的*为我答辩，*而是如别处一样，指*垂听*或*应允*我求脱困、求昭雪的祈求，无论这祈求是无声的还是出口的。见上文诗篇 5:2 (1) 的解说，并参诗篇 3:5 (4)、4:2 (1)、13:4 (3)、17:6、18:42 (41)、20:10 (9)、22:3 (2)、27:7、34:5 (4)。——*主，*此处不是*耶和华，*而是*亚多乃（Adhonai），*这一神名的本义即*主*或*主宰。*见上文，诗篇 2:4、22:31 (30)、35:17, 22, 23、37:13。——*我的神，*既是如此，就按约有责任垂听我。

<span class="ax-anchor" id="psalms-38-16"></span><span class="ax-vnum">17 <span class="ax-veng">(16).</span></span> *因为我说，恐怕他们向我夸胜；在我脚滑跌之际，他们*（已经）*高抬*（自己）*来敌对我。*他的安稳并非出于对危险的麻木，乃是出于对神的信靠。他并非毫无惧怕，恐怕仇敌向他夸胜，正如他们在他不过失足、尚未真正跌倒之时，便已存着这样的心。

<span class="ax-anchor" id="psalms-38-17"></span><span class="ax-vnum">18 <span class="ax-veng">(17).</span></span> *因为我因跛行*（乃）*预备好了，我的忧愁常在我面前。*本节为仇敌的夸胜说明缘由，即他确实处在危险之中。*预备跌倒*或*瘸行，即*他那原本顺遂的路程，时时可能被什么打断。参见前面诗篇 35:15 的注释。这种说法并不排除他实际上正在跛行的意思，倒是更暗示了这一点。仿佛他说：「极小的缘故就足以使我跌倒、使我瘸行。」*忧愁*或*悲伤*在此似乎是以结果代原因，指那引起忧愁的事。我时时都把自己最深的苦难看在眼前。

<span class="ax-anchor" id="psalms-38-18"></span><span class="ax-vnum">19 <span class="ax-veng">(18).</span></span> *因为我的罪孽我要承认，我要因我的罪而忧虑。*按我们的语言习惯，这等于说：我必须承认我是有罪的；我有理由为我的罪忧虑。

<span class="ax-anchor" id="psalms-38-19"></span><span class="ax-vnum">20 <span class="ax-veng">(19).</span></span> *我那致死的仇敌强盛，虚妄恨我的人增多*（或作*无故）。*有人并不取*致死的*之意，而在此看出相反的观念，即*活着的*：*我的仇敌*（是）*活着的*（或*活的），他们强盛。*或作，*我那活着的仇敌强盛。*但 חיים 是希伯来文中表示*生命*的常用词；既然 שנאי שקר 意为*我那虚谎的仇敌*，איבי חיים 也可意为*我那生命的仇敌*，即恨我性命、欲夺我命的人。参上文诗篇 17:9 的 איבי בנפש。—— *虚妄恨我。*参诗篇 35:19，69:5（4）。

<span class="ax-anchor" id="psalms-38-20"></span><span class="ax-vnum">21 <span class="ax-veng">(20).</span></span> *并* （那些）*以恶报善的*——*他们要因我追求良善而与我为敌。* 前一分句似当归属上文，以完成对他仇敌的描述：「那些无故恨我的，并以恶报善的。」参诗篇 35:12-16。*与我为敌，* 即作我的仇敌。此希伯来动词乃 *Satan*（撒但）一名的字根，撒但即神与人的仇敌或对头。从其字源看，这动词似乎特指阴险诡诈的敌意。——末一分句中的介词本义为 *在……之下，* 继而为 *代替，* 更罕见地作 *作为回报，* 此处即取此义。*作为我追求良善的回报，即* 热切殷勤地力求为善行义。单单这一点就足以激起他们的仇恨。

<span class="ax-anchor" id="psalms-38-21"></span><span class="ax-vnum">22 <span class="ax-veng">(21).</span></span> *不要离弃我，*（哦）*耶和华！*（哦）*我的神，不要远离我！*他两次陈明自己的急迫需要之后，此时又回到本篇起首的哀诉语调。本节的祈求在诗篇中屡见不鲜。参看上文诗篇 10:1，13:2 (1)，22:2 (1)，35:22。然而最可注目的平行经文仍是诗篇 22:20 (19)。

<span class="ax-anchor" id="psalms-38-22"></span><span class="ax-vnum">23 <span class="ax-veng">(22).</span></span> *快来帮助我，*（哦）*主啊，我的拯救！* 第一个分句的字面意思是*快来作我的帮助（或为我的帮助而急速前来）。* 同样的词构成诗篇 22:20 (19) 的末一分句。*我的拯救，*即我的拯救者、我的救主。这一呼求的方式与诗篇 35:3 中的祷告极为相似：*对我的魂说，我是你的拯救。*
