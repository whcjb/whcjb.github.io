<span class="ax-vnum">1,</span> *一首歌。一篇诗。大卫的。*此篇并非原创或独立的作品，乃是由另外两篇已经解释过的诗篇辑录而成。引言部分，即第 2-6 节（1-5 节），与诗篇 57:8-12（7-11）实质相同；诗篇的主体部分，即第 7-13 节（6-12），则与诗篇 60:7-14（5-12）相同。若设想此处出于抄本讹误或后来的窜乱，比起诗篇 18 篇、53 篇、70 篇的情形更难成立。迄今所提出最好的解释是：大卫自己将这些段落合并起来，作为一组三联诗（诗篇 108-110 篇）的基础，以适应教会在诗篇 57 篇与 60 篇写成之后某一时期的使用。此处的注释将只限于相异之处，一如诗篇 53 篇与 70 篇的处理。

<span class="ax-anchor" id="psalms-108-1"></span><span class="ax-vnum">2 <span class="ax-veng">(1).</span></span> *我的心坚定，神啊，我的心坚定；我要歌唱弹奏*——*也用我的荣耀。*参上文诗篇 57:8（7）的注释。此处所加的话，*也用我的荣耀，*与那篇诗下一节的首句相应，*我的荣耀啊，醒起！*

<span class="ax-anchor" id="psalms-108-2"></span><span class="ax-vnum">3 <span class="ax-veng">(2).</span></span> *琴与瑟啊，醒来！我要唤醒黎明（或早晨）。* 见上文诗篇 57:9 (8) 的注释。唯一的不同即前面已提及的那一处，就是此处略去了*我的荣耀啊，醒来*这几个字，而以第 2 (1) 节的末句代之。

<!-- PAGE 459 -->
<span class="ax-anchor" id="psalms-108-3"></span><span class="ax-vnum">4 <span class="ax-veng">(3).</span></span> *耶和华啊，我要在列国中称谢你，我要在万民中歌颂你。* 见前，诗篇 57:10（9）。唯一的差别是以*耶和华*之名代替了 *Adhonai*（我主），这一改动在英文译本中几乎看不出来。

<span class="ax-anchor" id="psalms-108-4"></span><span class="ax-vnum">5 <span class="ax-veng">(4).</span></span> *因为从诸天之上而来是大的*（乃是）*你的慈爱，直到云霄是你的信实。*参看前面诗篇 57:11（10）的注释。唯一的变动是把（עַד）*直到*换成了*（מעל）从……之上*，显然是要引出神的慈爱降临于人的意思。

<span class="ax-anchor" id="psalms-108-5"></span><span class="ax-vnum">6 <span class="ax-veng">(5).</span></span> *神啊，愿你高过诸天，愿你的荣耀高过全地。* 参看上文诗篇 57:12（11）。唯一的差别，是在第二分句开首加上了连系词*和*。

<span class="ax-anchor" id="psalms-108-6"></span><span class="ax-vnum">7 <span class="ax-veng">(6).</span></span> *为要使你所爱的*（人）*得蒙拯救，求你用右手施行拯救，并垂听*（或*应允）我们。*参看上文诗篇 60:7(5) 的注释，本节与那里各点全同，连末一词上的旁读（keri，即马所拉旁注所当读之文）或异文也不例外（*我*作*我们*）。

<span class="ax-anchor" id="psalms-108-7"></span><span class="ax-vnum">8 <span class="ax-veng">(7).</span></span> *神在他的圣洁中已经说话*（因此）*我要欢胜，我要分开示剑，疏割的山谷我要丈量。* 见前，诗篇 60:8（6），本节与该处完全相合。

<span class="ax-anchor" id="psalms-108-8"></span><span class="ax-vnum">9 <span class="ax-veng">(8).</span></span> *基列属我，*（归于）*玛拿西属我，以法莲是我头上的力量，犹大是我的立法者。*见前，诗篇 60:9 (7) 的注释。唯一的差异在于，本节于 *基列* 之后省去了那个 *和* 字。

<span class="ax-anchor" id="psalms-108-9"></span><span class="ax-vnum">10 <span class="ax-veng">(9).</span></span> *摩押*（是）*我的洗脚盆；我要向以东抛我的鞋；我要向非利士高声欢呼。*参上文，诗篇 60:10（8）。本节末尾是全篇最实质的一处异文，然而这显然不是偶然，也非出自后人之手，而是出于原作者有意为之。*我要高声欢呼，*作为胜过被征服之敌的凯旋之声。

<span class="ax-anchor" id="psalms-108-10"></span><span class="ax-vnum">11 <span class="ax-veng">(10).</span></span> *谁要领我*（到）*那坚固城！谁引领*（或*曾引领）我上以东去？*见前，诗篇 60:11（9）。唯一的差异是以一个同义词替换另一个同义词，用以表达「坚固城」的意思。

<span class="ax-anchor" id="psalms-108-11"></span><span class="ax-vnum">12 <span class="ax-veng">(11).</span></span> （岂）*不是神已将我们丢弃，且不与我们的军队同出么？*参上文，诗篇 60:12 (10)。唯一的差异在于略去了那强调性的代词*你，*在平行的那处经文中是明言的，而在我们眼前这一处只是隐含的。有些解经者认为此处由第三人称突然转为第二人称：*岂不是神*——（就是你，曾）*将我们丢弃，*……

<span class="ax-anchor" id="psalms-108-12"></span><span class="ax-vnum">13 <span class="ax-veng">(12).</span></span> *求赐* 我们 *脱离仇敌的帮助*（或作：脱离患难的帮助）；*并且*（更因为）*人的拯救是虚空的，* 意思是人所施予的拯救。参看前面诗篇 60:13 (11) 的解说，那里与此处完全相合。

<span class="ax-anchor" id="psalms-108-13"></span><span class="ax-vnum">14 <span class="ax-veng">(13).</span></span> *在神里面我们要得（即* 赢得或聚集）*力量，他必踏下*（或*践踏）我们的仇敌*（逼迫者或压迫者）。见前，诗篇 60:14（12）的注释；那一节与我们眼前这一节之间毫无丝毫差别。
