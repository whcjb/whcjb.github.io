<span class="ax-vnum">1.</span> *交与伶长。一篇诗。大卫作。* 读这篇诗，我们觉得自己不但被带回大卫的时代，更是被带回扫罗逼迫的那段岁月，诗中的意象显然取自那时。除却其中的战斗口吻、刚健的简洁、与大卫诸诗在字句上的吻合（而又兼具卓然的独创性）之外，连结构本身也是大卫式的，呈出那为人熟知的次序：哀诉，第 2-6 节（1-5 节）；祈求，第 7-9 节（6-8 节）；以及笃定的期待，第 10-14 节（9-13 节）。这几样特征如此清楚地标明了此诗的来历，甚至无须倚靠题注；因此，它之所以置于此处，除了前面已经说过的那个假设之外，别无可解：这些古老的诗篇被编入了一组年代较晚的诗中，其在汇集中的位置，并非按各篇自身的古老程度来定，乃是按它们所被编入的那整组或整套诗篇的年代来定。与紧接在前的几篇一样，此篇大概也是大卫在领受那伟大的弥赛亚应许之后所作，且直接指向那应许。

<span class="ax-anchor" id="psalms-140-1"></span><span class="ax-vnum">2 <span class="ax-veng">(1),</span></span> *求你搭救我，耶和华啊，脱离那恶人；脱离强暴（们）之人，你必保守我。*这是真正大卫诗篇中极为常见的那一类描画之一，其原型似乎是扫罗所提供的。参诗篇 52 篇。前一个*人*是通称（אָדָם），后一个则是指个体的称谓*（איש）*，不过在此二者似乎是当作同义词使用的。从直接的祈求不着痕迹地转入笃定的期待，正是大卫诗篇的特色。*强暴之人*是另一个他所爱用的说法。见前文诗篇 18:49（48）的注释，并参平行经文撒母耳记下 22:49，那里用的是复数形式（强暴们），与我们眼前这一节相同。

<span class="ax-anchor" id="psalms-140-2"></span><span class="ax-vnum">3 <span class="ax-veng">(2).</span></span> *图谋恶事在* （他们的）*心中的人；终日他们聚集* （为了）*争战。* 前一节虽指向扫罗，所描写的却是整整一类人，这从本节的复数形式即可看出。*图谋，*默想、筹划、设想。*恶事，*尤指加于他人身上的恶，通行译本作 *mischiefs*（祸害）甚为得当。末句另有一种解法，为若干释经者所取，即 *终日他们与争战同住* （或 *在争战之中），即* 时常卷入其中、忙于其事。这一动词（גור）的此种用法，可由诗篇 5:5（4）、105:23、125:5 得到支持。但诗篇 56:7（6）、59:4（3）的类比，决定性地支持前一种解释。参诗篇 31:14（13），35:15，以赛亚书 54:15。

<span class="ax-anchor" id="psalms-140-3"></span><span class="ax-vnum">4 <span class="ax-veng">(3).</span></span> *他们使舌头尖利如蛇；虺蛇的毒*（在）*他们嘴唇之下。细拉。* 不是说（磨舌）*如蛇*（所为），而是说（怀恨或含毒）*如蛇一般*。参看上文诗篇 64:4 (3) 的注释。末一分句可比较诗篇 10:7、58:5 (4)。此处表示*蝰蛇*或*虺蛇*的词仅见于本节。就解经而言唯一要紧的一点是：它指一种有毒的蛇，因而是对另一分句中那一般性说法的具体指明。

<span class="ax-anchor" id="psalms-140-4"></span><span class="ax-vnum">5 <span class="ax-veng">(4).</span></span> *求你保守我，耶和华，脱离恶人*（人）*的手；脱离强暴的人，你必保全我，他们图谋推倒我的脚步。*这是第 1 节祷告的另一种说法。末句可比较诗篇 35:5，36:13 (12)，56:14 (13)，118:13。

<span class="ax-anchor" id="psalms-140-5"></span><span class="ax-vnum">6 <span class="ax-veng">(5).</span></span> *高*（者）*为我暗设网罗，又有绳索*——*他们在路旁张开了网*——*他们为我布下了机槛。细拉。*这里不过是把大卫在别处用以描摹他所爱用的一个比喻的各样措辞汇集起来，仿佛他看见自己的危难在将来重现。*高者，即*骄傲或狂傲之人。*在旁边，*字面作*手，*正如我们说「在左右手」。译作*路*的那个词，按其字源，指的是车行之道，即车轮碾出的辙迹。

<span class="ax-anchor" id="psalms-140-6"></span><span class="ax-vnum">7 <span class="ax-veng">(6).</span></span> *我曾对耶和华说，我的神*（是）*你；求耶和华侧耳听*（听）*我恳求的声音。*本节的各个组成部分在大卫的诗篇中都屡见不鲜。第一句可比较诗篇 16:2，31:15（14）。第二句可比较诗篇 5:2, 3（1, 2），17:1，28:2, 6（1, 5），31:23（22），39:13（12），53:4（3）。

<span class="ax-anchor" id="psalms-140-7"></span><span class="ax-vnum">8 <span class="ax-veng">(7).</span></span> *耶和华，主，我救恩的力量；在争战的日子你遮盖了我的头。*我立约的神与我的主宰，他的大能施行拯救。*头*字前面有一个介词（ל），即*你作了遮盖*（或*给予庇护）于（或为）我的头。*争战的日子，字面意思是兵器或军械的日子，*即*动用兵器的那一日。本节可与诗篇 5:12(11)、60:9(7)、62:2, 12(1, 11)、139:13、撒母耳记上 28:2 相比较。

<span class="ax-anchor" id="psalms-140-8"></span><span class="ax-vnum">9 <span class="ax-veng">(8).</span></span> *不要应允，耶和华，恶人的心愿*——*不要使他的诡计得逞*——*他们就要高举自己。* 不要使……得逞，不容其顺遂；字面是不要拉出，*即*拉到成功的结局。末句说明他们一旦得逞会有何后果：他们就要自高，或说高举自己。此节可与诗篇 27:12, 31:14 (13), 37:12, 66:7 (6), 申命记 32:27 相比较。

<span class="ax-anchor" id="psalms-140-9"></span><span class="ax-vnum">10 <span class="ax-veng">(9).</span></span> *围绕我之人的头*——*他们嘴唇的毒害必遮盖他们。* 这独立主格回指第 8（7）节中诗人的头得蒙遮盖。当我的头被神的保护所遮盖时，那围困我之人的头却要被他们的谗谤与侮辱所惹起的毒害之后果或刑罚所遮盖。或者说，他们的嘴唇给别人带来的祸患，必归到他们自己身上。参诗篇 7:17（16）。*围绕我之人，*或作名词，*我的周围之人，*如列王纪下 23:5。按类比与用法，这分词本可解作*使我转回*或*退却*（耶利米书 21:4），在此也讲得通：那曾驱我退后之人的头必被遮盖……

<span class="ax-anchor" id="psalms-140-10"></span><span class="ax-vnum">11 <span class="ax-veng">(10).</span></span> *炭火必被倾落在他们身上；他必使他们坠入火中，又坠入深水，*（从那里）*他们必不能起来。*头一个名词在*希伯来文*中一贯指燃烧的炭或炭火。参上文诗篇 18:13, 14（12, 13）的注释。*必被倾落*是 קרי（keri，即旁注的读法），无疑是为了缓和正文读法的生硬与晦涩；正文作*他们必倾落*或*抖落*，乃是一种不定人称或无人称的结构，其意实与被动相当。在本句的后半，这动作则归于神自己。*深水*所对应的是一个仅见于此处的希伯来词，有人以为它的意思是*深坑*或掘成的坑穴。上面所取的头一个意思，是依据阿拉伯文的类比而立的。

<span class="ax-anchor" id="psalms-140-11"></span><span class="ax-vnum">12 <span class="ax-veng">(11).</span></span> *舌头的人必不在地上坚立，*（也）*不（坚立）强暴的人，恶（人）*——*他必追猎他直到毁灭。*口舌放纵、善于毁谤之人（雅各书 1:26）必不得长久安坐于兴盛之境。参上文论诗篇 101:7、102:29（28）。其后数语可有不同的解法：*恶毒强暴的人，*或者，不理会重音符号，译作*强暴的人，恶必追猎他，……*按后一种解法，神是该动词的主语，正如第 11（10）节中第二个动词的主语一样。*直到诸般毁灭，*用复数形式表示充盈与完全。另有人译作*藉着击打，即*连续不断的击打；又有人译作*急速地，*此说与该动词字根的用法颇为吻合。参历代志下 26:20，以斯帖记 3:15、6:12、8:14。

<span class="ax-anchor" id="psalms-140-12"></span><span class="ax-vnum">13 <span class="ax-veng">(12).</span></span> *我知道耶和华必为受苦的人伸张公义，为贫穷人施行审判。*参诗篇 9:5, 17（4, 16）。字面作：*受苦者的权利，贫穷人的审判。*

<span class="ax-anchor" id="psalms-140-13"></span><span class="ax-vnum">14 <span class="ax-veng">(13).</span></span> *惟有义人要称谢你的名，正直人必坐在你面前。*惟有义人才有称谢的缘由。因此不必离开希伯来小品词（אַף）的本义。参看前面诗篇 73:1 的注释。*坐在你面前，*如同你的朋友、你的客人，或蒙恩宠的仆人。或许其义为*（登位）坐在你面前。*参马太福音 19:28。有些人认为其义是：*必住（在地上）在你面前，即*在你的保护与看顾之下。参诗篇 21:7（6）、41:13（12）、56:14（13）。
