<!-- PAGE 353 -->
<span class="ax-vnum">1.</span> *交与伶长。用*（或*按）迦特。亚萨作。* 关于*迦特*（Gittith）一词可能的含义，见上文诗篇 8:1 的注释。既无相反的证据，这题注中的亚萨就必须认定为大卫同时代的人。见上文诗篇 50:1 的注释。本篇大概是预备在逾越节时歌唱的，因为它由三部分构成：劝人为以色列蒙拯救出埃及而赞美神，第 2-8 节（1-7）；控诉他们的忘恩负义，第 9-13 节（8-12）；以及一幅热切的图画，描绘顺服与忠信可望带来的美好果效，第 14-18 节（13-17）。

<span class="ax-anchor" id="psalms-81-1"></span><span class="ax-vnum">2 <span class="ax-veng">(1).</span></span> *你们要向神我们的力量高声歌唱，向雅各的神欢呼！*第一个动词本是使役形，意为*使*或*叫人欢乐。*参看上文诗篇 65:9 (8)，并比较申命记 32:43；在那处与此处，它通常被认为是不及物的。平行的那个动词是一个泛称，既用于呼喊，也用于号筒之声。参看上文诗篇 41:12 (11)、47:2 (1)。*神我们的力量，*即我们大能的保护者与拯救者；他正是以这一身份，在拯救以色列出埃及一事上特别显明了自己——那也是本篇的主要题旨与内容——并由此证明自己确是雅各立约的、护佑的神。

<!-- PAGE 354 -->
<span class="ax-anchor" id="psalms-81-2"></span><span class="ax-vnum">3 <span class="ax-veng">(2).</span></span> *扬起歌声，击鼓，甜美的琴连同琵琶*（或 *瑟）。击，*字面意为 *给，即* 发出其声，或奏响它。参看上文诗篇 46:7(6)、68:34(33)、77:18(17) 的注释。这当理解为乐师们在实际演奏之际彼此间的相互劝勉。

<span class="ax-anchor" id="psalms-81-3"></span><span class="ax-vnum">4 <span class="ax-veng">(3).</span></span> *在月朔吹角，当满月，在我们节期之日。* 这「月」，按卓越之义而言，乃是正月，即守逾越节的那一月（出埃及记 12:1, 2）。此处与利未记 23:5 的希伯来原文一样，先举出月份，再指明其中的某一日。这后一点并非无关紧要的情形，可见于以下事实：当人补守逾越节时，乃是在另一月的同一日（民数记 9:9-14）；而耶罗波安更改住棚节时，也是把它移到八月的同一日（列王纪上 12:32）。如此选定作宗教守节之用的时候，似乎就是满月之时。可比较箴言 7:20 的原文与旁注的译法。*我们节期之日*或筵宴之日，*即*逾越节的大日。*我们的节期，*若是着重语，意在把它描述为一个具有民族特色的严肃聚会。此节期上持续使用器乐，可见于历代志下 30:21。

<span class="ax-anchor" id="psalms-81-4"></span><span class="ax-vnum">5 <span class="ax-veng">(4).</span></span> *因为这是给以色列的一条律例，*（是）*这，是一项权利，*（属）*雅各的神的。*守这节期并非仅是习俗或约定俗成的安排，乃是百姓当尽的义务，也是归于耶和华作他们神的本分。第一分句末尾的人称代词（它）带有强调的意味，中文里用指示代词来表达更为贴切。*一项权利，jus（权利），*即他按理当得的。

<span class="ax-anchor" id="psalms-81-5"></span><span class="ax-vnum">6 <span class="ax-veng">(5).</span></span> （作）*约瑟中的一个法度，他设立了它，在他出来经过埃及地的时候。我未曾晓得的言语，我正听见。* 除了*法度*常用作*律法*之意，如诗篇 19:8（7）、60:1、78:5、80:1，此词按其严格意义也正适用于逾越节，作为出埃及的永久纪念。此处以*约瑟*代*以色列*，是因他在寄居埃及期间的卓越地位（创世记 49:26，出埃及记 1:8）。*他设立了它，即*神设立或命定这节期。*在他出来的时候，*指他起行之时，或正当起行之际。*经过埃及地*一语含有通常的说法，即*从*那地或*出*那地（出埃及记 34:18），但另有公开与凯旋的意味。以色列人在出埃及时，走过了埃及境内相当长的一段地带，同时也仿佛是从被贬抑、惊惶的埃及人头上走过。参出埃及记 14:8，民数记 33:3。*言语，*字面作*唇，*是指方言或语言的常见惯用语。按上文所给这末句的译法，它指随后神的话语，形容百姓当时听见了他们素来未曾听过的话。然而有些释经者认为，此句是以其中一桩最显著、最痛苦的情形来描述百姓在埃及的光景，即他们住在异族、也就暗指异教之民中间。这与*唇*在他处的比喻用法更为相合，并有申命记 28:49、耶利米书 5:15、诗篇 114:1 的类比有力地支持。参我在以赛亚书 33:19 的注释。如此理解，此句可译作：（在那里）*我听见我所不明白的言语。*第一个动词用将来时形式，乃是着眼于事件实际发生的时间，说话者在此把自己置身其中。

<span class="ax-anchor" id="psalms-81-6"></span><span class="ax-vnum">7 <span class="ax-veng">(6).</span></span> *我使他的肩头离了重担；他的手脱离筐子。*头一个动词严格说来是*我使*（或*容许）其离去。*这意思取自出埃及记 6:6, 7。所指的无疑是搬运砖与灰泥之事，而下半句中的罐或筐，正是为此所用的器皿，其形制曾在底比斯的一座墓室中见有绘像。*脱离，*字面作「过去」。

<span class="ax-anchor" id="psalms-81-7"></span><span class="ax-vnum">8 <span class="ax-veng">(7).</span></span> *你在急难中呼求，我便搭救你；我还要*（再）*在雷的隐密处应允你；我要在米利巴水旁试验你。* 雷的隐密处或藏身之所，就是颁布律法时笼罩在西奈山上、满载风暴的黑云（出埃及记 20:18）。这里是预先提及或预言此事，正如也预言了百姓在米利巴的发怨言（出埃及记 17 章；民数记 20 章），以此作为他们不信与悖逆的一个显著例证。照此理解，本节仍是神自己在出埃及那一紧要关头所说的话。按照前面已经提过的另一种解经假设，此处说话者骤然更换，而本节中的将来时动词则当解作历史现在时。

<span class="ax-anchor" id="psalms-81-8"></span><span class="ax-vnum">9 <span class="ax-veng">(8).</span></span> *听啊，我的民，我要向你作见证；以色列啊，但愿你肯听我。* 本节与诗篇 50:7 极为相似。末一分句中的条件小品词（若）有人取作愿望语气，作*但愿你肯听，*或照英文的说法，作*你若肯听就好了。*用以证明此种用法的例证，有诗篇 95:7、139:19，箴言 24:11。另有释经者否认有此用法，而视本处为一处顿绝（aposiopesis），*你若肯听我*（你就有福了），正如出埃及记 32:32、路加福音 19:42 所见。参看上文诗篇 27:13 的解释。但比这两种都更简明、更自然的结构，是把这一分句作为前一分句所言之条件：「你若肯听我，我就要说。」

<span class="ax-anchor" id="psalms-81-9"></span><span class="ax-vnum">10 <span class="ax-veng">(9).</span></span> *在你中间必不可有外邦的神，你也不可敬拜外族的神。* 这里所用的神名是指能力的那一个。「除了那真实的全能者以外，你不可承认别的全能者。」这些表禁止的将来时语气，比某些译本所表达的更为强烈，即*不要容外邦的神在你中间，即*在你当中、在你们之中。*外邦的神，*就是与耶和华、与以色列相疏离的神。*敬拜，*字面意思是俯伏或屈身下拜。*外族的神，*就是属于异域、或属于外邦之地的神，换言之，即异教的神祇。参上文诗篇 18:45, 46（44, 45）的注释。此处暗含的具体理由，即申命记 32:12 所明言的那一条。其总的原则，与第一条诫命（出埃及记 20:3，申命记 5:7）所陈明的相同。

<span class="ax-anchor" id="psalms-81-10"></span><span class="ax-vnum">11 <span class="ax-veng">(10).</span></span> *我是耶和华你的神，是把你从埃及地领上来的；你要大大张口，我就给你充满。*前一节诫命的理由，于此明白宣告出来。*那*（位）*使你上来的，*或说使你得以上来的。*你要大大张口，*字面作*使它张大。*这里以食物的供给代表一切需用的供给。此处提出当专靠耶和华的理由是：祂不但曾把他们从埃及领出来，也绰绰有余地能在迦南和旷野中供养他们。

<span class="ax-anchor" id="psalms-81-11"></span><span class="ax-vnum">12 <span class="ax-veng">(11).</span></span> *我的百姓却不听我的声音，以色列也不依从我。* 神既已被引入作说话者，其后事件的叙述便仍归于他口中。*我的百姓*一语意在加重他们悖逆的罪责。*我的声音*特指第 7-11（6-10）节中的警戒，那被视为在出埃及之时所发。然而有些释经者把全节作一般性的描述。*依从我，*即默从我的要求，甘愿遵行我的旨意。其措辞形式与申命记 13:9（8）中的相同。

<span class="ax-anchor" id="psalms-81-12"></span><span class="ax-vnum">13 <span class="ax-veng">(12).</span></span> *我就任凭他们随自己心里的败坏；他们照自己的计谋而行。*第一个动词严格说来意思是*我打发他们出去，即*去行在他们自己心里的败坏之中。译作*败坏*的那个词，别处只见于申命记 29:18，以及耶利米对该处的仿用（耶利米书 3:17，7:24，9:13，11:8）。按叙利亚文的类比，并按最可能的希伯来文词源，它本义是*刚硬，*与新约的*πώρωσις*（刚硬）相应（马可福音 7:5，罗马书 11:25，以弗所书 4:18）。*照自己的计谋，*即在推行他们自己邪恶的意图与不智的筹划之中。末句的动词可以读作一种容让或许可，只要把这话归到更早的一个时间点上：「我任凭他们……（说）任他们照自己的计谋而行吧。」至于此处所宣告的这种可畏的报应，参箴言 1:30, 31，罗马书 1:24，帖撒罗尼迦后书 2:10, 11。

<span class="ax-anchor" id="psalms-81-13"></span><span class="ax-vnum">14 <span class="ax-veng">(13).</span></span> *我的民若肯*（只要）*听我，*（且）*以色列肯行在我的道中。*开头的条件词虽与第 9 节（8）所用的不同，其句法构造却相同，只是带有更强的愿望语气。听从神的教训与诫命，含有受教顺服之心的意思。行在他的道中，即照他所喜悦、所吩咐的而行。

<span class="ax-anchor" id="psalms-81-14"></span><span class="ax-vnum">15 <span class="ax-veng">(14).</span></span> *不多时我就使他们的仇敌屈服，又向他们的敌人伸回我的手。*希伯来文头一个短语严格说来意为*如同一点，*其用法却与英文的*「再过一点时候」，即*不多时相同。见上文诗篇 2:12 的注释，并参诗篇 73:2。*收回手，*在诗篇 74:11 意为撤回或按住不动；但在此处所传达的却是相反的意思，即重新动手，有人认为这是特指从前危难之际它所起的作用，第 8 节（7）。这短语本身不过指动作而言；敌对或毁灭性的动作之意，是由上下文带出来的。参我在以赛亚书 1:25 的注释。

<span class="ax-anchor" id="psalms-81-15"></span><span class="ax-vnum">16 <span class="ax-veng">(15).</span></span> *恨耶和华的人必向他谄媚屈服，他们的时候必存到永远。*前一句意在提示一个安慰的思想：神子民的仇敌就是神自己的仇敌。因此，无须照申命记 33:29（本句即由此借来）把*他解作以色列*或*我的民，*。前后文的复数形式使这样的解法不甚自然；况且神与他子民的利益原是一致的，两种解法的意思相同。此处的*谄媚屈服*，是指向征服者或占上风的仇敌献上虚伪的顺从。参看上文诗篇 18:45（44）、66:3 的注释。*他们的时候，即*以色列作为蒙拣选之民的继续存留。参撒母耳记下 7:24。

<span class="ax-anchor" id="psalms-81-16"></span><span class="ax-vnum">17 <span class="ax-veng">(16).</span></span> *他必以上好的麦子养他，并从磐石中以蜂蜜使他饱足。* 首个动词是使役式，意为*要让*（或*使）他吃。* 麦子的脂油，即其最肥美的部分或最上等的品质，这又是把动物的属性移用于植物之物。参看上文诗篇 81:16(15) 的注解。「从磐石而来的蜂蜜」，有人以为指野蜜；另一些人则更有可能地认为，是神迹所供给的蜂蜜，正如旷野中从磐石而出的水一样。这一切强烈的措辞都取自申命记 32:13, 14，诗篇 147:14、以赛亚书 34:16 也同样加以仿效。麦子与蜂蜜，按着自然而原始的联想，在此代表人生所需的必需品与丰美之物，而这二者又转而代表最高的享受与昌盛。英译本把这四节经文全归于过去的时间：*曾听从、曾遵行、本必制伏、本必屈服、本必长存、本必养活、本必使之饱足。* 就以赛亚书 48:18 那处相似的经文而论，这实在是正确的句法；但在那里，条件或祈愿的虚词是与过去时连用的，而非像此处与将来时连用，这就造成了句法上本质的差别。见诺德海默（Nordheimer）《希伯来文法》§ 1078。
