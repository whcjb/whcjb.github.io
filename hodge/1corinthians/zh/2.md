<p class="title-block-h2" style="text-align:center; font-size:16px; font-weight:bold; margin:18px 0 12px;" markdown="1"><span style="color:#006411">第二章</span></p>

使徒在此继续为自己传道的方式辩护。在第1至5节，他表明自己所行的正合乎前段所立的原则。在第6至9节，他表明福音才是真智慧。至于这知识的根源——无论就其外在的启示而言，还是就其被属灵地领悟而言——皆在于圣灵，见第10至16节。

<p style="text-align:center" markdown="1"><span style="color:#0000d4">**保罗继续为其传道方式辩护，第1-16节**</span></p>

既然神已定意不藉人的智慧、而藉福音拯救世人，故保罗在哥林多出现时，既不以雄辩家的身分，也不以哲学家的身分，乃单单作一个见证人，第1、2节。他毫不自恃，其成功全然仰赖圣灵的明证，第3、4节。信心的真正根基不是理性，乃是神的见证，第5节。

他所传的虽非人的智慧，却是神的智慧，是人的理性无从发现的（6-9节）。启示这神圣智慧者乃是圣灵，惟独祂堪作此启示，因为惟有祂知道神隐秘的旨意（10-12节）。使徒在传达这从圣灵而来的知识时，所用的言语也是圣灵所指教的（13节）。所传达的知识虽是属神的，所用的言语虽是合宜的，却不是凭着高言大智；或作 <span style="color:#800000">*宣讲*</span>，"我来不是用属灵的宣讲"（14-16节）。

**1.** <span style="color:#800000">*弟兄们，从前我到你们那里去，并没有用高言大智对你们宣传神的奥秘。*</span>

<span style="color:#800000">*我……也*</span>，即 <span style="color:#800000">*因此我*</span>——「既然神已明明显出祂的旨意，是要弃绝世上的智慧，而以十字架作为拯救的方法。」

<!-- PAGE 50 -->
<span style="color:#800000">*高言或智慧*</span>。此处言语与智慧（<span style="color:#0000d4">λόγος</span> 与 <span style="color:#0000d4">σοφία</span>）既分别而言，前者大概指其传道的方式或形式，后者则指其内容。他出现在他们中间，既非以修辞家的身分，也非以哲学家的身分。此句或可与<span style="color:#800000">*到*</span>（came）一词相连，作“我到你们那里，并没有用高言”；或与<span style="color:#800000">*传*</span>（declaring）一词相连，作“我到你们那里，并非用高言传讲……”。前一种连法通常更为可取，不仅因为词语在句中的位置如此，也因意思如此。保罗的意思不仅仅是说，他传讲神的见证时未用修辞或哲学的方式；而是说，他所传讲的并非人的智慧，乃是神的启示。

<span style="color:#800000">*神的见证*</span>一语，或指保罗为神所作的见证，或指神自己的见证，即神所启示、所证实为真的事。按后一意义，“神的见证”即是福音，正如提摩太后书 1:8 所用者。后一种解释最合上下文，因为在这几章中，保罗始终以理性所教导的与神所教导的相对照。他出现于人前，并非作人间智慧的教师，乃是宣告神所启示的事。

**2.** <span style="color:#800000">*因为我曾定了主意，在你们中间不知道别的，只知道耶稣基督并他钉十字架。*</span>[^f3]

<span style="color:#800000">*因为*</span>一词有确证之意。「我来并不用高言大智，<span style="color:#800000">*因为*</span>我曾定了主意」等等。此句中的否定词，或可与<span style="color:#800000">*知道*</span>一词相连，即「我定了主意<span style="color:#800000">*不*</span>知道」；或可与<span style="color:#800000">*定了主意*</span>一词相连，即「我并未定意，就是说，我并无此心意或目的」。就词序（<span style="color:#0000d4">ouj</span> <span style="color:#0000d4">γὰρ</span> <span style="color:#0000d4">έκρινά</span>）而论，则有利于后一种解释。然无论取何解，其意皆同。

<span style="color:#800000">*耶稣基督，并他钉十字架。*</span> 保罗前往哥林多，唯一的目的就是传扬基督；而所传的基督，并非作为教师，或作为榜样，或作为完全的人，或作为人类发展史上一个新的起点——凡此种种，皆不过是彼处的哲学罢了；他所传的乃是<span style="color:#800000">*钉十字架的*</span>基督，就是为我们的罪而死的基督。基督作为挽回祭，乃是保罗讲道的要旨。有人说得好：<span style="color:#800000">*耶稣基督*</span>指向基督的位格，<span style="color:#800000">*他钉十字架*</span>则指向他的工作；二者合起来便是福音的总纲。

<!-- PAGE 51 -->

**3.** <span style="color:#800000">*我在你们那里，又软弱，又惧怕，又甚战兢。*</span>

<span style="color:#800000">*我到你们那里去*</span>，<span style="color:#0000d4">ἐγενόμην</span> <span style="color:#0000d4">πρὸς</span> <span style="color:#0000d4">ὐμᾶς</span>，意即我到你们那里去，与你们同在，参见约翰福音 1:2。他在此所说的软弱，并非身体上的软弱；因为他虽在别处论到自己身体软弱（哥林多后书 10:10），又提及自己身患疾病之苦（加拉太书 4:14），然而此处的上下文全然表明，他所指的乃是他的心境。他出现在他们中间，并非怀着刚强的自觉，自恃自倚，而是深感自己的软弱与不配。他所要作的工，是他自觉全然超乎自己能力之上的。

<span style="color:#800000">*又战兢恐惧*</span>，即因自知不足、又深感所负使命关系至大，心中生出焦虑与忧惧，参哥林多后书 7:15、腓立比书 2:12、以弗所书 6:5。

**4.** <span style="color:#800000">*我说的话、讲的道，不用智慧委婉的言语，乃是用圣灵和大能的明证。*</span>

**我说的话，我讲的道**（<span style="color:#0000d4">λόγος</span> 与 <span style="color:#0000d4">κήρυγμα</span>）。此二词若须加以分别，则前者或指他私下的教导，后者指他公开的教导；或者说，前者是泛指，涵盖一切讲论的方式，后者是特指，限于公开的宣讲。意即：「我一切的教导，尤其是我公开所传的道。」然而这两个词也可能是指同一件事，只是着眼的方面不同。

<!-- PAGE 52 -->
使徒论及自己传道的方式，先从反面说，再从正面说。那不是用人智慧上的动听言语，即人的智慧所能提供的那种劝服之辞。他在竭力引人顺服真道时，并不倚靠自己在辩论或劝服上的本领。这是反面的陈述。从正面说，他的传道乃是用（或在，<span style="color:#0000d4">ὲν</span>；两个分句中所用的介词相同，虽然我们的译者在前一处译作<span style="color:#800000">*with*</span>，后一处译作<span style="color:#800000">*in*</span>）<span style="color:#800000">*圣灵和大能的明证*</span>。这话或可解作「那大能之圣灵的明证」；或解作「圣灵的明证与（神迹的）大能的明证」，指福音的双重凭据或证明，即圣灵内在的运行与神迹这外在的凭据。<span style="color:#800000">*大能*</span>一词（<span style="color:#0000d4">δύναμις</span>）常指行神迹的能力，但在下一节中不可能作此解，故此处也未必是这个意思。这一短语大概是说：「这明证以圣灵为其作者，并以大能为其特征」；如此，其意即为<span style="color:#800000">*圣灵大有能力的明证*</span>。

<span style="color:#800000">*明证*</span>（<span style="color:#0000d4">ἀπόδειξις</span>），意即<span style="color:#800000">*显明、陈明*</span>，是凭据的呈示。所以保罗所倚赖以致成功的，既不是自己论辩或劝服的本领，也不是人间智慧的任何资源，乃是圣灵为真理所作的见证。是圣灵证明了福音的真实。

**5.** <span style="color:#800000">*叫你们的信不在乎人的智慧，只在乎神的大能。*</span>

<span style="color:#800000">*叫*</span>，即<span style="color:#800000">*为要*</span>之意。使徒之所以照前一节所述而行，其用意乃在于：使听者的信心不依凭人的理性，而依凭神的见证。他若要凭辩论使哥林多人确信福音的真实，本非难事：他大可指出福音远胜于异教，并援引预言与神迹所提供的、证明福音出于神的凭据。他也可以揭露拜偶像的愚妄、外邦人祭仪礼节的荒谬，使他们确信基督教在历史上的真确性。如此产生的确信固然合乎理性，也不可谓不重要，然而这并不是得救的信心。建立在这等凭据之上的信，不过是思辨之信而已。信心真正的根基——或不如说，真信心的根基——乃是<span style="color:#800000">*神的大能*</span>。这一点，可由他先前所称的“圣灵的明证”得着解释。因此，他所指为信心根基的那神能的施行，就是圣灵大有能力的运行：圣灵与真理一同、并藉着真理，在我们心里作见证。有一种信，是建立在教会的权柄之上，或建立在诉诸悟性的论证之上，甚或建立在真理触动天然良心时所生的道德力量之上（如腓力斯所有的那样）；这样的信摇摆不定，且无功效。惟有建立在圣灵明证之上的信心，才是长存的、无谬的，且生发仁爱，洁净人心。

<!-- PAGE 53 -->

所以，在这几节经文中，我们受教如此：<span class="enum-num">1.</span> 无论在哪一个群体中，无论是基督教的还是异教的，使人归正的正当方法，乃是传扬并阐明有关基督位格与工作的真理。凡所使用的其他一切手段，都必须居于从属和辅助的地位，其用意在于除去障碍，为真理开辟进入人心的通路，正如先将田地里的杂草荆棘清除，好为那宝贵的种子预备土壤一样。

<span class="enum-num">2.</span> 传讲福音时当有的心态，与自恃或轻忽正好相反。传福音者当自觉软弱，并怀着极大的忧惧与关切。

<span class="enum-num">3.</span> 福音的果效不在乎传道者的技巧，乃在乎圣灵的明证。

<span class="enum-num">4.</span> 得救之信心的根基不是理性，即不是诉诸悟性的论证，而是神的大能——这大能借着真理、与真理一同运行在人心之上。

**6.** <span style="color:#800000">*然而，在完全的人中，我们也讲智慧。但不是这世上的智慧，也不是这世上有权有位、将要败亡之人的智慧*</span>。

在前一章 17-31 节，保罗已断言人的智慧不足；在本章 1-5 节，他又说自己并非传授人间智慧的教师。是否可由此推论：他轻视知识，是个不通文墨、鄙薄学问之人，或者他所教导的尽是无稽之谈？绝非如此；他所教导的乃是至高的智慧。从整段论述可以看出，保罗所谓"世上的智慧"，是指人凭理性所得关于神与属神之事的知识。同样显而易见的是，他论及这种知识毫无价值时，乃是就其作为得救之途径而言。人所以责难他，是因他不讲哲学。他的回答是：哲学不能拯救人。哲学在其本分之内、为其本身的目的，或有何等价值；但一旦用来取代福音，则比无用更糟。他并非要把哲学逐出学堂，而是要把它逐出讲台。任凭死人埋葬死人；只是不可让他们妄称自己能赐人生命。

<!-- PAGE 54 -->
<span style="color:#800000">*然而*</span>，即：“我们虽不传讲属人的智慧，却传讲真正的智慧。”<span style="color:#800000">*在完全的人中*</span>（<span style="color:#0000d4">ἐν</span> <span style="color:#0000d4">τοῖς</span> <span style="color:#0000d4">τελείοις</span>），即成熟的人、长大成人的人、有资格领受的人。此处的 <span style="color:#0000d4">ἐν</span> 并非赘词，其意不等于“向完全的人”，而是保有其本义<span style="color:#800000">*在……中间*</span>。在一类人中间，他所传的道理被视为愚拙；但在另一类人中间，这道理却被看为神的智慧。所谓“完全的人”指谁？对此问题有两种解答。有人说，他们是长进的、成熟的基督徒，与在基督里的婴孩相对。另有人说，他们是信徒，与不信的人相对；即受圣灵教导、因而能明白真理的人，与未曾重生的人相对。按后一种看法，保罗的意思是：福音在希腊人看为愚拙，在真正蒙光照的人看来却是至高的智慧。支持后说而反对前说的理由可举如下：<span class="enum-num">1.</span> 那些视保罗所传之道为愚拙的，并非在基督里的婴孩，乃是未曾重生之人，即“这世上有智慧的人”；因此，视此道为智慧的，也就不是长进的基督徒，而是一切信徒。纵观整段上下文，其对立乃在“蒙召的”或已归正的人与未归正的人之间，而非在一类信徒与另一类信徒之间。

<span class="enum-num">2.</span> 若此处“完全人”指的是与在基督里的婴孩相区别的成熟信徒，那么保罗所传的智慧便不是福音本身，而是福音中更高深的道理。然而这是不可能的，因为他所宣称为神的能力、神的智慧的，正是十字架的道理，是基督钉十字架的道理（1:24）。而本章下文对此处所指之智慧的描述，所论的并非福音中更高深的道理，乃是福音本身。

<!-- PAGE 55 -->
此处的对照，是世界的智慧与神的智慧之间的对照，而非福音中初阶道理与高阶道理之间的对照。何况，保罗单单向教会中的精英所传的这些"高深道理"究竟是什么？无人知晓。众说纷纭，各执一词。然而，再没有比本书信以及罗马书、以弗所书中所教导的更高深的道理了，而这些书信都是写给广大信众的。新约并未在（<span style="color:#0000d4">πίστις</span> 与 <span style="color:#0000d4">γνῶσις</span>）高等道理与低等道理之间作出区分。它确实论到奶与干粮的分别，但那不是道理种类的分别，而是此种教导方式与彼种教导方式的分别。在为孩童编写的要理问答中，教会倾倒出她一切知识的宝藏，只是以奶的形式，即以适合最软弱之领受力的形式呈现。基于以上一切理由，我们断定：使徒所说的"完全的人"，是指那些有领受能力的人，是与世人有别的属神的子民；而他所说的智慧，并非什么更高深的道理，乃是那单纯的福音，即与人的智慧相对的神的智慧。

使徒先从反面描述这智慧，说它不是<span style="color:#800000">*这世上的智慧*</span>，或说是<span style="color:#800000">*非属这世界的智慧*</span>，就是说，它不属乎这世界，也不是世人所能得着的。也不是这世上有权有位之人的智慧。这一称谓包括一切在人中间居于首位的人，即有影响力的人，无论其影响力来自智慧、出身，还是权势。使徒并非单指官长或狭义上的君王。这从上下文，以及第8节所说的话，似乎显而易见。<span style="color:#800000">*那些将要败亡的*</span>，就是神定意要使之羞愧的人，正如上文1:28所教导的。

**7.** <span style="color:#800000">*我们乃是在奥秘中讲神的智慧，就是那从前所隐藏的智慧，是神在万世以前预定使我们得荣耀的。*</span>

使徒在第 6 节已说明这智慧不是什么，此处则说明它是什么。第一，它是神的智慧；第二，它是奥秘的，或说是隐藏的；第三，它是一套真理体系，是神从永远里就定意要为他子民的救恩而启示出来的。换言之，它就是那关乎人之救赎的永恒筹算的启示。

<!-- PAGE 56 -->
<span style="color:#800000">*神的智慧*</span>，即源于神的智慧；这智慧是他所启示的，与任何出于人的知识判然有别。<span style="color:#800000">*在奥秘中*</span>。"奥秘"一词，始终指人必须经过引导方能与闻之事，即凭人的理性所不能察知的事。至于其所以不可察知，究竟是因为它属于将来，还是因为它隐藏在神尚未启示的旨意之中，抑或是因为按其本性即超乎我们的领悟——这并非由该词的字义所决定，乃须从上下文中求得。此处这几个字最自然的联系是与前文相连，即"在奥秘中的智慧"，意为奥秘的、隐藏的智慧，这正是紧接着的下文所解释的。因原文中（<span style="color:#0000d4">σοφίαν</span> 与 <span style="color:#0000d4">μυστηρίῳ</span> 之间）并无连接的冠词，故有人宁将此句与动词相连，作"我们在奥秘中讲说"，即宣讲一件奥秘或启示之事。

就是神<span style="color:#800000">*在万世以前*</span>（<span style="color:#0000d4">πρὸ</span> <span style="color:#0000d4">τῶν</span> <span style="color:#0000d4">αἰώνων</span>），<span style="color:#800000">*在诸世代以前*</span>，即在时间之先，或说从永远，<span style="color:#800000">*预定使我们得荣耀的*</span>——就是为着我们的荣耀而预先定下的。<span style="color:#800000">*荣耀*</span>一词常用以概指救恩的一切福分，包括基督为祂子民所成就的一切美善与福乐（罗马书 5:2）。使徒在此称为神的智慧的这救赎计划，乃是从永远就在神的心意中定下的，远非人的洞察力所能测度，如今在福音之下为着人的得救而显明出来：这一思想，是使徒屡屡陈明的（罗马书 16:25, 26；以弗所书 3:9）。

**8.** <span style="color:#800000">*这智慧世上有权有位的人没有一个知道；他们若知道，就不把荣耀的主钉在十字架上了。*</span>

<span style="color:#800000">*这*</span>字所指的是<span style="color:#800000">*智慧*</span>，而非<span style="color:#800000">*荣耀*</span>；因为前者才是此处论说的主题，后者则不是。‘这智慧，世上的首领，即世上的伟人，没有一个知道。’此处所指主要是犹太人的首领，他们乃是把基督钉十字架的主谋，也是他们所属那一阶层的代表。弃绝基督的，正是以其首领为代表的这个世界。

<span style="color:#800000">*荣耀的主*</span>乃是神性的称号，意即拥有神圣的卓越。“荣耀的王是谁呢？就是万军之耶和华，他是荣耀的王！”（诗篇 24:10）。参使徒行传 7:2、雅各书 2:1、以弗所书 1:17。可见被钉十字架的那一位乃是一位神圣的位格。因此，这一行径证明了何等不可思议的瞎眼与邪恶；这样的事惟有出于无知才做得出来。使徒彼得对犹太人说：“弟兄们，我晓得你们做这事是出于不知，你们的官长也是如此”（使徒行传 3:17）。这世上有权有位的人竟瞎眼到看不出基督就是荣耀的主，保罗以此为凭据，证明他们不认识神的智慧。他们若认识这一样，也必认识那一样。

<!-- PAGE 57 -->

这段经文说明了圣经中一条极重要的原则或用法。我们看到，基督的位格可以按其神性来称谓，而所论及之事却仅就其人性而言为真。荣耀的主被钉十字架；神的儿子为妇人所生；那与神同等的，却自己卑微，存心顺服以至于死。同样，我们说到一个人的生与死，并非指他的灵魂被生出或死亡；圣经说到神儿子的诞生与死亡，也并非指神性会经历这些变迁。同样显明的是：将无知、顺服、受苦、死亡或任何其他限制归于神的儿子，并不比将生与死归于一个人更有损于这位格的神性——正如后者并不有损于人之灵魂的非物质性与不朽性。凡对灵魂或身体为真的，都可以论及作为位格的人；凡对基督的神性或人性为真的，也都可以论及作为位格的基督。因此我们尽可以与保罗一同说：荣耀的主被钉了十字架；甚至照使徒行传 20:28 通行的经文说：“神用自己的血买来的教会。”那受死的位格实在是神，虽然神性并未死去，正如人断气之时，其灵魂并未死去一样。

**9.** <span style="color:#800000">*如经上所记：「神为爱他的人所预备的，是眼睛未曾看见，耳朵未曾听见，人心也未曾想到的。」*</span>

本节的意思是明白的，虽然其中牵涉若干难处。保罗说过，他所传的是神那隐藏的智慧，是这世上有权有位的人所不知道的；他所教导的乃是眼未曾见、耳未曾闻、人心也未曾想到的。就是说，他所传的真理，是人的理性无从发现的。<span style="color:#800000">*入了心*</span>意即浮现于思想之中。可比照希伯来文，以赛亚书 65:17。

<!-- PAGE 58 -->
与本节相关的第一个难处是文法上的，因译文较为自由，在我们的译本中并未显出。按字面直译，此段应作：‘眼睛未曾看见，耳朵未曾听见，人心也未曾想到的，就是神为爱他的人所预备的——。’这句话并不完整。要解决这一难处，或可参照前一章末节（v. 31）注释中所提及的用法，即使徒引用旧约经文时，惯于不将其在文法上织入自己的论述之中。或者，我们也可像许多人所作的那样，补上（<span style="color:#0000d4">λαλοῦμεν</span>）一词：‘神为爱他的人所预备的，正是<span style="color:#800000">*我们所讲的*</span>。’再或者，可将本节与下文相连：‘眼睛未曾看见的——就是神为他子民所预备的——他已藉着自己的灵向我们显明了。’——这几种解释中，第一种为一般所采纳，也最令人满意。

第二个难处与所引的经文有关。既然“如经上所记”这一套语，除了引用旧约正典各卷之外，使徒们从不使用，那么就不能承认保罗有意引用某卷现已失传的书，或某部次经作品。若假定他所要引用的是以赛亚书 64:4，难处便有两重：第一，用语文字不同；第二，意思也不同。以赛亚书 64:4（希伯来文作第 3 节），照 J. A. Alexander 博士的直译是：“从亘古以来，人未曾听见，未曾耳闻，眼未曾看见，在你以外有神能为等候他的人行事。”其意为：除耶和华以外，人从未认识别的神曾行、或能行他所警戒要行的事。七十士译本所表达的也是同一意思。在以赛亚书中，就其与上文的关联而言，其意似乎是：所以当预料这等可畏之事必从耶和华而出，乃因惟独他曾证明自己能成就这些事。为化解此难处，有人提出对先知这段话的另一种解释。若将其与下文相连，并将<span style="color:#800000">*神*</span>一词取为呼格，则意思可以是：“从亘古以来，人未曾听见，未曾耳闻，眼未曾看见，神啊，离了你（即：没有启示），他为等候你的人所预备的是何等事”（或改换人称作“你为等候你的人所预备的”）。武加大译本即作此译法，如此便使这段经文与使徒的引用相合。

<!-- PAGE 59 -->
另有一些人认为，前面所提以赛亚书那段经文的第一种解释才是正解，因而主张使徒不过是借用圣经的措辞，并无意表达原文的含义。此种做法我们常有，在新约中亦屡见不鲜，如罗马书 10:18。照此说来，<span style="color:#800000">*如经上所记*</span>在此并非引证的格式，倒不如说相当于说：“借用圣经的话来说。”

对这一难题的第三种解释是：使徒并非有意引证圣经中的某一处经文，而是就一项已经明白启示的真理诉诸圣经的权威。旧约确实教导说，人的心思无法测透神的旨意；他的计划惟有借着超自然的启示才能为人所知。这正是使徒引用旧约权威所要证明的真理。因此，若说这位受默示的使徒记忆有误，或作了错误的解经，实无丝毫根据。

**10.** <span style="color:#800000">*只有　神藉着圣灵向我们显明了，因为圣灵参透万事，就是　神深奥的事也参透了。*</span>

人的理性所无从发现的，神已借着他的灵启示出来。<span style="color:#800000">*向我们*</span>，即向那领受此启示的人，就是"神的圣使徒和先知"（以弗所书 3:5）。此启示是借着圣灵而作的，<span style="color:#800000">*因为*</span>惟有他能作此启示；因为惟有他参透神深奥的事。<span style="color:#800000">*参透*</span>，即探究，确切而彻底地知晓。这词所表达的并非查考的过程，乃是查考的结果，即深彻的知识。故此，经上说神鉴察世人的心，意在表明人里面没有一样能逃过他的洞察（罗马书 8:27；启示录 2:23）。照样，神里面也没有一样是圣灵所不知的。<span style="color:#800000">*深奥的事*</span>，即神的深处，可以说是他的存有、全备和旨意最隐秘的所在。所以，那历世历代隐藏在神里面的智慧，圣灵完全有能力将其启示出来。这段经文同时证明了圣灵的位格与神性：证明其位格，因为经文将有智慧的活动归于他，他<span style="color:#800000">*参透*</span>；证明其神性，因为经文将全知归于他，神所知道的一切，他都知道。

**11.** <span style="color:#800000">*除了在人里头的灵，谁知道人的事；像这样，除了神的灵，也没有人知道神的事。*</span>

<!-- PAGE 60 -->

本节意在说明两点：其一，正如除了人自己以外，无人知道人心里的意念，照样，除了神自己以外，也无人知道神的意念。所以，惟有具有神性的位格，才有资格将神的意念与旨意启示出来。其二，正如各人都知道自己心里的意念，照样，神的灵也知道神的意念。祂对神里面之事的知识，与我们对自己意识中所存之事的知识相类。然而，圣经中的类比，不可推至其本意所要说明的那一点之外。此处所要说明的一点，乃是圣灵的知识：祂知道神里面所存的，正如我们知道自己里面所存的。却不可由此推论说，在别的方面，神的灵与神的关系，也如同我们的灵与我们的关系一样。

**12.** <span style="color:#800000">*我们所领受的，并不是世上的灵，乃是从神来的灵，叫我们能知道神开恩赐给我们的事。*</span>

使徒在此提出了两个知识的来源：一为属人的，一为属神的；一是人里面那使人知晓的本原，一是从神而来那使人知晓的本原。他断言，他所传讲的那智慧或知识，其源头不是前者，乃是后者。不是人的理性，乃是神的灵。<span style="color:#800000">*世上的灵*</span>在此并非指属世的性情或心态；"灵"乃是那知晓并教导的。因此"世上的灵"是"理性"的一种委婉说法，理性即人里面知识的本原。保罗说他未曾领受那灵，意思是：人的理性并非他所传讲之知识的源头。<span style="color:#800000">*从神来的灵*</span>，即圣灵，是从神而出、由神差遣来作人的教师。<span style="color:#800000">*领受*</span>圣灵，就是成为圣灵运行的对象。因此，究竟谁是那"领受圣灵"的人，须视上下文以及所论及之运行的性质而定。此处通篇的关联表明，使徒所说的乃是启示与默示；故此他所指的必是<span style="color:#800000">*我们使徒*</span>（或保罗自己），而非"我们基督徒"。

<!-- PAGE 61 -->
<span style="color:#800000">*叫我们*</span>，即为叫我们，<span style="color:#800000">*得知神开恩赐给我们的事*</span>，即神施恩启示给我们的事。这一句所指的，并非信徒如今所享受的内在属灵福分，也不是圣徒将来的福乐，除非就其包含在保罗所传讲的总题之内而言。此处的连贯当上溯至第 10 节：“人的理性所不能寻见的，神已启示给我们使徒，为叫我们得知他如此施恩传达的事。”所论的题目乃是神的智慧，即福音，与世上的智慧相对。这一点从上文与下文都可看得分明。

**13.** <span style="color:#800000">*并且我们讲说这些事，不用人智慧所指教的言语，乃用圣灵所指教的言语，将属灵的话解释属灵的事。*</span>

<span style="color:#800000">*这些事*</span>，即圣灵所启示的事。我们<span style="color:#800000">*也*</span>讲说。我们不单知道，也把神所启示的事传与人。此事如何成就？使徒在传达他藉神的启示所领受之事时，用的是何等言语？他照其惯常的方法作答：先从反面说，然后从正面说。这不是「用人智慧所指教的言语」。此中含有两义：使徒所用的言语，既非修辞家的技巧所能提供，亦非他自己的心思在未受神的灵感动之下所能想出的。正面的宣告则是：所用的言语乃是圣灵所指教的。这就是逐字默示，即以下的教义：圣经的作者在拣选他们用以传达神的真理的字句时，是受神的灵所掌管的。有人给这教义加上恶名，称之为「默示的机械论」，说它把神圣的执笔者贬为机器。反对此教义者又说，它无法解释圣经各卷之间在文体上的差异。然而，若神能掌管一个人的思想而不使他沦为机器，为何不能掌管他的言语？各样作者，或诗体或散体，或典雅或质朴，或善用箴言或长于论理，神为何不能使他们各自在运用其独特文体时都无谬误？倘若圣经的言语并非受默示的，那么我们所得的真理，便是经由人之不完全这一层使之变色、使之走样的媒介传来的。保罗的断言是直截了当的：他所用的言语，乃是圣灵所指教的。

<span style="color:#800000">*将属灵的事与属灵的事相比较*</span>；或更确切地说，<span style="color:#800000">*将属灵的事与属灵的言语相联*</span>，即用圣灵的言语解明圣灵的事

<!-- PAGE 62 -->

灵。关于 <span style="color:#0000d4">συγκρίνειν</span> 用作<span style="color:#800000">*解释*</span>或<span style="color:#800000">*讲明*</span>之意，可参看七十士译本中的创世记 40:8；16:41；12:15，以及但以理书 5:12。上下文亦要求作此解。使徒方才说，他所教导的真理是圣灵所启示的，他所用的言语也是圣灵所指教的；如今他将此总括为一句话：他是用属灵的言语讲解属灵的事。这样解释此节，与原文词义完全相合。原文一词（<span style="color:#0000d4">συγκρίνω</span>）不仅指在心中合而观之、因而作比较，也指连合在一起，并指解释。七十士译本即用此词表达解梦或解谜之举。故此，所论之句既可译作<span style="color:#800000">*将属灵的事与属灵的言语相配合*</span>，亦可译作以此<span style="color:#800000">*解释*</span>彼。此外，<span style="color:#800000">*属灵的*</span>（<span style="color:#0000d4">πνευματικοῖς</span>）一词并无与之相连的名词，最自然是与紧接其前所隐含的<span style="color:#800000">*言语*</span>（<span style="color:#0000d4">λόγοις</span>）相配。

另一种解释是<span style="color:#800000">*将属灵的事与属灵的事相比较*</span>，无论其意如某些人所说，是将旧约与新约相比较，还是如另一些人所理解的，是将圣灵教训的这一部分与那一部分相比较，都与上下文不合。至于许多人所采用的对此分句的第三种解释，则更少可取之处；他们认为使徒是说，他将属灵的事解释给属灵的<span style="color:#800000">*人*</span>听。这样解释乃是提前说了下文的意思。

**14.** <span style="color:#800000">*然而，属血气的人不领会神圣灵的事，反倒以为愚拙，并且不能知道，因为这些事惟有属灵的人才能看透。*</span>

<!-- PAGE 63 -->
虽然<span style="color:#800000">*属灵的事*</span>，即神话语中的真理，已经如此清楚地启示出来；虽然这些真理是用圣灵所指教的言语传达的，然而某一类人却弃绝它们。也就是说，他们不信、不看重、也不顺服这些真理。这一类人被称为<span style="color:#800000">*属血气的*</span>。这个词的含义不能仅凭字面意义（<span style="color:#0000d4">ψυχικός</span>）来断定，因为它既可指"属肉欲的"（即受我们本性中较低等的动物性原则所支配），也可指<span style="color:#800000">*属血气的*</span>，即受人现今本性中所固有者所支配，与神的灵相对。许多注释家说，（<span style="color:#0000d4">ψυχικοί</span>）<span style="color:#800000">*属血气的*</span>就是纵欲的人，而与之相对的一类（<span style="color:#0000d4">πνευματικοί</span>）<span style="color:#800000">*属灵的*</span>则是有智性的、有理性的人，即受（<span style="color:#0000d4">πνεὺ͂μα</span>）灵所支配的人——此处"灵"是指我们本性中较高的原则，与较低的原则相对。照此看法，保罗的意思乃是：纵欲之人固然不领受属灵的事，有智性的人却能领受。然而这样的解释不可能正确。

<span class="enum-num">1.</span> 因为这种解释所赋予经文的意思，不但与使徒明确的断言相抵触，更与他整个论证的走向和目的背道而驰。使徒不仅宣告：领受福音的并非那些有智慧的、有教养的、有学识的人；他通篇的用意乃在证明：人的理性，或说人性发展至最高境界的人，既不能发现"属灵的事"，即或这些事被启示出来，也不能领受。人在基督里，乃是出于神，并非因着他们较为优越的教养或学识，1:30。这些事向聪明通达人就藏起来，向婴孩就显出来，马太福音 11:25：

<span class="enum-num">2.</span> 因为<span style="color:#800000">*属灵的*</span>一词，在新约中用于指人时，从不作<span style="color:#800000">*理智的*</span>解。它始终指那受圣灵感动、居于圣灵影响之下的人。因此在此处也必是此义。

<span class="enum-num">3.</span> 此处及别处以“属血气的”与“属灵的”二词所要表达的分别，正是本性与恩典之别，亦即自然与超自然之别，参雅各书 3:15、犹大书 19。

<span class="enum-num">4.</span> 此处所陈明的理由，说明属血气的人为何不领会属灵的事，乃是因为"这些事惟有属灵的人才能看透"；这话并非说"惟有凭理性才能看透"，因此，属血气之人的特征并非理性未曾得着适当的陶冶，而是缺乏圣灵。所以，所谓<span style="color:#800000">*属血气的人*</span>，我们当理解为未曾重生之人，即受人性支配之人，与那受圣灵支配之人相对。属血气的、未曾重生的人不<span style="color:#800000">*领会*</span>属灵的事。圣灵所启示的事，不但向理智陈明其为真实，也向良心陈明其为当尽之责，并向情感陈明其为美善可爱；因此，不领会这些事，就是在内心的经验中不承认其真实、其权威、其美善。

<!-- PAGE 64 -->

<span style="color:#800000">*因为在他看来是愚拙的*</span>。<span style="color:#0000d4">μωρός</span> 一词，即<span style="color:#800000">*愚拙的*</span>，在希腊文中作形容词用时，意为<span style="color:#800000">*迟钝、乏味、无味*</span>；作名词用时，指迟钝或愚昧之人，即真理、本分与美善在其身上不能产生应有果效的人。<span style="color:#800000">*愚拙*</span>（<span style="color:#0000d4">μωρία</span>）则指在我们看来荒谬、乏味、无力的事物。因此，当经文说属灵的事在属血气的人看来是愚拙的，其意乃是：这些事在他看来乃是荒谬、乏味、可厌的。

<span style="color:#800000">*而且他也不能知道，*</span>所谓*知道*，就是分辨一事物之性质——是否为真、为善、为美。这与圣经一贯的用法相符。认识神，就是分辨他的真实与卓越；认识真理，就是领会它为真、为善。智慧人即是善人，就是那些能分辨神圣之事的真实与卓越的人。愚顽人即是恶人，就是那些对真理与良善毫无知觉的人。因此，使徒在此论到属血气的人、即未重生之人所断言的，乃是：他不能分辨神圣之事的真实、卓越或美善。他**不能**如此行。这并非仅仅说他没有如此行，也不是说他不愿如此行，而是说他不能。我们不会说一个粗鄙之人是"不愿"分辨一首诗的真实、卓越与优美。其难处不单在他的意志，而在他整个内在的状态。这事在他看来乃是愚拙。照样，圣经论到属血气的人，也不单说他不愿分辨属灵的事，因为他的难处不单在意志，而在他整个内在的状态。他不能知道这些事。其缘由乃是：

<span style="color:#800000">*因为这些事惟有属灵的人才能看透。*</span>意思是说，这些事惟有借着圣灵才能看透。所以凡没有圣灵的人，便不能看透。罪加于人心灵的果效，就是使人对神圣之事的真理、卓越与佳美盲然无睹；若如使徒所断言的，属血气的人，即未蒙重生之人，其光景乃是以圣灵的事为愚拙、为荒谬、为淡而无味、为可厌，那么随之而来的结论便是：他惟有借着圣灵才能看透这些事。在他能领会福音的真理与卓越之先，他内心的光景必须先被圣灵的作为所改变。领受者与所领受之物之间，必须有性情上的相契。惟有清心的人才能看见神。使徒说，我们的福音若是蒙蔽，就是蒙蔽在灭亡的人身上。所以，未蒙重生之人惟一的指望，就是效法当年那瞎眼的人所行的——

<!-- PAGE 65 -->

基督。他们必须到他那里去求属灵的悟性；凡到他那里去的，他总不丢弃。

**15.** <span style="color:#800000">*惟有属灵的人能看透万事，却没有一人能看透了他。*</span>

此处所说的<span style="color:#800000">*看透*</span>，意思是分辨、领会，并因而作出判断。原文用词与前一节相同，故译文实无变动之理由。属灵人能看透那些惟有属灵才能看透的事，虽然他自己却不被任何属血气的人所看透，也不被其正确领会。此处所说的<span style="color:#800000">*万事*</span>，按上下文所限，乃指属乎圣灵的事。使徒所肯定的这种分辨神圣之事的真理、卓越与荣美的能力，并非单指教会的圣职人员，也非单指教会全体，乃是指凡有圣灵内住的每一个人。一人无法替另一人分辨何为真、何为善，正如一人无法替另一人观看一样。我们必须自己看见，否则就根本看不见。在宗教之事上私人判断的权利，与圣灵的内住不可分割。凡能看见的人，就有看见的权利。圣灵的职分乃是启示真理，开我们的眼睛，使我们按其本相分辨真理，并感受其能力。如前文所论，得救的信心正是建立在圣灵这样的明证之上。既然凡有圣灵的人都蒙赐这明证，那么基督徒的信心便既非建立在人的智慧之上，也非建立在教会的权威之上，因而也不受二者的辖制。

<!-- PAGE 66 -->
<span style="color:#800000">*惟有他自己不被别人看透了*</span>。这话同样须按上下文加以限定。凡没有圣灵的人，都不能真正认识他。保罗随后说，被人论断，在他看来乃是极小的事（4:3）。他在此并非否定信徒当受弟兄合法的察验；因为他在别处教导说，有圣灵的人可以审断那些自称属灵之人，判定他们究竟在何等程度上真是被圣灵引导。他也定下了这审断当循的准则（5:9-12；12:3；加拉太书 1:8）。倘若有人自称属灵，所行的却是圣灵在其话语中所禁止的，或所否认的正是圣灵所教导的，我们就知道他是自欺，真理不在他里面。我们必须试验那些灵是出于神的不是。这话是真的，与使徒在此所说的完全相合；使徒的话不过是说：属灵的人不能被那不属灵的人正确地看透或衡量。

**16.** <span style="color:#800000">*谁曾知道主的心去教导他呢？但我们是有基督的心了*</span>。

这是对上文的确证。无人能审断属灵之人，因为审断属灵之人无异于审断主。主已启示了某些真道，属灵之人辨明这些真道为真。若有人断定这些真道为虚妄，并因此审断持守这真道的人，这就等于自以为能教导主。既无人能教导主，也就无人能审断那些有基督心思的人，就是那些蒙基督藉着他的灵教导明白真理的人。若以三段论表述，此论证当如此：无人能教导主；我们有主的心思；所以无人能教导或审断我们。这三段论的大前提，是引自以赛亚书 40:15 七十士译本的语句。希腊的哲士与犹太人中的文士曾坐在审判的位上评断保罗，断定他所传的为愚拙。保罗告诉他们，他们并不配作审断之人。属血气的人不能领会圣灵的事，也就无资格审断那受圣灵教导的人。既然我们所传的乃是主的心思，那么定我们所传之道为罪，或审断我们这传扬此道的人，就是定主的罪。

旧约中论及耶和华的话，在新约中往往被应用于基督。此处正是如此。"谁曾知道主的心？"意即：谁曾知道耶和华的心？因此，<span style="color:#800000">*我们是有基督的心了*</span>，其意便是：我们是有耶和华的心了。凡对其一为真者，对其二亦为真。那位在新约中被启示为神儿子的，正是古时被启示为耶和华的同一位。这便教导我们：信徒的信心有何等稳固的根基；而凡受圣灵教导的人，欲将自己的确信屈从于人的权威之下，又是何等不可能的事。
