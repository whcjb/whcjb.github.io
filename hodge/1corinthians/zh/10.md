<p class="title-block-h2" style="text-align:center; font-size:16px; font-weight:bold; margin:18px 0 12px;" markdown="1"><span style="color:#006411">第十章</span></p>

承接前文，继续劝人克己谨慎，1-13节。明令禁止参与外邦人的祭偶像筵席，14-22节。就祭偶像之物的食用所作的具体指示，23-33节。

<p style="text-align:center" markdown="1"><span style="color:#0000d4">**从以色列人的事例论证**</span> <span style="color:#0000d4">**克己之必要。第1-13节。**</span></p>

在前一章末尾，使徒曾劝勉读者当克己努力，以求得生命的冠冕。此处他重申这一劝勉，指出以色列人正因缺乏这样的自制而招致何等惨痛的结局。他们所蒙的恩眷并不亚于我们：他们曾蒙云柱奇妙的引导，曾经过红海，曾以天上降下的吗哪为食，以磐石中流出的水解渴；然而其中绝大多数人终究倒毙旷野（1-5节）。这对基督徒是严肃的警戒，叫他们不可像以色列人那样向试探屈服（6节）。也就是说：不可陷入拜偶像（7节），不可行奸淫（8节），不可试探基督（9节），不可发怨言（10节）。在这一切事上，以色列人的经历都是给基督徒的鉴戒；因此，自以为站立得稳的人，须要谨慎，免得跌倒（11、12节）。神有怜悯，必不叫他们受过于所能受的试探（13节）。

**1.** <span style="color:#800000">*弟兄们，我不愿意你们不晓得，我们的祖宗从前都在云下，都从海中经过*</span>；

<!-- PAGE 193 -->
<span style="color:#800000">*并且*</span>。真确的读法不是（<span style="color:#0000d4">δέ</span>）<span style="color:#800000">*并且*</span>，而是（<span style="color:#0000d4">γάρ</span>）<span style="color:#800000">*因为*</span>，它标明与上文的关联。“我们必须克己、必须努力；<span style="color:#800000">*因为*</span>，弟兄们，我们的祖宗虽经历了那一切，仍然灭亡了。”<span style="color:#800000">*我不愿意你们不晓得*</span>，罗马书 1:10；11:25，这是有特别要紧之事将要陈明时所用的套语。<span style="color:#800000">*说的是（并非「怎样」）。我们的祖宗都*</span>。重点在<span style="color:#800000">*都*</span>字上。“我们的祖宗都出了埃及；惟有迦勒和约书亚进入了应许之地。”众人都赛跑，得奖赏的却只有一人。教会历史中，再没有比使徒所选取的这段事迹更适宜用来说明必须防备虚假的安稳了。以色列人站在红海彼岸之时，无疑觉得一切危险都已过去，进入应许之地已成定局。然而摆在他们面前的，却是一段处处有危险的路程；他们以为不必再费力，于是灭亡了。哥林多人也是如此：他们既已认识福音，便以为天堂稳当无虞。保罗提醒他们，他们不过刚踏上这条路，若不常常克己，必定灭亡。<span style="color:#800000">*我们的祖宗*</span>。亚伯拉罕是我们的父，虽然我们并非他肉身的后裔。以色列人也是哥林多信徒的祖宗，虽然他们多半出于外邦。这话固然不错，但使徒虽是写信给一间教会，其中许多、甚或大多数成员本出于异教，他在此大概是以犹太人的身分对犹太人说话；正如他常常对全会众讲话，而所说的其实只关乎其中一部分人。

<span style="color:#800000">*都在云下*</span>，并非指在云的下方，而是指在云的引导之下。出埃及记 13:21：“日间，耶和华在云柱中领他们的路；夜间，在火柱中光照他们，使他们日夜都可以行走。”参民数记 9:15, 23；14:14；申命记 1:33；诗篇 78:14 等处。这种超自然的引导，是他们蒙拣选作神子民最确凿不过的凭据。神同在与恩眷的记号，日夜显在他们眼前。若有哪一族人有理由自信其得救稳妥无虞，正是这些蒙神如此奇妙引领的人。<span style="color:#800000">*都从海中经过*</span>。神既为他们成就了这样显著的拯救，甚至为他们的缘故牺牲了埃及的全军，岂会容他们灭亡呢？然而他们的尸首却倒毙、遍布在旷野。可见，单单领受非常的恩眷是不够的，单单起步良好也是不够的。惟有藉着持续不断的克己与警醒，才能得着所应许的赏赐。这正是使徒所要教导的功课。

**2.** <span style="color:#800000">*都在云里、海里受了洗*</span>[^f14]<span style="color:#800000">*，归了摩西*</span>；

<!-- PAGE 194 -->
<span style="color:#800000">*受洗归了摩西*</span>，即：与摩西相关而受洗，因受洗而成为他的门徒。参一章13节；罗马书6:3。<span style="color:#800000">*在云里、海里*</span>。云与海为他们所作的、使他们与摩西发生关联之事，正如洗礼为我们所作的、使我们与基督发生关联之事。他们过海、并蒙云柱引导，就是他们的洗礼。这使他们成了摩西的门徒，使他们负有承认他所受神的差派、并服从他权柄的义务。两者之间的类比仅在此一点上成立，而使徒的论证所需要的也正只此一点。有一派注释家说，他们浸在海中，所以那是一次洗礼；另一派则说，云降雨在他们身上，故说他们受了洗。两说同样牵强。因为百姓在云里受洗与在海里受洗是同等的；然而他们既未浸在云中，也未被海水所洒。此处对洗礼的方式毫无暗示。这类比之点也不在于云是水气、海是水这一事实。夜间的云柱乃是火。相似之处不在任何外在之物，而在于所产生的果效。神的大能在云中、在海中的显明，使百姓进入了作摩西门徒的关系。它成立了这会众，可以说是把他们洗礼归给了摩西，使他们有义务事奉他、跟从他。

**3.** <span style="color:#800000">*并且都吃了一样的灵食；*</span>

他们既有自己的洗礼，也有自己的圣餐；而且人人都领受了。他们都吃<span style="color:#800000">*同样的*</span>灵粮。他们所蒙的恩眷是一样的，因此指望的根据也是相等的。然而其中真正进入所应许的安息的，何其稀少！

此处显然是指吗哪，使徒称之为灵粮。至于为何如此称呼，则甚难确定。

<span class="enum-num">1.</span> <span style="color:#800000">*属灵的*</span>一词，或可指具有灵之性质者，此义见于 15:44，其中「属灵的身体」被认作是一种精细的、以太性质的身体。依此看法，吗哪之所以称为属灵的食物，乃因其为一种精细的食粮；正如我们以<span style="color:#800000">*天上的*</span>一词作为卓越之形容。

此解释可从诗篇78:25获得若干支持，那里称吗哪为"天使的食物"。约瑟夫在<span style="color:#800000">*A*</span>. III. 1:6 中称之为"神圣而奇妙的食物"。

<!-- PAGE 195 -->

<span class="enum-num">2.</span> 第二种解释认为，<span style="color:#800000">*属灵的*</span>意为具有属灵含义。如此，“属灵的食物”便等同于<span style="color:#800000">*预表性的*</span>。即：‘他们所吃的那饼，乃是从天上降下来之真粮的预表。’然而这两种看法都与圣经中此词的用法不合。<span style="color:#800000">*属灵的*</span>既不指精微，也不指预表。在 15:44 中，“灵性的身体”是指与灵相适应、作灵之器官的身体。

<span class="enum-num">3.</span> 另有人取此词极常见之意，即<span style="color:#800000">*属乎灵的*</span>；正如前一章中，“属肉体的事”指关乎身体之事，“属灵的事”指关乎灵魂之事。照此解释，吗哪不仅是为身体而设，也是为灵魂而设。它是属灵的食物；是为人的灵所预备的食物，因有圣灵与之同在，并被用作属灵滋养的媒介。此解甚为通行。加尔文认定这是本段唯一可能的意思，并据此为他所钟爱的教义立论，即旧约的圣礼与新约的圣礼具有同等的效力。然而这样便把吗哪抬高为一种圣礼，而它本不是圣礼。它原是为寻常的食物而设；正如尼希米（9:15）所说：“从天上赐下粮食充他们的饥，从磐石使水流出解他们的渴。”我们的主也是从同样的角度看它，他说：“你们的祖宗在旷野吃过吗哪，还是死了。”（约翰福音 6:49）他将自己——那从天上降下、赐生命给灵魂的真粮——与那并无属灵效力的吗哪相对照。

<span class="enum-num">4.</span> <span style="color:#800000">*属灵的*</span>一词在圣经中最常见的含义之一，就是<span style="color:#800000">*出于圣灵的*</span>。属灵的恩赐与属灵的福分，乃是以圣灵为其源头的恩赐与福分。凡神在自然界中和在恩典中所行的，都是藉着圣灵而行。祂藉着圣灵妆饰诸天；圣灵也更新地面。因此，当经上说神赐他们从天上降下的粮食吃，其意即是圣灵所赐；因为神是藉着圣灵赐下的。照样，经上说神更新人、使人成圣，因为神的灵乃是重生与成圣的作者。所以吗哪之为属灵的食物，正与神特赐的恩赐被称为属灵的恩赐同出一义。就是说，它是圣灵所赐的。它并非天然的食物，乃是神迹所供应的食物。

<!-- PAGE 196 -->

同样，在下一节中，那水被称为<span style="color:#800000">*灵水*</span>，也是因为它是藉神迹而出的。在加拉太书 4:29，以撒按自然而生，却说他是<span style="color:#800000">*按着圣灵生的*</span>，因为这出于神的特别干预。以色列人蒙神迹拯救、蒙神迹引导，这便是他们的洗礼；他们蒙神迹喂养，这便是他们的主的晚餐。这些事之于他们，正如圣礼之于我们，同为神的临在与恩眷的显著标记。既然他们所有的特权未能拦阻他们倒毙旷野，我们所有的特权也不能救我们。既然缺乏克己与警醒毁了他们，同样也必毁了我们。

**4.** <span style="color:#800000">*也都喝了一样的灵水；所以他们所喝的，是出于随着他们的灵磐石，那磐石就是基督。*</span>

他们所喝的水是<span style="color:#800000">*灵水*</span>，因为这水出于圣灵，即藉神特别的介入而来。当水初次赐下之时，他们都曾喝过（<span style="color:#0000d4">έπιον</span>）；此后又不断地喝（<span style="color:#0000d4">έπινον</span>），因为那磐石随着他们。无论这一节的解释附带着何等的疑难，其中有两件事是明明教导的。第一，以色列人始终以神迹的方式得着水的供应；第二，这供应的源头乃是基督。本段主要的疑难在于：说那磐石随着以色列人，又说那磐石就是基督。这两句话当如何领会呢？

<span class="enum-num">1.</span> 有人按字面理解这段经文，认为摩西所击打的那磐石在以色列人整个行程中当真滚动跟随着他们。犹太人素有此种传说，韦茨坦（Wetstein）、朔特根（Schoettgen）与莱特福特（Lightfoot）从犹太著作中所引的大量文字足以证明这一点。[^f15] 按当地传说——其年代至少与《古兰经》一样久远——摩西所击打的磐石并非山体的一部分，而是一块独立的岩石，上有孔穴，据说水即由此涌流而出。如此解释这段经文，等于要使徒为一则犹太寓言负责，与他所具的神圣权柄不合。持此解释者并不认为那磐石真的跟随了以色列人，而是认为使徒被他那个时代的传说所误导。

<!-- PAGE 197 -->
<span class="enum-num">2.</span> 另有人说，那随着他们的磐石，意思是从磐石流出的水随着他们。此说并无牵强之处。若说法国的葡萄树随着这民所到之处而去，用以表达那些葡萄树所出的酒随着他们，也算不得是何等生硬的比喻。至少无人会将这样的说法按字面理解。诗篇 105:41 说：「他打开磐石，水就涌出；在干旱之处，水流成河。」这至少证明水的供应极其丰沛，且流出甚远。

<span class="enum-num">3.</span> 然而，我们并不必假定那磐石或从磐石里流出的水曾随着他们。随着他们的那磐石乃是基督。这位圣道（Logos），即那显现出来的耶和华，一路伴随以色列人前行，正是那位取了我们人性、成为基督的神的儿子。供应他们一切所需的，就是他。他向他们乃是活水的泉源。他就是他们所喝的那<span style="color:#800000">*灵*</span>磐石。此处<span style="color:#800000">*灵*</span>一词，其大意或与前面几句中所用的相同。

饼与水之所以被称为属灵的，是因为它们出于超自然。磐石同样是超自然的磐石，只是意义略有不同。吗哪的超自然在于其来源，磐石的超自然则在于其性质。同一个词在同一段文脉中取不同却相近的意义，并非罕见之事。可比较<span style="color:#800000">*属灵的*</span>一词在 2:15 与 3:1 中的用法，以及 3:17 中<span style="color:#0000d4">φθείρει</span>与<span style="color:#0000d4">φθερεῖ</span>的用法。然则磐石在何种意义上就是基督呢？并非说基督以磐石的形状显现；也不是说那磐石是基督的预表，因为这与上下文不合。此处的意思并非他们喝了那作预表之磐石的水；供应他们所需的，不是预表，而是预表所指的实体。这一说法纯属比喻。基督是磐石，与他是葡萄树同属一义。以色列人在旷野行路期间所享的一切扶持，其源头都是基督。

<!-- PAGE 198 -->
这段经文明确断言的，不仅是我们的主先在，更是他就是旧约中的耶和华。那位向摩西显现、自称为耶和华亚伯拉罕的神的，那位差他去见法老的，那位领百姓出埃及的，那位在何烈山显现的，那位引导百姓走过旷野的，那位居于圣殿的，那位向以赛亚显明自己的，那位在日期满足之时将亲身显现的，正是那位由童女所生、在肉身中显明自己的位格。故此在旧约中他被称为使者、耶和华的使者、耶和华、至高的主、全能的神、神的儿子——是神所差来的一位——因而就本体而言与神为一，却是有别的位格。我们的主说，亚伯拉罕看见了他的日子，因为在亚伯拉罕之先就有了他（约翰福音 8:58）；约翰说（约翰福音 12:41），以赛亚在殿中看见了他的荣耀；保罗说，以色列人在旷野试探他（哥林多前书 10:9），又说摩西为他受凌辱（希伯来书 11:26）；犹大书 5 节说，主（或如拉赫曼依古抄本与古译本所读，作耶稣）把他的百姓从埃及救出来。这一真理早已深印于基督教会的心中，古代礼文中的祷词即为明证：O Adonai (Supreme Lord), et Dux Domus Israel, qui Mosi in igne flammeo rubi apparuisti, et ei in Sina aquam dedisti, veni ad redimendum nos in brachio extracto.（哦，Adonai［至高的主］，以色列家的元首，你曾在荆棘的火焰中向摩西显现，在西奈为他赐下水泉，求你伸出膀臂来救赎我们。）

**5.** <span style="color:#800000">*但他们中间多半是神不喜欢的人，所以倒在旷野。*</span>

<span style="color:#800000">*但*</span>，意即：*纵然*他们蒙受了如此崇高的恩眷。<span style="color:#800000">*许多人*</span>；按字面作「其中大多数人」。<span style="color:#800000">*神不喜欢*</span>，意即神向他们发怒不悦。神不悦的明证，就是他们<span style="color:#800000">*倒毙*</span>在旷野。按字面作：<span style="color:#800000">*他们的尸首横陈*</span><span style="color:#800000">*在旷野*</span>。他们穿越旷野所经的路途，可凭那些因神的审判而灭亡之人的骸骨辨认出来。

**6.** <span style="color:#800000">*这些事都是我们的鉴戒，叫我们不要贪恋恶事，像他们那样贪恋的。*</span>

<!-- PAGE 199 -->
<span style="color:#800000">*这些事都是我们的鉴戒*</span>；按字面当作<span style="color:#800000">*我们的样式（types）*</span>。所谓 *type*，本指印痕，即凡由击打所留下的痕迹；进而指与他物相似的印记；再进而指一个模型，使别的人或物按之被塑造，或事实上必然与之相符。以色列人及其历史上的事迹乃是我们的样式，因为我们若不谨慎，就必与他们相同。我们的结局也必与他们的结局一样。故此他们立在那里，作我们的警戒。他们的遭遇特要警戒我们的，就是贪恋恶事。据民数记 11:4，百姓贪恋，即过度地渴慕埃及的肉锅，说：谁给我们肉吃呢？神将他们所求的赐给他们——“肉在他们牙齿之间尚未嚼烂，耶和华就用极重的灾殃击杀他们，那地方便叫作‘基博罗哈他瓦’（贪欲之人的坟墓），因为他们在那里葬埋那贪欲的人”（民数记 11:34）。参诗篇 78:27-31 及 105:14, 15。这事乃是一个永远的警戒，叫人不可放纵那对禁止之物的无节制欲望。这警戒对哥林多人尤为切合，叫他们不要贪求参与外邦人的祭筵，那筵席原是他们素常纵情其中的。

**7.** <span style="color:#800000">*也不要拜偶像，像他们有人拜的；如经上所记：「百姓坐下吃喝，起来玩耍。」*</span>

哥林多人在这事上所受的诱惑，与以色列人当年所受的一样大，也同样容易陷入拜偶像的行径。以色列人铸造金牛犊时，并不以自己为拜偶像之人；他们不认为第二条诫命禁止人用形像敬拜真神，而他们所要敬拜的，原是耶和华。那筵席也是宣告为向耶和华守的节（出埃及记 32:6）。他们为使用形像所作的辩解，与今日罗马教中人所作的相同；就其实质而言，也与哥林多人为自己迁就异教习俗所作的辩解无异。后者并不以在偶像庙中参与筵席为拜偶像之举。以色列人虽有此等辩解，仍因其罪而灭亡；照样，凡实际上是拜偶像的人，无论自己是否如此看待，也必当预料同样的结局。我们以为某事为是，并不足以使那事成为是。事物的性质不因我们对它的看法而改变。杀人便是杀人，纵然人在自负与骄傲中称之为可容许的杀人。

<span style="color:#800000">*他们坐下吃喝*</span>，即吃喝那在金牛犊面前献与耶和华的祭物——金牛犊乃是创造之能力的象征——又起来<span style="color:#800000">*玩耍*</span>，即跳舞；在古人中间，此种娱乐是与其宗教筵席相连的。参荷马《奥德赛》8:251。

<!-- PAGE 200 -->

**8.** <span style="color:#800000">*我们也不要行奸淫，像他们有人行的，一天就倒下二万三千人。*</span>

拜偶像与行淫向来密不可分，前者鲜有不引人陷入后者的。以色列人的事便是明证。民数记 25:1-9 记着说：<span style="color:#800000">「百姓与摩押女子行起淫乱。因为这女子叫百姓来，一同给她们的神献祭……以色列人归附巴力毗珥。」</span>这巴力毗珥乃摩押人的神明，敬拜之法即以处女卖淫。在那件事上，拜偶像与行淫是不能分开的。哥林多城中最主要的庙宇是献给维纳斯的，向她所献的敬拜，其污秽几与向巴力毗珥所献的不相上下。哥林多人若容让自己进入她的庙中赴祭筵——还借口说偶像算不得什么——又怎能逃脱这样的罪恶呢？

<!-- PAGE 201 -->
<span style="color:#800000">*一天就倒斃了二萬三千人。*</span>在希伯来文圣经、七十士译本中，以及在斐罗、约瑟夫和拉比们的著作里，这数目都作二万四千。两种说法同样正确。事情丝毫不取决于确切的数目。按通常的用法，凡介乎二者之间的任何数目，皆可约略地说成前者或后者。圣经作者的无谬性在于：他们所说的，恰是神的灵所定意要他们说的；而圣灵定意要他们照人的说法而言——称天为坚硬的、称地为平的，并使用整数，并不打算在日常言谈中做到数学般的精确。圣经既是神的灵的产物，故完全是神的；然而它也完全是人的。圣经作者的言谈与写作，恰如处于其境遇中的别人所会言谈与写作的一样，然而却在这样一种感动之下，使他们所说的每一件事都无谬地与圣灵的心意相符。当大师之手抚风琴，我们听见一种声音；当他抚琴瑟，我们听见另一种声音。故此圣灵默示以赛亚时，是一种笔调；默示阿摩司时，又是另一种笔调。摩西与保罗与多数人一样，习于使用整数；他们在默示的感动之下仍使用整数，正如他们使用别的惯常表达方式一样。二人都不打算在数目上说得分毫不差，因为当时的情形并不需要如此。圣经何等奇妙的一部书！它是在一千五百年之久的岁月中，断续写成的，而人竟须抓住这等貌似不确之处，来指控它的无谬性！

**9.** <span style="color:#800000">*也不要试探基督，*</span>[^f16] <span style="color:#800000">*像他们有人试探的，就被蛇所灭*</span>。

<span style="color:#800000">*试探*</span>一词的意思是试验，或指<span style="color:#800000">*尝试*</span>，或指加以试验，其用意或善或恶。神被说成试探他的百姓，是指他试验他们的信心与忍耐，为要操练并坚固这些恩赐（希伯来书 11:17）。撒但与恶人被说成试探他人，是指他们试验人的德行，意在引诱人陷入罪中（加拉太书 6:1；雅各书 1:3；马太福音 4:1 等）。人被说成试探神，是指他们试验神的忍耐、信实或权能（使徒行传 5:9；马太福音 4:7；希伯来书 3:9）。以色列人在旷野中正是这样试探神。他们试验神的宽容，惹动他的怒气。此处的劝勉，是叫我们不可如此<span style="color:#800000">*试探基督*</span>。这就假定了基督对我们拥有权柄，他是我们道德上的治理者，我们要向他交账，他也有权惩罚那些招致他不悦的人。换言之，这段经文假定了：我们与基督所处的关系，乃是理性受造之物唯独能与神所处的关系。因此，基督就是神。至于哥林多人在此所受的警告，究竟是不可像以色列人在所引这一事例中那样，以不耐烦与怨言试探基督；抑或是警戒他们不可无故涉险，以此试验基督的信实（参马太福音 4:7），尚难断定。大概是前者。

<!-- PAGE 202 -->
<span style="color:#800000">*也不要试探主，像他们有人试探的。*</span>既然紧接的上下文提到基督，最自然的补足便是代词<span style="color:#800000">*他*</span>：“我们不可试探基督，像他们试探<span style="color:#800000">*他*</span>一样。”这不但是最自然的解释，且有第4节为证，又合于圣经的类比，因为圣经别处也教导说，那位引领以色列人的乃是神的儿子。惟有出于神学上的成见，就是为要除去本段作为我们主之神性明证的权威，才有人如此解释：“我们不可试探基督，像他们试探神一样。”然而，如此所对付的不过是这论证的一种形式罢了。因为即便照此解释，本段仍旧教导说：我们与基督所处的关系，正如以色列人与神所处的关系。<span style="color:#800000">*就被蛇所灭。*</span>民数记 21:6。百姓因怨言，又因懊悔自己得救脱离埃及，惹动了神的怒气。“于是耶和华使火蛇进入百姓中间，蛇就咬他们，以色列人中死了许多。”哥林多人若耗尽了主的宽容，同样的审判也必临到他们。

**10.** <span style="color:#800000">*你们也不要发怨言，像他们有的人发过怨言，就被灭命的所灭。*</span>

<span style="color:#800000">*发怨言*</span>即怀着悖逆之心而抱怨。此处所指乃民数记 14:2：「以色列众人向摩西、亚伦发怨言；全会众对他们说：巴不得我们早死在埃及地，或是死在这旷野。」第 11、12 节：「耶和华对摩西说，这百姓藐视我要到几时呢？我在他们中间行了这一切神迹，他们还不信我要到几时呢？我要用瘟疫击杀他们，等等。」第 27 节：「这恶会众向我发怨言，我忍耐他们要到几时呢？……他们的尸首必倒在这旷野。」或者所指乃民数记 16 章，其中记载可拉的背叛，以及随后百姓的怨言（第 41 节），因此有一万四千七百人被瘟疫所灭（第 49 节）。此两处的罪过与刑罚都是一样的。<span style="color:#800000">*就被灭命的所灭*</span>，即被神所差遣的使者所灭，那使者以瘟疫为毁灭的工具。故此，毁灭之事有时归于瘟疫，如民数记 14:14；有时归于天使，如此处；有时则将执行者与其所用的工具并提，如撒母耳记下 24:16。参看使徒行传 12:23。

**11.** <span style="color:#800000">*他们遭遇这一切的事，都要作为鉴戒；并且写在经上，正是警戒我们这末世的人*</span>。

<!-- PAGE 203 -->
<span style="color:#800000">*他们遇见这些事*</span>（即不断有这样的事临到），<span style="color:#800000">*都要作为鉴戒。*</span>按字面说，这些事乃是<span style="color:#800000">*预表*</span>，参第6节。这些事被定意作为历史的图画，如加尔文所说，用以显明拜偶像、行奸淫、发怨言等等所招致的后果。<span style="color:#800000">*并且写在经上*</span>云云。记载下来，是要我们从这些作为中得益处，使我们受警戒，好躲避那招来如此审判的罪。<span style="color:#800000">*正是警戒我们这末世的人*</span>（按字面为<span style="color:#800000">*诸世代之末*</span>）。就是说，临到我们这些生活在末后世代之人。时间有时被视为一个整体，故用单数<span style="color:#0000d4">αἰών</span>表达；有时被视为由若干段落所构成，便用复数<span style="color:#0000d4">αἰῶνες</span>表达。因此我们见有<span style="color:#0000d4">συντέλεια</span> <span style="color:#0000d4">τοῦ</span> <span style="color:#0000d4">αἰῶνος</span>与<span style="color:#0000d4">τῶν</span> <span style="color:#0000d4">αἰώνων</span>两种说法，见马太福音 24:3、希伯来书 9:26，二者皆指某一段时间的终结，或视之为一，或视之为由数个时期合成。这类说法有时指犹太体制的终结，标明基督第一次降临之时；有时指现今体制的终结，标明祂第二次降临之时。参马太福音 13:39 等处。至于意义相当的说法，可见以弗所书 1:10 与希伯来书 1:1。既然在希伯来书 9:26 中，<span style="color:#800000">*诸世代的终结*</span>意指犹太体制的结束，那么此处<span style="color:#800000">*诸世代之末*</span>也可作同样解释。或者，就本处而言更为自然的是：其意为我们正生活在分配给这世界、或说分配给现今万事秩序的诸时期中的末一个时期。一系列的世代随基督降临而告终；另一系列，即末后的一系列，如今正在过去。

**12.** <span style="color:#800000">*所以，自己以为站得稳的，须要谨慎，免得跌倒。*</span>

<!-- PAGE 204 -->
这句话表明了使徒引述以色列人历史上述事件的用意。跌倒的危险是常在的。我们已有的长进无论多大，我们所享的特权无论多丰，都不足以成为不加谨慎的理由。<span style="color:#800000">*所以，自己以为站得稳的*</span>，就是说，凡自以为稳妥的人。这既可指对得救的稳妥感，也可指对抵挡试探之力的稳妥感。二者大不相同，所依据的根基通常也各异。对得救的虚假稳妥感，通常建立在自己属于一个蒙特权的团体（教会）或一个蒙特权的群类（选民）之上。这两种想法同样虚妄。教会中人也好，选民也好，若不恒忍于圣洁，就不能得救；而人若不常常儆醒努力，也不能恒忍于圣洁。至于对自己抵挡试探之力的虚假稳妥感，则出于对自身力量过度的自信。最容易跌倒的，莫过于那些自以为刚强、便轻率地投身于试探之中的人。使徒在此警戒哥林多人所防的，大概正是这一种虚假的稳妥感，因为紧接着他就劝勉他们要躲避试探。

**13.** <span style="color:#800000">*你们所遇见的试探，无非是人所能受的；神是信实的，必不叫你们受试探过于所能受的；在受试探的时候，总要给你们开一条出路，叫你们能忍受得住。*</span>

<span style="color:#800000">*你们所遇见的试探*</span>，即<span style="color:#800000">*一切试炼*</span>，无论是以诱惑的形式临到，还是以患难的形式临到，<span style="color:#800000">*无非是人所能受的*</span>；按字面即<span style="color:#800000">*属人的*</span>，是与人的力量相称的，是人所能担当的。“你们所受的试探，并非超乎人力、非同寻常的试探。你们迄今所经历的试炼都是有节制的；神也必不叫你们受过于所能受的试炼。”这是本节通常的解释，其意思简明而自然。然而，这话也可能是说：“要谨慎，免得跌倒。你们至今所经历的试探，比起将来所要遭遇的，还算轻微。”依此看法，这话与其说是安慰，不如说是警告，表明危险尚未过去。据此解释，使徒是指那将要伴随“末后的日子”而来的特殊试炼。既然那日子已近，哥林多人所处的境况便要求格外谨慎。他们不可自投于试探，因为那日子将到，若是能行，连选民也要被迷惑。然而，本节经文中并无现今与将来的对比之意，故通常的解释更为自然。

<!-- PAGE 205 -->
<span style="color:#800000">*然而神是信实的*</span>。祂已应许保守属祂的人，故此祂若容许他们受过分的试探，便与祂的信实相干。在此，正如在 1:9 及圣经其余各处一样，信徒的稳固既不归于重生所注入他们里面之恩典原则的强度，也不归于他们自身的坚定，乃归于神的信实。祂曾应许，赐给圣子作为祂产业的人，永不灭亡。因此他们是"因信蒙神能力保守"，以致得救（彼得前书 1:4）。然而这稳固的应许，乃是脱离罪的稳固之应许，故此那些陷入故意而惯常之罪中的人，并不在此应许之内。他们纵有失足，也是在剧烈的挣扎之后，且不久便再度被更新，归于悔改。信徒的绝对稳固与常常警醒的必要，二者完全一致。神所应许要拯救的人，也是祂所应许要使之警醒的人。<span style="color:#800000">*祂必不叫你们受试探过于所能受的*</span>，即过于所能担当的。这便是祂信实的凭据。<span style="color:#800000">*在受试探的时候，总要给你们开一条出路*</span>。这话的意思或是说，试探来临之时，神必开一条出路；或是说，神既带来试探，也必一同带来出路。按后一意思，神被视为试探的发动者；按前一意思，则不然。因有 <span style="color:#0000d4">σύν</span>（<span style="color:#800000">*与…同*</span>）一词，故当取后者。"祂必<span style="color:#800000">*与*</span>试探一同开一条出路"，即：祂既发动其一，也必成就其二。使徒雅各固然说："神不能被恶试探，祂也不试探人"（雅各书 1:3）。然而那里的<span style="color:#800000">*试探*</span>，意思是引诱，或企图诱人入罪。在此意义上，神不试探任何人。但祂确实常将人的德行加以考验，如亚伯拉罕之事便是。在此意义上，祂便试探或试验他们。使徒在此所说的是：当神如此试验属祂的百姓时，必不过于他们的力量，且祂总要开一条出路，<span style="color:#800000">*叫他们能忍受得住。*</span>这句表明神开出路的旨意所在。（<span style="color:#0000d4">τοῦ</span> <span style="color:#0000d4">δύνασθαι</span> 等属格，乃表目的之属格。）

<p style="text-align:center" markdown="1"><span style="color:#0000d4">**证明赴异教庙宇中的**</span> <span style="color:#0000d4">**祭筵即是拜偶像。14-22节。**</span></p>

<!-- PAGE 206 -->
这全段讨论，起因于一个问题：献给偶像之祭物是否可以吃。保罗虽承认吃这类祭肉本身并无不可，却劝哥林多人为软弱的弟兄之故而戒绝不吃。此外还有一个当戒绝的理由：他们可能因此被引入拜偶像之事。人若行到可容许之事的边缘，便容易被牵入有罪之事。哥林多人既确信偶像算不得什么，就极有可能被诱去参加庙宇范围之内的祭筵，这危险实在不小。而危险之所以更大，是因为同样的筵席若设于私人家中，便失去其宗教性质，人赴席可以毫无顾忌。本段的目的，正是要使读者确信：筵席若设于庙中，赴席便是拜偶像之举。

使徒的论证出于类比。领受主的晚餐，乃是与基督（基督教敬拜的对象）相交，并与一切同我们一起领受之人相交。就其本质而言，凡分领饼与杯的人，都因此进入与基督并彼此之间的团契，第14-17节。犹太人的祭祀亦是如此。凡吃那祭物的，就因此与犹太敬拜的对象相交。这行为本身即是敬拜之举，第18节。结论明显之至，无须明言——凡参与外邦人祭筵的，就是参与拜偶像。这行为的意义本是如此，行此事之人纵然否认，也不能改变其性质。

然而，不可由这样的推论方式断定：外邦敬拜的对象果真如外邦人所设想的那样存在。保罗既论证说，领受主的晚餐既是基督教敬拜之举，参加偶像的筵席便必是外邦敬拜之举，我们却不可因此推断他视丢斯或希拉为与基督一样真实的存在。绝非如此。外邦人所献的祭，是献给鬼魔的；因此，在使该行为具有宗教意义的情形下分领他们的祭物，便使他们进入与鬼魔的相交，第19、20节。这两者断不相容。人不能既作基督的敬拜者，又作鬼魔的敬拜者；也不能一面与这一位相交，一面与那一者相交。赴主的筵席，就是弃绝鬼魔；赴鬼魔的筵席，就是弃绝基督，第21节。他们如此行事，必激动主的忌邪之心与他们为敌，正如古时犹太人偏离去随从假神，激动主的忌邪一样，第22节。

**14.** <span style="color:#800000">*所以，我所亲爱的弟兄啊，你们要逃避拜偶像的事*</span>。

<!-- PAGE 207 -->
<span style="color:#800000">*所以*</span>，就是说：因为如此严厉的刑罚临到了拜偶像的以色列人；因为你们与他们一样，都有陷入那罪的危险；又因为你们那些卓越的特权，既不能保你们免于此罪，也不能保你们免于此罪的刑罚，正如他们的特权也未曾保住他们。<span style="color:#800000">*我所亲爱的*</span>——保罗以慈爱之词称呼他们，虽然他这封书信满是严肃的劝诫与警告。<span style="color:#800000">*你们要逃避拜偶像的事*</span>，即以逃离的方式躲开它。这是躲开罪的唯一稳妥之法。罪的存在如瘴气一般，唯有远离方为安全。这包含两件事：第一，避开一切可疑之事，即凡处在可行之事边界上的、或临近罪之疆界的一切；第二，避开犯罪的机会与诱惑，凡能激动邪情、或易于罗网人心灵的，都当远离。

**15.** <span style="color:#800000">*我好像对明白人说的，你们要审察我的话。*</span>

<span style="color:#800000">*我好像对通达人说的*</span>；即，如同对有见识之人说话，对能够看出论证力量之人说话。保罗在此并非诉诸权威，无论是他自己的权威，还是圣经的权威。整个问题在于：某一项事奉是否落在圣经对拜偶像所下的定义之内。他仿佛甘愿把裁断之权交与他们自己，故此说，<span style="color:#800000">*你们要审察我的话*</span>，即：请你们对我所提出的论证加以判断。倘若他们与使徒的看法相左，事情本身也不会因此改变。那事奉既是拜偶像，无论他们如何看待，都仍是拜偶像。但使徒采取这样的方式来使他们信服。

**16.** <span style="color:#800000">*我们所祝福的杯，岂不是同领基督的血吗？我们所擘开的饼，岂不是同领基督的身体吗*</span>？

<!-- PAGE 208 -->
此处的前提是：领受主的晚餐使我们与基督相交。若果真如此，那么领受鬼魔的筵席也必使人与鬼魔相交。这就是使徒的论证。它建基于这一前提之上：同领这杯，就是同领基督的血；同领这饼，就是同领基督的身体。在这一点上，罗马天主教徒、路德宗信徒与改革宗信徒对这段重要经文的解释是一致的。他们都同意：同领这杯，即是同领基督的血；同领这饼，即是同领基督的身体。然而，一旦追问这"同领"的性质究竟为何，所给出的答案便有根本的分歧。改革宗从反面回答说，这"不是按着肉身或血气的方式"；也就是说，不是藉着口，也不像领受寻常食物那样。从正面而言，他们回答说，乃是藉着信心，因而是藉着灵魂。这自然也就决定了所领受之物的性质，即基督的身体与血是在何种意义上被领受的。倘若领受不是藉着口，而是藉着信心，那么所领受的便不是物质的身体与血，而是作为祭物的身体与血，也就是其献祭的功效。因此，一切改革宗教会都教导（甚至英国国教的礼文规程亦然）：基督的身体与血也可在主的桌子以外之处领受，且不必领受饼与酒——在圣礼中，饼与酒不过是身体与血的表记，是传通的器皿，正如在别处道乃是这样的器皿。改革宗教义中另有一点同样清楚：既然基督的身体与血是藉着信心领受的，那么不信的人便不能领受。

罗马教会对上述问题的回答是：口乃领受的器官；所领受之物乃基督真实的身体和血，饼与酒的实质藉祝圣之举已变成基督的身体和血；因此，信者与不信者同样是领受者。路德宗则教导说，饼与酒虽未改变，然而基督的身体和血既在圣礼中于饼酒之内、之下、与饼酒同在，按处所而临在，故领受的器官乃是口；所领受之物乃基督真实的身体和血；且信者与不信者所领受的相同、相等；只是不信者领受，反招损害与定罪，信者领受，则得灵性的滋养与恩典中的长进。路德宗与罗马教会更一致教导说，主的晚餐中有一种对基督身体和血的领受，是在别处所不能有的。

此三者，乃教会在此题目上历来所持的三大教义形态；而本段经文，各家皆按其独有的观点加以解释。这段经文本身并未裁定任何争端。倘若罗马教会的化质说能从别处得着证明，那么这段经文自然须按其教义来理解。倘若路德宗的合质说能藉神话语中其他的宣告得以确立，那么这段经文也须按那教义来解释。然而，倘若从圣经、并从神铭刻在我们本性中的那些信念法则，能清楚证明这些教义乃是虚妄的，那么这段经文所教导的，就必是在灵里、而非在肉身上有分于基督的身体和宝血。这段经文所断言的，不过是"有分"这一事实；至于这有分的性质如何，则须由别的根据来断定。

<!-- PAGE 209 -->
<span style="color:#800000">*我们所祝福的杯*</span>。（<span style="color:#0000d4">εὐλογέω</span>）一词，即<span style="color:#800000">*祝福*</span>，其含义有：<span class="enum-num">1.</span> 称颂、说其好处。

<span class="enum-num">2.</span> 称颂、感谢，如我们称颂神时便是。3. 赐下祝福，如神赐福与我们时便是。因着第二种含义，此字与（<span style="color:#0000d4">εὐχαριστέω</span>）<span style="color:#800000">*祝谢*</span>可以互换使用。就是说，同一个举动，有时用这个字表述，有时用另一个字表述。马太福音 26:26 与马可福音 14:22 中以<span style="color:#800000">*祝福了*</span>所表述的，在路加福音 22:17、19 和哥林多前书 11:25 中则以<span style="color:#800000">*祝谢了*</span>来表述。而在马太、马可所记主的晚餐一事中，论到饼用了这一个字，论到杯又用了另一个字。所以二者所指相同，或不如说所表述的是同一举动，因为那一举动既是祝福，也是感谢；即是向神的祷辞，承认他的怜悯，并求他赐福，故此既可用祝福一词表述，亦可用感谢一词表述。

在这些经文中，不必断定（<span style="color:#0000d4">εὐλογήσας</span>）<span style="color:#800000">*祝福了*</span>是取（<span style="color:#0000d4">εὐχαριστήσας</span>）<span style="color:#800000">*献了感谢*</span>这一狭义。事实上不可能如此，因为（<span style="color:#0000d4">εὐλογήσας</span>）的宾语，至少在其中若干处，并非神，而是那饼或那杯。其意乃是"祝福了那饼"。因此，就字义而论，<span style="color:#800000">*祝福之杯*</span>一语既可译作感谢之杯（即感恩之杯），也可译作祝谢之杯，即被分别为圣之杯。后者无疑是真正的含义，因为紧接着便有解释：<span style="color:#800000">*我们所祝福的*</span>。被祝福的是杯，而非神。若将此语按主动之意理解为<span style="color:#800000">*赐下祝福之杯*</span>，则不仅与用法不合，且与紧随其后的解释相冲突。祝福之杯就是我们所祝福的杯。在逾越节的礼仪中，那杯被称为"祝福之杯"，因为有祝谢之辞在其上宣告。分别为圣的意思必然包含在内。酒作为酒本身，并非基督之血的圣礼象征，唯当其被郑重分别为此用途时才是。甚至我们日常的饮食也被说成"藉着神的道和人的祈求成为圣洁"（提摩太前书 4:5），因为它藉宗教性的礼仪被分别出来，归于所定的目的。照样，祝福之杯就是那藉着在其上所宣告的祝谢之辞，"从平常之用分别出来归于神圣之用"的杯。

<!-- PAGE 210 -->

<span style="color:#800000">*我们所祝福的*</span>。这是对前一分句的解释。祝福之杯就是我们所祝福的杯；此语只能指我们为之祈求祝福的杯，也就是我们祈求神使之成就其所设立之目的的杯，即成为我们所领受的基督之血。换言之，成为将基督之死的益处传通与我们的凭借。正如我们为食物祝谢，祈求神使之成为滋养我们身体的凭借一样。对此分句的其余解释都不自然，因为它们都须补入原文所无的成分。于是有人说，其意乃是“拿起它”而祝谢，或“手中持定它”而祝谢，或“在其上”祝谢。凡此皆属多余，因为经文照其本来的样子（<span style="color:#0000d4">ὁ</span> <span style="color:#0000d4">εὐλογοῦμεν</span>）已有极完好的意思：<span style="color:#800000">*我们所祝福的*</span>（杯）。故此，这一段似乎断定了马太福音 26:26 与马可福音 14:22 一类经文的意思：“祝福了（即祝福那饼），就擘开。”受祝福的乃是那饼或那杯。可比照路加福音 9:16，那里说我们的主“拿着这五个饼、两条鱼，望着天祝福<span style="color:#800000">*它们*</span>”。这也表明，在此类上下文中，“祝谢了”乃是“以感谢之心祈求神的祝福”之意。所以，那杯是藉着祷告而受祝福的，我们在祷告中祈求神使它成就其所设立之目的。

<!-- PAGE 211 -->
<span style="color:#800000">*岂不是同领基督的血吗*</span>？意即：这岂不是与基督的血有份的途径吗？凡领受这杯的，就与基督的血有份。当然，这惟独就信徒而言。保罗是写给信徒的，并假定领受者心中有信心。同样，圣经也说洗礼洗去罪恶，说神的道使人成圣；这并非因洗礼与道本身含有某种能力，也不是就外在礼仪或临于外耳的言语而言，更不是对一切凡受洗或凡听道之人一概而论；乃是因它们是神所设立的媒介，当人以信心领受、又有圣灵运行相伴之时，便生此功效。以信心领受这杯与得与基督的血有份，其相连之确定，正如以信心领受神的道与经历道中赐生命的大能相连一样。使徒全部的论证都建基于此。他要证明：吃外邦人祭偶像的筵席，实在使人与鬼魔相交，因为领受主的晚餐实在使我们与基督有份。<span style="color:#0000d4">κοινωνία</span> 一词，<span style="color:#800000">*相交*</span>，意即<span style="color:#800000">*有份*</span>，出自动词 <span style="color:#0000d4">κοινωνέω</span>，<span style="color:#800000">*与……有份*</span>；希伯来书 2:14 说，基督也照样亲自成了血肉之体（与血肉之体有份）。罗马书 15:17 说，外邦人在犹太人属灵的福分上有份。因此便有以下诸般说法：与他儿子有份，哥林多前书 1:9；与圣灵有份，哥林多后书 13:13，腓立比书 2:1；在这供给圣徒的事上有份，哥林多后书 8:4；在福音上有份，腓立比书 1:5；在苦难上有份，腓立比书 3:5。当然，这“有份”的性质，取决于所份之对象的性质。与基督有份，是分享他的灵、他的品格、他的苦难与他的荣耀；与福音有份，是分享福音的益处；照此，与基督的血有份，便是分享其血的功效。此节丝毫不能为罗马教或路德宗所谓领受基督身体与血之实质的教义提供根据。1:9 说“我们蒙召与他儿子一同得分”时，我们所得之分并非神性的实质。使徒约翰说“我们就彼此相交”，即我们彼此互为（<span style="color:#0000d4">κοινωνοί</span>）同伴，约翰一书 1:7，他并非指我们分享彼此肉身的实质。分享一场为我们献上的祭，就是分享其功效；既然基督的血是指他为祭所流的血，那么与他的血有份，并不比“他的血洗净一切的罪”这话意味着他肉身的血本身具有洁净之功效更多。经上说我们受了他血所洒，彼得前书 1:1，也不是指他肉身的血。

<!-- PAGE 212 -->
<span style="color:#800000">*我们所擘开的饼，岂不是同领基督的身体吗*</span>？意即：我们藉着领受这饼，便与基督的身体有分。这不过是重述前一分句所含的思想。杯是与祂的血相交的凭藉，饼是与祂的身体相交的凭藉。<span style="color:#800000">*基督的身体*</span>在此不能指教会，因为祂的血也在同一处一并提及；又因在主的晚餐的设立之时，饼乃是基督真实身体的象征，而非祂奥秘身体的象征。与祂的身体有分，就是分享祂身体为我们擘开所带来的益处。<span style="color:#800000">*我们所擘开的*</span>。这显然是暗指圣礼当初设立之事。我们的主"拿起饼来，祝谢了，就擘开，说：'你们拿着吃，这是我的身体，为你们擘开的。'"哥林多前书 11:24。因此，整个礼仪常被称为"擘饼"。使徒行传 2:42；20:7。所以，那将未曾擘开的薄饼放入领受者口中的习俗，便把这圣礼中一个意义重大的要素遗漏了。

**17.** <span style="color:#800000">*我们虽多，仍是一个饼，一个身体，因为我们都是分受这一个饼。*</span>

按字面直译，本节当作：<span style="color:#800000">*因为饼只有一个，我们虽多，仍是一个身体；因为我们都是分受这一个饼。*</span>经文并未说我们是一个饼；乃是说我们因分受一个饼，故成为一个身体。使徒的用意，是要表明凡来领受主的晚餐的人，都与其余一切领受者进入相交。他们因共同有分于基督，遂成为一个身体。既然如此，那些参加异教献祭筵席的人，也就构成一个宗教团体。他们彼此处在宗教的相交之中，因为他们与那些作其敬拜最终对象的鬼魔相交。然而，许多著名的注释家更倾向于如下的解释：“因为我们虽多，仍是一个饼、一个身体。”同领一个饼使我们成为一个饼，共同有分于基督的身体使我们成为一个身体。至少可以说，这是一个不寻常且生硬的比喻。圣经从未说信徒是一个饼；而以饼乃由许多麦粒合成这一点作为比较的根据，也过于牵强。至于说我们实实在在是一个饼，因为借着同化作用，饼进入了一切领受者身体的构成之中，这无异于让使徒教导近代的生理学。

在前一节所用的 <span style="color:#0000d4">κοινωνία</span> <span style="color:#800000">*同领*</span> 一词中，含有共同participate、即共同有分之意。“我们所擘开的饼，乃是同有分于基督的身体；因为（<span style="color:#0000d4">ὅτι</span>）饼既是一个，我们也就成为一体。”此处所要证明的，乃是凡分领这一个饼的人彼此的联合。许多注释家不将本节与第16节相连、视之为对该节所言的印证，反而把它当作一个独立的句子，引出一句附带的评论：“主的晚餐使我们与基督相交。既然如此，我们就是一体，*行事也当与此相称*。”然而这样解释不但割断了上下文的关联，且加入了经文所无的意思。其真意乃是：“领受圣礼即是同领，因为我们众人都是分领这一个饼。”

**18.** <span style="color:#800000">*你们看属肉体的以色列人；那吃祭物的，岂不是在祭坛上有分吗？*</span>

<span style="color:#800000">*属肉体的以色列人*</span>，即作为一个民族的犹太人，与<span style="color:#800000">*属圣灵的*</span>以色列人，或说属灵的以色列、神真正的百姓相区别。因"以色列"素来是极尊荣的称号，保罗甚少不加此类限定语而径以此称犹太民族。参罗马书 2:28；9:8。加拉太书 4:29；6:16。

<!-- PAGE 214 -->
<span style="color:#800000">*吃祭物的人*</span>。在犹太人中，如同在其他民族中一样，大多数祭物只有一部分焚烧在坛上，其余则由祭司与献祭者分而食之。利未记 7:15；8:31。申命记 12:18。按摩西律法所规定的方式吃祭物，即是参与整个献祭之礼。「要在耶和华你神面前，在耶和华你神所要选择的地方吃。」申命记 12:18。因此使徒说，凡吃祭物的人便是<span style="color:#800000">*与祭坛有分*</span>；也就是说，他们与祭坛相交，成为那坛所归奉之神的敬拜者。这就是参与此等祭筵的意义与效果。问题不在于行事者的意图如何，而在于此举本身的意义，以及世人普遍加于此举的解释。以祭物为祭物、并在圣所之内吃犹太人的祭物，就是一种犹太教的敬拜行为。依同一道理，以祭物为祭物、并在庙宇之内吃外邦人的祭物，也必然是一种异教的敬拜行为。犹太人的祭祀惟犹太人得以参与，凡参与者皆自认为犹太人，自认与人同奉耶和华；他们既与祭坛相交，就不能不彼此相交。同理，凡参与外邦人祭筵者，也就使自己与拜偶像之人进入了宗教上的相交。至于有人据此段以为主的晚餐乃是一种祭祀，则几乎不必置辩：此处所比较的并非此点。使徒的论证并不含有这样的意思，即因犹太人与外邦人的筵席乃是祭筵，所以基督徒的筵席也具有同样的性质。其全部重心乃在<span style="color:#0000d4">κοινωνία</span>一词上：「因参与基督教的圣礼便含有与基督相交，故参与异教的祭礼便含有与鬼相交。」

**19.** <span style="color:#800000">*我是怎么说呢？岂是说偶像算得甚么呢？或说祭偶像之物算得甚么呢*</span>？

这句话显然是要防止有人从上述推理中得出错误的结论。使徒既已如此说了，却不可由此推断：他认为外邦人所敬拜的那些对象，与犹太人和基督徒所敬拜的神一样具有客观的实在性；也不可推断他认为外邦人的祭物本身带有什么能力。偶像算不得什么，献给偶像之物也算不得什么。然而这并不改变事情的实质。因为，尽管并不存在外邦人心中所设想的那些神明，尽管他们的祭物也并非他们所以为的那样，他们的敬拜仍是真真实实的拜偶像，并且对灵魂有毁坏的作用。至于其中的缘由，下一节便有解释。

**20.** <span style="color:#800000">*我乃是说，外邦人所献的祭是献给鬼的，并非献给神；我不愿你们与鬼相交。*</span>

这就是说：『我并非说外邦人的神明真有其实存，说真有丘比特或密涅瓦这样的位格；我所说的乃是：外邦人的敬拜就是敬拜鬼魔。』本节引出两个当加考究的问题。第一，保罗在此使用<span style="color:#0000d4">δαιμόνια</span>一词（译作<span style="color:#800000">*鬼魔*</span>）是在何种意义上说的；第二，在何种意义上可以真确地说，外邦人所敬拜的乃是鬼魔。

<!-- PAGE 215 -->
<span style="color:#0000d4">δαίμων</span> 与 <span style="color:#0000d4">δαιμόνιον</span> 二词，希腊人用以指任何神明、神祇或灵体，一般也用以指任何受人敬畏或惧怕的对象。新约中唯一在此意义上使用该词的地方是使徒行传 17:18（"他似乎是传说外邦鬼神的"）。在别处，这些词一概指堕落的天使。我们的译者未能持守新约在使用 <span style="color:#0000d4">διάβολος</span> 与 <span style="color:#0000d4">δαιμόνιον</span> 二词时始终作出的区分。他们将两词都译作 <span style="color:#800000">*devil*</span>（鬼魔），因此当后者以复数形式出现时，便译作 <span style="color:#800000">*devils*</span>。然而前者在圣经中（除去其"控告者"这一称谓性含义外）从未用于撒但以外的任何存有。他就是那魔鬼，圣经从不说有一个以上的魔鬼。所以此处所谓的 devils，当理解为 <span style="color:#800000">*demons*</span>（鬼魔），即堕落的天使或邪灵。此处希腊文一词当取此义，理由甚明：<span class="enum-num">1.</span> 因为这是它在圣经中唯一的用法。使徒行传 17:18 那一处乃是雅典人的话，无从证明说希腊话的犹太人如何使用此词。2. 在七十士译本中，我们所见的正是使徒所用的词，且是同一意义。见申命记 32:17。另见诗篇 95:5，七十士译本作 <span style="color:#0000d4">ὅτι</span> <span style="color:#0000d4">πάντες</span> <span style="color:#0000d4">οἱ</span> <span style="color:#0000d4">θεοὶ</span> <span style="color:#0000d4">τῶν</span> <span style="color:#0000d4">εθνῶν</span> <span style="color:#0000d4">δαιμόνια</span>，<span style="color:#800000">*外邦人的神都是鬼魔*</span>。使徒有意按此词在圣经中确立的意义来使用它，这几乎是无可置疑的。

另参启示录 9:20。3. 该词在古典希腊文中的含义与上下文不合。保罗方才说过，异教的神明算不得什么；若此时承认按希腊文<span style="color:#0000d4">δαιμόνιον</span>一词的意义确有<span style="color:#800000">*诸神*</span>存在，便是自相矛盾了。因此我们必须这样理解使徒的话：一方面，外邦人的神祇乃是虚构之物；另一方面，他们的祭物实在是献给了邪灵。然而，这话在何种意义上为真呢？

异教之人固然并非有意敬拜恶魔，然而他们所行的实是如此。世上的人在追求所欲之物而违犯神的律法时，也并非有意事奉撒但；但他们如此行，实在是顺从了那大仇敌的意旨，屈从他的推动，成就他的计谋。故此撒但被称为这世界的神。凡一切罪恶，对他而言都是献祭与尊崇。我们或敬拜神，或敬拜撒但，二者之外别无余地；因为凡拒绝或忽略敬拜真神，或将独归于神的敬拜献与他者，便是敬拜撒但及其使者。所以，就最深的意义而言，异教之人所献的，实在是献给鬼魔。他们的神虽本无实存，然而确有真实的存在者，即这世界黑暗的掌权者、天空属灵气的恶魔（以弗所书 6:12），他们的敬拜终归于这些恶者。

<!-- PAGE 216 -->

<span style="color:#800000">*我不愿意你们与鬼相交*</span>。此处所说的<span style="color:#800000">*相交*</span>或交通，使徒所指的与前几节中同一词语的意思相同。凡彼此心志相合、利益相共、往来亲密者，即可说是有相交。在此意义上，我们与众信徒相交，与神并与他儿子相交。也正是在此意义上，拜偶像的人与邪灵相交。他们与邪灵联合，同属一个团体，同有一种品性，同归一个结局。他们藉着向邪灵献祭，即藉着拜偶像，便进入这种相交的地位；而拜偶像乃是背离真神、投靠黑暗国度的行为。哥林多人极需知道：他们是否与鬼相交，并不取决于他们的存心如何。外邦人并非有意要敬拜鬼，然而他们所行的实是拜鬼；那么，那些赴外邦祭筵的哥林多人，纵然轻率地声称自己并无敬拜偶像之意，又有何用呢？问题不在于他们意欲何为，而在于他们实际所行；不在于他们存心如何，而在于其行为的含义与后果如何。人将手伸入火中，不必存心要烧伤自己；人流连于罪恶之地，也不必存心要污秽自己的灵魂。后果与他的存心毫无关系。此原则同样有力地适用于今日随从外邦人宗教礼仪的事。凡在异教之地参与外邦人宗教仪式的人，其拜偶像之罪与哥林多那些挂名的基督徒毫无二致，其被带入与鬼相交之中也同样确实无疑——那些人虽知偶像算不得什么，也知神只有一位，却仍赴外邦人的筵席。这同一原则也适用于更正教徒随从天主教徒宗教礼节之事。无论其存心如何，若他们与那些存心敬拜圣体的众人一同向圣体屈身，他们便是在敬拜圣体。因着行为本身的效力，我们便与那些同我们一齐敬拜的人合而为一。我们与他们、并与他们所敬拜的对象，构成同一交通体。

**21.** <span style="color:#800000">*你们不能喝主的杯，又喝鬼的杯；不能吃主的筵席，又吃鬼的筵席。*</span>

<!-- PAGE 217 -->

<span style="color:#800000">*主的杯*</span>就是使我们与主相交的那杯（16节）；<span style="color:#800000">*鬼的杯*</span>就是使我们与鬼相交的那杯。使徒所指的，并非专指或特指那奠祭之杯，即倾倒出来献与诸神的酒，而是指在这些祭筵上众客所饮的杯。整个筵席都带有宗教性质：席上一切食物，无论酒或肉，都奉偶像之名受祝，因而被分别为圣归与偶像，其方式与主的桌子上饼与酒被分别为圣归与主相类；参撒母耳记上 9:12, 13。<span style="color:#800000">*主的桌子*</span>乃是主亲自主持的桌子，他的百姓在其上作他的客。<span style="color:#800000">*鬼的桌子*</span>乃是鬼所主持的桌子，一切在席之人都作鬼的客。使徒的意思是说：一个人既作基督的客与友，又作邪灵的客与友，这不仅不相宜、不相合，而且是根本不可能的事。这正如同一个人不能同时是黑的又是白的，同时是邪恶的又是圣洁的。无论在哪一种情形下，这样的赴席都不是虚空无效的举动。人不能吃鬼的桌子上的东西而不落在鬼的权势与影响之下；我们也不能吃主的桌子上的东西而不与他有所接触——或得救，或受审判。我们若轻率而来，全无与基督相交的愿望，便是吃喝自己的罪了。但我们若存谦卑之心而来，愿意顺服我们神圣的主，寻求他的同在，就必蒙悦纳、蒙赐福。关于本节，可参哥林多后书 6:14-18。

**22.** <span style="color:#800000">*我们可惹主的愤恨吗？我们比他还有能力吗？*</span>

<!-- PAGE 218 -->
嫉妒乃是爱受了伤害而生的情感，是人一切情欲中最猛烈的。因此，圣经用它来说明神对偶像崇拜的恨恶。这好比新妇将自己的爱慕，从那在各方面都配得她爱的合法丈夫身上，转移到某个卑贱可憎之物上去。这一比喻虽然软弱，却是从人间关系中所能借取的最有力的比喻，圣经也屡屡用它来显明拜偶像之罪何等可憎。申命记 32:21，诗篇 78:58，以及别处。<span style="color:#800000">*我们可惹主的愤恨么*</span>，意即，我们的目的岂是要惹动主的嫉妒么。哥林多人不应赴这些筵席，除非他们有意最大限度地招惹主向自己发怒。而他们也不应如此惹动他的忿怒，除非他们<span style="color:#800000">*比他还有能力么*</span>。<span style="color:#800000">*主*</span>按上下文当指基督。所离弃的是主的筵席，所惹动嫉妒的也正是这同一位主。在此又一次表明，基督徒与基督所处的关系，与以色列人与耶和华所处的关系相类。故此，基督就是我们的耶和华。他是我们的丈夫，我们至高的爱慕当归于他，他也如丈夫爱妻子一般爱我们。「因为造你的是你的丈夫，万军之耶和华是他的名」，以赛亚书 54:5；参以弗所书 5:25-31。

<p style="text-align:center" markdown="1"><span style="color:#0000d4">**在何种情形之下，吃祭偶像之物是可行的。**</span> <span style="color:#0000d4">**第23-33节。**</span></p>

使徒在前段已证明：凡在使情形带有宗教性质的场合下吃献给偶像之物，即是拜偶像；如今他转而说明，在何种情形之下，这些祭物可以毫无顾虑地食用。他先回到基督徒自由的一般原则，并加上与第 6:12 相同的限制。使用献与偶像之物的权利，正如使用其他本身无关紧要之物的权利一样，要受合宜与否的限制。在此事上，我们应以顾念他人的益处与自己的造就为准，第 23、24 节。倘若祭肉在市上出售，第 25 节，或在私人筵席上遇见，第 27 节，都可以毫不迟疑地吃。但若在私人筵席上，有人因良心上的顾忌而告知我们某道菜中有祭物的成分，那么为他的缘故，而非为我们自己的缘故，我们就当禁食，第 28 节。我们不可这样使用自己的自由，以致我们所以为好的反被人毁谤，第 29 节。行事的总则，不但关乎饮食，也关乎一切别的事，其一是行事当顾念神的荣耀，第 31 节；其二是行事当避免叫任何一类人跌倒（即成为他人犯罪的机会），第 32 节。在此事上，保罗以自己为众信徒的榜样，第 33 节。

**23.** <span style="color:#800000">*凡事我都可行，但不都有益处；凡事我都可行，但不都造就人。*</span>

<!-- PAGE 219 -->
使徒在第六章12节及第八章中，已经承认吃献给偶像的祭物本身乃是无关紧要之事。然而，对无关紧要之事的使用，却受两个原则的限制：第一，顾念他人的益处；第二，顾念自己的益处。（<span style="color:#0000d4">συμφέρει</span>）<span style="color:#800000">*有益的*</span>一语表达前一层意思，（<span style="color:#0000d4">οἰκοδομεῖ</span>）<span style="color:#800000">*造就人*</span>则表达后一层意思。凡事并非都对他人有益或有用；凡事也并非都能造就我们自己。后一语固然也可指向他人，如同指向我们自己一样——但既与前一分句相对而言，此处似是取其较狭的用法。照此看来，它与第六章12节“我却不受它的辖制”一语相合。

**24.** <span style="color:#800000">*无论何人，不要求自己的益处，乃要求别人的（益处）。*</span>

就是说，人人在运用自己的自由时，都当顾念他人的益处。这条准则确实是普遍适用的。不单在无关紧要之事的运用上，就是在其余一切事上，我们行事也不当单顾自己的利益，而应兼顾他人的好处。换言之，自我不应成为我们行事的目标。然而上下文表明，使徒的意思是要将这条准则应用于所论的这个题目上。「别人的 wealth」，即别人的<span style="color:#800000">*益处*</span>或福祉——按 wealth 一词的古义，正是此意。

**25.** <span style="color:#800000">*凡市上所卖的，你们只管吃，不要为良心的缘故问什么话；*</span>

凡使献祭之举失去宗教性质的情形之下，祭肉皆可食用——这一总原则，在此处及下文被应用于若干具体情形。肉类一旦陈列于市场公开售卖，便丧失其作为祭物的性质，食之无碍。<span style="color:#0000d4">μάκελλον</span> 一词是拉丁文转入希腊文的借词，意即<span style="color:#800000">*肉市*</span>。

<span style="color:#800000">*只管吃，不要为良心的缘故问什么话*</span>。此句可有三种解释。

<!-- PAGE 220 -->
<span class="enum-num">1.</span> 其意或为：“你们上市场买东西，只管照自己所要的买，不必在这事上存良心的顾虑。你们无需有良心上的犹疑，因此也不必追问这肉是否曾献给偶像。”这是最简明、最自然的解释。这几节包含了全段讨论的结论。偶像算不得什么；祭物本身也毫无神圣之处；然而外邦人实际上乃是敬拜邪灵，故此若以祭物为祭物而吃，与他们的敬拜有分，便是拜偶像；但若只当作食物来吃，则是无关紧要之事；所以不要将它当作良心的问题。下一节印证了这一解释，因为那一节说明了我们在此事上无需顾虑的理由。

<span class="enum-num">2.</span> 或者，其意乃是：不要发问，免得在自己心里引起疑惑。人若不知某肉是祭物，便可凭无亏的良心而食；但他若得知这肉曾献与偶像，就必生出严重的疑虑。因此，为自己的缘故，不发问乃是明智之举。然而，保罗断不会劝人蒙着眼睛行事。人若认为吃祭偶像之物是错的，那么他在陈列祭物出售的市场上买肉，以致冒着吃到祭物的风险，这在他就是错的。

<span class="enum-num">3.</span> 另有人认为，使徒在此是要警戒刚强的人不可提出这类查问，以免在他人心中生出疑惑来。支持此说的理由是：使徒在整段讨论中，一贯的目的都是劝导刚强的人尊重软弱之人良心上的顾虑。而在第29节中，他更明说自己所指的是别人的良心。

前一项理由分量不重，因为此处所给的是适用于各类人的普遍训诲。使徒在上文既已表明，在某些情形之下吃这等祭物即属拜偶像，那么他接着告诉刚强的人和软弱的人，在何种情形下可以毫无顾虑地吃，乃是极其自然的事。至于第二项理由，它与其说有利于这种解释，不如说反倒不利于这种解释。因为使徒若在指别人的良心时明说是别人的良心，那么可以推知，凡他未作此等说明之处，所指的便是本人自己的良心。况且下一节所陈明的，乃是我们在此事上何以不必存什么顾虑的缘由，而非我们何以当顾念他人顾虑的缘由。

**26.** <span style="color:#800000">*因为地和其中所充满的，都属乎主。*</span>

<!-- PAGE 221 -->

这是犹太人饭前谢恩的通常用语，乃是承认神为万物之主、万物之赐予者，尤其承认他为儿女预备了食物。这句话取自诗篇24:1。<span style="color:#800000">*地的丰富*</span>指充满其中的一切，即遍布地上的各样果实与走兽；这些都是神所造的，因此都是好的。故此，凡按其受造之目的而顺服使用之物，其本身皆不能玷污人。既然献祭的牲畜本是要作人的食物，那么以此为用的人就不会因之受污。使徒举出这个理由，是要表明：就神一方面而言，哥林多人吃那祭过偶像之物，无须心存疑虑。它既是神所造之物，就不当视为不洁。可比较提摩太前书4:4，那里所教导的是同一道理，也出于同一目的。

**27.** <span style="color:#800000">*倘有一个不信的人请你们赴席，你们若愿意去，凡摆在你们面前的，只管吃，不要为良心的缘故问什么话*</span>。

正如祭物一经在市上出售，便失去其宗教性质，同样，在任何私人的席上，这些食物也不当视为祭物，而应视为寻常饮食，可以毫无疑虑地吃。使徒并未禁止基督徒与外邦人有social往来。若受邀赴他们的筵席，他们尽可前去。

**28.** <span style="color:#800000">*若有人对你们说，这是献过祭的物，就要为那告诉你们的人，并为良心的缘故不吃。因为地和其中所充满的都属乎主*</span>：

<!-- PAGE 222 -->
这是一个例外。凡摆在他们面前的，他们本可毫无顾忌地吃。但若同席的人中有谁告知他们，某一道菜乃是祭过偶像之物，那么，出于对那作此提醒之人良心顾虑的顾念，他们就当禁戒不吃。<span style="color:#800000">*但若有人*</span>。即同席之人中的任何一位。会作此提醒的，多半只能是一位心存顾忌的基督徒。<span style="color:#800000">*为那指示你们的人，并为良心的缘故*</span>；后一句是对前一句的解释。意即：“为那作提醒之人的缘故，也就是为他良心的缘故。”虽然吃是可以的，你也确知这是可以的，然而为免伤害或搅扰你软弱弟兄的良心，你就有责任禁戒不吃。在这整段议论中所显明的，乃是最开明的自由与最谦卑地迁就他人软弱二者的结合，实在足以令人由衷敬佩。他是那一世代中最有见识的人，却在一切无关紧要的事上最肯让步、最肯迁就。

本节末尾的“因为地和其中所充满的都属乎主”一语，最佳的抄本中并无此句，故希腊文新约的各种校勘本皆将其删去。此语置于此处，显然全不相宜。在第26节中，这话说明了哥林多人何以可以毫无疑虑地吃市上所卖的一切；但在此处，它与上文毫无关联。地既属乎主，这一事实并不能成为我们为顾念弟兄的良心而<span style="color:#800000">*不吃*</span>祭偶像之物的理由。因此，此句当予删去，几无可疑。

**29、30节。** <span style="color:#800000">*我说的良心不是你的，乃是他的；因为我这自由为什么被别人的良心论断呢？我若谢恩而领受，为什么因我所感谢的物被人毁谤呢*</span>？

如同前面第25、27节中「良心」一词指的是自己的良心，为免第28节中的「良心」也被如此理解，保罗便加上解释说：「我说的良心，不是你的，乃是别人的。」意即：「我所指的并非你的良心，而是那警告你不可吃之人的良心。」<span style="color:#800000">*因为我这自由何必由别人的良心论断呢*</span>？这句话以及随后的话，可容三种解释。

<!-- PAGE 223 -->
<span class="enum-num">1.</span> 若与前面的分句相连，这些话必是要说明保罗为何是指“别人的良心”。“我说的良心，不是你自己的，乃是别人的；<span style="color:#800000">*因为*</span>我这自由（或良心）何必被别人的良心论断呢？我若感谢着吃（且以无愧的良心而吃），为什么被人毁谤呢？”对此解释显而易见的反驳是：它把一个附属分句抬举成了主要论题。保罗所指并非那人自己的良心，本已十分明白，因此无须用两节经文来证明他并非如此说。此外，这种解释使使徒转换了立场。他从起初一直是为软弱之人说话；而依此解释，他在此处竟几乎以愤慨之词为刚强之人辩护，而刚强之人本无须辩护者。他们也无须被告知：他们的自由不当受软弱之人顾忌的限制。

<span class="enum-num">2.</span> 若将本段与第28节相连，所得之意便好得多。‘不要为你弟兄的良心之故而吃；因为我的（你的）自由何必被别人的良心论断（即定罪）呢？我何必因我感谢而领受的食物被人毁谤呢？’意即：我何必如此运用自己的自由，以致使人跌倒呢？这样解释，本段便与全段上下文相合，并与前一节的主旨相连，而不是与其中一个居间的、附属的分句相连。使徒所着眼的，正是要使刚强的人体恤软弱之人的顾忌。就他们自身而论，他们在私人筵席上尽可自由地吃祭过偶像的肉；但使徒问道，他们何必如此行，以致使人跌倒，叫软弱的人定他们的罪、毁谤他们呢？3. 有些注释家认为这段话是反对者之言，而非使徒自己的话。刚强之人听见说不可为软弱弟兄的良心之故而吃，或许要问：‘我的自由为什么被别人的良心论断呢——我为何要因我感谢而领受的食物被人毁谤呢？’（按此说法，<span style="color:#0000d4">γάρ</span> 不作 <span style="color:#800000">*因为*</span> 解，而是加强语气，<span style="color:#0000d4">ἱνατί</span> <span style="color:#0000d4">γάρ</span>，即 <span style="color:#800000">*那么为什么*</span>。）这样解释意思甚佳，但与下一节不符（下一节是以 <span style="color:#0000d4">οϋν</span> 与第30节相连，而非以 <span style="color:#0000d4">δέ</span> 相连）。

保罗并未接着答复那反对之辞，乃视全案为已定。第二种解释才是既合乎上文、又合乎下文的唯一解释：「若有人警戒你不可吃，就不要吃；因为你何必这样用你的自由，以致招来责难呢？所以，你们或吃或喝，无论作什么，都要为荣耀神而行。」我这自由为什么被论断（<span style="color:#0000d4">κρίνεται</span>）呢，即被人不利地评判、被定罪。<span style="color:#800000">*我若谢恩而领受*</span>；直译作<span style="color:#800000">*我若以感谢领受*</span>。<span style="color:#0000d4">χάρις</span> 一词，即<span style="color:#800000">*恩*</span>，此处用作<span style="color:#800000">*gratia，感谢*</span>之意，正如常用语中所谓<span style="color:#800000">*谢饭祷告*</span>。参路加福音 6:32、提摩太前书 1:12 等处。

<!-- PAGE 224 -->

**31.** <span style="color:#800000">*所以，你们或吃或喝，无论做什么，都要为荣耀神而行*</span>。

这句话可有两种理解：或是说“行事为人皆当以神的荣耀为念”，即以此为恒常追求的目标；或是说“行事为人皆当以能使神得荣耀的方式行之”。这两种解释相去不远。若我们行事的目的不在于神的荣耀，我们的品行便不能使神得荣耀。后一种解释可与彼得前书 4:11 相印证：“叫神在凡事上得荣耀。”参歌罗西书 3:17。使徒在前文讨论中所给的一切具体指示，都总归于此：“忘却自己。定睛于神。凡你所行的，都以增进他的荣耀为目的。务要在每一件事上如此行事，使人称赞那位你所自称事奉的神。”圣经论到神儿女的罪，总说这罪是使神自己受羞辱。罗马书 2:24。以西结书 36:20, 23。唯有以增进神的荣耀之心愿作我们生命的主导动机，我们一切的行为才有秩序与和谐可言。如此，太阳便成了这体系的中心。世人以自己为其行为的目的。哲学家教导我们以他人的益处为目的；如此便将宗教消融于博爱或仁慈之中，使宗教的情怀荡然无存。圣经却告诉我们，要以神的荣耀为目的。这样做既保全了其他一切目的（使之居于从属地位），同时又将一位无限的、有位格的对象置于灵魂面前，从而提升了灵魂。以神（那有位格的耶和华）的荣耀为我们行为的目的，与以宇宙的福祉或一般存在的福祉为目的，二者之别正如对基督的爱与对一个抽象观念的爱之别。前者是宗教，后者只是道德。

**32.** <span style="color:#800000">*不拘是犹太人，是外邦人，是神的教会，你们都不要使他跌倒*</span>：

<!-- PAGE 225 -->
<span style="color:#800000">*不拘是……都不要使人跌倒*</span>，即不要给人犯罪的机会。所谓「跌倒之事」，乃是使人绊跌之物。此劝勉是要人避免成为他人犯罪的缘由，参8、9两节；罗马书 14:13、21。他们在此事上当顾及各等人，无论是基督徒或非基督徒。后者又分为两大类，即犹太人与外邦人。<span style="color:#800000">*神的教会*</span>，即神的子民；乃是神从世界中呼召出来、归为自己特有产业的那些人。故此他们被称为 <span style="color:#0000d4">κλητοί</span>，<span style="color:#800000">*蒙召的人*</span>，或就其整体而言，称为 <span style="color:#0000d4">ἐκκλησία</span>，<span style="color:#800000">*教会*</span>。基督徒行事为人的第一大原则，是促进神的荣耀；第二大原则，是避免使人跌倒、避免叫人犯罪。换言之，爱神与爱人当支配我们一切的行为。

**33.** <span style="color:#800000">*就好像我凡事都叫众人喜欢，不求自己的益处，只求众人的益处，叫他们得救。*</span>

他劝勉他们所当行的，他自己先行了。他所求的并非自己的益处，乃是他人的益处。因此，凡在可行之事上，他向众人都作了众人的样子，为要使他们得救。“向什么样的人，我就作什么样的人。无论如何，总要救些人。”9:22。

使徒在此所宣示的原则，也是他在前几章中极力推荐的原则，却屡屡遭人可悲地曲解。以“向什么样的人，就作什么样的人”为借口，基督徒往往受试探而在世俗的习尚与娱乐上与世人罪恶地随流合污。罗马教会也以同样的借口，接纳了异教的节期、礼仪与仪式，以致异教与基督教之间的分别几乎只剩下名义上的差异。异教庙宇被称为教堂；异教诸神受洗成为圣徒，仍如从前一样受人尊崇。在民众的观念中，今日的罗马几乎与古罗马一样多神。同样地，罗马教会的宣教士也在极大程度上迁就异教的观念与形式，以致他们所称的基督教与该国原有的宗教之间，其分别几乎荡然无存。即便是更正教的宣教士，对于归信者从前的习俗与礼仪，何者当容忍、何者当禁止，也常常难以决断。保罗与其余使徒在此事上所依循的原则，与罗马教会所采纳的原则有着根本的不同，这从二者所结的果效上便显而易见。罗马已被异教化；而使徒的行事却保守了教会，使之不沾染异教或犹太教的丝毫污秽。使徒们所遵循的准则，从保罗的行事与书信中不难推知。

<!-- PAGE 226 -->

<span class="enum-num">1.</span> 他们迁就犹太人或外邦人的习俗，仅限于无关紧要之事。

<span class="enum-num">2.</span> 即便在无关紧要之事上，一旦情形使这些事带上宗教意涵，他们也一概不作任何通融。他们容许人吃祭物；但在庙中吃，则是被禁止的。

<span class="enum-num">3.</span> 当这类让步并非被人当作必须之事而强求时，他们便予以让步；但若被视为必须，他们就断然拒绝。保罗曾说受割礼算不得什么，不受割礼也算不得什么；然而当犹太主义者强求提多受割礼时，他却起而抵挡。

<span class="enum-num">4.</span> 他们作出这些让步，目的不在于赢得挂名的归信者，也不在于除去十字架的绊脚石（加拉太书 4:11），而在于救人。因此，无论是对世俗风尚的迁就，还是对无知者偏见的迁就，凡不是真诚地以此为目的的，都不能援引使徒的榜样为其辩护。

<span class="enum-num">5.</span> 上述各项之中已然含有此意：保罗虽向众人作了众人的样子，却从未在任何真理上妥协让步，也从未认可任何谬误。

十一章 1 节 <span style="color:#800000">*你们该效法我，像我效法基督一样。*</span>

本节理应归入第十章，因为它是前文论述的结语，而新的题目自下一节方才开始。保罗曾以自己那忍让顺服的行事为哥林多人的榜样，如今便劝勉他们效法自己，正如他效法基督一样；基督乃是终极的标准。
