<p style="text-align:center" markdown="1"><span style="color:#006411">**第六章**</span></p>

父母与儿女、主人与仆人彼此当尽的本分，第1-9节。——论属灵争战的劝勉与指引，第10-20节。——结语，第21-24节。

<p style="text-align:center" markdown="1">**第一段 — 第1-9节**。</p>

<span style="color:#800000">*1. 你们作儿女的，要在主里听从父母，这是理所当然的。*</span>

<span style="color:#800000">*2. 要孝敬父母，使你得福，在世长寿。这是第一条带应许的诫命。*</span>

<span style="color:#800000">*3. 使你得福，在世长寿。*</span>

<span style="color:#800000">*4. 你们作父亲的，不要惹儿女的气，只要照着主的教训和警戒养育他们。*</span>

<span style="color:#800000">*5. 你们作仆人的，要惧怕战兢，用诚实的心听从你们肉身的主人，好像听从基督一般；*</span>

<span style="color:#800000">*6. 不要只在眼前事奉，像是讨人喜欢的，要像基督的仆人，从心里遵行神的旨意；*</span>

<span style="color:#800000">*7. 甘心事奉，好像服事主，不像服事人。*</span>

<span style="color:#800000">*8. 因为晓得各人所行的善事，不论是为奴的，是自主的，都必按所行的得主的赏赐。*</span>

<span style="color:#800000">*9. 你们作主人的，待仆人也是一理，不要威吓他们；因为知道，他们和你们同有一位主在天上，他并不偏待人。*</span>

<!-- PAGE 242 -->

<p style="text-align:center" markdown="1">**分析**</p>

儿女应当顺服父母。这种顺服应当在主里，即以对基督的敬畏来决定并规范之，第1节。这一责任的根据在于：1. 顺服本身就是理所当然的。2. 十诫中有明文诫命强制此事，且附有特别的应许，第1-3节。

为父母者，不可有任何举动去滋长儿女心中的恶念，却要照着基督教的管教养育他们，4、5节。

仆人当顺服自己的主人。这顺服当如此献上：一、存敬畏之心；二、心思专一；三、视之为顺服基督的一部分，见第5节。故此，不可单在人眼前、或出于讨人喜欢之意而行，乃要如同服事基督、一心讨他的喜悦；甘心乐意地尽其职事，像是给主作的，不是给人作的；因为他们知道，在他的审判台前，无论为奴的或自主的，众人都必照自己所行的受报，见第6至8节。

作主人的，也当本着同样的原则行事，即顾念基督的权柄，并在待仆人的事上顾念自己向祂所负的责任，不可严厉苛刻；因为主人与仆人在天上同有一位主，在祂并没有偏待人的事，第8节。

<p style="text-align:center" markdown="1">**注释**</p>

<!-- PAGE 243 -->
<div class="commentary-anchor" id="ephesians-6-1"></div>
第1节。<span style="color:#800000">*你们作儿女的，要在主里听从父母。*</span>这种顺服的性质或特征，由<span style="color:#800000">*在主里*</span>这几个字表明。它当是敬虔的顺服，出于这样的确信：如此顺服乃是主的旨意。这就使它成为比出于惧怕、或仅出于天然亲情所作的更高的事奉。它保证这顺服是及时的、诚心的、全面的。此处的<span style="color:#0000d4">Κύριος</span>是指基督，从上下文看甚为明显。在前一章第21节，我们读到那总括性的劝勉，对儿女的这一特别吩咐即包含于其中，而那里所要求的顺服乃是<span style="color:#800000">*存敬畏基督的心*</span>而行的。在随后各节中，<span style="color:#0000d4">Κύριος</span>也一贯指基督，因此这里必定也是如此。儿女顺服的义务之根据，见于<span style="color:#800000">*这是理所当然的*</span>一语。这义务不是因着父母个人的品格，也不是因着他们的慈爱，更不是基于利害的考量，乃是因为这样做是<span style="color:#800000">*当然的*</span>；这义务出于父母与儿女之间关系的本性，故凡有此关系之处，此义务便必然存在。

<div class="commentary-anchor" id="ephesians-6-2"></div>
第2节。此项劝勉又以神的明令加以强化。这一本分何等重要，以致被列入神在西奈山所颁赐的道德律那简短的总纲之内。它是神用指头刻在石版上的：<span style="color:#800000">*当孝敬父母*</span>。按摩西律法，凡公然违犯此诫者，必治死。孝敬即是敬重；因此，这条诫命所涉及的不仅是外在的行为，也包括内心的情感。使徒说这条诫命是 <span style="color:#0000d4">πρώτη ἐν ἐπαγγελίᾳ</span>。此语或可解作：它是十诫中第一条附有明确应许的诫命；因为与第二诫相连的应许，并非关乎遵守那一条具体的诫命，而是关乎守神的约。或可解作：它是律法第二版的第一条诫命，且附有应许。又或者，此处的 <span style="color:#0000d4">πρώτη</span> 可如马可福音 12:28, 30 那样，取“首要”之意，即在重要性上居首。如此，其意便是：“当孝敬父母；这是首要的诫命，在关乎我们对人本分的诸诫之中居首，并且附有明确的应许：使你在世上得享福乐。”总体而论，当以此解为优。保罗若称这是“第一条带应许的诫命”，似不甚可能，因为事实上它是十诫中唯一附有具体应许的诫命。而若说它在律法第二版的排列次序上居首，不但于其重要性毫无增益，而且假定使徒是在指十诫两版之间的分别，然而这一分别在圣经别处并无明证。

<!-- PAGE 244 -->

这应许本身在旧约中带有神权政体的形式。就是说，它特指在神所赐给祂百姓为业的那地上得享亨通与长寿。使徒略去末尾之语，将其一般化，使之成为一个不限于某一地或某一民族、乃是临到各处顺命儿女的应许。若有人问：顺命的儿女实际上果真以长寿与亨通著称吗？答曰：此应许与其余一切同类的应许一样，乃是神一般旨意的启示，向人显明祂护理之工通常的途径。有些顺命的儿女遭遇不幸、寿数短促，这与本应许并无矛盾，正如有些殷勤之人反倒贫穷，也与“殷勤人的手使人富足”一语并无矛盾。殷勤，就通例而言，确能致富；顺命的儿女，就通例而言，也确是亨通而有福的。这普遍的应许在个人身上得着应验，其分寸正在于“何等程度上足以彰显神的荣耀，并成全他们自己的益处”。

<!-- PAGE 245 -->
<div class="commentary-anchor" id="ephesians-6-4"></div>
第4节。为父母者的本分——此处以父亲为代表——从反面与正面两方面加以陈明。<span style="color:#800000">*你们作父亲的，不要惹儿女的气*</span>。这是他们所不可行的。他们不可因严苛、不公、偏心，或不合理地行使权柄，而激动儿女心中的恶情。一个人宁可在指望收取自己与全家口粮的田地里撒下稗子，也胜过因自己行事不端而在儿女心中培育罪恶。为父母者本分的正面，则表述于这一包罗甚广的吩咐之中：<span style="color:#0000d4">ἀλλὰ ἐκτρέφετε αὐτὰ</span> <span style="color:#0000d4">ἐν παιδείᾳ καὶ νουθεσίᾳ κυρίου</span>，即：教养他们，抚育他们，藉着（<span style="color:#0000d4">ἐν</span> 表工具）主的教训和警戒，使他们一切的才能得以发展。<span style="color:#0000d4">Παιδείᾳ</span> 是一个涵义广泛的词，意为<span style="color:#800000">*对孩童的训练或教育*</span>，包括教导与管教的全部过程。<span style="color:#0000d4">Νουθεσία</span> 出于 <span style="color:#0000d4">νουθετέω</span>（由 <span style="color:#0000d4">νοῦς</span> 与 <span style="color:#0000d4">τίθημι</span> 合成），意为<span style="color:#800000">*使人记在心上*</span>，包含在前一更广泛的词之下，译为<span style="color:#800000">*警戒*</span>是恰当的。它是提醒人留意自己的过失或本分的举动。不可任凭儿女无人看顾、无人约束地长大。必须教导他们、管教他们、警戒他们，好使他们得着知识、自制与顺服。这全部的教育过程都当是宗教性的，而且不单是宗教性的，更当是基督教的。这是<span style="color:#800000">*主的教训和警戒*</span>，乃是神所设立、也是唯一有效达成教育目的的方法。凡忽略此法，或以别法取而代之的，其结果必是惨痛的失败。我们本性中道德与宗教的成分，正如理智的成分一样，同是本质的，同是普遍的。因此，宗教对心智的发展，正如知识一样不可或缺。既然基督教是唯一真实的宗教，在基督里的神是独一的真神，那么唯一有益的教育之法，便是主的教训和警戒。也就是说，教导与管教的全部过程，都必须是祂所吩咐、祂所施行的，以致祂的权柄得以经常而直接地与孩子的心思、心灵和良心相接触。父母若以自己为终极的目的、为知识的源头、为断定真理与本分之权柄的持有者，这是断然不可的。如此行，不过是给自己的孩子一种纯粹属人的发展。父母若凡事都以抽象的理性为根据来劝勉、来传授，这同样不可；因为如此行，便是把自己的孩子淹没于自然之中。唯有使神、使在基督里的神作教师与治理者，凡事因祂的权柄而信，凡事因顺服祂的旨意而行，教育的目的才有可能达成。人自以为比神更有智慧，或试图以神所指定之外的别法来成就一个目的，实在是无穷的愚妄。

<div class="commentary-anchor" id="ephesians-6-5"></div>
第5节。以下五节论及主人与仆人之间彼此当尽的本分。<span style="color:#0000d4">Δοῦλος</span> 与 <span style="color:#0000d4">κύριος</span> 在此是一对相关的称谓，不过在希腊文中与 <span style="color:#0000d4">δοῦλος</span> 相对的词通常是 <span style="color:#0000d4">δεσπότης</span>，如提摩太前书 6:1、提多书 2:9；亦可参彼得前书 2:18。<span style="color:#0000d4">Δοῦλος</span> 出于 <span style="color:#0000d4">δέω</span>（<span style="color:#800000">*捆绑*</span>），意指为奴之人，与受雇的工人有别；后者称为 <span style="color:#0000d4">μίσθιος</span> 或 <span style="color:#0000d4">μισθωτός</span>。此处确为此义，不仅可从该词的通常用法看出，也可从第8节中 <span style="color:#0000d4">δοῦλος</span> 与 <span style="color:#0000d4">ἐλεύθερος</span>、<span style="color:#800000">*为奴的*</span>与<span style="color:#800000">*自主的*</span>之对举得知。<span style="color:#0000d4">Κύριος</span> 意为<span style="color:#800000">*占有者、所有者、主人*</span>。它所表明的关系，既可对人，也可对物。但这关系的性质究竟如何，其中所含权柄属何种类、及于何等程度，并非由这个词本身决定，而须在各处按上下文断定。无论从此处所用词语的含义，还是从众所周知的史实——使徒时代奴隶制通行于整个罗马帝国——都显然可见，新约这一处及别处经文所指的正是这一制度。使徒对待它的方式，与对待国中的专制统治如出一辙：既不吩咐，也不禁止，只是单单假定其为合法，以致一个基督徒可以一面作国中的专制君主，或作蓄奴的主人，而无碍于其信仰的一贯。照此看来，圣经在这题目上的教训，一方面有别于那种主张——即蓄奴本身即是罪，理由是一人不能合法地占有并施行主人对奴仆所含的那些对同类之人的权利与权柄。此说势必要立一条高过圣经的信仰与行为准则，因而趋于毁坏圣经的权威。它又引人生出无爱心的情绪与不公义的论断，并采取无正当根据的手段去革除此弊。另一方面，圣经的教训也反对那种见解，以为奴隶制本身乃是可取的制度，因而当加以珍护并使之长存。此说所导致的结果，其可叹之处不亚于前一谬误。因奴隶制既以社会中一等人劣于另一等人为根基，那么以为当珍护此制的见解，自然会引人采取种种手段，藉阻止被辖之阶层长进，来加增或延续这种低劣状况。它又构成一种强烈的试探，使人否认世人同为弟兄，而视受奴役者为属于低等的种族。持前一谬误之人的大错，乃在于——一。

<!-- PAGE 247 -->
其一，他们以为主人的财产权可以延伸到奴仆的服事之外。在此情形下，唯一可能存在的财产权，乃是按奴仆与其主人同具一样人性这一事实来使用他，并且是照神的律法与万物的本相可以正当使用他。其二，把奴仆法与奴仆制度本身相混淆；这就如同把专制政体这一种国家政制，与某一专制国家的具体律法相混淆一样不合情理。那些律法可以是好的，也可以是坏的。它们纵然是坏的——事实上也常常是坏的——却无论在专制政体或奴仆制度上，都不能证明该制度本身违背神的律法。至于持相反极端之见者，就圣经而论，他们的错误在于：把圣经在特定情形下容许为合法之事，视为可以珍守并使之永久存续。这就如同主张儿女若有可能便应当永远停留在未成年的状态一样不合情理。圣经处理此类制度的方法，乃是向一切相关之人申明道德义务的伟大原则——深信这些原则若得以自由施行，必将终止人在政治与社会关系中的一切恶。因此，使徒既不斥责奴仆制度，也不称许它，只是单单教导主人与奴仆各尽本分。对奴仆，他吩咐顺服的本分。在<span style="color:#800000">*按肉体作你们主人的*</span>这一说法中，显然隐含着对更高权柄的提示。它将主人的权柄限于外在之事，而灵魂仍是自由的。奴仆有两位主人：一位是<span style="color:#0000d4">κατὰ σάρκα</span>的，一位是<span style="color:#0000d4">κατὰ πνεῦμα</span>的；一位是人，一位是基督。此处所给的教训，乃是关乎他们对前者当尽的本分。至于所要求之顺服的性质，使徒教导说——一，这顺服当是<span style="color:#0000d4">μετὰ φόβου καὶ τρόμου</span>，<span style="color:#800000">*存着惧怕战兢的心*</span>，即怀着凭良心行事的殷切之心。这些字眼并不含有奴颜婢膝之意，这从上下文，以及与使用同样语句的其他经文相比较，便可清楚看出。使徒所说的，不是惧怕人，乃是敬畏神，下文明明证实了这一点。在哥林多前书 2:3，保罗告诉哥林多人，他到他们那里是"又软弱又惧怕，又甚战兢"；在哥林多后书 7:15，他提到他们"恐惧战兢地接待"提多；在腓立比书 2:12，他劝勉信徒"恐惧战兢做成你们得救的工夫"。在这一切情形中，这些字眼所含的，无非是殷切求行所当行之事而已。

<div class="commentary-anchor" id="ephesians-6-2-2"></div>
**2.** <span style="color:#800000">*这顺服当以*</span> <span style="color:#0000d4">ἐν ἁπλότητι τῆς καρδίας</span> <span style="color:#800000">*诚实的心*</span>而献上，即以专一的心志——我们外表所显的，正是我们心里所存的。它与假冒为善、虚情假意、欺诈诡诈相对。参罗马书 12:8；哥林多后书 8:2；9:11。<span style="color:#0000d4">ἁπλότης</span> 一词意为<span style="color:#800000">*专一*</span>，源自 <span style="color:#0000d4">ἁπλόος</span>，意即<span style="color:#800000">*单层的*</span>，与 <span style="color:#0000d4">διπλόος</span> 即<span style="color:#800000">*双层的*</span>或<span style="color:#800000">*双重的*</span>相对。故此处所吩咐的，正是二心的反面。

<span class="enum-num">3.</span> 这顺服乃是要如此献上：<span style="color:#0000d4">ὡς τῳ Χριστῳ</span>，<span style="color:#800000">*像听从基督一般*</span>。仆人当把自己对主人的顺服，看作是对基督之顺服的一部分。如此，这顺服便具有了敬拜事奉的性质，因为其动机在于顾念神的权柄，其对象乃是一位属神的位格。这样，顺服便不再是奴颜卑屈的，反倒与最高的心志超拔和属灵的自由并行不悖。

<!-- PAGE 248 -->

<div class="commentary-anchor" id="ephesians-6-6"></div>
第6节。使徒在接下来的两节中说明，他所谓<span style="color:#800000">*心中诚实*</span>，即是真诚的顺服，究竟何指。这不是眼前事奉，即不是那种惟有主人眼目看见时才尽的事奉，仿佛所求的不过是讨人的喜悦。仆人当以<span style="color:#0000d4">δοῦλοι τοῦ Χριστοῦ</span>，即<span style="color:#800000">*基督的奴仆*</span>的身分行事；基督的眼目无处不在，所以他们若愿意讨他的喜悦，就必须在主人不在时与在主人面前时一样忠心。<span style="color:#0000d4">Ποιοῦντες τὸ</span> <span style="color:#0000d4">θέλημα τοῦ θεοῦ</span>，<span style="color:#800000">*遵行神的旨意*</span>。这是描写基督的仆人，与讨人喜悦者相对。他们行事乃是出于顾念神的旨意，出于讨他喜悦的心愿——<span style="color:#0000d4">ἐκ ψυχῆς</span>，<span style="color:#800000">*ex animo，发自内心*</span>。<span style="color:#0000d4">ψυχῆ</span>有时指欲望与情感之所在，其意便与<span style="color:#0000d4">καρδία</span>相合；有时二者则加以区别，如马可福音12:30，“尽心（<span style="color:#0000d4">καρδία</span>）、尽性（<span style="color:#0000d4">ψυχῆ</span>）”。此处的意思是：顺服的本原绝非外在之物，乃是在内里。这是从心灵——即整个内在的人——里涌出的顺服。这几个字通常且最自然地是与前一分句相连：“从心里遵行主的旨意。”然而许多注释家与编者却把它们与下文相连：“从心里、甘心乐意地服事。”这样一来，<span style="color:#0000d4">δουλεύοντες</span>便有了两个意义几乎相同的修饰分句，而前面的分词<span style="color:#0000d4">ποιοῦντες</span>反倒一个也没有了。

<div class="commentary-anchor" id="ephesians-6-7"></div>
V. 7. 仆人顺服的全部品格，都总括在本节之内：<span style="color:#0000d4">δουλεύοντες ὡς τῳ κυρίῳ καὶ οὐκ ἀνθρώποις</span> <span style="color:#800000">*甘心事奉，好像服事主，不像服事人*</span>。按圣经的教训，这并非仆人顺服主人一事所独有，乃是适用于凡一人当顺服另一人的一切情形。它适用于儿女之于父母，妻子之于丈夫，百姓之于官长。凡受了合法权柄的，都是神的代表。掌权者（即受托有权柄之人）乃是神所命定的；因此，凡出于尊重神旨意而向他们所献的顺服，就是向神所献的顺服。而顺服神，既是顺服那无限真实、无限良善者，就比顺服真理与良善本身更能提升人的心灵。人心骄傲悖逆，藐视一切尊长与权柄，这一切于它固然全然扞格；然而神的子民每日都在实证此理：即便那些神使他们所当服从之人，其权柄的行使乃是任性无理的，他们仍然欢然忍耐地顺从。<!-- PAGE 249 -->当留意的是，使徒陈明这一原则，不单是以宗教的形式，更是以基督教的形式。所吩咐我们的，乃是<span style="color:#800000">*甘心事奉，好像服事主，不像服事人*</span>。那位受此顺服的，是基督，是神在肉身显现；是那本有神的形像、不以自己与神同等为强夺，反倒虚己、取了奴仆之形像的主，<span style="color:#0000d4">μοπφὴν δούλου λαβών</span>；正是向这位无限尊高又无限俯就的救主，每一个基督徒——无论为仆、为子、为妻、为民——才真实而自觉地献上顺服。如此，最难堪的轭也成了容易的，最沉重的担子也成了轻省的。

<span style="color:#0000d4">μετ</span><span style="color:#0000d4">’</span> <span style="color:#0000d4">εὐωοίασ</span> 一语修饰 <span style="color:#0000d4">δουλεύοντες</span>，即<span style="color:#800000">*甘心乐意地服事*</span>。这与那种因惧怕刑罚而被迫的服事恰成对照：此等服事往往带着闷闷不乐与内心的愤懑。凡献给基督的服事，断不可属于这一类，乃是踊跃欢欣地献上的。

<div class="commentary-anchor" id="ephesians-6-8"></div>
第8节。本节为仆人提出一条令人振奋的真理，以作勉励：在基督的审判台前，众人都处于同等地位。在他里面、在他面前，并不分犹太人或希腊人，为奴的或自主的，或男或女；就这些外在的区别而言，众人都是一样的。因此使徒对作仆人的说，当这样甘心顺服，<span style="color:#0000d4">εἰδότες</span>，即知道，或说因为你们知道，<span style="color:#800000">*各人所行的善事，不论是为奴的，是自主的，都必按所行的得主的赏赐*</span>。在今世，有人为主，有人为仆；到了来世，这些分别便要止息。那时所问的，不是谁为主、谁为仆，乃是谁遵行了神的旨意。此句中的 <span style="color:#0000d4">ὅ</span> <span style="color:#0000d4">ἐάν τι</span> 相当于 <span style="color:#0000d4">ὅ, τι ἐάν,</span>，如歌罗西书 3:23 所用者，<span style="color:#0000d4">ἐάν</span> 在此代 <span style="color:#0000d4">άν</span>。<span style="color:#0000d4">Κομίζομαι</span> 意为为自己领受，即领回作为报偿，参林后 5:10。在基督的审判台前，从他手中，各人必照自己所行的而得报应，无论是为奴的，是自主的。

<div class="commentary-anchor" id="ephesians-6-9"></div>
第9节。使徒既已嘱咐仆人尽其本分，便转向主人说话。<span style="color:#0000d4">Καὶ οἱ κύριοι</span>，<span style="color:#800000">*你们作主人的*</span>。此处 <span style="color:#0000d4">καὶ</span> 的语气是：“不单仆人有当尽的本分，你们作主人的也有你们特有的义务。”主人的本分乃以概括之语表明：<span style="color:#0000d4">τὰ αὐτὰ ποιεῖτε πρὸς αὐτούς</span>，<span style="color:#800000">*待他们也是一理*</span>。

<!-- PAGE 250 -->

<!-- PAGE 251 -->
这并非专指前一分句中的 <span style="color:#0000d4">μετ</span><span style="color:#0000d4">’</span> <span style="color:#0000d4">εὐνοίας</span>，仿佛其意是说：“仆人当以善意顺服，主人也当以同样的心肠管辖。”此处所指更为宽泛。主人待奴仆，当与奴仆所受的吩咐一样：同样顾念神的旨意，同样承认基督的权柄，同样存诚实与善意。主人与奴仆同是人，同是弟兄，同受道德与宗教义务上那些伟大原则的支配。在平行经文歌罗西书 4:1 中，所用的话是 <span style="color:#0000d4">τὰ αὐτὰ ποιεῖτε πρὸς αὐτους</span>，<span style="color:#800000">*你们作主人的，要公公平平地待仆人*</span>。就是说，要按公义与公平的原则待他们。公义要求他们作为人、作为丈夫、作为父亲所有的一切权利都当受尊重。而这些权利不是由民法来断定，乃是由神的律法来断定。加尔文说：“因为律法给了主人极大的放纵，许多人便以为凡民法所许可的就都是合法的；他们的严酷竟至于罗马的皇帝不得不加以约束，以遏止其暴虐。然而纵使君王并无诏令为奴仆申辩，神也不曾在爱的律法所许可的范围之外，向主人让步分毫。”保罗为奴仆所要求的，不仅是严格意义上的公义，更有 <span style="color:#0000d4">τὴν</span> <span style="color:#0000d4">ἰσότητα</span>。这是什么？按字面，就是<span style="color:#800000">*平等*</span>。这不单是它的字义，也正是它的含义。主人待奴仆，当按平等的原则。这并不是说奴仆在权柄、地位或境遇上与主人平等；乃是说，待他们时当承认他们作为人、作为丈夫、作为父亲，与主人享有同等的权利。剥夺奴仆劳动应得的报酬，或使他愚昧无知，或夺去他的妻子儿女，其罪与如此待一个自由人同样重大。这就是神的律法所要求的平等，末后的审判也要按这原则施行。主人亏负奴仆，基督必刑罚他，正如奴仆抢夺主人，基督必刑罚他一样严厉。侵犯这一方为夫为父的权利，与侵犯那一方的权利，所受的刑罚也必相同。因为，正如使徒所补充的，他并不偏待人。在他的审判台前，所问的是“所行的是什么”，而不是“行的人是谁”。保罗将这原则推行得如此之远，以致不仅适用于主人的行为，也适用于主人的心态。他们不但要按公义与公平的原则待奴仆，更要<span style="color:#800000">*不再威吓他们*</span>。[^f29] 这包括一切轻蔑、坏脾气或过度严酷的表现。凡此一切，都以这一点为其强制的理由：主人在天上也有一位主，他们如何待奴仆，必向他交账。通行的经文在此作 <span style="color:#0000d4">καὶ ὐμῶν αὐτῶν ὁ</span> <span style="color:#0000d4">κύριός</span> ——<span style="color:#800000">*你们的主*</span>。拉赫曼、吕克特、哈勒斯、迈尔等人则采用 <span style="color:#0000d4">αὐτῶν καὶ ὐμῶν</span> 的读法，即<span style="color:#800000">*他们的和你们的*</span>，意思是<span style="color:#800000">*你们共同的主在天上*</span>。

圣灵对待奴隶制度，正是如此。经上并未吩咐作奴仆的拒绝为奴、挣断锁链、否弃主人的权柄；乃是要他们甘心乐意地顺服，诚心诚意地向主人尽本分，视此为向基督尽本分的一部分。经上也未吩咐作主人的以此为当下必行之责，立即释放奴仆，乃是要他们按公义公平的原则待之。世人在这事上不肯遵行福音，正如在别的事上一样，原是意料中事；然而信徒必要遵行。倘若这样的顺服得以普及，其结果便是：先是奴隶制度之种种恶果，继而是奴隶制度本身，都要如同孩童长大成人、不再为未成年人一般，自然而健全地归于消逝。

<p style="text-align:center" markdown="1">**分析**</p>

关于属灵争战的指示。既然这样的争战无可避免，信徒就当——1. 为这场争战积蓄力量。2. 当从基督支取这力量。3. 既然他的仇敌并非血肉之躯，乃是超乎人的，即撒但与一切黑暗的权势，信徒所需要的就不仅是超乎人的力量，更需要神所赐的军装。因此他应当穿戴神所赐的全副军装，好在磨难的日子抵挡仇敌。这全副军装包括——1. 认识并领受真理。2. 基督的义。3. 由福音之平安所生的敏捷。4. 得救的确据。5. 信心。6. 神的道，就是圣灵的宝剑。

我们若要得着能力，善用这军装，并为自己、也为我们所隶属的这支军队赢得胜利，就当祷告。这祷告当是：一、各样的祷告。二、随时随事的祷告。三、恳切而恒久的祷告。四、藉着圣灵的帮助。五、为众圣徒而作。

使徒既深信这样的祷告确有功效，便恳求以弗所的信徒为他代祷，求神使他能以合宜的方式传讲福音。

为缓解他们的挂虑，他已差遣推基古前去，将自己的境况与身体状况告知他们。

他祈求父与子将属神的平安、并与信心相连的爱赐给众弟兄；又为一切以不朽之爱爱我们主耶稣基督的人，恳求神特别的恩眷。

<p style="text-align:center" markdown="1">**注释**</p>

<div class="commentary-anchor" id="ephesians-6-10"></div>
第10节。 本书信所述基督所买赎的救赎，虽如此完备、如此白白赐下，然而自这工作的起头直到成全，其间却有一场旷日持久的争战。这并非修辞的比喻，乃是真实而艰苦的事。救恩虽是白白得来的，却非不费大力便可得着。基督徒的争战不但是真实的，而且是艰难的、危险的。在这争战中，真信徒也常受重创；而号称信徒的人，更有许多全然溃败。并且在这争战中，人往往因不明其性质，不知当用何种相宜的方法进行，以致大有错谬，大受亏损。人惯于把它看作不过是一场道德的交战：一面是理性与良心，一面是邪情私欲。于是他们便倚靠自己的力量，指望凭本性的资源取胜。使徒正是要警戒读者远离这些错谬。他教导说，凡与这争战相关的，无不是超乎自然的。力量的源头不在乎本性。这争战并非我们本性中善恶两种原则之间的交锋。他指明：我们既属乎自然界，也属乎灵界；我们所投身的这场战斗，牵动着宇宙间更高的权势；而这场关乎我们得救与否的争战，绝不可用路旁拾来的草梗去应付。我们所要抵挡的既是超乎人的仇敌，我们所需要的就不仅是超乎人的力量，更是神所赐的盔甲与兵器。我们争战的兵器本不是属血气的，乃是属神的。

<!-- PAGE 255 -->
<span style="color:#800000">*我还有末了的话：你们要靠着主，依赖他的大能大力作刚强的人*</span>，<span style="color:#0000d4">τὸ λοιπὸν, ἀδελφοί μου,</span> <span style="color:#0000d4">ἐνδυναμοῦσθε ἐν κυρίῳ</span>。本书信满载高超的属灵洞见，又极其丰富地揭示了救赎的奥秘；使徒在结束之际，便转而指教信徒当如何争战，以得着救恩。他首先劝勉的，是要为这场不可避免的争战积蓄力量，并从正确的源头去求取这力量。我们乃是要<span style="color:#800000">*靠着主作刚强的人*</span>。枝子离了葡萄树，肢体离了身体，是何光景；基督徒离了基督，也是何光景。所以，人若不思想基督，不倚靠他，不时时仰望他得力，不以自己为他身上的肢体、一切生命与活力皆从他而来，却贸然投入这场争战，实是丧心失智。他不知自己在作什么。他连走到战场的力气也没有。于他而言，整场争战不过是虚假的作戏。<span style="color:#0000d4">ἐν τῳ κράτει τῆς</span> <span style="color:#0000d4">ἰσχύος αὐτοῦ</span> 这几个字的意思是：<span style="color:#800000">*在从他的力量而来的大能里*</span>。人手臂的力气，是从他身体的力量而来的。我们惟有作基督身上的肢体，才有生命，才有能力。如今活着的不再是我们，乃是基督在我们里面活着；我们所有的力量也不是自己的，乃是他的。我们什么时候软弱，什么时候就刚强了。我们越是倒空自己，就越是被神充满。

<div class="commentary-anchor" id="ephesians-6-11"></div>
第11节。第二个指示论及成功进行这场争战所必需的兵器：<span style="color:#0000d4">ἐνδύσασθε τὴν πανοπλίαν τοῦ</span> <span style="color:#0000d4">θεοῦ</span>，<span style="color:#800000">*要穿戴神所赐的全副军装*</span>。<span style="color:#0000d4">Πανοπλία</span>，<span style="color:#800000">*全副军装*</span>，兼指兵丁防守与进攻的装备。信徒不仅要防卫自己，也要攻击他属灵的仇敌；后者对他的安全而言，与前者同样必需。他若只取守势，断不能成事；他不但要抵挡，还须务求制胜。至于当如何行，本章下文自有教导。<span style="color:#800000">*神的军装*</span>，意即神所预备、并由祂所赐的军装。于是我们从一开始便受教：正如我们所需的力量不出于自己，攻守的凭借也同样不出于自己。

<!-- PAGE 256 -->
这些兵器也不是人所设想发明的。此乃历代教会所忽略的真理，以致神的子民深受其害，可悲可叹。人向来不肯倚靠神所预备的军装，反倒乐意信赖自己所造的，或他人所定规的。避世隐遁（即逃避争战而非与之交锋）、苦修与礼仪的遵守、向圣徒与天使祈求，尤其是独身、自愿贫穷、修道院式的顺从——这些便是假宗教用以取代神所赐军装的全副装备。这一致命的谬误自起初便已显露，使徒在歌罗西书 2:18-23 详加论述。他在那里劝勉听众，不可容任何人因血气的智慧自高自大、不持定基督这生命与力量的唯一源头，藉着假谦卑与敬拜天使，夺去他们的奖赏；这等人规定不可拿、不可尝、不可摸这样那样——这些胜过邪恶的法子，在自表谦卑、私意崇拜、苦待己身上，固然*似乎*有智慧的样子，实则并无实质，不过是纵情肉体罢了。它们反倒增添了自己声称要克服的罪恶。凡血气的智慧用以取代神军装之物，历史上所能作的最准确描述，也不过如此处预言中所给出的。向圣徒和天使祈求、以自我贬抑为谦卑、或将自己的意志屈从于人的权威、苦待己身或苦修的操练、戒绝合法之物、未受吩咐的礼仪规条、谨守月份日期——这些便是教会在其背道之中，为儿女预备以应此战的兵器。使徒一一指名，加以定罪，并吩咐我们要穿戴神所赐的全副军装；他接下来就逐一加以描述。

<span style="color:#0000d4">Πρὸς τὸ δύνασθαι ὐμᾶς στῆναι πρὸς τὰς μεθοδείας τοῦ διαβόλου</span>。这属神的军装乃是必需的，为要使我们<span style="color:#800000">*能抵挡魔鬼的诡计*</span>。倘若我们的仇敌不过是人，只有属人的力量、机巧与狡诈，我们尽可用属人的方法自卫。然而我们既是与撒但争战，就必须有神所赐的军装。圣经的一部分，自然以其余各部分为真。假如实在并无撒但这样的存在，或他并不具有极大的权势与聪明，或他无从接近人游荡无守的心思、并施展其权势以致人于灭亡；假如这一切都已成陈迹，那么超自然的能力与超自然的防御之法，便实在没有必要了。若撒但与撒但的作为不过是寓言或比喻，那么其余一切关乎这属灵争战的描述，也都成了空洞的譬喻。但若这描述的一部分是按字面确实的，其余各部分也必有同样深沉而真实的意义。若撒但真是那幽暗权势的首领，是这世界的统治者与神；若他是肉身之恶与道德之恶的始作俑者，是神、是基督、是神子民的大仇敌，满怀诡诈与恶毒；若他时常寻找可吞吃的人，引诱人犯罪，弄瞎人的心眼，将邪恶与不信的意念投入人心——若这一切都是真的，那么对此茫然无知，或加以否认，或以为这场争战不过是我们自己心中善恶两种原则的角力而贸然上阵，便无异于蒙着眼睛奔向灭亡。

<!-- PAGE 257 -->

<div class="commentary-anchor" id="ephesians-6-12"></div>
第12节。这是使徒最恳切坚持的一点。他要唤起读者，使他们充分认识到那些必须与之争战的仇敌何等有能力。他揭开幔子，将属灵的世界向他们显明，就是黑暗国度的众军。我们必须抵挡魔鬼的诡计，<span style="color:#0000d4">ὅτι οὐκ έστιν ἠμῖν ἠ πάλη πρὸς αιμα</span> <span style="color:#0000d4">καὶ σάρκα</span>，<span style="color:#800000">*因我们并不是与属血气的争战*</span>，即不是与人争战。<span style="color:#0000d4">πάλη</span> 一词意为<span style="color:#800000">*摔跤*</span>。使徒或是随即更换了比喻，或是在此以更宽泛的意义使用该词。后者更为可能。“血肉之体”在此处与别处，都不是指我们败坏的本性（虽然<span style="color:#800000">*肉体*</span>一词单用时常有此义），而是指<span style="color:#800000">*人*</span>。加拉太书1:16“我没有与属血气的人商量”，意即‘我没有求问于人’。使徒归主之后，未曾向人寻求教导或指引；他对福音的一切认识，都是借着直接的启示领受的。

<!-- PAGE 258 -->
我们所争战的，并非与人争战，<span style="color:#800000">*乃是与那些执政的、掌权的、管辖这幽暗世界的，以及天空属灵气的恶魔争战*</span>。此处所用词语的含义、上下文以及圣经的类比，都确定无疑地表明所指乃是邪灵。圣经称他们为<span style="color:#0000d4">δαιμόνια</span>，<span style="color:#800000">*鬼魔*</span>，经上宣称他们是堕落的天使（彼得后书 2:4；犹大书 6），如今伏在其首领撒但之下。他们被称为<span style="color:#0000d4">ἀρχαί</span>，<span style="color:#800000">*执政的*</span>，即位分居首或居高者；又称为<span style="color:#0000d4">ἐξουσίαι</span>，<span style="color:#800000">*掌权的*</span>，即受有权柄者。这些称谓大概是就众灵彼此之间的关系而言。<span style="color:#0000d4">κοσμοκράτορες</span>（管辖世界者）这一名称，则表明他们在这世界上所行使的权能或权柄。<span style="color:#0000d4">κόσμος</span>，即世人，是服在他们之下的；参见哥林多后书 4:4；约翰福音 16:11。此词严格说来只用于那些统治普世的君王。犹太人也正是在这个意义上称死亡的天使为<span style="color:#0000d4">κοσμοκράτωρ</span>。在随后的短语<span style="color:#0000d4">τοῦ σκότους τοῦ αἰῶνος</span> <span style="color:#0000d4">τούτου</span>，<span style="color:#800000">*这世界的幽暗*</span>中，据最佳抄本的权威，<span style="color:#0000d4">τοῦ αἰῶνος</span>数字通常略去。无论采用哪一种读法，意思大体相同。这些邪灵是这幽暗的管辖者。其意或是说，他们辖制着现今无知并与神隔绝的光景，即堕落中的世界伏在他们的掌控之下；或者说，<span style="color:#800000">*这幽暗*</span>等同于幽暗的国度。他们是幽暗国度的管辖者，而按照圣经的教义，这国度所包括的乃是与神真正的子民相区别的那个世界。<span style="color:#0000d4">σκότος</span>一词在别处也曾以抽象代具体，指那些在黑暗中的人，即那些属于幽暗国度或构成幽暗国度的人，路加福音 22:53；歌罗西书 1:13。因此，我们所争战的，乃是与那些管辖现今幽暗国度的掌权者争战。

他们又被称为 <span style="color:#0000d4">τὰ πνευματικὰ τῆς πονηρίας</span>，即我们译本所译的<span style="color:#800000">*属灵的邪恶*</span>。但这不可能是其含义；按上下文以及这些词本身的力量看，所指的并非抽象的邪恶，乃是邪恶的灵。比撒及他人将这些词理解为等同于 <span style="color:#0000d4">πνευματικαὶ</span> <span style="color:#0000d4">πονηρίαι</span>，即<span style="color:#800000">*属灵的诸般邪恶*</span>。这样解释亦通。既然这些灵被称为 <span style="color:#0000d4">ἀρχαί</span> 与 <span style="color:#0000d4">ἐξουσίαι</span>，自然也可称之为 <span style="color:#0000d4">πονηρίαι</span>。然而 <span style="color:#0000d4">τὰ πνευματικὰ τῆς πονηρίας</span> 不能化解为 <span style="color:#0000d4">πνευματικαὶ πονηρίαι.</span> <span style="color:#0000d4">Τὰ πνευματικὰ</span> 等同于 <span style="color:#0000d4">τὰ</span> <span style="color:#0000d4">πνεύματα</span>，正如在许多别的情形中，中性形容词的单数或复数被用作名词一样，例如 <span style="color:#0000d4">τὸ ἱππικόν</span>，意即<span style="color:#800000">*马兵*</span>；<span style="color:#0000d4">τά αἰχμά λωτα</span>，意即<span style="color:#800000">*被掳的*</span>，也就是被掳之人。如此，<span style="color:#800000">*邪恶之灵*</span>就是指<span style="color:#800000">*邪恶的灵*</span>。使徒在前面各句中称之为执政的、掌权的、管辖者的那些存在者，在此称之为邪恶的灵，为要表明它们的品性与本质。

<!-- PAGE 259 -->
本节主要的难处在于 <span style="color:#0000d4">ἐν τοῖς</span> <span style="color:#0000d4">ἐπουρανίοις</span> 这几个字。有极多古今的注释家将其与本节开头相连，译作“我们的争战是为着天上的事”；天乃是我们所争取的奖赏。这一解释虽意思不错，也甚合宜，但有两点反对意见，一般被视为定论。其一是，<span style="color:#0000d4">ἐν</span> <span style="color:#0000d4">τοῖς ἐπουρανίοις</span> 在本书信中一向指<span style="color:#800000">*天上*</span>；其二是 <span style="color:#0000d4">ἐν</span> 并无<span style="color:#800000">*为着*</span>之意。故此当与前一分句相连。如此说来，这些邪恶的灵乃被称为在天上。但这是何意？许多人说，此处的天是指我们的大气层，即假定为恶魔的居所；参二章2节。然而 <span style="color:#0000d4">τὰ ἐπουράνια</span> 在本书信别处从未用以指大气之天；圣经也丝毫不支持古代世人的通俗见解，以为空中乃是灵界所居之域；这一想法与上下文亦不相合。若说这些邪灵住在我们的大气层中，并不足以显出它们权势之大。然而通篇上下文都表明，使徒的用意是要以最能感人的方式，呈现我们仇敌那可畏的性情。另有人以为，保罗所指的乃是这些高位者先前的居所，而非如今的居所；它们是堕落的天使，曾一度住在天上。更好的解法，是将“天”字取广义。此字极常与<span style="color:#800000">*地*</span>字对举。“天地”二字包括全宇宙。凡不属地的，便属天。一切有理智的存在，非属地即属天。属后一类的，有善有恶，正如天使曾住在天上一样。但这显然与他话语的本意不合。他说它们是在天上。更好的解法，是将“天”字取广义。此字极常与<span style="color:#800000">*地*</span>字对举。“天地”二字包括全宇宙。凡不属地的，便属天。一切有理智的存在，非属地即属天。属后一类的，有善有恶，正如天使中有圣洁的，也有不圣洁的。这些执政的、掌权的，这些管辖者与邪恶的灵，并非地上的权贵，乃是属乎天界智者之列，因此更当畏惧；使徒所论的这场争战，所需的也就不止是人的力量与属地的兵器了。这便指明了与下一节的关联。

<div class="commentary-anchor" id="ephesians-6-13"></div>
第13节。<span style="color:#800000">*所以*</span>，即，因为你们有如此可畏的仇敌，又因这场争战无可避免，<span style="color:#0000d4">ἀναλάβετε τὴν πανοπλίαν τοῦ θεοῦ</span>，不仅是要武装自己，乃是要<span style="color:#800000">*拿起神所赐的全副军装*</span>；此外别无军装足以应付这样的危急。<span style="color:#0000d4">Ινα δυνηθῆτε ἀντιστῆναι ἐν τῃ ἠμέρᾳ τῃ πονηρᾳ</span>，<span style="color:#800000">*好叫你们能以抵挡*</span>，即能够成功地抵挡，<span style="color:#800000">*在那磨难的日子*</span>。这磨难的日子乃是受试炼之日。诗篇41:2，“他遭难的日子，耶和华必搭救他”；七十士译本作<span style="color:#0000d4">ἐν ἠμερᾳ</span> <span style="color:#0000d4">πονηρᾳ</span>；诗篇49:5，“在患难的日子，我何必惧怕”；七十士译本作<span style="color:#0000d4">ἐν ἠμερᾳ πονηρᾳ</span>。此处所指的日子，乃是前面所提那些仇敌前来攻击的那确定之日。然而，这并不可特别地、更不可专一地理解为主再来之前与黑暗权势所要发生的那末后大争战。整段劝勉所论的乃是信徒当下的本分。他们此时就当披上军装，时刻预备迎受那可畏仇敌的攻击。

<span style="color:#0000d4">Καὶ άπαντα κατεργασάμενοι στῆναι</span> <span style="color:#800000">*并且成就了一切，还能站立得住*</span>。许多人将此解作预备迎战之意：既已作了万全的预备，就当站定，以待敌人的攻击。但这一意思已包含在本节前半部之中。另有人取 <span style="color:#0000d4">κατεργάζεσθαι</span> 为 <span style="color:#800000">*debellare, vincere*</span> 之义，即：既已胜过一切抵挡、征服了一切，就当站立。此词的通常意义本已含有这层意思。凡与争战相关的事都已作成，便得站立；也就是说，使你们在战事既毕之后，能以得胜者的身分守住自己的阵地。

<div class="commentary-anchor" id="ephesians-6-14"></div>
第14节。东方人衣袍宽大飘垂，故凡预备做事，第一件当行的便是束腰。所以使徒说，<span style="color:#0000d4">στῆτε οϋν περιζωσάμενοι τὴν ὀσφὺν ὐμῶν ἐν ἀληθείᾳ</span>，<span style="color:#800000">*所以要站稳了，用真理当作带子束腰*</span>。此处的<span style="color:#800000">*真理*</span>，不可理解为客观启示的神圣真理，即神的道；因为神的道在下一节已被称为宝剑。它也不是指<span style="color:#800000">*心地的诚实*</span>，因为诚实乃属天然的德行，不属于神所赐的军装；按上下文，这军装乃是由超自然的恩赐与恩典所构成。它所指的乃是主观方面的真理，即对真理的认识与相信。这是基督精兵首要而不可或缺的资格。若在无知或疑惑之中投入这场属灵的争战，便如同瞎眼瘸腿上阵。腰带既赐人力量与行动的自由，因而也赐人胆量；真理在人心里被属灵地领悟并相信时，其功效亦复如是。谁也不要以为，自己胸中装满了个人的见解，或别人的玄思臆度，就算预备好抵挡幽暗权势的攻击了。惟有神的真理被清楚明白、被诚心接纳，才能使人在这些天空的执政者面前站立片刻。理性、传统、思辨得来的信念、僵死的正统，不过是蛛网结成的带子，一经冲击便即断裂。惟有真理以神圣知识的形式常存于人心，才能在基督徒日常的争战中赐人力量与胆量，何况是在真正的“磨难的日子”。

<!-- PAGE 261 -->

<span style="color:#0000d4">Καὶ ἐνδυσάμενοι τὸν θώρακα τῆς δικαιοσύνης</span>，<span style="color:#800000">*又用公义当作护心镜遮胸*</span>。<span style="color:#0000d4">θώραξ</span>乃是“自颈项至股间遮护全身的甲胄，由两片构成，一片护前胸，一片护后背”。战士若无<span style="color:#0000d4">θώραξ</span>，便是赤身露体，仇敌的每一击刺，甚至偶然飞来的每一支箭，都能加于其身。在此境地，非逃即死。那在属灵军装中与护胸甲相应的公义，究竟是什么？许多人说，那是我们自己的公义、正直，或心思的端正。然而这算不得护卫。它抵挡不住良心的控告、沮丧的低语、试探的势力，更不必说律法的严厉，或撒但的攻击。保罗为自己所切慕的，并不是有自己的义，乃是有那因信神而来的义（腓立比书 3:8, 9）。无疑，这也正是他在此劝勉信徒当作护心镜穿戴的公义。这义无限完全，成于神儿子的顺服与受苦，满足了神的律法与公义的一切要求；无论内里或外来的攻击，它都是稳妥的防卫。正如在这一段落中，使徒无一处以纯然的道德美德作为基督徒的军装，此处亦然。这样的解释更不可能，因为主观意义上的公义，已包含在前一句“真理”一词所表达的意思之内。此处所用词语当取何义，乃由上下文的精神所决定。因为“公义”一词虽为使徒屡屡用以指因信而得的神的义，就其本身而论，自然也可表示个人的正直或公正。在以赛亚书 59:17，耶和华被描述为“以公义为铠甲，以拯救为头盔戴在头上”；正如以赛亚书 11:5论到弥赛亚说：“公义必当他的腰带，信实必当他胁下的带子。”

<div class="commentary-anchor" id="ephesians-6-15"></div>
第15节。古代战争在很大程度上是短兵相接的肉搏，因此脚步敏捷乃是好兵最要紧的素质之一。使徒劝勉读者当把脚穿好鞋，正是指此，<span style="color:#0000d4">ἐν ἑτοιμασίᾳ τοῦ εὐαγγελίου τῆς</span> <span style="color:#0000d4">εἰρήνης</span>，<span style="color:#800000">*用平安的福音当作预备走路的鞋穿在脚上*</span>。按一种解释，<span style="color:#0000d4">εὐαγγελίου</span> 是同位所有格，福音本身就是基督徒所当穿上的那 <span style="color:#0000d4">ἑτοιμασία</span>。如此，其意或是说福音乃是坚固之物，我们可将信靠安放其上；或是说福音使人轻捷，仿佛给双脚添上翅膀。另有人以 <span style="color:#0000d4">εὐαγγελίου</span> 为宾语所有格，而以 <span style="color:#0000d4">ἑτοιμασία</span> 为预备或敏捷之意。如此则其意为：“你们的脚穿上为福音而有的敏捷”，即为护卫福音、传扬福音而有的敏捷。然而最简明、也最合上下文的解释，乃是以 <span style="color:#0000d4">εὐαγγελίου</span> 为来源所有格，其意即：“你们的脚穿上平安的福音所赐的那份轻捷。”福音既使我们与神和好，又赐下神施恩眷顾的确据，就在人心里生出那欢欣轻快之情；而这正是在属灵争战中得胜所不可少的。凡疑惑皆使人软弱，绝望更是死亡。

<!-- PAGE 263 -->
<div class="commentary-anchor" id="ephesians-6-16"></div>
第16节。<span style="color:#0000d4">’</span><span style="color:#0000d4">Επὶ πᾶσιν</span>，<span style="color:#800000">*此外*</span>；并非指“最要紧的是”，好像它最为重要。除了前面已经提到的各样军装之外，他们还要拿起<span style="color:#0000d4">τὸν θυρεὸν τῆς πίστεως</span>，<span style="color:#800000">*信德当作藤牌*</span>。<span style="color:#0000d4">Θυρεός</span> 字面意思是门，转而指一种形如门扇的长方形大盾。这种盾长四尺、宽二尺半，足以遮蔽全身，为战士的安全所不可少。使徒的比喻正是由此而来贴切。信心便是这样一种护卫，也同样不可或缺。盾牌的用途愈多，这个比方也就愈为合宜。此处所指的信心，就是我们藉以称义、藉基督的血与神和好的那信心；就是以基督为对象、接受他为神的儿子和世人救主的那信心；就是“所望之事的实底，是未见之事的确据”的那信心，它一面洞察分辨属灵的事，一面又领受这些事。它胜过世界，希伯来书第十一章中的许多例证足以为证。信心本身既如此大有能力，且自古以来已屡屡显明其功效，所以使徒接着说：<span style="color:#0000d4">ἐν</span> <span style="color:#0000d4">ῳ δυνήσεσθε πάντα τὰ βέλη τοῦ πονηροῦ τὰ πεπυρωμένα σβέσαι</span>，<span style="color:#800000">*可以灭尽那恶者一切的火箭。*</span>这里显然是暗指古代战争中所用的一种投射武器，箭上缠有易燃之物，点着后射向敌人。诗篇 7:13 提到这等火箭：“他要使他的箭成为火箭”；参看亚历山大《诗篇注释》。这些箭被称为 <span style="color:#0000d4">τοῦ πονηροῦ</span> 的，不是如英文译本所译“恶人的”，而是<span style="color:#800000">*那恶者的*</span>，即魔鬼的。参马太福音 13:19、38。在后一处经文中，<span style="color:#0000d4">ὁ πονηρός</span> 于第39节被解释为 <span style="color:#0000d4">ὁ διάβολας</span>。另参约翰一书 2:13；3:12；5:18 及其他经文。火箭不但射穿，且将所射穿之物点燃，故其危险加倍。因此这里用它们象征撒但猛烈的攻击。他将火箭如雨般射在信徒心上；信徒若无信德的藤牌遮护，必速速灭亡。神的子民常有这样的经历：有时种种可怕的意念——污秽的、亵渎的、疑惑的、狠毒的——蜂拥而至，既非寻常心理活动的规律所能解释，又无法驱除。它们像火箭一般钉住不放，使人心灵痛苦不堪。这些惟有藉信心才能灭尽，就是呼求基督的帮助。然而火箭不止这一种，也不是最危险的一种。还有别的火箭，点燃情欲、煽动野心、激起贪婪、骄傲、不满或虚荣；所生的火焰，我们诡诈的心并不急于扑灭，往往任其焚烧，直到酿成重大的损害，甚至败亡。抵挡那恶者这些最危险的兵器，惟一的护卫就是信心。惟有仰望基督，恳切求他为我们出手干预，我们才能抵挡这些阴险的攻击——它们煽动罪恶，却不以痛苦先作警告。不过，本节所指的并不限于某一类特定的试探，乃是泛指撒但一切的攻击，就是那些使信徒的平安与稳妥格外陷于危险的攻击。

<!-- PAGE 264 -->
<div class="commentary-anchor" id="ephesians-6-17"></div>
第17节。古代盔甲中最具装饰性的部分，其重要性也几乎不亚于护心镜与盾牌的，便是头盔。因此，基督徒受劝勉要戴上 <span style="color:#0000d4">τὴν περικεφαλαίαν τοῦ</span> <span style="color:#0000d4">σωτηρίου</span>，<span style="color:#800000">*救恩的头盔*</span>。按前面几个说法——“公义的护心镜”、“信德的盾牌”——的类比，救恩本身就是那头盔。使基督徒得着装饰与保护、使他能满有确信与喜乐地昂首挺立的，正是他已蒙拯救这一事实。他是蒙救赎之人中的一个，已从黑暗的国度被迁入神爱子的国里。倘若他仍在定罪之下，仍与神疏远，作外人、作客旅，没有神、没有基督，他就断无勇气进入这场争战。正因他是与众圣徒同国的人，是神的儿女，是福音之救恩的有分者，他才能坦然无惧地面对最强大的仇敌，知道自己靠着那爱他的主，在这一切的事上已经得胜有余（罗马书 8:37）。使徒在帖撒罗尼迦前书 5:8 论到以得救的盼望为基督徒的头盔时，所表达的乃是同一思想，只是形式不同。后一处经文并不容我们在此处把“救恩的头盔”理解为<span style="color:#800000">*盼望*</span>的比喻性称谓。这两处经文虽然相似，却并不相同。一处说救恩是我们的头盔，另一处说盼望是；正如一处说“信与爱”是我们的护心镜，另一处却说公义是。

迄今所提及的军装都是防御性的。基督徒惟一的进攻兵器，乃是“圣灵的宝剑”。此处 <span style="color:#0000d4">τοῦ πνεύματος</span> 不能作同位属格。圣灵并非那宝剑；如此解释乃是不合宜的，因为剑是兵士所挥动之物，而基督徒却不能如此支配圣灵。况且，解释紧随其后，<span style="color:#800000">*就是神的道*</span>。“圣灵的宝剑”意即圣灵所赐的剑。所谓 <span style="color:#0000d4">ρῆμα θεοῦ</span>，既不可理解为神的诫命，也不可理解为神向仇敌所发的威吓。这一表述并无任何限定。它乃是神所说的话，是他的道，是圣经。这道比一切两刃的剑更快。它是神的智慧，也是神的大能。它有自证之光。它向人的理性与良心自荐其真。它不仅有真理的能力，更有神圣真理的能力。我们的主曾应许赐给门徒口才和智慧，是他们一切敌人所敌不住、驳不倒的。对抗一切谬误、一切虚假的哲学、一切虚假的道德原则、一切为罪恶所作的诡辩、一切魔鬼的试探，那惟一的、简明的、又是充足的答案，就是神的道。这道使一切黑暗的权势溃散奔逃。基督徒在自己的经历中发觉此事为真。它驱散他的疑惑；它逐去他的惧怕；它救他脱离撒但的权势。这也是全教会共同的经历。她胜过罪恶与谬误的一切凯旋，都是藉着神的道成就的。只要她使用这道、单单倚靠这道，她便所向披靡；但一旦容许别的东西——无论是理性、科学、传统，还是人的吩咐——取代它的位置，或分享它的职分，那么教会或基督徒便任凭仇敌宰割了。Hoc signo vinces——“凭此旌旗，你必得胜”——使徒对每一位信徒、对整个教会所说的，或可如此领会。

<div class="commentary-anchor" id="ephesians-6-18"></div>
第18节。战士之所以为战士，不在于甲胄兵器。必须有勇气与力量；即便如此，他仍常需援助。基督徒自身既无力量的源头，非蒙上面的帮助便不能得胜，故使徒力劝祷告的本分。信徒当：一、运用各样的祷告。二、在一切合宜的时机祷告。三、靠着圣灵祷告。四、在尽此本分上儆醒不倦。五、为众圣徒祈求；使徒也劝勉以弗所人为他祷告。

本节与第14节的 <span style="color:#0000d4">στῆτε οϋν</span> 相连：“所以要站稳了，藉着各样的祷告和祈求，随时靠着圣灵祷告。” <span style="color:#0000d4">Διὰ πάσης προσευχῆς καὶ δεήσεως</span> 可与下文的分词 <span style="color:#0000d4">προσευχόμενοι</span> 相连，英译本的译者即如此处理，将此处译作“用各样的祷告和祈求而祷告”。然而如此一来，经文便成了同义反复。另有人将此短语单独看待，把 <span style="color:#0000d4">διὰ</span> 理解为表明条件或情状：“所以，要用各样的祷告站稳了，随时祷告”云云。至于 <span style="color:#0000d4">δεήσις</span> 与 <span style="color:#800000">*祷告、祈求*</span> 二词的分别，有人说前者以求得善为目的，后者则以避免或脱离祸患为目的。但这两个词的用法并不支持此说。较为通行的看法是，其分别有二：其一，<span style="color:#0000d4">προσευχή</span> 只向神献上，而 <span style="color:#0000d4">δεήσις</span> 亦可向人提出；其二，前者包括一切向神的陈说，后者则限于祈求。<span style="color:#800000">*各样的祷告*</span> 这一说法，是指各类的祷告，无论是口中的还是心中的，是片语短求的还是循规成式的。保罗愿基督的战士所用的祷告，不只是密室之中、定时之刻的祷告，也包括那习以为常、随时而发的心灵仰望与归向神的心愿——这乃是常觉神之临近、常觉自己之缺乏所必然生出的。

<!-- PAGE 266 -->
不仅当用各样的祷告，信徒更当<span style="color:#0000d4">ἐν</span> <span style="color:#0000d4">παντὶ καιρῳ</span>，<span style="color:#800000">*随时*</span>祷告，即在每一急难之际祷告。这种恒切祷告，乃是我们的主所吩咐的，路加福音 18:1 说：“人常常祷告，不可灰心。”在帖撒罗尼迦前书 5:17，使徒劝勉信徒“不住的祷告”。由此可见，祷告包括与神一切的交通，乃是我们一切归于神的情感与愿望的表达。所以，按圣经所用此词的意义而言，人几乎可以字面地不住祷告。

第三条指示，是要<span style="color:#0000d4">ἐν πνεύματι</span>祷告。这并非如格老秀斯所解释的，意指<span style="color:#800000">*内心地*</span>或<span style="color:#800000">*用心灵*</span>祷告——non voce tantum, sed et animo（不仅用口，也用心）；乃是指在圣灵的感动之下、藉着他的帮助而祷告。因为圣灵恩慈的职分，正是教导我们当怎样祷告，并用说不出来的叹息为我们代求（罗马书 8:26）。第四条指示，与祷告中的警醒与恒切有关；<span style="color:#0000d4">εἰς αὐτὸ</span> <span style="color:#0000d4">τοῦτο ἀγρυπνοῦντες</span>，<span style="color:#800000">*为此儆醒不倦*</span>。所谓“此事”，即他方才所论的事，就是靠着圣灵祷告。他们当在这一本分上警醒儆惕，不容自己懈怠疲倦。<span style="color:#0000d4">πάσῃ προσκαρτερήσει καὶ</span> <span style="color:#0000d4">δεήσει περὶ πάντων τῶν ἁγίων</span>，<span style="color:#800000">*为众圣徒多方恒切祈求*</span>。“恒切与祈求”合起来，即恒久不懈、迫切不舍的祈求。在罗马书 12:12，其语为<span style="color:#0000d4">τῃ</span> <span style="color:#0000d4">προσευχῃ προσκαρτεροῦντες</span>，<span style="color:#800000">*祷告要恒切*</span>。这恒切的祈求，是要<span style="color:#800000">*为众圣徒*</span>献上的。使徒所论的这场争战，不单是个别基督徒与撒但之间的单人交锋，更是神的子民与幽暗掌权者之间的战争。上阵的兵丁，没有只为自己祷告的，也必为一切同袍祷告。他们同属一军，一人的得胜即众人的得胜。照样，基督徒也联合为一军，因而有共同的事业；故各人都当为众人祷告。本书信及圣经他处所阐明的圣徒相通，正是如此：他们彼此关切各人的福祉，断不能失，正如手不能不与脚相顾恤一样。

<!-- PAGE 267 -->
<div class="commentary-anchor" id="ephesians-6-19"></div>
第19节。使徒何等看重代祷，又何等确信代祷之功效，从他屡屡吩咐信徒尽此本分，以及恳切地为自己求人代祷，便可明见。使徒盼望以弗所信徒所求的，并非什么属世的福分，甚至不是求他得脱捆锁，好能更自由地传扬福音，乃是求神使他能照着所当传的那样，放胆坦然地传讲：<span style="color:#0000d4">, ἵνα μοι δοθῃ λόγος ἐν ἀνοίξει τοῦ στόματός μου,</span> <span style="color:#0000d4">ἐν παρρησίᾳ γνωρίσαι, κτλ</span>。我们的译者将此句意译为：<span style="color:#800000">*使我得着口才，能以放胆开口讲明*</span>，等等。按字面直译则是：<span style="color:#800000">*使我在开口的时候得着口才，可以放胆讲明*</span>，等等。保罗所渴望的，乃是在传道时得着从神而来的帮助。他求读者为他祷告，<span style="color:#0000d4">ἵνα μοι δοθῃ λόγος</span>，<span style="color:#800000">*使他开口之时，得着言语之能，或畅达的口才*</span>。保罗在哥林多后书11:6说，自己是<span style="color:#0000d4">ἰδιώτης τῳ λόγῳ</span>，<span style="color:#800000">*言语粗俗*</span>。<span style="color:#0000d4">λόγος</span>一词本身有时确按此处所取的借代义使用，因此<span style="color:#0000d4">ἐν</span> <span style="color:#0000d4">ἀνοίξει τοῦ στόματός</span> 最自然的理解，是不带强调之意，等同于<span style="color:#800000">*当我开口的时候*</span>，即当我被召去说话的时候。加尔文与许多人则把重点放在这几个字上，将<span style="color:#800000">*以开口*</span>解作<span style="color:#800000">*大张其口*</span>，即加尔文所说的 pleno ore et intrepida lingua（口舌全开、言语无惧）。Os opertum cupit, quod erumpet in liquidam et firmam confessionem. Ore enim semiclauso proferuntur ambigua et perplexa responsa.（他所愿的是张开的口，好迸发出清晰而坚定的承认；因为半闭之口所吐出的，乃是含糊迟疑之辞。）然而这样解释，便是把<span style="color:#0000d4">ἐν παρρησίᾳ γνωρίσαι</span>所要表达的意思提前说了。另有人把<span style="color:#0000d4">ἐν ἀνοίξει</span> <span style="color:#0000d4">τοῦ στόματός</span>与<span style="color:#0000d4">ἐν παρρησίᾳ</span>都连于<span style="color:#0000d4">γνωρίσαι</span>，作“开口放胆讲明这奥秘”等等。我们的译者似乎正是采取了这一句法。但从词序与分句的关系看，这样解殊不自然。<span style="color:#0000d4">Παρρησίᾳ</span>（<span style="color:#0000d4">πᾶν ρῆσις</span>）意即<span style="color:#800000">*尽情直言，畅所欲言*</span>。此处带<span style="color:#0000d4">ἐν</span>的与格可作副词用，即<span style="color:#800000">*坦然地、放胆地*</span>；毫无隐讳，乃将福音公开无饰地宣讲出来。不过这也含有心志上的坦荡与无惧之意，而这种毫无拘束的宣讲真理，正是此种心志的流露。<span style="color:#0000d4">Μυστήριον</span> <span style="color:#0000d4">τοῦ εὐαγγελίου</span>，<span style="color:#800000">*福音的奥秘*</span>；福音本身就是那奥秘，即神的启示。这真理体系从前在神那里是隐藏的，如今却已显明，使我们得荣耀；见哥林多前书2:7。

<!-- PAGE 268 -->
<div class="commentary-anchor" id="ephesians-6-20"></div>
第20节 <span style="color:#0000d4">’</span><span style="color:#0000d4">Υπὲρ ου</span>，<span style="color:#800000">*我为这福音的缘故*</span>，<span style="color:#0000d4">πρεσβεύω ἐν ἁλύσει</span> <span style="color:#0000d4">εἰμί</span>，<span style="color:#800000">*作了带锁链的使者*</span>。所谓使者，乃是君王藉以发言之人。“我们作基督的使者，就好像神藉我们劝你们一般。我们替基督求你们与神和好”（哥林多后书 5:20）。使徒既奉基督差遣，得着权柄奉他的名说话，与世人交涉，向他们提出和好的条件并力劝他们接受，便在极卓越的意义上作了基督的使者。而一切传道人既同样为基督所差、受他委任去提出得救的条件，也就配得这同一尊荣的称号。保罗是带着锁链的使者，然而他并未因此丧胆，反倒一如既往地放胆传讲。

<span style="color:#0000d4">Ινα ἐν αὐτῳ παρρησιάσωμαι</span>，<span style="color:#800000">*叫我按着当尽的本分放胆讲论*</span>。此句可视为承接第19节的 <span style="color:#0000d4">ἵνα δοθῃ</span>，其意则为：“使我得着口才，可以放胆讲说。”然而前面的 <span style="color:#0000d4">ἐν παρρησίᾳ γνωρίσαι</span> 已是承接 <span style="color:#0000d4">ἵνα δοθῃ</span> 而言，故两个分句毋宁说是彼此平行的。保罗所求于以弗所人的代祷乃是：“使我得着口才，就是使我能放胆传道”，<span style="color:#0000d4">ὡς δεῖ με λαλῆσαι</span>，<span style="color:#800000">*照着我所当讲的*</span>。凡作神使者的人，既深知自己所当传之信息的真实与重大，就理当放胆而言。连保罗尚且恳求众信徒为他代祷，使他能正确地传扬福音，足见他何等深切地体会到这工作的艰难与重大。

<div class="commentary-anchor" id="ephesians-6-21"></div>
第21节。 末了，使徒告知以弗所人，他已打发推基古到他们那里去，好解除他们为他所怀的忧虑；<span style="color:#0000d4">ἵνα δὲ εἰδῆτε</span> <span style="color:#0000d4">καὶ ὐμεῖς</span>，<span style="color:#800000">*但要叫你们也知道*</span>，即：你们和其他在我受捆锁时为我挂心的基督徒朋友一样；<span style="color:#0000d4">τὰ κατ</span><span style="color:#0000d4">’</span> <span style="color:#0000d4">ἐμέ</span>，<span style="color:#800000">*我的景况*</span>，即我的处境；<span style="color:#0000d4">τί πράσσω</span>，不是指我在作什么，因为这一点他们已经知道，乃是指<span style="color:#800000">*我如何行事、境遇如何*</span>。他的身体状况与他的处境一样，都是他朋友们所挂虑的。<span style="color:#800000">*推基古必将一切的事都告诉你们*</span>；<span style="color:#0000d4">ὁ ἀγαπητὸς ἀδελφὸς καὶ πιστὸς διάκονος ἐν κυρίῳ</span>；这句话容许两种解释。其一可指推基古既是保罗的弟兄，也是保罗的<span style="color:#0000d4">διάκονος</span>，即仆人。此说虽未为加尔文所采纳，却为他所称许，并得许多最优秀的注释家所主张；其理由是：<span style="color:#0000d4">ἀδελφὸς</span> 与 <span style="color:#0000d4">διάκονος</span> 二词最自然的读法乃是同指一人一事，即“我所亲爱的弟兄和忠心的仆人”；况且保罗在别处也屡次提到那些随侍他、以各样方式服事他的人。按此解释，<span style="color:#0000d4">ἐν</span> <span style="color:#0000d4">κυρίῳ</span> 这几个字同属于两个称呼：他在主里既是弟兄，也是仆人，即基督徒的弟兄与基督徒的仆人。

<!-- PAGE 269 -->

然而更为常见的理解，乃是使徒在此称许推基古为福音忠心的执事。在歌罗西书 4:7，他被称为*同作仆人的*，这有利于以下推断：他在圣工上是保罗的同工。提及他的地方还有使徒行传 20:4、提摩太后书 4:12、提多书 3:12。不过这些经文除了表明他是随从保罗的人之一以外，对他与使徒的关系并未提供更多亮光。然而，既然保罗在下一节说，他打发推基古去，不但是要他们知道他的景况，也是要<span style="color:#0000d4">παρακαλέσῃ τὰς καρδίας ὐμῶν</span>，<span style="color:#800000">*叫他安慰你们的心*</span>；那么，他是基督的执事这一看法便大有可能，因为他不但能将有关保罗的好消息带给以弗所人，使之得安慰，更能以福音中更高的安慰传与他们。

<div class="commentary-anchor" id="ephesians-6-23"></div>
第23节。<span style="color:#0000d4">Εἰρήνη τοῖς ἀδελφοῖς</span>，<span style="color:#800000">*愿平安归与弟兄们*</span>。这是通常的问安或祝福的形式。此处所指的并非和睦，乃是<span style="color:#0000d4">χάρις</span>即神之恩眷所结的一切果子。<span style="color:#0000d4">Καὶ ἀγάπη μετὰ πίστεως</span>，这并非指爱与信心并列，仿佛所指的是两样各自独立的福分；乃是指与信心相连的爱。信心他们已经有了；保罗所祈求的，是愿爱与信心相联。此处所指的爱，必是弟兄相爱之爱。这些福分是求<span style="color:#0000d4">ἀπὸ θεοῦ πατρὸς καὶ κυρίου</span> <span style="color:#0000d4">’</span><span style="color:#0000d4">Ιησοῦ</span> <span style="color:#0000d4">Χριστοῦ</span>，<span style="color:#800000">*从父神并主耶稣基督而来*</span>。父与子在此联合为敬拜的对象，并为属灵与拯救之福的源头。保罗向之祈求这些福分的那一位，也正是凡需要这些福分的人为得着它们所当仰望的那一位。

<!-- PAGE 270 -->
<div class="commentary-anchor" id="ephesians-6-24"></div>
第24节。使徒至终不渝，如磁针之指北极，再度转向基督，为一切诚心爱我们主耶稣基督的人祈求神的恩惠。<span style="color:#0000d4">ἐν ἀφθαρσίᾳ</span> 一语，和合本作<span style="color:#800000">*诚心*</span>，伊拉斯谟与加尔文即如此理解，此外持此见者亦众。然而对其确切含义，众说纷纭。<span style="color:#0000d4">’</span><span style="color:#0000d4">Αφθαρσίᾳ</span> 意为<span style="color:#800000">*不朽坏*</span>，如哥林多前书 15:53, 54 所言，<span style="color:#0000d4">δεῖ γὰρ τὸ φθαρτὸν τοῦτο</span> <span style="color:#0000d4">ἐνδύσασθαι ἀφθαρσίαν</span>，<span style="color:#800000">*这必朽坏的总要变成不朽坏的*</span>。由此引申为<span style="color:#800000">*不朽*</span>，如罗马书 2:7；提摩太后书 1:10。有人将此语与 <span style="color:#0000d4">’</span><span style="color:#0000d4">Ιησοῦ Χριστοῦ</span> 相连，作<span style="color:#800000">*在不朽中的基督*</span>，即得荣耀的基督。另有人将其与 <span style="color:#0000d4">χάρις</span> 相连，并使 <span style="color:#0000d4">ἐν</span> 取 <span style="color:#0000d4">εἰς</span> 之意，解为“归于不朽、归于永远的恩惠；即永不止息的恩惠”。还有人虽采同一句法，却译作“恩惠与不朽同在，即永生”。惟一自然的连法是与 <span style="color:#0000d4">ἀγαπώντων</span> 相连，那么其意或如英文译本所表达的：“诚心爱我们主耶稣基督的人”；或作“以恒久之心，即以至死不渝、永不朽坏之爱爱他的人”。无论取何解，大意相同：神的恩惠临到那以主耶稣为至上所爱之人。在哥林多前书 16:22，保罗说：“若有人不爱主耶稣基督，这人可诅可咒。”这两处经文虽极不相类，却同样教导我们：爱基督乃是得救不可或缺的条件。此中必有充足的理由。不爱基督必当受最终的沉沦，爱基督必包含进天国的预备。这就必然以基督是神为前提。不爱他，就必然意味着与神为敌。倘若一个人不肯在神性情最清晰的启示中、在他最确定的位格显现中、在他与我们最亲密的关系中（他取了我们的本性，爱我们，又为我们舍己）认识并爱这同一位神，却自以为能爱那在自然界或在圣经中显明的无限之灵，这全是自欺。爱基督包含对他位格的敬慕称叹、对他同在的渴慕、为他荣耀的热心、以及对他事奉的献身。这爱不必是狂喜的，却必须是支配全人的。

<p style="text-align:center" markdown="1">**全书完**</p>
