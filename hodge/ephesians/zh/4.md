<p style="text-align:center" markdown="1"><span style="color:#006411">**第四章**</span></p>

劝勉合一，第1-16节——劝勉圣洁及各样具体美德，第17-32节。

<p style="text-align:center" markdown="1">**第一段　— 第1-16节**</p>

<span style="color:#800000">*1. 我为主被囚的劝你们，既然蒙召，行事为人就当与蒙召的恩相称，*</span>

<span style="color:#800000">*2. 凡事谦虚、温柔、忍耐，用爱心互相宽容，*</span>

<span style="color:#800000">*3. 用和平彼此联络，竭力保守圣灵所赐合而为一的心。*</span>

<span style="color:#800000">*4. 身体只有一个，圣灵只有一个，正如你们蒙召，同有一个指望，和你们所蒙的召一样；*</span>

<span style="color:#800000">*5. 一主，一信，一洗，*</span>

<span style="color:#800000">*6. 一神，就是众人的父，超乎众人之上，贯乎众人之中，也住在你们众人之内。*</span>

<span style="color:#800000">*7. 我们各人蒙恩，都是照基督所量给各人的恩赐。*</span>

<span style="color:#800000">*8. 所以经上说：他升上高天的时候，掳掠了仇敌，将各样的恩赐赏给人。*</span>

<span style="color:#800000">*9. （既说升上，岂不是先降在地下吗？*</span>

<span style="color:#800000">*10. 那降下的，就是远升诸天之上要充满万有的。)*</span>

<span style="color:#800000">*11. 他所赐的，有使徒，有先知，有传福音的，有牧师和教师；*</span>

<!-- PAGE 138 -->

<span style="color:#800000">*12. 为要成全圣徒，各尽其职，建立基督的身体：*</span>

<span style="color:#800000">*13. 直等到我们众人在真道上同归于一，认识神的儿子，得以长大成人，满有基督长成的身量：*</span>

<span style="color:#800000">*14. 使我们不再作小孩子，中了人的诡计和欺骗的手段，被一切异教之风摇动飘来飘去，就随从各样的异端；*</span>

<span style="color:#800000">*15. 惟用爱心说诚实话，凡事长进，连于元首基督：*</span>

<span style="color:#800000">*16. 全身都靠他联络得合式，百节各按各职，照着各体的功用彼此相助，便叫身体渐渐增长，在爱中建立自己。*</span>

<p style="text-align:center" markdown="1">**分析**</p>

使徒劝勉读者行事为人当与所蒙的呼召相称。如此行事为人，必以谦卑、温柔、忍耐，以及竭力促进属灵的合一与和睦为其标志（1-3节）。教会之所以为一，乃因它是一个身体，有一位圣灵、一个指望、一位主、一个信、一个洗，并有一位神——就是众人的父，超乎众人之上，贯乎众人之中，也住在众人之内（4-6节）。

<!-- PAGE 139 -->
然而，这合一与恩赐的极大差异并不相悖，基督照着自己的旨意将各样恩赐分给各人，第7节。此点由《诗篇》中的一段经文得着印证，该处论到弥赛亚将恩赐赏给人；而这段经文必定是指着基督说的，因为它所说的是一位神圣的位格升上高天，而升上高天必然含有先前降到地上之意，第9-10节。基督赐给祂教会的恩赐，就是各等各样的执事：使徒、先知、传福音的、以及作教师的牧师，第11节。设立圣职的目的，乃在于建立教会，使其全体肢体在信心与知识上同归于一，并长成基督的身量；使他们不再有小孩子的摇摆不定，乃要成为坚固、联络合式、日渐长进的身体，与作元首的基督有活泼的联合，第12-16节。

<p style="text-align:center" markdown="1">**注释**</p>

<div class="commentary-anchor" id="ephesians-4-1"></div>
第1节。 <span style="color:#0000d4">Παρακαλῶ οϋν ὐμᾶς ἐγὼ ὁ δέσμιος ἐν Κυρίῳ</span>。这一劝勉是笼统而言的；它由前面所阐述的教义流出，并借着发出劝勉之人的权柄与所受的苦难而得以加重。既然你们同有基督所买赎的救恩，“我因此劝你们。”我这作囚犯的——不是说主的囚犯，乃是说<span style="color:#800000">*在*</span>主里的囚犯，<span style="color:#0000d4">ἐν Κυρίῳ</span>。他之所以身陷囹圄，是因他在主里，且是为主的缘故。他之被囚，乃是因为身为基督徒，且为基督的事业而受苦。可参看屡次出现的说法：<span style="color:#0000d4">συνεργὸς   ὲν Χριστῳ, ἀγαπητὸς ἐν Κυρίῳ, δόκιμος ἐν Χριστῳ,</span> <span style="color:#0000d4">ἐκλεκτὸς ἐν Κυρίῳ</span>。他自称为囚犯，并非为要引人同情，也不仅仅是为使自己的劝勉更有分量，倒不如说，是因自己被算为配得为基督的缘故受苦而欢欣夸耀。这正合乎提阿多勒那句优美的评语：<span style="color:#0000d4">τοῖς  διὰ τὸν Κριστὸν δεσμοῖς</span> <span style="color:#0000d4">ἐναβρύνεται μᾶλλον ή βασιλεὺς διαδήματι,</span> <span style="color:#800000">*他以自己的锁链为荣，过于君王以冠冕为荣*</span>。“我，殉道者保罗，戴冠冕的使徒，劝你们”云云。如此，这一切便与前段经文所显明的那种崇高情怀完全一致。

<!-- PAGE 140 -->
这劝勉乃是：<span style="color:#0000d4">ἀξίως περιπατῆσαι τῆς κλήσεως ης ἐκλήθητε</span>，<span style="color:#800000">*行事为人与他们所蒙的召相称*</span>。那召乃是召他们得儿子的名分（第一章5节）。这其中包含三样：圣洁、高升与合一。他们蒙召效法基督的形像，有分于他的高升与荣耀，并且既同为神的儿女，便构成一家。因此，与这样的呼召相称的言行，必当以圣洁、谦卑、彼此宽容和弟兄相爱为特征。所以使徒随即加上：<span style="color:#800000">*凡事谦虚、温柔*</span>。凡心地纯正之人，得着不配得的尊荣，总必生出这样的果效。从卑贱困苦的深处被提拔起来，作了神的儿子，因而被高举到难以想象的地位与尊荣，这事必然产生谦卑与温柔；也理当如此。若不见这等果效，我们就可以断定：那高升并未发生。<span style="color:#800000">*谦虚的心*</span>，<span style="color:#0000d4">ταπεινοφροσύνης</span>，包含对自己的低微看法——这看法建立在自知有罪、自知软弱之上——并由此而来的甘居卑下、不求人见、不求人赞的心志。它所敌对的，不仅是自满自负，也是自我高举，以及抬高自己以博取从人而来的尊荣。罗马书12:16即教导此理，那里的 <span style="color:#0000d4">τὰ ὑψηλὰ</span>，<span style="color:#800000">*志气高大*</span>，正与此处所劝的谦虚之心相对。谦卑与温柔之间原有一种天然的联系，故此处将二者并列，正如在许多别处一样。<span style="color:#0000d4">Πραότης</span> 就是<span style="color:#800000">*柔和、温良、温驯*</span>，此德若与刚强相联，便是我们本性中最可爱的属性之一。那有福的救主论到自己说：“我心里柔和（<span style="color:#0000d4">πρᾶος</span>）谦卑”（马太福音 11:29）；使徒也提到“基督的温柔”（哥林多后书 10:1）。温柔乃是那不抵抗、不怨尤的心境，使我们能担当别人的过失或加害，而不动气、不怀恨。羔羊在剪毛的人手下无声，正是这心志的象征；这也是神儿子一切美德中最令人惊叹的一样。万有之中至尊至高的那一位，也是最温柔的。

与我们所蒙的召相称的第三样相关美德，乃是<span style="color:#800000">*恒忍*</span>；<span style="color:#0000d4">μακροθυμία</span> 是一种克制怒气的心性，见哥林多后书 6:6；加拉太书 3:22；歌罗西书 3:12；它也指延缓施行刑罚，故此常被归于神，见罗马书 2:4；9:22；彼得前书 3:10；又指对我们同胞的耐心宽容，见提摩太后书 4:2；提摩太前书 1:16。下文即是对它的解释，即，用爱心互相宽容。<span style="color:#800000">*或者更确切地说，谦卑、温柔、恒忍这三样美德，都在这彼此的宽容中得以显明和表现出来。*</span> <span style="color:#0000d4">’</span><span style="color:#0000d4">Ανέχρ</span> <span style="color:#800000">*是"约束"之意，*</span><span style="color:#0000d4">ἀνέχομαι</span>，<span style="color:#800000">*即"约束自己"*</span>，故 <span style="color:#0000d4">ἀνεχόμενοι ἀλλήλων ἐν ἀγάπῃ</span> 的意思便是<span style="color:#800000">*在爱中彼此约束自己*</span>。当让爱心促使你们彼此宽容。

<!-- PAGE 141 -->
我们译者所采取的句读，胜于另外两种读法：一是将 <span style="color:#0000d4">μετὰ μακροθ.</span> 与 <span style="color:#0000d4">ἀνεχ</span>. 相连，作“<span style="color:#800000">*用恒忍彼此宽容*</span>”；二是将 <span style="color:#0000d4">ἐν ἀγάπῃ</span> 从本句分出，归于下一句，读作 <span style="color:#0000d4">ἐν ἀγάπῃ σπουδάζοντες</span>。分词 <span style="color:#0000d4">σπουδάζοντες</span> 自然是与前文相连的。他们当行事为人与蒙召的恩相称，彼此宽容，竭力保守圣灵所赐合而为一的心。论到<span style="color:#800000">*圣灵所赐的合一*</span>这一短语，历来有三种解释：一、指教会的合一，如格老秀斯所言：unitatem ecclesiae, quod est corpus spirituale（教会的合一，教会即属灵的身体）。譬如哥林多教会所显露的种种不和——不但分党结派，更有“诸灵”之相争，即在领受属灵恩赐之人中间的争竞——使徒愿以弗所人在教会中显明他们是被同一位灵所感动的。然而此解不但与词语的浅明意义不合，也与上下文不合。二、以“灵”指人的灵，“灵的合一”即 <span style="color:#800000">*concordia animorum*</span>（心志的和洽），亦即和睦。三、唯一既合乎词语通常用法、又合乎上下文的解释，乃是将此语理解为：圣灵为其创始者的那种合一。圣经处处都说，圣灵的内住乃是基督身体中合一的本原。这合一可以被促进，也可以被搅扰。劝勉的话是：当以极大的热忱保守此合一；而保守的凭借，乃是<span style="color:#800000">*和平的联索*</span>，即那以和平为内容的联索。由爱心、谦卑、温柔与彼此宽容而生的和睦，对基督身体各肢体的联合与相交乃是不可或缺的，而这联合与相交正是圣灵同在的果子与凭据。正如基督徒中间的仇恨、骄傲与争竞叫圣灵离开他们，照样，爱与和睦使他们得着祂的同在。既然祂的同在乃是一切善的条件与源头，祂的离去乃是一切恶的根源，则此处所命之本分，其紧要处无论如何估量也不为过。我们的主说过：“使人和睦的人有福了。”教会之内既有不同邦国、不同风俗、不同名称、不同宗派的人，其间素有不谐之处；凡在其中竭力保守那作为圣灵同在之条件的和睦的人，便是有福的。使徒在本书如在其余书信中一样，竭力要引犹太人与外邦人的信徒同归于这彼此宽容的心志，并使他们确信：在基督耶稣里我们都成为一了。[^f12]

因为在歌罗西书 3:14 中，爱被称为“联络全德的”，所以许多注释家认为本处“和平的联络”即是爱。

<!-- PAGE 142 -->

本格尔即持此说：<span style="color:#800000">*Vinculum quo pax retinetur est ipse amor*</span>（维系和平的联络就是爱本身）。然而这两处经文其实并不真正平行：歌罗西书中提及了爱，此处却未提；况且若不偏离字面的浅明意义，其义已简明而通顺。因此绝大多数解经者采纳上文所述的看法。

<div class="commentary-anchor" id="ephesians-4-4"></div>
第4节。使徒既已力劝信徒当守合一之责，便进而阐明这合一的性质与根据。这合一之所以存在，乃是基于这一事实——身体只有一个，圣灵只有一个，指望只有一个，主只有一位，信心只有一个，洗礼只有一个，神只有一位，并且也不能有别的。

<span style="color:#800000">*身体只有一个*</span>，<span style="color:#0000d4">ἑν σῶμα</span>。这并非劝勉，而是宣告。其意不是说：我们当在一个身体里、或在灵与身上联合为一；按上下文所要求的，这乃是一句单纯的陈述。事实是：有一个身体，即基督那一个奥秘的身体。凡信徒都在基督里；他们都是他的肢体；他们所构成的不是许多身体，更不是彼此相争的身体，乃是一个身体。“我们这许多人，在基督里成为一身，互相联络作肢体。”罗马书 12:5；哥林多前书 10:17；12:27。在第一章 23 节，教会被称为“他的身体，是那充满万有者所充满的”。既然一切真信徒都是这身体的肢体，而这一切人又不能尽包于任何一个外在的组织之内，那么显然，使徒所说的这一个身体，并非某一个外在可见的团体，乃是一个属灵的身体，基督是元首，一切重生的人都是肢体。因此，信徒彼此之间所处的关系，正如人身上各肢体彼此相联的关系。缺乏体恤之情，即是并非肢体的凭据。

<span style="color:#800000">*一个灵*</span>，<span style="color:#0000d4">ἑν πνεῦμα</span> 此处同样不是指<span style="color:#800000">*一个心*</span>。这既非劝人情感一致，也非宣告这种一致已然存在。<span style="color:#800000">*他仿佛是说，我们当在身体与灵魂上全然合一，而非仅在某一部分上合一*</span>。上下文与圣经的类比——若将平行经文加以对照便可显明——证明此处的"灵"乃是指圣灵。正如身体只有一个，灵也只有一位；这灵是那身体的生命，住在它一切肢体之中。使徒说：“我们不拘是犹太人，是外邦人，是为奴的，是自主的，都从一位圣灵受洗，成了一个身体，饮于一位圣灵。”哥林多前书 12:13。论到一切信徒，他说：“神的灵住在你们里头。”<!-- PAGE 143 -->哥林多前书 3:16；6:19；罗马书 8:9, 11。圣经中再没有比这更明白启示的道理：神的灵住在一切信徒里面，而他的同在乃是他们作为基督身体而合一的终极根据。人的身体因有一个魂贯通其中而为一；照样，基督的身体也因有同一位圣灵贯通其中而为一，这位圣灵住在众人里面，成了共同的生命原则。所以，一切干犯合一的罪，都是干犯圣灵的罪。这些罪把圣灵所联合的拆散了。我们既作基督身体的肢体，与他有此关系；又与作我们生命的圣灵有此关系；这两重关系都要求我们爱弟兄，并与他们和睦同居。

<!-- PAGE 144 -->
<span style="color:#800000">*正如你们蒙召，同有一个指望和你们所蒙的召一样*</span> <span style="color:#0000d4">καθὼς καὶ ἐκλήθητε ἐν</span> <span style="color:#0000d4">μιᾳ ἐλπίδι τῆς κλήσεως ὐμῶν</span>。<span style="color:#800000">*正如*</span>。意即：信徒既同有一个指望，便是一个身体、有一个圣灵。他们既同有这至高的归宿，又同怀这一样的期盼，此事本身就证明他们是合一的。他们指望的合一，乃是圣徒相通的又一凭据，也是其中的又一要素。圣灵住在他们里面，便生出同样的渴慕，同样的期待，指望那同一荣耀的基业——他们原是蒙召去承受这基业的。<span style="color:#800000">*指望*</span>一词，有时指所指望的事物，如使徒论到那存在天上的盼望（歌罗西书 1:5）。又见提多书 2:13；希伯来书 6:18。当然，此词多数场合取其主观之义，即对将来美善之事的期待。此处并无理由离弃这一意义，虽然另一义与之紧密相连，且必然包含在内。正因所盼望的对象是同一的，那期待才是同一的。<span style="color:#800000">*你们所蒙的召的指望*</span>，即由你们蒙召而生发的指望。圣灵内在的有效恩召之所以生出这指望，有两个缘故。其一，因他们所蒙的召，乃是召他们去承受圣徒在光明中的基业。人既受邀去领受什么，自然就指望得着什么。他们既被召去与神和好、与神相交，便指望他所赐的救恩。其二，这恩召的性质本身也使其生发盼望。它既是他们将来基业的凭据，又是其预尝。参看第一章 14 节及哥林多前书 1:22。它使信徒确知自己在救赎诸福中有份（罗马书 8:16）；正如一滴水使干渴的旅人更加渴慕那涌流的活泉，照样，圣灵初结的果子，即他在人心中起初的成圣工作，也使人心渴慕神（诗篇 42:1, 2）。指望既兼含期待与渴慕，那么圣灵内在的工作，其性质既是凭据又是预尝，就必然生出指望。

教会合一的另一根基，乃是其全体肢体同有一位主。主权（Lordship）包含所有权与权柄两层意思。严格说来，一位主既是产业的所有者，又是统治者。当这字用于神或基督时，便以至高的程度表达这两层意思。基督是那主，即 omnium rerum summus dominus et possessor。他是我们的主，就是我们合法的所有者与绝对的君王。这所有权与主权兼及灵魂与身体。我们不是自己的人，理当在身子和灵里荣耀他，因为身子和灵都是他的。我们的理性顺服他的教训，我们的良心顺服他的诫命，我们的心与生活都在他的掌管之下。我们是他的奴仆。而我们的自由正在于此。这就是奥古斯丁所说的<span style="color:#800000">*felix necessitas boni*</span>。这好比人绝对降服于真理与圣洁，只是此处所降服的乃是一位在知识与美善上皆为无限的位格。这加于我们之上的主权，并非单单因基督是神、是道（Logos）而归于他，乃是因他是神人二性合一者（Theanthropos）而归于他。它不仅建基于他的神性，更特别建基于他救赎的工作。我们属他，因他曾用自己至宝的血把我们买来。哥林多前书 6:20；彼得前书 1:1。他死而复活，正是为此，要作死人并活人的主。罗马书 14:9。基督主权的性质与根基既然如此，就必然将属他的子民联结为一。同一主人的仆役、同一君王的臣民，彼此之间尚且亲密相连，虽然那所有权与权柄不过是外在的。但在我们与基督的关系中，这所有权与主权乃是绝对的，兼及灵魂与身体，其中的联合便亲密到无可言喻。对同一位主宰之忠诚，使基督一切的门徒同被一个心志所激励。

<span style="color:#800000">*一信*</span>。这是使徒所列举的第五重联合的纽带。许多注释家否认<span style="color:#0000d4">πίστις</span>一词曾用以指信心的对象，即所信的内容；因此他们否认此处的<span style="color:#800000">*一信*</span>意指一个信条。然而，既然这种解释与语言的普遍用法相合，且在许多经文中该词的客观意义最合乎上下文，那么似乎没有充分理由拒绝承认这一用法。在加拉太书 1:23，保罗说：<!-- PAGE 145 -->“他传扬他原先所残害的真道”；在使徒行传 6:7，经上说，人“信从了这道”。使徒犹大也论到“从前一次交付圣徒的真道”。在这些以及许多别的例证中，客观意义乃是最自然的意义。在许多情形下，该词的两种意义可以合而为一。就徒有思辨之信的人而言，也可以说他们有一个信仰，因为他们所宣认的是同一信条，尽管他们内心的确信可能彼此迥异。英国国教会的全体成员都有一个信仰，因为他们都宣称接受《三十九条信纲》，虽然他们中间盛行着极大的教义分歧。但真信徒有一个信仰，不仅因为他们宣认同一信条，更因为他们真实地、由衷地怀抱此信条。所以，他们的联合不只是外在的联合，乃是内在的、属灵的联合。他们在客观上与主观上都有同一的信心。这信心的合一尚未完全。正如使徒在本章后文所告诉我们的，那乃是教会所竭力奔赴的目标。信心上的完全合一意味着完全的知识与完全的圣洁。惟有就根本要道而言，就是那些为敬虔所必需、因而为得救所必需的要道，才可以说如今地上的全教会有此合一。在这界限之内，神一切真正的子民乃是联合为一的。他们都领受圣经为神的话，并承认自己服在圣经的教训之下。他们都承认并敬拜主耶稣为神的儿子。他们都仰赖他的宝血得蒙救赎，仰赖他的圣灵得以成圣。

<span style="color:#800000">*一洗*</span>。在旧约的时代，外邦人归入犹太人中时，他便公开承认自己加入神与其子民所立的约，并领受割礼的记号；这记号不仅是门徒身分的标记，更是那约的印证。因此凡受割礼的人都是<span style="color:#800000">*foederati*</span>，即被立约之带所联结、同归于一位神、彼此相联的人。照样，在新约的时代，凡受洗的人也是<span style="color:#800000">*foederati*</span>，即在约中与基督相联、并彼此相联的人。洗礼只有一个。凡受洗的人都作同样的宣认，接受同样的约，并被分别为圣归于同一位主和救赎主。所以他们乃是一个身体。“你们受洗归入基督的，都是披戴基督了。并不分犹太人、希腊人，自主的、为奴的，或男或女，因为你们在基督耶稣里都成为一了。”加拉太书 3:27, 28。

<div class="commentary-anchor" id="ephesians-4-6"></div>
第6节。<span style="color:#800000">*一神，就是众人的父，超乎众人之上，贯乎众人之中，也住在我们众人之内。*</span><span style="color:#0000d4">εις θεὸς καὶ πατὴρ πάντων, ὁ ἐπὶ πάντων καὶ διὰ πάντων καὶ</span> <span style="color:#0000d4">ἐν πᾶσιν ἡμῖν</span>。教会之所以为一，既因有同一位圣灵贯乎其中，又因它归属于同一位主、受同一位主治理；照样，教会之所以为一，也因它有同一位神与父，有同一位荣耀者，教会对他兼有受造之物与儿女的双重关系。这位神不仅在我们之上、远隔于我们，而且贯乎众人之中、住在我们众人之内，就是说，他以自己那托住万有、赐予生命的同在，遍透并充满万有。圣经中有许多经文，虽未直接申明三位一体的教义，却因这教义而具有神圣的节律，此处便是如此：有一位圣灵，有一位主，有一位神，就是众人的父。教会的合一即建立在这一教义之上。教会所以为一，是因为在我们只有一位神与父、一位主、一位圣灵。这是真正奥秘的联合，并非意见、利益或情感上的联合，乃是出于共同的生命原则而有的、超乎自然的联合。这生命不是我们身为受造之物所有的自然生命，也不是我们身为有理性者所有的理智生命，乃是属灵的生命，别处称之为神在灵魂里的生命。这生命一面为基督与他一切肢体所共有，一面又为基督与神所共有；因此教会的这一联合，不仅是与基督联合，也是与三位一体的神联合。所以圣经说圣灵住在信徒里面，说基督住在他们里面，也说神住在他们里面。因此，我们的主也为他的百姓祈求说：“使他们都合而为一。正如你父在我里面，我在你里面，使他们也在我们里面。”（约翰福音 17:21）

<!-- PAGE 147 -->
从整段文脉看，<span style="color:#0000d4">πάντων</span>（“万有的”、“贯乎万有”）一词显然不是中性。使徒在此并非论及神对宇宙的统治，也非论及他在整个自然界中的护理作为。所指的也不是他对有理性的受造者或对全人类的统治。此处通篇所论的，乃是神与教会的关系。神作为父，超乎教会众肢体之上，贯乎他们众人之中，也住在他们众人里面。教会是神藉着圣灵居住的所在，是他的殿；他住在其中，他的同在充满并贯彻这殿的各个部分。因此，介词 <span style="color:#0000d4">διὰ</span> 在此并非表示凭藉，而是表示遍满。这话的意思不是神“藉着万人”（<span style="color:#0000d4">διὰ πάντων</span>）运行，而是他遍满众人，并住在众人里面。这便是全句的高峰。被神充满，被他的同在贯彻，被他所掌管，就是达到了一切受造之卓越、福乐与荣耀的顶点。

<div class="commentary-anchor" id="ephesians-4-7"></div>
第7节。教会的这种合一，虽然含有一切信徒本质上平等之意，却仍与恩赐、影响力和尊荣上的极大差异并行不悖。按使徒所喜用的比喻，教会好比人的身体，由许多肢体组成，各有不同的功用。全身不都是眼，也不都是耳。这恩赐上的差异不但与合一并行不悖，而且正是合一所必需的。身子原不是一个肢体，乃是许多肢体。在任何有机体中，各部分的差异乃是全体合一所必需的。使徒问道：若全都是一个肢体，身子在哪里呢？加尔文说：Summa praesentis loci est, quod Deus in neminem omnia contulerit; sed quisque certam mensuram receperit; ut alii aliis indigeant et in commune conferendo quod singulis datum est, alii alios mutuo juvent.（本段的要旨是：神并未将一切恩赐都赐给任何一人，乃是各人领受一定的分量，以致彼此有需要，各人将所得的拿出来归于众用，从而彼此相助。）再者，每一肢体在身体中的位置，并非由它自己决定，乃是由神决定。眼睛不能使自己成为眼睛，耳朵也不能使自己成为耳朵。教会中的情形也是如此。众肢体不同的地位、恩赐和功用，不是由他们自己定的，乃是由基督定的。使徒说：“但（即：虽然教会是合一的）我们各人蒙恩，都是照基督所量给各人的恩赐”，所教导的正是这一切。恩赐有这样的差异，而这些恩赐的分配则操在基督手中。此处所说的<span style="color:#800000">*恩典*</span>，既包括内在的属灵恩赐，也包括由此而生的影响力、功用或职分，随各人的情形而定。有的作使徒，有的作先知，有的作传福音的。那使他们成为如此的<span style="color:#800000">*恩典*</span>，就是内在的恩赐与外在的职分。

<!-- PAGE 148 -->
赐予者乃是基督；祂是那赋予能力之属灵影响的源头，也是那授予权柄之职分任命的源头。所以，祂就是神，因为祂是教会内在生命的源头，也是教会及其职事人员权柄的源头。在恩赐的分配上，祂有至高的主权。这些恩赐的分配，是<span style="color:#0000d4">κατὰ τὸ μέτρον τῆς δωρεᾶς τοῦ Χριστοῦ</span>，<span style="color:#800000">*照基督所量给各人的恩赐*</span>；就是说，照祂自己看为合宜的而赐下。其准则既不是我们的功德，也不是我们先前的才具，更不是我们的祈求，乃是祂自己的美意。保罗从前是亵渎神的、凌辱人的，却被立为使徒。正如使徒所教导的，由这一切而生的本分，就是各人都当满足于所分派给他的地位；既不嫉妒在其上的，也不轻看在其下的。若不肯占据教会中分派给我们的位置，就等于全然不肯属乎教会。脚若不肯作脚，它并不因此成为手，反倒被砍下而枯亡。凡有共同生命的身体，同感共受乃是其定律。一个肢体受苦，所有肢体就一同受苦；一个肢体得荣耀，所有肢体也一同快乐。因此，我们可以借着查验自己是否甘心于所分得的本分，是否与众肢体同感共受，来断定我们是否属乎基督的身体。

<div class="commentary-anchor" id="ephesians-4-8"></div>
第8节。前一节所赋予主耶稣的地位——教会中一切生命与能力的泉源——是何等崇高，以致使徒在此中断论述，要表明这样的陈述与圣经早已在此题目上所教导的相合。第7节说到基督赐下恩赐。既然这是他的职分，圣经便把他描绘为一位满载战利品的得胜者，因胜利而富足，并将恩赐分给人。诗人所指的乃是弥赛亚，这是显而易见的，因为该处经文说到他的升上。然而一位神性的位格升到天上，便预设了他先前降到地上。降下的是神的儿子，是弥赛亚；因此升上的也是神的儿子；圣经作者把他描绘为因他在地上得胜的工作而致富，并照自己的心意分派他征服所得的果实。就上下文而言，这似乎是本段的大意，虽然其中充满难解之处。其中的大真理是：基督的高升乃是他降卑的赏赐。他借着顺服与受苦，胜过了这世界的王，救赎了他的子民，并得着权柄将一切所需的美善赐给他们。他被高举，为要赐下圣灵，赐下他一切的恩赐与恩典，赐人悔改与罪得赦免。这一大真理在旧约圣经中早已预表并预言了。<span style="color:#800000">*所以经上说*</span>，<span style="color:#0000d4">διὸ λέγει</span>，即神说，或圣经说。“他升上高天，掳掠了所掳的，将各样的恩赐赏给人。”这就是说，我所讲论的基督乃是属灵恩赐的分派者，正与那先知性的宣告相符，即升天的弥赛亚必将恩赐赏给人。诗人把弥赛亚描绘为一位得胜者，在凯旋中牵引俘虏，满载战利品，分给跟随他的人。基督正是如此得胜的。他败坏了那掌死权的，就是魔鬼；他释放了那些一生因怕死而为奴仆的人（希伯来书 2:15）。他既将一切执政的、掌权的掳来，便明显给众人看，就仗着十字架夸胜（歌罗西书 2:15）。壮士披挂整齐，看守自己的住宅，他所有的都平安无事；但有一个比他更壮的来，胜过他，就夺去他所倚靠的盔甲兵器，又分了他的赃（路加福音 11:21, 22）。论到基督的工作，圣经惯用的表达方式正是如此。他胜过了撒但，他掳掠了所掳的。此处是以抽象代具体——以“被掳”代“被掳之人”——即以 <span style="color:#0000d4">αἰχμαλωσίαν</span> 代 <span style="color:#0000d4">αἰχμά</span>，正如以 <span style="color:#0000d4">συμμαχία</span> 代 <span style="color:#0000d4">σύμμαχοι</span>。可比照士师记 5:12：“底波拉啊，兴起！兴起！你当兴起，兴起，唱歌。亚比挪庵的儿子巴拉啊，你当奋兴，掳掠你的敌人。”这些在凯旋中被牵引的俘虏，或是指基督的仇敌——撒但、罪与死，死乃是末了所要毁灭的仇敌；或是指他的子民，为他的大能所救赎，为他的恩典所降服。前一种解释或许与这比喻以及上文所引的平行经文更为吻合。两者其实都是真的：基督已胜过撒但，牵他为俘虏，这是真的；他救赎自己的子民，使他们归服于己，牵引他们作甘心的俘虏，这也是真的。在他掌权的日子，他们都甘心乐意。因此加尔文将两种说法合而为一：Neque enim Satanam modo et peccatum et mortem totosque inferos prostravit, sed ex rebellibus quotidie facit sibi obsequentem populum, quum verbo suo carnis nostrae lasciviam domat; rursus hostes suos, h. e. impios omnes quasi ferreis catenis continet constrictos, dum illorum furorem cohibet sua virtute, ne plus valeant, quam illis concedit.（“他不但击败了撒但、罪、死亡与整个阴间，并且天天使悖逆之人成为顺服他的子民，因他用自己的话语制伏我们肉体的放纵；再者，他也把自己的仇敌，就是一切不敬虔的人，如同用铁链捆锁住，以自己的大能约束他们的狂怒，使他们不能超出他所容许的范围。”）然而引文的这一句完全是从属性的，重点乃在末一句：“他将各样的恩赐赏给人。”

与这处引文相关的，有两个严重的难题。第一个难题是，所引之语与原文不合。在诗篇 68:18，经文作：“你在人间受了供献。”保罗却作：“他将各样的恩赐赏给人。”为解决这一难题，有人以为使徒所引的并非诗篇，而是以弗所人素常所用的某首诗歌。然而这不但与新约作者一贯的用法相违，也与整段上下文相违，因为使徒正是把所引的经文当作具有神圣权威来立论的。另有人假定希伯来文经文有讹误。理性主义者则说，这是因记忆失误而致的误引。还有人主张，诗人所用的 <span style="color:#800000">*laqah*</span> 一词，<!-- PAGE 150 --> 既可作“取”解，也可作 <span style="color:#800000">*给*</span> 解；或者至少说，此字常有 <span style="color:#800000">*带来*</span> 之意，因此原文一句可译为“你将礼物带到人间”，其意即“你把恩赐赐给人”。如此，二者的差异便只剩下字面上的更动，意思仍旧相同。迦勒底文意译本（他尔根）所表达的正是这个意思：<span style="color:#800000">*dedisti dona filiis hominum.*</span> 这有力地印证了上述看法。亚历山大博士（Dr. Addison Alexander）在注释诗篇 68:18 时说：“一面 <span style="color:#800000">*受取礼物*</span> ，一面 <span style="color:#800000">*颁赐礼物*</span> ，乃是相关相应的观念与措辞；所以保罗将这幅描写神权国度凯旋的图画应用于我们救主的得胜时，便以其中一种说法替换了另一种。”这或许是最自然的解答。新约的圣灵默示的作者，既被那感动古时众先知的同一位圣灵所充满，便不受字句形式的拘束，常常只传达所引经文的大意。得胜者总要分发他所夺得的掳物；他受取，为的是颁赐。因此，在描绘弥赛亚为得胜者时，说他受了恩赐，或说他赐下恩赐，全无分别，意思是一样的：他是满载掳物的得胜者，能使跟随他的人得着丰富。

<!-- PAGE 151 -->
与此段引文相关的第二个难处，是诗篇 68 篇并非弥赛亚诗篇。它所指的并非弥赛亚，乃是神胜过仇敌的凯旋。然而使徒不但将其应用于基督，更据以论证它必定是指着基督说的。这一难处可由三条原则得着解答，而这些原则不仅适用于本处，也适用于许多类似的经文。第一条是旧约体制的预表性质。它不过是将来美事的影儿。神古时的子民下到埃及、蒙拯救脱离为奴之家、行过旷野、进入迦南，这些经历与教会的经历之间不但有显著的类比，而且这类比乃是神所设定的预示——神作为古时神权政体之元首的作为，正是他日后对待教会之作为的预表。他拯救自己的百姓、征服他们的仇敌、以掳掠之物使跟随他的人得着丰富，凡此种种，皆是基督那更高之工作的影像。正如逾越节既纪念出埃及的拯救，又预表基督所成就的救赎；照样，旧约体制之下对神的作为与得胜的许多描述，既是历史，也是预言。故此使徒所引的这篇诗，既是神胜过其古时子民之仇敌的征战史，也是弥赛亚得胜的预言。

适用于此处及类似情形的第二条原则，乃是：在新约时代于肉身中显现的道（Logos）或子，与旧约体系中显现的耶和华，实为同一位。因此，凡论到这一位所说的话，理当也视为论到那一位所说的。所以，摩西既说耶和华领他的百姓经过旷野，保罗便说是基督领他们（哥林多前书 10:4）。以赛亚既在殿中看见耶和华的荣耀，约翰便说他看见了基督的荣耀（约翰福音 12:41）。先知书上既记着说：“耶和华说，我指着我的永生起誓，万膝必向我跪拜，万口必向神承认”（以赛亚书 45:23），保罗便说，这证明我们众人都必站在基督台前（罗马书 14:10, 11）。诗篇 102:25 等处论到神为创造主、为永恒不变者所说的话，在希伯来书 1:10 中乃是用在基督身上。依照同一原则，诗篇 68:18 论到耶和华升上高天、掳掠仇敌所说的话，在此处便说是指着基督说的。

<!-- PAGE 152 -->
还有第三条原则须加考虑。旧约中许多历史性与预言性的描述，并非任何单一的应用或应验所能穷尽。"愿神使雅弗住在闪的帐棚里"这一应许，每当雅弗的后裔得以分享闪的属世或属灵福分时，便应验一次。以赛亚论以色列得赎的预言，并未因神的百姓从巴比伦被掳之地得释放而告穷尽，乃是直接指向基督所要成就的那更高之救赎。论到弥赛亚降临所带来之福分的那些辉煌描述，不仅关乎他头一次降临的果效，也关乎他第二次显现、与罪无关、乃是为拯救他们时所要随之而来的一切。"万膝必向神跪拜，万口必向他承认"的预言，不仅预言真宗教必普世通行，按使徒的教训，也预言末日必有普世的审判。同样，旧约所说耶和华降下与升上、胜过仇敌、使他的子民得丰富，既不因他为彰显权能而作的象征性降临而穷尽，也不因西奈山上、圣殿之中那等显赫的神显，或希伯来圣经所载的诸般凯旋而穷尽，乃是同时指向他亲身成为肉身的降临、他的升天以及他属灵的得胜。因此，使徒把诗篇 68 篇论耶和华作得胜者的话应用于主耶稣的工作，实与全部圣经的类比完全相合；主耶稣既是神在肉身显现，便升上高天，掳掠了仇敌，将各样的恩赐赏给人。

第9、10节。<span style="color:#800000">*（既说升上，岂不是先降在地下吗？那降下的，就是远升诸天之上要充满万有的。）*</span>

这几节经文的明显用意，是要表明所引用诗人的话乃是指着基督说的。其证据在于：就一位神性的位格、一位将属灵恩赐赐与人者而言，升上必然含有先前的降下。降下的既是基督，那么升上的也就是基督。诚然，旧约常说到神的降临，因而也可说到他的升上。但按使徒所解，那些描述中所指的神性位格乃是圣子；并且先前任何一次的降下或升上，先前任何一次胜过仇敌的凯旋，都未能尽括预言之灵藉这等描述所要表明的一切。因此，诗人的言语在其涵盖之内，必定包括了神最为显赫、最为荣耀的那一次屈尊降卑与升高。其余一切的降临，不过是他道成肉身之降临的预表；一切的升上，也不过是他从坟墓中升上的预表。

因此，使徒在此教导说：那位作第六十八篇诗的主题的神，曾“降在地下”；他又“升上高天”，而这一切的目的，乃是“要充满万有”。

<!-- PAGE 153 -->
希伯来文短语 <span style="color:#800000">*tahton ’erets*</span>（使徒所用的 <span style="color:#0000d4">τὰ κατώτερα</span> <span style="color:#0000d4">μέρη τῆς γῆς</span>，即"地的低下之处"，正与之相应）有数种用法：在以赛亚书 44:23 中用以指地，与天相对；在诗篇 63:10 中大概指坟墓；在诗篇 139:15 中用作母腹的诗意称谓；在以西结书 32:24 中则指阴间或不可见的世界。多数注释家或许认为末一义即本处经文之意。他们以为此处所指乃 <span style="color:#800000">*descensus ad inferos*</span>，即基督"降在阴间"。然而第一，此意与使徒所引诗篇那节经文的含义全然不合。第二，无论在诗篇还是在此处，上下文所言的"降下"惟独与"升天"相对。"那升到天上的，就是那先降到地上的。"第三，这种对比在别处屡见不鲜，只是措辞各异，如约翰福音 3:13："除了从天降下仍旧在天的人子，没有人升过天。"约翰福音 6:38："我从天上降下来。"约翰福音 8:14："我知道我从那里来，往那里去。"约翰福音 16:28："我从父出来，到了世界；我又离开世界，往父那里去。"故此使徒之语意即"低下之处，就是地"。所有格 <span style="color:#0000d4">τῆς γῆς</span> 乃通常的同位所有格。可比较使徒行传 2:19，其中上天与下地相对；亦参约翰福音 8:23。

那降到地上、取了我们人性的，也就是那<span style="color:#800000">*远升诸天之上*</span>的。<span style="color:#0000d4">Υπεράνω</span>，即<span style="color:#800000">*longe supra*</span>，表明至高无上的高升。希伯来文中"天"一词作复数形式，故新约作者即便将诸天视为一个整体时，也常用复数，如<span style="color:#0000d4">βασιλεία τῶν οὐπανῶν</span>这一说法。但亦有多处确指诸天不止一层，譬如"诸天之上"这样的表述。犹太人算有七层天，保罗在哥林多后书 12:2 提到第三层天；即大气层、星辰所在之域，以及在其上神的居所。<span style="color:#800000">*远升诸天之上*</span>显然是指高于整个宇宙，高于一切被造之物，无论有形无形；高于一切有位的、主治的、执政的。万有，即一切受造之物，都服在那升天的救赎主之下。

祂如此被高举，<span style="color:#0000d4">ἵνα πληρώσῃ τὰ πάντα</span>，<span style="color:#800000">*叫他充满万有*</span>。既然 <span style="color:#0000d4">πληρόω</span> 一词有<span style="color:#800000">*充满、成全、使之完全*</span>以及<span style="color:#800000">*完成*</span>之意，这句话可有以下数解——1. 叫祂充满万有，即以祂的同在与权能充满宇宙。

<!-- PAGE 154 -->

<span class="enum-num">2.</span> 使他得以成就神论到他国度的一切预言与应许。3. 使他得以成全万有，使之充满恩典与良善。4. 使他得以成就一切必需之事，以完成他的工作。其中第一种解释远为可取。<span style="color:#0000d4">Τὰ πάντα</span> 本义即指宇宙万有；若要取别的意思，必须是上下文有此要求，而此处并非如此。其次，本段显然与第一章 21 节平行，那里论到被高举的基督，同样说他“充满万有者所充满的”。第三，圣经的类比也支持这一解释。神的无所不在与普世统治，在别处也是以类似方式表述的。“耶和华说：我岂不充满天地吗？”（耶利米书 23:24）同样宏大的思想也见于马太福音 28:18：“天上地下所有的权柄都赐给我了”；又见于腓立比书 2:9, 10 以及其他许多经文。使徒在此所论的，并非路德宗所主张的基督身体的无所不在，而是升天之神子的普遍同在与权能。如今行使这普世统治的，乃是披戴了我们人性的神；因此，使徒论到那道成肉身的神——基督——说他将各样的恩赐赏给人，实属允当。

<div class="commentary-anchor" id="ephesians-4-11"></div>
第11节。<span style="color:#0000d4">Καὶ αὐτὸς έδωκεν</span>，<span style="color:#800000">*他所赐的*</span>。他，就是升天的救主，一切权柄与一切资源都已赐予他——他所赐的，有使徒，有先知，有传福音的，有牧师和教师。这些都在基督赐给他教会的恩赐之列；这些恩赐虽含有恩典与职分的差异，却是教会作为一个有组织的整体得以合一所必需的。此处提及这些职分，是按其重要性的次序排列的。

首先是<span style="color:#800000">*使徒*</span>，即基督所亲自差遣的使者，为他作见证的人，为他的教训、他的神迹、他的复活作见证；他们凭着所受的默示恩赐与所领的使命，作教师则无谬误，作治理者则有绝对权柄。因此，无人得为使徒，除非——1. 他是由基督亲自设立的。2. 他曾在基督复活之后见过他，并且是藉着直接的启示领受了福音的知识。

<!-- PAGE 155 -->

<span class="enum-num">3.</span> 除非他因着默示的恩赐而不致有误。这些乃是使徒职分的构成要素，也是其权柄之所系。凡未领受这些恩赐与资格而自称居此职分者，即被称为“假使徒”。

<span style="color:#800000">*先知*</span>。先知乃是代人发言者，即传话之人，正如亚伦作了摩西的先知。凡神使之作口舌向世人说话的，都是先知，无论其所传的是教义、是训诲、抑或是狭义上的预言。凡凭默示而说话的人，都是先知。新约的先知与使徒有别：他们所受的默示乃是间或临到的，故其作教师的权柄也居于次位。这一职分的性质，在哥林多前书 14:1-40 中已有充分的教导。无谬的恩赐既是使徒职分所不可少的，间或受默示的恩赐也是先知职分所不可少的。神若将新约使徒与先知所宣称并行使的权柄授予一班人，要求众人相信他们的教训、服从他们的权柄，不然就要沉沦，却不赐下使他们胜任此工的内在恩赐——这是不可想象的。加尔文在注释本节时已把这一点说得明白；论到某一难处，他说：“Respondeo, quoties a Deo vocati sunt homines, dona necessarie conjuncta esse officiis; neque enim Deus, apostolos aut pastores instituendo, larvam illis duntaxat imponit; sed dotibus etiam instruit, sine quibus rite functionem sibi injunctam obire nequeunt. Quisquis ergo Dei auctoritate constituitur apostolus, non inani et nudo titulo, sed mandato simul et facultate praeditus est.”

<span style="color:#800000">*有传福音的*</span>。论到传福音者这一职分的性质，向来有两种看法。有人视之为使徒的代理：即由使徒为某一确定目的所差派、并在当时被授以特殊权柄之人，正与罗马教中所谓使徒的代理相仿；又如宗教改革之后苏格兰教会所设立的临时监督，在有限的时期内、为着确定的目的被授以长老会议的权柄，就是说，在某种程度上握有长老团的权柄，可以按立、就职与革除。按此意义而言，传福音者乃是临时性的职分。宗教改革之时，对这一职分性质的看法即是如此。[^f13]

<!-- PAGE 156 -->

按另一种看法，传福音的是巡回的传道人，正如提阿多勒及其他早期作家所描述的，<span style="color:#0000d4">οἱ</span> <span style="color:#0000d4">περιιοντες ἐκήπυττον</span>。他们本是受差遣的宣教士，前往福音尚未传到之地传扬福音。此为通行的看法，可为之申述的理由有——<span class="enum-num">1.</span> 该词的含义：此词本身所指，不过是传福音之人而已。

<span class="enum-num">2.</span> 腓利是传福音的，但绝非使徒的代理人；提摩太受劝勉去作传福音的工夫，这劝勉不过是要他作福音忠心的传讲者。使徒行传 21:8、以弗所书 4:11 与提摩太后书 4:5，是此词仅有的三处出处，而在其中任何一处，上下文或别的任何考量，都不要求它有别于通常所赋予的意思。

<span class="enum-num">3.</span> <span style="color:#0000d4">Εὐαγγέλισθαι</span> 与 <span style="color:#0000d4">διδάσκειν</span> 二字皆可用以表示传扬福音之举；但如此处，<span style="color:#0000d4">εὐαγγελιστής</span> 既与 <span style="color:#0000d4">διδάσκαλος</span> 相区别，则所隐含且可容许的唯一分别，乃在于一者是向素未听闻福音之地传扬福音的人，另一者则是教导已归信之基督徒的人。<span style="color:#0000d4">εὐαγγελίσθαι</span> 一字在使徒行传 8:4；14:7；哥林多前书 1:17 与哥林多后书 10:16 等处的用法，足以印证通行的见解：传福音的，乃是将福音传开的人。至于提摩太与提多在某种意义上是使徒的代理人，即为着特定目的、在有限时期内被赋予特殊权柄之人，这固然可以承认，然而此事并不能决定传福音者这一职分的性质。他们行使那些权柄，并非以传福音者的身分，乃是以受托者或受差者的身分。

<!-- PAGE 157 -->
<span style="color:#800000">*有牧师和教师*</span>，<span style="color:#0000d4">τοὺς δὲ ποιμένας καὶ διδασκάλους</span> 依一种解释，此处所载乃两种彼此有别的职分——牧师之职与教师之职。加尔文说，后者"与治理无涉，与施行圣礼无涉，与劝诫勉励亦无涉，而单单在乎解释圣经"。《基督教要义》4:3, 4。凡此种种，皆是从<span style="color:#800000">*教师*</span>一词之意义推断而来。然而圣经并无凭据，足证当时有一等人受命教导而不受命劝勉。此事几乎不可能。此一职能已包含彼一职能。凡教导人何为本分、并本分之根据者，同时即是在劝诫勉励。然而正是基于这种违乎情理的解释，《威斯敏斯特崇拜指南》遂将<span style="color:#800000">*教师*</span>立为教会中一个独立而恒久的、出于神命（jure divino）的职分。新英格兰的清教徒力图将此理论付诸实行，设立了有别于传道人的<span style="color:#800000">*教法师*</span>。但此举终归失败。这两种职能无法彼此分开。整个理论所依据的，乃是对圣经的错误解释。<span style="color:#0000d4">διδασκάλους</span> 之前没有冠词，足证使徒所指的乃是同一班人，他们既是牧师，又是教师。前一称谓称他们为 <span style="color:#0000d4">ἐπίσκοποι</span>，即<span style="color:#800000">*监督*</span>；后一称谓则称他们为施教者。凡为牧师或监督的，都必须善于教导。奥古斯丁与耶柔米即作如此解释，后者说：Non enim ait: alios autem pastores et alios magistros, sed alios pastores et magistros, ut qui pastor est, esse debeat et magister.（他并未说：又有牧师，又有教师；乃说：又有牧师和教师，意即凡作牧师的，也当作教师。）近代的注释家对这一解释几乎无一例外地表示赞同。诚然，当两个名词虽指不同类别、却同属一个团体时，其间的冠词有时也会省略——如马可福音 15:1，<span style="color:#0000d4">μετὰ τῶν πρεσβυτέρων καὶ γραμματέων</span>，因为长老与文士本是一个团体。但在本节这样的列举中，<span style="color:#0000d4">τοὺς μὲν ἀποστόλους, τοὺς δὲ προφήτας, τοὺς δὲ</span> <span style="color:#0000d4">εὐαγγελιστάς, τοὺς δὲ ποιμένας</span>，倘若使徒有意将 <span style="color:#0000d4">διδάσκαλοι</span> 与 <span style="color:#0000d4">ποιμένες</span> 区分开来，则按语法规则必当作 <span style="color:#0000d4">τοὺς</span> <span style="color:#0000d4">δὲ διδασκάλους</span>。故此，<span style="color:#800000">*牧师和教师*</span>当视为对同一班职分者的双重称谓，他们既是百姓的引导者，也是百姓的教导者。

<div class="commentary-anchor" id="ephesians-4-12"></div>
第12节。使徒既已述及基督赐给教会的各样职分，随即说明赐下此恩的目的，即 <span style="color:#0000d4">πρὸς τὸν</span> <span style="color:#0000d4">καταρτισμὸν τῶν ἁγίων εἰς έργον διακονίας, εἰς οἰκοδομὴν τοῦ</span> <span style="color:#0000d4">σώματος τοῦ Χριστοῦ</span>，<span style="color:#800000">*为要成全圣徒，各尽其职，建立基督的身体。*</span>

<!-- PAGE 158 -->
本节中词语的含义以及各分句之间的关系，都存在疑问。译作<span style="color:#800000">*成全*</span>的 <span style="color:#0000d4">καταρτισμὸς</span> 一词可有不同的解释。其词根 <span style="color:#0000d4">άρω</span> 意为联合或捆绑在一起。因此 <span style="color:#0000d4">άρτιος</span> 意指联合的、完备的、完全的；动词 <span style="color:#0000d4">καταρτίζω</span> 按字面意思是<span style="color:#800000">*补网*</span>，见马太福音 4:21；又指整顿使有次序、使之完备或完全，见路加福音 6:40、哥林多后书 13:11；也指预备或使之合用，见希伯来书 10:5、13:21。此名词可表达该动词在其各种意义变化中的动作。因此本处有以下几种译法——一、成全圣徒，即使其数目满足。二、使他们更新或复原。三、使他们归于次序与联合，成为一体。四、使他们得以预备（以供服事）。五、使他们得以完全。最后一种解释当为首选，因为这与本书作者常用此动词的用法相合，也因为它所给出的意思最切合上下文。

<span style="color:#0000d4">διακόνια</span> 一词（<span style="color:#800000">*服事*</span>）可指人与人之间彼此所尽的服事——路加福音 10:40，“伺候的事多”；也可专指对信徒所作的服事，哥林多前书 16:15，“他们专以<span style="color:#800000">*服事*</span>圣徒为念”；亦可指圣职人员职分上的服事。因此 <span style="color:#0000d4">εἰς έργον διακονίς</span> 这一短语，或可解作“为要作彼此服事、彼此效力之工”，或可解作“为要作圣职事奉之工”——即职分意义上的事奉。后一解释乃通行的解释，也是当取的解释；不仅因为此词在这一意义上使用得更为频繁，也因为上下文的缘故，盖使徒在此正论到传道之职的各等职分。

<!-- PAGE 159 -->
与本节相关的主要难点，在于其中几个分句彼此的关系。1. 有人主张将第一与第二分句互换，如此其意便是：“基督设立使徒等职分，是为着职事的工作，而此工作的目的乃在成全圣徒、建立基督的身体。”然而，意思虽因此通顺贴切，这样的调换却出于武断。2. 另有人视诸分句为并列的：“这些职分的设立，是为成全圣徒，为职事的工作，为建立基督的身体。”反对此说者指出，所用的介词有变化（<span style="color:#0000d4">πρὸσ, εἰς</span> <span style="color:#0000d4">—</span> <span style="color:#0000d4">εἰς</span>），且各分句所表达的思想彼此不称——这些语句并非平行。

<span class="enum-num">3.</span> 后两个从句可视为从属于第一个从句。‘基督设立圣职，意在装备圣徒，使他们能彼此服事之工，’（参 <span style="color:#0000d4">εἰς διακονίαν τοῖς</span> <span style="color:#0000d4">ἁγίοις</span> 哥林多前书 16:15，）并建立他的身体。然而此解乃是假定 <span style="color:#0000d4">διακονία</span> 具有一种与上下文不合的含义。

<span class="enum-num">4.</span> 另有人将带 <span style="color:#0000d4">εἰς</span> 的两个分句视为对头一分句的解释，即：“基督设立这些职分，为要成全圣徒；其中有些是为着职事的工作，有些是为着建立他的身体。”但这与本段的结构不合。若作此解，就必须加入 <span style="color:#0000d4">τοὺς μὲν</span> <span style="color:#0000d4">—</span> <span style="color:#0000d4">τοὺς δὲ</span>，即“有些为此，有些为彼”。

<span class="enum-num">5.</span> 又有人这样解释：“为要成全圣徒，基督设立这些职分，乃为叫他们作执事的工夫，建立他的身体。”前一分句 <span style="color:#0000d4">πρὸς κατ.</span> 表明此项设立的远因目的，<span style="color:#0000d4">εἰς</span> <span style="color:#0000d4">—</span> <span style="color:#0000d4">εἰς,</span> 则表明其直接目的。“执事的工夫”即执事所作之工，就是建立基督的身体。末一种看法或许最为妥当。

加尔文说：“若非将这功效归于圣道的职事，便无从更高地尊崇它了。因为还有什么更崇高的工作，胜过建立教会、使之臻于完全呢？所以，那些轻忽此途径、却盼望在基督里得以完全的人，实在是丧失了理智；狂热派便是如此，他们妄称领受了圣灵的密传启示；骄傲之辈也是如此，他们以私下诵读圣经为满足，自以为无需教会的职事。”基督既已设立职事，为要建立祂的身体，那么指望借别的途径成就此目的，便是徒然。

<!-- PAGE 160 -->
<div class="commentary-anchor" id="ephesians-4-13"></div>
第13节。圣职并非一时之设，乃要存留到教会达成其至高呼召的目标为止。这并不证明上文所提的各样职分都是永久的。众所公认，先知乃是一时的职分。要继续存留的，是这圣职本身，而非那些特定的职分。教会的目标在此以三种同义的说法来描述：一、在信仰上同归于一，并认识神的儿子。二、长成一个完全的人。三、满有基督长成的身量。

<!-- PAGE 161 -->
<div class="commentary-anchor" id="ephesians-4-1-2"></div>
**1.** <span style="color:#800000">*直等到我们众人……得以同归于一*</span>等语，<span style="color:#0000d4">μέχρι καταντήσωμεν οἱ πάντες</span>。此处所说的<span style="color:#800000">*众人*</span>并非指全人类，乃指属基督的众人。所指的不是万国从地极各方汇聚而来，而是基督的身体，即上下文所论的众圣徒之群。教会正朝着此处所标明的目标前进。[^f14] 我们的英译作<span style="color:#800000">*在合一里*</span>，然而希腊原文是 <span style="color:#0000d4">εἰς τὴν ἑνότητα</span>，故当译作<span style="color:#800000">*归于*</span>或<span style="color:#800000">*达到*</span>，正如随后各分句中的 <span style="color:#0000d4">εἰς άνδρα τέλειον</span> 与 <span style="color:#0000d4">εἰς μέτρον κτλ</span> 一样。信仰上的合一乃是众人所当达到的终点。属格 <span style="color:#0000d4">υἱοῦ</span> <span style="color:#0000d4">τοῦ θεοῦ</span> 同时统辖 <span style="color:#0000d4">πίστις</span> 与 <span style="color:#0000d4">ἐπίγνωσις</span>。神的儿子既是此处所言之信心的对象，也是此处所言之知识的对象。许多注释家将知识与信心视为同义，因而把此句的后半当作前半的解释，作：“达到信心的合一，即达到对神儿子的认识。”但这忽略了 <span style="color:#0000d4">καὶ</span> 一字。使徒说的是“信心<span style="color:#800000">*与*</span>知识”，如此便将二者区别开来。事实上二者确有分别，无论其关系何等紧密，无论此词何等常用以代彼词。信心是知识的一种形式，故可以“知识”一词表之；但知识并非信心的一种形式，故不能以“信心”一词表之。知识是信心的一个要素；而信心按其独有之意义而言，却不是知识的要素。此处所用的希腊文不是 <span style="color:#0000d4">γνῶσις</span>，而是 <span style="color:#0000d4">ἐπίγνωσις</span>。我们没有一个词可以表达这一分别，德文中却有 Kennen 与 Erkennen 之分。它不单是认知，更是确认。信心与知识，<span style="color:#0000d4">πίστις</span> 与 <span style="color:#0000d4">ἐπίγνωσις</span>，表明并涵括了那一种心灵状态的一切要素；这心灵状态的对象，就是神的儿子，就是那在肉身显现的神，那爱我们、为我们舍己、在各各他受死、如今在天上登宝座的主。这心灵状态既包括对他荣耀的领悟，也包括对他慈爱的支取，更包括信靠与献身。这心灵状态本身就是永生。它包含美善、福乐，以及最高形式的活动，即我们最高才能的最高运用。我们见他的时候，就必像他。完全的知识就是完全的圣洁。所以，当全教会都达到了这排除一切歧异的完全知识时，它便已抵达终点；那时，它必带着属天者的形像。

信心与知识的对象乃是<span style="color:#800000">*神的儿子*</span>。此一称谓表明我们的主与父同具一性，拥有同样的属性，配受同样的尊荣。若非如此，认识基督为神的儿子便不能成为永生；这认识便不能充满、扩展、成圣我们的灵魂，使之得福；也不能构成我们蒙高召所趋之标的，即我们本性的全然完全。

有人感到诧异：使徒在此以信仰的合一为完全的目标，而在第6节却说基督徒如今已有"一信"，正如他们有一主、一洗。有人试图化解此难，把重点放在<span style="color:#800000">*众人*</span>一词上，谓教会的长进在于使<span style="color:#800000">*众人*</span>都达到这合一之境。然而保罗在第6节的断言中也已把<span style="color:#800000">*众人*</span>包括在内。倘若那一节的"一信"与此处的"信仰合一"是同一回事，那么教会的起点与终点岂不成了一样？另有人说，"信仰与知识的合一"并非指众人在信心与知识上归于一致，乃是指众人都要达到那信心与知识合而为一的境地——信心要消融于知识之中。照此说法，此处所指的合一乃是信心与知识之间的合一，而非信徒之间的合一。但这显然牵强不自然。"我们<span style="color:#800000">*众人*</span>都归于合一"，只能是说"我们众人都联合为一"。其实此处并无真正的难处。合一是有程度之分的。教会现今是、且向来是一个身体，然而其联合何等不完全！我们的主为他的子民祈求他们合而为一，并不证明他们现今不是一。此处的情形与别处相同。圣洁是开端，圣洁也是终局。我们必须圣洁才能属乎教会，然而圣洁又是教会终极的完全。信仰的合一现今仅限于最初的要道；此处所瞻望的信仰合一，乃是那完全的合一，其中含有完全的知识与完全的圣洁。

<span style="color:#800000">*得以长大成人*</span>，<span style="color:#0000d4">εἰς άνδρα τέλειον</span>。此句乃是对前一句的解释，并限定其含义。完全乃是目的；即完全的成人。

<!-- PAGE 162 -->

<span style="color:#0000d4">Τέλειος</span> 的意思是 <span style="color:#800000">*ad finem perductus*</span>（已达至终点者）；用于人时，指成年人，即已达到其为人之发育终点者。用于基督徒时，指已达到其作基督徒之成长终点者，希伯来书 12:23；教会之完全，则在于它已达到其发展的终点，完备地站立于荣耀之中。在哥林多前书 13:10 中，<span style="color:#0000d4">τὸ τέλειον</span> 与 <span style="color:#0000d4">τὸ ἐκ</span> <span style="color:#0000d4">μέρους</span> 相对，在那里与在此处一样，指的是将来要达到的那种境界，那时我们的知识将如同主知道我们一样。

教会完全的标准，乃是全然效法基督、与他相似。这就是要达到 <span style="color:#0000d4">εἰς μέτρον ἡλικίας τοῦ πληρώματος τοῦ</span> <span style="color:#0000d4">Χριστοῦ</span>。这些话是对前面所言的解释。当教会达到基督丰满的程度时，它便成了长大成人的、完全的人。无论这些词语在细节上如何解释，其总意即在于此。<span style="color:#0000d4">ἡλικιά</span> 究竟指<span style="color:#800000">*身量*</span>还是<span style="color:#800000">*年岁*</span>，须视上下文而定。此处多数注释家取后一义，因为前一分句中的 <span style="color:#0000d4">τέλειος</span> 意为<span style="color:#800000">*长大成人的*</span>，所指是年岁而非身量；而下一节中的 <span style="color:#0000d4">νήπιος</span> 所指的孩童，也是就年岁而言，并非就身材大小而言。

若按“神的丰满”“神本性一切的丰盛”等语的类比来解释“基督的丰满”一语，则其必指基督所具有、或所赐予的那完备的美善。而“基督丰满的年岁”，即指达到基督之丰满的那一成熟程度。可比照 3:19，那里说信徒被充满，以致得着神的丰盛。

<!-- PAGE 163 -->
然而，若参照“基督丰盛的恩典”（罗马书 15:29）一类表述的类比——该语意为“丰满或丰盛的恩典”——则此处经文的意思便是“基督完全的年岁（或身量）”。教会要长成一个完全人，即要达到基督完全成熟的程度。换言之，教会要完全与他相似，像他完全一样完全。这种解释把 <span style="color:#0000d4">πληρώματος</span> 视为形容词性地修饰 <span style="color:#0000d4">ἠλικίας</span>，正合乎保罗文体中一个常见的特征：他屡次这样把三个属格连缀在一起，其一支配其余，而其中一个须作形容词解。参看歌罗西书 1:13，<span style="color:#0000d4">εἰς βασιλείαν τοῦ</span> <span style="color:#0000d4">υἱοῦ τῆς ἀγάπης αὐτοῦ</span>，“他爱子”实即“他所爱的儿子”；“丰满的年岁”实即“完全的年岁”。又见歌罗西书 2:2、18；帖撒罗尼迦后书 1:9。

关于此处所说教会长进的目标，即那<span style="color:#800000">*终极所归*</span>（terminus ad quem），究竟是在今世达到还是在来世达到，注释家们意见颇为分歧。主张在今世达到的人，主要依据下一节：“我们要成为长大的人，*为要*使我们不再作小孩子”云云。若要断定此问题，似乎只须说明所悬想的那完全之境究竟是什么，也就够了。那是完全，而且是全教会的完全。我们要成为完全的人，要达到与基督完全相似；而且我们众人都要达到这至高的标准。然而，圣经从不将教会的完成描述为发生在今生。基督为教会舍己，是要使教会作荣耀的教会归给自己，毫无玷污皱纹；但这归献要等到他第二次降临，在圣徒的身上得荣耀，又在一切信的人身上显为希奇的时候，才得成就。上下文非但不排斥此解，反倒要求我们如此理解使徒的意思。若说我们必须先达到完全然后才能长进，未免不通；但若说以完全为目标，好叫我们不住地竭力追求，则并无不通之处。

<!-- PAGE 164 -->
<div class="commentary-anchor" id="ephesians-4-14"></div>
第14节。上文所言，已足以表明本节与前数节之间的关联，此关联由 <span style="color:#0000d4">ἵνα</span>（<span style="color:#800000">*使*</span>）一词标示出来。本节与以下各节并非从属于第13节，仿佛其意是"我们要达到完全，为要长进"；乃是与之并列——同是论及第12节所提职分之目的。在所存心要达到的完全成熟与我们现今的光景之间，乃是长进的时期；基督设立圣职，正是要引领教会达到那终局，使我们不再作孩童，乃要不住长进。此居间之目的，在本节是从反面说出，在第15、16节则是从正面说出。我们不可仍作孩童（第13节），乃要不住向着成熟前进（第15、16节）。此处所举孩童的特征，乃是他们的不坚定，以及他们易受迷惑、被引入歧途。前者是以一条无舵之船作比：被波浪抛来抛去，被各样的风吹来吹去——<span style="color:#0000d4">κλυδωνιζόμενοι καὶ</span> <span style="color:#0000d4">περιφερόμενοι παντὶ ἀνέμῳ</span>；或可说是比作两样不定之物，即翻腾的波浪，与被风吹动之物。使徒在希伯来书13:9中用大致相同的比喻，劝勉信徒不要"被那诸般怪异的教训勾引了去"。使徒雅各也将心怀二意的人比作"海中的波浪，被风吹动翻腾"（雅各书1:6）。第13节所说之完全，其主要成分之一便是在真理上的坚定；故此，与之相对的不完全之境，便被描述为不坚定，易被各样的异教之风摇动。

孩童不但反复无常，也极易受骗。他们容易成为狡诈而工于心计之人的猎物。故此使徒接着说：<span style="color:#0000d4">ἐν τῃ κυβείᾳ τῶν</span> <span style="color:#0000d4">ἀνθρώπων</span>，<span style="color:#800000">*藉着*</span>（<span style="color:#0000d4">ἐν</span> 在此为工具用法）<span style="color:#800000">*人的诡计*</span>。<span style="color:#0000d4">Κυβείᾳ</span> 源于 <span style="color:#0000d4">κυβός</span>（<span style="color:#800000">*立方体、骰子*</span>），意为<span style="color:#800000">*掷骰赌博*</span>；赌博之中多有行骗之术，故此词转用以指狡猾或欺诈。其义由下文一语加以说明：<span style="color:#0000d4">ἐν πανουργίᾳ πρὸς τὴν μεθοδείαν τῆς</span> <span style="color:#0000d4">πλάνης</span>；按路德译本，此语作 Tauscherei damit sie uns erschleichen zu verfuhren，即<span style="color:#800000">*他们藉以跟踪我们、好加以迷惑的狡诈*</span>。所谓诡计（<span style="color:#0000d4">κυβείᾳ</span>），即诱惑者或传异端者所用的伎俩。介词 <span style="color:#0000d4">πρὸς</span> 或可解作<span style="color:#800000">*按照*</span>：“按照谬误所惯用的伎俩而行的狡诈；或谬误所特有的那种狡诈。”或亦可依其通常之意，表示方向或趋向：“指向谬误之伎俩的狡诈，即那专为引诱人而设的伎俩。”两解意思相同。<span style="color:#0000d4">μεθοδεία</span> 一词仅见于此处与 6:11——在该处以复数形式出现，译作<span style="color:#800000">*诡计*</span>，即“魔鬼的诡计”。此词derived 自 <span style="color:#0000d4">μεθοδεύω</span>（<span style="color:#0000d4">μετὰ ὀδός</span>），意为<span style="color:#800000">*尾随某人、追踪某人*</span>，如野兽追踪其猎物一般。故其名词形式乃指那些欲设网罗、掳掠人者所用的狡猾伎俩。

<!-- PAGE 165 -->
在此处有两件事几乎不容忽视。其一，是使徒对真理的高度看重；其二，是谬误之为恶。人若不认识、不相信真理，成圣便无从谈起；正如第13节所教导的，全备的圣洁乃以全备的知识为前提。所以，谬误就是恶。宗教上的谬误既出于道德上的败坏，也生出道德上的败坏。圣经论到"假师傅"，总说他们是恶的，是自私的、怀恶意的、行诡诈的。这一原则顺带提供了辨别真理最可靠的凭据之一：凡善人所持守的、为属灵之人、谦卑之人、圣洁之人所珍爱的道理，就是真的。传统所具有的唯一真正权威，也不过在此。在本段经文中，使徒将人离弃真理归因于诡诈与欺哄，而这正是谬误、亦即假师傅的本色。在罗马书 16:17, 18；哥林多后书 2:17；11:13；加拉太书 2:4；歌罗西书 2:8, 18 中，凡引诱人离弃信仰的，也都被描绘为同样的品性。可见谬误绝非无害，假师傅亦非无辜。然而有两点当加考虑，好使我们在运用这些原则时存温和谦让之心。其一，谬误固然意味着罪，纯正的信仰却未必就意味着圣洁。人是可能"行不义阻挡真理"的，可能只有思辨上的信心而没有爱心。在神与人面前最可憎的品格，莫过于一个为真理而心怀恶毒的狂热者。其二，人往往比他所持的信条好得多。就是说，他们赖以生活的道理，比他们口头所承认的道理更接近真理。他们因给字句附上错误的含义而自欺，看似弃绝真理，其实所弃绝的不过是自己的误解。人常说，世人的祷告比他们的信条更为纯正，此言不虚。

<div class="commentary-anchor" id="ephesians-4-15"></div>
第15节。这些话与本题并非无关；因为使徒一面谴责信仰上的一切摇摆不定，一面揭露假师傅的诡诈，随即便加上一条命令：要用爱心持守真理。他所要求的，不只是在纯正教义上的坚定不移，乃是与爱心相联合的信心。唯有那借着爱心发动、并洁净人心的信心，才是使人得救、于人有益的信心。

<!-- PAGE 166 -->
<span style="color:#0000d4">’</span><span style="color:#0000d4">Αληθεύοντες δὲ ἐν ἀγάπῃ</span>，我们的译本作“惟用爱心说诚实话”。但这与上下文不合。此句乃与第14节所言相对。我们不当作小孩子，被一切异教之风摇动飘来飘去，乃当在承认并相信真理上坚定不移。这一为文脉所要求的解释，也为 <span style="color:#0000d4">ἀληθεύειν</span> 一词的用法所证实；此词不但指<span style="color:#800000">*说实话*</span>，也指为 <span style="color:#0000d4">ἀληθής</span>，即坦诚、正直、真实、持守真理之意。此处所指的真理，乃是神的真理、福音的真理，是我们当承认并持守的。<span style="color:#0000d4">ἐν ἀγάπῃ</span> 一语，通常且恰当地与 <span style="color:#0000d4">ἀληθεύοντες</span> 相连，作“用爱心持守真理”。然亦可与下一词相连，意为“让我们在爱中长进”。但如此则使分词过于孤立，且词序也不支持这样的读法。况且下一节（与本节同属一句）中已有 <span style="color:#0000d4">αύξησιν ποιεῖται εἰς οἰκοδομὴν ἐν ἀγάπῃ</span>，如此便是同一意思的无谓重复。

我们要“长进…连于（更确切地说是<span style="color:#800000">*归于*</span>）他”，<span style="color:#0000d4">εἰς αὐτὸν</span>。此语当参照第13节中<span style="color:#0000d4">εἰς άνδρα τέλειον, εἰς</span> <span style="color:#0000d4">μέτρον ἠλικίας κτλ</span>. 诸语来解释。这些乃是表达同一意思的不同说法，即：与基督相似乃是所当达到的终点。我们当如此长进，以致得以与他相似，<span style="color:#0000d4">τὰ πάντα</span>，<span style="color:#800000">*凡事上*</span>。这一位，“就是元首，即基督”。我们当与我们的元首相似——因他是我们的元首，即因他与我们之间有亲密的联合。这一比喻中略有交错之处：基督一面被presented为我们所当效法的典范，一面又是我们当被其生命所充满的元首；然而此种交错并不足以推翻此解释，因上下文正要求如此解释。

<div class="commentary-anchor" id="ephesians-4-16"></div>
第16节。 <span style="color:#800000">*全身都靠他联络得合式，百节各按各职，照着各体的功用彼此相助，便叫身体渐渐增长，在爱中建立自己*</span>。教会是基督的身体，他是元首。这身体是生长的。论到这生长，使徒说——第一，它是从他而来的（<span style="color:#0000d4">ἐξ ου</span>）。他是那本源，一切生命与能力皆由他而出。第二，它有赖于身体各部分藉着合宜的联络与元首的亲密联合。第三，它是匀称的。第四，它是在爱中的生长。此节的大意如此；至于其中某些用语的含义，以及各分句彼此的关系，解经者的意见则颇多分歧。

<!-- PAGE 167 -->
<!-- PAGE 168 -->
首先论及这些词的意思：<span style="color:#0000d4">Συναρμολογέω</span>（由 <span style="color:#0000d4">ἁρμός</span> 与 <span style="color:#0000d4">λέγω</span> 合成），意为<span style="color:#800000">*将一物的各部分联结在一起*</span>。此词用于建筑物，如2:21；亦用于人的身体。这两种情形中，都有彼此相合的各部分之联合。用在此处尤为贴切，因教会正被比作由众多肢体紧密相连所构成的身体。<span style="color:#0000d4">Συμβιβάζω</span> 意为<span style="color:#800000">*聚拢、召集、联合*</span>；作比喻用时，意为<span style="color:#800000">*在心思上加以综合*</span>。此词本用于将人聚到一处，使他们和好，或使他们结为友谊。因此它正可用来解释前一个词。教会按比喻说是由许多关节或肢体构成的身体；按字面说，则是彼此紧密联合的一群信徒。故此使徒论到教会时兼用这两个词。<span style="color:#0000d4">Αφή</span>（出自 <span style="color:#0000d4">ἁπτώ</span>）本义为<span style="color:#800000">*触、触觉*</span>，由此转喻为<span style="color:#800000">*感觉*</span>。因此 <span style="color:#0000d4">διὰ πάσης ἁφῆς τῆς ἐπιχορηγίας</span> 或可解作“藉着每一次对帮助的感觉或体验”。然而此词有时亦作<span style="color:#800000">*联络*</span>或<span style="color:#800000">*关节*</span>解。歌罗西书 2:19 的平行经文作 <span style="color:#0000d4">διὰ τῶν ἁφῶν καί</span> <span style="color:#0000d4">συνδέσμων</span>，即<span style="color:#800000">*藉着节与筋*</span>，似足以断定此处当取后一义。至于 <span style="color:#0000d4">ἐπιχορηγία (χορηγέω, χορός, άγω)</span> 一词，意为<span style="color:#800000">*供应、帮助*</span>，本身并无难解之处。惟一的问题是：所指的是何种帮助或供给？属格在此有何意义？此词或指身体各组成肢体彼此供给的互助。路德即取此义，他将该句意译为 durch alle Gelenke, dadurch eins dem andern Handreichung thut——<span style="color:#800000">*藉着各样关节，一肢体由此帮助另一肢体*</span>。或者，此词亦可指从元首基督所领受的生命之力的供应。如此，“藉着各样供应的关节”便是指：藉着作供应之管道的每一节与筋。歌罗西书 2:19 的平行经文支持后一种看法。那里说：<span style="color:#0000d4">τὸ σῶμα διὰ τῶν ἀφῶν ἐπιχορηγούμενον</span>，即<span style="color:#800000">*全身藉着节与筋得着滋养与供应*</span>。此处那滋养扶持之力，即 <span style="color:#0000d4">ἐπιχορηγία</span>，无疑是从基督流出的；故本处经文亦当作同样的解释。至于属格的用法，有人视之为同位属格，如此“供应的节或筋”便是指<span style="color:#800000">*那作为供应本身的联络*</span>。基督所赐的神圣感力，乃是联结他身体各肢体的纽带。此说固然不错，但歌罗西书 2:19 较为明白，理当作我们解释本节的准绳；而那里说供应乃是 <span style="color:#0000d4">διὰ τῶν ἀφῶν</span>，即<span style="color:#800000">*藉着节*</span>。因此本处平行的说法 <span style="color:#0000d4">διὰ</span> <span style="color:#0000d4">πάσης ἁφῆς τῆς ἐπιχορηγίας</span> 必是指“藉着每一个<span style="color:#800000">*为着*</span>供应而设的关节”，就是说，藉着作神圣感力之凭藉或管道的关节。此处所说的“节筋”与“供应”显然有别：后者乃是那传通于教会各部分的神圣生命或圣灵；前者（即 <span style="color:#0000d4">ἁφαί</span>）则是各样属灵的恩赐与职分，它们被用作这神圣传通的管道或凭藉。

第二点须加考究的，是本段中若干分句彼此的关系。<span style="color:#0000d4">διὰ πάσης ἁφῆς. κτλ.</span> 这一分句，可与本节末了的 <span style="color:#0000d4">αύξησιν ποιεῖται</span> 相连。若如此，其意便是：“身体藉着各样供应的节，叫自己渐渐增长。”此解不误，亦与上下文相合。然而这并非最自然的读法。就句中各部分的相对位置而言，宁将此分句归属于前面的分词：“全身藉着各样供应的节，被联络、被联合。”歌罗西书中的平行经文，断定此即使徒之意。在那里，他将身体的联合（而非其增长）归之于他所说的“节”（<span style="color:#0000d4">ἁφαί</span>）。他描述身体为 <span style="color:#0000d4">συμβιβαζόμενον διὰ τῶν ἀφῶν</span>，故此处彼此紧邻的 <span style="color:#0000d4">συμβιβαζόμενον</span> 与 <span style="color:#0000d4">διὰ πάσης ἁφῆς</span> 也当连属而读。

“<span style="color:#800000">*照着各体的功用彼此相助，便叫身体渐渐增长*</span>”这一小句（即“照着各部分按其分量所发的功效”），可有三种解法。其一，可与前面的分词相连——“藉着各[节]的供应而联络在一起，照着……的功效”，即 <span style="color:#0000d4">συμβιβαζόμενον διὰ</span> <span style="color:#0000d4">—</span> <span style="color:#0000d4">κατὰ</span>。其二，可与紧接在前的词语相连，即 <span style="color:#0000d4">ἐπιχορηγίας κατ</span><span style="color:#0000d4">’</span> <span style="color:#0000d4">ἐνέργειαν</span>——“那供应乃是照着各个部分的功效”。其三，可与 <span style="color:#0000d4">αύξησι ποιεῖται</span> 相连，即那增长乃是照着……的功效。后两种解法之间，实难断定。有利于第二种解法的，一是词序的位置，二是比喻本身的贴切。说神圣的感化乃是照着各部分的功用，即照着各部分的容量与职分，较之说“那增长乃是照着……的功效”，更为自然。身体的增长，出于那贯注全身的生命感化，而非出于各肢体的效能。然而无论取哪一种解法，其中都含有匀称发育之意。

<!-- PAGE 169 -->
<span style="color:#800000">*全身……便叫身体渐渐增长*</span>，即增长其自身。因句子冗长之故，此名词乃重复使用。这增长乃是在爱中的建立，即与爱相连的建立。教会趋向其完全境地的长进，正是在这一元素之中成就的。

<!-- PAGE 170 -->
故此，正如人的身体，藉着从头而来的生命influence——不，按此重译：正如人的身体，藉着从头而来的生命之力，经由相应的脉络维系联络，并按各肢体与器官的功用分布于其上，便不断长成；照样，教会也藉着从元首基督流出的神圣感化，经由相应的脉络联络成为一体，并按各肢体独特的才能与职分分给各人，便不断向着完全迈进。又如在人身上，无论是手是脚，任何一个肢体若不与身体相连，便不能存活生长；照样，与基督奥秘之身体的联合，乃是每一个信徒长进所不可缺的条件。Fallitur ergo siquis seorsum crescere appetit（故此，凡想要离群独自长进的人，便是自欺）。—— 加尔文。再者，正如人的身体中有一定的脉络，生命之力由头藉此流至各肢体，若无此脉络便无从传递；照样，也有神所定的一定媒介，藉以将圣灵从基督分赐给他身体的各个肢体。这些承载神圣感化、使教会得以维系并向前的脉络究竟是什么，使徒在第11节已清楚说明：“他所赐的，有使徒，有先知，有传福音的，有牧师和教师，为要成全圣徒。”所以，神圣的感化正是藉着圣道的职事，从元首基督流到他身体的一切肢体；那职事若废弛，神圣的感化也就断绝。这并不是说，传道人以其个人身份或以其职分，乃是圣灵通往教会众肢体的管道，以致离了他们职务上的居间转达，就无人能有分于圣灵。乃是说，传道人作为真理的分授者，在这个意义上是神圣交通的管道。基督藉着启示与默示的恩赐，设立了一些人作使徒、一些人作先知，为要传达并记录他的真理；又藉着他的灵在内心的呼召，兴起一些人作传福音的、一些人作牧师，为要恒常宣讲并教导这真理。并且（就成年人而言）惟有与这样启示出来、这样宣讲出来的真理相连，圣灵才被赐下。因此，使徒、先知、传福音的和教师这一职事之所以赐下，正是为了建立教会，其途径乃是传达那惟一与圣灵之赐予相连的真理。

凡此种种，罗马教会尽皆歪曲。她声称，那些被她称为使徒的高级教士乃是圣灵的管道，圣灵先藉他们临到祭司，再临到百姓；且这种传递并非藉着真理，而是触碰性的，藉着按手而成。因此，除非藉着他们，无人能与基督联合；除非与他们相交，无人能得存活。可见谬误总是真理的拙劣摹本。

<p style="text-align:center" markdown="1">**第二节**</p>

<p style="text-align:center" markdown="1">**第17-32节 — 第五章1-2节**</p>

<span style="color:#800000">*17. 所以我说，且在主里确实地说，你们行事不要再像外邦人存虚妄的心行事；*</span>

<span style="color:#800000">*18. 他们心地昏昧，与神所赐的生命隔绝了，都因自己无知，心里刚硬；*</span>

<span style="color:#800000">*19. 良心既已丧尽，就放纵私欲，贪行种种的污秽。*</span>

<span style="color:#800000">*20. 你们学了基督，却不是这样；*</span>

<span style="color:#800000">*23. 又要将你们的心志改换一新；*</span>

<span style="color:#800000">*24. 并且穿上新人；这新人是照着神的形像造的，有真理的仁义和圣洁。*</span>

<span style="color:#800000">*25. 所以你们要弃绝谎言，各人与邻舍说实话，因为我们是互相为肢体。*</span>

<span style="color:#800000">*26. 生气却不要犯罪；不可含怒到日落，*</span>

<span style="color:#800000">*27. 也不可给魔鬼留地步。*</span>

<span style="color:#800000">*28. 从前偷窃的，不要再偷；总要劳力，亲手做正经事，就可有余分给那缺少的人。*</span>

<p style="text-align:center" markdown="1">**分析**</p>

<!-- PAGE 172 -->
本节首先是关于圣洁的总体劝勉，第17至24节；其次是关于各项具体本分的训诫，第25节至第五章第2节。按使徒一贯的笔法，劝人圣洁的话先以否定的方式提出——不要再像外邦人那样行，第17至19节；继而以肯定的方式提出——要照着基督所教导的而行，第20至24节。外邦人存虚妄的心而行，即处于道德与属灵的昏昧愚顽之中，既不知自己所作何事，也不知自己所往何处，第17节；因为他们心地昏暗，又因自己无知、因心里刚硬，就与神的生命隔绝了，第18节；其明证便是他们放纵自己，行各样的污秽、贪婪，第19节。基督徒的行事为人恰与此相反——因为信徒已经受了教导。真理住在他们里面，光照并洁净他们，取代了从前的无知。因此他们被引导脱去旧人，并穿上新人，这新人日益与神的形像相符，第20至24节。所以，他们必须弃绝谎言，各人与邻舍说实话，第25节；不可含怒，并当谨防给撒但留地步，第26、27节。不可偷窃，倒要殷勤劳作、乐意分给人，第28节。要避免一切败坏人的言语，谈吐当叫人得造就，免得叫圣灵担忧，第29、30节。他们不可怀恶毒之心，倒要存心温和、仁爱、饶恕，并在此事上效法神，第31节至第五章第2节。

<p style="text-align:center" markdown="1">**注释**</p>

<div class="commentary-anchor" id="ephesians-4-17"></div>
第17节。使徒在前一段中已经教导说，基督已定意要使祂的教会完全与祂自己相似，并已为此目的作了预备；既如此，作为自然的推论，他便郑重地吩咐那些自称为基督徒的人，当照着这崇高的呼召而生活。“<span style="color:#800000">*所以*</span>我说，且在主里确实地说，你们行事不要再像外邦人存虚妄的心行事。”在此处，<span style="color:#800000">*确实地说*</span>即是郑重地吩咐，正如一个人呼求神为他所说之话的真实与重要作见证一样。<span style="color:#0000d4">Μαρτυρέω</span> 是作见证之意，而 <span style="color:#0000d4">μαρτύρομαι</span> 则是呼求某位作见证；此处所用的是后者。<span style="color:#800000">*在主里*</span>的意思，是在与主的相交之中。保罗说话，乃是以一个得以进入基督心意、知道祂旨意、因而能奉祂的名说话的人的身分。这劝勉乃是叫人<span style="color:#800000">*不要*</span>像外邦人那样行。<span style="color:#800000">*行事为人*</span>一语，按圣经的用法，包括生命一切的表现，无论内在的或外在的、可见的或不可见的；它并非仅仅指外表可见的举止。圣经说人与神同行，这所指的乃是灵魂与其造物主之间隐秘的相交，多过指外在的生活。因此，使徒在此吩咐我们当避免的那种行事为人，不仅是外邦人外表可见的举止，也包括那外在举止所由以表现出来的内在生命。

<!-- PAGE 173 -->

他们"存虚妄的心行事"。新约的语言乃是犹太人的语言，故或多或少受希伯来语用法的影响。而希伯来词语的用法，自然又受使用这语言之民族的哲学与神学的影响。有两条原则，对一大类希伯来词语的含义有显而易见的作用，因而也影响到与之相应的希腊文词语的含义。其一是灵魂的合一性：这合一性不容许在灵魂的认知功能与情感功能之间，即在悟性与心之间，划出我们的哲学所假定、因而也铭刻在我们语言中的那种鲜明界限。在希伯来文中，我们通常视为彼此分立之官能的，却由同一个词来指称。圣经既说"心中的思念"，也说"明白的心"和"悟性的愿望"。圣经承认，我们的认知之中有情感的成分，我们的情感之中也有理智的成分。按照圣经的人观，以为心可以败坏而理智却不受影响，这种观念之不合情理，正如同说灵魂的一部分蒙福而另一部分受苦，一种官能得救而另一种官能沉沦一样。

与前一原则密切相关的另一原则，是真理所具的道德与属灵的美善。真理并非仅仅是思辨性的，仅为认知的对象；它自有其道德之美。因此，按圣经的说法，知识包含爱，智慧包含良善，愚昧包含罪恶；智慧人即是圣洁人，愚顽人即是作恶之人。真理与圣洁的联合，犹如同一道光线中的光与热，不能有此而无彼。认识神就是永生；不认识神就是彻底败坏。圣徒是光明之子，恶人是黑暗之子。蒙光照即是得更新，被蒙蔽即是被弃绝。圣经所呈现的，始终如是。

<!-- PAGE 174 -->
因此，在我们眼前这段经文中，<span style="color:#0000d4">νοῦς</span>（<span style="color:#800000">*心思*</span>）并非指排除了情感的理智，也非指排除了理智的情感。它二者兼含；理性、悟性、良心、情感，都包括在这个词之内。有时特指其中这一种属灵活动，有时特指另一种，但在此处所指的乃是整个灵魂。至于 <span style="color:#0000d4">ματαιότης</span>（<span style="color:#800000">*虚妄*</span>）一词，按上文所论及的圣经用法，既包括理智上的无用与昏愚，也包括道德上的无用与昏愚。凡 <span style="color:#0000d4">νοῦς</span> 一词所涵盖的，即悟性与心，都被断定为虚妄。因此，下文数节中论到外邦人之瞎眼与败坏的一切，都已包含在“虚妄”这个词里了。

<div class="commentary-anchor" id="ephesians-4-18"></div>
第18节。<span style="color:#800000">*他们心地昏昧，与神所赐的生命隔绝了，都因自己无知，心里刚硬*</span>。这一节既解释又印证了前面的话。外邦人行在虚妄之中，就是行在理智与道德的黑暗之中，乃是因为他们的心地昏昧，又因为他们与神所赐的生命隔绝了。

前一分句中的 <span style="color:#0000d4">διάνοια</span>（<span style="color:#800000">*悟性*</span>）一词，意为贯通的思想；指与身体相对的心智（quatenus intelligit, appetit et sentit）；亦指心思的活动，即一个念头、意图或心性；又指与情感相对的理智。我们受命爱神，要 <span style="color:#0000d4">ἐν</span> <span style="color:#0000d4">ὅλῃ τῃ διανοίᾳ</span>，即<span style="color:#800000">*尽意*</span>；歌罗西书 1:21 说人为仇敌，是 <span style="color:#0000d4">τῃ</span> <span style="color:#0000d4">διανοίᾳ</span>，即<span style="color:#800000">*就其心思的状态而言*</span>；又有人狂傲，是 <span style="color:#0000d4">τῃ διανοίᾳ</span> <span style="color:#0000d4">τῆς καρδίς αὐτῶν</span>。使徒彼得劝我们“束上<span style="color:#800000">*心中*</span>的腰”，又提到我们“诚实的心”。使徒约翰则说：“神赐给我们 <span style="color:#0000d4">διανοίαν</span>，使我们认识。”此词在以弗所书 2:3 与 <span style="color:#0000d4">σάρξ</span> 相对，在马太福音 22:37、希伯来书 8:10 及别处则与 <span style="color:#0000d4">καρδία</span> 相对。因此，该词究竟指整个灵魂，或指<span style="color:#800000">*理智*</span>，或指心性，须视上下文而定。在本处它指理智；因为它既与上一节的 νοῦς 有别，又与本节末一分句的 <span style="color:#0000d4">καρδία</span> 有别。

“与神所赐的生命隔绝”，意思是与那生命无分。“神的生命”，是指以神为创始者的生命，即属灵的生命；换言之，就是以内住的圣灵为本原或源头的生命。伯撒说：“Vitam Dei, appellat vitam illam, qua Deus vivit in suis.”（他所称的“神的生命”，乃是神在属他之人里面所活的那生命。）可比照 3:16, 17，并参看那一段的解释。

<!-- PAGE 175 -->
在本节末句中，<span style="color:#0000d4">πώρωσις</span> 被译为<span style="color:#800000">*瞎眼*</span>，然其本义更宜作刚硬。此字并非出于 <span style="color:#0000d4">πωρός</span>（<span style="color:#800000">*瞎的*</span>），而是出于 <span style="color:#0000d4">πῶρος</span>，即一种特殊的石头，引申而指凡坚硬或麻木之物。动词 <span style="color:#0000d4">πωρόω</span> 在马可福音 6:52；8:17；约翰福音 12:40 中译作<span style="color:#800000">*刚硬*</span>，且在这几处皆是就心而言。罗马书 11:7 亦然：“其余的就成了顽梗不化的。”此名词在马可福音 3:5 译作“刚硬”，在罗马书 11:25 则译作“瞎眼”。个中缘由不难理解：该动词常用以指眼睛蒙上一层不透明的硬翳，因此 <span style="color:#0000d4">πεπώρωται</span> 有时与 <span style="color:#0000d4">τετύφλωται</span> 同义。故 <span style="color:#0000d4">πώρωσιν τῆς καρδίας</span> 一语，或可译为<span style="color:#800000">*心的瞎眼*</span>，或可译为<span style="color:#800000">*心的刚硬*</span>。除非上下文必须取前一义，否则后者才是本义；而此处并无此种必要。

<!-- PAGE 176 -->
本节主要的难处在于各分句彼此之间的关系。第一，分词 <span style="color:#0000d4">όντες</span> 可与第二分句相连，读作：“心地昏昧，乃因（<span style="color:#0000d4">όντες</span>）与神所赐的生命隔绝。”我们的译者即持此见，其所设想的是：第一分句不过述说外邦人的一个特征，第二分句则为之陈明缘由，即“他们昏昧，因为他们隔绝”。然而此解与本节同上文的关系不合，因上文所言乃是“外邦人行事虚妄，因其昏昧”云云。况且按使徒之意，外邦人并非因与神所赐的生命隔绝才陷于黑暗，乃是因其无知才与那生命隔绝。第二，本节所含四个分句，或可视为第一句与第三句相连，第二句与第四句相连，如此则读作：“心地昏昧，因其心中的无知；与神所赐的生命隔绝，因其心里刚硬。”但这样便不自然地拆散了各分句，与使徒文风中最显著的特征之一相违；他的句子如同锁链的环节，一环扣一环，次第相承。此种解法又使无知成为昏昧之因，其实无知乃是昏昧之果。人被黑暗笼罩，是他看不见的原因；他看不见，却不是黑暗的原因。痴愚是无知之因，而非无知为痴愚之因。使徒所设想的外邦人，乃是心智已然受损昏暗之人，故此陷于无知。第三，各分句可照其本来次序理解，即 <span style="color:#0000d4">όντες</span> 与第一分句相连：“外邦人行事虚妄，因其心地昏昧，因心中的无知、因心里的刚硬而与神所赐的生命隔绝。”心思的黑暗是无知之因；无知以及由此而生的心硬，乃是与神隔绝之因。此既是逻辑的次序，也是神学的次序。灵魂在其本性的光景中不能领会神的事，故不认识这些事，故心刚硬，故毫无圣洁。此正是使徒在哥林多前书 2:14, 16 所教导的。瞎眼的不能看见，故不知受造之物的美丽，故不能以其荣美为乐。你不能用光治好他们，必须先开他们的眼，然后才有看见，然后才有喜乐与爱慕。如此解释本段，正合乎圣经的类比；圣经始终以重生为属灵洞见所必需，以属灵洞见为圣洁情感所必需。所以使徒论外邦人说：他们心地昏昧，眼上蒙着一层翳膜，且因心智瞎眼所致的无知而与神隔绝。

第19节。<span style="color:#800000">*他们*</span>，此处不是简单的关系代词，乃是<span style="color:#0000d4">οἵτινες</span>，即<span style="color:#800000">*那等人*</span>。他们确处于上文所述之光景，其实证便在于：他们既已丧尽知觉，就放纵自己去行下文所列的诸般罪恶。<span style="color:#0000d4">’</span><span style="color:#0000d4">Απηλγηκότες</span>意即<span style="color:#800000">*不再能感受痛苦*</span>。良心既不再责备他们，也不再约束他们。因此他们放纵自己，肆行各样的污秽，<span style="color:#0000d4">ἐν πλεονεξίᾳ</span>，即<span style="color:#800000">*贪得无厌地*</span>，永不知足。就意思而论，彼得后书2:14的平行经文可支持此解：“他们满眼是淫色，止不住犯罪。”然而<span style="color:#0000d4">πλεονεξία</span>一词在别处总是指<span style="color:#800000">*贪婪，即想要得更多的欲望*</span>。既然按此确定的含义解释也通顺，就不宜离弃其固有之义。所以<span style="color:#0000d4">’</span><span style="color:#0000d4">Εν πλεονεξίᾳ</span>意为“连同贪婪”。外邦人放纵自己行污秽的事，又行贪婪的事。这两样恶行在别处也常并提，如第5章3、5节：“至于淫乱并一切污秽，或是贪婪，在你们中间连提都不可。”“因为你们确实地知道，无论是淫乱的，是污秽的，是有贪心的……”另参歌罗西书3:5；罗马书1:29；哥林多前书5:10。此处与罗马书1:24一样，将不道德视为不敬虔不可避免的后果。世人愚昧，以为离了宗教仍可保全道德，甚至以为道德就是宗教；然而理性、经验与圣经都证明：人若不爱神、不惧怕神，就必以某种形式放纵于恶行，而通常不是污秽，便是贪财。其中有双重缘由：其一在乎灵魂的本性——它自身并无独立的良善源头，故一旦转离神，便沉沦于污秽；其二在乎神刑罚的公义——凡离弃他的人，他也离弃之。罗马书1:24及别处说“神任凭那不敬虔的人陷入污秽”；此处却说，他们放纵自己。这不过是同一真理的两种表述。人之不行恶，是因有神的手拦阻；他一旦松手，人便自行奔向灭亡。凡不以宗教为根基的教育制度，凡不以宗教为根基的社会改革或政治改革方案，按本段并全部圣经的教训，都必然引向灭亡。

20节。<span style="color:#800000">*你们学了基督，却不是这样*</span>。意即：你们对基督的认识，并未使你们如外邦人那样生活。按通常用法，我们说学一样事物，却从不说<span style="color:#800000">*学*</span>一个人，故 <span style="color:#0000d4">μαθάανειν τὸν Χριστόν</span> 这一说法别无他例。然而圣经既说传扬基督——这不单指传讲他的教义，乃指传扬基督本身，将他立为至高爱慕与信靠的对象——照样，“学基督”也不仅指学他的道理，乃指认识基督为神的儿子，是取了我们人性的神，是神的圣者，是救人脱离罪恶的救主；认识他便是圣洁，便是生命。凡如此学了基督的人，断不能活在黑暗与罪中。这样的知识，其本性就是光。它进入何处，何处的心思便被照亮、被炼净、被洁净。Nihil ergo de Christo didicit qui nihil vita ab infidelibus differt; neque enim a mortificatione carnis separari potest Christi cognitio.（凡生活与不信者毫无分别的人，就是对基督一无所学；因为对基督的认识，断不能与治死肉体相分离。）——加尔文。

第21节。<span style="color:#800000">*如果你们听过他的道*</span>。“听他”并非指听见关于他的事。使徒写信给基督徒，断不会以假设的口吻说这样的话。他深知以弗所的基督徒早已听闻基督。此处“听”乃含领悟与顺从之意，正如常见的那句话：“有耳可听的，就应当听”；又如“你们今日若听他的话，等等”，以及其他许多类似之处。故此，听神的声音或听基督的声音，并非仅以外在的耳朵有所感知，乃是以悟性和心灵加以领受。<span style="color:#0000d4">είγε</span>这一小品词，意即“如果确实”，并不表示怀疑，乃是说“如果——我视之为当然——”。使徒假定他们是顺服真理的。‘你们学了基督，就不该容让自己像外邦人那样行事；如果——我视之为当然——你们真是听了他的声音，并且<span style="color:#800000">*在他里面*</span>受了教。’<span style="color:#0000d4">’</span>不过<span style="color:#0000d4">Εν αὐτῳ</span>一语，严格说来并非“藉着他”，乃是“在与他的相交中”。‘你们既在他里面受教，因为真理本在耶稣里，就当脱去旧人。’认识基督、听从基督、与他联合、受他内在的教导，这些必然与治死罪相连。

<span style="color:#0000d4">καθώς ἐστιν ἀλήθεια ἐν τῳ</span> <span style="color:#0000d4">’</span><span style="color:#0000d4">Ιησοῦ</span> 这一分句，在我们的译本中作 <span style="color:#800000">*如同真理在耶稣里一样*</span>，解释各不相同。上文所提示的解法，乃是把 <span style="color:#0000d4">καθώς</span> 取其常见的因果之义，即 <span style="color:#800000">*因为、既然*</span>；而以 <span style="color:#800000">*真理*</span> 指道德上的真实，或曰德性上的美善。此字常有这样的含义。它屡屡指真宗教，并与不义相对而用，如罗马书 2:8。此处所含的原则是：认识神与犯罪的生活断不相容，因为认识含有爱在其中，而神是圣洁的。所以，认识他就是爱慕圣洁。使徒的论证是：“你们若认识基督，就必撇弃罪恶，因为他是圣洁的——真理，即道德上的美善，在他里面。你们既与他相交，若在这相交中学了什么，所学的便是脱去旧人。”

另一种解释以为 <span style="color:#0000d4">καθώς</span> 意为<span style="color:#800000">*如同*</span>，用以表明方式。即：“你们若照着真理在耶稣里的样式受了教”，意思是受了正确的教导。然而这样解，即便在英文中也须有冠词——<span style="color:#800000">*那*</span>真理，指耶稣所传授的那一确定的真理体系。但在希腊文中，赋予此解以根据的冠词却付之阙如。此外，若以“真理”指真确的教义，则“真理在耶稣里”一语既晦涩难明，又不合圣经的用法。不仅如此，这样的解释还假定藉着基督、或在与基督的相交中，可能有真的教导，也可能有假的教导。此事断不可能。使徒所设的前提，并非基督是否正确地教导了他们，乃是基督究竟有没有教导他们。

第三种解释则以下文的不定式为句子的主语：“在耶稣里的真理，就是脱去旧人。”如此，全段的意思便是：“你们若认识基督，就不能像外邦人那样生活，因为在耶稣里的真理就是除去罪恶”，即：与基督<!-- PAGE 179 -->真实的相交，就在于脱去旧人云云。然而这种解法违背了本段自然的句法结构；按该结构，不定式 <span style="color:#0000d4">ἀποθέσθαι</span> 是系于 <span style="color:#0000d4">ἐδιδάχθητε,</span> 之下的，意即“你们既已受教，要脱去”云云。况且“除去罪恶乃是在耶稣里的真理”这一说法，本身也生硬晦涩。因此，总的说来，仍当以首先提到的那种解释为优。

第22节。成圣包括向罪而死，即治死肉体，以及向义而活；或如此处所表述的，脱去旧人，穿上新人。这显然是以更换衣服为喻。脱去，就是弃绝，将其从我们身上除去，如同脱下的衣服。穿上，就是采纳，使之归于我们自己。我们蒙召要脱去暗昧的行为（罗马书 13:12），要弃绝谎言（以弗所书 4:25），要脱去恼恨、忿怒、恶毒等（歌罗西书 3:8），要脱去一切的污秽（雅各书 1:21）。另一方面，我们也蒙召要披戴主耶稣基督（罗马书 13:14，加拉太书 3:27），要带上光明的兵器（罗马书 13:12），要存怜悯的心肠（歌罗西书 3:12）；圣经又说人要被从上头来的能力所充满（路加福音 24:49），要穿上不死的、不朽坏的（哥林多前书 15:53）。正如一个人的衣着乃是最先映入眼帘的，所以这些说法乃是指着全部外显的生命而言——即那藉以彰显灵魂内在生命的一切行为与属性；不仅如此，也指着这些行为所由出的内在原则本身。因为此处说我们要脱去旧人，就是我们败坏的本性；这本性之所以称为旧的、原初的，乃是与新人、即属灵生命的原则相对。可比较歌罗西书 3:9，“不要彼此说谎，因你们已经脱去旧人和旧人的行为。”罗马书 6:6，“因为知道我们的旧人和他同钉十字架。”此处所称的“旧人”，保罗在别处则称之为自己，如罗马书 7:14，“我是属乎肉体的”；第18节，“在我里头没有良善”；第23节，“肢体中犯罪的律”；或如加拉太书 5:16、17，与灵相对的“肉体”。这恶的原则或本性之所以称为旧的，是因它先于那新的，也因它是败坏的。而之所以称为“人”，是因它就是我们自己。当被改变的是我们自身，而不仅是我们的行为。我们要将自己钉死在十字架上。这原初的恶的原则在重生之时并未被消灭，乃是要在一生之久的争战中天天治死。如上文所提示的，此处与第21节前一分句相连：<span style="color:#0000d4">ἐδιδάχθητε</span> — <span style="color:#0000d4">ἀποθέσθαι ὐμᾶς</span>。在这类结构中，当不定式的主语与所管辖之动词的主语相同时，通常不予明言。因此有人以文中出现 <span style="color:#0000d4">ὐμᾶς</span> 为由，力主此种结构不能成立。然而参看路加福音 20:20、罗马书 2:19、腓立比书 3:13，便可见此规则亦有例外。

中间的一句 <span style="color:#0000d4">κατὰ τὴν προτέραν ἀναστροφὴν</span>，<span style="color:#800000">*就要脱去你们从前行为上的*</span>，是修饰动词的，不是修饰其后的名词。其意思并非"那从前行为上的旧人"（若是此意，则须作 <span style="color:#0000d4">κατὰ τὴν προτέραν ἀναστροφὴν, κτλ.</span>），而是"就你们从前的行为而言，要脱去旧人"。当脱去的，不单是旧性情从前所显露的那些表现，乃是那旧的原则全体。既然那原则从前是居于主宰地位的，使徒便说：论到你们从前为人的样式，当脱去旧人。

“就朽坏的”，<span style="color:#0000d4">φθειρόμενον</span>，意即“趋于败亡的”。后一译法更为可取，因为<span style="color:#800000">*旧*</span>这一形容词本身已含败坏之意。若说“那败坏的人是败坏的”，便成了同义反复。所要脱去、或当不住治死的，正是这趋于灭亡的旧人，即败坏的本性（qui tendit ad exitium.——格劳秀斯）。

它趋向败坏，<span style="color:#0000d4">κατὰ τὰς ἐπιθυμίας τῆς ἀπάτης</span>，<span style="color:#800000">*照着那诱人的私欲*</span>；不过 <span style="color:#0000d4">ἀπάτης</span> 带有冠词，因此不宜仅仅看作限定性的所有格——当译作<span style="color:#800000">*那迷惑所生的私欲*</span>。使徒在罗马书 7:11 说，<span style="color:#800000">*罪引诱了他*</span>；希伯来书 3:13 又提到“罪迷惑人的诡诈”。实在是内住之罪本身，藉着这些趋于败坏的私欲来迷惑人。

<!-- PAGE 181 -->
二十三节。在本节与下一节中，我们看见成圣的积极方面，即以"更新"与"穿上新人"来表达的。动词 <span style="color:#0000d4">ἀνανεοῦσθαι</span>，<span style="color:#800000">*而变成新的*</span>，是被动语态。这更新始终被描述为神的工作。"我们原是他的工作，在基督耶稣里造成的，为要叫我们行善"（第二章10节）。故此它被称为"圣灵的更新"（提多书3:5）。"被更新"与"穿上新人"这两个说法，既可指重生那一瞬间的作为，也可指成圣那渐进的工夫。所以在罗马书12:2中，我们受劝勉"不要效法这个世界，只要心意更新而变化"。在此处，以及在歌罗西书3:9, 10的平行经文中，这些用语所表达的，乃是灵魂得以恢复神的形像的全部过程。这是一个自始至终的更新过程。使徒说："我们内在的人却一天新似一天"（哥林多后书4:16）。

<span style="color:#0000d4">νέος</span>（<span style="color:#800000">*年幼的、新的*</span>，就起源而言）与 <span style="color:#0000d4">καινός</span>（<span style="color:#800000">*新鲜的、光洁的、未曾用过的*</span>，就性质或品格而言）之间的区别，在新约中大体是保持着的。故在马太福音 9:17 说 <span style="color:#0000d4">οϊνον νέον εἰς ἀσκοὺς</span> <span style="color:#0000d4">καινούς</span>，即把新近酿成的酒装在未曾用过的皮袋里。<span style="color:#0000d4">Μνημεῖον</span> <span style="color:#0000d4">καινὸν</span> 意为<span style="color:#800000">*新坟墓*</span>，即一座未曾葬过人的坟墓，无论它凿成已有多久。因此 <span style="color:#0000d4">καινός</span> 乃是一个表示美好的形容词。在“直到我在神的国里同你们喝新的那日子”（马可福音 14:25）一语中，所用的是 <span style="color:#0000d4">καινός</span>，而非 <span style="color:#0000d4">νὲον</span>。<span style="color:#800000">*新造的人、新天、新命令、新名、新耶路撒冷*</span>等等一切说法，所含的也都是同一观念；在这些地方，所用的字无一不是 <span style="color:#0000d4">καινός</span>。这两个字的派生词，本也当有同样的分别：<span style="color:#0000d4">ἀνανεόω</span> 是使之成为 <span style="color:#0000d4">νὲον</span>，而 <span style="color:#0000d4">ὰνακαινίζω, ὰνακαινόω</span> 则是使之成为 <span style="color:#0000d4">καινός</span>。所以，凡论到灵魂的更新——那是一种变得更美好的改变——所用的字总是 <span style="color:#0000d4">καινός</span> 的派生词，惟独本节是例外。参看罗马书 12:2；哥林多后书 4:16；歌罗西书 3:10；提多书 3:5。然而，既然凡是 <span style="color:#0000d4">νέος</span> 的也就是 <span style="color:#0000d4">καινός</span>，因为新鲜、活力与美丽正是青春的属性，所以同一事物也可以用这两个词中的任何一个来指称。因此，得了更新的灵魂，在本节被称为 <span style="color:#0000d4">καινός άνθρωπος</span>，而在歌罗西书 3:10 则称为 <span style="color:#0000d4">νέος άνθρωπος</span>；那在歌罗西书 3:10 用 <span style="color:#0000d4">ὰνακαινόω</span> 所表达、在罗马书 12:2 与提多书 3:5 用 <span style="color:#0000d4">ὰνακαίνωσις</span> 所表达的属灵改变，在此处乃是用 <span style="color:#0000d4">ἀνανεόω</span> 来表达的。

<!-- PAGE 182 -->
这更新的对象，即人在何事上要成为新的，乃由以下短语表明：<span style="color:#0000d4">τῳ πνεύματι τοῦ νοὸς ὐμῶν</span>，即<span style="color:#800000">*就你们心思的灵而言*</span>。此种组合别无先例。格罗修斯说：Spiritus mentis est ipsa mens（心思的灵即是心思本身）；在他之先，奥古斯丁也曾说：Spiritum mentis dicere voluit eum spiritum, quae mens vocatur（他所谓心思的灵，乃指那称为心思的灵）。然而此处灵与心思是有分别的。人的灵不是那"作为人"的灵，乃是人"所有"的灵。另有人以此处的"灵"字为性情、心性之意，遂译作"就你们心思的性情而言得以更新"。但此义在新约中即便不属可疑，也甚为罕见。又有人说，"灵"字即指圣灵，故此节当译为"藉着你们心中的圣灵"。然此说断不可能。此处"心思的灵"与神的灵判然有别，正如罗马书 8:16 所言，神的灵与我们的灵同证。

关于这一短语，可作如下几点评述：——1. 虽然罗马书 12:2 中“心意更新”一语，所表达的总体意思显然与此处“心志改换一新”相同，但并不能由此断定“心意”与“心志”所指的正是同一事物。前者是笼统的说法，后者则精确而明确。2. <span style="color:#0000d4">πνεῦμα, νοῦς, καρδία, ψυχή</span>，即<span style="color:#800000">*灵、心意、心*</span>、<span style="color:#800000">*魂,*</span>这几个词在圣经中有两种用法：既指我们本性中那整个非物质、不朽的要素，即我们位格之所在；也指这一要素在其某一表现方式之下的情形，时而指此一方式，时而指彼一方式；例如 <span style="color:#0000d4">νοῦς</span> 有时指作为悟性的灵魂，有时则指作为情感的灵魂。3. 虽然情形如此，但这些词各有其主要所指的表现方式，彼此有别；如 <span style="color:#0000d4">νοῦς</span> 主要指悟性，<span style="color:#0000d4">καρδία</span> 主要指情感，<span style="color:#0000d4">ψυχή</span> 则指感觉的所在。4. 在这几个词中，<span style="color:#0000d4">πνεῦμα</span> 是最高的一个。它的意思是气息、风、无形的能力、生命。能力的观念与此词不可分离；<span style="color:#0000d4">τὸ</span> <span style="color:#0000d4">πνεῦμα ἐστι τὸ ζωοποιοῦν.</span> 约翰福音 6:63。

因此，这词可用于神，用于圣灵，用于天使，用于撒但，用于鬼魔，也用于人的灵魂。哥林多前书 2:12 所说的"世上的灵"，乃是支配并鼓动这世界的原则，是使世界成其为世界的那个东西。所以，"心志的灵"就是心志内在的生命；<span style="color:#0000d4">νοῦς, καρδία, ψυχή</span> 不过是这生命显明出来的种种方式。由此可见，需要被更新的，不仅是外在的习惯或生活方式，也不仅是一时的性情或倾向，乃是那潜伏在一切外在的、表面的、暂时的事物背后的内在生命原则。

第24节。<span style="color:#0000d4">Καὶ ἐνδύσασθαι τὸν καινὸν άνθρωπον</span>，<span style="color:#800000">*并且穿上新人*</span>。我们既蒙召要脱去败坏的本性，如同脱去褴褛污秽的衣裳，也就同样被要求穿上新的本性，如同穿上光明的衣裳。前者既被拟人化为一个旧人，衰残、丑陋、趋于朽坏，后者便被拟人化为一个新人，清新、美好、强健，与神相似；因为经上说它是<span style="color:#0000d4">τὸν κατὰ θεὸν κτισθέντα,</span> <span style="color:#0000d4">κτλ.</span>，<span style="color:#800000">*照着神在真理的仁义和圣洁上所造的*</span>。在与此平行的经文中，说它是“照着神的形像”而更新的，见歌罗西书 3:10。因此，“照着神”的意思就是照着他的形像。而这形像所在之处，经上说乃是仁义与圣洁。二词之中，<span style="color:#0000d4">δικαιοσύνῃ</span> 单独使用时，往往涵括一切形式的道德美善；但与 <span style="color:#0000d4">ὀσιότητι</span> 并列时，前者指正直，即为人行事之正当，后者则指圣洁。前者使我们对邻舍公义，后者使我们对神虔敬。这两个名词并列于路加福音 1:75；其形容词形式“公义的”与“圣洁的”并列于提多书 1:8；其副词形式“圣洁地”与“公义地”并列于帖撒罗尼迦前书 2:10。希腊人也作同样的区分：<span style="color:#0000d4">πρὸς θεούς  ὅσιον καί πρὸς</span> <span style="color:#0000d4">ἀνθρώπους ἐστι.</span>。我们的译本将此句译作“有义和真理的圣洁”；但 <span style="color:#0000d4">ἀληθείας</span> 一词与两个名词的关系是相同的，倘若仅视之为修饰性的属格，则应译作“有真实的仁义和圣洁”。然而多数近代注释家认为，此处的“<span style="color:#800000">*真理*</span>”乃是与第22节所说的“<span style="color:#800000">*私欲的迷惑*</span>”相对。如此，“真理的仁义和圣洁”便是指真理所具有的、或真理所生出的仁义与圣洁。倘若那里将内住之罪的原则拟人化为 <span style="color:#0000d4">ἀμάτη</span>，即<span style="color:#800000">*迷惑*</span>，生发并运行那些引人灭亡的私欲；那么此处便将属灵生命的原则拟人化为 <span style="color:#0000d4">ἀληθείας</span>，即<span style="color:#800000">*真理*</span>，生出仁义与圣洁。真理就是属灵的知识，就是那作为永生的知识，它不仅光照悟性，也使人心成圣。圣灵被称为真理的灵，因为他乃是这照彻全人心灵的神圣光照的作者。这真理是藉耶稣基督来的，约翰福音 1:17。他就是真理，就是生命，约翰福音 14:6。我们因真理得自由，也因真理成圣。福音被称为真理的道，因为它是那神圣知识的客观启示，而这知识在主观方面就是属灵生命的原则。按此意义理解这词，本节便与歌罗西书 3:10 的平行经文更为吻合。此处说神的形像在于真理的仁义和圣洁；彼处则说在于知识：“这新人……渐渐更新，正如造他主的形像，在知识上得以更新。”两处经文的差别，不过是一处较另一处更为简约而已。知识（即 <span style="color:#0000d4">ἐπίγνωσις τοῦ Θεοῦ</span>）包含仁义、圣洁与真理。因此，若轻看神圣的真理，将教义视为仅属思辨悟性之事，再没有比这更违背圣经的了。仁义与圣洁，道德与宗教，都是真理的产物；离了真理，它们便不能存在。

这段经文在教义上具有特殊的重要性，因为它教导我们：人受造之初所具有的神的形像，其真正的性质究竟为何。那形像并不仅仅在于人的理性本性，也不在于他的不朽，更不在于他的治理之权，乃是特别在于那公义与圣洁，在于他一切原则中的正直，以及那与领受真理、或说与对神的真知识不可分离的、领受敬虔情感的能力。这是圣经对人原初状态、即原义（original righteousness）的看法；它一面反对伯拉纠派的理论，即人受造时并无道德品性，另一面也反对罗马教的教义，即原义乃是一种超自然的恩赐，并不属于人的本性。知识，以及随之而来的公义与圣洁，乃是内在于始祖、与之一同受造的，正如他对美的感受力和对外部世界的感应力一样。他睁开眼睛，便看见那可见之物，并察觉其中的美；他将心思转向神，便看见神的荣耀，心中充满一切圣洁的情感。

<div class="commentary-anchor" id="ephesians-4-25"></div>
第25节。使徒既已申明圣洁、即效法神形像的一般本分，接着便逐一论及各项具体的本分。可以看出，几乎每一处都是先有反面的告诫，继之以正面的吩咐，最后再加上一个动机。此处即是如此：不可说谎，总要说实话，因为我们是互相为肢体。<span style="color:#800000">*所以*</span>，即基于效法神形像这一普遍的义务，<span style="color:#800000">*你们要弃绝谎言*</span>，因这乃是属乎旧人的污秽衣裳之一；<span style="color:#800000">*各人与邻舍说实话*</span>。圣经教导我们，所谓邻舍，<span style="color:#0000d4">ὁ πλησίον</span>，乃是指凡与我们相近之人，无论属何信仰、何邦国的同类；对一切这样的人，我们都有责任说实话。但上下文表明，保罗在此是对基督徒说话，而他用以加强此本分的动机也表明，他这里所说的邻舍是指信主的弟兄，正如<!-- PAGE 185 -->罗马书 15:2 中一样。这里所说的动机，就是信徒彼此之间那亲密的关系。他们同属一个身体，都是其中的肢体，正如他在第16节所教导的，彼此紧密相连，也与他们共同的元首基督相连。手欺骗脚，或眼欺骗耳，既是违反本性、荒谬可笑的事，那么一个基督徒欺骗另一个基督徒，也就是干犯了他们联合的根本法则。以属灵的理由来加强道德本分，乃是使徒、也是整本圣经的特色。这种方法固然提出了更高、更特殊的责任根据，却并非要排除其他的根据。诚实的义务，本就立于真理内在的美善、神的命令，以及我们同类之人的权利之上。他们既有权不被我们诈取财物，也同样有权不被我们欺骗。然而这一切并不妨碍我们从信徒的特殊关系上来加强这一本分——他们因圣灵的内住，已联合成为基督奥秘的身体。

第26、27节。他接下来的劝勉论及忿怒；在这事上他教导说——1. 不可让忿怒成为犯罪的机会。2. 不可怀怒。3. 当我们发怒时，不可给撒但留地步胜过我们。

<!-- PAGE 186 -->
<span style="color:#0000d4">ὀργίζεσθε καὶ μὴ ἁμαρτάνετε</span> 一语，即“你们生气，却不要犯罪”，取自七十士译本诗篇 4:5，可有数种不同的解释：1. 诗篇 4:5 的原文既可译作 <span style="color:#800000">*你们发怒，却不要犯罪*</span>，意即不可因发怒而犯罪[^f15]——故使徒此语亦可解为：不要犯发怒这宗罪。有人反对此说，谓如此则否定词须同时管辖两个动词，而实际上它只属于后一动词。其实不必假定使徒是照原文的确切意思使用这些字句；因为新约的作者往往在稍改字句的情形下表达旧约某段的意思，或用同样的字句而稍改其意思。此处本不是严格意义上的引用；保罗并非把它当作诗人所说的话加以援引，乃是借这些字句表达他自己的意思。在罗马书 10:18“他们的声音传遍天下”一语中，我们所见的是诗篇第 19 篇的措辞，却不是诗人本意的表述。2. 另有人以此句中第一个命令语气为容许之意，第二个为命令之意：『你们可以生气，但（却）不要犯罪。』3. 又有人以第一个为条件句：『若生气，不要犯罪。』即：不要在怒中犯罪；不可让你的怒气成为犯罪的机缘。要抑制它、管束它，免得它催逼你陷入罪中。其意与说 <span style="color:#0000d4">ὀργιζόμενοι μὴ</span> <span style="color:#0000d4">ἁμαρτάνετε</span><span style="color:#800000">*，生气的时候不要犯罪*</span> 相同。这或许是对本节最为妥帖的解释。

诚然有人反对说，使徒在此所论的乃是罪；并且在第31节，他禁止一切怒气，故此凡假定怒气本身并非罪的解释，皆不可取。然而可以确定的是，并非一切怒气都是罪。经上说，基督自己也曾“怒目”看那些悖逆刚硬的人（马可福音 3:5）。同一种类的情感，若与圣洁的情愫相调和，或存于圣洁的心中，便是美德；若与恶毒相混杂，便是罪。这两种情感，或说这两种情感的组合，在圣经中都以“怒”一词表达。凡本身为罪的，都不可归于神，然而经上却将忿怒归于祂。第31节与这一解释并无抵触，因为那里的上下文表明，使徒所说的乃是含着恶毒的怒气——正如“一切的恶毒”是指一切的毒恨，而非指对恶的憎恶。

<span style="color:#800000">*不可含怒到日落*</span>。此处所用之词为 <span style="color:#0000d4">παροργισμός</span>，即<span style="color:#800000">*一时之忿*</span>或<span style="color:#800000">*激动*</span>。怒气纵然事出有因，也不可长久存留。智者有言：“恼怒存在愚昧人的怀中。”传道书 7:9。

<!-- PAGE 187 -->
<span style="color:#800000">*也不可给魔鬼留地步。——*</span>“<span style="color:#800000">*给……留地步*</span>”即让开路、任其自由施展，因而也就是给人以可乘之机或便利。我们既不可怀藏怒气，也不可容撒但因我们发怒而得着机会。怒气若一经存留，便使那试探者大得权势，因为这给了我们顺从他恶意怂恿的动机。<span style="color:#0000d4">διάβολος</span> 一词，路德译作<span style="color:#800000">*Lasterer，即毁谤者*</span>。此词在提摩太前书 3:11、提摩太后书 3:3 和提多书 2:3 中即以此义用作形容词；但若带冠词（<span style="color:#0000d4">ὁ διάβολος</span>），则一律指撒但——那大控告者——众鬼魔或堕落天使的首领，他是神的大敌，又是诱惑世人者；我们奉命要常常防备他的诡计。

<div class="commentary-anchor" id="ephesians-4-28"></div>
第28节。下一条劝勉论及偷窃——我们不可偷窃，乃要劳力做工，不但使自己得以正当度日，也能分给那缺乏的人。

<span style="color:#0000d4">ὁ κλέπτων</span> 一语并非指那曾经偷窃的人，而是指那正在偷窃的人，即贼。然而有人要问：使徒怎能设想以弗所教会中竟有贼？尤其他所对之说话的，乃是已经重生的人，是他正劝勉其当按新性情而生活的人。为解此难，加尔文说，保罗所指的，不仅是民法所惩治的那类偷窃，乃是一切不义之得。耶柔米则说：Ephesios monet, ne sub occasione emolumenti furti crimen incurrant, furtum nominans, omne quod alterius damno quaeritur. 如此扩大偷窃的观念，虽越出人间法律为此罪所划定的界限，却并未越出神的律法。正如“不可杀人”的诫命，包含了对怀恨的禁止；照样，“不可偷盗”的诫命，也禁止一切已经或可能不义地妨害邻舍财物与外在产业之事。实在可以确定：许多为人间习俗所容忍的事，许多甚至为自称基督徒者所行、将他人产业据为己有的方式，在神圣律法的光照之下，不过是偷窃的不同形式，并且在末日的审判中必如此显露出来。使徒此命的精意，无疑包括一切不诚实的形式。然而仍可追问：这一原则是否就是本节的真解。另有人说，正如哥林多教会中连淫乱、甚至乱伦也被容忍（参林前书 6:1-6），那么以弗所教会中偷窃被置之不理，或至少未受惩戒，也并非不可信之事。不过更为可能的是：我们的译本（与武加大译本及路德的译文相合）所表达的，才是真意。这并非说 <span style="color:#0000d4">ὁ κλέπτων</span> 与 <span style="color:#0000d4">ὁ</span> <span style="color:#0000d4">κλέψας</span> 同义，乃是说：正如“凶手”指犯过杀人罪的人，不论其如今何等悔改；照样，“贼”也可指犯过偷窃之罪的人。狱中某些囚犯被称为贼，是因其过往的行为，而非因其现今的行为。

<!-- PAGE 188 -->

使徒这一吩咐的正面内容是：他不当再不义地靠别人的劳力度日，乃要<span style="color:#800000">*亲手作正经事劳力*</span>。他从前用手行窃，如今就当用手行正当之事——就是从事诚实的劳作。保罗在别处立下一条普遍的原则：“若有人不肯作工，就不可吃饭。”帖撒罗尼迦后书 3:10。凡能自养的人，都无权受他人供养。这是圣经论经济的一大原则。然而还有另一条同样重要的原则，就是那不能作工的人有权得人相助；因此使徒又补上一个理由，说明强壮之人为何当劳力——<span style="color:#800000">*就可有余分给那缺少的人*</span>。人没有一个是为自己而活的；也没有一个人当单为自己劳力，乃当存着明确的目的，好能扶助他人。基督教的这些原则若切实施行，必能迅速把贫困及其他相关的祸患从我们近代的文明中驱除净尽。

<div class="commentary-anchor" id="ephesians-4-30"></div>
第29、30节 —— 禁止污秽的言语 —— 吩咐有益的谈论，并以造就他人和敬畏圣灵为动机。

<!-- PAGE 189 -->
<span style="color:#800000">*污秽的言语，一句不可出口*</span>。<span style="color:#0000d4">Πᾶς λόγος</span> <span style="color:#0000d4">σαπρὸς</span>，<span style="color:#800000">*任何污秽的言语*</span>。<span style="color:#0000d4">σαπρὸς</span> 一词按字面意思是<span style="color:#800000">*腐烂的*</span>，引申而言则指令人厌恶的、有害的。<span style="color:#800000">*只要随事说造就人的好话，*</span><span style="color:#0000d4">ἀγαθὸς πρὸς οἰκοδομὴν</span>，即宜于造就人的话。<span style="color:#0000d4">οἰκοδομὴν τῆς χρείας</span> 这几个字，<span style="color:#800000">*需要的造就*</span>，意思是那需要所要求的造就——或说合乎当时情境的造就。这是通行且令人满意的解释。我们的译本作“<span style="color:#800000">*随事说造就人的*</span>”——则是将这两个字前后倒置了。<span style="color:#800000">*叫听见的人得益处*</span>。<span style="color:#0000d4">χάριν διδόναι</span> 这一片语，意为施恩惠，乃是常见的说法，向来都指施予恩惠——即给人喜乐或益处。此处并无必要离开这一含义。其意即是：“使听见的人得益。”<span style="color:#800000">*不要叫神的圣灵担忧*</span>，即不要以这等污秽的言语叫他担忧。从歌罗西书 3:8 可见，使徒在 <span style="color:#0000d4">πᾶς λόγος σαπρὸς</span> 这一名目之下，包括了一切不敬虔的、恶毒的、污秽的言语；这等言语不但伤害他人，也叫圣灵担忧。殿既是圣的，凡玷污它的都得罪神；照样，圣灵内住于神的子民之中，也就成了我们当以敬畏之心待他们的理由，正如这位使徒所教导的：“岂不知你们是神的殿，神的灵住在你们里头吗？若有人毁坏神的殿，神必要毁坏那人；因为神的殿是圣的，这殿就是你们。”哥林多前书 3:16, 17。所以，以不敬虔或污秽的意念挑动信徒，从而玷污他们的灵魂，乃是亵渎神的殿，是得罪圣灵。这是此处所呈明之真理的一面。另一面，也是本句更直接要说的，乃是：那俯就而住在我们心中的圣灵，每逢我们如此犯罪，他便担忧、被得罪。故此保罗在哥林多前书 6:19 说：“岂不知你们的身子就是圣灵的殿吗？这圣灵是从神而来，住在你们里头的；并且你们不是自己的人。”所以，敬畏那住在别人里面的圣灵，也敬畏那同一位住在我们里面的圣灵，就当拦阻我们，使我们永不吐露败坏人的意念。使徒说，圣灵<span style="color:#800000">*担忧*</span>。这不单是他的圣洁受了冒犯，更是他的慈爱受了伤害。若还有什么能加增这等行为的罪咎，那就是它的忘恩负义；因为正如使徒接着所说，我们乃是借着他<span style="color:#800000">*受了印记，等候得赎的日子来到*</span>。他的内住证实我们是神的儿女，并保证我们终必得救。参 1:13。所以叫他担忧，就是伤害那位我们的救恩所系于他的圣灵。他固然不会最终离弃他所内住的人，然而一旦担忧，他便收敛其同在的显明。而人若轻忽这些显明，就足以证明我们没有基督的灵，也不属乎他。

接着，使徒劝勉读者除去一切怀恨报复之心，要以恩慈相待，彼此饶恕。此劝勉乃以神的怜悯与基督的大爱为依据而加以申明，见第四章31节至第五章2节。

第31节。<span style="color:#800000">*一切苦毒、恼恨、忿怒、嚷闹、毁谤，并一切的恶毒，都当从你们中间除掉*</span>。这几样罪恶彼此密切相关。<span style="color:#800000">*苦毒*</span>一词，原是由感官的范畴移用于心思的范畴。形容词 <span style="color:#0000d4">πικρός</span> 意为锐利，如箭之锐利；进而指味觉上的辛辣、令人不快；再进而指含有毒性。民数记 5:18 中给那被疑与人行淫之妇人所喝的毒水，就称为“苦水”。故此，苦毒一词在其比喻的意义上，乃指凡有腐蚀之力者，如忧愁，或凡对己心所起的作用如同毒药之于身体者，或凡对他人之心所起的作用如同毒液之于其身体者。蛇的毒液藏于牙中原无害处；然而一切邪恶的情感，对怀有它的人既是毒药，对其所指向的人亦是毒液。所以，吩咐我们除掉一切苦毒，就是吩咐我们除掉凡腐蚀自己心思、或伤害他人情感之事。属于这一总目之下的，便是随后所列的各项，即：<span style="color:#800000">*恼恨*</span>；<span style="color:#0000d4">θυμὸς</span>（出于 <span style="color:#0000d4">θύω</span>，意为燃烧）指心思本身，乃情欲与欲望所居之处，进而指处在情欲激荡中的心思。<span style="color:#0000d4">’</span><span style="color:#0000d4">Οργή</span>，即<span style="color:#800000">*忿怒*</span>，乃是那情欲本身，亦即 <span style="color:#0000d4">θυμὸς</span> 的发作；正如嚷闹与毁谤乃是忿怒向外的流露。上下文表明，<span style="color:#0000d4">βλασφημία</span> 在此既非指向神的亵渎，也不仅仅是指向人的诽谤，乃是指凡出于忿怒、足以伤害或损及他人的言语。<span style="color:#800000">*并一切的恶毒*</span>。<span style="color:#0000d4">κακίᾳ</span> 是泛指任何一种<span style="color:#800000">*邪恶*</span>或<span style="color:#800000">*败坏*</span>的通称。在此，上下文表明它是指<span style="color:#800000">*恶意*</span>，即存心加害于人。我们不但要除掉恼恨与忿怒，也要除掉其余一切怀恶待人的情感。

<div class="commentary-anchor" id="ephesians-4-32"></div>
第32节。劝人当有与上述相反的美德。我们蒙命要作 <span style="color:#0000d4">χρηστοί</span>。此字本意为 <span style="color:#800000">*有益的*</span>，进而指乐于行善。故经上说神是 <span style="color:#0000d4">χρηστός</span>，即对那忘恩的和作恶的仍施 <span style="color:#800000">*恩慈*</span> 或 <span style="color:#800000">*慈爱*</span>（路加福音6:35）。<span style="color:#800000">*存怜悯的心*</span>，<span style="color:#0000d4">εύσπλαγχνοι</span>，在平行经文歌罗西书3:12中作“怜悯的心肠”，即对受苦之人的怜恤、同情。<span style="color:#800000">*彼此饶恕*</span>，<span style="color:#0000d4">χαριζόμενοι</span> <span style="color:#0000d4">ἑαυτοῖς</span>。此动词意为以恩惠相赐，进而指白白地饶恕、赦免。<span style="color:#800000">*正如*</span>，即因为 <span style="color:#800000">*神在基督里白白地饶恕了你们*</span>。这正是当激励我们饶恕他人的动机。神对我们的赦免是白白的；它甚至先于我们的悔改，并且是我们悔改的根由。我们的过犯虽多、虽重、虽积久不改，他仍施行赦免。他所赦免我们的，远超过我们有可能被要求去饶恕别人的。神在基督里赦免我们。在基督以外，按其圣洁与公义，他乃是烈火；但在基督里，他却是恒久忍耐、满有慈爱、乐意赦免的。

第1、2节。既然神使我们负有如此重大的义务，"<span style="color:#800000">*所以你们该效法神*</span>。"这劝勉在此又加以推广。我们不但要在饶恕上<!-- PAGE 191 -->效法神，也当如同<span style="color:#800000">*蒙慈爱的儿女，凭爱心行事*</span>。神既是爱，我们既藉重生与得儿子的名分成为他的儿女，就当以爱为常行。我们全部的行事为人都当以爱为特征。<span style="color:#800000">*正如基督爱我们*</span>。这就是我们当彼此相爱的缘由。我们应当像基督，而像基督即是像神，因为基督就是神。使徒在此并不区分我们是神所爱的对象与我们是基督所爱的对象。我们要在爱上效法神，因为基督爱了我们。<span style="color:#800000">*为我们舍了自己。*</span>在此如同别处，神圣之爱的伟大凭据即是基督的死。参看第25节；第3章19节；约翰福音15:13："人为朋友舍命，人的爱心没有比这个大的。"加拉太书2:20："他是爱我，为我舍己。"约翰壹书3:16："主为我们舍命，我们从此就知道何为<span style="color:#800000">*神的爱*</span>；我们也当为弟兄舍命。"基督的死是<span style="color:#800000">*为我们*</span>作了祭物，因此就此事之性质而论，乃是代我们而死。代替之意是否由 <span style="color:#0000d4">ὐπὲρ ἠμῶν</span> 表达出来，取决于上下文，而非取决于该介词本身的含义。为某人而死，或可指为其益处，或可指代其而死，视文脉所需而定。基督献上自己，<span style="color:#800000">*当作馨香的供物和祭物*</span>，<span style="color:#0000d4">προσφορὰν καὶ θυσίαν</span>；后一词解释前一词。凡献与神之物皆为 <span style="color:#0000d4">προσφορά</span>，而 <span style="color:#0000d4">θυσία</span> 则是被宰杀之物。因此，添上后一词便确定了此供物的性质。这一点在别处是由所献之物的性质来确定的，如希伯来书10:10"基督的身体"之献上；或"自己"，希伯来书9:14、25；也由归于它的功效来确定，即罪咎的赎除与神的息怒，这正是赎罪祭所当有的功效；参看希伯来书2:17；10:10、14；罗马书3:25；5:9、10；也由解释性的语句来确定，"基督一次的献上"被称为 <span style="color:#0000d4">μίαν ὑπὲρ ἁμαρτιῶν θυσίαν</span>，希伯来书10:12，即"一次为罪献上的祭"；又称 <span style="color:#0000d4">προσφορὰ περὶ ἁμαρτίας</span>，希伯来书10:18；又称 <span style="color:#0000d4">ἀντίλυτρον</span> 与 <span style="color:#0000d4">λυτρον ἀντὶ πολλῶν</span>，如提摩太前书1:6、马太福音20:28；它既被称为挽回祭，罗马书3:25，也被称为赎价。因此基督自己被称为担当我们罪孽的神的羔羊；他的血是信心的对象，是我们所倚靠的根基，我们正是藉着这如同祭牲之血的血得蒙救赎，彼得前书1:18、19。他以祭司的方式拯救我们，即藉着献祭。异教祭坛上每一只被宰的牺牲，都是在宣告这样一种献祭的必要；犹太祭坛上所流的一切血，都是对藉基督之血<!-- PAGE 192 -->得以挽回的预言与应许；而整部新约乃是神的儿子献上自己为世人的罪作祭物的记载。按照普世教会的信仰，这就是福音的总纲——永恒之神子的道成肉身与受死，作为赎罪的挽回祭。因此，使徒在此宣告基督为供物、为祭物，其意义如何，断无可疑。

“献与神”这几个字当如何连属，尚有疑义。它们或可与前句相连，作“他将自己献与神为祭”；或与下句相连，作“作馨香之祭献与神”，即为神所悦纳之意。若取后者，全句之意便是：“他舍了自己，<span style="color:#0000d4">παρέδωκεν ἑαυτὸν</span>（以至于死，<span style="color:#0000d4">εἰς θάνατον</span>），作神所喜悦的供物和祭物。”赞成此种连属的理由如下：一、<span style="color:#0000d4">παραδιδόναι</span> 本义为交付于人之权下，并非表达“献为祭物”之意的恰当或惯用之词。表达此意几乎总是用 <span style="color:#0000d4">προσφέρειν</span> <span style="color:#800000">*即带到近前、献上*</span>。二、保罗惯用的构造，是 <span style="color:#0000d4">παραδιδόναι</span> 与 <span style="color:#0000d4">εἰς</span> 连用，而非与与格连用。三、此处所用 <span style="color:#0000d4">εἰς ὀσμὴν εὐωδίας</span> 一语出自希伯来文，其意为<span style="color:#800000">*献与耶和华的馨香之气*</span>，七十士译本译作 <span style="color:#0000d4">ὀσμὴ εὐωδίας τῳ Κυπίῳ</span>。保罗既用如此熟悉的圣经成语，未必会离弃其惯常构造。这希伯来成语本义为安息之香气，就是能使人安定、平息、喜悦的气味。

末一说法正是希腊文所表达的，故其对应的说法是 <span style="color:#0000d4">εὐάπεστος τῳ θεῳ</span>，<span style="color:#800000">*蒙神悦纳*</span>。罗马书 12:1；腓立比书 4:18。基督将自己舍了，作馨香的供物和祭物献与神，正是出于那可想象的至高之爱的运行；这爱也当支配我们一切的行事为人。
