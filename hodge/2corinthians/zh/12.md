<p class="title-block-h2" style="text-align:center; font-size:16px; font-weight:bold; margin:18px 0 12px;" markdown="1"><span style="color:#006411">第十二章</span></p>

使徒蒙赐一异象之记述，1-6节。

他使徒职分的其余凭据，以及他在履行此职分时的行事为人与心志，7-21节。

<p style="text-align:center" markdown="1">**保罗所得的启示与异象。**</p>

他要停止夸口，不再述说自己所行的，而要述说神所行的；不再述说那些以他为行动者的场景，而要述说那些他不过是承受者的场景——即启示与异象。他曾被提到第三层天上，领受了不得传述的信息与启示。对他自己、以及对一切相信他话的人而言，这比他此前所提的任何凭据，都更能可靠地证明神眷顾他为使徒，1-6节。伴随这非凡的神恩明证，又有一样痛苦的身体疾患加在他身上，是他无法脱离的，为要使他保持应有的谦卑，7-10节。这样提及自己的亲身经历，于他极其难堪。是他们无理的反对，逼得他不得不如此论到自己；因为他使徒职分的外在凭据，本应使他们确信他乃是基督亲自差遣的使者，11、12节。他们自己就是他确为使徒的明证。他们所领受的恩赐，并不逊于其他使徒所建立的众教会。若说有何不及之处，也只在于他曾拒绝由他们供养。这是他不能不如此行的。他决意在此事上，将来仍走从前所走的路：无论亲自或藉着别人，无论间接或直接，他都不从他们手中受取什么，13-18节。这一切自辩其实无足轻重。他们如何看他，乃是小事。惟有神是唯一有资格作最终判断的。他所忧虑的是，及至到了哥林多，他必被迫以审判者的身分出现；因见他们并非他所愿望的光景，就不得不摆出责备者的面目，19-21节。

**1.** <span style="color:#800000">*我自夸固然无益，但我要说到主的显现和启示。*</span>

关于本节的经文，诸家所据颇有不同。通行本作 <span style="color:#0000d4">δή</span>（<span style="color:#800000">*实在*</span>、<span style="color:#800000">*诚然*</span>），然支持此读法的抄本与译本甚少。许多最古的抄本作 <span style="color:#0000d4">δεῖ</span>，即<span style="color:#800000">*这是必需的*</span>；另有少数作 <span style="color:#0000d4">δέ</span>，迈尔以此为原文。诸读法之别仅在思路的细微色调上。其意乃是：自夸无益；使徒将转到别的事上，或至少转到那些不含他本人作为或超凡能力的事上。**无益**。此处又有一些抄本与通行本相合，作 <span style="color:#0000d4">οὐ συμφέρει μοι</span>，<span style="color:#0000d4">ἐλεύσομαι γάρ</span>（于我无益，因我要说到）；另有一些则如拉赫曼、提申多夫与吕克特所取，作 <span style="color:#0000d4">οὐ συμφέροι μὲν</span>，<span style="color:#0000d4">ἐλεύσομαι δέ</span>，<span style="color:#800000">*（诚然无益*</span>，<span style="color:#800000">*但我要说到）*</span>。总的说来，仍当以通行本为优。使徒说，自夸<span style="color:#800000">*于我无益*</span>：或指这与我不相称，非体面合宜之事；或指这无所裨益，不能使我的使徒职分显得分明。要证明我所受的乃是神的差遣，另有更好的途径。前一解释更合于使徒的表达方式。他一再称自夸为一种愚妄，是有损身分、令人痛苦的事。此处说"无益"，所表达的正是同样的心情。<span style="color:#800000">*我要说到*</span>。我们的译本略去了 <span style="color:#0000d4">γάρ</span>，即<span style="color:#800000">*因我要说到*</span>。此处所连接的是一个略去未言的意思：自夸无益，（故此我就住口，）<span style="color:#800000">*因*</span>我要转到别的事上。下文所述他所得的启示，并非自我称扬，乃是述说神的恩慈。<span style="color:#800000">*异象和启示*</span>。后一词一方面比前一词更为宽泛，因为有启示之处未必有异象；另一方面，后者又比前者更高，因为它含有所见之事的意义得以显明之意。<span style="color:#800000">*主的*</span>；这并非指以主为对象的异象；他此处所说的并非看见主，乃是指以主为作者的异象与启示。<span style="color:#800000">*主*</span>显然当理解为基督；由此可见，祂如今仍然存活，并对人心中的思念与状态握有神性的权能。

**2.** <span style="color:#800000">*我认得一个在基督里的人，他在十四年前*</span>，<span style="color:#800000">*（或在身内，我不知道；*</span><span style="color:#800000">*或在身外，我不知道；只有神知道；）*</span><span style="color:#800000">*这人被提到第三层天上去*</span>。

<!-- PAGE 299 -->
他以第三人称说到自己：“我认得一个人。”他为何如此，并不清楚。他叙述所发生之事，仿佛自己是当时的旁观者，或许因为他自身的活动完全停止了。<span style="color:#800000">*在基督里的一个人*</span>；即一个在基督里的人；这是圣经对基督徒的称谓，因为与基督联合使人成为基督徒。这是得救唯一不可或缺的条件；凡在基督里的人都得救，凡在基督以外的人都灭亡。圣经也明明教导：就成年人而论，这与基督救恩性的联合，其条件不在于任何外在之事，不在于与这个或那个外在教会的联合，而在于信心个人性的领受之举，藉此我们接受基督、单单倚靠基督得救。更进一步，圣经同样清楚地教导：内心与生活的圣洁，乃是这信心确实的果子，因而也是其真伪唯一令人满意的凭据。<span style="color:#800000">*十四年前*</span>。本节所提及之事，与保罗归主之时所发生的并非同一件事。那一次是基督向使徒在地上的显现，这一次却是使徒被提到天上；那一次发生在本书信可能写作年代的二十年之前。可见二者无论在性质上还是在发生的时间上都不相合。<span style="color:#800000">*或在身内，或在身外，我都不知道*</span>。保罗所存疑的一点，并非此事的性质，不是它究竟只是他意识与知觉的提升，还是真实的被提，而仅仅是：这被提乃是灵魂与身体分离的被提呢，还是灵魂与身体一同被提。天堂虽是一种状态，却也是一个地方。按照圣经的表述，人进入天堂，所需的不仅仅是睁开眼睛看见此刻就在我们四围之物。我们主得荣的身体在某一处，而非无所不在。<span style="color:#800000">*这样的一个人被提；*</span><span style="color:#0000d4">ἁρπαγέντα</span>，<span style="color:#800000">*被夺去*</span>，这是表明不藉当事人自身作为而由此处移至彼处的确切用词。保罗在他此处所说的被提中，完全是被动的。参使徒行传 8:39；帖撒罗尼迦前书 4:17，“被提到云里，在空中与主相遇。”<span style="color:#800000">*到第三层天上。*</span>这或指至高的诸天；或者，若假定保罗采用了拉比们的语言、并有意迎合他们“天有七层”的观念，则指空气，即云霄之域。他先被提到空中，然后又被进一步提到乐园。前一种解释更为可取：一、因为没有证据表明，那些著作至今尚存的犹太作者的见解，在使徒的时代已经流行。二、因为新约中没有证据表明，圣经作者采纳了那些见解。三、因为倘若保罗相信并教导天有七层，也就是说，倘若他认可了拉比在这题目上的教义，那么这就成了基督教教义的一部分，而事实并非如此。这并不属于基督教会所信的内容。四、因为显然“第三层天”与“乐园”是同义之词；而乐园，至少在那些认为保罗此处是以犹太人身份说话的人看来，也是公认指天堂。

**3、4节。** <span style="color:#800000">*我认得这人；（或在身内，或在身外，我都不知道，只有神知道。）他被提到乐园里，听见隐秘的言语，是人不可说的。*</span>

此节是第2节的重述，唯一的不同，是以"乐园"一词取代了"第三层天"这一说法。<span style="color:#800000">*乐园*</span>一词源出梵文，意为园囿或花园。七十士译本在创世记 2:8 描述伊甸时即用此词，因伊甸原是一座乐园或花园。犹太人很早便以此词指称天堂，即蒙福之人死后的居所，路加福音 23:43 可为明证（参《便西拉智训》40:17, 28）。启示录 2:7 中此词亦是同一意思。<span style="color:#800000">*听见隐秘的言语*</span>，<span style="color:#0000d4">άρρητα ρήματα</span> 直译作"未曾说出的言语"；在此处其意显然是"不可说出的言语"，下文即为其解释。<span style="color:#800000">*是人不可说的。*</span>使徒所领受的启示，是不许他向别人传述的。那遮蔽天上奥秘与荣耀的幔子，神未曾允许人揭开。我们只需知道：在那世界里，众圣徒必得完全成圣，完全蒙福，永远尽享神的自己，这就够了。

**5.** <span style="color:#800000">*为这人，我要夸口；但论到我自己，我并不夸口，只夸自己的软弱。*</span>

<span style="color:#800000">*论到这人*</span>，<span style="color:#0000d4">ὑπὲρ τοῦ τοιούτου</span>，即<span style="color:#800000">*为着*</span>这样的人，意即代他而夸；或者，将 <span style="color:#0000d4">ὑπέρ</span> 取作 <span style="color:#0000d4">περί</span> 的意思，即<span style="color:#800000">*关于*</span>、论到。后一种解法意思更好：「论到这样的人，我要夸口。」这等于说：「这样的事乃是夸口的正当根据。」但 <span style="color:#0000d4">τοιούτου</span> 不可作中性解（「这样的事」），因与之对举的 <span style="color:#0000d4">ἑμαυτοῦ</span> 已清楚表明这一点：「论到这人我要夸口，论到我自己却不夸口。」他所经历的这次被提，确是可夸的正当根据，因为那纯是白白的恩宠。这并不表明蒙此神圣恩眷之人本身有何优越之处，故此可以夸口，而不必自居有何特殊功德。<span style="color:#800000">*论到我自己，我就不夸口*</span>；意即他不愿以自己的个人资质自夸，仿佛这些足以使他受人钦羡。<span style="color:#800000">*只*</span>（<span style="color:#0000d4">εἰ μή</span>，<span style="color:#800000">*除了*</span>）<span style="color:#800000">*夸自己的软弱*</span>。就是说：「论到我自己，我只夸那些足以证明或显明我自己软弱的事。」

**6.** <span style="color:#800000">*我就是愿意夸口，也不算狂，因为我必说实话；只是我禁止不说，恐怕有人把我看高了，过于他在我身上所看见、所听见的。*</span>

由（<span style="color:#0000d4">γάρ</span>）<span style="color:#800000">*因为*</span>所指明的关联，并非直接连于上一节所表述的内容，而是连于其中显然隐含的一层思想。保罗曾说，他不愿为自己夸口。他如此决定，并非因为缺少可夸之据。‘我本可以夸口，<span style="color:#800000">*因为*</span>我若愿意夸口，<span style="color:#800000">*也不算狂*</span>；即不算是空口自夸的人——因为我所说的乃是真话。’<span style="color:#800000">*但我禁止自己*</span>（<span style="color:#0000d4">φείδομαι δέ</span>，即 <span style="color:#0000d4">τοῦ καυχᾶσθαι</span>）。使徒手中可供夸口的材料何等丰富，他本可名正言顺地提及自己所受的非凡恩赐，以及随其劳苦而来的非凡果效，然而他并不在这些事上多加铺陈。他为这样的自我节制所给出的理由是：免得别人因此把他看得太高。他不愿人凭他自述之言、或自述之经历来判断他；他宁愿人凭所看见、所听见的来判断他。

**7.** <span style="color:#800000">*又恐怕我因所得的启示甚大，就过于自高，所以有一根刺加在我肉体上，就是撒但的差役要攻击我，免得我过于自高。*</span>

保罗既定意不给人以过高看待他的机会，此处便告诉我们，神也预防他在自己心中过分自高。人所共知的一个经验是：上位者的特别恩宠，与自身所具的优长一样，都能使人在自己眼中自视甚高。因此使徒虽不肯自夸，仍有因所受神恩的非凡显示而过分自高的危险。此处词序是倒装的。“又恐怕我因所得的启示甚大，就过于自高”；<span style="color:#0000d4">ὑπεραίρωμαι</span>，即被高举过于合宜、合理的分际。<span style="color:#800000">*甚大*</span>（或作极其丰盛）<span style="color:#800000">*的启示*</span>这一说法，似乎不单指上文所述的那一次经历，也指他在别的时候所领受的类似传达。神向使徒揭开神圣知识之宝藏，并非仅此一次。<span style="color:#800000">*有一根刺加给我*</span>，即出于神。此处所说的试炼是神所降下的，使徒也是向神求脱离。<span style="color:#800000">*一根刺加在肉体上*</span>，<span style="color:#0000d4">σκόλοψ τῃ σαρκί</span>。<span style="color:#0000d4">σκόλοψ</span> 一词本义为削尖的木桩、栅栏，进而指任何削尖的木条，特指荆棘。末一义最合于本段，也是通常所采纳的。另有人说其意为“刺肉体的刺棒”，取喻于驱牛之具，如加尔文所说 metaphora a bobus sumpta；又有人以 <span style="color:#0000d4">σκολόψ</span> 指刺穿犯人所用的桩，或悬挂犯人的十字架。加于肉体的桩或十字架，便是身体受苦的比喻说法。<span style="color:#800000">*肉体*</span>可按字面指身体，也可按比喻指败坏的本性。加尔文与许多人取后一解。但既无理由离弃字面之义，而在其他条件相等时字面义总当优先，故不必如此。与格 <span style="color:#0000d4">σαρκί</span> 可译为<span style="color:#800000">*为着*</span>肉体，或<span style="color:#800000">*关乎*</span>肉体，即在肉体上。末一译法为佳，因它既合上下文，又有平行经文加拉太书 4:14 为证：<span style="color:#0000d4">τὸν πειρασμόν</span> <span style="color:#0000d4">μου τὸν ἐν τῃ σαρκί μου</span>。若这是 <span style="color:#0000d4">σάρξ</span> 一词的正解，则使徒此处所说之刺的性质大体也就可以断定了。它不可能是撒但的邪恶暗示或火箭，如

<!-- PAGE 302 -->

路德、加尔文等人正是如此理解的；也不是指某个显要的敌人，如古代许多人所推测的；它无疑是某种痛苦的身体疾患。<span style="color:#800000">*撒但的差役*</span>。圣经中常常提出这样的观念：身体的疾病有时是撒但直接施为的结果，故此可视之为他的使者，是由他所差来的。此处 <span style="color:#0000d4">Σατᾶν</span> 一词大概是用作不变格的名词，正如七十士译本中一两处的用法；但在新约中，除此一处外，该词总是变格的，主格作 <span style="color:#0000d4">Σατανᾶς</span>，属格作 <span style="color:#0000d4">Σατανᾶ</span>。因此许多人倾向于把这里的词看作主格，将该短语译为<span style="color:#800000">*天使撒但*</span>，即一位就是撒但的天使（或使者）。但既然 <span style="color:#0000d4">Σατᾶν</span> 有时是不变格的，且新约中从未称撒但为天使，绝大多数注释家仍持与英文译本相同的解释。<span style="color:#800000">*攻击我*</span>，<span style="color:#0000d4">ἵνα</span> <span style="color:#0000d4">με κολαφίζῃ</span>，<span style="color:#800000">*叫他*</span>（即那天使或使者）<span style="color:#800000">*攻击我*</span>。现在时态的使用似乎表明，“身上的一根刺”是使徒持续忍受、久久不去的一种疾患。<span style="color:#800000">*免得我过于自高*</span>。末一句道出了神容许使徒如此受苦的用意。他随身带着自己软弱的持续凭据。无论他被高举到何等地步——纵然被提到第三层天——他仍不能拔去这根刺人的荆棘。神子民的经历表明，身体的痛苦在成圣之工中担负着特殊的职分。在未重生之人身上，它的倾向是激起怨愤；若是自己加诸己身的，其倾向则是使人卑贱，叫灵魂充满对神与信仰的鄙陋观念，并生出低下的自负。然而当神把痛苦加在自己的儿女身上时，它比任何别的事都更能教导他们认识自己的软弱与倚靠，并在最难顺服之时呼召他们顺服。“他必杀我，我仍要信靠他”，乃是信心最高形式的表达。

**8、9节。** <span style="color:#800000">*为这事，我三次求过主，叫这刺离开我。*</span><span style="color:#800000">*他对我说：我的恩典够你用的，因为我的能力是在人的软弱上显得完全。*</span><span style="color:#800000">*所以，我更喜欢夸自己的软弱，*</span><span style="color:#800000">*好叫基督的能力覆庇我。*</span>

<span style="color:#800000">*为这事*</span>，<span style="color:#0000d4">ὑπὲρ τούτου</span>，<span style="color:#800000">*就这事而言；*</span><span style="color:#0000d4">ὑπέρ</span> 在此用作 <span style="color:#0000d4">περί</span> 之意。<span style="color:#0000d4">Τούτου</span> 可作中性，意即<span style="color:#800000">*为这事*</span>，就是指这苦难；也可作阳性，指 <span style="color:#0000d4">άγγελος</span>，即“为这撒但的差役”，

<!-- PAGE 303 -->

<!-- PAGE 304 -->
等等。因下文的从句 <span style="color:#0000d4">ἵνα</span> <span style="color:#0000d4">ἀποστῇ</span>，<span style="color:#800000">*叫这刺离开我*</span>，此解一般更为人所取。使徒说，我<span style="color:#800000">*三次*</span>求过主。我们有福的主也照样祷告，“第三次说，叫这杯离开我。”可见保罗为脱离这一沉重的试炼，恳切不已地祈求。他说，我求过<span style="color:#800000">*主*</span>，即基督；这不仅从圣经通常的用法可以看明，也从第9节所说“基督的能力”可以看明。<span style="color:#800000">*他对我说*</span>，<span style="color:#0000d4">είρηκέ μοι</span>。此处完成时或作不定过去时用，或按其本身的力量把过去与现在连接起来。这答复不单是已成过去之事，乃是其安慰之力持续不断之事。参温纳《文法》41。“他已经说了”；这答复常在使徒耳中回响，且不单在他耳中回响，也在自那日以来一切受苦圣民的耳中回响。人人都听见主说：<span style="color:#800000">*我的恩典够你用的*</span>，<span style="color:#0000d4">ἀρκεῖ σοι ἡ χάρις μου</span>。这话当铭刻在每一个信徒的掌上。<span style="color:#800000">*我的恩典*</span>，或指“我的慈爱”，或以转喻指“圣灵的帮助”，<span style="color:#800000">*恩典*</span>一词常有此义。就上下文而论，取该词通常的意义为宜。“我的爱够你用的了。”这是基督的话。他对那些求脱离痛苦忧伤之人说：“我爱你，这就够了。”这一句话保证并包含了其余一切的美善。他的恩眷就是生命；他的慈爱比生命更好。<span style="color:#800000">*因为我的能力是在人的软弱上显得完全。*</span>此语说明基督的恩典何以充足有余。理由就是：他的能力在软弱上得以完全，即清楚显明为达成了其目的。主的意思是：“换言之，软弱正是我彰显能力的条件。我的子民越软弱，我扶持他们、拯救他们的能力就越显著。”<span style="color:#800000">*所以我更喜欢夸自己的软弱。*</span>其意并非“我夸软弱过于夸别的事”，仿佛保罗写的是 <span style="color:#0000d4">μᾶλλον ἐν ταῖς ασθενείαις</span>；乃是“我宁可夸软弱，而不求脱离”。若保罗的苦难要成为基督荣耀彰显的机缘，他便以受苦为乐。他如此行是 <span style="color:#0000d4">ἡδίστα</span>，<span style="color:#800000">*极其甘心地*</span>，怀着自己深觉喜悦的顺服。他的苦难因此成了最纯洁最崇高之喜乐的泉源。<span style="color:#0000d4">Καυχάομαι ἐν ταῖς ἀσθενείαις</span> 不是说<span style="color:#800000">*我在软弱之中夸口*</span>，而是<span style="color:#800000">*因*</span>软弱夸口。参5:12；10:15；罗马书2:23等处。这种因苦难、因那些显明他软弱与依靠之事而生的喜乐，并非狂热之情，乃有合理而充分的根据，就是<span style="color:#800000">*好叫基督的能力覆庇我。*</span>原文作 <span style="color:#0000d4">ἐπισκηνώσῃ</span>，<span style="color:#800000">*在我身上支搭帐幕*</span>；即如住在帐幕中一般住在我里面，正如古时舍吉拿住在会幕中。得以如此作基督能力的居所，作他显明荣耀之处，实在是为那些软弱欢喜的合理根据——因为那软弱正是他同在的条件，也是他彰显能力的机缘。多数基督徒只求在苦难中甘心顺服，便以为满足。他们以为，若能使自己甘愿作基督能力的居所，便是了不起的事了。至于因苦难而欢喜，因为基督藉此得荣耀，则非他们所敢企望。保罗的经历远在这标准之上。基督的能力不但如此彰显在他子民的软弱上，也彰显在他成就旨意所用的手段上。这些手段在其自身，无一不是全然不足，与所要成就的结果全不相称。宝贝放在瓦器里，是要显明这莫大的能力是出于神。他藉着人所当作愚拙的道理，拯救那些信的人。藉着十二个未受学问的人，教会得以建立，并遍传于文明世界。藉着少数几位宣教士，异教之地变为基督教之国。在一切事上都是如此：基督的能力在软弱上得以完全。在这段经文中，我们清楚看见使徒的属灵生命，也得着最有力的凭据，证明他是与作神的基督相交而活。他仰望基督为至高的、无所不在的、充足有余的主，求他救自己脱离“身上的刺”，脱离撒但差役的攻击——他曾在其下受尽苦楚。他向基督祷告。他从基督领受祷告的答复。那答复乃是神的答复；它意味着答复者具有神性的完全。受造之物的恩眷，能使何等的受苦者得着满足呢？除神以外，谁能说“我的恩典够你用的”？对保罗而言，这恩典确是足够的。它使他得着完全的平安。它不仅使他在苦难中甘心顺服，更使他能在苦难中欢喜。基督得着荣耀，在他看来乃是一个目的，为此受苦，任何人都当引以为荣。所以极其明显，使徒的敬虔，他内里的属灵生命，是以基督为对象的。他一切宗教的情感都归止于基督；他至高的爱、信靠与献身的敬拜都归与基督。基督教不仅是基督所传的宗教；从主观方面说，它乃是以基督为源头、以基督为对象的宗教。

<!-- PAGE 305 -->

**10.** <span style="color:#800000">*我为基督的缘故，就以软弱、凌辱、急难、逼迫、困苦为可喜乐的；因我什么时候软弱，什么时候就刚强了。*</span>

「以软弱夸口」与「以软弱为可喜乐的」，二者之别在于：前者是后者所表之心情的外在流露。他夸口于自己的软弱，就是以此自夸，把这些软弱当作足以增添他荣耀之事、当作喜乐的源头而加以称述。既然这些软弱正是显明基督能力的机缘，保罗便以之为喜，且乐意身受其中。<span style="color:#800000">*软弱*</span>是个总称，凡我们境遇中足以证明或显明其无力的，无论属道德的还是属身体的，皆包括在内。从上下文看，此处显然是指苦难而言，凌辱、穷乏、逼迫、困苦不过是苦难的种种形态。<span style="color:#800000">*为基督的缘故*</span>。这几个字统摄前面所列的一切。使徒所喜悦的，乃是为基督的缘故所忍受的苦难，无论是凌辱、穷乏、逼迫，还是困苦。他所喜悦的，不是就苦难本身而言的苦难，不是自加于己身的苦难，也不是因自己的愚妄或恶劣性情所招致的苦难，乃是为基督的缘故所忍受的苦难，即视之为显明基督能力的条件。<span style="color:#800000">*因我什么时候软弱*</span>，<span style="color:#800000">*什么时候就刚强了。*</span>当我们在自己里面真是软弱，并自觉这软弱之时，我们便处在适宜于神的能力得以显明的光景中。我们里面倒空了自己，就被神充满。凡自以为能更改自己的心、能为自己的罪赎愆、能在自己或他人心中制伏罪恶权势的人，凡自觉在患难中能自立自持的人，神就任凭他们倚靠自己的资源。惟有当他们觉察并承认自己的软弱时，神才将属天的力量分赐与他们。

**11.** <span style="color:#800000">*我成了愚妄人，是被你们强逼的；我本该被你们称许才是。我虽算不了什么，却没有一件事在那些最大的使徒以下*</span>。

<!-- PAGE 306 -->
<span style="color:#800000">*我成了愚妄人*</span>等语。有人认为这是反语，因为前面所作的自辩并非愚妄之举，虽然在保罗的反对者看来或许如此。但把这话理解为使徒自己心中的感受，则更为自然，也更合乎全段的文理。自我称许本是愚妄。这有损使徒的尊严，也令他心中不安，但他不得不勉强为之。因此，就他的处境而言，此举虽属屈辱，却是正当的。<span style="color:#800000">*这是你们逼我的*</span>。正是他们的行为，使使徒不得不自我称许。这在下一句中得着解释。<span style="color:#800000">*我本该被你们称许才是*</span>。他们若尽了本分，为他辩明，驳斥假师傅的毁谤，他就无须自辩了。他们本有责任如此为他辩护，<span style="color:#800000">*因为他一点不在那些最大的使徒以下*</span>。凡有机会为义人辩护的，都负有此不可推卸的责任。当好人遭人毁谤，或其品格与劳苦被人轻看之时，我们若缄默不言，便是在毁谤之罪上有份。哥林多人在此事上的罪咎更为加重；因为保罗使徒职分与忠心的凭据本是丰富确凿的。他无论在哪一方面都不在那些最大的使徒以下。不仅如此，他们不但亲眼见过他神圣使命的凭据，而且亲身领受了这使命所带来的福分。因此，他们若不为他的凭据与劳苦辩护，便是忘恩负义、怯懦失职。这里所说"最大的使徒"，比 11:5 处更为明显，是指真使徒中最著名的几位，如彼得、雅各、约翰；在加拉太书 2:9 中，他们被称为教会的柱石。无论此处或 11:5 处，都不是对假师傅的讽刺称呼。<span style="color:#800000">*虽然我算不了什么*</span>。使徒深知，凡出于神恩典、出于神白白赏赐的，都不能作为自满自高的根据。哥林多前书 4:7；15:8-10。所以在他身上，一面是对自身不配与无能的深切自觉，一面又是因圣灵内住而满有知识、恩典与能力的确信与自知，二者并存。

**12.** <span style="color:#800000">*我在你们中间用百般的忍耐，行了使徒的凭据，就是神迹、奇事、异能。*</span>

<!-- PAGE 307 -->
<!-- PAGE 308 -->
这就是他不在那些"超等的使徒"之下的证据。<span style="color:#800000">*诚然*</span>；<span style="color:#0000d4">μέν</span>，其后并无相应的 <span style="color:#0000d4">δέ</span>。但从上下文的关联看，对比之意甚为明显。'使徒的凭据<span style="color:#800000">*确实*</span>在你们中间显出，<span style="color:#800000">*但你们*</span>却不肯承认。'吕克特（Ruckert）、德韦特（De Wette）等人即如此解。<span style="color:#800000">*使徒的凭据*</span>乃是使徒职分的标记，即神所指定、用以证明一人受神差遣的那些事。这些标记既已显明，凡目睹之人便有责任承认持有此等标记者的权柄。而这些标记若不存在，一面，自称为使徒便是渎神之举；另一面，承认其有此职分便是背弃神的行为。承认那些自称使徒而实非使徒之人的宣称，昔日如此，今日亦然，就是离弃神而归向受造之物，把本属人的、甚或属撒但的当作属神的领受。这显然就是保罗对此事的看法，从 11:13-15 可以看出；在那里他论到那些实为撒但的差役、却自称为基督使徒的人。参启示录 2:2。据圣经所示，这使徒的凭据有数种不同的类别。其一在于使徒职分内在恩赐的显明（即那些使人成为使徒的恩赐）：如从耶稣基督直接启示而来的、对福音的完全认识（加拉太书 1:12；哥林多前书 15:3）；又如默示，即圣灵的那种感动，使领受之人在传达真理时绝无谬误（哥林多前书 2:10-13；12:8，并参 12:29 与 14:37）。其二在于神施恩的外在显明，以印证其使徒职分的宣称（加拉太书 2:8）。属此类者，有在教导真理上的忠信，即与那已被证实的信仰准则相符（加拉太书 1:8, 9）。人若不这样被保守在福音里，则无论他能举出何等别的凭据证明自己是使徒，都当被视为可咒可诅的（加拉太书 1:8）。属此类者，还有传福音的果效（哥林多前书 9:2；哥林多后书 3:2, 3）；藉按手赐下圣灵的权能（使徒行传 8:18；19:6）；行异能的权能，这从本段经文、从罗马书 15:18, 19 以及许多别处经文可见，如希伯来书 2:4；马可福音 14:20；使徒行传 5:12；14:3；此外还有圣洁的行事为人（哥林多后书 6:4）。若无这些凭据，无人能被承认为使徒而受人顺从，否则便是背弃神，便是离弃真使徒而归从那些撒但的差役。<span style="color:#800000">*凡事忍耐*</span>，或作恒忍。这并非说忍受严酷试炼的忍耐本身乃是他使徒职分的凭据之一，而是说那些凭据是在艰难逆境中显出的，其处境需要极大的恒忍。<span style="color:#800000">*用神迹*</span>、<span style="color:#800000">*奇事*</span>、<span style="color:#800000">*异能*</span>。这三者乃是同一件事的不同称法。称异能为<span style="color:#800000">*神迹*</span>，是就其目的而言，即证实行此事者受神差遣；称为<span style="color:#800000">*奇事*</span>，是就其所生的效果而言；称为<span style="color:#800000">*异能*</span>（<span style="color:#0000d4">δυνάμεις</span>），则因其为神能力的显明。

**13.** <span style="color:#800000">*我在什么事上使你们比别的教会有所不及呢？只是我未曾累着你们这一件事罢了。这不公之处，望你们饶恕我！*</span>

<span style="color:#800000">*因为*</span>。此小品词所指明的连接，是与第12节的断言相连：“我一点不在那些最大的使徒以下，因为你们并不落在别的教会以后。”保罗所建立的众教会，其人数之众、恩赐与恩典之丰富，既与其他使徒所建立的教会相等，这便证明他与他们平等。换言之，正如加拉太书 2:8 所说：“那感动彼得、叫他为受割礼之人作使徒的，也感动我，叫我为外邦人作使徒。”参 哥林多前书 1:5-7。<span style="color:#800000">*你们比别的教会有什么不及处呢*</span>，按字面即“较小于”或“较弱于”。动词 <span style="color:#0000d4">ἡττάομαι</span>（<span style="color:#800000">*源于*</span> <span style="color:#0000d4">ἥττων</span>，<span style="color:#800000">*较小*</span>）带有比较之意，故其后接 <span style="color:#0000d4">ὑπέρ</span>，<span style="color:#800000">*过于*</span>；即“弱于别的教会”。哥林多人所受的唯一不利之别，乃是使徒拒绝接受他们的供给。这话不可视为讥讽，也不可视为责备。乃是以温柔的口吻说的，从下文即可看明。<span style="color:#800000">*这不公之处，求你们饶恕我罢。*</span>这在哥林多人看来，显然是对他们的一种非议；保罗甘愿从别的教会领受，却不肯从他们领受，似乎暗示他对他们的慷慨或爱心缺乏信任。在前一章中，他极力使他们确信：他如此行，并非证明他对他们缺少爱，也非证明他不信任他们对他的爱。他在此事上的作为另有缘由，且是充分的缘由；这些缘由迫使他坚持这样行，纵然此举于他于他们都是痛苦的。

**14.** <span style="color:#800000">*看哪*</span>，<span style="color:#800000">*我打算第三次到你们那里去，也必不累着你们；因我所求的是你们*</span>，<span style="color:#800000">*不是你们的财物。儿女不该为父母积财*</span>，<span style="color:#800000">*父母该为儿女积财。*</span>

使徒行传只提到保罗在本书信写成之前到过哥林多一次。但从本节，以及 2:1 和 13:1、2 看来，显然他已两次到过那城。因此本节中<span style="color:#800000">*第三次*</span>一语是与<span style="color:#800000">*来*</span>相连，而非与<span style="color:#800000">*我已预备好*</span>相连。其意不是"我第三次预备好了"，乃是"我预备第三次前来"。他的心意是：这第三次探访，仍要依前两次所遵行的同一原则而行。<span style="color:#800000">*我必不累着你们*</span>，意即我不从你们受什么。为此他举出两个理由，二者不但与他对他们的爱相符，更是他爱他们的凭据。<span style="color:#800000">*因我所求的是你们*</span>，<span style="color:#800000">*不是你们的财物*</span>。这是第一个理由。他并无贪财或自利的目的可图。他所要得的不是他们的钱财，乃是他们的灵魂。<span style="color:#800000">*儿女不该为父母积财*</span>，<span style="color:#800000">*父母该为儿女积财*</span>。这是第二个理由。他与他们乃有父子之谊。按着自然的常理，是父母当供养儿女，而非儿女供养父母。保罗说，你们必须容我享有作父母的权利。使徒就这样温柔而得体地，将一件看似不近情的举动，与他自己心中所存、也愿在他们心中激发的慈爱之情调和起来。

**15.** <span style="color:#800000">*我也甘心乐意为你们的灵魂费财费力；难道我越发爱你们，就越发少得你们的爱吗？*</span>

既然我是你们的父亲，我就甘心尽父亲的本分，为你们花费，也为你们花上自己；纵然我这样行会失去你们的爱，而爱又逼着我不得不如此行。这是无私之爱最强烈的表达。保罗不但愿意献上自己的财物，更愿意献上自己、自己的性命与精力，为着他们（原文作<span style="color:#800000">*为你们的灵魂*</span>，<span style="color:#0000d4">ὑπέρ τῶν ψυχῶν ὑμῶν</span>），不但不求报答，甚至以失去他们的爱为代价。

**16.** <span style="color:#800000">*罢了*</span>，<span style="color:#800000">*我自己并没有累着你们；你们却说，我是诡诈*</span>，<span style="color:#800000">*用心计牢笼你们。*</span>

<!-- PAGE 310 -->

<span style="color:#800000">*罢了；*</span>意思是，纵然承认我本人未曾累着你们，然而（你们或许要说）我却借着别人诡诈地行了此事。这话是为着应付假师傅可能提出的那不厚道的指控。他们或许暗示说，保罗虽自己不肯收受什么，却把他的同伴安置在哥林多人身上就食，或是借着别人搜刮他们。<span style="color:#800000">*我是诡诈，用心计牢笼你们*</span>，<span style="color:#0000d4">δόλῳ ὑμᾶς έλαβον</span>，即：我用巧计掠夺了你们，如同野兽因受骗而落网一般。这就显出使徒在哥林多的那些反对者是何等样人。他竟以为有必要防备这般不厚道、毫无根据的暗讽，正证明他拒绝给这等敌手留下丝毫余地去质疑他动机之纯正，实为智慧之举。

**17、18.** <span style="color:#800000">*我所差到你们那里去的人，我曾借着他们中间的哪一个占过你们的便宜吗？我劝了提多去，*</span><span style="color:#800000">*又差那位弟兄与他同去。提多占过你们的便宜吗？我们行事，不同是一个心灵吗？不同是一个脚踪吗？*</span>

有人暗指保罗自己公然不肯做的事，却借着别人暗中去做；对这种影射，最有力的驳斥便是诉诸事实。哥林多人自己知道这指控毫无根据。他们知道，保罗所差往哥林多的人，没有一个从他们手中收取过任何报酬。这在提多的事上尤其确凿，因为他是保罗的直接代表。凡保罗所差遣的人，都效法保罗的榜样——无疑也遵从保罗的吩咐——自付一切费用。这里所提提多往哥林多之行，并非第八章所说的那一次（那次尚未成行），乃是第七章所记的那一次，目的是查明保罗前一封信所产生的果效。<span style="color:#800000">*同一心灵；*</span>或指内心同样的意念，或指<span style="color:#800000">*凭*</span>同一位圣灵，即被那位管理神百姓行事为人的同一位神圣主宰所充满、所引导。<span style="color:#800000">*同一脚踪。*</span>保罗与他所差遣的人行在同样的脚踪里。就是说，他们都跟随基督，基督的脚踪标明了凡跟随祂的人当行的道路。

**19.** <span style="color:#800000">*你们再者*</span>，<span style="color:#800000">*还想我们是向你们分诉么？我们本是在基督里当神面前说话；但*</span><span style="color:#800000">*亲爱的弟兄啊，*</span><span style="color:#800000">*一切的事都是为造就你们。*</span>

<!-- PAGE 311 -->
使徒在此要纠正两种错误的印象。其一，以为他自觉当向哥林多人交账，或以为他们就是那审判官，他正站在他们的公堂上为自己申辩。其二，以为他的目的多少带着个人的私意或自利。他乃是在神面前说话，不是在他们面前；乃是为造就他们，不是为博取自己的名声。

<span style="color:#800000">*你们再想*</span>。你们岂是又如从前那样想么。抄本 D、E、J、K 不作 <span style="color:#0000d4">πάλιν</span>（<span style="color:#800000">*再*</span>），而作 <span style="color:#0000d4">πάλαι</span>（<span style="color:#800000">*从前*</span>、<span style="color:#800000">*久已*</span>）。近代大多数校勘者采此读法。如此则意为“你们久已如此以为”，或“你们早就这样想”。可比较马可福音 15:44 的 <span style="color:#0000d4">εἰ πάλαι</span> <span style="color:#0000d4">ἐπέθανεν</span>（<span style="color:#800000">*耶稣是不是已经死了许久*</span>）。然而通行读法既有众多抄本为据，所得之意又甚妥当，故旧时校勘者与注释家多予保留。若从 <span style="color:#0000d4">πάλιν</span>，则此句最宜作疑问句读。你们又这样想么？如他们先前所行的一般。参 3:1；5:12。他们过于倾向于认为，使徒也像那些假教师一样，急欲讨他们的欢心，并以他们为自己的审判官。使徒屡次让他们明白：他并不在他们权下，他的职分不是从他们手中领受的，他如何执行此职分也无须向他们交账。参哥林多前书 4:3。<span style="color:#800000">*向你们分诉*</span>；<span style="color:#0000d4">ὑμῖν</span>，即<span style="color:#800000">*在你们面前，以你们为审判官*</span>。<span style="color:#800000">*分诉*</span>，<span style="color:#0000d4">ἀπολογέομαι</span>，意为<span style="color:#800000">*为自己开脱*</span>、<span style="color:#800000">*申辩*</span>，或为自己答辩。但使徒所处的地位并非如此。他不是一个被告——无论实为有罪或被人疑为有罪——站在他们的审判台前受审。恰恰相反，正如他所说，<span style="color:#800000">*我们在神面前说话*</span>；即向神负责，并在他面前说话；<span style="color:#800000">*在基督里*</span>，即以一个自觉与主耶稣联合之人所当有的方式说话。他一切的自辩，都是把自己看作一个在神面前说话的基督徒；作为奉神差派的使者，他所说的话只向神一人交账。<span style="color:#800000">*亲爱的弟兄啊，一切的事都是为造就你们*</span>。这是第二点。他的申辩，或说自我辩护，其目的乃在他们的益处，而不在自己的名声或利益。

**20.** <span style="color:#800000">*我怕我再来的时候，见你们不合我所望的*</span><span style="color:#800000">*，*</span><span style="color:#800000">*你们见我也不合你们所望的；又怕有分争、嫉妒*</span><span style="color:#800000">*、*</span><span style="color:#800000">*恼怒*</span><span style="color:#800000">*、*</span><span style="color:#800000">*结党*</span><span style="color:#800000">*、*</span><span style="color:#800000">*毁谤*</span><span style="color:#800000">*、*</span><span style="color:#800000">*谗言*</span><span style="color:#800000">*、*</span><span style="color:#800000">*狂傲*</span><span style="color:#800000">*、*</span><span style="color:#800000">*混乱的事*</span>。

<!-- PAGE 312 -->
他所求的是他们得造就，因他恐怕他们的光景并非他所愿见的。他恐怕他们不合他的心意，他也不合他们的心意。他所惧怕的，乃是前面已屡次提及的那些恶事至今仍存。这些恶事就是：<span style="color:#0000d4">έρεις</span>，<span style="color:#800000">*分争*</span>，即教会分裂而成的各党派之间的争竞，有的说我是属保罗的，有的说我是属矶法的，等等，参哥林多前书 1:11；<span style="color:#800000">*嫉妒*</span>，<span style="color:#0000d4">ζῆλοι</span>，即通常伴随分争而生的猜忌与疏远之情；<span style="color:#0000d4">θυμοί</span>，<span style="color:#800000">*恼怒的发作*</span>；<span style="color:#0000d4">ἐριθεῖαι</span>，<span style="color:#800000">*结党营私*</span>。此词源于 <span style="color:#0000d4">έριθος</span>，<span style="color:#800000">*雇工*</span>，常用以指结党分派之心；<span style="color:#0000d4">καταλαλιαὶ</span> 与 <span style="color:#0000d4">ψιθυρισμοί</span>，即毁谤与谗言，一为公然的贬损，一为暗中的诬陷；<span style="color:#0000d4">φυσιώσεις</span>，<span style="color:#800000">*狂傲*</span>，即骄傲与凌人之态的流露；<span style="color:#0000d4">ἀκαταστασίαι</span>，<span style="color:#800000">*混乱*</span>，即上述情形所必然招致的种种失序。这是一串可畏的恶行；而此处所言，与本书前半部分（尤其第七章）中对该教会悔改顺服所作的热切称述，似难以相调和。为解释这一不一致之处，有人如前所述，以为本书后半，即自第十章至末尾，原是另一封独立的书信，写作的时间与情境皆与前半不同。另有人虽承认两部分同属一书、同时寄出，却仍推测前半与后半的写作之间相隔颇久；而在这段间隔之中，有消息传到使徒耳中，说教会中盛行的恶事并未如他所望的那样得着彻底纠正。对此难题通常且足够的解释是：会众中的一部分（大概是多数）已然悔改顺服，另一部分却恰恰相反。使徒眼中所念的是前一类人时，便用称许之言；所念的是后一类人时，便用责备之语。此类例子在他的书信中屡见不鲜。他给哥林多人的前书，开头满是极强烈的赞许之辞，而其后的篇章却大多充满严厉的责备。

**21.** <span style="color:#800000">*且怕我来的时候，我的神叫我在你们面前惭愧，又因许多人从前犯罪，行污秽、奸淫、邪荡的事，不肯悔改，我就忧愁。*</span>

<!-- PAGE 313 -->

同一忧虑，只是以另一种方式表达出来。<span style="color:#800000">*再*</span>字或可归于<span style="color:#800000">*来*</span>，即"我再来"；或可归于<span style="color:#800000">*叫我惭愧*</span>，即"神必再叫我惭愧"。后者含有此意：在他那次未被记载的第二次探访期间，保罗因在哥林多所见之事而受了羞辱，并且忧伤，正如他在 2:1 所言，因不得不用严厉手段压制那里盛行的混乱。他惟恐第三次探访也如那次令人痛苦的第二次探访一样。然而 <span style="color:#0000d4">πάλιν</span> 更明显、更自然的连接是与 <span style="color:#0000d4">ἐλθόντα</span> 相连，如我们的译本所示，意即"恐怕我再来的时候，神要叫我惭愧"。使徒们最大的喜乐，莫过于看见他们所牧养的众教会在信心上、在顺从真理上坚立不移；而最使他们痛心、最使他们羞愧的，莫过于自己的门徒偏离真理与圣洁之路。叫我<span style="color:#800000">*在你们面前*</span>惭愧；<span style="color:#0000d4">πρὸς ὑμᾶς</span>，即<span style="color:#800000">*在与你们的关系上*</span>。

<!-- PAGE 314 -->
<span style="color:#800000">*我必忧愁*</span>，<span style="color:#0000d4">πενθήσω</span>。此处 <span style="color:#0000d4">πενθέω</span> 一词作及物动词用，意为为某人哀哭、为某人悲伤。许多人认为，这里所说的忧伤是因不得不施行惩罚而生的；照此，其真意乃是："我恐怕必须惩戒（或革除）若干人"云云。但至少可以说，这样解释并非必要。经文与上下文所要求的，不过是保罗惧怕自己将不得不为教会中许多不悔改的肢体哀哭。<span style="color:#800000">*许多人从前犯罪，而竟不悔改*</span>，<span style="color:#0000d4">πολλοὺς τῶν</span> <span style="color:#0000d4">προημαρτηκότων καὶ μὴ μετανοησάντων</span>，<span style="color:#800000">*就是那些从前犯罪、到时仍未悔改的许多人。*</span> <span style="color:#0000d4">προημαρτηκότων</span> 中的 <span style="color:#0000d4">προ</span>，大概不宜过于强解，以致使该词专指在某一特定时间——如他们归信基督之时，或保罗前次探访之时——<span style="color:#800000">*以前*</span>犯罪的人。这个前缀的意思，用<span style="color:#800000">*向来*</span>一词已足以表达："那些向来犯罪的人。"保罗所惧怕的，是他到了哥林多，会发现许多犯罪的人并未一同悔改，而他先前却曾就悔改一事称赞过全会众。<span style="color:#800000">*为他们所犯的污秽*</span><span style="color:#800000">*等罪*</span>。按迈尔的看法，<span style="color:#0000d4">ἐπὶ τῃ ἀκαθαρσία</span>、<span style="color:#0000d4">κ</span>. <span style="color:#0000d4">τ</span>. <span style="color:#0000d4">λ</span>. 当与 <span style="color:#0000d4">πενθήσω</span> 相连："我要因那污秽等罪为许多人哀哭。"但词序显然有利于通常的读法："他们为所犯的污秽并不悔改。"哥林多最盛行的罪，一类是第20节所提及的，起于教会中不同阶层或党派之间的争竞；另一类即此处所举的，起于那时代与那社会的败坏。要在异教徒中间、并在异教环境之内建立一间圣洁的教会，除全能的膀臂以外，无人能成。而我们知道，无论是个人还是群体的成圣之工，即便是全能者也是渐次而行。初期的基督徒在基督里是婴孩，正如近世从异教中归信之人一样。
