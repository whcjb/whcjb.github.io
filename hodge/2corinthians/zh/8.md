<p class="title-block-h2" style="text-align:center; font-size:16px; font-weight:bold; margin:18px 0 12px;" markdown="1"><span style="color:#006411">第八章</span></p>

马其顿众教会非凡的慷慨，1-6节。

劝勉哥林多人效法马其顿弟兄的榜样，7-16 节。称许提多热心推动为贫穷圣徒募捐之事，并称许那与他同往哥林多的其余弟兄，17-24 节。

<p style="text-align:center" markdown="1">**劝勉慷慨周济穷人**</p>

使徒以本章及下一章专论此事。他先将马其顿众教会的慷慨陈明于哥林多人面前。他们身处大患难与极度贫穷之中，为圣徒所作的捐输却过了力量所能及的，1-3节。这并非出于勉强，也非因使徒的恳切请求而不得已；恰恰相反，乃是他们再三恳求使徒收纳并经手他们的捐项，4节。周济穷人不过是他们所行的一部分；他们更是将自己献与主，5节。马其顿人的这般行事，促使使徒劝勉提多：既然在哥林多已经开了这工，就当把它办理成全，6节。

因此，使徒恳求他们在其余各样恩典之上，再加上这一样，第7节。这是劝勉，不是命令。他之所以作此劝勉，一则因为别人在这事上显出了何等的热心，二则因为他愿他们证实自己爱心的真诚。他们为别人所能做的一切，与基督为他们所成就的相比，又算得什么呢？第8、9节。慷慨施舍于他们自己有益，只是他们心中的意念必须见于相应的行动，第10、11节。捐输所看重的是心志，不是数目的多寡，第12节。使徒所愿的，乃是众信徒之间可以略趋均平，使这人的富余可以补那人的不足，第13-15节。

<!-- PAGE 208 -->

他感谢神，因神使提多的心中生出这样的热忱来办理此事（16、17节）。他打发一位弟兄与提多同去；这位弟兄不但为众教会所称许，而且是被特意选派，与使徒一同经管这捐项的（18、19节）。保罗立定心意，要杜绝一切招人非议的机会，因此在经管所托付于他的银钱一事上，使别人与自己同负其责（20、21节）。除已提及的这几位之外，他又打发另一位弟兄同去；这位弟兄品格素为人所嘉许，且甚有热心（22节）。所以，若有人查问提多是谁，他们尽可回答：他是保罗的同伴与同工；若查问那几位弟兄是谁，他们尽可说：他们是众教会的使者，是基督的荣耀。所以，愿教会显明他们的爱心，也证实使徒为他们所夸的口（23、24节）。

<div class="commentary-anchor" id="2corinthians-8-1"></div>
**1.** <span style="color:#800000">*弟兄们，我把神赐给马其顿众教会的恩告诉你们。*</span>

<span style="color:#800000">*弟兄们*</span>（<span style="color:#0000d4">δέ</span>）一词标志着话题的转换。<span style="color:#800000">*我把……告诉你们*</span>（<span style="color:#0000d4">γνωρίζομεν</span>），意即"我们使你们知道"。to wit 一词（盎格鲁—撒克逊语作 <span style="color:#800000">*Witan*</span>，德语作 <span style="color:#800000">*Wissen*</span>），意为"知道"，连同同源的 <span style="color:#800000">*Wis*</span> 与 <span style="color:#800000">*Wot*</span>，如今几近废弃不用，虽然在我们的英译本中屡屡出现。<span style="color:#800000">*神的恩*</span>，即神的恩宠。哥林多人的慷慨乃是出于神恩典的运行。圣经作者始终承认这一事实：人最自由、最自发的行为，人内在的心境以及这些心境的外在表现，凡为善的，都出于神的灵那隐秘的、我们的意识所无从察觉的感动。信徒惟有在被神的恩典所决定之时，才是最真实地自我决定的。<span style="color:#800000">*所赐给*</span>（<span style="color:#0000d4">δεδομένην ἐν</span>），即"赐在……里面"，就是所赐的恩在其中。参 1:22："又赐圣灵在我们心里作凭据。"本章第 16 节中，<span style="color:#0000d4">διδόντι ἐν</span> 译作"<span style="color:#800000">*放在……里面*</span>"。<span style="color:#800000">*马其顿众教会*</span>。在罗马治下，马其顿包括希腊北部诸省的全境。使徒在该地区所建立的教会，就是腓立比、帖撒罗尼迦与庇哩亚的教会。关于这些教会非凡的慷慨，保罗的书信中屡有透露。参 11:9；腓立比书 2:25；4:15, 18。

**2.** <span style="color:#800000">*就是他们在患难中受大试炼的时候，仍有满足的快乐，在极穷之间还格外显出他们乐捐的厚恩。*</span>

<!-- PAGE 210 -->
这是一句略显浓缩的话。有人解为：在他们的患难之中，他们的喜乐格外洋溢；在他们的贫穷之中，他们的慷慨格外丰盛。但这样便牵出两种恩典——患难中的喜乐与贫穷中的慷慨——而上下文只需要一种。其意毋宁是：虽在患难之中，他们的喜乐与他们的贫穷却都丰丰足足地显在他们的慷慨上。经文的文法结构正要求如此。<span style="color:#800000">*就是说*</span>（<span style="color:#0000d4">ὅτι</span>）；此字与前一节的动词相连：“我把……告诉你们。”<span style="color:#800000">*在患难中受大试炼的时候*</span>，即在诸般患难之中，而这患难乃是极大的试炼（<span style="color:#0000d4">δοκιμή</span>），也就是对他们真诚与忠心的试验。这些患难或是他们与同城之人共同承受的、由其社会处境而来的苦难，或是他们身为基督徒所特有的、因逼迫而来的苦难。保罗写信给帖撒罗尼迦人时，提醒他们曾在大难之中领受了道。帖撒罗尼迦前书1:6；2:14；参使徒行传16:20；17:5。<span style="color:#800000">*他们满足的快乐*</span>；即由罪得赦免、蒙神喜悦而生的喜乐——在帖撒罗尼迦前书1:6中，他称之为圣灵所赐的喜乐——是丰丰满满的。就是说，这喜乐胜过了他们的忧伤，并在他们身上生出使徒随后所说的果效。<span style="color:#800000">*和极穷之间*</span>（<span style="color:#0000d4">ἡ κατὰ βάθους πτωχεία</span>），即赤贫，或深至极处的贫穷。<span style="color:#800000">*格外显出*</span>，即在与某事的关系上显为丰盛。同一个动词（<span style="color:#0000d4">ἐπερίσσευσεν</span>）同属前面“喜乐”与“贫穷”二名词，但意思略有不同。他们的喜乐显于慷慨，因为喜乐生出了慷慨；这果效证明其喜乐何等丰盛。他们的贫穷显于慷慨，因为相形之下，其贫穷显得何等深重；他们的慷慨反倒使他们的贫穷更显其甚。<span style="color:#800000">*厚厚的*</span>（<span style="color:#0000d4">πλοῦτος</span>）是保罗所爱用的字，他常以之表“丰盛”之意。罗马书2:4“他丰富的恩慈”，即极其丰盛的恩慈；以弗所书1:7“他丰富的恩典”，即他极丰盛的恩典；1:18“荣耀的丰盛”，即极大的荣耀，等等。<span style="color:#800000">*捐输*</span>，<span style="color:#0000d4">ἁπλότης</span>，此字本与二心、三心两意相对，故指心志专一、纯朴、诚实。以弗所书6:5；歌罗西书3:22。然而圣经常以类名代指某一特定之物，如以“荣耀”指智慧、怜悯或权能，因这些都是神的荣耀的不同形式。此处亦然，以表“正直存心”的通称，代指慷慨；慷慨正是这通称之德的一种具体形式或表现。参9:11；罗马书12:8。论到马其顿众教会的贫穷，司丹利先生在其本书注释中大略引用了阿诺德博士《罗马共和国》中的一段话，其中说：“奥古士督时代的希腊，处于荒凉困苦之中。它先后作了凯撒与庞培之战、三头与布鲁图和喀西约之战、末后又是奥古士督与安东尼之战的战场，受害极重。此外，这地自被罗马征服时所遭并随之而来的一连串长久苦难中，从未恢复过来；而在那些年代与庞培、凯撒的内战之间，当苏拉与米特拉达梯的将领争夺此地时，它又一次遭受了战争的一切祸患……。提比留在位时，马其顿与亚该亚两省呈请减轻其负担，当局认为它们委实堪怜，遂将其暂由元老院管辖之下转归皇帝管辖（因皇帝辖区赋税较轻）。”

**3-5.** <span style="color:#800000">*我可以证明，他们是按着力量，而且也过了力量，自己甘心乐意的捐助；再三的求我们，准他们在这供给圣徒的恩情上有分；并且他们所作的，不但照我们所想望的，更照神的旨意先把自己献给主，又归附了我们。*</span>

<!-- PAGE 211 -->
这几节经文因文法结构之故，必须合在一起来看。凡读英文译本者，若见斜体字频频出现，即可断定原文此处必有难解或晦涩之处，译者乃以增补字句加以解释。在这几节中，此类插入的字句竟不下五处；其中三处对文意大有影响，即 <span style="color:#800000">*they were*</span>、<span style="color:#800000">*take upon us*</span> 与 <span style="color:#800000">*this they did.*</span> 首要之事，是确定经文本身。<span style="color:#0000d4">δέξασθαι ἡμᾶς</span> 一语，在绝大多数抄本、古译本及教父著作中皆付阙如，看来颇像是解释性的旁注，或与我们译本中常见的斜体解释相类的插入语。故格里斯巴赫将其删去，自他以后的编订者也几乎一致如此。此语之有无，使文意大为不同。若保留此语，保罗便是说马其顿的基督徒恳求他收下他们的捐献，并由他负责分发。若删去此语，其意则为：他们恳求得蒙准许，可以捐输。然而，纵然承认此语当删，本段的结构仍属可疑。斯坦利说，这是"一个在使徒心思中穿行之际已被完全打碎的句子"。他提议以本革尔所用的同一方法来整理它；不过本革尔却认为，此句非但未被打碎，反而处处平顺自然。他说 <span style="color:#0000d4">έδωκαν</span> 一词支撑着全段的结构；<span style="color:#0000d4">αὐθαίρετοι</span> 与 <span style="color:#0000d4">δεόμενοι</span> 是其主格，<span style="color:#0000d4">χάριν</span>、<span style="color:#0000d4">κοινωνίαν</span> 与 <span style="color:#0000d4">ἑαυτοὺς</span> 是其宾语。如此，其意便是："他们乃是甘心乐意、过于力量、并多方恳求，不但把捐资献与圣徒，更将自己献与主，又献与我们。"然而，凡稍看希腊原文者都会觉得，使 <span style="color:#0000d4">χάριν</span> 依附于 <span style="color:#0000d4">έδωκαν</span> 甚不自然；它当属于 <span style="color:#0000d4">δεόμενοι</span>。因此，弗里切、比尔罗特、迈尔等人所取的结构，至少就这一点而言，更为可取。迈尔说，<span style="color:#0000d4">έδωκαν</span> 一词附有四个限定或修饰的分句：<span style="color:#800000">*他们捐输*</span>，一<span style="color:#800000">*、*</span>过于力量；二、出于自愿；三、恳求得蒙准许而捐；四、

并不像我们所指望的，乃是他们自己。德威特（De Wette）及其他许多人，为缓和这一句法的生硬（就末一分句而言），便将句子终于第四节，而在第 3 节中补入 <span style="color:#0000d4">έδωκαν</span>：“他们过了力量捐输，且是甘心乐意的，再三求我们准他们在供给圣徒的事上有分。而出乎我们所指望的，他们又将自己献给主。”

至于上下文的关联，<span style="color:#0000d4">ὅτι</span> 显然相当于 <span style="color:#0000d4">γάρ</span>，因为这几节是对第2节所言的证明。马其顿众教会的慷慨是极大的，<span style="color:#800000">*因为他们是按着力量*</span>（<span style="color:#0000d4">κατὰ δύναμιν</span>），即照着他们的能力，这是我可以作见证的，<span style="color:#800000">*并且过了力量*</span>（通行本作 <span style="color:#0000d4">ὑπὲρ</span>，校勘本作 <span style="color:#0000d4">παρὰ δύναμιν</span>）。此处隐含 <span style="color:#0000d4">έδωκαν</span> 一词，即"他们的捐输超过了自己的能力"；<span style="color:#0000d4">αὐθαίρετοι</span>，出于自愿，就是说，是自发的，并非出于我的任何提议或鼓动。由 9:2 可见，保罗曾向马其顿人夸奖亚该亚（那

<!-- PAGE 212 -->

林多人）一年前就已预备妥当，这消息激起了他们的热心。这两种说法完全一致。使徒在叙述福音在哥林多的成效时，自然会提到那里门徒的慷慨。正是这一事实的简单提及，使马其顿人未经使徒任何劝勉，乃是出于自愿，作了他此处所说的捐输。我们的译者插入 <span style="color:#800000">*they were*</span> 二字，改变了本节的意思，使使徒成了说："他们的心愿过于他们的力量。"然而他所说的乃是："他们自发地捐输，过于他们的力量。" <span style="color:#0000d4">έδωκαν</span> <span style="color:#800000">*他们捐输*</span> 一词虽直到这段末了才出现，但从开头起就已清楚含蕴其中。

<!-- PAGE 213 -->
<span style="color:#800000">*再三的求我们*</span>。按照通行的经文和我们的译本，马其顿人如此恳切所求的，乃是使徒收下他们的捐资，并担起分派之责。然而众家一致认为，<span style="color:#0000d4">δέξασθαι ἡμᾶς</span>（<span style="color:#800000">*我们收下*</span>）二字当予删去；至于所增补的<span style="color:#800000">*担起*</span>一语，希腊原文亦无相应之词。原文乃是 <span style="color:#0000d4">δεόμενοι ἡμῶν τὴν</span> <span style="color:#0000d4">χάριν καὶ τὴν κοινωνίαν</span>，<span style="color:#800000">*求我们准其得此恩惠与有分*</span>（或作分担），即得以有分之恩惠。后一词乃解释前一词：他们所求的恩惠，就是在<span style="color:#800000">*供给圣徒的事上*</span>有分。<span style="color:#0000d4">διακονία</span> 一词，<span style="color:#800000">*供职*</span>、<span style="color:#800000">*服事*</span>，常用作<span style="color:#800000">*帮助*</span>或<span style="color:#800000">*周济*</span>之意，见 9:1、13；使徒行传 6:1、11、29。有人以为句子至此为止。较通行的解释则以 <span style="color:#0000d4">καὶ οὐ καθὼς</span> <span style="color:#0000d4">ἠλπίσαμεν</span> 为主要意思的又一层转折，“并不像我们所指望的”，即不止于适度的捐输，<span style="color:#800000">*他们先把自己献给主，又照神的旨意归附了我们*</span>。这并非说他们先献上自己，然后才捐输财物；乃是说他们先将自己献给主，然后归与我们；<span style="color:#0000d4">πρῶτον</span> 系连于 <span style="color:#0000d4">κυρίῳ</span>，而非连于 <span style="color:#0000d4">έδωκαν</span>。<span style="color:#800000">*先*</span>字所指的不是时间之先，而是重要性与次序之先。可比照使徒行传 15:28；出埃及记 14:31。这奉献直接立时是归与基督的，其次才是归与使徒。使徒所谓将自己献给主，意思是他们不以捐出钱财为满足，更献上了自己，将其所有的一切、所是的一切，全然奉献于那神圣的主。这远超使徒的指望。若以此语为表明：对基督的献身乃是决定他们慷慨的动机，则与上下文不合。他们内心对基督的忠诚，本不足以令使徒惊讶；这原是他们承认福音时所当有的。超出他所指望的，乃是他们的慷慨竟不止于献上钱财，更献上了自己。有人说，这是指他们自愿前往哥林多或别处，为穷人募集捐款。然而如上所释，其意更为丰满，也更为简明。<span style="color:#800000">*照神的旨意*</span>。就是说，神的旨意乃是他们将自己献给主等等的缘由。原文是 <span style="color:#0000d4">διὰ θελήματος</span>，而非 <span style="color:#0000d4">κατὰ θέλημα</span>，故为<span style="color:#800000">*藉着*</span>神的旨意，而非<span style="color:#800000">*按照*</span>神的旨意。

<div class="commentary-anchor" id="2corinthians-8-6"></div>
**6.** <span style="color:#800000">*因此我们劝提多，*</span><span style="color:#800000">*既然在你们中间开办了这慈惠的事，*</span><span style="color:#800000">*就当把这事办成了。*</span>

<!-- PAGE 214 -->
以致（<span style="color:#0000d4">εἰς τὸ παρακαλ</span>.）我们受激励而劝提多。保罗在哥林多前书 16:1 曾催促哥林多人为贫穷的圣徒捐输。那封信写成之后，提多曾往哥林多去，把这事开了头。及至保罗来到马其顿，见那里众教会捐输何等慷慨，便催促提多再回哥林多，把他已经如此顺利开端的事办完。所以使徒此处所说对提多的劝勉，并非在他刚刚回来的那次访问之前所给的劝勉，乃是就他将要再作的一次访问而给的劝勉。因此与其译作<span style="color:#800000">*我劝了提多*</span>，不如译作<span style="color:#800000">*我已劝了他*</span>，意思更为明白。<span style="color:#800000">*叫*</span>（<span style="color:#0000d4">ἵνα</span>，此处不照该虚词通常的语力作<span style="color:#800000">*为要*</span>解，乃作<span style="color:#800000">*说*</span>解，表明所求之内容），<span style="color:#800000">*他既然开了头*</span>（<span style="color:#0000d4">προενήρξατο</span>，此字除本章外别处不见），<span style="color:#800000">*先前已经开始*</span>。这或指“已经开始了”，即在保罗写信之前已经开始；或指在马其顿人捐输之前已经开始。后一意思较为可取，因为从第 10 节看来，哥林多人在马其顿众教会举办此事之先，就已着手了。<span style="color:#800000">*就当办成这事*</span>，即或指把既定的工作作到底（希伯来书 9:6），或指使内在的恩德臻于完全（7:1）。<span style="color:#800000">*在你们中间*</span>，<span style="color:#0000d4">εἰς ὑμᾶς</span> 即“就你们而言”，或“为着你们”。参马太福音 10:10。<span style="color:#800000">*这慈惠的事*</span>；<span style="color:#0000d4">χάριν</span> 在此或指<span style="color:#800000">*善工*</span>，或按此字通常之义指<span style="color:#800000">*恩典*</span>。与下一节的关联，支持取后一意思。提多所受的劝勉，乃是要使哥林多人心中的这一情性得以充分发挥。此处所说的恩，与信心、知识、爱心同属一类。

7<span style="color:#800000">*．所以*</span>，<span style="color:#800000">*你们既然在凡事上（*</span><span style="color:#800000">*在）信心*</span>、<span style="color:#800000">*口才*</span>、<span style="color:#800000">*知识*</span>、<span style="color:#800000">*（并在）各样的热心*</span>、<span style="color:#800000">*（并在）待我们的爱心上都格外显出满足来*</span>，<span style="color:#800000">*（就当留意）在这慈惠的事上也格外显出满足来。*</span>

自本节起，直至第16节，使徒力劝哥林多人尽慷慨捐输之责。其理由如下：一、因为这对于他们基督徒品格的完全与均衡乃属必需；二、因为这可证明他们的真诚；三、因为基督曾为他们的缘故成了贫穷；四、因为这于他们自己有益，既然已显出这样的心志，前后一致就要求他们将之付诸行动；五、因为对他们所提的要求全然合乎情理。所求于他们的，不过是按其力量而捐；而今日呼召他们为别人所行的，他日别人在同样境况中也当为他们而行。<span style="color:#800000">*所以*</span>并非 <span style="color:#0000d4">ἀλλά</span> <span style="color:#800000">*(但)*</span> 的确切译法。此字常用以标明转入新的题目，尤其是当下文为劝勉或命令之时。参马可福音16:7；使徒行传9:6, 10, 20。<span style="color:#800000">*你们既然充足*</span>，即富有，或说，比别人有得更多，即出众。<span style="color:#800000">*在诸事上*</span>（<span style="color:#0000d4">ἐν παντί</span>），其范围自然受上下文所限，并由下文"各样的恩赐与美德"加以解释。哥林多前书1:5, 7亦为哥林多人作了同样的称许。使徒有时如此嘉许、有时又如此责备哥林多教会，其缘由在于：那里有些人极其良善（大概是多数），而另有些人，尤其在教师中间，则大为相反。<span style="color:#800000">*信心*</span>。在信心上充足，就是有坚强、恒久、发生功效的信心，托住并管理其内外全部的生活。<span style="color:#800000">*口才、知识*</span>（<span style="color:#0000d4">λόγῳ καὶ γνώσει</span><span style="color:#0000d4">）</span>，与哥林多前书1:5中的组合相同。此处与彼处，我们的译者皆将 <span style="color:#0000d4">λόγος</span> 译作<span style="color:#800000">*口才*</span>；在这两处，此字皆可解作<span style="color:#800000">*道理*</span>，正如它在许多经文中的用法，尤以"真理的道"、"救恩的道"、"仁义的道"、"基督的道"这类说法为然。

<!-- PAGE 215 -->

所以，其意或是说他们在言语与知识的恩赐上富足，或是说他们在教义与知识上富足。<span style="color:#0000d4">Λόγος</span> 指所传讲的基督教真理，<span style="color:#0000d4">γνῶσις</span> 则指所领受、所明白的这真理。<span style="color:#800000">*在殷勤上*</span>（<span style="color:#0000d4">σπουδή</span>），即<span style="color:#800000">*热切*</span>，是一个总称，指他们属灵生命的活力与朝气，而爱心即为其表现之一。<span style="color:#800000">*在你们待我们的爱心上。*</span>希腊文的说法颇为特别：<span style="color:#0000d4">τῃ</span> <span style="color:#0000d4">ἐξ ὑμῶν ἐν ἡμῖν ἀγάπῃ</span>，<span style="color:#800000">*那出于你们而在我们里面的爱*</span>，即你们（对我们）的爱，是我们珍藏于心中的；也就是说，是我们所极其看重的。或者简单地作：<span style="color:#800000">*amore a vobis profecto et in me collato。使你们也格外显出。*</span><span style="color:#0000d4">ἵνα περισσ</span> 最自然的解释，是像英译本那样补上一词：<span style="color:#800000">*当留意*</span>你们要格外显出。可比较加拉太书 2:10。<span style="color:#800000">*在这恩惠上也*</span>，即施舍慷慨之恩。另有人在此处如同前一节一样，将 <span style="color:#0000d4">χάρις</span> 解作<span style="color:#800000">*善工*</span>。但这与上下文不甚相合。信心、知识与爱心与其说是善工，不如说是神所赐的恩赐，慷慨施舍亦然。

8<span style="color:#800000">*. 我说这话，不是吩咐你们，*</span><span style="color:#800000">*乃是藉着别人的热心，*</span><span style="color:#800000">*要试验你们爱心的真诚。*</span>

<!-- PAGE 216 -->
使徒依其一贯的笔法，先从反面、后从正面说明他方才所言的用意。这并非命令的性质。他所求的不是顺服，乃是甘心乐意的慷慨。慷慨可以藉着陈明适当的动机来激发，却不能凭权柄强索而得。若施舍是出于遵命，或是为叫良心得安，便算不得慷慨之举。凡非甘心而出者，即非慷慨。故此，保罗不肯用命令勉强他们。他的用意，乃是要试验他们的爱心是否真实。至于试验的方式，则由马其顿众人的热心提示出来。他正是借着别人踊跃乐捐这一时机，将他们的爱心付诸这般试炼。凡内心的情感，其真伪的实在凭据，与其说在于该情感在我们意识中所显出的性质，毋宁说在于它所引出的行为。许多人若单凭自己的感受来判断自己，必以为自己确是满有怜悯之心；然而若照其行为来判断，所得的结论则适相反。同样，许多人自以为爱神，因为他们意识到某种情感，便以“爱神”这尊名相称；然而他们并不顺服神。可见无论论己论人，我们都必须凭情感所结的果子，来判断其真伪。

<div class="commentary-anchor" id="2corinthians-8-9"></div>
**9.** <span style="color:#800000">*你们知道我们主耶稣基督的恩典*</span>，<span style="color:#800000">*他本来富足*</span>，<span style="color:#800000">*却为你们成了贫穷*</span>，<span style="color:#800000">*叫你们因他的贫穷，可以成为富足。*</span>

<!-- PAGE 217 -->
本节是一段插入语，第8节所起的句子在第10节接续。然而本节与前一节的关联仍是紧密而直接的。本节所指明、所意图的有两件事：其一，自我牺牲乃是爱的确切试验；其二，基督的榜样以及我们对他所负的义务，当引我们行善于人。使徒显然是将这两个思想合而言之。他说：‘我愿以自我牺牲来试验你们的爱，<span style="color:#800000">*因为*</span>你们知道基督的爱正是这样显明的；’又说：‘既然基督“为你们舍了自己”，理当期望你们也为别人牺牲自己。’此处所举出供我们效法的，不单是基督的榜样；我们从他领受了无限的福分，对他当有的感恩之心，也被提出来作为乐捐的动机。<span style="color:#800000">*因为你们知道*</span>。所提及的这一事实，包含福音至高的奥秘，即神子的道成肉身，或神在肉身显现，以及其中所显明的爱；使徒假定凡自称为基督徒的人都已知晓并承认此事。保罗说，你们知道——正如凡基督徒都必知道的——<span style="color:#800000">*我们主耶稣基督的恩*</span>，即他那不凭功德、自发的爱。这里所用的称号，是最亲切与最尊崇者的合称。<span style="color:#800000">*我们的主*</span>，即那至高绝对的主宰，我们承认他是我们正当的君王与主人；他又是<span style="color:#800000">*我们的*</span>，属于我们，因为他以其爱，将其全能的看顾、保护与扶持应许给了我们。<span style="color:#800000">*耶稣基督*</span>。那位作我们之主的，也是我们的救主，是基督，是神所膏立的，蒙神授以至高的统治权。凡按其神性本应归于道（Logos）的，圣经总是表述为赐予了神人二性者（Theanthropos）。参见希伯来书 1:2。<span style="color:#800000">*他本来*</span>如何等语。此句是对前句的解释。‘你们知道我们主耶稣的恩’，就是说，‘你们知道他本来富足’云云。这恩就在于、或藉着他为我们的缘故成了贫穷而显明。<span style="color:#800000">*本来富足*</span>，<span style="color:#0000d4">πλούσιος ων</span>，其义或如我们的译本所作，<span style="color:#800000">*他本来富足*</span>，即拥有创世以前与父同享的荣耀（约翰福音 17:5）；或作<span style="color:#800000">*本来富足*</span>，即实际且恒常拥有一切神性的特权。若取后一解，其意乃是：我们所称颂的主在世之时，虽然他自身有神本性一切的丰盛，并有对万有的占有之权与能力，却仍是贫穷的。他不曾运用其权能使自己富足，反而甘愿承受贫穷的一切匮乏。前一种解释乃是通常且合宜地被采纳的。<span style="color:#0000d4">ἐπτώχευσε</span>，<span style="color:#800000">*他成了贫穷*</span>，所指的并非我们的主在世时所行的事，而是他降世之时所行的事。此处与腓立比书 2:6 平行：“他本有神的形像，与神同等，却虚己（<span style="color:#0000d4">ἐκένωσε</span>）。”就是说，他将其神性尊荣的荣耀搁置到如此程度，以致在众人眼中他全然是一个人，甚至是一个仆人，以致人们不肯承认他是神，反倒藐视他、迫害他，末后又把他当作一个人钉在十字架上。那在一切神性属性与特权的丰盛中本为富足的，就这样成了贫穷，<span style="color:#0000d4">δἰ ὑμᾶς</span>，<span style="color:#800000">*为你们的缘故*</span>，出于对你们的爱。神子这样自卑所要成就的目的，乃是<span style="color:#800000">*叫你们因他的贫穷可以成为富足*</span>。信徒得以在基督所搁置或所隐藏的那荣耀上成为富足。他们得与神的性情有分（彼得后书 1:4），即有分于神的圣洁、尊荣与福乐。这之所以为神性的，不单因其源头出于神，也因其性质如此。所以我们的主说：“你所赐给我的荣耀，我已赐给他们”（约翰福音 17:22）。因此圣经说信徒与基督同得荣耀，与他一同作王（罗马书 8:17）。他百姓这尊荣与永远福乐的代价，乃是他自己的贫穷。我们成为富足，是藉着他的贫穷。他若不曾承受道成肉身与受死的一切屈辱，我们就必永远贫穷，在一切圣洁、福乐与荣耀上一无所有。当注意的是，诸如周济穷人一类的道德本分，在新约中所依据的理由，与其说是道德的，不如说是基督教所独有的。人若不因此甘心为别人牺牲自己，便不能领会本节的意义，也不能感受其中的力量。使徒在此所教导的，也正是使徒约翰所教导的（约翰一书 3:17）：人若不爱弟兄，不慷慨周济他们的缺乏，则他自称或自以为爱基督，尽属虚妄。

<!-- PAGE 218 -->

10<span style="color:#800000">*. 我在这事上把我的意见告诉你们，因为这与你们有益，*</span>，<span style="color:#800000">*你们既是先前就已开始的，*</span>，<span style="color:#800000">*不但去办这事，*</span>，<span style="color:#800000">*而且一年前就已甘心乐意了。*</span>

此处的连接是与第8节相接。‘我不是命令，我在这件事上，即在为穷人募捐这件事上，只发表我的意见；’<span style="color:#0000d4">γνώμην</span> 此处取“意见”之义。参照哥林多前书 7:6。<span style="color:#800000">*因为这于你们是有益的。*</span>这句话可有两种解释。‘我劝你们办理这捐项，因为这样周济穷人于你们有益。这不但促进你们自己德行的长进，也是前后一贯所要求的。既已开始这工，半途而废反于你们自己有损。’这是通行的解释，总体而言也是较可取的。它满足上下文的一切要求；并且使 <span style="color:#0000d4">ἐν πούτῳ</span> 与 <span style="color:#0000d4">τοῦτο</span> 指向同一件事。‘在这件事（捐输）上我发表我的意见，因为这（捐输）于你们有益。’迈尔、比尔罗特及其他许多人则以 <span style="color:#0000d4">τοῦτο</span> 指紧接在前的话。‘我发表我的劝告，因为就你们的情形而言，劝告胜过命令，既然你们一年前就已乐意去行。’然而上下文并不要求如此解释，且使文意降格。前一种解释所揭示的真理，高于后一种。行善原是为我们自己的益处。<span style="color:#800000">*就是*</span>，<span style="color:#0000d4">οἵτινες</span>，（作为这样的人。）‘这于你们有益，<span style="color:#800000">*因为你们一年前不但先开始去行*</span>（<span style="color:#0000d4">τὸ</span> <span style="color:#0000d4">ποιῆσαι</span>），<span style="color:#800000">*而且先有此心愿*</span>（<span style="color:#0000d4">τὸ θέλειν</span><span style="color:#0000d4">）</span><span style="color:#800000">*。*</span>因意愿先于行为，许多注释家便假定这里的次序倒置，遂将二者对调：‘你们不但开始有意愿，而且开始去行。’这是武断且不必要的。另有人如英译本的译者，将 <span style="color:#0000d4">θέλειν</span> 取一种强调的意思，即热心去行。路加福音 20:46；约翰福音 8:44。‘你们不但开始去行，而且开始热心去行。’然而这与下一节不合，那里 <span style="color:#0000d4">θέλειν</span> 是按通常的意思使用的。又有人以 <span style="color:#0000d4">ποιῆσαι</span> 指工作的开始，以 <span style="color:#0000d4">θέλειν</span> 指要行得更多的心愿。但这需要补上许多经文中并没有的意思。何况这与“一年前”这限定语不合。按此解释，<span style="color:#0000d4">θέλειν</span> 所表达的并非一年前所发生的事，而是如今被假定存在的、在一年前开始的行动之后才有的心态。德威特、温纳与迈尔所给的解释要自然得多。<span style="color:#0000d4">προενήρξασθε</span> 一词，如第6节一样，是指马其顿众教会而言。‘你们不但在这工上，也在这心愿上，先于马其顿人。’就是说，在他们尚未开始为穷苦的圣徒募捐之先，你们已经开始了；<!-- PAGE 219 -->在他们尚未想到此事之先，你们已经定意去行。‘你们既这样走在他们前头，如今若把工作半途而废，便于你们有损，因为单单提说你们的心愿（9:2），就已激动他们如此舍己慷慨地捐输了。’<span style="color:#800000">*一年前*</span><span style="color:#0000d4">（</span><span style="color:#0000d4">ἀπὸ πέρυσι</span>。）这并不表示中间已隔了整整一年，乃是与我们通俗所说的<span style="color:#800000">*去年*</span>相类。若保罗按犹太人的算法以十月为岁首，那么他在十一月写信时，提到春天发生的事，自然会说是去年发生的。据此看来，保罗前后两封哥林多书信的日期之间，从春到秋，相隔不过六个多月。

<div class="commentary-anchor" id="2corinthians-8-11"></div>
**11.** <span style="color:#800000">*如今就当办成这事；既有愿作的心，也当照你们所有的去办成。*</span>

<span style="color:#800000">*如今就当办成这事*</span>，意即：既已有此心愿，且已开工，就当把这工作完成。原文直译为：<span style="color:#800000">*你们也当把所行的办成*</span>。<span style="color:#800000">*叫*</span>（<span style="color:#0000d4">ὁπως</span>，为要）<span style="color:#800000">*你们随着乐意的心去办成，正如你们当初乐意的心一样*</span>。前后一致的要求是：他们既已公开表明的美意，就当付诸实行。<span style="color:#800000">*就当照你们所有的去办成*</span>，<span style="color:#0000d4">ἐκ τοῦ έχειν</span>，即按照（你们的）产业。此处介词 <span style="color:#0000d4">ἐκ</span> 不当译作<span style="color:#800000">*从……中出*</span>，而是表明衡量的准则或标准。可比较约翰福音 3:34。使徒无意勉强他们，既不越过他们的心愿，也不越过他们的能力。他们所捐的，使徒愿他们甘心乐意地捐，并且顾及自己的财力。

<div class="commentary-anchor" id="2corinthians-8-12"></div>
**12.** <span style="color:#800000">*因为人若有愿做的心，必蒙悦纳，乃是照他所有的，并不是照他所无的。*</span>

此处的关联显然是与第 11 节末尾的话相承。他们当按自己的家业量力而捐，因为在神面前衡量的标准乃是心志，而非所捐的数目。我们的主也教导了同样的道理，见马可福音 12:42。<span style="color:#800000">*人若有愿做的心*</span>，按字面直译为<span style="color:#800000">*若有此心存在*</span>；<span style="color:#0000d4">πρόκειται</span> 的意思并非 <span style="color:#800000">*prius adest*</span>（先有），而不过是 <span style="color:#800000">*adest*（存有）。愿做的心*</span>，<span style="color:#0000d4">ἡ προθυμία</span>，即<span style="color:#800000">*那甘心乐意*</span>，或曰<span style="color:#800000">*心志。这心*</span>；就是说，那 <span style="color:#0000d4">προθυμία</span>（心志）<span style="color:#800000">*就蒙悦纳*</span>，<span style="color:#0000d4">εὐπρόσδεκτος</span>，意即<span style="color:#800000">*可蒙悦纳的*</span>。此字常用以指献与神的供物，如罗马书 15:16；彼得前书 2:5。古时有些

<!-- PAGE 220 -->

有抄本在动词 <span style="color:#0000d4">έχῃ</span> 与 <span style="color:#0000d4">έχει</span> 之前加入不定代词 <span style="color:#0000d4">τὶς</span> 作主语，故我们的译者也补入 <span style="color:#800000">*人*</span> 字，作‘乃是照<span style="color:#800000">*人*</span>所有的，并不是照<span style="color:#800000">*他*</span>所无的’。然而本节中一切动词的文法主语，实为 <span style="color:#0000d4">προθυμία</span>（乐意的心）；保罗照其惯例将其拟人化，故说：蒙悦纳乃是<span style="color:#800000">*照着它所可能有的*</span>（<span style="color:#0000d4">εαν έχῃ</span>），或多或少皆然；<span style="color:#800000">*并不是照着它所没有的*</span>。这并非说，当那心志超乎其捐输之力，或以致捐输过度时，便不蒙悦纳。此说或许不错，却非此处所要表达之意。其意不过是：神所看重的乃是心志，而这心志要按其所能支配的资财来衡量。在此人，微小的捐项所显出的乐捐之心，或远胜于彼人大得多的馈赠。

<div class="commentary-anchor" id="2corinthians-8-13"></div>
**13.** <span style="color:#800000">*我原不是要别人轻省，你们受累，*</span>

使徒不愿他们的捐输超过自己的力量，其缘由在此先从反面说明；正面的说明则见于下一节。使徒无意将不均之重担压在哥林多人身上。他并不愿别人尽都免去捐输的责任，而独让哥林多人为此所困。他以简练之语说：不是叫别人 <span style="color:#0000d4">άνεσις</span>（轻省），而叫你们 <span style="color:#0000d4">θλῖψις</span>（受累）。按此解法，<span style="color:#0000d4">άλλοις</span>，即<span style="color:#800000">*别人*</span>，当指别的教会或别的基督徒；而 <span style="color:#0000d4">άνεσις</span> 则指免去捐输之责。但这样解释，与上文下文皆不相合。使徒所求的均平，并非各教会在捐输上的均平，乃是由这一等人的缺乏得那一等人的富余补足而生的均平。因此，<span style="color:#800000">*别人*</span>当指贫穷之人，在此即耶路撒冷的贫穷圣徒；<span style="color:#0000d4">άνεσις</span> 当指从贫穷的压迫中<span style="color:#800000">*得释*</span>，<span style="color:#0000d4">θλῖψις</span> 则指困乏的重担。故其意乃是：保罗不愿哥林多人捐输超过自己的力量，因他并不愿别人富足，而他们反倒穷乏。富足的人并没有使自己变为贫穷、好叫贫穷的人富足的义务。这不是这里的准则。

<div class="commentary-anchor" id="2corinthians-8-14"></div>
**14.** <span style="color:#800000">*乃要均平*</span>，<span style="color:#800000">*就是要用你们现今的富余，补他们的不足*</span>，<span style="color:#800000">*使他们的富余，将来也可以补你们的不足，这就均平了*</span>。

<!-- PAGE 221 -->

<span style="color:#0000d4">ἰσότης</span> 一词在此既非指互惠，亦非指公平，而是指均平，正如第15节的例证所显明的。此处的 <span style="color:#0000d4">ἐκ</span>，与第11节（<span style="color:#0000d4">ἐκ τοῦ έχειν</span>）相同，表明施与所依的准则或标准。这准则就是均平；我们的捐输当以造成均平、使均平得以实现为度。这并非均产主义，也不是财物公有。新约在此题目上的教训是：<span class="enum-num">1.</span> 一切施与皆出于自愿。人的产业是他自己的，存留或散去，权柄在他自己手中；若他要施与，多寡亦由他自己定夺。使徒行传 5:4。这正是本段上下文所教导的道理。捐输必须出于甘心，乃是爱的果子。就道德本分而言，它固然是当尽的义务，不肯施与便是心中没有神的爱的凭据（约翰一书 3:17）。然而这类本分，别人却不能当作自己应得的权利来强索，仍须由我们自行斟酌。<span class="enum-num">2.</span>

施舍所要成就的目的，乃是救济穷人的缺乏。因此，所要达到的均平，并非财产数额上的均平，乃是同得纾解、脱离穷乏之苦。本节余下的话正教导此意。使徒说：‘在现今的时候’，要叫你们的富余补（<span style="color:#0000d4">γένηται εἰς</span>，及于、分与，加拉太书 3:14）他们的不足，好使他们的富余将来也补你们的不足，这就均平了；也就是说，同样得着纾解，脱离穷乏困苦。<span class="enum-num">3.</span> 关于此事的第三条圣经原则是：虽然世人皆为弟兄，凡贫穷之人，无论是否基督徒，都当是施舍的对象，然而基督的肢体对救济同信之人的缺乏，却负有特别的责任。使徒说，我们要向众人行善，向信徒一家的人更当这样。加拉太书 6:10。本章和下一章中的一切嘱咐，都是论到基督徒对同信之人的本分。其中有两个缘由。其一，信徒同为基督身上的肢体，与基督有共同的关系，故向他们所行的，就是向基督所行的；因此他们彼此之间也有亲密的关系，因为在基督耶稣里同为一身。其二，可以确知，向他们所行的善乃是纯粹的善。不必担心所施的赒济会助长懒惰或恶行。

<!-- PAGE 222 -->

<span class="enum-num">4.</span> 第四条准则，意在防止有人滥用基督徒之间的弟兄情谊。穷人并无权利因着弟兄的名分，就倚赖富人的周济度日。这位使徒也曾说：“若有人不肯作工，就不可吃饭”（帖撒罗尼迦后书 3:10）。圣经如此行，一面承认私有财产之权，并使一切施舍出于自愿，从而避免了均产共有之制所带来的不公与破坏；另一面又谆谆教导信徒普世的弟兄情谊，以及各人当从自己的富余中捐输、以周济穷人缺乏的本分，从而避免了对穷人漠然无情。与此同时，圣经也教导穷人当尽其所能自食其力。他们受命要“安静作工，吃自己的饭”。倘若这些原则果真得以施行，基督徒中间就既无懒惰，也无匮乏了。

<div class="commentary-anchor" id="2corinthians-8-15"></div>
**15.** <span style="color:#800000">*如经上所记：*</span><span style="color:#800000">*“多收的也没有余，少收的也没有缺。”*</span>

出埃及记 16:18 所教导的道德功课，正是使徒方才所劝勉的。那里记载：百姓遵神的吩咐收取吗哪，各人按自己的食量收取。多收的并未多留，只存所分定的分量；少收的，其所得亦增至那既定的标准。就必需的食物而言，众人是均等的。倘若有人企图积存自己的分量，那分量便在他手中坏了。故此，出埃及记与保罗所教导的功课乃是：在神的子民中间，一人的富余当用以补别人的不足；凡图谋违逆此律的，终必蒙羞受损。财物如同吗哪，是经不起囤积的。

<div class="commentary-anchor" id="2corinthians-8-16"></div>
**16.** <span style="color:#800000">*感谢神，*</span><span style="color:#800000">*祂把这同样恳切的心赐给提多，叫他这样挂念你们。*</span>

<!-- PAGE 223 -->
从本节直到本章结束，使徒将提多以及那两位要陪同他返回哥林多的弟兄，荐与哥林多人，求他们以信任相待。提多首次前往，是为要查明该教会的光景，尤其是保罗前一封书信所生的果效。而此次差遣的目的，则是要促成那早已在哥林多人考虑之中、却迟迟未了的赒济穷人的捐项。提多在此事上的热心不亚于保罗，故此使徒感谢神，<span style="color:#800000">*他把这样恳切的心赐给提多*</span>；<span style="color:#0000d4">τῷ διδόντι έν</span>，“感谢神，他把这心放在提多心里，即赐下这心，使之存于提多心中。”<span style="color:#800000">*为你们同样的殷勤*</span>；<span style="color:#0000d4">τὴν αὐτὴν σπουδὴν</span>，同样的热心，即与我为你们所存的热心相同。提多对哥林多人属灵的益处怀着同样的关切，也同样切望他们行事前后一致——这正是保罗在前面几节中所热切表达的。每逢有机会，仍当留意一件事：圣经何等一贯地视两大根本真理为不言而喻，而人的哲学却难以领会、难以承认。其一是：神能够并且确实掌管人内心的行动与情感，却丝毫不干涉人的自由与责任。提多的热心乃是他自己心中自发的流露，是他品格的标志与要素。然而，这热心却是神放在他心里的。这并非修辞上的说法，而是一个朴实而严肃的真理，是向神郑重献上感谢的根据。另一大真理是：信徒属灵生命的存续与运行，全然仰赖于神。圣灵并非只在灵魂里栽下一个新的生命原则，便撇下这原则，任凭它凭自己的力量挣扎求存、力求长进。恰恰相反，重生乃是神常住人心的开端，因此这新生命的存续与运行，皆出于他的同在。然而这神圣的感化又是何等相契相合，以致神在我们里面的生命，在最高的意义上，正是我们自己的生命。

<div class="commentary-anchor" id="2corinthians-8-17"></div>
**17.** <span style="color:#800000">*他固然接受了劝勉；但他自己更加热心*</span>，<span style="color:#800000">*情愿往你们那里去*</span>。

<!-- PAGE 224 -->
这正是提多热心的明证。有些注释家认为，此处的 <span style="color:#0000d4">μέν</span> 与 <span style="color:#0000d4">δέ</span> 是用来代替 <span style="color:#0000d4">οὐ μόνον</span> — <span style="color:#0000d4">ἀλλά</span> 的，意即：“他不但听从了我们的劝勉，更以极大的热心去成全此事，甘心乐意地前往。”然而迈尔的解释更佳：“他固然领受了我们的劝勉，就是说，他谦卑地顺服我的指示；但他既是格外热心（<span style="color:#0000d4">σπουδαιότερος</span>），无须人劝，便自己甘心前往了。”他不必人催促就动身前去，虽然在这事上，如同在别的事上一样，他也乐意照我的心愿而行。<span style="color:#800000">*他就往你们那里去*</span>。提多无疑是这封书信的带信人，书写此信时他正与使徒同在，尚未启程。按书信体的笔法，写信的人可以采用适合自己当下处境的时态，也可采用适合读者处境的时态。保罗在此处以及下文数节中用了过去时，因为当这封信送到收信人手中时，所提及的事已成过去。

<div class="commentary-anchor" id="2corinthians-8-18"></div>
**18.** <span style="color:#800000">*我们还打发了那位弟兄与他同去，*</span><span style="color:#800000">*这人在福音上得了众教会的称赞。*</span>

<span style="color:#800000">*我已打发*</span>。所用时态仍如前，是从读者的角度而言。<span style="color:#800000">*同他打发那位兄弟去*</span>。既未提名，又无任何线索可据以断定此处所说的兄弟是谁，臆测便属徒然。此人是提多的助手，作同伴与他同去，在众教会中素有令名，尤其得马其顿众信徒的信任（19节）。然而这些条件在《使徒行传》与保罗书信所提及的许多人身上都可相合，故不能得出确定的结论。因此，究竟是路加、马可、特罗非摩，抑或另有其人，只能存而不论。注释家们在此事上所费的心力，实在与其价值不相称。经上说这位兄弟所得的称赞是<span style="color:#800000">*在福音上*</span>。他因在这一领域的努力而著称，即因其热心与劳苦推广福音而著称。<span style="color:#800000">*传遍了众教会*</span>。纵然将"众教会"限于马其顿的众教会，这仍足以证明所论及的这位兄弟特别配得哥林多人的信任。

<div class="commentary-anchor" id="2corinthians-8-19"></div>
**19.** <span style="color:#800000">*不但这样*</span>，<span style="color:#800000">*他也被众教会挑选，与我们同行，办理这慈惠的事*</span>，<span style="color:#800000">*这事由我们经手办理，是为荣耀主*</span>，<span style="color:#800000">*又（表明）你们乐意的心。*</span>

<!-- PAGE 225 -->
这位弟兄配得信任，可以放心地将哥林多人的捐资交托于他，不单因他素有美名，也因他正是为此被选出的——要与保罗一同经管为圣徒所收的捐项。<span style="color:#800000">*被选*</span>，<span style="color:#0000d4">χειροτονηθεὶς</span>，字面意思是举手而选，故为众人公举。然而此字常泛指拣选或委派，并不特指方式。故约瑟夫论到王时，说他是<span style="color:#0000d4">ὑπὸ τοῦ θεοῦ κεχειροτονημένος</span>。《犹太古史》6:4.2。参韦茨坦。<span style="color:#800000">*众教会*</span>所选，大概是马其顿的众教会。<span style="color:#800000">*和我们同行*</span>，<span style="color:#0000d4">συνέκδημος ἡμῶν</span>，即被选为我们同行的伴侣。使徒行传 19:29。<span style="color:#800000">*办这慈惠的事*</span>。<span style="color:#0000d4">χάρις</span> 一字或指心中的意向，或指此意向的表达与显明，即或指仁慈之心，或指一件仁慈之举。故凡白白赐予之物皆可称为恩惠。此处所指的乃是为穷人所收的捐款。<span style="color:#800000">*这就是我们所经管的*</span>，即我们乃是这捐项的经手人。保罗曾承担将外邦信徒的捐助分派给耶路撒冷弟兄的职任，而所提到的这位弟兄被选出，要与他同行，在这事奉或职分上协助他。<span style="color:#800000">*要荣耀这位主*</span>，即荣耀我们共同的主。此句照其自然的结构，当与紧接其前之语相连：“这捐项由我们经管，为要荣耀主。”惟一的异议是：如此则须使介词 <span style="color:#0000d4">πρός</span> 在同一句中表达不同的关系。“经管此事，<span style="color:#0000d4">πρὸς</span> <span style="color:#0000d4">δόξαν καὶ προθυμίαν ὑμῶν</span><span style="color:#0000d4">(</span>或作 <span style="color:#0000d4">ἡμῶν</span><span style="color:#0000d4">)</span>，即为促进主的荣耀，并证明你们的乐意。”故迈尔等人将此句系于 <span style="color:#0000d4">χειροτονηθείς</span>：“被选出，为要藉他的协助使基督得荣耀，并使我（<span style="color:#0000d4">ἡμῶν</span>）在福音上劳苦的热心不为此等挂虑所累，得以放手施展。”但这样解释颇不自然，且须补入过多字句方能成义。若保留通行经文所作的 <span style="color:#0000d4">ὑμῶν</span>，则文义明白，正如我们译本所表达的：“这捐项的经管，是为显明基督的荣耀，并显明你们（在捐输上）的乐意与踊跃。”然而最古的抄本以及古译本均作 <span style="color:#0000d4">ἡμῶν</span>，几乎所有近代编者都采此读法。如此，其义便是：这捐项既促进了基督的荣耀，也证明了使徒servir穷人的甘心乐意。

<div class="commentary-anchor" id="2corinthians-8-20"></div>
**20.** <span style="color:#800000">*我们防备这事*</span>，<span style="color:#800000">*免得有人因我们所经管的这许多捐项，就挑我们的不是。*</span>

<!-- PAGE 226 -->
分词 <span style="color:#0000d4">στελλόμενοι</span> 系承接第18节的动词 <span style="color:#0000d4">συνεπέμψαμεν</span> 而来。意即：“我们打发那位弟兄与提多同去，是要避免此事”；也就是说，为要避免。然而，保罗为防人误解所定意而行的，不仅是指派一位弟兄与提多同行，更是指定这位弟兄参与分派众教会的捐资。所以，此处所指的乃是前面整句话。<span style="color:#0000d4">στέλλειν</span> 一词，字面意为安置，也有整顿、预备之意，有些人在此即取此义，作“为此预备、为此留意”解。此词又有收回、收缩之意，由此引申为避免；这一意思最合此处的文义，也最合帖撒罗尼迦后书 3:6，那里也用了此词。<span style="color:#800000">*免得有人挑我们的不是。*</span>他定意不给任何人留下质疑其正直的机会。<span style="color:#800000">*在我们所经管的这许多捐资上；*</span>就是说，在处置托付于他手中的大笔银钱上。<span style="color:#0000d4">ἁδρότης</span> 一词意为成熟、丰盛，进而指丰裕；其具体所指自然由上下文决定。

<div class="commentary-anchor" id="2corinthians-8-21"></div>
**21.** <span style="color:#800000">*我们留心行光明的事，*</span><span style="color:#800000">*不但在主面前，*</span><span style="color:#800000">*就在人面前也是这样。*</span>

这里说明了方才所提防范之举的缘由。使徒以为，行事正直尚且不够，他深知在人前显为正直同样要紧。若因骄妄而藐视众人的观感，实属愚妄。我们行事为人，当使那鉴察人心、洞悉万事的神认可我们的品行，也当使世人不得不承认我们的诚实。使徒在此所宣告的，乃是支配他一生的普遍原则。<span style="color:#0000d4">Προνοούμενος</span>：<span style="color:#800000">*为自己一方预先筹划。*</span>使徒说，他预先留意，使神与人都看见他是诚实的。可比照罗马书 12:17，以及七十士译本的箴言 3:4。

<div class="commentary-anchor" id="2corinthians-8-22"></div>
**22.** <span style="color:#800000">*我们又打发一位弟兄与他们同去*</span>，<span style="color:#800000">*这人的殷勤，我们在许多事上屡次试验过*</span>，<span style="color:#800000">*但如今因他深信你们，就更加殷勤了*</span>。

<!-- PAGE 227 -->
保罗打发这位弟兄与提多及其同行者一同前去，此人究竟是谁，已无从考定。使徒既已察验他为 <span style="color:#0000d4">σπουδαῖον</span>，即热心或殷勤的，<span style="color:#0000d4">ἐν πολλοῖς πολλάκις</span>，在许多事上屡次如此。<span style="color:#800000">*但如今*</span>，即在此事上，<span style="color:#800000">*格外殷勤*</span>或<span style="color:#800000">*格外热心*</span>。他的热忱与踊跃大受激发，乃是<span style="color:#800000">*因他*</span><span style="color:#800000">*向你们所存的极大信心。*</span>他深信此行必获成功，故以极大的恳切承担这一使命。此解为多数注释家所采纳，我们英文圣经的旁注中亦有此提示，较之加尔文、贝撒等人所取之解更为自然。他们将 <span style="color:#0000d4">πεποιθήσει</span> 与 <span style="color:#0000d4">συνεπέμψαμεν</span> 相连：“我们打发这弟兄与他们同去……乃因我们对你们所存的信心。”然而，这并非差遣的缘由；且说“我们满有把握地打发他去”，与上下文亦不相合。词序也支持前一种解释。

<div class="commentary-anchor" id="2corinthians-8-23"></div>
**23.** <span style="color:#800000">*若有人问到提多，他是我的同伴，与我同为你们劳苦的；若有人问到我们的那两位弟兄，他们是众教会的使者，是基督的荣耀。*</span>

此处乃是总括，或曰概括性的举荐。原文措辞极为简练。<span style="color:#800000">*论到提多*</span>，即：我若提及提多；或：若有人问起提多；又或不必补足任何词语，直译为"至于提多"。<span style="color:#800000">*他是我的同伴*</span>，<span style="color:#0000d4">κοινωνὸς</span>，我的同工，在共同的职事上与我有分之人。<span style="color:#800000">*并且*</span>，特别地，<span style="color:#800000">*在你们中间是我的帮手*</span>（<span style="color:#0000d4">συνεργός</span>）。<span style="color:#800000">*论到那两位弟兄*</span>，（他们乃是）<span style="color:#800000">*众教会的使者*</span>（<span style="color:#0000d4">ἀπόστολοι</span>）。此处"使徒"一词显然是取其字面意义，而非其职分上的意义。这些人断然不是保罗那种意义上的使徒。同样，在腓立比书 2:25，以巴弗提被称为腓立比人的使者，因他是他们所差遣、往罗马去服事保罗的人。因此，上文所提及的两位弟兄，都是由众人所选派的，而不单是那位特别提到为众教会所挑选的一位。经上又说他们是<span style="color:#800000">*基督的荣耀*</span>。加尔文说，惟独基督是信徒的荣耀，照样，基督也因信徒得着荣耀。他们反映他的荣耀。他们以自身的圣洁引人看见基督的卓越，因他们身上带着基督的形像。

<div class="commentary-anchor" id="2corinthians-8-24"></div>
**24.** <span style="color:#800000">*所以你们务要在众教会面前，向他们显明你们爱心的凭据，并我所夸奖你们的凭据。*</span>

<!-- PAGE 228 -->
最后，使徒劝勉哥林多人，向这几位如此值得信任的使者显明他们的爱心，并证实他曾为他们的慷慨所作的美好见证确属真实。<span style="color:#800000">*当在众教会面前，向他们显出*</span>（<span style="color:#0000d4">τὴν ένδειξιν ἐνδείξασθε</span>）<span style="color:#800000">*你们爱心的凭据*</span>。这或可指"你们对我的爱"，或指"你们基督徒的爱"，但最自然的理解是"你们对他们的爱"。要给他们看见你们爱心的凭据，就是以亲切的信任接待他们，并使他们看出我为你们所夸的乃是真的。<span style="color:#800000">*在众教会面前*</span>，就是要使差派这几位弟兄前来的众教会，得见你们爱心的凭据。公认经文作命令语气的 <span style="color:#0000d4">ἐνδείξασθε</span>，而拉赫曼、蒂申多夫、迈尔等人则依据较古的抄本读作 <span style="color:#0000d4">ἐνδεικνύμενοι</span>，意即"你们既显出爱心的凭据等等，就当在众教会面前如此行"。整章经文足以证明初期基督徒彼此联结何等亲密：不但从此处所显明的各教会之间的往来可见，也从他们彼此的影响、彼此的弟兄之爱与同情，以及各人都被视为当向他人的判断负责一事上可见。
