**1.** <span style="color:#800000">*直等到我们众人……得以同归于一*</span>等语，<span style="color:#0000d4">μέχρι καταντήσωμεν οἱ πάντες</span>。此处所说的<span style="color:#800000">*众人*</span>并非指全人类，乃指属基督的众人。所指的不是万国从地极各方汇聚而来，而是基督的身体，即上下文所论的众圣徒之群。教会正朝着此处所标明的目标前进。[^f14] 我们的英译作<span style="color:#800000">*在合一里*</span>，然而希腊原文是 <span style="color:#0000d4">εἰς τὴν ἑνότητα</span>，故当译作<span style="color:#800000">*归于*</span>或<span style="color:#800000">*达到*</span>，正如随后各分句中的 <span style="color:#0000d4">εἰς άνδρα τέλειον</span> 与 <span style="color:#0000d4">εἰς μέτρον κτλ</span> 一样。信仰上的合一乃是众人所当达到的终点。属格 <span style="color:#0000d4">υἱοῦ</span> <span style="color:#0000d4">τοῦ θεοῦ</span> 同时统辖 <span style="color:#0000d4">πίστις</span> 与 <span style="color:#0000d4">ἐπίγνωσις</span>。神的儿子既是此处所言之信心的对象，也是此处所言之知识的对象。许多注释家将知识与信心视为同义，因而把此句的后半当作前半的解释，作：“达到信心的合一，即达到对神儿子的认识。”但这忽略了 <span style="color:#0000d4">καὶ</span> 一字。使徒说的是“信心<span style="color:#800000">*与*</span>知识”，如此便将二者区别开来。事实上二者确有分别，无论其关系何等紧密，无论此词何等常用以代彼词。信心是知识的一种形式，故可以“知识”一词表之；但知识并非信心的一种形式，故不能以“信心”一词表之。知识是信心的一个要素；而信心按其独有之意义而言，却不是知识的要素。此处所用的希腊文不是 <span style="color:#0000d4">γνῶσις</span>，而是 <span style="color:#0000d4">ἐπίγνωσις</span>。我们没有一个词可以表达这一分别，德文中却有 Kennen 与 Erkennen 之分。它不单是认知，更是确认。信心与知识，<span style="color:#0000d4">πίστις</span> 与 <span style="color:#0000d4">ἐπίγνωσις</span>，表明并涵括了那一种心灵状态的一切要素；这心灵状态的对象，就是神的儿子，就是那在肉身显现的神，那爱我们、为我们舍己、在各各他受死、如今在天上登宝座的主。这心灵状态既包括对他荣耀的领悟，也包括对他慈爱的支取，更包括信靠与献身。这心灵状态本身就是永生。它包含美善、福乐，以及最高形式的活动，即我们最高才能的最高运用。我们见他的时候，就必像他。完全的知识就是完全的圣洁。所以，当全教会都达到了这排除一切歧异的完全知识时，它便已抵达终点；那时，它必带着属天者的形像。
