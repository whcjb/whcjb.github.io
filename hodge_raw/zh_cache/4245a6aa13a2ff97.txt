名词 <span style="color:#0000d4">πίστις</span> 在各种结构中同样表示依靠、信赖之意；如其后接 <span style="color:#0000d4">εἰς</span> 时，见使徒行传 20:21，<span style="color:#0000d4">τίστιν</span> <span style="color:#0000d4">τὴν</span> <span style="color:#0000d4">εἰς</span> <span style="color:#0000d4">τὸν</span> <span style="color:#0000d4">Κύριον</span> <span style="color:#0000d4">ἡμῶν</span>，又见 24:24；26:18；接 <span style="color:#0000d4">ἐπί</span> 并带宾格者，见希伯来书 6:1；接 <span style="color:#0000d4">πρός</span> 者，如帖撒罗尼迦前书 1:8，<span style="color:#0000d4">πίστις</span> <span style="color:#0000d4">ὑμῶν</span> <span style="color:#0000d4">ἡ</span> <span style="color:#0000d4">πρὸς</span> <span style="color:#0000d4">τὸν</span> <span style="color:#0000d4">Θεόν</span>；接 <span style="color:#0000d4">ἐν</span> 者，见罗马书 3:25，<span style="color:#0000d4">διὰ</span> <span style="color:#0000d4">Χριστῷ</span>，参加拉太书 3:26；提摩太前书 3:13，<span style="color:#0000d4">πίστει</span> <span style="color:#0000d4">τῇ</span> <span style="color:#0000d4">ἐν</span> 提摩太后书 3:15；或接所有格者，如罗马书 3:22、26，加拉太书 2:16、3:22，此类甚多。因此，与救恩相连的信心，包含知识，即对真理及其属性的认识；包含赞同，即确信所信之对象为真；也包含信赖，即依靠。圣经中<span style="color:#800000">*信心*</span>一词所表达的心灵活动或心灵状态，并非单纯的赞同，也非单纯的信赖，乃是对福音所启示之真理的明达认识、领受与依靠。
