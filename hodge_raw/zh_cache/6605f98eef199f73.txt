我们既观看他的荣光，<span style="color:#800000">*就变成主的形状*</span>，<span style="color:#0000d4">τὴν αὐτὴν</span> <span style="color:#0000d4">εἰκόνα μεταμορφούμεθα</span>，<span style="color:#800000">*我们被变化成为同一形像*</span>。此动词通常与 <span style="color:#0000d4">εἰς</span>（成为）或 <span style="color:#0000d4">κατά</span>（依照）连用，但有时如本处，只接直接宾格。<span style="color:#800000">*同一形像*</span>，即我们藉圣灵得以观看的那一形像。“我们观看，就被变化”；二者之间有因果的关联。这是神的话语中处处承认的真理。一方面，圣经教导说，属血气的人不能领会属灵的事，因为这些事惟有属灵的人才能看透（哥林多前书 2:14），并且这种瞎眼正是与神隔绝、污秽败坏的根源（以弗所书 4:18）；另一方面，圣经同样清楚地教导，知识乃是圣洁的源头（以弗所书 5:9），属灵的洞见既以性情相契为前提，也生出性情相契。我们必要像基督，因为我们必要看见他的本相（约翰一书 3:2）。既然与基督形像相符是由观看他的荣光而来，这种相符自然必从今生开始。虽然我们如今只是从镜中观看那荣光，然而正是这观看具有变化人的能力。观看既不完全，变化也就不完全；及至观看完全了，相符也就完全了（罗马书 8:29；约翰一书 3:2）。惟有像基督的人，才是基督徒。使徒在此所说的相符，虽如此处所呈现的乃是属灵的，却不限于灵魂。论到身体，经上说：我们既有属土的形状，将来也必有属天的形状（哥林多前书 15:49；腓立比书 3:21）。<span style="color:#800000">*荣上加荣。*</span>这或可指这变化乃是*从荣光*出发（即从我们所领会的基督的荣光出发），而以荣光为其结果。希腊教父采取此解。或者，这话表明由荣光的一个阶段进到另一阶段。参诗篇 84:7，“他们行走，力上加力。”这是通行且最自然的解释。这变化不间断地向前推进，从起初几乎难以辨认的一点相似，直到灵魂与身体都完全与基督的形像相符。<span style="color:#800000">*如同从主的灵变成的。如同*</span>，即正如从这样一位施行者所当期望的。这工作与其作者的性情相称。<span style="color:#800000">*从*</span>；介词是 <span style="color:#0000d4">ἀπό</span>，<span style="color:#800000">*从*</span>，表明这荣耀的果效所出的源头。主的灵。希腊文作 <span style="color:#0000d4">κυρίου πνεύματος</span>，武加大译本译为 <span style="color:#800000">*Domini Spiritu*</span>，奥古斯丁、加尔文及其他许多人，连同我们英文译本的译者，都采纳这一解释。但这样便颠倒了词序；而且在此处尤其不自然，因为紧接的上一节使徒已说 <span style="color:#0000d4">τὸ πνεῦμα κυρίου</span>，<span style="color:#800000">*主的灵*</span>；他断不至于在同一段文脉中，又用 <span style="color:#0000d4">κυρίου</span> <span style="color:#0000d4">πνεύματος</span> 来表达同一意思。另有人译作 <span style="color:#800000">*主圣灵*</span>，即那位为主的灵。旧约与启示录中有“主神”这一常见的说法；但这不过是“耶和华以罗欣”（那位是神的耶和华）的翻译，七十士译本作 <span style="color:#0000d4">κύριος ὁ θεός</span>，武加大作 Dominus Deus，英文作 “Lord God”。与本处经文更为类似的，是希伯来文 Adonai Jehovah，七十士译本作 <span style="color:#0000d4">κύριος κύριος</span>，武加大作 Dominus Deus，英文作 Lord God。在约书亚记 22:22，有一个不寻常的组合：El Elohim Jehovah；七十士译本作 <span style="color:#0000d4">ὁ θεὸς θεὸς κύριός ἐστι</span>，紧接着又作 <span style="color:#0000d4">θεὸς θεός</span>；武加大作 Fortissimus Deus Dominus；英文作 “The Lord God of gods”。既然希伯来文的 Adonai Jehovah，希腊文的 <span style="color:#0000d4">κύριος</span> <span style="color:#0000d4">κύριος</span>（或 <span style="color:#0000d4">κύριος ὁ θεός</span>），拉丁文的 Dominus Deus，英文的 Lord God，都是指<span style="color:#800000">*那位为主的神*</span>，那么 <span style="color:#0000d4">κύριος πνεῦμα</span> 也可指<span style="color:#800000">*那位为主的灵*</span>，即神圣的灵。屈梭多模、狄奥多勒及某些近代学者采取此解，与他们对第17节前半句所作的解释相符；如上文所述，他们将该句理解为<span style="color:#800000">*圣灵是主*</span>，<span style="color:#0000d4">πρὸς τὸ</span> <span style="color:#0000d4">Πνεῦμα ἐπιστρέφων</span>，<span style="color:#0000d4">πρὸς Κύριον ἐπιστρέφεις κύριος γὰρ τὸ</span> <span style="color:#0000d4">Πνεῦμα</span>，<span style="color:#0000d4">καὶ ὁμόθρονον</span>，<span style="color:#0000d4">ὁμοπροσκύνητον καὶ ὁμοούσιον Πατρὶ</span> <span style="color:#0000d4">καὶ υἱῳ</span>。但保罗在第17节所说的并非“圣灵是主”，恰恰相反，乃是“主就是那灵”；因此若在此处使他说我们是被<span style="color:#800000">*那位为主的灵*</span>变化，便不自然。若在一处<span style="color:#800000">*主*</span>是主词，在另一处也必是主词。又有人主张，所讨论的这一短语当译作<span style="color:#800000">*圣灵之主*</span>，即基督；说基督是圣灵之主，其意义与说神是基督的神相类。也就是说，正如神差遣基督，并藉他显明出来，照样基督差遣圣灵，并藉圣灵显明出来。这是比尔洛特、奥尔斯豪森、迈尔等人的解释。然而“圣灵之主”这一说法，在圣经中既无根据，也无类比。惟有论到道成肉身的神子，才说父是他的神。文法上并无采取此解的必要，而且此解与第17节不合。路德、伯撒等人将 <span style="color:#0000d4">ἀπὸ κυρίου</span> <span style="color:#0000d4">πνεύματος</span> 译作<span style="color:#800000">*那位是灵的主*</span>。支持这一解释的理由，首先是类似说法的类比，如 <span style="color:#0000d4">ἁπὸ θεοῦ πατρός</span>，<span style="color:#800000">*从那位为父的神*</span>（加拉太书 1:3）；其次是第17节的权威。使徒在那里说过“主就是那灵”，在此便说，使我们像基督的那变化之能，乃是从“那位是灵的主”流出。前一处经文决定了后一处的意义。“那位是灵的主”，意即那位与圣灵为一的主，本体相同，权能与荣耀同等；圣灵在哪里，他就在哪里；圣灵作什么，他也作什么。
