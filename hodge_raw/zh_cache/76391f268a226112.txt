律法被称为<span style="color:#800000">*属乎灵的*</span>（属灵的），并非因为它关涉我们的心灵、如伯撒所说触及内在的人（“mentem et interiorem hominem respicit”），更不是因为它<span style="color:#800000">*合乎理性*</span>，或与作为我们本性中较高机能的 <span style="color:#0000d4">πνεῦμα</span> 相符；也不是因为它是由圣灵默示而赐下的；而是因为这词表明律法的性质。它之为属灵的，意思是它是属神的，或说它分有那位神圣作者——圣灵——的性质。因此这一称谓涵括了前面所说的一切，即律法是圣洁的、公义的、良善的。<span style="color:#800000">*但我是属肉体的*</span>。通行本中所用的词是 <span style="color:#0000d4">σαρκικός</span>；格里斯巴赫、拉赫曼与提申多夫依据较古的抄本及教父的引证，读作 <span style="color:#0000d4">σάρκινος</span>。这两个词（在需要区分时）的差别在于：前者表明性质，后者表明一物所由构成的质料；故 <span style="color:#0000d4">σάρκινος</span> 意为由肉造成的、多肉的、肥胖的。这与以 <span style="color:#0000d4">ινος</span> 结尾诸词的类比相合：<span style="color:#0000d4">λίθινος</span>，<span style="color:#800000">*石头做的*</span>；<span style="color:#0000d4">ξύλινος</span>，<span style="color:#800000">*木头做的*</span>。然而这并非一成不变的规则，因 <span style="color:#0000d4">ἀνθρώπινος</span> 意为属人的。在哥林多后书 3:3 中，<span style="color:#0000d4">σάρκινος</span> 一词是按其严格意义使用的，那里 <span style="color:#0000d4">ἐν πλαξὶ καρδίας</span> <span style="color:#0000d4">σακρίναις</span>（在肉的心版上）与 <span style="color:#0000d4">ἐν</span> <span style="color:#0000d4">πλαξὶ λιθίναις</span>（在石版上）相对。然而在此处，纵然 <span style="color:#0000d4">σάρκινος</span> 是正确的读法，它也必与那更常用的词 <span style="color:#0000d4">σαρκικός</span> 同义；出于内证的缘故，多数注释家更取后者。既然<span style="color:#800000">*属灵的*</span>一词表明律法的性质，那么属肉体的也必表明性质，而非质料。<span style="color:#800000">*我是属肉体的*</span>，意思是我在肉体的权势之下。而<span style="color:#800000">*肉体*</span>所指的，并非身体，也不单是我们的感官性情，乃是我们堕落败坏的整个本性。它包括人身上一切与圣灵无关的成分。按新约的用语，<span style="color:#0000d4">πνευματικοί</span>，即<span style="color:#800000">*属灵的人*</span>，是那些受神之灵管辖的人；<span style="color:#0000d4">σαρκικοί</span>，则是那些受自己本性管辖的人。然而，即便在重生的人身上，圣灵的这种管辖也从未达于完全，肉体在他们里面仍保留着许多原有的势力，因此他们不得不承认自己也是属肉体的。无论在圣洁上长进到何等地步，没有一个信徒不能采用使徒在此所用的话。在哥林多前书 3:3 中，他对信徒说：“你们岂不是属肉体的吗？”由于人类语言的不完全，同一个词必须按不同的意思来理解。有时<span style="color:#800000">*属肉体的*</span>意指完全地、惟独地受肉体管辖，指那些以肉体为惟一行事原则的人。另一些时候它有较缓和的意思，可用于那些虽已在圣灵的治权之下、却仍被肉体所污染、所影响的人。一切类似的词都是如此。当我们说到“圣徒与罪人”时，我们并不是说圣徒——按他们在此世的实况——不是罪人。照样，当圣经把人分为 <span style="color:#0000d4">πνευματικοί</span> 与 <span style="color:#0000d4">σαρκικοί</span>，即<span style="color:#800000">*属灵的*</span>与<span style="color:#800000">*属肉体的*</span>时，也并非要教导说属灵的人就不属肉体。因此，惟有把此处所用的词取其极端之义——一种与上下文不合的意义——才能断定它们不适用于重生之人。那些神秘派作者，如奥尔斯豪森，依照他们中许多人所采纳的理论，以为人由三个主体或实质构成，即身、魂、灵，<span style="color:#0000d4">σῶμα ψυχή</span> 与 <span style="color:#0000d4">πνεῦμα</span>，于是说在此类语境中 <span style="color:#0000d4">σάρξ</span> 应理解为<span style="color:#800000">*das ganze seelische Leben*</span>，即整个魂的生命；在人身上，惟有这魂的生命、而非 <span style="color:#0000d4">πνεῦμα</span>（灵，或我们本性中较高的成分），才是罪的所在。反之，在天使身上，<span style="color:#0000d4">πνεῦμα</span> 本身即是罪的所在，故此他们不能得赎。而在人身上，当罪侵入 <span style="color:#0000d4">πνεῦμα</span>（灵）之时，便有了亵慢圣灵的罪，救赎也就成为不可能。这不过是一种精致的、或神秘化的理性主义罢了；因为 <span style="color:#0000d4">πνεῦμα</span> 只是<span style="color:#800000">*理性*</span>的别名，人里面的争战便被归结为感性与理性之争，而救赎便在于使我们本性中较高的能力得以驾驭较低的能力。然而按照圣经，我们整个堕落的本性都是罪的所在；我们主观上脱离罪的权势而得救赎，并非藉着使理性居于优势，乃是藉着圣灵的内住。彼此相争的成分不是感性与理性，不是<span style="color:#800000">*anima*</span> 与 <span style="color:#800000">*animus*</span>，乃是肉体与圣灵，是属人的与属神的，是我们从亚当所承受的与我们藉基督所得着的。“从肉身生的就是肉身；从灵生的就是灵。”约翰福音 3:6。
