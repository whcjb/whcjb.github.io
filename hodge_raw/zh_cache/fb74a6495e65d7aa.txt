<span style="color:#0000d4">νέος</span>（<span style="color:#800000">*年幼的、新的*</span>，就起源而言）与 <span style="color:#0000d4">καινός</span>（<span style="color:#800000">*新鲜的、光洁的、未曾用过的*</span>，就性质或品格而言）之间的区别，在新约中大体是保持着的。故在马太福音 9:17 说 <span style="color:#0000d4">οϊνον νέον εἰς ἀσκοὺς</span> <span style="color:#0000d4">καινούς</span>，即把新近酿成的酒装在未曾用过的皮袋里。<span style="color:#0000d4">Μνημεῖον</span> <span style="color:#0000d4">καινὸν</span> 意为<span style="color:#800000">*新坟墓*</span>，即一座未曾葬过人的坟墓，无论它凿成已有多久。因此 <span style="color:#0000d4">καινός</span> 乃是一个表示美好的形容词。在「直到我在神的国里同你们喝新的那日子」（马可福音 14:25）一语中，所用的是 <span style="color:#0000d4">καινός</span>，而非 <span style="color:#0000d4">νὲον</span>。<span style="color:#800000">*新造的人、新天、新命令、新名、新耶路撒冷*</span>等等一切说法，所含的也都是同一观念；在这些地方，所用的字无一不是 <span style="color:#0000d4">καινός</span>。这两个字的派生词，本也当有同样的分别：<span style="color:#0000d4">ἀνανεόω</span> 是使之成为 <span style="color:#0000d4">νὲον</span>，而 <span style="color:#0000d4">ὰνακαινίζω, ὰνακαινόω</span> 则是使之成为 <span style="color:#0000d4">καινός</span>。所以，凡论到灵魂的更新——那是一种变得更美好的改变——所用的字总是 <span style="color:#0000d4">καινός</span> 的派生词，惟独本节是例外。参看罗马书 12:2；哥林多后书 4:16；歌罗西书 3:10；提多书 3:5。然而，既然凡是 <span style="color:#0000d4">νέος</span> 的也就是 <span style="color:#0000d4">καινός</span>，因为新鲜、活力与美丽正是青春的属性，所以同一事物也可以用这两个词中的任何一个来指称。因此，得了更新的灵魂，在本节被称为 <span style="color:#0000d4">καινός άνθρωπος</span>，而在歌罗西书 3:10 则称为 <span style="color:#0000d4">νέος άνθρωπος</span>；那在歌罗西书 3:10 用 <span style="color:#0000d4">ὰνακαινόω</span> 所表达、在罗马书 12:2 与提多书 3:5 用 <span style="color:#0000d4">ὰνακαίνωσις</span> 所表达的属灵改变，在此处乃是用 <span style="color:#0000d4">ἀνανεόω</span> 来表达的。
