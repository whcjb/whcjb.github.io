<p style="text-align:center" markdown="1"><span style="color:#006411">**第三章**</span></p>

保罗所受职分的性质与目的，第1-13节——他为以弗所人的祷告，第14-21节。

<p style="text-align:center" markdown="1">**第一段　— 第1-13节**</p>

<span style="color:#800000">*1. 因此，我保罗为你们外邦人作了基督耶稣被囚的，*</span>

<span style="color:#800000">*2 谅必你们曾听见神赐恩给我，将关切你们的职分托付我。*</span>

<span style="color:#800000">*3. 用启示使我知道福音的奥秘，正如我以前略略写过的，*</span>

<span style="color:#800000">*4. 你们念了，就能晓得我深知基督的奥秘；*</span>

<span style="color:#800000">*5. 这奥秘在别的世代没有叫人知道，像如今藉着圣灵启示他的圣使徒和先知一样。*</span>

<span style="color:#800000">*6. 这奥秘就是外邦人在基督耶稣里，藉着福音，得以同为后嗣，同为一体，同蒙应许。*</span>

<span style="color:#800000">*7. 我作了*</span> <span style="color:#800000">这福音的</span> <span style="color:#800000">*执事，是照神的恩赐，这恩赐是照他运行的大能赐给我的。*</span>

<span style="color:#800000">*8. 我本来比众圣徒中最小的还小，然而他还赐我这恩典，叫我把基督那测不透的丰富传给外邦人；*</span>

<span style="color:#800000">*9. 又使众人都明白，这历代以来隐藏在创造万物之神里的奥秘，是如何安排的：*</span>

<!-- PAGE 110 -->

<span style="color:#800000">*10. 为要藉着教会使天上执政的、掌权的，现在得知神百般的智慧，*</span>

<span style="color:#800000">*11. 这是照祂在我们主基督耶稣里所定的永恒旨意。*</span>

<span style="color:#800000">*19. 我们因信耶稣，就在他里面放胆无惧、笃信不疑地来到神面前。*</span>

<span style="color:#800000">*13. 所以我求你们，不要因我为你们所受的患难丧胆，这原是你们的荣耀。*</span>

<p style="text-align:center" markdown="1">**分析**</p>

保罗所领受的职分，乃是作外邦人的使徒，见第1-2节。为着这职分，他藉着耶稣基督直接的启示得着装备，明白救赎的旨意；他在本书信前面各段所写的，已足以证明他确有此等知识，见第3、4节。如今比先前更加明白显明的特殊真理，就是外邦人与犹太人联合，藉着福音同为应许的后嗣，同得救赎之应许，见第5、6节。既然福音是使外邦人得以与众圣徒相交的凭藉，保罗便因着神特殊的恩典与全能的大力，得蒙归正，并被立为福音的执事，见第7、8节。他职事的目的，是要将基督那测不透的丰富传开，并要照明众人，使他们明白那从永远以来藏在神心意中的救赎旨意，见第9节。而救赎本身的目的或用意，则是要向天上执政的、掌权的显明神的智慧，见第10节。这荣耀的旨意已在基督里成就；我们既蒙救赎，就在他里面坦然无惧地亲近神。为如此大业所忍受的患难，绝非灰心丧胆的缘由，反倒是荣耀，见第11-13节。

<p style="text-align:center" markdown="1">**注释**</p>

<div class="commentary-anchor" id="ephesians-3-1"></div>
第1节<span style="color:#800000">*。因此缘故，*</span>即：因为你们外邦人是与圣徒同国，尤其因为你们以弗所人也被包括在神的殿中。

由于<span style="color:#0000d4">ἐγὼ Παῦλος</span><span style="color:#800000">*，我保罗，*</span>这几个字并无可作其主语的动词，故此处该如何解析，众说纷纭。最通行的看法是：此处所起的这句话，在第14节重新接续并告完成，因为那里又重复了"因此"二字。使徒在本章开头所要说的，正是他在第14节所说的："因此，我保罗……屈膝"，意即：'因你们以弗所人既已被带到神面前，我便为你们的坚固和恩中的长进祈求。'

另有人仅补入系词动词（<span style="color:#0000d4">εἰμὶ</span>），读作："因这缘故，我作了耶稣基督的囚徒。"但如此解释，至少可说，谓语之前的冠词（<span style="color:#0000d4">ὁ</span> <span style="color:#0000d4">δέσμιος</span>）便属多余。还有人以"基督的囚徒"一语与<span style="color:#800000">*我保罗*</span>同位，而补出谓语<span style="color:#800000">*我作了囚徒*</span>。其意便是："我保罗，耶稣基督的囚徒，为你们外邦人作了囚徒，身被捆锁。"在各家所提出的诸般解法中，此说较他说为优，惟不及首先所提的那一种，因其所得之义远为美善。使徒说："因你们如今已成为神属灵殿宇的一部分，我便为你们的坚固与长进祈求"——这比说"因你们已被引入圣徒的团契，我便作了耶稣基督的囚徒"，语意远为崇高，也更合乎保罗的品格。

<!-- PAGE 112 -->
<span style="color:#0000d4">ὁ δέσμιος τοῦ Χριστοῦ</span> 这一语，<span style="color:#800000">*基督的囚徒*</span>，并非指<span style="color:#800000">*为基督的缘故作囚徒*</span>。因为紧接着就说明，他为之受捆锁的乃是外邦人。此语的意思是：属基督的囚徒。他既是基督的仆人、使徒、执事，也照样是基督的囚徒。在他一切的身分关系中，他都是属乎基督的。他作囚徒，是 <span style="color:#0000d4">ὐπὲρ ὐμῶν τῶν ἐθνῶν</span>，<span style="color:#800000">*为你们外邦人*</span>。正因他向外邦人传福音，才招致本国同胞的仇恨，使他们在罗马官长面前控告他，以致他被当作囚犯解往罗马。

<div class="commentary-anchor" id="ephesians-3-2"></div>
第2节。本节与紧接其前的话相连。——‘我受托的使徒职分是向外邦人的；我为你们的缘故作了囚犯，既然你们曾听见神为你们的益处所赐给我的职分。’<span style="color:#0000d4">είγε</span> 一词，我们的译本译作<span style="color:#800000">*若*</span>，并不一定表示疑惑。保罗知道以弗所人晓得他是外邦人的使徒。此词常用于所论之事已被视为当然的场合，如以弗所书 4:21、哥林多后书 5:3。在此类情形中，宜译作<span style="color:#800000">*既然、因为*</span>。它不过是一种较为精致委婉的断言方式。因此，我们无须假定本书信并非特别写给以弗所人；也无须假定 <span style="color:#0000d4">ἀκούειν</span> 当取 <span style="color:#800000">*bene intelligere*</span>（意即“若你们已确实领悟”）之意；更无须假定保罗在以弗所传道时，对自己的使徒职分缄默不言。他说自己是为他们的缘故作囚犯，因为他们已听见他是外邦人的使徒。

<span style="color:#800000">*神赐恩给我，将这职分托付我*</span>这句话，乃是对他职分的称谓。这是一个 <span style="color:#0000d4">οἰκονομία</span>，即一项<span style="color:#800000">*管家的职任*</span>。所赐之恩的管家职任，<span style="color:#0000d4">τῆς  χάριτος τῆς δοθείσης,</span> 或指这职任本身即是一种恩典、恩惠，或指这职任出于恩典，即是白白赐下的。可比较第8节，他在那里说：“这恩赐给了我。”职分本身被称为 <span style="color:#0000d4">χάρις</span>，即恩典或恩惠，并非罕见。参罗马书 12:3, 15:15；哥林多前书 3:10；加拉太书 2:9。保罗看基督使者的职分，乃是神向他施行不配得之慈爱的彰显，故他提及此职时，总带着感恩与谦卑。在他眼中，使这职分宝贵的，既不是它的尊荣，也不是它的权柄，更不是与之相连的任何利益，乃是它所包含的特权——得以传扬基督那测不透的丰富。

<span style="color:#0000d4">οἰκονομία</span> 一词，除可按上文所释作 <span style="color:#800000">*职分*</span> 解外，亦可指神的作为，而译为 <span style="color:#800000">*安排*</span>。意即：“倘若，或既然，你们已听见神如何分赐那赐给我的恩典”，也就是说，若你们晓得我所领受之恩赐的性质。在歌罗西书 1:25，保罗称那 <span style="color:#0000d4">οἰκονομία</span> 为所赐下的；而此处所说赐下的乃是 <span style="color:#0000d4">χάρις</span>。二者的总意相同，所异者惟在措辞形式而已。

<!-- PAGE 113 -->

他的职分以及与之相连的恩典——包括使他成为使徒的一切恩赐，无论寻常的还是非常的——既是一种<span style="color:#0000d4">οἰκονομία</span>，也是一种<span style="color:#0000d4">χάρις</span>。使徒的职分并非像主教或君王的职位那样，只是授予某些权利与权柄；它乃是一种内在的恩典，其中包含完全无误的知识。你无法指派一个人作使徒，正如你无法指派一个人作圣徒。默示与圣洁，都不是靠委任而来的。没有默示的使徒，正如没有圣洁的圣徒一样自相矛盾。罗马教会在此处一如在别处，所存留的是徒有其表而无其实，有敬虔的形式却无其能力。她有使徒而无默示，有职分却无那本该藉职分表明出来的恩典。她就这样以灰为食，也以灰喂养她的儿女。

<span style="color:#800000">*向你们所施的。*</span>保罗所受的差遣是往外邦人那里去。他所领受的职分以及随之而来的恩赐，都是特特为着他们的。当基督在他往大马士革的路上向他显现时，对他说：“我特意向你显现，要派你作执事，作见证，将你所看见的事和我将要指示你的事证明出来。我也要救你脱离百姓和外邦人的手。我差你到他们那里去，要叫他们的眼睛得开，从黑暗中归向光明，从撒但权下归向神；又因信我，得蒙赦罪，和一切成圣的人同得基业。”使徒行传 26:16-18。这里我们看见保罗受差遣一事的可靠记载。他被立为见证人，为已经指示他的事、并将要藉启示指示他的事作见证。他奉差往外邦人那里去，要使他们离开撒但归向神，以致得救。

<!-- PAGE 114 -->
<div class="commentary-anchor" id="ephesians-3-3"></div>
第3节。<span style="color:#800000">*用启示使我知道福音的奥秘，等等。*</span> 此句与上文相连，并作解释。——“你们既听见我所领受的恩典，就是说，你们既听见我是如何藉着启示得知这奥秘的。” <span style="color:#0000d4">Κατὰ ἀποκάλυψιν</span>，<span style="color:#800000">*按着启示的方式*</span>，即 <span style="color:#0000d4">δι</span><span style="color:#0000d4">’</span> <span style="color:#0000d4">ἀποκαλύψεως</span>，加拉太书 1:12。保罗对福音的认识并非得自他人的教导，这一点他在加拉太书中已藉着历史上一系列事实的详尽列举加以证明。这是使徒职分不可或缺的资格之一。使徒既是见证人，他们的知识就必须是直接的，不可建立在传闻之上。所显明的乃是一个“奥秘”，即一件隐秘之事，是人的理性无从发现的，唯有藉着启示才能得知。这启示乃是赐给使徒本人的恩典或恩宠。

他此处所说的奥秘，正是前面各章所论的题旨，即外邦人与犹太人的联合。关于这一题目，他方才已<span style="color:#800000">*略略*</span>写过；<span style="color:#0000d4">ἐν  ὀλίγῳ</span>，即<span style="color:#800000">*以少许*</span>，意即用寥寥数语。

<div class="commentary-anchor" id="ephesians-3-4"></div>
第4节。 他们读了他所写的，便能判断他对基督奥秘的认识。<span style="color:#0000d4">πρὸς ὁ</span>，<span style="color:#800000">*就能知道。*</span>他所写的可以作为衡量或证明他认识程度的标准。<span style="color:#800000">*基督的奥秘，*</span>可指关乎基督的奥秘或启示；或指以基督为其作者的奥秘（即那救赎的隐秘旨意）；或指那奥秘就是基督自己。基督本身就是敬虔的大奥秘，就是神在肉身显现。祂乃是那历世历代隐藏起来的<span style="color:#0000d4">μυστήριον</span>、即神隐秘旨意的启示。故此使徒写信给歌罗西人说：“神愿意叫他们知道，这奥秘在外邦人中有何等丰盛的荣耀，就是基督在你们心里成了有荣耀的盼望。”歌罗西书1:27。

保罗在前一章中所写关于外邦人蒙召之事，正显明他深知全备的救恩计划——此处称之为“基督的奥秘”，其所包含的，远不止外邦人与圣徒同为国民这一真理。在歌罗西书 4:3 中，这一短语也具有同样宽广的含义；保罗在那里祈求神为他开传道的门，“得以讲基督的奥秘”。因此，本节实际上乃是一段插语，因为下一节开首的关系词 <span style="color:#0000d4">ὁ</span> 是指第 3 节中的 <span style="color:#0000d4">μυστήριον</span> 一词；即或以为它是指第 4 节所用的那一词，那也是就其包含第 3 节所表达的那较狭之意而言。

<!-- PAGE 115 -->
<div class="commentary-anchor" id="ephesians-3-5"></div>
第5节。神藉着启示将一个奥秘，或曰旨意，指示了保罗，<span style="color:#800000">*这*</span>奥秘在先前并未像如今向众使徒所显明的那样被启示出来。外邦人要同得弥赛亚国度的福分，并要在他的国里与犹太人联为一体——此事不但古时众先知屡屡预言，保罗自己也一再详引他们在这一点上的宣告，以证明他所传讲的与旧约相合；参罗马书 9:25-33。因此，重音必须落在<span style="color:#800000">*如今所显明的那样*</span>这句话上。这教义在从前并非未曾启示，乃是未曾<span style="color:#800000">*如此*</span>启示，即不像在福音之下这般完全、这般清晰。

通行本作 <span style="color:#0000d4">ἐν ἑτέραις γενεαῖς</span>，即<span style="color:#800000">*在*</span>别的世代<span style="color:#800000">*里*</span>。然而多数校订者依据较古的抄本，删去了此介词。尽管如此，绝大多数注释家仍将上述词组解作限定时间，译为<span style="color:#800000">*在别的世代之中*</span>。但有人反对说，<span style="color:#0000d4">γενεά</span> 从不指时期意义上的世代，而总是指<span style="color:#800000">*一代人*</span>，即某一时代的人，某一时期中活着的人。倘若此反对成立，则 <span style="color:#0000d4">γενεαῖς</span> 须视为单纯的与格，而 <span style="color:#0000d4">υἱοῖς τῶν ἀνθρώπων</span> 则当视为其解释语。如此，该处经文当读作：“这奥秘未曾向别的世代，即向世人之子显明”云云。但在使徒行传 14:16、15:21，尤其在歌罗西书 1:26（<span style="color:#0000d4">ἀπὸ τῶν αἰώνων καὶ ἀπὸ τῶν γἐνῶν</span>）中，<span style="color:#0000d4">γενεά</span> 最自然的解法仍是时代，或历时之期。七十士译本诗篇 72:5、102:25，以赛亚书 51:8 中，此词亦为同一意义。

<!-- PAGE 116 -->
<span style="color:#800000">*正如今日藉着圣灵启示他的圣使徒和先知一样*</span>，<span style="color:#0000d4">ὡς νῦν ἀπεκαλύφθη ἐν πνεύματι</span>。新约时代惟有使徒与先知这两类人受了默示；前者是圣灵常设的器皿，后者是圣灵偶尔使用的器皿。故此，惟独他们领受直接的启示。这里称他们为<span style="color:#800000">*圣*</span>，意即<span style="color:#800000">*神圣的、分别为圣的*</span>。他们是被分别出来、专作神特殊事奉的人。旧约的先知被称为圣先知，也是这个意思（路加福音 1:70；彼得后书 1:21）。与<span style="color:#800000">*使徒*</span>相连的代词<span style="color:#800000">*他的*</span>，或可指神，即所论启示的作者；或可指基督，因使徒乃是基督的使者。‘我对基督奥秘的认识，这奥秘在历代以前未曾叫人知道，不像如今藉着圣灵启示<span style="color:#800000">*他的*</span>使徒那样’云云。<span style="color:#800000">*藉着圣灵*</span>，即由圣灵所启示。<span style="color:#0000d4">Πνεύματι</span> 虽无冠词，仍是指圣灵，他乃是这些神圣传达的直接作者。按圣经论三位一体的教义，父、子、圣灵在本体上是同一的，由此可知，此一位格的作为即是其余两位格的作为。所以保罗论到自己所领受的启示，有时归于神，如第 3 节；有时归于基督，如加拉太书 1:12；有时又归于圣灵。

<div class="commentary-anchor" id="ephesians-3-6"></div>
第6节。向新约时代的使徒和先知所显明的奥秘，就是 <span style="color:#0000d4">εϊναι τὰ έθνη συγκληρονόμα, κτλ.</span>，即：外邦人在名分上、在事实上，<span style="color:#800000">*乃是*</span>同为后嗣，同为一体，同蒙这应许。旧约预言外邦人蒙召的方式，使人普遍以为：外邦人要得享弥赛亚国度的福分，须先成为犹太人，须以归化者的身份并入旧有的神权政体之中，而这神权政体连同其一切特性都要存留不废。直到五旬节那日以前，似乎从未有人想到：这神权政体本身将要废去，另有一种新的宗教形态要被引进，其设立与安排乃是同等地为着全人类的，在其中犹太人与外邦人的分别要被除掉。福音的这种普世性，正是向使徒们所作的那开阔而提升人心的启示，正是它把使徒们从宗派之人提升为基督徒。

外邦人<span style="color:#800000">*是同为后嗣。*</span>他们与犹太人享有同等的承受产业之权。这产业乃是恩典之约的一切福分：认识真理，教会的一切特权，称义、得儿子的名分、成圣，圣灵的内住，以及永远的生命。这产业何等浩大，单是要领会它，就需要神的帮助，并将灵魂提升至天庭的边际。故此保罗祈求（1:17, 18），愿神将启示的灵赐给以弗所人，使他们知道他们所蒙召得的基业，其荣耀的丰富是何等浩大。

他们乃是 <span style="color:#0000d4">σύσσωμα</span>，即：他们是基督身体的构成部分；与基督的关系何等亲密，分享基督的生命何等充分，与他们犹太人的弟兄毫无分别。手并非因着眼的许可才在身体之内，眼也并非因着手的许可才在身体之内。照样，外邦人不是靠犹太人的通融才得以在教会之中，犹太人也不是靠外邦人的通融才得以在教会之中。他们乃是一个身体。

<!-- PAGE 117 -->
前面那些说法以比喻的方式所表达的，在接下去所加的话里则以字面的方式说明了：<span style="color:#800000">*同为*</span>神<span style="color:#800000">*应许的一分子*</span>。这应许就是救赎的应许，即最初向我们始祖所作、后又向亚伯拉罕重申的那应许，也是旧约一切预言所共同指向的要旨。加拉太书 3:14, 19:22, 29。

得享救赎之恩的唯一根本而不可或缺的条件，乃是与基督联合。使徒说，外邦人同为后嗣，同为一体，同蒙应许，是<span style="color:#800000">*在基督耶稣里*</span>，即凭着他们与基督的联合。而这联合的成就，是<span style="color:#800000">*藉着福音*</span>。我们与基督联合、因而得作神的后嗣，并非藉着出生，也非藉着任何外在的礼仪，更非藉着与任何有形团体的结连，乃是藉着福音——藉着以信心领受并据为己有的福音。所以本节教导我们三件事：一、外邦人所同得之福的性质，即应许给神子民的基业；二、得享此福所系的条件，即与基督联合；三、成就此联合的途径，即福音。因此，使徒便详论传福音这一职事的尊贵与重要。这正是以下数节所论的主题。

<div class="commentary-anchor" id="ephesians-3-7"></div>
第7节。<span style="color:#800000">*我作了这福音的*</span>（福音）<span style="color:#800000">*执事；*</span>即 <span style="color:#0000d4">διάκονος</span>，<span style="color:#800000">*奔走者、仆役、执事。*</span>福音的执事，意思是以传讲福音为其职分的人。这就是他的服事，是他所受托的工作，也是他必须为之献身的事。关于自己得以进入这职分，保罗在本节和下一节说了两件事：第一，这是极大的恩惠；第二，这其中有神的大能运行。

<!-- PAGE 118 -->
<span style="color:#800000">*我作了这福音的执事*</span>，<span style="color:#0000d4">κατὰ τὴν δωρεὰν τῆς χάριτος τοῦ θεοῦ</span><span style="color:#800000">*，是照神恩赐的恩典所赐给*</span>他的。按通行的经文作（<span style="color:#0000d4">δωρεὰν δουεῖσαν)</span>，<span style="color:#800000">*这恩赐乃是所赐下的*</span>。“神恩典的恩赐”，可解作那出于恩慈的恩赐，即因着神的恩典而得的恩赐；或解作那恩赐本身即是神的恩典，如此则<span style="color:#0000d4">χάρις</span>（恩典，保罗常以此称其使徒职分）便是所赐之物。无论取哪一解，此处所说的恩赐都是指他蒙召作使徒一事。他本是逼迫人的、亵渎神的，竟蒙召作使徒，在他看来实是神恩典奇妙的彰显。

所论之恩赐，乃是照着 <span style="color:#0000d4">κατὰ τὴν ἐνέργειαν τῆς δυνάμεως</span> <span style="color:#0000d4">αὐτοῦ</span>，即<span style="color:#800000">*照他（神）大能的运行*</span>而赐下的。保罗蒙召作使徒，其中包含了他的归正，而他的归正乃是神大能的果效。此处所指的是这工作的性质，而非其外在的情形。他归诸神大能的，并非那使人目盲的光，也非那可畏的声音，乃是那内在的变化：他本是恶毒敌挡基督的人，顷刻之间竟变为顺服的仆人。灵魂的重生被列在神的大工之中，是出于他浩大无比的能力。参见第1章19节。

<div class="commentary-anchor" id="ephesians-3-8"></div>
第8节。<span style="color:#800000">*我本来比众圣徒中最小的还小*</span>，使徒又说，<span style="color:#800000">*然而他还赐我这恩典，叫我把基督那测不透的丰富传给外邦人。*</span>

<span style="color:#800000">*圣徒*</span>一词，所指的并非使徒，乃是神的子民，就是那"蒙召作圣徒的"人，参哥林多前书1:7、罗马书1:7。<span style="color:#800000">*比众圣徒中最小的还小*</span>，<span style="color:#0000d4">ἐλαχιστοτέρος</span>，是由最高级构成的比较级。重压在使徒良心上的，并不单是他对自己一般罪性的知觉，乃是他逼迫基督的罪——这罪他永不能饶恕自己。神一在他心里启示他的儿子，他一领会基督那无限的卓越与慈爱，弃绝并毁谤这样一位救主的罪便显得如此重大，以致其他一切的罪相形之下都算不得什么了。保罗在此事上的经历，正是其他基督徒经历的典范。这就是不信的罪，就是弃绝基督的罪；照我们救主自己的宣告，圣灵受差遣来，正是要为这罪责备世人。约翰福音16:9。

<!-- PAGE 119 -->
对于一个罪咎如此深重的人，竟蒙准许传讲基督，这实在是莫大的恩宠。<span style="color:#0000d4">τὸ ἀνεξιχνίαστον πλοῦτος τοῦ Χριστοῦ</span><span style="color:#800000">*，基督那测不透的丰富；无从追寻、不能探究的丰富*</span>这一语，或指基督所赐下的丰富与福分，或指基督自身所拥有的丰富。二义或许兼而有之，然后者无疑更为显著。基督那测不透的丰富，就是神性的全备，是一切神圣荣耀与全德在他里面的充充满满；是赦罪、成圣、施救之恩典的丰盛；一言以蔽之，凡使他成为足以饱足人灵魂之分的一切，尽在其中。

<div class="commentary-anchor" id="ephesians-3-9"></div>
第9节。保罗首要的职分，是在外邦人中传扬基督那测不透的丰富，因他特为“外邦人的使徒”。然而他的职分并不以外邦人为限。他所受的差遣，既是向外邦人传道，<span style="color:#800000">*又要叫众人都明白*</span>，云云。此乃本节通常的解释。但也有人坚持，此处的<span style="color:#800000">*众人*</span>受上下文所限，仅指外邦人。若如此，则<span style="color:#800000">*又*</span>字所标示的新意之增添，其力便大半丧失了。而下一节也正支持将这几个字作最宽泛的理解。

<span style="color:#0000d4">φωτίζειν</span> 一词本义为发光，如一切发光之体所为；进而意为<span style="color:#800000">*照亮*</span>，即将光赐予他物，如烛照亮受其光者，如神照亮人的心思，又如福音之所行——福音正如照在暗处的光。故此使徒在哥林多后书 4:4 论及 <span style="color:#0000d4">φωτισμὸς τοῦ ευαγγελίου</span>。加尔文说：<span style="color:#800000">*Utitur apta similitudine,*</span> <span style="color:#800000">*quum dicit*</span> <span style="color:#0000d4">φωτίσαι πάντας</span><span style="color:#800000">*, quasi plena luce effulgeat Dei gratia in suo apostolatu*</span>（他说 <span style="color:#0000d4">φωτίσαι πάντας</span> 时，所用的比喻甚为贴切，仿佛神的恩典在他的使徒职分中大放光明）。教会被比作灯台，传道人被比作星辰，他们的职任就是施予光照。福音所赐的光就是知识，因此"照亮"实际上就是"教导"，这正是此处这个词所要表达的意思。

<!-- PAGE 120 -->
所教导的内容乃是 <span style="color:#0000d4">ἠ οἰκονομία τοῦ μυστηρίου τοῦ</span> <span style="color:#0000d4">ἀποκεκρυμμένου</span><span style="color:#800000">*，即那历世以来隐藏在神里面之奥秘的安排*</span>。此句在通行本中作 <span style="color:#0000d4">κοινωνία</span>，即交通；但一切经过校勘的新约版本，依据古抄本的权威，均作 <span style="color:#0000d4">οἰκονομία,</span> 即 <span style="color:#800000">*计划*</span>，或 <span style="color:#800000">*安排*</span>。这奥秘或曰隐密之事，并非单指召外邦人进入教会的旨意，乃是指救赎的奥秘。这奥秘，<span style="color:#0000d4">ἀπὸ τῶν αἰώνων</span><span style="color:#800000">*，即历世以来*</span>，自时间之始，就隐藏在神里面。可比较罗马书 16:35，“这奥秘自创世以来是隐藏不言的”；哥林多前书 2:7，“从前所隐藏、神奥秘的<span style="color:#800000">*智慧*</span>，就是神在万世以前预定的”；歌罗西书 1:26，“这道理就是历世历代所隐藏的奥秘。”在这一切经文中，所论的奥秘都是神救赎的旨意：此旨意定于永恒的筹算之中，在神自己的时候未到以先，人的眼目无从窥见。保罗所奉差遣的，正是要把这样定下、这样长久隐藏、如今却借福音显明的救赎计划，作为引导人、拯救人的光，传与万人。

<span style="color:#800000">*创造万物的神*</span>。<span style="color:#0000d4">διὰ</span> <span style="color:#0000d4">’</span><span style="color:#0000d4">Ιησοῦ Χριστοὺ</span>（<span style="color:#800000">*藉着耶稣基督*</span>）一语，在绝大多数最古的抄本中均付阙如，故一般视为窜入之文。此处所说的<span style="color:#800000">*万物*</span>，有人限定为一切属乎福音时代之事。然上下文并无作此解释的必要，且与词语的通常用法及其本身的分量相违。若要将“创造万物的主”解作“新时代的创始者”，必得有极强的理由方可。另有人将此语限于万人：“那创造万人的，如今也呼召万人。”[^f9] 然而这样的限定纯属武断，亦无必要。此语当按其本义理解，即指宇宙万有。这救赎的旨意长久隐藏，正是隐藏在创造万物者的怀中。此处之所以提到神是创造主，或可仅视为一种敬虔的称呼。我们常称神为无限者、全能者、创造主等等，并不一定要使这些称号与所论之事有何特别的关联。保罗也常称神为可称颂的，并无特别的缘由。不过也有人认为，使徒在此用这称呼，是要印证他所宣告的：救赎的计划乃历世历代隐藏在神里面——因为创造万物的那一位，其起初的旨意中必当已包含了救赎。又有人以为这两个观念的联系在于：那创造的，也施行救赎；造宇宙的神与定救赎之计划的，乃是同一位神。惟有创造主才能作救赎主。

<!-- PAGE 121 -->
<div class="commentary-anchor" id="ephesians-3-10"></div>
第10节。<span style="color:#800000">*为要藉着教会使……现在得以知道*</span>，<span style="color:#0000d4">ἵνα γνωρισθῃ νῦν</span>。若此分句是承接紧接其前的一句，则使徒在此所教导的，乃是创造以救赎为目的。神创造万有，是为要藉着教会显明他百般的智慧。这便是关于神诸旨意次序的"堕落前拣选论"之见解；既然全部圣经中唯有此节被引为直接断言该理论的凭据，则其确解便格外值得留意。对上述那种句法关联，有以下几点异议——<span class="enum-num">1.</span> 如此解释，则本段所教导的乃是新约所无的一种教义，即：神创造宇宙，是为要在人的得救与沉沦上彰显他的荣耀；这就等于说，拯救的预旨先于创造的预旨，也先于容许人堕落的预旨。

<span class="enum-num">2.</span> 姑且不论此说在教义上的难处，这样连接各分句本身即不自然；因为“创造万物的”一语纯属附带、并非要义所在，故不宜作为贯串全段之主旨的连接之点。此句纵然略去，全节之意亦无实质损减。

<span class="enum-num">3.</span> 使徒在此所论的，是他自己的归正与蒙召作使徒之事。这恩典赐给了他，叫他传扬基督那测不透的丰富，并将救赎的计划教导众人，<span style="color:#800000">*为要*</span>藉着教会使神百般的智慧得以显明。惟有如此解释，本节与上下文主旨的关联才得以保全。他在此所论的，并非创造的目的，乃是救赎奥秘之启示的目的。

<span class="enum-num">4.</span> 此解又可由此处所用<span style="color:#800000">*如今*</span>一词的语气得着进一步的支持。<span style="color:#800000">*如今*</span>与「历代以来隐藏」相对。神差遣保罗传福音，<span style="color:#800000">*为要使*</span>那久已隐藏的奥秘如今得以显明。使徒在此所论的，乃是传福音的目的，而非创造的目的。因此 <span style="color:#0000d4">ἵνα</span> 的自然关联，乃是与 <span style="color:#0000d4">εὐαγγελίσασυαι</span> 和 <span style="color:#0000d4">φωτίσαι</span> 二动词相连，这两个动词表达了上下文的主要思想。奥尔斯豪森说：「保罗将自己蒙召之职分的浩大，与他个人的卑微无有相对照，因而将其受差遣的目的分作数层追溯。他说，他首先要向外邦人传道；其次，要使众人明白救赎的奥秘；而这二者，又都是为要将神无穷的智慧甚至向天使显明。」

圣经明明教导我们：天使不但对救赎之工深怀关切，而且神在拯救世人之事上所彰显的荣耀，也使他们的知识与福乐得以增长。

<!-- PAGE 122 -->

<span style="color:#0000d4">ἠ πολυποίκιλος σοφία</span>（“百般的智慧”）一语，是指神的智慧在救赎之中所彰显的种种方面：使公义与怜悯相和；高举不配之人，同时又切实使之谦卑；在救赎主的位格上，在他的工作上；在圣灵的运行上；在新旧两约诸般不同的安排上；并在这整个施怜悯之工的进行及其荣耀的成全上。正是借着这被基督宝血所赎、被他的灵所成圣的教会，神的全备完美要在将来万世之中，向各等有理性的受造者作最光辉的显明。这百般智慧的显明，乃是<span style="color:#0000d4">διὰ τῆς ἐκκλησίας</span>，向<span style="color:#0000d4">ταῖς ἀρχαῖς καὶ ταῖς ἐξουσίαις ἐν τοῖς</span> <span style="color:#0000d4">ἐπουρανίοις</span>作出的。这使我们对教会的尊荣得着最崇高的认识。神的作为，因其本身如此，便彰显他的荣耀。正因宇宙如此浩大，诸天如此荣美，大地如此秀丽丰盛，它们才显出其创造主无穷的丰富。那么，若神定意要借着教会，速速向最高等次的有理性者显明他无限的权能、恩典与智慧，则教会在其完全之境，必是他一切作为中最荣耀的。因此，传讲福音——乃是为达此至终目的所设立的方法——在保罗看来便是何等大的恩宠。这恩典赐给我这比众圣徒中最小的还小的人。

<div class="commentary-anchor" id="ephesians-3-11"></div>
第11节。神百般的智慧如此彰显，乃是在救赎计划最初的构想中就已定意的；因为使徒接着说，这是<span style="color:#800000">*照*</span>他在我们主基督耶稣里所定的永远旨意。<span style="color:#0000d4">Πρόθεσιν τῶν αἰώνων</span>指在永恒中所立的<span style="color:#800000">*旨意*</span>——贯穿以往万世而常存的旨意——并非指关乎诸世代、或世界不同时期的旨意。可比照提摩太后书 1:9，<span style="color:#0000d4">πρόθεσιν</span>——<span style="color:#0000d4">πρὸ χρόνων αἰωνίων.</span>。<span style="color:#0000d4">ἡν ἐποίησε</span>一语，既可如我们的译本所译作<span style="color:#800000">*他所定的*</span>，亦可译作<span style="color:#800000">*他所成就的*</span>。多数注释家取后一种译法，以为更合上下文，尤其更合“在我们主基督耶稣里”这句话；因为“基督*耶稣*”这一称谓，总是指历史中的基督，即道成肉身的神子。神为人类的救赎预备恩典的旨意，已在他儿子的降生与受死中得了成全。

<!-- PAGE 123 -->

<div class="commentary-anchor" id="ephesians-3-12"></div>
第12节。因此，作为这已成之工的结果，<span style="color:#800000">*我们*</span>在他里面<span style="color:#0000d4">χομεν τὴν παρρησίαν καὶ προσαγωγὴν ἐν πεποιθήσει</span>，<span style="color:#800000">*就坦然无惧、笃信不疑地得以进到神面前*</span>，即自由无阻地亲近神，如同儿女亲近父亲。我们前来时确信必蒙悦纳，因为我们的把握不在于自己的功德，乃在于一位无限之救主的无限功德。我们是<span style="color:#800000">*在他里面*</span>才有这自由。我们得以这样自由地亲近神；我们这些信徒；并非某一特殊阶层，并非基督徒中间唯独他们才得亲近的祭司团，乃是一切信徒，无需任何祭司的居间，只有那一位已经升入高天的大祭司，就是神的儿子耶稣。<span style="color:#0000d4">Παρρησία</span> 在圣经中的用法，不只是<span style="color:#800000">*直言无讳*</span>，也不只是单纯的<span style="color:#800000">*坦率*</span>，乃是<span style="color:#800000">*无所畏惧*</span>，即不再忧惧被弃绝或遭祸患。这正是基督为我们所成就的。即便是至卑污的人，在基督里也可以毫无惧怕地亲近那无限圣洁者，那位烈火般的神。惟有一位无限的救主，才能成就如此的救赎。此句中名词的连用——<span style="color:#800000">*坦然无惧、亲近、笃信*</span>——表明保罗眼见人藉着耶稣基督与神完全和好，心中所感的，实非任何一个词所能道尽。

我们得以这样自由地亲近神，并且满有蒙悦纳的确信，乃是<span style="color:#800000">*因信他*</span>，即借着相信基督。这是对本节前一分句的解释：<span style="color:#0000d4">ἐν ῳ</span> —— <span style="color:#0000d4">διὰ τῆς πίστεως αὐτοῦ</span>，<span style="color:#800000">*在他里面*</span>，即<span style="color:#800000">*因信他*</span>；这信以他为对象。参看 2:13。正是因为看见了他位格的尊荣，信靠他宝血的怜悯，并确知他的慈爱——这一切或多或少都自觉地包含在信心之内——我们才得以欢然亲近神。每一个罪人都需要得着解答的大问题正在于此：我如何能带着蒙悦纳的确据来到神面前？使徒所给的答案，也是历代圣徒的经历所印证的答案，乃是：“因信耶稣基督。”许多人想要进到神面前却不得其门而入，正是因为他们倚靠别的途径：或是手中带着一无价值的贿赂，或是信赖别的中保，或为祭司，或为圣徒。

<!-- PAGE 124 -->
<div class="commentary-anchor" id="ephesians-3-13"></div>
第 13 节。<span style="color:#800000">*所以*</span>，即：既然我们得以如此亲近神——神乃一切美善之总汇——我们就当胜过今生一切的苦难，常存喜乐之心。信徒既已蒙受这样的救赎，又有这亲近神的自由，就不当因福音传扬时种种看似不利的境遇而灰心。由于动词 <span style="color:#0000d4">αἰτοῦμαι</span> 的宾语未曾写明，动词 <span style="color:#0000d4">ἐγκακεῖν</span> 的主语亦未写明，故本节可有数种解释。其意或为：「我求<span style="color:#800000">*你们*</span>不要丧胆」；或为：「我求<span style="color:#800000">*神*</span>使<span style="color:#800000">*我*</span>不丧胆」；或为：「我求<span style="color:#800000">*神*</span>使<span style="color:#800000">*你们*</span>不丧胆」。这动词的宾语究竟是「<span style="color:#800000">*神*</span>」还是「<span style="color:#800000">*你们*</span>」，实难断定；因为说「我求神」或说「我求你们」（即我恳求你们不要灰心），在文义与用法上都同样合宜。然而总体而言，当以后一种为优，因上下文中并无任何线索表明神是所求告的对象；且动词 <span style="color:#0000d4">αἰτεῖν</span> 虽本义只是<span style="color:#800000">*求*</span>——无论向神求或向人求——却常用于更强的意思，作<span style="color:#800000">*要求*</span>或<span style="color:#800000">*责成*</span>解，见路加福音 23:23；使徒行传 25:3, 15。保罗既顾念以弗所人所已同得之救赎何等荣耀，自然大可责成他们不要灰心。至于第二点，即动词 <span style="color:#0000d4">ἐγκακεῖν</span> 的主语，则疑义较少。就全段语气而论，保罗所指的应是他们的丧胆，而非他自己的丧胆，这远为贴切。前者的危险远大于后者。而下文所说的（「这原是你们的荣耀」），正是加强他对他们这番劝勉的理由。

下一分句中的关系代词 <span style="color:#0000d4">ἥτις</span> 可作两种指涉。它或指 <span style="color:#0000d4">θλίψεσίν</span><span style="color:#800000">*，即患难*</span>；或指 <span style="color:#0000d4">μὴ ἐγκακεῖν</span><span style="color:#800000">*，即不丧胆*</span>。若属前者，其意便是：“我为你们所受的患难，非但不是使你们灰心的缘由，反倒是你们的荣耀。”若属后者，则意为：“不丧胆乃是你们的光荣。”后一解平淡无味，在这样的上下文中几无意义。使徒素以所受的患难夸口，其气概何等英伟，上下文所流露的情感又何等崇高；他将自己为外邦人所忍受的患难称为荣耀，而非耻辱与沮丧之因，正与此完全相合。

<p style="text-align:center" markdown="1">**第二段 — 第14-21节**</p>

<span style="color:#800000">*14. 因此，我在父面前屈膝，*</span>

<span style="color:#800000">*15. 天上地上的各家，都是从他得名，*</span>

<span style="color:#800000">*16. 求他按着他丰盛的荣耀，藉着他的灵，叫你们心里的力量刚强起来；*</span>

<span style="color:#800000">*17. 使基督因你们的信，住在你们心里，叫你们的爱心有根有基，*</span>

<span style="color:#800000">*18. 能以和众圣徒一同明白基督的爱是何等长阔高深；*</span>

<span style="color:#800000">*19. 并知道这基督的爱是过于人所能测度的，便叫神一切所充满的，充满了你们。*</span>

<span style="color:#800000">*20. 神能照着运行在我们心里的大力，充充足足地成就一切，超过我们所求所想的，*</span>

<span style="color:#800000">*21. 但愿他在教会中，并在基督耶稣里，得着荣耀，直到世世代代，永永远远。阿们。*</span>

<p style="text-align:center" markdown="1">**分析**</p>

使徒的祷告乃是向我们主耶稣基督的父发出的，这位父在基督里也是我们的父。他只提出一项祈求，就是愿他的读者藉着圣灵在里面的人得以刚强；或说，愿基督因着信住在他们心里。其结果便是：他们要在爱中得以坚固，从而在某种程度上能够领会基督那无限的爱，而这爱又要扩充他们的度量，直到得着神一切的丰盛；也就是说，最终使他们按各自的度量，如同神在其自身的圣洁与福乐中一样，充满圣洁与福乐。

<p style="text-align:center" markdown="1">**注释**</p>

<div class="commentary-anchor" id="ephesians-3-14"></div>
第14节。本节接续第1节中被打断的思路。使徒在那里所起首的祷告，此处重新开始。

<span style="color:#800000">*因此，*</span> <span style="color:#0000d4">τούτου χάριν</span>，此语乃承第1节而重述，故此处的关联与彼处相同，即：因为你们以弗所人得以有分于基督所买赎的救恩。<span style="color:#800000">*我在……面前屈膝*</span>。以祷告的姿态代指祷告本身。<span style="color:#800000">*向我们主耶稣基督的父。*</span>[^f10] <span class="enum-num">2.</span> 这是称呼神的一个独特的基督教称谓，表明他与信徒所立的圣约关系。正因他是我们主耶稣基督的父——耶稣基督乃是道成肉身的神、我们的救主——所以他也是我们的父，我们才可以借着祷告亲近他。除了作为那差遣主耶稣来作我们挽回祭与中保的神以外，我们不能凭着他别样的身份蒙悦纳地来到他面前。因此，我们是凭着信心，信他已与我们和好，才称他为我们主耶稣基督的父。

<!-- PAGE 127 -->
<div class="commentary-anchor" id="ephesians-3-15"></div>
第15节。<span style="color:#800000">*天上地上的全家，都是从他得名*</span>。<span style="color:#0000d4">πατριά</span> 一词是集合名词，指同出一父（无论是直系之父或远祖）的后裔。路加福音 2:4 提到大卫的家族，使徒行传 3:25 提到地上的万族。此处最要紧的问题是：<span style="color:#0000d4">πᾶσα πατριά</span> 当译作 <span style="color:#800000">*每一家*</span>，抑或 <span style="color:#800000">*全家*</span>。支持后者的理由有二：其一，按惯例固当有冠词，然凡名词已带有专有名词的性质，或上下文明白无致误解之虞者，省略冠词并不罕见（参温纳《文法》第131页）。其二，此义与全段文脉更为相合。倘若保罗意在指众天使的各等次序与世人的各等类别——若将 <span style="color:#0000d4">πᾶσα πατριά</span> 译作 <span style="color:#800000">*每一家*</span>，便必是此意——那么他所设想的，乃是神为普世之父，一切有理性的受造之物皆为其儿女。然而本段的整个走向表明：此处所论的，并非以创造者身份而言的神，乃是以属灵之父身份而言的神。保罗称他为“我们主耶稣基督的父”，因而也是我们的父。由此可见，此处被视为儿女的，乃是藉着耶稣基督被带入与神这种关系之中的人。所以 <span style="color:#0000d4">πατριά</span> 一词，除蒙救赎之人外，不能包括他人。故此，天上的全家不能指众天使，乃指已经得救的蒙赎之民；地上的家则指仍在世的信徒群体。

正如儿女从其父得名，并因此确定了他们与父的关系，使徒说，神的全家也是从他得名，并因此被认识、被承认为他的儿女。

<div class="commentary-anchor" id="ephesians-3-16"></div>
第16节。本节载有使徒为以弗所人所献之祷告。他祈求神照着他丰盛的荣耀，藉着他的灵，叫他们心里的力量刚强起来。

<span style="color:#800000">*他丰盛的荣耀*</span>，<span style="color:#0000d4">πλοῦτος τῆς δόξης</span>，意指神一切完美的丰盛。这不是排除了祂怜悯的能力，也不是排除了祂能力的怜悯，乃是神里面一切使祂荣耀、使祂成为敬拜之正当对象的东西。使徒所祈求的，是神照着那构成祂荣耀、并使祂成为受造者一切美善之源的恩典与能力的丰盛，来待祂的子民。

<span style="color:#0000d4">Δυνάμει κραταιωθῆναι</span>。<span style="color:#0000d4">Δυνάμει</span> 可作副词解，即<span style="color:#800000">*“大有能力地*</span>得坚固”；或可解作<span style="color:#800000">*“在能力上”*</span>，指明那要被坚定、被刚强起来的本原；又或解作“<span style="color:#800000">*用能力*</span>”，表示所要赐下的恩赐。他们要藉着圣灵领受所赐的能力。当以末一解为优，因为承受这刚强之工的，并非某一项本原，乃是整个“里面的人”。

<!-- PAGE 128 -->
对于 <span style="color:#0000d4">κραταιωθῆναι εἰς τὸν έσω</span> <span style="color:#0000d4">άνθρωπον</span><span style="color:#800000">*，就是在里面的人上得以刚强*</span> 这一短语，有两种解释，二者取舍必须依据圣经的类比。按照关于人性的一种理论，灵魂中较高的能力——理性、心思、灵、里面的人——自堕落以来仍保全其完整，只是就其自身而言太软弱，不足以胜过我们本性中那被称为肉体或外面的人的动物性或较低的原则。据此说法，即便在重生以先，人里面善恶两种原则之间、理性或曰 <span style="color:#0000d4">πνεῦμα</span> 与肉体或曰 <span style="color:#0000d4">σάρξ</span> 之间，也有持续不断的争战。前者既较为软弱，便需要神的灵加以坚固。迈尔说：“<span style="color:#800000">*里面的人*</span>，就是 <span style="color:#0000d4">νοῦς</span>，即那有理性、有道德的自我，是人里面与神的旨意相合的理性灵魂，然而需要神的灵使之刚强（<span style="color:#0000d4">δυνάμει κραταιωθῆναι διὰ τοῦ</span> <span style="color:#0000d4">πνεύματος</span>），免得被 <span style="color:#0000d4">σάρξ</span> 的罪恶私欲所胜；而 <span style="color:#0000d4">σάρξ</span> 的生机或生命原则乃是 <span style="color:#0000d4">ψυξή</span>，即动物性的魂。”这便是半伯拉纠主义的理论，在罗马教会的神学中得到了具体体现与发展。与之相反的是奥古斯丁的理论，为路德宗与改革宗教会所采纳，即全然败坏之说：整个灵魂，我们本性中较高的能力与较低的能力一样，都是原罪的所在与主体；属血气的人因此丧失能力，且与一切属灵的善相敌对。因此，圣经所说的争战，并非我们本性中较高与较低能力之间的争战，乃是本性与那非出于本性者之间、旧人与新人之间的争战。这新的原则乃是神的灵所赐下的超性之物。圣经论及此事的经典经文，是罗马书 7:14-25；哥林多前书 2:14, 15；加拉太书 5:17-26。在这些经文中，<span style="color:#0000d4">πνεῦμα</span> 无一处是指与情欲原则相对的理性，乃是指神的灵住在已蒙更新的灵魂里，将自己的性情赋予它，因而也把自己的名称给了它。灵魂之所以被称为灵，乃是因它是神所影响的对象，是圣灵的居所。所以，本节中的“里面的人”，不可理解为与身体相对的灵魂，也不可理解为与情欲原则相区别的理性原则；乃是指属灵生命的内在原则，是神的灵大能大力的产物——本书信第一章 19 节已清楚教导了这一点。即便在哥林多后书 4:16，使徒说“我们外体虽然毁坏，内心却一天新似一天”，其意也是一样。这样的话，断不能用在未蒙更新的人身上。这并非仅仅是说，身体虽日渐衰残，心思却时常得以振作。那一天新似一天的“里面的人”，乃是已蒙更新的、属灵的人，是作为神的灵之器皿与殿宇的灵魂。

<!-- PAGE 129 -->
<div class="commentary-anchor" id="ephesians-3-17"></div>
第17节。<span style="color:#800000">*使基督因你们的信，住在你们心里*</span>，<span style="color:#0000d4">κατοικῆσαι τὸν</span> <span style="color:#0000d4">Χριστὸν διὰ τῆς πίστεως ἐν ταῖς καρδίαις ὐμῶν</span>。基督住在他的子民里面——他住在他们心里；他藉着信住在他们里面。这几点便是本节所含的真理。

至于第一点，即基督的内住，它与前一节所表达的并无不同，只是指明了那一节所说的属灵力量的源头与性质。保罗祈求他的读者在内心里刚强起来，也就是祈求基督住在他们心里。那无所不在、无限的神，凡在何处特别地、常在地显明祂的同在，就说祂住在何处。因此说祂住在天上（诗篇 123:1）；住在以色列人中间（民数记 35:34）；住在锡安（诗篇 9:11）；与心灵痛悔谦卑的人同居（以赛亚书 57:11）；并住在祂的百姓中间（哥林多后书 6:16）。有时说是神住在祂百姓心里，有时说是神的灵，有时如罗马书 8:9 所说，是基督的灵；有时如罗马书 8:10 及我们眼下这段经文所说，则是基督自己。这些不同的说法，唯有在三位一体的教义中才能得到解答。因着神的本体为一，人看见了子，就是看见了父；人有了子，就是有了父；神的灵在哪里，神就在哪里；基督的灵在哪里，基督就在哪里。罗马书 8:9, 10 那段经文尤其发人深省。使徒在那里说：“神的灵住在你们心里。人若没有基督的灵，就不是属基督的；基督若在你们心里……”由此可见，基督在我们里面，意思就是我们有祂的灵；而有祂的灵，意思就是神的灵住在我们里面。所以，当使徒说到基督住在我们心里时，他所指的乃是圣灵的内住，因为基督是藉着祂的灵住在祂的百姓里面。他们由此得以有分于祂的生命，以致活着的乃是基督在他们里面活着（加拉太书 2:20）。这就是属灵力量以及神圣生命一切彰显的真实而长存的源头。

经上说基督住在<span style="color:#0000d4">ἐν ταῖς καρδίαις</span>，即住在他百姓的<span style="color:#800000">*心里*</span>。「心」字在圣经中常见的两种比喻用法：一是指与悟性相区别的情感，二是指整个灵魂，兼含理智与情感。圣经论到「聪明的心」（列王纪上 3:9, 12；箴言 8:5），以及心中的思念、筹划与谋算（士师记 5:15；箴言 19:21；<!-- PAGE 130 --> 20:5），所用的正是后一种意义。按圣经所言，敬虔既非排除理智的情感，亦非排除情感的知识。基督住在心里，乃是取这字最广的意义。他是全人灵性生命的源头，既是属灵知识的源头，也是属灵情感的源头。

<span style="color:#800000">*因着信，*</span><span style="color:#0000d4">διὰ τῆς πίστεως</span>，<span style="color:#800000">*藉着信。*</span>基督如此内住，有两项必要的条件：一是具有理性的本性，二是就成年人而言，必须有信心。前者乃是一切与神相交之事所必然预设的。然而，神并非与每一具有理性的受造之物都进入相交之中。基督的内住所包含的，不止是灵与灵之间的交通，它还意味着性情的相合。而这性情的相合，乃是信心所产生、或说信心之中所含有的；因为信心包含属灵的领悟——即看出“属乎圣灵的事”之真实与美善；也因为信心藉着爱而发动，它显明于欣悦、渴慕与喜乐的运用之中。一件最美之物或许就置于瞎子的居室之内，他却毫无察觉；纵然藉着别的途径得知它近在身旁，他也无从因其美丽而生喜乐。基督藉着信住在我们里面，因为惟有藉着信，我们才能察觉他的同在、他的美善与他的荣耀；也惟有藉着信，我们才能领受并回应他慈爱的显明。信心之于这属灵的相交，正如敬重与爱慕之于家庭生活中的相亲相契。

第18节。<span style="color:#0000d4">ἀγάπῃ ἐρριζωμένοι καὶ</span> <span style="color:#0000d4">τεθεμελιωμένοι, ἵνα, κτλ,</span> 这一分句的文法结构如何，尚有疑问。许多古今的注释家将它与前一分句相连，如此则意思是：“叫基督如此住在你们心里”，<span style="color:#0000d4">ἐν</span> <span style="color:#0000d4">ταῖς καρδίαις ὐμῶν. ἐρριζωμένοι</span>，“在爱中生根立基”。这样解，便须承认文法结构不规则，因为 <span style="color:#0000d4">ἐρριζ.</span> 与 <span style="color:#0000d4">ὑμῶν</span> 在格上并不相符。支持此解的惟一理由是：保罗既将读者视为已经重生的人，就不能再求基督住在他们心里，因为这样的内住与他们已得的重生原不可分。为基督的内住祈求，无异于为他们的重生祈求。故此，尽管字句的文法形式如彼，其内在的意思却要求采取一种与此观念相合的结构。保罗所求的，不是基督住在他们心里，而是基督住在他们心里，使他们在爱中得以坚固。所以他所祈求的并非基督的内住，乃是他们在爱中得坚固。然而此种推论似乎并无多少分量。基督的内住是有程度之分的。神在祂子民心中显明自己，有时较为充分而恒常，有时则不然。任何基督徒都可为神的同在祈求，而神的内住岂不正是祂同在的显明么？因此，大多数注释家只假定小品词 <span style="color:#0000d4">ἵνα</span> 的位置有所前后移易（参使徒行传 19:4；加拉太书 2:10；帖撒罗尼迦后书 2:7），而将此分句与下文相连：<span style="color:#800000">*使你们的爱心有根有基，能以明白*</span>云云。圣灵在里面加力，或说基督的内住，其果效即是爱心得以坚固；而爱心坚固的果效，则是（按着我们的度量）能以领会基督的爱。

我们要在其中生根的爱，并非神或基督向我们所施的爱，乃是弟兄相爱之心，或作为基督徒恩德而不必限定其对象的爱。这爱由信心而生，神与弟兄同为其对象。使徒在此所祈求的，正是要藉着基督住在心里，使这恩德日益增长、渐居主导，直至托住并坚固整个里面的人，叫信徒得以像扎根深固的树、根基稳妥的房屋一般屹立不摇。

第19节。<span style="color:#0000d4">ἐξισχύσητε καταλαβέσυαι,</span> *能够完全地*（因 <span style="color:#0000d4">ἐκ</span> 是加强语气）<span style="color:#800000">*明白。*</span>若非圣灵在里面的人上加力，若非基督住在心里，若非在爱中生根立基，人就不可能对福音、或对福音中所启示的基督的爱，有任何相称的领悟。所以使徒祈求，愿他的读者如此得着刚强，<span style="color:#800000">*为要*</span>能和众圣徒一同明白他所讲论的真理。此处所说的知识乃是<span style="color:#800000">*圣徒*</span>所独有的。它是属灵的知识，就其来源而言如此，就其性质而言亦然。它出于圣灵，且在于唯有属灵之人方能经历的那些看见。这知识的对象是无限的。“他的智慧高于天，你还能做什么？深于阴间，你还能知道什么？其量比地长，比海宽。”（约伯记11:8, 9）这话是用以表达神的无限。使徒也采用类似的表述方式，来指明信徒知识之对象那无边无际的性质。要认识那无限的、因而是超过知识的事物，只能意味着对其性质、并对其为无限这一事实，有某种相称的体会。我们认识空间、浩渺、永恒或神，也无非如此。所以保罗要我们明白：他所论的这一题旨，有其长阔高深，是超乎一切悟性的。然而这不可测度的题旨究竟是什么？对此问题所给的答案繁多，难以尽述。关键在于：<span style="color:#0000d4">γνῶναί τε</span> 一语中由 <span style="color:#0000d4">τέ</span> 所引出的那一附加成分，究竟当从 <span style="color:#0000d4">καταλαβέσθαι</span> 与 <span style="color:#0000d4">γνῶναί</span> 之别（即“明白”与“知道”之别）中去寻求，抑或当从对象之别中去寻求。若照前一说，本段的意思便是：“叫你们能明白、并知道那超过人所能知的基督的爱，是何等长阔高深。”正如我们会说：“叫你们能知道，并且体会。”按圣经的用法，<span style="color:#800000">*知道*</span>一词大可包含经历性的认识，即与相应的情感相联合的认识。这是较为简明的解释，意思也十分妥当。若照另一说，意思则是：“叫你们能明白某事物的长阔高深——并且也知道基督的爱”；即首一分句所指的乃是有别于基督之爱的某种事物。持此说的注释家占绝大多数，他们以为所指的是第9节所说的救赎之安排。保罗祈求听者能明白那怜悯之计划的浩大，并知道基督的爱。另有人指为救人之事上所显出的百般智慧；又有人指为基督那测不透的丰富。这些题旨诚然都在上文提及，但并未见于这段祷告之中。到第14节，题旨与论述的进程既已有所转换，若再回溯到该节以前去寻求宾语，未免生硬。较为自然的，是在随后的分句中去寻，而那里正有一个现成的，使人无须再作他求。这就是基督的爱，即他向我们所存的、那超过人所能测度的爱。它是无限的；不仅因为它内在于一位无限的主体，更因为它所导致的屈尊俯就与受苦，以及它为所爱之人所成就的福分，都是我们无法测度的。基督这爱，虽然超越我们悟性所能把握的能力，却仍是可以经历而知的。我们能知道它何等美善、何等奇妙、何等白白赐下、何等不求己益、何等恒久忍耐、何等丰富而不改变，并知道它是无限的。这是一切知识中最高的、也最能使人成圣的知识。凡如此知道基督向自己所存之爱的人，就洁净自己，像他洁净一样。

<span style="color:#800000">*便叫神一切所充满的，充满了你们。*</span> <span style="color:#0000d4">εἰς πᾶν τὸ</span> <span style="color:#0000d4">πλήρωμα τοῦ θεοῦ</span> 一语，若译作<span style="color:#800000">*“被神一切的丰满所充满”*</span>，并不确切；应译作<span style="color:#800000">*“以至于神完全的丰满”*</span>。这才是所当达到的标准。<span style="color:#0000d4">Πλήρωμα</span> 或可取其通常之义，即“使某物得以充满者”；或可取其引申之义，即<span style="color:#800000">*丰盈*</span>，正如我们说“江河的丰盈”。若取后一义，则 <span style="color:#0000d4">Θεοῦ</span> 为宾语属格，“神的丰满”便是那从神流出、并由他所赐予的丰盈。若仍守前一通常之义，则 <span style="color:#0000d4">Θεοῦ</span> 为主语属格，“神的丰满”便是神自己所充满的那丰满，即神一切完全的丰盈，正如歌罗西书 2:9 所言，神本性一切的丰盛都有形有体地居住在基督里面。多数注释家在此亦按此大意理解此语。屈梭多模说，神的丰满就是神自己所充满的那卓越。如此，这话便与马太福音 5:48 “你们要完全，像你们的天父完全一样”相平行；所表明的真理，实质上亦与以弗所书 4:13 “直等到我们众人……得以长大成人，满有基督长成的身量”，及哥林多前书 13:12 “到那时就全知道，如同主知道我一样”相同。绝对的完全，乃是信徒所当达到的标准。他被预定效法神儿子的模样（罗马书 8:29）。人当作为人而完全，正如神作为神而完全；而人的完全，就在于被神充满，神住在他里面，以致完全掌管他一切的认知、情感与外在的行为。提阿多勒对此语的解释正表明此意：<span style="color:#0000d4">ἵνα τελείως</span> <span style="color:#0000d4">αὐτὸν ένοικον δέξησυε.</span>

<!-- PAGE 134 -->
然而，纵使采纳另一种解释，所得的结果也几乎相同。那时，“神的丰盛”即指从神而来的恩赐与恩典之丰富；整句的意思便是：“愿你们被充满，直到神一切丰盛的恩惠都倾注于你们。”所盼望达到的目的，乃是领受那 <span style="color:#800000">*donorum plenitudo,*</span> 即恩赐的丰盛，或 <span style="color:#800000">*donorum Dei perfectio.*</span> 即神所赐诸恩的完全。加尔文说：“凡有基督的人，就在神里面拥有了成全我们所需的一切，因为这正是**神的丰盛**一语的意思。”

然而，支持前一种看法的理由有：<span style="color:#0000d4">πλήρωμα</span> 一词的通常含义、“神的丰盛”这一短语在别处经文中的意思、上文所引平行经文所显明的圣经类比，以及这一解释的简明——无须任何意译的铺陈，意思便已自明。我们要长成基督的身量；要完全，像我们的父完全一样；要被充满，达到神丰盛的程度。然而，纵使我们如此被充满，我们与神之间的距离仍是无限的。这是使徒祷告的顶点。他祈求他们得着刚强，为要能够领会基督那无限的爱；又祈求他们能领会基督的爱，为要叫他们被充满，达到神丰盛的程度。

<div class="commentary-anchor" id="ephesians-3-21"></div>
第20、21节。保罗的祷告似乎已升至一个极处，信心、盼望、乃至想象都无从再往上去，然而他仍不以此为足。极处之外，仍有无量的广大。神所能作的，不但超过他所求的，更无限地超过他所晓得如何求、如何想的。既已用尽祷告的一切言辞，他便投身于神的无限之中，满有把握地确信：凡全能本身所能成就的，神都能作，也必要作。使徒所期望所渴慕的，其尺度不是我们的祷告，也不是我们至高的心思，乃是神的权能。他将这一意念织成一篇颂赞，其中所有的，属天远多于属地。

此处有两种表达方式合而为一；保罗说 <span style="color:#0000d4">Τῳ ὐπὲρ πάντα</span> <span style="color:#0000d4">ποιῆσαι δύναμένῳ</span>，<span style="color:#800000">*归与那能行超过万事的主，*</span>仿佛这还不够，他又加上一句：<span style="color:#0000d4">ὐπὲρ πάντα ποιῆσαι</span> <span style="color:#0000d4">ὐπερεκπερισσοῦ ων αἰτούμεθα η νοοῦμεν</span><span style="color:#800000">*，超过我们所求所想的。*</span> 神不但在自己本身没有限量，也不受我们的祷告或知识所限制。因此，凡有基督住在其心里、又是祂无限之爱所眷顾的人，他们所可指望的，实在无法划定任何确切的界限。

<!-- PAGE 135 -->

<span style="color:#0000d4">Κατὰ τὴν δύναμιν τὴν ἐνεργουμένην ἐν ἠμῖν</span>，<span style="color:#800000">*照着运行在我们心里的大力*</span>。我们所能指望于神的既是如此之多，那无限的能力如今正运行在我们身上。这正是那曾运行在基督身上的能力，叫他从死里复活，使他坐在神的右边（第一章19至20节）；这能力也在信徒身上成就了相类的变化，叫他从罪的死中复活，又使他在基督耶稣里坐在天上；这能力至今仍扶持并推进救恩在灵魂中的工作。已过之事乃是将来之事的先尝与凭据。凡从死里被救活的人，凡心意更新而变化的人，凡从黑暗的国度被迁入神爱子国度的人，凡神自己藉着圣灵住在其中的人，既已亲身经历了非全能不能成就的改变，自当同声将颂赞归与那位能照着我们所求所想的充充足足成就一切、超过我们所求所想的主。

<span style="color:#800000">*荣耀*</span>，<span style="color:#0000d4">ἡ δόξα</span>，或指当归与神的荣耀，或指神所具有的荣耀。将荣耀归与神，或是称颂他，或是彰显他的荣耀，即使其荣耀被人看见、被人承认。故此，"愿荣耀归与他"这一颂词，既可解作"愿他受称颂"，亦可解作"愿他的荣耀被人承认"。

<span style="color:#800000">*在教会中，藉着基督耶稣。*</span>[^f11] 原文作 <span style="color:#0000d4">ἐν τῃ ἐκκλησίᾳ καὶ ἐν</span> <span style="color:#0000d4">Χριστῳ</span> <span style="color:#0000d4">’</span><span style="color:#0000d4">Ιησοῦ</span>，路德译作<span style="color:#800000">*在那在基督里的教会中*</span>，即基督的教会。数位近代注释家采纳了这一解释。然而若果真如此，<span style="color:#0000d4">ἐν Χριστῳ</span> 之前的冠词 <span style="color:#0000d4">τῃ</span> 就不该省略。况且，既然除基督的教会之外别无他教会可言，加上<span style="color:#800000">*在基督里*</span>这几个字便属多余。所以仍当以通常的解释为是。荣耀要在教会中，并在基督耶稣里、藉着那位作教会元首与代表的基督耶稣，归与神。<span style="color:#800000">*教会*</span>乃是地上与天上一切蒙救赎之人的总集；他们构成一个身体，神要藉此显明他百般的智慧，而这身体也要世世代代将荣耀、尊贵、权柄归与他。

<!-- PAGE 136 -->
永恒或无尽延续的观念，在圣经中有多种表达方式。有时永恒被视为一个整体，于是使用单数的 <span style="color:#0000d4">αίων</span>；有时则被视为世代或时代的无穷相续，于是使用复数的 <span style="color:#0000d4">αἰῶνες</span>。故此，<span style="color:#0000d4">ἐις τὸν αἰῶνα</span> <span style="color:#800000">*直到永远，*</span>与 <span style="color:#0000d4">ἐις τούς</span> <span style="color:#0000d4">αἰῶνας</span>，或 <span style="color:#0000d4">ἐις τοὺς αἰῶνας τῶν αἰῶνων</span><span style="color:#800000">*，直到无限的世世代代，*</span>即无穷的世代，二者同样是指<span style="color:#800000">*永远。*</span>照样，<span style="color:#0000d4">βασιλεὺς τοῦ αἰῶνος</span><span style="color:#800000">*，永恒之王，*</span>与 <span style="color:#0000d4">βασιλευς τῶν αἰῶνων</span><span style="color:#800000">*，无穷世代之王，*</span>都是指<span style="color:#800000">*那永恒的君王。*</span>此处的特别之处在于，使徒把这两种形式合并起来：<span style="color:#0000d4">εἰς πάσας τὰς γενεὰς τοῦ αἰῶνος τῶν</span> <span style="color:#0000d4">αἰώνων</span><span style="color:#800000">*，直到万世无穷之永恒的一切世代。*</span>这与整段上下文层层堆叠的特征正相吻合。使徒既寻不着寻常的措辞足以表达他所要表达的，便把含义最广大的词语堆积在一处，好使那些他自觉无法言传的思想与渴慕稍得宣泄。这些都属于他在罗马书 8:26 所说的 <span style="color:#0000d4">στεναγμοὶ</span> <span style="color:#0000d4">αλαλήτοι</span>。
