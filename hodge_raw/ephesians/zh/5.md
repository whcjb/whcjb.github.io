<p style="text-align:center" markdown="1"><span style="color:#006411">**第五章**</span></p>

具体的劝勉，第3-20节。——夫妻彼此当尽的本分，第21-33节。

<p style="text-align:center" markdown="1">**第一段 — 第3-20节**</p>

<span style="color:#800000">*3. 至于淫乱，并一切污秽，或是贪婪，在你们中间连提都不可，方合圣徒的体统。*</span>

<span style="color:#800000">*4. 淫词、妄语和戏笑的话都不相宜，总要说感谢的话。*</span>

<span style="color:#800000">*5. 因为你们确实地知道，无论是淫乱的，是污秽的，是有贪心的，在基督和神的国里都是无分的；有贪心的，就与拜偶像的一样。*</span>

<span style="color:#800000">*6. 不要被人虚浮的话欺哄；因这些事，神的忿怒必临到那悖逆之子。*</span>

<span style="color:#800000">*7. 所以你们不要与他们同伙。*</span>

<span style="color:#800000">*8. 从前你们是暗昧的，但如今在主里面是光明的，行事为人就当像光明的子女。*</span>

<span style="color:#800000">*9.（光明所结的果子就是一切良善、公义、诚实，）*</span>

<span style="color:#800000">*10. 总要察验何为主所喜悦的事。*</span>

<span style="color:#800000">*11. 那暗昧无益的事，不要与人同行，倒要责备行这事的人。*</span>

<span style="color:#800000">*12. 因为他们暗中所行的，就是提起来也是可耻的。*</span>

<!-- PAGE 194 -->

<span style="color:#800000">*13. 凡受责备的事，都被光显明出来；因为一切能显明的，就是光。*</span>

<span style="color:#800000">*14. 所以主说：你这睡着的人当醒过来，从死里复活，基督就要光照你了。*</span>

<span style="color:#800000">*15. 你们要谨慎行事，不要像愚昧人，当像智慧人，*</span>

<span style="color:#800000">*16. 要爱惜光阴，因为现今的世代邪恶。*</span>

<span style="color:#800000">*17. 所以不要作糊涂人，要明白主的旨意如何。*</span>

<span style="color:#800000">*18. 不要醉酒，酒能使人放荡；乃要被圣灵充满；*</span>

<span style="color:#800000">*19. 当用诗章、颂词、灵歌彼此对说，口唱心和地赞美主；*</span>

<span style="color:#800000">*20. 凡事要奉我们主耶稣基督的名，常常感谢父神；*</span>

<p style="text-align:center" markdown="1">**分析**</p>

<!-- PAGE 195 -->
圣徒所当为者，不仅要远避污秽与贪婪之罪，也要远避一切不合宜的举止与轻浮的言语，第3-4节。因为污秽与贪婪不但使人不得进入天国，而且无论持谬误者如何辩说，这些罪必招致神的忿怒，第5-6节。所以基督徒不当在这些罪上有份，因他们既已蒙神光照，又已领受那光，而此光所结的果子乃是良善、公义、诚实。他们有本分在行事为人上显明这一点，既要远避暗昧之事，又要责备这些事，第7-10节。那些行为污秽可耻，提说尚且不可；然而藉着那光的能力，它们仍可得着改正，而传扬此光正是信徒的特权。故此圣经论到从基督而来的光，说它甚至临到死人，第12-14节。所以基督子民当作智慧人，身处四围的诸般罪恶之中，仍要爱惜光阴，善用每一个行善的机会，第13-16节。他们不当从酒中求欢畅，乃当从圣灵得畅快，并以诗章、颂词抒发心中的喜乐，藉着耶稣基督颂赞感谢神，第17-20节。

<p style="text-align:center" markdown="1">**注释**</p>

<div class="commentary-anchor" id="ephesians-5-3"></div>
第3节。 <span style="color:#800000">*至于淫乱并一切污秽，或是贪婪，在你们中间连提都不可，方合圣徒的体统。*</span>

在前一段中，使徒论及得罪邻舍的罪；自第3节至第20节，则主要论及得罪自己的罪。不但淫乱当避，凡属同类的事、或引人入于此的事，都当避免；不但当避免，甚至在信徒中间连提也不可提。凡这一切的罪，与基督徒作<span style="color:#800000">*圣徒*</span>的身分——即从世界中被拣选、归与神为圣之人——何等不相称，以致在基督徒的交往中连提说都不当有。使徒在此将污秽之罪与<span style="color:#0000d4">πλεονεξία</span>，即<span style="color:#800000">*贪婪*</span>，连在一处，正如前一章第19节所行的。此字当按其通常的意思领会，因上下文中并无任何根据容人另作别解。若以为本节与下节所提的惟有情欲之罪，就必致对其中若干词语作出极牵强的解释。

<div class="commentary-anchor" id="ephesians-5-4"></div>
第4节。<span style="color:#800000">*淫词妄语*</span>。<span style="color:#0000d4">αἰσχρότης</span> 一词并非单指<span style="color:#800000">*猥亵*</span>，而是泛指一切道德上可憎之事。形容词 <span style="color:#0000d4">αἰσχρός</span> 意为<span style="color:#800000">*丑陋、可厌*</span>，即凡引人嫌恶者，无论是身体上的还是道德上的。它与 <span style="color:#0000d4">καλός</span> 相反，后者兼有美与善两义；故 <span style="color:#0000d4">καλόν καὶ τὸ</span> <span style="color:#0000d4">αἰσχρός</span> 即<span style="color:#800000">*德与恶*</span>之意。其名词形式所涵同样广泛，包括言语或行为中一切卑污可厌之事。较轻的恶则以 <span style="color:#0000d4">μωρολογία</span> 与 <span style="color:#0000d4">εὐτραπελία</span> 二词表之，即<span style="color:#800000">*妄语*</span>与<span style="color:#800000">*戏笑的话*</span>。前者指愚人所惯有的言谈，即轻浮无稽之语。后者按其词源与早期用法，意为<span style="color:#800000">*文雅、有礼*</span>。然而此词自然而然地转为贬义，因形容词 <span style="color:#0000d4">εὐτράπελος</span>（<span style="color:#800000">*易于转动者*</span>，如风一般）用于言语时，不仅指机敏、巧妙、悦人、诙谐，也指轻佻、讥讽、粗鄙。因此其名词形式便用以指<span style="color:#800000">*戏谑*</span>与<span style="color:#800000">*秽言*</span>。

<!-- PAGE 196 -->

前一种意义最适合本段经文，因为它与愚妄的话相连，并且使徒论及这二者时，只是简单地说它们<span style="color:#800000">*都不相宜*</span>，即不合体统、不合时宜。若就<span style="color:#0000d4">αἰσχρότης</span>（污秽）或就<span style="color:#0000d4">εὐτραπελία</span>一词更坏的含义而言，这样的措辞未免过于温和。保罗是说，这些事（愚妄的话与戏笑的话）与基督徒不相称；<span style="color:#0000d4">οὐκ ἀνήκοντρα</span>意即<span style="color:#800000">*与人不相干的事*</span>，或<span style="color:#800000">*与其身分职任不相干的事*</span>。愚妄的话与戏笑的话，并非基督徒的喜乐所当藉以流露的方式，当藉以流露的乃是<span style="color:#800000">*感谢*</span>。信仰固然是欢欣快乐的泉源，但其欢乐当以合乎敬虔的方式表达出来，即以感恩与颂赞表达出来。

<div class="commentary-anchor" id="ephesians-5-5"></div>
第5节。使徒回到他在第3节所说的话，并加强其中所发的劝勉。「因为你们确实地知道，无论是淫乱的，是污秽的，是有贪心的，在基督和神的国里都是无分的；有贪心的，就与拜偶像的一样。」此处的表达方式颇为特别：<span style="color:#0000d4">ίστε</span>[^f16] <span style="color:#0000d4">γινώσκοντες</span>，<span style="color:#800000">*你们知道，知道着*</span>。许多解经者将此归于人们熟悉的希伯来文惯用语，即将一个动词的不定式与限定式如此连用；在希腊文和英文中则以分词与动词连用来仿效，如「死你必死」、「增多我必使你增多」、「赐福我必赐福」等等。但在所有这些例子中，不定式与限定式都是同一动词的不同形式。而此处所用的却是不同的词。较可取的解释是：将 <span style="color:#0000d4">ίστε</span> 归于第3节前面所说的，将 <span style="color:#0000d4">γινώσκοντες</span> 归于下文所说的——「这事你们是知道的，即这等事在你们中间连提都不可提，因为你们知道，凡纵容这等事的人，等等。」

<!-- PAGE 197 -->
<span style="color:#800000">*有贪心的，就与拜偶像的一样*</span>。<span style="color:#0000d4">ὅ ἐστιν εἰδωλολάτρης</span> 这几个字，许多人认为是指着前面所有的名词说的，如此则行淫的、污秽的、贪心的，都同样被称为拜偶像的。就文法结构而言，这样解释是可能的；但并不自然，也与歌罗西书 3:5 的平行经文不合，在那里使徒从一连串罪恶中单单挑出贪婪，说"就是拜偶像"。这一说法既有本性上的根据，也有圣经上的根据。这种对钱财至上的爱恋，这种事奉玛门之举，与拜偶像之间的类比，比所提到的任何别的罪与拜偶像之间的类比都更为明显，圣经中也更为清楚地予以承认。这一点应当为人所明白：人当知道，一切罪中最寻常的那一样，在神眼中乃是最可憎的。因为拜偶像，就是把受造之物放在神的地位上，在神的话语中处处被斥为在他眼中一切罪中最大的罪。它可以与外表的体面、与世人的尊敬并行不悖，这一事实并不改变它的本质。它乃是不敬虔之心与不敬虔之生活中那持久而具支配力的原则，使灵魂转离神。对这种毁灭性的贪爱钱财，除了将钱财用于非自私的目的之外，别无医治之法。所以，人若不将钱财用于别人的益处和神的荣耀，钱财必定败坏拥有它的人。

<!-- PAGE 198 -->
使徒说，贪婪之人与淫乱之人一样，在基督的国里都没有基业。所谓基督的国，即基督降世所要建立之国——由一切蒙救赎之人所组成，他们在祂血中得洗净，藉祂的灵得成圣，并在永永远远中完全享受神而得着完全的福乐。这国有时称为基督的国，有时称为神的国；因为基督在哪里作王，神就在哪里作王。此处所用的称谓是 <span style="color:#0000d4">τῃ βασιλείᾳ τοῦ</span> <span style="color:#0000d4">Χριστοῦ καὶ θεοῦ</span>，即那一位同时是 <span style="color:#0000d4">Χριστός</span> 又是 <span style="color:#0000d4">θεός</span> 者的国；既是基督，又是神。这无疑是最自然的解释。正如人人都承认 <span style="color:#0000d4">τῳ Θεῳ καὶ πατρί</span> 意为「归与那位既是神又是父的」，此处没有理由不适用同一规则。可比较提多书 2:13。此种解释使本节成为对我们主之神性的直接断言，为近代若干最卓著的解经家所力主，如哈勒斯与吕克特，前者持正统信仰，后者则属理性主义者。然而另有人说，此处的<span style="color:#800000">*基督*</span>指救赎主，神则指那位神圣者；国度不但称为基督的国，也称为神的国。此说采纳者较众，虽然它违背了文法的通则，因为 <span style="color:#0000d4">θεοῦ</span> 之前并无冠词。若在提多书 2:13 中，<span style="color:#0000d4">ἐπιφάνεια τῆς δόξης τοῦ</span> <span style="color:#0000d4">μεγάλου Θεοῦ καὶ σωτῆρος ἡμῶν</span> <span style="color:#0000d4">’</span><span style="color:#0000d4">Ιησοῦ Χπιστού</span> 意指耶稣基督既是至大的神又是我们的救主，而温纳也承认（《文法》第148页）他之所以不同意该解释，纯粹出于教义上的理由；那么在本处，表达形式如此相似，作者又是同一人，其含义相同便不容合理的怀疑。倘若保罗承认基督是神乃是罕见或不确定之事，则强用文法规则使他教导此教义，便是不当的。但既然他书信中几乎每一页都充满了证据，表明基督就是他的神，那么为阻止他教导此教义而背离那些规则，就是不当的了。

<div class="commentary-anchor" id="ephesians-5-6"></div>
第6节。不单在外邦人中间，就是在各世代、各邦国的众人中间，为使徒在此所指的那些罪开脱，也是常有的事。人们辩称：这些罪根源于我们本性的构造；它们并非恶毒的；它们可以与和善的性情并存；它们并不伤害他人，若无人知晓，便无人因此受损，如此等等。所以保罗警戒教会各世代的读者，不要被这样虚浮的话欺哄，并向他们确言：因这些事（因奸淫和贪婪），神的忿怒必临到那悖逆之子。<span style="color:#800000">*用虚浮的话*</span>，<span style="color:#0000d4">κενοῖς λόγοις</span>。<span style="color:#0000d4">Κενοῖς</span> 意即<span style="color:#800000">*空虚的*</span>。因此 <span style="color:#0000d4">Κενοὶ λόγοι</span> 就是空洞之言；其中并无真理，故既是虚假的，又是欺人的，凡倚靠这等话的人终必发觉如此。<span style="color:#800000">*神的忿怒*</span>。这话是可畏的；因为人的忿怒不过是施加恶害的意向，受人自身软弱的限制；而神的忿怒，乃是一位无论在同在还是能力上都无有界限者施行刑罚的定意。使徒说，这忿怒<span style="color:#800000">*临到*</span>那悖逆之子。此处的现在时，或是用以表明确定的将来，即"必定要临到"；或是取其本义。神对这些罪的忿怒，如今已显明在他对待犯这些罪之人的作为上。他从他们身上收回他的灵，终至任凭他们存邪僻的心。关于"悖逆之子"一语，参第2章2节。

<div class="commentary-anchor" id="ephesians-5-7"></div>
七节。神既如此定意要刑罚污秽的人和贪婪的人，使徒便说：“所以你们不要与他们同伙。”意即：不可在这些罪上与他们为伴，因为这样必然使你们也落在那向他们所发的刑罚之下。

<!-- PAGE 199 -->
<div class="commentary-anchor" id="ephesians-5-8"></div>
第8节。此处借着提及他们从先前罪恶悲惨的光景归正、进入圣洁蒙福的境地，来加强这一劝勉。<span style="color:#800000">*从前你们是暗昧的*</span>。光既代表知识，而知识按圣经的用法必生出圣洁，圣洁又生出福乐；照样，<span style="color:#800000">*黑暗*</span>便代表无知，就是那种必然生出罪、而罪又生出愁苦的无知。所以，“你们是暗昧的”一语，意即你们是无知的、污秽的、可怜的。<span style="color:#800000">*但如今*</span><span style="color:#800000">*在主里面是光明的*</span>，即因着与主联合，你们得了光照、得了成圣、得了福分。<span style="color:#800000">*行事为人就当像光明的子女*</span>，即像圣洁与真理的子女。“光明之子”意即<span style="color:#800000">*受了光照的人*</span>；正如“饥荒之子”意即“挨饿的人”；参看第2章2节。这劝勉是要他们所行的，与他们因与主耶稣联合而成为蒙光照、蒙成圣之人的身份相称。

<div class="commentary-anchor" id="ephesians-5-9"></div>
第9节。<span style="color:#800000">*因为光明所结的果子,*</span>[^f17] 即神光照的果子或果效,乃在于一切,即在于良善、公义、诚实的一切形式之中。良善,<span style="color:#0000d4">ἀγαθωσύνῃ,</span> 乃是使人成为 <span style="color:#0000d4">ἀγαθός</span>（<span style="color:#800000">*良善的*</span>）的那种品质；<span style="color:#800000">*公义*</span>,<span style="color:#0000d4">δικαιοσύνῃ</span>,乃是使人成为 <span style="color:#0000d4">δίκαιος</span>（公义的）的那种品质。这两个希腊文词彼此之间的差别，与英文中相应的两个词之间的差别大体相同。良善是仁爱与施惠；公义是恪守正直的准则。然而二者也都可泛指道德上的卓越。恶人与善人，包括了一切邪恶之辈与一切有德之人。善行乃是凡在道德上卓越的行为，无论属于何种。但当这两个词如罗马书5:7那样彼此对举，或如罗马书7:12那样彼此区别时，<span style="color:#800000">*良善的*</span>便指仁爱的、施惠的；<span style="color:#800000">*公义的*</span>则指公正的、正直的。良善乃是使一物合乎其受造之目的、并使其堪用的那种性质。故此我们不但说好人，也说好树、好土。<span style="color:#800000">*公义*</span>则只能恰当地用于位格，或用于可具道德品格之物；因为公义意即合乎律法；若以公义论律法本身，则意即合乎神的本性——正直的终极标准。<span style="color:#800000">*诚实*</span>在此指宗教上或道德上的真理，或即指敬虔本身。所以，光明所结的果子，乃是敬虔与美德的一切形式。

<!-- PAGE 200 -->
<div class="commentary-anchor" id="ephesians-5-10"></div>
第10节。第9节乃是插入语，因第10节在文法上是与第8节相连的。“行事为人就当像光明的子女，要察验……”，<span style="color:#0000d4">περιπατεῖτε</span>——<span style="color:#0000d4">δοκιμάζοντες</span> 的意思是试，是验，是察考；引申为判断、估定；再引申为认可。所以经上说：“火要试验各人的工程”；又说神“察验人心”；又说我们“心意更新而变化，叫我们察验神的旨意”（罗马书 12:2），即查考并断定神的旨意是什么。本节也是如此，要求信徒行事为人像光明的子女，察验并断定何为主所喜悦的。他们当以何为主所喜悦，作为规范自己行为的准则。凡事是正是邪，是配得还是不配得那从上头蒙了光照的人，最终都当以此为判断的标准。

在新约中，“主”一词绝大多数情况下都是用来指称主耶稣基督的，因此除非上下文不容许，总当归之于他。而此处的上下文非但不禁止，反而要求这样的指称。因为在本句的前半，“主”显然是指基督：“你们在主里面是光，所以行事为人当像光明的子女，总要察验何为主所喜悦的事。”故此，这里又是新约中众多经文之一，承认基督乃是良心之主，他的旨意对我们乃是是非善恶的终极标准；圣经的作者们正是以此表明，基督就是他们的神：他们常活在他的面前，常寻求他的喜悦，他们一切敬虔的情感都以他为归宿。他不仅是他们神学中的神，更是他们宗教生命中的神。

<div class="commentary-anchor" id="ephesians-5-11"></div>
第11节。使徒在前一节中已着重申明基督徒当有的本分，即行事为人要藉着所行的显明自己是蒙神光照之人；此处他又进一步说明，基督徒对那仍在黑暗中之人所犯的罪，当持何等态度。这些罪，他称为“暗昧无益的事”。所谓“无益”，不仅指<span style="color:#800000">*空乏*</span>或<span style="color:#800000">*无价值*</span>，更是积极地指其为恶。因为在道德的事上，凡不是善的，就是恶的。<span style="color:#800000">*暗昧的事*</span>乃是由黑暗所生出的行为，即由不认识神而生出的行为；正如“光明的事”乃是光，或说神的知识，所结出的果子。

<!-- PAGE 201 -->
基督徒对于暗昧之事所当尽的本分有二：其一，不可与之相交；其二，当责备这些事。前者以 <span style="color:#0000d4">μὴ συγκοινωνεῖτε</span> 一语表明，即不要与之有交通。凡彼此共有其物、气味相投、见解情感与利益相同，因而以彼此为乐的人，便称为有交通。在此意义上，信徒与神相交，也彼此相交。同样，凡我们所喜悦、所有分的事，也称为与之有交通。故此，与暗昧之事有交通，就是喜悦这些事并有分于其中。凡此一切结交都在禁止之列，因与光明之子的身分不相称。我们的第二重本分乃是<span style="color:#800000">*责备这些事*</span>。<span style="color:#0000d4">’</span><span style="color:#0000d4">Ελέγχειν</span> 并非仅指劝诫或斥责意义上的责备，而是指以凭据使人信服。它所表达的，乃是光照所生的果效，藉此将一事的真相显明出来。所谓圣灵叫人为罪自责，意思就是他将亮光照在人的罪上，使其真面目显露，因而生出对罪咎与污秽的自觉。在哥林多前书 14:24，保罗说明白传讲福音所生的果效乃是使人知罪——其解释便是“他心里的隐情显露出来”。所以此处所吩咐的本分，就是将亮光照在这些暗昧的行为之上，把它们照其真相显为可鄙可憎、能败坏人的事。用这方法，这些行为便得以纠正；下文数节对此有更详尽的教导。圣经的伦理与圣经的神学同样建基于这一原则：知识与圣洁、无知与罪恶，彼此不可分离。你若将知识传与人，就是使人得圣洁；你若使人无知，就是使人败坏。这话自然不适用于世俗知识——即宗教以外各题目的知识；也不适用于对宗教真理仅有的思辨性知识。它惟独适用于圣经所称为属灵悟性的那种知识。然而在那种知识里，理智上的认知乃是不可缺的要素。至于人在使人知罪一事上所能尽的功用，则仅限于将生命的道表明出来；或者说，让神真理的亮光照进人昏暗的心思，照在他们的恶行之上。

<div class="commentary-anchor" id="ephesians-5-12"></div>
第12节。这些暗昧的行为理当如此责备，**“因为他们暗中所行的，就是提起来也是可耻的。”** 罪之所以被称为暗昧的行为，有两个缘由。第一个也是主要的缘由，如前所述，乃因这些行为出于黑暗，即出于对神的无知；第二个缘由，则因这些行为是在黑暗中所犯的。它们躲避光。使徒正是以这些罪的极度可耻，作为当责备它们的理由。

<!-- PAGE 202 -->
<div class="commentary-anchor" id="ephesians-5-13"></div>
第13节。然而，这些罪虽然可憎，却并非不可纠正。它们并非无药可医。当责备它们。将神圣真理之光照入其中，它们便必得纠正或医治。因为真理有属神的功效。它是神的工具（organon）；神正是藉着它施展大能，使人成圣得救。这节难解的经文，其大意似乎正在于此。

本节与前一节相连，意在强化那命令：<span style="color:#0000d4">ἐλέγχετε,</span> <span style="color:#800000">*责备*</span>。‘要责备恶人暗中所行的事——这些事虽污秽得连提都不可提，然而一经责备，便藉着光显明出来，因而得着改正；因为凡被显明的，即凡藉神的光而其真相被揭露的，就成为光，也就是说，得了改造。’此解释所得之意简明而前后一贯，既不假定所用词语有何不寻常之义，也不强作牵合之结构，且与上下文相合。此说预设：一、<span style="color:#0000d4">τὰ πάντα ἐλεγχόμενα</span> 是指第12节的 <span style="color:#0000d4">τὰ κρυφῃ γινόμενα</span>。暗中所行的事就是那<span style="color:#800000">*一切的事*</span>，这些事一受责备，就被显明。二、<span style="color:#0000d4">ὐπὸ τοῦ φωτός</span> 不应与 <span style="color:#0000d4">ἐλεγχόμενα</span> 相连，仿佛意思是‘被光所责备’；乃应与 <span style="color:#0000d4">φανερούται</span> 相连，故其意为‘藉着光被显明’。下一分句要求如此解析。三、<span style="color:#0000d4">Φανερούμενον</span> 是被动，而非带主动之意的中间语态。其义为‘凡被显明的’，而非‘凡使之显明的’。既然紧接在前的 <span style="color:#0000d4">φανερούται</span> 一词是被动，把 <span style="color:#0000d4">φανερούμενον</span> 解作主动便不自然。况且使徒在此所论的，并非属灵之光的性质，乃是其功效。光所触及之处，或凡光所透入之处，无不被它照亮，化为光明。

<!-- PAGE 203 -->
倘若将 <span style="color:#0000d4">Φανερούμενον</span> 视为主动意义——如加尔文及其他许多人所为，我们的译者亦然——其意便是：“要责备这些事；这是你们的职分，因为你们是光，而光乃是显明一切的。”然而这并非保罗所言。他并非说“要责备恶事，因为你们是光”，乃是说“要责备恶事，因为恶事被光责备时就显明出来，既显明出来，就成了光”，也就是说，它被变为光，或被纠正过来。在第8节，他曾说“你们是光”；故此在这里他说，凡被真理照明的，便成为光。二处的意思是一样的。属灵之光，即神的真理，其贯透之力何其大，以致凡它所住之人，无不被它照明、被它成圣。因此使徒在别处祈求，愿神的道用诸般的智慧和属灵的悟性住在信徒心里。按使徒所说，真理与圣洁之间的关系，正如光与视觉之间的关系。光不能造出眼睛，也不能使瞎眼得见。然而眼目的运用却断不能离了光。光所透入之处，黑暗即被驱散，万物尽显于目前——并使之产生其当有的果效。照样，真理不能使人重生，也不能赋予属灵生命的本原。然而一切圣洁的操练却断不能离了真理。真理所透入之处，谬妄的云雾即被驱散，万事尽显于目前，以致当人以属灵的眼光辨明之时，真理便在灵魂里生出其当有的果效。真理既是如此不可或缺，基督徒就有本分将真理施于一切无知之人，并一切暗昧的行为之上。

<!-- PAGE 204 -->
<div class="commentary-anchor" id="ephesians-5-14"></div>
第14节。 既然光如此有效，又是可以亲近、可以得着的，所以圣经甚至呼唤沉睡的人和死了的人起来，迎向这赐生命的光辉。<span style="color:#0000d4">Διὸ λέγει</span>，即 <span style="color:#0000d4">ἡ  γραφή</span>。此种引证格式在新约中除引用旧约之外从不使用，故不可妄自设想使徒在此所引的是以弗所信徒所熟悉的某首基督徒诗歌，或某卷伪经，或某卷已不存世的受默示之书。我们只能这样理解他：或是他在此提及旧约圣经中许多劝勉之语，而以此处寥寥数言概括其要义；或是他道出某一段经文的精神，虽未照其字句。这两种解释方式都可以借相似的经文得到支持。使徒们引用旧约时，有时将数处经文合于同一引证之中；有时又把某事说成是先知们的教训，而那事在先知书中并无明文教导或断言，却在其言语中充分而清楚地含蕴着。另有些时候，所指显然是某一处经文，然而既不严守希伯来原文，也不严守七十士译本，只是重述其大意而已。我们虽没有使徒所有的权柄与神的引导，却也以同样的方式处理神的话，几乎每一篇讲道都可举出例证。一般认为保罗此处所指的是以赛亚书 60:1：“兴起发光！因为你的光已经来到，耶和华的荣耀发现照耀你。”或照德维特的译法：“Auf, werde licht, denn es kommt dein Licht, und die Herrlichkeit Jehovah’s gehet uber dir auf.” <span style="color:#800000">*起来，成为光；因为你的光*</span> <span style="color:#800000">*已来到，耶和华的荣耀在你之上升起*</span>。这段经文与使徒的引证之间的类似之处是显而易见的。两处都有：1. 呼召那沉睡的或死了的人起来。2. 呼召他们接受那光。3. 应许耶和华、主、或基督（在使徒心中乃是同义之称）必将光赐给他们。因此几乎无可置疑，保罗有意就其大意所引的，正是以赛亚的话。伯撒认为以赛亚书 26:19“睡在尘埃的啊，要醒起歌唱”等语也当包含在所指之内；另有人加上以赛亚书 9:2“在黑暗中行走的百姓看见了大光；住在死荫之地的人有光照耀他们。”诚然，在这些经文以及其他经文中，都包含着光（即神之真理）的能力、它在基督身上的降临，以及对身处黑暗之人接受它的呼召。但最有可能的是，以赛亚书 60:1 才是使徒心中最为清晰的那一处经文。

睡着的人与死了的人都在黑暗之中，故此凡陷于属灵黑暗中的人，就被称为睡着的。从基督而来的光有能力临到死人，正如我们的主用另一比喻所说的：“时候将到，现在就是了，死人要听见神儿子的声音，听见的人就要活了”（约翰福音 5:25）。这并非说死人必须先复活，然后才听见神儿子的声音；乃是他的声音使他们听见而得生。故此我们眼前这段经文，也不是说睡着的人必须先从死里起来、到基督那里求光；而是说基督周遭所发的光，有能力唤醒那沉睡的死人。如此，这一节便印证了上一节所言，即：凡被光显明出来的，就是光。

<!-- PAGE 205 -->
<div class="commentary-anchor" id="ephesians-5-15"></div>
第15节。若将本节视为借 ouv 与上文构成推论性的关联，则思路的连结是：“信徒既有责任驱散他人心中与生活中的黑暗，就当何等谨慎，免得自己反倒处在黑暗之中，就是说，他们当像智慧人那样行事为人。”然而这样的联系似乎失之牵强。本节与下一节所含的劝勉，最自然的关联乃是第10、11两节中的劝勉。信徒既是光明之子，就当与暗昧的行为无份，倒要责备行这事的人；<span style="color:#800000">*所以你们要谨慎*</span>，即：因此要留意，<span style="color:#0000d4">πῶς ἀκριβῶς περιπατεῖτε</span>，<span style="color:#800000">*行事为人要严谨*</span>。然而 <span style="color:#0000d4">Πῶς</span> 并不作 <span style="color:#800000">*那*</span> 解，虽然它常用在本可使用 <span style="color:#0000d4">ὅτι</span> 或 <span style="color:#0000d4">ἵνα</span> 之处。此处与别处一样，它的意思是 <span style="color:#800000">*如何、以何等方式*</span>。“要看你们以何等方式使自己的举止合乎准绳。”<span style="color:#0000d4">’</span><span style="color:#0000d4">Ακριβῶς περιπατεῖτε</span> 意即严格按着规矩而行，丝毫不偏离。<span style="color:#800000">*不要像愚昧人，当像智慧人*</span>。保罗常以 <span style="color:#0000d4">σοφία</span> 一词指神的真理。<span style="color:#0000d4">σοφοί</span> 就是拥有这真理之人——他先前称这真理为光——而 <span style="color:#0000d4">άσοφοι</span> 则是没有这真理的人。因此，此处的 <span style="color:#800000">*智慧人*</span> 与 <span style="color:#800000">*愚昧人*</span>，相当于 <span style="color:#800000">*得光照的人*</span> 与 <span style="color:#800000">*在黑暗中的人*</span>。所以他的劝勉是：信徒行事为人当存谨慎，不可像外邦人和未蒙重生之人那样——他们没有使徒方才所论的那属神之光——而要像那些从上头得了光照、因而有智慧的人那样。

<!-- PAGE 206 -->
<div class="commentary-anchor" id="ephesians-5-16"></div>
第16节。<span style="color:#0000d4">’</span><span style="color:#0000d4">Εξαγοραζόμενοι τὸν καιρόν</span>，<span style="color:#800000">*要爱惜光阴*</span>。这是智慧的一种表现，是他们作为光明之子的基督徒品格当有的一种彰显方式。这几个字的解释向来不一：——1. 利用、把握行善的时机，不让它白白过去。2. 把时间赎回来，仿佛从撒但或从世界手中赎回。3. 尽量善用时间，即以最有益的方式使用光阴。4. 使自己适应时势，等等。在这几种看法之间取舍，一部分取决于 <span style="color:#0000d4">ἐξαγοραζόμενοι</span> 当作何解，一部分取决于 <span style="color:#0000d4">καιρός</span> 是当按其本义解作<span style="color:#800000">*时机、合宜的时候*</span>，还是按 <span style="color:#0000d4">καιρός</span> 的泛义解作<span style="color:#800000">*时间*</span>。<span style="color:#0000d4">ἀγοράζειν</span> 与 <span style="color:#0000d4">ἐξαγοράζειν</span> 二字都含有以价购得之意。后者因 <span style="color:#0000d4">ἐκ</span> 的力量，本义为赎回，或以赎价使之得自由。但它也可用作单纯动词之义，如但以理书 2:8 中所见；本节的说法大概即由此而来。在该处，按七十士译本，王对那些不先知梦的内容便不肯解梦的迦勒底人说：<span style="color:#0000d4">οϊδα ελὼ καιπὸν</span> <span style="color:#0000d4">ὑμεῖς ἐξαγοράζετε</span>，“我知道你们是要拖延时间。”动词的这一含义与我们眼前的经文相合。于是，若 <span style="color:#0000d4">καιρός</span> 在此与它在新约几乎所有其他出现之处同义，则这一分句最自然的解释便是“把握时机”，即善用一切行善的机会。若把 <span style="color:#0000d4">καιρός</span> 当作 <span style="color:#0000d4">κρόνος</span>（这样解勉强可通），意思便是“尽量善用时间”，即不让光阴虚掷或滥用。这两种解释都是好的，也都与下面一句相合：<span style="color:#800000">*因为现今的世代邪恶*</span>。<span style="color:#0000d4">Πονηρός</span>，<span style="color:#800000">*邪恶*</span>，可按物质的意义解，也可按道德的意义解。族长说：“我平生的年日又少又苦”（创世记 47:9）。然而按上下文，此字的道德含义更为合宜。<span style="color:#800000">*邪恶的日子*</span>，指罪恶充斥的日子。这与“邪恶的世代”（马太福音 12:39）、“罪恶的世代”（加拉太书 1:4）等说法相平行。罪恶充斥，正是基督徒当抓住每一个行善机会的充分理由，也是他们当尽量善用光阴的理由。所以这一分句与本节前半的任何一种解释都相合。而 <span style="color:#0000d4">καιρός</span> 的本义与通常用法既是<span style="color:#800000">*时机*</span>或<span style="color:#800000">*合宜的时候*</span>，这便是宁取上述前一种解释的有力理由。同样的劝勉、在同样的关联中，也见于歌罗西书 4:5。使徒在那里说：“你们要用智慧与外人交往，爱惜光阴。”可见这样善用光阴，或抓住每一个行善的机会，在两处都被表明为智慧的凭据与果效，即神所启示的、作为神智慧的神圣真理的果效（哥林多前书 2:6-13）。

<div class="commentary-anchor" id="ephesians-5-17"></div>
第17节。<span style="color:#800000">*所以*</span>，即或是因为这世代邪恶，或是因为你们理当像智慧人那样行。后一种连接更可取，因为此处所指的是前面第15、16两节的主要思想，而非其中的从属分句。<span style="color:#800000">*不要作*</span><span style="color:#0000d4">άφρονες</span><span style="color:#800000">*无知的、不思不想的、轻浮的人。*</span>可比照路加福音11:40，“你们这愚拙的人哪（你们这不思想的人哪），造外面的，不也造里面吗？”又见路加福音12:20；哥林多前书15:36；哥林多后书11:16等处。在这一切经文中，<span style="color:#0000d4">άφρων</span>都是指那不正当使用自己悟性的人；他不按事物的真实光景去看事物，也不按其相对轻重去衡量事物。此处该词与<span style="color:#0000d4">συνιέντες</span>相对。‘你们不要作无知的人，对真与假、是与非、重要与不重要之间毫无分辨，却要作明白的人，即分辨何为主的旨意。’也就是说，要照着主看事物的眼光去看事物，以他的旨意或判断为你们自己判断的标准，为你们行事的准则。主的旨意即基督的旨意。此处的“主”指基督，这不仅从新约一贯的用法（前面已多次提及）可以明白，也从本章中该词始终用以称呼救赎主一事上得见。所以在此又一次看出，基督的神性乃是一项实践的教义，进入信徒日常的敬虔生活之中。他的旨意就是真理与本分的准则。

<div class="commentary-anchor" id="ephesians-5-18"></div>
第18节。<span style="color:#800000">*不要醉酒*</span>（此为尤当戒者）。这乃是一种 <span style="color:#0000d4">ἀφόσθνη</span>，即缺乏理智，与真信徒所有的悟性最为不合。人若有正当的辨别力，就不会从酒中寻求爽快与兴奋，乃从圣灵求之。因此使徒接着说，<span style="color:#800000">*乃要被圣灵充满*</span>。他说，醉酒中有 <span style="color:#0000d4">ἀσωτία</span>，即<span style="color:#800000">*放荡、淫乱、狂宴*</span>，凡趋于败亡之事皆是；因这字源于 <span style="color:#0000d4">άσωτος</span>，意即<span style="color:#800000">*不能得救的*</span>，指那沉溺于败亡生活之人。参提多书1:6；彼得前书4:4。人全然受酒力支配时，便说他被酒充满；照样，当圣灵掌管人一切的思想、情感、言语与行为时，便说他被圣灵充满。此语在圣经中甚为常见。论到我们的主自己，经上说：“他被圣灵充满”，路加福音4:1；论到司提反，说他“大有信心，圣灵充满”，使徒行传6:5；论到巴拿巴亦然，使徒行传11:35等。所以对基督徒而言，力量与喜乐的源头不是酒，乃是神有福的圣灵。醉酒既生出狂宴与淫乱，圣灵也照样生出喜乐，这喜乐藉着诗章、颂词、灵歌发表出来。Quid gignit ebrietas? dissolutam proterviam, ut quasi excusso freno indecenter homines exultent. <div class="commentary-anchor" id="ephesians-5-19"></div>
第19节。<span style="color:#0000d4">Λαλοῦντες ἑαυτοῖς</span>（即 <span style="color:#0000d4">ἀλλήλοις</span>，如4:32及别处所用），<span style="color:#800000">*彼此对说，而非对自己说*</span>。可比较歌罗西书 3:16，那里作 <span style="color:#0000d4">διδάσκοντες καὶ νουθετοῦντες ἑαυτούς</span>，<span style="color:#800000">*彼此教导，互相劝戒*</span>。“彼此对说”，是指藉所唱的诗章与颂词而有的思想与情感的交流。一般认为，这是指基督徒在私下聚集与公开敬拜中轮唱应和的方式；小普林尼那段著名的话——<span style="color:#800000">*Carmen Christo quasi Deo dicunt secum invicem*</span>（他们彼此轮流歌颂基督，如同歌颂神一般）——似乎也是指此而言。然而，从歌罗西书的平行经文看（保罗在那里说到他们彼此教导），本节是否指轮唱应和的方式尚属可疑；但无论如何，它至少证明：歌唱自起初就是基督徒敬拜的一部分，且所用的不仅有诗篇，也有颂词。

<span style="color:#0000d4">ψαλμός, ὕμνος, ῳδή</span> 这几个词早期的用法，似乎与我们今日所用的相应英文词 <span style="color:#800000">*诗篇、颂词、灵歌*</span> 一样宽泛。诗篇即是颂词，颂词即是歌。然而它们之间仍有分别，如今也依然如此。1. <span style="color:#800000">*诗篇*</span>，按 <span style="color:#0000d4">ψαλμός</span> 一词的词源，乃是配合乐器伴奏而唱的歌。2. 它指诗篇一书中所载的圣诗，如使徒行传 13:33，<span style="color:#0000d4">ἐν τῳ ψαλμῳ τῳ δευτέρῳ</span>，<span style="color:#800000">*在第二篇诗上*</span>；又如使徒行传 1:20，<span style="color:#0000d4">ἐν βίβλῳ ψαλμῶν</span>，<span style="color:#800000">*在诗篇上*</span>。3. 指一切仿照旧约诗篇体裁所作的圣诗，如哥林多前书 14:26，那里的 <span style="color:#0000d4">ψαλμόν</span> 似乎是指藉着默示所赐下的这类诗歌，而非大卫的诗篇之一。<span style="color:#800000">*颂词*</span>则是颂赞神的歌，即属神的诗歌。亚里安（ARRIAN），《亚历山大远征记》卷四：<span style="color:#0000d4">Θεοὺς ὕμνοι μὲν ἐς τοὺς ποιοῦνται, ἕπαινοι δὲ ἐς ἀνθρώποθς</span>。

AMMON. de differ. vocbl. <span style="color:#0000d4">ὁ μὲν γὰρ ὕμνος έστι θεῶν, τὸ δὲ</span> <span style="color:#0000d4">ἐγκώμιον τῶν ἀνθρώπων</span>. PHAVOR. <span style="color:#0000d4">ὕμνος, ἡ πρὸς θεὸν ῳδή</span>.

既然这词的一般意义如此，约瑟夫便用它来指那些颂赞神的诗篇：<span style="color:#0000d4">ὁ Δαυιδος ῳδὰς εἰς τὸν</span> <span style="color:#0000d4">Θεὸν καὶ ὕμνους συνετάξατο</span>，《犹太古史》7卷12章3节。诗章与颂词，无论在当时或如今，都是宗教的歌唱；至于 <span style="color:#0000d4">ῳδαί</span>，则或属宗教，或属世俗，因此此处所指的便以<span style="color:#800000">*灵歌*</span>来限定。这或可指<span style="color:#800000">*受圣灵默示的*</span>，即出于圣灵；或指表达属灵的思想与情感的。后一解较为可取；因为被圣灵充满，并非单指受默示的人，也指一切在日常思想与情感上受圣灵管治的人。

<!-- PAGE 209 -->

<span style="color:#800000">*口唱心和地赞美主*</span>。此句若视为与前句并列，则所指乃另一种歌唱。前者以 <span style="color:#0000d4">λαλοῦντες ἑαυτοῖς</span> 表达，是发声而唱；后者以 <span style="color:#0000d4">ᾳδοντες ἐν τῃ καρδίᾳ</span> 表达，乃心灵之乐，是情感的韵律，未形诸言语。赞成此说者，有近代数位最优秀的注释家，如哈勒斯（Harless）、吕克特（Ruckert）、奥尔斯豪森（Olshausen）与迈尔（Meyer）。他们所持的理由是：使徒所说的是 <span style="color:#0000d4">ᾳδοντες</span> <span style="color:#0000d4">ἐν τῃ καρδίᾳ ὐμῶν</span>，而非仅仅 <span style="color:#0000d4">ἐκ τῃ καρδίᾳ</span>，<span style="color:#800000">*发自内心*</span>；又说，倘若他的意思不过是歌唱当出于诚心，则代词 <span style="color:#0000d4">ὐμῶν</span>（<span style="color:#800000">*你们的*</span>）便属多余。况且此处所指的歌唱，乃是被圣灵充满之人的歌唱，因此告诫他们不可徒以口舌事奉，实属不必。虽有这些理由，绝大多数注释家仍以此句从属于前句，视之为对所要求之歌唱的描述：“你们当彼此用诗章、颂词相和，心中歌唱。”可比较罗马书 1:9，使徒在那里说 <span style="color:#0000d4">ῳ λατπεύν</span>（不是 <span style="color:#0000d4">ἐκ</span> <span style="color:#0000d4">πνεύματος</span>）而是 <span style="color:#0000d4">ἐν τῳ πνεύματί μου</span>，<span style="color:#800000">*我用心灵所事奉的*</span>，并参哥林多前书 14:15。要离弃对本节的通常解释，并无充分理由。

<span style="color:#0000d4">ᾳδοντες καὶ ψάλλοντες,</span> <span style="color:#800000">*口唱心和*</span>，此二语乃同一事之两种表述。后者涵义较广；盖 <span style="color:#0000d4">αίδειν</span> 是以声音作乐，<span style="color:#0000d4">ψάλλειν</span> 则是 <span style="color:#800000">*以任何方式作乐*</span>：按字义是弹奏弦乐器，继而指和着弦乐而歌，再而泛指歌唱或吟咏。参看哥林多前书 14:15；雅各书 5:13；罗马书 15:9。

<span style="color:#800000">*向主*</span>，即向基督。在平行经文歌罗西书 3:16 中，则是向神。二者意思相同。我们敬拜基督，即是敬拜神。然而，在基督里的神，乃是基督徒敬拜确定而特殊的对象；心中充满圣灵之人，必本能地转向祂。这种对基督的特殊敬拜，既不与对父的敬拜相悖，也从未与之分离。此一敬拜自然汇入彼一敬拜。且

第20节。因此使徒将这两件事连在一起：“你们要被圣灵充满，歌颂基督，又感谢神，就是父。”

圣灵所默示的这一样，与那一样同是自然而然的。我们当<span style="color:#800000">*常常*</span>感谢。这不是一次作过便了的本分，也不是单在蒙受新恩之时才行；乃要常常如此，因为我们既已领受属世与属灵的诸般福分，便负有当尽之责，这就要求我们不住地称谢。我们要<span style="color:#800000">*凡事谢恩*</span>；古代的解经家说，这包括患难，也包括喜乐。此意本文并未明言，虽然从别处经文可知，保罗确以他所受的患难夸口。此处这话乃为上下文所限定，即<span style="color:#800000">*为我们所蒙的一切恩惠。奉我们主耶稣的名*</span>。使徒奉主耶稣的名传道；奉他的名行神迹；信徒也受命奉他的名祷告，奉他的名谢恩，奉他的名行一切事。在这一切事上，总的意思正如本革尔（Bengel）所言：ut perinde sit, ac si Christus faciat（使其如同基督亲自行事一般）。我们奉基督的名所行的，乃是凭他的权柄而行，并且倚靠他使之成就。基督使我们得以进到父面前；我们藉着他来到神那里；这前来的权利是他所赐的，我们前来之时蒙悦纳，也全在乎他。<span style="color:#0000d4">Τῳ Θεῳ καὶ πατρί</span>，<span style="color:#800000">*父神*</span>，即归与我们主耶稣基督的父神。这是新约时代神的立约名号，也是我们唯一可据以称他为我们的父、并来到他面前的根基。

<p style="text-align:center" markdown="1">**分析**</p>

使徒吩咐信徒彼此顺服，以此为基督徒的本分，见第2节。在这一题目之下，他论及夫妻、父母与儿女、主人与仆人彼此当尽的本分。本章余下的部分专论夫妻之间的本分。因婚姻的关系与基督同教会的关系相类，故此二者可以彼此发明。所以使徒在这一整段中，将两个题目交织并论。

妻子当顺服丈夫，如同教会顺服基督。其一，此顺服的动机，乃是顾念主，见第22节。其二，此顺服的根据，乃是丈夫为妻子的头，正如基督为教会的头，见第23节。其三，此顺服不限于某一方面，乃是凡事都当如此，见第24节。

丈夫当爱妻子。1. 这爱的尺度，就是基督爱教会的爱，他为救赎教会而舍命，25-27节。2. 爱的根据，在两处是相同的——妻子是丈夫骨中的骨，肉中的肉。教会也照样是基督骨中的骨，肉中的肉。丈夫与妻子乃是一体；基督与教会也是如此。论及此者为真的，论及彼者亦为真，29-31节。3. 基督与他教会之间的联合，其位分固然高于丈夫与妻子之间的联合——然而两者之间的类比，足以使丈夫有本分爱妻子如同爱自己，也使妻子有本分敬重丈夫。32-33节。

<p style="text-align:center" markdown="1">**注释**</p>

<!-- PAGE 213 -->
<div class="commentary-anchor" id="ephesians-5-21"></div>
第21节。本节开始一个新的段落，这一点学者大体公认。其一，因为前面的劝勉在第20节显然已告一段落——即以<span style="color:#800000">*归与神，就是父*</span>这几个字作结。其二，因为彼此顺服的命令，贯穿本章其余部分并延及下一章的一部分，与上文并无自然的衔接。既然如此，本节开首的分词<span style="color:#0000d4">ὐποτασσόμενοι</span>，即<span style="color:#800000">*当顺服*</span>，就不能解作承接第18节的动词<span style="color:#0000d4">πληροῦσθε</span>。若如此解，意思便成了“要被圣灵充满，彼此顺服。”基于上述理由，多数注释家皆不取此种解法。另有人以此分词作命令语气，译为“你们要彼此顺服。”但这与该语言的用法不合。最通行的解释，是将本节与下文相连：“既然你们彼此顺服（这本是你们当尽的本分），你们作妻子的，就当顺服自己的丈夫。”由这普遍的顺服之义务，引出妻子、儿女、仆人各自特殊的义务，正如下文所阐明的。

彼此顺服的命令，也见于新约其他经文，如彼得前书 5:5：“你们众人也都要以谦卑束腰，彼此顺服。”又如罗马书 12:10、腓立比书 2:3。圣经在这一题目上的教训是：人并非彼此隔绝的个体，各自独立于众人之外。没有人为自己活，也没有人为自己死。人在本质上的平等，以及彼此之间的相互倚赖，正是彼此顺服之义务的根基。然而使徒在此所论的，乃是基督徒的本分。因此本节所讲的，是彼此顺服这一基督徒的本分。它不但禁止骄傲、禁止一切自居高位之举，更吩咐人要彼此顺服，就是部分顺服全体，各人顺服那些与自己有特殊联系的信徒同伴。每一个基督徒，其信仰与行为都要向主内的弟兄负责，因为他与他们同构成一个身体，有共同的信仰，共同的生命。若说一个基督徒可以独立于众信徒之外，或一个基督徒团体可以独立于一切同类团体之外，这既与信徒彼此所处的关系不合，也与圣经的明令相违。

<!-- PAGE 214 -->
我们当如此彼此顺服，乃是 <span style="color:#0000d4">ἐν φόβῳ Χριστοῦ</span>。[^f18] 此语或可解作：对基督的敬畏——我们都要站在他台前受审——当催促我们如此彼此顺服；或可解作：此本分当以敬虔之心履行。其动机当是对基督的敬畏，是顾念他的旨意、顾念他的荣耀。正是藉着这条途径，一切社会本分，纵然是最卑微屈己的，也被提升到宗教的境界，并且与最高的尊荣和自由并行不悖。当使徒论到仆人对主人的本分时，尤其着力申明这一点。还有一点不应逃过读者的注意：本节及类似经文所设定的我们与基督之间的关系，是我们唯独可以与一位有神性的位格所建立的关系。那位我们要向他交代一切行为、敬畏他乃是履行本分之首要动机的，正是神。

<div class="commentary-anchor" id="ephesians-5-22"></div>
22节。<span style="color:#800000">*你们作妻子的，当顺服自己的丈夫，如同顺服主*</span>。彼此顺服这一普遍的本分，包含了妻子顺服丈夫这一特定的本分，由此使徒便转而论及丈夫与妻子彼此相待的本分。又因婚姻的关系与基督和他教会之间的关系相类，使徒遂以此喻彼，彼此相互阐明。关系既是相同的，由此而生的本分也是相同的：妻子当顺服，丈夫当爱。使徒在此教导妻子当向丈夫所尽之顺服的性质、根据与范围。

至于这顺服的性质，乃是宗教性的。这顺服是 <span style="color:#0000d4">ὡς τῳ Κυρίῳ</span>，即<span style="color:#800000">*如同顺服主*</span>。此处的 <span style="color:#0000d4">ὡς</span> 并非表示相似，仿佛妻子顺服丈夫，当如她理当向主所献的顺服那般虔敬、那般无条件。乃是说，她对丈夫的顺服，当视为她对主之顺服的一部分。参看 6:5, 6。这顺服最终归于主，因此是宗教性的，既由宗教的动机所决定，又指向宗教情感所归的对象。正因如此，担子就轻省，轭就容易了。因为信徒向基督所献的一切服事，无不是甘心乐意、欢欢喜喜地献上的。

<!-- PAGE 215 -->
<div class="commentary-anchor" id="ephesians-5-23"></div>
第23节。 然而，妻子顺服丈夫虽因由属灵动机所定，故具宗教义务的性质，却与神其余一切诫命一样，在本性中亦有其根基。故此使徒说，妻子当顺服自己的丈夫，<span style="color:#800000">*因为丈夫是妻子的头，如同基督是教会的头*</span>。所以，这一义务在本性中所立的根据，乃是丈夫的优越；即他在那些使他有能力、有资格发号施令的属性上占有优势。他形体更大、力量更强、胆识更壮；作首领所需的心智与德性上的素质，他也更为具备。这一点之明显，正如铁比水重之明显，历史足以为证。因此，男人就其有资格、有能力治理这一方面而言，被称为神的形像和荣耀（哥林多前书 11:7）；正如使徒在该处接着补充的，男人不是由女人而出，女人乃是由男人而出；并且男人不是为女人造的，女人乃是为男人造的。男人在上述各方面的优越，既为圣经所教导，又根基于本性，且为一切经验所证实，若加以否认或漠视，必致败坏社会，并使男女双双堕落：使男人流于柔弱，使女人流于粗豪。然而，男人的这种优越，不但与两性彼此依存、与两性本质上的平等、与他们在神国中的平等并行不悖，亦与男人在权柄以外的其他素质上不及女人的事实并行不悖。圣经的教训一面命妻子顺服丈夫，为秩序奠定根基；一面又高抬妻子，使她成为丈夫的伴侣与服事的天使。因此，单就这一点而论，丈夫与妻子的关系，正如基督与教会的关系。不过，基督与教会之间尚有一重关系，是丈夫与妻子之间所无从比拟的。基督不仅是教会的头，更是教会的救主，<span style="color:#0000d4">καὶ αὐτὸς</span> <span style="color:#0000d4">ἐστι σωτὴρ τοῦ σώματος</span>。使徒为何加上这几句话，不易断定。或许是为标明这两种本来极为相似的情形之间的分别。又或许如许多人所设想的，是为提醒丈夫有责任保障妻子的安全与幸福：因基督是教会的头，所以是教会的救主；照样，丈夫既是妻子的头，就不但当治理，也当保护她、赐福与她。[^f19] 最可能的解释是：使徒的用意不单在于教导夫妻关系的性质，也在于教导基督与教会之间关系的性质，故加上这一句以达此目的，而与夫妻关系并无干涉。这一句并非与前句同位，乃是独立的一个命题：基督是教会的头；并且他是他身体的救主。

<!-- PAGE 216 -->
<div class="commentary-anchor" id="ephesians-5-24"></div>
第24节。**但**，<span style="color:#0000d4">ἀλλὰ</span>，即：虽然基督与教会的关系中有这一特殊之处，是妻子与丈夫的关系所无从比拟的，"然而，正如丈夫是妻子的头，妻子也当<span style="color:#800000">*凡事*</span>顺服自己的丈夫，如同教会顺服她的元首基督一样。"我们的译者在此赋予 <span style="color:#0000d4">ἀλλὰ</span> 一种三段论式的意味，译作<span style="color:#800000">*所以*</span>，仿佛它是要引出上文论证的结论。但这与该虚词的通常用法不合，而且也无此必要，因为按其寻常的意思已足以给出良好的意义。

第22节既教导妻子顺服丈夫的性质，第23节教导其根据，那么本节所教导的便是其范围。她当凡事顺服，<span style="color:#0000d4">ἐν παντί</span>，<span style="color:#800000">*凡事*</span>。就是说，这顺服并不限于社会生活中的某一范围或某一部分，乃是遍及一切。妻子并非在某些事上顺服，在另一些事上独立，乃是在一切事上都顺服。这自然不是说丈夫的权柄漫无限制。此处所教导的是权柄的范围，而非其程度。权柄遍及一切领域，但在一切领域中皆有其界限：其一，受这关系本身的性质所限；其二，受神更高之权柄所限。任何在上者，无论为主人、父母、丈夫或官长，都不能使我们有义务去行神所禁止的事，或不行神所吩咐的事。只要我们对神的忠顺得以保全，并且对人的顺从乃是我们顺从神的一部分，我们便仍保有自己的自由与正直。

<div class="commentary-anchor" id="ephesians-5-25"></div>
第25节。妻子的本分既在于顺服，丈夫的本分便特在于爱。论到这爱，使徒既教导其分量，也指明其根据。就其分量而言，当与基督爱教会的爱相仿。就其根据而言，则在于夫妻之间那亲密而奥秘的联合。

<!-- PAGE 217 -->
<span style="color:#800000">*你们作丈夫的，要爱你们的妻子，正如基督爱教会，为教会舍己*</span>。丈夫当爱妻子，<span style="color:#0000d4">καθὼς</span> <span style="color:#800000">*正如*</span>，即兼有<span style="color:#800000">*因为*</span>与<span style="color:#800000">*像*</span>二义。丈夫与妻子的关系既与基督同教会的关系相类，这便加给丈夫一种本分：要照基督爱教会的样式去爱妻子。然而基督爱教会，竟至为教会舍命。所以，丈夫也当甘愿为妻子舍命。这似乎是本节自然的含义，也是通常所取的解释，且在人的本性中自有其根基。基督的爱在此被立为榜样与准则。诚然，他的爱在别处被宣称为无限的；我们之能像他那样爱，正如我们之能像天父怜悯人那样怜悯人，除此以外并无别的意义。虽然如此，真正的夫妻之爱必使丈夫为妻子舍己，这是无可置疑的。[^f20]

<div class="commentary-anchor" id="ephesians-5-26"></div>
<div class="commentary-anchor" id="ephesians-5-27"></div>
第26、27节。使徒在教导婚姻关系所生之本分的同时，又存心阐明基督与教会联合的性质；故此这两节所关乎的是后者，而非前者。它们陈明基督受死的旨意。其远旨，是为自己得着教会，作他所喜悦的对象；其近旨，则是预备教会以承受这至高的命定。这些意思是用比喻的方式表达的。教会被看作基督的新妇。此中所要教导的是：1. 教会乃是一种特殊而专一之爱的对象。正如新郎对新妇所怀的爱，是他对别人所没有的；照样，基督对他教会所怀的爱，也是他对宇宙间任何别类受造之物——无论其何等尊贵——所没有的。2. 新妇既专属于她的丈夫，教会也就专属于基督。教会与他所存的关系，是它与别的存有所没有的，也是别的存有无分的。3. 这关系不但是特殊而专一的，并且基督与他教会之间的联合，比他与任何别类受造之物之间的联合更为亲密。我们是他骨中的骨，肉中的肉。4. 教会是基督特别喜悦的对象。论到锡安，经上说：“新郎怎样喜悦新妇，你的神也要照样喜悦你”（以赛亚书 62:5）。他要把教会献给自己，作他独有的喜乐。教会既有如此崇高的命定，基督受死的近旨便是要洁净她、装饰她、使她荣美，好叫她得以预备妥当，与他一同坐在他的宝座上。她要作新妇，为丈夫妆饰整齐。这些并非臆想，并非夸张，也并非空洞的比喻，乃是朴实的、合乎圣经的、能使人成圣得救的真理。凡对教会全体为真的，对教会的各个肢体也一一为真。每一个信徒都是基督特殊之爱的对象；每一个信徒都与他有这特殊、专一而亲密的关系；每一个信徒都是他如此喜悦的对象；每一个信徒也都要被造成完全圣洁、毫无瑕疵、满有荣光的。

<!-- PAGE 218 -->

虽然本段经文的大意如此显明，然而其细节的解释却颇有难处。经上说，基督为教会舍己，<span style="color:#0000d4">ἵνα αὐτὴν ἁγιάσῃ</span>，加尔文译作 Ut segregaret eam sibi，即<span style="color:#800000">*使他可以将她分别出来归与自己*</span>；他说，这是藉着赦罪与圣灵的重生而成就的。<span style="color:#0000d4">ἁγιάζειν</span> 一词固然有此意义，但在保罗的书信中，它通常用以表达洁除污秽，且此义最合上下文，故一般译者多取此解。基督受死的目的，乃是要使属他的人成为圣洁。此目的的成就，在于使他们与神和好，并为他们取得圣灵的恩赐。故此加拉太书 3:13, 14 说：“基督既为我们受了咒诅，就赎出我们脱离律法的咒诅，……使我们因信得着所应许的圣灵。”

<!-- PAGE 219 -->
至于下一小句 <span style="color:#0000d4">καθαρίσας τῳ λουτρῳ τοῦ ὕδατος</span>，既已洁净（或作<span style="color:#800000">*用水藉着道把教会洗净*</span>）<span style="color:#800000">*，用水洗净了她*</span>，我们必须探究：一、<span style="color:#0000d4">λουτρὸν τοῦ ὕδατος</span> 所指为何。二、<span style="color:#0000d4">καθαρίσας</span> 何意；三、此小句与前文有何关系。此处“水的洗”是指洗礼呢，还是指一种类似于用水洗涤的洗净？后一种解释并非不可。使徒所指的，或许不过是属灵的洁净。在以西结书 16:9，神论及以色列说：“那时我用水洗你，洗净你身上的血，又用油抹你。”在 36:25 又说：“我必用清水洒在你们身上，你们就洁净了。”希伯来书 10:22 也说：“我们心中天良的亏欠已经洒去，身体用清水洗净了，就当存着诚心和充足的信心来到神面前。”在以上各处，用水洗涤都是属灵洁净的比喻说法。然而，注释家几乎无一例外地认为本节的说法是指洗礼。他们中的绝大多数，连同加尔文和其他改教家，甚至不曾讨论这一问题，似乎不承认还有别种解释的可能。近代所有的释经学者也持同样看法。这种意见的一致本身几乎就是定论。若无极为迫切的必要，任何人都不当提出与基督徒这一共同认信相违的解释。而此处并不存在这样的必要。洗礼就是用水洗涤。这正<span style="color:#800000">*是*</span>保罗的读者作为基督徒所熟悉的那用水的洗涤，他们读到此处，不能不想到所指的就是这洗。况且，此处归于洗礼的，并未超出神的话语在许多别处归于洗礼的。尤可比较使徒行传 22:16：“起来，受洗，洗去你的罪（即 <span style="color:#0000d4">ἀπόλουσαι τὰς ἁμαρτίας σου</span>）。”因此，使徒以“用水洗净”所指的乃是洗礼，这几乎无可置疑。

<!-- PAGE 220 -->
至于分词 <span style="color:#0000d4">καθαρίσας</span> 的含义，则较为可疑。此动词意为洁净，或按字面，或按礼仪，或按比喻而言。圣经既论及脱离罪的双重洁净：其一是藉赎罪除去罪咎，其二是藉圣灵除去污秽；而 <span style="color:#0000d4">καθαρίζειν</span> 一词两者皆可指，故问题在于此处所指为何。使徒在此所言，究竟是赦罪，抑或是藉这水的洗涤所成就的成圣？此词可表祭祀上的洁净。希伯来书 9:22, 23；约翰一书 1:7：“他儿子耶稣的血也洗净我们一切的罪。”希伯来书 9:14；参希伯来书 1:3：“他洗净了人的罪。”主张此处取此义者，其理据在于：受洗在别处亦与赦罪相连，如使徒行传 22:16，又如使徒行传 2:38：“你们各人要悔改，奉耶稣基督的名受洗，叫你们的罪得赦。”然而此词之义，实取决于它与前一分句的关系。<span style="color:#0000d4">Καθαρίσας</span> 可与 <span style="color:#0000d4">ἁγιάσῃ</span> 相连，作同一时态解。如此，它所表明的便是基督洁净其教会的方式：“他为教会舍己，是要洁净她，用水洗涤而洁净她。”[^f21] 依此说，若 <span style="color:#0000d4">ἁγιάσῃ</span> 指道德上的洁净或成圣，则 <span style="color:#0000d4">καθαρίσας</span> 亦当如此。但若依其形式取过去时，则此分词所表明者，必是先于成圣之事。其意便是：“基督为教会舍己，要使她成圣，既已用水的洗涤洁净了她。”依此说，<span style="color:#0000d4">καθαρίσας</span> 必指赎罪或祭祀上的洁净，即罪咎的涤除。上下文有利于此解，圣经的类比亦然。圣经始终以赦罪或除去罪咎为成圣之先。我们得蒙赦免、与神和好，为的是可以成为圣洁。故此，基督既已用自己的血洗净其教会的罪咎，便使她成圣，成为圣洁。无论取哪一种看法，我们都可说是藉着洗礼得了洁净（或脱离罪咎，或脱离污秽）。

这是什么意思？无论取以上哪一种意义，洗礼如何洗去罪呢？合乎新教与圣经的回答是：洗礼洁净人脱离罪，正如道洁净人一样。圣经说我们藉真理得救，藉真理得生，藉真理成圣。这话并不是说——1. 神的道在人听见或诵读之时，自身具有某种内在的、更不用说是巫术般的能力，足以产生这些果效。2. 也不是说，道只要正确地传讲，便随时随地如此使人成圣、使人得救，以致凡听见的人都得享这些福分。3. 更不是说，神的灵与道捆绑在一起，除藉着道之外绝不在人心中施行拯救之工。因为婴孩虽不能领受真理，却仍可成为重生的对象。同样，当圣经论到洗礼洗去罪（使徒行传 22:16），或论到洗礼使我们与基督联合（加拉太书 3:27），或论到洗礼使基督的死成为我们的死（罗马书 6:4；歌罗西书 2:12），或论到洗礼救我们（彼得前书 3:21）时，其所教导的并不是——1. 洗礼本身或施洗者本身有何内在的功效足以产生这些果效；2. 也不是说，凡按正当方式施行洗礼，这些果效必定随之而来；3. 更不是说，圣灵与洗礼相连到一个地步，以致洗礼成为他传递救赎恩益的唯一管道，凡未受洗的人尽都灭亡。这三项命题乃是罗马教与礼仪派所一概主张的，却与圣经明白的宣告并普世的经验相违。受洗之人中不圣洁者甚多，未受洗之人中得成圣、得拯救者亦复不少。

<!-- PAGE 221 -->
那么，说洗礼洗除罪孽、使我们与基督联合、并保障我们的救恩，这话在何种意义上为真呢？答案仍旧是：洗礼之为真，与圣道之为真同出一辙。神乐意将救赎的诸般益处，系于人以信心领受真理；他也同样乐意将这些益处，系于人以信心领受洗礼。也就是说，圣灵怎样与真理同工、藉真理作工，他也照样与洗礼同工、藉洗礼作工，将恩典之约的福分传与人。因此，既说我们藉圣道得救，便同样有理由说我们藉洗礼得救；然而没有信心的洗礼，正如神的道之于不信者一样，是没有什么功效的。按改革宗教会的看法，圣经论洗礼的教义如下——<span class="enum-num">1.</span> 洗礼是神所设立的圣礼。

<span class="enum-num">2.</span> 洗礼是得救的条件之一。“信而受洗的，必然得救”（马可福音 16:16）。然而，这乃是诫命上的必要，并非作为不可或缺之途径的必要（<span style="color:#800000">*sine qua non*</span>）。就此而言，它与认信相类。“因为人心里相信，就可以称义；口里承认，就可以得救”（罗马书 10:10）。也与割礼相类。神曾说：“不受割礼的男子，必从民中剪除”（创世记 17:14）。然而，未及第八日便夭亡的孩童，断不至于被从天国剪除。使徒也教导割礼（罗马书 3:26）。

<!-- PAGE 222 -->
<span class="enum-num">3.</span> 洗礼是施恩之具，即圣灵藉以赐下恩典的管道；然而并非每次如此，并非对一切领受者皆然，也不是唯一的管道，更不是为着作重生的通常途径而设。信心与悔改乃是圣灵的恩赐、重生的果子，然而二者却被要求作为受洗的条件。因此，圣经视重生为先于洗礼。但若信心——救赎的一切益处都是应许给信心的——先于洗礼，那么这些益处又怎能说是藉着洗礼授予的呢？这正如父亲可以先将产业给了儿子，其后再以契据正式转让与他。况且，救赎的诸般益处，即罪得赦免、圣灵的恩赐、以及救赎主的功劳，并非一次性地授予灵魂。每一次信心的新行动，每一次凭信心重新领受圣礼，这些益处都被重新授予、重新支取。罪人在悔改与信心的运用中前来受洗，便是接受父神为他的父，接受子神为他的救主，接受圣灵神为他的成圣者，接受神的话语为他信仰与行为的准则。施洗者于是奉神的名、凭神的权柄，用水洗他，作为记号，表明他因基督的宝血得洁净、因圣灵得成圣；也作为印记，印证神的应许，即按着他如此公开承认的悔改与信心，将这些福分赐给他。无论他从前经历了什么、享受了什么，此举乃是圣约诸般益处向他公开的授予，是他被列入蒙救赎者之中的就任之礼。他若在自己这一方的礼仪中出于真诚，洗礼便确实将其所象征的福分施与他。

<span class="enum-num">4.</span> 婴孩受洗，是凭着父母的信心。他们的洗礼向他们保证恩典之约的一切益处，只要他们日后以信心批准此约；正如割礼保证神治政体的益处，只要那些在婴孩时受割礼的人遵守律法。所谓洗礼重生的教义，即主张凡按正当方式施行于不加抗拒者的洗礼，内在属灵的更新必定随之而来，且若无洗礼重生便绝不成就——此说与圣经相违，颠覆福音信仰，也与普遍的经验相悖。不仅如此，它与改革宗众教会的教义断难相容。因为改革宗的教义乃是：凡重生的人都必得救。“预先所召的人又叫他们得荣耀”（罗马书 8:30）。然而圣经明明指出，普世教会的信仰也一致承认，受洗之人中有许多沉沦。故此，受洗者本身并不就是重生者。

以上所论，意在说明改革宗如何理解圣经中这一类的宣告。基督借着洗礼洁净他的教会。洗礼乃是入教之礼，它向信徒表明、印证并施用救赎主之死所成就的一切益处。使徒在此所论的是教会，即基督的身体与新妇，以及洗礼在构成此教会之人身上所生的功效；他所论的并非洗礼在那些不在圣约之内、与以色列国民相隔绝之人身上的功效。[^f22]

<!-- PAGE 223 -->
此段经文还提示了另一点意见。在浸信派与婴孩受洗派之间的争论中，就施洗的方式而言，其关键之处在于：洗礼按其本质究竟是浸入水中，还是洗净。若是前者，则施洗只有一种方式可行；若是后者，则凡能成就洗净之事的方式皆可施行，或洒水，或浇灌，或浸入。而在我们眼前的这段经文中，洗礼被称为「用水洗净」。

<!-- PAGE 224 -->
本节主要的释经难点，在于如何解释 <span style="color:#0000d4">ἐν ρήματι</span> <span style="color:#800000">*藉着道*</span> 这几个字。<span style="color:#0000d4">Ρῆμα</span> 一词不但可指某一句具体的话语，无论是命令、应许或预言，也可总括地指神的道，且无论带不带冠词皆然；参罗马书 10:8, 17；以弗所书 6:17。这几个字可以像通常所作的那样，与前一分句"水的洗"相连。若如此，其意便是：这以水而行的洗，是与道相连的。它并非寻常的洗濯，乃是一种与神的道相联的洗濯。人视此为对洗礼的描述，洗礼正因这一联系而与其他一切洗濯有别。如此，"藉着道"或可理解为洗礼的程式，或可理解为赦罪与重生的应许——洗礼乃是这应许的记号与印证，也正是领受此圣礼者信心的特定对象。路德的译文作："Durch das Wasserbad im Wort"；这与他常引用的奥古斯丁那句话相合：<span style="color:#800000">*道加于元素，便成为圣礼*</span>。对此解释有人提出异议：1. 若使 <span style="color:#0000d4">ρῆμα</span> 所指超出一般意义上的神的道，无论是指施洗的命令、应许，抑或洗礼的程式，就必须带冠词，当作"藉着**那**道"。然而希腊文中并无冠词。2. "以道而行的水的洗"或"藉着道的洗礼"，这种说法晦涩难明。3. 若要使上述的关联成立，此处经文当作 <span style="color:#0000d4">τῳ λουτρῳ τοῦ ὕδατος τῶ</span> 或 <span style="color:#0000d4">τοῦ ἐν ρήματι。</span> 保罗若这样写，所指的关联自然毫无疑问；不过在保罗的著作中，此类情形下本应有连接冠词而实际缺省的例外，为数甚多。尽管如此，冠词的缺省诚然使人倾向于另寻别解，倘若确有别解可寻。另有人将 <span style="color:#0000d4">ἐν ρήματι</span> 与 <span style="color:#0000d4">καθαρίσας</span> 相连，视其为对前一分句的解释：'用水的洗洁净了她，即藉着道洁净了她。'但此解显然不合自然：其一，因为 <span style="color:#0000d4">καθαρίσας</span> 已有 <span style="color:#0000d4">τῳ λουτρῳ, κτλ.,</span> 作其限定；其二，因为"用水的洗"一语本不需要任何解释。第三种解释法，是将这几个字与 <span style="color:#0000d4">ἁγιάσῃ</span> 相连：'基督藉着道洁净了他的教会，先已用水的洗将她洁净。'如此意思亦通。在约翰福音 17:17，我们的主祷告说："求你用真理使他们成圣"；且圣经处处都将神的道呈现为成圣的伟大凭藉。此解为许多最优秀的释经家所采纳，如吕克特、迈尔与温拿。然而，这几个字的位置如此有力地支持第一种解释，以致绝大多数解经者都予以赞同。

<div class="commentary-anchor" id="ephesians-5-27-2"></div>
第27节。基督为教会舍己、并使教会成圣，其终极目的乃是要将教会献给自己，即将教会得为自己特有的产业。关于本节，注释家提出了两个问题。其一关乎此处所用比喻的性质；其二关乎基督如此将教会献给自己，所指的是何时。有人（虽为数甚少）从此处加于教会的形容词——<span style="color:#800000">*毫无玷污、无可指摘*</span>——的性质推论，认为这一意象取自献祭之律。基督要将教会作为毫无瑕疵的祭物献与自己。然而：第一，这与上下文全然不合，因上下文所论乃夫妻之关系，意在藉新郎与新妇之间的关系来阐明基督与教会之间的联合。第二，将教会比作祭物，不但与上下文不合，也与圣经通篇的表述方式不合；反之，将教会比作新妇，则既恰切又常见。第三，所论的这些形容词，虽常用于祭物，但用来表达容貌或身体之美，不但恰切，且实有其例；而此处的容貌之美，正是内心纯洁的象征。

<!-- PAGE 225 -->
更多的注释家主张，本节所设想的目的乃是在今生成就的。换言之，此处所描述的教会光景，是在今世即已达到的。持此见解者当中，有些人——如古时的伯拉纠派——解释此段，谓完全的圣洁不但可以企及，而且信徒在离世之前实际上已经达到。另有些人则认为本段所说的并非圣洁，而是挽回祭，而挽回祭乃是一次献上、永远有效的。照此解法，本节与希伯来书 10:10 相平行，那里说我们「靠耶稣基督只一次献上他的身体，就得以成圣」；又与第 14 节相平行，那里说「他一次献祭，便叫那得以成圣的人永远完全」。希伯来书这两处经文显然都是指基督献祭的完全；它们无疑证明了一件无人置疑的事，就是此处所用的 <span style="color:#0000d4">ἁγιάζειν</span> 与 <span style="color:#0000d4">καθαρίζειν</span> 二字，可以表示祭祀上的洁净或赎罪。然而这远不足以证明这两个字——尤其是前一个字——在此处也当如此解。按圣经的用语，「使成圣」通常是指使人在属灵上成为圣洁；而这一含义比该字的任何别的意思都更合乎上下文。但若本处所表明的基督之死的目的，乃是要使他的教会全然圣洁，那么这目的在何时成就，就再无争辩的余地了。因为纵然容许说，在众多信徒中间偶有一二人在今生达到完全——而这样的例子无论圣经或经验都不曾提供——但这总不能就全体信徒而言。所以，自奥古斯丁以至于今，绝大多数注释家都认为，使徒在此所陈述的，乃是基督第二次降临、在一切信的人身上显为希奇之时所要成就的事。到那时，死人要照着神儿子的形像复活，那仍活着的人要被改变——这必朽坏的既变成不朽坏的，这必死的既变成不死的——到那时，教会就要「如新妇妆饰整齐，等候丈夫」（启示录 21:2；19:7-9）。

<!-- PAGE 226 -->
<span style="color:#0000d4">Ινα παραστήσῃ</span> 一语承接紧接在前的话：“既洁净了教会，<span style="color:#800000">*可以献给自己*</span>”，即使她如新妇一般站立在自己面前、侍立于自己身旁。故使徒写信给哥林多人时说，他已把他们“许配给一个丈夫，<span style="color:#0000d4">παρθενὸν ἁγνὴν παραστῆσαι τῳ</span> <span style="color:#0000d4">Χριστῳ,</span> <span style="color:#800000">*要把你们如同贞洁的童女献给基督*</span>”。此处的比喻略有不同：是基督把教会献给自己，<span style="color:#0000d4">αὐτὸς ἑαυτῳ</span>[^f23] ——是<span style="color:#800000">*他*</span>，而非别人；是献<span style="color:#800000">*给自己*</span>。此事乃他所成就。他为教会舍己，他使教会成圣；在聚集的万有面前，他要将这以自己宝血买来的新妇安置在自己身旁。他把教会献给自己，作<span style="color:#800000">*荣耀的教会*</span>。凡令人赞叹者即为荣耀。教会将要成为一切有理性之存有所惊叹的对象，因她毫无瑕疵，因她绝对完全。她要与神儿子那得了荣耀的人性相符；门徒在山上见此荣耀，便仆倒如同死人；及至基督第二次降临，此荣耀显明之时，天地都要逃避。神已预定他的百姓要模成他儿子的形像。主若显现，我们必要像他，因为必得见他的真体（约翰一书 3:2）。此处描写教会最终成全之荣耀，仍沿用前面的比喻：她要如毫无瑕疵的新妇，美丽完全，妆饰华美。<span style="color:#800000">*毫无玷污、皱纹等类的病*</span>，即毫无损其美丽之处，毫无衰老之迹，无瑕疵而不朽坏。这以比喻所表达的，在本节末句则以直言表明：<span style="color:#800000">*乃是圣洁没有瑕疵的*</span>，<span style="color:#0000d4">ἁγία καὶ άμωμος</span>。试比较 1:4，那里说神拣选了我们，<span style="color:#0000d4">εϊναι ἁγίους καὶ ἀμώμους</span>。可见创世以前所定的拣选之原初旨意，正要在教会的这一终极成全中得以实现。

<div class="commentary-anchor" id="ephesians-5-28"></div>
第28节。 <span style="color:#800000">*丈夫也当照样爱妻子，如同爱自己的身子*</span>。这并非说丈夫当以 <span style="color:#800000">*如同*</span> 爱自己身子的方式来爱妻子，仿佛"照样"与"如同"这两个虚词，即 <span style="color:#0000d4">οὕτως</span> 与 <span style="color:#0000d4">ὡς</span>，是彼此相关的。本节开首的 <span style="color:#0000d4">Οὕτως</span>，即 <span style="color:#800000">*照样*</span>，是承接前文所述而言。基督怎样爱教会，为教会舍己，教会又怎样是他的身体， <span style="color:#800000">*照样*</span>，按着二者之间相类的关系，丈夫也当爱妻子， <span style="color:#800000">*如同*</span>，即因妻子乃是他们自己的身子。基督爱他的教会，因为教会是他的身体；丈夫当爱自己的妻子，因为妻子是他的身子。句子后半所用的 <span style="color:#0000d4">Ως</span>，即 <span style="color:#800000">*如同*</span>，并非比较之辞，乃是立论之辞。它所指明的不是丈夫之爱的分量，仿佛意思是说他爱妻子当与爱自己的身子一样多；乃是指明那作为他爱之根据的关系的性质。他当爱妻子，因为妻子就是他的身子。

<!-- PAGE 227 -->

这话当如何理解？使徒说妻子是丈夫的身体，或如下一节所说，二人成为一体，究竟是什么意思？有几点是明显的——1. 这并非指任何物质上的合一。当亚当论到夏娃说：“这是我骨中的骨，肉中的肉”（创世记 2:23），无疑是指她乃是取自他的身体所造。但既然这些说法是用来表达一切妻子与其丈夫的关系，它们所指的就必不是本质上的同一，而另有含义。

<span class="enum-num">2.</span> 同样明显的是，这些说法也不可按任何与丈夫、妻子各自独立存在、彼此为不同位格相抵触的意义去理解。此一位的知觉并非另一位的知觉。

<span class="enum-num">3.</span> 其次显而易见的是，婚姻关系并非在我们本性存在的一切状态中，都是其完全或完备所必需的。到复活之时，婚姻即要止息。在将来的状态中，人在这一方面要像神的使者一样，不娶也不嫁。

<span class="enum-num">4.</span> 另一方面，婚姻的联合也不仅仅是利益与情感上的联合。丈夫与妻子乃是如此合而为一，以致丈夫是妻子的补全，妻子是丈夫的补全。婚姻的关系，对于我们本性的完全，以及对于本性在今生得以充分发展，都是必需的。诚然，有些人，如保罗，在独身中所达到的完全，或高于在婚姻中所能达到的；然而这乃是出于性情或处境上某种特殊之故。人身上有些才能与美德、优长与情感，非在夫妻的关系中得着发展，便一直潜隐不显。所以，罗马教会贬低婚姻、视之为不及独身圣洁的教义，既违背本性，也违背神的话语。

<span class="enum-num">5.</span> 除了因人性本初的构造而生的夫妻合一——使此一方成为彼一方之完成而为必需者——之外，我们主所宣告的「夫妻不再是两个人，乃是一体的了」一语之中，无疑还含有一种生命上的合一，此则无人能测度。

<!-- PAGE 228 -->
既然婚姻的性质如此，那么就可以推出：——<span class="enum-num">1.</span> 婚姻乃是一男一女之间终身的结合；由此可知，重婚、多妻以及任意离婚，都与婚姻的性质相违。

<span class="enum-num">2.</span> 婚姻必须由双方自由且诚心地缔结，即双方都确信彼此相宜、能够互相补足，从而按圣经所用这些词语的意义成为一体。因此，父母一方的任何强迫都与这一关系的性质相违；凡仅为便利而缔结的婚姻，都与这一制度的本意相悖。

<span class="enum-num">3.</span> 国家既不能缔结婚姻之约，也不能解除婚姻之约。它可以立法规定婚礼的举行方式与认证程序，并确定婚姻在民事上的效力。它可以保护妻子免受丈夫的虐待，正如它可以将子女从无能或残暴的父母手中带离一样。当这种结合事实上已因神的律法之运行而解除时，国家可以查明并宣告此一事实，使双方脱离该契约在民事上的约束。但国家决不可能有权柄去解除由神所设立的结合，因为这结合的职责与存续，乃是由神的律法所决定的。

<span class="enum-num">4.</span> 按照圣经的教训，并依更正教会的解释，惟有配偶一方死亡、犯奸淫，或蓄意遗弃，方能解除婚约。当后两项解除婚约的缘由经司法查明并宣告之后，受害的一方便可自由缔结新的婚姻。

<!-- PAGE 229 -->
婚姻的正确教义，既载于本段经文，亦见于神话语的其他部分；使人知晓并重视这一教义，对于社会的至高福祉，实有攸关生死的重要性。丈夫在社会伦理上最高的本分，就是爱自己的妻子；这一本分若被忽略，不但自己的灵魂大受亏损，全家也必陷于苦境。人所能犯的社会罪行中，除杀人之外，最大的莫过于诱使妻子的情爱离弃丈夫，或使丈夫的情爱离弃妻子。而执政掌权者加于社会的最大祸害之一，便是凭着圣经以外的理由解除婚约（就其为民事契约而言；除此之外，民政权柄再不能及于其他）。凡有律法，把神所宣告为一体的二人重新分作两人——即赋予妻子以自己的名义经商、举债、持有产业、控告与被告的权利——对这类律法也当作同样的评断。此举无异于为纠正一类弊端，却付出招致百倍更大弊端的代价。神的话语乃是立法行动与个人品行二者唯一可靠的指南。

若如圣经所教导的，夫妻乃是一体，那么<span style="color:#800000">*爱妻子的，便是爱自己*</span>，因为妻子就是他自己。这话原是神所说的，最初记在创世记 2:24，我们的主又在马太福音 19:4-6 重述之；主引了创世记那段话之后，接着说：“既然如此，夫妻不再是两个人，乃是一体的了。”加尔文注释马太福音这段经文时说：Hoc autem axioma sumit Christus, Ab initio Deus marem adjunxit feminae, ut duo efficerent integrum hominem. Ergo qui uxorem repudiat, quasi dimidiam sui partem a seipso avellit. Hoc autem minime patitur natura, ut corpus suum quispiam discerpat. 无论是神藉摩西之口，或是我们的主，都不是单单说夫妻应当成为一体，乃是说他们本是一体。他们所宣告的不是一项本分，乃是一个事实。照样，使徒说“爱妻子的，便是爱自己”，所宣告的也是一个事实。

<!-- PAGE 230 -->
<div class="commentary-anchor" id="ephesians-5-29"></div>
第29节。所以，夫妻之爱与自爱一样，同是本性的要求；人恨恶自己的妻子，正如恨恶自己或自己的身体一样，同属违反本性之事。一个人所有的身体，或许并不全然合他的心意。他或许巴不得它更俊美、更健壮、更有力、更敏捷。然而它究竟是他的身体，就是他自己；他保养顾惜它，其温存体贴，不亚于它是世人所曾有过的最上等、最可爱的身体。照样，人所娶的妻子，或许他巴不得她更良善、更美丽、更可意；然而她究竟是他的妻子，按着本性的构造与神的定规，乃是他自己的一部分。他若疏忽她、苛待她，所干犯的不仅是神的律法，也是本性的法则。保罗正是如此陈明此事。夫妻既是一体，作丈夫的就当爱妻子，“因为从来没有人恨恶自己的身子，总是保养顾惜。” <span style="color:#0000d4">’</span><span style="color:#0000d4">Εκτρέφειν</span> 本义为<span style="color:#800000">*养育*</span>，即如父母养育儿女那样加以抚养教导；参6:4。<span style="color:#0000d4">θάλπειν</span>，意为<span style="color:#800000">*温暖*</span>，即如母亲将婴孩怀抱胸前那样顾惜。二词皆表温存关切之意，因此都适于形容人照料自己身体所需与安适时的那份体贴。

<span style="color:#0000d4">Καθὼς καὶ</span>，<span style="color:#800000">*正像*</span>，<span style="color:#0000d4">Χριστὸς τὴν ἐκκλησίαν</span>，<span style="color:#800000">*基督待教会一样*</span>，即：基督保养顾惜教会，正如人保养顾惜自己的身子。丈夫与妻子之间的关系，类似于人与自己身体之间的关系；而基督与他教会之间的关系，又类似于丈夫与妻子之间的关系；因此，基督保养顾惜教会，正如人待自己的身子一样。

<div class="commentary-anchor" id="ephesians-5-30"></div>
第30节。本节说明前面宣告的理由。基督待祂的教会，正如人待自己的身体，<span style="color:#800000">*因我们是祂身上的肢体*</span>。这话或许可以仅仅是说，我们与祂所处的关系，乃是那样亲密而活泼的联合，正如人的身体与人本身的关系一样。但随后的话使其意义更为确定：<span style="color:#0000d4">ἐκ τῆς σαρκὸς αὐτοῦ καὶ ἐκ τῶν ὀστέων αὐτοῦ.</span>[^f24] 不是说属于祂的骨肉的肢体，乃是说从<span style="color:#800000">*祂的骨肉*</span>而出、有分于<span style="color:#800000">*祂的骨肉*</span>。无论这话究竟何指，这总是其字面含义；<span style="color:#0000d4">ἐκ</span> 所表达的乃是出于与有分。这是圣经中最难解的经文之一。使徒在下一节中宣称，此处所教导的道理乃是极大的奥秘。因此，凡是把这奥秘驱散、使所教导之真理变得全然可以通晓的解释，必定是错的。人所能正当从事的，无非是防备错误的解释，并将此事仍旧留在使徒所留下的地位上，作为当信、当敬畏，却非人所能测透之事。

<!-- PAGE 231 -->
对于我们面前这段经文，**最低层次的解释**是完全撇开字句本身的含义，认为使徒并无意教导我们与基督联合的性质究竟如何，而不过是肯定这一事实而已。丈夫与妻子亲密联合，基督与祂的教会也是如此。这根本算不上解释，无非是说：使徒所言并无实意，或并无确指。圣经固然笼统地教导基督与祂的子民乃是一体。然而当我们的主说他们合一如同葡萄树与枝子合一时，祂所教导的就不只是祂与祂子民联合这一事实而已。同样，当使徒说这联合与亚当和他后裔之间的关系相类时，他所教导的也不只是事实，更是这事实之性质的一个方面。照样，当他以夫妻的关系来说明此事，并指出相类之处在于：夏娃既是取自亚当的骨肉而成，我们也照样是基督骨肉的一部分——那么，他所指的就断不可能仅仅是我们与祂联合而已。

**第二种解释**将这话看作比喻，认为使徒的意思是：正如夏娃的肉身生命出于亚当，我们的属灵生命也出于基督。自屈梭多模以下，持此说者甚多，然而这解释与前一种同样难免非议：它不肯承认使徒所断言的话。使徒所说的，不仅是我们的生命出于基督——这固然不错——而且说我们的生命出于祂的身体，我们乃是有分于祂的身体的。这必定含有更为确切的意思，不只是说基督是我们生命的源头、祂住在我们里面而已。[^f25]

对这段经文的**第三种看法**，认为此处所指的是道成肉身。我们之所以与基督的肉身有份，是因为我们与他所取的人性相同。希伯来书 2:10 说：“那使人成圣的和那些得以成圣的，<span style="color:#800000">*都是*</span>出于一，”即出于同一本性；14 节又说：“儿女既同有血肉之体，他也照样亲自成了血肉之体。”这些及类似的经文确实证明，与基督联合的要素之一，便是这本性上的共通。同样真确的是，本节所指的那更为特定的联合，乃以道成肉身之事实为前提、为根基。然而，保罗在此所指的不可能是道成肉身。道成肉身乃是神的永恒之子取了真实的身体与具理性的灵魂；但此处所论的联合，却是由<span style="color:#800000">*我们*</span>与基督身体有份而生，即与他的骨、他的肉有份。此处所断言的，不是他取了我们的血肉之体，而是在他取了血肉之体以后，我们与他的血肉有份。况且，单就取了人性而言，那是基督与全人类之间的联结；而使徒在此所讲的，却是唯独属他的子民才有的、与基督的联合。

<!-- PAGE 232 -->

**第四**；罗马天主教人士、路德宗人士，以及较早期的加尔文派人士（如加尔文本人与伯撒），都在圣餐中寻求本段经文的解答。既然在那圣礼中我们被说成是领受基督的身体和血，他们便认定此处所说的联合，正是借着圣餐所成就的联合。我们与他「二人成为一体」，乃因我们分领他的肉身。当然，因各人对该圣礼所持的见解不同，这话的意思也各不相同。罗马天主教人士相信，借着祝圣之举，饼的全部实质变成了基督身体的实质，并为领受者所领受；他们自然相信，按字面最严格的意思，我们乃是他骨中的骨、肉中的肉。路德宗人士虽然相信在圣餐中饼于祝圣之后仍旧是饼，然而既主张基督真实的身体在空间上临在于饼之内、与饼同在、在饼之下，并由口所领受，那么就其所成就之联合的性质而论，他们便得出了相同的结论：基督徒既按字面意义分领基督的肉身，也就按字面意义与他同为一体。加尔文并不主张基督的身体在空间上临在于圣餐之中，也不主张身体由口领受，更不主张不信者在任何意义上领受了它。然而他确实主张，基督得荣的身体——那在天上登宝座的身体——其实质在该圣礼中，借着某种奇妙的方式，与饼一同传通与信徒。因此，他认为使徒在此所指的正是这一事实，并断言我们之所以是基督身体的肢体，乃因他身体的实质在圣餐中传通给了我们。[^f26] 对这些解释有两点反驳：——一、

其一，按改革宗众教会共同的信念，圣经并未教导任何关于主的晚餐的教义，可与上述对本段经文的诸般解释中的任何一种相合。2. 其二，不但整段上下文中全无一处暗指主的晚餐，而且此处所用的语词，在圣经论及那圣礼时也从未被使用。“身体与血”乃是圣餐中一向使用的语词，断不用“骨肉”。此处所指的，乃是女人的受造与婚姻的关系，而非圣餐。

<!-- PAGE 233 -->
**第五**；施莱尔马赫所创立的那种哲学式神学的倡导者，则认为本段经文所教导的，乃是我们有分于基督的神人二性之生命。就基督的位格而言，这一体系的主导观念乃是否认一切二元性。基督只有一个生命。这生命既非人性的，亦非神性的，而是神性兼人性的，或曰人性之被神化者。灵魂与身体之间也同样没有二元性；二者不过是同一生命在不同彰显之下的形态。有分于基督，就是有分于他的生命；有分于他的生命，就是有分于他的神人之性；有分于他的神人之性，就是既有分于他的神性，也有分于他的人性；而有分于他的人性，就是既有分于他的灵魂与神性，也有分于他的身体。我们有分于基督的神人之性，正如我们有分于亚当败坏的人性一样。亚当的生命乃是其全族的普遍生命，彰显于构成该族的各个体之中；基督的神人生命乃是教会的普遍生命，彰显于教会的众肢体之中。教会是基督的展开，正如人类是亚当的展开，又如橡树或森林是一粒橡实的展开。因此，我们既被称为亚当骨中的骨、肉中的肉，则在同样的意义上、以同样的妥当性，我们也被称为基督骨中的骨、肉中的肉。[^f27] 此解释是否正确，全系于其所依据之体系是否正确。作为神学，该体系乃是撒伯流派与欧迪奇派异端的复活；作为哲学，它归根结底是泛神论的。它使神的生命与人的生命成为同一；神只活在他的受造之物里面。

**第六**；我们只当满足于简要陈明使徒所肯定的，谨防曲解他的言辞，并对其含义略作探求，却不可自以为能驱散他所教导我们的、笼罩于此题之上的奥秘。

经文断言：一、我们是基督身体上的肢体；二、我们是他骨中的骨、肉中的肉，其意乃是我们与基督的关系，与夏娃与亚当的关系相类。

<!-- PAGE 234 -->
对这段经文的三种一般解释是：<span class="enum-num">1.</span> 正如夏娃的肉身生命出于亚当，我们的属灵生命也出于基督。此说言之太少，因其略去了本节所作的具体断言。

<span class="enum-num">2.</span> 第二种解释谓：正如夏娃是由亚当身体的本质所造成的，我们也同样有分于基督身体的本质。此乃加尔文的解释，罗马天主教、路德宗与超验论者所持的见解，皆可包括在内。然而此说已越出本节经文所宣告的范围，并将一种与圣经类比不合的意义强加于经文之上。

<span class="enum-num">3.</span> 第三种解释取乎其中，认为使徒在此所教导的是：正如夏娃的生命乃是从亚当<span style="color:#800000">*的身体*</span>而出，我们的生命也照样是从基督<span style="color:#800000">*的身体*</span>而出；她既有分于亚当的生命，我们也照样有分于基督的生命。故此，此处所教导的教义并非基督与属他之人在本体上相通，乃是在生命上相通；而属他之人生命的源头，正是基督的肉身。

为支持此种解释，可提出以下理由：

<span class="enum-num">1.</span> 此说保全了本段经文的完整。它既不曲解其义使之落空，也不使经文所断言的超出字句所必含的意思。所教导的教义仍是极大的奥秘，正如使徒自己所宣称的。

<!-- PAGE 235 -->
<span class="enum-num">2.</span> 这一解释是按所用词语通常而自然的意义去理解的。分享一个人的肉与血，无论在日常生活中，还是按圣经的用法，都不是指分享他的实质，而是指分享他的生命。任何成年人的身体所由构成的实质，全然来自他的饮食与空气。夏娃受造之后数年，亚当身上已无一微粒进入她身体的构成；然而她那时仍与起初一样，真真实实是他骨中的骨、肉中的肉，因为她是从他而出，并分享他的生命。出于同样的理由、在同样的意义上，我们也被称为亚当的肉中之肉、骨中之骨，尽管我们绝无分享他身体的实质。同样，人们极常说父亲的血流在子孙的血管之中，说他们是他的骨肉。这话所指的、也只能指的，是他们分享他的生命。在此事上，实质的相通是不可能的。生命是什么，无人知晓。但我们知道它不是物质；因此，纵然没有实质的相通，仍可有生命的相通。国族、部族、家族与个人各有其独特的生命形态；这种独特的类型代代相传，影响承受之人的容貌、体质与性情。当我们说到哈布斯堡家族或波旁家族的血脉时，所指的正是这种家族类型，而非任何物质之物。当今的奥地利皇帝从其家族的始祖承受了他独特的身体生命类型，却没有承受其身体实质的一微粒。丈夫与妻子在圣经中被称为一体。但此处所指的，仍不是实质的同一，而是生命的相通。既然分享一个人的肉在别的关系中并不指分享他的实质，那么论到我们与基督的关系时，也就不能公允地照那意思去理解。而既然在一切类似的情形中，这话所表达的都是生命的承受或相通，那么在此也必须如此理解。

<span class="enum-num">3.</span> 圣经明明教导：此处所描述的与基督联合，乃是得救所必不可少的。神的话语也同样明明教导，并为一切更正教信徒所持守（虽罗马教会不然）：旧约时代的信徒是完全得救的。因此，此处所教导的与基督联合，无论其性质如何，必定是基督降世以前的信徒与降世以后的信徒所共有的。旧约时代的圣徒既以基督为创世以来被杀的羔羊，从他的身体支取生命，这是可能的；但他们分有他身体的实质，或分有他得荣耀的人性，却是不可能的。所以，我们面前的这段经文，绝不能用来教导任何此类实质上的相通。

<!-- PAGE 236 -->
<span class="enum-num">4.</span> 与基督生命的相通，以及生命从他肉身而出——此种解释以为本段经文所教导的，正是这一教义——乃是圣经别处也教导的道理。经上不但说我们藉他的身体得救（罗马书 7:4），藉他的血得救（以弗所书 2:13），藉他的肉体得救（2:15），藉他肉身的身体得救（歌罗西书 1:22）；更说他的肉是我们的生命，与之有分即为永生之源。“你们若不吃人子的肉，不喝人子的血，就没有生命在你们里面。吃我肉喝我血的人就有永生。”（约翰福音 6:53, 54）

因此，基督与其子民之间的联合乃是奥秘的。这联合可以得着说明，却不能被完全解释。它类似于丈夫与妻子之间的联合——圣经宣告二人成为一体，以表明他们生命的相通；尤其类似于亚当与夏娃之间的联合，因为夏娃的生命乃是从亚当的肉身而出。既然这些关系彼此类比，那么论到此一关系所说的话，也可以用来论那一关系。为证明此点，并为他所用的言语作辩护，使徒引用了神在创世记 2:24 中的话。第 31 节。<span style="color:#800000">*为这个缘故，人要离开父母，与妻子连合，二人成为一体。*</span>这就是说，既然丈夫与妻子之间的关系比其他任何关系都更为亲密，甚至比父母与儿女之间的关系更为亲密，所以人就当视一切其他关系为次要的，而以他对妻子所负的关系为首，因为他与妻子乃是在共有一个生命的联结之中。既然圣经用这样的言辞论到夫妻的关系，使徒便有充分的理由，用同样的言辞论到基督与其子民之间的联合。他们也是一体，因为他们有共同的生命，又因为他的子民从他的肉身得着生命，正如夏娃从亚当的肉身得着生命一样。

<!-- PAGE 237 -->
此处主要的困难在于上下文的连接。这段经文是这样的：“我们是他身上的肢体，是他的骨他的肉。为这个缘故，人要离开父母，与妻子连合，二人成为一体。”前提与结论之间似乎并不相称。我们既是基督身上的肢体，这如何证明人当离开父母、与妻子连合呢？解决这一难题有三种途径。第一，有人假定这两节之间并无连接，而第31节乃是上承第28节。如此，其意便是：“人当爱妻子，因为妻子就是他自己的身体。<span style="color:#800000">*为这个缘故*</span>，人要离开父亲，与妻子连合”云云。这种解法既与上文不合，也与下文不合。与上文不合，是因为第30节中<span style="color:#800000">*他的肉*</span>等语，既指着基督说的，又原是创世记那段经文的一部分，而第31节正是那段经文的接续。若其一指着基督，另一处也必指着基督。它又与下文相抵触；因为在第32节中，第31节所含的主要意思（<span style="color:#800000">*二人成为一体*</span>）被明说为是指着基督和教会说的。

第二种解释法则假定第30节与第31节之间有直接的关联，并将后一节整体理解为指基督与祂教会之间的关系。如此解释，或可指向现今，或可指向将来。若指现今，其意便是：“我们是基督身上的肢体，<span style="color:#800000">*所以*</span>，祂离开了祂的父以及天上一切所亲爱的，为要与祂的子民联合。”然而，“人要离开父母”这句话，怎能解作基督离开了神与天堂呢？若将此段理解为指向将来，其意便是：“我们是基督身上的肢体，<span style="color:#800000">*所以*</span>将来祂第二次降临之时，必要离开祂父的宝座，娶祂的教会为新妇。”[^f28] 但这种看法不但同样曲解了经文的字义，而且与上下文全然相悖。保罗并未说教会将来才要与基督联合为新妇，乃是说祂的子民如今就是祂身上的肢体，是祂骨中的骨，肉中的肉。

第三种解释认为，本节前半部分与基督和教会无关，引用创世记的话语，仅仅是为了末尾那句<span style="color:#800000">*二人成为一体*</span>。如此，其意义与上下文的关联便是：“夏娃既是从亚当的身体中取出而造成的，所以说，人要离开父母，与妻子连合，二人成为一体。照样，我们既是基督身上的肢体，<span style="color:#800000">*所以*</span>基督与他的教会也是一体。”此种看法：1. 与上下文完全吻合。2. 避免了那些勉强而不自然的解释——若将第31节的前半部分解作指基督，这类解释便无可避免。3. 满足了第32节的要求，因为该节断言<span style="color:#800000">*一体*</span>二字确是指着基督与教会说的。

<!-- PAGE 238 -->

<span class="enum-num">4.</span> 这与使徒们引用旧约经文的惯例相符。他们常常照旧约原文整段引述某处经文，其实只为其中某一分句或某个用语，并无意将所引经文的其余部分应用于眼前所论之事。在希伯来书 2:13，全部重点与论证都系于<span style="color:#800000">*儿女*</span>一词；亦可参看加拉太书 3:16。尤其常见的是，那些在旧约原有文脉中表明文法或逻辑关联的虚词，也一并被纳入引文之内，虽然与引入该经文的新文脉全然不合。此种做法频繁到几乎成为通例。因此，将本节末了的话解作指着基督说的，而其前半部分则解作承接创世记原文的上下文，并非任意武断之举。

<div class="commentary-anchor" id="ephesians-5-32"></div>
第32节。<span style="color:#0000d4">Τὸ μυστήριον τοῦτο μέγα ἐστίν</span>，<span style="color:#800000">*这是极大的奥秘*</span>。此处的“奥秘”一词，并非指创世记 2:24 那段经文，仿佛使徒的意思是说那段经文含有一层神秘的意义，而他方才已将其应用于基督与教会的关系，从而把这层意义揭示出来。他所宣称为极大奥秘的，乃是基督与他子民之间的联合，即他们<span style="color:#800000">*二人成为一体*</span>这一事实。<span style="color:#0000d4">μυστήριον</span> 一词在此处的用法与在别处一样，指某种隐藏之事，某种超乎人的知识所能企及之事。至于其所以隐藏，究竟是因为它尚属将来之事，抑或因为它启示得尚不完全，抑或因为它本性上即是人所不能测透的，则须由上下文断定。在本处，所指的大概是末一种意思：这事本身超乎我们的理解。武加大译本将此句译作 <span style="color:#800000">*sacramentum hoc magnum est*</span>。拉丁文 <span style="color:#800000">*sacramentum*</span> 一词，除其通常的古典义“神圣的寄存物”之外，也常用以指任何神圣之物，或含有隐藏意义之物。就后一义而言，它与 <span style="color:#0000d4">μυστήριον</span> 一词意义相合，因为后者同样用以指某种意义隐藏之事。故此，武加大译本常如此处一般，用此字翻译该词。然而在拉丁教会中，<span style="color:#800000">*sacramentum*</span> 一词的意义逐渐发生变化。它不再泛指一切具有神圣或隐秘意义之事，而被限定于那些被认定具有施予恩典之能力的礼仪或行为。这便是罗马教会关于圣礼的观念。教皇派的神学家们在此处按这一意义取用该词，又以为使徒所论的是婚姻，遂引这段经文来证明婚姻是一项圣礼。对此论据的答复是显而易见的。

首先，保罗称之为 <span style="color:#0000d4">μυστήριον</span>、武加大译本称之为 <span style="color:#800000">*sacramentum*</span> 的，并非婚姻，乃是基督与祂教会之间的联合。

其次，无论希腊文还是拉丁文的这个词，都不含罗马教所谓"圣礼"之义。武加大译本将提摩太前书 3:16 译作<span style="color:#800000">*magnum est pietatis sacramentum*</span>，然而没有一位罗马教徒会以为此处是说：神在肉身显现乃是教会意义上的一项圣礼。

<div class="commentary-anchor" id="ephesians-5-33"></div>
第33节。本节与前文的关系，由 <span style="color:#0000d4">πλὴν</span> 一词标示，可有两种解释。此语助词常用于话头中断之后，置于分句之首，以引出对主题的重拾。此处或即如此。自第21节以来，整段的主要目的，乃在阐明夫妇关系的真义及其本分。与此相连者，则是对基督与教会之间类似关系的论述。而在第30、31两节中，所呈现的唯有后一层意思。故此处使徒复归于本题：既如此，回到我所论的题目，<span style="color:#800000">*你们各人都当爱妻子如同爱自己一样*</span>。此解乃通常所采纳者。然而 <span style="color:#0000d4">Πλὴν</span> 亦可作<span style="color:#800000">*然而*</span>解，如我们译本所译者，如此则本节与第32节相连：“基督与教会的关系乃是极大的奥秘；然而，你们也当爱你们的妻子。”意即：基督与教会的关系之中，固有某些远超夫妇关系之处，然而两者之间仍有足够的类比，足以使作丈夫的负有本分，当爱妻子，如同基督爱教会一样。此种关联之见解更为可取，尤因 <span style="color:#0000d4">καὶ ὐμεῖς</span>（<span style="color:#800000">*你们也*</span>）二字，显然预设了所指乃是紧接在前之文。

<!-- PAGE 240 -->
<span style="color:#0000d4">’</span><span style="color:#0000d4">Υμεῖς οἱ καθ</span><span style="color:#0000d4">’</span> <span style="color:#0000d4">ένα,</span> <span style="color:#800000">*你们各人*</span>，<span style="color:#0000d4">έκαστος τὴν ἑαυτοῦ γυναῖκα</span> <span style="color:#0000d4">οὕτως ἀγαπάτω ὡς ἑαυτόν</span>，<span style="color:#800000">*务要各人爱妻子如同爱自己。*</span> 此处句法有变：动词 <span style="color:#0000d4">ἀγαπάτω</span> 与 <span style="color:#0000d4">έκαστος</span> 相配，而非与真正的主语 <span style="color:#0000d4">ὐμεῖς</span> 相配。其意与第28节相同：丈夫当爱妻子如同爱自己。下一分句（<span style="color:#0000d4">ἠ δὲ γυνὴ</span> <span style="color:#0000d4">ἵνα φοβῆται τὸν άνδρα</span>）中，<span style="color:#0000d4">ἠ δὲ γυνὴ</span> 乃独立主格，<span style="color:#0000d4">ἵνα</span> 则系于一个省略了的动词。<span style="color:#800000">*至于妻子*</span>，当留意<span style="color:#800000">*敬重她的丈夫*</span>。<span style="color:#0000d4">φοβέω</span> 一词可表达畏惧之情的种种形态与各样程度，视其对象而定：自单纯的尊重，进而为敬畏，直至崇拜。然而无论程度如何，它总是对尊长地位的一种承认。因此，婚姻关系所赖以立的情感——即那出于自然本性的构造、为神的命令所要求、并为双方的幸福与福祉所不可少的情感——在丈夫一方，乃是那种使他珍爱并保护妻子如同自己的爱；在妻子一方，则是对丈夫居首之位的体认，由此自然而然地生出信赖与顺服。
