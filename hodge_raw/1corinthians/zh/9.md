<p class="title-block-h2" style="text-align:center; font-size:16px; font-weight:bold; margin:18px 0 12px;" markdown="1"><span style="color:#006411">第九章</span></p>

使徒藉着自己放弃那无可置疑的、由教会供养的权利一事，说明为他人的益处而放弃行使自己权利的本分，见1-18节。他又表明，自己在别的方面也迁就他人的意见与成见，19-23节。他提醒读者：若无克己，便不能成就任何美善或伟大之事，24-27节。

<span style="color:#0000d4">**传道人得享充足供养之权。**</span>

<span style="color:#0000d4">**克己之必要。第1-27节。**</span>

<!-- PAGE 175 -->
在前一章中，使徒曾力劝刚强的人为着软弱弟兄的缘故放弃使用自己的权利；如今他便指出自己是如何依此原则而行的。他是使徒，因此享有使徒的一切权利。他的使徒职分极其明确，因为他曾看见主耶稣，是主亲自差遣的使者；而他所受的神圣使命，至少在哥林多人中间，已得着无可争辩的证实。他们就是他使徒职分的印证（1-3节）。他既是使徒，便与彼得或其他使徒一样，有权得着供养；倘若他选择婚娶，也有权使家室得着供养（4-6节）。关于这领受足够供养的权利，他的证明如下：第一，本于社会赖以建立的原则，即作工的人配得工价（7节）。第二，本于这一原则在旧约中已得承认的事实，甚至在应用于牲畜之事上亦然（8-10节）。第三，本于交易公义的原则（11节）。第四，本于哥林多人在别的教师身上已然承认此权利的事实（12节）。第五，本于万国普遍承认的这一原则：伺候圣殿的人，从殿中得食（13节）。第六，本于基督明确的命定：他曾定规，传福音的靠着福音养生（14节）。这无可置疑的权利，保罗却未曾使用；并且他已决意，尤其在哥林多，将来也绝不使用。他如此行，便断绝了别人质疑其动机的把柄，也为自己在抵挡反对者时立定了可夸的根据，这根据是他决意不肯放弃的（15-18节）。然而，这并非他为他人益处而不行使自己权利的唯一事例。凡在无关紧要之事上，他都迁就犹太人与外邦人，为要多得人（19-23节）。外邦人尚且如此克己，不过为得能坏的冠冕——基督徒岂不更当如此克己，以得那不能坏的冠冕么？若无克己与竭力奔跑，他们那从上头来的呼召之奖赏，断不能得着（24-27节）。

**1.** <span style="color:#800000">*我不是使徒吗？我不是自由的吗？*</span>[^f10] <span style="color:#800000">*我不是见过我们的主耶稣基督吗？你们不是我在主里面所做之工吗？*</span>

按照充分的外证与内证，多数编者将这两个问题的次序对调。<span style="color:#800000">*我不是自由的吗*</span>？意即：我岂不是一个基督徒，得着了基督使他子民得享的一切自由吗？我岂不与任何别的信徒一样自由，可以照自己对是非的确信来规范自己的行为，不受任何约束去迎合他人的意见或成见吗？然而，这自由我并未加以利用。不但如此，<span style="color:#800000">*我不是使徒吗*</span>？除了众基督徒共有的权利之外，我岂没有使徒的一切特权吗？我岂不与那些最大的使徒同列吗？他们中间有谁能出示比我更好的凭据，证明自己配得此职分呢？使徒职分的凭据共有三类。

<span class="enum-num">1.</span> 直接领受于基督、且当着见证人之面所授予的职分，或以其他方式得着印证的职分。

<span class="enum-num">2.</span> 神迹、奇事、异能，哥林多后书 12:12。

<span class="enum-num">3.</span> 他们事奉的果效。凡未曾在主耶稣复活之后见过他的人，都不能作使徒，因为主的复活正是他们所要见证的根本事实之一，使徒行传 1:22。

凡未曾藉着基督直接的启示领受福音知识的人，也不能作使徒；因为使徒同样是祂教训的见证人，参使徒行传 1:8；10:39；22:15。加拉太书 1:12。

关于这直接受召与独立得启示之必要，保罗在加拉太书中已详加申论。此处保罗为证明自己的使徒职分，仅诉诸两方面的凭据：其一，他曾亲见主耶稣；其二，他事奉所得的果效。<span style="color:#800000">*你们在主里面岂不是我所作之工么*</span>。意即：或指你们在主里面，你们之得以在

<!-- PAGE 176 -->

主（即你们的归信）乃是我的工作；或者，这两个字（<span style="color:#0000d4">ἐν</span> <span style="color:#0000d4">κυρίῳ</span>）也可解作<span style="color:#800000">*藉着主*</span>，即藉着他的同工。前一种解释更为可取，因为使徒的用意是要说明他们在何种意义上是他的工作。乃是就其在主里面而言的。本节以及全章与上文的联系是显而易见的。他的用意是要表明，自己素来所行的，正是他劝勉他人所持守的原则。无论是作为基督徒，还是作为使徒，他都不曾坚持自己的权利，以致不顾他人的顾虑或教会的益处。

**2.** <span style="color:#800000">*假若在别人我不是使徒，在你们我总是使徒；因为你们在主里正是我作使徒的印证*</span>。

<span style="color:#800000">*假若在别人*</span>，即在别人的看法中，<span style="color:#800000">*我不是使徒，在你们，我总是使徒*</span>。别人若有什么借口质疑我的使徒职分，你们却断然没有；<span style="color:#800000">*因为你们在主里面正是我作使徒的印证。*</span>你们的归正就是神在我所受的使命上所盖的印。人的归正乃是神的工作，凡藉之成就此事的人，也就因此被证实为神所派的使者。这与奇事一样，同是神的作为，故此，当其得着适当的验证时，便与神的差派凭据具有同等的效力。此种凭据虽然确实有效，使徒亦据以为证，却极易被人滥用。其一，因为许多被视为归正的事其实是假的；其二，因为传道人常以事工的成效为自己的谬误张目，而那成效其实出于他们所传的真理。然而，有时那成效的性质如此显明、如此不容否认、如此宏大，以致无需再有别的凭据来证明神的呼召。使徒们的情形便是如此，改教家们的情形也是如此，我们近代许多宣教士的情形亦复如是。

**3.** <span style="color:#800000">*我对那盘问我的人就是这样分诉：*</span>

<!-- PAGE 177 -->
这是指前文，而非后文；因为后文并不能回答那些质疑他使徒职分的人。此处所用的两个词，(<span style="color:#0000d4">ἀνακρίνω</span>) <span style="color:#800000">*察问*</span> 与 (<span style="color:#0000d4">ἀπολογία</span>)，<span style="color:#800000">*申辩*</span> 或 <span style="color:#800000">*答辩*</span>，都是法庭用语。保罗的意思是：当他的反对者中有人仿佛以审判的方式盘问他的使徒职分时，他便回答说：“我已见过主耶稣，并且他已用他所赐给我劳苦的果效，为我的职任加上了印证。”这一回答使彼得、雅各、约翰都得了满足；他们既看见向外邦人传福音的使徒职分已托付与保罗，就与他行相交之礼，握手为证（加拉太书 2:8, 9）。

**4.** <span style="color:#800000">*难道我们没有权柄吃喝吗？*</span>

<span style="color:#800000">*权柄*</span>一词，在此与上文第8、9节相同，意即<span style="color:#800000">*权利*</span>。我们没有吃喝的权利吗？此语若单独看来，或可解作："我们岂没有别人在饮食上所有的同样权利吗？在这事上一切的分别，为我们废去，正如为别人废去一样。我们岂不是自由的吗？"然而上下文清楚表明，使徒的意思并非如此。这里所论的权利，正是他接下去所要确立的，即免于作工、由教会供养的权利。他既已证明自己的使徒职分，便进而证明自己有受供养的权利，随后又表明他并未使用这权利。因此他就可以更加坦然地劝勉哥林多人，为着软弱弟兄的缘故，放弃他们吃祭偶像之物的权利。

**5.** <span style="color:#800000">*难道我们没有权柄娶信主的姊妹为妻，带着一同往来，仿佛其余的使徒和主的弟兄并矶法一样吗？*</span>

这是对前一节的申述。<span style="color:#800000">*我们岂没有权柄*</span>，即：岂没有这样的权利。<span style="color:#800000">*带着同行*</span>，之所以采用这样的说法，是因为使徒们并非驻守一地的传道人，各有自己的堂区或教区，而是不断地从这处往那处奔走。<span style="color:#800000">*姊妹*</span>，即：一位基督徒妇人。<span style="color:#800000">*作妻子*</span>，此语确定了这位同行者所居的关系，等于是说：“一位作妻子的姊妹。”许多教父将本节解作指当时的一种风俗，即富有的妇人随行于使徒左右，以供给他们的需用。许多罗马教人士承袭了这一解释，为要避开那通常的、也是唯一合法的解释所带来的结论——即此语认可了圣职人员的婚姻。<span style="color:#800000">*和别的使徒一样*</span>；按字面作“<span style="color:#800000">*那*</span>些别的使徒”。这未必意味着其余的使徒尽都已婚，但其含义是：他们作为一个群体乃是有妻室的人。奥尔斯豪森等人认为，使徒在第4至6节中是就三个方面宣告自己的自由：

<!-- PAGE 178 -->

<span class="enum-num">1.</span> 论到食物，‘凡你们所主张的吃喝之自由，我岂不同样有么？’

<span class="enum-num">2.</span> 论到婚姻，"我岂没有娶妻的权利吗？"

<span class="enum-num">3.</span> 指供养而言。然而，这样解释乃是把上下文并不担保的意思读进经文里。上文所论及的婚娶之权，本无争议；下文所辩护的，既不是他可以不理会犹太人有关饮食之律的自由，也不是他娶妻的权利。

<span style="color:#800000">*并主的弟兄。*</span>这些人究竟是约瑟与马利亚的儿女，还是主的母亲之妹妹马利亚的儿女，此点极难断定。传统，或说教会普遍的声音，大体倾向于后一种看法。然而前一种看法，或许才是近代大多数注释家所持的。此问题的讨论，本当归入福音史的范围。[^f11] 关于此题，可比较以下经文：马太福音 1:25；12:46；13:55。路加福音 2:7。约翰福音 2:12。使徒行传 1:14。加拉太书 1:19。<span style="color:#800000">*和矶法*</span>；除加拉太书之外，保罗每逢提及彼得，所用的都是这个名字；而拉赫曼在加拉太书 1:18；2:9；10:14 各处，均读作矶法而非彼得，如此便只余加拉太书 2:8、9 为例外。彼得已经娶妻，由马太福音 8:14 与马可福音 1:30 可以清楚看出。

**6.** <span style="color:#800000">*独有我与巴拿巴没有权柄不作工吗？*</span>

<span style="color:#800000">*可以不作工的权柄*</span>；按字面直译，即<span style="color:#800000">*不作工的权利*</span>。“难道传道之人当由众教会供养，这一通则单单要以我和巴拿巴为例外，有何缘故呢？”由此可见，巴拿巴与使徒同工宣教期间，也效法使徒亲手作工，好叫基督的福音不至叫人破费。保罗接着论证这项权利，所依据的并非使徒所独有的理由，亦非教会某一特定时代所独有的理由，乃是适用于一切传道人、一切世代的理由。他的头一个论据，取自人所公认的原则：作工的当得工价。此原则在下一节中加以说明。

<!-- PAGE 179 -->

**7.** <span style="color:#800000">*有谁当兵自备粮饷呢？有谁栽葡萄园不吃园里的果子呢？有谁牧养牛羊不吃牛羊的奶呢*</span>？

此处从人们日常的职业中举出三个例证，用以说明所论的原则。兵丁、农夫、牧人，皆靠自己的劳力维生；传道人为何不当如此？他的工作与他们的同样耗尽心力，同样劳苦，同样有益；为何不当得着相似的报酬呢？<span style="color:#800000">*有谁当兵*</span>，即谁作兵丁在战事中服役，<span style="color:#800000">*自备粮饷呢*</span>（<span style="color:#0000d4">ῖδίοις</span> <span style="color:#0000d4">ὀψωνίοις</span>），即靠自己的口粮。战时哪有兵丁被要求自行供养的呢？你若强迫他如此，便是逼他去作强盗；照样，若要求传道人自行供养，其危险便是逼他们成为属世之人。然而使徒所着眼的，与其说是这样行的恶果，不如说是这样行的不义。凡对兵丁为真的，对农夫、牧人，以及各行各业的人，也同样为真。

8<span style="color:#800000">*. 我说这话，岂是照人的意见；律法不也是这样说吗*</span>？

<span style="color:#800000">*我说这话岂是照人的意见*</span>？这一短语（<span style="color:#0000d4">κατὰ</span> <span style="color:#0000d4">άνθρωπον</span> <span style="color:#0000d4">λαλεῖν</span>），即<span style="color:#800000">*照人的意见说话*</span>，或说依人的方式说话，一般是指按人惯常说话的样式发言，述说人的思想或原则，或采用取自人间习俗的例证。罗马书 3:5；加拉太书 3:15；参罗马书 6:19。使徒此处的意思是要问：为证实"劳作理当得报"这一原则，是否非得援引人间的惯例？<span style="color:#800000">*律法不也是这样说吗*</span>？就是说，神的话岂不也认可同一原则？<span style="color:#800000">*律法*</span>（<span style="color:#0000d4">ὁ</span> <span style="color:#0000d4">νόμος</span>）一般指那具有约束力者。凡神的律法，无论以何种方式启示——或铭于人心，或载于十诫，或见于摩西五经，或见于全部圣经——皆可称为律法。至于每一处的具体所指，必须由上下文断定。此处所指乃是摩西的律法。

**9.** <span style="color:#800000">*就如摩西的律法记着说：「牛在场上踹谷的时候，不可笼住牠的嘴。」难道神所挂念的是牛么*</span>？

<!-- PAGE 180 -->
<span style="color:#800000">*因为*</span>一词，是承接上文所设之问而给出的暗含答案。“律法岂不也是这样说吗？确是这样说的：<span style="color:#800000">*因为*</span>经上记着说”云云。所引之言见于申命记 25:4，那里禁止给牛戴上嚼环——无论是牛拉着打谷器碾过禾稼，还是用蹄踹踏谷物；因为这两种打谷之法在巴勒斯坦都很通行，此外也用连枷或棍杖。参以赛亚书 28:28；41:15；何西阿书 10:11。<span style="color:#800000">*神所挂念的岂是牛么*</span>？神确实顾念牛，这是断然无疑的；因为小乌鸦哀鸣求食，他也赐食与它（约伯记 38:41；诗篇 147:9；马太福音 6:26；路加福音 12:24）。故此，使徒绝非要否认这一点。他所要说的，不过是律法有更高的指向。这条诫命的近处目的，固然在于使劳作的牲畜得着公道的对待；然而其终极的用意，乃是要藉此教导人明白其中所含的道德真理。牛既为我们的益处耗尽气力，神尚且要求不可克扣它应得的酬劳；那么，将同样的公义原则施行于他有理性的受造之物身上时，他岂不更要严格地加以责成么。

**10.** <span style="color:#800000">*还是特为我们说的吗？分明是为我们说的。因为耕种的当存着指望去耕种；打场的也当存得粮的指望去打场。*</span>

<!-- PAGE 181 -->
“他说这话，是<span style="color:#800000">*全然*</span>如此。”此处并非这个意思；因为若如此，便是说使徒断言这条诫命专指人而言。这个词（<span style="color:#0000d4">πάντως</span>）当译作<span style="color:#800000">*确实*</span>，如路加福音 4:43、使徒行传 18:21；21:22 以及别处屡见之用法。使徒说：“这条诫命确实是为<span style="color:#800000">*我们*</span>的缘故而写的”，即为人的缘故——并非<span style="color:#800000">*为我们作传道的*</span>，或<span style="color:#800000">*为我们作使徒的*</span>。此命之意，是要确立一条原则：劳力当得其报，使人可以欢然作工。<span style="color:#800000">*那*</span>（<span style="color:#0000d4">o[ti</span>）；即<span style="color:#800000">*因为*</span>。“这话记着，是为我们的缘故，<span style="color:#800000">*因为*</span>耕种的人理当（<span style="color:#0000d4">ὀφείλει</span>，参哥林多后书 12:11）存着指望去耕种”，即指望得报。“打场的人也当存着分享其所望的指望去打场”，即分享他所盼望之物。此处经文的读法尚有疑问。多数校勘者所取的读法，使此句形式更为简明[^f12]——“打场的人（当）存着有分的指望（去打场）”（<span style="color:#0000d4">ejp’</span> <span style="color:#0000d4">ἐλπίδι</span> <span style="color:#0000d4">τοῦ</span> <span style="color:#0000d4">μετέχειν</span>）。其意则一。有些古代注释家，并且不少最著名的近代注释家，都以为保罗是对申命记那处经文作了寓意的解释。他们认为保罗是说：那处经文不当指牛而言，乃当指我们传道人而言。“这条诫命是为我们传道的缘故而设，使我们耕种的可以存指望耕种，我们打场的可以存指望打场。”然而这与新约作者的作法全然不合。[^f13]他们除了依据圣经真实的历史本义之外，从不据以立论。加拉太书 4:21-31 并不构成此说的例外；因为那处经文是一个例证，而非一个论据。

**11.** <span style="color:#800000">*我们既把属灵之物撒在你们中间，若从你们收取属肉身之物，这还算大事吗*</span>？

这就是说，我们既将一类的益处赐予你们，我们从你们领受另一类的益处，岂是不合理的吗？我们所施与的既是<span style="color:#800000">*属灵的*</span>，如知识、信心与盼望，乃圣灵所结的果子，其价值无可限量；那么我们从你们收取属肉体的事物，即维持身体所必需之物，又算得了什么呢？按着交易公义的一切原则，传道人受供养的权利都必须得到承认。

**12.** <span style="color:#800000">*若别人在你们身上得分享这权柄，何况我们呢？然而我们并没有用过这权柄，倒是凡事忍受，免得基督的福音受到阻碍。*</span>

这是特别针对哥林多人所发的论证。他们既已承认别的教师有受供养之权，就断无任何理由否认使徒也有此权。<span style="color:#800000">*这权柄是在你们身上*</span>（<span style="color:#0000d4">τῆς</span> <span style="color:#0000d4">ὑμῶν</span> <span style="color:#0000d4">ἐξουσίας</span>），即以你们为对象的权柄。关于所有格的这种用法（以<span style="color:#800000">*你们的权柄*</span>表示<span style="color:#800000">*在你们身上的权柄*</span>），可比较马太福音 10:1、约翰福音 17:2。就保罗而论，此权虽无可置疑，他却不曾行使，<span style="color:#800000">*反倒凡事忍受*</span>，即忍受各样的匮乏。此字之意为<span style="color:#800000">*默然承担*</span>。<span style="color:#800000">*免得基督的福音被阻隔*</span>（免得在福音的道路上设下任何拦阻）。保罗处于四面皆是不肯罢休之敌的境况中，倘若他所行的稍有可使人质疑其动机纯正之处，福音便要受阻。他宁愿忍受一切，也不肯给反对他的人留下丝毫借口。

<!-- PAGE 182 -->

**13.** <span style="color:#800000">*你们岂不知为圣事劳碌的，就吃殿中的物吗？伺候祭坛的，就分领坛上的物吗*</span>？

保罗在此所言，对一切宗教皆为真实，虽然他所指的大概仅限于犹太教。<span style="color:#800000">*那些办理圣事的*</span>（<span style="color:#0000d4">οἱ</span> <span style="color:#0000d4">τὰ</span> <span style="color:#0000d4">ἱερὰ</span> <span style="color:#0000d4">εργαζόμενοι</span>）；<span style="color:#800000">*即那些执行圣职之事奉的人*</span>，也就是献祭之人。<span style="color:#800000">*吃殿中的物*</span>，即他们从殿中得着供养。<span style="color:#800000">*伺候祭坛的，分领坛上的物*</span>，即祭司从献在坛上的祭物中得着一份。既然这是神自己在旧约时代所设立的制度，它便有神圣权柄为其认可。使徒论此事的最后一项、也是决定性的论证，载于下一节。

**14.** <span style="color:#800000">*主也是这样命定，叫传福音的靠着福音养生*</span>。

<span style="color:#800000">*照样*</span>（<span style="color:#0000d4">ou[tw</span> <span style="color:#0000d4">καί</span>），<span style="color:#800000">*也照样*</span>，意即：神在旧约之下如何设立，主（即基督）在新约之下也照样设立。神既为律法之下的祭司定了这规矩，基督也为福音的执事定了同样的规矩。<span style="color:#800000">*主也是这样命定*</span>云云（<span style="color:#0000d4">διέταξεν</span> <span style="color:#0000d4">τοῖς</span>），即<span style="color:#800000">*他吩咐那传福音的*</span>云云。这原是给传道人自己的命令：不可从世俗的职业中谋取供养，乃当<span style="color:#800000">*靠福音养生*</span>，正如祭司靠圣殿养生一样。马太福音 10:10，路加福音 10:8。这是基督的律法，对传道人和会众同有约束力：会众当供给，传道人当从教会而非从属世的营生中寻求供养。诚然，正如保罗的情形所显明的，在某些境况之下，这命令对传道人不再具有约束力。但这些乃是例外，各按其本身的情由而得以为正当；至于这条规矩，作为规矩仍然有效。倘若传道人与会众都以此眼光看待这事，供养福音的事工便鲜有难处，也少有传道人被属世的营求所分心了。

**15.** <span style="color:#800000">*但这权柄我全没有用过。我写这话，并非要人这样待我，因为我宁可死，也不叫人使我所夸的落了空。*</span>

<!-- PAGE 183 -->

<span style="color:#800000">*这些权柄我全没有用过*</span>，或可指上文所列举的各样论据。即：“这些论据我一样也未曾运用”；也可指那权柄本身，而这权柄是多方面的：作工得报酬的权柄（第7节）；所施与人益处当得回报的权柄（第11节）；与别的传道人一样受待遇的权柄（第12节）；照旧约中神的律法与新约中基督的命令而受待遇的权柄。“这些权柄我一样也没有用过<span style="color:#800000">*。我写这话，并非要人这样*</span>（在将来）<span style="color:#800000">*待我*</span>（即照我所写的）（<span style="color:#0000d4">ἐν</span> <span style="color:#0000d4">ἐμοί</span>）”，就是在我身上如此行。保罗全无意在此事上改弦更张。这一决意的缘由，他随即说明。<span style="color:#800000">*因为我宁可死，也不叫人使我所夸的落了空*</span>，即：不叫人夺去我所夸的根据。保罗之所以能满怀喜乐的确信面对仇敌，正在于他传福音不受报酬这一无私的克己。这就是他所称的（<span style="color:#0000d4">καύχημα</span>），即所夸的根据。他能满有把握地据以为凭、证明自己正直的，并非单单是传福音，而是这一点——这在下文数节中他加以说明。

**16.** <span style="color:#800000">*我传福音原没有可夸的，因为我是不得已的。若不传福音，我便有祸了*</span>！

他之所以如此看重拒绝作传道人的一切报酬，缘由在于：<span style="color:#800000">*他虽然传福音*</span>，这却不是（<span style="color:#0000d4">καύχημα</span>）他可夸的凭据。传福音是他不得不作的；不但如此，他若不传福音，便有祸了。可夸之事必是他有自由去作、或不作的事。至于因传道而领受报酬，或是推辞不领，他都有自由；因此他推辞不领，便成了可夸的凭据，即成了他正直无伪的明证，是他可以坦然诉诸的。

**17.** <span style="color:#800000">*我若甘心作这事，就有赏赐；若不甘心，责任却已经托付我了。*</span>

<!-- PAGE 184 -->
这是证明传道并非可夸之事。他若<span style="color:#800000">*甘心*</span>传道，就是说，传与不传由他自己决定，那便有可夸之处；但他若<span style="color:#800000">*不甘心*</span>，就是说，此事并非由他自己作主（事实正是如此），他不过是在履行职分上的本分，无可夸口。保罗乐意传福音，视此为他至高的喜乐与荣耀，这从他的生平与著作中显而易见（罗马书 1:5；11:13；15:15, 16；哥林多前书 15:9, 10；加拉太书 1:15, 16；以弗所书 3:8）。所以此处所表明的（<span style="color:#0000d4">ἑκών</span> 与 <span style="color:#0000d4">άκων</span>）<span style="color:#800000">*甘心*</span>与<span style="color:#800000">*不甘心*</span>之别，并非欣然与勉强之别，乃是自主与受命之别。他说有职分或管家之责（<span style="color:#0000d4">οἰκονομία</span>）托付了他。这些管家（<span style="color:#0000d4">οἱκονόμοι</span>）通常是奴仆。奴仆奉命而行，与人出于己意自愿而行，二者大不相同。使徒此处所指的，正是这一分别。奴仆或许因主人的吩咐而觉荣幸，也乐意顺从，然而这终究只是服事而已。保罗既受命传福音，他便全心去传；但他并未受命拒绝接受众教会的供给。所以前者不是可夸之事，不是他可据以要求人格外信任的凭据；后者却是。他可以举出此事，不但证明自己的顺服，更证明促成这顺服之动机的纯正。医生诊治病人，纵然收取酬劳，其动机仍可能极其高尚；但他若无偿诊治穷人，虽然动机未必更高，其动机之纯正却已昭然无可置疑。所以保罗所夸的并非传道，因传道乃是本分；他所夸的乃是白白地传道，这全然出于自愿。他说，我传道若是出于自愿，<span style="color:#800000">*我就有赏赐*</span>；这不是指在神面前有何功德，乃是就一般意义上的报偿而言。他由此得着了些什么。他甚至赢得了仇敌的信任。但传道既非自主，乃是受命，他便不能藉此赢得信任。所以单单传道并非（<span style="color:#0000d4">καύχημα</span>）可夸之事，白白地传道才是。<span style="color:#800000">*责任却已经托付我了*</span>；希腊原文只作“<span style="color:#800000">*我是受托作管家的*</span>（参加拉太书 2:7，即受托一项职分），这是我不得不尽的。在这事上我不过是个仆人。”使徒立论所据的原则，正是我们的主所认可的，他说：“这样，你们作完了一切所吩咐的，只当说：我们是无用的仆人，所作的本是我们应分作的。”（路加福音 17:10）

<!-- PAGE 185 -->

**18.** <span style="color:#800000">*这样，我的赏赐是什么呢？（就是）我传福音的时候，叫人不花钱得福音，免得我用尽我传福音的权柄*</span>。

做他所受命去做的事，并不构成得赏赐的根据；但传福音而不取分文，却是他可以夸口的，即可以引以为凭据的。<span style="color:#800000">*这样，我的赏赐是什么呢*</span>？意即：什么构成我的赏赐？此处按前面所解释的意思而言；什么给了我夸口的根据？回答随即而来（此处用 <span style="color:#0000d4">i[na</span> 代替解释性的不定式；参看约翰福音 15:8；约翰一书 4:17）：<span style="color:#800000">*就是我传福音的时候叫人不花钱得福音*</span>。换言之，<span style="color:#800000">*免得我用尽我传福音的权柄*</span>。换言之，保罗的赏赐就是为别人牺牲自己。他把自己得以无偿服事他人称为赏赐。这确实如此：不仅因为得蒙允许以服事基督的百姓来服事基督，本是尊荣与福乐；也因为这样做证明了他毫无私心，从而赢得了他在其中劳苦之人的信任。通行译本作<span style="color:#800000">*免得我滥用*</span>，虽合乎 <span style="color:#0000d4">καταχράομαι</span> 的通常含义，却与上下文不合，也非该词的用法所必需；见 7:31。使徒所放弃的，并非滥用他受供养的权利，而是使用这权利本身。

**19.** <span style="color:#800000">*我虽是自由的，无人辖管，然而我甘心作了众人的仆人，为要多得人。*</span>

<!-- PAGE 186 -->
使徒的克己，以及他迁就他人的软弱与成见，并不限于他前面所论的那一件事。他向来所持守的原则是：在无关紧要之事上，宁可不坚持自己的权利。<span style="color:#800000">*我虽是自由的，无人辖管*</span>，即不受任何人辖制，也没有义务使自己的行事为人合乎他们的意见，<span style="color:#800000">*然而我甘心作了众人的仆人*</span>。他如何行此事、行到何等地步，下文有所解释。他这样迁就众人，其动机乃是<span style="color:#800000">*为要多得人*</span>，即得着更多的人、大多数的人；参看 10:5。在无关紧要之事上，无人比这位使徒更肯让步；在关乎真理原则之事上，也无人比他更不肯让步。只要那些事仍被看作无关紧要，他就情愿迁就最不合理的成见；但一旦有人坚持这些事为必须遵守的，他便一刻也不容让（加拉太书 2:5）。

**20.** <span style="color:#800000">*向犹太人，我就作犹太人，为要得犹太人；向律法以下的人，我虽不在律法以下，还是作律法以下的人，为要得律法以下的人*</span>；

向犹太人，他就作犹太人，即：他照他们所行的而行，顺从他们的习俗，遵守律法，但同时公开声明他如此行乃是出于通融迁就。凡在这样的顺从会让人合理地推断他视这些犹太人的礼仪为必需之时，他便坚决拒绝顺从。前面所提及他对提摩太与提多的做法，正显明了他行事所依的原则。前者他为之行了割礼，因为那被视为一种让步；后者他却拒绝为之行割礼，因为那是被当作必需之事而强求的。因此，凡在向他人的意见与习惯作出让步之时，有两件事必须谨慎留意：第一，所让步之事必须是无关紧要之事；因为凡本身为恶的，保罗从未有丝毫退让。在这一点上，他的行事与那些迁就世人罪恶、或迁就假宗教之迷信礼仪的人，恰恰相反。第二，这让步不可含有任何默认，仿佛那实际上无关紧要之事竟是道德上的义务。保罗为笼络犹太人所走的地步，可从使徒行传 21:18-27 所记载的事看出。

<span style="color:#800000">*向律法以下的人*</span>。这些人并非已归信的犹太人，因为他们既已被得着归于福音，就无须再去赢得；而"得"字在本节中正是此义，正如使徒方才所说的"得犹太人"。或许<span style="color:#800000">*律法以下的人*</span>与犹太人有别，乃是指入犹太教的外邦人。但这等归化者多半并非严格地处在<span style="color:#800000">*律法以下*</span>。他们承认耶和华为独一真神，却未使自己顺服摩西的典章。通说以为，此句不过是对前句的申明：'向犹太人，即向律法以下的人，我就作犹太人，即作律法以下的人。'

<!-- PAGE 187 -->

“我自己虽不在律法以下”，<span style="color:#0000d4">μὴ</span> <span style="color:#0000d4">ὡν</span> <span style="color:#0000d4">αὐτὸς</span> <span style="color:#0000d4">νόμον</span>。此句恰好在我们据以翻译的爱尔兹维尔版希腊文新约中被漏去，故英文通行译本中亦未见。然而，所有较古的抄本中皆有此句，许多教父著作与早期译本中亦有，因此为多数近代校勘者所采纳。内证亦支持此句。对保罗而言，声明自己虽行事如在律法之下、实则不在律法之下，是要紧的；因为他所传的福音有一条根本原理，即信徒已从律法中得释放。“我们不在律法之下，乃在恩典之下”（罗马书 6:14）。所以必须使人认清：他之遵从犹太律法，乃是出于自愿的迁就。

**21.** <span style="color:#800000">*向没有律法的人，我就作没有律法的人（其实我在神面前不是没有律法，在基督面前正在律法之下），为要得没有律法的人。*</span>

<!-- PAGE 188 -->
<span style="color:#800000">*没有律法的人*</span>指外邦人，他们没有成文的启示作为行为的准则；参罗马书 2:12。然而，因这字（<span style="color:#0000d4">άνομος</span>）<span style="color:#800000">*没有律法*</span>亦可解作<span style="color:#800000">*放纵无忌*</span>，即不受道德约束，故保罗谨慎地说明他所谓"如同没有律法的人"是何意。他在外邦人中间时，不遵守犹太律法；就此而言，他是没有律法的；但他并非<span style="color:#800000">*在神面前没有律法*</span>，即并非不顾道德律的约束；乃是<span style="color:#800000">*在基督面前正在律法之下*</span>，即承认自己有顺服基督的责任，而基督的旨意乃是本分的最高准则。换言之，他不在犹太律法之下，却在道德律之下。他置犹太律法于不顾，为要<span style="color:#800000">*得那没有律法的人*</span>，即外邦人。他在耶路撒冷时，遵守犹太律法；在安提阿时，则拒绝如此行，并且责备彼得在外邦人中间还按犹太人的样式行事，加拉太书 2:11-21。倘若福音负上犹太礼仪与种种禁例的全副重担，福音在外邦人中间的进展纵不至完全受阻，也必大受妨碍。彼得自己甚至对犹太人说过，摩西的律法是一副轭，是他们和他们的祖宗所不能负的，使徒行传 15:10。保罗也对加拉太人说，他之所以抵挡那些犹太派的人，是要叫福音的真理仍存在他们中间，加拉太书 2:5。

**22.** <span style="color:#800000">*向软弱的人，我就作软弱的人，为要得软弱的人。向什么样的人，我就作什么样的人，无论如何总要救些人。*</span>

许多人认为<span style="color:#800000">*软弱的人*</span>是指从另一角度来看的犹太人与外邦人，即那些无力领会、无从体认福音之人。此种解释的唯一理由，乃是先行假定：<span style="color:#800000">*得*</span>在此处必解作使人归正、使人成为基督徒，因此所要得着的，必是尚未归信之人。然而该词不过是<span style="color:#800000">*赢得*</span>之意，即引人持守正当的看法；故此，它既可指未归信的犹太人与外邦人，亦同样可用于软弱而迷信的信徒。既然前一章中<span style="color:#800000">*软弱的人*</span>指的是软弱的基督徒，即见识尚不清晰、心志尚不坚定之人，而整段论述的宗旨，正是要劝那些较为通达的哥林多信徒迁就那些软弱的弟兄，那么在此处照样理解，就自然得多。保罗以自己为榜样：向软弱的人，他就作软弱的人；他迁就他们的偏见，为要赢得他们归于更正的见识。他也愿哥林多人如此行。<span style="color:#800000">*向什么样的人，我就作什么样的人*</span>。这句话把前面所说的一概总括起来。他如此俯就迁就，并非只对这一类或那一类人，乃是对各样的人，并且是在一切无关紧要的事上如此；为要<span style="color:#800000">*无论如何*</span>（<span style="color:#0000d4">πάντως</span>）<span style="color:#800000">*总要救些人*</span>。

**23.** <span style="color:#800000">*凡我所行的，都是为福音的缘故，为要与（你们）同得这福音的好处。*</span>

<span style="color:#800000">*这些事我都作了*</span>；或依如今普遍采纳的读法（作 <span style="color:#0000d4">πάντα</span> 而非 <span style="color:#0000d4">τοῦτο</span>），则为<span style="color:#800000">*凡我所行的*</span>，意即：“我一生的行事，不单是这样迁就他人的成见，乃是在一切事上，都以推进福音为准则。”这样解释意思更佳；因为若作<span style="color:#800000">*这些事我都作了*</span>，便不过是重复上一节所已包含的意思。保罗是为福音而活的。他所行的一切都是为着福音。<span style="color:#800000">*为要与人同得这福音的好处*</span>，即与众人一同有分；而非<span style="color:#800000">*与你们同得*</span>，因经文并无任何限定，将此语专指哥林多人。所谓有分于福音，自然是指有分于福音的诸般益处，<!-- PAGE 189 -->即得着福音所宣告的那救赎。人必须为福音而活，方能有分于福音。

**24.** <span style="color:#800000">*岂不知在场上赛跑的都跑，但得奖赏的只有一人？你们也当这样跑，好叫你们得着奖赏。*</span>

此处是以比喻性的语言，劝人克己自制、竭力奋进。因这劝勉主要是向外邦归信者所发，所用的意象便取自他们极为熟悉的公众竞技。这些竞技——即奥林匹亚赛会与地峡赛会（后者每三年夏季在哥林多附近举行）——乃是希腊各地民众聚集之期。赛中的角逐激起各阶层居民极大的争胜之心，连罗马的皇帝也不推辞下场参赛。得胜者便得以不朽，就人的口所能给予的不朽而言。因此，对希腊人而言，再没有比引用这些制度更易明白、更为有力的了；而这类制度在近世是无可与之相当的。

<span style="color:#800000">*岂不知*</span>。使徒视为当然的是，他们熟悉他所提及的这些竞技的规则。<span style="color:#800000">*在场上赛跑的*</span>；按字面即在举行竞技的<span style="color:#800000">*司他丢场*</span>或<span style="color:#800000">*跑马场*</span>中，如此称呼是因其长度为一<span style="color:#800000">*司他丢*</span>（略多于二百码）。<span style="color:#800000">*众人都跑，但得奖赏的只有一人*</span>。在这场赛跑中，起跑并不够；几乎坚持到终点也不够；必须胜过所有的对手，率先抵达终点。得奖赏的只有一人。<span style="color:#800000">*你们也当这样跑，好叫你们得着奖赏*</span>。就是说，要像那一人那样跑，<span style="color:#800000">*为要*</span>得着奖赏。惟有在预备时极力克己，在竞赛中竭尽全力，方能得胜。在基督徒的赛程中，得胜者原有许多；然而这劝勉的要点在于：众人都当像希腊竞技中那独得奖赏的一人那样奔跑。

**25.** <span style="color:#800000">*凡较力争胜的，诸事都有节制。他们不过是要得能坏的冠冕；我们却是要得不能坏的冠冕。*</span>

<!-- PAGE 190 -->
<span style="color:#800000">*凡较力争胜的*</span>等语（<span style="color:#0000d4">πᾶς</span> <span style="color:#0000d4">ὁ</span> <span style="color:#0000d4">ἀγωνιζόμενος</span>），意即<span style="color:#800000">*凡惯于竞技角逐之人*</span>，也就是每一个职业的竞技者。此词涵盖各样比赛，无论赛跑、摔跤或搏斗。<span style="color:#800000">*诸事都有节制*</span>，即在一切事上克制自己。他在饮食上、在肉体的享受上都行克己之道，并接受艰苦而长久的操练。古代作家论及参赛者备战期间当守的禁戒与操练之规，所在多有。<span style="color:#800000">*他们不过是要得能坏的冠冕*</span>，<span style="color:#800000">*我们却是要得不能坏的冠冕*</span>。外邦人为得一顶橄榄枝编成的花环或松叶编成的花冠，尚且甘受如此严苛的操练；基督徒为那永不衰残的公义冠冕，岂不当付出同样的代价么？

**26.** <span style="color:#800000">*所以，我奔跑不像无定向的；我斗拳不像打空气的*</span>：

<span style="color:#800000">*所以，我奔跑*</span>，即：因为要得胜，须付出如此之多的努力。<span style="color:#800000">*我奔跑*</span>，意即：我奔跑并不像那<span style="color:#800000">*无定向*</span>（<span style="color:#0000d4">ἀδήλως</span>）奔跑的人。此词或可指<span style="color:#800000">*不引人注目地*</span>，即不像无人看见之人，乃像众目所注视之人。但更可能的意思是：不像那不知自己往何处跑、为何而跑的人。人若不确知自己的路程或目标，奔跑起来便无精神、无气力。<span style="color:#800000">*我斗拳*</span>。此处所喻乃是拳斗，即以拳相搏。<span style="color:#800000">*不像打空气的*</span>。此处的比喻亦有两解。人若只是操练，并无对手，便可说是打空气。在这样的假打之中，人不必用多少力气。又或者，人向对手挥拳而未击中，也是打了空气。后一解更佳。维吉尔用同样的比喻表达同样的意思，他说到一位拳手未击中对手，便是“vires in ventum effudit”（力气尽泄于风中）。见《埃涅阿斯纪》五卷446行。无论取哪一解，意思都是一样：一无所成，徒劳无功。在14:9，使徒论到那些说方言的人，说他们是向空气说话，就是说，他们说了却毫无果效。

**27.** <span style="color:#800000">*我是攻克己身，叫身服我；恐怕我传福音给别人，自己反被弃绝了。*</span>

与上文所述那种徒劳无果、漫无目标的争战相反，保罗说：<span style="color:#800000">*我是攻克己身*</span>；按字面即<span style="color:#800000">*我痛击我的身体*</span>。（<span style="color:#0000d4">ὑπωπιάζω</span>，意为<span style="color:#800000">*击打眼下之处，打伤，击打*</span>，参路加福音 18:5。）他的对手就是自己的身体；他如此击打，即如此对付它，<!-- PAGE 191 --><span style="color:#800000">*叫身服我*</span>，字面意思是<span style="color:#800000">*像牵领奴仆一般带着走*</span>。这或许是暗指当时的习俗：得胜者把被征服的对手当作仆役牵着示众；不过此说并不确定。身体既在一定意义上是罪的居所与器官，此处便用来代表我们整个有罪的本性（罗马书 8:13）。保罗所要制服的，不单是他属肉体的情欲，更是他心中一切邪恶的倾向与私欲。<span style="color:#800000">*恐怕我传福音给别人*</span>（<span style="color:#0000d4">κηρύξας</span>）——使徒或许有意仍沿用前面的比喻而说：“恐怕我作了传令官（在希腊竞技中，传令官的职责是宣布比赛规则，并召唤竞技者或角斗者入场），自己反被判为不配得奖赏的。”然而，这个词既常用以指<span style="color:#800000">*传讲福音*</span>，他也可能有意放下比喻而说：“他之所以如此竭力奋斗，是恐怕自己传福音给别人，自己反成了（<span style="color:#0000d4">ἀδόκιμος</span>）被弃绝的人。”这是何等有力的论证，何等严厉的责备！那些轻率懈怠的哥林多人以为自己尽可放纵到罪的边缘而安然无恙，而这位竭诚尽忠的使徒却视自己为在毕生的搏斗中力争自己的救恩。然而，这同一位使徒，显然按“义人得救也是仅仅得救”“天国是努力进入的”这一原则而行，在别处却又发出最喜乐的得救确信，说他深信天上、地上、阴间的任何事物都不能使他与神的爱隔绝（罗马书 8:38, 39）。前一种心境正是后一种心境的必要条件。惟有那些自觉与罪常作殊死争战的人，才得蒙赐这样的确信。保罗几乎在同一口气之间说：“我真是苦啊！”又说：“感谢神，使我们得胜。”（罗马书 7:24, 25）惟有那懒惰放纵自己的基督徒，才终日疑惑不定。
