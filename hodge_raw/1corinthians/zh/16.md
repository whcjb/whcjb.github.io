<p class="title-block-h2" style="text-align:center; font-size:16px; font-weight:bold; margin:18px 0 12px;" markdown="1"><span style="color:#006411">第十六章</span></p>

本章所论：一、为耶路撒冷圣徒所当办的捐项，1-9节。二、论提摩太与亚波罗，使徒嘱咐哥林多人当以信任相待，10-14节。三、第三段为劝勉与问安之语，15-20节。四、末段乃保罗亲笔所写的问安，21-24节。

<p style="text-align:center" markdown="1"><span style="color:#0000d4">**论为耶路撒冷圣徒**</span> <span style="color:#0000d4">**捐资之事。**</span></p>

<!-- PAGE 386 -->
由于某种如今已无法确知的缘故，耶路撒冷信徒中的贫穷状况，比教会其他任何地方都更为严重。保罗书信中几乎所有关于周济穷人的特别劝勉，其首要所指都是耶路撒冷的穷人。他曾劝加拉太众教会为救济他们而捐资，随后又劝马其顿的众教会，如今他就此事向哥林多人陈说。有一种相当普遍的看法，认为耶路撒冷基督徒的贫穷，源于起初在他们中间实行的凡物公用；那原是爱心过于知识所生出的一个错误。三十年之久，这一失误足以产生其必然的后果。一事上的完全，须以凡事上的完全为前提。财物上完全的均平，须以完全脱离自私与懒惰为前提。使徒行传 11:29 所记叙利亚众教会所办的捐项，乃是因基督徒先知亚迦布预言天下将有大饥荒，警告众弟兄而起。无论其缘由如何，有一事是确凿的：耶路撒冷的圣徒确实特别需要那些较为富足的弟兄的帮助。因此，保罗虽被犹太基督徒轻看、猜疑，仍殷勤地为他们劳苦。他劝哥林多人在此事上采用他在加拉太众教会所定的同样办法：每逢七日的第一日，各人照自己的进项抽出来捐上，好叫他来到的时候不用现凑（第 1、2 节）。他或是差遣他们所认可的人把捐项送往耶路撒冷，或是若数目够大、值得如此行，他便亲自与他们所差的人同去（第 3、4 节）。他宣告自己的计划：要经过马其顿之后往哥林多去，或者要在他们那里过冬。但他在以弗所大有作工的指望，使他必要住到五旬节（第 5-9 节）。

<span style="color:#800000">*论到提摩太与亚波罗*</span>，他劝勉他们要如此对待提摩太，使他在他们中间无所惧怕，因为他是配得他们信任的（10、11节）。论到亚波罗，他说自己曾力劝他与其余弟兄同往哥林多，但他那时不愿前去，只等有合宜的机会才会前往（12-14节）。他劝勉他们顺服司提反一家，并顺服凡为这美好事工劳苦的人（15、16节）。他表明见到从哥林多来的弟兄们心中甚是欢喜，又替身边众人向亚该亚的众基督徒问安（17-20节）。书信的结语是他亲笔所写，作为全书的凭证（21-24节）。

**1.** <span style="color:#800000">*论到为圣徒捐钱，我从前怎样吩咐加拉太的众教会，你们也当怎样行。*</span>

<span style="color:#800000">*论到为圣徒捐钱。*</span>所指的是哪些圣徒，哥林多人早已知晓。在罗马书 15:26，并非<span style="color:#800000">*为圣徒*</span>这样的说法，而是更为明确的措辞：“为耶路撒冷圣徒中的穷人”；使徒告诉罗马人，马其顿与亚该亚已为这些人捐输。希腊文<span style="color:#0000d4">λογία</span>一词用作<span style="color:#0000d4">συλλογή</span><span style="color:#800000">*、即捐项*</span>之意，仅见于<span style="color:#800000">*本处。我从前怎样吩咐*</span>，即我如何安排或命定。这是带着权柄的话。因为这些捐献虽是甘心乐意的，且必须乐意而作（哥林多后书 9:7），却仍是一项本分；故此，无论捐项本身，抑或办理捐项的方式，都适宜成为使徒指示的内容。在加拉太书中并未提及此次捐项。这吩咐大概是保罗探访那些教会时所发的。<span style="color:#800000">*你们也当这样行*</span>，即在办理捐项的方式上采用同一办法。那办法是什么，下一节即有说明。

**2.** <span style="color:#800000">*每逢七日的第一日，各人要照自己的进项抽出来留着，免得我来的时候现凑。*</span>

捐资当于每主日进行；人人都当有分；所捐之数则当按各人的力量而定。这便是使徒在加拉太众教会中所立的三项原则，也是他劝哥林多人当采行的。<span style="color:#800000">*每逢七日的第一日*</span>，按字面即<span style="color:#800000">*安息日之一*</span>，乃循犹太人称呼周内各日的方式。希伯来文"安息日"一词（意为*安歇*），不但用单数，也用复数形式，既指第七日，也指整个七日，见路加福音18:12。七日的第一日既由神所设定，成为基督徒的圣日，此可由下列各端推知。

<span class="enum-num">1.</span> 由于我们的主自己使那一日显为特别，见约翰福音 20:19, 26。

<span class="enum-num">2.</span> 其次，出于所要纪念之事的重大。将七日的第七日分别为圣，本是要人常记创造世界这一伟大真理，而全部启示宗教的体系皆建基于此；既然基督教乃建基于基督的复活，那么基督复活的那一日，便因此成了基督徒的安息日。

<span class="enum-num">3.</span> 使徒约翰称此日为主日，即分别出来事奉主的日子，见启示录 1:10。

<span class="enum-num">4.</span> 从种种证据可见，自始以来这一日便是基督徒聚集敬拜的日子，使徒行传 20:7。

<span class="enum-num">5.</span> 由于全教会一致的作法；此作法既有使徒认可的明证，便具有权威。

<!-- PAGE 388 -->
<span style="color:#800000">*每逢七日的第一日，各人要……*</span> 使徒所定这些安排中有一要点，即捐输不可限于某一等人。所需款项，或许单从少数富足之人身上便可筹得；但这样便不能达成使徒心中一个重要的目的。保罗所切望成就的，与其说是解救穷人肉身上的困乏，不如说是这些捐项在灵性上所生的果效——即促进基督徒的团契，显明福音的真实与大能，并激发人向神发出感谢与颂赞（哥林多后书 9:12-14）。各人都当 <span style="color:#800000">*在自己那里存留*</span>，即多数近代注释家所谓 <span style="color:#800000">*在家中*</span>，<span style="color:#0000d4">paræ</span> <span style="color:#0000d4">ἑαυτῷ</span>。可比较路加福音 24:12 中的 <span style="color:#0000d4">πρὸς</span> <span style="color:#0000d4">ἑαυτόν</span><span style="color:#800000">*，*</span>又见约翰福音 20:10。照此解释，所吩咐的便是：各人当在七日的第一日，在家中把力所能及的捐资撇开存放，如此 <span style="color:#800000">*积蓄*</span> 其捐项。然而对此解释可有几点异议：其一，这样整句话便显得晦涩而拗口——“各人当在家中放置，积蓄他所要献的。”况且原文并非 <span style="color:#800000">*在家中存留*</span> 之意，乃是 <span style="color:#800000">*在自己那里存留*</span>。这吩咐所指不过是 <span style="color:#800000">*让他放在自己那里*</span>，即让他把打算捐献的取出归于己旁。至于他当如何处置、存于何处，则未曾言明。<span style="color:#0000d4">Θησαυρίζων</span> 一词意为 <span style="color:#800000">*放入库中*</span> 或 <span style="color:#800000">*积存*</span>，与所存之处乃是某一公共库房、而非各人自己家中的假设，全然相合。其二，倘若保罗吩咐将这银钱存 <span style="color:#800000">*在家中*</span>，何以要拣选七日的第一日呢？显然，第一日必是为行此所吩咐之事提供了某种特别的便利。要求此事必于七日的第一日举行，所能给出的惟一理由，就是基督徒素常于那日聚集，各人从一周所得中撇开的，便可积存起来，即投入教会的公库。其三，使徒所欲成就的目的，若非如此便无从达到。他所愿的是 <span style="color:#800000">*免得我来的时候现凑*</span>。但若各人把银钱存在自己家中，到时仍须现凑。所以，保罗多半是要吩咐哥林多人于每主日聚集敬拜之时，为穷人举行捐输。<span style="color:#800000">*照自己的进项抽出来留着*</span>；直译为 <span style="color:#800000">*凡他所亨通的*</span>。各人当按其营业所得的顺利，量力撇出所能捐的。这是使徒愿基督徒遵行的另一项原则：捐献当与自己的力量相称。

**3.** <span style="color:#800000">*等我来到，你们所推举的人，我就打发他们带着你们的信，把你们的捐资送到耶路撒冷去。*</span>

<!-- PAGE 389 -->
保罗并不亲自收取这银钱。这银钱要交给哥林多人所选定并认可的人，而保罗应许打发这些人带着他的书信往耶路撒冷去。<span style="color:#0000d4">dij</span> <span style="color:#0000d4">ἐπιστολῶν</span>，<span style="color:#800000">*带着书信*</span>，不当与前文相连而解作“凭<span style="color:#800000">*你们的*</span>书信而蒙认可”，乃当与后文相连，解作“我要带着书信打发他们去”。若非如此，保罗便无须打发他们——即那些为哥林多人所认可的人——前去了。众人负责募集银钱；银钱要交托与他们自己所选的人；然而保罗既是发起此次募捐的人，便当由他将银钱送往耶路撒冷。使徒既以为，将自己置于嫌疑之外，连最存恶意的人也不得有机会质疑他的正直，乃是智慧之举（此处已有暗示，哥林多后书 8:19, 20 更明言之），那么别人与传道人以同样的谨慎行事，也必是智慧之举。人若受托支配他人或教会的银钱，当尽可能不由自己保管，而交与他人保管，使众人得知这银钱如何使用。至少保罗正是如此行的。

**4.** <span style="color:#800000">*若我也该去，他们可以和我同去。*</span>

<span style="color:#800000">*若我也值得去，*</span>意即：若所捐之数足以使我一同带往耶路撒冷为宜，你们所派的人便与我同去。据使徒行传 19:21，保罗曾定意在游历马其顿、亚该亚之后往耶路撒冷去。但他是否在哥林多人的捐项送去之时同往，则视其数目多寡而定。他不会为了掌管一笔微不足道之款的分派，而更改自己的计划。

**5.** <span style="color:#800000">*我要从马其顿经过，既经过了，就要到你们那里去，因为我要路过马其顿。*</span>

<!-- PAGE 390 -->
从哥林多后书 1:15, 16 看来，保罗起初的计划是从以弗所直接到哥林多，再从那里往马其顿去，然后又回到哥林多，由此往耶路撒冷去。如今他告知他们，自己要先经过马其顿，然后才到哥林多。哥林多的假教师们极力搜寻可以攻讦他的把柄，竟以这计划的更改为极大的过失，作为凭据，说他无论在心意上或在道理上都不足倚赖。这从他在后书中为自己所作的辩白，便可清楚看出。<span style="color:#800000">*我要经过马其顿；*</span>并非说我"正在经过"；此处的现在时态所表达的，乃是使徒已定之意。对此处时态语气的误解，大概使抄写者将本书信的写作地定为腓立比；然而由第 8 节可以明白，此书乃是从以弗所写的。

**6.** <span style="color:#800000">*或者和你们同住几时，或者也过冬，无论我往哪里去，你们就可以给我送行。*</span>

「我要经过马其顿，却要在你们那里住下。」他在前者只是短暂经过，在后者则要久留。在后书中，他说自己正在马其顿；而使徒行传 20:2, 3 记载，他在以弗所城的骚乱之后离开那城，前往马其顿，又从那里往希腊去，在那里住了三个月。可见此处所拟的计划确已实行。他说要在他们那里过冬，<span style="color:#800000">*为要*</span>叫他们送他前行，即在路上陪送他一程，这是当时通常的敬重之礼。保罗宁愿从哥林多人得着这份礼遇，而不愿从别人得着；因为尽管他们给他带来许多麻烦与忧虑，他对他们的爱却格外深厚，这从后书中可以明显看出。

**7.** <span style="color:#800000">*我如今不愿意路过见你们；主若许我，我就指望和你们同住些时候。*</span>

<!-- PAGE 391 -->
有些人将 <span style="color:#0000d4">άρτι</span><span style="color:#800000">*，现今，*</span>与 <span style="color:#0000d4">θέλω</span><span style="color:#800000">*，我愿意，*</span>相连，解作："我现今不愿意，虽然从前有此打算。"但它自然的联系当是与 <span style="color:#0000d4">ἰδεῖν</span><span style="color:#800000">*，看见，*</span>相连："我不愿意现今路过时见你们。""<span style="color:#800000">*但*</span>我盼望"；较古的抄本此处不作 <span style="color:#0000d4">δέ</span>（<span style="color:#800000">*但*</span>），而作 <span style="color:#0000d4">γάρ</span><span style="color:#800000">*；"因为*</span>我盼望与你们同住些时候。"看来保罗在以弗所得知哥林多的种种乱象，遂决意给他们写这封信，而不作匆匆一访，并将探访推迟数月，好让这封信有时间生出果效。同一缘由也使他后来真去哥林多时，在那里逗留了一段时日，以便纠正他不在时滋生的弊端。哥林多后书表明，他何等挂虑这封信的效果，及至提多带来消息说众人已因此悔改，他又何等欢喜。<span style="color:#800000">*主若许我，*</span>（<span style="color:#0000d4">ἐπιτρέπῃ</span>）或作："主若已许我"（<span style="color:#0000d4">ἐπιτρέψῃ</span>）。后一读法为晚近的编校者所采纳。<span style="color:#800000">*主*</span>即基督；保罗认定万事皆由祂安排，祂的引导是他所寻求、也是他始终顺服的。

**8、9.** <span style="color:#800000">*但我要仍旧住在以弗所，直等到五旬节；因为有宽大又有功效的门为我开了，并且反对的人也多。*</span>

因此，他留在以弗所有两个理由：一是可以大有作为的机会甚多，二是必须抵挡福音的敌人。保罗的计划是：春季在以弗所，夏季在马其顿，冬季在哥林多。次年的五旬节他是在耶路撒冷度过的。他不能即刻离开以弗所，<span style="color:#800000">*因为*</span>，他说，<span style="color:#800000">*有宽大又有功效的门为我开了。门*</span>就是进入之路，喻指得以进入人的心思意念、掌握其心的机会。使徒面前有宽大的门敞开，他有广阔的作工之地。<span style="color:#800000">*有功效的*</span>这一形容词与门的比喻并不相称，但其意甚明——这机会是可以收得实效的。<span style="color:#800000">*并且反对的人也多。*</span>福音的敌对者在各处性质大不相同。在以弗所，主要是那些与敬拜亚底米有利害关系的人。外邦人的压迫似乎逼使犹太人与基督徒联手（使徒行传 19:22）。而在哥林多，保罗最激烈的对手却是犹太化派。既有如此凶暴的敌人在场，教会就更需要使徒亲自扶持了。

**10.** <span style="color:#800000">*若是提摩太来到，你们要留心，叫他在你们那里无所惧怕；因为他劳力作主的工，像我（一样）。*</span>

<!-- PAGE 392 -->
在使徒行传 19:22 我们读到，保罗“就打发帮助他的人提摩太、以拉都二人往马其顿去，自己暂时等在亚细亚。”可见提摩太此时正行经马其顿，并预期抵达哥林多，那正是使徒差他前去之地；参 4:17。除提摩太此行之外，稍后还另有一次差遣，由提多与别的弟兄同去，为要知道这封信所产生的果效；使徒极其焦切地等候他们回来，见哥林多后书 2:12, 13。保罗请求哥林多人如此接待提摩太，使他在那里可以<span style="color:#800000">*无所惧怕*</span>。这并非惧怕人身的暴力，乃是惧怕不为人所尊重、所信任。他为此请求所举的理由，显明了他所忧虑之患的性质，<span style="color:#800000">*因为他劳力作主的工，像我一样*</span>。他们若肯承认这一点，提摩太就心满意足了。<span style="color:#800000">*主的工*</span>，如在 15:58 中一样，或指主自己所从事的工，或指主所吩咐的工。<span style="color:#800000">*像我一样*</span>。这是一句涵盖极广的称许。提摩太所传的，正是保罗所传的同一福音；其殷勤与忠信亦复相同。

**11.** <span style="color:#800000">*所以，无论谁都不可藐视他，只要送他平安前行，使他能到我这里来；因为我与众弟兄一同等候他。*</span>

<span style="color:#800000">*所以，*</span>就是说，因为他作主的工，他理当受人敬重，不可被人藐视。或许正是提摩太年轻，才使使徒在这事上格外挂虑（提摩太前书 4:12）。<span style="color:#800000">*但要送他平安前行；*</span>就是以友爱之情送他上路。<span style="color:#800000">*叫他到我这里来。*</span>保罗并不愿提摩太长留哥林多；他既完成所受的托付（4:17），就要回到使徒那里。他后来果然如此回去了，保罗写第二封书信时，他正与保罗同在（哥林多后书 1:11）。<span style="color:#800000">*我指望他和弟兄们同来，*</span>即保罗所指派作提摩太旅途同伴的那些弟兄。在新约中，我们极少读到有人独自出外作传道之行。

**12.** <span style="color:#800000">*至于我们的兄弟亚波罗，我甚愿他同着那几位弟兄到你们那里去；但他此时全无来意，将来得着方便的时候他必来。*</span>

<!-- PAGE 393 -->
或是亚波罗曾在其中劳苦过的哥林多人，请求保罗再打发他到他们那里去；或是出于别的缘由，使徒极愿他与那些从哥林多来、要把这封书信带回去的弟兄同行（参第17节）。从本节可见，亚波罗并不在保罗的权柄之下。他推辞不往哥林多去，除了"不愿意"以外，未给出任何理由。至于他为何不愿意，只能推测。许多人以为，是因他的名字被牵连进搅扰该教会的党派之争中（1:12）。<span style="color:#800000">*我极力劝他；*</span>或作，<span style="color:#800000">*我屡次劝他往你们那里去，*</span>等等。<span style="color:#0000d4">ἱνα</span> 在此并非"*为要*"之意，而是指出所请求的内容。

13、14<span style="color:#800000">*节。你们务要警醒，在真道上站立得稳，要作大丈夫，要刚强。凡你们所做的都要凭爱心而做。*</span>

这些简短的劝勉，为本书信作了合宜的收束；每一句都切合哥林多人所处的特殊境况，然而理所当然，也适用于一切在与世界争战中的基督徒。

<span class="enum-num">1.</span> 他劝勉<span style="color:#800000">*他们要儆醒*</span>，即要保持警觉，时常戒备，免得属灵的仇敌趁他们尚未察觉危险之际，就已胜过了他们。

<span class="enum-num">2.</span> 他们既被假教师所环绕，那些人诡诈行事、篡改神的道（哥林多后书 4:2），故使徒劝勉他们<span style="color:#800000">*在真道上站立得稳*</span>。不要把每一条教义都当作尚未定论、可任意争辩之事。凡属信仰的要道，凡神已有明白启示的教义——例如复活的教义——都当视为已定之事；在基督徒中间，这些已不再是可争议的问题。有些教义载于一切正统教会的信条之中，圣经教导得如此清楚，若总是把它们重新提出质疑，不但徒劳无益，而且大有损害。

**3.** <span style="color:#800000">*要作大丈夫。*</span>哥林多人所处的境况，需要极大的勇气。他们既要抵挡有学问之人的藐视，又要抵挡有权势之人的逼迫。

**4.** <span style="color:#800000">*刚强壮胆*</span> 他们所需要的不仅是胆量，更是力量，好抵挡仇敌，并在将临的试炼之下站立得住。

**5.** <span style="color:#800000">*凡你们所做的都要凭爱心而做，*</span>意即：要让爱心居于主导，在你们心中，在你们家中，在你们的聚会中。本书信前面各部分已表明，这一劝勉是何等必要；因为教会为党派之争所撕裂，甚至连主的晚餐——在别处无不是爱的筵席——在哥林多也竟成了苦毒的源头。

<!-- PAGE 394 -->
**15、16.** <span style="color:#800000">*弟兄们，我劝你们，[你们晓得司提反一家，是亚该亚初结的果子，并且他们专以服事圣徒*</span> <span style="color:#800000">*为念，] 你们要顺服这样的人，也要顺服一切与（我们）同工同劳的人。*</span>

司提反一家是亚该亚最先归信福音的一家。按通行的经文，罗马书 16:5 说以拜尼土是<span style="color:#800000">*亚该亚*</span>初结的果子；但那里正确的读法是<span style="color:#800000">*亚细亚*</span>，故两处经文并无冲突。论到司提反一家，经上说<span style="color:#800000">*他们专以服事圣徒为念*</span>，即甘心献身于信徒的服事。这一说法未必含有任何职分性事奉的意思。所劝勉的是：<span style="color:#800000">*我劝你们顺服这样的人。*</span>‘他们既服事你们，你们也当服事他们。’顺服良善之人，再自然不过。<span style="color:#800000">*并一切同工同劳的人*</span>。这或可解作：凡与这样的人同工的，你们都当顺服；即凡同样专以服事信徒为念的人。服事人的，理当受人服事。

**17.** <span style="color:#800000">*司提反、福徒拿都、亚该古到这里来，我很喜欢；因为你们所缺乏的，他们补上了。*</span>

这几位是哥林多教会的成员，他们前往以弗所，多半正是为了见使徒，就教会的光景向他请教。哥林多人写给保罗的那封信——就是他在7:1所提及的——大概也是由他们带去的。他因他们的到来而欢喜，缘由在于他们<span style="color:#800000">*补上了哥林多人所缺的；*</span>或者更确切地说，补上了<span style="color:#800000">*对你们的思念*</span>（<span style="color:#0000d4">τὸ</span> <span style="color:#0000d4">ὑμέτερον</span> <span style="color:#0000d4">ὑοτέρημα</span>；此处 <span style="color:#0000d4">ὑμέτερον</span> 作宾格用法，与15:31相同）。这几位弟兄的在场，在某种程度上弥补了哥林多人不在身边的缺憾。另有一种解释是：「他们做了你们所未做的事」，即把哥林多的实情告知了使徒。前一种理解较为通行，也更合乎本段的语气——那是慈爱而抚慰的语气。下文所言亦印证了这一点。

**18.** <span style="color:#800000">*因为他们使我和你们的心都得了舒畅；所以你们要敬重这样的人。*</span>

<!-- PAGE 395 -->

<span style="color:#800000">*因为，*</span>即：他们补上了你们的缺席，因为他们的到来所生的果效，正与我们彼此相聚所要生的果效一样。这使我心里畅快，也在你们身上产生了相应的果效。迈尔等人解释说：‘我信中凡使你们畅快的话，都当归功于他们。’另有人认为，使徒所指的是这几位弟兄归回哥林多所要产生的效果，以及他们所要带去的、关乎使徒之爱的确据。或者，保罗的意思是：凡使他畅快的，也必使他们欢喜；他们必因他的喜乐而喜乐。无论如何理解，这都是这位使徒著作中比比皆是的温雅得体之一例。<span style="color:#800000">*所以你们要敬重这样的人，*</span>即：要正确地认识并珍视他们。

**19.** <span style="color:#800000">*亚细亚的众教会问你们安。亚居拉和百基拉并在他们家里的教会，因主多多地问你们安。*</span>

<span style="color:#800000">*亚细亚*</span>在此指方伯所辖的亚细亚省，以以弗所为首府，启示录中所提的七个教会即在其境内。<span style="color:#800000">*问安*</span>，就其一般意义而言，乃是祝人平安；就其基督徒的意义而言，则是祝人得救。这一层意思已包含在希伯来人问安的套语「愿平安与你同在」之中，此语后来也进入了基督徒的礼仪。<span style="color:#800000">*在主里*</span>问安，就是以基督徒的身份、并用基督徒的方式向人问安；乃是因他在主里而向他问安，且以主所悦纳的方式问安。亚居拉和百基拉被逐出罗马之后（如使徒行传 18:2 所记），定居在哥林多。他们随使徒同往以弗所，并留在那里（使徒行传 18:18）。<span style="color:#800000">*在他们家里的教会*</span>，即在他们家中聚会的基督徒群体。罗马书 16:5 在提及他们名字时用了同样的说法，故此可以推想，无论在罗马或在以弗所，他们都开放自己的居所，作为基督徒定期聚会之处。他们以制造帐棚为业，所需的房舍想必宽敞，正合于这类聚会之用。

**20.** <span style="color:#800000">*众弟兄都问你们安。你们要亲嘴问安，彼此务要圣洁。*</span>

<!-- PAGE 396 -->
<span style="color:#800000">*众弟兄*</span>在本节中既与第19节所提亚居拉和百基拉家中的教会有所区别，便可推知：以弗所的基督徒中只有一部分，而且很可能只是一小部分，习惯在那处地方聚集。使徒劝勉他们要<span style="color:#800000">*彼此*</span><span style="color:#800000">*用圣洁的亲嘴问安，*</span>参罗马书 16:16；哥林多后书 13:12；帖撒罗尼迦前书 5:26。这是当时表达基督徒相爱之情的通行记号。在东方，亲嘴或是同辈之间friendship友爱的表示，或是下位者敬重顺服的表示。百姓亲吻他们神像的偶像，也亲吻君王的手。在初期教会中，基督徒相遇时的习惯便是亲嘴；在他们的聚会中，尤其在领受主的晚餐之后，彼此交换这基督徒弟兄之情的记号。此处保罗似乎是请求：当他的书信在众人面前诵读之时，教会的成员当彼此授予这相互饶恕与相爱的凭据。

**21.** <span style="color:#800000">*我保罗亲笔问安。*</span>

保罗通常口授而由代笔者书写，故他惯于亲手写下书信末尾的几句话，作为真确的凭证（歌罗西书 4:18；帖撒罗尼迦后书 3:17）。在加拉太书 6:11，他特意提到那封书信乃是亲手所写，视之为不寻常之举，也表明其中含着格外深切的情感。

**22.** <span style="color:#800000">*若有人不爱主耶稣基督，这人可诅可咒。主必要来！*</span>

<!-- PAGE 397 -->
这一句以及随后的话，是保罗亲笔所写。这些话无需解释，其可畏的分量自会临到每一颗心。<span style="color:#800000">*若有人不爱主耶稣基督。*</span>倘若我们的主是"在万有之上，永远可称颂的神"，那么不爱他，就是干犯了我们全部的本分。倘若他不但是真神，更是为拯救我们而成了肉身显现的神；倘若他一身兼具一切属神的与属人的美善；倘若他如此爱我们，以致将我们的性情与他自己联合，又降卑自己，存心顺服以至于死，且死在十字架上，为叫我们不至灭亡，反得永生；那么，我们若不爱他，我们自己的良心也必承认：这咒诅即便临到我们自己身上，也是公义的。我们必觉得，在这种光景中，我们理当被<span style="color:#800000">*咒诅*</span>。不，我们已然是被咒诅之物；圣洁既必然与罪为敌，我们也就必然成为一切圣者所憎恶、所厌弃的对象。<span style="color:#800000">*主必要来*</span>乃是两个亚兰文的词，意思是"主"，或"我们的主来了"。这是一句严肃的警告。人所不肯承认、不肯爱的那位主，即将在他父的荣耀里，同着他一切的圣天使降临，要报应那不认识神、不听从福音的人。使徒们对基督的神性感受何等深切，对耶稣乃是神在肉身显现一事确信何等笃定，以致在他们看来，人若不肯或不能如此认他，便是被弃绝的记号。他们说，这真理若是遮蔽了，就是遮蔽在灭亡的人身上（哥林多后书 4:3-6）。

**23.** <span style="color:#800000">*愿我们主耶稣基督的恩常与你们同在。*</span>

正如被咒诅而与基督隔绝、作他咒诅的对象即是永远的沉沦；照样，得他的恩眷便是永生。「愿他的爱与你们同在」，这是为一切美善所作的祈求。

**24.** <span style="color:#800000">*我在基督耶稣里的爱与你们众人同在。阿们。*</span>

“我在基督里的爱”即我基督徒的爱。保罗在结尾处向他们众人保证——向哥林多所有的信徒，甚至包括那些他不得不加以责备的人——他的爱是真诚的。
